## A5 봉인 근거

143파일에는 `A5_SHA256SUMS` 자체와 그 목록의 142개 파일이 들어 있다. 목록 SHA256은 `26bdbdc05ba3f6c71a0b042ebd13adb64b38271c1889a894898a4ccf55322f1d`, 승인 진입점 `run_unload_a5_candidate.sh`의 SHA256은 `4aecae42ca5463400aee2426b45e4ed21a314381f7a779bb302ee33fa3e94d6d`이다.

독립 재확인 입력 ZIP과 1저자가 현장 사전 점검에 사용한 ZIP에서 키트 143파일 전부를 바이트 단위로 다시 대조했다. 원 키트 ZIP 753,535 B의 SHA256은 `d8074dfd86d227d80bc3188fa8817a7af7b22b333caa3c22292ce62b10650920`이다. 기존 ZIP을 그대로 넣고 바깥에 날짜·저자 결정·목록과 진입점 지문을 붙여 보관용 봉인본을 만들었다. 원 키트 안의 생산 코드·덱·역사 자료는 그대로다.

A5R-01 독립 한정 종결 근거는 `docs/reviews/p1_rt_a5r01_closure_20261120/RECEIPT.md`, 현장 사전 점검(rc0·A3 원위치 45파일 및 20검사·A4 현재 입력 3개)의 원 반환은 `docs/reviews/nonrint_returns_cd_20261120/a5/author_receipt.json`이다. 당시 영수증의 발사 승인값 false는 당시 사실로 보존한다. 오늘 발행한 것은 지정 키트·진입점의 운영 봉인이다. 현장 배포·새 RJ 발사·재시도·후속 팔은 승인 대기다.

기존 Slurm 래퍼는 역사 소스로 남는다. 새 한 잡의 외부 호출은 A5 러너로 한정하며 입력·동시 실행 검사, NP6, 새 시도 기록과 기존 산출물 보존을 유지한다. 복원에는 별도 이력 원판정이 필요하고, 발사 시에는 같은 신원을 다시 확인해야 한다.
