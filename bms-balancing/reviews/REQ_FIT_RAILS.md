## 1. 확인된 출력 관계 (37 행 전수, 실측)

각 파일의 cycle 0 을 자체 기준으로:

```
x_cell = C_cell / C_cell₀
LAM_PE = 1 − x_cell · a_PE/a_PE₀        LAM_NE = 1 − x_cell · a_NE/a_NE₀
LLI    = 1 − c_lit/c_lit₀
c_lit  = C_cell · (a_PE + b_PE − b_NE)          ← 1차 리뷰가 찾았다
  ⟹  LLI = 1 − x_cell · s/s₀ ,  s = a_PE + b_PE − b_NE
```

최대 절대오차: `x_cell` 0 · `LAM_PE` 2.567e-16 · `LAM_NE` 1.596e-16 · `LLI` 5.551e-17 ·
**`c_lit` 0.000e+00** (네 파일 전부).

**따라서 세 "열화모드" 는 전부 `(C_cell, a_PE, b_PE, a_NE, b_NE)` 의 후처리다.**
LLI 도 예외가 아니다 — 다만 용량 감소율과는 **다르다** (§2-1).

> **주의**: "실제로 적합한 변수는 다섯 개" 라고 말할 수 없다. `c_lit` 이 β 에서 유도됐는지,
> 반대로 β 가 `c_lit` 에서 유도됐는지, 제약으로 묶였는지는 결과 파일로 못 가른다.
> 후처리라는 사실 자체는 결함이 아니다.

### 2-1. LLI 는 용량 감소율과 다르다 (v1 의 가장 큰 오류)

기준행(각 파일 cycle 0, 세 손실이 정의상 0) 제외 **33 행 전부**에서 `LLI ≠ 1 − x_cell`:

| | 값 |
|---|---|
| atol 1e-12 로 일치하는 행 | **0 / 33** |

| 가장 짧은 반례 (ref1 cycle 3) | LAM_PE = LAM_NE = **3.6633 %** · LLI = **5.8185 %** (차 2.1551 %p) |

### 2-2. α 의 반복값

| 파일 | `a_PE` 가 cycle-0 값과 비트 동일 (기준행 포함 / 제외) | `a_NE` | `LAM_PE ≈ LAM_NE` |
|---|---|---|---|
| ref1 | 8/10 / 7/9 | 파일 내부 일정 (= 1) | 8/10 |
| ref2 | 6/10 / 5/9 | 파일 내부 일정 (= 1.020080608741945) | 6/10 |
| PE1 | 9/10 / 8/9 | 파일 내부 일정 (= 1.0240193955979178) | 9/10 |
| PE5 | 7/7 / 6/6 | 파일 내부 일정 (= 1) | 7/7 |
| **합계** | **30/37 / 26/33** | 전체 **세 값** (파일 간에는 다르다) | |

`a_PE` 는 네 파일 모두 cycle-0 값을 넘지 않는다 (argmax = cycle 0). 다만 **동률 최댓값 중
첫 행일 수 있고**, 유일한 최댓값이나 optimizer bound 를 뜻하지 않는다.

`b_NE` 는 기준행 외에서 0 이다 — 단 **정확히 0 이 아닌 곳이 둘** 있다:
ref1 cycle 8 `−2.1778531752142977e-17`, PE5 cycle 4 `−1.762553861534616e-16`.
"exact 0" 과 "|·| < 1e-15" 는 구분해서 다뤄야 한다.

`a_PE` 가 cycle-0 값과 같은 행에서는 `a_PE/a_PE₀ = 1` 이므로 `LAM_PE = LAM_NE = 1 − x_cell`
이 된다. **두 LAM 출력이 같아진다는 것까지가 관측이다.**

### 3-1. α 좌표 — "전극용량 증가 금지" 와 `α_k ≤ α₀` 는 다르다

문헌 좌표(`x_full = α·x_e + β`, Schmitt et al. 2022 §3.1 식 (2)–(12))에서 α 는 **절대
전극용량이 아니라 셀용량 대비 비율**이다: `C_e = C_cell × α`.

반례 (실측 재현):

| | 기준 | 열화 후 |
|---|---:|---:|
| 셀용량 | 1 | 0.9 |
| PE 용량 | 1.1 | **1.1 (불변)** |
| α_PE = PE/셀 | 1.1 | **1.2222…** |
| LAM_PE | 0 | **0** |

전극용량이 전혀 안 늘었는데 α 는 초기값보다 크다. 따라서

```
전극용량 증가 금지  ⟺  α_k ≤ α₀ / x_cell,k        (약한 제약)
α_k ≤ α₀            ⟹  LAM_PE ≥ 1 − x_cell        (강한 제약)
```

후자는 "셀용량이 줄면 PE 도 **적어도 그 비율만큼** 줄었다" 를 강제한다.
실데이터는 `LAM_PE ≥ 1−x_cell` 을 **33/33 만족**한다 (최소 여유 −1.1e-16 = 수치오차) —
관측이 그 제약과 **일치**하지만, 그것이 제약의 **존재 증거는 아니다.**

## 5. 재현

```python
import pandas as pd, numpy as np
d = pd.read_excel('result_L_ref1__0.1C_12h__charge.xlsx')
x = d.C_cell / d.C_cell.iloc[0]
s = d.a_PE + d.b_PE - d.b_NE
for lbl, err in (('x_cell', d.x_cell - x),
                 ('LAM_PE', d.LAM_PE - (1 - x*d.a_PE/d.a_PE.iloc[0])),
                 ('LAM_NE', d.LAM_NE - (1 - x*d.a_NE/d.a_NE.iloc[0])),
                 ('LLI',    d.LLI    - (1 - d.c_lit/d.c_lit.iloc[0])),
                 ('c_lit',  d.c_lit  - d.C_cell*s)):
    print(f'{lbl:7s} max|err| = {np.abs(err).max():.3e}')
post = slice(1, None)
print('LLI == 1-x_cell (atol 1e-12), 기준행 제외:',
      int(np.isclose(d.LLI[post], (1-x)[post], atol=1e-12, rtol=0).sum()), '/', len(d)-1)
print('LLI-(1-x_cell) 범위(기준행 제외):', float((d.LLI-(1-x))[post].min()), '~', float((d.LLI-(1-x))[post].max()))
print('a_PE 반복(기준행 포함/제외):', int((d.a_PE.values==d.a_PE.iloc[0]).sum()), '/',
      int((d.a_PE.values[1:]==d.a_PE.iloc[0]).sum()))
print('b_NE 정확히 0 아닌 미세값:', [(int(c), v) for c, v in zip(d.cycle, d.b_NE) if v != 0 and abs(v) < 1e-14])
```
