### 1. P-2 (550 K) β 오차막대 (Q8-①)

시간원점 블록 부트스트랩 (`msd_diffusive_check.py --beta_boot` · 창 2–50 ps · 공통원점 행렬 원점 2000 · lag 150 · 블록 사다리 1–32 · n_boot 2000 · b = plateau 최소, BU 규칙).

| 양 | 550 K | 400 K (참고) |
|---|---|---|
| β · 카드 곡선 (STO, `msd_Li_A2`) | **0.805** (0.8047) | 0.641 |
| β · 다중 원점 (MTO, 정본) | 0.856 | 0.562 |
| β · 공통원점 행렬 평균 | 0.879 | 0.624 |
| **σ(β)** (b = 12) | **0.010** | 0.016 |
| 68 % 구간 (행렬) | 0.869–0.889 | 0.608–0.640 |
| 0.8 과의 거리 / σ | STO +0.0047 = **0.46σ** · MTO +0.056 = 5.4σ | −9.9σ |

- 회신 CC 의 폭 규칙(0.005)으로 STO 0.805 는 **"경계 · 구분 불가"** 입니다. 400 K 의 미통과는 오차 안에서 확실합니다.
- σ(b) 사다리가 b = 32 까지 단조 증가(550 K: 0.0032 → 0.0166)라 도구가 "사다리 성김 · 1 간격 재확인" 을 붙였습니다. σ 0.010 은 **하한**으로 읽어야 합니다 (상관시간이 길다는 신호).
- **Q-CC-1**: 카드 §5 C2 는 "β = d log MSD / d log t 가 0.8–1.2" 라고만 적고 STO/MTO 를 안 박았습니다. 파일럿 판독은 도구 기본값(STO)이었고, 추정자에 따라 P-2 가 경계/통과로 갈립니다. **본 런 전에 하나로 정해 주십시오** — 우리는 제안하지 않고 둘 다 보고합니다. σ 는 MTO 추정자의 것이고 STO 산포의 하한입니다.
