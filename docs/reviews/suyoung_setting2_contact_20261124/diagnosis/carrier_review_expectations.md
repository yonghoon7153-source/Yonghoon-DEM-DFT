# 물질면 기준 운반자 재구성 · 독립 합성 점검의 기대

1. 한쪽에만 물질점이 있는 바닥 표지에서도 일정 속도와 임의의 비대칭 선형 속도장을 정확히 재현한다. 가중치의 합과 격자 위치 일차 모멘트를 직접 계산한다. 개별 APIC 외삽 계수가 음수인 경우도 허용하되 표지 속도, 운동량 수지와 정지판의 운동에너지 감소를 직접 대조한다.
2. 같은 물체의 물질점 행을 임의로 섞어도 물리 좌표가 같은 표지 궤적과 판 충격량이 수치 정밀도 내에 일치해야 한다. 같은 위치에 다른 물체 물질점이 있어도 힘이나 표지 운반을 나눠 갖지 않아야 한다.
3. 판에서 멀어지거나 닿기 전 남은 간격을 이 걸음에 못 닫는 경우에는 충격량 0, 하중 작용 시 양수가 기대된다. 한 행에서는 정확 해 J = max(0,ℓ−Nv)/Σ(Nᵢ²/mᵢ)이다. 투영 후 판 표지 수직속도와 입자 G2P 운동량 변화도 대조한다. 지지점이 사라지면 물리적 근거 없는 무제한 탐색 대신 명시적으로 거부한다.
4. 실제 입력 네 격자의 표지·운반자 매핑 생성 비용·표지당 운반자 수를 확인한다. 승인 없는 완주·재실행 없이 기하 초기화 혹은 합성 상태 소수 단계만 허용한다. 기존 평판의 균일·선형 깊이 응력 대조를 묶인 판독기로 재생할 수 있으면 판 수지와 민감도를 보고한다. 새 운반자에서 이산 해가 달라질 수 있으므로 옛 수치를 새 정답으로 사용하지 않는다.
