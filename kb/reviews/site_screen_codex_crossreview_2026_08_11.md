## 요청 사항

너희 `tools/sdcp/ptfe_linio2_uma/` 패키지와 **같은 질문에 대한 독립 구현**을 만들었다.
같은 슬랩·같은 PTFE 조각(sha256 동일)을 쓰되, SDCP 2종을 추가하고 우리 쪽 사고 이력에서
나온 게이트를 더 넣었다. 아래 3가지를 봐 줬으면 한다.

1. **반박** — 우리 게이트/판정 규칙이 틀렸거나 지나치거나 모자란 곳
2. **누락** — 너희가 이미 막아 둔 실패 모드 중 우리가 안 막은 것
3. **이식 대상 확정** — 우리가 가져가야 할 너희 구성요소, 너희가 가져갈 만한 우리 구성요소

## 1. 이미 확인된 일치점 (독립 구현끼리)

| 항목 | 결과 |
|---|---|
| 슬랩 sha256 | `26a48473060243fe…` — **바이트 동일** (`db/structures/linio2_104_sym_1x4L4_relaxed.vasp` = 너희 `inputs/linio2_104_1x4_relaxed.vasp`) |
| PTFE 조각 sha256 | dimer `dcc0f678…` · C10 `66dd0bcc…` — **동일** |
| `Li_top` 앵커 | 우리 (8.357, 4.290, 18.277) = 너희 값 |
| `Ni_top` 앵커 | 우리 (4.832, 6.152, 18.307) = 너희 값 |
| `O_top` 앵커 | 우리 (6.496, 5.188, 18.344) = 너희 값 |
| 표면 자리 등가성 | 대표 1개로 충분 — 아래 §2 |
| C10 면내 이미지 문제 | 너희: azimuth 를 15/60/165° 로 축소 / 우리: 이미지 게이트가 **112건 자동 탈락**. 같은 현상을 다른 경로로 발견 |

브리지/hollow 앵커만 다르다 — 대표 쌍 선택 규칙이 달라서다(둘 다 유효, 우열 없음).

## 2. 표면 자리 등가성 — 너희 `central_atom` 단일 선택의 정당성

허용오차를 바꿔가며 표면 원자를 국소환경으로 군집화한 결과:

| 원소 | 표면 수 | z 편차 | 최근접결합 편차 | 군집수 @0.02/0.05/0.10/0.20 Å |
|---|---|---|---|---|
| Li | 12 | 0.010 Å | 0.012 Å | 3 / 2 / 3 / 1 |
| Ni | 12 | 0.010 Å | 0.001 Å | 2 / 3 / 2 / 1 |
| O | 24 | 0.022 Å | 0.015 Å | 3 / 4 / 3 / 2 |

군집수가 허용오차에 따라 **요동친다** = 수치잡음 과분할이지 비등가가 아니다.
→ 12개 표면 Li 를 전수 열거해도 얻는 게 없다. 너희 단일 대표 선택이 맞다.
(우리도 같은 결론이라 12개 전수 열거를 버렸다.)

## 3. 우리가 추가한 것 — 반박해 주기 바라는 부분

### (a) 세로(진공 너머) 이미지 게이트 5.0 Å
우리는 2026-07 에 **티오펜 S ··· 주기 이미지 슬랩 O = 1.506 Å** "샌드위치" 자세를 UMA 챔피언으로
뽑았고, 그걸로 낸 Δ(doped−neutral) = +0.689 eV 를 **당일 철회**했다. 너희 가로 4.5 Å 는 있으나
세로 조항이 `README_KO.md` 의 "수직 이미지 거리 < 5.0 Å" 로만 서술돼 있어 우리는 이걸
**자세 생성 단계에서** 강제로 걸었다. 임계 5.0 Å 이 적절한가? 분산 컷오프(D3 ~ 6–9 Å)를 생각하면
더 커야 한다는 주장도 가능하다.

### (b) Li 추출/재구성 격리
근거: UMA freeze_frac 0.6 에서 −1.465 eV 를 "doped 가 훨씬 강하게 붙는다"로 읽었는데,
VASP+U 로 재보니 `dE_extract = +0.336 eV`(σ→0: 0.339) — **추출은 열역학적으로 불리**했다.
그래서 깨끗한 슬랩(같은 구속으로 이완) 대비 ① 표면 원자 변위 > 0.50 Å 또는 ② 슬랩 양이온이
분자 O/F/S 에 < 2.20 Å 이면 격리한다.
질문: 0.50 Å 임계가 표면 이완의 정상 범위를 잘라내지 않는가? 너희 `vasp_stage.py` 의
"top-layer extraction/reconstruction quarantine" 은 어떤 양으로 자르나?

### (c) freeze 1.0 / 0.85 이중 프로토콜
우리 `site_preference.py` 자체 경고문이 "고정 슬랩이 Ni 쪽에 불리하게 작용할 수 있다"고 적어 뒀다.
그래서 **하나를 고르지 않고 둘 다** 돌려 편향을 결과로 드러낸다.
(0.6 은 추출을 유발했으므로 배제.) 이중 프로토콜이 과한가, 아니면 셋(1.0/0.85/0.7)이 맞나?

### (d) 자세 표본화 — 피보나치 12방향 × roll 4
너희는 azimuth 3 × roll 3–4 × 시작 registry 7 이고, 우리는 **분자 프레임 피보나치 12방향** ×
roll 4 × 자리 7 = 조각당 364 자세다. azimuth 를 손으로 고르지 않고 이미지 게이트가 자르게 한다.
결과: dimer 364/364 통과, C10 252/364 (LATERAL 112 탈락), 자리별 생존 균등
(Li_top 36 = Ni_top 36) → **모든 (방향, roll) 에 대해 Li/Ni 대조쌍이 존재**.
질문: SO(3) 를 12×4 로 덮는 게 basin 다양성 보존에 충분한가? 너희 diversity 규칙과 비교해서.

### (e) 이완 대상 선정에서 Li/Ni 짝 강제 보존
점수 상위만 고르면 Ni 자세가 하나도 안 남아 자리 비교가 **조용히 사라진다**.
그래서 `shortlist_with_matched_pairs()` 가 자리별 상위 2개 ∪ 대조쌍 상위 5쌍(양쪽 다) 을 예약한다.
너희 `DFT_HANDOFF` 의 matched counterfactual 은 **rigid** 쌍인데, 우리는 **relax 단계부터** 짝을
살린다. 어느 쪽이 맞나? (rigid 쌍만 넘기면 Ni 쪽 이완 basin 을 못 본다는 게 우리 논리다.)

### (f) 판정 바닥 = max(30 meV, 쌍 편차)
너희 문서의 "approximately 30 meV practical floor" 를 그대로 쓰되, **대조쌍들의 표준편차**를
같이 넣어 둘 중 큰 쪽을 쓴다. 쌍마다 값이 흩어지면 바닥이 자동으로 올라간다.

### (g) 카이랄성 불변식 — **너희가 맞았고 우리 초안이 틀렸던 곳**
우리 `rot_align` 초안은 반평행(src ≈ −dst)에서 `−I` 를 돌려줬다. det = −1 이라 **분자가 거울상이 된다**.
SDCP 는 카이랄 중심이 있어 조용히 뒤집히면 치명적이다.
너희 `rotation_from_to`(`scan.py:329–337`)는 이미 수직축 180° 회전(`axis_angle`)으로 올바르게
처리하고 있었고, 우리는 그 방식으로 고쳤다.
추가로 우리는 자세 생성마다 **4원자 부호부피**와 **강체 조건**을 실측 검사한다 —
회전행렬이 나중에 또 바뀌어도 조용히 통과하지 못하게. 이 검사를 너희 쪽에도 권한다.

### (h) 게이트 회귀시험
`site_screen.py selftest` 가 **일부러 나쁜 구조 11개**를 만들어 각 게이트 발동을 확인한다
(충돌 / 장축을 최단 격자에 눕히기 / 진공 너머 접근 = 샌드위치 재현 / C–F 1.2 Å 인장 /
H cap 아래 / gap 6 Å 분리 / F···Li 1.8 Å / 표면 Li +1.5 Å / 반평행 정렬). 11/11 통과.
너희 `RELEASE_VALIDATION.md` 의 가짜 산출물 회귀시험과 겹치는 부분·빠진 부분을 알려 달라.

## 4. 우리가 아직 없는 것 — 이식 후보

- **basin 클러스터링** — 너희의 1×4 병진 고려 원자별 주기 RMSD ≤ 0.75 Å. 우리는 아직 없다.
  가장 먼저 가져가고 싶은 것.
- **프로토콜 지문 기반 원자적 JSON 재개** — 우리도 같은 방식을 넣었으나 너희 구현이 더 촘촘하다
  (`require_matching_record`, `validate_record_set`, 구조파일 검증).
- **VASP 단계** — `vasp_stage.py` 를 5단계에 그대로 쓸 수 있는지. 우리 SDCP 조각(S/O/H, 라디칼)
  까지 확장 가능한지.

## 5. SDCP 쪽에서 새로 정리된 사실 (너희 패키지 범위 밖)

- `sdcp_doped` = **알짜중성 doublet 라디칼**(산성 H 를 균일분해 제거). 2026-06-01 보고서의
  "anion, charge −1" 은 폐기된 기술이다. **UMA 에 다중도 입력이 없다** → doped 의 UMA 점수는
  doped 구조들 사이 순위까지만.
- 조성 `sdcp_neutral` C₁₁H₁₆O₆S₂(35) / `sdcp_doped` C₁₁H₁₅O₆S₂(34). 기체상 ORCA 기하가 repo 에
  없어 gabia 회수 대기.
- v7c **다이머**(장축 16.6 Å > 최단 면내 격자 11.51 Å)는 방향의 65%가 이미지 게이트에 걸린다 —
  불가능해서가 아니라 **표본이 편향**되므로 셀 확장 전에는 자리 판정에 쓰지 않는다.
- repo 배포 Phase-B 자세 2종을 게이트에 넣어 보니 기하는 전부 통과하나 **3.2 Å 안에 Ni 접촉이 없다**
  → "Li 자리를 선호한다"는 지금까지 **재본 적이 없다**가 정확한 서술이다.
- 출처 불일치: `db/structures/sdcp_poses_phaseB/` 는 freeze **1.0**(r90_g22 / r180_g01),
  `db/properties/sdcp_phaseB_dftu_v1.json` 의 VASP 단일점은 freeze **0.85**(r0_g20 / r180_g22).
  같이 인용 금지.

## 실행 방법 (검증하려면)

```bash
python3 tools/sdcp/site_screen.py inputs      # 입력·전자상태·인용금지 목록
python3 tools/sdcp/site_screen.py sites       # 자리 열거 + 등가성 검사
python3 tools/sdcp/site_screen.py selftest    # 게이트 회귀시험 11개
python3 tools/sdcp/site_screen.py bond-limits # 결합 임계와 실측치
python3 tools/sdcp/site_screen.py atlas --frag ptfe_c10 --out /tmp/x --dry-run
python3 tools/sdcp/site_screen.py crosscheck --codex <너희 실행 산출물 디렉터리>
```
GPU 는 `score` 단계에서만 필요하다. 위 6개는 전부 로컬에서 몇 초 안에 돈다.
