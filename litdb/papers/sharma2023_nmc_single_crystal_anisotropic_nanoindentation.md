## 1. 한 줄 요약

**단결정 NMC622 분말을 소결해 결정립을 키운 펠릿**에서, 결정립 108 개에 **Berkovich CSM 나노압입(200 nm)** 을 하고 **같은 자리의 EBSD 방위**를
짝지어 **Vlassak 이방 압입 이론**으로 **삼방정(−3m) 탄성상수 6 개**를 역산했다 (C₁₁ 194.89 · C₁₂ 133.74 · C₁₃ 11.85 · C₁₄ 8.61 · C₄₄ 74.14 ·
C₃₃ 177.24 GPa).  기저면 (0001) 압입탄성률이 **가장 크고 (172.2 GPa)** 기둥면들은 **≈127 GPa 로 서로 거의 같다**.  VRH 등방 평균은
**E 140.16 GPa · ν 0.253** — ★ **우리 DEM 의 E_AM 140 · ν_AM 0.25 와 소수 첫째 자리까지 같은 짝**이다 (단 **NMC622**).
이어서 **소결 펠릿 NMC111 · 622 · 811** (+ 선행 NMC532) 의 **M_exp · H · K_c** 를 비교했다: M **192.78 / 200.81 / 150.88 / 229.9 GPa**,
H **9.37 / 14.29 / 9.92 / 14.17 GPa**, K_c 평균 **0.162 / 0.296 / 0.258 / 0.271 MPa m^½** (111/532/622/811).  NMC622 가 가장 무르고 NMC811 이
가장 단단한 **비단조** 순서를 저자는 **가전자 밀도** (Ni 이온반경 ↔ Ni²⁺→Ni³⁺) 로 설명한다.  K_c 는 **조성 추세가 뚜렷하지 않다**.
⇒ 우리에게는 **(i) E_AM/ν_AM 짝의 유력한 원출처 (NMC622 한정어)**, **(ii) 단결정 NMC622 결정립의 K_c 평균 0.258 (NMC811 펠릿 0.271) — K_IC_AM_S 1.0 의 ≈ ¼**,
**(iii) 결정립 안 (작은 압흔) NMC 압입경도 ≈ 9–14 GPa — "3–6 GPa 문헌대" 는 이 부류로는 서지 않는다** (압흔 ≥ 결정립 부류는 `stallard2022` 카드)를 준다.

## 4. 실험 · 이론 방법 ★

### 4-1. 시료 — "단결정 분말 → 다결정 펠릿 → 결정립 단위 측정"
- 단결정 NMC622 분말 ([29]) 은 입자가 작아 (≈ 2–6 µm, 판독) 압입·EBSD 를 입자 하나에 하기 어렵다 → **볼밀로 풀어 성형·소결해 결정립을 키운다** (Fig 2).
- 소결 조건은 *"maximum grain size without significant deviation in the XRD peak positions and relative intensities"* 로 최적화 (p. 3) — 판정 근거는
  I(003)/I(104) **3.203 → 3.087** (양이온 혼합 소폭 증가 방향) 와 (104) 0.107° 이동 뿐.
- 결과 = **기공이 섞인 다결정 펠릿** (Fig 3a SEM 에 어두운 기공), 결정립 **≈ 수–10 µm** (판독).

### 4-2. 측정 순서 (p. 3)
연마(→ 0.05 µm + 이온빔) → **글러브박스 반입** → Berkovich **CSM 200 nm** (이방 M · 유효 M · H) / **cube-corner** (K_c) → **밀봉 운반** → 압입 자리의 **EBSD**.
⚠ 연마(콜로이달 실리카, 보통 수계) 가 대기 중인지는 **미기재** (측정만 불활성).

### 4-3. 이방 압입 이론 — Vlassak et al. [32] (Eq. 1–8, p. 3–4)
- 시료 = **이방 탄성 반무한체**, 하중은 경계에 수직, 접촉 **무마찰** [33], 참 접촉면적 = 주어진 깊이에서 **하중을 최대화**하는 면적 [34] (Barber 1974).
- 표면 그린함수: **B 행렬** B_js(t) = (1/8π²) ∫₀^{2π} ({mm}_js − {mn}_jk {nn}_kr⁻¹ {nm}_rs) dφ (Eq. 1), {mn}_jk = m_i C_ijkl n_l (Eq. 2),
  m = [cos φ sin θ; −cos φ cos θ; −sin φ], n = [−sin φ sin θ; sin φ cos θ; −cos φ] (Eq. 3–4).
- 단위 점하중의 표면 변위 **w(y) = h(θ)/r**, h(θ) = (1/8π²) α_k B_km⁻¹(y/|y|) α_m (Eq. 5; α = 표면 법선의 방향코사인).
- **타원 접촉** (장축 a · 단축 b · 이심률 e = √(1 − b²/a²) · 방위 φ): E(e) = ∫₀^{π/2} √(1 − e² sin²θ) dθ (Eq. 6),
  α(e, φ) = ∫₀^π h(θ + φ)/√(1 − e² cos²θ) dθ (Eq. 7).  Rayleigh–Ritz: 하중 ∝ 1/[α(e,φ)E(e)] → **곱을 최소화하는 (e, φ)** 가 참 접촉.
- **M_cal = 1 / [α(e,φ)(1 − e²)^{1/4}]** (Eq. 8) — 등방체면 E/(1−ν²) 로 돌아간다 (우리 확인).

### 4-4. 역산 알고리즘 (SI Table S1, SI p. 2 = 인쇄 20)
- 입력: **C 의 초기 추정값** (⚠ 값 미보고) · 자리별 M_exp · 자리별 Euler 각 (N = 108).
- 자리 i 마다: *"while E_r < tolerance do"* (⚠ 부등호 **거꾸로** 인쇄 — 뜻은 "허용오차보다 **클 동안**") —
  격자 제약으로 C 갱신 → 회전행렬 ℛ(φ₁, Φ, φ₂) 로 C → Cʳ → θ 0 → 2π 적분으로 B → h(θ) → α·E 최소화 → M_cal → E_r (Eq. 9) · **허용오차 0.1 %**.
- 출력: **자리마다** 한 벌의 C.  보고값 = **108 벌의 평균** (Fig 5a 검정 점).
- ⚠ 자리마다 **스칼라 1 개 (M_exp) 로 미지수 6 개**를 맞춘다 — 해가 유일하지 않다 (§8-4).

### 4-5. VRH (Eq. 10, p. 5)
B_V = (1/9)[2(C₁₁ + C₁₂) + 4C₁₃ + C₃₃] · B_R = C²/Q · G_V = (1/30)[Q + 12C₄₄ + 12C₆₆] · G_R = (5/2)C²C₄₄C₆₆ / [3B_V C₄₄C₆₆ + C²(C₄₄ + C₆₆)] ·
Q = C₁₁ + C₁₂ + 2C₃₃ − 4C₁₃ · C² = (C₁₁ + C₁₂)C₃₃ − 2C₁₃² · Hill = 산술평균 → **Y = 9BG/(3B + G) = 140.16 GPa · ν = (3B − 2G)/2(3B + G) = 0.253**.
(육방 식이라 **C₁₄ 는 안 들어간다** — 넣으면 138.6, §3-1.)

### 4-6. Oliver–Pharr M · H (SI Table S2, SI p. 3 = 인쇄 21)
- **M_exp = (1 − ν²) / [ (2β/S)·√(A_c/π) − (1 − ν_i²)/E_i ]** · **H = F/A_c** — β 1.034, S 동적강성 (CSM), A_c 용융실리카 보정 면적.
- ⚠ 이 식은 **시료 영률 E 의 꼴**이다 (1/E_r = (1−ν²)/E + (1−ν_i²)/E_i 를 E 로 푼 것).  **ν 값은 없다.**  같은 M_exp 를 K 식의 **E′ (평면변형 E/(1−ν²))** 로,
  그리고 Eq. 8 의 **압입탄성률 M_cal** 과 맞추는 표적으로 쓴다 — 셋이 동시에 맞으려면 **식에 ν = 0 을 넣었어야** 한다 (그러면 M_exp = 팁 보정한 E_r = E/(1−ν²)) (§8-1).

### 4-7. ★ 입자 처리 (우리 DEM "무질서 처리" 대응) — **이 측정이 보는 "입자" 는 무엇인가**
- **결정립 하나** (단결정 영역, ≈ 수–10 µm) 의 **국소 부피** — Berkovich 200 nm 압흔 한 변 ≈ **1.5 µm** (이상 기하, 우리 산수) · Fig S2 실측 윤곽 ≈ 2–2.5 µm.
  ⇒ **입계 · 기공 · 이차입자 구조를 보지 않는다** (NMC622 는 Fig S2 로 확인; NMC811 은 확인 불가).
  · `stallard2022` 카드의 정리 축 **A_P^½/d** (압흔 크기 ÷ 결정립 크기; < 0.1 = stage I 입내 소성, > 0.1 = 입계 파쇄 동반) 로 적으면: A_P = 24.5 h_c²
    (h_c 160–200 nm 가정) → A_P^½ ≈ 0.8–1.0 µm, d ≈ 5–10 µm → **A_P^½/d ≈ 0.08–0.2** (우리 산수) = **stage I 의 가장자리**.  "결정립 내부 값" 이지만
    입계 영향이 전혀 없다고 말할 여유는 없다.
- 스케일 사다리는 **같은 조성끼리만** 세운다 (조성이 섞이면 NMC622 150.9 < NMC532 펠릿 177.5 처럼 뒤집힌다):
  · **NMC811**: 이차입자 국소 **E 138 ± 24** ([Sedl26]) ↔ 소결 펠릿 **M 229.9 ± 40.55** (이 논문; → E ≈ 206–230, D6) — **≈ 1.5–1.67 배**.
  · **NMC532**: 이차입자 국소 **E 142.5 ± 11.3** ↔ 치밀 소결 펠릿 **E 177.5 ± 19.5** ([Xu17]) — **1.25 배**; 이 논문이 재수록한 [23] **M 200.81** 은 시료 부류 미기재.
  · **NMC622**: 결정립 **M 150.9** · C_ij → VRH **E 140.16** (이 논문만 — 이차입자 값 없음).
  ⚠ M 과 E 가 섞여 있다 — M ≈ E/(1−ν²) 로 ≈ 6–10 % 높게 나오는 양이다 (§8-1).  이차입자 **전체**의 압축 응답은 어느 논문도 안 쟀다.
- **방위**: NMC622 는 자리마다 EBSD 로 **해상** (그래서 C_ij 가 나온다).  M·H·K_c 조성 비교는 **무작위 방위 평균** — H·K 의 방위 의존은 **재지 않았다**.
- 우리 DEM 은 입자를 **등방 강체구 + 탄성 접촉**으로 본다 — 결정 방위도 결정립도 없다 → 이 논문의 이방성은 DEM 에 **"입자마다 다른 M(n)" 산포**로만 들어갈 수 있다 (§9-4).

### 7-1. E_AM 140 · ν_AM 0.25 — **"숫자는 이 논문, 부류는 NMC622 결정"**
- 우리 (140, 0.25) 는 이 논문의 **NMC622 VRH (140.16, 0.253)** 와 **E −0.10 % · ν −1.2 %** (D8).  리포에 올라온 옛 출처 (지어진 서지 · "Xu 2017 PRX") 어느 것보다
  **둘을 한꺼번에** 맞히는 짝이다 ⇒ **원출처 후보 1순위**.  그러나 입력 파일의 1.4e8 · 0.25 는 git 이력 이전 (2026-04-24 전체 임포트) 부터 있어 **확인 불가** —
  *"출처였다"* 가 아니라 *"일치한다"* 로만 쓴다.
- ⚠ **부류 교정**: `xu2017` 카드 §7-1 은 *"우리 140 = 이차입자 응집체 부류"* 라고 판정했다.  그 판정은 **NMC532/811 응집체 값 (142.5 · 138) 과의 정합**으로는 옳지만,
  같은 숫자가 **NMC622 결정립 상수의 등방 평균**이기도 하다 ⇒ **140 이라는 값만으로는 부류를 판정할 수 없다.**  NCM811 치밀체 (소결 펠릿) 부류는 이 논문 기준
  **≈ 206–230** (D6 — 방위 평균 · M/E 정의 모호 · 결정립 내부인지 미확인) 이다.
- 판정: **AM_P = 140 유지** (출처 [Sedl26] · [Xu17]) · **AM_S = 140 은 "Assumed (= AM_P)"** — NCM811 치밀체 기준으로는 ≈ 1.5× 부드럽다.  AM_S 에 NCM811 치밀체 값을
  넣을지는 **감도 팔 {140, 215}** 을 먼저 보고 1저자가 정한다 (압밀·σ_ion 영향 ≈ 0, AM_S 파괴 분류에 P_c × 0.65).

### 7-2. ν_AM 0.25 — **라벨만 바꾸면 되는 항목**
- 값 0.25 는 이 논문의 **0.253** (NMC622, 적합 C_ij 의 VRH) 로 방어된다.  Hertz 가 보는 E/(1−ν²) 에서 ν 의 몫은 0.25 ↔ 0.253 사이 **0.1 %** — 수치 영향 없음.
- 한정어: **측정이 아니라 계산값**이고, 그 C_ij 가 **비유일 적합**이다 (§8-4).  작업 브랜치의 *"(Xu 2017)"* · *"(ceramic)"* 표기를 이 출처로 교체 (§9-1).
- 같은 날 정본에 들어온 `stallard2022` 카드 §0-2 는 *"ν_AM 출처 없음 유지"* 로 판정했다 (그 리뷰엔 ν 값이 없다) — **이 카드가 그 빈칸의 첫 원문 후보**다.
  그 카드가 남긴 포인터 (`so2022_dem_compaction_coated_particles_assb` 가 ν_AM 0.25 를 **Cheng [37]** — NMC333 hot-pressed, 이 논문의 [26] 과 같은 논문일 가능성 — 에
  귀속) 는 **두 번째 후보** (원문 미확인).  둘 중 어느 것이 우리 0.25 의 뿌리인지는 리포 이력으로 가릴 수 없다.

### 7-3. K_IC — **AM_S 1.0 은 이 논문과 ≈ 4 배 어긋난다**
- 이 논문의 NMC622 인성은 **단결정 결정립 안**에서 잰 값이다 (SI Fig S1: *"NMC622 single crystals"*) — 평균 **0.258** · NMC811 소결 펠릿 **0.271** · 중앙값 0.21–0.22 (판독).

  우리 AM_S 1.0 은 그 **3.7–3.9×** (중앙값 대비 4.5–4.7×).  **1.0 을 뒷받침하는 값은 이 논문에 없다** — 채택 h_min 100 nm 에서 가장 큰 개별값이 ≈ 0.65
  (Fig 6d · S1), h_min 을 150 nm 로 올려도 ≈ 0.8 (판독).
  (LiCoO₂ 의 0.2–6.5 [43] 는 **2차 인용 · 다른 소재**라 근거가 못 된다.)
- 바꾸면 AM_S–AM_S **P_c × 0.067–0.073 (1/14–1/15)** · δ_c × 0.16–0.18 (D9) — 혼합쌍 (기하평균) 은 0.548 → ≈ 0.28.  `fracture_aware_excluded_pct` (σ_ionic T1 β_F) ·
  `frac_severe_force_pct` (σ_e 22.5 β_Fe) 가 걸려 있어 **분류 재실행 + 두 폼 재적합** = **1저자 결정** (Xu 카드 §7-3 과 같은 처방).
- ⚠ **방법이 다르다** — 이 논문은 **예리한 압자 + pop-in 추정 균열길이**, 우리 Auerbach 는 **구–구 헤르츠 원뿔균열**.  그리고 K 가 **h_min 하나로 ±30–40 %** 움직인다 (Fig S1).

  논거가 사라진다.  그 모듈 자신의 등록 규칙 (*"역산값이 그 밴드 밖이면 모델이 틀린 것"*) 에 문헌 H 를 넣으면 **역산 3.83 은 기각**된다 — 1저자 판단.
- 두께 예측 자체는 H_AM 에 둔감 (VACUOUS 기록) → **숫자 재계산은 불요**, 흔들리는 것은 **판정 문장 · 사전등록 밴드**.

### 7-5. frame [5] 로 본 자리
- 이 논문은 **DEM 도 MPM 도 아니다** — 두 모델의 **AM 재료 입력** 원전이다.  DEM 쪽: AM–AM 접촉의 **E·ν** (압밀 영향 작음) + 파괴 분류의 **K_IC** (영향 큼) +
  하중분담 모델의 **H_AM** (판정 문장).  MPM 쪽: AM 은 얼린 scaffold → **영향 0**.
- 가진 반쪽: **결정 한 알의 탄성 이방성 (NMC622) · 소결 펠릿의 H · K (NMC622 는 결정립 내부)**.  없는 반쪽: **입계 · 이차입자 · 전극** (접촉망 · 압밀 · 수송) — 전부 우리 쪽 (또는 [Sedl26] · [Xu17] 의 층).

## 8. ★★ 비판적 검토 — 원고에 옮기기 전 확인할 것 (내부 불일치 · 재현 불가 지점)

1. **M_exp 의 정의가 세 갈래다** — SI Table S2 식은 분자 **(1 − ν²)** = **시료 영률 E** 꼴인데 (ν 값 없음), 같은 표는 M_exp 를 **평면변형 E′** 로 K 식에 넣고,
   본문은 Vlassak **압입탄성률 M_cal** (등방이면 E/(1−ν²)) 과 맞춘다.  **우리 산수 D5** (VRH E/(1−ν²) = 149.7 ≈ 평균 M_exp 151.8) 는 역산이 M_exp 를
   **압입탄성률로 다뤘다**는 쪽을 지지한다 ⇒ **230 GPa 를 "NMC811 영률" 로 인용하지 말 것** — 최대 (1−ν²) ≈ 6–10 % 차의 **정의 모호 값**이다.
2. **NMC622 M_exp 가 두 벌이다** — p. 5 **151.81 ± 23.74** (EBSD 연계 108 자리) ↔ Fig 6a **150.88 ± 58.35** (N = 80).  평균은 같고 **산포가 2.5 배** 다르다.
   같은 자료인지 · 다른 캠페인인지 **미기재**.  (판독 IQR 31 GPa 는 ±23.74 쪽과 어울린다.)
3. **± 정의 없음 · K 의 ± 와 N 없음** — §0.  K 는 NMC622 의 N = 174 (SI Fig S1) 만 안다 — 그런데 그 S1 의 h_min = 100 nm 정규곡선 봉우리 (≈ 0.23, 판독) 가
   Fig 6d 의 NMC622 평균 **0.258** 과 다르다 (중앙값 0.212 와는 가깝다).  정규곡선이 평균에 놓였다면 **두 그림이 같은 자료가 아니거나**, 곡선이 다른 통계로 그려졌다 — 미기재.
4. **역산이 유일하지 않다** — 자리마다 **방정식 1 개 (M_exp) 에 미지수 6 개**, **초기 추정값 미보고**, 허용오차 0.1 % 에 닿는 즉시 멈춘다.  Fig 5a 에서 **C₁₁·C₁₂ 만
   크게 흩어지고 C₃₃ 상자는 ≲ 1 GPa 로 뭉친 것** (판독) 은 "알고리즘이 주로 C₁₁·C₁₂ 를 움직였다" 와 정합한다 ⇒ **C₁₃ · C₁₄ · C₃₃ · C₄₄ 는 초기값에 가까울 수 있다.**
   잘 정의된 판은 **108 쌍 (M_exp, 방위) 전체에 C_ij 한 벌을 최소제곱으로 맞추는 것**인데, 그것은 하지 않았다 (또는 보고하지 않았다).  초록의 *"fully determine the stiffness matrix"* 는 과장.
5. **그 결과가 층상 산화물 통념과 반대 방향이다** — 적합 C_ij 로 방향 영률을 계산하면 **c축 176 > 기저면 내 100** (D3).  C₁₂/C₁₁ = 0.69 · C₁₃/C₁₂ = 0.09 라는 특이한
   비율이 만든 결과다.  비교: [Sedl26] 이 전하는 제일원리 NMC811 결정값은 **면내 249 · 면외 210 GPa** (Min & Cho 2018 — **2차 인용**) 로 **면내 > 면외** 다.
   ⇒ **이 C_ij 로 방향 강성을 모델에 넣지 말 것** (방위 평균 E·ν 만 쓴다).  저자의 Bi₂Te₃ 유비 (*"weak bonding along the c-axis … smaller elastic constant"*) 는
   C₃₃ < C₁₁ 과는 맞지만 **c 방향 압입탄성률이 최대**라는 자기 결과와는 어긋난다.
6. **VRH 식이 C₁₄ 를 버린다** — 영향 −1.1 % (D2).  무시 가능하지만 "삼방정" 이라 적고 육방 식을 쓴 셈.
7. **Table S1 부등호 오기** — *"while E_r < tolerance do"* (의도는 >).  본문 오기: *"Fig. 6c range from 0.05 to 0.65"* (K 는 6d) · *"elsatic"* · Fig 2c 축 *"Furnance"*.
8. **조성 비교가 통제된 실험이 아니다** — 622 = 단결정 분말 소결체 (EBSD·결정립 확인), 111·811 = **이력 미상 소결체** (XRD 만), 532 = **선행 논문 재수록** (N 25, 시료 부류
   미기재).  M 의 **비단조 (622 최저, 811 최고)** 를 가전자 밀도로 설명하지만, 시료 차 (밀도·결정립·양이온 혼합) 를 배제하지 못한다.  NMC811 을 대기 880 °C 급으로
   소결했다면 Li 손실·양이온 혼합이 걸리는데 조건 자체가 없다.
9. **K 법의 가정 위반 신호** — cube-corner 압흔 둘레 **전단띠** (Fig S3) = 소성 → pop-in LEFM 식 (α · Q 경험상수) 의 전제 약화.  저자도 *"generating ideal radial cracks is
   challenging"* 이라 인정하나 **제외·보정하지 않았다**.  E′·H 에 **조성 평균**을 넣어 **자리별 이방성**을 무시한다.  균열 형상 가정도 본문 half-penny ↔ SI penny 로 갈린다.
10. **K 가 분석 인자에 1차로 민감** — h_min 50 → 150 nm 에 봉우리 0.20 → 0.32 (+55 %, 판독).  100 nm 선택 근거는 "50 은 너무 많이 버리고 150 은 더 퍼진다" 뿐.
11. **"h_min = 50 nm 가 시험을 더 많이 버린다" 의 논리가 설명되지 않는다** — h_min 이 작을수록 셀 수 있는 pop-in 이 **늘어야** 할 것 같은데 반대로 적혀 있다 (기준곡선
    적합 구간이 짧아진 탓으로 추정 — 미기재).
12. **데이터 비공개** ("on request") · **역산 코드 비공개** · **초기값·갱신 규칙 미보고** ⇒ C_ij **재현 불가**.

## 9. 적용 인사이트 — 우리 연구에 어떻게

1. **E_AM · ν_AM 의 라벨을 둘로 쪼갠다** (값은 그대로):
   AM_P 140 = *"consistent with nanoindentation of polycrystalline NMC811 secondary particles, 138 ± 24 GPa [Sedl26] (NMC532: 142.5 ± 11.3 [Xu17])"* ·
   AM_S 140 = *"Assumed equal to AM_P; numerically equal to the VRH average of indentation-derived NMC622 single-crystal constants (140.16 GPa, ν 0.253) [Sharma 2023];
   the orientation-averaged indentation modulus of sintered NMC811 pellets is 229.9 ± 40.55 GPa [Sharma 2023]"* · ν 0.25 = *"≈ 0.253 (VRH, NMC622) [Sharma 2023]"*.
2. **K_IC 두 값은 원문 앵커가 생겼다 — 그러나 교체는 등록부터**: AM_S 후보 **0.26–0.27** (이 논문 결정립 평균) · AM_P 후보 **0.10** ([Xu17] 이차입자 계면).
   두 값 모두 **같은 그룹 · 같은 pop-in 법**이라 비 (2.5–2.7) 가 교차-실험실 비보다 믿을 만하다.  권고: **{AM_S 1.0 ↔ 0.26} × {AM_P 0.3 ↔ 0.10} 감도 팔을 사전등록**하고
   `fracture_aware_excluded_pct` · `frac_severe_force_pct` 가 얼마나 움직이는지 본 뒤 생산값을 정한다.  ⚠ `wheatcroft2023` 카드 §7.3: 우리 식에 **실측 입자 분할 하중**을
   대면 유효 K 가 **0.21–0.37** 로 나온다 — K 만 단독으로 내리면 그 실측과 충돌하므로 **A_AUERBACH (200) · Lawn 배수와 함께 재보정**하는 등록 절차 뒤에만 바꾼다.  원고 `paper_brittle_caveat.md` 의 *"K 비 3.3 → P_c 11×"* 는
   **"문헌 2.5–2.7 → 6.4–7.1×"** 로 바꾸거나 한정어를 단다.
3. **H_AM "문헌대 3–6" 을 스케일 명시 구간으로 다시 등록** — 작은 압흔 H (소결 펠릿 9.4–14.3 · 이차입자 8.6) = **상한** · 압흔 ≥ 결정립 부류 (`stallard2022` 의
   NMC532 3.2–5.5, 2차) · 입자 파괴 명목 접촉압 (`wheatcroft2023` 의 NMC811 H_f 3.6 ± 0.9) = **밴드와 겹치는 두 부류** · 입자 압축 강도 (`jung2023` 의 SC 973 / PC 113 MPa 급 — **다른 양**) = **하한** 쪽.  역산값은 **어느 부류에 대한 판정인지**
   런 전에 적고 비교하거나, 판정 없이 서술만 한다 (Xu · Sedl · Stallard 카드와 같은 결론).
4. **탄성 이방성은 넣지 말 것 (지금은)** — 이 논문의 C_ij 는 방향 부호가 의심스럽다 (§8-5).  DEM 에 입자별 M(n) 산포를 넣고 싶다면 **±15 % (127–172)** 라는 **크기**만
   빌리고, 방향은 제일원리 C_ij 원문 (예: [Sedl26] 이 인용한 Min & Cho 2018 — **미확인**) 을 먼저 digest 한다.
5. **AM_S 가 "결정립 부류" 라는 사실이 AM_S/AM_P 비대칭의 올바른 근거다** — AM_S 입자 (Fig 1c 와 같은 2–6 µm 단결정) 는 이 논문의 결정립과 같은 물체이고,
   AM_P 는 [Sedl26]·[Xu17] 의 응집체다.  ⇒ E 는 **AM_S ≳ AM_P** (≈ 1.5× — NMC811 펠릿 M 229.9 → E ≈ 206–230 vs 이차입자 138, 정의 모호 한정어),
   K 는 **AM_S > AM_P** (≈ 2.6× — NMC622 결정립 0.258 vs NMC532 이차입자 계면 0.102, 조성 다름) 가 문헌 방향이다 — 우리 코드는 E 를 같게, K 를 3.3× 로 두고 있다.
6. **G_c 서열 갱신** — NMC 이차입자 입계 ≈ 0.07 ([Xu17]) < NMC811 펠릿 ≈ 0.32 · NMC622 결정립 ≈ 0.44 (이 논문, K²/M) ≈ 치밀 NMC532 ≈ 0.49 ([Xu17]) ≪ 황화물 SE ≈ 2.8
   (`bucci2017`).  (방법이 다른 값의 비 — 자릿수만.)

### 10-1. 저자가 밝힌 것
- 경도 추세 해석은 전위·슬립계 정보 부족으로 어렵다 (p. 6).
- cube-corner 로 **이상적 방사형 균열**을 만들기 어렵고 **전단띠**가 생긴다 (p. 6, Fig S3).  K 에 조성 추세가 보이지 않는다.

### 10-2. 우리가 추가하는 것 (논문이 말하지 않은 것)
- **C_ij 는 NMC622 하나** · 역산 비유일 · 초기값 미보고 · 방향 결과가 통념과 반대 (§8-4, 8-5).
- **NMC811 은 방위 미분해 M·H·K 뿐**, 시료 이력 미상 → "단결정 NMC811" 로 인용 금지.
- **M_exp 정의 모호** (E vs E/(1−ν²)) · ν 미기재 (§8-1).
- **± · N (K) 미기재** · NMC622 자료 두 벌 · K 의 h_min 민감도.
- 펠릿 **밀도 · 결정립 크기 미보고** · 연마 분위기 미기재 · **원자료 비공개**.
- **스케일**: 결정립 내부 sub-µm 국소값 — 이차입자·전극의 유효 강성·인성이 아니다.
- **상태**: pristine 한 점 — SOC · 사이클 의존은 이 논문 밖 ([Xu17] 참조).

## 🗨️ Q&A 로그

- (2026-09-26) **Q. Sedlatschek 2026 은 이 논문 시료를 "NMC811 pellets, 230 GPa" 라 하는데 제목은 "single crystalline NMC" 다 — 어느 쪽인가?**
  → **둘 다 맞다, 다른 시료다.**  "단결정" = **NMC622** 이방성 부분 (단결정 분말 → 소결 펠릿 → 결정립마다 EBSD + 압입, 108 자리 → C_ij).  **NMC811 은 "sintered pellets" 로만**
  기술되고 (분말·조건·결정립 미보고), 230 GPa 는 그 **방위 미분해 압입탄성률 M_exp 229.9 ± 40.55 (N 80)** 이다 — 영률도 단결정 방위값도 아니다 (§0).
- (2026-09-26) **Q. 우리 E_AM 140 · ν_AM 0.25 는 어디서 왔나?**
  → 이 논문의 **NMC622 VRH 쌍 140.16 · 0.253** 과 −0.10 % · −1.2 % — 원출처 후보 1순위 (리포 이력으로는 확인 불가).  단 **NMC622 결정 부류**이고, AM_P 의 출처는
  [Sedl26] · [Xu17] 의 응집체 값 (138 · 142.5) 이다 (§7-1).
- (2026-09-26) **Q. K_IC_AM_S = 1.0 은?**  → 이 논문의 평균 **0.258 (NMC622 단결정 결정립) / 0.271 (NMC811 펠릿)** 의 3.7–3.9×.  뒷받침 없음.  교체는 감도 팔 등록 후 1저자 결정 (§7-3).
