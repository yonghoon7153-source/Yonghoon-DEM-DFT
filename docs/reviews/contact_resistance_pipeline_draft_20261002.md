### 4-2. (a) 법선 L1 보정 — 해상되는 확장 계면

- 정의: 계면 면마다 `r_face = r·(|n_x|+|n_y|+|n_z|)`. 평면이면 면 수 = A_true·L1/vox² ⇒ 총 컨덕턴스 = A_true/r 정확. 구 평균 L1 = 1.5 = 탐침의 ×1.5.
- 법선: 면 중심 국소 창 (5³) 안 A 셀 · B 셀 중심의 차 — 입자 수천 개에 지시함수 스무딩 불요. 창 크기는 시험이 정함.
- 대안 (시험 비교만): 축별 `r/|n_k|` (면마다 도약 균일). 평면에선 둘 다 정확, L1 은 [1, √3] 유계라 법선 잡음에 강함 → **L1 권고**.
- 적용 금지: r/vox < 3 곡면 · 1-셀 실 · 2-셀 구 (법선 무의미) → (b) 부류로.

### 4-3. (b) 접촉별 정규화 — 미해상 접점

- 정의: 접점 c 의 실현 면 N_c (주기 wrap 면 포함) 에 `r_face = R_c·N_c·vox²` [Ω·cm²], R_c = r/A_true 또는 R_j ⇒ N_c 면 병렬 = R_c 정확 · origin · vox 무관.
- 원장 판정 (격자 무관): AM–AM = `rasterize` 브리지 규칙과 같은 쌍 (간극 ≤ tol 0.10 µm) · 섬유 = 중심선 선분–선분 / 선분–구 거리 ≤ d_f/2(+r) + tol (② 신설).
- DEM 면적 조인: pid = `am_scaffold.csv` 행 번호 (`viz_mpm_continuum.load_am`:73 순서 보존) · CSV 에 원자 id 열이 없음 → atoms.csv 와 **위치** KDTree (선례 `dem_fracture_scaffold` — 단 허용 오차 0.5·r_med 가 아니라 CSV 자릿수 1e-6 box ≈ 1 nm) → contacts.csv (id1, id2) → LIGGGHTS contactArea (Hertz) · `film_area_from_overlap(mode='physics')`.
- 예외는 조용히 처리하지 않고 센다: **미실현** (원장 있음 · 면 0, 예 대각 접점) · **미등록 면** (면 있음 · 원장 없음 = 양자화 가짜 연결 → (a) + 표지) · **간극 접점** (브리지 됐는데 DEM δ ≤ 0 → 면적 없음, D4).
- 거부: `dilate_z ≠ 1` + DEM 면적 (기하가 DEM 이 아님) · 조인 최대 거리 > 1 nm · DEM 파일이 `input_digest` 밖.

### 5-1. 단계마다 무엇을 모델하나 — 막 vs 협착
