## 2. 질문 — 동의 · 반대를 받고 싶은 것

**Q1 — 탈락선 0.05 (절대 · MID 의 절반).**  결과 전에 정할 수 있는 근거는 MID 뿐이라 절대값으로 두었다 (seed 산포 SE 는 확인 전에 없다).  대안 = |r₁| ≤ 0.5·|d₁| (상대) — 효과 크기에 종속돼 택하지 않았다.  절대값 0.05 가 "큰 오차 탈락" 의 뜻에 맞는가, 아니면 다른 규약이 있는가.

**Q2 — 궤적 갈림.**  같은 seed 라도 E · dt 가 다르면 DEM 궤적이 갈라져 r₁ · t₁ 에 seed 간 산포 부류의 성분이 섞인다.  그래서 (a) r₁ · t₁ 을 §5 의 결정론적 상한 ε_s 로 쓰지 않고 (b) 탈락선은 총 이동에 대한 것으로 두었다.  n = 1 에서 이 검사가 "큰 오차 탈락" 으로서 여전히 뜻이 있는가 — 7차 §5-2 의 *"한 seed 의 성공은 자격화가 아니다"* 를 어긴 곳이 있으면 지적해 달라.

**Q3 — 탈락 뒤 절차.**  탈락 → E_ref ×28 (t₁ 이면 dt/2) 로 올려 재봉인 · 확인 런은 그 뒤.  이것이 Q4 ⑤ (개발 자료만 본 개정 = 개정 이력 + 재봉인 · 새 holdout 불요) 의 적용으로 맞는가.  올린 수준에서는 §4-d 를 다시 하지 않는다 (예산 · 한 번의 탈락선) — 이 "한 번" 규칙이 결과를 보고 고르는 것으로 읽힐 여지가 있는가.

**Q4 — 개발 `LC_ref` · `LH_ref` 를 8 바퀴로 연장.**  v2 의 bin 0–1 짧은 런 (§4-a′ 회전 중 계약 · 기술 스모크) 은 그 8 바퀴 런의 **앞부분**으로 같은 것을 본다 — 별도 짧은 런을 두지 않아도 되는가.

**Q5 — 저자 목적 문장 (§9).**  *"코팅의 효과를 확실하게"* 를 모체 §1-3 의 *"코팅 = AM–AM 점착 제거의 대리"* 안에서만 쓰고 *"실제 코팅 효과"* 는 금지 그대로 — 문안이 판정문 §5-3 끝의 금지 목록과 충돌하지 않는가.

**Q7 — 후행 선별의 지위 (v2.2).**  확인 뒤의 n = 1 검사는 수준을 고칠 수 없으므로 사후 강건성 검사가 된다.  탈락선을 넘으면 (a) d_ref 에 한정어 (b) ×28 재확인 = 새 캠페인 — 이 규칙이 Codex ② (확인 자료로 수준 선택 금지) 와 맞는가.  또 후행 검사 자체를 예산 허락 시 항목으로 두는 것 (7차 §5-2 권고 그대로) 에 반대가 있는가.

**Q6 — NP.**  개발 긴 런 6 을 NP 실측 (§8-3) 전에 NP 20 으로 돌려도 되는가.  r₁ · t₁ 은 개발 런끼리의 비교라 같은 NP 면 되고, 확인 18 런의 NP 는 실측 뒤 따로 정한다 (rank 증서 §8-1 은 그 NP 로).
