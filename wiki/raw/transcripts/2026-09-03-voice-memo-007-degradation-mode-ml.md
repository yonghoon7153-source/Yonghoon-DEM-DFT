## 슬라이드에 없고 구술에만 있는 것 (이 자료의 값어치)

1. **동기** (00:00) — 셀 안에서는 여러 메커니즘이 일어나지만 전기화학적으로
   확인 가능한 것은 전압·전류 신호뿐이고, 그 중간 단계로서 degradation mode
   분석이 연구되고 있다. 그런데 mode 를 재려면 **20시간 이상의 측정 + half-cell
   데이터**가 먼저 필요하다. **이 둘에 의존하지 않고** mode 를 잴 수 있으면
   진단에 유용하다. → 슬라이드 p.3 의 빨간 글씨가 이 문장이다.
2. **왜 physics-inspired 인가** (01:24) — 순수 data-driven 과 달리 도메인 지식에
   기반해 feature 를 설계하면 **학습 데이터 수가 줄고 정확도가 는다**고 알려져
   있다. → p.4 의 근거.
3. **왜 Peak2·Valley2 인가** (03:29) — ICA 는 크게 4개 feature 로 구성되는데,
   **두 번째 peak 과 valley 는 mid-SOC 에 있어 SOH 가 많이 변한 뒤에도 유지**
   된다. 그래서 이 둘을 잇는 할선의 기울기를 PVS 로 정의했다. → p.7 이 인쇄하지
   않은 **선택 이유**.
4. **peak/valley 의 전극 귀속** (05:03) — peak 은 NCM811 의 H1→M 상전이,
   valley 는 graphite stage 2 단일상 영역. 그래서 **peak 은 양극, valley 는
   음극에 더 민감한 신호**다.
5. **P2D 를 쓴 이유** (05:03~) — MJ1 셀을 그대로 모사한 P2D 모델을 만들고 각
   열화 모듈을 시뮬레이션해 모드별 PVS 변화를 확인했다. → p.8 우상 도표의 생성
   방법.
6. **SEV 검증 논리** (07:53) — pristine 과 EOL 셀 모두 SOC 별 임피던스를 재고,
   **DRT 에서 양극 charge transfer 에 해당하는 peak 만 정량 추출**해 R_ct,PE 를
   얻은 뒤, R_ct,PE 와 voltage relaxation 의 SOC 개형을 **비교**했다. pristine
   에서는 U 자 상승이 SOC 100 근처에서 늦게, EOL 에서는 두드러지게 나타난다.
   → p.10 의 논증 순서.
7. **LAM_PE → SEV ↑ 의 메커니즘** (09:15, 끊기기 직전) — LAM_PE 가 생기면
   양극 용량이 축을 따라 수축하므로 **U 자 곡선 자체가 수축**하고, 그래서 EOC
   지점의 값이 올라가 SEV 가 증가한다. → p.11 좌상 도식의 말.
