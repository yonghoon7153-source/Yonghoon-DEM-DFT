# 계산된 두 구조 — 표시용 정리본

패널 (c) 인셋용. 원본과 **원자 좌표는 같고** 표시 문제만 고쳤다.

```
python3 tools/neb_diffusion/li3n_hop_frames.py --fix_display <min.vesta> <ts.vesta> \
  --shift=-0.1819,0.3267 --outdir docs/figures/li3n/computed_fixed
```

## 왜 필요했나 (2026-08-12)

인셋 두 장의 슬랩 실루엣이 서로 달라 "더러워" 보였는데, **구조 차이가 아니라 렌더 잘림**이었다.
이완 중 원자가 셀 경계를 넘어가면 VESTA 의 `BOUND`(0~1)가 그 원자를 안 그린다:

| | 총 원자 | xy 가 [0,1) 밖 |
|---|---|---|
| min (원본) | 136 | **10개** (Li7 Li29 Li73 N3 N4 N8 N11 **N12** N16 N27) |
| TS (원본) | 136 | **9개** (N12 는 안쪽) |

서로 **다른 원자**를 잃어서 실루엣이 달라졌다. 원자 수는 둘 다 136 으로 동일.

## 고친 것

1. 분수좌표 xy 를 `[0,1)` 로 접음 → 경계 밖 **0개** (두 파일 다)
2. `BOUND` zmax 0.4 → **0.49** 로 통일 (adatom 이 z≈0.45–0.46 이라 원래 경계 밖이었고,
   결합선 덕에 겨우 보이던 상태였다)
3. 궤적 파일과 같은 평행이동 (−0.1819, +0.3267) → 세 패널의 원점이 일치
