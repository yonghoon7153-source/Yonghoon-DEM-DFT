# S와 F 공통 커널 설계 준비

## 1. 같은 것과 바뀌는 것

권고안 전제(SF1): 메모 §4 단계2의 단일 코드·희소 입자별 장 방향을 설계 계약으로 이어간다. 이번 새 코드/시험 실행0건. 실제 알고리즘과 수치 프로필 고정은 다음 구현 전 문서다.

| 구성 | S | F | 고정해야 할 것 |
|---|---|---|---|
| 물질점 소속 | 원 입자 ID 보존 | 원 입자 ID 보존 | 같은 출발 ID와 질량·재료 |
| 2D 장 할당 | 무른 원판을 장 하나에 배치 | 원판마다 독립 장, 색 재사용 없음 | 장 ID와 입자 ID 혼동 금지 |
| 공통 경로 | P2G→같은 구성식/외력/경계→접촉 단계→G2P | 같은 커널 | 접촉 단계 외의 팔별 구현 차이 금지 |
| 접촉 단계 | 장 하나면 no-op | 쌍/다물체 법칙 | 같은 장 단위 시험 U0 |
| 판과 벽 | 일방향 접촉 | 일방향 접촉 | 현재 양방향 덮어쓰기를 대조군으로만 |
| 강체 혼합 | A 팔: 강체 움직임·힘/토크 적분 | F 팔: 같은 강체 처리 | S-얼림은 판정 팔이 아님 |
| 3D 확장 | 단계4 S 코드 | 3D 자격 뒤 색칠/희소 설계 | 2D 독립 장과 3D 재사용 색칠을 섞지 않음 |

S에 명시적 입자간 접촉/분리 법칙이 없다는 것과 기하학적 분리가 불가능하다는 것은 다르다. U7은 F와 시험용 늘-붙음 F의 판별력을 확인하고 S의 관측을 합격 조건으로 미리 정하지 않는다. 원 M32P 수정의 뜻을 보존한다.

## 2. 접촉 단계의 계약

다물체 노드의 solver 방식은 아직 선택하지 않았다. 쌍별 같은 크기/반대 방향 충격량을 쓰는 방향을 후보로 두되 운동량만 맞으면 합격이라고 하지 않는다. 최종 모든 쌍 충격량을 적용한 뒤의 상대 미끄럼을 기준으로 마찰 방향과 일을 확인한다. 순차 처리 중간값을 최종 값으로 대신하지 않는다.

메모 U5(c)의 여덟 의무를 한 세트로 둔다: ①침투, ②쌍별 Coulomb/일방향·분리 충격량, ②′최종 사후 미끄럼 기준 마찰 일, ③접촉 단계 에너지 비증가, ④선/각운동량, ⑤입자·장 순열, ⑥해상도 대조, ⑦같은 장·노드의 다입자 기여 금지. 수치 허용폭·영분모·스케일·동률 규약은 등록 프로필에 있어야 한다. 벌칙 방식으로 바꾸면 에너지 기준과 등록을 먼저 개정하고 결과 뒤 바꾸지 않는다.

## 3. 시험 먼저 순서

| 묶음 | 고치기 전 실패가 필요한 작은 사례 | 보호할 정상 사례 | 통과 뒤 열리는 범위 |
|---|---|---|---|
| ID·심기 | 소속 상실·질량 손실·단위 혼용 | 입자별 양 보존 | 작은 커널 비교 준비 |
| U0 | 장 하나에서 접촉 단계가 상태/반력을 바꿈 | 같은 커널 접촉-off 동일성 | S/F 공통 경로 자격 |
| U1/U2 | 구성식/경계·경사면 음성 | 원판 하나/등록 해석해 대조 | 구성식/접촉 국소 자격 |
| U5 | 잘못된 마찰 방향·처리 순서·다물체 에너지 | 쌍별 정상 사례와 비대칭 다물체 | 다물체 국소 자격 |
| U6 | 누락된 순열·해상도·의무, 보고만 하고 통과 | 조밀 배치 전체 필수집합 | 단계3 앞 필수 문 |
| U7/U8 | 분리 꺼짐 F / 판 속도−1·노드−2 덮어쓰기 | F 국소 해제, 일방향 판 무충격 | 가압 중 해제/판 자격 |

수치 예시의 단위·허용폭은 정본/등록 프로필에서 고정한다. 시험을 아직 실행하지 않았으므로 red/green 수는0이 아니라 미실행이다. 현재 권한은 설계 준비까지이며 새로운 물리 solver의 구현/고정 핀/반박 묶음은 다음 범위로 분리한다. 3D U시험과 전체 탈압 U3/U4를 2D 문서 준비가 통과시킨 것으로 쓰지 않는다.
