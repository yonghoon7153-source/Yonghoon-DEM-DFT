# 처음 쓰는 사람을 위한 사용법

랩에 처음 온 대학원생 기준으로 씁니다. 전기화학은 알지만 이 프로그램은
처음이라고 가정합니다.

## 이게 뭘 해 주나

WonATech Smart Interface 가 남긴 `.wrd` 파일을 넣으면,

- 엑셀로 열 수 있는 CSV 로 바꿔 주고
- 충방전 프로파일(전압 vs 용량)을 그려 주고
- 질량·면적·조성을 입력하면 **mAh/g, mAh/cm²** 로 자동 환산하고
- 이 셀이 **아직 돌고 있는지 끝났는지** 판단해서 그에 맞는 사이클 값을 보고하고
- 용량이 **언제부터 급감했는지(knee)** 찾아 주고
- 여러 셀을 겹쳐서 비교하게 해 줍니다.

핵심은 **질량을 나중에 고쳐도 다시 올릴 필요가 없다**는 것입니다. 저장하는 건
계측기가 준 raw 값(mAh, V, s)뿐이고, mAh/g 는 볼 때마다 계산합니다. 저울을
다시 달았으면 숫자만 고치면 화면의 모든 값이 따라옵니다.

## 0. 켜기

터미널(WSL)에서:

```bash
bml
```

브라우저가 <http://localhost:5003> 으로 열립니다. 안 열리면 주소를 직접 치세요.
처음 한 번은 설치하느라 1~3분 걸립니다. 끌 때는 `bml stop`.

안 되면 `bml doctor` 를 먼저 돌리세요 — 무엇이 문제고 무슨 명령을 치면 되는지
알려 줍니다. 설치가 아직이면 [[bml-command]], Windows 라면 [[wsl-setup]].

## 1. 파일 올리기

**업로드** 탭 → `.wrd` 를 끌어다 놓습니다. 20 MB 파일도 몇 초면 끝납니다.

올릴 때 셀을 하나 정해야 합니다.

- **기존 셀에 연결** — 같은 실험이 `..._011.wrd`, `..._012.wrd` 로 쪼개져 있으면
  전부 같은 셀에 붙이세요. 사이클 번호는 알아서 이어집니다.
- **새 셀 만들기** — 이름만 입력하면 됩니다. 파일 이름을 그대로 쓰면 나중에
  찾기 쉽습니다 (`No_1_dry_0.0316g_13pi_80wt_0.2C_60oC` 처럼).

> 같은 파일을 두 번 올려도 괜찮습니다. 내용 해시로 판정하므로 중복 저장되지
> 않고, 이미 있는 run 을 그대로 돌려줍니다.

컷오프 전압, C-rate, 계획 사이클 수, 샘플링 주기는 **묻지 않습니다.** `.wrd`
안의 스케줄에 들어 있어서 파싱해 채웁니다. 값이 다르면 셀 화면에서 덮어쓰면
됩니다.

## 2. 질량·면적·조성 넣기

**셀 상세** 화면(라이브러리에서 셀 이름 클릭)에 넣습니다. 이걸 넣어야 mAh 가
mAh/g 로 바뀝니다.

| 넣는 곳 | 예시 | 왜 |
|---|---|---|
| 전극 총 질량 | `31.6` mg | 여기서 활물질 질량을 계산합니다 |
| 집전체 질량 | `5.0` mg | 있으면 빼고 계산합니다. 자립막이면 비워 두세요 |
| 전극 지름 | `13` mm | 면적(mAh/cm²)과 로딩(mg/cm²)이 나옵니다 |
| 조성 | `NCM811:LPSCl:VGCF:PTFE = 78:17:3:2` | 활물질 wt% 를 여기서 뽑습니다 |

### 조성을 쓰는 법

한 줄로 치면 됩니다. 이런 형태를 다 알아듣습니다:

```
80:17:3
AM:SE:VGCF = 80:17:3
NCM811:LPSCl:VGCF:PTFE 78:17:3:2
SiOx:Super P:CMC = 90:5:5
AM 80 / SE 17 / VGCF 3
```

**PTFE 가 안 들어간 조성이면 0 으로 적어도 됩니다** (`80:17:3:0`). 0 wt% 는
"안 넣었다" 는 기록이라 지우지 않고 남겨 둡니다.

**중요 — 분모에 뭐가 들어가는가.** mAh/g 의 분모는 전극 전체가 아니라
**활물질 질량만**입니다. 그래서 이름을 보고 역할을 판정합니다:

- 활물질: NCM, NCA, LFP, LCO, SiOx, Si, Gr, 흑연, LTO …
- 고체전해질: LPSCl, LGPS, LLZO, argyrodite …
- 도전재: VGCF, Super P, CNT, 케첸블랙, graphene …
- 바인더: PTFE, PVDF, SBR, CMC, PAA …

**모르는 이름은 절대 활물질로 치지 않습니다.** 조용히 분모에 들어가면 수치가
틀리는데 화면에는 아무 표시가 없기 때문입니다. 대신 못 알아봤다고 말해 주고,
그럴 땐 **활물질 함량 직접 입력**에 wt% 를 넣으면 그 값이 이깁니다.

> 조성을 적었는데 활물질을 하나도 못 알아보면 mAh/g 를 아예 계산하지 않고
> 이유를 보여 줍니다. 틀린 값을 내놓는 것보다 낫습니다.

## 3. 화면 읽는 법

### 대시보드 — 셀 한 줄씩

| 열 | 뜻 |
|---|---|
| 상태 | **구동 중** / **종료**. 그리고 왜 그렇게 판단했는지 근거를 펼쳐 볼 수 있습니다 |
| 보고 사이클 | 이 값이 몇 번 사이클 것인지 |
| 방전용량 | 위 사이클의 방전 용량 |
| 유지율 | 기준 사이클(기본 3번) 대비 % |
| 초기 쿨롱효율 | 기준 사이클의 CE |
| 스파크라인 | 유지율 추세. 점선이 급감 시작(knee) |

**왜 3번 사이클이 기준인가.** 1~2번은 formation 이라 설계상 몇 % 를 잃습니다.
그걸 열화로 세면 안 되니 3번을 기준으로 잡습니다 (ADR 0004). 셀마다 바꿀 수
있습니다.

**구동 중인 셀은 마지막 사이클을 보고하지 않습니다.** 지금 돌고 있는 사이클은
중간에 잘려 있어서 용량이 실제보다 작게 나오기 때문입니다. 그 **직전** 완료
사이클을 씁니다. 종료된 셀이면 마지막 사이클을 그대로 씁니다.

### 셀 상세 — 사이클 표와 프로파일

- 사이클 번호를 고르면 그 사이클의 충방전 프로파일이 그려집니다.
- 여러 개 고르면 겹쳐서 그려집니다.
- 단위(mAh / mAh/g / mAh/cm²)는 위에서 바꿉니다. 질량이 없으면 그 단위는
  회색으로 비활성이고, 무엇이 없어서 못 쓰는지 말해 줍니다.

### 비교 — 셀 여러 개

**비교** 탭에서 셀을 고르고 지표(방전용량 / 유지율 / 쿨롱효율 / 평균전압 …)를
고르면 한 축에 겹칩니다. 최대 30개.

경고가 뜨면 읽어 주세요. 두 가지가 있습니다:

- **단위 혼재** — 질량이 있는 셀과 없는 셀을 같이 골랐습니다. 곡선 높이를 그대로
  비교하면 안 됩니다.
- **기준 사이클 대체** — 3번 사이클이 없어서 다른 사이클을 기준으로 삼은 셀이
  있습니다. 곡선마다 100% 의 뜻이 다릅니다.

## 4. 내보내기

셀 상세 화면의 **내보내기**에서 CSV 또는 XLSX 를 받습니다.

- **사이클 표** — 사이클별 용량·효율·전압
- **프로파일** — 고른 사이클의 전압 vs 용량
- **raw** — 계측기 원본 컬럼 그대로

잘린 마지막 사이클은 기본적으로 빠집니다. 굳이 보려면 옵션으로 켤 수 있는데,
그 줄의 용량 칸은 비어서 나옵니다 — 숫자가 적혀 있으면 측정값으로 읽히기
때문입니다.

## 5. 자주 막히는 곳

**mAh/g 가 회색이고 안 눌립니다**
: 활물질 질량이 없습니다. 셀 상세에서 총 질량 + 조성(또는 활물질 wt%)을
  넣으세요. 무엇이 없는지는 그 자리에 적혀 있습니다.

**용량이 예상의 몇 배로 나옵니다**
: 분모를 확인하세요. 조성을 안 넣으면 **전극 전체**를 활물질로 가정합니다
  (그렇게 가정했다고 화면에 적혀 있습니다). 80 wt% 전극이면 값이 1.25배로
  나옵니다.

**"구동 중" 인데 실제로는 끝난 실험입니다**
: 상태 옆의 근거를 펼쳐 보세요. 판단이 틀렸으면 셀 상세에서 상태를
  `종료` 로 고정할 수 있습니다. 고정하면 그게 근거 목록의 첫 줄이 됩니다.

**사이클 번호가 이상합니다 (1부터 다시 시작)**
: 쪼개진 파일을 서로 다른 셀에 올렸을 수 있습니다. 같은 셀에 붙이면
  이어집니다. 이미 올렸으면 run 을 옮길 수 있습니다.

**knee 를 못 찾았다고 합니다**
: 4가지 기준으로 찾는데 다 해당이 없으면 못 찾았다고 말합니다. 아직 열화가
  뚜렷하지 않거나 사이클이 적으면 정상입니다 — 없는 걸 있다고 하지 않습니다.

**올린 `.wrd` 를 지우고 싶습니다**
: 셀이나 run 을 지워도 **원본 파일은 지우지 않습니다.** 일부러 그렇게 했습니다
  (계측 원본은 불변). `data/uploads/` 에 그대로 있습니다.

## 6. 데이터는 어디 있나

- `data/uploads/` — 올린 `.wrd` 원본 (내용 해시 이름)
- `data/runs/` — 파싱 캐시
- `data/workbench.db` — 셀·그룹·사이클 요약

**git 에 올라가지 않습니다.** 두 사람이 각자의 데이터를 가집니다. 같은 데이터를
보려면 공유 드라이브에 두고 가리키세요:

```bash
WORKBENCH_DATA=/srv/battery-data bml
```
