조건부 GO예요. CA의 재현된 코드 결함은 해제됐습니다. registry 명세 두 가지를 보완하고, 이미 선언한 미완료 항목을 채우면 S1 봉인으로 진행할 수 있어요. 본 계산 전체의 실행 승인은 아닙니다.
검토 기준은 `c1acd8cd021ac56402fa5ff0d17af558d73c95a5`이며, 첨부 카드 v4와 저장소 파일의 SHA256도 일치했어요. selftest 120/120 통과와 돌연변이 8종의 실패를 재현했습니다. UMA·DFT 계산이나 저장소 원본 수정은 하지 않았어요.

## Q1. 측방 마스크·인덱스 검증 — GO
CA에서 지적한 경로는 닫혔어요.

* V2 측방 마스크 생략·빈 목록은 오류로 중단합니다.
* Ag만 지정하거나, 움직인 C 원자를 제외한 부분집합을 주면 전체 흡착층 집합과 불일치하므로 거부합니다.
* 소수·불리언·중복 인덱스는 거부하고, NumPy 정수는 정상 수용합니다.
* CLI에서도 생략·소수 JSON·불리언·잘못된 몸체·부분집합은 rc 2, 정상 입력은 rc 0을 확인했어요.

관련 검사를 제거한 돌연변이도 모두 시험이 잡았습니다. 검사한 범위에서 추가 P0 우회는 재현되지 않았어요. 다만 이것이 앞으로 작성할 흡착층 빌더까지 검증했다는 뜻은 아니에요.

## Q2. G3 기록·허용 문구 — GO
`|ΔW|`, `|ΔE|` 기준과 `ΔE_far·ΔE_bound·ΔW`의 분리 기록이 CA의 요구와 맞아요.
허용 문구를 **"지정한 두 간격 변화에 대한 W 민감도 통과"**로 제한한 것도 적절합니다. 작은 ΔW를 끝점 변화의 부재나 무한분리 수렴의 증거로 확대하지 않아요. G5의 종결별 표현도 실제 판정 단위와 일치합니다.
봉인 전 추가 수정은 없습니다.

## Q3. CPU/GPU 프로브 예외 — GO, 절차 명세에 한정
CPU까지 예외 범위에 포함했고, `scf` 한정·전용 작업 및 임시 디렉터리·정지 조건·원출력 보존·에너지의 downstream 사용 금지가 명시됐어요. CA의 누락은 해소됐습니다.
다만 GPU 문구는 **"최대 2회 SCF 반복 후 종료 또는 자원 가드로 중단"**으로 쓰세요. 조기 수렴하면 두 번을 채우지 않을 수 있어요. 이는 표현 정리이며 새 P0는 아닙니다.
이번 확인은 절차 검토이지, 실제 GPU 메모리 안전성이나 종료 동작의 실기 검증은 아니에요.

## Q4. registry 주기영상·동률 — 조건부, P1 명세 보완
`x=0.1, 9.9`, 주기 길이 10인 반례는 해결됩니다. 최소영상 변위는 −0.2이고, 중점은 감은 뒤 0.0이지 5.0이 아니에요.
다만 카드 v4의 registry 규칙 (line 55)에 다음 두 가지를 명시해야 합니다.

1. 동률 집합은 전역 최단거리 기준으로 정의하세요.
먼저 `d_min`을 구하고, `d − d_min < 10⁻³ Å`인 후보들에서 원자 ID → 이미지 오프셋 사전순으로 선택하세요. 두 후보씩 "거의 같다"고 비교하는 방식은 순서 의존성이 생깁니다. 예를 들어 거리 `1.0000, 1.0008, 1.0016 Å`는 인접 쌍끼리는 동률이지만 양 끝은 동률이 아니에요.
2. `Σ \ {a}`가 비면 B 생성은 차단하세요.
표면 창을 자동으로 넓히거나 다른 registry로 대체하면 안 됩니다. 별도 대안을 원하면 봉인 전에 선언해야 해요.

기존 `10⁻³ Å`를 그대로 쓰므로 새 문턱 제안은 아닙니다. 여기서는 독립적인 수학 검산만 했으며, 아직 없는 registry 빌더의 실행 정확성을 확인한 것은 아니에요.

## Q5. S1 봉인 — 조건부 GO
봉인 전 필수 조건은 아래 네 묶음입니다.

1. 선언한 UMA 체크포인트 SHA·fairchem 버전·실제 추론 설정을 채우기.
2. 선행 배치 08–13에서 이미 본 결과를 지정한 기록에 채우기.
3. 흡착층 빌더와 registry 구현·시험을 완료하고 실제 코드 버전을 고정하기.
4. 위 Q4의 전역 최단거리 기준 동률 처리·이웃 없음 차단을 명세와 시험에 반영하기. 주기경계·정확한 동률·후보 순서 변경도 시험에 포함하기.

그 뒤 최종 내용을 기준으로 digest와 봉인을 생성하면 됩니다. 새로운 물리 계산이나 추가 문턱을 이번 해제조건으로 요구하지 않아요.
정리하면, CA 코드 차단은 해제됐고, 남은 것은 registry P1 명세 보완과 이미 인정한 S1 미완료 항목입니다. 이 조건을 채우면 S1 봉인이 가능하며, 이후 단계의 게이트까지 자동 승인되는 것은 아니에요.
