## 조건과 판독

- 합성 정사각 배열 7×7, 동일 지름 원판 49개. 이 정렬 배열은 첫 개발 입력이다. 각 원판에 할당한 기준 면적의 합은 두 해상도 모두 πD²/4, 시작 Φ_m은 0.78이다. 질량과 기준 면적을 입자별로 보존한다. 지름당 12 또는 16셀, 물질점 간격은 반 셀이다.
- E=10 MPa로 응력을 정규화한다. ν=0.45, 단축 항복 0.4 MPa에 대응하는 2D 문턱은 (0.4/10)√(2/3), 위판 속도는 0.034 c_S다. F는 원판별 속도장, µ=0.5, 겹치는 노드에서 접근하는 쌍의 비탄성·쿨롱 충격량을 계산한다. Cauchy 견인력 분리와 틈·거리 옵션은 이번 개발 커널에 들어 있지 않다. 순서 ②–④의 판독값은 만들지 않는다.
- 아래판 충격량/(dt·폭)이 0.12 E(1.2 MPa)를 처음 상향 통과한 두 step에서 판 높이를 선형 보간한다. Φ_m=ΣA₀/(폭·높이)이다. 순간 첫 통과는 접촉 충격에도 민감하므로 trace를 보존한다. S 팔이나 응력비는 계산하지 않는다.
- 공통 입력: 판 높이가 처음의 75% 아래면 중단. 팔당 570초에 새 step 시작을 멈춘다. 590초에서 TERM, 600초에서 KILL로 정리한다. 두 해상도 모두 목표를 끼웠을 때만 |ΔΦ_m|≤0.005 여부를 출력한다. 미도달/시간초과는 미완료(rc4)다. 명령 오류·중단도 회수하며 자동 재시도는 0이다.
- 개발용 격자 전사·규칙 배열·마찰 투영의 수치 자격은 미확인이다. 양 해상도에서 문턱을 넘는지 개발 자료로 읽고, 이 결과만으로 공식 접촉 설정·U6·S/F 해석을 채택하지 않는다. ② 틈 보정, ③ 거리 판정, ④ 둘 다의 진행 여부는 이 반환 뒤 확인한다. 11-16 응력비는 설정 선택에 쓰지 않는다.

## 전달 및 검사

소스 `scripts/suyoung_u6_first_dev.py`는 첫 개발 런의 `scripts/dem_suyoung_sf2d_dev.py`에서 stencil, 재료 함수와 접촉 충격량 함수를 읽는다. 3a 상수는 독립 모듈 인스턴스에 설정한다. 각 물체에서 쓰는 격자 노드만 저장한다. 원래 스크립트 파일과 기존 입력을 변경하지 않는다.

블록과 같은 폴더에 소스 tar를 둔다. 첫 저자는 WSL에서 두 파일이 있는 폴더를 열어 블록을 붙여 넣는다. 기존 프로젝트 venv의 NumPy로 한 CPU에서 순차 실행하며 정상 종료 또는 미완료 시 새 반환 폴더의 결과 tar, SHA256SUMS, 화면 요약을 회수한다. 현장 소요시간은 미측정이며 전체 상한은 약 20분과 준비·포장 시간이다.

새 검사는 `scripts/test_suyoung_u6_first_dev.py`. 최초 6개 시험을 작성한 뒤 구현 전 모듈 부재로 적재 실패(rc1), 구현 후 6/6. 소형 제조 입력 전사·다물체 접촉의 기존 커널 대조 및 시간예산 0의 미완료 확인을 추가해 9/9. 49원판 하중 진행 step은 작성 측 실행 0이다.
