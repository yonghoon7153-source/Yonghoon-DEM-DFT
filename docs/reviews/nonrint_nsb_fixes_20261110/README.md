## 2. 유지하는 계약과 한정

정확한 내장 int와 유한 float만 받으며 bool·하위형·비유한 값의 기존 거부를 유지한다. float 입력 전에 호출자가 잃은 정밀도를 복구하는 것은 아니다. T5의 정확한 평균/예산 flag와 표시 숫자는 다를 수 있으므로 정확한 분자·분모를 함께 기록한다. RMSE는 유한 float 진단으로 남고 표현 범위 초과·비영 값의 표시 underflow는 거부한다. 무제한 자릿수·자원·다른 소비자의 정수 정확성을 인증하지 않는다.
