# 수영 2D · 선택된 설정 ②의 U6(b) 개발 대조

같은 충전율에서 하나의 속도장을 쓰는 S와 원판별 속도장을 쓰는 F의 아래판 압력을 비교한다. 근거는 docs/reviews/dem_redesign_direction_20261109/memo_v3_2.md §4 U6(b)와 docs/reviews/suyoung_u6b_development_20261121/README.md의 기존 판독 규칙이다. 선택 근거와 주간보고 그림은 docs/reviews/suyoung_u6a_setting2_return_20261123/weekly_u6a.md에 있다.

| 항목 | 이번 묶음 |
|---|---|
| 이미 확보한 F | 설정 ② U6(a)의 8·12·16·24칸 완주 압력 곡선 네 개. 출처·영수증·첫 1.2 MPa를 다시 확인해 사용한다. |
| 필요한 S | 같은 49개 원판의 좌표·초기 부피·물리 번호·아래판 접촉면을 사용한다. 모든 물질점에서 하나의 격자 속도를 읽는다. 벽과 만나는 서로 다른 원판 표면이 같은 격자 속도를 공유하는 경우 벽 조건을 함께 푼다. |
| 비교 조건 | F와 같은 격자별 시간 간격, 초기 상태, 일정한 판 속도, 위·아래판, 재료식과 종료 조건을 사용한다. 과거 S 반환은 아래판 구현이 달랐다. |
| 관측점 | 충전율 0.84·0.90·0.95에서 판 높이에 따라 압력을 선형 보간한다. 첫 1.2 MPa 상한과 기존 기하 한계까지 얻은 자료만 쓴다. |
| 판독 | 양쪽 네 격자가 모두 도달한 충전율에서 기존 판독기로 해상도 변화, 치우침·잡음 신호, 산출 가능한 로그 압력비 구간을 기록한다. F8은 충전율 0.945090에서 상한에 닿아 0.95의 네 격자 공통 비교가 성립하지 않는다. 다른 목표점의 독립 판독은 계속한다. |
| 운영 | 1저자 WSL CPU 한 개. 8→12→16→24칸 순서로 S를 한 번씩 계산한다. 팔별 계산 상한은 30·60·90·240분, 종료 정리 유예 30초다. 첫 오류에서 기록을 반환한다. 자동 재시도 0회. |

**개발 자료.** 비교의 결과는 충전율별로 보고한다. U6(c) 접촉 자격과 단계 3·3D는 보류 중이다. U6(b) 결과에 치우침 신호가 있으면 등록된 §7 Q13 절차를 따른다.

실행 블록은 이 폴더의 build_block.py로 고정 커밋에서 만든다. 입력은 설정 ② U6(a) 반환 TAR 하나이며 같은 폴더의 화면 파일과 SHA256SUMS를 함께 읽는다. CHECK_ONLY는 원 입력·소스·네 시드 및 합성 단일 속도장 조건을 검사한다. GO_SUYOUNG_U6B_SETTING2_ONCE가 네 S 팔을 실행한다. 반환 폴더에는 TAR, 화면, SHA256SUMS가 남는다.
