## 0. 이 논문이 우리에게 *왜* 중요한가 (한눈 positioning)

같은 그룹의 2020 시뮬레이션 (강체 + 무른 원판 · 등방 · NSCD+FE) 이 만든 압밀 법칙을, **실제 무른 (실리콘) + 단단한 (PVC)
원기둥 혼합을 일축으로 눌러** 검증한 실험 Letter 다.  우리에게 값진 이유는 실험 기법이다 — **입자 하나하나의 내부 변형장
(대변형 DIC)** · 입자 경계 · 접촉 · 충전률 · 배위수를 **한 실험에서 동시에** 잰다.

| 우리가 필요한 것 | 이 논문이 주는 것 |
|---|---|
| 재설계 모델이 맞춰야 할 **입자 수준 관측량**의 실측 선례 | 배위수 Z − ZJ · 무른 입자 비구형도 ⟨a⟩ · **상대 접촉 길이 ⟨l⟩** · 입자 내부 von Mises 변형 ⟨C⟩ 와 그 표준편차 σ_C |
| **느슨한 출발 → jamming → 치밀화** 를 출력으로 보는 절차 | "the systems were prepared loosely enough to observe the jamming transition" — φJ · ZJ 를 실험에서 뽑는다 (선택법은 SM) |
| **일축** (우리 다이와 같은 하중 축) 압밀 법칙 | 등방 법칙을 일축으로 확장한 식 (1) — 유효 마찰 (1 + μM) · 기하 매개변수 Γ · 혼합 유효 영률 E\* = E0/[2κ(1 − ν²)] |
| 시뮬레이션 ↔ 실험 **독립 교차검증** 사례 (frame[4] 형) | 실험 Z − ZJ = **k (φ − φJ)^0.5, k = 4.9** ↔ 2020 시뮬 **ξ = 5.1** (다른 하중 · 마찰 · 크기분포) |
| 피복 (coverage) 정의 검증 축 | **⟨l⟩ 가 φ − φJ 에 선형, 기울기 κ 무관** — 접촉 길이가 밀도 하나로 접힌다 |
| "이산 입자계 → 연속체" 전이의 실측 | 평균 변형 ⟨C⟩ 가 **C_c = 0.991 ± 1.2 × 10⁻³** 을 경계로 밀도 지배 → 압력 지배로 바뀜 (κ 무관) |

⚠ 하중 쪽만 · kPa · 2D · 초탄성 — 탈압 · 소성 · 3D 는 범위 밖.

## 1. 한 줄 요약

**KR:** 2D 피스톤 (270 × 202 mm²) 이 평판 스캐너 유리 위의 실리콘 (E0 0.45 MPa) + PVC (1.2 GPa) 이분산 원기둥 (지름 20 · 30 mm,
높이 15 mm, 약 100 개; 무른 개수 분율 κ = 0.2–1) 을 단계적으로 일축 압축하고, 2400 dpi 영상 + 대변형 DIC 로 입자별 변위장 ·
경계 · 접촉 · von Mises 변형을 재어 ① **Z − ZJ = 4.9 (φ − φJ)^0.5** 가 κ 무관하게 성립함을 확인하고 ② 2020 의 등방 압밀
법칙을 **일축으로 확장한 식 (1)** 이 모든 κ 의 P–φ 곡선을 따름을 보이며 ③ 비구형도 ⟨a⟩ ∝ P (기울기는 κ 에 비례), 접촉 길이
⟨l⟩ ∝ φ − φJ (기울기 κ 무관), 평균 변형 ⟨C⟩ 가 **C_c ≈ 0.991** 아래 · 위에서 각각 밀도 · 압력에 선형, 변형 분포 폭
σ_C ∝ φ − φJ (선형 구간의 끝은 κ 와 함께 증가) 라는 국소–전역 법칙을 보였다.

**EN:** A 2D uniaxial piston compresses ~100 bidisperse silicone (soft, hyperelastic, E0 = 0.45 MPa, ν = 0.5) and PVC (rigid,
1.2 GPa) cylinders on a flatbed scanner; large-deformation DIC resolves each grain's strain field.  The coordination law
Z − ZJ = k(φ − φJ)^0.5 (k = 4.9) holds for all soft fractions κ; the 2020 isotropic compaction law, extended to uniaxial loading
(Eq. 1), matches all P–φ curves; asphericity grows linearly with P (slope ∝ κ), relative contact length linearly with φ − φJ
(κ-independent slope), mean von Mises strain is linear in φ below and in P above a κ-independent crossover C_c ≈ 0.991, and the
strain spread grows linearly with φ − φJ up to a κ-dependent cutoff.

**우리에게 왜 중요한가 (3 줄):** ① **재설계 모델이 낼 수 있어야 할 국소 관측량 목록**을 실험이 정해 준다 (접촉 길이 · 형상 ·
내부 변형 분포).  ② **"느슨하게 시작해 jamming 을 관측"** 하는 절차가 1저자 11-09 결정 (MPM 은 느슨한 패킹에서 출발) 과 같은
방향이다.  ③ **우리 MPM 은 "연속체 같은" 두 번째 체제에서만 출발**하므로, C_c 앞쪽의 이산 구간은 지금 구조로는 원리적으로 없다.

## 4. 방법 ★

### 4-1. 장치 (그림 1a)

- 2D 피스톤 (270 × 202 mm²) 이 **평판 스캐너 위**에 놓인 원기둥 집합을 **일축** 압축.  스테퍼 모터 → 나사 → 움직이는 변 →
  두 힘 센서 (100 Hz).  선행 장치는 refs [12, 33] (Vu & Barés 2019 PRE; Barés et al. 2021 EPJ Web Conf.).
- **단계식**: 0.5 mm 이동 (2 mm/min) → 1 min 이완 → 바닥에서 스캔 (2400 dpi).
- 바닥 마찰 제거: 유리 기름 코팅 → 모든 접촉 마찰 < 0.1.

### 4-2. 영상 처리 (그림 1b · ref [12, 38])

1. 변형 전 영상을 **문턱 처리**해 입자를 하나씩 검출.
2. 입자마다 전 영상열에서 **추적** — 강체 운동 (병진 · 회전) 을 재고, 입자를 따라가며 보정한 부분 영상을 잘라낸다.
3. **무른 입자**: 대변형용 DIC 알고리즘 (ref [37]) → 입자 내부 변위장 **u**.  **단단한 입자**: 고전 DIC (모든 영상을 초기 영상과
   상관, 작은 변형 가정).
4. **입자 경계** = 변위장 u 에서 얻음 → **충전률 φ** 를 직접 계산.
5. **비구형도** a = p² / (4πs) (p = 둘레, s = 면적; 원 = 1).
6. **오른쪽 Cauchy–Green 변형 텐서장 C** (refs [12, 39]) → 그 **von Mises 척도 𝒞** (SM).  작은 변형에서 ε = ½(C − I).
7. **접촉 · 접촉 길이 l** = 경계의 근접 + von Mises 변형으로 판정 (ref [12]).

### 4-3. 시료 준비 · 통계

- 계가 작아 초기 조건 · 준비에 민감 → **최대한 균질**하게 (같은 크기 · 같은 강성 이웃 최소화) · **κ 마다 독립 3 시료 평균**.
- **jamming 을 관측할 만큼 느슨하게** 준비 → 계가 재배열할 여유를 줘 초기 조건을 "어느 정도 잊게" 한다.
- φJ (jamming 충전률) · ZJ (그때 평균 배위수) 의 선택법 = SM.

### 4-4. 압밀 법칙의 일축 확장 (식 1 — 원문 그대로)

`P ≃ (E*/4Γ)(1 + μM) · ((φmax − φJ)/φJ) · [Z0 + k(φ − φJ)^0.5] φ · ln((φmax − φ0)/(φmax − φ))`

- **E\* = E0/[2κ(1 − ν²)]** = 혼합의 평균 유효 영률 · **φmax** = 점근 최대 충전률 · **Γ** = local vs global strain 곡선에서 직접
  잰 기하 매개변수 (SM) · **μM** = 거시 마찰 ≈ 0.25 (2D 문헌값).
- 저자 설명: 2020 등방 모델 (refs [22, 24, 25]) 에 ① **κ 를 유효 영률에 넣어** 무름 변화를 반영하고 ② **일축성** (ref [47]) 을 위해
  **유도된 유효 마찰을 앞 인자에** 더했다 → "without any ad hoc parameters".
- ⚠ 식 안의 **Z0 · φ0** 는 본문이 정의한 **ZJ · φJ** 와 표기가 다르다 (같은 뜻인지 SM 확인 필요 — [미확인]).
- ⚠ 2020 식 (12) 의 **단일 입자 상수 b 와 1/(2π)** 자리에 **E\*/(4Γ) · (1 + μM) · (φmax − φJ)/φJ** 가 들어간 셈이다 — 유도는 SM.

### 4-5. ★ 입자 처리 (실험이라 "진짜" — 무엇이 진짜이고 무엇이 근사인가)

| 질문 | 이 실험 |
|---|---|
| 무른 입자 형상 변화 | **진짜** (실리콘이 실제로 다각형화 — 그림 1b) · 가역 초탄성 |
| 단단한 입자 | PVC — 변형 무시 가능 (본문) · 재배열은 진짜 |
| 접촉 | 진짜 접촉 (마찰 < 0.1) · **판정은 영상 근접 + 변형 기준** (판정 문턱 SM) |
| 차원 | **준 2D** — 높이 15 mm 원기둥의 **바닥면**만 본다 (높이 방향 변형 · 기울어짐 [미확인]) |
| 크기비 | 20 : 30 mm (1.5 배) — 두 상 모두 같은 이분산 |
| 측정 해상도 | 10.6 µm/px · 무늬 50 µm |

## 5. 결과 — 절별 상세

### 5-1. 연결성 (그림 2a)

- Z − ZJ vs φ − φJ 가 **κ 와 무관하게 한 곡선**으로 붕괴, **α = 0.5 · k = 4.9** — 이전 실험 · 수치 관찰 (refs [36, 43, 44]) 과 일치.
  ⇒ 이 관계를 **이원 혼합으로 확장** (2020 시뮬 [22] 에 이어 실험으로).
- 토의: 지수 α 는 κ 사이에서 **재현적**이고 문헌과 완전히 일치 — 이 법칙을 기존 모델에 꽂아 등방 압밀식을 얻는다 (refs [22, 25]).

### 5-2. 압밀 곡선 (그림 1c · 2b)

- 그림 1c: 전역 힘 f vs 전역 변형 ε — κ 0.2 는 작은 ε 에서 힘이 가파르게 오르고 **톱니** (재배열) · κ 가 클수록 완만.
- 그림 2b: P vs φ − φJ 에 식 (1) (실선) — **모든 κ 에서 잘 맞는다**.  작은 κ 에서 작은 불일치 = **입자가 급격히 재배열할 때**, 계가
  작아 (n ≈ 100) 더 두드러진다고 저자 해석.
- 식 (1) 의 φmax 는 이상적으로 **순수 무른 계에서 1 → 순수 강체 계에서 φJ** — "which is what we observe in our experimental data"
  (κ = 1: 0.97, κ = 0.2: 0.88).  → **모델 검증**이라고 결론.

### 5-3. 비구형도 (그림 3a)

- 무른 입자 평균 비구형도 ⟨a⟩ 가 전역 응력 P 에 **선형** (몇 번의 급격한 재배열 제외) — κ 무관하게 선형.
- 기울기는 κ 와 함께 **거의 선형으로** 증가 (삽도).  ⇒ **입자 경계 변형만 재서 압력을 간접 측정**할 수 있다 (저자).

### 5-4. 상대 접촉 길이 (그림 3b)

- ⟨l⟩ 이 φ − φJ 에 **선형**, **기울기가 κ 와 무관**.
- 작은 변형 구간에서는 Hertz 접촉 법칙의 척도 고찰 + Z–φ 식으로 이 선형을 **예측**할 수 있다 (SM).  흥미롭게도 **작은 변형 구간을
  훨씬 넘어서도**, 어떤 혼합에서도 선형이 유지 → **접촉 기하 관찰만으로 충전률 변화를 간접 추정** 가능.

### 5-5. 입자 내부 평균 변형 — 두 체제 (그림 4a · 4b)

- 압축되면 ⟨C⟩ 가 1 에서 내려가고 P · φ 는 오른다.
- **⟨C⟩ ≳ C_c ≈ 0.991 (작은 압축)**: ⟨C⟩ 가 **φ 에 선형** — κ 와 무관하게 곡선이 꽤 잘 붕괴.  전역 변형이 φ 와 척도화되는 성질이
  국소 변형으로 "외삽" 된 것으로 해석.
- **⟨C⟩ < C_c (큰 압축)**: ⟨C⟩ 가 **P 에 선형** — 재료가 **벌크처럼** (작은 재배열 제외) 행동, 틈새 공극이 거의 없는 매우 조밀한 상태와
  정합.  큰 압축에서 κ 가 작을수록 변형에 대한 압력 감소가 빠르다 = **κ 가 작을수록 재료가 더 뻣뻣**.
- **C_c ≈ 0.991 은 κ 무관** — 이전 관찰 [12] 의 두 체제와 같다 ⇒ **"이산 계 → 연속체 같은 계" 전이**.

### 5-6. 변형 분포 폭 (그림 4c)

- 변형의 평균뿐 아니라 **분포도 넓어진다** (refs [12, 32]).  σ_C 가 φ − φJ 에 **선형** (안내선 기울기 4.0 × 10⁻⁴), φJ 로 이동시키면
  κ 무관하게 붕괴 — **선형 구간의 cut-off 는 κ 와 함께 선형 증가** (삽도).
- 해석: **κ 가 작으면 무른 입자가 더 많이 · 더 빨리 변형**해 비선형 구간에 일찍 들어간다.

### 5-7. 결론 · 전망 (저자)

계가 작아 보여도 거시 측정은 반복 가능 · 압밀 법칙 확장 · 검증 · 전역 관측량 ↔ 변형된 국소 구조의 선형 관계 (a ∼ P, l ∼ φ − φJ,
𝒞 ∼ φ − φJ 또는 P, σ_C ∼ φ − φJ).  장치로 **비원형 입자 · 다른 유변학 입자 혼합**으로 확장 가능.

| 크기비 | 1.5 (20 : 30 mm) · 두 상 같은 분포 | AM ⌀4–9 µm vs SE ⌀~1 µm |

### 8-1. 같은 점 · 맞물리는 점

- **일축 · 단계 + 이완**: 실험의 "0.5 mm 이동 → 1 min 이완 → 측정" 은 우리 MPM `hold` (목표 도달 후 판 고정 · 이완) 와 같은 계열의
  준정적 절차.
- **무른상이 거의 비압축** (실리콘 ν 0.5 · 우리 MPM ν 0.49) — 치밀화가 무른상 부피 감소가 아닌 **형상 변화**로 일어나는 같은 구조.
- **φmax 가 κ 와 함께 오른다** (0.88 → 0.97) — 2020 시뮬 · `bouvard2000_…` · `martinbouvard2003_…` 와 같은 방향.

### 8-2. 다른 점 — 그리고 왜

| 차이 | 종류 | 설명 |
|---|---|---|
| 2D 바닥면 영상 | **차원 인공물** | φ · Z · ⟨l⟩ 의 값은 3D 로 옮기지 않는다 |
| 초탄성 vs 소성 | **구성식 (실제 차이)** | 실리콘은 가역 — 우리 SE 는 소성 잔류 (탈압 후 기공 유지) |
| kPa vs 300 MPa | **척도** | 절대 압력 비교 불가 — P/E 무른상 기준만 유비 |
| κ = 개수 분율 | **정의** | 두 상 크기분포가 같아 부피 분율과 거의 같지만, 우리 (AM ≫ SE) 에서는 개수 ≠ 부피 — 우리 κ 는 **부피** 로 쓴다 |
| 크기비 1.5 | **범위** | 작은 SE 가 큰 AM 틈을 채우는 우리 기하는 실험에 없다 |

### 8-3. 우리 MPM 의 구조적 공백을 이 실험의 언어로

- 실험의 **C_c 앞쪽 (이산 구간)** = 입자가 재배열하며 접촉이 늘고 변형이 밀도를 따라가는 구간.  우리 MPM 은 DEM 끝 (이미 조밀) 에서
  **연속체로 출발**하므로 이 구간이 **원리적으로 없다** — 재설계에서 느슨한 출발을 정한 이유와 같은 축.
- 실험의 Z · ⟨l⟩ · ⟨a⟩ 는 **입자 정체성** (경계가 살아 있는 입자) 이 있어야 계산된다.  단일 속도장 MPM 은 SE 가 융합해 셋 모두
  정의 불가 → 입자 번호 승계 설계 (주 리포 `docs/reviews/mpm_coverage_interface_design_memo_20261103.md` §4) 만으로는 부족하고,
  **입자별 장 (A′) 또는 입자별 메시 (B)** 가 필요하다 (추론).
- ⟨l⟩ (접촉 길이) 는 우리 **소성 피복**과 같은 계열 — 지금 우리 소성 피복은 DEM 골격 위의 부분 독립량이고 소성 증분이 씨앗 치우침과
  같은 크기라는 열린 결함 (`MPMC-02`) 이 있다.  실험의 "⟨l⟩ ∝ φ − φJ, κ 무관" 은 피복 정의를 시험하는 **외부 모양 기준**이 된다
  (값이 아니라 선형 · 조성 무관성).

### 8-4. frame 규율

- **frame[4]**: k = 4.9 (실험) 와 ξ = 5.1 (2020 시뮬) 은 서로 맞춘 값이 아니라 **각자 측정** — 우리 원칙 ("DEM 과 MPM 은 각자 실험에
  보정, 일치 = 교차검증") 의 외부 사례.  ⚠ 같은 그룹 · 같은 분석 관례 (Z 판정, φJ 선택 = SM) 라 완전 독립은 아니다.
- **frame[5]**: 실험은 형상 (모양) 과 접촉 (패킹) 을 함께 본다 — 재설계 후보 비교에서 **두 축을 같은 시료에서 동시에** 재는 기준.

## 9. 깊은 통찰

1. **"연속체로 출발하는 모델은 전이의 뒤쪽만 본다."**  C_c ≈ 0.991 의 두 체제는 우리 MPM 이 왜 DEM 끝에서 짧게 재압축하는 방식으로는
   압밀 전체를 설명할 수 없는지를 **실측 언어**로 말해 준다.  재설계의 첫 시험: 느슨한 출발에서 평균 변형이 **밀도 지배 → 압력 지배**
   로 바뀌는 점이 생기는가.
2. **접촉 길이는 조성이 아니라 밀도의 함수다** (⟨l⟩ ∝ φ − φJ, κ 무관).  우리 피복 (SE 가 AM 을 덮는 비율) 이 조성별로 크게 달라진다면,
   그것이 **밀도 차의 결과인지 조성 고유 효과인지** 먼저 가려야 한다 — 이 실험이 제시하는 분해 방법 (φ − φJ 에 대해 그려 보기).
3. **강체가 많을수록 무른 입자에 변형이 몰린다** (σ_C cut-off 가 κ 와 함께 줄어든다 → 작은 κ 에서 비선형 일찍).  AM-rich 전극의 SE 는
   **변형 · 응력 집중**을 더 받는다는 방향 — SE 국부 소성 변형 · 응력 핫스팟 (MPM 장) 의 조성 의존을 볼 때의 기대 방향 (추론).
4. **모양이 압력계다** (⟨a⟩ ∝ P, 기울기 ∝ κ).  SEM 단면의 SE 형상 기술자 (원형도 등) 로 국부 압력 이력을 거꾸로 읽는 발상 — 2D ·
   초탄성이라 그대로는 못 쓰지만, 재설계 MPM 의 SE 형상 출력을 SEM 과 대조하는 **정량 축**의 원형.
5. **일축 확장은 "유효 마찰 (1 + μM)" 과 "기하 Γ" 두 인자로 들어온다** — 등방 → 다이 (일축) 로 옮길 때 무엇이 바뀌는지의 최소 목록.
   우리 재설계도 등방 단위 시험 (단일 입자 상자) 과 일축 침대 사이에 이런 인자가 낄 것을 미리 적어 둘 것.

## 10. [DEM 우선 (수영)] 트랙 — 후보별 함의 + 구체 행동

### 10-1. 후보별 판정

| 후보 | 이 실험이 지지 / 불리 | 이유 |
|---|---|---|
| **A** (MPM + 움직이는 강체 AM) | **부분 지지** | 강체 재배열 (그림 1c 톱니) · jamming 출발은 낼 수 있으나, ⟨l⟩ · ⟨a⟩ · Z · 입자별 변형 분포는 SE 융합 때문에 정의 불가 |
| **A′** (다중 속도장 접촉 MPM) | **지지** | 입자 경계 유지 → ⟨l⟩ · ⟨a⟩ · σ_C · C_c 전이를 원리적으로 계산 가능 — 이 실험이 **검증 관측량 세트** |
| **B** (NSCD + FE) | **지지 (같은 그룹의 방법)** | 2020 시뮬 (B) 과 이 실험이 Z 법칙에서 독립으로 만난다 (5.1 vs 4.9) — B 가 이 관측량들을 낼 수 있다는 근거 |
| **C** (MDR DEM) | **조건부** | Z · φ(P) · φmax 는 낼 수 있으나 구 형상이라 ⟨a⟩ · 입자 내부 변형 분포 · 실제 접촉 길이 (다각형 면) 는 근사만 (접촉 반경으로 대리) |
| **C′** (두 재료 항복캡 DEM) | **조건부** | C 와 같음 + 무른상 항복이 실험 (초탄성) 과 다른 물리 |
| **D0** (LIGGGHTS gen-2) | **검사 가능** | CN–기공률로 Z − ZJ 법칙 · 접촉 면적 분율 vs 기공률 (⟨l⟩ 의 3D 대응) 의 κ 무관성을 기존 자료로 확인 |

### 10-2. 구체 행동

1. **[D0 · 새 런 0]** 우리 DEM 압축 궤적에서 **접촉 면적 분율 (또는 피복) vs (φ − φJ)** 를 조성별로 그려 **선형 · 조성 무관성**을 확인
   (실험 그림 3b 의 3D 대응 시험).  φJ 정의 (예: 판 힘이 처음 오르는 점) 를 결과 전에 적는다.
2. **[재설계 공통] 관측량 세트에 국소 4 종 추가**: ⟨l⟩(φ − φJ) · ⟨a⟩(P) · ⟨𝒞⟩ 의 두 체제와 교차점 · σ_𝒞(φ − φJ) 와 cut-off.  각 후보를
   랩 기공률 (10–13 %) 에 **따로** 보정한 뒤 이 세트로 비교.
3. **[재설계 출발]** "jamming 을 관측할 만큼 느슨하게" 를 우리 출발 조건 문구로 차용 — 출발 패킹의 φ · Z 를 기록하고 φJ 를 **출력**으로
   얻는다 (11-09 결정과 정합).
4. **[문헌]** SM (Γ · φJ 선택 · 일축 유도) 확보 → 이 카드 [미확인] 해소 · 같은 장치의 실험 학회판 **Barés et al., EPJ Web Conf. 249,
   05004 (2021)** (ref [33]) · 선행 장치 **Vu & Barés, PRE 100, 042907 (2019)** (ref [12]) 확보 후보.
5. **⛔** kPa · 2D 값 (φmax 0.88 / 0.97, k = 4.9, C_c) 을 우리 수치로 옮기지 않는다 · 탈압 근거로 쓰지 않는다.

## 13. 기법 미니 용어집

| 용어 | 뜻 |
|---|---|
| **DIC** (digital image correlation) | 영상 무늬 상관으로 변위장을 재는 기법 — 무른 입자엔 대변형용, 단단한 입자엔 작은 변형용 |

| **von Mises 척도 𝒞** | C 의 등가 (스칼라) 척도 — 압축에서 1 아래로 (정의 상세 SM) |
| **φJ · ZJ** | jamming 충전률 · 그때 배위수 (실험에서 선택, SM) |
| **비구형도 a** | p²/(4πs) — 원 = 1, 찌그러질수록 커짐 |
| **상대 접촉 길이 ⟨l⟩** | 입자 경계 중 접촉한 길이의 상대값 (%) — 2D 판 "피복" |

| **μM** | 거시 마찰 (2D 집합 ≈ 0.25, 문헌) — 일축성 반영 인자 (1 + μM) |
| **Γ** | local vs global strain 곡선에서 잰 기하 매개변수 (SM) |
| **C_c** | 작은/큰 변형 체제의 교차 평균 변형 (0.991 ± 1.2 × 10⁻³) |
