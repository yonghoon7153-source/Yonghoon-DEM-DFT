## 6. Q6 — 전칭 보장 불수용과 실제 경계 반례

### 6-1. 결과 줄이 생기기 전에 모두 멈추는 것은 아니다

R1·R2·attempt-null 반례에서 실제 recover는 rc0으로 **resume_ok=false 결과 줄을 기록**한다. 요청한 “서로 어긋나면 결과 줄을 쓰기 전에 멈춘다”는 문장은 이 동작과 다르다. 다음 재개를 거부하는 목적은 충족하지만 기록 자체를 금지하는 설계는 아니다.

### 6-2. 요약 없는 copied prefix의 단일 불일치는 놓칠 수 있다

실제 ResumeRunner._copy를 사용한 작은 반례다.

1. 원천 attempt_1의 L01은 완료, L02는 자원 실패·부분 출력이다.
2. attempt_2가 L01 payload와 group 기록을 실제로 복사한다.
3. read_run 지점에서 음성 조건에만 **복사된 L01 payload 한 파일**의 불일치를 주입한 뒤, 모의 BaseException으로 요약 미생성 중단 상태를 구성한다.
4. 원천·원장·launch/end는 같이 바꾸지 않는다. 양성은 파일 변경 없이 같은 중단을 모의한다.

| 관측 | 정상 중단 대조 | 단일 copied payload 불일치 |
|---|---:|---:|
| 원천과 복사 payload | 같음 | 다름 |
| 요약 상태 | absent | absent |
| group 검증 사유 | null | null |
| 결과 cause | parent_dead | parent_dead |
| 결과 resume_ok | true | true |
| 다음 order/presolve 사유 | null/null | null/null |
| 다음 runner _src_done(L01) | true | true |

근거: rint_r_chain.py:4756은 s가 dict일 때만 ⓒ를 부른다. summaryless의 ⓓ(:4676)는 원천의 첫 미완료 L02를 대조하며, 완료된 L01 copied prefix는 대조하지 않는다. 다음 _src_done(:5727)은 완료 표지·폴더를 보고 복사를 허용한다.

**이것은 요청서 §4의 공개 한정이 발화한다는 독립 반례다. 새 숨은 P1/P2로 중복 등재하지 않는다.** 정상 copytree 또는 디스크 부족만으로 잘못된 payload가 생긴다는 것은 입증하지 않았다. 생산자 _copy는 payload→로그→launch/end→read_run 순서(:5755–5768)이며 일반 복사 예외는 실패 처리된다. 모든 사본을 일관되게 고친 위조와도 다른 반례다.

보장 범위를 고정하는 선택은 둘이다.

- 현재 범위 유지: **“요약 없는 시도의 이미 복사된 선행 런과 원천 사이 모든 불일치 검출은 보장하지 않는다”**를 명시하고, Q6의 “모든 모순” 표현을 쓰지 않는다.
- 그 부류까지 보장: summaryless에서도 원천상 완료된 prefix 중 현재 시도에 완료 흔적이 있는 런의 launch/end와 payload를 원천에 대조한다. 아직 복사하지 않았거나 복사가 중단된 정상 상태는 보존해야 한다. 위 정상 대조/단일 불일치 및 rerun=None·첫 새 런 미시작·3시도 effective 원천을 회귀로 둔다.

실제 재부팅·디스크 부족·다른 기계·비결정성 전체에 대해 틀린 결과 수용이 절대로 없다는 주장은 이번 합성 시험으로 증명할 수 없다. 새 지적의 인정 기준을 두 전칭 문장에만 고정하기보다, **검사한 상태와 제외된 상태를 함께 고정**해야 한다.

### 7-2. SELF-159: 특정 rc 보완은 닫힘, 자동 인증은 아님

## 8. Q7 — RCA-11과 새 RR5-01 [P2]

### 8-1. 0 µm 선택 자체는 수용 가능

등록문:99–103은 빈 분포에서 최적값을 추정한 것이 아니라 **등록 바닥 밖의 추가 필터를 두지 않는다**는 저자 선택을 기록한다. 규칙을 실행하는 두 사람은 같은 0을 얻는다. 식별된 물성·최적값이라는 뜻은 아니다.

D = 2r_f + tol_ff = **0.22381254285530133 µm**.
코드 _self_floor(carbon_junction.py:200)는 s>D 및 s>(π/2)d를 요구하고, 그 이후 s≥s_min을 적용한다. 따라서 **같은 D에서 s_min∈[0,D]의 분류 동등성은 항등적으로 맞다.** 자기 후보0 때문에 성립하는 것이 아니다. 상태/수치/지문까지 같은 바이트라는 의미도 아니다.

### 8-2. RR5-01 — 자기 후보0만으로 DBE 동등성과 영향 경로를 한정하면 틀린다
