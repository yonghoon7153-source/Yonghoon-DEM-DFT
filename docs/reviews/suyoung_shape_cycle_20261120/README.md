# 수영 설정 ① · 네 원판 가압과 판 분리 개발

기존 네 원판 2D S와 F에서 **같은 압축 뒤 판을 정지했다가 올렸을 때 재료가 판에서 떨어지는지** 관측한다. S는 모든 원판이 한 노드 속도장을 공유한다. F는 원판별 속도장 사이에 접근하는 쌍의 Coulomb 충격량을 적용한다. 설정 ①은 F의 틈 보정과 거리 판정을 모두 끈 것이다. 두 팔 모두 판보다 빨리 올라가는 접촉 노드의 속도 성분을 판 속도로 제한한다. 물질점이 상승판보다 느리면 판이 끌어당기는 힘은 발생하지 않는다. 칸 폭의 수치 접촉과 실제 계면은 구별한다.

## 입력과 네 단계

`scripts/suyoung_shape_cycle_dev.py`가 `00f0a1758349079a10d9c3fe9d1424620117dd27`의 `scripts/dem_suyoung_sf2d_dev.py`를 호출한다. 11-16의 네 원판 입력(32×32, 물질점 1,108, Δt=0.0005, 속도 0.15, 마찰 0.20, E=1)을 유지하고 F의 노드 법선은 11-18 수정 핀을 사용한다. 49원판 U6(a)의 1.2 MPa·마찰 0.5·지름당 12/16셀 반복은 별도 블록이다. 각 팔은 고유한 동일 초기 배열에서 시작한다. 한 팔 내에서는 `x, v, C, F_elastic, particle_id`와 관측용 `F_total`을 단계 경계에서 그대로 이어가고, 경계 양쪽 바이트 해시를 기록한다. 응력 계산은 탄성 상태를 쓰며, 총 변형 지도는 형상 출력에만 쓴다.

| 실제 step | 판 운동(정규화 단위) | 저장 단면 |
|---|---|---|
| 0 | 첫 판 높이 0.80 | 초기 |
| 1–1200 · 가압 | 속도 −0.15, 끝 높이 0.71 | 가압 끝 |
| 1201–1800 · 정지 이완 관측 | 높이 0.71에서 600 step | 정지 끝 |
| 1801–3400 · 상승 | 속도 +0.15, 끝 높이 0.83 | 상승 중간·끝 |
| 3401–4000 · 상승 후 관측 | 높이 0.83에서 600 step | 끝 |

정지·상승·상승 후 길이는 이번 첫 형상 관측의 개발 선택이다. 정지 반력과 운동에너지 이력을 함께 기록한다. 600 step 정지만으로 정적 평형을 판정할 수 없다. 응력은 정규화 개발 단위다. 기존 2.469는 법선·판독 단계가 다른 과거 계산에 남는다.

## 형상·힘 판독

- 같은 step·판 위치의 S/F를 한 그림에 둔다. 재료점 중심과 `x + F_total·δX`의 네 꼭짓점으로 각 점의 기준 정사각형을 운반한다. 점·입자 번호, 기준 면적·질량, 현재 좌표·속도, 아핀·탄성·총 변형 상태는 실제 step NPZ에 들어간다. 중간 형상을 보간하지 않는다.
- 매 step 판 반력(판 폭으로 나눈 양의 압축 압력), 판과 최고 점 중심의 간격, 판과 아핀 셀의 최고 꼭짓점 간격, 운동에너지와 접촉 잔차를 남긴다. 간격은 겹치면 음수, 떨어지면 양수다. 판 응력 0의 최초 시각과 셀 간격 양수의 최초 시각은 가압 종료 이후 각각 기록한다.
- **개발 분리 관측**의 표지는 가압 중 양의 판 반력이 있었고 상승 후 마지막 120 step에서 반력이 정확히 0이며 아핀 셀 간격이 매번 양수일 때다. 처음 떨어진 뒤 다시 눌리는 경우는 마지막 양의 반력과 연속 관측 길이로 구별한다. 조건을 끝까지 충족하지 못한 팔도 실제 형상·시간 이력을 반환하고 비교 rc 4를 남긴다. 표지는 물리적인 분리 자격, 시료 탄성회복 또는 논문 수치로 쓰지 않는다.
- 판–재료 간격은 입자 **서로 간**의 겹침과 다른 값이다. ID 간 형상을 정량 비교할 때는 기존 `scripts/dem_suyoung_overlap.py`의 `measure_frame`에 같은 프레임을 주어 점 중심 면적 추정과 셀 교집합 면적을 분리한다. 두 입자 영역의 겹침을 공극이 채워진 면적으로 집계하지 않는다.

## 1저자 WSL 블록

`PASTE_SUYOUNG_SHAPE_CYCLE_ONCE.txt`는 고정 커널·새 드라이버의 Git 바이트를 담은 자체 포함 ASCII 파일이다. WSL 프로젝트 venv의 NumPy와 CPU 한 개를 사용한다. S와 F를 각 1회 차례로 실행하고 팔당 내부 570초, 590초 TERM·600초 KILL이다. 과거 네 원판 압축 1,200 step은 팔당 약 4초였고, 이번 각 4,000 step·형상 쓰기의 실제 벽시계 시간은 미측정이다. 자동 재시도는 0이다. 입력 또는 한 팔의 기술 오류·시간 제한이면 중단하며 가능한 반환 파일을 묶는다.

반환물은 새 폴더의 결과 tar·SHA256SUMS·screen.txt다. `comparison.json`은 두 팔의 최종 지속 분리 관측 여부, `shape_pair.svg`는 공통 step 6장의 S/F 그림이다. `selected_setting=null`, `u6_qualified=false`로 둔다. 49원판 해상도 차이 0.00495694가 0.005 기준을 통과한 여유는 0.00004306(기준의 약 0.86%)이고 각 1회라 반복 오차는 미측정이다. 공식 선택은 1저자가 요청한 같은 조건 반복 결과와 후속 자격을 따로 본다.

최종 같은 12개 시험은 구본 12실패·오류 0 → 후보 12/12다. 첫 8개 실패를 확인한 뒤 구현했고, 수령 경계 보강에서 구 커널·공통 누락 프레임·음수 반력/비유한 간격이 각각 거부되는지 시험했다. S/F 두 팔·비교 진입에서 정정 커널 SHA256 `6e8073230f14142f3f802e1fed316bea22610502a98292e2ef794a123ea7e5f4`을 먼저 대조한다. 실제 개발 전 구간 실행은 1저자가 수행한다.
