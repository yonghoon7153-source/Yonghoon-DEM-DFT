## 설계 전에 알아낸 것 (PyPI 바퀴를 내려받아 읽음 · 설치 · 실행 0 · 읽은 뒤 지움)

1. **2D 평면 변형 + 유한 변형 J2 법칙이 10.4.4 에 없다** (바이너리 문자열 0 회).  유한 변형 J2 는 3D · 평면 응력에만 있다 → 주 경로 = **3D 한 층 + u_z = 0** (= 평면 변형).  2D 는 작은 변형 J2 뿐 → 교차 검산만.
2. J2 법칙은 **`KratosConstitutiveLawsApplication`** 에 있다.  주어진 설치 목록에 없었다 → 넣었다 (+8.3 MB).
3. **gmsh 4.15.2 는 PyPI 에 있지만** `libGLU.so.1` 을 요구하고 이 컨테이너에 없다 → 메셔 기본 = numpy (같은 O-격자) · gmsh 경로도 같은 스크립트에.
4. **닿으면 붙임 (분리 없음) 접촉이 Kratos 에 없다** (접촉 `.so` 에 Adhesion · Cohesive · Glued · Tied 문자열 0 · mesh tying 은 처음부터 묶음) → 2 단계 FE-G 대신 FE-S* (µ 5 · 분리 허용 · 'S 와 같은 것 아님').
5. 접촉 조건은 선형 면 (2D2N · 3D4N · 3D3N) 만 → 접촉 몸은 선형 요소 · 잠김 방지 = `TotalLagrangianQ1P0MixedElement3D8N` (소성 법칙과 짝 [미확인]).
6. 설치: 받기 ≈ 98 MB · 설치 뒤 ≈ 0.33 GB [추정] · cp311 (컨테이너) · cp312 (WSL) 해시 모두 고정.
