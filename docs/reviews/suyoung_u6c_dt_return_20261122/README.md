# 수영 U6(c) F8 반걸음 반환과 물질점 표본 대조

## 1. 반환 판독

1저자 WSL에서 F8 격자·초기 물질점 9,653개·접촉 설정 ①을 유지하고 시간 간격을 기존 F16과 같은 0.0011231835082397789로 줄였다. 고정 소스 `c36516a26d4a66f3db71c70de31b75802cb4bdb7`. F8 반걸음은 5,191걸음, 198.48초에 목표 압력을 걸쳤다. 실행·요약·명령은 모두 rc 0이었다.

직전 사전 지정 변위 `u = 0.11562281664031926`에 세 궤적이 모두 도달했다. 개발 반력은 아래판에 작용한 힘을 판 폭으로 나눈 값이다.

| 궤적 | 반력 (MPa) | 같은 변위에서의 부호 있는 차이 (MPa) |
|---|---:|---|
| 원 F8 | 1.200856 | 원 F8 − F16 = +0.565977 |
| F8 반걸음 | 1.170890 | 원 F8 − F8 반걸음 = +0.029966 |
| 원 F16 | 0.634878 | F8 반걸음 − F16 = +0.536012 |

지정 변위에서 원 차이의 5.29%가 줄고 94.71%가 남았다. **5.29%의 분모는 원래 두 팔의 차이**다. U6(c)에서 정한 분모는 공통 변위 구간의 F16 최대 반력 0.634878 MPa다. 이 분모로 읽은 반걸음 대조의 최대 차이는 **84.43%**다. F8의 시간 간격만 절반으로 줄여서는 기존 5% 기준에 이르지 못했다. 이 한 번의 시간 간격 대조를 시간 수렴 차수나 원인별 확률로 해석하지 않는다.

공통 구간 5,157점에서 원 F8과 반걸음 F8 차이의 절댓값은 최대 0.038050 MPa였다. F16 분모의 5%를 넘는 점은 원 비교에서 3,528개, 반걸음 대조에서 4,063개다. 가장 큰 차이는 줄었지만 초과 표본 수는 늘었다. 표본은 연속된 궤적에서 나온 변위점이다. 원 자격용 두 쌍의 고정 판독값 F8↔F16 89.15%, F12↔F24 19.11%는 그대로이며 U6(c) 자격과 단계 3은 보류한다.

## 2. 다음 한 팔 (결과 전)

시간 간격을 맞춘 F8과 F16은 격자와 원판을 채운 물질점 개수가 동시에 다르다. F8 격자에서 **F16의 원 물질점 39,053개**를 그대로 쓰는 개발 계산 한 팔을 추가한다. 고정된 초기 좌표·입자 ID·점 부피와 원판 49개의 순서를 확인한다. F8 반걸음에서 바뀌는 것은 초기 물질점 표본뿐이다. 원 F16과는 시간 간격과 초기 물질점이 같다.

| 같은 변위의 대조 | 고정한 것 | 관측할 차이 |
|---|---|---|
| F8 반걸음 − F8 조밀 표본 | F8 격자·시간 간격·판 속도·재료·접촉 설정 | 이 격자에서 바뀐 물질점 표본의 효과 |
| F8 조밀 표본 − 원 F16 | F16 물질점 전체·시간 간격·판 속도·재료·접촉 설정 | 같은 표본에서 격자를 바꾸었을 때 남는 차이 |

두 부호 있는 차이의 합을 같은 변위의 F8 반걸음 − F16과 대조한다. 두 대조의 개별 최댓값을 더하지 않는다. 주 비교점은 §1의 사전 지정 변위다. 새 팔이 1.2 MPa에 먼저 도달해 주 비교점이 빠지면 해당 칸은 미도달로 두며 외삽하지 않는다. 별도로 세 궤적 모두가 있는 구간에서 기존 F8 반걸음 − F16 차이가 가장 큰 변위를 표시한다. 이 순서에서 격자·표본 간 상호작용의 고유한 몫은 정해지지 않는다. 실패·시간 초과는 불완전으로 회수한다.

## 3. 1저자 실행과 회수

WSL CPU 한 코어에서 F8 조밀 표본 한 팔만 새로 계산한다. 두 개의 이전 반환 TAR를 벽 관측, 반걸음 관측 순으로 지정한다. 새 팔 소요 시간은 미측정이다. 앞선 F16 팔(같은 점 수)이 약 12분 33초 걸렸다. 새 팔 상한 30분, 판독 상한 별도 2분, 자동 재시도 0회다.

```sh
bash "$BLOCK" CHECK_ONLY "$WALL_TAR" "$HALF_TAR"
bash "$BLOCK" GO_SUYOUNG_F8_DENSE_SEED_ONCE "$WALL_TAR" "$HALF_TAR"
```

화면의 RETURN_DIRECTORY에서 suyoung_seed_result.tar.gz, screen.txt, SHA256SUMS를 회수한다. 원 자료는 1저자가 보존한다. §1의 두 입력은 `docs/reviews/suyoung_u6c_dt_return_20261122/check_dt_return.py`에 같은 순서로 주면 계산기 없이 판독을 재현할 수 있다.
