### 1-2. 허용 영역이 LII 에 거는 조건

G 와 LII 식을 합치면 (max_q > 0): **`LII ≤ m_P − 1e-4/max_q < m_P`**. 상자에서 `d_P − d_N ≤ 0.5 − 0 = 0.5` 이므로 **`LII ≥ m_P −
0.5/max_q`**. 즉 그들 영역 (상자 ∩ G) 에서 `m_P − LII ∈ [1e-4/max_q, 0.5/max_q]`.

## §3 목적함수 · 문턱 (R3)

| 이름 | 식 | 단위 · 비고 |
|---|---|---|
| **J_V** (V–Q) | `sqrt(f2(x))` = 100 점 RMSE | [V] |
| **J_D** (dV/dQ) | `sqrt(f4(x))` = 마스크 M = {i : `dVdQ_exp_interp[i] < 0.4`} 위 RMSE | [V/mAh] · M 이 비거나 값이 비유한이면 그 셀 · 목적은 **UNFIT** |
| **결합** | 벡터 제약 집합 `S_VD = {x ∈ A : J_V ≤ T_V, J_D ≤ T_D}` — 가중 합을 쓰지 않는다 | 점 추정 (H1 결합) = `argmin max(J_V/T_V, J_D/T_D)` — 각 목적의 문턱으로만 무차원화 · 규칙은 결과 전에 고정 |
| f1 · f3 | E3 에서만 그대로 (f1 은 제곱 오차와 RMS 를 섞은 합) | H 분석에 쓰지 않는다 |

| 문턱 | 정의 | 쓰는 곳 |
|---|---|---|
| 잡음 기준 | `T_V = J_V_hat + ε_noise` · `ε_noise = 2 σ̂_v` | **H2 주 판정** (V–Q) |
| 상대 | `T_o(δ) = (1 + δ) · J_o_hat` · δ ∈ {0.01, 0.05, 0.1, 0.2} 곡선 · 판정 δ = 0.1 | H3 (J_V · J_D · 결합) |
| 퇴화 분기 | J_o_hat 이 유한한 양수가 아니면 상대 문턱을 정의하지 않는다 → 그 셀 · 목적 UNFIT (상대 판정 없음) | floor 숫자를 만들지 않는다 |

**σ̂_v (맞춤 전 · 셀마다):** 그들 추출 경로가 낸 원 측정점 (중복 제거 뒤 · 보간 전) 의 V 를 **표본 순서** 위에서 Savitzky–Golay
(polyorder 3 · window 21 · `mode='interp'` = SciPy 기본) 로 평활하고 `σ̂_v = RMS(V − SG(V))`. Q 간격이 불균일해도 보정하지 않는다
(`savgol_filter` 는 Q 좌표를 받는 불규칙 격자 평활기가 아니다). 점이 21 개 미만이거나 비유한 값이 있으면 **UNFIT** (조용히 버리지
않는다). **이 2σ̂_v 는 사전 고정한 경험적 허용 폭이다** — 잡음 표준편차의 검증된 추정도 95 % coverage 도 아니다 (선형 평활기 S 의 잔차
(I − S)y 의 RMS 기대값은 독립 잡음에서도 일반적으로 σ 와 같지 않다 — 검토자 해석). χ² · 우도 문턱으로 바꾸지 않는다 (잔차 모형 · 상관 ·
유효 자유도 가정이 없다).

H2 (잡음 기준) 와 H3 (상대 기준) 는 별도 표다. 반복 셀 (11 셀 × 3 좌표 × 허용오차 2 × 영역 × 목적) 을 독립 표본 수나 통계적 신뢰도
증가로 세지 않는다.

### 4-3. 점 추정 (H1)

시작점 = Sobol 64 (scramble · seed 0) + 독립 Sobol 64 (seed 1) 를 영역에 펼친 것 (G 를 어기는 시작점은 그대로 둔다 — 지역 방법이
제약을 처리한다) · 지역 방법 = **COBYQA** (SciPy `minimize` · 경계 = 영역 상자 · G 는 `LinearConstraint` · 도함수 없음 — 목적에 index
선택 · 구간 보간의 불연속이 있다 · 옵션은 판 기본값 · `maxfev = 2000` = 4 변수 기본값) · `J_hat` = 128 결과의 최소 · 두 seed 묶음 각각의
최소를 함께 보고 (탐색 안정 지표 — 문턱 없음). 결과 x 마다 상자 잔차 · G 잔차 · J 를 **독립 재계산**한다. v1 의 L-BFGS-B → Nelder–Mead
는 일반 부등식을 강제하지 못하므로 철회한다.

### 4-4. 집합 (H2 · R1) — 대상은 H(S)

`S = {x ∈ A : J(x) ≤ T}` · 대상 `h(x) = (m_P, m_N, LII)` · 묻는 것은 "명목 ∈ S" 가 아니라 **h_true ∈ H(S)** 다.

| 측정 | 정의 |
|---|---|
| 개별 투영 (프로파일) | 좌표 k 마다 `J_k(t) = min{J(x) : x ∈ A, h_k(x) = t}` — 우도가 아니라 **목적값의 제약 최소**다. t 격자 = 그 영역에서 h_k 가 가질 수 있는 범위 (선형 계획) 의 41 등분점 + 명목 · 명목 ± 0.02 · ± 0.05 (참값은 맞춤 전에 알려져 있으므로 사전 고정). 내부 최소화 = 시작 4 (이웃 격자점의 최적 둘 + Sobol 둘) · COBYQA · `h_k(x) = t` 는 선형 등식 제약. 발견 투영 = `{t : J_k(t) ≤ T}` — **끊긴 구간을 그대로 보고**한다 (min/max 사이를 채우지 않는다) |
| 개별 양립 (좌표 k) | `[t_k − τ, t_k + τ]` 안의 격자점 중 `J_k(t) ≤ T` 가 있으면 증인 (그 내부 최적 x) |
| 동시 양립 | `min{J(x) : x ∈ A, ‖h(x) − h_true‖∞ ≤ τ}` (선형 제약 · 시작 16) `≤ T` 이면 동시 증인. 개별 양립 셋이 있어도 동시 양립은 따로 묻는다 — 두 점 (0, 1) · (1, 0) 의 좌표 범위는 [0, 1] 이지만 (0, 0) 은 집합에 없다 |
| 명목점 정확 대조 (τ = 0) | m_P · m_N 을 명목에 고정하면 `d_P − d_N = max_q (m_P − LII_true)` 로 정해지고 남는 nuisance 는 공통 offset `d_N` 하나 → 그 허용 구간에서 1 차원 격자 (201 점) + 최저점 COBYQA 다듬기로 `min J` |

### 4-5. 판정 상태 (R2 — 실용 선택)

| 상태 | 조건 | 허용되는 해석 |
|---|---|---|
| **COMPATIBLE** | 증인 (개별 또는 동시 — 어느 쪽인지 적는다) 발견 · 독립 재계산으로 `J ≤ T` · 영역 잔차 0 확인 | 이 모델 · 문턱 · 영역에서 명목과 양립 |
| **WIDE** | 발견 투영에서 서로 2τ 넘게 떨어진 증인 둘 | 이 정의 · 탐색에서 넓은 허용 범위 확인 — T 가 J_hat (인증된 J* 아님) 기준이므로 인증된 집합의 넓음으로 자동 승격하지 않는다 |
| **NARROW_FOUND** | 발견 투영 폭 ≤ 2τ | **UNRESOLVED** — 좁음 확정 아님 (발견 폭 ≤ 참 폭) |
| **NOT_FOUND** | 증인 없음 | **UNRESOLVED** — 배제 확정 아님 (optimizer 가 증인을 못 찾은 것은 포함 부정의 증명이 아니다) |
| **PRIOR_INCOMPATIBLE** | P0 에서 영역 ∩ 허용오차 상자가 빈 집합 | 맞춤 전 대수적 배제 — 편향 · 축퇴 칸에 넣지 않는다 |
| **UNFIT** | 빈 마스크 · 비유한 목적 · ε 정의 불가 · 지역 방법 전부 실패 · 자료 영역 부적합 | 별도 실패 — 편향 · 축퇴 칸에 넣지 않는다 |

- 문구 축소: v1 의 "식별 + 무편향" → "명목 양립 + 좁게 발견 (미해결)" · "편향" → "명목 양립 미확인". 조건당 명목값 하나의 비교로
  추정기의 통계적 무편향을 말하지 않는다.
- **비대칭을 미리 적는다:** 이 설계에서 축퇴 논지의 지지는 **양의 증거로만** (COMPATIBLE + WIDE) 성립하고, 식별 (좁음) 은
  UNRESOLVED 로만 남는다. 강한 식별 주장 (전역 하한 · 극값 인증) 은 이번에 등록하지 않는다 — 필요하면 별도 설계.
- 경계 행 (#0 · #4 · #5) 의 LII 폭에는 "제약 절단" 을 붙인다 · A1/A2 에서 열리면 그 차이를 보고한다.

## §5 H4 형상만 — 정규화 계약 (R6)

v1 의 "용량 열을 Q_max 로 나눈다" 는 모델의 절대 좌표 · offset · cutoff 를 남긴다 (실험 Q 만 나누면 다른 단위의 좌표 대입이 된다) →
철회하고 다음으로 바꾼다.

| 항목 | 정의 |
|---|---|
| 정규화 | 실험과 모델 **각각** 같은 cutoff (2.0 V · 3.6 V) 의 용량 `Q_lo · Q_hi` 로 `s = (Q − Q_lo)/(Q_hi − Q_lo)` |
| 실험 쪽 | `Q_lo = 0` · `Q_hi = Q_exp_max` — 그들 추출 구간이 cutoff 에서 cutoff 까지라는 가정. P0 의 끝점 전압 기록으로 확인하고, 아니면 그 셀은 H4 UNFIT |
| 모델 쪽 | `V_full(Q)` 의 2.0 · 3.6 V 교차를 `Q ∈ [0, max Q_PE]` 의 1000 점 격자에서 선형 보간으로 구한다 (원 코드의 250 점 argmin 은 쓰지 않는다 — 격자 의존 제거). 교차가 없거나 둘 이상이면 그 x 의 H4 목적은 비유한 |
| 목적 | `J_V^s = RMSE_k |V_sim(s_k) − V_exp(s_k)|` · `s_k = linspace(0, 1, 100)` [V] · 미분형은 `dV/ds = (Q_hi − Q_lo) dV/dQ` 를 양쪽에 각자의 span 으로 적용하고, 마스크는 실험 쪽에서 `0.4 V/mAh × (Q_hi^exp − Q_lo^exp)` 로 환산해 같은 실험 점 집합을 쓴다 (이번 등록은 `J_V^s` 만 판정 · 미분형은 기록만) |
| 남기지 않는 것 | 절대 용량 잔차 · 원 용량의 은닉 가중치 |
| 대칭 대조 (구현 검증 — 결과 전) | 정적 모델에서 `x → c·x` 이면 Q 축과 LII 가 c 배가 된다 (코드 식에서의 조건부 대칭 — 실측 셀의 동역학 검증이 아니다). **양성:** x 와 c·x (c ∈ {0.9, 1.1}) 가 둘 다 영역 안 · 외삽 0 일 때 `|J_V^s(x) − J_V^s(c·x)| ≤ 1e-9 V` · **음성:** 절대 용량 J_V 는 둘을 구별한다. 양성이 깨지면 **H4 구현을 기각**한다. 고정 1e-4 부등식과 상자는 전역 scale 불변 영역이 아니므로 대조 쌍이 둘 다 허용 영역 안인지 먼저 확인한다 |
| 예측 (v1 유지) · 반증 | 형상 목적에서 근최적 집합은 척도 방향 `{c·x̂}` 으로 열린다 — 그 방향이 영역 경계 (상자 · G · 외삽 시작) 에 닿는 곳까지. 보고: 셀마다 열린 방향의 두 끝과 그 원인. 반증: 대칭 양성이 통과한 구현에서 ray 위의 점 (직접 평가) 이 `T` 를 넘으면 예측 기각. 상자 끝에 닿았다는 사실만으로 실측 세 모드가 구조적으로 식별 불가능하다고 확정하지 않는다 |
