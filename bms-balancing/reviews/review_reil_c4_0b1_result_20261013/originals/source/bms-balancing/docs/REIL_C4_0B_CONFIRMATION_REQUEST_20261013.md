# REIL C4-0b 착수 확인 요청 — H 실행기 + 미봉인 배열 3 종 · 2026-10-13

> 근거:
> - C4-0a 종결 (상태 문서 §45 · 재검토 판정 `C4_0A_LIMITED_IMPLEMENTATION_CLOSED_WITH_DOCUMENTED_SCOPE`).
> - §39 — C4-0b = H 실행기 (C4 v2 §4-2) · RED 1 · GREEN 1 · 건조 1 · 같은 배정 · 전체 4 h.
> - §42 · §45 — C4-0b 착수 확인에 미봉인 배열 3 종의 목록 · 배정 · 봉인 시점을 넣는다.
>
> 이 문서는 사용자 확인 요청이다. 확인 전에는 아무것도 실행하지 않는다. C4-0 범위 자체는 이미 승인됐다 (§36 · C4 v2 §8) — 이 확인은 그 안의
> C4-0b 착수 문턱이다.

## 1. 봉인할 것 — 맞춤 전 · 첫 국소 실행 전 (부속 B §2-1)

부속 B §2-1 은 첫 지역 실행 전에 **규칙 · label 형식 · 자료에 기대지 않는 고정 배열 전부**를 봉인하라고 한다. Phase A Sobol 64 × 2 는 C4-0a 에서
봉인했다 (`reil_c4_arrays_20261013/`). 남은 것은 다음 넷이다.

| 묶음 | 정의 (근거) | 개수 (상한) | label |
|---|---|---|---|
| **profile Sobol 2** | 단위 × 좌표 k ∈ {m_P, m_N, LII} × 격자점마다, 등식 소거 뒤 자유 변수 상자 위 2 점 (s3 · s4 — 부속 A §3-3 · B §2-2) | ≤ 77 × 3 × 46 = **10,626 배열** (각 2 × 3) | `reil-v2a\|셀\|영역\|목적\|profile\|k\|격자 index\|-` |
| **동시 Sobol 16** | 단위 × τ ∈ {0.02, 0.05} 마다, 상자 P × N × (d_P 상자) × (d_N 상자) 위 16 점 (부속 A §3-4 · B §2-3) | ≤ 154 − 20 = **134 배열** (각 16 × 4) | `reil-v2a\|셀\|영역\|목적\|simultaneous\|-\|-\|τ` |
| **label → seed 표** | 위 두 묶음의 모든 label 과 seed = `int(sha256(label)[:8], 16)` (부속 A §3-6) | 두 묶음 label 수의 합 | — |
| **규칙 · label 형식** | 순회 · 동률 · 대체 · 중복 · 부족 규칙과 label 문자열 형식 (부속 B §2-1) | 기록 1 | — |

- **단위 77:** H1 / H2 J_V × {A0, A1, A2} × 11 = 33 · H3 {J_D, ρ} × A0 × 11 = 22 · H4 J_V^s × {A0, A1} × 11 = 22 (C4 v2 §1).
- **격자:** 좌표 k 의 t 범위 (부속 A §2-5 의 닫힌 식) 를 41 등분한 점에 명목 · 명목 ± 0.02 · ± 0.05 를 더한다. 범위 밖과 같은 float 은
  빼므로 ≤ 46 점이다. 격자는 P0 기록 (`P0_RESULT.json` 의 max_q · 사전표) 으로 정해진다 — 자료 개봉이 아니라 이미 있는 P0 결과를 읽는다.
- **동시 상한의 −20:** P0 의 `PRIOR_INCOMPATIBLE` 칸에서는 돌리지 않는다. C4 v2 §1 의 산술 "동시 −320 실행" = 20 (단위 · τ) × 16 이다.
- **16 전부 봉인 · 앞 12 만 사용.** 12 점에 16 점 Sobol 의 균형 성질을 주장하지 않는다 (부속 B §2-3).
- **정확한 개수는** C4-0b 가 P0 기록에서 계산해 봉인 기록에 적는다. 위 숫자는 상한이다.
- **봉인 형식 제안:** label 이 1 만 개를 넘으므로 배열 파일을 label 마다 두지 않는다. 단위마다 npy 하나 + label 색인 (label · seed · 행 범위 ·
  그 배열의 raw float64 sha) 으로 묶고, raw sha 와 npy sha 를 따로 적는다 (C4 v2 §4-3).
- **C4-0b 에서 봉인하지 않는 것 — 적응적 시작점:** profile s1 · s2 와 동시 양립의 Phase A 상위 증인. 앞선 결과에 기대므로, 그것을 쓰는 지역
  실행 직전에 봉인한다 (부속 B §2-1 둘째 행).

**label 토큰 제안 (봉인할 label 형식 — 확인 부탁):**

| 칸 | 값 |
|---|---|
| 셀 # | P0 분석 행 번호 `0`–`10` |
| 영역 | `A0` · `A1` · `A2` |
| 목적 | `J_V` · `J_D` · `rho` · `J_Vs` |
| 단계 | `profile` · `simultaneous` |
| k | `m_P` · `m_N` · `LII` (해당 없으면 `-`) |
| 격자 index | 오름차순 격자에서의 0 부터 번호 (해당 없으면 `-`) |
| τ | `0.02` · `0.05` (십진 문자열 · 해당 없으면 `-`) |

- **해석 하나를 밝힌다:** C4 v2 §4-3 의 "label-seed 배열" 을 위 **label → seed 표**로 읽었다. 검토 때 확인받는다.

## 2. H 실행기 범위 (C4 v2 §4-2)

- 영역 A0 / A1 / A2 (A2 는 G 없음).
- 목적 J_V · J_D · ρ · J_V^s (교차점 · 끝점 ν · 1000 점 근사 — 부속 A 291–313 · B 137–147).
- Phase A (128 실행 · 결합 ρ Phase A 포함).
- Phase B — profile 소거 · 등록된 대체 사슬 · 동시 · 명목 격자 201 점 + 1-D 다듬기.
- H4 대조 (양성 R1–R3 · 음성) · ray · 공통 갱신 · 문턱 (H2 T_V · H3 δ · H4 T_s) · 표지 · 부속 B 의 증인 분류.
- 위 배열 · 규칙 봉인, 적응적 시작점의 "쓰기 직전 봉인" 연결.
- 합성 입력과 보존 util 사본만 쓴다. 자료 개봉 · 맞춤 · 실제 H 실행 (C4-A · C4-B) 은 이 범위가 아니다.

## 3. 배정 — 그리고 하나로 할지 둘로 나눌지

§39 의 배정은 identity 60 · RED 600 · GREEN 600 · 배열 봉인 240 · 건조 300 = **계산 1,800 s · 전체 작업 4 h** · 자동 재시험 0 이다.
실행은 이 세션에서 한다 (수용된 C4 환경이 여기 있다). 시작할 때 identity 를 대조하고, 맞지 않으면 시작하지 않는다.

솔직한 판단: H 실행기는 프로토콜의 대부분 (Phase A · B · H4 대조 · ray · 공통 갱신) 이다. C4-0a (감시 보완 + E3a) 보다 몇 배 크고, GREEN 은 한
번뿐이다. 4 시간 한 번에 다 넣으면 시간 안에 끝나지 않거나, GREEN 의 예상 밖 실패로 멈춰 결국 한 바퀴를 더 돌 가능성이 높다.

| 안 | 내용 | 장단점 |
|---|---|---|
| **A · 한 번에** | C4-0b 하나 (§39 그대로) | 확인 · 검토가 한 번. 넘치면 미완으로 멈추고 다시 승인 |
| **B · 둘로 (권장)** | **C4-0b1:** 배열 · 규칙 봉인 (위 넷 전부) + H 핵심 — 목적 넷 · Phase A · 결합 ρ · 증인 분류 · 정확 잔차 · 문턱 · 공통 갱신. **C4-0b2:** Phase B (profile 순회 · 대체 사슬 · 적응적 시작점 봉인 연결 · 동시 · 명목) + H4 대조 · ray · 표지. 각각 같은 배정 (0b2 에는 배열 봉인 240 s 없음) | 단계마다 GREEN 실패의 범위가 작다. RED / GREEN 이 C4-0 전체로 각 3 회가 된다 (검토자에게 밝힌다) |

- 어느 안이든 배열은 **첫 번째 단계에서 전부** 봉인한다. 첫 확인적 국소 실행 (C4-A) 전이라는 시점 규칙을 지킨다.
- 어느 안이든 C4-E / A / B (자료 실행) 는 C4-0b 가 끝나고 검토를 거친 뒤 따로 승인한다.

## 4. 정하실 것

1. **배열 목록 (§1)** — 토큰 표와 "label-seed = label → seed 표" 해석으로 진행해도 될지.
2. **A (한 번에) 또는 B (둘로)** — 권장은 B.
3. **착수** — 확인하시면 이 세션에서 바로 시작한다 (B 면 C4-0b1 부터 · 결과 제출 뒤 멈춤 · 0b2 는 다시 확인).
