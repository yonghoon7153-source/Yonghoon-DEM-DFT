## Q1. BZ 필수 수정 이행 — 부분 GO, G2는 NO-GO
이행을 확인한 것은 다음이에요.

* G5의 종결별 평균 복구와 G3/G4 PASS 선행 조건.
* 고정 마스크 생략·음수 인덱스·정책 집합 불일치 차단.
* 초기·최종 좌표와 셀의 NaN 차단.
* 초기 법선 유지와 최종 흡착면 뒤집힘 차단.
* 정상 V2 구조의 검사 경로 신설.
* DEM 문구를 "성립한다"에서 "변경된 조건의 적용 가능성을 확인 요청한다"로 정정.
* S1/S3 경계와 선행 작업 예외 명시.

Ag₄도 비영 초기 자화·총자화와 절대자화 기록·고립 조각 한정이라는 BZ 요구를 반영했어요. 다만 선언한 비편극 모델을 사용하는 정책이지, 모든 흡착 끝점의 비자성을 검증했다는 뜻은 아니에요.

### P0 — V2 측방 마스크가 여전히 선택 입력이에요
`se_sym_slab.py:1174`는 측방 마스크 누락을 빈 목록으로 받고, 제공된 목록만 검사해요. 그 목록이 그래핀 전체인지 검사하지 않아요.
배포 selftest의 V2 합성 구조로 재현했어요.

* 그래핀 전체를 x 방향으로 0.1 Å 이동하고 올바른 측방 마스크 제공 → 차단.
* 같은 구조에서 측방 마스크 생략 → `flags=[]`, CLI 종료 코드 0.
* 측방 마스크에 움직이지 않은 Ag 원자만 제공 → 통과.
* 그래핀 원자 하나를 움직이고 그 원자만 측방 마스크에서 제외 → 통과.

즉 "검사 함수를 지우면 시험이 실패한다"는 것은 확인됐지만, 검사 대상 목록을 비우는 경로는 여전히 열려 있어요.
필수 수정: V2 정책에서는 측방 마스크를 필수로 하고, 초기 구조의 그래핀 원자 전체 집합과 정확히 일치하도록 대조하세요. 누락·빈 목록·부분집합·다른 몸체의 원자 목록에 대한 음성 시험도 연결해야 해요.

### P1 — 정수 검사가 아니라 정수 변환이에요
`se_sym_slab.py:1134`의 `int(i)`가 잘못된 값을 조용히 고쳐요.

* 올바른 마스크 `[0, 1, …, 17]` 대신 `[0.9, 1.9, …, 17.9]` → 정책 일치·통과.
* 첫 값을 `-0.9`로 변경 → `0`으로 바뀌어 통과.
* `False/True` → `0/1`로 바뀌어 통과.

소수 목록을 JSON 파일로 제공하는 CLI 경로도 종료 코드 0을 재현했어요.
필수 수정: 변환 전에 원소 타입을 검사하세요. JSON에서는 불리언을 제외한 정수만 허용하고, CLI 문자열 파싱과 내부 인덱스 검증을 구분하면 돼요.

## Q2. G3의 두 셀 조작 — 조건부 GO
카드 G3 (v3 L193)의 기하 조작은 맞아요.

* 기준: 직접/영상 간격 `8/8`.
* 셀 c만 +2 Å: `8/10`.
* 셀 c와 흡착층 z를 각각 +2 Å: `10/8`.

기존의 `10/6` 문제는 해결됐어요. 두 변화를 한 번에 적용한 단일 검사보다도 명확해요.
다만 기하 변수의 분리와 에너지 기여의 완전한 분리는 달라요. 두 검사 모두 셀이 커지므로 결합 끝점 에너지도 달라져요.
`ΔW = [ΔE_far − ΔE_bound] / A`
따라서 두 ΔW가 작다고 해서 각각의 끝점 변화나 모든 상쇄가 없었다고 말할 수는 없어요. 이는 W라는 차이량의 성질이지, 현재 검사를 폐기할 이유는 아니에요.
봉인 전 보완:

* 문턱을 명확히 **`|ΔW|`·`|ΔE|`**로 적으세요.
* 이미 계산하는 `ΔE_far`, `ΔE_bound`, 최종 `ΔW`를 각각 기록하세요.
* 허용 문구는 **"지정한 두 간격 변화에 대한 W 민감도 통과"**로 제한하세요. "모든 주기영상 효과 제거"나 무한분리 수렴 인증은 아니에요.

새 셀 계산을 추가하라는 요구는 아니에요.

## Q3. S군 3개·Li군 2개 — GO
지정한 유한 표본의 운영 기준으로는 괜찮아요. 두 군의 개수를 같게 만들거나 독립 표본이라고 주장할 필요는 없어요.
BZ 반례 `+0.06,+0.06,−0.09,−0.09,+0.06`을 다시 계산하면 전체 평균은 0이지만 S군은 +0.06, Li군은 −0.09예요. 복구된 v3 규칙은 이를 탈락시켜요.
다만 허용 문구 93행에는 아직 평균 앞의 **"종결별"**이 빠져 있어요. 실제 G5와 동일하게 고치세요. 표본 ①·⑤의 상관성 한정은 그대로 유지하면 돼요.

## Q4. S3 전 예외 작업 — 조건부 · P1
예외를 입력·정지·출력·금지 사용으로 나눈 방향은 맞아요. 다만 두 군데를 닫아야 해요.
첫째, CPU 프로브가 허용 목록에서 빠졌어요. S2에는 CPU 프로브가 있지만, 예외 목록 62–88행은 GPU 프로브만 적고 "이 넷 밖의 pw.x는 위반"이라고 해요. ③을 CPU/GPU 자원 프로브로 묶고 각 정지 조건을 적으면 해결돼요.
둘째, `electron_maxstep=2`는 실행 전체의 종료 보장이 아니에요. QE에서 이는 한 SCF 단계의 최대 반복 수예요. 이완 입력이면 다음 이온 단계가 생길 수 있고, 2회 안에 수렴할 수도 있어요. 프로브를 `calculation='scf'`로 한정하고, 전용 실행·스크래치와 자원 가드를 명시하세요. [QE 공식 규약](https://www.quantum-espresso.org/Doc/INPUT_PW.html#electron_maxstep)
"에너지 기록 금지"도 다음처럼 좁히는 편이 맞아요.
원출력은 감사용으로 보존한다. 프로브 에너지는 결과표·W 계산·후보 선택·게이트 조정에 사용하지 않는다.
원출력을 지워서 못 보게 만드는 것이 사전등록을 지키는 방법은 아니에요.

## Q5. Registry 선택 규칙 — 조건부 · P1
초기 구조만 사용한다는 경계는 맞아요. 다만 선택 규칙 55행은 주기경계에서 아직 하나의 좌표를 정하지 못해요.
예를 들어 길이 10 Å인 셀에서 두 원자의 x가 0.1과 9.9 Å이면:

* 좌표를 그대로 평균한 중점: 5.0 Å
* 가까운 주기영상을 사용한 중점: 0.0 Å

원자 인덱스는 같은데 전혀 다른 registry가 돼요. 이는 규칙의 수학적 반례이며, 아직 없는 빌더가 실제로 틀렸다고 주장하는 것은 아니에요.
필수 명시:

* A 후보는 `z_max − z_i < 0.05 Å`처럼 최대 높이에 대한 집합으로 정의.
* B의 이웃 후보가 어느 표면 집합인지 정의.
* 면내 최소영상의 변위와 이미지 오프셋으로 중점을 계산.
* 동거리일 때 원자 ID뿐 아니라 이미지 오프셋까지 순서를 정함.
* 중점을 정해진 셀 안으로 감고, 선택 원자·이미지·좌표를 S2에 기록.

새 물리 기준보다 동일 입력에서 동일 registry가 나오게 만드는 명세 보완이에요.

## Q6. S1 digest 구성 — 설계 GO
S1에 방법·선택 규칙을 고정하고, S2에서 실제 입력을 기록하며, S3에서 산출 좌표와 계보를 봉인하는 경계는 맞아요.
카드에 적힌 결정 아홉 개의 digest를 현재 결정 본문에서 직접 재계산했어요. 모두 카드·비준 기록·본문이 일치하고 상태도 `active`예요.
UMA 체크포인트·환경·빌더가 아직 비어 있다는 것은 요청에서 이미 선언한 미완료 항목이므로, 이번에 새 결함으로 세지 않겠어요. 다만 빈 상태 그대로 S1 봉인해도 된다는 승인은 아니에요. 값을 채우고 사용 전에 결박한다는 조건은 그대로예요.
