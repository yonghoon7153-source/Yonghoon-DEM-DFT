# 후막 복합양극 DEM (LIGGGHTS) raw 데이터 — 인수인계 README

받는 사람이 **바로 계산에 들어갈 수 있게** 쓴 문서다.  이 폴더의 파일은 건식 후막 ASSB
복합양극을 LIGGGHTS 로 압밀한 결과이고, 목적은 그 좌표에서 **미세구조 디스크립터**를 뽑는 것이다.

> ⚠⚠ **먼저 읽을 것 — 이 데이터는 스케일된 단위로 저장돼 있다.**
> 파일 안의 숫자를 µm 로 읽으면 **1000배 틀린다**.  §2 를 건너뛰지 말 것.

---

## 1. 파일 구성

| 파일 | 무엇 | LIGGGHTS 명령 |
|---|---|---|
| `input_real_*.liggghts` | **입력 스크립트 = 모든 규약의 정본** | — |
| `atom_restart3_<step>` | 입자 스냅샷 (좌표·반지름·속도·응력) | `dump ... custom` |
| `contact_restart3_<step>` | **접촉쌍** 목록 (힘·접촉면적·중첩) | `dump ... local` |
| `mesh_restart3_<step>` | 상부 가압판 STL (그 시점 높이) | `dump ... mesh/stl` |

⚠ 파일명이 `atom_restart3_*` 인 것은 **restart 에서 이어 돌린** 런이라서다.  입력 스크립트의
`dump` 경로(`post_real_1/atom_*.liggghts`)와 이름이 다르지만 **열 구성은 같다**.

`<step>` 은 타임스텝이다.  `dt = 1.0e-6`, 진행은
**① 삽입 → ② settling(20만) → ③ stabilize(20만) → ④ 압축(300 MPa 도달까지 루프) →
⑤ 이완(10만)** 순이고, atom dump 는 ④ 부터, contact dump 는 ⑤ 부터 켜진다.
⇒ **contact 파일이 존재하는 스텝은 이미 압축이 끝난 상태다.**  그 스텝을 쓰면 된다.
(가장 큰 스텝이 최종 상태인지 폴더에서 한 번 확인할 것.)

## 2. ★★ 단위 — 여기가 유일하게 크게 틀릴 수 있는 곳

입력 스크립트 머리에 규약이 적혀 있다:

```
# Scale: r×1000, E×0.001, P×0.001
units si
region reg_box block 0.0 0.05 0.0 0.05 -0.01 1.0     # "RVE: 50×50 μm → Sim 0.05×0.05 m"
variable r_AM_S equal 2.0e-3                          # "AM_S r=2μm → Sim 2mm"
```

| 물리량 | 변환 | 검산 |
|---|---|---|
| **길이** | `물리[µm] = 파일값 × 1000` | 상자 0.05 → **50 µm** · `radius` 2.0e-3 → **2 µm** |
| **응력/압력** | `물리[MPa] = 파일값 × 1000` | `target_press = 0.30` → **300 MPa** |
| **탄성계수** | `물리[GPa] = 파일값 × 1e-9 × 1000` | `1.4e8 Pa` → **140 GPa** (NCM811) |
| **밀도** | **스케일 안 됨** (실제값) | AM 4800 · SE 2000 kg/m³ |

⇒ 좌표·반지름은 **× 1000 하면 µm** 다.  그것 하나만 지키면 기하 계산은 전부 맞는다.

**자가검증 (반드시 한 번 하고 시작할 것)**
`radius` 열의 고유값 × 1000 이 입력 스크립트의 `r_AM_S` / `r_SE` / `r_AM_P` (µm) 와
정확히 같아야 한다.  안 맞으면 위 변환을 적용하지 말고 먼저 원인을 찾을 것.

## 3. ★★ 타입 번호 — **케이스마다 다르다.  절대 가정하지 말 것**

`input_real_1` 은 P:S = **0:10** (소립만) 이라 타입이 **둘뿐**이다:

```
create_box 2 reg_box
# --- 3. Material Properties (Type 1:AM_S, 2:SE) ---
fix pts1 all particletemplate/sphere ... atom_type 1 ... radius constant ${r_AM_S}
fix pts2 all particletemplate/sphere ... atom_type 2 ... radius constant ${r_SE}
```

⇒ 이 케이스에서 **type 1 = AM_S(소립 활물질) · type 2 = SE(고체전해질)**.

⚠ 대립이 들어가는 케이스(3:7 · 5:5 · 7:3 · 10:0)는 타입이 **셋**이고 번호가 달라진다.
**케이스마다 그 케이스의 입력 스크립트에서 `create_box` 줄과 `Material Properties` 주석,
`particletemplate` 의 `atom_type` ↔ `radius` 짝을 직접 읽어서 매핑할 것.**
가장 안전한 판별은 **반지름**이다 — 활물질(대립/소립)과 전해질은 크기가 확연히 다르다.

## 4. dump 열 구성

### 4-1. `atom_*` — 입력 스크립트 167행 그대로

```
id type x y z radius vx vy vz c_strs[1] c_strs[2] c_strs[3] c_ke
```

| 열 | 뜻 | 비고 |
|---|---|---|
| `id` | 입자 ID | contact 파일과 이걸로 연결 |
| `type` | 재료 (§3) | |
| `x y z` | 중심 좌표 | **× 1000 → µm** |
| `radius` | **반지름** (직경 아님) | **× 1000 → µm** |
| `vx vy vz` | 속도 | 이완 후엔 ~0 이어야 정상 |
| `c_strs[1..3]` | per-atom 응력 **σxx, σyy, σzz** | ⚠ 아래 주의 |
| `c_ke` | 운동에너지 | 준정적 확인용 |

⚠ **`compute stress/atom` 은 응력이 아니라 `응력 × 부피`** 다 (LAMMPS/LIGGGHTS 규약).
입자 응력을 얻으려면 **입자 부피 (4/3)πr³ 로 나눠야** 한다.  그 위에 §2 의 압력 스케일
(×1000 → MPa)이 또 걸린다.  **검산**: 이렇게 얻은 σzz 를 전체 평균 내면 가한 압력
**≈ 300 MPa** 가 나와야 한다.  안 나오면 응력은 쓰지 말고 기하만 쓸 것 (기하는 안전하다).

### 4-2. `contact_*` — `compute pair/gran/local` (입력 74행 / dump 185–189행)

```
compute cpl all pair/gran/local pos id force force_normal force_tangential torque contactArea delta contactPoint
dump ... c_cpl[1] … c_cpl[26]
```

키워드 순서대로 열이 붙는다.  내 계수로는:

| 키워드 | 열 수 | 누적 |
|---|---|---|
| `pos` | 6 (x1 y1 z1 x2 y2 z2) | 1–6 |
| `id` | 2 (id1 id2) | 7–8 |
| `force` | 3 | 9–11 |
| `force_normal` | 3 | 12–14 |
| `force_tangential` | 3 | 15–17 |
| `torque` | 3 | 18–20 |
| `contactArea` | 1 | 21 |
| `delta` | 1 (중첩량) | 22 |
| `contactPoint` | 3 | 23–25 |

⚠ **합이 25 인데 dump 는 26 개를 쓴다.**  한 열이 내 계수와 안 맞는다 (빌드에 따라
`torque` 가 6 열이거나 접촉 플래그가 하나 더 붙는 경우가 있다).
⇒ **열 인덱스를 믿기 전에 파일 헤더의 `ITEM: ENTRIES` 줄과 실제 열 개수를 직접 세어
확인할 것.**  검산 두 가지: ⓐ `id1`/`id2` 열은 정수이고 atom 파일의 `id` 집합에 들어간다
ⓑ `pos` 두 점 사이 거리가 `r1 + r2 − delta` 와 같다.

### 4-3. `mesh_*` — 상부 가압판 STL

그 시점의 판 높이 `plate_z` 를 준다 (STL 정점의 z).  **전극 두께 = plate_z − 0**
(바닥 벽이 `zplane 0.0` 이다).  ×1000 하면 µm.

## 5. 경계조건 — 계산 전에 알아야 한다

```
boundary p p f
```

- **x, y = 주기경계 (periodic)** ⇒ **측면 벽이 없다.**  좌표를 그대로 쓰면 상자 경계에서
  이웃을 놓친다.  **최소상거리(minimum image)** 로 이웃·접촉·경로를 계산할 것.
  상자 = `0 ≤ x,y < 0.05` (물리 50 µm).
- **z = 고정 (fixed)** — 아래는 벽(z=0), 위는 가압판(mesh).  z 는 주기화하지 말 것.

## 6. 뽑아야 할 디스크립터

| 디스크립터 | 정의 (합의된 규약) |
|---|---|
| **porosity** | `1 − Σ(4/3)πr³ / (50 × 50 × 두께)` — **구 부피의 단순 합**을 쓴다 (겹침을 빼지 않는다). 소성 압밀에서 밀려난 재료는 부풀음으로 되돌아온다는 관례이고, 우리 코퍼스 전체가 이 규약이다. 참고용으로 union 부피(겹침 제거)도 같이 내면 좋다 — 둘의 차이가 곧 겹침량이다. |
| **coverage (대립 / 소립 / 전체)** | 활물질 구 표면 중 **SE 가 덮은 면적 비율**. 표면을 균일 샘플(예: Fibonacci 구면점)하고, 각 점에서 가장 가까운 SE 구까지의 간극이 문턱 이하면 "덮임". 문턱은 **두 개를 병기**할 것 — 접촉(간극 ≤ 0) 과 근접(간극 ≤ 0.14 µm). 둘의 차이가 물리적으로 의미가 있다. |
| **tortuosity** | SE 상(相)을 따라 아래 → 위로 가는 경로의 `경로길이 / 직선거리`. SE 구를 노드, 접촉을 간선으로 놓고 최단경로를 쓰면 된다. **주기경계(§5)를 반드시 반영**할 것. |

두 개 더 같이 내주면 아주 유용하다: **배위수**(입자당 접촉 수, 종류별 AM-AM / AM-SE / SE-SE)와
**퍼콜레이션 여부**(SE 망이 위아래를 잇는가 · 활물질 망이 잇는가).
⚠ SE 가 안 이어지는 케이스가 실제로 나온다 — 그건 결함이 아니라 **결과**다.  버리지 말고
"비퍼콜" 로 표시해서 남길 것.

## 7. 이 시리즈가 무엇을 비교하는가

면용량 **6 mAh/cm²** · RVE **50×50 µm** · 압력 **300 MPa** · AM:SE ≈ **81.6:18.4 wt%** 고정.
**바뀌는 것은 대립:소립 비(P:S) 하나뿐**이다.

| P:S | 입력 스크립트 | 대립 r (µm) | 소립 r (µm) | SE r (µm) |
|---|---|---|---|---|
| 0:10 | `input_real_1` | — (없음) | 2.0 | 0.5 |
| 3:7 | `input_real_2` | 6.0 | 2.0 | 0.5 |
| 5:5 | `input_real_3` | 6.0 | 2.0 | 0.5 |
| 7:3 | `input_real_4` | 6.0 | 2.0 | 0.5 |
| 10:0 | `input_real_5` | 6.0 | — (없음) | 0.5 |

⚠ **표의 크기는 반지름이다** (입력 스크립트가 반지름으로 쓴다).  직경으로 말하려면 2배 —
대립 Ø12 µm · 소립 Ø4 µm · SE Ø1 µm.

⚠⚠ **케이스를 더 받게 되면 함정이 하나 있다.**  같은 6 mAh 세트에 **SE 반지름이 1.5 µm 인
평행 시리즈**가 또 있다.  파일명이 이어져 보여도 두 시리즈를 섞으면 P:S 효과와 SE 크기 효과가
분리되지 않는다.  ⇒ **케이스를 추가할 때마다 `r_SE` 가 0.5 인지 입력 스크립트에서 확인할 것.**

## 8. 시작 체크리스트

1. `radius` 고유값 × 1000 이 입력 스크립트의 r 값(µm)과 일치하는가 → **단위 확인** (§2)
2. `create_box` 의 타입 수와 `particletemplate` 의 `atom_type` ↔ `radius` 짝 → **타입맵** (§3)
3. contact 파일의 실제 열 개수 → **열 인덱스** (§4-2)
4. x, y 를 **주기경계**로 다룰 것 (§5)
5. `c_ke` 가 충분히 작은가 → 준정적 상태 확인 (아니면 더 이완된 스텝을 쓸 것)
6. 응력을 쓸 거면 `stress/atom` = 응력×부피 임을 반영하고, 평균 σzz ≈ 300 MPa 로 검산 (§4-1)

막히면 물어보면 된다.  특히 **단위와 타입맵이 안 맞는 것 같으면 그 즉시** 물어보는 게
좋다 — 그 둘은 조용히 틀리면서 끝까지 그럴듯한 숫자를 낸다.
