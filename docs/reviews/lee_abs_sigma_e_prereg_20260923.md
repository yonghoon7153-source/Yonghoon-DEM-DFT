## 1. 대조 A — Lee STEP3 16팔 (모델) vs Lee 2025 (실험)

- 데이터: v100 `/home/ubuntu/runyourai/1/pa/lee_step3_v015_20260923` — `p2_VGCF_PTFE_3_0.5_a0..7.json` (Lee 첨가제 조성) ·

  (정본 카드 `lee2025_corolling_dryprocess_lpscl_ptfe`, stated).  같은 논문 PTFE 2 wt% → 4.5 · 5 wt% → 0.011 mS/cm.
- 비교량: **R = mean₈(σ_e, VGCF_PTFE_3_0.5) / 34 mS/cm**, 8 origin 표준오차 병기.
- 한계 병기 (prereg §6): AM:SE 는 스캐폴드 실측 34.18 vol% 로 고정 (Lee 의 80:17 wt% 가 아니다) · 침대 압력 300 MPa 목표 vs
  Lee 측정 75 MPa · 재하율 mach 0.01 · 격자 0.15 (수렴 미확인 — CL-72: "하한" 서술 금지).
- 판정선 (제안):

  | R | 판정 |
  |---|---|
  | 0.5 ≤ R ≤ 2 | **밴드 안** (Tier 2 — "밴드 안" 문장 가능) |
  | 0.1 ≤ R < 0.5 또는 2 < R ≤ 10 | **자릿수 정합** 까지만 (Tier 1) |
  | R < 0.1 또는 R > 10 | **불일치** — 모델 절대값 주장 철회 |

- 런 전 예상 (원장 CL-46 · CL-49 근거): **R ≈ 1.5 ~ 2.5** — 모델은 PTFE 의 탄소 표면 코팅 효과가 없어 높은 쪽.
- 대조 A′ — PTFE 감도: **Q = mean₈(σ_e, PTFE 1) / mean₈(σ_e, PTFE 0.5)**.  Lee 곡선 로그보간 (CL-46: PTFE 1 wt% ≈ 15) → **0.44**.
  런 전 예상 (CL-49 실측: PTFE 부피 스탬프가 SBE(1 wt%) −25.2 % · DBE(0.5 wt%) −13.0 %): **Q ≈ 0.85** — 모델이 PTFE 감도를
  **과소평가**한다는 예측.  Q ≤ 0.6 이면 예측 실패 (모델이 PTFE 차단을 생각보다 잘 본다).
- 적격 조건: 8/8 수렴 (러너 규약의 cg_info · resid 게이트) · 영수증 `code_sha` 일치 · `ptfe_stamp=centerline` · SKIP 캐시 재사용 0

## 2. 대조 B — 영진 DC 분극 (실험) vs 원고 모델

- 모델 기준값: 원고 페이로드 `f752da` SBE **54.5** · `f79b67` DBE **71.4 mS/cm** (SELF-45 재현, 상대편차 8e-13).
  ⛔ 비(DBE/SBE) 는 인용 금지 상태 — **방향 (DBE > SBE) 만** 본다.
- 측정 요건: SS/복합양극/SS 이온차단 DC 분극 · **펠릿 두께 2종** (기울기 = 벌크 σ_e · 절편 = 접촉저항) · SBE·DBE 같은 조건 ·
  압력·온도·두께 기록.  σ_e ≈ 50 mS/cm 면 0.5 mm 펠릿의 벌크 저항이 ≈1 Ω·cm² 라 두께 하나로는 접촉저항과 못 가른다.
- 판정선 (제안, SBE 기준):

  | DC 분극 σ_e(SBE) | 판정 |
  |---|---|
  | ≥ 10 mS/cm | 모델 절대값 **자릿수 성립** · 대칭셀 TLM r_e (Fig 4c 59.7 Ω·cm²) 는 접촉 지배 (CL-38 읽기 (a)) |
  | ≤ 1 mS/cm | 모델 **두 자릿수 과대** — 접촉저항을 모델에 넣어야 한다 (동료 해석이 맞음) |
  | 1 ~ 10 | 보류 — 두께 절편(접촉저항)으로 재판정 |

- 방향: DBE > SBE 를 양쪽 다 예상.
