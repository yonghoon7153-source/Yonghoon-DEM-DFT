## 4. 판정 — 결과 전 숫자

> **이 절의 식 · 쌍 · 문턱 · 처분은 결과를 본 뒤 옮길 수 없다.**  바꾸려면 결과 전 개정 (1저자 비준) 만 한다.  결과를 본 뒤의 변경은 그 사실을 표지하고 이 판정을 대신하지 않는다.

### 4-1. 격자 수렴 (J1) — U6(c) ⑥ 와 같은 식

`docs/reviews/suyoung_u6c_force_rule_20261122/rule.json` 의 식을 그대로 쓴다.

- 응답 = 아래판 명목 응력 σ_b = (아래판 힘 / D) × 10 MPa (침대는 판 폭으로 나눈다 · 어느 길이로 나눠도 비는 같다).  좌표 u = 처음 윗판 높이 − 지금 높이 (모형 길이).
- 구간 = [0, 두 팔 끝 변위의 작은 쪽] (양 끝 포함) · 표본 = 두 팔 원표본 변위의 합집합 · 이웃 원표본 사이 선형 보간 · 외삽 · 평활 없음.
- 분자 N = 구간 안 |σ_거친 − σ_고운| 의 최대 · 분모 = 같은 구간 고운 쪽 |σ| 의 최대.  **20 N ≤ 분모 = 이내** (같으면 이내 · 반올림 전 값) · 분모 0 = 보류.
- **판정 쌍 = 16↔32 · 24↔48.**  둘 다 이내 = **수렴** · 하나라도 초과 = **초과** · 그 밖 (결측 · 무효) = **보류**.  보고 쌍 = 8↔16 · 32↔48.
- 24 칸을 넣지 않기로 하면 (Q1): 판정 쌍 = 16↔32 · 32↔48.  32↔48 은 1.5 배 쌍이라 같은 5 % 가 두 배 쌍보다 느슨하다는 표지를 붙인다.
- 8↔16 을 판정에서 빼는 근거: 8 칸은 Bardenhagen 최소 해상도라 점근 영역 밖일 수 있어 메모 3.2 도 차수 판정에서 뺐다 (§4 단계 3).  침대 8↔16 은 79 % 였다.

### 4-2. 준정적 검사 (J2) — 기술 조건

- Q = 구간 안 |윗판 힘 − 아래판 힘| 의 최대 / 아래판 힘 |·| 의 최대 (같은 합집합 표본).  **Q ≤ 0.05 = 준정적.**
- J2 는 J1 을 막지 않는다 (침대도 V0 로 돈다).  J3 · J4 · J5 는 준정적 팔에서만 판정 · 보고한다.

| J4 2D Hertz (탄성) | 원판 직경 압축 `F = (π/4)·E/(1−ν²)·R·ε` (NG17 식 (2) · `litdb-canon:nguyen2017_mpm_bpm_deformable_particle_compaction` §4.3).  σ_b 기울기 (π/8)·E/(1−ν²) = 4.924 MPa (카드 §3.2 와 같다) | 보고만 | E-G1 · V0/4 · ε = (u − 2g_p)/D = 0.01 · 0.02 · 0.04 에서 ρ = σ_b / (4.924 MPa × ε).  범주 "±20 % 안 / 밖" 만 적는다 |
| J5 공개 MPM 곡선 (탄소성) | NZ22 단일 원판 H0: 꺾임 ≈ 0.40–0.42 MPa @ ε ≈ 0.035–0.04 · 꺾인 뒤 기울기 ≈ 0.7 MPa [카드 판독] | 보고만 · 이론 아님 | P-G1 · V0/4 의 꺾임 응력 · 꺾인 뒤 기울기를 나란히 적는다 |
| (없음) 탄소성 접촉 이론식 | 2D 원기둥 (평면 변형) 첫 항복 · 완전 소성 하중 | **정본 카드 없음** | 쓰지 않는다 |

J4 를 판정으로 쓰지 않는 이유: ① 식 (2) 는 직선 근사다.  교과서의 2D 원기둥 Hertz 는 로그 항을 가진다 [교과서 식 · 미확인 — 원문 확인 전].  그 꼴이면 이 창 (ε 0.01–0.04) 에서 식 (2) 의 약 0.6–0.8 배일 수 있다 [우리 산술 · 미확인 식으로 셈 · 판정에 쓰지 않는다].  ② 카드는 ε = ln(1 + d/R), d = 입자 중심 변위로 적는다.  아래판 고정 · 대칭이면 d = u/2 라 ε ≈ u/D 로 읽었다 [카드 판독 · 원문 PDF 미열람].  ③ 아래판 판독 자체가 평판에서 −5.2 % 치우친다 (§1) — 보정하지 않고 나란히 적는다.  J5 는 σ_yy · ε_yy 정의가 카드에 없다 → 우리 σ_b 와 부피 평균 σ_yy 를 둘 다 적는다.

## 6. 실행 블록 (WSL · 코어 둘 · 1저자가 붙여 넣는 꼴)

실행 묶음은 드라이버 구현 · 시험 통과 뒤 고정 커밋에서 만든다 (Q13 의 `docs/reviews/suyoung_q13_setting2_20261125/build_block.py` 와 같은 꼴: 원천 tar 를 base64 로 품은 TXT 하나 · 그 sha256 짝 파일).  지금은 파일이 없어 **이름 · 해시 칸은 빈칸**이다.

```bash
# 1저자 WSL · 새 빈 폴더에서 · 받은 TXT 와 .sha256 를 둔 뒤
sha256sum --strict -c "$PASTE.sha256"                 # PASTE = 빌드 때 정해지는 TXT 이름
bash "$PASTE" CHECK_ONLY                              # 계산 0: 원천 해시 · 코어 둘 · 시드 · 걸음 계획만
bash "$PASTE" GO_SUYOUNG_CONTACT_MINI_ONCE            # 1저자 GO 뒤 한 번 · 다시 치면 ALREADY_RESERVED
bash "$PASTE" READBACK "$RETURN_DIRECTORY"            # 반환 검산 · 가압 0 회
```

| 단계 | 하는 일 |
|---|---|
| CHECK_ONLY | 원천 목록 sha256 · Python 3.12.3 · NumPy 2.5.2 확인 · 물리 코어 둘 (서로 다른 core_id) 확인 · 50 팔 계획표 (팔 · 격자 · 속도 · 걸음 수 · 한도) 출력 · 시드 점 수와 해시 · 계산 0 |

## 7. 시간 어림 [우리 산술]

- 걸음 수 = 이동 / (V Δt).  V0 Δt × (지름당 칸) = 3.588 × 10⁻⁴ (모형 길이) 이라 G1 은 V0 에서 56.7 × 칸 걸음, G2 는 113.4 × 칸 걸음 · V0/4 는 4 배.  48 칸 G2 V0/4 = 21,775 걸음.
- 걸음당 시간 = 5–15 ms + 물질점 수 × (S 4.7–4.9 · F 3.0–3.6 µs).  49 원판 실측에서 옮겼다: F 걸음당 3.1–3.7 µs/점 (12–48 칸) · S 4.1–4.8 µs/점 (12–36 칸) (`docs/reviews/suyoung_u6a_setting2_return_20261123/receipt.json` · `docs/reviews/suyoung_u6b_return_20261123/receipt.json` · Q13 반환 · 고해상도 반환).  **원판 1–2 개의 고정 비용은 미측정 (가정).**
- 50 런 합: CPU 3.3–4.8 h.  코어 둘 (긴 것부터 나눔): 벽시계 **1.7–2.4 h** + 포장 · 판독 약 6 % (Q13: 팔 본시간 대비 +5.5 %).  가장 긴 팔 = 48 칸 G2-S V0/4 약 26–31 분.  24 칸을 빼면 CPU 상한 4.2 h.
