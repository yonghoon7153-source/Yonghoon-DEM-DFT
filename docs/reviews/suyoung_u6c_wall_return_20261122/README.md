## 2. 반력 차이가 발생한 위치

공통 변위 구간의 양끝과 모든 기록 변위를 합한 5,157점 중 총 반력 차이가 가장 큰 위치는 원 변위 단위 `u=0.11562281664031926`이다. F8 2,578번째와 F16 5,156번째가 정확히 이 변위에 있다. 같은 위치에서 성긴 격자 반력에서 고운 격자 반력을 뺐다.

| 아래판 처리 | F8 (MPa) | F16 (MPa) | F8 − F16 (MPa) |
|---|---:|---:|---:|
| 이번 걸음의 입자 간 접촉 처리 전 | 1.200855516 | 0.634878183 | +0.565977332 |
| 이번 걸음의 입자 간 접촉 처리 직후 | 2.88 × 10⁻²⁰ | 0 | +2.88 × 10⁻²⁰ |
| 합계 | 1.200855516 | 0.634878183 | +0.565977332 |

공통 구간 전체에서 두 번째 아래판 처리의 격자 간 절대차는 최대 0.00000340801 MPa였다. 최대 총 차이 위치에서 두 격자 모두 윗판 제약을 시작하는 격자 행이 같은 높이에 있다 (59/80 = 118/160 = 0.7375). 그 위치까지 누적된 입자 접촉, 재료 응력, 벽 처리, 입자–격자 전송의 영향은 첫 성분에 함께 들어간다.

보간 없이 양쪽에 똑같이 기록된 양의 변위 2,578개에서도 살폈다. 윗판 제약 시작 행의 물리 높이가 같은 1,270점 중 856점이 기존 분모의 5%를 넘었다. 높이가 다른 1,308점 중에서는 907점이었다. 연속 궤적의 표본이며, 독립 반복으로 세지 않는다.

5% 규칙은 `docs/reviews/suyoung_u6c_force_rule_20261122/README.md`에 고정한 그대로다. F8↔F16 89.15%, F12↔F24 19.11%. U6(c) 자격과 단계 3은 보류한다. 해시로 결속한 반환 TAR의 CSV를 별도 구현으로 재판독하려면 아래 명령을 쓴다.

```sh
python3 -I -B docs/reviews/suyoung_u6c_wall_return_20261122/check_wall_return.py "$RETURN_TAR"
```

## 3. 다음 개발 대조 (결과 전)

기존 비교는 격자를 세분할 때 시간 간격도 절반으로 줄였다. F8 한 팔에서 기존 F8의 격자·초기점·접촉·벽·재료·판 속도와 압력 중단 기준을 유지하고, 시간 간격만 절반으로 줄여 기존 F16과 맞춘다. 과거 F8·F16은 해시가 일치하는 위 반환에서 읽는다.

세 궤적이 모두 도달한 물리 변위에서 두 차이 **F8 − F8(반걸음)**, **F8(반걸음) − F16**의 합을 **F8 − F16**과 대조한다. 주 비교 위치는 이미 고정된 최대차 변위다. 새 팔이 먼저 압력 상한에 도달해 그 위치를 관측할 수 없으면 그 칸은 미도달로 두고 세 팔의 공통 변위 구간을 별도로 표시한다. 조기 종료·시간 초과나 결측은 성공으로 올리지 않는다. 반걸음에서 바뀌는 양은 시간 간격을 바꾼 개발 민감도다. 나머지 차이에는 격자·물질점 표본·누적 이력이 함께 들어간다. 이 대조로 5% 판정을 새로 정의하지 않는다.

## 4. 1저자 WSL 실행

CPU 1코어에서 F8 한 팔만 새로 실행한다. 이전 반환 TAR 한 개를 두 번째 인수로 지정한다. 원 F8이 약 100초 걸렸으므로 두 배 걸음 수 기준 어림은 약 3–4분이다. 같은 압력 중단점에 이르는 걸음 수는 달라질 수 있다. 계산 상한은 12분, 판독 상한은 별도로 2분이다. 자동 재시도는 0회다. 정상·부분 반환 모두 출력된 RETURN_DIRECTORY 아래의 suyoung_dt_result.tar.gz, screen.txt, SHA256SUMS로 회수한다.

```sh
bash "$BLOCK" CHECK_ONLY "$PRIOR_WALL_TAR"
bash "$BLOCK" GO_SUYOUNG_F8_HALF_ONCE "$PRIOR_WALL_TAR"
```

개발 결과 승인 범위는 그대로다. 이전 반환물과 원 소스 다섯 개의 검산은 §1, 실제로 사용하는 세 계산기 소스의 결속과 시간 간격 대조는 `docs/reviews/suyoung_u6c_wall_return_20261122/dt_control.py`를 따른다.
