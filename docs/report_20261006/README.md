## 2. 다시 만들기

```
python3 docs/report_20261006/build_deck.py --part1 <part1.pptx> --part15 <part1.5.pptx> \
    --part175 <part1.75.zip> --part2 <part2.pptx> \
    --tsv docs/data/ps45_r45_network_webapp_20261005/network_5comp.tsv --out report_20261006_dem.pptx
```

- 의존: `lxml` · `python-pptx` (그래프 두 개를 만들 때만).
- `--merge-only` = 손보기 없이 원 6 장만 합친 덱 (원본 대조 · 되돌림용).
- 같은 입력이면 **같은 바이트** (zip 시각 · 내장 xlsx 작성 시각 고정): 10-05 빌드 `report_20261006_dem.pptx` = `f3629c80cd7d62529bd0cc737acd09454f11723ad67b1cf10d1d0c414cd5bafd` (51773353 B).
- 값이 바뀌면 멈춘다 — `derived()` 가 화면 문장이 기대는 사실 (σ_ion 7:3 최대 · σ_e 단조 감소 · 수송 tortuosity 7:3 최소 · 접촉 저항 비 3.85–4.25 등) 을 단언한다.  TSV 를 새로 받으면 문장부터 다시 볼 것.

## 7. 바꾸지 않은 것 · 1저자 결정 대기

- ★ **10-05 밤 1저자: 아래 글꼴 · 1 장 각주 · 3–6 장 "Tortuosity" 는 PPT 에서 직접 정리** (*"알아서할게"*) — 생성기는 손대지 않는다.  1 장 각주 (10 % = 출처 미확인 보정 표적 · `CL-94`) 는 *"나중에 다시 말해줘"*.  8 장 "수송 tortuosity" 는 생성기에만 반영 — 덱 최종본 = 1저자가 손본 PPT.

- **글꼴** (덱 전체 · 원칙 §4 ↔ 기존 양식): 손대지 않았다.  1 · 2 장의 "3세부 2차년도 연구개발 추진 내용" 머리줄은 원본 part1 그대로 라틴 글꼴 미지정 (테마 Calibri) 이고 3–8 장은 맑은 고딕 지정 — 숫자 모양이 다르게 보일 수 있다.  그래프 안 영문은 옆 (5 장) 과 같은 Arial — 원칙 §4 "그림 안 영문 = Aptos [판독]" 은 글꼴 결정과 함께.
- **1 장 각주** "(순수 고체전해질 300 MPa 냉간 가압 기공률 약 10 % 에 맞춰 보정)": 이 10 % 는 원장 `CL-94` (hold) 의 "출처 [미확인] · 외부 실험 앵커 아님" 보정 표적과 같은 값이다.  문구는 1저자 결정 (손대지 않음).
