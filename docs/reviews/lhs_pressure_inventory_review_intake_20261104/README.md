## [LHS] Q2 — 수정 선택과 권고 (비준 대기)

1. **권고:** LPI-01은 계산/직렬화와 출력 오류 처리를 분리한다. 결과 JSON+개행을 확정한 후 출력·flush하고, 출력 시작 뒤 실패 시 두 번째 JSON을 만들지 않으며 비정상 종료한다. 인터프리터 종료 시 버퍼 재flush, shell fallback의 추가 stdout도 확인한다. 단일 write도 원자성을 보장하지 않으므로 “정상 stdout이면 완전한 JSON 하나, 출력 장애면 없거나 불완전한 출력과 비정상 종료”로 문구를 한정한다.
2. **권고:** LPI-02는 반례와 “파일·줄·문자 수 상한은 시간 상한이 아니다”라는 한정을 남긴다. 정규식·디렉터리 열거·파일시스템 대기·전체 wall-clock의 시간 상한은 없다. B7 regex·집계 정의·압력/등록 규칙을 유지한다. 별도 시간 제한이나 동등 파서 교체는 이번 수정에 넣지 않는다.
3. 대안은 현 준비 수용 상태에서 P3를 열린 채 유지하는 것이다. 실제 재고 실행 전 출력 오류 경계와 설명을 보강하는 1+2를 권고한다. 어떤 선택도 전체 HOLD 해제·실행/배포 GO를 뜻하지 않는다.

비준 뒤 시험 먼저: 첫 write 실패, 일부 출력 뒤 실패, flush 실패, 지속 실패, 해석기 시작 실패를 구분해 두 번째 JSON/종료 재출력/shell fallback 중복이 없는지 확인한다. 수신 조건은 **프로세스 rc0 + 완전한 JSON 한 개 + 최상위 INVENTORY_COMPLETE/rc0**를 모두 요구한다. 준비 명령·README를 고친 뒤 관련 직접 시험, 짧은 외부 재확인을 요청한다. 현재는 코드를 고치지 않았고 자체 CLOSED도 하지 않았다.

## 인계와 게이트

외부 판정은 준비 핵심 계약 수용, 새 P1/P2 없음, P3 두 건이다. LPI-01/02를 원장 `open`으로 제안하는 새 쪽지만 썼고 공유 원장은 그대로다. 11-04 인계서 §0-1의 “수정 계획 → 1저자 비준 → 시험 먼저 고침”을 따른다. Q1 기록·MXD2R의 외부 판정은 이 판정에 포함되지 않는다.
