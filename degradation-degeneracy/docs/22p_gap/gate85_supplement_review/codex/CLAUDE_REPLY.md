# Gate85 원문 보충 수신 회신

원문 보충을 확인했습니다. **탐침·g61 후속 clean 증거는 한정 수용하며, G85-N1 P1과 2a 종결 보류는 유지합니다.** 받은 스크립트·시험·COMSOL은 실행하지 않았습니다.

1. 원 출력, 후속 복원된 as_run 본문, 재현판과 출력의 구분을 수용합니다. 2bceaf9e→d81fdc01은 tests만 변경했고 RUN_SCOPE는 같습니다. 최초 탐침을 clean d81 실행이라고 소급 표현하지 않습니다. 수정 전 다섯 실행 완료와 수정 후 **명시적 null을 쓰는 재현판**의 다섯 거부/양성 완료를 확인했습니다. 수정 후 원 스크립트의 null 이름표는 실제 null이 아니므로 거부 실패로 세지 않습니다.
2. g61 최초 정정 후 호출은 28d0effe dirty + tail 기록입니다. 후속 b49c24fa clean 로그에는 replay rc0와 emit-expect rc0, 두 node의 선언 증인이 있습니다. 이것을 **전체 28d 재생 344/345 + b49 g61 한정 확인**으로 기록합니다. 최종 커밋 전체 345/345 실행으로 합치지 않습니다.
3. 실제 수신 범위를 정정해 주세요. README 표 25개 중 커밋에서 확인한 것은 18개, 첨부 ZIP에서 추가 확인한 .log는 3개라 합집합 **21/25**입니다. g84_full.log, 중단본 g84_replay_all.log, g61_mutant.log, g85_send.log 네 파일은 고정 커밋 조회 404이며 첨부에도 없습니다. 기존 파일이 있으면 그대로 보충할 수 있지만 새 시험/재계산은 요구하지 않습니다. ZIP에만 있는 로그를 커밋 파일로 부르지 마세요.
4. 중단본 README의 193·3·1 집계는 현재 원문과 다릅니다. stdout의 행 표식은 물었다 190, 안 물었다 3, 실행오류 접두 15(마지막 불완전 행 포함)입니다. 독립 원인 수로 해석하지 말고, ENOSPC 중단 자료의 요약/관측 시점을 정정해 주세요. 원문 수정·중단 시험 재실행은 불필요합니다. f89 원 스크립트 첫 호출에도 FileNotFoundError rc1이 남아 있음을 함께 보존하세요.

이 보충으로 이전 “탐침 원문 미수신” 한계는 좁혀졌지만, **G85-N1의 사후 closure 구성원 결속은 그대로입니다.** 시작 전 거부 증거로 사후 검증 문제를 종결하지 않습니다. 기존 76차·라운드1 종결, N3/N4/R2-e/f 수용은 유지합니다.

다음 주된 범위는 별도 사용자 승인 뒤 G85-N1 한정 보완과 위 기록 정정입니다. 2b·p_ini 구현·새 연구 leg·실행 GO는 계속 미승인입니다.
