# [요청] LPSCl / Ag–C 인터레이어 / VGCF 계면의 점착일(W_ad) DFT 계산

> DFT 팀 전달용 원문 (2026-09-23).  우리 쪽 설계·범위는 `docs/adhesion_agc_interlayer_20260923.md`.
> 아래 구분선 사이를 그대로 보내면 된다.

---

## 배경 — 왜 필요한가

전고체전지(ASSB) 음극 쪽 적층 **LPSCl(Li₆PS₅Cl) 고체전해질 | Ag–C 인터레이어 | VGCF 호스트** 에서
두 계면 ① **LPSCl ↔ Ag–C** ② **Ag–C ↔ VGCF** 의 박리 저항(임계 점착에너지)을 추정하려 한다.

우리 팀은 DEM(LIGGGHTS)으로 입자 스케일 **박리 시험**을 만들고 **구동압(stack pressure)** 의존성을 본다.
그런데 DEM 은 점착에너지를 **입력으로 받을 뿐 스스로 만들지 못한다**.  그래서 원자 스케일의
**열역학적 점착일 W_ad** 를 DFT 로 구해 주기를 요청한다.

- **정확도 목표 = 자릿수.**  각 계면이 물리흡착 급(수십~수백 mJ/m²)인지 화학결합 급(J/m²)인지를 가르면 된다.
- 다만 계면끼리 **같은 규약**으로 계산돼 서로 비교할 수 있어야 한다 (아래 규약).
- 참고: 구동압(수~수십 MPa)은 원자 결합 응력(GPa 급)보다 세 자릿수 이상 작아 **원자 스케일 W_ad 를 거의 바꾸지
  않는다**.  구동압 효과(실접촉 면적)는 우리가 DEM 층에서 넣는다 — DFT 쪽에서 압력을 걸 필요는 없다.

## 계산할 계면 — Ag–C 는 복합체라 구성 쌍으로 나눈다

| 우선 | 계면 | 대표 모델 (제안 — 더 나은 선택이 있으면 알려 달라) |
|---|---|---|
| **P1** | LPSCl ↔ Ag | Ag(111) / LPSCl 저에너지 면, **종단 두 가지** (S 쪽 · Cl 쪽) |
| **P1** | Ag ↔ 흑연 (VGCF 외벽) | Ag(111) / graphite(0001) basal |
| P2 | LPSCl ↔ 탄소 | graphite(0001) 또는 비정질 탄소 / LPSCl 같은 면 |
| P2 | 탄소 ↔ 흑연 | 흑연 층간 — **기준값** (문헌과 대조해 규약 검증용) |
| P3 (선택) | 리튬화 상태 | LPSCl ↔ Li–Ag 합금 (예: LiAg) · Li–Ag ↔ 흑연 |
| P3 (선택) | 결함 흑연 | Ag ↔ 흑연 (단일 공공 또는 가장자리) |

복합체 전체의 실효값은 **구성 쌍의 값 × 각 상의 접촉 면적 비율**로 우리 쪽에서 조합한다.

## ★ 기존 워크플로와 같은 규약으로 (비교 가능성)

팀에 이미 **LPSCl ↔ NCM 계면 W_ad 워크플로**가 있다 (litdb 정본 브랜치 claude/friendly-meitner-lldvar 의
kb/methodology/adhesion_energy.md · db/properties/adhesion.json · db/inputs/adhesion_templates/).
- 이번 계산도 **그 W_ad 정의(isolated slab method)** 를 그대로 쓴다 — 그래야 LPSCl|Ag 값을 기존 **LPSCl|NCM 값과
  바로 나란히** 놓을 수 있다 (같은 SE 슬랩·같은 표면에너지 재사용).
- 계면 제작 프로토콜(v5 결정 슬랩 + surface-only MQA, 셀 정합 ≤ 3 %)과 SE 조성·슬랩도 가능하면 재사용한다.
- MLIP 로 계산한 값은 **MLIP 라고 표시**하고, 계면마다 최소 한 구조는 **DFT 단일점으로 검증**한다.

## 계산 규약 — 반드시 지켜 주세요

1. **범함수**: PBE + D3(BJ) 를 기본으로 하고, **D3 를 끈 값도 함께** 보고한다.  물리흡착 계면은 분산 보정이
   값의 대부분이라 mJ/J 판별의 핵심이다.
2. **정의** — 주값은 기존 워크플로의 **W_ad (isolated slab)** = (E_A,고립 + E_B,고립 − E_AB) / A.  A = 계면 면적.
   가능하면 **W_sep** (계면을 그대로 떼어낸 비이완 슬랩 기준)도 병기한다 — 두 값의 차가 이완·재구성 기여다.
   - 슬랩과 계면은 **같은 셀·같은 변형**에서 계산한다.
3. **격자 불일치**: 적용한 변형률(%)과 어느 쪽을 변형했는지 적는다.  가능하면 3 % 이하, 필요하면 coincidence 초격자.
4. **수렴**: 슬랩 두께를 늘려 W_ad 변화가 0.05 J/m² 미만인지 확인한다 (Ag 4 층 이상 · LPSCl 약 10 Å 이상).
   진공 15 Å 이상, 비대칭 슬랩은 쌍극자 보정.
5. **계면 정렬(registry)**: 면내 평행이동을 **최소 3~4 가지** 계산해 **최소값과 범위**를 함께 보고한다.
   값 하나만 주지 말 것.
6. **분리 스캔(UBER)**: 이완된 계면을 강체로 0.2~0.5 Å 간격, 평형 + 약 8 Å 까지 벌린 E(d) 를 달라.
   우리가 여기서 견인–분리 곡선(최대 인장응력 σ_max · 임계 개구 δ_c)을 뽑아 박리 모델에 넣는다.
7. **반응성**: Ag–황화물과 Li–LPSCl 은 반응성이 있다.  이완 중 **결합 재구성이나 원소 이동**(예: Ag–S 결합 형성,
   S·Li 이동)이 보이면 반드시 적고, 계면이 열역학적으로 불안정하면(반응 에너지 < 0) 그 사실을 적어 달라 —
   급격한 계면의 W_ad 가 물리적인 값이 아닐 수 있다.  가능하면 가장 강한 계면에 짧은 AIMD(300 K, 수 ps)로
   안정성을 확인한다.
8. **단위**: J/m² (추적용으로 eV/Å² 병기.  1 eV/Å² = 16.02 J/m²,  1 meV/Å² ≈ 16 mJ/m²).

## 받고 싶은 것

- **표 (CSV)**: 계면 · 종단 · registry · A(Å²) · 변형률(%) · W_sep · W_ad (D3 켬/끔) · γ_A · γ_B (표면에너지) · 비고
- **UBER 곡선 E(d)** CSV — 계면별
- **구조 파일** (POSCAR 또는 CIF: 이완 계면 + 각 슬랩) + 주요 설정 (코드·버전 · ENCUT · k-mesh · 수렴 기준)
- **한 쪽 요약**: 계면별로 물리흡착 급(≲ 0.3 J/m²)인지 화학결합 급(≳ 1 J/m²)인지 판정 + 그 불확도 근거
  (registry 범위 · D3 기여 · 두께 수렴)

## 하지 말아 주세요

- 계산하지 않은 칸을 문헌값으로 채우기 — 빈칸으로 두고, 문헌 비교는 **출처를 달아 별도 열**로.
- registry 하나 · 두께 하나로 결론 내기.
- 슬랩 기준 에너지를 다른 셀이나 다른 변형에서 가져오기.
