## 1. 목적·이름·순서

목표는 실물 입력을 모르는 상태에서 **어느 모델 조건에서 어떤 혼합 모습이 가능한지** 지도로 만들어 실험 승인에 필요한 질문을 좁히는 것이다. 장비·시료·사람을 지금 정해야만 이 초안을 만들 수 있다는 조건을 두지 않는다.

표지는 **“보정 전 탐색 — 미보정·개발 자료·판정 아님”**, 제안 식별자는 `precal-map-1104`다. 이것은 실행 코호트 이름이 아니며 기존 정책에 등록하지 않는다. 과거 dev-bo/dev-u, 파이프라인의 **보정 후 S5 DEV**, D3의 C0·C1·C2, 새 확인 블록과 구분한다.

순서: **보정 전 탐색 지도 → 1저자의 실험 승인 요청 → S1 동결 후 D3 실측 및 상대축 자료 확보 → 조건부 보정 → 별도 확인 블록**. D3 실측은 지도의 우리 위치를 좁히지만 한 점을 반드시 고르는 것은 아니다. 실측과 양립하는 유한 후보 집합이 비거나 여러 개일 수 있다. 지도에서 본 결과로 실험을 선택한 이력은 남기고 새 확인 블록에는 독립 자료/시드가 필요하다.

## 7. 지도가 실험에 주는 것과 허용 문장

실험 승인 문서 뼈대는 `docs/reviews/mixer_precal_experiment_request_outline_20261104.md`다. 지도는 관측이 크게 달라지는 **표본 조건**, 가를 수 없는 조건, 계약 때문에 계산 못 한 조건을 함께 보여 준다. 연구 결과는 지금0건이므로 특정 조건이 이미 갈렸다고 쓰지 않는다.

- 쓸 수 있는 형식: “지정한 γ 비·Bo·벽/마찰·밀도·기하와 2바퀴 조건에서, 평가한 격자점의 SE 접촉 군집/부착/기존 M이 이 양상이라면 이 관측을 가르는 실험을 요청한다.”
- 실제 γ 비가 이 범위라는 **독립 자료가 생긴 경우에만** 그 조건부 예측을 해당 분말 후보에 연결한다. 표본점 사이를 연속 전이/상도 경계로 확정하지 않는다.
- 금지: “실제 비코팅 물성은 r=…”, “코팅 효과가 …%”, “0.31을 넘으면 반드시 분산”, “seed1로 유의/재현”, “D3 실측 하나로 두 축과 벽을 모두 식별”, “실험 없이 P1/P2/P3 확인”, “이 결과로 실제 σ_ion/피복 개선 인증”.

## 8. 실행 전 관문과 1저자 결정

지금 완료하는 것은 **검토 가능한 초안**뿐이다. 실행 전에는 초안 비준 → MXD2R 외부 판정/남은 D2 계약 → 전용 덱·짝 비교·판독 연결과 기준군/계약 시험 → 독립 검토 → 새 준비·봉인·정책/자원 확인 → 1저자 ibb 실행 승인이 필요하다. 구체 장비 실측은 보정 전 탐색의 선행조건으로 두지 않지만, 실제 물성·확인 단계의 조건은 생략하지 않는다.
