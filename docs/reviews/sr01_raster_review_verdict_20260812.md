## 1. ★★ 가장 큰 발견 — 2C CCCV 이득의 귀속이 ~300배 틀렸다 (전기화학 렌즈)

원장 §5.5: CC 평균 ΔV **9.3 mV = 옴 4.5 + kin 4.8**.
CLAUDE.md 실측 분해: **2C 옴강하 = 전자 0.01–0.03 mV vs 이온 84–90 mV.**

| 항 | 무엇이 설명하나 | 계산 | 관측 |
|---|---|---|---|
| 옴 4.5 mV | **σ_ion +5.6 %** | 93.3 × (1−1/1.056) = **4.95 mV** | ✓ |
| kin 4.8 mV | **BV 면 +18 %** | 36.2 × (1−1/1.18) = **5.5 mV** | ✓ (36.2→31.7) |
| — | σ_e +52 % | **≤0.02 mV** | — |

⇒ **9.3 mV 의 99.8 % 가 σ_ion 과 BV 면에서 나온다.**  원장의 "DBE 우위가 수송-기원
(σ_e +52 % · 반응면 +18 %)" 문장은 **σ_e 를 약 300배 과대 귀속**한다.

★★ 그리고 이것이 가장 나쁜 소식이다: §8 캐비엇이 "이온/반응면/R_geom/분산 축은
**σ_SDCP(e) 무관** = 유효" 라고 적었는데, **σ_SDCP 에 무관한 것과 래스터에 무관한 것은
다르다.**  셀-수준 결론은 σ_e 아티팩트에는 면역이지만, **오염이 확인된 두 축(σ_ion·BV)에
100 % 노출**돼 있다.

## 2. ★★ σ_ion +5.6 % 는 모델이 **자기 과잉 스탬프를 수리한 것**

이온 dof SBE 909,738 → DBE 974,942 = **+65,204**.
유도된 "SDCP 가 VGCF 셀을 덮어쓴 수" ≈ **5.9×10⁴**.  거의 일치.
VGCF 는 이온 절연, SDCP 는 이온 전도(σ_i=0.001) ⇒ **이온 이득의 대부분은 "4.9배 과잉
스탬프된 VGCF 가 막고 있던 셀을 SDCP 가 도로 뚫은 것"**.  물리적으로 0.3 µm SDCP 입자가
0.4 µm VGCF 구간을 지우지 않는다.
⚠ 추가로 `σ_ion(SDCP) = 0.001 S/cm` 는 **명시적 §F1 훅**(DFT 앵커 대기) — 헤드라인 축
하나가 앵커 없는 가정값에 얹혀 있다.

## 3. ★★ EMT 13.3× — 두 렌즈가 **다른 경로로** 같은 기각

원고: φ=1.28 vol% 에 3φ(Maxwell–Garnett, **고립 구**)를 적용 → +3.9 % 를 "부피 천장"이라

| 렌즈 | 올바른 천장 | 관측의 위치 |
|---|---|---|
| 전기화학 | **혼합법칙(Wiener) +65.2 %** (SBE 4.98 → DBE 8.22 S/cm) | **80 % 실현** |

⇒ **토폴로지 없이도 +64 % 가 부피 산수의 자연스러운 답.**

## 4. ★★ 협착 부재 — 기전의 **부호가 뒤집힐** 수 있다

모델의 SDCP|VGCF 면 컨덕턴스 5.71×10⁻³ S 를 Holm `g = 4a/(ρ₁+ρ₂)` 로 환산하면
**접촉반경 a = 0.20 µm**.  그런데 VGCF 반경은 **0.075 µm** — **접촉점이 두 물체보다 크다.**
기하 최대(a=섬유반경)로 잡아도 **2.7배**, 현실적 a≈20–50 nm 면 **4–10배 과전도**.
σ_SDCP 등가로 250 → **7.7–36.5 S/cm**, 그때 이득은 **+0 ~ +19 %**.
★ 그리고 결정적으로: **협착이 있으면 SDCP 다리는 접촉을 2개 만들어** 직접 섬유-섬유 접촉
1개보다 **나쁘다** ⇒ 원고의 기전은 협착을 넣는 순간 **부호가 뒤집힌다**.
⚠ 원고 §3 은 "전도도를 깎는 것은 접합부의 좁은 목" 이라 하는데 Methods 는 "sub-voxel
constriction 미해상" 을 인정한다 — **모델이 표현할 수 없는 물리를 기전으로 지목**했다.

## 6. ★ 브래킷이 없다 + 부호는 증명 가능했다 (물리 렌즈)

**정리**: 점 셀 집합 ⊆ 선분 셀 집합 (`_fibre_segment_ijk` 가 모든 원점 floor 셀을 포함하고
`segment_cells` 가 끝점 셀을 보장) ⇒ Rayleigh 단조성으로
**`σ_e,A ≤ σ_e,B` 와 `σ_ion,A ≥ σ_ion,B` 는 측정 전에 증명 가능했다.**
⇒ `sr01_stamp_compare` 도입부의 "부호는 재야 안다" 는 **틀렸다** — 재야 했던 것은 크기뿐.

**그러나 점이 참값의 하한은 아니다** (arm A 도 살아남은 조각의 단면이 6배 부풀어 있음):
```
σ_e(AM-only, 같은 베드) ≤ σ_e(참) ≤ σ_e(선분)/~6      ← 탄소-몸통 지배 시
σ_e(점) ≤ σ_e(선분)                                     ← 정리
σ_e(점) vs σ_e(참)                                      ← 순서 미정
```
**진짜 하한은 같은 베드의 AM-only 바닥이고, 리포에 없다.**

## 8. σ_SDCP 스윕 — 강한 아티팩트 가설은 **기각**, 약한 것과는 **축퇴**

σ_SDCP {15/50/150/250/1500} → 이득 {+0.8/+25.8/+45.5/+52.0/+63.4 %}.
1셀 SDCP 다리는 σ=15 에서도 그것이 잇는 34셀 VGCF 사슬 전체보다 **5배** 잘 통한다
(전체 경로 대비 다리 저항 **2 %**) ⇒ 개방 단절 치유였다면 **15 에서 이미 +45 % 급**이 나와야
한다.  관측 **+0.8 %** ⇒ **강한 아티팩트 가설 기각.**
⚠ 그러나 반-이득 지점 σ_SDCP ≈ 69 (= VGCF 면 하나의 0.8배) ⇒ SDCP 가 미는 우회로는
**VGCF 복셀 1개 남짓**이고, **대각 코너 단절의 우회 비용도 정확히 1–2 복셀**이다
⇒ **약한 아티팩트 가설과는 스윕 모양으로 구분 불가.**
⚠ "분담 역행 = 직렬 시그니처" 도 절반만 유효 — **덮어쓴 백본 복셀도 직렬**이고 같은 역행을
낸다 (SDCP 가 VGCF 를 덮어쓰는 제3 위상: 예측 Δdof_e +7.2×10⁴ vs 관측 **+6.5×10⁴** 일치).

## 9. 원고의 "독립 readout 4개" 는 ≤3 개

  9.05×10⁻⁶ Ω·cm² 로 실측 R_int(46–110)의 **10⁻⁷** — 5백만분의 1짜리 양의 변화.
- **j_mean_z 273→414.2 (+52 %)**: `3.002/72.48 µm = 414.2` = **항등식**, 검산이 아니다.
- **접점 +19.3 %** (433→517): AM당 +84점 × 1,271 = +107,000 ≈ SDCP 137,384점의 78 %
  = "AM 표면에 심은 입자가 AM 표면 0.3 µm 안에서 세어졌다" = **동어반복**.
- **분산 D=1.13**: uniform-random 시딩의 **입력 재진술**.
- **focus 87.6→67.5 (−23 %) 는 정규화값**.  절대 첨두는 87.6×273 = 23,915 → **27,960
  (+17 %)** — 줄 발열/열화(#29)에 중요한 것은 절대값이고 **올라갔다**.  원고는 내려간 쪽만 쓴다.

## 10. ★ 오늘 실측의 자기일관성 — 그리고 이상한 곳 둘

**정합 (예상보다 강한 진술 가능)**: κ +2.4 % vs σ_e ×35.8.  열은 **多상**(모든 고체 전도)이라
연결성에 둔감하고 σ_e 는 **단일상 백본**이라 임계적이다.  같은 격자 변경이 κ 는 2.4 %만,
σ_e 는 3,479 % 움직였다 ⇒ **부피 효과가 아니라 순수 연결성 효과**임이 실측으로 확정.
dof +2.7 % 만 변한 것이 못을 박는다.

**⚠ 이상 1 (결론에 영향)**: arm A 의 σ_e 0.005122 는 AM-only 망 치고 **너무 높다** —
σ_AM_S(0.010)의 **0.51배**.  SDCP base(무첨가 AM 골격 단독)는 5.85e-4 = σ_AM 의 0.06–0.12배.
후보: (a) `rasterize` 의 **AM-AM contact bridge**(반경 1.2·vox, tol 0.10 µm)가 과발화
(b) VGCF 4 % 가 죽은 망이 아니라 부분 퍼콜 (c) 조성 차이.
**(a)라면 ×35.8 의 분모가 부풀어 배수가 과소평가다.**
→ 확인: arm A 의 분담을 **contact-bridge 복셀만 따로** 집계.

**⚠ 이상 2 (서사에 영향)**: 선분 스탬프는 σ_e↑ 와 **σ_ion↓ 를 동시에** 낸다 ⇒ **래스터를
고치면 "전자↑/이온↓" 트레이드오프가 되살아난다.**  SDCP 원고의 셀링 포인트가 "상쇄 축
없음" 인데, 오늘 실측은 그 상쇄가 **부분적으로 스탬프에 가려져 있었다**는 것을 보여준다.

## 11. BV +18 % — 면적 인플레 + **앵커 없는 i0 이식**

SDCP 셀이 4.3배 부풀고 44.4 % 가 AM 표면에 붙으니 면 수가 오른다 (≈**1.4배 과대**).
**더 큰 문제**: `solve_reaction_current` 가 AM|SDCP 면에 AM|SE 와 **동일한 i0 = 2.0 A/m²**
(§F1 훅)를 부여한다.  NCM|황화물SE 와 NCM|전도성고분자의 Li⁺ 교환전류밀도가 같다는 앵커는
리포에 없다.  게다가 SDCP 는 250 S/cm 전자도체라 그 계면은 **전자적으로 단락된 계면** —
실셀에선 반응면이 아니라 자기방전/부반응 자리일 수 있고 **모델은 이 위험을 구조적으로 못 본다.**

## 16-2. ★ Codex 만 잡은 것

**(a) ★★ 소산분담과 σ_SDCP 스윕은 독립 증거가 아니다 (E-04).**
harmonic face conductance 에서 코드가 상 a 에 주는 가중치
`w_a = σ_b/(σ_a+σ_b) = ∂ln g/∂ln σ_a` 는 **정확히 phase-conductivity elasticity** 다.
고정 topology 선형 Dirichlet 문제에 envelope 정리를 적용하면
`∂ln σ_eff/∂ln σ_phase ≈ 보고된 dissipation share` (⚠ plate-coupling 항을 분모에서 빼므로
**엄밀 항등식이 아니라 plate 항이 작을 때의 근사**).  실제 스윕이 그대로 따라간다:

| 구간 | Δln σ_eff/Δln σ_SDCP | 양끝 share |
|---|---|---|
| 15→50 | 18.4 % | 19.6 → 16.3 % |
| 50→150 | 13.2 % | 16.3 → 10.0 % |
| 150→250 | 8.5 % | 10.0 → 7.3 % |

⇒ **"분담 역행 + 스윕 단조 = 직렬 브리지를 독립 확인"은 같은 해의 국소 민감도를 두 번 센 것.**
`VGCF 92.5 %` 도 `∂lnσ_eff/∂lnσ_VGCF ≈ 0.925` 를 뜻할 뿐 **백본 관통의 증명이 아니다.**
⚠ 단 전기화학 렌즈의 "스윕이 **강한** 아티팩트 가설(개방 단절 치유)을 기각한다"는 별개로 유효
(σ_SDCP=15 에서 +0.8 % 밖에 안 나온 것) — 기각에는 쓰이고 **입증에는 못 쓰인다**.

**(b) PTFE 는 열 격자에도 없다 (E-02).**  세 solve 가 같은 `sid3` 를 공유하므로
`thermal_k_table()` 의 PTFE 값은 production 에서 **dead parameter**.  κ +2.4 % 는 "전상 열전도"가
아니라 늘어난 carbon label 효과.  (내부 렌즈는 전자·이온만 잡았다.)

**(c) `segment_cells` 음방향 경계 (E-06).**  음의 방향 진행 중 끝점이 복셀 경계에 **정확히**
놓이면 한 셀을 지나쳤다 `endc=floor(p1/vox)` 로 되돌아오는 backtrack/여분 셀 가능.
현재 selftest 의 음방향 사례는 **정확한 경계 끝점이 아니라** 이 경로를 안 탄다.
또 `_fibre_segment_ijk` 는 edge list 대신 `2×median` 휴리스틱을 쓴다 — median 이 0 이면 큰 gap 도
이어지고, 실제 연속 섬유가 국소적으로 늘어나면 거짓 단절.

**(d) ★ 제 브리핑의 오류 (E-03).**  요청서가 `σ(VGCF)/σ(AM) ~ 2e5` 라고 적었는데 기본값은

**(e) 부하 의존이 단조일 이유가 없다 (Q3).**  낮은 부하에서 양쪽 미퍼콜(비 ≈1) → 중간에서

⇒ 물리 렌즈의 "부하의 함수" 프레이밍을 **단조 가정 없이** 다시 써야 한다.
