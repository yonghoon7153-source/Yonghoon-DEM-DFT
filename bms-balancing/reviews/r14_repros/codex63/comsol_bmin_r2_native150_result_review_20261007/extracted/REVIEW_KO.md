## 입력 식별과 증거 연결

검토한 본체는 `BMIN_R2_NATIVE150_RESULT_FOR_REVIEW_20261006.zip`, 256,397,169 bytes, SHA-256 `7c40d5babd69a92a70952ddef1fb5bf328878021fb7eb1caef834754cac1aa62`다. 내부 manifest는 1,450,858 bytes, SHA-256 `82ebc1ef12ebdc594d3b25ead9b0b2722a5ad4f4c9df01a6fc534aaa4b0adc2d`다.

모든 압축 멤버를 끝까지 읽어 크기·SHA와 CRC를 대조했다. 원 제출자는 별도 CRC 계산을 하지 않았다고 적었지만, 이번 수신 검토에서는 ZIP 읽기 과정의 CRC 검사까지 통과했다. 이 차이는 원 영수증을 고쳐 쓰는 이유가 아니다.

코드 manifest `4cdca2e6bf7d073f813d97be73825b8cd2043c2fc44e285f4a190bc6fb97cf25`, 생산 5개 파일, 실행 폴더 Java 사본, class 식별, 기준 CSV 9개 및 외부 의존 16개를 결속했다. 기존 검증 종결·사전 관측 수용 회신 ZIP의 전체 SHA도 앞선 검토 식별과 일치한다. 비활성 원 계약·manifest의 플래그를 덮어쓰지 않고 별도 사용자 결정·검증 release·실행 approval이 연결된 형태다.

부모 시작 기록의 approval/release 해시, 실행 approval의 USER_DECISION/release 해시, 계약과 예약된 compile/batch argv·cwd·예산이 일치한다. 실제 인가의 출처는 제출된 사용자 결정 기록이며 이번 검토가 새 승인을 발행한 것은 아니다. 기존 PS01-16 외부 fail-closed 수용과 내부 분기 `UNOBSERVED` 한계를 그대로 유지한다.

native 콘솔에 실린 CSV 35개의 Base64 바이트를 별도로 해시하여 `run/tables/`의 각 파일 및 분석 결과의 table manifest와 대조했다. 이는 요약 JSON끼리의 일치에만 의존하지 않는 원 로그–CSV 연결이다. 포장 전 선택 원본 목록 8,674개도 수신 멤버와 모두 일치한다.

## 저장 CSV 독립 검산

수신 분석기를 import하거나 실행하지 않았다. 검토자가 작성한 읽기 전용 코드로 CSV를 순차 읽고 Decimal 산술로 비교했다. 새 모델 계산·보간·외삽·가까운 시각 대체는 없다.

현재 2,447시각과 기준 NORMAL480의 5,740시각을 확인했다. 1,637개 요청시각은 현재와 기준 양쪽에 정확히 존재하고, 주 비교는 120.0부터 150.0까지 0.1초 간격 301시각이다. 해당 구간의 요청 외 정확 공통 저장시각은 0개다. 현재 프로파일은 N/P 각각 589,727행, 합계 **1,179,454행**이며 각 시각마다 241좌표를 가진다. 기준은 N/P 각각 1,383,340행이다. 전체 프로파일의 유한값·좌표·domain·표면 조성/OCP 범위를 확인했다.

| 120–150초 주 비교 | 독립 검산 최대 절대차 | 선언 한도 |
| --- | ---: | ---: |
| 전압 | 3.449917063×10⁻⁷ V = **0.0003449917063 mV = 0.3449917063 µV** | 0.001 V |
| N 표면 조성 | 1.1309035403×10⁻⁸ | 1×10⁻⁴ |
| P 표면 조성 | 3.3226834×10⁻⁹ | 1×10⁻⁴ |

전압과 N 표면 최대는 120초, P 표면 최대는 150초다. N의 최대는 좌표 index 60, P는 240이다. 전해질 전체 최소 차 `4.048767×10⁻⁶ mol/m³`, 총 Li 차 `3.12×10⁻¹⁵ mol/m²`도 보고값과 일치한다. 전해질/총량 차는 이 비교의 세 개 판정량을 대체하지 않는 보조 관측이다.

현재 전체 저장시각에 대한 Li 상대량 변화 최대 `3.3963860727623301184460517996875217741990888132101×10⁻¹⁵`, 전압 분해 잔차 최대 `6.96×10⁻¹⁶ V`를 재확인했다. 초기 Li 세 항의 절대차는 각각 `1.4×10⁻¹⁷`, `1.4×10⁻¹⁵`, `0 mol/m²`로 기준 조건 이내다. 22개 runtime 설정의 차이는 요청시각 목록뿐이고, 현재 목록은 NORMAL480 목록의 정확한 1,637개 prefix다.

**중요한 표현 범위:** 0.000345 mV는 120–150초 주 비교의 최대다. 주 비교 밖 요청 공통시각 1,336개에서는 0.0005초에 **0.3081961318368 mV**가 최대이며, N/P 표면 차 최대는 각각 약 `5.1801×10⁻⁶`, `7.0772×10⁻⁷`다. 이 구간은 원 계약에서 관측 전용이므로 주 비교에 넣거나 사후 새 기준으로 판단하지 않았다. 따라서 “0–150초 전체 최대 전압 차가 0.000345 mV”라고 쓰면 안 된다.

이번 결과는 두 입자 격자의 민감도 관측이다. 세분화 순서·참해 오차 상한·물리 공간 격자 수렴·480초 후반의 격자 민감도·유한 microshort 조건·실험 타당성을 입증하지 않는다.

## 실행과 마지막 반환의 경계

단일 Time-Dependent Solver 구간의 저장 출력 2,447개를 CSV 시각과 반올림 범위 안에서 연결했다. 마지막은 150초이고 뒤의 적분 출력은 없다. 보호 종료 메시지·native fatal 흔적은 확인되지 않았으며 완료 표식은 각각 1개다. 실제 read-back은 물리 격자 120/60/120, 입자 640/640, transient DOF 156,925 + 내부 12와 일치한다. transient 구간 밖 DOF 1,202 + 내부 12를 transient DOF로 세지 않았다.

compile과 batch 기록은 각각 rc0, 정리 PASS, 남은 소유 프로세스·귀속 불명 COMSOL 목록 없음, handle 닫힘·종료 조회 성공, 기록/정리 오류 없음이다. 기본 prefs 기대 SHA와 보안 16개 값, 정책 변경 0 조건이 연결되어 있다. 실행 후 보존·정책 검사는 고정 entry의 `finally` 확인 결과와 봉인된 상태 기록에 근거한다. 실행기기의 현재 전체 프로세스·prefs를 수신자가 직접 검사한 증거로 확대하지 않는다.

부모의 native 자식 rc0, 분석 자식 rc0, local decision → PRE_WRITE → POST_WRITE의 식별·순서·판정 필드가 일치한다. 부모 PRE_WRITE는 4,471.8464505초, **POST_WRITE는 4,471.8936425 / 10,500초**다. POST_WRITE의 delivery 구간은 1.1545496 / 300초이며 기록 오류는 없다. POST_WRITE는 transcript 밖의 사용자 제공 화면 텍스트를 후속 저장한 자료다. `-NoExit` PowerShell 프로세스 자체의 종료코드는 없으므로 `raw_host_rc=null`을 유지한다. 마지막 STOP은 재실행 금지 안내이며 실패 신호로 보지 않는다.

포장은 부모와 별도 승인 예산이다. 본문에 제공된 chunk `6b5778`의 후속 전사는 rc0, 반환 전 snapshot **271.031481 / 1,800초**, poll wall time 13.5086222초를 구분한다. 이 wall time을 누적 snapshot에 더하지 않는다. “전사까지 320.981초”는 제출자 보고로 남기며, 현재 원자료만으로 그 추가 종결 시점을 독립 확정하지 않는다.

## 남은 전달 항목

ZIP 밖 `SELECTED_SOURCES_AFTER.json`의 전체 원파일이 아직 없다. 기대 식별은 2,861,947 bytes / SHA-256 `4dc9b2387d56566c9d1107ce8d12ee448338741397b582f4a7a451e2acab1aa8`다. 현재는 그 식별과 “불변” 요약만 있으므로 8,674개 선택 파일의 포장 전후 집합·크기·SHA를 수신자가 모두 대조했다고 말할 수 없다.

당시 파일 그대로 보내면 된다. 가능하면 기존 `DELIVERY_RECEIPT.json`(1,425 bytes / SHA `7760236d6238e24ce205b4b20ab794028fce8c1ee75fbacd085e510b2a22399c`)과 `FINAL_PACKAGE_TOOL_RETURN.json`도 함께 전달한다. 과거 시점 검증을 지금 재실행하거나 원 ZIP을 재포장하여 대체하지 않는다. 파일이 남아 있지 않으면 그 결손을 기록한다. 이 요청은 native·분석기 재실행이나 승인 필드 변경을 허용하지 않는다.

결과 MPH는 6,162,301,981 bytes / SHA `f6053533e299e6688da0063aa9c0c271ea6755d6dee0721dd30c0c7a4a13fcd1`로 native 기록과 포장 시 현지 해시가 일치한다. MPH 바이트는 이번 ZIP에 없어 수신자가 직접 재해시하지 않았다. 전달 보존 종결이 남아 있으므로 기존 MPH 보존을 유지한다.
