# Phase 1l — **팽창은 통한다.** 그리고 왜 통하는지도 나왔다 (음극 채널이 Lin 의 null 을 본다)

**정본은 `mode-observability/results/phase1l/` 의 CSV 다.** 아래 숫자는 사본이며
인용 근거가 아니다. 재현: `python3 mode-observability/phase1l_expansion_axis.py`

## 왜 이 계산인가

이 계보에는 축퇴 처방이 셋뿐이다 — **등식으로 죽인다**(Birkl·Lin), **믿음으로
못 박는다**(Marongiu), **센서를 하나 더 단다**(Mohtat). 앞의 둘은 우리 격자에서
이미 기각됐다:

| 라운드 | 좌표 | 판정 |
|---|---|---|
| Phase 1e | 창 | 제약이 **강한** 특이쌍과 1.5°·2.0° → 여분이 아니라 정보를 지운다 |
| Phase 1h | 모드 | 컷오프 등식이 null 과 84° → 못 본다. 끝점 얹어도 σ_min **+3~6 %** |
| Phase 1i | 모드 | 제약을 걸면 σ 는 −88 % 지만 편향 **+8.9 %p** (최대 σ 의 173배) |

**남은 처방은 Mohtat 의 것 하나다.** 이 라운드가 그것을 잰다 (통합 논지 Gap 8).

## 막힌 자리와 그 우회

`Chen2020_composite` 에는 **전극 팽창 파라미터가 없다** — 실측하니
`partial molar volume` 은 **SEI 것뿐**이고 `Cell thermal expansion coefficient`
는 열팽창이다. 그러므로 Mohtat 식 팽창 채널을 **우리 셀로 교정할 수 없다.**

**교정 없이 판정하는 길이 있다.** Mohtat 식 (39) 계열의 팽창 모형은 전부

```
Δt(x) = n_c · Σᵢ tᵢ⁰ ξᵢ · (전극 i 의 화학량론 변화)
```

곧 **전극 화학량론의 고정 선형범함수**다. 계수가 무엇이든 gradient 는 화학량론
궤적의 Jacobian 을 통과한다. 그래서 궤적 자체를 재면 **모형 하나가 아니라
모형 족(族) 전체**에 대해 답할 수 있다.

화학량론은 격자 parquet 의 `v_pe`·`v_ne` 를 봉인 평형 OCP 표로 **역보간**해
얻었다 (단조성 확인: PE 2.487~5.678 V ✓ · NE 0.024~3.577 V ✓).
**`modes_to_params` 도 창 대수도 안 쓴다** — 그래서 Phase 1k 의 `'paper'` 규약
경고가 여기엔 **안 걸린다.**

## 실측 ① — 채널마다 `(1,1,1)` 을 보는 정도가 완전히 다르다

`∠(u_min, (1,1,1))` — **작을수록 못 보는 것**(그 방향이 그 관측의 최약축):

| 관측 | pristine | 22p 근방 | 조건수 (22p) |
|---|---:|---:|---:|
| 전압 `U_full(x)` | 12.04° | **4.61°** | 16.3 |
| PE 화학량론 `y(x)` | 13.93° | 25.61° | **1726** |
| **NE 화학량론 `z(x)`** | **77.45°** | **70.53°** | 41.2 |
| 화학량론 궤적 `[y;z]` 통째 | 8.49° | 4.20° | 11.5 |

`(1,1,1)` 방향 미분의 크기 (22p):

```
전압      ‖J·(1,1,1)/√3‖ = 0.8261    자기 최대의 0.0764 · 자기 최소의  1.25 배
y (PE)                    0.3353    자기 최대의 0.0231 · 자기 최소의 39.84 배
z (NE)                    2.0152    자기 최대의 0.1148 · 자기 최소의  4.73 배
```

`[해석]` **음극 화학량론 채널은 Lin 의 null 을 본다.** `u_min` 이 70~77° 떨어져
있다는 것은 `(1,1,1)` 이 그 관측의 **약한 축이 아니라는** 뜻이고, 방향 미분이
자기 최소의 4.7배라는 것이 같은 말을 크기로 한 것이다. 반면 전압은 1.25배 —
거의 최약축이다.

**그리고 `[y;z]` 를 통째로 합치면 다시 4.20° 로 눈이 먼다.** 두 채널의
`(1,1,1)` 응답이 서로 **상쇄**하기 때문이다. 즉 **섞는 비가 판정을 뒤집는다.**

## 실측 ② — 스칼라 팽창 `E = cosθ·y + sinθ·z` 를 훑는다

실제 팽창은 궤적 둘이 아니라 **스칼라 하나**다. 계수를 모르므로 비를 훑었다
(22p 근방):

| θ | ∠(u_min(E), (1,1,1)) | σ_min 이득 |
|---:|---:|---:|
| 0° (순수 PE) | 25.61° | +11.8 % |
| 30° | **0.83°** | +35.2 % |
| 45° | **1.27°** | +53.4 % |
| 60° | 3.03° | +70.9 % |
| 75° | 24.50° | +87.7 % |
| **90° (순수 NE)** | **70.53°** | **+103.7 %** |

`[해석]` **θ = 30~60° 의 균형 혼합이 가장 나쁘다** — 각이 1° 안으로 떨어져
`(1,1,1)` 을 거의 완전히 놓친다. **순수 NE 쪽이 가장 좋다.**

**그리고 물리가 그쪽이다.** Gr+Si 음극의 리튬화 팽창은 Si 가 ~300 %, 흑연이
~10 % 수준이고 NMC 양극은 수 % 다. 즉 실제 셀의 `Δt` 는 **압도적으로 음극이
지배**하므로 θ → 90° 가 현실이다.

## 판정

1. **팽창 축은 통한다 — 이 계보에서 유일하게 기각되지 않은 처방이다.**
   순수 NE 팽창이 `(1,1,1)` 과 **70.53°** 이고 σ_min 을 **두 배 이상**(+103.7 %)
   올린다. 컷오프 등식의 **+3~6 %** (Phase 1h) 와 견주면 **20배 이상**이다.
2. **왜 통하는지도 나왔다** — 음극 화학량론이 `(1,1,1)` 을 따라 실제로 움직이고,
   전압은 그 움직임을 **양극의 반대 움직임으로 거의 상쇄해** 못 본다.
   팽창은 음극만 크게 반영하므로 그 상쇄를 깬다.
3. **그러므로 "센서 하나가 등식 열 개보다 낫다"** — 이 프로젝트가 지금까지
   기각해 온 처방들과 대비되는, 실행 가능한 유일한 방향이다.

## 이 판정이 말하지 않는 것 (경계)

1. **σ_min 이득 +103.7 % 는 가중에 매인 수다.** 팽창 채널을 전압 채널과 **같은
   총 노름**으로 얹었는데, 실제 가중은 `σ_V` 대 `σ_팽창` 의 비가 정하고 우리는
   그 비를 모른다 (Mohtat 자신도 `n_c` 를 인쇄하지 않았다 — 그의 Fig. 8 이
   재현 불가한 이유). **가중에 무관한 수는 각(70.53°) 쪽이므로 그것을 인용한다.**
2. **`z` 를 직접 재는 것이 아니다.** 여기서 `z` 는 시뮬의 `v_ne` 를 역보간해 얻은
   것이고, 실제 셀에서 `v_ne` 를 재려면 기준전극이 필요하다. **팽창의 값어치는
   기준전극 없이 그 정보에 닿는다는 데 있다** — 그것이 Mohtat 의 논지이고,
   이 계산이 보인 것은 **"그 정보가 실제로 거기 있다"** 까지다.
3. **격자 곡선은 0.05 C 유한 전류다.** 그래서 역보간이 주는 것은 **겉보기
   화학량론**이다 (Phase 1j 가 그 과전압을 18.7 mV 로 쟀다). 평형에서 다시
   재면 숫자가 움직인다.
4. **선형 팽창 모형 족에 한정된다.** 이력(hysteresis)·비선형 팽창·SEI 두께 성장
   같은 항이 있으면 이 논증의 사정권 밖이다. 특히 Si 는 **이력이 크다** —
   우리 파이프라인이 `current sigmoid` 로 다루는 바로 그 성질이다.
5. **두 동작점·한 화학·한 스텝(0.02).** Phase 1h·1k 가 잰 스텝 산포가 여기도 걸린다.
