# 정규화 유효 이온전도도 (σ_eff/σ₀) · 망 솔버 기준 · 펠릿 값 — 설명 (11-02)

1저자 질문 (11-02): *"σ₀ 에 grain boundary 관련된 접촉 저항들이 다 포함되어 있는 거야? · network solver 에서 값이 산정되는 기준이 뭔가 · 펠릿도 SE 단독일 때 값이니까 물질의 고유 이온전도도 + 접촉 저항이 들어간 건가?"*

## 1. 솔버가 계산하는 방법 (`scripts/network_conductivity.py` · 이온 채널)

| 요소 | 식 · 내용 |
|---|---|
| 망 | DEM 이완 끝 구조에서 전해질 입자 = 노드, 전해질–전해질 접촉 = 간선. 아래 · 위 판 쪽 입자에 전위차를 걸고 키르히호프 식 (전류 보존) 을 푼다 |
| 간선 저항 | R = R_bulk,i + R_bulk,j + R_c (간선마다 직렬) |
| 입자 안 (R_bulk) | R_bulk,i = (d/2) / (σ₀ · π · r_i²) — 중심–중심 거리 d 의 반을 입자 단면 (반지름 r_i) 원기둥으로 본다 |
| 접촉부 (R_c) | R_c = 1 / (2 · σ₀ · a) — 반지름 a 인 접촉점을 전류가 비집고 지나가는 협착 저항 (Holm). a 는 DEM 접촉 면적에서 구한다 |
| 결과 | 전체 전류 → σ_eff → f = σ_eff / σ₀ (판 간격에서 푼 값을 질량 보존 두께로 다시 잰 값) → 3 µm = 1 로 나눈 것이 덱의 1.0 · 1.7 · 2.4 |

## 2. 질문별 답

| 질문 | 답 |
|---|---|
| σ₀ 에 입계 · 접촉 저항이 들어 있나? | σ₀ 는 전해질 하나의 이온전도도이고, 솔버는 입자 안과 접촉부에 **같은 σ₀** 를 쓴다 (코드 상수 3.0 mS/cm · 봉인 · **보고 기준은 1.5 mS/cm** — 1저자 10-12 · 이종기술과 같음 · 절대값 = f × 1.5). 모든 저항이 1/σ₀ 에 비례하므로 σ_eff/σ₀ 에서 σ₀ 는 정확히 약분된다. 그래서 정규화 유효 이온전도도는 σ₀ 에 무엇이 들어 있든 상관없는 **순수 구조 계수** (기공 · 연결 · 접촉부 협착) 다 |
| 모델의 접촉 저항은? | **기하 협착뿐이다.** 좁은 접촉점 때문에 생기는 저항만 있고, 입계 저항 · 계면층 · 피막 같은 면적당 계면 저항 항은 모델에 없다 (그 항을 넣는 것이 Rint 작업). 8장 "이온 전달 저항의 약 3/4 이 접촉부" 도 이 기하 협착의 몫이다 (망 소산 중 R_c 의 몫 71–74 %) |
| 펠릿 5.1 · 2.3 mS/cm 은? | **예.** 전해질만 눌러 만든 펠릿의 값이라, 입자 고유 전도도 + 입계 + 입자 간 접촉 저항 + 펠릿의 남은 기공이 모두 섞인 펠릿 전체 값이다. 출처 = 50kg 킥오프 덱 (3차년도 실측). 성형 압력 · 밀도 · 측정 온도 · 입계/입자 성분 분리 여부는 리포 기록에 없다 (미확인) |

## 3. 7장 (손익분기) 에 미치는 영향

- 7장의 "정규화 유효 이온전도도 2.4배 × 전해질 이온전도도 0.45배 ≈ 1.1배" 는 펠릿 값을 σ₀ 자리에 넣은 계산이다.
- 펠릿 값 속의 접촉 저항 (펠릿 입자끼리) 과 구조 계수 속의 접촉 협착 (전극 안 전해질끼리) 이 일부 겹쳐 셀 수 있다 → **조건부 추정** (이전 Codex 판정 조건 · 원장 `KG50B-02` "조건부 시나리오 · 이중계상 위험").
- 펠릿은 전해질만으로 치밀하고, 전극 안 전해질 망은 활물질 사이에 끼어 성기다 — 펠릿의 접촉 수 · 상태가 전극 안과 같다는 보장이 없다.
- 1 µm 펠릿이 낮은 원인 (입계 증가인지 · 밀링 손상인지) 은 모른다 → "입계 증가 때문" 이라고 쓰지 않는다 (초안 3 하지 않을 말).
