## §2 누설 환산에서 지킬 구분 (R1)

- MPHR l.113–124 의 표 (σ ↔ 셀 환산 저항 ↔ 4 V 누설 %) 는 **원본 모델의 `ElectricCorrModel = Bruggeman` · epss 0.45 · b 1.5 가정** 아래 값이다.
  현 NORMAL480 의 `NoCorr` 에 그 저항값을 옮기지 않는다 — 역사 기록으로만 남긴다.
- 현 모델을 균일 1D 전도체로 볼 때의 **조건부** 관계 (CX 와 같게): `R_eq = L_sep / (σ_eff · A_eff)` · `I_leak = Δφ_s,sep / R_eq`. 여기서
  Δφ_s,sep 는 **분리막 양단의 고체 전위차**이고 셀 단자 전압과 자동으로 같지 않다. `A_eff` 도 국소 Fe 경로의 실제 면적과 같다고 두지 않는다.
- 실험 저항 · 누설을 받더라도 면적 · 길이 · 유효 전도도 보정의 대응을 확정하기 전에는 현재 σ 로 **자동 역산하지 않는다.** 이를 위해 유한 σ
  계산을 하지 않는다.

## §3 비교 사양 — **제안** (A2 에서 확정 · 잔차를 보기 전)

### 3-0. 순서 규칙 (고정)

- **A1 (자료 식별) 에서는 모델과의 차를 계산하지 않는다** — 형식 · 단위 · 시각 기준 · 기기 메타데이터 · 직전 이력 · sha256 · 대응표 칸만
  채운다. 모델 곡선과 겹쳐 그리지 않는다. 내용을 보기 전에 무엇을 볼지 정하고, 이미 보게 된 결과는 노출 기록에 남긴다 (CX).
- 아래 3-1–3-3 은 **제안**이다. A2 에서 A1 의 **사실** (기기 정확도 사양 · 샘플링 · 단계 구조 · 직전 이력) 을 반영해 지표별 판정 규칙까지 확정해
  커밋한 뒤에만, 비교를 한 번 한다. 고치면 새 판 · 옛 판 보존 · 사유.
- 결과를 본 뒤에는 구간 · 정렬 · 지표 · 판정 규칙을 바꾸지 않는다. 더 보는 분석은 "사후" 라벨 · 판정에 쓰지 않는다. 전압이 잘 맞는 구간을
  사후에 고르지 않는다.
- 비교는 기존 저장 해 (NORMAL480 0–480 s) 만 쓴다 — 새 solve 가 필요해지면 별도 준비 · 승인.

|---|---|
| 시각 원점 t = 0 | 충전 단계 시작 — 충방전기의 단계 시작 기록이 있으면 그것, 없으면 충전 방향 전류가 공칭 0.1C 전류의 50 % 이상이 된 첫 샘플. 시간 이동 맞춤 없음 |
| 전류 | 실측 I 와 실측 면적이 **둘 다** 있을 때만 전류밀도 대응을 판단한다. 면적이 없으면 대응 = 미확인 · A_cell 로 한 환산은 "가정 환산" 칸 (대응 근거 아님). 모델 전류 · 용량을 실측에 맞춰 바꾸지 않는다 · 부호: 충전 = 양 (READY l.55) |
| 전압 | 오프셋 · 배율 보정 없음. 모델 V = 경계 4 (z = 121 µm) − 경계 1 (z = 0) (SPEC §10-1 l.436) · 실측 V = 기기의 셀 단자 전압 그대로 |
| 시각 맞춤 | 모델의 **정확 저장 시각**에서 비교한다 — 모델은 보간하지 않는다. 실측은 같은 단계 안의 앞뒤 두 샘플로 선형 보간 · 두 샘플 간격이 공칭 샘플링 간격의 2 배를 넘으면 결측 (채우지 않음) — 보간 · 결측 규칙도 A2 에서 확정 |
| OCV 근접성 분류 | 충전 직전 OCV 가 모델 무부하 평형 2.1653 V 와 ±20 mV 안인가 — **근접성 라벨일 뿐이다.** 같은 시작 상태의 충분조건이 아니며, 이것만으로 정량 비교 경로를 열지 않는다 |
| 시작 상태 대응 | 따로 확인한다: 직전 단계 · 휴지 시간 (이력) · 전류 · 온도 · 실험 단계가 모델 조건과 각각 대응하는가. 대응이 확인되지 않은 동안 비교는 **진단**으로만 보고하고 차를 모델 오차로 해석하지 않는다. 대응 확인의 기준은 A2 에서 항목별로 정한다 |

### 3-2. 구간 (제안)

모델 저장 해의 범위 안에서만 — W0 [0, 5] · W1 (5, 30] · W2 (30, 120] · W3 (120, 240] · W4 (240, 480] s (저장 결과 분석과 같은 창 — SPEC §39-5).
480 s 이후의 실측은 이번 비교에 쓰지 않는다 (모델 해가 없다).

### 3-3. 지표 — 정의만 (판정 규칙은 A2)

| 지표 | 정의 | 단위 | 판정 근거 (A2 에서 정할 것) |
|---|---|---|---|
| M1 점 차 | ΔV(t_k) = V_model(t_k) − V_meas(t_k) · t_k ∈ {5, 30, 60, 120, 240, 360, 480} s (모델 정확 저장 시각 — R480 selected_times 와 같은 시각). t = 0 은 쓰지 않는다 (모델의 t = 0 은 CDI 초기화 뒤) | V | 단일 읽기의 기기 정확도 · 보간 · 시각 정렬의 기여 — 셋의 결합 규칙 |
| M2 구간 기울기 | 창 W1–W4 마다 할선 (V(끝) − V(시작)) / (끝 − 시작) — 모델 · 실측 각각과 그 차 | **V/s** | 두 읽기 · 창 길이 · 시각 기준에서 오는 기울기 불확도 — **전압 정확도 U_V 와 직접 비교하지 않는다** |
| M3 무부하 OCV → 충전 5 s 까지의 총 변화 | V(5 s) − V_rest · 모델 V_rest = 무부하 평형 2.1653333265 V → **186.843 mV** (2.3521763195 − 2.1653333265 · R480 selected_times · SPEC l.297–301 — 우리 산술) · 실측 V_rest = 충전 직전 OCV | V | **두 읽기의 차**이므로 단일 읽기 정확도를 그대로 쓰지 않는다 (상관 · 휴지 / 부하 상태 차 포함) |

- M3 은 **부하 t = 0 → 5 s 상승** (모델 2.3521763195 − 2.2306115890 = **121.565 mV**) 과 다른 관측량이다. 어느 쪽도 다른 쪽의 정정값이 아니다.
- 지금은 기기 · 샘플링 정보가 없으므로 수치 문턱 · 오차 합산 규칙을 만들지 않는다. 기기 정확도 **사양**과 평가된 **측정 불확도**를 구분해
  기록한다. dV/dt 를 쓰게 되면 차분 · 필터 · 창 길이 · 끝점 · 결측 처리 · 기기 해상도를 함께 사전 고정한다 (CX).

### 3-4. 허용되는 문장

첫 결론으로 쓸 수 있는 문장은 "어느 입력이 실측과 **맞고 / 다르고 / 확인할 수 없는가**" 와 A2 에서 확정한 규칙에 따른 지표 분류까지다.
"모델이 실험과 맞는다" · "OCP 를 바꿔야 한다" 는 쓰지 않는다 (SPEC §40-2 · S2 l.2854). 시작 상태가 맞지 않으면 "현재 입력과 조건 불일치" 로
보고하고, OCP · 초기 조성 · 전류 변경은 별도 결정이다 (CX).

## §4 A1 에서 하는 일 (자료가 온 뒤 · 비교 아님)

자료마다 sha256 · 출처 · 라이선스 · 셀 ID 를 남기고 (원자료는 저장소에 넣지 않는다 — 지금까지 원본 파일 · 규진팀 자료 · 결과 ZIP 을 두지 않은
것과 같다: SPEC l.12–13 · l.3236), 대응표의 실험 칸 · 상태를 채우고, 단위 · 환산을 검사하고, 기기 정확도 사양 · 샘플링 · 단계 구조 · 직전 이력을
기록한 뒤, A2 의 판정 규칙을 **비교 전에** 정한다.
