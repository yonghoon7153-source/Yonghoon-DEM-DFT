# 단계 1 census와 메모리 안전 설계

## 1. 목적과 입력 경계

메모 §4 단계1을 입력/출력 계약으로 분리했다. 실제 census0건, scaffold 좌표·원자료 열람0건이다. 메모에 인용된 수·반경은 선언 메타일 뿐 이번 재확인 관측이 아니다. 압축 끝 좌표를 새 느슨한 충전 씨앗으로 쓰지 않는다.

| 입력 ID | 계획 대상 | 사용 목적 | 지금 상태 | 다음 |
|---|---|---|---|---|
| B1 | real_14 압축 끝 | 순간 지지/색 수 관측 하나 | 0: 좌표 미열람 | 별도 접근 허용과 신원 확인 뒤; 최악 보장/초기 씨앗 아님 |
| B2 | 같은 수·반경, DEM 붓기 높이 | 느슨한 출발 설계 | 1: 형식만 | 생성 규약·ID 고정 |
| B3 | 같은 수·반경, 무작위0.35 높이 | 느슨한 출발 설계 | 1: 형식만 | 생성 규약·ID 고정 |
| B4 | 순수 SE, 측방50×50·최종 두께30 µm | 단계4 최종 상자 메모리 | 1: 두 출발 높이 하위행 | 실제 포장/구현별 바이트 미확인 |
| B5 | 순수 SE, 측방25×25·최종 두께30 µm | 단계4 줄인 상자 메모리 | 1: 두 출발 높이 하위행 | B4와 바꾸어 세지 않음 |
| H100 | 100 µm급 후막 높이 | 별도 확장 한 줄 | 0: 정확한 규격 미정 | 숫자를 임의 채우지 않음 |

메모의 ‘침대 다섯’은 B1–B5의 다섯 범주다. B4/B5는 각각 붓기/무작위 두 높이를 별도 하위행으로 남긴다. 이를 정확히5회만 센 것처럼 집계하지 않는다. 격자384/435 및 이동 예산0.5/1/2셀은 메모의 제안 차원이며 실행 입력 동결 전이다.

## 2. 신원과 지지 관계

입자 원 ID → 물질점 ID → 그 점의 원부피/현재 위치 → P2G 지지 노드/가중치의 연결을 보존한다. 같은 점 위치가 겹치더라도 서로 다른 입자의 기여를 최근접 입자 하나로 합치지 않는다. 입자 ID와 격자 장 ID는 다른 필드다. 주기 경계의 이미지와 축별 최대 노름 규약을 명시한다.

K_now는 지금 노드를 함께 쓰는 쌍 그래프의 등록된 탐욕 순서 색 수다. K_safe는 이동 예산을 포함한 안전 그래프의 같은 순서 색 수다. 둘 다 최소 색 수를 증명한 값이 아니다. 안전 변의 조건은 최소 물질점 거리 ≤ 2w+b_i+b_j, w는 커널 지지 반폭이다. b_i는 병진·회전·변형을 모두 포함한 마지막 색칠 이후 입자 소속 점의 최대 이동 예산이다. 판 변위만으로 대체하지 않는다.

## 3. 출력 계약

| 묶음 | 필수 필드 | 미완전 처리 |
|---|---|---|
| 신원 | 입력 ID/hash, 생성 규약/씨앗, 코드/정책 핀, 경계·단위·격자·커널·예산·색칠 순서 | 비어 있으면 결과 인증 불가 |
| 지지 통계 | 활성 노드 수, 노드당 물체 수 분포, ≥2/≥3 개수와 분모, 중복 ID/미분류 기여 수 | 빈 집합을0% 양성으로 쓰지 않고 비적용/미완료 사유 |
| 색칠 | K_now/K_safe, 색별 입자 목록의 신원, 변 위반 수, 순서 민감도 보고 | 변 위반 있으면 부적격 |
| 메모리 | 아래 byte 항목별 개수·단위·합계·상한·여유, 측정/산술 구분 | 누락 비용을0으로 채우지 않음 |
| 실행 자격 | 정적 관측 범위, 동적 가드 구현/시험 여부, 미확인 | census 완료를 안전 인증으로 승격 안 함 |

메모리 계수는 장별 mass/momentum/force 등 payload, 인덱스/키, 물질점 상태, 좌표/소속, 그래프, 충돌 검출, 재색칠 old/new 동시 보관, 임시/정렬/압축 버퍼, runtime 여분으로 나눈다. 활성 크기뿐 아니라 예약 용량과 재색칠 순간 peak를 포함한다. 36 B/노드는 기존 단순 산술 가정이며 실제 구현 전체 비용이 아니다. ‘48 GB’와 GiB 단위도 같은 것으로 바꾸지 않는다. 이번에 사용가능 메모리나 성능을 측정하지 않았다.

## 4. 3D 장 재사용의 동적 불변식

메모의 3D 색칠 후보에만 적용한다. 걸음마다 P2G 전 예산 초과를 확인하고 필요하면 재색칠한다. P2G 중 같은 색의 서로 다른 입자가 같은 노드에 질량을 주면 그 걸음의 P2G 전체를 버린다. 완결된 이전 상태를 보존한 채 재색칠 후 해당 걸음을 다시 처리해야 하며 오염된 장을 G2P로 넘기지 않는다. 필요한 색 수가 예약 장 수를 넘으면 기술 실패로 멈춘다.

완료된 P2G의 불변식은 ‘한 색 장의 한 노드에 질량을 준 입자≤1’이다. 예산 검사만으로 이를 대신하지 않는다. rollback·재시도 상한·검사 비용의 실제 구현은 아직 없고 다음 고정 설계에 포함한다. 임의 동시 변경·장 수 상한 정리를 보장하지 않는다.

## 5. 먼저 설계할 작은 반례

| 반례 | 요구되는 관측/거부 | 이번 상태 |
|---|---|---|
| 겹친 세 입자 기여를 최근접 하나로 합침 | 원 소속3개 보존, ≥3 노드 누락 검출 | 1: 설계, 미실행 |
| 두 입자가 각각 예산만큼 서로 접근 | b_i+b_j를 모두 넣고 빠진 변 검출 | 1: 설계, 미실행 |
| 회전/변형 이동이 판 변위보다 큼 | 점의 실제 이동으로 예산 초과 판단 | 1: 설계, 미실행 |
| 주기 경계 양끝 입자의 지지 중첩 | 주기 이미지 관계 보존 | 1: 설계, 미실행 |
| 같은 색 P2G 충돌 또는 재색칠 용량 초과 | 걸음 폐기/기술 실패, 정상 결과 없음 | 1: 설계, 미실행 |
| 재색칠 old/new 동시 메모리 | 순간 peak 비용 누락 검출 | 1: 설계, 미실행 |

구현·시험 착수 시 expected-correct 시험을 먼저 쓰고 고치기 전 실패를 고정 핀에서 기록한다. 지금 문서를 합성 시험 통과 수로 세지 않는다.
