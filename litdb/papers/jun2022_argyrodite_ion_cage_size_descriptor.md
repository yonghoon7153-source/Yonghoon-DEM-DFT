## 0.5 처음 읽는 사람을 위한 배경 (이 논문이 전제하는 것들)

**descriptor(기술자) 논문이란 무엇인가**
스크리닝 논문에는 두 종류가 있다. **깔때기를 돌린 논문**과 **깔때기가 쓸 잣대를 만든 논문**.
이건 후자다. 좋은 잣대의 조건은 딱 둘이다 —
① **싸게 구할 수 있을 것**(구조만 있으면 계산되어야 한다) ② **비싼 정답과 상관이 있을 것**.
이 논문은 그 상관을 AIMD 로 직접 보여서 잣대의 자격을 증명한다.

**argyrodite 의 "이온 우리(ion cage)"**
Li₆PS₅Cl 같은 argyrodite 에서 Li 는 아무 데나 있는 게 아니라 음이온(S·Cl)이 만든
**바구니 모양 자리** 안에 앉아 있고, 이웃 바구니로 건너뛰며 이동한다.
바구니의 **크기**가 그 뛰기 쉬움을 좌우한다 — 너무 작으면 갇히고, 너무 크면 오히려 깊게 앉는다.

**핵심은 평균이 아니라 균일도다 ★**
이 논문이 제안한 건 "바구니가 크다" 가 아니라 **"바구니 크기가 고르다"** 이다.
크기가 들쭉날쭉하면 Li 가 큰 자리에 붙잡혀 거기가 병목이 된다. 즉 **분포의 분산**이 잣대다.
> 평균이 아니라 산포를 보는 것 — 이건 우리 BVSE 병목 분석과 같은 종류의 사고다.
> (⚠ 개념이 겹칠 뿐 정의가 달라서 값을 직접 대응시키면 안 된다.)

**우리와의 거리**
같은 argyrodite 계열이라 문맥이 제일 가깝다. 다만 실험이 0인 순수 계산 논문이고,
같은 그룹(한양대 이상욱)의 후속인 [Kim2025 CSP](`kim2025_csp_metastable_edge_sharing_sse.md`) ·
[Kim2026 HTS](`kim2026_hts_li3sc2po43_coating_midni_ncm.md`) 와 이어 읽으면 계보가 보인다.

## 1. 한 줄 요약

Li₆₋ₓPS₅₋ₓX₁₊ₓ(X = Cl/Br/I, x = 0–0.75)의 **4a/4c 단일음이온 배열 45가지를 전수 AIMD** 로 돌려,
Li⁺ 전도도가 **"free anion 주위 Li 케이지 반지름의 표준편차(STD)"** 와 반비례함을 보이고
이를 argyrodite 고속 스크리닝용 **기술자**로 제안한다.
부수적으로 (a) **배열 앙상블을 하나의 σ_bulk 로 접는 Boltzmann 가중식**과 (b) **결정화도 보정 σ_exp = σ_calc·χc^7.14** 를 도입한다.
— **기술자 자체는 유용하나 §14의 한계가 크다.** 특히 (b)는 경험 회귀, (a)는 **차원상 무의미**하다.

### 3.3 σ 산출 체인 (ESI Section A, Eq 1–4)

```
AIMD 궤적  →  MSD(t)  →  D = MSD/(2·d·t)            (eq 1, d = 차원수)
MSD = (1/N) Σᵢ ⟨[rᵢ(t+t₀)]² − [rᵢ(t₀)]²⟩            (eq 2)
D(T) = D₀ exp(−Ea/kT)  →  log D vs 1/T 선형피팅       (eq 3)
σT = (ρ z²F²/R) · D T                                (eq 4, Nernst–Einstein)
```

- **MSD 창(fitting window)은 명시되지 않음** — 우리 규율(2–50 ps 고정)에 대응하는 서술이 없다. **판독 불가.**
- **Haven ratio 보정 없음** (NE, H_R = 1 가정) — 우리와 동일한 근사. Adeli 2019 실측 H_R 0.23–0.30 을 생각하면 **σ 계통 과소** 방향.
- **Ea 는 D(T) 피팅 기울기** — Table 1의 Ea(meV)는 여기서 나온다.

## 4. 구조 모델 & 무질서 처리 ★

### 4.1 argyrodite 골격 (Fig 1)

- 공간군 **F4̄3m (no. 216)**, 화학식 표기 **[Li₆⁺][PS₄³⁻][S²⁻X⁻]**
- **4b** = PS₄³⁻ 폴리음이온 (팔면체 자리)
- **4a** = fcc 면심 → 단일음이온 (S²⁻ 또는 X⁻)
- **4c** = 사면체 공극의 절반 → 단일음이온 (**= Kraft/우리 4d**)
- **24g + 48h** = Li⁺ 부분점유 → **케이지 네트워크**
- **Fig 1(b) 핵심 기하**: **4c-cage 4개가 정사면체 배치**, 그 **중심에 4a-cage** 가 있고, **4a-cage 와 4c-cage 는 48h 자리 3개를 공유**한다.
- 확산 경로 (본문 §3.2, Fig S8):
  - **intra-cage**: 케이지 내부 48h ↔ 48h
  - **inter-cage 4c→4c**: 4a-cage 를 경유 (**48h–48h**)
  - **inter-cage 4a→4a**: 4c-cage 를 경유 (**48h–24g–48h**)
  - → **경로 자체는 무질서 여부와 무관하게 같다.** 무질서가 바꾸는 것은 **경로의 통과 난이도**뿐.

### 4.2 6배열 (Table 1, Fig 2) — **무질서 처리의 정본**

- **생성기: `enumlib`** (https://github.com/msg-byu/enumlib; refs [9–12] = Hart & Forcade 2008/2009/2012, Morgan 2017)
- **Li₆PS₅X**: 4a+4c 8자리에 **S²⁻ 4개 + X⁻ 4개** 를 배치하는 **대칭적으로 구별되는 조합 전수 → 6개**
- **명명은 "X⁻ @ 4c 점유율"**: 0 % / 25 % / 50 %(2종) / 75 % / 100 %
- **50 %는 배열이 두 가지** (P2₁22, P2mm) — *"we adapted the **highest space symmetry** for all configurations"*

| X⁻@4c | 공간군 | 의미 |
|---|---|---|
| **0 %** | F4̄3m | X 전부 4a, S 전부 4c → **ordered** |
| 25 % | R3m | disordered |
| 50 % | **P2₁22** | disordered |
| 50 % | **P2mm** | disordered (같은 점유율·다른 배열) |
| 75 % | R3m | disordered |
| **100 %** | F4̄3m | X 전부 4c, S 전부 4a → **ordered** |

- **실험 대조** (본문 ref 49 = **Rayavarapu 2011**): 4a:4c = **Cl 0.37:0.63 / Br 0.57:0.43 / I 1.0:0.0**
  → 즉 실험 Cl 은 **4c-Cl ≈ 63 %**, Br 은 43 %, I 는 0 %. 계산 최안정은 Cl 50 % / Br 25 % / I 0 % → **정성 일치**.

### 4.3 할로겐 과잉 (Table S3) — **여기서 처리가 달라진다** ⚠

- **음이온 배열**: 각 조성에서 (4a 점유율, 4c 점유율) **분할 조합만** 열거 → x=0.25는 **4개**, x=0.5는 **3개**, x=0.75는 **2개**
- **Li 공공 배열**: 전하중성을 위해 24g 에서 Li 를 1/2/3개 제거해야 함 → `enumlib` 로
  **Li₅.₇₅PS₄.₇₅Cl₁.₂₅ = 23개 / Li₅.₅PS₄.₅Cl₁.₅ = 114개 / Li₅.₂₅PS₄.₂₅Cl₁.₇₅ = 211개** 의 Li 배치를 생성한 뒤
  → **"full relaxation 으로 가장 안정한 것 하나만 선택"**

> 🔑🔑 **여기가 우리 config-variance 축과 직접 충돌하는 지점이다.**
> **음이온 배열 = 전수 열거 + 각각 AIMD**(=앙상블 취급) 인데,

## 5. ★★★ ion-cage size 기술자 — 정의식과 역공학

### 5.1 논문이 쓴 정의 (본문 §3.2 말미, 원문 그대로)

> *"We calculated the **size of the Li-cage as the average of the distances measured from the free anions located at
> 4a and 4c sites in the heated argyrodite crystal structure to the surrounding Li-ions by AIMD simulation**."*

즉 **케이지 크기 = 반지름**이고,

$$r_{\text{cage}}(j) \;=\; \big\langle\, \big| \mathbf{r}_{\text{Li}} - \mathbf{r}_{\text{anion}(j)} \big| \,\big\rangle_{\text{surrounding Li},\; \text{AIMD}}$$

- $j$ = 4a 또는 4c 의 **개별 free-anion 자리** (단위셀당 4a 4개 + 4c 4개 = **8개**)
- 평균은 **(i) 그 자리를 둘러싼 Li 들**과 **(ii) AIMD 시간**에 대해 잡는다

Table 1 은 이 반지름을 **자리종류별(4a-X⁻ / 4a-S²⁻ / 4c-X⁻ / 4c-S²⁻)로 묶어 평균**해 4열로 인쇄한다.

**STD** = Table 1/S3 각주 c: *"Standard deviation of all Li-cage sizes."*

## 8. ★ σ_bulk 보정법 (ESI Section B) — **이 논문의 두 번째 기여이자 가장 약한 고리**

### 8.1 배열 앙상블 → 단일 σ_bulk (Eq 6–8)

$$P_i(E) \propto e^{-\Delta E / kT}, \qquad P_i(\sigma) \propto e^{-\Delta \sigma / kT}, \qquad
P_i = \frac{P_i(E)\,P_i(\sigma)}{\sum_j P_j(E) P_j(\sigma)}, \qquad \sigma_{\text{bulk}} = \sum_i P_i \sigma_i$$

- ΔE = 최안정 배열 대비 상대에너지 (**meV/atom**)
- Δσ = **가장 느린 배열 대비 전도도 차** (**mS/cm**)
- 논거: *"the Li-ion diffusion through the bulk argyrodite is limited by the **slowest** diffusion region, not the fastest"*
  → 느린 배열이 **병목(bottleneck)** 이므로 큰 가중을 준다 (Fig S2 모식도)
- **T 는 명시되지 않음**. 우리가 Table S1 수치에서 역산하면 **kT ≈ 25.9 meV → T = 300 K**.

**(a) 차원.** $\Delta\sigma$ 는 **전도도(mS/cm)** 인데 $kT$ (에너지) 로 나눈다. 지수 인자의 인수가 무차원이 아니다.
우리가 검산하면 **"σ 값을 mS/cm 숫자 그대로 meV 처럼 취급"** 했을 때만 Table S1 이 재현된다
(예: 25 % → exp(−(45−0.02)/25.85) = 0.1755 vs 인쇄 0.1739 ✓).

**(b) 단위를 바꾸면 결과가 바뀐다.** 같은 σ 를 **S/cm** 로 쓰면 모든 $P_i(\sigma) \to 1$ 이 되어
$\sigma_{\text{bulk}} = 18.79 \to$ **87.6 mS/cm (4.7×)**. → **단위 선택이 결과를 결정한다.**

**(c) 혼합규칙 선택이 3자릿수를 가른다** (우리가 같은 Table S1 로 계산):

| 혼합 방식 | σ_bulk (χc=1.0) | ×χc^7.14 (0.8) | 실험 (Table S2) |
|---|---:|---:|---|
| **논문 (E·σ 동시 Boltzmann)** | **18.79** | **3.82** | **3.10 / 2.30 / 2.5** |
| E-가중만 (열역학만) | 87.8 | 17.8 | ↑ 대비 6–8× 과대 |
| 단순 산술평균 | 67.3 | 13.7 | 과대 |
| 조화평균(직렬저항=진짜 병목) | 0.116 | 0.024 | 2자릿수 과소 |

→ **논문이 실험과 맞은 것은 "E-가중만 쓰면 6–8× 과대"인 상황에서 차원상 무의미한 kinetic 가중이 정확히 4.7× 를 깎아 줬기 때문**이다.
   그리고 그 위에 **χc^7.14 라는 두 번째 경험 노브**가 다시 4.9× 를 깎는다.
   **자유 노브 2개로 6–8× 를 맞춘 것**이므로, 이 일치는 **방법의 검증이 아니다.**

**(d) 표 안에도 산술오류 1건.** 50 %(ΔE=11) 행의 $P_i(\sigma)$ = 0.0028 인데, 같은 식으로 계산하면 **8.4×10⁻⁴** 다 (3.3× 차이).
   σ_bulk 에 미치는 영향은 작지만(0.53 / 18.79), 표가 자기 식을 따르지 않는 셀이 있다.

**(e) 논거의 자기모순.** *"가장 느린 영역이 율속"* 이라면 물리적 혼합규칙은 **직렬(조화평균)** 이다.
   그런데 실제로 쓴 것은 **가중 산술평균**이고, 조화평균으로 하면 0.12 mS/cm (실험보다 20배 낮음) 가 된다.
   즉 **서사는 병목인데 식은 병렬**이다.

```
[전제] argyrodite 전도의 율속 = inter-cage diffusion  (선행연구 + 본 논문 재확인)
   ↓
[기하] 4a-cage 4개가 4c-cage 를 정사면체로 둘러싸고 48h 3개를 공유
   → 4c→4c 이동은 반드시 4a-cage 를 통과, 4a→4a 는 4c-cage 를 통과
   ↓
[크기 결정 요인] 케이지 크기 = (Li–음이온 인력) × (음이온 이온반경)
   · 인력이 세거나 음이온이 작으면  → 케이지 작음
   · 인력이 약하거나 음이온이 크면  → 케이지 팽창
   · 4a 와 4c 의 음이온이 다르면    → 두 케이지 크기차 ↑
   ↓
[관측 1] 4a-cage > 4c-cage 항상.  X⁻-케이지 > S²⁻-케이지 항상.
[관측 2] ordered(S 전부 4c, X 전부 4a) = 4a 2.90 / 4c 2.42 Å → 크기차 최대
   → 큰 4a-cage 가 48h–48h 거리를 늘려 4c-cage 에 Li 가 갇힘
   ↓
[관측 3] disordered → X 일부가 작은 4c 로 들어가 4c 를 키우고, S 일부가 큰 4a 로 들어가

   ↓
[검증 A] Fig 4(a): ordered = 확률밀도가 한 종류 케이지에만 국재 / 50 % = 4a–4c 연결

   ↓
[기술자] STD of Li-cage size ↓  ⇔  σ ↑        (Fig 5)
   ↓

```

### 12.2 ⛔ 어긋나는 조건 4가지 (= 이 작업의 결과 중 하나)

**(1) "케이지를 키우는" 변화 — 논문 자체의 데이터가 반례를 준다.**
Table 1 에서 **가장 큰 케이지(I⁻ @4a, r = 3.11 Å)를 가진 배열이 가장 느리다** (6.9×10⁻⁷ mS/cm).
free-volume 계열 기술자는 "더 큰 공간 = 더 좋음" 쪽으로 기울기 쉽다.
→ **큰 음이온을 한쪽 자리에만 몰아넣는 변화에서 두 기술자는 반대 방향을 가리킬 수 있다.**
   같은 긴장이 `rao2025` 안에도 있다: Rao 는 σ 최대(Cl–I 0.75:0.75)의 근거로 **"Li Voronoi 부피 9.39 Å³ = 넓은 채널"** 을 들지만,
   Jun 은 **큰 할라이드가 케이지 균일성을 깨서 나쁘다**고 한다. **두 서사의 화해점 = "크기가 아니라 균일도"** 이다.

**(2) Li 공공 축 — 우리 static-channel paradox 를 Jun 기술자는 통과한다.**
우리 db 의 기록: **comp1 → modelc 에서 BVSE 채널 % 는 −15 % 인데 σ 는 ×4** (`kb/concepts/ordered_vs_disordered.md` §4,
`tools/ionic/li_percolation.py` docstring). 우리는 이걸 **F\* (0.191 → 0.078 eV)** 로 해소했다.
Jun 기술자를 같은 축에 얹으면: Table 2 Cl 에서 **x = 0 → 0.6 (=modelc 조성) 로 STD 0.1193 → ≈0.07 (감소)**, σ 는 증가 방향.
→ **Jun STD 는 F\* 와 같은 편, 우리 BVSE 채널 % 와 반대 편**이다.
   ⚠ 단, 이건 STD 가 **AIMD 로 실제 Li 위치를 보기 때문**이지 기하학적 우월성 때문이 아니다.

**(3) 연결성이 없다.** STD 는 **완전한 국소 통계**다. "케이지가 다 똑같은데 목(neck)이 막혀 있는" 구조를 **구별하지 못한다.**
우리 `li_percolation` F* 와 `dopant_blocking_fraction` 은 정확히 그 축을 잰다.
→ **도펀트 양이온이 채널 목에 앉는 경우**(우리 blocking 축)에서 두 기술자가 갈릴 것으로 예상. **테스트 가능한 예측.**

**(4) 정의역이 다르다.** BVSE 채널 % 는 **아무 셀에나** 정의된다. Jun STD 는 **argyrodite 골격(4a/4c free anion 자리)** 이 있어야 정의된다.
→ 우리 47종 중 **치환형(O, Nd 등)** 은 계산 가능, **개재/코팅형(B₂O₃·Sc₂O₃·WO₃ 등 별상)** 은 **정의 불가**.

### 15.2 구현 레시피 (우리가 쓸 경우) — 후처리만, 새 시뮬레이션 0

```python
# 입력: 기존 UMA-MD 궤적 (comp1/modelc/comp2-cfg/LPSOCl), 온도 T 고정
# 1) free-anion 자리 식별: 초기 구조에서 PS4 에 속하지 않는 S/Cl/O 원자 index
#    (P 로부터 2.2 Å 이내 S = PS4 의 S → 제외)
# 2) 각 free anion j 에 대해, 프레임마다 컷오프 R_c 안의 Li 를 모아 평균거리
#    r_j(t) = mean( |r_Li - r_j| for Li within R_c )
# 3) 시간평균 r_j = <r_j(t)>_{창}          # 창은 우리 MSD 창(2–50 ps)과 통일
# 4) STD = population std over ALL free-anion sites  (Jun 의 Table S3 정의)
#    보조로 자리종류별 평균 → 그 4~6값의 std  (Jun 의 Table 1 정의)
# 5) cfg 앙상블이면 cfg 간 산포를 오차막대로 보고     ← 논문에 없는 우리 몫
```

**우리가 반드시 고정해야 하는 것 (논문이 안 정한 것)**
- **R_c**: Li–S 1차 껍질이 ~2.4–2.5 Å, Li–Cl 이 ~2.9 Å 이므로 **R_c = 3.2–3.5 Å** 가 자연스럽다.
  → **R_c 민감도 스캔을 반드시 같이 낸다** (2.8 / 3.2 / 3.6 / 4.0 Å).
- **온도**: **600 K 단일 온도**로 고정 (우리 3-시드 기준 온도와 통일).
- **창**: **2–50 ps** (우리 MSD 창과 동일) — CLAUDE.md 규율.
- **시드**: 3-시드 평균 + 산포.

### 15.3 우리가 이미 갖고 있는 사촌 도구

`tools/comp1_v3/voronoi_volume_disorder.py` 가 **원자별 Voronoi 부피의 종별 mean/std** 를 낸다.
docstring: *"std(V) = 0 → crystallographically equivalent sites (ordered); larger std → more site disorder"*.
→ **"국소 부피의 산포 = 무질서 지표" 라는 발상을 우리도 이미 갖고 있다.**
   차이는 **중심을 무엇으로 잡느냐**: Voronoi 는 **원자 중심**, Jun 은 **free-anion 중심의 Li 껍질**.
   → **두 지표를 같은 궤적에 동시에 얹어 비교하는 것이 가장 값싼 검증**이다 (둘 다 후처리 전용).

## 18. 인용 가능 문장 (deck / manuscript 용)

- "argyrodite 의 Li 전도는 케이지가 **큰가**가 아니라 4a-cage 와 4c-cage 가 **서로 비슷한가**에 달려 있다 —
  케이지 크기의 표준편차가 작을수록 inter-cage 확산이 활성화된다[Jun 2022]."
- "완전질서 배열(할로겐 전부 4a 또는 전부 4c)의 Li 확산 장벽은 무질서 배열의 **2–4배**이며, 실온 전도도는 **3–7자릿수** 낮다
  (Li₆PS₅Cl: Ea 452/339 vs 151–193 meV)[Jun 2022]." ⚠ σ 절대값은 병기하지 말 것
- "van Hove 자기상관에서 질서 배열은 **~5 Å(= 케이지 지름)에 강한 띠가 50 ps 유지**되어 Li 가 케이지에 갇혀 있음을 보이고,
  무질서 배열은 전 거리로 번져 inter-cage 확산이 열렸음을 보인다[Jun 2022]."
- "distinct-part van Hove 분석은 argyrodite 의 Li 이동이 **수 ps 안에 여러 이온이 동시에 뛰는 highly concerted mode** 임을 보인다 —
  그래서 단일 경로를 전제하는 NEB 가 초이온 전도체에 부적합하다[Jun 2022]."
- "할로겐 과잉 Li₆₋ₓPS₅₋ₓCl₁₊ₓ 에서 x 가 커지면 과잉 Cl⁻ 가 작은 4c 자리를 메워 케이지 크기 산포가 줄고
  Li 전도도가 단조 증가한다 (x = 0 → 0.75 에서 STD −48 %)[Jun 2022]." ⚠ σ 는 비율만
- "AIMD 로 얻은 배열별 실온 전도도는 **같은 구조·같은 온도의 독립 시행 3회 사이에서도 무질서 배열은 1.3–2.5배,
  질서 배열은 3–260배** 흔들린다[Jun 2022 Table 1 의 min–max 로부터]." ← **단일시드 판정 금지 규율의 외부 정량 근거**
- (⚠ 비판적 인용) "argyrodite 배열 앙상블을 하나의 벌크 전도도로 접는 문헌 관행은 **열역학·동역학 Boltzmann 가중 + 결정화도 경험보정(χc^7.14)**
  두 개의 자유 파라미터에 의존하며, 가중식의 지수 인수는 차원이 맞지 않는다[Jun 2022 ESI Section B]."
