원 반박 탐침을 변경하지 않고 같은 두 메모에 적용한 결과도 rc1→rc0이다. 산술/수동 문서 전사이며 생산 코드 실행으로 세지 않는다. 원 증거 ZIP과 before 사본, 고정 커밋 snapshot, 1개 수정 패치를 동봉한다. 원장 제안만 있으며 실제 상태는 바꾸지 않았다.

M32RF-01은 M32R-01/DRD-01의 잔여 문구 P2이고 별개 P1이 아니다. 해당 문서 범위 종결 가능 여부와 새 P1/P2/P3 유무만 짧게 재확인해 달라. 그 밖의 트랙·실제 자료·현장·연구 계산은 요청하지 않는다.
