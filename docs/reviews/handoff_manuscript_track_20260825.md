# A. 판별 런 — SDCP 접촉 브리지 (사전등록 완료, **손대지 마라**)

## A-1. 무엇을 묻나

CL-41: 세 격자에서 이득이 **단조 증가하고 멈추지 않는다**.  증분비 **1.773** 이
`R = R∞ − C·h^p` 의 최소값 **2.187**(p→0⁺)보다 작아 **어떤 p > 0 도 안 맞는다** ⇒
Richardson 무의미.  기전은 원장에 `Q-B2, 후보 없음` 으로 적혀 있었다.

**SELF-11 이 후보를 댔다 — SDCP 접촉 양자화.**  생산 격자(vox 0.15, d/vox 2.00)에서
Ø0.30 구 쌍은 **참 접촉의 35 % 를 놓치고**, **10 % 물리적 틈의 32.5 % 를 가짜로 잇는다.**
두 오차는 σ 에 **반대 방향**이고 h 수렴 속도가 달라 **멱법칙이 원리적으로 안 맞는다** —
CL-41 의 관측과 정합한다.

★ 왜 하필 **비**가 움직이나: 전자 격자에서 SBE↔DBE 의 유일한 차이가 SDCP 다
(CL-33 의 **SBE 음성 대조 8/8 셀 단위 동일**이 증인) ⇒ 이 오차는 **DBE 전용**이라
침대 간 공통모드 상쇄가 원리적으로 없다.

★★ 코드는 이 문제를 **이미 알고 다른 상에는 고쳐 두었다** (`step3_sigma.py:232`:
*"plain rasterization randomly DROPS touching contacts"*): AM–AM 은 접촉 브리지,
섬유는 `_fibre_segment_ijk` 로 6-면 보장.  **SDCP 구만 무처리**였다.

## A-2. 판정선 — **런 전에 고정됐다.  결과를 보고 옮기면 무효다**

정본: `docs/reviews/sdcp_bridge_prereg_20260825.md` (런 전 커밋).

`ΔR_grid ≡ |R(vox 0.125) − R(vox 0.15)|`, 구 스탬프 Ø0.30 · 8팔 factorial · 쌍대응.

| | |
|---|---|
| **h1** (채널 A 지배) | `ΔR_grid` 가 off 대비 **≥ 70 %** 축소 |
| **h0** (채널 B 지배) | **< 30 %** 축소 |
| 사이 (30–70 %) | `BOTH_REJECTED` — 두 채널이 섞여 있다는 뜻이고 **그 자체가 결과다** |
| SE 요건 | 8팔 비대응(quadrature) SE 가 `ΔR_grid` 의 **1/3 이하**.  넘으면 판정 안 한다 |

⚠ **이 노브는 보장된 해결책이 아니라 판별기다.**  런 전 CPU 측정(고정 격자, 120 회):
참 접촉 연결확률의 격자 폭이 **0.300 → 0.000** (채널 A 완전 제거)인데,
10 % 틈 가짜 연결은 **0.333 → 0.283** (채널 B 거의 그대로).  브리지가 만드는 것이 아니라
**스탬프 해상도 자체의 산물**이라 연결 검출로는 못 고친다.

## A-3. 결과별 다음 수 (**미리 적어 둔다 — 결과를 보고 정하지 않는다**)

- **h1** → 메모리를 안 늘리고 수렴하는 파이프라인을 얻는다.  ⚠ 그래도 **생산 규약 승격은
  별도 판단**이다 (목 면적이 `1.2·vox` 로 양자화되는 v1 한계가 남는다).

- **BOTH_REJECTED** → 두 채널의 상대 크기를 재는 것이 다음 실험이 된다.

★ 해상도 산술을 미리 알아 둘 것: 구 스탬프 게이트는 `d/vox ≥ 2.0` 인데 리포가 확립한

# B. 이온 보정 — Figure 2h/2i (D13, **아직 사전등록 없음**)

## B-1. 왜 이것이 지금 가장 값어치 있나

원고 D12 가 **이온 행을 전부 비운 이유**가 이것이다: 생산 설정에서 **PTFE 가 전도 격자에
아예 스탬프되지 않아**, Figure 2h 가 보고하는 효과를 모델이 표현할 수 없다.  그러면
SBE↔DBE 이온 차이가 "DBE 에만 SDCP 가 있어 부피를 점유한다" 하나로 줄어든다.

Figure 2h/2i 는 **9:1 wt 펠릿**을 재는데, 이것이 곧 **이 논문 자신의 상-수준 보정 데이터**다.

## B-2. 이미 확정된 것 (원고 D13, 리포 밀도 규약 LPSCl 2.00 · PTFE 2.20 · SDCP 1.30 g cm⁻³)

| 바인더 (9:1) | vol % | 희석만(Bruggeman `(1−φ)^1.5`) | 실측 | 실측/예측 |
|---|---:|---:|---:|---:|
| PTFE | 9.17 | 3.09 mS cm⁻¹ | **0.97** | **0.31** |
| SDCP | 14.60 | 2.82 mS cm⁻¹ | **2.86** | **1.02** |

⇒ **SDCP 는 이온망에서 사실상 불활성 충전재**다 (부피 희석만으로 1.5 % 안에서 설명;
Maxwell–Garnett 교차확인 절연가정 2.84 vs 실측 2.86, `σ_ion=1.0` 가정은 3.10 으로 벗어남).
ρ_SDCP proxy 1.3 을 1.1–1.7 로 흔들어도 비는 1.06–0.96 로 결론 불변.
⇒ **PTFE 는 희석으로 설명되는 것의 3.2 배를 더 깎는다** = 부피 점유가 아니라
**표면 피복 / 피브릴 웹의 차단**.

⇒ 지금 모델은 **둘 다 놓치고 있다**: `σ_ion(SDCP)=1.0 mS cm⁻¹` 로 후하게 잡았고 PTFE 는
안 그린다.  두 오차가 **같은 방향**으로 이온 비를 DBE 에 불리하게 민다.

## B-3. ★ 설계 — **이온에 맞추고 전자를 예측한다** (이게 핵심이다)

같은 9:1 펠릿 RVE 를 같은 복셀 파이프라인으로 만든다 (작아서 CPU 로 된다).

- **맞출 것 (2 자유도 → 2 표적 = 정확결정, 검증 아님)**
  ⓐ `σ_ion(SDCP)` ⓑ PTFE 차단 표현(스탬프 + 표면층) → **0.97 / 2.86 mS cm⁻¹** 재현
- **예측할 것 (검증)** — 같은 RVE·같은 기하로 **전자 축**을 돌린다.
  Figure 2i 가 같은 펠릿의 σ_e 를 준다: LPSCl **0.30** → +PTFE **0.12** → +SDCP **1.53**
  (단위 `× 10⁻⁷ S cm⁻¹` — ⚠ **그림에서 지수 귀속을 먼저 확인할 것**).
  자유 파라미터는 `σ_e(SDCP)` 하나뿐 ⇒ **3 표적 − 1 파라미터 = 2 자유도만큼 과결정** =
  **진짜 검정**이다.

⚠⚠ **2 표적에 2 파라미터를 맞추는 것만으로는 아무것도 검증되지 않는다** (항상 맞는다).
검증은 **전자 축**에서 온다.  이 순서를 바꾸지 마라.

★ 가장 날카로운 부분: SDCP 14.6 vol% 는 **3D 구 퍼콜레이션 문턱(≈16 vol%) 바로 아래**다.
그런데 실측 σ_e 는 1.53 × 10⁻⁷ 수준으로 **작다** ⇒ 그 펠릿에서 **SDCP 는 퍼콜하지 않는다**.
모델이 14.6 vol% 에서 퍼콜해 버리면 σ_e 가 수십 자릿수 커져 **모델이 틀렸다는 것이 즉시
드러난다**.  현행 `σ_e(SDCP)=250 S cm⁻¹` 는 **논문 밖에서 온 가정값**이므로, 같은 RVE 로
1.53 × 10⁻⁷ 을 재현하는 값을 찾으면 **전자·이온 두 축이 모두 이 논문 자신의 Figure 2 에
앵커**된다.

# C. 열린 채무 (둘 다에 걸린다)

- **`σ_SDCP = 250` 출처** — 캐스트 필름인지 압착 펠릿인지 미상.  펠릿이면 접촉저항이
  포함된 값인데 복셀 솔버는 접촉을 융합하므로 **이중계상**이다 (CL-47 이 σ_VGCF 에서
  지적한 부류).  **사용자 회신 대기.**  ★ B 가 이것을 **실측으로 대체**할 수 있다.
- **`ρ_SDCP`** — 코드에 `1.30 g/cm³` 가 `PROXY, REPLACE with the user's manuscript value`
  로 박혀 있다.  wt%→vol% 환산에 쓰이므로 침대 조성이 걸린다.
- **원고 D3 = 재압밀** — 지금 미세구조는 **AFM 이전 세대**(PTFE 0.30 · SDCP 23.6 GPa)로
  압밀한 것이다.  투고 전 재압밀이 필요하고, 그때 Table S3 의 두께·porosity·면적용량·σ_e
  가 바뀐다.  ⇒ **그 셋을 지금 채우지 마라** (SELF-07 주석 정정 참조).
- **원고 D4 의 낡은 문장** — *"두께·porosity·면적용량은 … 그대로 두었고"* 는 D3 이 그 셋을
  비우기 **전의** 잔여 문장이다 (표는 셋 다 `—`).  D3 이 맞다.  산문이라 사용자 확인 대기.
- **porosity 관례** — D4 는 **구 부피 기준(ε_sphere)** 을 지시한다.  MPM(union) 값과는
  부기 오프셋이 있고 그 크기는 침대마다 다르다 ⇒ **빼서 옮기지 말고 새 침대에서 다시 낼 것.**
