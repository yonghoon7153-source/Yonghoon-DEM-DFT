## 산출 방법

각 걸음은 입자 간 접촉 계산 앞뒤로 아래판 조건을 한 번씩 적용한다. 각 적용 직전 아래로 움직이고 양의 질량을 가진 격자 속도장 항목을 모았다. 그 총질량을 *M*, 그 질량이 가진 평균 하향속도를 *v*, 계산 시간 간격을 Δ*t*, 판 폭을 *W*라 둔다. 압력 성분은 *P* = (10 / *W*) × *A* × *v*이고 *A* = *M* / Δ*t*다. 10은 압력을 MPa로 바꾸는 모델의 단위 계수다.

두 격자에 모두 해당 질량이 있을 때 격자 간 곱의 차이를 대칭 분해했다. 질량/시간 몫은 (10 / *W*) × (*A*₈ − *A*₁₆) × (*v*₈ + *v*₁₆)/2이고, 속도 몫은 (10 / *W*) × (*A*₈ + *A*₁₆)/2 × (*v*₈ − *v*₁₆)이다. 이 방식은 두 인자가 함께 바뀌는 몫을 반씩 배분한다. 백분율 분모는 각 행의 F8 − F16 총압력 차이다.

접촉 전 적용에서는 두 격자 모두 하향 질량이 있었다. 접촉 후 적용에서는 F16에 해당 질량이 없어 평균 속도가 정의되지 않았다. 이때 F8에만 생긴 반력을 별도 열에 넣었다. 각 행에서 세 성분을 반올림 전 합산하면 원 차이가 배정밀도 오차 이내에서 복원된다. 첫 초과 부근의 압력 구성을 설명하는 자료이며 전체 구간 최대 오차(80.86%)의 원인 분해와 물리적 정확성은 미확정이다. U6(c) 자격과 단계 3은 HOLD다.
