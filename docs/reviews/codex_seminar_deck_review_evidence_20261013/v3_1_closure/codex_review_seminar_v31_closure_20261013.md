# 연구세미나 v3.1 종결 판정

2026-10-13. 대상은 제출 ZIP의 **17장 v3.1 PPTX와 17쪽 PDF**다.

## 1. 판정

**GO. SEMV3-01–10을 이번 발표물 범위에서 닫는다.** 직전 필수 수정 다섯 묶음이 실제 슬라이드·그림·발표 노트에 반영됐다. 새 발표 차단 항목은 발견하지 못했다. 이 판정으로 v3 발표물 수정 검토는 종결할 수 있다.

이것은 **현재 한정어를 유지한 연구세미나 발표 GO**다. 믹서 모델의 물리적 검증, 미달 겹침 조건의 해소, 18런 발사, 194/보충20 생산, v1.3 배포 승인으로 확장되지 않는다. 해당 보류 상태는 덱에도 남아 있다.

작은 글씨의 투사 가독성과 PowerPoint 고유 렌더는 발표 환경에서 한 번 점검할 사항이다. 현재 PDF에서 글자 충돌·잘림이 남았다는 판정이나 새 HOLD 조건은 아니다. 원본 파일은 수정하지 않았다.

- PowerPoint 앱에서 직접 열어 검사한 것은 아니다. 제출 PDF는 요청서가 밝힌 LibreOffice/Carlito 출력이며, 여기서는 그 실제 PDF와 PPT 내부를 대조했다.

### So 크롭은 데이터 변경 없이 넓어졌다

구 크롭은 **1045×1005 px**, 새 크롭은 **1133×1005 px**, 제공된 원 Fig.4는 **2201×1005 px**다. 구 크롭의 모든 픽셀은 새 크롭의 왼쪽 영역과 완전히 같고, 새 크롭도 원 그림의 같은 영역과 완전히 같다. 오른쪽 **88 px를 추가**한 것으로, 데이터 재그리기가 아니다. 실제 PDF에 500 MPa 눈금과 오른쪽 데이터가 들어온다.

문헌 정본 카드 자체의 잘못된 DOI를 별도로 정리하는 일은 남을 수 있으나, **현재 덱은 그 DOI를 쓰지 않는다**. 발표 출처 항목을 다시 열 이유는 없다.

### p13 식의 지위

현재 표현은 `W_AS = 2√(γ_Aγ_S)`를 **가정한 모형 안에서** `ΔW = 2(√γ_A−√γ_S)² ≥ 0`라는 항등식을 제시한다. 이 가정과 J/m² 단위가 화면에 있으므로 실제 코팅에서 총 에너지가 반드시 방출된다는 주장으로 바뀌지 않는다.

0.309/0.391도 각각 `1/1.8² = 0.3086419753`, `1/1.6² = 0.390625`의 올바른 반올림이다. 군집 생존 판정선으로 재사용하지 않는 현재 한정을 보존하면 된다.

## 4. 수치와 그림

직전 판정은 여섯 비믹서 그림의 수치를 확인했다. 이번 직접 대조에서도 **CSV 6개가 SHA-256까지 동일**하다. F_mix1의 M·SD 20칸도 그대로다. F_mix2의 15값과 F_mix3의 mean/lo/hi 9값은 보존된 프레임 자료에서 다시 계산해 CSV와 절대차 `1e−12` 미만으로 일치했다.

## 5. Q5 작은 글씨와 발표 화면

실제 PPT 배치 폭과 SVG 원 크기에서 계산한 최소 그림 글씨는:

- p4: 배율 0.895993292 × 원 글씨 9.5 pt = **8.51194 pt**
- p8: 배율 0.845886104 × 원 글씨 10.5 pt = **8.88180 pt**

요청서의 8.5/8.9 pt와 맞는다. **발표장에서 작게 보일 위험은 있다.** 다만 독립 1600 px 렌더에서 축·범례가 서로 침범하지 않고 읽히며, 결론을 제한하는 본문은 더 큰 글씨로 제시한다. 숫자가 작다는 이유만으로 새로운 과학적 HOLD를 만들지는 않는다.

발표자는 실제 프로젝터 또는 전체화면에서 p4·p8을 점검하고, 필요하면 해당 그림을 확대해서 설명하면 된다. 현재 내용·판정의 필수 수정은 아니다. PowerPoint에서 열 때 글꼴 대체로 줄바꿈이 바뀌는지도 한 번 확인하는 것이 좋다.

**p11–13 우상단 출처 줄은 잘리지 않았다.** PDF 폭 720 pt 중 오른쪽 끝이 각각 687.632/687.634/687.604 pt로 약32.4 pt의 여유가 있다. 채팅 미리보기에서 끝부분이 잘려 보이는 현상을 파일 결함으로 세지 않았다.

네 빈 그림 자리(p5 우측·p7 좌측·p11 우측·p12 우측)와 표지 날짜는 기존에 의도한 상태이므로 결함이 아니다. 이후 새 이미지를 넣는다면 팔·상태·단위·출처는 그 새 이미지에 대해 확인해야 한다.

### 축소판의 승계 조건

이번 실물은 17장이고 MANIFEST에도 p8–10 유지 기록이 있다. 아직 없는 축소판을 승인했다고 읽으면 안 된다.

향후 p8–10만 삭제한다면 대응은 `1–7→1–7`, `11–17→8–14`다. 새 값·새 문장·새 그림이 없다면 과학적 전면 재심은 필요 없다. 대신:

1. 남은 각 장의 **본문·notes·표 값·삽입 이미지·크롭**이 해당 v3.1 장과 같은지 비교한다. 페이지 번호 같은 기계적 변경만 구분한다.
2. 새 PPTX/PDF 해시와 장 번호 대응표를 남긴다. **해시는 파일을 식별할 뿐 내용 동일성을 대신하지 않는다.**
3. 재생성 PDF에서 남은 장의 줄바꿈·잘림, 장 간 참조, 인용 번호를 확인한다. 참고문헌에 미인용 항목이 남는 것과 잘못된 인용을 구분한다.
4. 남은 p7·Plan·Summary의 격자 의존성, 이상적 계면, 절대값·최종 판정 미확인 한정은 삭제하지 않는다. 본문의 제한 세부를 덜 보여 준다고 해결된 것으로 바꾸면 승계 범위를 벗어난다.

원인 설명 없이 본문이나 도식까지 고친 축소판, 새 화면 캡처를 넣은 판은 변경 부분만 다시 확인하면 된다. 모든 연구 결과를 처음부터 재심할 필요는 없다.

## 7. 비차단 잔여와 재현

생성기 머리말 `build_seminar_v3.py:13`에 `cohesive / non-cohesive NCM`이라는 옛 설명이 남아 있다. **현재 본문·그림·CSV·notes로 출력되지 않는 주석**이다. 다음 유지보수에서 정리할 수 있으나 SEMV3-02를 다시 열지 않는다.

핵심 증거:

- `evidence/input_manifest.json`: 직접 계산한 입력 파일 식별값
- `evidence/pptx.json`, `all_slide_text.txt`, `body_notes.diff`: 실제 본문·노트·삽입 이미지와 이전 판 대비
- `evidence/closure_checks.json`: 제출 해시 83건·PPT 삽입 그림 10건·So 크롭 픽셀·출처 줄 경계
- `renders/page-01.png`–`page-17.png`: 독립 PDF 렌더
- `evidence/numeric_closure.json`, `evidence/numeric_inputs/`: 프레임 산술·CSV·SVG 검산과 필요한 이전 입력 사본 19개

`python audit_closure.py`는 이 묶음에서 식별·삽입·문구·크롭·PDF 경계 검사를 다시 수행한다. `python notes/audit_numbers.py`는 보존한 입력에서 수치와 SVG 막대를 다시 계산한다. 둘 다 제작자 selftest나 시뮬레이션을 실행하지 않는다. `inspect_closure.py`는 최초 제출 ZIP과 이전 검토 폴더를 읽은 환경별 추출 기록이다.
