# 미팅 2026-05-12

> 원본: `../sources/2026.05.12_미팅.pdf` (19 p). 과제 진행보고 + 2차년도 설계방향.

## 1. 일정
- 1차년도(2025.10~2026.03): ① 전기화학-기계 모델 구축 24주 ② 임피던스 디커플링 12주.
- **2차년도(2026.04~2027.03):** ① 모델기반 단결정 적용 전극 전기화학 거동 예측 36주
  ② 양극재·전극 설계요소별 후막 성능결정인자 정량분석 36주 ③ 성능결정인자 기반 후막 양극 기본 설계안 16주.

## 2. DEM 활용 복합양극 미세구조 예측 (★ DEM↔실험 교차검증)
- 입자: **대립 P = 12 µm, 소립 S = 4 µm, SE = 1 µm**, 면용량 8 mAh/cm².
- P:S = 0:10 / 3:7 / 5:5 / 7:3 / 10:0 porosity 비교 (Simulation vs Experiment 나란히).
  - DEM(시뮬) porosity: 대략 14–20 % 범위, bimodal에서 dip.
  - 실험 porosity: S only 23.9 → 7:3 19.7(최소) → P only 25.3 % (`../../../db/porosity/`).
  - → **bimodal dip 경향을 DEM과 실험이 모두 재현** (절대값은 조건차로 상이, 경향 일치 = cross-validation).
- DEM **tortuosity** vs P:S: 3:7 / 5:5 / 7:3 / P only 구간에서 **1.20–1.24** (대립↑ 시 소폭 증가).
- 연계: DEM/MPM 브랜치 `claude/stoic-knuth-NObVQ` (McGeary/Bouvard Furnas dip).

## 3. 엘앤에프 단결정 샘플 분석 (No.1 & No.2)
- No.2에서 Ni 함량 증가 (No.1 Ni 82.5 < No.2 Ni 86.9 mol%).
- Powder/건식 충방전 (0.2C, **60 ℃**), 면용량 2 & 4 mAh/cm² 프로파일.
- **Powder 풀셀 임피던스 TLM 피팅** (`../../../db/electrochemistry/impedance_tlm.csv`):
  | 샘플 | Rion (Ω·cm²) | Rint (Ω·cm²) |
  |---|---|---|
  | No.1 | 0.61 | **4.42** |
  | No.2 | 0.87 | **23.37** |
  → No.1(매끈 표면)이 No.2(satellite 잔류물) 대비 **계면저항 5배↓**. 표면 잔류물이 계면저항 주범.
  등가회로: ri(이온)–rint(계면)–Zw(Warburg)–cpe_int–re(전자) TLM 구조.

## 4. 건식 후막셀 데이터
- Bimodal **7:3 (No.1, No.2)**, 6 mAh/cm², 0.2C, 60 ℃ 충방전.
- (p19) 수명/쿨롱효율 데이터 정리.

## 5. ★ 다층구조(구배) 후막 양극 설계안 — 2차년도 핵심
- **고정 조건:** 면적당 8 mAh, AM 80 wt%, **P:S = 7:3**. 0.5C 충전. 구성: 분리막 / 상부 복합양극 / 하부 복합양극 / 집전체 / Li metal.
- **설계변수 (1) 상/하부 AM 함량 구배** → 유효 이온전도도 제어:
  - 균일 80% (ref) / 상부 65%·하부 95% / 상부 95%·하부 65%.
  - 분리막측(상부) AM↓ → catholyte↑ → 이온 path 형성; 집전체측(하부) AM↑ → 전자전도·에너지밀도↑.
- **설계변수 (2) 상/하부 P:S 분율 구배** → 활물질 표면적·입자크기로 반응 제어 (분리막측 소립↑).
- (1)+(2) 결합 + **3층 구조** 설계안. **SE bimodal** (large SE ~4 µm 고이온전도 활용).
- 설계 참고문헌 (논문 에이전트로 digest 후보):
  - *Batteries & Supercaps* 2024, 7, e202300522
  - *ACS Energy Lett.* 2025, 10, 1664–1670
  - *Nat. Commun.* 2025, 16, 7667
  - *Adv. Mater.* 2024, 36, 2309306

## 인사이트 (이 브랜치 작업 연결)
- **P:S 7:3 = porosity 최소**가 실험·DEM 공통 → 다층 설계의 기준 조성으로 확정.
- No.1 vs No.2: 용량(No.2↑) ↔ 계면저항(No.1↓) **trade-off** → 다층에서 위치별 배치 전략 가능
  (예: 고율 필요한 분리막측 No.1, 고용량 필요한 집전체측 No.2 등).
- 다층/구배 = 단일조성 후막의 두께방향 반응 불균형(연차보고서 모델 결과) 해결책 → 2차년도 설계 메인.
