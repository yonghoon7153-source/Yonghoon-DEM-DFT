# 수영 U6(c) 원판 번호 반전 F8 반환

## 1. 49개 원판의 번호만 바꾼 결과

고정 F8 격자·시간 간격·원판 49개·물질점 9,653개의 행 순서·좌표·부피를 유지했다. 각 점의 원판 번호만 `i → 48 − i`로 뒤집었다. 원 F8 개발 팔은 기존 벽 관측 반환을 사용했다. 두 팔 모두 1.2 MPa에 처음 도달한 걸음에서 가압을 멈췄다. 반전 팔은 92.85초에 끝났다.

| 지표 | 원 F8 | 번호 반전 F8 |
|---|---:|---:|
| 1.2 MPa에 도달한 첫 걸음 | 2,578 | 2,475 |
| 1.2 MPa 통과 변위 (양옆 두 걸음 사이 선형 보간) | 0.11559721 | 0.11099432 |
| 공통 끝 변위 0.11100329의 아래판 반력 (MPa) | 1.10965834 | 1.20049863 |
| 사전 지정 변위 0.11562282의 아래판 반력 (MPa) | 1.20085552 | 미도달 |

번호를 반전하자 103걸음 먼저 압력 상한에 도달했다. 공통 구간 2,476개 점은 모두 양쪽의 같은 걸음, 같은 변위다. 절대 반력 차이의 최댓값은 공통 구간 끝에서 **0.09084029 MPa**였다. 부호는 원 F8 − 반전 F8 = −0.09084029 MPa다. 종점 전 `u=0.100`에서도 반전 팔이 0.03225037 MPa 높았다 (구간 내 선형 보간).

사전에 지정한 변위에서의 차이는 미정이다. 이 결과는 **번호 부여가 한 개발 가압 궤적의 반력에 영향을 미쳤다**는 증거다. 이를 F8↔F16의 격자 차이에서 빼거나 그 원인의 몫으로 환산할 수 없다. ⑤ 번호 순서에 대한 정량 수용 문턱은 미확정이다. ⑥ 격자 대조의 두 결과 89.15%, 19.11%와 5% 기준은 그대로다. U6(c) 자격과 단계 3은 보류한다.

## 3. 한 노드의 접촉을 더 반복하면 차이가 줄어드는가

두 물체가 정면으로 만나는 사례와 세 물체가 한 노드에 모이는 대칭·비대칭 삼각형을 사용했다. 물체의 위치, 질량, 접근 속도를 고정하고 물체 번호의 가능한 모든 순서를 적용했다. 아래 값은 결과를 원래 물체 순서로 되돌린 뒤, 순열 간 같은 물체의 속도 차이의 최댓값이다 (합성 속도 단위).

| 배치 | 번호 순서 수 | 마찰계수 0.5 | 마찰계수 0 |
|---|---:|---:|---:|
| 두 물체 | 2 | 0 | 0 |
| 대칭 삼각형 | 6 | 0.345994 | 0.378886 |
| 비대칭 삼각형 | 6 | 0.412535 | 0.451913 |

세 물체 계산에서 기존 함수는 한 번 호출할 때 접촉 쌍을 네 차례 순회한다. 속도를 이어받아 총 4·8·16·64차례 순회했을 때 표의 각 값은 동일했다. 처음 네 차례 뒤부터 추가 순회가 바꾼 속도는 0이었다. 모든 쌍의 법선 접근 속도가 이미 0 이하였고, 쌍을 방문한 순서에 따라 서로 다른 최종 속도가 남았다. 같은 고정 노드의 순회 횟수만 늘리는 처방은 이 두 삼각형에서 효과가 없었다.

무마찰 대조에서는 두세 물체의 법선 제약을 동시에 만족하는 속도를 별도로 구했다. 질량으로 가중한 속도 변화의 제곱합이 최소가 되도록 활성 접촉 집합을 열거했다. 두 물체에서 기존 함수와 동시 해의 최대 속도 차이는 1.11 × 10⁻¹⁶이었다. 대칭 삼각형에서는 동시 해가 세 물체 모두 정지이고, 기존 함수는 물체 번호에 따라 서로 다른 속도를 남겼다. 이 해의 적용 범위는 고정된 단일 노드의 무마찰·비탄성 접촉이다. 가압 계산의 마찰계수 0.5에 대한 물리 기준은 별도로 검토해야 한다.

두 합성 검사의 결과는 `docs/reviews/suyoung_u6c_order_return_20261122/frozen_node_sweeps.json`과 `docs/reviews/suyoung_u6c_order_return_20261122/normal_reference.json`에 있다. 검사 재현은 리포 루트에서 다음과 같다.

```sh
review=docs/reviews/suyoung_u6c_order_return_20261122
fixtures=docs/reviews/suyoung_u6c_seed_return_20261122/node_permutation.json
python3 -I -B "$review/test_frozen_node_sweeps.py" --repo . -v
python3 -I -B "$review/test_normal_reference.py" -v
python3 -I -B "$review/frozen_node_sweeps.py" --repo . --out "$NEW_DIR/frozen_node_sweeps.json"
python3 -I -B "$review/normal_reference.py" --scripts scripts --fixtures "$fixtures" --out "$NEW_DIR/normal_reference.json"
```

두 시험 묶음은 각각 4/4 통과했다. 재생성은 존재하는 빈 출력 폴더를 사용한다. 이 검산은 물질점의 위치나 계산 시각을 전진시키지 않는다.

## 4. 다음 개발 비교

다음은 마찰을 포함한 다중 접촉 후보를 위의 같은 노드에서 비교하는 일이다. 두 물체의 달라붙음·미끄러짐과 접선 충격량 한도, 세 물체의 여섯 순열에서 물체별 결과, 운동량 보존·에너지 비증가를 함께 확인한다. 무마찰 극한에서는 동시 법선 해와 대조한다. 이를 만족하는 후보가 생기면 원 번호와 반전 번호의 F8 가압 궤적을 다시 비교할 수 있다. 이번에는 추가 WSL 팔이 필요하지 않다.
