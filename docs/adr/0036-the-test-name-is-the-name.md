# ADR 0036 — 세워 놓은 `test.bmlwork.kr` 을 그대로 쓴다

- 상태: **채택** (2026-09-13)
- 검증: 관문 10개 중 8개 통과 — `docs/log.md` 의 2026-09-13 `verify` 항목 둘
- 관련: ADR 0034(우리 VPS 를 앞에 둔다), `docs/guides/vps-rollout.md`,
  `docs/guides/vps-first-run.md`

## 맥락

ADR 0034 는 이름을 두 단계로 걸기로 했다: 버릴 VPS 에 임시 이름
(`test.bmlwork.kr`)을 걸어 관문 10개를 통과시키고, 그다음 **실제 이름**
(`bml.bmlwork.kr`)을 실제 인스턴스에 건 뒤 버릴 쪽을 지운다.

임시 이름의 목적은 하나였다 — **처음 겪는 문제를 실제 이름에 걸지 않는 것.**
Let's Encrypt 는 실패한 검증도 이름 단위로 세고, 남에게 뿌린 주소가 죽으면
그 주소를 다시 걷는 일이 생긴다.

그 목적은 이미 달성됐다. 오늘 첫 실행에서 버그 넷이 나왔고
(`grep -q` × `pipefail`, 중복 default_server, 자기 파일에 걸리는 덮어쓰기
관문, 셸 없는 계정을 실패로 읽는 두드림) 전부 이 이름 위에서 깨고 고쳤다.
그리고 그 기계는 지금 관문 8개를 통과한 채 **살아서 돌고 있다.**

## 결정

**이름을 옮기지 않는다.** `test.bmlwork.kr` 이 이 워크벤치의 바깥 주소다.

따라서 **`bml-relay-test` 인스턴스는 버릴 기계가 아니다. 지우지 않는다.**
ADR 0034 와 두 안내서가 "그다음에 지운다" 고 적어 둔 그 기계가 이것이다.

## 왜

옮겨서 얻는 것이 이름 한 글자뿐이다. 옮기면서 잃을 수 있는 것은 지금 초록인
상태다 — 인증서를 새 이름으로 다시 받고, nginx 사이트를 하나 더 세우고,
`bml share domain` 을 바꾸고, DNS 를 하나 더 만진다. 네 번 다 오늘 처음
해 본 일이고, 오늘 그 네 자리에서 다 걸렸다.

`test` 라는 낱말이 주소에 남는 것은 미관 문제지 기능 문제가 아니다. 사람에게
주는 것은 어차피 링크 한 줄이다.

## 대가

- **주소에 `test` 가 남는다.** 밖에 공유할 때 임시처럼 보인다.
- **되돌리기는 언제든 3줄이다.** Cloudflare 에 A 레코드 하나,
  `sudo bash vps-setup.sh bml.bmlwork.kr <메일>`,
  `bml share domain bml.bmlwork.kr`. 두 이름이 같은 기계를 가리켜도 되고,
  옮기는 동안 옛 주소가 계속 살아 있다 — 그래서 급할 것이 없다.
- **`bml.bmlwork.kr` 에 남아 있는 Cloudflare Tunnel 레코드는 지운다.**
  ADR 0031 에서 접은 `cloudflared` 의 흔적이고, 살아 있는 이름처럼 보이면
  다음 사람이 그리로 붙어 보고 안 된다고 할 자리다.
- **공인 IP 가 `Ephemeral` 이다.** 재부팅은 견딘다(실측). 인스턴스를
  삭제하면 사라진다. 이제 이 기계가 상시 대문이므로 Reserved IP 로 바꾸는
  것을 고려한다 — 지금 당장은 아니다.
- **Oracle 의 idle 회수 정책은 그대로 걸린다** (ADR 0034 의 대가 항목).
  임시 기계였을 때는 없어져도 그만이었지만, 이제는 없어지면 밖에서 아무도
  못 본다. 밖에서 살아 있는지 가끔 보는 일이 더 중요해졌다.

## 결과

`https://test.bmlwork.kr` 이 바깥에서 워크벤치를 여는 주소다. 밖에 있는
기계는 `bml pull && bmlout https://test.bmlwork.kr` 을 **한 번** 치면 되고,
재부팅해도 랩 PC 를 재시작해도 그대로다. `bmlonly` 도 IP 전달도 중계기도
필요 없다.

**랩 안 기계는 `bmlin` 그대로다.** 랩 망은 이 이름의 TLS 를 끊는다 —
랩 PC 에서는 손잡기가 안 끝났고(`443 에 TCP 는 붙는데 그 뒤가 안 끝납니다`),
`DESKTOP-L60RV2M` 에서는 즉시 끊겼다(`curl: (35) Recv failure: Connection
reset by peer`, 0.05초). SNI 를 보고 끊는 장비로 보인다. 이름을 바꿔도
달라질 이유가 없고, 애초에 랩 안에서는 랜으로 직접 가는 편이 빠르다.
