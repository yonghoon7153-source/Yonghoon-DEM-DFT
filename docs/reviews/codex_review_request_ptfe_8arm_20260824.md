# Codex 리뷰 요청 — PTFE 스탬프 팔을 8팔로 올릴 것인가 (2026-08-24)

**리뷰어에게**: 이 문서는 **런 전** 설계 리뷰 요청이다.  아직 아무것도 안 돌렸다.
정본 원장은 `docs/reviews/claims.json` (CL-49 · CL-46 · CL-38 · CL-44 · CL-41),
규율은 `CLAUDE.md` 최상단 SR-01 절과 `docs/reviews/sdcp_next_prereg_v3_20260818.md`.
**결과를 보고 창을 옮기는 것**이 이 리포의 1급 금지사항이므로, 그 관점에서 특히 §3 을 봐 달라.

## 1. 배경 — 무엇을 재고 있나

**비교 대상** (총 첨가제 4 wt% 고정, PTFE 0.5 를 SDCP 0.5 로 **치환**):

| | VGCF | PTFE | SDCP |
|---|---|---|---|
| SBE | 3 wt% | **1.0** | — |
| DBE | 3 wt% | **0.5** | 0.5 |

**생산 규약에서 PTFE 는 전자 격자에 찍히지 않는다** — `mpm_webapp_payload.py` 의
`_cond_ph = (2,3,5,6,4) if a.sigma_ptfe > 0 else (2,3,5,6)` 이고 기본 `sigma_ptfe = 0`.
게다가 PTFE 는 상 루프에서 VGCF·SDCP **뒤**라 안 찍으면 그 셀이 **탄소로 남는다**
(같은 셀 VGCF+PTFE → sid 7, 실행 확인).  ⇒ 생산 모델에서 PTFE 가 탄소망을 끊는 효과는 **정확히 0**.

**CL-49 진단 팔** (2026-08-19, `SIGMA_PTFE=1e-16`, **arm 0 한 팔**, vox 0.15, 구 스탬프 Ø0.30,
브리지 0.48, LEAN=2):

```
                   PTFE 미표현(생산)   PTFE 스탬프(진단)
  σ_e(SBE)            73.0 mS/cm    →     54.63 mS/cm    (−25.2 %)
  σ_e(DBE)            82.2          →     71.5           (−13.0 %)
  비 (DBE/SBE)         1.126267            1.309170
```

판정 = `BOTH_REJECTED` (등록 측정량은 σ_e(SBE) 절대값; h0 = 73 무영향 · h1 = 30 문헌급 붕괴,
분해능 5 → 둘 다 기각).  **비의 크기는 등록하지 않았다** (방향만 등록했고 적중).

한 단어다.  `ARMS=1` → `ARMS=8` (기본값이므로 생략).  나머지 환경변수 동일:

```bash
VOX=0.15 SDCP_SPHERE_D=0.30 BRIDGE_UM=0.48 LEAN=2 SIGMA_PTFE=1e-16 \
```

`OUTDIR` 이 `prereg_v2_vox015_sph_b048_ptfe1e-16_lean2` 로 동일하게 만들어지므로
(`sdcp_gain_vox015_8arm.sh:100` 의 태그 합성) **끝난 arm 0 은 SKIP** 되고
7팔 × 2전극 = **14 솔브**만 추가된다.

## 3. ⚠ 규율 질문 (이 리뷰의 핵심) — 이게 사후 창 이동인가

**우리는 이미 arm 0 의 답(1.3092)을 봤다.**  그 상태에서 8팔을 돌리는 것이
사전등록 규율 위반인지 판단해 달라.  우리 잠정 입장은:

- 이것은 **새 가설검정이 아니라 정밀도 측정**이다.  이미 측정된 양에 **표준오차를 붙이는** 것뿐이다.
- 따라서 등록할 것은 문턱이 아니라 **측정 계약**이다: ①팔 수 8 ②고정 인자 목록
  ③보고할 통계(쌍대응/비대응 둘 다) ④arm 0 을 **버리지 않고 포함**한다는 것.
- `sdcp_gain_verdict.py` 의 `h0/h1` 출력은 **값 측정**이지 검정이 아니다 (prereg §7, CL-41 선례).

**질문 3-1.** 위 입장이 맞나?  아니면 arm 0 을 본 이상 8팔 결과를 "측정" 으로도 못 쓰나?
**질문 3-2.** arm 0 을 앙상블에 포함하는 것이 편향인가 (그것만 사전에 봤으므로)?
  버리면 7팔이 되어 생산 팔(8팔)과 팔 수가 달라진다 — 어느 쪽이 덜 나쁜가?
**질문 3-3.** 등록해야 할 **진짜 미지의 예측**이 하나 있다고 본다 — §5 의 팔-폭.  그것을
  런 전에 등록하면 이 런이 검정 자격을 얻나?

## 4. 이 런이 사는 이유 — 이득의 2조각 분해

두 규약의 비를 나누면 분해가 나온다:

```
  1.309170 / 1.126267 = 1.16240
```

| 조각 | 배수 | 로그 지분 |
|---|---|---|
| SDCP 새 도체 부피 | ×1.126267 | 44.2 % |
| PTFE 절반 제거 | ×1.16240 | **55.8 %** |
| 합 | ×1.309170 | 100 % |

이것이 원고의 서사를 바꾼다 — 주장이 *"SDCP 가 전도가 좋다"* 가 아니라
*"SDCP 는 절연 바인더를 절반으로 줄이면서 전극을 유지시킨다"* 가 된다.
리포의 실험 앵커가 그것을 직접 뒷받침한다:
- **S12**: SDCP 단독 = dough 형성 불가 ⇒ PTFE 웹이 필수 ⇒ **절반 치환은 강제이지 임의가 아니다**
- **Fig 2f** (LPSCl+X 펠릿 σ_ion): SDCP **×0.80** vs PTFE **×0.27**
  ⇒ 부피 희석(Bruggeman (1−φ)^1.5) 대비 SDCP 1.02 (불활성) · PTFE **0.31** (희석의 3.2배로 막음)
- **Fig 3a**: DBE 에서 PTFE 분산 균일화

**질문 4-1.** 이 로그-지분 분해가 타당한가?  두 규약의 차이를 "PTFE 제거 몫" 으로 읽는 것이
  정당한가 — 아니면 두 팔 사이에 PTFE 말고 다른 것도 바뀌나 (스탬프 순서·덮어쓰기 상호작용)?
**질문 4-2.** 지금 이 분해는 **양쪽 다 n=1 은 아니다** — 생산 팔은 8팔(SE 0.098 %p)이고
  PTFE 팔만 1팔이다.  분해의 오차 전파를 어떻게 보고해야 하나?

## 5. ⚠ 기술 위험 — σ 대비 1e18 에서 origin 앙상블이 살아 있나

이게 우리가 제일 걱정하는 것이고, **런 전에 등록할 만한 진짜 예측**이다.

생산 팔에서 8팔이 잘 듣는 이유는 상들의 σ 가 **비슷한 자릿수**라 격자 위치가 바뀌어도
망이 크게 안 변하기 때문이다 (실측 팔-폭 0.68 %, 비의 SE 0.098 %p).

**PTFE 를 1e-16 으로 찍으면 대비가 1e18 이 된다.**  PTFE 한 셀이 VGCF 섬유를 **완전히 절단**할
수 있고, 절단되느냐 마느냐가 **격자 원점에 달린다**.  ⇒ 팔-폭이 생산 팔보다 훨씬 클 수 있다.

관련 선례가 리포에 있다 — **prereg v3 STEP 3** 은 `σ_VGCF = 0` 으로 두자
σ 대비 25,000배에서 **CG 가 안 붙었다** (cg_info=30000, resid 2.2e-08, Joule 집중 1,912 → 39,281×).
그래서 그 STEP 은 지금도 HOLD 다.  PTFE 1e-16 은 대비가 그보다 **13 자릿수 더 크다**.
arm 0 은 수렴했지만, 다른 7팔이 수렴한다는 보장이 없다.

**질문 5-1.** `1e-16` 이 옳은 표현인가?  이것은 셀을 **제거**하는 게 아니라 **극저-σ dof** 로
  남긴다.  차라리 PTFE 셀을 **격자에서 빼는**(dof 자체를 없애는) 것이 수치적으로 더 건전하고
  물리적으로도 더 맞지 않나?  현재 솔버가 그걸 지원하나?
**질문 5-2.** 팔-폭에 대해 런 전에 무엇을 등록해야 하나?  우리 잠정 예측:
  *"팔-폭이 생산 팔의 0.68 % 보다 크다"* — 이건 너무 약한(거의 확실한) 예측이라 정보가 없다.
  더 나은 등록 문장을 제안해 달라.
**질문 5-3.** 8팔 중 일부만 수렴하면 어떻게 하나?  현재 러너는 **fail-fast** (한 팔 실패 =
  전체 중단, `sdcp_gain_vox015_8arm.sh:277`).  그게 맞나, 아니면 수렴한 팔만 보고하고
  실패 팔을 명시해야 하나 (후자는 앙상블 오염이라 우리는 fail-fast 를 지지한다)?

## 6. 이 런이 **사지 못하는** 것 (우리 이해가 맞는지 확인해 달라)

- **⛔ PTFE 표면 코팅**.  문헌(Lee 2025, 같은 재료계)은 PTFE 0.5 → 5 wt% 에서 σ_e 가
  **3,000배** 무너진다고 보고하는데 우리 부피 스탬프는 **−25 %** 다.  그 차이는 나노미터급
  피브릴 막이고 **vox 0.15 µm 로는 원리적으로 못 그린다**.  ⇒ 8팔을 돌려도 이 갭은 그대로다.
- **⛔ 상한**.  위 때문에 **두 규약 다 PTFE 를 과소평가**한다.  ⇒ +30.9 % 는 상한이 아니다.
  우리가 말할 수 있는 것은 여전히 **"+12.3 % 는 하한"** 하나뿐이다.
- **⛔ 격자 크기**.  CL-41 의 미수렴(1.123 / 1.144 / 1.155, 증분비 1.773 < 이론 최소 2.187)은
  이 런과 무관하다.
- **⛔ 생산 규약 승격**.  이 팔은 진단 팔이고 매니페스트 `sigma_ptfe_S_cm` + 판정기 고정-인자
  게이트 ⑭ 가 생산 팔과의 혼합을 HOLD 로 잡는다.

**질문 6-1.** 위 네 개 외에 우리가 놓친 "이 런이 못 사는 것" 이 있나?
**질문 6-2.** 특히 — 8팔 결과가 나온 뒤 우리가 **저지르기 쉬운 과대주장**이 무엇일지
  미리 짚어 달라 (이 리포는 CL-24 에서 헤드라인 3개를 철회한 이력이 있다).

## 10-2. PTFE — 이건 규약 선택이 아니라 **틀린 물리**로 보인다

`mpm_webapp_payload.py:_cond_ph` 가 `sigma_ptfe > 0` 일 때만 phase 4 를 찍는다.
그리고 PTFE 는 상 루프에서 VGCF·SDCP **뒤**라 그 셀을 **덮는다**.

⇒ **PTFE 를 안 찍으면 그 셀이 "없어지는" 게 아니라 "탄소로 남는다".**
즉 현재 생산 규약은 절연 바인더를 **도체로 바꿔치기**하고 있다.  메모리와 무관하다.

**질문 10-2-a.** PTFE 스탬프를 **생산 규약으로 승격**해야 하나?  그러면 CL-49 의 "진단 팔" 지위와
  판정기 고정-인자 게이트 ⑭ 를 어떻게 재정의하나?
**질문 10-2-b.** ⚠ 승격하면 **소급 문제**가 생긴다 — 지금까지의 모든 σ_e 값(CL-33/34/41 의 격자
  스윕 세 점 포함)이 옛 규약이다.  격자 미수렴 판정(1.123/1.144/1.155)을 새 규약에서 다시
