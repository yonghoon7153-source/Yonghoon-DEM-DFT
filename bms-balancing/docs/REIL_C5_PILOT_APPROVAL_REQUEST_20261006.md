## §0 무엇이고 왜 지금인가

- **C5** = 부속 A §3-9 의 "한 셀 · 한 단위의 비용 측정" — **맞춤이다** (P0 와 다르다). 목적은 확인적 실행 (C4) 의 벽시계 예산표와 병렬 수를 정하는 것 하나뿐이다.
  이 측정의 결과는 **확인적 분석에 쓰지 않는다** (Ĵ · H1–H4 · 상태표에 들어가지 않는다 · 확인적 실행은 그 단위를 처음부터 다시 돈다).
- 선행: C3 (P0 출력 고정) 한정 수용 · 실행 기록 완결은 미완으로 신고 (상태 §22 · 회신 `prereview_reil_v2_p0_result_20261006` · `C3_OUTPUTS_ACCEPTED_WITH_EXECUTION_RECORD_GAPS`).
  회신의 다음 단계가 이 요청문이다 — 그 회신이 열거한 항목 (셀 고정 · A0 · J_V · Phase A 128 · 옵션 · 내부 평가와 독립 재평가 상한 · 실행본 / 환경 / Sobol 봉인 · 시간 /

- 대응표 13 / 13 `판정 불가` (P0 · 부속 D §3-4) 는 이 요청 옆의 **제한**이다 — 선택 경로를 바꾸지 않고, 논문의 다섯 번째 cycle · 방향이 확인됐다고 쓰지 않는다.

## §2 평가 함수 · 예외 · 증인 (결과 전에 고정)

| 항목 | 규칙 |
|---|---|
| 평가 함수 | `J_V(x) = sqrt(util.objective_fun(x, M, halfcell)[1])` — `M` 은 셀 #1 의 `extract_battery_data` 결과. `objective_fun` 은 `M` 에 키를 써 넣는다 (`Vf_sim` · `Q_sim` 등 — f2 의 입력 `Q_exp_interp` · `V_exp_interp` 는 바꾸지 않음) → 실행마다 **새 깊은 사본**을 쓴다 |
| 예외 | 평가 중 예외 (예: 205 행 `np.max` 의 빈 배열 — x 에 따라 날 수 있음) 는 **잡지 않고 그 지역 실행을 끝낸다** → `termination = solver_error` · `witness = invalid:SOLVER_ERROR` · 예외 형 · 메시지 · 그때까지의 평가 수 기록. 벌점 값으로 바꾸지 않는다 |
| 비유한 | f2 가 nan / inf 면 그 값을 그대로 solver 에 넘긴다 (바꾸지 않음) · 기록에 비유한 평가 수를 센다 |
| 독립 재평가 | 반환점 x (float 그대로 · clip · 투영 없음) 마다 같은 평가 함수 · 새 사본으로 **1 회** — solver 의 `fun` 을 쓰지 않는다 (A §2-1) |
| 증인 | A §2-1 · §2-2 · §2-3 · B §1-2 그대로: 재평가 유한 · 상자 · G 잔차를 정확 유리수로 계산해 모두 ≤ `1e-10` → `valid` · 그 밖 `invalid:<NONFINITE · INFEASIBLE_RETURN · SOLVER_ERROR>` · `termination` (`converged` · `budget` · `solver_error` + 원 status · message) 은 따로 · `feasibility_class` (영역 A0 에 대해 `exact_feasible` · `numerically_accepted`) |
| 외삽 라벨 | `n_out_PE` · `n_out_NE` (재평가 때 — 실험 Q 점 중 그들 슬라이스 `Q_*_hc_ad[Q0*_ID:Qmax*_ID]` 의 범위 밖 수) — 라벨이지 유효성 조건이 아니다 (A §2-1 3) |
| **구조 오류** (증인 무효와 다름) | 스크립트 · 환경 · 입출력 · 작업자 프로세스 비정상 종료 · 기록 쓰기 실패 · 봉인 대조 실패 — 이것은 지역 실행의 결과가 아니다 → **파일럿 전체를 그 자리에서 멈춘다** (§6) · 남은 실행은 `미실행` 으로 기록 · 재시도 없음 |
