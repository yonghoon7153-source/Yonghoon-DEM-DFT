## 0. 이 digest 를 읽는 법 — ⛔ **먼저 판정: 이건 우리 축이 아니다**

**결론을 앞에 둔다. 이 논문의 주제(엑사스케일 O(N) KS-DFT)는 우리가 쓸 수 있는 기술이 아니다.**

- 필요 자원: **20,480 노드** (노드당 ARMv9 LX2 프로세서 2개 = **608 코어** + HBM 64 GB + DDR 512 GB).
  우리는 **RTX3090 1대(kgy) + A6000 1대(gabia)** 가 전부고 KISTI 접근은 끝났다.
- 그들의 O(N) 처리량은 **노드당 5,120 원자 / SCF 71 초**다 (`Fig. 5` 캡션). 코어수만으로 gabia(20 코어)에
  환산하면 **≈170 원자** — **우리가 이미 돌리는 120–160 원자 셀과 같은 자리**다 (우리 검산, §8-③).
  ⇒ **O(N) 알고리즘 자체가 우리에게 주는 것은 없다. 100M 은 알고리즘이 아니라 20,480 노드가 만든 숫자다.**
- XLSDFT 는 공개 코드지만 **ARM SVE/SME 인트린식 + 자체 BLAS/LAPACK** 로 짜여 있다
  (§V-B). x86 + NVIDIA 인 우리 두 기계에서는 성능 경로가 통째로 없다.

**그래서 이 digest 의 목적은 "이식"이 아니라 세 가지다.**
1. 1저자가 명시적으로 물은 **네 질문에 근거로 답하는 것** (→ **§9**, 이 digest 의 중심).
2. **MLIP(구조) → DFT(전자구조)** 라는 우리 작업 분업이 *엑사스케일에서도 같은 형태로 채택됐다*는 외부 선례 (→ §8-①).
3. **계산–실험 대조 프로토콜의 반면교사** — 이 편의 "quantitative agreement" 주장이 실제로는
   추세 일치뿐이고, **보고량(estimand) 정의가 비어 있다** (→ §12-C). 우리 repo 의
   *"던지기 전에 보고량 정의"* 규율(CLAUDE.md)에 딱 걸리는 실물 사례다.

⛔ **이 논문에서 우리 물성 4축(A 이온전도 / B 산화 / C 기계 / D 전자구조)으로 넘어오는 수치는 0 건이다.**
σ·Ea·ESW·탄성상수·밴드갭 **하나도 없다.** `comparison_vs_ours.md` 물성표에 행을 만들지 않는다
(§J-7 🔧 방법 원전 블록에만 둔다).

## 1. 한 줄 요약

밀도행렬의 **근시안성(nearsightedness)** 을 써서 계를 **코어+버퍼 부분영역**으로 쪼개고(divide-and-conquer) 각 부분영역을 **CheFSI** 로 푸는 O(N) 실공간 유한차분 KS-DFT 코드(**XLSDFT**)를 엑사스케일기(LineShine, 20,480 노드)에 올려 **Si 결정 1억/2억 원자**(약 주기 SCF 71.2 s / 143.7 s, FP64 지속 **157.9 Pflop/s**, weak-scaling 효율 **96.6 %**)와 **Li|LGPS|Li 계면 1,132만 원자**(57×44×90 nm, SCF 167회, 총 6,936 s)를 돌리고, 계면 근처에서 **저원자가 Ge·P 가 농축되고 벌크로 갈수록 사라지는** 전자구조 재편을 계산해 **XPS 깊이프로파일의 같은 추세**와 맞췄다.

⚠ 단 **정확도 검증 수치는 이 논문에 단 하나도 없다** — O(N) 근사가 총에너지·힘·DOS 를 얼마나 희생하는지,
버퍼 반경이 수렴했는지, 3차 스케일링 코드와 비교하면 얼마나 다른지에 대한 **표·그림·숫자가 전무하다**(§12-A).

- **Strong scaling**: 5,242,880 원자 고정, 1,024 → 20,480 노드. 68.8 → 33.6 → 17.6 → 7.5 → **4.2 s**,
  효율 100.0 → **102.3** → 98.0 → 91.3 → **81.3 %**.
- FD 스텐실 커널: 평범한 SVE 구현 **1.66 Tflop/s/node → 최적화 후 5.25** (3.2×).
  100M 런에서 Laplacian·V_nl 커널 집계 HBM 대역 **143 PB/s (피크의 89 %)** / **107 PB/s**.
- 화학퍼텐셜 μ 단계: 전역 reduction **~25회 → 4–5회**, wall time **5–6 s → 80 ms**.
- Poisson 풀이: 2억 원자까지 **SCF 당 3 s 미만**.

## 4. DFT / 계산 방법 ★

- **code / version**: **XLSDFT** (신규 C++ 구현, MPI + OpenMP + ARM SVE/SME 인트린식). 공개: `github.com/NSCCSZ-HPC/XLSDFT`.
  컴파일 `clang 17.0.6 -O3 -march=armv9-a+sve+sme` (벤더 최적화판).
  ⚠ 계보상 **SPARC 계열**이다 — 실공간 FD 정식화[29,30], 국소 정전기 재정식화[31], Periodic Pulay[40],
  타원형 전처리[41,42] 가 전부 Suryanarayana 그룹 라인이고 교신저자 Qimen Xu 가 SPARC 논문[19] 공저자다.
- **이산화**: 실공간 **유한차분(FD)**, **12차 스텐실** (n₀ = 6, 격자점당 3 × 2n₀ = 36 이웃).
  **평면파도 기저함수도 아니다** — 우리 QE(평면파)와 수렴 손잡이가 다르다.
- **격자 간격 h**: Si **≈0.5 Bohr** · Li/LGPS **≈0.4 Bohr**. (평면파 ecut 과 직접 환산 불가 — §13 용어집)
- **functional**: ⚠ **"GGA" 라고만 적혀 있다.** PBE/PBEsol/revPBE 중 무엇인지 **전문에 없다**
  (`PBE` 검색 0건). ref [47] 은 **Hamann ONCV 유사퍼텐셜** 논문이지 XC 범함수 논문이 아니다.
- **vdW**: 없음 (언급 0).
- **pseudo / PAW**: **norm-conserving (ONCV, Hamann 2013)**. PAW 아님. 원자별 원자가 설정·반경 미기재.
- **k-points**: **Γ 점만** — Eq. (1) 에 *"(neglecting spin and restricting to Γ-point sampling)"* 로 명시.
- **스핀**: **무시(non-spin-polarized)** — 같은 문장. Li 금속 환원계면에서 Ge⁰/Li–Ge 합금·라디칼 종이
  생기는 계인데 스핀 자유도를 통째로 끈 것이고, 이에 대한 논의가 **없다** (§12-A).
- **전자 스미어링 σ = k_BT**: 정의만 있고 **값이 없다.** Fermi–Dirac 점유를 쓴다는 것만 안다.
  ⚠ 금속계에서 근시안성 감쇠길이 ξ 는 σ 에 민감하므로, **σ 를 모르면 버퍼가 충분한지 판정할 수 없다**.
- **supercell / nat**: Si 5,242,880 / 104,857,600 / 209,715,200 · Li/LGPS **11,325,600** (57 × 44 × 90 nm).
  **부분영역 개수 K, 코어 크기, 부분영역당 원자수는 전부 미기재.**
- **DFT+U**: 없음.
- **D&C 버퍼 반경 R_buffer**: Si **≈9.2 Bohr** (≈4.87 Å) · Li/LGPS **8.0 Bohr** (≈4.23 Å).
  🔴 **수렴 시험 없음.** 그리고 **금속 포함계에 더 *작은* 버퍼를 썼다** — 근시안성 이론이 요구하는 방향과 반대다(§12-A).
- **CheFSI**: 체비셰프 차수 **m = 24** (두 계 공통). 부분영역 크기 **N_d^α ≈ 200,000 격자점 · N_s^α ≈ 640 시험궤도**.
- **SCF 수렴 판정**: 상대 전자밀도 잔차 **5 × 10⁻⁴** (두 계 공통). ⚠ 생산 계산 기준으로 느슨한 편이고,
  이 문턱이 보고된 관측량에 무엇을 보장하는지에 대한 근거가 없다.
- **혼합·전처리**: **Periodic Pulay**[40] + **물질-마스크 실공간 타원형 전처리**[41,42]
  `(−∇² + κ²(x)) R̃ₖ = −∇² Rₖ`. 균질 Si 는 κ² 상수, Li/LGPS 는 **κ²(x) = s(x)·k²_TF,Li** —
  매끄러운 마스크 s 가 **Li 영역에서 금속 스크리닝을 켜고 절연 LGPS 에서 끈다**.
  ⭐ 이게 이 논문에서 **우리에게 제일 이식성이 있는 한 줄**이다 (§8-②, CLAUDE.md 의 *"local-TF/저β 믹싱"* 과 같은 계열).
- **초기밀도**: 통상 SAD(superposition of atomic densities) + *"material-specific correction"*
  (⚠ 내용 미기재 — 무엇을 어떻게 보정했는지 한 줄도 없다).
- **Poisson**: FD Laplacian(12차) + **CG + 구조화 AMG 전처리**(StructMG[43–46]).
  외부 CG 는 **FP64**, AMG V-cycle 은 **FP32**, 최미세 레벨만 **7점(3D7) 부정확 연산자를 matrix-free** 로.
  halo 교환을 x→y→z 3단계로 나눠 **26 이웃 대신 6 면이웃**과만 통신.
- **정밀도**: 전 구간 **FP64**, 예외 2개 — AMG 전처리 **FP32**, SCF 간 궤도 초기추측 저장 **FP16**(warm start).
- **MLIP**: **DeePMD-kit**[6]. 학습 데이터 = **~100–500 원자 대표 계면 셀의 AIMD 궤적**.
  ⚠ AIMD 코드·범함수·프레임수·힘 RMSE·검증 **전부 미기재**. MD 앙상블·열욕·시간간격·길이도 없다
  — *"300 K 에서 열적으로 평형화"* 한 줄이 전부다.
- **무질서 처리**: **해당 없음/미기재.** LGPS 의 Li 부분점유·음이온 배열을 어떻게 정했는지 서술이 없다.
  (우리 관심축인 SQS/enumerate/단일배열 판정을 이 논문에서 가져올 수 없다.)
- **XLSDFT 로 한 일**: **단일점 SCF 1회.** 구조최적화 0 · MD 0 · NEB 0. 힘은 Hellmann–Feynman 으로
  계산할 수 있다고 적었지만 **보고된 힘 값이 없다.**
- **실험**: **PHI VersaProbe 4** XPS + **Ar⁺ 스퍼터링** 깊이프로파일. 반응 후 LGPS 펠렛을 Li 금속에서
  분리해 **반응면에서 in situ** 측정. 스퍼터 **0 / 20 / 50 분** = 계면 / 서브계면 / 벌크유사 LGPS.
  ⚠ 스퍼터 시간 → 깊이(nm) 환산이 **없다.** 그래서 계산의 x(nm) 축과 정량 대응이 불가능하다.

## 5. 결과 — 절별 상세 (그림 실독 포함)

### 5.1 왜 O(N) 이 되는가 — 밀도행렬 + 근시안성

출발점은 궤도가 아니라 **1입자 밀도행렬**이다.

`D = g(H; μ, σ) = [1 + exp((H − μI)/σ)]⁻¹` (Eq. 2) — Fermi–Dirac 함수를 해밀토니안에 씌운 것.
바닥상태 관측량이 전부 D 에서 나온다. 특히 전자밀도는 대각성분 `ρ(x) = 2D(x,x)`.

핵심은 **근시안성 원리**[Prodan–Kohn 2005]다:
`|D(x, x′)| ≲ exp(−|x − x′| / ξ)` — **개별 KS 궤도 ψₙ 은 완전히 비국소적이어도 밀도행렬은 실공간에서
지수적으로 죽는다.** 그래서 x 근처의 관측량을 구하는 데 계 전체가 필요 없다.

🔑 **1저자 질문 ① 에 대한 원문 근거**: 저자는 *"**for insulating as well as metallic systems at finite
temperature** [32],[33], the density matrix decays exponentially"* 라고 쓴다.
⇒ **밴드갭은 필요조건이 아니다.** 유한온도(σ = k_BT > 0)면 금속도 지수감쇠한다.
**다만 ξ 가 갭이 클수록 짧고, 금속은 σ 가 작을수록 길어진다** — 이게 §9-① 의 전부다.

### 5.2 Divide-and-conquer 분할 (`Fig. 3` — 실독)

전역 셀 Ω 를 **겹치지 않는 코어 {Ω^α_C}** 로 타일링하고, 각 코어를 두께 **R_buffer** 만큼 키워
부분영역 `Ω^α = Ω^α_C ∪ Ω^α_buffer` 를 만든다 (Eq. 5).
전역 유효퍼텐셜 V_eff 를 Ω^α 로 제한해 **국소 해밀토니안 H^α** 를 정의하고, 그 고유쌍만으로
부분계 밀도행렬 D^α (Eq. 6)를 만든다. 전역 D 는 **이진 분할단위(binary partition of unity)** 로 조립한다:
`D(x,x′) ≈ Σ_α p^α(x) D^α(x,x′)` (Eq. 7) — p^α 는 코어 안에서 1, 밖에서 0.
버퍼는 `D^α ≈ D`(코어 위에서)를 보장하고, 오차는 R_buffer 에 대해 지수적으로 준다[34,35].

**`Fig. 3` 을 실제로 보고 얻은 것** (캡션만으로는 안 나오는 것):
- 그림의 옅은 파랑 격자 하나하나가 **코어**이고, 그 중 한 칸(진한 초록)만 실제로 "보관"된다.
- 노란 점선 상자(= 실제로 푸는 부분영역)는 **코어보다 훨씬 크다**. 픽셀로 재면
  `figure-read ≈` **R_buffer ≈ 1.3 × 코어 한 변**, 즉 부분영역 한 변 ≈ **3.4 × 코어 한 변**
  → **푸는 부피 / 보관하는 부피 ≈ 40×**.
- ⇒ **O(N) 은 "공짜"가 아니라 "큰 상수를 내고 산 지수"다.** 같은 결론이 논문의 숫자에서도 나온다:
  N_d^α ≈ 200,000 격자점과 h 로 부분영역 한 변을 역산하면 Si **29.2 Bohr** · LGPS **23.4 Bohr**,
  여기서 R_buffer 를 빼면 **코어 부피가 부분영역의 5.1 % (Si) / 3.2 % (LGPS)** 다 (우리 검산,
  부분영역을 정육면체로 가정. 논문은 코어 크기를 안 적는다).

### 5.3 부분계 풀이 — CheFSI 4단계 (`Fig. 2` — 실독)

각 Ω^α 에서 **Chebyshev-filtered subspace iteration**[36,37] 을 돈다. H^α 를 명시적으로 완전대각화하지 않는다.

1. **체비셰프 필터링** `Ψ^α_f = p^α_m(H^α) Ψ^α` — 3항 점화식이라 **희소 H·벡터 곱 m 회**면 된다.
   `C_m` 이 [−1,1] 밖에서 폭증하는 성질로 컷오프 λ_c 위 성분을 죽이고 점유 부분공간을 증폭. **비용 O(m N_d^α N_s^α)**
2. **Projection** `H_s^α = (Ψ_f^α)ᵀH^αΨ_f^α`, `M_s^α = (Ψ_f^α)ᵀΨ_f^α` → **O(N_d^α (N_s^α)²)**
3. **부분공간 고유문제** `H_s^α Y^α = M_s^α Y^α Λ^α` (조밀 일반화 고유해) → **O((N_s^α)³)**, N_s ≪ N_d 라 싸다
4. **부분공간 회전** `Ψ^α = Ψ_f^α Y^α` → **O(N_d^α (N_s^α)²)**

부분영역 크기가 N 과 무관하게 고정이므로 **부분영역당 O(1) → 전체 O(N) 계산·O(N) 메모리**.
이 국면에는 **MPI 통신이 전혀 없다** (§V-A5).

**`Fig. 2` 실독 소득**: 흐름도 오른쪽 열에 각 단계 복잡도가 붙어 있고 — Initial guess → Construct V_eff[ρ] →
Restrict V_eff → (CheFSI 4단계 루프) → Compute μ → Update ρ → Mixing & preconditioning → Converged? →
**Energy, DOS/PDOS, forces** — **모든 행이 O(N) 또는 그 이하**로 라벨돼 있다. 즉 O(N³) 단계가 하나도 남지 않았다는
주장을 흐름도 자체가 시각적으로 하는 그림이다.

### 5.4 전역 관측량 조립 — DOS/PDOS 가 왜 여전히 O(N) 인가

모든 부분계 분해 관측량이 **내부영역 가중치** `c^α_n = ∫_{Ω^α_C} |ψ^α_n(x)|² dx` 하나로 묶인다.

- 전자밀도 `ρ(x) = Σ_α p^α(x) ρ̃^α(x)` (Eq. 10), μ 는 전하중성 `∫ρ = N_e` 로 결정
- 밴드에너지 `E_band = 2 Σ_α Σ_n g(λ^α_n) c^α_n λ^α_n` (Eq. 11) · 엔트로피항 (Eq. 12)
- **DOS** `D(E) = 2 Σ_α Σ_n c^α_n δ(E − λ^α_n)` (Eq. 13) — **부분계 고유값을 내부가중치로 가중해 모은 것**
- **PDOS**: 국소 KS 궤도를 원자중심 궤도 `ϕ_{I,lm}` 에 투영, `P^α_{n,I,lm} = (∫ϕ*_{I,lm}ψ^α_n dx)²` (Eq. 14)
  → 궤도분해 `D_{I,lm}(E)` (Eq. 15) → 원자분해 `D_I(E)` (Eq. 16) → 원소분해
- 힘은 Hellmann–Feynman[30]

⇒ CheFSI 가 이미 국소 고유쌍을 주므로 DOS 는 가중치만 재활용, PDOS 는 고정 개수의 원자중심 궤도 투영만
추가 → **둘 다 O(N) 유지**. **이게 이 논문이 MLFF 대비 주장하는 유일한 차별점**이다.

🔴 **여기가 우리 관점에서 제일 중요한 구조적 사실이다.** 이 DOS 는 전역 H 의 고유값 스펙트럼이 아니라
**부분영역 H^α 들의 고유값 모음**이다. 밴드분산·k-분해량은 원리적으로 없고(Γ 점만), ICOHP/COHP 처럼
**궤도쌍 사이 비대각 해밀토니안 원소**를 요구하는 지표는 이 정식화에 **자리가 없다** (§9-②).

### 5.5 SCF 절차와 두 개의 병목 처리

- **화학퍼텐셜 μ**: `N_e(μ) = 2 Σ_α Σ_n g(λ^α_n; μ,σ) c^α_n = N_e` 를 풀어야 하는데,
  Brent 법으로 풀면 함수 평가마다 분산 스펙트럼에 대한 `MPI_Allreduce` 가 필요해 극한규모에서 치명적.
  ⇒ **2단 통신효율 해법**: ① 전역 DOS 히스토그램을 **Allreduce 1회**로 만들어 근사 μ 확보
  ② **Newton 3–4회** 정제 (각 회당 N_e(μ) 와 도함수용 collective 1회).
  + 내부가중치 c^α_n 계산을 DDR → **HBM 으로 이동**.
  ⇒ 전역 reduction **~25 → 4–5회**, wall time **5–6 s → 80 ms**. **weak scaling 96.6 % 의 직접 원인**이라고 본문이 지목.
- **SCF 수렴 (이종 금속–절연체계)**: 위 §4 의 물질-마스크 타원형 전처리 + Periodic Pulay + 개선 SAD.
  본문은 *"이 물질인지(material-aware) 처리가 11M 계면의 견고한 SCF 수렴을 가능하게 했다"* 고 명시.

### 5.6 HPC 구현 (요지만 — 우리 기계에 이식 불가)

- FD 스텐실 `H^αΨ^α` 는 arithmetic intensity **≈0.97 flop/byte** → **완전 메모리대역 한계**.
  `objdump` 디스어셈블로 load 명령 수·배치를 보며 최적화. Ψ 를 **16-밴드 타일**로 재배치,
  `(i,j,k)` 를 **64×4×8** 로 캐시 블로킹, non-temporal store, SVE 로 FP64 16개씩 갱신,
  V_nl 은 원자별 projector 묶음 + **역방향 CSR** 로 atomic 연산 없이 backprojection.
- 조밀선형대수: `N_d^α ≈ 200,000 × N_s^α ≈ 640` 크기에 맞춘 **자체 FP64 DGEMM/DSYRK** (SME 외적 누산 +
  다단 블로킹 + **Stream-K** K차원 분할 + gather prefetch), 자체 **DSYGVD**(Cholesky + Householder +
  병렬 implicit-QL). 벤더 BLAS 대신 쓰면 **NUMA 도메인당 HBM 약 1 GB 회수** → 이게 2억 원자를
  같은 노드수에 올린 결정적 요인.

### 5.7 스케일링 결과 (`Fig. 5` — 실독, 수동 크롭)

**캡션·본문에 없고 그림에서만 읽히는 것 = 시간이 어디로 가는가.**

`figure-read ≈` (20,480 노드, 총 71.2 s 막대 기준):

- CheFSI 4단계 합계 ≈65–66 s ⇒ **≈92 %**
- 전역·통신성 단계 전부(Construct V_eff[ρ] = Poisson · Mixing & preconditioning · Chemical potential ·
  Update ρ(x) · Other) 합쳐 **≈6 s ⇒ ≈8 %**

⇒ **해석**: 이 코드의 비용은 사실상 **국소 해밀토니안–벡터 곱 하나**다. 전역 통신은 8 % 밖에 안 되고,
그래서 96.6 % weak scaling 이 나온다. 뒤집으면 — **성능을 더 내려면 알고리즘이 아니라 메모리대역**이다
(§3.2 의 "피크의 6.4 %" 와 같은 이야기).

- (b) strong: 68.8 → 33.6 → 17.6 → 7.5 → 4.2 s. **2,048 노드에서 효율 102.3 %** —
  **초선형**이다. ⇒ 이 측정계의 잡음 바닥이 **±2 % 수준**이라는 뜻이고, 96.6 % 와 98.4 % 같은
  차이는 유의하지 않다고 읽어야 한다 (§12-B).
- 20,480 노드 막대에서는 보라(필터) 비중이 상대적으로 줄고 통신성 조각이 커진다 — 효율 81.3 % 의 원인
  (본문: *"per-node subsystem grain 이 작아지며 통신지배 영역으로 전이"*).

## 9. ⭐ 1저자가 물은 네 질문 — 근거 있는 직답

### ① linear-scaling 이 성립하는 조건 — 밴드갭이 있어야 하나? 우리 계(갭 2–2.2 eV)는 조건 안인가?

**답: 갭은 필요조건이 아니다. 유한온도면 금속도 된다. 그리고 우리 계는 이 방법이 가장 잘 듣는 쪽 끝에 있다.**

- 논문 §V-A1 원문: *"for insulating **as well as metallic** systems **at finite temperature** [32],[33],
  the density matrix decays exponentially, `|D(x,x′)| ≲ exp(−|x−x′|/ξ)`, whereas the individual KS
  orbitals ψₙ may be fully delocalized."*
- 즉 조건은 **"갭이 있을 것"** 이 아니라 **"밀도행렬 감쇠길이 ξ 가 버퍼 반경보다 충분히 짧을 것"** 이다.
  - **넓은 갭 절연체** → ξ 짧다 → 작은 버퍼로 충분 (가장 유리)
  - **금속** → T = 0 에서는 대수적 감쇠, 유한 T(σ = k_BT)에서만 지수감쇠. **σ 가 작을수록 ξ 가 길다** → 큰 버퍼 필요
- **우리 계**: LPSCl/LPSCl1.6 은 PBE 갭 **2.066 / 2.099 eV** 의 wide-gap 절연체다
  ⇒ **조건을 아주 여유 있게 만족한다.** 이 논문이 다룬 두 계(Si 갭 ~1 eV 급, Li 금속 갭 0)보다 **유리**하다.
- 🔴 **그런데 그게 우리에게 이득이 아니다.** 이유는 ②·③.
- ⚠ 이 편에서 **ξ 값도, σ 값도, 버퍼 수렴 시험도 주어지지 않는다.** 그래서 *"우리 계면 어느 정도 버퍼면
  되는가"* 를 이 논문에서 답으로 가져올 수 없다. (그 답은 인용된 [35] Suryanarayana,
  *"On nearsightedness in metallic systems ... a case study on aluminum"*, CPL 679, 146 (2017) 쪽에 있을
  것으로 보이는데, **우리는 그 논문을 읽지 않았다** — 서지만 확인.)

### ② 정확도 대가 — O(N) 근사가 무엇을 얼마나 희생하나? (우리가 DFT 를 쓰는 이유가 전자구조라 이게 핵심)

**답 (전반부): 이 논문은 그 질문에 답하지 않는다. 정확도 검증 수치가 단 하나도 없다.**

전문 검색 결과 — `benchmark` **0건**, 정확도 오차를 보고한 표·그림 **0개**, R_buffer 수렴 시험 **0개**,
3차 스케일링 코드와의 대조 **0건**. *"retaining DFT accuracy"*(초록) · *"production-quality"*(§IV-C) 는
**수사이지 측정이 아니다.** ⇒ **"O(N) 이 정확도 손실 없다" 의 근거로 이 논문을 인용하면 안 된다.**

**답 (후반부): 다만 *구조적으로* 무엇이 희생되는지는 정식화에서 읽힌다.**

| 양 | 이 정식화에서의 지위 | 우리에게 |
|---|---|---|
| 전체에너지 / 밴드에너지 | 부분계 합 (Eq. 11–12), 내부가중치 `c^α_n` 로 조립. **버퍼 오차가 지수적으로 준다는 주장만 있고 크기 미측정** | ⚠ 검증 없음 |
| 힘 | Hellmann–Feynman 으로 가능하다고 적음. **보고된 값 없음** | ⚠ 검증 없음 |
| **DOS** | 전역 H 의 스펙트럼이 **아니다** — 부분영역 H^α 들의 고유값을 `c^α_n` 로 가중해 모은 것 | 🔴 **밴드갭을 우리 규율(fixed-occ nscf VBM/CBM 고유값)로 정의할 방법이 없다.** 이 코드는 갭을 보고하지도 않는다 |
| **밴드분산 / k-분해량** | **존재하지 않는다.** Γ 점만 (Eq. 1 명시) | 🔴 원리적 불가 |
| **스핀 분해량** | **존재하지 않는다.** 스핀 무시 (Eq. 1 명시) | 🔴 자성·라디칼·열린껍질 계에 못 쓴다 |
| **PDOS** | 있다. 원자중심 궤도 투영의 제곱 (Eq. 14) | ⭕ 이 논문이 실제로 낸 유일한 전자구조 관측량 |
| **ICOHP / COHP / COBI** | 🔴 **자리가 없다.** COHP 는 *두 원자의 궤도쌍 사이 비대각 해밀토니안 원소* `H_{μν}` 를 요구하는데, 이 정식화는 부분영역 고유값 λ^α_n 과 대각 투영가중치만 조립한다. LOBSTER 가 필요로 하는 것을 이 코드는 만들지 않는다 | 🔴🔴 **우리 전자구조 축의 중심 지표가 통째로 빠진다** |
| Bader | 가능하다고 *주장*만 (§III). **결과 없음** | ⚠ 미확인 |
| ELF / 전하밀도차 | 언급 없음 | — |

🔑 **우리 맥락의 결론**: 우리가 DFT 를 돌리는 이유는 **ICOHP·밴드갭·PDOS 성격** 이다.
그 중 **ICOHP 는 이 정식화에 원리적으로 없고, 밴드갭은 이 코드가 우리 규율대로 정의하지 못한다.**
⇒ **우리 목적 함수에 O(N) DFT 는 부분적으로만 대응한다.** 이건 우리 기계가 작아서가 아니라
**방법의 성질**이다. 이게 이 질문에 대한 가장 중요한 답이다.

### ③ "Bridging Quantum Simulations and Experiments" — 어떤 실험량과 어떻게 맞췄나? 프로토콜이 옮겨올 만한가?

**답: 맞춘 것은 "추세의 방향"뿐이다. 프로토콜로 옮겨올 만한 것은 *구조*이고, *정량성*은 아니다.**

**그들이 실제로 한 대조**:

| | 실험 | 계산 |
|---|---|---|
| 양 | Ge 3d · P 2p **XPS 결합에너지 스펙트럼** (eV) | **E_F 이하 점유 PDOS 적분** (무차원) |
| 공간축 | Ar⁺ **스퍼터 시간** 0 / 20 / 50 분 | **x (nm)**, 25–65.5 nm |
| 대조 방식 | — | **양쪽 다 "계면에서 크고 벌크로 갈수록 준다"** 는 것만 |
| 겹쳐 그림 | **없음** | |
| 맞춘 숫자 | **없음** | |
| 스퍼터시간 → 깊이 환산 | **없음** | |

⇒ 초록의 *"in **quantitative** agreement with spectroscopy experiments"* 는 **본문이 뒷받침하지 않는다.**
본문 자신은 더 정직하게 *"The consistent interface-to-bulk **trend** validates..."* 라고 쓴다.
**초록과 본문의 강도가 다르다** (§12-C).

**그래도 옮겨올 만한 것 (구조)**:
- ⭕ **"계산 관측량을 실험이 실제로 재는 공간축 위에 놓는다"** 는 설계. 그들은 계산을 **깊이 방향
  프로파일**로 냈다 — XPS 깊이프로파일이 그렇게 나오기 때문이다. 우리가 XPS anchor 와 계산을 맞출 때
  같은 규율을 쓸 수 있다: *"실험이 주는 축이 무엇인가 → 계산도 그 축으로 내라."*
- ⭕ **3단(구조생성 → 전자구조 → 실험대조) 을 논문 구조로 명시**한 것 자체.
- ⛔ **정량 대조 프로토콜로는 못 쓴다** — 공통 관측량이 없다. 우리가 진짜로 XPS 와 정량 대조를 하려면
  **core-level 결합에너지(또는 화학적 이동)를 계산**해야 하고, 그건 이 논문이 하지 않은 일이다.

### ④ SE·배터리 계를 사례로 썼나?

**답: 썼다. 그리고 그게 이 논문에서 우리에게 유일하게 의미 있는 부분이다 — 다만 정성적이다.**

- 계: **Li | LGPS | Li**, 11,325,600 원자, 57×44×90 nm, LGPS 층 `figure-read` **35 nm**.
  ⇒ **황화물 SE + Li 금속 계면**, 우리 축 E(환원/음극계면)와 같은 물리.
- 결과: **계면에서 Ge·P 가 저원자가화**(= 환원), **벌크로 갈수록 감쇠**, **면내로 불균일**.
  XPS 가 Ge⁰/Li–Ge 합금까지 확인.
- ⚠ **우리 물질이 아니다** — LGPS(Li₁₀GeP₂S₁₂)는 Ge 중심의 LGPS 계열이고 우리는 argyrodite(Li₆PS₅Cl)다.
  **Ge 가 없다.** 공통은 `PS₄³⁻` 골격과 Li 금속 접촉이라는 상황뿐.
- ⚠ **수치가 없다** — Δ(계면−벌크)는 `figure-read ≈ 2 %` 인데 오차막대도 통계도 없고
  그 양의 정의(§7 마지막)도 열려 있다.
- ⇒ **우리 축 E 표에 행으로 넣지 않는다.** 정성 관찰로만 기록한다.

## 11. 인용 가능 문장 (영문 초안)

- "Linear-scaling Kohn–Sham DFT rests on the nearsightedness of the one-particle density matrix, which
  decays exponentially in real space **for insulators and, at finite electronic temperature, for metals
  as well**, even though the individual Kohn–Sham orbitals remain delocalized [Xu et al., arXiv:2609.13115]."
- "Xu et al. deployed an O(N) real-space finite-difference KS-DFT code (XLSDFT) on 20,480 nodes of an
  exascale system, reporting 104,857,600- and 209,715,200-atom silicon calculations at 71.2 and 143.7 s per
  SCF iteration respectively, i.e. a 2.02× wall-time increase for a 2× increase in atom count."
- "For an 11,325,600-atom Li|LGPS|Li interface model spanning 57 × 44 × 90 nm, the computed occupied-PDOS
  integrals of Ge and P are enhanced near both Li contacts and decay toward bulk-like LGPS, **in the same
  direction as** XPS depth profiles that show low-valence Ge, Ge metal / Li–Ge alloy and low-valence P
  concentrated at the interface."
- "Machine-learned force fields reach millions of atoms for energies and forces but **yield no
  electronic-structure observables** — band alignment, charge transfer and projected DOS remain inaccessible
  [Xu et al.]." ← **우리 MLIP+DFT 분업을 정당화하는 데 쓰는 문장**
- ⛔ **쓰면 안 되는 문장**: *"O(N) DFT achieves the same accuracy as cubic-scaling DFT"* —
  **이 논문은 그것을 측정하지 않았다.**

## 12. 비판 — 이 논문의 약한 곳 ★

### A. 🔴🔴 정확도 검증이 **완전히** 없다 (이 편의 치명상)

- **O(N) 근사의 오차를 보고한 표·그림이 0개다.** 총에너지/원자, 힘, DOS, 밴드갭 — 어느 것도
  3차 스케일링 기준계산과 대조하지 않았다. 같은 계를 작은 크기로 잘라 SPARC/QE/VASP 와 맞춰보는
  **가장 기본적인 검증조차 없다.**
- **R_buffer 수렴 시험이 없다.** 지수수렴한다는 인용[34,35]만 있고 *이 계에서 얼마면 충분한지*를
  안 보였다.
- 🔴 더 나쁜 것: **금속을 포함한 Li/LGPS 에 더 *작은* 버퍼(8.0 Bohr)를 썼고, 순수 반도체 Si 에
  더 큰 버퍼(9.2 Bohr)를 썼다.** 근시안성 이론은 정반대를 요구한다 (금속 ξ 가 더 길다).
  논문은 이 선택을 **설명하지 않는다.** 정황상 비용 제약(LGPS 는 h=0.4 Bohr 라 같은 물리적
  버퍼가 격자점으로 2배 비싸다)으로 보이는데, **오차분석 없이 내린 예산 결정**이다.
- **전자 스미어링 σ 값이 없다.** 금속계에서 ξ 는 σ 에 직접 매인다 ⇒ 버퍼 적정성을 독자가 **판정할 수 없다.**
- **XC 범함수 종류가 없다** ("GGA" 뿐, PBE 인지 PBEsol 인지 미기재).
- **스핀을 껐다** — Li 금속이 황화물을 환원해 Ge⁰/Li–Ge 합금이 생기는 계인데 스핀 자유도를
  통째로 제거했고, 이에 대한 정당화가 **한 줄도 없다**.
- **SCF 문턱 5×10⁻⁴** (상대 밀도 잔차)가 보고된 관측량에 무엇을 보장하는지 근거가 없다.

⇒ **종합**: 성능 논문 심사기준으로는 통과할 수 있지만, **재료 결과의 신뢰성 근거로는 인용할 수 없다.**

### B. 🟠 성능 보고의 약점

- **Li/LGPS 런의 노드수가 없다.** Table II·III 어디에도 없다. §VII-B 의 대역 외삽이 20,480 을
  쓰므로 그렇게 **추정**할 뿐이다 ⇒ **재현성·비용 비교가 원천적으로 막힌다.**
- **"167 accumulated iterations"** — *accumulated* 가 무슨 뜻인지 설명이 없다.
  재시작을 이어 붙였다는 뜻으로 읽히는데, 그렇다면 한 번에 수렴한 것이 아니다.
- **strong scaling 에서 효율 102.3 %**(초선형) — 측정 잡음 바닥이 **±2 %** 라는 뜻이다.
  96.6 % 같은 값을 소수 첫째자리까지 의미 있게 읽으면 안 된다.
- **Si 런은 wall time 의 54–56 % 가 초기화·I/O** 다 (우리 검산). "71.2 s/SCF" 와 "1,082.7 s 총" 사이의
  간극이 거기다.
- **헤드라인 157.9 Pflop/s = 피크의 6.4 %** (우리 검산). 논문은 피크 대비 비율을 어디에도 적지 않는다.
- **Li/LGPS 의 지속 HBM 대역이 피크의 3.2 %** (Si 는 50.7 %) — **실제 재료 문제는 벤치마크보다
  16배 나쁘게 돈다.** 논문은 이 숫자를 표에 넣어 놓고 **한 문장도 논의하지 않는다.**
- **"1,000× beyond DFT SoTA for such interfacial systems"** 의 비교대상 [5] 는 **MLFF 연구(~12,000 원자)**
  이지 DFT 가 아니다. 범주가 어긋난 비교다.

### C. 🔴 "Bridging"·"quantitative agreement" 는 과주장이다

- 초록: *"in **quantitative** agreement with spectroscopy experiments"* ↔ 본문: *"The consistent
  interface-to-bulk **trend** validates..."* — **강도가 다르다.** 실제로 대조된 것은 **부호/추세**다.
- 실험 축(결합에너지 eV)과 계산 축(무차원 PDOS 적분)이 **다른 물리량**이고, 겹쳐 그린 적도
  수치로 맞춘 적도 없다.
- **스퍼터 시간(0/20/50 분) → 깊이(nm) 환산이 없다** ⇒ 계산 x(nm) 축과 대응이 불가능.
- **시료와 모델의 조성이 다르다**: XPS 에 **O 2s** 가 뚜렷한데(`Fig. 6b` 실독) 모델 LGPS 에는 O 가 없다.
- 계산 신호 자체가 작다: `figure-read` Δ(계면−벌크) **≈2 %** (Ge) / **≈1.8 %** (P) 인데
  **산점 구름의 퍼짐이 그 4–5배**이고 **오차막대·통계가 없다.**
- 계산 관측량의 정의가 열려 있다 (§7 마지막 5항목).

### D. 🟠 재료 서술의 부실

- **"LGPS" 의 화학식·공간군·격자상수·원소별 원자수가 전문에 없다.**
- MLFF-MD 상세 전무: 코드 버전·학습 프레임수·힘 RMSE·앙상블·열욕·dt·길이 **전부 미기재**.

## 13. 기법 미니 용어집 (이 논문을 읽는 데 필요한 것만, 한 단계씩)

- **KS-DFT 의 O(N³) 이 어디서 오나**: 해밀토니안 H 를 대각화해 점유궤도 N_s ≈ N_e/2 개를 찾는 일이
  `O(N_d · N_s²)` 다. N_d(격자자유도)도 N_s 도 원자수 N 에 비례하니 **N³**. 메모리는 궤도 N_s 개를
  격자 N_d 점에 저장하니 **N²**.
- **밀도행렬 D**: 궤도 대신 쓰는 바닥상태 기술자. `D = f(H)` (Fermi–Dirac). 밀도는 그 대각성분
  `ρ(x) = 2D(x,x)`. **궤도가 비국소적이어도 D 는 국소적일 수 있다**는 점이 전부의 출발점.
- **근시안성(nearsightedness, Prodan–Kohn 2005)**: `|D(x,x′)| ≲ e^{−|x−x′|/ξ}`.
  "멀리 있는 원자를 바꿔도 여기 전자밀도는 거의 안 바뀐다". **ξ 는 갭이 클수록 짧고, 금속은 온도가
  낮을수록 길다.**
- **Divide-and-conquer (D&C)**: 계를 **코어 + 버퍼** 조각으로 쪼개 각각 독립적으로 풀고, **코어 부분만**
  모아 전역량을 만든다. 버퍼는 "경계 때문에 생기는 오차"를 코어 밖으로 밀어내는 완충재.
  대가는 **버퍼를 푸는 비용**(§5.2 의 ≈40×).
- **CheFSI (Chebyshev-filtered subspace iteration)**: 완전대각화 대신, 체비셰프 다항식 `C_m` 이
  구간 [−1,1] 밖에서 폭발적으로 커지는 성질을 이용해 **점유 부분공간만 증폭**하고 나머지를 눌러
  근사 고유벡터를 얻는 방법. 필요한 연산이 **H·벡터 곱 m 회**뿐이라 희소·실공간에 잘 맞는다.
- **실공간 유한차분(FD) DFT**: 평면파(QE/VASP) 대신 **격자점 위의 값**으로 파동함수를 나타내고,
  라플라시안을 **유한차분 스텐실**로 근사한다. 손잡이가 `ecut` 이 아니라 **격자간격 h** 와 **스텐실 차수**다.
  ⚠ **h ↔ ecut 직접 환산식은 없다** — 수렴은 각자 확인해야 한다.
- **Norm-conserving (ONCV) 유사퍼텐셜**: PAW 보다 전송성은 좋지만 더 높은 컷오프를 요구하는 계열.
  실공간 FD 코드가 PAW 대신 이걸 쓰는 이유는 정식화가 단순해서다.
- **Periodic Pulay 혼합**: SCF 밀도 갱신 가속법. 매 회가 아니라 **주기적으로만** Pulay(DIIS) 외삽을 섞는다.
- **타원형 전처리 (elliptic / Kerker 계열)**: 밀도 잔차의 **장파장 성분**이 SCF 를 흔드는 것을 막는다.
  `(−∇² + κ²)R̃ = −∇²R`. **κ² 가 Thomas–Fermi 스크리닝 파수** 역할. 금속은 스크리닝이 강해 κ² 가 커야 하고
  절연체는 작아야 한다 ⇒ **한 셀에 둘 다 있으면 κ² 를 공간의 함수로** (이 논문의 물질 마스크).
- **weak / strong scaling**: **weak** = 노드당 일감을 고정하고 노드·문제를 같이 키운다(→ 시간이
  일정해야 이상적). **strong** = 문제를 고정하고 노드만 늘린다(→ 시간이 반비례로 줄어야 이상적).
- **arithmetic intensity (flop/byte)**: 메모리에서 1 바이트 읽어와 몇 번 연산하나. 낮으면
  (여기 **0.97**) 연산기가 아니라 **메모리 대역**이 한계 ⇒ 피크 Flop/s 를 못 채운다.
- **Pflop/s · Eflop/s**: 10¹⁵ · 10¹⁸ 부동소수점연산/초. **"지속(sustained)"** 은 특정 국면의 측정치,
  **"피크(peak)"** 는 하드웨어 이론상한. 둘의 비를 안 적으면 숫자가 커 보인다.
- **HBM vs DDR**: HBM 은 프로세서 패키지 위의 고대역 메모리(여기 프로세서당 32 GB / 4 TB/s),
  DDR 은 바깥의 대용량 저대역 메모리(다이당 128 GB). 메모리대역 한계 커널을 HBM 에 올리는 것이
  이 논문 최적화의 절반이다.
- **ARM SVE / SME**: ARMv9 의 가변길이 벡터 명령(SVE)과 **행렬 외적 누산 유닛**(SME).
  x86 AVX-512 / NVIDIA Tensor Core 에 각각 대응하는 자리지만 **명령집합이 다르다** ⇒ 코드 이식 불가.
