## 다음에 확인할 운동량

처음 눌리기 전 둥근 입자의 기하와 원래 격자 함수를 사용해 첫 윗판 속도 적용 한 번을 검사했다. 윗판과 최상단 입자 사이 틈은 각각 0.00142820 D와 0.00157770 D였다. 이때도 윗판 지지 노드에는 코드 단위의 하향 충격량 1.54996e-6, 1.49380e-6이 생겼다. 같은 충격량을 입자 보간 가중치로 별도 합산했다. 판을 멀리 두거나 입자가 판보다 빠르게 아래로 움직이는 대조에서 두 값은 0이었다. 이는 첫 시각의 윗판 경계 거동이며, 27.87% 중 윗판이 설명하는 몫은 아직 정해지지 않았다.

다음 개발 관측에서는 두 팔의 기존 가압 이력을 첫 초과와 이른 최대점까지만 재생한다. 첫 초과에서는 두 격자의 윗판 후보 행 높이가 같다. 이른 최대점에서는 그 높이가 F24 한 셀만큼 벌어진다. 구간 동안 윗판·아래판의 수직 충격량과 입자 접촉으로 아래쪽 입자에 전달되는 운동량을 함께 기록한다. 같은 걸음까지 저장 압력 원곡선이 재현되는지 확인한 뒤 두 시점과 누적 수지를 대조한다. 비교 근거는 docs/reviews/dem_redesign_direction_20261109/memo_v3_2.md §4 U6(c)다.
