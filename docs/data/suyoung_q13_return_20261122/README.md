# 수영 2D 설정 ① · 36셀 S/F 개발 판독

36셀을 더하자 같은 충전율에서 S(공유 속도장)와 F(원판별 속도장)의 아래판 응력비를 비교할 수 있는 점이 0곳에서 2곳으로 늘었다. 한 가지 49원판 배열의 개발 결과다. 1저자가 WSL CPU 1에서 S36과 F36을 한 번씩 돌렸다. 이전 반환에서 S·F의 12·16·24셀 궤적 여섯 개를 재사용했다.

## 같은 충전율의 아래판 응력

| 충전율 Φ_m | 36셀 S (MPa) | 36셀 F (MPa) | S/F의 격자 오차 추정 구간 | 해상도 판정 |
|---|---:|---:|---|---|
| 0.84 | 0.272311 | 0.272320 | 산출 불가 | 양팔 미수렴 |
| 0.90 | 0.440636 | 0.440625 | 0.836–1.197 | 양팔 규칙 A, 보조 대조에서 변화 방향 반전 |
| 0.95 | 0.621903 | 0.621833 | 0.807–1.240 | 양팔 규칙 A, 보조 대조에서 변화 방향 반전 |

12·16·24·36셀의 두 팔이 세 충전율에 모두 도달했다. 앞선 8셀 S·F가 도달하지 못했던 0.95도 이번 사다리에서는 비교할 수 있다. 표의 구간은 각 팔의 로그 응력 오차 구간을 뺀 뒤 지수로 환산했다. 단일 해상도의 두 숫자를 나눈 값으로 수렴을 판단하지 않는다.

0.84에서는 16→24셀과 24→36셀에서 양팔 응력이 계속 낮아졌다. 두 로그 응력 변화량의 절댓값 비가 S 약 0.807, F 약 0.806으로 규칙 A의 상한 0.75를 넘었고, 규칙 B도 충족하지 못했다. 0.90·0.95에서는 16→24→36셀의 감소가 규칙 A에 들어왔지만 12→16셀에서는 응력이 증가했다. 이 때문에 두 팔 모두 `suspect_asymptotic=true`를 기록했다.

두 추정 구간은 1을 포함하고 양쪽 모두 계획의 동등성 대역 [1/1.15, 1.15] 바깥까지 걸친다. 이 배열로 S와 F의 동등성이나 차이를 확정할 수 없다. 구간은 격자 세분화에서 추정한 수치 오차다. 시드·초기 배열 반복 오차는 미측정이다. `u6_qualified=false`, `stage3_go=false`. F8의 U6(c) 조밀 접촉 판정은 HOLD다.
