## 보낼 글 (그대로 붙여 넣는다)

**[DFT → DEM] Ag–C 점착일 요청 회신 — 계산 0 건, 구조 검증부터 시작합니다**

요청 잘 받았습니다. 두 리뷰(내부 · Codex)를 거쳐 설계를 고쳤고, **본 계산은 아직 안 걸었습니다.** 먼저 착수 전 질문 셋에 답하고, 요청서와 달라지는 점과 확인할 것을 적습니다.

**① 이미 가진 LPSCl 슬랩·종단·표면에너지**
- **옛 LPSCl|NCM 파이프라인의 숫자는 기준으로 못 씁니다.** 수정본의 "기존 isolated slab W_ad 와 나란히" 의 전제가 깨졌습니다.
  - 정방 SE 셀을 육방 NCM 셀에 변형 없이 접어 넣었습니다(원자 겹침).
  - v6 러너의 NCM 은 R-centering 이 빠져 **LiNiO₂ 가 아닙니다** (Ni 주변 O 0개).
  - 출판 표의 comp1 1.277 은 20 시드 중 **5개를 골라낸** 값입니다.
  - "실험 0.18–0.32 J/m²" 는 실제로는 AFM **aJ**(에너지) 값을 J/m² 로 잘못 옮긴 것입니다.
  - 원장의 옛 γ_SE(comp1 1.21 J/m²)는 UMA 비정질 표면 값이라 역시 쓰지 않습니다.
- **새 SE 슬랩**은 comp1 입방셀(001)을 **PS₄ 를 안 끊는 위치**에서 자릅니다.
  - 단순 절단은 PS₄ 48개 중 8개를 끊습니다.
  - 허용되는 절단은 두 틈뿐이고, 한쪽 면은 **S 바깥**, 반대쪽 면은 **Li·PS₄ 바깥**이 됩니다.
  - 그래서 요청서의 **"S 쪽"은 바로 되지만 "Cl 쪽"은 comp1 으로는 안 나옵니다** (절단 창에 Cl 이 없습니다).
- **SE 자체의 이상 벽개 문턱** (문헌 · PBE · vdW 없음, Pustorino 2025): 같은 (100) 면의 화학량론 벽개가 **≈ 0.47 J/m²**, (110) 은 **0.37 J/m²** 입니다.
  - ⚠ 트랙 문서 §6 의 "Pustorino 0.20 J/m² = LPSCl 벽개 에너지" 는 **대칭 비화학량론 슬랩의 2γ(화학퍼텐셜 조건값)**입니다. 벽개 문턱으로 쓰면 SE 를 2배 넘게 약하게 잡습니다.

**② P1 두 계면의 계산량·일정** — 약속은 첫 프로브를 잰 뒤에 드립니다. 순서만 먼저 알려드립니다.
1. 구조 빌더·검증 (좌표·배위·조성) — CPU, 며칠
2. 불변성·가산성 대조 (UMA) — 분 단위
3. LPSCl|Ag registry 20개 (UMA) — GPU 수 시간 (GPU 가 비는 대로)
4. DFT 검증 — **미리 고정한 5개**, 848원자급 단일점. repo 견적은 점 하나에 ~48 h 라 프로브로 실측한 뒤 예산을 잡습니다
5. Ag|흑연 — 분산 없는 MLIP 를 건너 **DFT+D3 로 직접**. 작은 셀이라 쌉니다

**③ 대표 모델보다 나은 선택**
- **LPSCl 종결**은 두 방식 중 하나입니다. 1저자 결정 대기입니다.
  - (가) S 바깥·Li 바깥 **대칭 슬랩 두 장** — 면마다 쌍극자 없이 따로 잽니다
  - (나) 화학량론 **비대칭 한 장** — 쌍극자 보정이 필요합니다
- **Ag|흑연 셀**은 Ag 격자상수에 따라 답이 뒤집힙니다. √3 셀이 a 4.086 Å 에서는 −1.7 % 인데, PBE 4.16 Å 에서는 −3.4 % 로 요청서 3 % 를 넘습니다. **DFT 단계의 Ag 격자를 먼저 재고** 셀을 고릅니다 (회전 셀은 0.3–0.5 %).
- **흑연 대조 기준**은 이상 ABAB 벽개 **0.39 ± 0.02 J/m²** (Wang et al. 2015) 로 합니다. 0.37 은 비정합 쌍결정 값이라 다른 양입니다.

**요청서와 달라지는 점**
- **주값** = 정해진 기하·셀·전자상태 규칙에서의 **DFT(PBE+D3(BJ)) 고정기하 W_sep** 입니다 (UMA 로 만든 기하 위 DFT 값).
  - 848원자를 DFT 로 이완한 열역학적 W_ad 는 규모상 못 냅니다. "UMA 이완 슬랩 + DFT 단일점" 값은 내되 그 이름표를 붙입니다.
- **"D3 끈 값"** = 같은 기하에서 D3 항만 뺀 값입니다. D3 없이 이완하면 물리흡착 계면은 떨어져 나가서 값이 정의되지 않습니다.
- **D3 3체 항**: QE 는 기본으로 3체 항(ATM)을 켭니다. 요청서의 "D3(BJ)" 관례(2체)에 맞춰 끄고 ATM 은 따로 보고하는 쪽을 제안합니다.
- **"물리흡착 급 / 화학결합 급" → "저·고 접착 구간"** (0.3 / 1 J/m²). 크기로 기전을 판정하지 않습니다.
  - Giovannetti 2008: 같은 계산에서 **화학흡착인 Pd 가 ≈ 0.52 J/m²** 입니다.
  - ⚠ 트랙 §6 설계 결론 3 정정: Maurer 2015 의 45 meV/C 는 논문 셀 밀도로 **0.26 J/m²** 입니다 (0.28 은 평형 그래핀 밀도로 환산한 값). 더 중요한 건 분산 방법 7개가 **0.19–0.45 J/m²** 로 흩어진다는 점입니다 — 0.3 경계를 가로지르므로 *"mJ/J 판별에는 영향 없음"* 은 맞지 않습니다. Ag|흑연 값은 **"PBE+D3(BJ) 조건부"** 로 드립니다.
  - Giovannetti 원문 용어는 "physisorption" 이 아니라 **"weak bonding"(LSDA)** 입니다.
- **MLIP(UMA) 절대값은 넘기지 않습니다** (정본 repo 규칙). 넘기는 것은 DFT 값과, 같은 프로토콜 안의 비입니다.
- **NCM 대비**는 정상 LiNiO₂ 를 새로 짓고 자기 상태 정책을 정한 뒤 **조건부 비**로만 드립니다. 옛 NCM 숫자와 AFM 실험값을 곱하는 방식은 쓰지 않습니다.

**CSV 에 추가할 열** — 방법 표지(D3 2체/ATM) · 기하 출처(UMA) · d_eq · 양쪽 일함수 · ΔV · 표본 종류(UMA 20 / DFT 검증 5) · 집합 표지(`intermixed` · `PS4-topology-changed`).

**확인 부탁드립니다**
1. **DEM 입력 연결**: 트랙 §3 의 JKR pull-off F = 1.5πR·w 에서 **w = 우리 W (면적당 점착일, J/m²)** 로 받으시면 됩니다. γ 가 아닙니다 — 같은 두 면이면 W = 2γ 입니다. 헤드라인을 고정기하 W_sep 으로 받아도 되는지, 이완 W_ad 가 꼭 필요한지 알려 주세요.
2. **LPSCl 종결**: "S 쪽"은 그대로 갑니다. "Cl 쪽" 대신 **"Li·PS₄ 쪽"**(Cl 은 두 번째 층)으로 받아도 될까요? 아니면 음이온 자리바꿈 변형을 만들어야 할까요?
3. **P2·P3**(LPSCl↔탄소 · 리튬화 LiAg)를 지금 범위에 넣을지요.

## 받은 회신 (DEM → DFT · 2026-09-23 저녁 · 원문 그대로)

> 아래는 DEM 트랙이 보낸 글이다. 우리 판단은 다음 절에. **원문은 고치지 않는다.**

**[DEM → DFT] 회신 잘 받았습니다 — 정정 셋 수용, 확인 요청 셋에 답합니다**

**정정 수용 — 트랙 문서 §1 · §2-1 · §4 · §6 을 고쳤습니다**
- Pustorino 0.20 J/m² 는 비화학량론 대칭 슬랩의 2γ 이고 화학량론 벽개는 (100) ≈ 0.47 · (110) 0.37 — 반영했습니다.
  결론 1·2 의 "이상 벽개 0.20" 을 0.37–0.47 로 바꿨고, SE|SE 대조 앵커 0.47 (경보용) 도 적었습니다.
- Maurer 0.28 → 0.26 (논문 셀 밀도), 분산 방법 7개가 0.19–0.45 로 0.3 경계를 가로지른다 — *"판별에 영향 없음"* 은 철회했습니다.
  Ag|흑연 값은 PBE+D3(BJ) 조건부로 받습니다.
- Giovannetti 의 용어는 weak bonding — "물리흡착" 은 우리 번역이었습니다.  "저/고 접착 구간 (0.3 / 1 J/m²)" 명명과
  "크기로 기전을 판정하지 않는다" 도 받습니다 (Pd 0.52 예).
- 옛 LPSCl|NCM 파이프라인 숫자를 기준으로 못 쓴다는 것 — §2-1 의 "나란히" 전제를 내렸습니다.  정의·프로토콜 재사용 요구만
  남기고, NCM 대비는 정상 LiNiO₂ 를 새로 지은 뒤 조건부 비로만 받습니다.
- D3 끈 값 = 같은 기하에서 D3 항만 뺀 값 · ATM 은 끄고 따로 보고 · MLIP 절대값은 안 넘김 · CSV 열 추가 — 전부 좋습니다.
  우리 쪽에 걸리는 것이 없습니다.

**① DEM 입력 연결**
- 맞습니다.  JKR pull-off `F = 1.5πR*·w` 의 w 는 **W (면적당 점착일, J/m²)** 입니다.  γ 가 아니고, 같은 면이면 W = 2γ.
- 헤드라인은 **고정기하 W_sep 으로 받겠습니다**.  이유 둘 — 목표가 자릿수이고, 요청서 6번 강체 분리 스캔에서 E(d) 의 끝값 차이
  (= 견인–분리 곡선 아래 면적) 가 곧 W_sep 이라 곡선과 헤드라인의 정의가 같아집니다.
- "UMA 이완 슬랩 + DFT 단일점" 값도 그 이름표 그대로 주십시오.  DEM 을 두 값에서 돌려 G_c 를 **띠**로 냅니다.  아래 끝이 하한 보장이
  아니라는 점 (DFT@UMA 에서는 W_ad ≤ W_sep 가 게이트가 아님) 은 그대로 라벨합니다.

**② LPSCl 종결**
- **"S 바깥" + "Li·PS₄ 바깥"** 두 면으로 받겠습니다.  음이온 자리바꿈 변형은 지금 만들지 마십시오 — "Cl 쪽" 요청의 뜻은
  Ag–S 와 Ag–Cl 화학의 차이를 보자는 것이었는데 Li·PS₄ 면 2층의 Cl 로 일단 충분하고, 자리바꿈은 별개 축입니다.
- (가)/(나) 는 DFT 쪽 비용 판단이 우선입니다만 우리 선호는 **(가) 대칭 슬랩 두 장**입니다: 우리가 받는 것은 W 뿐이고 γ 의
  화학퍼텐셜 항은 W 에 안 들어가므로 비화학량론이 문제가 안 되고, SE 슬랩 자체의 쌍극자가 없습니다.

**③ P2 · P3**
- **P2 (LPSCl↔탄소) 는 P1 과 같은 우선순위로 지금 넣어 주십시오**.  Ag–C 인터레이어의 Ag 는 **5.7 vol%** (22.5 wt%,
  Spencer-Jolly 2023, 정본 카드) 라 LPSCl 이 닿는 면적의 대부분이 탄소입니다 — 원문도 Ag 가 SE 와 직접 접촉이 거의 없다고
  적습니다.  우리 조합식 (구성 쌍 W × 접촉 면적 비율) 에서는 LPSCl|Ag 가 LPSCl|C 의 약 16배 이상 강하지 않으면 탄소 항이
  지배합니다 (면적 비율 ≈ 부피 비율 가정).  유일한 실험 앵커 (Liao 2025) 도 Ag 없는 탄소/LPSCl 계면입니다.
- 탄소 모델은 **LPSCl|graphite(0001) 먼저**, 비정질은 뒤로 가도 됩니다 (Liao 의 탄소는 카본블랙·하드카본, VGCF 외벽은 흑연질).
- P3 (리튬화) 는 뒤로.  흑연이 먼저 리튬화된 뒤 Ag 가 Li_xAg → LiAg → Li₉Ag₄ → Li₁₀Ag₃ 순으로 합금화하고, LiAg 를 만들 만큼
  반응성 있는 것은 LiC₆ 뿐입니다 (Spencer-Jolly) — 하게 되면 LiAg|LPSCl 부터.

**우리 쪽에서 드리는 정보**
- 정본에 카드 넷을 넣었습니다: `liao2025_…` (탄소/LPSCl 180° 박리 · lamination 100→400 MPa 에서 Γ 9→41 J/m² · Ag 없음 ·
  사이클 적층압 5 MPa 고정), `song2025_…` (다공 13 % LPSCl E 4.7 GPa · K_IC 0.17 → G_c 5.3–6.2 J/m²), `spencerjolly2023_…`,
  `tabakovic2026_…` (SSRN 프리프린트 — 수치 인용 금지).
- SE 자체 값의 자리: 화학량론 벽개 0.37–0.47 (Pustorino) ↔ 파괴인성 환산 G_c 3–6 (Song · Fan) ↔ 실측 박리 Γ 9–41 (Liao).
  층마다 대략 한 자릿수씩 다릅니다.  우리 문서는 *"박리값의 상한은 W_ad 와 SE 벽개 중 약한 쪽"* 이라던 결론을 철회했습니다 —
  Γ 가 SE 의 G_c 보다 큰데도 300 MPa 시편은 계면에서 떨어졌습니다.
- 압력 축: 문헌의 압력 효과는 전부 제조 압착 (lamination · 조립) 압 축이고 운전 적층압 축은 대조가 없습니다.  DFT 쪽엔 영향이
  없습니다 (요청서대로 압력은 걸지 않습니다).

**확인 부탁**
1. 848원자 DFT 단일점 5개의 실측 비용이 나오면 알려 주십시오 — 우리 DEM 박리 일정은 그 뒤에 잡습니다.
2. P2 를 넣으면 SE 슬랩은 P1 과 같은 것을 씁니까?  같은 슬랩이어야 LPSCl|Ag 와 LPSCl|C 를 면적 가중으로 합칠 수 있습니다.

## 회신 2 (DFT → DEM · 2026-09-23 밤 · 발송 전 정정본 — 1저자 검토)

> 정정 이유 (첫 판 대비): ① Ag 셀 "2×7" 표기가 방향이 모호해 거꾸로 읽으면 5.8 × 35.0 Å 가 된다 → Å 치수로 ② 원자 수는 흑연 3층·Ag 4층 **가정** ③ **3번 — GPU 한 장에 안 들어간다**: gabia CPU 추정으로 SE 슬랩 SCF 가 **55.8 / 50.2 GB** (벌크 6.7). ⛔ KISTI 이전 제안은 **철회** — KISTI 접근은 2026-09-15 에 끝났다. → SE|SE 는 4층으로 축소, P1·P2 는 방식 결정 대기 (계획 §0′ *KISTI 없이*).

**[DFT → DEM] 회신 감사합니다 — 같은 SE 슬랩 확인 · P2 수용 · 비용은 첫 실측 뒤**

1. **같은 SE 슬랩입니다.** P1(LPSCl|Ag) · P2(LPSCl|C) · SE|SE 대조 전부 정본 `db/structures/wad_se_slabs_2026_09_23/` 의 대칭 슬랩 두 장(S 바깥 Li₇₆P₁₂S₆₂Cl₁₂ 162원자 · Li·PS₄ 바깥 Li₆₈P₁₂S₅₈Cl₁₂ 150원자 · 단면 10.055 Å · PS₄ 12/12 · 양면 C2 대칭)을 씁니다. 계면 셀은 이 단면의 정수배(후보: P1 1×2 · P2 1×3)이고 W 는 면적당 값이라 면적 가중 합산이 됩니다. 격자 정합 규칙은 P1·P2 에 같은 규칙으로 걸고, 정하면 알려 드립니다.

2. **P2 를 P1 과 같은 우선순위로 넣습니다** (LPSCl|graphite(0001) 먼저, 비정질은 뒤). 정합 후보:
   - P2: SE 1×3 (10.06 × 30.17 Å) 위에 흑연 직사각 셀 9.84 × 29.83 Å — 흑연 변형 +2.2 % / +1.1 % · 흑연 3층 가정 시 ≈ 820원자
   - P1: SE 1×2 (10.06 × 20.11 Å) 위에 Ag(111) 직사각 셀 10.01 × 20.22 Å — Ag 변형 +0.5 % / −0.6 % (a 4.086 실험값 기준 · PBE 격자상수로 다시 잽니다) · Ag 4층 가정 시 ≈ 436원자
   registry ≥ 4 · D3 2체 필수 · P3 은 범위 밖입니다.

3. **비용·방식은 첫 실측 뒤에 드립니다.** 우리 계산기는 전부 단일 노드(GPU 한 장 48 GB 가 최대)이고 클러스터 접근은 끝났습니다. 그래서 P1(~436원자)·P2(~820원자) **전체 계면의 평면파 DFT 는 우리 쪽에서 돌릴 수 없습니다** — 150–162원자 SE 슬랩 SCF 도 QE 추정 50–56 GB 였습니다. SE|SE 대조는 슬랩을 얇게(4층) 줄여 우리 GPU 에서 돌리고, P1·P2 는 (a) 작은 모델에서 DFT 로 검증한 MLIP+D3 값 또는 (b) 가우스 기저 DFT 로 전체 계면 단일점 — 둘 중 하나로 정해 알려 드립니다. 848원자 5점 비용은 그 방식이 정해진 뒤에 드립니다.

4. **전달 값은 둘** — `W_sep(DFT · 고정기하)` 헤드라인과 `W(DFT@UMA-이완 슬랩 단일점)`. 후자에는 "하한 보장 아님"을 붙입니다.

5. 16배 규칙(면적비 ≈ 부피비)은 DEM 조합식의 가정으로 이해합니다 — 우리는 두 쌍의 W 만 냅니다.

6. SE 값 사다리 정리와 "상한 = 약한 쪽" 철회, 잘 받았습니다. 우리 SE|SE 앵커 0.47 은 합격선이 아닌 경보로 봉인했습니다.
