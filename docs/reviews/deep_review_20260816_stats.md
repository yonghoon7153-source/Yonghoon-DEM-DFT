## §1 [공격 1] 8팔 factorial 통계 — 판정은 살고, SE 기계는 틀렸다

### 1-a. 축별 분산분해 (2³ factorial, a1=z·a2=y·a3=yz·a4=x·a5=xz·a6=xy·a7=xyz)

| | 평균 | iid-SD | range | **y 효과** | z 효과 | x 효과 | 주효과 SS몫 | 잔차SD(4df) |
|---|---|---|---|---|---|---|---|---|
| SBE | 0.072651 | 0.574 % | 1.82 % | **−0.774 % (SS 51.9 %)** | +0.451 % (17.6 %) | +0.114 % (1.1 %) | 70.7 % | 0.412 % |
| DBE | 0.073835 | 0.539 % | 1.75 % | **−0.670 % (SS 44.3 %)** | +0.298 % (8.7 %) | +0.217 % (4.6 %) | 57.6 % | 0.464 % |
| 쌍별 비 | 1.016296 | 0.156 % | 0.419 % | +0.104 % (12.7 %) | −0.152 % (27.3 %) | +0.104 % (12.7 %) | 52.6 % | 0.142 % |

- **팔은 iid 가 아니다.**  y-이동 하나가 팔 분산의 절반을 지고, 같은 부호·같은 크기로
  **두 침대에서 독립 재현**된다 (SBE↔DBE 팔값 상관 **r = 0.963**).  솔버 잡음이면 두
  독립 솔브가 이렇게 정렬할 수 없다 — 위상 효과는 **결정론적 공통모드**다.
  (축 라벨 a1=z 등은 의뢰문 제공 — 라벨이 틀려도 "한 축 지배·공통모드" 결론은 순열 불변.)
- prereg v2 §4(`docs/reviews/sdcp_gain_prereg_v2_20260816.md:74`)의 "정규표본 8개
  range ≈ 2.85σ" 는 **iid 전제**다.  주효과가 지배하면 range 는 잔차가 아니라 효과 크기를
  재고, σ 추정은 잔차 대비 **과대**해진다 (관측: iid-SD 0.574 % vs 잔차 0.412 %).

### 1-b. 어긋남의 크기와 방향 — 셋 다 보수(保守)였다

1. **팔 σ 과대**: prereg §4 는 RVE 폭 4.66 %(`docs/data/sdcp8_v04.json`
   `origin_spread_point_pct`)에서 σ≈1.64 % 를 유도했는데, 실침대 실측은 SBE 0.57 % ·
   DBE 0.54 % (range/2.85 로도 0.64/0.61 %) — **2.9배 과대**한 가정이었다.
2. **비-SE 과대**: 판정기 `scripts/sdcp_gain_verdict.py:108` 은
   `hypot(se_SBE/μ, se_DBE/μ)` = **비대응(unpaired) 전파** = 0.278 %p.  그러나 팔이
   쌍(같은 origin)이고 공통모드 r=0.963 이므로 정직한 SE 는 **쌍별 비의 SD/√8 =
   0.055 %p** — 판정기 값이 **5.1배 과대**다.
3. **게이트 1.17 %p** (= 판별간격 3.5 %p / 3, `sdcp_gain_verdict.py:33`) 는 위 두 과대
   추정으로도 통과됐다 (0.278 < 1.17).  즉 기계가 틀렸지만 **틀린 방향이 전부 판정을
   어렵게 하는 쪽**이었다 — 운이 아니라 구조다: iid 가정도 unpaired 전파도 분산을 키운다.

### 1-c. h1 판정의 생존 검사 (h0: 비 ≥ 1.05 / h1: ≤ 1.025)

- **쌍별 비 8값 전부** [1.01408, 1.01834] — **최댓값조차 h1 상한 1.025 아래**.  SE 를
  어떻게 잡아도 (iid·쌍별·주효과-잔차·유효 df=2 의 t임계 4.30) 결론이 안 바뀐다.
- 지배축으로 팔을 2군 평균으로 붕괴시켜도 (극단적 유효표본 n=2):
  x {1.01577, 1.01682} · y {1.01577, 1.01682} · z {1.01552, 1.01707} — 전부 < 1.025.
- 쌍별 SE 기준 h0 경계와의 거리 **60.3σ**.
⇒ **사전등록 판정 h1(비 1.0163)은 정직한 SE 에서 생존한다.  CL-33 의 판정 자체는 유지.**

### 1-d. 원장 반영 권고

- CL-33 의 "비의 표준오차 0.28 %p" 는 "**비대응 상한**; 쌍별 SE 0.055 %p" 로 주석할 것.
- prereg §4 의 SE 기계(iid + range/2.85 + ×√2)는 **차기 prereg 에서 교체**: 팔은 쌍으로
  묶고, 게이트는 쌍별 비의 SD 로.  균형 factorial 은 주효과·2원 교호를 평균에서 정확히
  상쇄하므로(설계의 덕) **origin 16 증설은 불필요**해질 가능성이 크다 — §5-2 의 적응
  규칙("SE > 1.17 → 16으로")이 발동할 일이 쌍별 기준으로는 사실상 없다.
- F5: 위상 잡음이 결정론적 공통모드라는 사실 자체가 정보다 — 비교 런은 **같은 origin
  쌍**으로만 묶으면 팔당 정보량이 크게 오른다 (이미 그렇게 하고 있었고, 판정기만 몰랐다).

## §3 [공격 3] CL-30/31 교차-침대 추론 — "방향 시사" 인용의 5조건

대상 문장 (CL-30 verdict, `docs/reviews/claims.json:1146`; `review_request_20260816.md:49-51`):
"같은 0.3→0.25 에서 AM+SE RVE 는 +1.7 %, 실침대 SBE σ_ion 은 +27.0 % ⇒ 첨가제(또는
MPM 침대 기하)가 지배".

**공유되는 것**: 솔버(`solve_sigma_z`)·BC·vox 쌍·sid 규약.  **다른 것**: ① 기하 —
미변형 해석적 구 vs post-MPM 압밀 침대 (neck·ligament 의 자체 해상도 민감성은 미측정,
CDX-R2-03 = CL-30 hold 사유), ② 첨가제 유무, ③ φ·조성, ④ origin 프로토콜 — RVE 는
**crop 이 움직인** 4팔 평균(CDX-R2-01 결함 포함), 실침대 +27.0 % 는 **단일 origin**.

**수치 정직성 문제 하나 추가**: RVE 증분 +1.69 % (Ø/dx 3.3→4.0 구간; 0.3→0.25 대응)는
같은 데이터의 **origin 폭 2.44–5.78 %** 이내다 — 증분이 자기 잡음보다 작다.  "+1.7 %"
점값 인용은 부당하고 "**|증분| ≲ 3 % (origin 폭 이내)**" 로만 쓸 수 있다.  반면 실침대
+27.0 % 는 단일 origin 의 최대 위상 잡음(~5.8 %)의 4.7배라 방향은 견고하다.

**인용 조건 (전부 충족 시 "방향 시사" 로만)**:
1. 교차-침대임을 문장 안에 명시 (침대 정체: 20 µm 미변형 해석적 RVE vs 실침대 SBE).
2. RVE 증분은 origin 폭과 병기 ("≲3 %, 폭 이내") — 점값 +1.7 % 단독 인용 금지.
3. 귀속은 **양자택일 그대로**: "첨가제 **또는** post-MPM SE 기하" — 첨가제 단독 귀속
   금지 (판별은 GPU ②상별 부피 원장 + post-MPM 기하 RVE 가 한다).
4. 정량(예: "16배") 인용 금지 — GPU ①(실침대 0.25 origin 앙상블)·② 전까지.
5. CL-31 을 보조 근거로 쓸 때 두 한계 병기: SDCP 배치가 합성 균일 랜덤(`seed_sdcp` 아님)
   · 미변형 침대.  (CL-31 의 crop-고정 8팔 수치는 리포 데이터와 일치함을 확인:
   `docs/data/sdcp8_v04/v03/v025.json` 의 구 6.11/5.12/5.53 % vs 점 26.08/9.84/6.06 %,
   `vol_sphere_over_true` 0.987–1.001.  hold 유지가 옳다.)

이 조건이면 현재 CL-30 verdict 의 "⚠ 시사점" 문단은 사실상 합격선이다 — 위반은 조건 2
(점값 +1.7 %)와, 요약문들이 "또는 MPM 침대 기하" 를 빠뜨리는 경향뿐이다.

## §4 [공격 4] "5배 안정" — 성급 판정 확정 (F1, HIGH)

CL-34(`docs/reviews/claims.json:1239`) 와 커밋 `fb77dc76` 메시지의 문장 "origin 폭

- **0.34 %** = 구 스탬프 **비(DBE/SBE)** 의 4팔 폭.
- **1.8 %** = 점 스탬프 **팔값(σ_e)** 의 8팔 폭 (CL-33 의 SBE 1.84/DBE 1.77 %).
⇒ **비-폭을 팔-폭과 나눈 범주 오류다.**  같은 통계량끼리 재면:

| 비교 축 | 구 스탬프 | 점 스탬프 | 배율 |
|---|---|---|---|
| **비 폭, 같은 4팔(a0–a3)** | 0.344 % | 0.248 % | 구가 **1.38배 더 넓다** |
| 비 폭, 점은 8팔 전부 | 0.344 % (4팔) | 0.419 % (8팔) | 1.2배 (5배 아님) |
| 팔 폭 (DBE) | 1.677 % (4팔) | 1.749 % (a0–a3) | **동일** — 팔 수준 위상 잡음 저감 없음 |

- 게다가 구 비-폭 0.344 % 는 **전부 a3(yz) 한 팔**에서 온다 (앞 3팔 폭 0.009 %, a3 편차
  −0.34 %).  4표본 range 는 CV≈0.42 의 취약 통계량 — 한 팔이 폭 전체를 정한다.
- SBE 팔이 구/점 **완전 동일**(SDCP 없음 = no-op; CL-34 의 SBE 값이 점-스탬프 a0–a3 과
  비트 일치)이므로 비의 변동은 전부 DBE 쪽이라는 의뢰문 지적도 실측으로 확인.
- 이 4팔은 **상 우선순위 결함 포함본**이다 (구 스탬프가 PTFE·SWCNT 를 덮음; 수정은
  `fb77dc76` 의 `scripts/step3_sigma.py` rasterize 재배치로 들어갔으나 "지금 도는 런에
  적용되지 않는다" 라고 커밋 자신이 적었다).  결함 크기 판별(DBE 1팔 재실행)도 미실행.

**판정: "5배 안정" 은 성급을 넘어 현 데이터에서 역방향이다.**  원장 반영:
- CL-34 verdict 의 "유의미한 관측: origin 폭 0.34 % … 5배 안정적" 문장을 **삭제/정정**:
  "같은 축 비교에서 팔-폭은 점과 동일(1.68 vs 1.75 %), 비-폭은 4팔 기준 점(0.25 %)보다
  넓다(0.34 %) — **안정성 이득은 입증되지 않음**.  폭이 a3 한 팔 소산."
- "부피를 제대로 주면 위상 잡음이 준다" 는 방향 주장은 **CL-31 의 격자-간 안정**(구 이득
  5.1–6.1 % @ vox 0.4/0.3/0.25)으로만 말할 것 — 그것은 **격자 축** 안정이지 **origin 축**
  안정이 아니다.  두 축을 섞은 것이 이 오류의 뿌리다.
- CL-34 hold 유지 + 우선순위-수정 DBE 1팔 판별(≈1.5 h)이 +12.6 % 인용의 선행 조건.
