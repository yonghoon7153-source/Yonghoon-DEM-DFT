## 합성 데이터로 학습한 모델이 작은 표 데이터에서 GBDT를 앞선다

> 합성 데이터셋으로 사전학습한 TabPFN은 경사하강 없이 한 번의 forward pass로 소규모 표 데이터에서 튜닝된 GBDT를 능가한다. (L7–9)

### 요점

1. 약 1억 개의 합성 데이터셋으로 트랜스포머를 사전학습해, 훈련 데이터와 테스트 입력을 통째로 받아 예측분포를 내는 TabPFN을 만들었다. (L12–15)
2. 10,000행·500특징 이하의 분류·회귀 벤치마크에서 기본값 TabPFN이 4시간 튜닝한 CatBoost·XGBoost보다 높은 점수를 몇 초 만에 냈다. (L8–9 · 21–24)
3. 원문은 검증 범위가 소규모 데이터에 한정되고, 외삽에 취약하며, 해석가능성 보장이 없다고 적었다. (L32–33)

### 문제와 접근

소규모 표 데이터 예측은 그동안 경사 부스팅 결정트리(GBDT)를 오래 튜닝하는 방식이 주류였다. TabPFN은 이 과정을 데이터셋 하나하나에 대한 학습이 아니라 데이터셋을 푸는 알고리즘 자체의 학습으로 바꾼다. (X_train, y_train, X_test)를 한꺼번에 입력받아 y_test의 분포를 출력하는 트랜스포머다. (L8–9 · 12–13)

사전학습에는 실데이터를 쓰지 않는다. 인과 DAG에 랜덤 신경망·트리 매핑과 노이즈, 결측, 이상치, 범주형 변수를 주입해 만든 약 1억 개의 합성 데이터셋을 쓴다. 원문은 이를 베이지안 사후예측의 근사로 해석한다. (L14–15)

### 구조와 비용

아키텍처는 특징 방향과 샘플 방향 어텐션을 엮은 2D 어텐션을 12층 쌓아 표의 행과 열 구조를 직접 다룬다. 회귀 출력은 점 추정이 아니라 구간별 상수(Riemann) 형태의 전체 예측분포이며 다봉 분포도 표현한다. 이중슬릿 광강도 분포 재현 데모에서 1.2s가 걸렸고, CatBoost로 분위수를 조립하면 169.3s가 걸렸다. (L16–18)

사전학습은 8×RTX2080Ti로 2주 동안 한 번만 한다. 사용 단계에서는 소비자 GPU 1장이나 CPU로 충분하다고 원문은 적었다. (L19)

### 벤치마크 결과

AutoML Benchmark와 OpenML-CTR23의 분류 29개, 회귀 28개 데이터셋에서 기본값 TabPFN이 튜닝한 GBDT보다 앞섰다. 분류의 normalized ROC AUC는 0.939로 기본값 CatBoost의 0.752보다 높았고, 4시간 튜닝 앙상블보다도 우위였다. 회귀의 normalized −RMSE는 0.923으로 기본값 CatBoost의 0.872보다 높았다. (L21–24)

속도 차이도 컸다. 원문은 분류에서 5,140×, 회귀에서 3,000×의 스피드업을 보고했다. 자체 앙상블 버전(PHE)은 ROC AUC 0.971로 4시간 돌린 AutoGluon의 0.914를 넘었고, 트리 모델 우위로 알려진 벤치마크에서도 모든 베이스라인을 능가했다. (L23–24 · 27–28)

### 강건성과 부가기능

TabPFN은 무정보 특징과 이상치에 둔감했다. 같은 조건에서 MLP는 성능이 무너졌다. 행을 절반만 써도 전체 행을 쓴 CatBoost의 성능을 재현했고, 결측, 범주형, 행·열 수로 나눈 서브그룹 전부에서 우위를 유지했다. (L25–26)

예측 외에도 fine-tuning, 데이터 생성을 통한 증강, 밀도추정을 이용한 이상탐지, 재사용 가능한 임베딩을 지원한다. (L29)

### 어디까지 믿나

원문이 밝힌 검증 범위는 10,000행·500특징 이하이며 대용량 데이터는 범위 밖이다. 훈련 범위 밖으로의 외삽은 여전히 취약하다고 적었다. (L32)

모델은 블랙박스여서 물리식처럼 해석가능성이나 단조성을 보장하지 않는다. 특징중요도는 permutation 같은 사후 방법으로만 얻는다. 파라미터에 데이터가 저장되지 않으므로 추론할 때마다 훈련 데이터를 컨텍스트로 함께 넣어야 한다. (L33–34)

### 용어 풀이 (논문에 없는 일반 설명)

- **in-context learning (ICL)**: 모델 가중치를 갱신하지 않고 입력으로 주어진 예시들만 보고 새 입력에 대한 예측을 내는 방식이다.
- **GBDT**: 약한 결정트리를 잔차 방향으로 차례로 더해 가는 경사 부스팅 결정트리 모델로, CatBoost와 XGBoost가 대표적이다.
- **Prior-data Fitted Network (PFN)**: 사전분포에서 뽑은 합성 데이터셋으로 학습해 베이지안 사후예측을 근사하도록 만든 신경망이다.

### 우리 연구에 주는 뜻

- 우리 코퍼스는 n=88–132 케이스에 특징 수십 개 규모라 TabPFN이 강한 영역에 들고, 현행 GPR/RF predictor를 튜닝 없이 대체하거나 보완할 후보다. (L37–39)
- 우리 물리 스케일링 법칙을 대체하지는 않고, 신규 타깃의 빠른 베이스라인, 물리식이 놓친 잔차 신호 탐색, 대량 설계 스크리닝에 쓴다. (L40–42)
- 5-phase Phase 3 서로게이트, STEP4 곡선 스칼라 서로게이트, R_int Phase 3, active learning 획득함수용 분포에 적용하되 생성기능으로 만든 합성 케이스는 학습보조로만 쓴다. (L43–46)

### 읽을 때 조심할 것

- 검증은 10,000행·500특징 이하에서만 이루어졌으므로 더 큰 데이터에는 결과를 그대로 옮길 수 없다. (L32)
- 훈련 범위 밖으로의 외삽은 여전히 취약하다고 원문은 적었다. (L32)
- 해석가능성과 단조성 보장이 없어 물리적 해석이 필요한 자리에는 사후 특징중요도로만 보완해야 한다. (L33)
- 추론마다 훈련 데이터를 컨텍스트로 넣어야 하므로 학습된 모델만 따로 배포해 쓸 수는 없다. (L34)
