S1은 실측 SOP, 주 관측량, 판독 구간/방법, 실패·결측 규칙, 시작 담당/시각, 원자료 비공개/열람 절차를 **실측 시작 전** 고정하고 그 판과 비준을 기록하는 단계다. 본 초안의 문서 날짜만으로 S1을 완료했다고 표시하지 않는다. T2 평균각·최대각·최소각이나 T3 정지의 처리 방식을 결과를 보고 바꾸지 않는다. 정지를 임의의 긴 흐름 시간으로 치환하지 않는다.

S3에 속하는 Bo 격자·역할별 실제 시드·반복·불확도 모형/폭·자유도·날 효과·검증 비교 규칙·확장 규칙·예산은 이 문서에서 등록하지 않는다. S1의 실측 규칙을 이후 S3에서 측정 결과에 맞춰 바꾸지 않는다. S3의 DEM 선택은 실측값 비공개 조건에서 정한다.

## 3. 보정·검증 원자료의 분리와 열람 순서

| 순서 | 준비·기록할 내용 | 열람 경계 |
|---|---|---|
| 측정 전 S1 | 보정 자료(T1·보정용 T2)와 검증 자료(T3·검증용 T2 등)의 열람 단위, 담당·권한·예외 규칙을 고정 | 보정 접근 권한으로 검증 평문까지 열 수 있는 구조는 허용하지 않음 |
| 측정·보관 | 보관자가 원자료와 백업을 보존하고 단위별 암호문 SHA 또는 동등한 무결성 기록, SOP 판, 시작/종료 시각, 보관 위치와 권한자를 기록 | 분리 암호화/키 또는 동등한 접근 통제의 구체 방식은 미정; 외부 보관·전송 권한은 별도 |
| C1 열람 전 | 필요한 B×시험의 곡선·관측 정의·적격성·불확도·판독기/데이터/등록 SHA를 봉인. 실패·결측 점과 이유도 함께 봉인 | 보정 원자료를 분석자에게 공개하기 전 완료해야 함 |
| C1 열람·판정 | 보정 키/권한 전달·실제 열람 시점과 사람을 기록하고 등록된 유한 후보 교집합 S 계산 | 결과를 본 뒤 후보 추가·문턱 이동·마찰 재맞춤 금지. 사전등록된 한 번 확장만 별도 표지로 처리 |
| C2 단위별 열람 전 | S의 모든 후보에 대한 해당 검증 단위의 예측을 봉인 | 각 검증 단위의 키/권한은 그 단위 예측 봉인 뒤에만 전달 |
| C2 열람·판정 | 단위별 열람 기록과 후보×필수 항목의 판정·미평가 이유 보존 | 계산 완료와 실측 양립을 구분. 검증 결과로 보정 집합 S를 줄여 다시 맞추지 않음 |

단위별 계산·봉인은 순차적으로 할 수 있으나, 먼저 열람한 단위 결과에 맞춰 후속 단위의 예측 생성·판독/제외·재시도 규칙을 바꾸면 기존 무맞춤 검증으로 집계하지 않고 변경 이력과 새 분석 지위를 별도로 기록한다.

원본 하나에 보정·검증 내용이 섞였으면 S1에서 누설 없이 분리할 방법을 정하거나 해당 검증을 비맹검으로 분류한다. 평문을 분석자에게 넘긴 후 “SHA만 확인했다”고 기록하지 않는다. 측정자와 분석자가 같거나 이미 결과를 알고 있다면 맹검이라고 부르지 않는다. 그래프·요약값·구두 전달 등으로 먼저 알게 된 경우도 열람 단위·사람·시점·범위를 기록하고 확인적 분석 지위를 재판단한다. 이 초안은 이미 본 데이터를 다시 봉인해 맹검으로 복원하는 절차를 제안하지 않는다.

봉인·열람 기록에는 문서/코드 판, 자료 단위의 식별자, 무결성 값, 보관·권한 담당, 봉인/전달/열람 시점과 예외를 남긴다. 구체 식별자·파일 위치는 미정이다. SHA와 시각은 기록 순서·무결성을 뒷받침할 뿐, 사람이 값을 몰랐다는 사실을 증명하지 않는다.

## 4. 실패·결측과 보고 한정

- 기술 실패·관측 정의 불가·미지원 계약·결측은 이유와 원자료를 보존한다. 실패한 Bo 점을 삭제하거나 그 점을 건너 연속 곡선처럼 연결하지 않는다. 정의 불가와 유효하지만 평탄한 응답(`INSENSITIVE`)을 구별한다.
- 후보별 필수 검증 항목에 미평가가 하나라도 있으면 후보 요약은 `unassessed`이며, 이미 확인한 불일치도 원 표에 남긴다. 예산 때문에 일부 후보만 검증하면 미검증 후보를 감추지 않는다.
- S가 비면 해당 유한 격자 안에서 후보를 찾지 못한 결과이고 검증 성공이 아니다. `all-compatible`도 등록한 항목·조건 안의 양립이며 물리 타당성·응용·실행 GO가 아니다.
- 공급된 관측의 `eligible`과 불확도 구조, 파일 해시 대조는 원자료 수치 추출의 정확성이나 통계 방법의 정당성을 인증하지 않는다. 실제 파서·기하·덱·출력 일치 검토는 별도 선행 조건이다.

## 5. 시드·시간·다음 결정

예약 확인 시드 **15485863·86028121·104395301**은 기존 예약의 인용이다. 새 시드 선정이 아니다. C0·C1·C2와 새 확인 블록의 시드 집합을 S3/S6에서 분리하고 실제 manifest의 교집합을 확인해야 한다. 예약 확인 시드와 C0/C1/C2의 교집합은 공집합이어야 하며 발견 시 HOLD한다. D3 내부 C0/C1/C2의 역할 간 중복/짝짓기는 결과 전에 정하며 다른 역할명만으로 독립 표본이라 세지 않는다. reader가 공급된 manifest를 검사해도 역사적 미사용을 인증하지 않는다. 실제 사용 이력은 별도 근거가 필요하다.

현 기하의 처리량·탭·깔때기 비용은 미측정이다. v2의 처리량 가정에 따른 시간 산술을 이번 실측이나 완료 일정으로 옮기지 않는다. 장비·보관·판독 준비, 시드/반복 예산과 C0의 감도·관측 가능성 확인이 선행되어야 하며 이 초안은 기계시간이나 실행 일정을 약속하지 않는다.

다음 결정은 1저자가 장비·시료·측정자·보관자를 정한 뒤 해당 시험의 미정 입력과 S1 절차를 구체화하고 측정 전 동결본을 검토·비준하는 것이다. 시험 코드·C0·S3·실측/DEM 실행 승인과 새 확인 블록 승인은 각각 별도다. 업무 우선순위는 사용자 지시의 **Rint② → DEM → 나머지**이며, 외부 리뷰 발송 순서도 1저자가 정한다. 이번 문서 작성으로 앞선 트랙의 우선순위를 바꾸지 않는다.

## 6. S6 이후 응용 경계 — 별도 피복 계약 참조
