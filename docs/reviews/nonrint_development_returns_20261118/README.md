## F 접촉 법선 방향

두 원판의 물질점 하나씩을 공유 노드 양쪽에 두고 실제 입자→격자 전사를 거쳤다. 원래 `stencil`은 점 좌표에 대한 가중치 미분을 돌려준다. 접촉 단계는 노드 좌표에 대한 질량 기울기를 요구한다. 이전 두 구현에서는 이 부호 변환이 빠졌다. 접근 상대속도 0.04가 그대로 남았고, 분리 상대속도 −0.04가 반올림 오차 수준까지 줄었다. 수정은 두 실무 개발 모듈에서 접촉용 질량 기울기를 모을 때만 부호를 바꾼다. 공급자 함수의 반환 규칙, 압력 목표, CPU 시간, 틈·거리 옵션은 같다. U6 응답은 새 protocol로 식별해 구·신 결과의 혼합을 거부한다.

동일 5시험은 수정 전 5실패 → 수정 후 5/5다(두 구현의 접근·분리 4건 + 구·신 protocol 혼합 1건). U6 기존 시험 9/9, 4원판 커널 9/9. 형상 회귀 14/14는 S를 원래 기준과 바이트 대조하고 F는 형상 코드 이전의 기준 계산기에 같은 노드 방향만 적용해 대조했다. 수정 후 F와 구본 F의 trace가 서로 같다는 근거로 사용하지 않는다.

접촉 방향 오류는 합성 입력에서 확인했다. 49원판의 미도달에 이 오류가 차지한 몫과 수정 후 도달 여부는 미확인이다. 이전 4원판 S/F 2.469의 물리 해석도 보류한다. 새 개발 비교는 같은 조건의 새 핀 한 번으로 구분하며 현장 실행은 1저자 몫이다.

전체 수령 ZIP SHA256은 `2df8663ec26a3d383cacb790ebb01eacce8b9ad96e0ef7d7faeef1cb0deb0fa7`이다. 원 덤프·로그·현장 경로는 1저자 원본에 보존한다.
