- **Q2 1쪽** — (a) *"덱 실행 줄 차이 = SE 반지름 · 시드 · SE 수 · 이름"* (D3 만 v2 덱) 전칭이 성립하는가 (b) SE 영률 두 줄 문구 (*"물성 22 GPa (DFT E_VRH 22.06 · 문헌)"* · *"DEM 유효 입력 1.35 GPa (선행 이종기술 DEM 과 같은 규약)"*) 가 `KG50B-06` 을 담는가 (c) 0.928 µm *"이상화 기준선 (실제 침대의 문턱 아님)"* 문구 (d) 단면 처리 (벽 · 판 선에서 자름 · 끝 덤프 SE 의 벽 겹침 최대 = 반지름의 0.8–0.9 배 관찰) (e) D3 AM 1,482 를 계획 1,481 옆에 그대로 적는 것.
