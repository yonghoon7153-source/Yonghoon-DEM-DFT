# Phase 1k — 축퇴는 **모드→창 층**에 있다. 그리고 그 층은 우리 것이 아니다

**정본은 `mode-observability/results/phase1k/` 의 CSV 다.** 아래 숫자는 사본이며
인용 근거가 아니다. 재현: `python3 mode-observability/phase1k_tilt_decomposition.py`

## 물었던 것

Phase 1j 가 "12° 는 전류와 무관하고 **창 모델의 구조**에서 온다" 까지 좁혔다.
그 구조의 **어느 층**이냐를 물었다. 창 대수로 지은 판은 두 사상의 합성이다:

```
(LLI, LAM_PE, LAM_NE)  --M-->  (α_PE, β_PE, α_NE, β_NE)  --W-->  U_full(x)
```

## ① 먼저 합성이 성립하는지부터 (안 하면 아래가 다 무의미하다)

동작점을 **22p 근방 (0.16, 0.12, 0.12)** 으로 잡았다 — pristine 에서는 모드가 0 이라
`−H` 조건이 없어 `J`·`M` 을 전방차분으로만 만들 수 있고, `W` 는 중심차분이라
**방식이 섞인다.** 첫 시도에서 그 불일치가 그대로 잔차로 나왔다 (0.1838).
22p 는 ±H 가 격자에 다 있어 **셋 다 중심차분**으로 맞출 수 있다.

```
모드 스텝 0.04   ‖J − W·M‖/‖J‖ = 0.13849
모드 스텝 0.02                  = 0.06783      비 2.04  → 1차 수렴
```

`[해석]` 비가 ≈2 이므로 잔차는 **이산화 오차**이고 합성 `J = W·M` 은 성립한다.
격자 간격이 0.02 라 더 줄일 수 없어 **0.068 은 남는다** — 아래 수치를 소수
둘째 자리까지 믿으면 안 되는 이유다.

## ② 실측 — 축퇴는 압도적으로 **M** 쪽이다

| 사상 | 특이값 | 조건수 |
|---|---|---:|
| **M** (모드 → 창) | 3.2988 · 1.2276 · **0.001412** | **2337.0** |
| **W** (창 → 곡선) | 19.04 · 10.56 · 1.704 · 0.6042 | 31.5 |
| **J** (합성·실측) | 24.61 · 6.151 · 0.5103 | 48.2 |

`[해석]` **2000배 대 30배다.** 곡선이 창을 못 보는 것이 아니라, **모드 셋이 창
넷으로 갈 때 이미 거의 한 방향이 죽는다.** `σ_min(M) = 0.0014` 는 최대의
1/2337 이다.

그리고 `M` 의 **넷째 행이 통째로 0** 이다 — `modes_to_params` 가 `β_NE` 를 항상
0 으로 돌려주기 때문이다. 즉 이 사상의 상(image)은 창 4차원 중 **3차원 부분공간**
이고, 그 안에서 다시 거의 2차원으로 눌린다.

## ②′ 그런데 방향은 여기서 못 읽는다 (내가 처음에 틀린 자리)

처음엔 `d = M·(1,1,1)` 을 정규화해 `W` 의 약한 부분공간과의 각을 재려 했다.
**그러면 안 된다:**

```
‖M·(1,1,1)/√3‖ = 0.068626   = σ_min(M) 의 48.6 배
‖M·u_min‖      = 0.004277   = σ_min(M) 의  3.0 배
```

둘 다 `M` 의 null 근처에서 **거의 상쇄돼 사라진다.** 그래서 그 상을 정규화한
방향은 **남은 잔여가 정하는 잡음**이다 — 실제로 `u_min` 과 `(1,1,1)` 은 모드
좌표에서 **1.22°** 인데 그 상은 **82.4°** 떨어져 있다. 두 벡터가 거의 같은데 상이
직교에 가깝다는 것은 물리가 아니라 **0으로 나눈 결과**다.

`[해석]` **이것이 이번 라운드의 실질적 교훈이다.** 근사 null 사상을 통과시킨 뒤
정규화하면 방향 비교가 의미를 잃는다. 처음 판을 그대로 실었으면
"`M·(1,1,1)` 이 약한 쌍과 32.8°" 같은 **숫자처럼 보이는 잡음**을 발표할 뻔했다.

## ③ 각 자체 — 그리고 Phase 1h 의 "띠" 가 더 넓어진다

22p 근방, 중심차분, 무전류 창 대수 판:

```
u_min = [0.56016, 0.58840, 0.58310]      ∠(u_min, (1,1,1)) = **1.22°**
```

Phase 1h 는 **같은 동작점**을 **전방차분 · 시뮬 곡선**으로 **4.61°** 로 쟀다.
판이 둘 다 다르므로(차분 방식 + 곡선 출처) 이 둘을 빼서 하나를 탓하면 안 된다.
다만 **관측된 산포는 넓어진다**:

> Phase 1h 가 "12.04° 는 점이 아니라 **4.61°~21.89°** 의 띠" 라고 정정했는데,
> 여기 1.22° 가 들어오면서 그 띠가 **1.2°~21.9°** 로 넓어진다.

`[해석]` 방어할 수 있는 문장은 여전히 **"이 측정의 분해능 안에서 Lin 의 방향과
같다"** 이고, 그 분해능이 생각보다 나쁘다는 것이 계속 확인된다.

## ④ 반사실 — PE 창 비대칭은 **원인이 아니다**

Phase 1j 가 "PE 는 전극의 65.61 %, NE 는 96.70 %" 라는 비대칭을 쟀고, 그것이 기울기의
원인이라는 가설이 있었다. 평형 OCP 를 더 넓은 가짜 창으로 다시 정규화해 봤다
(⚠ **완방 끝 `y₀` 를 고정하고 뒤로** 넓힌다 — 앞으로 넓히면 `y > 1` 로 표 밖에
나가 보간자가 포화되고, 첫 시도가 그래서 69° 라는 **artifact** 를 냈다):

| PE 창 | ∠(u_min, (1,1,1)) | 조건수 | `u_min` |
|---|---:|---:|---|
| 65.61 % (실제) | **1.22°** | 48.2 | [0.560, 0.588, 0.583] |
| 75 % (가짜) | **1.17°** | 55.6 | [0.561, 0.587, 0.585] |
| 90 % (가짜) | **1.19°** | 56.9 | [0.560, 0.588, 0.583] |

`[해석]` **각이 0.05° 안에서 안 움직인다 — 가설 기각.** 창을 1.4배 넓혀도
null 방향은 그대로다. (조건수는 48 → 57 로 움직이므로 넓히는 것이 **아무** 효과도
없는 건 아니다. null 의 **방향**에 무관할 뿐이다.)

## 판정

1. **창 대수 판의 축퇴는 `M` 층에 있다** (cond 2337 대 31.5).
2. **PE 창 비대칭은 그 방향의 원인이 아니다** (반사실 기각).
3. **근사 null 사상 뒤의 방향 비교는 하면 안 된다** (②′).
4. **각의 산포가 또 넓어졌다** — 1.2°~21.9°.

## ★ 이 판정이 말하지 않는 것 — 그리고 앞선 라운드에 붙는 경고

1. **이 `M` 은 우리 파이프라인의 사상이 아니다.** `modes_to_params()` 는
   `src/fitting.py` 헤더가 **"역함수 — 테스트·진단용, 'paper' 규약"** 이라 못 박은
   함수이고, 그 규약의 합성 격자 평균 |오차| 는 **0.128**(production 이 쓰는
   `"derived"` 는 **0.012**). 게다가 **production 에는 모드→창 사상이 아예 없다** —
   창 좌표를 직접 맞추고 모드는 사후 변환으로 얻는다.
   `[해석]` 그러므로 `cond(M) = 2337` 은 **진단용 허구의 성질**이지 우리 추정기의
   성질이 아니다. "우리 파이프라인이 2337 로 병들었다" 로 읽으면 **틀린다.**

2. **★ 앞선 라운드에 소급되는 경고.** 창 대수로 지은 판은 전부 이 `modes_to_params`
   를 통과한다 — **Phase 1g 의 B·C 판, Phase 1j 의 D 판, 그리고 여기.**
   그 판들의 절대 각도(10.56° · 12.54° · 1.22°)에는 **'paper' 규약의 몫이 섞여
   있고, 그 사실을 1g·1j 는 신고하지 않았다.** 여기서 신고한다.
   **다만 그 판들의 *비교*는 살아남는다** — Phase 1j 의 핵심은 `B → D` 이고
   둘은 **같은 규약, 같은 스텝, reference 만 다른** 짝이라 규약의 몫이 약분된다.
   약해지는 것은 "A(시뮬) → D(대수)" 같은 **층을 건너는** 비교다.

3. **한 동작점·한 화학·잔차 0.068.** ①의 잔차가 남아 있으므로 위 수치를 소수
   둘째 자리까지 인용하면 안 된다.

4. **④ 의 반사실은 다른 셀이다.** 창 폭만 바꾸고 나머지 물리는 그대로 뒀으므로
   "그런 셀이 실재하면 어떨까" 가 아니라 **"이 각이 그 파라미터에 민감한가"** 만
   읽는다. 답은 "민감하지 않다" 이고, 그것이 기각의 근거다.

## 다음

- `"derived"` 규약으로 같은 분해를 다시 — 그러려면 모드→창의 **우역원**을 골라야
  하는데 4 > 3 이라 유일하지 않다. **그 비유일성 자체가 "우리에겐 M 이 없다" 의
  다른 표현**이므로, 고르는 방식을 명시하고 민감도를 보는 형태가 될 것이다.
- 12° 의 남은 후보(음극 제한)를 반사실로 같은 방식으로 찌른다 — NE 창을 줄여 본다.
