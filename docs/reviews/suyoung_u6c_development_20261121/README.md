# 수영 U6(c) 조밀 F 접촉 개발 관측

기준은 `docs/reviews/dem_redesign_direction_20261109/memo_v3_2.md` §4 U5(c)·U6(c)와 `docs/reviews/a5_seal_u6_decision_20261120/suyoung/decision.json`이다. 11-20에 고정한 설정 ①(틈 보정·거리 판정 꺼짐, 마찰계수 0.5)의 첫 F8 계산에서 U6(b) 궤적과 U6(c) 관측을 함께 회수한다. 이 문서 작성 시 현장 실행과 연구 결과는 0건이다.

## 관측 방법

`scripts/suyoung_u6c_dev.py`는 기존 `scripts/suyoung_u6_first_dev.py`와 `scripts/dem_suyoung_sf2d_dev.py`의 SHA256을 확인한다. 자기 전용 모듈 인스턴스에서 지정한 걸음에만 관측 가능한 접촉 투영을 사용한다. 쌍 충격량과 속도 갱신은 고정 재료 모듈의 같은 pair_impulse 함수를 호출한다. 공유장 S, 기존 F12·F16 반환, 연구용 원본 모듈은 그대로 사용한다.

첫 걸음부터 25걸음마다(1, 26, 51, …) 모든 활성 다물체 노드에서 기록한다. 활성은 기존 계산기의 상대 질량 절단 기준, 다물체는 그 노드에 활성 물체 장이 셋 이상인 경우로 정한다. 벽 처리 사이의 입자끼리 접촉 단계만 비교한다. 표본에서 다물체 노드가 없으면 분모 0, 관측되지 않은 극값은 JSON null이다. 조사하지 않은 중간 걸음의 위반 빈도를 외삽하지 않는다.

쌍의 법선은 왼쪽에서 오른쪽 물체로 향한다. 측정 충격량은 실제 풀이에서 반환한 법선·접선 크기와 그때의 접선 방향으로 복원한 **오른쪽 물체에 주어진 벡터**다. 네 순회 동안 같은 노드·쌍에 누적한 뒤, 모든 쌍 처리가 끝난 속도에서 미끄럼을 측정한다. 접촉 에너지는 노드별과 한 표본의 다물체 노드 합계 양쪽을 기록한다. 각운동량은 원래 격자 원점에 대한 공통 노드의 궤도 각운동량이다.

| U5(c) | 이번에 회수하는 개발 관측 | 남는 판정 조건 |
|---|---|---|
| ① 침투 | 최종 상대 법선 접근 속도의 최댓값 | 변형 원판의 실제 경계 간 침투 측정과 판정 규약 |
| ② Coulomb | 쌍별 누적 충격량의 인장 성분·마찰 원뿔 초과, 각 투영에서 접근하지 않는 쌍의 비영 충격량 횟수 | 완결된 쌍의 분리 판정과 크기 반올림 허용폭 |
| ②′ 마찰 방향 | 최종 상대 접선 속도 × 누적 접선 충격량의 양수 개수·최댓값, 미끄럼이 정확히 0이 아닌 쌍의 포화 오차 | 붙음·포화·반올림 허용폭. 숫자상 양수 횟수에는 반올림 오차가 섞일 수 있음 |
| ③ 에너지 | 접촉 전후 운동에너지 증가의 노드별/표본별 최댓값과 양수 노드 수 | 에너지 반올림 허용폭 |
| ④ 선·각운동량 | 노드별 운동량 잔차의 크기 / 모든 쌍의 순 충격량 크기 합, 각운동량은 같은 방식으로 노드 위치에 대한 쌍 모멘트 크기 합 사용. 분모 양수이면 등록한 1% 초과 횟수, 분모 0이면 별도 횟수와 절대 잔차 | 표본 밖의 노드·걸음과 0 분모의 상대 오차 미확정 |
| ⑤ ID·장 순열 | 이번 형식에 전체 궤적의 순열 결과 없음 | 3물체의 여섯 순서를 포함한 순열 실험과 비교 허용폭 |
| ⑥ 두 배 격자 | `trace.csv`로 실제 시각·위치·아래판 응력 회수 | 짝지은 두 해상도의 힘–변위 곡선, 좌표와 분모를 고정한 비교, 5% 기준 |
| ⑦ 신원 | 매 걸음 입력 물질점의 ID 벡터 불변 확인. 고정 풀이의 F 키는 원판 ID와 노드 번호로 구성 | 상류 물질점 소유·장 배정의 독립 대조 |

원 분모는 `steps_seen`, `sampled_steps`, `dense_node_steps`, `dense_pair_steps`, `dense_pair_projections`에 구별해 담는다. `raw` 표지 값은 수학적 0과 직접 비교한 수다. 정한 ④의 1% 초과, 분리로 계산한 개별 투영의 비영 충격량, 고정 물질점 신원 위반은 FAIL을 먼저 부여한다. 그 외에도 필수 규약이나 관측이 빠져 있으면 HOLD다. U6 전체 자격은 false로 남는다. FAIL이면 단계 3과 해당 3D F의 판정을 멈추고 U5/U6 원인을 검토한다. 다른 접촉 설정을 자동 선택하지 않는다.

## 1저자 실행과 반환

WSL CPU 1개, 수치 스레드 1개로 준비한 통합 블록에서 F8을 한 번만 실행한다. 명령은 `python3 -I -B scripts/suyoung_u6c_dev.py --cells 8 --budget 1200 --out F8` 꼴이며 실제 예산과 시간 제한은 배포 블록 값을 따른다. F8 폴더에 U6(b)의 result.json·trace.csv, U6(c)의 u6c_observations.json이 같이 생긴다. 시간 제한 반환은 부분 증거로 남긴다. 진행 중 예외는 관측기가 실제 걸음에 들어갔을 때만 같은 새 폴더에 부분 진단을 남긴다. 프로세스가 외부에서 강제 종료되면 진단이 비어 있을 수 있다. 비어 있는 진단을 성공으로 집계하지 않는다.

합성 검증은 `scripts/test_suyoung_u6c_dev.py`에서 수행한다. 격리된 표본의 실제 쌍 투영·세 걸음 전진에 대해 기록을 켠 경우와 원 계산의 점 위치·속도·변형·판 응력 바이트를 대조한다. 합성 동일성은 전체 조밀 연구 궤적이나 U6 자격을 인증하지 않는다.
