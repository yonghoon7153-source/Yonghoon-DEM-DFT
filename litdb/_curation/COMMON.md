# 한 편 공통 지시 (논문 에이전트에게 주는 덧붙임 · 2026-11-12 · 본 세션 `_top5_common.txt` 의 일반판)

1저자 말 그대로: "아까 준 후보군 논문들이야. 체크하면서 확인하고 논문에이전트 진행하고 잘 크롭핑하고 litdb로 보내줘. 지금 리스트에 있는 논문들은 너가 서치해서 준거니까 너가 한 의도를 확실하게 내용들 뽑고, 추가로도 자세하게 분석해서 정리해놔줘"

- 먼저 `litdb/_curation/CURATOR_BRIEF.md` 를 처음부터 끝까지 읽고 그대로 따른다 · 정독 질문 a–n 의 뜻 = `litdb/_curation/READING_BRIEF.md` 5 절.
- 이 논문은 후보 표 (`litdb/_curation/S8_candidates.md`) 의 한 행이다.  그 행의 '왜' 칸 = **고른 의도** · 근거 칸 = 의도를 적은 카드 (가리킨 카드).
- 카드에 반드시 넣을 절 둘 (CURATOR_BRIEF 의 절들에 더해):
  ① **"고른 의도 대조"** — 의도의 문장마다 원문이 그것을 채우는지 (채움 / 일부 / 없음) 와 원문 위치 (쪽 · 그림 · 표 · 식) · 값 · 측정 조건 (누른 채 / 뺀 뒤 · 압력 · 온도 · 조성 · 진밀도 기준) 을 표로.  의도가 틀렸으면 (원문에 없으면) "없음" 이라고 분명히 적는다 — 지어내지 않는다.  가리킨 카드의 2 차 인용 값이 원문과 같은지도 대조해 적는다 (다르면 그 카드의 줄을 적고 고치지 않는다 — 카드 문제로 보고).
  ② **"자세한 분석 — 우리 계획에 무엇을 주나"** — 정독 지시서의 이름 (단계 0–7 · 후보 D0 · A′-0 · A · A′ · B · C · C′ · M0 · 단위 시험 U0–U6 · 조건 R1–R7) 마다 이 논문이 주는 것 / 못 주는 것 · 우리 랩 기준 (순수 SE 기공률 10–13 % · LPSCl 진밀도 1.64 g/cm³ — 고정 · 판정하지 않는다 · 다른 값은 "랩 표준과 다른 문헌 값") 과 나란히 놓을 숫자 · 우리 DEM (18 배 연화 · E_eff 1.35 GPa · Heckel P_y 138 MPa) · MPM (E 1.53 · σ_y 0.30 · ν 0.49) 과 견줄 자리 · 재료 · 차원 · 조건 차이.
- 크롭: CURATOR_BRIEF 2-1 절대로 — 그림 · 표 전부 + 핵심 식을 식 번호별로 + SI 가 있으면 SI 의 그림 · 표도 · 끝에 모음 그림 (sheet png).
- 정독 출력 = `batch_NN.tsv` · `batch_NN_findings.md` (질문 a–n 절 · 카드 문제 절) → `litdb/_curation/reading/`.
- 숫자는 원문에서만.  그림 판독은 [판독] 표지 + 판독 방법.  SI 값과 본문 값이 다르면 둘 다 적는다.
- 같은 가지에 다른 세션 · 조수가 push 한다 — `litdb/_curation/README.md` 2 절의 push 규칙.
- 답장 = 한국어 12 줄 안 (slug · 커밋 · 줄 수 · 크롭 수 · 핵심 값 · 카드 문제 · 남은 [미확인]) + 끝에 "의도 대조 결과 한 줄 (채움 / 일부 / 없음)".
