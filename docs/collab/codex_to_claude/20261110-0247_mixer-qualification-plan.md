## 2. 권고안 전제

Q-M2-1은 한 설치의 실제 링크·권한·binary/MPI·자원/회수 범위를 고정하는 계획, Q-M2-2는 exact source/environment/승인 묶음과 반박 창 GO·1저자 GO의 결속, Q-M2-3은 런 실패 뒤 담당자의 후속 wave 중단·원 증거 보존·수동 판단이라는 **권고안 전제**다. 믹서 Q2/Q3/Q5는 미승인 그대로이며 발사·배포 기준을 낮추지 않는다.

E0 pilot의 목적·입력·정량 문턱·STOP·회수·확대 칸은 결과 전 빈칸이다. 미수령 값을 default로 채우지 않고 E0 수용을 first8 전체 GO로 확대하지 않는다. 제출 뒤 런 실패의 자동 캠페인 중단 기능이 생겼다고 주장하지 않는다.
