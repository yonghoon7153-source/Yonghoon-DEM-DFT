# 수영 U6(c) ⑥ · 두 배 해상도 5% 판독 규칙

1저자 11-22 지시에 따라 설정 ①의 조밀 가압 경로에서 아래판 힘–변위 곡선을 비교하는 규칙을 고정했다. 근거는 `docs/reviews/dem_redesign_direction_20261109/memo_v3_2.md` §4 U5(c)·U6(c)다. 5%와 지름당 셀 수를 두 배로 하는 조건은 정본을 따른다. 이번에 정한 것은 비교의 분모와 표본이다. 기계 판독 사본은 `docs/reviews/suyoung_u6c_force_rule_20261122/rule.json`이다.

## 분모와 5% 경계

두 팔이 실제로 도달한 같은 판 변위 구간에서 **고운 격자 아래판 응력의 최대 절댓값**을 분모 D로 쓴다. 분자는 그 구간에서 **두 응력 차이의 최대 절댓값** N이다. 20N ≤ D이면 해당 쌍이 5% 이내다. 표시용 반올림 전 값으로 비교하고, 5%와 정확히 같으면 이내로 센다.

두 팔은 같은 아래판 폭과 재료 탄성률을 사용하므로 힘을 폭으로 나눈 응력으로 비교해도 무차원 비는 같다. 한 가지 기준 크기로 곡선 전체의 차이를 나타내며, 초기의 반력이 0인 시각도 표본으로 남는다. 분모가 0이면 비를 정의할 수 없어 보류한다. 분모에 작은 수를 더하거나 압력 상한 1.2 MPa를 대입하지 않는다.

## 표본과 입력

1. 필수 쌍은 F8↔F16, F12↔F24다. 8·12·16·24는 원판 지름당 셀 수다. 설정 ①, 같은 49원판 초기 배열·재료·마찰·판 속도·종료 규칙을 사용한다. 거친 팔과 고운 팔의 순서를 고정한다.
2. 각 팔의 0번째 판 높이에서 현재 높이를 뺀 실제 판 변위 u를 사용한다. 힘 관측은 `bottom_pressure_E` × 10 MPa다. 두 완결 궤적의 공통 구간은 0에서 두 종료 변위 중 작은 쪽까지이며 양끝을 포함한다. 두 팔의 종료 변위와 공통 끝을 별도로 남긴다. 더 길게 진행한 팔의 꼬리는 분자와 분모 양쪽에서 제외한다.
3. 공통 구간에서 양쪽의 **모든 원래 변위 표본의 합집합**을 쓴다. 같은 변위는 한 번 센다. 각 곡선은 인접 원표본 사이에서만 선형 보간한다. 구간 끝이 다른 곡선의 표본 사이에 있어도 같은 방식으로 읽는다. 두 보간 곡선 차이는 두 이웃 표본 사이에서 선형이므로 가장 큰 절대차가 합집합에 나타난다. 평활, 매 25걸음 추출, 특정 충전율 세 점만 선택, 외삽은 하지 않는다.
4. 입력 출처·설정·해상도·trace와 영수증의 해시, 첫 스텝과 마지막 스텝·연속성, 유효 종료와 양의 공통 변위 폭을 확인한다. 잘린 궤적·시간 초과·결측·팔 안에서 중복되거나 역행하는 변위·유한하지 않은 값은 해당 쌍 보류다. 11-21 원본에는 보존된 고정 해시와 직전 판독의 종점 검사를 사용한다. 이후 자료에는 같은 입력 계약과 별도로 고정한 신원이 필요하다.
5. 쌍별 D, N, 비율, 최대차가 처음 나타난 변위, 비교점 수와 5%를 넘은 점 수를 남긴다. 유효한 쌍 하나라도 초과하면 그 초과를 기록한다. 다른 쌍의 결측은 따로 표시하고, 둘 다 유효하고 이내일 때만 두 쌍이 모두 기준을 충족한다고 쓴다. 평균이나 초과 빈도로 하나의 위반을 덮지 않는다.

## 적용 시점과 자격

이 규칙을 커밋한 뒤 11-21 반환에 적용한다. 그 반환의 최대 절대차와 일부 반력은 이미 `docs/reviews/suyoung_u6c_doubling_readback_20261122/README.md`로 공개됐다. 따라서 기존 반환에 대한 백분율은 **사후 개발 판독**이다. 같은 결정적 계산을 다시 돌려도 관측의 선후 관계는 바뀌지 않는다.

이 규칙은 ⑥의 동일 가압 구간 비교에 적용한다. 25걸음 간격의 다물체 노드 표본, 마찰·에너지 반올림 허용폭, 실제 변형 경계 침투, ID 순열, 상류 장 소유 검증은 각 항목의 별도 규약을 따른다. 새 자격 판정에는 노출 전 고정된 입력과 해당 U5(c)·U6(c) 관측이 필요하다. U6(c) 전체와 단계 3은 보류다.
