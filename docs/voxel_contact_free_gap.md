## 0. 한 줄

DEM 접촉망은 접촉마다 **Holm/Maxwell 협착 `R = 1/(2σa)`** 를 직렬로 넣고 그것을 뺀 가지를
코드 주석이 **`CONTACT_FREE — upper bound, ideal contact limit`** 이라 부른다.
**복셀 FV(STEP3)는 그 가지 위에 있다** — 라벨만 안 붙어 있었다.
그리고 그 가지의 크기는 **이미 157 케이스에 계산돼 저장돼 있었다: 중앙값 4.04× / 6.69×.**

## 1. 두 이산화가 계면을 어떻게 다루나

### 1-1. DEM 접촉망 — **있다**

`scripts/network_conductivity.py` §docstring:6-16

```
Each SE-SE (or AM-AM) contact → edge with R = R_bulk + R_constriction (series).
  R_constriction: Maxwell spreading resistance R = 1/(2σa), Holm (1967)

  1. FULL:             R_bulk + R_constriction → σ_full
  2. CONTACT_FREE:     R_constriction = 0      → σ_cf  (upper bound, ideal contact limit)
  3. CONSTRICTION_ONLY: R_bulk = 0             → σ_constr
```

구현 `:398` — Mikic(1974) 유한원통 보정(`psi`)까지 선택 가능하다:

```python
R_constriction = 1.0 / (sigma_rel_contact * k_weight * 2 * a_eff * psi)
```

⇒ **접촉면적 `a` 가 물리로 들어온다** (Hertz `a=√(Rδ)` 또는 Stage-E 소성 면적).

### 1-2. 복셀 FV (STEP3) — **없다**

`scripts/voxel_conductivity.py:162` — 면 결합이 **harmonic mean 하나뿐**이다:

```
SE 셀 ↔ SE 셀   g_face = 2·(σ₁σ₂)/(σ₁+σ₂) = 2·(3.0·3.0)/(3.0+3.0) = 3.0 mS/cm
⇒ 계면 저항 항 = 정확히 0
```

~~먹이는 σ 도 grain-interior 값이다 (`:92` 가 스스로 그렇게 라벨한다)~~ ⛔ 정정 2026-09-25 (SELF-51 · CL-91) — 먹이는 σ 는
**펠릿값**이다 (옛 `:92` 라벨은 틀렸고 철회):

```
SIGMA_GRAIN_S_CM_25C = 3.0e-3 S/cm = Cronau 2021 SI 그림 S2c µC-Li6PS5Cl 펠릿, 적층압 ≥146 MPa
                                     평탄 2.88–3.46 mS/cm (판독) 의 하단 — 입계 포함 펠릿값
```

⇒ 이 문서의 결손 서술은 **복합체 접촉 저항**에 대해서만 선다 — 순수 SE 펠릿 수준의 입계 저항은 입력에 이미 있고, 펠릿의
잔류기공 벌점은 STEP3 의 명시 기공과 부분 이중계상될 수 있다 (반대 방향 · 크기 미상).  *상한* 표현은 그 이중계상이 정량될
때까지 한정어를 붙인다 (⬜ 저자 결정).

⚠ `Cronau(r_SE)` GB 인자 (출처 없는 모델 가정 — SELF-51) 는 **스케일링법칙 스크립트에만** 있고(`nested_cv_sat` 계열) STEP3 경로엔
적용되지 않는다.  게다가 그것은 **입경** 인자(sub-µm 비정질화)라 접촉 협착과 **다른 물건**이고,
생산 `r_SE = 0.5 µm` 에서 값이 **1.00** 이라 적용해도 아무 일도 일어나지 않는다.

⇒ **STEP3 = `CONTACT_FREE` 가지.**

## 2. 크기 — 새 런 없이 이미 저장돼 있었다

`docs/data/case_master.csv` 의 `R_brug_over_full` = `σ_cf / σ_full`.
코드가 인쇄하는 이름이 그대로 **"Contact-free overestimation"** 이다 (`:1116`).

### ⚠ 배수의 정확한 지위

복셀은 기하 협착을 **일부** 해상한다 (Hertz neck `a ≈ 0.3–0.5 µm` vs vox 0.15–0.4 µm ⇒ **1~3 셀**).
따라서 복셀 σ 는 `σ_full` 과 `σ_cf` **사이**이되 `σ_cf` 쪽에 붙어 있다.
⇒ 위 배수는 **상한의 크기**이지 복셀 오차의 정밀 측정이 **아니다**.

## 3. 결손은 **둘**이고 처방이 다르다

```
(1) 기하 협착        부분적으로 있음 · 격자 의존 · 조이면 좋아진다
    step3_sigma.py docstring:15-16
      "sub-voxel constriction NOT modelled — a 1-voxel neck's area is
       quantized to the face area; documented limit"

(2) 본질적 계면 저항   완전 부재 · 격자와 무관 · 조여도 영원히 안 생긴다
    항 자체가 없으므로 h → 0 극한에서도 0 이다.
```

⇒ ★ *"격자를 더 조이면 되지 않나"* 는 **(1) 에만 답이고 (2) 에는 답이 아니다.**

⚠ 그리고 **상대비교도 자동으로 안전하지 않다.**  협착 저항은 SE–SE 접촉의 **수와 면적**의
함수라 조성·압밀에 따라 변한다 — 실제로 `R_brug_over_full` 이 코퍼스에서 **2.3 ~ 13.6× (6배)**
산포한다.  ⇒ 공통모드 상쇄를 **가정하지 말 것**.
(전자축의 플래튼 Mach 편향과 **다른 부류**다: 그쪽은 모든 팔에 같은 크기로 걸리지만
이쪽은 **침대 구조**에 걸린다.)

## 4. 상(phase)별로 — VGCF 는 구제되고 SDCP 는 안 된다

| 상 | 복셀에서 협착이 지워지나 | 보상이 있나 |
|---|---|---|
| **SE** (이온) | 예 | **부분적** — 입력 3.0 은 고적층압 µC **펠릿**값이라 순수 SE 입계 저항은 들어 있다 (옛 *"단결정 grain-interior"* 표기 철회, SELF-51).  복합체 고유 접촉 저항은 없다 — §2 배수 중 얼마가 남는지는 재정량 필요 |
| **VGCF** (전자) | 예 | **있다 (설계상)** — CL-47 읽기 (ii) |
| **SDCP** (전자) | 예 | **없다** — CL-61 |
| **AM** (전자) | 예 | Stage-E 교차보정이 별도 축 (`step3_sigma` docstring:15) |

### 4-1. VGCF 가 구제되는 논거 (CL-47 (ii))

VGCF 에는 **밴드**가 있다 — 압착분말 **83 S/cm** ↔ 단섬유 **1e4 S/cm**, 2자릿수 차이가
**전부 섬유-섬유 접촉저항**이다.  접촉저항을 지우는 융합 복셀에는 **접촉 포함(= 낮은) 끝**을
고르는 것이 정합적이다.  코드값 **100** 은 그 낮은 끝(83)과 같은 자릿수다.
⇒ σ 가 협착 결손을 **lumping** 한다 = DEM `E_eff` 18배 연화와 **같은 인식론**(frame[2]).

### 4-2. SDCP 가 구제되지 않는 이유 (CL-61)

```
· 그런 밴드가 아예 없다 (S-PEDOT 계 접촉-포함/접촉-없는 쌍이 문헌에 없다).
· 원고 [35](Patil 1987)는 3-치환 폴리티오펜 = 계열이 달라 재료 출처가 못 된다.
· 그리고 [35] 가 주는 유일한 값은 **연속 캐스팅 필름** — 즉 VGCF 의 '단섬유' 자리
  (= 접촉저항이 애초에 없는 쪽) — 인데 **그조차 10 S/cm** 다.  우리는 **250** 을 쓴다.
```

⇒ SDCP 에는 **"두 밴드 중 보수적인 쪽을 골랐다"** 를 쓸 수 없다.
**ⓐ 접촉-없는 문헌값의 25배 위** + **ⓑ 복셀 융합이 접촉저항을 또 지움** = **같은 방향으로 겹친다**.

⚠ **값 자체의 지위는 다투지 않는다** — CL-61 대로 `Assumed (specified by the authors, S-PEDOT class)`
이고 사용자가 2026-09-02 에 확인했다 (*"저자가 이걸로 쓰라고 해서 하는 거야"*).
**새로 등재하는 것은 융합이 그 위에 한 겹 더 얹힌다는 사실**이다.

⚠ CL-47 이 이미 경고한 **서사의 부호**가 여기 걸린다: 현행 표에서 SDCP(250)는 VGCF(78.5)보다
3.18배 좋은 도체 → *'고전도 다리'* 서사.  단섬유 기준이면 63배 **나쁜** 도체 →
*'절연 부피(SE·pore)를 도체로 바꾼다'* 서사이고, 그쪽이 **CL-44 의 h1 과 오히려 정합**이다.

### ★ ③ 이 이미 맞는 범위를 덮는다

문헌의 접촉-없는 값 **10 S/cm** 는 `C₂` 축의 범위 **[2.5, 250]** **안에 있다** (= ×1/25).

**"[35] 의 접촉-없는 캐스팅 필름 값"** 이라는 **이름 붙은 점**이다.

### ④ 는 왜 아직 못 하나 — ⚠⚠ **초판의 *"GPU 불요"* 는 틀렸다** (2026-09-08 정정)

측정하려는 것은 맞다: 복셀 FV(협착 없음) ÷ 접촉망(Holm 협착) 의 σ_ion 비가 곧 이 결손의
실측이고, CLAUDE.md frame[4] 가 요구하는 교차검증이 정확히 이 자리다.  `R_brug_over_full`
은 **접촉망 안에서의** 비라 방향과 자릿수만 준다.

무너진 것은 **비용 서술**이다.  리포를 실제로 뒤져 보면 두 이산화가 **같은 침대·같은
첨가제 상태**로 있는 쌍이 **없다**:

```
복셀 σ_ion   있다.  docs/data/ion8_isd10e-03_20260831/ (vox 0.15, 8 origin)
             ⚠ 그러나 SBE(PTFE 1.0) · DBE(PTFE 0.5 + SDCP 0.5) 뿐 — 첨가제 없는 팔이 없다
접촉망 σ_ion  있다.  case_master.csv `sigma_full_mScm` (DEM 코퍼스)
             ⚠ 그러나 DEM 침대는 첨가제 **이전** 상태다
neat_ion.json 은 침대가 아니라 균일 블록 솔버 검증이다 (σ_eff = 3.000000000001)
```

PTFE·SDCP 는 이온 절연이라 (`ionic_sigma_table`: 탄소 3,4 = 0 · PTFE 7 = 0) 부피로 경로를
막는다 ⇒ 첨가제 유무를 섞으면 그 차이가 **협착 결손과 교란**된다.  필요한 것은 둘 중 하나:

- **(a)** 코퍼스에 DEM 케이스가 있는 침대에서 **첨가제 없는 STEP3 σ_ion 팔 1회** — 솔브가
  실제로 든다 (GPU 또는 CPU 시간).
- **(b)** 첨가제 불일치를 리포의 PTFE 이온-차단 스윕(`docs/data/pellet_calib_20260825/
  ptfe_ion_blk*.json`)으로 **경계 지어** 보정 — 선행 확인: 그 스윕이 실침대인지 합성 펠릿인지.

★ **크기 추정(4.04× / 6.69×)은 영향을 안 받는다** — 그것은 접촉망 **안에서의** 비(σ_cf/σ_full)라
첨가제 문제가 안 걸린다.  무너진 것은 *"교차-이산화 대조가 공짜다"* 하나뿐이다.
(정본 = 원장 CL-81 의 같은 날 정정.  이 문단은 그 전파다 — 초판이 그것을 빠뜨려
2026-09-09 전수 감사에서 P0 로 잡혔다.)

⚠ **Phase A 는 영향 없다** (근거): `electronic_sigma_table()` 의 `SE(6) = sigma_se` **기본 0.0**
(*"펠릿 보정 전용 훅 … 기본 0.0 = 생산 불변"*), `sid 9 (SE_blk)` 는 **항상 0**.
⇒ SE–SE 면에 **전자 전류가 흐르지 않으므로** 그 면의 표현 정밀도가 판정에 들어오지 않는다.
