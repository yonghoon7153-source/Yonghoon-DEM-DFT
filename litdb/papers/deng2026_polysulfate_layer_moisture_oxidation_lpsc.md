## 0.5 처음 읽는 사람을 위한 배경 (이 논문이 전제하는 것들)

**1) 황화물 SE 의 두 고질병.** Li₆PS₅Cl(이하 **LPSC**) 같은 황화물은 σ 가 높고(>1 mS/cm) 무르기까지
해서 좋은데, 두 가지가 발목을 잡는다.
- **산화 불안정**: S²⁻ 가 환원력이 강해 고전압 산화물 양극(LCO·NCM)과 닿으면 산화분해된다 →
  전자·이온 절연성 부산물 → 계면 저항 급등 → 용량 급락.
- **수분 민감**: 대기 중 수분과 반응해 **H₂S** 를 뿜고 구조가 깨진다 → 이슬점 −60 °C 이하
  초건조 환경이 필요 → 공정 비용 폭증.

**2) 지금까지의 처방과 그 함정.** 표면에 보호막을 씌우는 게 정석이다(CO₂·HF·LiDFOB·도데칸티올…).
그런데 이 방법들은 **SE 자신이 반응물**이라 표면 PS₄³⁻ 골격이 깨지고 σ 가 크게 떨어진다.
이 논문의 출발점은 이 한 문장이다 — *"Ideally, if the sulfide electrolyte acts only as a **catalyst
or initiator**, rather than a direct reactant … a non-destructive and controllable modification
strategy could be achieved."*

**3) 이 논문의 수(手).** LPSC 표면의 **S²⁻ 를 친핵체(nucleophile)** 로 써서, 고리형 단량체
**DTD**(1,3,2-dioxathiolane 2,2-dioxide = ethylene sulfate, 흔히 리튬전지 전해액 첨가제)의
**개환중합(ring-opening polymerization)** 을 개시시킨다. S²⁻ 는 개시자로 한 번만 쓰이고 소모량이
미미하므로 벌크 구조는 그대로 — 그래서 "non-destructive". 생성물이 **poly(sulfate) = PS** 층이고,
개질된 전해질을 **PS-LPSC** 라 부른다.

**4) 왜 하필 DTD 인가** (본문이 직접 밝힌 두 이유).
① 분자가 대칭이고 중심 S 가 **전자결핍**이라 친핵공격에 개환이 잘 된다.
② 생성된 poly(sulfate) 자체가 **내산화성**이 강해 고전압 차단막으로 쓸 만하다.

**5) 용매가 이 논문의 숨은 주인공이다.** DTD 를 녹이면서 LPSC 를 안 깨는 용매가 필요하다.
- 극성(DME·PC·NMP): DTD 는 잘 녹이지만 **PS₄³⁻ 의 P–S 결합을 깬다** → 탈락.
- 비극성(톨루엔·자일렌): LPSC 와는 잘 지내지만 **DTD 가 안 녹는다** → 탈락.
- **IBB(isobutyl isobutyrate, 이소부티르산 이소부틸)**: 중간 극성이라 DTD 를 녹이고,
  **isobutyl 기의 입체장애**가 에스터기를 가려 SE 와의 부반응을 막는다 → 채택.
  ⇒ 우리 언어로 옮기면 **"용매 선택 = 반응성-용해도 사이의 좁은 창을 뚫는 문제"** 다.

**6) 읽는 순서 제안.** 이 논문은 사실상 **그림 두 장**이다.
`Fig. 3` (수분 + 산화 + DFT 를 한 판에 몰아넣은 판넬 8개) 과 `Fig. 6` (사이클 후 계면화학).
`Fig. 4`·`Fig. 5` 는 성능 자랑이고, `Fig. 1`·`Fig. 2` 는 "막이 진짜 있다"는 증명이다.
**계산 하는 사람이 볼 것은 `Fig. 3f` 딱 하나**이고, 그 근거는 SI 4쪽의 `Computational details`
**한 문단(11줄)** 이 전부다 — 즉 이 논문은 **DFT 논문이 아니다**(§11).

## 1. 한 줄 요약

LPSC 표면의 **S²⁻ 를 개시자로 써서** DTD 를 그 자리에서 개환중합시켜 **비파괴적으로 ~10 nm
poly(sulfate) 층**을 입히면, **σ 는 4.64 → 4.32 mS/cm (93 % 유지)** 로 거의 안 깎이면서
**13 % RH 4 h 노출 후 σ 유지율이 0.5 %(무처리) → 35 %** 로 올라가고, 전자전도도가
**5.69×10⁻⁹ → 7.84×10⁻¹⁰ S/cm (7.3× ↓)** 로 떨어져 NCM955 계면의 산화분해(S⁰·Li₂SO₄·P₂Sₓ 생성)가
XPS·DRT 로 관측되지 않을 만큼 억제되고, 결과적으로 **RT 10 C 36,000 사이클 70.0 % 유지**·
**60 °C 50 C 20,000 사이클 62.4 % 유지** 를 낸다.
⚠ 단 이 헤드라인들은 **양극 로딩 0.93–2.3 mg/cm²·스택압 180 MPa** 조건이고,
LSV 로 본 **산화 개시전위는 개질 전후가 거의 같다**(억제된 것은 개시가 아니라 **전류 크기**) — §16.

## 4. 합성·시료 규약 (SI 2–3 pp) — 재현에 필요한 전부

7. **표준 조건 = 0.1 M · 12 h** (§9-A 의 최적화 근거).

## 5. 기구 — S²⁻ 개시 개환중합 (`Fig. 1a` + §"Preparation")

**반응식 (`Fig. 1a` 하단 점선 상자, figure-read)**

```
        O   O                            O   O                        ⎡  O   O           ⎤
         \ //                             \ //                        ⎢   \ //           ⎥
   ┌──O — S — O──┐   + S²⁻  →   ⁻S — S — O — CH₂CH₂ — O⁻   +DTD→   ─⎢ O — S — O — CH₂CH₂⎥─
   │      ‖      │                        ‖                          ⎣      ‖            ⎦ₙ
   └─CH₂—CH₂─────┘                        O                                  O
        DTD                     개환 (친핵공격 → 알콕사이드 말단)         poly(sulfate) = PS
```

- **1단계**: 표면 S²⁻ 가 DTD 의 전자결핍 중심 S 를 친핵공격 → 고리가 열려
  한쪽은 **S–S 결합**, 반대쪽은 **알콕사이드(–O⁻)** 말단.
- **2단계**: 그 알콕사이드가 다음 DTD 를 다시 공격 → **연쇄성장** →
  반복단위 **–[O–SO₂–O–CH₂CH₂]–ₙ**.
- **핵심 주장**: S²⁻ 는 개시자로 **한 번** 쓰이고 사슬은 스스로 자란다 ⇒ SE 소모량이 미미 ⇒ **비파괴**.
- **다중 개시점 → 균일·치밀**: 표면 전체에 S²⁻ 가 깔려 있으니 개시점이 많고, 그래서 막이
  국소적으로 뭉치지 않고 **균일**해진다는 논리 (`Fig. 1a` 오른쪽 도식의 파란 껍질).
- **막의 두 기능**을 `Fig. 1a` 오른쪽 확대도가 그림으로 못박는다 — **H₂O 반사** + **e⁻ 차단**.

**독립 검증 (SI, `Fig. S1–S3`)**: LPSC 대신 **Li₂S**(잘 정의된 S²⁻ 공급원)로 같은 반응 →
GPC 로 중합체 확인(Mw 2,618, PDI 1.49) + IR 로 sulfate ester 확인 + XPS S 2p 로 **표면 PS
(169.1) / PS–Li₂S 계면(162.5) / 벌크 Li₂S(159.9)** 3성분 분해.
⇒ **"S²⁻ 면 된다"는 명제는 검증됐다.** ⚠ 다만 **"LPSC 의 S²⁻ 가 그렇게 했다"는 직접 증거는 아니다**
— LPSC 표면의 Cl⁻·PS₄³⁻ 도 후보이고, 논문은 그 배제를 하지 않는다 (§16-10).

## 6. 개질층이 실재한다는 증거 (`Fig. 1b,c` · `Fig. 2` · `Fig. S6–S10`)

**형태 (`Fig. 1b,c`, figure-read)**
- `Fig. 1b` TEM (200 nm bar): 입자 약 **0.8–1 µm**, 가장자리에 밝은 얇은 띠.
- `Fig. 1c` HRTEM (10 nm bar): 위쪽은 **비정질**, 아래는 뚜렷한 격자 무늬. 그 경계가 점선.
  확대상(1 nm bar)에 **0.182 nm** 격자간격 표시, 본문은 이를 **LPSC (200) 면**으로 배정.
- 대조군 `Fig. S6`(TEM)·`Fig. S7`(HRTEM): 무처리 LPSC 에는 그 비정질 띠가 없다.

> 🔴 **(200) 배정은 격자상수와 안 맞는다.** argyrodite 는 입방 *F*-43*m*, a ≈ 9.85 Å (실험) —
> 우리 comp1 EOS 값 V₀ = 254.16 Å³/f.u. × 4 f.u. 로 환산해도 **a ≈ 10.06 Å (PBE)** 다.
> 어느 쪽이든 **d(200) = a/2 ≈ 0.49 nm** 로, 표시된 **0.182 nm 와 2.7배 차이**다.
> 0.18 nm 대는 (440) ≈ 0.174 nm 나 (511)/(333) ≈ 0.190 nm 근방이다.
> ⇒ **"0.182 nm = (200)" 은 인용 금지.** 비정질 껍질/결정질 코어라는 정성 결론은 그대로 유효하다.

**결합 (`Fig. 2b`, figure-read)** — IR (3200 → 650 cm⁻¹), LPSC(빨강)/PS-LPSC(파랑)/DTD(회색).

**S–O 773 cm⁻¹**. DTD 원료 스펙트럼과 비교해 **고리 특유 밴드가 사라지고 사슬 밴드가 남는** 양상.

**SO⁻·S₂O⁻ 는 큐브 윗면(표면)이 뚜렷하게 밝고**(주황), 아래로 갈수록 어두워진다 = **표면 편재**.

⚠ **본문은 "SO₂⁻" 라 썼는데 그림·SI 는 "S₂O⁻" 다** — 표기 불일치(SI `Fig. S10` 목록이 정본).

## 7. 수분 저항 (`Fig. 3c,d,e` + `Fig. 3f` DFT + `Fig. 3g,h`)

**7-A. 임피던스 (`Fig. 3c` vs `Fig. 3d`, figure-read)**
두 판넬의 **축 범위가 같다(Z′ 0–400 Ω)** 는 점이 이 그림의 설계다.
- `Fig. 3c` LPSC: pristine 은 절편 ≈ 20 Ω 의 깨끗한 블로킹 직선. 0.5 h 만에 절편이 ≈ 45 Ω 로
  밀리고, **1/2/4 h 는 400 Ω 안에 안 들어와 삽입도(0–6000 Ω)로 뺐다** — 거기서 반원이
  **≈ 5,000–6,000 Ω** 까지 자란다.
- `Fig. 3d` PS-LPSC: **4 h 노출까지 전부 400 Ω 안**, 4 h 도 ≈ 250 Ω 대.
⇒ **삽입도가 필요한 쪽과 필요없는 쪽**이라는 시각적 대비가 이 논문 수분 파트의 핵심 그림이다.

**7-B. σ 유지 (`Fig. 3e`)** — §3-B 표. 이중축 막대(왼쪽 log σ, 오른쪽 유지율 %).
무처리는 **0.5 h 만에 15 %** 로 무너지고 1 h 부터는 사실상 절연체. 개질은 **4 h 에도 1.51 mS/cm**.

**7-C. DFT (`Fig. 3f`) — 이 논문 유일의 계산**
- LPSC **(011) 표면 슬랩** 위 H₂O: **E_ads = −0.972 eV** ⇒ *"high hygroscopicity"*.
- **P-DTD 삼량체 분자사슬** 위 H₂O: **E_ads = −0.199 eV** ⇒ *"pronounced hydrophobicity"*.
- figure-read: 오른쪽 축이 "Adsorption energy (eV)" 이고 −0.9 ~ −0.3 구간에 점선 기준선(−0.6),
  두 값이 그 위·아래로 갈린다. **원자 색 범례가 없고**, 흡착 자리(S 위인지 Li 위인지 Cl 위인지)
  표시도 없다.
- 논리: 물이 덜 붙으니 가수분해가 덜 일어난다.
⇒ **§11 에 방법 비판 전부**. 요약하면 **주기 결정 슬랩 vs 고립 삼량체 분자**를 같은 축에 놓았고
**vdW 보정이 없다** — 유기 사슬 쪽 물리흡착이 **구조적으로 과소평가**되는 방향, 즉 **결론에
유리한 쪽으로 치우친 오차**다.

**7-D. 셀 수준 확인 (`Fig. 3g,h`)** — 펠릿을 13 % RH 에 **1 h** 노출한 뒤 조립.
- `Fig. 3g` LPSC: 214.1 → **168.1** mAh/g (**78.5 %**). 방전곡선이 눈에 띄게 짧아지고 분극도 커진다.
- `Fig. 3h` PS-LPSC: 230.5 → **226.4** (**98.2 %**). 두 곡선이 **거의 포개진다**.
⇒ 이 그림이 σ 실험보다 설득력이 큰 이유: **σ 는 회복 가능한 표면수화도 반영하지만, 셀 용량은
비가역 손상만 남는다.**

> ⚠ 이 논문 어디에도 **H₂S 발생량 측정이 없다**. 서론이 수분 문제를 "H₂S 생성"으로 정의해 놓고
> 정작 H₂S 를 재지 않는다. (`taklu2021` 은 1.07 → 0.49 cm³/g 로 쟀다.) 노출 후 **XRD·XPS·Raman 도
> 없다.** ⇒ **"가수분해를 억제한다"는 기구 주장의 실측 근거는 σ 유지율 + DFT 2점이 전부다** (§16-3).

## 8. 산화 안정성 (`Fig. 3a,b` + `Fig. 6`)

**8-A. LSV (`Fig. 3a`) — 이 논문에서 우리에게 제일 중요한 판넬**

§3-F 표가 figure-read 전부다. 정리하면:

| 읽은 것 | 함의 |
|---|---|
| 두 곡선의 **개시전위가 거의 같다** (≈2.85–2.9 vs ≈2.95–3.0 V) | **PS 층은 전기화학 창의 *상한* 을 옮기지 않는다.** 우리 축 언어로 **axis ① (S²⁻-limited onset) 은 불변** |
| 3.43 V 피크가 **210 → 83 µA (2.5×↓)** | 억제된 것은 **전류(=반응 속도·양)**. 우리 **axis ②–④** |
| 4.22 V 이후 LPSC 전류가 **감소** | 부동태화 또는 접근 가능한 LPSC 고갈. **"5 V 에서 LPSC 전류가 더 낮다 = 더 안정" 은 오독** |

## 10. 왜 이 논문이 그럴듯한가 — 논증 흐름 정리

논문의 주장은 **하나의 사슬**로 되어 있고, 각 고리에 서로 다른 실험이 하나씩 붙어 있다.

```
 ① S²⁻ 가 DTD 개환중합을 개시한다
      └ 증거: PS-Li₂S 모델 (GPC Fig S1 · IR Fig S2 · XPS Fig S3)          ← 유일한 기구 검증
 ② 그래서 균일·치밀한 ~10 nm PS 막이 생긴다
      └ 증거: HRTEM Fig 1c · EDS Fig 2a · IR Fig 2b · TOF-SIMS Fig 2c · GPC Fig S9
 ③ 벌크는 안 깨졌다
      └ 증거: XRD Fig S8 · σ 4.64→4.32 (93 %)                              ← "non-destructive"
 ④-a 막이 소수성이라 물이 안 붙는다
      └ 증거: DFT E_ads −0.972 vs −0.199 eV (Fig 3f)                       ← 계산은 여기 한 곳뿐
 ④-b 그래서 수분에 강하다
      └ 증거: σ 유지 Fig 3e · 임피던스 Fig 3c,d · 셀 용량 Fig 3g,h
 ⑤-a 막이 전자절연체라 계면 전자이동이 끊긴다
      └ 증거: σ_e 7.3×↓ (Fig 3b) · LSV 전류↓ (Fig 3a)
 ⑤-b 그래서 산화분해 산물이 안 생긴다
      └ 증거: XPS S⁰/Li₂SO₄/P₂Sₓ 부재 (Fig 6a,b) · SEM S 편석 없음 (Fig 6c,d)
 ⑥ 그런데 Li⁺ 는 통과한다
      └ 증거: CCD 1.0→1.6 (Fig S12) · PS σ 1.18×10⁻² mS/cm (Fig S13) · D_Li 5.3× (Fig S24)
 ⑦ 결과적으로 셀이 오래 간다
      └ 증거: Fig 4g (36,000 cyc) · Fig 5c (20,000 cyc) · Fig S19 (파우치 1,000 cyc)
```

**이 사슬의 강한 고리** = ②③⑤-b (특성분석이 다중이고 서로 독립적이다).
**약한 고리** = ①(모델계 검증뿐) · ④-a(DFT 2점, 방법 문제 있음) · ⑥(LiTFSI 첨가 값).
**논문에 없는 고리** = **①의 LPSC 상 직접 검증**, **H₂S**, **막 피복률/연속성 정량**.

## 11. DFT / 계산 방법 ★ (SI 4쪽 `Computational details` 전문 + 비판)

### 11-A. 논문이 밝힌 것 (11줄이 전부)

| **ecut** | **550 eV** |

| **힘 수렴** | **2×10⁻² eV/Å** |

| **폴리머 모델** | *"a segment of molecular chains (**trimer**)"* — **고립 분자 삼량체** |

### 11-B. 🔴 논문이 **안 밝힌** 것 (재현 불가 목록)

1. **슬랩 크기·원자수·층수·진공두께** — 전부 없음. Γ-only 가 타당한지 판단할 근거 자체가 없다.
2. **표면 종단(termination)** — argyrodite (011) 은 Li-rich / S-rich / Cl-rich 등 여러 종단이
   가능하고 표면E 가 크게 다르다(`qian2026` `Table S2` 는 같은 (011) 에서 **0.48 vs 0.70 J/m²**
   두 종단을 보고한다). Deng 은 어느 것인지 말하지 않는다.
3. **무질서 처리** — argyrodite 의 **4a/4c 자리 S²⁻/Cl⁻ 무질서**와 48h Li 부분점유를 어떻게
   다뤘는지 **한 마디도 없다**. 사실상 **질서 단일배열**로 보인다.
4. **vdW 보정 없음** — D3·TS·optB 등 언급 전무. **순수 PBE**.
5. **흡착 자리 샘플링 없음** — 각 표면에 **구성 1개씩**. 자리 의존성·피복률 의존성 0.
   (대조: `qian2026` 은 5자리 × 2배향 = 10 구성을 훑었다.)
6. **BSSE·영점진동·용매효과** 없음. 0 K 값.
7. **구조 파일·입력 파일 미공개.** 데이터 가용성은 "요청 시".
8. **오차·산포 없음.** 각 값이 **단일 숫자 1개**다.
9. **spin-polarized 라 적었지만** LPSC·유기 사슬·H₂O 는 모두 닫힌껍질계다 — 무해하지만
   방법 서술이 관성적으로 붙은 흔적.

### 11-C. 🔴 이 비교가 **왜 편향되어 있는가** (핵심 비판)

- **비교 대상이 같은 종류가 아니다.** 한쪽은 **주기 경계 결정 슬랩**, 다른 쪽은 **고립 삼량체 분자**.
  실제 PS 막은 사슬이 얽힌 **비정질 고체 표면**이라 H₂O 가 여러 S=O·C–O 와 동시에 수소결합할 수
  있다. 삼량체 하나는 그 협동 결합을 물리적으로 만들 수 없다 ⇒ **|E_ads| 과소평가**.
- **PBE 에는 분산력이 없다.** H₂O–유기 상호작용은 수소결합 + **분산**의 합인데 후자가 통째로
  빠진다 ⇒ **또 과소평가**. 두 편향이 **같은 방향(폴리머를 더 소수성으로 보이게)** 으로 겹친다.
- 반대로 **LPSC 쪽은 이온성 표면**이라 PBE 로도 정전 항이 대부분 잡힌다 ⇒ **−0.972 는 상대적으로
  덜 과소평가**. ⇒ **4.9배 차이는 방법이 만들어 낸 상한(上限)** 이다.
- ⛔ **결론**: *"−0.972 vs −0.199 eV"* 는 **정성적 방향(폴리머가 덜 친수성)** 까지만 인용 가능.
  **배율·절대값 인용 금지.**
- 📎 **선례가 하나 더 있다**: `qian2026` (같은 저널·같은 해·같은 문제) 도 **슬랩·흡착부에 vdW 를
  안 넣었고**, 우리 digest 가 *"비극성 꼬리 −0.077 eV 는 구조적 과소평가"* 라고 적었다.
  ⇒ **황화물 표면-유기 코팅 논문의 DFT 는 vdW 누락이 관행이 되어 있다.** 이건 우리가
  **차별화할 수 있는 지점**이다 (§15-③).

### 11-D. ⛔ 이 논문이 **하지 않은** 계산 (태그 오염 방지)

**AIMD · MD · MLIP · NEB · BVSE · ICOHP/COHP/LOBSTER · DOS/PDOS · ELF · Bader ·
grand-potential ESW · 탄성상수 · EOS · phonon · SQS/enumerate — 전부 없다.**
계산은 **단일점+완화 흡착에너지 2 값**이 전부다.

| **스택압** | 코인 **180 MPa** / 파우치 **2 MPa** | 우리 DEM 축(`comparison_vs_ours_DEM.md`) | **📎 DEM 쪽 앵커** — 180 MPa 는 우리 DEM 압밀 시뮬레이션 상단에 가깝다 |

## 15. ★★ 우리 문제설정과의 관계 — **표면 개질 vs 벌크 도핑** (사용자 요청 절)

우리 캠페인은 **comp1(Li₆PS₅Cl) → modelc(Li₅.₄PS₄.₄Cl₁.₆) → +B₂O₃ → LPSOCl(+O)** 로 이어지는
**벌크 조성 개질**이다. 이 논문은 **벌크를 절대 안 건드리는 것을 셀링 포인트로 삼는** 정반대 축이다.
그래서 이 대비 자체가 정보다.

### ① 두 접근의 정면 대조표

| 축 | **우리 (벌크 도핑: +B₂O₃, +O)** | **이 논문 (표면 개질: PS 층)** |
|---|---|---|
| 무엇을 바꾸나 | **격자 내부** — 음이온 자리에 O/B 도입, 결합·무질서·통로 변화 | **입자 껍질 10 nm** — 격자는 손대지 않음(`Fig. S8` XRD 불변) |
| σ 에 대한 대가 | 도핑은 **통로를 바꾸므로** σ 가 오를 수도 내릴 수도 (설계 변수) | **반드시 내려간다** — 0.1 M 93 % / **0.4 M 69 %** (`Fig. S4b`). 두께가 곧 비용 |
| 산화 onset (axis ①) | ⛔ **S²⁻ 가 pin 해서 거의 안 움직인다** — comp1·modelc **동일 2.256 V**, 도핑 D_plain 도 1.893–2.356 V | **역시 거의 안 움직인다** — LSV 개시 ≈2.9 V 로 개질 전후 동일 (figure-read) |
| 산화 *속도·양* (axis ②–④) | 우리는 **분해 양·산물·계면**으로만 본다 (Cl-rich 는 전자 적게·LiCl 많이) | **σ_e 를 7.3× 낮춰 전자 공급을 끊는다** — 우리 grand-potential 로는 **볼 수 없는 축** |
| 수분 | ⛔ **우리 축에 없다** (가수분해 반응E 계산 0건) | 이 논문의 절반 |
| 계면(양극) | ⛔ 우리는 아직 W_ad 미측정 | XPS·SEM·DRT 로 **전부 실험 관측** |
| 확장성 | 합성 단계에서 조성만 바꾸면 됨 | 용액 공정 1단계 추가 (원심분리·세척·건조) |

### ② 🔑 우리 cascade 스크리닝의 **빈 축 2개**에 이 논문이 붙는다

사용자가 지목한 대로 우리 cascade 도핑 스크리닝은 **σ 축**과 **계면 부착일 W_ad 축**이 비어 있다.
이 논문이 그 두 자리에 무엇을 놓아 주는지 정직하게 적으면:

- **σ 축** — ⚠ **부분적으로만 붙는다.** 이 논문의 σ 는 **실험 펠릿 σ (4.64 / 4.32 mS/cm)** 다.
  우리 축은 **MLIP-MD D(600 K)** 라 **단위도 물리도 다르다**. ⛔ 그대로 이식 금지.
  **붙는 것은 값이 아니라 "허용 손실의 상한"** 이다 —
  이 논문은 **σ 손실 7 % 는 허용, 31 %(0.4 M) 는 성능이 무너진다** 는 실험 경계를 준다.
  ⇒ 우리 cascade 의 σ 게이트를 **"host 대비 D 감소 10 % 이내"** 같은 상대 기준으로 잡을 때
  **외부 근거로 인용 가능**한 유일한 숫자다.
- **W_ad(계면 부착) 축** — ⛔ **직접 값은 없다.** 이 논문은 W_ad 도 표면E 도 계산하지 않는다.
  대신 **계면 저항의 실측 앵커**를 준다: **R_CEI 6.1 → 22.9 Ω (100 사이클, 무처리)** 와
  **2.7 Ω (개질)**. 그리고 **R_Diffusion 이 1사이클째부터 21.7 vs 7.7 Ω** 로 벌어져 있다는
  figure-only 사실은 **"접촉 품질 자체가 다르다"** 는 뜻이라 W_ad 축과 물리적으로 같은 방향이다.
  ⇒ 우리 W_ad 계산이 나오면 **비교 대상은 이 논문이 아니라 `qian2026` 의 γ_SE 표(0.40–0.72 J/m²)**
  다. 이 논문은 **"계면이 나빠지면 셀에서 이렇게 보인다"** 는 관측 사다리로만 쓴다.

### ③ 🔑 우리가 이 논문보다 **잘 할 수 있는 것** (기여 여지)

이 논문의 DFT 는 **11줄·2값**이다. 그 자리를 우리가 제대로 채우면 그 자체가 기여가 된다.

1. **vdW 를 넣는다.** PBE-D3(또는 optB88) 로 H₂O–폴리머 / H₂O–LPSC 를 다시 계산.
   현재 값(−0.199)은 **구조적 과소평가**라 **차이가 줄어들 가능성**이 크다.
2. **비교 대상을 같은 종류로 맞춘다.** 고립 삼량체 대신 **주기적 폴리머 슬랩(또는 비정질 셀)**.
   우리는 이미 **UMA melt-quench 로 비정질 표면을 만드는 파이프라인**이 있다(`adhesion.json` γ_SE).
3. **자리·피복률 샘플링.** `qian2026` 수준(5자리 × 2배향) 이상으로.
4. **무질서를 넣는다.** [Adeli] 중성자 점유율(4a-Cl 0.615 / 4d-Cl 0.834 / Li 48h 0.456) decorate —
   **우리 표준**이고 두 논문 모두 안 한 것이다.
5. **표면 종단 스캔.** (011) 하나가 아니라 저지수 면 × 종단 전수 (pymatgen).
6. ⇒ 이 다섯 개를 합치면 **"황화물 표면의 H₂O 흡착 지도"** 가 되고, 그건 `zhu2020`(벌크 가수분해
   열역학 177종) 과 `qian2026`(표면E) 사이의 **빈 칸**이다.

### ④ ⚠ 우리 +B₂O₃ 결과에 대한 **경고 하나**

이 논문은 **σ_e 를 낮추는 것이 산화 억제의 본체**라고 실측으로 말한다(`Fig. 3b`).
그런데 우리 canonical band gap 은 **+B₂O₃ 에서 1.9671 eV 로 host(2.066)보다 낮다**.
gap 과 σ_e 는 같은 양이 아니지만(gap 은 캐리어 생성의 열역학 문턱, σ_e 는 실제 전도),
**gap 이 좁아지는 방향의 도핑은 σ_e 를 올릴 위험**을 안는다.
⇒ 우리가 "+B₂O₃ 가 산화안정에 좋다"를 주장하려면 **axis 를 명확히 하고**, 가능하면
**결함준위·캐리어 축을 따로 확인**해야 한다. 이 논문은 그 필요성의 **외부 근거**다.
⚠ 단 이건 **우리 쪽 추론**이지 이 논문의 진술이 아니다 — 이 논문은 도핑을 다루지 않는다.

## 16. 주의 / 한계 (over-claim 방지) ★★

> 이 논문은 데이터가 많고 그림이 깨끗하다. 그래서 오히려 **어디까지가 통제된 비교인지**를
> 표시해 두지 않으면 그대로 인용하게 된다. 아래는 **인용 가능성에 영향을 주는 것만** 모았다.

1. 🔴 **헤드라인 수치의 로딩이 극단적으로 낮다.**
   36,000 사이클 → **1.44 mg/cm²**. 60 °C 20,000 사이클 → **≈0.93 mg/cm²**(1 C=0.186 mA/cm² 역산).
   60 °C 율속 → **≈1.15 mg/cm²**. 반면 `Table S1` 의 비교 문헌은 **2.67–12.73 mg/cm²** 다.
   그리고 **`Table S1` 에 자기 로딩이 없다.**
   ⇒ ⛔ **"state-of-the-art" 주장·`Fig. 5d` 우열 인용 금지.** 인용하려면 **반드시 로딩 병기**.
   ✅ 대신 **`Fig. 4f`(14.15 mg/cm²)** 와 **`Fig. S18`(10.8 mg/cm², 60 °C)** 는 실용 로딩이니
   그쪽 값을 쓴다.
2. 🔴 **본문이 인용하는 `Figure S17` 이 SI 에 없다.** SI 13쪽은 캡션 S17(위) → 그래프 → 캡션 S18(아래)
   구조인데, 그 **그래프는 S18 캡션의 내용(10.8 mg/cm² PS-LPSC)** 이다. 즉 **S17 의 그림이 누락**됐다.
   본문은 그 그림을 **"LPSC 의 60 °C ICE 70.3 %" + "2.6–3.4 V 산화분해 평탄부"** 의 근거로 든다.
   ⇒ ⛔ **그 두 값은 근거 그림이 없으므로 인용 금지.** 게다가 2.6–3.4 V 는 셀 하한 2.8 V 보다
   낮아 **기준전극 표기도 의심**된다.
3. 🔴 **H₂S 측정이 없다.** 서론이 수분 문제를 H₂S 로 정의해 놓고 끝까지 안 잰다. 노출 후
   **XRD·XPS·Raman 도 없다.** ⇒ **"가수분해를 억제한다"는 기구 주장의 직접 증거는 0**,
   있는 것은 σ 유지율 + 셀 용량 + DFT 2점이다.
4. ⚠ **수분 시험 조건이 온화하고, 측정 전에 되살린다.**
   ① **13 % RH** (`qian2026` 은 39 %). ② 노출 대상이 **분말이 아니라 냉간압축 펠릿** → 비표면적이
   훨씬 작다. ③ 노출 후 **80 °C 진공 12 h 건조** 후 측정 → **물리흡착 수분은 제거**된다.
   ⇒ 이 시험이 재는 것은 **"비가역 가수분해"** 이지 "습도 중 성능"이 아니다. 방향은 맞지만
   **가혹도는 낮다.**
5. 🔴 **LSV 개시전위는 개질로 안 움직였다** (figure-read ≈2.85–2.9 → ≈2.95–3.0 V).
   그리고 **≈4.6 V 위에서는 PS-LPSC 전류가 더 크다** — 본문은 *"below 4.6 V"* 라고 단서를 달았지만
   **초록·결론은 그 단서 없이 "greatly enhancing oxidation stability"** 라고 쓴다.
   ⇒ ⛔ **"전기화학 창을 넓혔다"는 인용 금지.** ✅ **"산화 전류를 2.5배 억제했다(3.43 V 피크 기준)"**
   또는 **"전자 접근을 차단해 분해 속도를 낮췄다"** 로만 쓴다.
6. 🔴 **PS 층 σ 는 "intrinsic" 이 아니다.** 본문은 *"the **intrinsic** ionic conductivity of the PS
   layer, measured at 1.18 × 10⁻² mS cm⁻¹"* 라 하지만 SI 3–4쪽은 *"a lithium salt (**LiTFSI**) was
   incorporated into the polymer"* 라고 적는다. **실제 PS-LPSC 의 막에는 LiTFSI 가 없다.**
   ⇒ ⛔ **"PS 층이 Li 전도성이다"의 근거로 이 값을 쓰면 안 된다.**
   ⇒ 🔑 **우리 정합성 계산(우리가 한 것, 논문에 없음)**: 두께 10 nm·σ_PS = 1.18×10⁻⁵ S/cm 이면
   접촉 1개당 ASR = t/σ = **8.5×10⁻² Ω·cm²**. 입자 ~1 µm(`Fig. 1b`·`Fig. 2a`) 이면 펠릿 두께 방향으로
   접촉이 **L/d = 10³ 개/mm** 직렬이므로, 코팅이 더하는 저항 ÷ 벌크 저항
   = (t/d)·(σ_LPSC/σ_PS) = (0.01)·(4.64×10⁻³/1.18×10⁻⁵) ≈ **3.9배**.
   즉 **σ 가 1/5 로 떨어져야 하는데 실제로는 7 % 만 떨어졌다.**
   ⇒ **"연속·치밀한 10 nm 막" + "σ 거의 불변" + "σ_PS = 1.18×10⁻² mS/cm" 셋이 동시에 참일 수 없다.**
   가능한 해소: (a) 2 ton 압착에서 막이 **접촉점에서 밀려난다**, (b) 막이 **불연속**이다,
   (c) 실제 계면 전도가 LiTFSI 없는 값보다 훨씬 좋다. 논문은 셋 다 논하지 않는다 (§20-Q1).
7. ⚠ **XPS 성분 배정이 순환논증에 가깝다.** 사이클 후 LPSC 의 신규 피크를 **S⁰ 166.5 / Li₂SO₄ 168.9**

   0.1–0.2 eV 차이** — XPS 분해능으로 구분 불가다. 무엇이 무엇인지는 **"이 시료엔 PS 층이 있다"는
   전제**로 정해진다.

   ⇒ ✅ **인용 가능한 것은 "LPSC 에만 신규 성분이 생기고 PS-LPSC 에는 안 생긴다"는 *변화* 뿐**이고,

## 19. 기술 용어 미니 사전 (이 논문을 읽는 데 필요한 것만)

| 용어 | 뜻 (우리 맥락으로) |
|---|---|
| **DTD** | 1,3,2-dioxathiolane 2,2-dioxide = **ethylene sulfate**, C₂H₄O₄S. 5원자 고리 안에 O–SO₂–O 가 들어간 환상 황산에스터. 액체전해액의 SEI 형성 첨가제로 유명 |
| **poly(sulfate) (PS)** | DTD 가 열려 이어진 사슬 **–[O–SO₂–O–CH₂CH₂]–ₙ**. ⚠ 이 논문의 "PS" 는 **polystyrene 이 아니다**. 또 **PS₄³⁻**(argyrodite 의 티오인산 사면체) 와 약자가 겹치니 문맥으로 구분 |
| **개환중합 (ROP)** | 고리 단량체의 고리를 열어 사슬로 잇는 중합. **개시자 1개가 사슬 1개**를 자라게 한다 → 개시자 소모가 적다 = 이 논문의 "비파괴"의 근거 |
| **친핵체 (nucleophile)** | 전자쌍을 내주며 전자결핍 원자를 공격하는 종. 여기선 표면 **S²⁻** |
| **IBB** | isobutyl isobutyrate. 중간 극성 에스터 용매. **입체장애로 SE 와의 부반응을 막는다**는 것이 선택 이유 |
| **LSV** | 선형주사 전압전류법. 전위를 일정 속도로 올리며 전류를 잰다. SE 의 산화 상한을 보는 표준 기법. ⚠ **개시전위와 피크전위는 다른 양**이고, 카본 함량·주사속도에 값이 크게 흔들린다 |
| **DC polarization** | 전자전도도 측정법. **이온 차단 전극(Al)** 사이에 직류를 걸어 정상상태 전류만 남기면 전자만 흐른다 → I/V 기울기로 σ_e |
| **CCD** | critical current density. Li 대칭셀에서 전류를 계단식으로 올리다가 **전압이 0 으로 붕괴(단락)** 하는 지점. dendrite 내성 지표 |
| **DRT** | distribution of relaxation times. 임피던스를 **등가회로 가정 없이** 이완시간 τ 스펙트럼 γ(τ) 로 분해. 저항은 원래 **∫γ(τ) dlnτ**(면적). τ 가 짧을수록 빠른 과정(계면), 길수록 느린 과정(확산) |
| **CEI** | cathode electrolyte interphase. 양극/전해질 계면에 자라는 반응층 |
| **GITT** | 짧은 전류 펄스 + 긴 이완을 반복해 **각 SOC 에서 D 를 뽑는** 기법 (Weppner–Huggins). ⚠ 유효 접촉면적 S 를 어떻게 잡느냐(여기선 BET)에 값이 **제곱으로** 민감 |
| **TOF-SIMS** | 1차 이온빔으로 표면을 때려 나온 2차 이온을 비행시간으로 질량분석. 스퍼터링과 병행하면 **깊이 프로파일**. 상대비교용 — 절대정량 어려움 |
| **GPC** | gel permeation chromatography. 분자크기별 용출로 **Mn·Mw·PDI** 를 얻는다. **PDI = Mw/Mn**, 1에 가까울수록 사슬 길이가 고르다 |
| **ICE** | initial Coulombic efficiency = 1사이클 방전/충전. 계면 부반응이 많으면 낮아진다 |
| **NCM955** | LiNi₀.₉Co₀.₀₅Mn₀.₀₅O₂. **단결정**(single-crystal) 형태를 썼다 — 다결정 대비 입계 균열이 적다 |
| **LiIn 음극** | Li–In 합금. 전위가 **Li/Li⁺ 대비 +0.62 V** 라 셀 전압창이 그만큼 내려간다 (2.18–3.68 V vs In/LiIn = 2.8–4.3 V vs Li⁺/Li) |
| **HNBR** | 수소화 니트릴 부타디엔 고무. 황화물 ASSB 슬러리 공정의 표준 바인더 중 하나 |
| **E_ads** | 흡착에너지 `E(표면+분자) − E(표면) − E(분자)`. **음수일수록 강하게 붙는다**. ⚠ vdW 보정·자리 샘플링·피복률에 크게 의존 |
| **(011) 면** | Miller 지수. argyrodite 는 입방정이라 (011)=(110) 계열. **같은 면이라도 종단(termination)에 따라 표면E 와 흡착E 가 크게 다르다** |

- **Q4 (누락 그림)** — `Fig. S17` 은 조판 사고인가 아니면 애초에 없는가? 저자 문의 없이는 불명.
  현재로선 **LPSC 의 60 °C 데이터가 논문 전체에 그림으로 존재하지 않는다**.
- **Q5 (압력 의존성)** — 180 MPa 에서 얻은 결과가 **2 MPa 파우치**에서 어디까지 살아남는가?
  파우치는 1,000 사이클 81.26 % 로 코인셀 36,000 사이클과 **자릿수가 다르다**. 코팅의 이점이
  압력에 얼마나 의존하는지는 미측정. (우리 DEM 축의 질문이기도 하다.)
- **Q6 (우리 쪽)** — 우리 **+B₂O₃ 의 좁아진 gap(1.9671 eV)** 이 σ_e 상승을 뜻하는가?
  이 논문이 σ_e 를 산화 억제의 본체로 지목한 이상, 우리도 σ_e/결함준위 축을 열어야 한다 (T2).
