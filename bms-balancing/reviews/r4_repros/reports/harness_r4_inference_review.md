## N1 [P1 후보 · U1 증거 범위] 유한한 plateau 전압에서 Inf가 생겨 빈 표본이 아닌 scale이 원문 설명과 갈린다

위치:

- `FINDINGS.md:921`: 원본은 NaN만, Python은 NaN/±Inf를 제거하지만 “rmse는 1e6 감시값이라 Inf는 안 나옴”이라고 설명.
- `FINDINGS.md:925`: 남은 ≠MATLAB은 빈 표본 가드뿐이라고 일반화.
- `bms_balancing/model.py:353`: `gradient(x)/gradient(v)`.
- `bms_balancing/model.py:405`–`:423`: `_auto_scales`가 raw `rmse_*`를 직접 호출하고 `isfinite`로 거름.
- `bms_balancing/model.py:435`의 유한성/1e6 처리는 이 직접 호출 경로 바깥이다.

### 구성과 실측

새 모델에서 만날 수 있는 수치 영역을 검사하기 위해 다음처럼 **유한하고 연속이며 비감소인** 전압곡선을 사용했다:

```python
V(x, p) = max(0, x - (p[0] - 1.1))
```

101개의 x 격자, 실제 경계 `LB5/UB5`, seed 0의 표본 50개를 사용했다. production `_model_dqdv()`, `rmse_dqdv()`, `_auto_scales()`를 그대로 실행했다. 전압 초반의 평탄부에서 `dV/dQ=0`이므로 역도함수에 Inf가 생긴다. 일부 표본은 평탄부가 없어 정상 유한 RMSE다.

```text
forward의 유한성/비감소성                  True / True
표본                                      50개
raw dQ/dV RMSE                             유한 14개, Inf 36개, NaN 0개
FINDINGS에 적힌 원본의 NaN 제거 후 표본     50개 (비어 있지 않음)
그 원본 설명식의 lower-half mean           Inf
production Python의 dQ/dV scale             0.9985672999510923

같은 정상 유한 parameter의 목적함수:
Python scale 사용                          3.0014347556233583
문서에 적힌 원본 scale 사용                 2.0
Inf parameter를 최종 wrapper로 호출         1e6
```

마지막 줄이 경로 차이를 보여준다. `Objective.__call__()`의 1e6 정책은 작동하지만, scale을 구할 때 호출하는 raw RMSE에는 아직 Inf가 남는다. 그래서 “1e6로 바뀌므로 Inf는 없다”는 문장이 성립하지 않는다. 정상 parameter의 가중합까지 약 3.00 대 2.00으로 바뀌므로 빈 배열 반환값의 형식 차이만도 아니다.

**증거 한계:** 원본 MATLAB을 실행하지 않았다. 비교한 “원본 식”은 §1-13이 직접 제시한 `NaN 제거 → sort → 하위 절반 평균`이다. 따라서 정확한 주장은 “공개 Python 실행 결과가 §1-13의 일반적인 예외 배제 설명과 모순되고, 보고된 원본 알고리즘과 이 입력에서 다르다”다. 실물 192개 비교값이나 이미 측정한 셀 결과가 바뀐다는 주장이 아니다. 원본이 실제로 다른 방어를 갖고 있다면 §1-13의 전사 설명부터 수정해야 한다.

최소 종결 조건: U1의 일치를 **검증된 자료/유한한 RMSE 표본 영역**으로 한정하고 “Inf가 안 나온다”, “빈 표본 가드만 다르다”라는 일반화를 고친다. 새 모델 요구서에는 plateau/작은 `dV/dQ`에서 dQ/dV 정의와 scale 표본의 nonfinite 처리 정책을 명시한다. 자료를 거부할지, 원본과 같은 감시값으로 바꿀지, 다른 도함수 표현을 쓸지는 모델 설계 선택이다. 어떤 선택이든 `n_scale_finite/n_scale_nonfinite`와 해당 행의 상태를 기록해야 해석할 수 있다.

이 발견을 이유로 비공개 원본 전체를 공개하라고 요구하지 않는다. 이미 봉인된 192값의 경험적 일치는 유지할 수 있다. 코드 제공자가 수행한 네 함수 대조도 **사용자 수행 소스 대조 기록**으로 인용할 수 있지만, 이 리뷰가 원본을 독립 재실행했거나 모든 입력의 동치를 증명했다고 부르면 안 된다.

## Q1: 상태당 곡선 하나로 더 할 수 있는 일

“관측 유지, 원인은 후보 가설”로 낮춘 대응은 충분하다. 현재 공개 산출물만으로는 비교 항목/기준 역할/단위/최적해 일치/표 집계를 다시 검증하고, 알려진 정답의 합성곡선으로 해석 규칙이 구분 능력을 갖는지 시험할 수 있다. 이번 검토가 그 예다.

사용자 기계의 실제 곡선 하나씩을 쓸 수 있으면, 추가 계측 없이도 아래 진단은 가능하다. 이는 **새 실행 제안**이며 이번 리뷰에서 수행했다고 주장하지 않는다.

- 같은 좌표·같은 전처리에서 잔차를 SOC별로 보존하고 구간별 편향·경계·전류/온도 기록과의 일치를 조사한다.
- 서로 같은 참조/데이터를 쓰는 제한된 비교 모델(PE 고정/상태별, γ 직접 적합/고정 등)을 비교하고 미사용 SOC 구간의 예측을 평가한다. 인접점 상관 때문에 무작위 점 분할을 독립 검증이라고 부르지 않는다.
- 원본과 재표본/평활 입력을 구분해 도함수·가중치·잔차의 민감도를 재계산한다. “가공 방식에 민감하다”는 것은 확인할 수 있어도 “실제 원인은 그 가공이다”는 추가 증거가 필요하다.
- 직접 half-cell γ 적합으로 특정 함수족이 해당 정렬/문턱에서 곡선을 재현할 수 있는지 시험한다. 그 실패를 곧바로 셀 물성의 원인으로 일반화하지 않는다.

관측 RMSE만으로 잡음과 표현 오차를 유일하게 분해하는 시험은 아니다. 계측 조건·독립 잡음 정보가 없으면 일부 후보는 남는 것이 맞다.

U2의 “간격 균일성 검사”도 같은 구분을 요구한다. `WORKING_STATE.md:92`의 “그 검사로 닫을 수 있다”는 표현은 낮추는 편이 맞다. 일정 간격은 원래 일정 주기의 계측에서도, 재표본에서도 나올 수 있고 평활 여부를 결정하지 않는다. 이는 이미 미결인 U2를 새 발견으로 센 것이 아니라 **계획한 진단의 한계**에 대한 답이다. export 설정/원시 timestamp 등 독립 provenance가 있어야 처리 이력을 확인할 수 있다.
