1. 이온 FULL의 `computed`도 **증서에서 재구성한 반올림 전 q**와 고정 정책을 대조. `q_withheld`라는 자기 신고만 읽지 말 것.

3. 경계 `1.4999999999999998`, `1.5`, `1.5000000000000002`를 구별. 셋 모두 저장 q는 1.5가 될 수 있으나 마지막은 생산자 정책상 보류다. **저장 q에만 `>1.5`를 붙이면 부족하다.**
4. CF/협착-only의 q>1.5 진단이나 별도 열 채널 상한을 이온 FULL 정책으로 일괄 거부하지 말 것.
