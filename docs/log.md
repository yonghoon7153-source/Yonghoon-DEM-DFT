## [2026-08-21] create | 누가 무엇을 했는지 — 이름과 활동 기록
서버를 하나로 모으니 바로 나온 질문이다. 이름 하나를 브라우저에 저장해서 모든
요청에 헤더로 보내고, 저장된 것에 붙인다. 검증하지 않는다 — 이 랩의 질문은
"누가 바꿨어" 이지 "네가 너임을 증명해라" 가 아니다 (ADR 0012).

`created_by`/`updated_by` 와 활동 기록은 라우터가 아니라 SQLAlchemy flush
리스너가 쓴다. 새 엔드포인트는 생기는 순간부터 기록되고, 빠뜨릴 곳이 없다.
리스너가 두 단계인 이유: 무엇이 바뀌었는지는 flush 전에만 읽히고, 새 행의 id 는
flush 후에만 존재한다 — 한 곳에서 다 하려다 모든 "추가" 기록의 id 가 비었다.

기록하지 않는 것도 정했다. 사이클 행(업로드 한 번에 만 개), 파서가 채운 필드
(업로드가 두 사건으로 읽힌다), 같은 값을 다시 저장한 것.

헤더 인코딩에서 하나 걸렸다. HTTP 헤더는 ASCII 만 담아서 한글 이름을 그대로
넣으면 요청이 브라우저를 떠나기도 전에 거절된다. 퍼센트 인코딩해서 보내고
서버가 되돌린다. 이 랩 이름은 대부분 한글이라 이게 빠지면 기능 자체가 없다.

같이: 데이터 폴더가 없을 때 bml 이 마운트된 드라이브 목록과 세 갈래 해결책을
같이 보여 준다. 문서의 예시 경로를 그대로 붙여넣은 경우가 가장 흔한데, 그때는
"드라이브를 꽂으세요" 가 오히려 오답이다.

## [2026-08-21] feat | 시험 조건 입력 — 라이브러리에서 비어 보이던 칸들

`num()` 이 0.2 를 "0.20" 으로 쓰는 것을 두 번째로 만나서 `plain()` 으로 뺐다 —
측정값을 유효숫자로 맞추는 것과 적힌 값을 그대로 보여 주는 것은 다른 일이다.

그것으로, 없으면 curl 로 DoH (WSL 기본 설치에는 dnsutils 가 없다 — IP 로 직접
물으므로 이 기계의 DNS 를 타지 않는다).

**여기서 알아낸 것 하나가 안내를 바꿨다.** 처음에는 이름이 잡히면 "터널은
살아 있습니다" 로 단정하려 했는데, 확인해 보니 `lhr.life` 는 **와일드카드**다:

    $ getent hosts nope-nope-xyz123.lhr.life
    3.234.18.192    dd.localhost.run nope-nope-xyz123.lhr.life

없는 이름도 같은 IP 로 잡힌다. 그러니 DNS 로 알 수 있는 것은 **"이 기계의 DNS 가
막는가" 하나뿐**이고, 터널이 살아 있는지는 알 수 없다. 화면도 딱 거기까지만
말한다 — "공용 DNS 에서는 잡힙니다 → 이 망의 DNS 가 막는 것입니다", 그리고
"이름이 잡히는 것과 터널이 살아 있는 것은 다릅니다" 를 덧붙인다. 뭉뚱그렸으면
죽은 터널을 기다리게 만들었을 것이다 (§0.4). `missing` 은 와일드카드가 아닌
도메인(`trycloudflare.com`)에서만 뜻이 있다.

`url_host()` 로 호스트 추출을 따로 뺐다 (`tunnel_block_layer` 가 쓰던 것을
공용화). 이 값이 그대로 `nslookup`·curl 에 들어가므로 `[A-Za-z0-9.-]` 밖의
글자는 거부한다 — 주소 한 줄로 남의 명령을 실행시키지 않는다. 터널 테스트
37 → 46건.

DoH 응답 파싱은 테스트로 고정했지만 **실제 왕복은 이 개발 컨테이너에서
확인하지 못했다** (프록시가 1.1.1.1 을 403 으로 막는다). 틀렸을 때의 결과가
`unknown` 이라 손해가 없도록 짰다 — 확실한 신호가 있을 때만 단정한다.

## [2026-08-24] fix | systemd 가 WSL 의 .exe 실행을 지운다

잡았다: **없는 것을 화면이 어떻게 말하는가.** 이 세션에서 같은 종류의 사고가
네 번 났고 셋은 앞선 커밋이 "고쳤다" 고 선언한 자리에서 다시 났으므로, 그것이
이 묶음의 실제 위험이다.

중점 여섯: 스케줄로 잘림·브랜치없음을 가르는 판정(CV 는 방향이 unknown 이다),
저장하는 판정과 옛 행의 "이유 미상", 숫자 없는 사이클을 그리는 것이 §3 을
위반하는가, 돋보기의 tolerance 와 setScale 훅 안의 setState, 껍데기 실행기와
터널 판정, 그리고 시험이 구현을 문자열로 베낀 자리.

확인 못 한 것을 앞세웠다 — 돋보기와 첫 열 고정을 **브라우저에서 못 눌러 봤다**
(jsdom 에 레이아웃이 없어 uPlot 이 안 그린다). restart 가 터널을 살려 두는
것도 실측 못 했다 (그 망에서 SSH 터널이 자꾸 끊겨 조건을 못 만들었다).
