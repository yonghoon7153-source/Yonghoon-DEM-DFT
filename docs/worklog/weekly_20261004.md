## ⛔ 슬라이드 · 원고에 쓰면 안 되는 것

  섞인다" 도 안 된다 · 계약 한정어를 떼지 않는다.
- `dev-rot` · `dev-bo` 의 d 를 판정이나 **코팅 효과**로 — 개발 자료 · n = 1 · 사후 선택 · 공동 개입 B · M 음수는 Lacey 척도 밖.  09-28 정지 LH 3 런의 어떤 값도 (미열람).

- 순수 SE Q1 을 "EDGE 로 확정" 으로 — "문턱 바로 위의 EDGE" 다.
- ps45 를 **"전이된다 · transferable"** 로 — PARTIAL (한 침대 예외).  AM_P 4/4 띠 안은 사후 분할이다.
- ps45 공극률을 **"실험과 1 %p 안에서 일치"** 나 COMSOL 대표값으로 — Codex HOLD · 실험 미가공 값 인용 금지 · 7:3 이 가장 낮은 것도 시드 산포보다 큰지 모른다.

## 예상 질문 대응

- *"믹서 본 캠페인 결과는 코팅이 소용없다는 뜻인가?"* — 아니다.  8 바퀴 뒤에는 점착 0 대조까지 모두 거의 다 섞여 (M 0.96–1.00) 이 칸 규모에서 둘을
  가를 해상도가 없다는 뜻이다.  더 이른 바퀴 · 더 작은 규모의 차이는 배제하지 않는다 — 그래서 고점착 확장을 따로 등록해 묻는다.
- *"고점착(dev-bo)에서 큰 차이가 났으니 코팅 효과가 확인된 것 아닌가?"* — 아니다.  개발 자료 (n = 1 · 판정 미사용) 이고, 수준을 앞 결과를 본 뒤에
  정했고 (사후 선택), AM–AM 과 AM–벽을 함께 바꿨고, 시작 상태부터 다르다 (d = 시작 상태 차 + 회전 뒤 차).  M 이 음수인 것도 척도 밖이다.
- *"Codex HOLD 가 계속 나오는데 런은 안 돌리나?"* — 개발 런 (DEV7 · `dev-rot` · `dev-bo`) 은 돌았다.  HOLD 인 것은 **확인 18 런** — 봉인 전 결정이
  남았고, HOLD 는 판정 도구 · 등록이 가상의 나쁜 경우를 못 거른다는 뜻이다.
- *"LHS 표를 ML 에 써도 되나?"* — 계산값 전달은 GO 다.  단 적격성 표지 (HOLD) 를 보존하고, 실제 전극의 물리 타깃 인증으로 읽지 않는다 (Codex §4 · §7).
- *"τ 를 COMSOL 에 어떻게 넣나?"* — `f_ion` 을 Porous Electrode 보정 User defined 칸에 (같은 틀 L_mc · φ_mc).  Tortuosity 칸이면 tau2 — √ 값이 아니다.
  아직 망 재계산 전이라 넘길 값이 없다.
- *"MPM 하중분담은 결론이 났나?"* — 아니다.  f_(a) 팔이 두 번 다 실패해 네 칸 · 순서가 미배정이다.  f = 0 은 과압축 (R1 과 같은 방향) · f_(b) 0.8085 는
  창 안 두께 — 값으로만 적는다.  다음은 A6000 기계 등록이다.
- *"VGCF 를 100 GPa 로 다시 돌렸더니 달라졌나?"* — 순서 판정은 그대로 (ORDER-ROBUST).  같은 짝의 값은 최대 1.5 % · 평균 +0.26 % 바뀌었는데, E 와 dt 가
  같이 바뀐 결과라 둘을 나누지 않았다.
