블록 첫 인자는 `CHECK_ONLY` 또는 `GO_SUYOUNG_36_ONCE`, 둘째는 기존 반환 TAR의 실제 경로다. CHECK_ONLY는 소스·환경·이전 반환과 여섯 trace를 점검한 뒤 끝난다. GO는 점검 뒤 새 작업 위치에서 이전 TAR의 고정 사본을 읽고 두 팔을 계산한다. 원본 스크립트와 서명 대상 자료는 고정 Git blob만 배포한다.
