# DEM 프로토콜 세대 2 T12 접합 구현 인계 (2026-10-24)

사용자 **“계속 진행” · “다 비준이야”**(조정 작업자가 전달한 2026-10-24 KST 맥락)를 반영한다. 비준을 다시 요청하지 않고 승인된 로컬 개발을 계속한다. 이 문서는 기존 소비자의 실제 계약과 다음 구현 범위를 정리한 것이며, **세대 2 생산기·T12 통과·실제 R-a 끝 상태를 만들었다는 주장은 없다.** 외부 검토 결과와 실제 측정·실행 결과의 존재는 사용자 비준과 별개 사실이다.

기준은 DEM 세대 2 요청서 **`962caea2d1857b0e34fe724e38815661936b7183`**, ULPR 소비자 **`8347d32ea678c0174bd77d4c79cfbd7b0591e4a3`**다. 아래 함수·행은 이 핀에만 적용한다. 이후 ULPR 변경은 별도 재대조한다. 정본 계획 `docs/reviews/dem_protocol_gen2_plan_draft_20261014.md` §2-5·2-6·§5 T12·§8–9 및 인계서 §5-5를 읽었다. 원 요청서·리뷰·공유 원장·CLAUDE·봉인 코드를 변경하지 않았다.

## 4. 다음 구현 묶음과 작은 반례

1. **계약 문안**: §3에서 미정인 bed/arm 식별, P2 params·활성 머리 생성, R-a 종료/S0, h₀ 환산과 시간, 재개 상태, 개발 케이스 선택을 결과 전 등록 문안에 채운다. Q1–Q16을 다시 선택하게 하지 않는다. A1–A5 산술/명세 지위는 기존 요청서와 이번 비준 맥락을 별도 기록한다.
2. **시험 먼저**: 새 명세를 읽는 실제 소비 경로에 한 작은 R-a/S0 기록을 연결한다. 합성이라고 명시한다. 긍정 경로와 다음 음성을 수정 전 소비자로 돌려 의도한 거부/실패를 남긴다. 코드 생성·판독·관문을 한 묶음으로 수정하며 P1 원 입력/결과를 보존한다.
3. **필수 작은 반례**: 같은 좌표지만 다른 δmax; 같은 파일명이지만 다른 S0 step; 같은 h₀지만 다른 질량/상 재고; g9.81와9.81e−6의 S3 무게 항; dt/2에서 W를 그대로 둔 절반 시간; `P2` 이름만 붙인 r8 머리; 중단된 새 시도에 남은 옛 단 줄; G2c 1열 결손; 소수/중복/비유한 식별자. 각각 어느 실제 함수·판정에 도달했는지 기록한다.
4. **독립 검토**: 구현 설명 없이 diff·시험·핀을 별도 검토자에게 전달한다. 통과 guard를 제거하는 변이로 관련 시험 실패를 확인하고, 새 수치 보장은 손으로 풀리는 예로 공격한다. 이후 필수 문서/원장 검사·전체 게이트를 실행한다. 이 문서 작업에 대해 수행했다고 기록하지 않는다.
5. **실제 자격 입력 확보**: 지정 빌드의 이력/문법, 실제 서보/R-a, dt/2, 단계별 재개 증거와 Q7–Q9 원자료를 수집한다. 실행 담당자가 현재 유휴 자원과 원자료 경로를 채운 뒤 실제 명령을 만들 수 있다. **현재는 P2 덱/등록/계약이 없으므로 실행 가능한 P2 발사 명령이 없다.** P1 `run_unload.sh` 명령을 P2 발사 지침으로 제시하지 않는다.

로컬 구현은 위 1–4를 진행할 수 있다. 기존 실제 P1 fixture/원자료를 재사용할 때는 적용 빌드·물성·이력·단위가 새 계약에 충분한지 대조하고 범위를 적는다. 주어진 환경에서 물리 실행·기계 배정·스케줄러 조작은 하지 않았다.

## 5. 사실 수집 양식과 확인 범위

`docs/reviews/dem_gen2_t12_readiness_evidence_20261024/factual-input-form.blank.json`은 **빈 작성 양식**이다. null은 이번 작업에 자료가 없다는 뜻이다. `RATIFIED`에 해당하는 사용자 발언과 실제 결과 칸을 분리했다. JSON 형식이 맞거나 모든 칸이 채워져도 T12/외부 GO를 판정하지 않는다. 파일 경로·hash를 나열하는 것만으로 물리·관측 의미를 인증하지 않는다.

이번 확인은 지정 Git blob 12개와 발췌 값의 대조, 문서 참조·금지문구 검사에 한정한다(실행 기록은 동봉 `verification.json`). 새로운 수치 시험·생산기·검사기·런을 작성하지 않았다. J20-l 검색에서 이 **DEM 프로토콜 T12 접합**을 표시하는 기존 웹앱 화면은 찾지 못했다. 접촉망 g2의 별도 T12 시험을 같은 기능으로 세지 않는다. 후속 코드가 사용자 표시를 새로 만들면 동일 계약·한정어를 함께 반영한다.
