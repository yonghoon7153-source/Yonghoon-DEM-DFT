# Triage 프롬프트 (관련도 재평가, 배치용)

아래 [연구 프로필]의 채점 가이드(0~1)를 기준으로 각 논문의 관련도를 매긴다.
초록이 없으면 제목·스니펫만으로 판단하되 불확실하면 ±0.1 폭으로 보수적으로 준다.
**IF는 고려하지 않는다** — IF 정렬은 별도 규칙이 한다. 오직 "내 연구에 쓸모가 있는가"만 본다.

출력: JSON 배열. 각 원소 `{"id": "...", "relevance": 0.0, "reason": "한 줄", "flags": ["review","preprint","duplicate_of:<id>","already_known"]}`.
- `already_known`: 프로필의 '읽은 논문' 목록이나 vault에 이미 있는 논문이면 표시.
- `duplicate_of`: 같은 논문의 프리프린트/정식 출판 중복이면 표시.
