## 3. 0.31/0.39의 독립 유도 — B 문턱이 아니다

생성기 `:92,785`의 AM_P:AM_S:SE 지름비는 9:4:1이며 공통 CGF를 곱해도 반경비가 같다. 구–구 환산 반경을 쓰면, q=R_AM/R_SE에 대해

```text
R*_AS / R*_SS = [R_AM R_SE/(R_AM+R_SE)] / (R_SE/2)
               = 2q/(q+1)

W_AS/W_SS = sqrt(r)
F0_AS/F0_SS = [2q/(q+1)] sqrt(r)
```

따라서 AM_P는 1.8√r, AM_S는 1.6√r이고 동등점은 다음과 같다.

| r | AM_P–SE / SE–SE 힘 척도 | AM_S–SE / SE–SE 힘 척도 |
|---:|---:|---:|
| 0.10 | 0.569210 | 0.505964 |
| 0.35 | 1.064894 | 0.946573 |
| 0.50 | 1.272792 | 1.131371 |
| C의 입자 표면값 1 | 1.800000 | 1.600000 |

- AM_P 동등점: **r = 1/1.8² = 0.3086419753**.
- AM_S 동등점: **r = 1/1.6² = 0.390625**.
- r=0.35는 두 힘 비교값 사이에 있다. AM 종류별로 나누어 읽자는 :26의 이유가 성립한다.
- 동일한 B가 분자·분모에 함께 들어가 소거된다. B를 1,000배 바꿔도 위 힘비는 같지만 힘의 절대 척도는 1,000배 바뀐다. 따라서 이 비만으로 혼합 상태가 같다고 할 수 없다.

정적 경로 `make_mixer_deck.py:603–620`은 F0_SS=B·m_SE·g에서 각 쌍의 F0를 환산 반경·기하평균으로 만들고 CED를 역산한다. `:972–984`는 SE 강성을 바꿀 때 쌍별 F0를 보존한다. 이는 **의도된 힘 척도의 소스 대응**이지 덱 발행·실행 검증이 아니다.

또한 실제 출력 접촉 모델은 `:1362,1371`의 Hertz+SJKR다. 전체 JKR의 변형·분리 일·동역학을 그대로 재현했다는 판정은 하지 않는다. 작은 겹침 근사의 `F=Aδ^(3/2)−Kδ`에서 δ0=(K/A)², F0=Kδ0로 놓으면 인장 최댓값의 크기는 4F0/27이다. 그래서 제시한 **Bo_po=B/6.75**는 해당 모델 근사의 산술이며, 세 값은 **0.03147259 / 3.14725926 / 31.47259259**다. 실분말 Bo 또는 γ의 측정값은 아니다.

등록 초안:26,28은 이 비교를 전이선·분산 방향·실물 물성으로 확대하지 않으므로 새 결함으로 올리지 않는다.

## 4. U/C와 벽 — 같은 벽 γ가 같은 AM–벽 힘은 아니다

**이 부분은 결과 그림에 명시하는 편이 좋다. 현재 문서는 같은 γ_W만 주장하므로 모순은 아니다.**

같은 (B,r)에서 U→C로 AM 표면값만 r에서 1로 올리면, 고정 기하에서:

| 힘 척도 F0의 C/U | r=0.10 | r=0.35 | r=0.50 |
|---|---:|---:|---:|
| AM–AM: 1/r | 10.000000 | 2.857143 | 2.000000 |
| AM–SE: 1/√r | 3.162278 | 1.690309 | 1.414214 |
| **AM–벽: 1/√r** | **3.162278** | **1.690309** | **1.414214** |
| SE–SE 및 SE–벽 | 1 | 1 | 1 |

즉 U/C 차이는 AM–SE 하나의 개입이 아니며, AM–AM과 AM–벽 변화도 포함한다. 표면에너지 동일화라는 제안에는 일관되지만 “벽 힘을 통제한 순수 부착 효과”라는 해석은 성립하지 않는다.

반대로 **같은 B의 C 팔들은 모든 입자 표면값이 1이므로 r 간 입자–입자 힘은 동일하고 벽 항만 달라진다.** r=0.10→0.50에서 모든 입자–벽 힘 척도는 √5=**2.236068배**다. 따라서 C 세 팔은 동일 코팅 조건의 통계적 반복이 아니라 서로 다른 벽 조건이다. 벽이 다르므로 단순 중복이라며 삭제할 근거도 없다.

등록 초안:22–24,89–91은 대리·결속·조건부 해석을 이미 명시한다. 다음 문장 추가는 **비차단 명료화 제안**이다.

> 같은 (B,r)의 U/C는 γ_W와 SE–벽 힘 척도를 공유하지만 AM 표면값 변화로 AM–벽 힘도 함께 달라진다. 같은 B의 C 팔끼리는 입자–입자 조건이 같고 r에 따른 벽 조건만 다르므로 독립 반복이나 순수 입자 γ 효과로 해석하지 않는다.

이 리뷰는 D2의 비준된 벽 규칙을 고정 벽 힘 규칙으로 교체하라고 요구하지 않는다.

## 6. 판독 연결에서 남는 구체 경계

여기는 **현 초안이 완료했다고 주장하지 않는 후속 자격 항목**이다. 새 P finding으로 세지 않는다.

### 접촉·군집

`mixer_contact_reader.py:168,320–351`의 정의는 초안과 맞는다. 엄격한 겹침으로 SE 연결성분을 만들며, 수평균 성분 크기는 singleton을 포함한 N_SE/성분 수다.

AM 종류별 부착 분율의 분모는 **각 AM 개수가 아니라 전체 SE 수**다. 한 SE가 AM_P와 AM_S 모두에 닿으면 각 타입 분율에 각각 포함되지만 합집합 분율에서는 한 번만 센다. 예컨대 SE 한 개가 두 타입에 모두 닿으면 P분율=100%, S분율=100%, 전체 부착=100%다. 타입 분율을 더해 전체 분율로 쓰면 안 된다. AM당 SE 수는 타입별 접촉쌍 수/N_AM_type이며 피복 면적이 아니다.

`:85,199–200,275–292,482–487`의 schema1·0/2바퀴·계획 원자수 정확 일치·이후 ID/type 보존 조건은 새 D2 schema2/D13에 자동 이식되지 않는다. 초안:54,61은 이 미지원 경계를 공개하므로, 이를 새 발견으로 재등재하지 않는다.

### M와 기준군

`measure_mixing_index.py:281–286,356–366`의 기존 M은 각 평가 런 t₀의 S₀²와 E0 t₀의 S_R²를 사용하는 경험적 정규화다. N0의 회전 자료를 E0 대신 넣거나 이를 이론적 무작위 분모라고 부를 수 없다.

```text
M = (S₀² − S²)/(S₀² − S_R²)
```

설명용 수치에서 S²=0.03, S_R²=0.01이 같아도 S₀²=0.09이면 M=0.75, S₀²=0.05이면 M=0.50이다. 같은 최종 분산이 서로 다른 M을 낼 수 있으므로 C−U의 M 차이를 순수 최종 혼합 상태 차이로 읽을 수 없다. 초안:56–57이 원 분산·시작 상태를 함께 내도록 한 이유가 맞다.

새 입력 연결에서는 실제 반경·축·격자·n_min·타입 매핑·E0 신원을 묶어야 한다. 현재 CLI 기본 반경은 `measure_mixing_index.py:1249`의 **0.02056 m**인 반면 제안 계획 반경은 **0.01258325 m**다. 기본값을 그대로 쓰면 반경이 약 **1.633918배** 달라진다. `:56,119–135`의 타입·공간 가정도 확인 대상이다. 이번 리뷰가 n_min이나 새 임계값을 대신 선택하지는 않는다.

기존 D3 reader를 가짜 T1/T2·가짜 실측으로 채우는 길은 초안:59가 명시적으로 금지한다. 별도 개발 표를 만들자는 Q3 권고를 지지한다. MXD2R 소비자 검토가 닫히더라도 이 관측 연결·기준군 자격이 자동 완료되는 것은 아니다.

유효한 경고 반례와 **현 문서 자체의 결함**을 구분했다. 위 반례를 현 초안이 이미 배제하거나 미지원으로 공개하고 있어 새 P1/P2/P3로 올리지 않는다. 수치가 맞는다는 이유로 전체 모형·기전·실물 타당성을 수용한 것도 아니다.
