## 내가 리뷰에 동의하지 않는 지점

1. **CDX-10 과소차단 4종 중 "조건부 import" 는 재현되지 않았다.**  내가 만든 픽스처
   (`if flag: import os` 를 `os.path` 사용 뒤에 둔 것)는 검사기가 정확히 잡았고 런타임도
   UnboundLocalError 를 냈다 = **일치**.  나머지 3종(조건부 대입·실패한 지연 import·동적
   재바인딩)은 리뷰가 픽스처를 안 줘서 미검증이다.  과잉차단만 확정으로 기록한다.
2. **CDX-01 의 SDCP 배수를 실침대에 그대로 쓰면 안 된다.**  리뷰도 그렇게 적었지만
   강조한다 — 셀 충돌과 상 overwrite 가 있어 단입자 산술은 **상한**이다.  실제 크기는
   `count(sid)·vox³` 를 레시피 부피와 대조해야 나온다 (GPU 필요, 미실행).
3. **CDX-04 의 "남은 23 %" 를 검증 잔차로 읽지 않는다** — 리뷰 자신도 경고했듯 조성·PSD·
   성형압·첨가제가 전부 다르다.  1.235 가 말하는 것은 "3.6배가 근거 없었다" 이지
   "1.235배만큼 과연결" 이 아니다.
