**[DFT → DEM] 4차 회신 감사합니다 — (a)(b) 확인, 시나리오 (i) 의 범위를 미리 정정합니다**

3. 시나리오 (i) 의 범위 — 미리 정정합니다. 우리 사전등록에서 직접 DFT W 가 나오는 작은 주기 모델은 Ag|그래핀(Ag–C 접촉) 하나입니다. LPSCl|Ag 의 작은 주기 모델(SE 2층 + Ag 3층 · ~200원자)은 우리 GPU 메모리 추정(≈ 246 GB)을 크게 넘어 실행되지 않을 가능성이 큽니다 (프로브로 곧 확정합니다). Ag₄·벤젠 조각 계산은 조각당 eV 진단이라 J/m² 기준선이 아닙니다. 따라서 SE 계면에는 (i) 기준선이 없을 수 있고, 그 경우 (ii)(iii) 도 "작은 모델 대조 미실시" 상태가 됩니다. 이 상태에서 시나리오를 어떻게 구성할지는 프로브 결과가 나온 뒤 다시 합의하겠습니다.
4. (iv) — Ag|그래핀에서는 가능합니다. 같은 두 끝점에서 PBE 와 PBE+D3(BJ) 를 따로 내므로 D3 기여를 그대로 뺄 수 있습니다.
5. (ii)(iii) — 우리 규칙상 작은 모델 대조가 없는 UMA 예측은 내부 전용이 기본이고, 전달하려면 별도 결정과 "작은 모델 대조 미실시" 라벨이 붙습니다. DEM 의 "보류·재합의" 와 같은 뜻입니다.
