`[인쇄]` 양극 `ML ⇌ M₁₋ₓL + x M⁺ + x e⁻`(`x_min ≤ x ≤ x_max`), 음극 `M ⇌ M⁺ + e⁻`. 교환 전류:

```
(5)  I⁺₀ = F k¹_s a^max_ML (1 − ā_ML/a^max)^α⁺ (ā_ML/a^max)^(1−α⁺) (ā_M⁺)^α⁺
(6)  I⁻₀ = F k²_s (ā_M⁺)^α⁻ (ā_M)^(1−α⁻)
(7)  I_bat = I⁺ = I⁻
```

`[추론]` 곱 구조: `I⁺₀ ∝ k¹_s · a^max · (a₀δ)^½`, `I⁻₀ ∝ k²_s · (a₀δ)^½ · a_M^½`(`a_M` 고정). 그리고 식 (3)·(4) 의 전류는 **기하 면적 `A` 로 나눈 밀도**라
**실제 반응 면적 / 기하 면적 비는 `k¹_s`·`k²_s` 에 흡수된다** — 박막에서도 계면 거칠기·박리(부분 접촉)는 **동역학 상수의 이름으로** 들어간다.

## 2-3. 전해질 (식 8–26)

`[인쇄]` 해리 `MN ⇌ M⁺ + N⁻`, 평형 공공 분율 `δ`, 자리 농도 `a₀`. 전기중성(`a_M⁺ = a_N⁻`)으로 두 물질수지를 더해 이동항을 지우면

```
(22)  ∂a/∂t = [2 D_M⁺ D_N⁻ / (D_M⁺ + D_N⁻)] ∂²a/∂y² + r
(23b) ∂a(0,t)/∂y = I⁻ / (2 D_M⁺ A z F)           ← 경계는 D_M⁺ 만
(25)  E(y,t) = (RT/F)(1/a){ −I/(2FAD_M⁺) + (D_M⁺−D_N⁻)/(D_M⁺+D_N⁻)·[∂a/∂y − I/(2FAD_M⁺)] }
(26)  η_mt,electrolyte = (RT/F) ln[a(J)/a(0)] − ∫E dy
```

`[인쇄]` 저자 스스로 "Equivalent Species" 를 지적한다 — 벌크는 `D_s`, 경계는 `2D_M⁺` 라 "등가 확산계수" 라는 말이 맞지 않는다고.
★ **ASSB 모델로서의 특이점**: 이 모델의 SE 에는 **농도 구배가 있다**(이온·공공 쌍, Danilov & Notten 2008 계열). 황화물 복합양극 P2D 에서 흔한 **"단일 이온 전도체 = 농도 균일"** 가정과
**반대편**이다. 저자는 이 선택을 Table 1 의 "no convergence regarding how to model the electrolyte zone" 논쟁 속에 둔다.

## 2-4. 양극 (식 27–32)


# 5. ★ Q4 본론 — "sensitivity analysis" 의 분류와 곱 축퇴

## 5-1. 분류 (사용자 체크리스트 1)

| 물음 | 이 편 | 근거 |
|---|---|---|
| 국소 민감도(편미분 · 정규화 민감도)인가 | **아니다** | ∂V/∂θ · 정규화 계수 · 유한차분 스텝 0. 배수가 ×0.1–×500 · ×5e-7–×1e5 — **대역** |
| one-at-a-time 인가 | **예 — OAT 대역 스윕** | §4.2–4.7 은 한 파라미터(또는 **같은 배수를 곱한 묶음** — 쌍 · 넷 · 여덟) |

| 파라미터 간 상관·공선성(FIM · Hessian 조건수 · profile likelihood · 신뢰구간)을 보나 | **아니다 — 전수 0** | 낱말 지문 §0 표 · 손실 함수를 흔든 그림 0 · 적합점 근방 탐색 0 |

⇒ **이 편의 "sensitivity analysis" 는 설계 민감도(design sensitivity)이지 추정 민감도(estimation sensitivity)가 아니다.** 질문이 "어느 물질 성질을 올리면 KPI 가 오르나" 이고
"데이터가 어느 파라미터를 정하나" 가 아니다. 우리 위키 [[constrained-crb-identifiability]] 가 갈라 놓은 **"민감도 ≠ 식별성"** 이 여기서는 한 단계 더 떨어진다 — **민감도조차 추정의 민감도가 아니다.**

# 6. 이 모델 대 우리 `degradation-degeneracy/` PyBaMM 모델 (사용자 체크리스트 5)

**액체셀 P2D 의 변형이 아니다 — 박막 전고체 계보(Danilov–Notten 2011 → Raijmakers 2020)의 1차원 평판 모델이다.** 공통점은 BV 계면 동역학과 평형 곡선 + 과전압 합이라는
골격뿐이다. 차이: (i) **입자 차원이 없다**(P2D 의 의사 차원 `r` 이 없고 양극 자체가 조밀막 — 확산 길이 = 막 두께 `H`, 측정 고정), (ii) **SE 에 농도 구배가 있다**(이온·공공 쌍 +
해리 반응 — 황화물 ASSB 의 "단일 이온 전도, 농도 균일" 가정과도, 액체 전해질의 농축 용액 이론과도 다르다), (iii) 양극 수송이 **이온·전자 쌍극 확산**(PyBaMM 은 전자
전도를 옴으로만), (iv) 음극은 **금속 — OCP 곡선이 없다**(우리 모델은 흑연 + Si 복합 음극 OCP 가 핵심), (v) **열화 모듈 0**(우리는 LLI · LAM_PE · LAM_NE 를 넣고 되찾는 것이 본체),
(vi) 이중층 없음. `[추론]` 그래서 **우리의 `(α, β)` · `LAM_NE ↔ γ_Si` 축퇴는 이 모델에 자리가 없다** — 음극 OCP 가 없기 때문이다(카드 첫 실측 "5 → 3 파라미터 붕괴" 와 같은 방향).
대신 이 편이 우리 프로젝트에 주는 것은 **방법론적 반례**다: **"곡선이 맞고 값이 문헌 근처" 를 추정 성공의 증거로 쓴 편에서, 데이터가 못 보는 파라미터가 10 자릿수 표류했다.**
우리 프로젝트가 합성 truth 로 채점하는 바로 그 실패 모드(맞는 곡선 ≠ 맞는 파라미터)가 **공개 문헌 안에서, 원전 수치로** 재현된다.

# 12. 이 digest 가 주장하지 않는 것

1. **Fig. 5a 가 틀렸다고 하지 않는다** — 적합값 5.24e-3 으로 계산했다면 정합이다. 주장은 **"그 그림의 결론(전자 확산은 중요하지 않다)은 LCO 의 성질이 아니라 적합점의 성질"** 까지다.
   문헌값 `D_e⁻` 에서의 곡선은 우리가 식 (30) 으로 **예측**한 것이지 풀어 본 것이 아니다(모델 코드 없음, G8).
2. **Nelder–Mead 가 안 움직였다고 단정하지 않는다** — 7/10 이 ×1.0500 이라는 비율표까지가 사실이고, 시작점 해석은 `[추론]` 이다(G1).
3. **§5-2 ② 의 대칭을 "정확한 비식별" 이라 하지 않는다** — `I⁺₀ ∝ a_max` 가 깨고, 실험 데이터의 가로축 변환(G3)에 따라 `a_max` 가 절대 용량으로 따로 고정될 수 있다. 주장은
   **"양극 부분계는 한 조합만 보고, 그것이 저자의 두 그림에서 곡선 단위로 나타난다"** 까지다.
4. **③·④·⑤ 를 근최적 폭으로 재지 않았다** — 한 율 그림의 모양 판독 + 인쇄된 식의 구조다. 4 율 동시 적합에서 몇 개 조합이 식별되는지는 **우리 폭 측정기**([[near-optimal-set-width-measurement]])의 일이다.
5. **이 편의 설계 결론(양극 확산이 용량을 정한다 등)이 틀렸다고 하지 않는다** — 전방 모델 안에서는 그림대로다. 다만 `D_e⁻` 에 걸린 결론(느린 종 지배)은 적합점 의존이다.
6. **Q4 가 움직였다고 하지 않는다.** 이 편은 재지 않았고, 명제로도 쓰지 않았다.
