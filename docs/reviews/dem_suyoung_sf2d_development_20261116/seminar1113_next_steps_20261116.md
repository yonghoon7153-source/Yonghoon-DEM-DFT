## 4. 첫 그림의 상태 저장·관측 계약 초안

### 4-1. 실제 변형을 그리는 입력

- S/F 공통 초기 물질점 좌표·원 입자 ID·기준 면적/질량을 고정하고, 각 저장 프레임에 step·시각·단계·판 위치·현재 좌표·속도·참조 좌표 연결을 둔다. 입자 ID는 시각이 달라도 유지한다.
- 현재 `F`는 `plastic_project`를 지난 상태다. 이를 곧바로 **전체 형상의 변환 지도**로 해석하지 않는다. 다음 구현에서는 전체 운동학적 변형 지도 `F_total` 또는 동등하게 운반한 재료 셀 형상을 별도로 저장하고, 구성식에 쓰는 상태와 구분한다. 총 지도는 실제 속도구배 이력으로 운반하며 그림의 모양을 목표 단면에 맞춰 조정하지 않는다.
- 첫 보완은 저장만으로 기존 물리 업데이트를 바꾸지 않는 방향이다. `F_total`을 수동 관측자로 둘 경우 그 값이 힘 계산으로 되먹임되지 않는지 확인한다. 출력 켬/끔의 기존 trace·마지막 평균 계산이 같은지 확인하고, 요약240 step 평균은 그240개의 압력 값을 함께 저장해 독립 재계산 가능하게 한다.
- 물질점의 현재 위치와 운반된 재료 영역을 함께 써 입자별 경계를 그린다. 원판 중심만 옮겨 원을 다시 그리는 방식이나, 큰 원/convex hull로 빈틈을 덮는 방식을 결과 경계로 쓰지 않는다. 재구성의 격자폭·보간·중복 면적을 함께 남기고, 여러 입자 영역의 겹침을 정상적인 공극 채움으로 숨기지 않는다.

### 4-2. 그림과 숫자를 연결하는 최소 자료

| 그림에서 볼 것 | 같이 저장/확인할 것 | 판정에 쓰는 범위 |
|---|---|---|
| SE 모양 변화 | 원 ID별 형상·기준/현재 면적·주축 변화, 비유한/역전 검사 | 2D 변형 관측. 3D 입자 비구형도와 별도 |
| 빈틈이 메워짐 | 같은 관측 영역의 공극 면적, 입자별 영역의 합·겹침 면적, 질량 기준 고체량 | 렌더링 커널이 키운 고체 영역과 구분. 2D 면적 기공을 3D 체적 기공 목표에 맞추지 않음 |
| 이동과 변형의 차이 | 원 ID별 중심/회전과 실제 물질점 상대 배치 | 단순 재배열과 재료 변형을 별도 관측. 반력비만으로 원인을 단정하지 않음 |
| 압력을 뺀 뒤 | 판 반력·판과 재료 간격·분리 접촉 상태·이완 관측 | 명시적 분리 법칙의 유무와 기하학적 분리 가능성을 구분; “모든 회복0” 문구 사용 안 함 |

그림 파일은 각 팔·프레임의 입력 해시와 연결한다. 첫 그림 묶음은 S/F 두 행에 동일 판 위치의 초기·가압 중·끝을 배치하고 축·색·시야를 같게 한다. 탈압 추가 뒤에는 같은 배열에 이완 끝·분리 후를 덧붙인다. 아직 존재하지 않는 프레임은 이미지 보간으로 채우지 않는다.
