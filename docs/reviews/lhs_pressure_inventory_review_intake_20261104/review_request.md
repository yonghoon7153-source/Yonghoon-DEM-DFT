# LHS 외부 판정 수령·수정 계획 한정 검토 요청

**이번 대상:** 판정·증거 바이트 보존, 동일 소스 재현의 해석, LPI-01/02 수정 계획의 범위.
**닫지 않는 것:** 두 P3의 수정 종결, 실제 재고 실행·압력 적격성·단계 A·배포, 전체 게이트 HOLD.

리뷰 핀은 `codex/lhs-v13-1104`에 게시한 이 수령 기록 커밋이며 전달 ZIP의 `PIN.txt`에 전체 SHA를 넣는다. 이 묶음은 수정 후 재확인 요청이 아니다. 사용자 발송이며 현재 즉시 추가 리뷰를 요구하지 않는다. 수정 비준 후 새 수정 핀·ZIP으로 짧은 재확인을 준비한다.

1. 원본 외부 판정·ZIP과 과거 검토 핀을 올바르게 보존하고, 재현의 범위를 모의·합성으로 한정했는가?
2. LPI-01의 출력 재시도·flush·해석기 종료·shell fallback 보강 계획이 과소하지 않은가? 구현 완료나 해결 판정으로 읽힐 문구가 있는가?
3. LPI-02의 문구 보강과 반례 보존이 B7·등록값 변경으로 넓어지지 않는가?
4. 전체 게이트 HOLD와 실제 환경 미검증, 아직 별도인 Q1·MXD2R 판정 대기가 드러나는가?

사전 대조: 숫자는 저장 실행 출력과 비교; 소스 17개·포장 68개·원래 전달 69멤버·외부 증거 목록 88개는 서로 다른 범위로 표시; P3는 open이고 전체 HOLD 유지; 외부 반례 두 건을 같은 소스에서 재현. 새로운 독립 외부 종결은 아니다.
