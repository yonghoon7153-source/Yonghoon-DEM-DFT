## 값의 출처 · 기준

- 미세구조 · 접촉 · 수송 · 응력 = `docs/50kg/report_y4/draft2/data/<침대>/metrics_<침대>.json` (덱 1–8장과 같은 원천) · 조건 = 끝 덱 (`kg50_y4_sources.parse_deck`) · 면적당 용량 6.5 = `docs/50kg/dem_plan_20261026.md` §0.
