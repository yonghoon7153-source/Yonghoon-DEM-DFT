Q1. DEM 주값과 W_ad ≤ W_sep — 조건부, 현재의 일반화에는 반대
현재 파일럿의 가장 방어 가능한 주값은 다음입니다.
지정된 기하·셀·전자상태 선택 규칙에서의 DFT(PBE+D3) 고정기하 분리일 \(W_{\rm sep}\)

UMA로 이완한 독립 슬랩을 DFT 단일점으로 평가한 값은 **DFT로 이완된 열역학적 \(W_{\rm ad}\)**가 아닙니다.
또한 \(W_{\rm ad}\le W_{\rm sep}\)는 다음이 맞을 때의 관계입니다.
- 동일한 에너지 함수와 조성·전하·상태 제약
- 일치하는 분리 참조
- 해당 에너지 함수에서 독립 슬랩 이완이 실제로 에너지를 낮춤
UMA에서 낮아진 에너지가 DFT에서도 낮아져야 한다는 법은 없습니다. 따라서 DFT@UMA 결과에서 이 부등식이 깨졌다고 무조건 코드 오류로 차단하면 안 됩니다.
DEM도 JKR·DMT·cohesive zone을 한데 묶으면 안 됩니다. 예를 들어 LAMMPS JKR/DMT의 입력은 γ이며, 통상적인 분리일 \(W\)와 연결할 때 **\(W=2γ\)**라는 계수 확인이 필요합니다. 이 관계를 실제 LIGGGHTS 구현에도 확인 없이 적용해서는 안 됩니다. 공식 접촉법칙 정의
결정: 원자 계산 주값은 조건부 \(W_{\rm sep}\). DEM 전달은 실제 접촉법칙·입력 필드·변환식을 확인한 뒤 별도 승인입니다.
Q2. 옛 wrap 값 — 보존하되 기준값에서 제외
옛 빌더는 선언한 균일 변형을 가하지 않습니다. 다른 xy 주기경계에 좌표를 재배치하므로, 그 값은 그 인공적으로 구성된 주기 구조의 에너지 차이지 의도한 정합 계면의 분리일이라고 할 수 없습니다.
- 원자료·실패 이력은 보존합니다.
- 새 기준값·검증 대조군·DEM 보정에는 사용하지 않습니다.
- 새 기준은 정상 모결정과 명시한 절단면에서 재생성합니다.
직사각 셀의 변형률 산술은 맞습니다. 그러나 그것이 원자 배치까지 인증하지는 않습니다. 같은 셀로 참조를 맞추어도 접착 자체의 변형률 의존성은 사라지지 않습니다.
추가로 “반전대칭이 없으므로 두 (001) 면이 다르다”는 추론만으로 종결면을 정할 수 없습니다. 실제 좌표와 절단 위치가 기준이어야 합니다.
Q3. 불변성 시험 — 필요한 방향이지만 현재 묶음은 수정해야 합니다
세 시험은 서로 다른 질문입니다.
1. 진공 시험: 수치·주기경계 불변성
2. 8 Å와 30 Å 비교: 분리 거리의 충분성
3. \(W_{\rm ad}\le W_{\rm sep}\): 조건부 에너지 최소화 관계
이를 같은 종류의 오류 검사로 묶으면 안 됩니다.
특히 1 meV/atom은 보고량 기준으로 느슨합니다. 실제 면적 404.4198 Å², 848원자에서:
\[
848\times0.001\ {\rm eV}/A
=\mathbf{0.0336\ J/m^2}.
\]에너지 항 사이 오차가 반대 방향이면 분리일 오차는 더 커질 수 있습니다. 원자당 에너지 대신 최종 에너지 조합을 면적으로 나눈 변화량으로 판정하세요.
제안은 다음입니다.
- 진공·수치 설정 변화에 따른 최종 \(W\) 변화 ≤ 0.01 J/m²
- 실제 원시 에너지의 8 Å–30 Å 차 ≤ 0.02 J/m²
- 후자는 UBER 적합값이 아니라 직접 계산한 에너지로 검사
- 실패하면 분리 거리를 늘려 확인하되, 결과를 맞추도록 영점을 바꾸지 않음

\[
E_{A+B,\rm far}\quad\text{대}\quad E_A+E_B
\]를 대조해야 합니다. 현재 UMA는 합친 분리계를, DFT 프로브는 독립 슬랩 둘을 사용할 가능성이 있습니다. UMA는 전체 원소 조성도 모델 라우팅에 사용하므로 두 경로의 가산성을 당연시할 수 없습니다. 실제 불일치가 있다는 판정은 아니며, 확인해야 한다는 뜻입니다. UMA 공식 설명
Q4. UMA ↔ 분산 없는 DFT — 찬성, 검증 범위를 제한해야 합니다
같은 기하에서 UMA와 분산 없는 PBE/PBE+U를 비교하는 것은 맞습니다.
다만 omat은 VASP·특정 PP 및 설정 계보입니다. QE에서 PBE와 같은 숫자의 U를 사용했다고 완전히 같은 기준계가 되는 것은 아닙니다. 이 경우 오차에는 모델 오차뿐 아니라 기준 계산 설정의 차이도 들어갑니다. UMA의 학습 기준계
DFT 힘은 기록하는 편이 좋지만:
- 고정기하 분리일이 목표라면 큰 잔류 힘 자체가 그 에너지 차를 무효화하지는 않습니다.
- 평형 접착일을 주장하려면 DFT 이완 또는 그에 준하는 별도 검증이 필요합니다.
- fmax < 어떤 값만으로 \(W\)의 에너지 오차가 보장되지는 않습니다.
따라서 힘은 우선 기하의 적정성 진단으로 두고, 보고량을 몰래 평형값으로 승격하지 않는 것이 핵심입니다.

“2개 통과하면 종료, 실패하면 5개”는 반대합니다.
- 처음 2개는 실행 가능성·조기 실패 확인용
- 실패하면 조기 NO-GO 가능

- 최소·하위 사분위·중앙·상위 사분위·최대 등 선택 규칙과 동률 처리를 DFT 결과 전에 고정
검증 실패 후에도 정상적인 DFT 계산값 자체는 보고할 수 있습니다. 다만 선별한 2–5개의 DFT 값으로 전체 20시드 분포를 대표시키면 안 됩니다.
Q6. NCM 상태선택 — 먼저 선언해야 하지만, Ag 전체를 묶을 필요는 없습니다
먼저 정상적인 LiNiO₂ 구조가 필요합니다. 그다음 다음 중 하나를 명시적으로 선택하세요.
- 저비용 조건부 경로: FM 등 하나의 상태 정책을 고정하고 FM-conditional로 보고
- 낮은 상태 탐색 경로: FM + 해당 초격자에 맞는 서로 다른 보상형 자기 시드 2개, 최소 3개 초기화 중 정상 수렴한 최저 상태를 선택
후자도 “바닥상태 발견”이 아니라 선언한 초기화 집합에서 찾은 최저 상태입니다. 전체 스핀을 뒤집은 것만으로 독립 시드 두 개를 채우면 안 됩니다.
Ni의 Dudarev U=6.2 eV, J=0은 MP 계보를 따르는 출발값으로 제안할 수 있지만, 보편적인 LiNiO₂ 정답은 아닙니다. PP·Hubbard projector·상태 선택을 함께 고정하고, W를 맞추려고 U를 조정하지 마세요. MP 설정의 Ni U
계면과 분리 참조에는 같은 상태 선택 정책을 적용해야 합니다. 전하·자기상태를 이어가는 분리인지, 각 끝점에서 최저 상태를 찾는 분리인지도 구분해야 합니다.
순서: NCM이 실패하면 Ag/NCM 대비를 중단하는 것이 맞습니다. 독립적으로 정의한 Ag|SE·Ag|흑연 계산까지 모두 중단할 이유는 없습니다.
Q7. 1L 라벨 — 조건부 모델에는 가능, 두께 수렴 주장에는 불가
먼저 기존 근거를 정정해야 합니다.

이것은 두께만 바꾼 대조가 아닙니다. +74%를 순수 두께 효과로 읽거나, 그 표로 ΔW<0.05 시험 실패를 확정하면 안 됩니다. 기존 기록
결정은 다음입니다.
- 1L이라는 유한 시트 모델의 조건부 비교: 허용
- 벌크 양극 표면의 대표값·DEM 보정 기준: 불허
- 3L 이상이면 자동 통과: 아님
수렴을 주장하려면 조성·종결면·고정층·registry를 맞춘 두께 대조에서 해당 보고량의 변화 <0.05 J/m²를 확인해야 합니다. \(W_{\rm sep}\)와 \(W_{\rm ad}\)는 각각 확인해야 합니다.
Q8. 반응성 — 접촉·혼입·반응을 분리해야 합니다
Ag–S <2.5 Å 자체를 반응 탈락 조건으로 쓰지는 마세요. 원하는 접착도 Ag–S 접촉을 만들 수 있습니다.
현재의 “미혼합·PS₄ 보존 계면”이라는 제한된 집합에는 다음 운영 정의를 제안합니다.
항목	제안 숫자·처리
Ag–S 접촉	<2.5 Å 개수/면적 보고. 이것만으로 제외하지 않음
PS₄ 연결	P–S <2.5 Å, 초기 네 S의 원자 ID까지 추적
PS₄ 보존 집합	초기 48/48 정상, 이완 후 부모 네 S 연결 변화 0개
뚜렷한 혼입	정렬된 상대 슬랩의 내부 경계를 1.0 Å 초과 침범한 이종 원자 ≥1개면 별도 집합
미혼합 집합	위 침범 원자 0개


P–S 2.5 Å는 이 시작 CIF의 네 이웃이 약 2.11 Å 이내이고 다음 이웃은 훨씬 멀다는 좌표 진단에 기반한 제안입니다. 모든 반응 구조에 통용되는 결합 판정은 아닙니다.
혼입 경계는 원자 전체의 순간 min/max가 아니라, 전체 이동·회전을 제거한 사전 지정 기준층으로 정의해야 합니다. 1 Å 역시 물리 상수가 아니라 명백한 내부 침범을 구분하는 운영값입니다.
이 판정은 intermixed 또는 PS4-topology-changed라고 부르세요. 화학반응 확인·반응 없음 인증은 아닙니다. 제외된 시드 수와 좌표도 모두 남겨야 합니다.
Q9. DEM에 넘길 값 — (a) 조건부, (b) 제한적, (c) 반대
- (a) DFT(PBE+D3) 값: 지정한 기하·표면·상태에 대한 값으로 가능. DEM 입력으로 쓰려면 Q1의 연결 규칙이 필요합니다.
- (b) Ag/NCM 비: 두 모델에 조건부인 비교로 가능. 그러나 비가 체계적 오차·두께 차이를 자동으로 상쇄하지는 않습니다.
- (c) 비 × 실험 NCM: 현재는 반대합니다. AFM aJ를 임의 접촉 반경으로 J/m²로 바꾸어 기준을 만드는 것은 검증되지 않은 면적을 통해 절대값을 만들어내는 것입니다.
DFT@UMA 기하의 에너지는 MLIP 에너지 자체가 아닙니다. 그렇다고 자동으로 원고 사용이 승인되는 것도 아닙니다. 카드에 “UMA 생성 기하의 DFT 고정기하 값”이라는 범위를 명시하고, 기존 금지 규칙과의 적용 범위를 기록하면 됩니다.
Q10. Ag|흑연·흑연 대조 — 직접 DFT+D3에 찬성, 대조량은 수정
가장 중요한 것은 0.37 J/m²가 임의의 흑연 층간 에너지의 정답이 아니라는 점입니다.
원 논문은 다음을 구분합니다.
- 비정합 흑연 쌍결정의 벽개에너지: 0.37 ± 0.01 J/m²
- 이상적인 ABAB 적층의 벽개에너지: 0.39 ± 0.02 J/m², 실험과 이론을 결합한 값
임의의 4–8원자 셀에서 계산한 이중층 결합·박리에너지를 여기에 직접 맞추면 다른 양을 검증합니다. 원 논문
최소 규약 제안:
항목	제안
Ag	흑연 registry

마지막 ±0.08은 제가 제안하는 파일럿 허용오차이지 논문 측정 불확도가 아닙니다. 범위 밖이면 D3 계수를 조정해 넣는 것이 아니라 원인 진단으로 돌립니다.
4–8원자를 유지하려면 그 셀이 어떤 분리 과정을 나타내는지 먼저 정의하고, 같은 양의 기준과 비교해야 합니다. 흑연 대조 통과가 Ag–S 화학이나 NCM 자기상태까지 검증하지도 않습니다.
또한 0.3/1 J/m²는 저·고 접착 구간으로만 부르세요. 그 숫자만으로 물리흡착·화학결합 기전을 판정할 수 없습니다.
Q11. 분포·제외·검정 — 일부 수정
중앙값·IQR, 고정 시드, 사전 선언 제외 규칙은 좋습니다. 다만 네 가지를 고쳐야 합니다.
1. 분포의 뜻을 제한하세요.
   이것은 균일한 xy 초기배치를 지정한 최적화로 보낸 결과의 분포입니다. 열평형 registry 점유분포가 아닙니다.
2. 실제로 짝지어진 설계면 짝 비교가 우선입니다.
   같은 SE와 같은 (dx,dy)를 사용했다면 시드별 차이와 paired bootstrap 등을 우선하세요. 시드 번호만 같고 난수 소비가 다르면 짝이 아닙니다. Mann–Whitney도 일반적으로 “중앙값 차이”만 검정하는 것은 아닙니다.
3. 반응 시드 제외는 보고 대상의 변경입니다.
   전체 20개 중 정상/미수렴/혼입/PS₄ 변화를 함께 보고하고, 통계는 미혼합·PS₄ 보존 조건부 분포라고 명시하세요. 비교 양쪽에서 탈락 집합이 다르면 그 선택 차이도 드러내야 합니다.
4. DFT 선택 표본의 중앙값을 전체 분포로 쓰지 마세요.
   UMA 최저·중앙값 또는 분위수로 고른 5점은 검증 표본입니다. 그 DFT 중앙값·IQR은 계산할 수 있어도 20개 전체의 대표 추정량은 아닙니다.
급 판정은 제안대로 경계를 걸치면 보류하되, 표본 범위뿐 아니라 Q5의 검증 오차도 고려하세요. “저·중·고 구간이 혼재한다”까지 보고하면 됩니다.
재개 조건
본 계산 전 최소 조건은 다음 다섯 묶음입니다.
1. 정상 NCM 모결정과 SE 절단면을 좌표·배위·조성으로 검증하고 입력을 고정.
2. 분리 참조·전자상태·에너지 계산기를 일치시키고, 진공·분리 거리·가산성 검사를 보고량 단위로 정의.
3. 2개 통과 시 종료를 폐기하고, 고정 검증 표본과 오차 예산을 봉인.
4. 혼입·PS₄ 변화·통계 집합을 기계적으로 정의하고, 선별 DFT 표본과 전체 분포를 구분.
5. 흑연 대조의 분리 과정과 실제 DEM 입력법칙을 특정.
핵심은 셀을 정방으로 바꾸는 데서 끝나지 않습니다. 정상적인 원자 구조를 만들었는지, 양쪽 계산이 같은 끝점을 비교하는지, 검증한 표본보다 넓은 주장을 하지 않는지가 이번 해제 조건입니다.
