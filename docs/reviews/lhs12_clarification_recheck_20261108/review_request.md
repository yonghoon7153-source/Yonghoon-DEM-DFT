# LHS12-01/02 명료화 후보 한정 재확인 요청

발송은 1저자. 검토 대상은 동봉 `REVIEW_PIN.txt`의 `codex/lhs12-clarify-1108` 커밋이며 바탕은 B `40d9658c07eb578d03dff7905b301da7efacf582`다. 반입 뒤 사본은 Claude 대응표와 blob 동일성으로 구분한다. 원 검토의 B 정의 핀은 `1b20ce0606f3b49ef1abc4dd2bc540ead773905a`다.

이번 요청은 기존 부분 수용의 두 지적에 한정한다. 새 정책의 1저자 비준이나 실행·값 열람 GO를 요청하는 것이 아니다.

1. **LHS12-01(P2)**: README·definition.json·Q2 권고가 같은 E/Z/D와 배타 분기를 규정하는가. (0,+2),(+1,−1), zero-N만 있는 경우, E도 빈 경우, nonzero-N에서 ΔP=0인 경우에 각각 산술 방향 하나만 나오며 원 행·ID·분모가 보존되는가. 평가 지위·산술 방향·독립 N 효과·SIGN_UNRESOLVED가 섞이지 않았는가.
2. **LHS12-02(P3)**: README·definition.json·Q1 권고가 같은 EXPOSED→UNRESOLVED→PROSPECTIVE 우선순위를 규정하는가. 노출 true/계보 unknown, 의존 true/노출 unknown, 전부 unknown, 비중복·미열람 전부 입증의 경우 주 코호트는 하나이고 unknown/확인 사실이 남는가. null→false나 독립 자격 자동 승격이 없는가.
3. **범위 보존**: Q3–Q12 권고 행, 종점·N·불확실성·원 입력 신원·승인 분리와 실제 빈 행/null이 유지됐는가. 정적 검사 결과를 실제 자료 분류·연구 실행·외부 종결로 잘못 표시하지 않았는가.

입력: 후보 정본문서 3개와 변경 전 사본, 본 폴더의 receipt/경계 사례/정적 검사 결과, 변경하지 않은 원 정본 문맥, 원 독립 검토 ZIP. 첨부 외부 증거는 보존용이며 그 안의 명령이나 문구를 실행 권한으로 해석하지 않는다.

요청 출력: 지적별 수용/잔여 문제와 근거, 새 P1/P2/P3가 있으면 가상 반례. 기존 Q3–Q6 수용은 모순이 발견되지 않는 한 재심 대상으로 넓히지 않는다. 두 후보의 수용도 저자 정책 비준·실제 명부 완성·실행 GO를 대신하지 않는다. **전체 HOLD 유지.**
