# NEXT_RUN_PLAN — 5초 축별 메시 진단 반영

**현재 세 조건의 비교를 마치고 실행을 멈췄다. 전체 메시 수렴은 미완이다.** 추가 600/80, 시간간격 반감, 장시간 전체 프로토콜·12시간 휴지·유한 sigma·sweep은 승인받지 않았으며 실행하지 않았다. 이전 계획은 mesh_axes/NEXT_RUN_PLAN_before_axes.md에 보존했다.

## 이번 결과

- 300/40·300/80·600/40을 모두 같은 새 187개 strict 요청 시각으로 5초 재계산했다. 첫 1초에107개가 있다. 옛 정수초 결과와 섞지 않았다.
- 반경축300/40→300/80: 최대 전압 차2.505310864 mV @.04초로1 mV 기준 초과. 같은 시각 최대 표면 x 차4.182398438e-5, 음극 z=52 µm로x 기준1e-4 이내.
- 물리축300/40→600/40: 최대 전압 차1.08668e-11 V @.001초; 최대 표면 x 차5.2286938e-9 @5초, 양극 z=121 µm. 지정 공통 표본의 두 기준 충족.
- 반경축 피크의 signed 성분 차: Eeq +2.550630094 mV, 과전압 −.045776896 mV, 전해질 전위차 +.000457665 mV. 최대 전압의 같은 시각에서 분해했다.
- 설정은 같지만 실제 step@.04초는 .005/.002/.005초다. 반경 세분 차이와 adaptive 시간 적분 반응을 완전히 분리한 결과라고 해석하지 않는다.

## 제안 A — 초기 구간 시간 민감도 분리, 아직 미실행

이유: 전압 차의 최대가 .04초이며 두 입자 격자의 실제 step 이력이 다르다. 설정상 maxstep .1→.05만 변경하면 strict 시간표가 이미 실제 step을 .05 이하로 제한하므로 검증력이 약할 수 있다.

제안 범위는 **300/40·300/80의 두 격자 × 초기 구간 상한 .001·.0005초, 총4회의 5초 계산**이다. 0–.1초에 각각 상한을 적용하고 이후에는 .1초 상한으로 복귀한다. 같은187개 요청 시각, rtol1e-6, 초기 step1e-5초, 초기화·물성·재고·OCP·보호 설정을 그대로 유지한다.

각 격자에서 상한 반감의 차이를0–1초와0–5초 모두 보고하고, 실제 상한 적용 여부와 내부 step을 확인한다. 두 시간상한에서 반경축 차이도 각각 비교한다. 초기 구간만 상한을 강화한 시험이므로 이후 모든 시간오차가 분리됐다고 주장하지 않는다. 결과가 충분치 않으면 범위를 다시 제안하며 자동 확장하지 않는다.

## 제안 B — 600/80 교차 비교, 별도 선택이며 미실행

같은0.1C·sigma1e-20 S/m·187개 시간표·maxstep.1초로 **600/80의5초 계산1회**를 추가하는 선택이다. 기존 새300/80과 물리축, 새600/40과 반경축을 비교해 축 사이의 결합 민감도를 확인한다. 서로 다른 시간 제어 설정의 결과를 이 교차 비교에 섞지 않는다. 600/80 한 번만으로 입자80요소의 반경 수렴이 증명되는 것은 아니다.

두 제안 모두 이번 요청의 실행 범위에 포함되지 않는다. 사용자가 다음 범위를 선택하기 전에는 제출하지 않는다. 평가 기준은 최대 전압 차1 mV·pointwise 표면 x 차1e-4로 유지하며,5초 끝점이나Li 보존만으로 수렴을 통과시키지 않는다.

## 장기 프로토콜은 계속 보류

이후에도 사용자의 별도 결정 전에는 전체 운전·12시간 휴지·유한 sigma·sweep을 시작하지 않는다. 장기 모델의2.7 V cutoff는 방전에만 적용한다. 최초 충전을 전역 저전압 조건으로 막지 않는다. 새 장기 모델은 단계별 adaptive step·출력 간격·이벤트 허용오차를 별도로 구현·시험하며,5초 파일의 tlist 끝만 늘리거나maxstep.1초를12시간 휴지에 그대로 복사하지 않는다.

단일 프로토콜 진단을 나중에 선택하더라도 표 경계에서 멈춘 결과는 미완이며, 외삽 허용이나 임의 OCP 연장으로 완주 PASS를 만들지 않는다.
