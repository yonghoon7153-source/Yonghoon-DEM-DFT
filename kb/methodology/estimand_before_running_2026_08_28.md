# 여덟 번 계산하고 여덟 번 반려됐다

> 1저자 질문(2026-08-28): *"왜 다른 논문들은 다 쉽게쉽게 바인딩에너지 구하는 것 같은데
> 우린 왤케 어려운거야. 리뷰를 꽤 받고 돌린 건데 뭐가 문제인거야."*
> 이 카드가 그 답이다.

## 0. 한 줄

**"제대로 돌렸나" 는 여덟 번 리뷰했고 여덟 번 통과했다. "맞는 양을 재고 있나" 는
여덟 번째에야 물었고 즉시 P0 가 나왔다.**

## 2. 🔑 뿌리는 하나였다 — **열린 껍질**

`sdcp_doped` = C₁₁H₁₅O₆S₂, **NELECT 107 (홀수)**, 알짜중성 **doublet**.
자기도핑이란 *"전분자 HOMO 에서 전자 1개 + SO₃H 의 산성 H 제거"* 이므로
SO₃ 는 음이온이 되고 **hole 은 백본 π 폴라론**으로 앉는다(n=1 에서 SO₃ 35 % / 백본 65 %).

이것이 붙는 상대는 **LiNiO₂ — 자성(AFM Ni³⁺)이고 산화환원 활성**이다. 그래서:

```
분자 스핀 상태 × 슬랩 AFM basin × hole 위치(분자 / 슬랩)
```

**전부 물리적으로 정당한 서로 다른 SCF 해**다. 실측 흔적:

| 계 | 총자화 | 있어야 할 값 |
|---|---:|---|
| `slab` | −0.00005 | 0 (AFM 상쇄) ✅ |
| `mol_neutral` | 0.0015 | 0 (닫힌 껍질) ✅ |
| **`mol_doped`** | **0.175** | **1.000 (doublet)** ⛔ |
| **`complex_doped`** | **2.378** | slab 0 + mol 1 = **1.0** ⛔ |

`mol_doped` 의 0.175 는 `ISMEAR=1 · SIGMA=0.2`(Methfessel–Paxton 0.2 eV)를 **진공 상자 속
고립 분자**에 건 결과다 — 이산 준위를 뭉개 SOMO 가 양쪽 스핀 채널에 분수 점유되고 스핀
편극이 죽는다. 엔트로피 −0.020 eV 가 그 흔적이다.
`complex_doped` 의 2.378 은 그것만으로 설명이 안 된다 — **hole 이 분자에 안 남았다**는 뜻이다.

⇒ **중성형은 여덟 번 다 살아남았다.** 닫힌 껍질이라 해가 하나여서다. *doped 만 죽은 것이
바로 이 진단의 증거*다.

## 3. 그런데 왜 리뷰가 못 잡았나

우리가 실제로 리뷰한 것:

| 리뷰 대상 | 결과 |
|---|---|
| 번들 무결성 · 해시 · RUN_PROVENANCE | ✅ 통과 (wave1.5 3다리 완벽) |
| INCAR 기대키 18건 · pin 수용검사 | ✅ 통과 |
| 게이트 설계 · 회귀시험 11/11 | ✅ 통과 |
| **E_ads 가 이 계에서 잘 정의되는가** | ❌ **한 번도 안 물음** |

**우리 파이프라인은 여덟 번 모두 "숫자를 냈다."** 한 번도 *"이 계는 상태 지정이 필요하다,
멈춘다"* 라고 하지 않았다. 그리고 매번 리뷰가 사후에 *"그 숫자는 네가 원한 양이 아니다"*
를 찾아냈다. **실패한 것은 물리가 아니라 질문의 형식이었다.**

## 4. ⚠ "남들은 쉽게 하는데" 에 대하여

같은 날 읽은 세 논문에서 실측한 것:

- **tu2026** — 끝점의 결합 위상이 다른 CI-NEB 을 "확산장벽" 이라 부름 · 자기 AIMD 와
  5–10배 어긋나는데 화해 문장 0 · NEB 설정(이미지·스프링·수렴) 전부 미기재 ·
  `W_ad = |E_ads|/2A` 라 정보 0 비트인데 신규 기술자로 제시
- **wang2026** — 계면 12개를 DFT 이완까지 하고 W_ad 를 안 뽑음 · 산물의 전자전도성 미검토
- **deng2026** — XPS 배정이 분해능 밖에서 순환논증

**저들이 더 어려운 문제를 쉽게 푼 것이 아니라, 우리가 거부하는 검사를 건너뛴 것이다.**
동시에 — 전형적 흡착 논문은 **닫힌 껍질 분자 + 비자성 표면**이라 SCF 해가 하나다.
우리 계가 실제로 더 어려운 것도 사실이고, 그 둘 다 참이다.

## 5. 처방 — CLAUDE.md 에 박았다

**계산 규율**: `kb/templates/estimand_card.md` 를 채우고, **번들이 아니라 그 카드의 §1–3 을**
계산 **전에** 리뷰에 보낸다. 판정 기준은 하나다 — **SCF 해가 여럿이면 그 양은 단일 숫자가
아니다.** 열린 껍질 · 자성 기판 · 산화환원 활성 중 하나라도 걸리면 상태를 선언해 `X(상태)`
로 정의하거나 질문을 바꾼다.

**검증 게이트를 결과 보기 전에 정한다** — 물리적으로 정수여야 할 양이 정수인지부터.
`mol_doped` 0.175 를 잡았을 검사가 우리에게 없었다.

**마감 규율**: 닫을 때 **조건을 먼저 박고** 그것이 채워졌으므로 닫는다
(`db/properties/sdcp_neutral_closed_2026_08_28.json` 이 선례).

## 6. doped 를 여는 길 — 질문을 바꾼다

단일 E_ads 를 그만 요구한다. 자기도핑 고분자 바인더에게 물어야 할 것은
*"얼마나 세게 붙나"* 가 아니라 **"붙을 때 캐리어를 유지하나"** 다.

```
상태 I   hole 이 분자에 남음      → E_ads(I)
상태 II  hole 이 슬랩으로 이동     → E_ads(II)
         차이 = 계면 전하이동 에너지
```

**첫 수는 잡 1개**: 기준 분자를 `ISMEAR=0 · SIGMA=0.01 · NUPDOWN=1` 로 재계산해
총자화 1.000 을 확인한다. 여기서 갈린다 — 여덟 번의 실패가 수치 문제였는지 물리 문제였는지.

## 7. ⛔ 이 카드가 말하지 않는 것

- **estimand 카드를 채우면 계산이 맞는다는 얘기가 아니다.** 질문이 성립하는지만 본다.
- **이 진단이 doped 를 살린다는 보장도 없다.** 자화 1.000 이 나와도 상태 II 가 더 낮으면
  "분자가 캐리어를 잃는다" 가 답이고, 그건 E_ads 를 얻는 것과 다른 결과다.
- 실패 8건 중 1–5 는 MLIP 단계라 **스핀이 아예 없는** 방법을 쓴 것이고, 6–8 과 같은
  종류로 묶는 것은 사후 정리다. 당시에는 각각 다른 문제로 보였고, 그렇게 보인 것도 사실이다.
