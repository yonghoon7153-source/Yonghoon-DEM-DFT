# ADR 0001 — 정규화된 용량은 저장하지 않는다

- 상태: 채택 (2026-08-20)
- 관련: `packages/wrdkit/normalize.py`, `apps/api/app/models.py`

## 맥락

건식전극 셀은 질량과 면적이 자주 바뀐다. 전극을 다시 재고, 펀칭 지름을 바꾸고,
조성(wt%)을 조정한다. 실측 파일 하나만 봐도 장비의 `TestReport.CellWeight` 는
기본값 `1.0` 그대로였다 — **조작자는 장비에 질량을 넣지 않는다.**

따라서 "mAh/g" 는 측정값이 아니라 **측정값 ÷ 그 시점의 가정**이다.

## 결정

DB 와 캐시에는 **raw 단위만** 저장한다: mAh, Wh, V, A, s.
mAh/g · mAh/cm² · mAh/cm³ · % 는 **조회 시점에** `ResolvedCell.divisor()` 로
나눠서 만든다. 어떤 정규화 결과도 영속화하지 않는다.

## 결과

- 질량을 고치면 재파싱 없이 모든 표·그래프·CSV 가 즉시 따라온다.
  (19.6 MB 파일 재파싱 0.37 s 라도, 셀 50개면 20 s 다.)
- 같은 데이터를 서로 다른 가정으로 동시에 볼 수 있다 (전극 전체 질량 기준 vs
  활물질 질량 기준).
- 대가: 모든 조회 경로가 셀 스펙을 알아야 한다. API 는 셀 스펙을 쿼리 파라미터로
  받거나 sample 에서 읽어 온다.
- 대가: 정규화 값으로 DB 정렬/필터를 걸 수 없다. 필요하면 raw 로 걸고 후처리한다.

## 대안

**정규화 값을 같이 저장하고 질량 변경 시 무효화**: 캐시 무효화 버그가
"어제 본 숫자와 다르다" 로 나타난다. 실험 노트로 쓸 데이터에서 가장 나쁜 실패다.
