## 7. 작업 규율

- 원격은 **"붙여넣기 블록 제공 → 사용자 실행 → 출력 회수"**.  ⚠ **경고를 명령 블록 앞에
  써라** — 오늘 뒤에 썼다가 두 번 사고가 났다.
- 새 스크립트 전에 `scripts/` 를 먼저 찾아라.
- 커밋 전 **`bash scripts/check_all.sh`** (2분 넘게 걸린다 — 백그라운드로 돌리고 기다려라).
  ⚠ **파이프로 넘기지 마라** — 종료코드가 가려진다.
  ⚠⚠ **`nohup … &` 로 돌렸으면 래퍼의 종료코드를 보지 마라 — 그건 `&` 의 것이다.**
  실사고 (08-29): 백그라운드로 띄우고 래퍼가 낸 `0` 을 초록으로 읽고 커밋·푸시했는데
  `check_all` 은 **빨간불**이었다 (철회값 누수 6건).  **로그 파일의 마지막 줄을 읽어라** —
  `✓ 전부 통과` 가 있어야 통과다.  이것도 §8-1 과 같은 형태다: **대상의 신고가 아니라
  대상 자신을 봐야 한다.**  같은 실수를 저지른 그 세션이 §8-1 을 쓴 세션이다.
- 작업 단위마다 커밋·푸시.  커밋 메시지에 **무엇을 왜** 적어라.
- 한국어 대화체.
