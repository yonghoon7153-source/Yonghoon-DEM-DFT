## 1. 과제 정보
- **상위과제:** 세라믹 공정 기반 황화물계 전해질 및 고용량 후막 전극 친환경 제조, 응용기술 개발
- **세부주제:** 세라믹 catholyte 기반 전극 성능 향상을 위한 **단결정 양극재 제조 기술 개발**
- **사업/과제번호:** 소재부품기술개발사업(이종기술융합형) · 총괄 **RS-2025-25463204** / 내역 **RS-2025-25463211**
- **기간:** 2025.10.01 ~ 2028.12.31 (4개년, 1단계) · **TRL** 착수 4 → 종료 7 (현재 4)
- **총 연구개발비:** 4,378,665천원 (정부 2,900,000 + 기관부담 1,478,665)
- **과제유형:** 혁신제품형 · 대형통합형 · 민간투자연계형 · 안전관리형 · IP R&D 연계
- **수행기관:** 주관 ㈜엘앤에프 · 공동 한국전자기술연구원(KETI) · 공동 한양대학교 산학협력단(이종원)
- **소재계:** 단결정 Ni-rich NCM811 (양극) + Li₆PS₅Cl 아지로다이트 catholyte (황화물 SE) + VGCF/Super C (도전재) + PTFE (바인더), **무용매 건식 공정**
- **최종목표:** 비수산화물 전구체 기반 **방전용량 210 mAh/g·입자강도 800 MPa↑** 단결정 양극재 +
  **8.0 mAh/cm²** 면용량 + **100사이클 후 고온수명 90%↑** 후막 전극 제조 기술.
- **진행 현황 → `06_STATUS.md`** (어디까지 되어있는지).

## 3. 기관별 역할
- **㈜엘앤에프 (주관):** 저가 친환경 전구체(탄산 공법) 기반 단결정 NCM 양극재 제조. 소성온도/profile 조절로 입자 균일도·미분 개선.
- **KETI:** 단결정 양극재 + 세라믹 catholyte 건식 전극 제조·전기화학 성능 평가, 후막 전극 분석 시스템(비대기 SEM-EDS/XRD/임피던스) 구축.
- **한양대 (이종원):** 전기화학-기계 다중물리 모델 구축, 임피던스 디커플링(TLM) 기법, 설계인자 정량 분석. **← 이 브랜치(실험+모델 연계)**.

## 5. 1차년도 핵심 성과 요약
**㈜엘앤에프** — 탄산 공법 전구체(수산화 대비 생산량 +20%, 암모니아 정제·알칼리 세정 불필요).
소성온도 최적화로 균일 단결정(Sample D) → 방전용량 200.4 mAh/g.

**KETI** — 건식 전극 제조 공정 확립: AM:SE:VGCF(또는 SuperC):PTFE 비율 제어, PTFE 섬유화가 전극
형성 핵심. PTFE 최소 0.5 wt% 필요(0.2%는 형성 불가), 2.0%까지 형성 가능.
이온/전자전도도, 율속, 양극재(NCM_2/3) 표면구조 영향 규명. (수치 → `db/electrochemistry/`)

**한양대** — 후막 bimodal 복합양극 전기화학-기계 연성 모델 구축. 설계변수(면용량·fam·P:S·σ_ion/σ_e)별
Li 농도·플럭스·응력·계면박리 정량 분석. TLM 기반 저항 디커플링(이온/전자/계면) 기법 확립.
(모델 파라미터 → `db/model/p2d_parameters.csv`, 결과 요약 → `03_ANNUAL_REPORT_Y1_DIGEST.md`)

## 6. 설계 변수 체계 (복합양극)
- **면용량 (areal capacity):** 4 / 6(Ref) / 8 mAh cm⁻²
- **활물질 분율 fam:** 0.7 / 0.8(Ref) / 0.9
- **대립:소립 비율 P:S** (Poly:Single = 다결정:단결정): 3:7 / 5:5(Ref) / 7:3
- **전극 특성:** σ_ion ↑, σ_e ↓
- **제작압:** 450 MPa (펠렛 ⌀10 mm) / **구동압:** 150 MPa
> 핵심 trade-off: fam↑ 또는 대립(Poly)↑ → 기공도↑ → catholyte 연속성↓ → Li⁺ 병목·두께방향 이용률 편차↑.
> Bimodal(대립+소립)의 목적 = packing 개선으로 이 trade-off 완화 (Furnas dip; DEM 브랜치 McGeary/Bouvard 참조).
