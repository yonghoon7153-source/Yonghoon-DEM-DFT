# NEXT_RUN_PLAN — 후보 A 5초 1회 후 정지

## 현재 판정과 승인 범위

**이번 지정·정확 공통 저장 표본의 후기 시간상한 민감도 기준 충족. 전체 수렴 미완, 장시간 운전 보류를 유지한다.** 사용자가 승인한 후보 A 새 5초 계산 한 번만 수행했다. 기준 재실행과 후속 계산은 하지 않았다. 이번 결과의 해석에는 사용자가 추가 승인한 실행 코어 2→16 변경에 따른 병렬 반올림 가능성이 포함된다. 이를 동일한 병렬 산술 조건의 완전한 단일 인자 실험으로 표현하지 않는다.

- 고정 기준: Caps300R320H0125 / job 18a00b03e38d4694b9ba30d88e7008f4.
- 기준 Java SHA-256: 8d35be8fab513f5e2def316c4d00e0fdc19983a5dd3bf492f4ffe47a58248be3.
- 새 해: Caps300R320LateCapA5s / job c40c05d3cfb643a4b706345637b00f57.
- 새 Java SHA-256: a03abb905454de63b34b55e314ed09f3cb6414d58444e8b605962166a872531f.
- 승인한 cap: `if(t<0.1[s],0.000125[s],if(t<1[s],0.005[s],0.025[s]))`, 방식 `expr`.
- t=0부터 같은 초기화, 물리300(120/60/120)·입자320/320, 물리 반경·재료·OCP·초기 조성·Li·0.1C·sigma1e-20·허용오차·scale·보호·187개 요청 시각·전극별241개 좌표 유지.
- 사용자 CPU 추가 승인에 따라 16코어 실행. 20코어 요청은 도구 범위1–16 검증에서 job 생성 전에 거부됐고, 당시 기존30개 ID 불변을 확인했다. 실제 새 job/solve는 한 개다. 기준2코어 대비 병렬 실행 차이를 별도 기록한다. 대기시간1200→1800초는 작업 중단 예산이며 물리5초·solver 조건이 아니다.

## 완료된 확인

8개 비교는 요청 시각과 정확 공통 저장 시각 각각의 .1–1, 1–5, 0–1, 0–5초다. 시각 보간·근접 시각 대체를 하지 않았다. 공통 저장 시각 수는 새 저장 결과에서 정했고 사전 고정하지 않았다. 값 비교에서1초는 두 인접 창에 포함되지만 accepted 간격은 경계를 완전히 포함하는 구간에만 배정한다.

- 지정187개 전체 최대 전압 차: 0.002344230141299999909201574183 mV @ 1.7 s.
- 지정 전체 최대 pointwise 표면 x 차: 3.8702635003e-08 @ 1.7 s.
- 판정 한계: 전압1mV, 표면x1e-4. 5초 끝점 또는 Li 수지 하나로 통과시키지 않는다.
- accepted 간격: 기준986→새1154. .1초와1초 도착/출발, 경계 횡단, 상한 도달 수와 세 구간 분포를 확인했다.
- 후기 두 구간의 실제 최대 간격 감소 확인: True.
- 저장 설정 `tout=tsteps`, `tstepsstore=1` 및 strict 요청 시각과 실제 최대 step 제약을 구분한다. 출력 시각을 내부 step으로 추정하지 않고 실제 저장 시간 이력·native 로그 대응을 확인한다.

1–5초 차이는 앞 구간의 상태 차이를 이어받을 수 있다. 두 후기 구간의 효과를 독립적으로 분리했다거나 참값 오차·전체 시간/공간 수렴·장시간 GO를 입증했다고 쓰지 않는다. 새 최대 시각과 .002/.1/1초의 성분은 같은 시각끼리 분해한다.

## 다음 작업은 별도 승인

현재 실행 큐는 종료한다. 추가 계산 횟수는0이다.

- 후보 B, 물리축300/320→600/320 교차 비교는 미승인·보류다. 실행하려면 기준 해·시간조건·단일 변경 축·횟수를 별도 확정한다. 기존300/40→600/40 결과로 대신하지 않는다.
- 추가 시간반감, 메시 세분, 전체 프로토콜, 12시간 휴지, 유한sigma 및 sweep은 모두 미승인·보류다.
- solver 실패나 필수 검사 미완을 설정 변경·재시도로 덮지 않는다. 추가 실행 전에 원인·상태를 사용자에게 회신한다. 다른 원인의 실패를 INCOMPLETE_RANGE_STOP으로 자동 분류하지 않는다.

## 보호와 보존

OCP 외삽 금지와 OCP 입력/고체 표면 조성 StopCondition을 유지했다. **전해질 양수는 후처리 검사**다. 전해질 음수까지 실시간 중단한다고 기록하지 않는다. 장기 모델의 필요한 추가 보호는 별도 배선·시험 대상이다. OCP·초기 조성·Li 재고를 바꾸거나 초기 전압을3.0524V로 보정하지 않는다.

기존 failed·INCOMPLETE_RANGE_STOP·원본 ZIP·원자료·이전 생성 영수증은 보존한다. 변경 전 계획서는 [보존 사본](late_cap_a/NEXT_RUN_PLAN_before_late_cap_a.md)에 있다. 최신 수신 확인은 [별도 추가 기록](post_r320_timecap_plan/RECEIPT_CONFIRMATION.json)으로 유지한다. 이전 수신 ZIP은632,054,218bytes·SHA e38968f13e3fae64948c2234fb020cad1d5f1119fc8535aa7fc8766e69274f67이고160payload+manifest/CRC/history333이 사용자에게 확인됐다. 옛 현지967개 목록 중 직접 포함56개(55불변+계획서 변경 전 사본1개) 확인을 전체967개 외부 검증으로 확대하지 않는다. 이번 현지 보존 목록 전체도 수신 측 검증과 구분한다. 이전 TIME_CAPS 두 raw ZIP 차이 원인은 미확인이다.
