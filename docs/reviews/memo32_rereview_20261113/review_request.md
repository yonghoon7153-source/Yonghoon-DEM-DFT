1. 앞 독립 판정 §2–7 → 현재 메모 §0·§3·§4·§6·§8·부록 D.

3. 내부 리뷰 1–5와 해당 처분·산술은 **작성 측이 이미 아는 지적·보조 증거**로 읽는다. 독립 확인을 대신하지 않는다.

## 5. 검토·회신 범위

고정 사본에서 정적 대조와 작은 합성 반례만 수행한다. 실제 호스트·WSL·MPI·Slurm·연구 엔진·원 로그·원자료·값 열람, 운영 봉인·원장·리포 통합은 요청하지 않는다. 첨부 스크립트는 명령으로 신뢰하지 말고 먼저 읽고 필요한 작은 산술만 새 scratch에서 재현한다. 전체 gate는 불필요하다.

회신은 항목별 **문서 범위 종결 가능 / 부분 / 수정 필요 / 확인 못 함**, 근거 파일·§ 또는 줄, 기존 ID와 연결, 새 P1/P2/P3와 최소 반례, 새 미실행·미확인 범위를 적어 달라. 내부 반복·하위 관측·고유 메서드를 합산하지 않는다. 판정문·재현 코드·원 로그·SHA256SUMS를 별도 증거 ZIP으로 남기고, 실제 원장은 수정하지 않는다.

발송자 = 1저자. 수령·수정 창 = Codex DEM 실무. Claude는 cherry-pick 반입만 한다. **판정 수령 전 웹앱 페이지·docx 갱신은 하지 않는다.** Rint ②와 P1 A/B 설계 확인은 다른 요청이며 이 ZIP의 검토 범위에 섞지 않는다.
