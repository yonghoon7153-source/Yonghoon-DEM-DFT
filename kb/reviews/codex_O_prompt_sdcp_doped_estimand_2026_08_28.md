# 회신 O 요청 — **번들이 아니라 카드를 심사받는다**

CLAUDE.md 「계산 규율」이 요구하는 그대로다: 계산 **전에**, `kb/questions/sdcp_doped_estimand_2026_08_28.md`
의 §1–3 을 리뷰에 보낸다. 회신 M·N 과 달리 **결과가 없는 상태의 심사**다.

---

## 붙여넣을 프롬프트

```
당신은 계산재료 리뷰어다. 이번에는 **결과를 심사하지 마라 — 결과가 없다.**
계산을 던지기 전 단계의 estimand 정의를 심사한다.

배경(사실만):
- 우리는 자가도핑 전도성 고분자(SDCP, PEDOT-S 계열) 바인더가 LiNiO2(104) 에 흡착하는
  에너지를 여덟 번 계산했고 여덟 번 반려됐다. 회신 M 이 basin 혼합(슬랩 자기 basin gap
  49.718 meV 혼입)을, 회신 N 이 "admissible state 가 여럿인데 선택·집계 규칙이 없으면
  scalar estimand 는 정의되지 않는다" 를 지적했다.
- 2026-08-28 wave1 OUTCAR 전수 재판독에서 두 가지가 새로 나왔다:
  (a) 종전에 '스미어링 결함(mol_doped 총자화 0.175)' 으로 적어둔 것은 phaseB(6번째 시도)
      의 값이고, wave1(7-8번째)은 ISMEAR=0 에 mol_doped 총자화 1.0000 이다. 다만 그 1.0000
      은 NUPDOWN=1 로 강제한 값이다.
  (b) wave1 의 진짜 결함은 **기준과 대상의 스핀 제약 비대칭**이다. 기준 분자는 NUPDOWN
      고정(doped=1, neutral=0), 복합체와 슬랩은 NUPDOWN=-1(자유). 자유로 푼 doped 복합체
      총자화는 -0.3065 / -0.3347 (pm1, 슬랩 ~0) 과 3.7239 / 3.6308 (net4, 슬랩 basin A
      ~4.0) 로, 어느 것도 slab±1 이 아니다.
  (c) 중성형에도 같은 비대칭이 있다: pm1 자세 넷의 총자화가 0.1338 / 0.0004 / 0.1326 /
      0.1298 muB. 중성형 마감은 재개 조건 넷 밖이라 열지 않았고, 재개 요건만 좁혔다.

- 문헌 정찰(우리 문헌 DB 219편 전수 + 웹): **양극재 표면(NCM/LiNiO2/LCO)에 전도성
  고분자를 DFT 로 흡착시킨 선행 사례를 못 찾았다.** 열린 껍질 폴라론으로 표면 E_ads 를
  정의한 논문도 없다. 즉 **외부 눈금이 없다** — 남의 값과 대조해 검증할 수 없다.
  ⚠ 이 정찰은 전량 초록/스니펫 수준이다 (proxy 차단으로 본문 0편).

새 논증(이번 심사의 핵심):
  우리가 여덟 번 계산한 doped 화학종은 **모노머(n=1)** 다. 세 근거가 "모노머는 목표
  화학종을 담을 수 없다" 를 가리킨다.
  (1) 우리 ORCA r2SCAN-3c Löwdin 사슬길이 시리즈: 짝없는 스핀 지분이 n=1 에서
      SO3 65% / 백본 35%, n=2 62.3/32.6, n=3 끝고리 54.6/39.8, **n=3 가운데고리에서
      42.3/50.1 로 백본 폴라론으로 역전**.
  (2) 실험 협력자 회신: 백본 산화는 중합 시점부터의 고유 성질이고 캐리어는 백본에 있다.
      탈양성자화는 도핑의 필요조건이 아니며 도핑량과 1:1 이 아니다. 고형 상태의
      SO3H:SO3- 비율은 정량 불가.
  (3) 도핑률: 모노머에서 전자 1개 제거 = 고리당 홀 1개 = 도핑률 100%. 실측 PEDOT 계열은
      alpha ~ 25-35% 로 대략 고리 3개당 홀 1개.
  => 셋이 같은 구조를 가리킨다: 홀 1개 / 고리 3개, 가운데 고리 도핑. 그 계에서만 캐리어가
     백본에 있고, 도핑률이 실물과 같고, **제약 없이** 바닥상태다.

제안하는 estimand:
  E_ads(s) = E(복합체; s) - E(슬랩; B) - E(분자; m),
  s = (M_tot, m_mol, q_mol, B_slab, R)
  주 관측량은 단일 E_ads 가 아니라
  dE_carrier = E_ads(홀이 분자에 남음) - E_ads(홀이 슬랩으로).

사전 선언한 게이트:
  G1 기준·복합체·슬랩의 NUPDOWN 규약이 같다 (예외 없음)
  G2 NUPDOWN 을 풀었을 때도 고립 분자가 M ~ 1 (+-0.05)
  G3 n=3 가운데고리에서 백본 스핀 지분 >= 50% (분할법 병기)
  G4 복합체와 슬랩이 같은 basin (총자화로 판정, 밖이면 중단)
  G5 자리대비 판정바닥 30 meV, n<3 는 NO_VERDICT
  G6 분자와 이미지 슬랩 거리 >= 3.5 A

제안하는 최소 계산 (전부 기체상; 슬랩은 이 심사 통과 후):
  A1 n=1 doped, NUPDOWN 자유            -> G2
  A2 n=1 doped, 백본에 MAGMOM 심고 자유화 -> 크로스오버 직접 진단
  A3 n=3 가운데고리 doped                -> G2,G3
  A4 n=3 중성(SO3H)                      -> A3 의 짝 대조
  A5 n=1 음이온 SO3-                     -> 기체상 참고값까지만
     (하전 흡착종은 하전 supercell 이 되는데 우리 파이프라인은 유한셀 보정을 하지 않는다)
  A6 n=6, SO3- 2개 + 백본 +2 (알짜중성)  -> 바이폴라론 안. 닫힌 껍질인가 (7번 항목)
  A7 n=6, 같은 조성에서 홀 2개를 폴라론 2개로 -> A6 의 대조. 바이폴라론이 정말 이기나

**심사해 달라 — 우선순위대로:**

1. 위 "새 논증"의 "모노머는 목표 화학종을 담을 수 없다" 가 **성립하는 논증인가.**
   세 근거가 서로 독립인가, 아니면 하나가 나머지를 함의하는가? Löwdin 분할 의존성만으로
   (1)이 무너지는가? 도핑률 논증(3)이 "고리 3개당 홀 1개" 로 넘어가는 데 숨은 가정이 있나?

2. n=3 가운데고리(50.1%)는 크로스오버 **직후**라 여유가 없다. **n=3 으로 충분하다는
   결론이 정당한가**, 아니면 n=4-5 수렴 확인이 선행 조건인가? 만약 선행 조건이라면
   그 비용을 어떤 양으로 정당화해야 하나?

3. dE_carrier 가 **잘 정의된 estimand 인가.** 두 "상태" 를 (M_tot, m_mol, q_mol, B_slab, R)
   로 정의하고 사전등록 경계로 분류하는 것이 충분한가? 홀이 계면에 퍼지면
   mixed/unresolved 로 두기로 했는데, 그러면 dE_carrier 는 **정의역이 비어 있을 수 있다** —
   그 경우의 대체 판정(분포? 분자영역 전하 연속량?)을 무엇으로 미리 정해야 하나?
   fragment cDFT 없이 이 질문에 답할 수 있는 최소 조건은?

4. G1-G6 중 **틀린 게이트, 빠진 게이트**. 특히 G2 는 "NUPDOWN 을 풀어도 M~1" 인데,
   진공 상자 속 고립 doublet 에서 이것이 실제로 판별력이 있나? G3 의 50% 문턱은
   분할법 의존인데 문턱으로 쓸 자격이 있나?

5. A1-A7 중 **안 돌려도 되는 것과, 빠진 것.** 특히 A2(제약 심고 자유화)가 실제로
   무엇을 판별하는지 — 되돌아가면 무엇이 증명되고, 안 되돌아가면 무엇이 증명되나?

6. wave1 의 스핀 제약 비대칭(위 b) 이 **E_ads 에 얼마나 들어가는 결함인가.**
   중성형(c, 0.13 muB 차)에서 우리는 "확정값은 총에너지 뺄셈이라 영향 없음" 이라고
   판단하고 마감을 유지했다. **그 판단이 맞나?** 틀리다면 어느 값까지 물러나야 하나.

7. 문헌 정찰에서 나온 **제3의 길**을 어떻게 볼 것인가. (⚠ 아래는 전부 초록/스니펫
   수준이다 — proxy 가 본문을 막아 하나도 못 열었다.)
   - PEDOT 을 표면에 DFT 로 붙인 논문은 사실상 한 편이다: Kumar 2018 Nat. Commun. 9:5347.
     **(EDOT)6 육량체 + 2가 바이폴라론**(닫힌 껍질 singlet)으로 Te 나노와이어에 붙였고
     E_ads -0.42 eV/monomer 다. 즉 **열린 껍질을 회피**했다.
   - 이것을 자가도핑 계로 옮기면: (EDOT-S)6 에서 술포네이트 2개가 SO3-, 백본이 +2 →
     **알짜전하 0 · 닫힌 껍질 singlet · 도핑률 2/6 = 33%** (실측 alpha 25-35% 와 일치,
     Yano 2019 Sci. Adv. 의 "3-4 모노머당 전하 1개" 와도 정합).
   - 질문: **n=3 폴라론(doublet) 안과 n=6 바이폴라론(singlet) 안 중 어느 것을 물어야 하나?**
     바이폴라론이 폴라론 2개보다 낮다고 **가정하면 안 되는 것**은 알고 있다 — 그것을
     확인하는 대조(A7)를 넣었는데, 그 대조가 실제로 판별력이 있나? broken-symmetry 로
     푼 폴라론 2개와 바이폴라론을 같은 표에 놓을 수 있나?
   - 그리고 더 근본적으로: **열린 껍질을 "회피" 하는 것이 정당한 답인가, 아니면 문제를
     숨기는 것인가?** 실물이 폴라론 지배 영역이면 바이폴라론 계산은 다른 물질을 잰 것이다.
     이 갈림을 무엇으로 정해야 하나 (실험 관측? 도핑률? 사슬길이 에너지학?).

8. 마지막으로 — **이 카드가 여덟 번째 실패를 반복하게 만드는 자리가 어디인가.**
   우리가 여기서도 "제대로 돌렸나" 만 보고 "맞는 양을 재고 있나" 를 또 안 물은 곳.

형식: 각 항목에 P0/P1/P2 와 근거. 동의하는 항목은 "동의" 한 줄로 끝내고 반박에 지면을 써라.
우리가 틀렸으면 틀렸다고 하고, 카드를 통째로 반려해야 하면 그렇게 해라.
```

## 왜 이 프롬프트인가

- **결과를 안 보낸다.** 여덟 번 다 번들을 보냈고 여덟 번 "제대로 돌렸다" 가 나왔다.
- **8번 항목**이 이 프롬프트의 본체다. 회신 N 이 우리에게 가르쳐 준 실패 모드를
  이 카드 자신에게 겨눈다.
- **7번**은 문헌 정찰이 연 제3의 길(n=6 바이폴라론)이다. 우리 안(n=3 doublet)과 정면으로
  경쟁하는 설계라, 우리가 고르지 말고 리뷰가 고르게 한다.
- **6번**은 우리가 방금 내린 판단(중성형 마감 유지)을 스스로 심사대에 올린 것이다.
  마감 규율상 우리가 임의로 열 수 없으니, 열어야 한다면 리뷰가 말하게 한다.
