## 2. H_S 와 판별력 — 결과 전 문장

> **이 절과 §3–§6 의 지표 · 문턱 · 처분은 결과를 본 뒤 옮길 수 없다.**  바꾸려면 결과 전 개정 (1저자 비준) 만 한다.

- **H_S**: "②-a 되튐 지표 m1 의 S/F 비 구간이 1 을 포함하고 판별력이 섰으면, 이 2D 배치 · 이 지표 · 이 구간 폭에서 F 가 S 보다 나은 근거가 없다.  탈압에서도 S 로 간다 (F 는 접는 후보 · 최종은 ②-b 뒤 1저자)."
- **격자 불확실성 U** = 사다리 규칙이 낸 팔 구간.  S/F ln 구간 = [lo_S − hi_F, hi_S − lo_F] — 폭 = 두 팔 폭의 합.
- **대조 팔 (기대 차이의 자리)**:
  - C1 = F②(µ 0) — 마찰만 끈 F (지금 커널 · 인자만 · **GO 안**).
  - C2 = 늘-붙음 F — 분리 판정만 끈 F (한 번 닿은 쌍은 떨어지지 않는다 · 시험 전용 · 메모 3.2 U7 의 음성 대조와 같은 코드 · **구현 필요 · 이번 GO 밖**).
  - **판별력 섬 (C)** ⇔ ln(F/C) 구간 [lo_F − hi_C, hi_F − lo_C] 가 0 을 포함하지 않는다.  대조 팔 구간이 미확정이면 그 대조는 판별력을 보이지 못한 것으로 센다.
- **결과 전 크기 어림** [우리 산술 · 가정]: 탈압 지표의 팔 구간 폭이 Q13 가압과 같다면 (0.17–0.19), S/F 구간 폭은 약 0.36 이다 → **약 ±20 % 보다 작은 S/F 차이는 이 시험으로 가를 수 없다.**  두 팔이 모두 δ 만 남기는 가장 좋은 경우에도 폭은 4δ = 0.08 (약 ±4 %) 이다.
- 대조 팔이 S/F 의 기대 차이를 대신할 수 있는 근거: S 는 "붙음 + 무한 마찰" 쪽 (한 속도장) 이다 (메모 3.2 DRD-11 · S 의 열림은 커널 가중으로만).  F 와 S 의 차이는 분리와 미끄럼 둘로 이루어진다.  C1 은 미끄럼 쪽, C2 는 분리 쪽 하나씩을 지표가 볼 수 있는지 잰다 [우리 해석].

### 3-3. 지표

- **m1 (판정) 되튐** e = h_sep / h_u − 1.  h_sep = 탈압 중 윗판 압력 (윗판 힘 ÷ 침대 폭 · 아래판 압력과 같은 정의) 이 0.008 MPa 이하가 되고 **그 뒤 런 끝까지** 그 아래에 머무는 첫 걸음의 판 높이.  런 끝까지 그런 걸음이 없으면 "미분리" → 그 팔 m1 없음.
- **사다리 규칙** = `scripts/suyoung_u6b36_dev.py` 의 `arm_rule` 을 x = ln e 에 그대로 쓴다 (A: 같은 부호 · 0.29 ≤ \|d₂\|/\|d₁\| ≤ 0.75 → [x₃, x₃ + 3d₂] ± δ · B: max(\|d₁\|, \|d₂\|) ≤ τ 이고 부호가 섞임 → 반폭 δ + 3 × 최대 \|d\| · δ = τ = 0.02).  e ≤ 0 이면 ln 이 없어 그 팔 보류.
- **m2 (보고) 탈압 계수**: 아래판 압력이 탈압 시작 값 P_u 의 0.9 배 → 0.5 배로 처음 떨어지는 두 걸음 사이의 할선 기울기 (압력 ÷ 판 높이 변형 (h − h_u)/h_u).
- **m3 (보고)**: 탈압 끝 아래판 압력 · F 의 열린 접촉쌍 수 (공유 노드가 있는데 마지막 걸음 법선 충격량 0 인 원판 쌍).
- **가압 보고**: 같은 런의 가압 구간에서 Φ_m 0.84 · 0.90 압력 (S · F② 는 Q13 과 같아야 한다 · C1 은 새 값).
- **U4 (2D) 판정 (결과 전)**: 탈압 중 윗판 압력 < −0.008 MPa (판이 침대를 끌어당김) 인 걸음이 모든 팔 · 모든 격자에서 0 개 → **U4 (2D) 합격** · 하나라도 있으면 불합격.  2D 판은 구조상 한쪽이라 합격이 기대지만 실측으로 확인한다.  0.008 MPa = U6(b) 잡음 바닥 재사용 (`scripts/suyoung_u6b_dev.py` `THETA_MPA`).
