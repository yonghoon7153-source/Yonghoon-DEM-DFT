## 2. 구현 계약

- RT30 = c_ul_ph[1]–[30] 정확한 차례. 필수 열 결손/파일 부재/양쪽 0행은 NOT_COMPUTED. 잘못된 머리·열 순서·추가 열·행 수·비유한·정확하지 않은 ID·시점·충돌 중복은 FAIL. 한쪽 0행/쌍 집합 차도 FAIL.
- ID는 원 토큰 Decimal로 양의 정수·상한 2^53을 확인한다. 나머지 수치는 유한 binary64로 읽는다. 임의 십진수의 정확 연산이나 이미 반올림된 입력의 복구를 주장하지 않는다.
- 무순서 ID 키, 방향 반전 때 위치 교환·힘 9/전단 이력 3 부호 반전, deltaMax 보존. 위치·접점 x/y 감음. torque·주기 표지는 수치 판정 밖이다. 비교 24열의 RT1 절댓값 중앙값을 바닥으로 쓰는 상대 허용값 1e-5를 적용한다.
- 동일 중복은 기존 1e-12×max(1,기준 절댓값)로 접는다. 다른 중복은 거부한다. 주기 거리·힘·중복의 기존 공통 열 처분을 합성 31사례에서 원 26열 대조기와 비교했다.
- 연속성 ⓡ = 26↔26, ⓣ = RT30의 26열 사영↔원 26. 공통 하중 쌍의 r>0.5를 reset_like로 셈한다. 원 접선력 크기 가중 W≤0.05, 쓴 격자 각 칸 W≤0.5, 각 칸 하중 쌍≥100, 쌍 집합 같음이 모두 필요하다.
- 쓴 격자 축/NP/단일 grid 줄/활성 balance를 확인한다. 원 덤프 상자·원 위치로 칸을 정하며 경계 1e-12×L 이내 원자는 안쪽에서 뺀다. 원 덤프 밖의 시험 위치로 칸을 다시 나누지 않는다.
- 계산된 집합/전역/유효 칸 위반이 미확정보다 우선한다. N=99 칸이나 격자 부재를 PASS로 바꾸지 않는다. 6×4의 모든 24칸 소실을 별도 대조했다.
- 큰 유한 힘은 스케일을 맞춰 norm/합을 구한다. 양의 가중치가 underflow로 0이 되면 NOT_COMPUTED로 남긴다. 임의 극단값에 대한 완전한 정밀도 자격은 아니다.

보고 전용: 열별 불일치 수·최대 상대차, 접선력/전단 이력의 각 비영 몫, 주기 표지 수, reset_like·r 중앙값·q95·무너짐 몫·칸별 수와 W. q95는 정렬값의 ceil(0.95N)번째(1부터 셈), 무너짐은 |Ft_test|<0.5|Ft_orig|로 명시했다. q95 보간 관례는 판정에 쓰지 않는다.
비트 수는 canonical 선택 24열 및 방향 정규화한 전체 30열의 binary64 바이트를 따로 비교한다. 파일 전체 SHA256 동일성과 구분한다. 원자 기본 12열/추가 벽 이력 보고는 다음 소비자 연결 몫이다.
