검토일: 2026-09-15 · **26/26개 PDF, 612/612쪽 확인 완료**

`1 Introduction.pdf.zip`의 PDF 25개와 별도 `머신러닝.pdf`를 대상으로 전 페이지 텍스트와 렌더링 이미지를 확인했다. 문자 추출량이 적은 수식·도표·이미지 페이지도 렌더링으로 읽었고, 적용상 핵심인 페이지는 개별 확대 대조했다. 강의 전반을 읽은 기록이며, 모든 수학적 유도를 독립적으로 재증명하거나 강의가 인용한 모든 논문을 원문 재검증한 작업은 아니다.

페이지는 인쇄된 슬라이드 번호가 아닌 **PDF의 1부터 시작하는 실제 페이지**다. 파일명의 중복 `.pdf`, `Dropbout` 등의 표기는 원본을 따른다. ‘차용’은 검토·설계에 반영한다는 의미이며 구현·성능 확인을 뜻하지 않는다.

적용 우선순위와 2차 계획은 [불량셀 적용 인사이트 보고서](<불량셀_ML_문서정독과_적용인사이트.md>)에 정리했다.

## D26 — 머신러닝.pdf · 26쪽

**내용:** BML 세미나 형식으로 EIS·DRT·전압/전류 특징을 Normal/Severe 분류 또는 SOH·저항 회귀와 연결한다. p.2–5는 문제와 모델 목록, p.6–7 GPR, p.8–9 KNN, p.10–13 Tree/RF, p.14–17 SVM, p.18–21 L1/L2 Logistic, p.22–23 Ensemble, p.24–26 비교와 선택 지침이다.

**차용할 내용:** 모델 출력·입력 스케일·과적합·중요도 방식·불확실성을 비교하는 설명 틀은 현재 작업에 직접 유용하다. 특히 GPR의 불확실성, 상관 특성에서 L1 선택의 불안정성, 공통 기준으로 평가하는 permutation의 발상을 활용한다.

**적용 전에 보정할 부분:**

- p.6–7: GPR도 커널·잡음 가정을 사용한다. 관측점을 항상 통과하거나 먼 곳의 불확실성이 항상 실제 위험을 정확히 반영하는 것은 아니다. 역길이척도는 조건부 모델 민감도 단서이며 물리 원인 순위가 아니다.
- p.9·15: permutation은 평가 자료와 지표를 정해야 한다. 1개 셀짜리 LOOCV 평가 fold 내부에서는 일반적인 행 섞기가 의미를 갖지 못한다.
- p.11–13: MDI는 모델의 분기 기여이고, 트리 간 오차막대는 모집단 일반화의 신뢰구간과 다르다.
- p.17–21: 계수 크기는 스케일과 상관관계에 의존한다. L2가 모든 계수를 반드시 0이 아닌 값으로 남긴다는 설명은 엄밀한 보장이 아니다. L1의 0도 물리적으로 불필요하다는 증명이 아니다.
- p.22–23: 앙상블의 성능 향상은 조건부다. 멤버 중요도의 단순 평균은 서로 다른 척도를 섞으며 최종 모델의 중요도와 같지 않다. 향후 stacking을 한다면 메타모델 입력도 학습 셀에 대한 독립 예측으로 구성해야 한다.
- p.24–26: 비교표와 선택 지침은 교육적 개괄이다. 실제 불량셀 데이터에서의 모델 순위나 검증된 성능을 제시한 벤치마크로 읽지 않는다.

`logp32_t`, `p3_h_ratio`, `p3_ht`, `p32_hr`의 정의·단위·추출 방식과 예시 값의 데이터 근거는 별도 확인이 필요하다. 문서의 Severe를 현재 코드의 용량 90% 이하와 같은 라벨로 간주하지 않는다.
