**D-1. 점 등급** (한 점 · 충전 k = 1 · 2 · 3 · 판정 단 n = 12 · 16 · 24 · 8 셀은 B 에만)

```
입력  st[k][n]  (n = 12 · 16 · 24)
        = 둘다닿음 | 분모만못닿음 | 분자만못닿음 | 분모만잡음 | 분자만잡음 | 둘다못닿음또는둘다잡음
        (분모만잡음 = 두 팔 모두 닿고 분모 ≤ θ · 분자 > 1.15 θ · 분자만잡음은 그 거울 ·
         한 팔 ≤ θ 이고 다른 팔 ≤ 1.15 θ 면 둘다못닿음또는둘다잡음)
      σ분자[k][n] · σ분모[k][n]  (n = 8 · 12 · 16 · 24 · 닿은 팔만 · 잡음 팔은 값이 아니라 위 경계 θ)

팔규칙(x ; δ , τ)       x = 한 팔의 ln σ (네 단)
   d0 = x(12) − x(8) ;  d1 = x(16) − x(12) ;  d2 = x(24) − x(16)
   A   d1·d2 > 0 그리고 0.5·|d1| ≤ |d2| ≤ 1.1·|d1|
         → 구간 [ min(x24 , x24 + 3·d2) − δ , max(x24 , x24 + 3·d2) + δ ]
           (d0 가 d1 · d2 와 반대 부호면 "점근 영역 의심" 표지 · 구간 불변)
   B   A 가 아니고 · x(8) 이 있고 · (d0 , d1 , d2) 가 0 아닌 같은 부호가 아니고 · max|d| ≤ τ
         → 구간 [ x24 − (δ + 3·max|d|) , x24 + (δ + 3·max|d|) ]
   그 밖 → 미수렴
   (3.2 초안의 "|d1| ≤ δ 그리고 |d2| ≤ δ" 길은 없앴다 · 1 회차 P1-2.
    1 회차 고친 판의 "q = ln σ분자 − ln σ분모 자신의 세 값으로 구간" 은 거뒀다 · 2 회차 MR2-01 · q 의 값은 보고만)

1. 어떤 k 에서 세 단 모두 분모만못닿음                        → 반대
2. 아니고 어떤 k 에서 세 단 모두 둘다못닿음또는둘다잡음          → 버림
3. 아니고 어떤 k 에서 세 단의 상태가 서로 다름                  → 중간 (미수렴)
4. 아니면 k 마다 (세 단의 상태가 같다)
     분자만못닿음   lo_k = hi_k = +∞
     둘다닿음       두 팔 모두 팔규칙 ;  어느 팔이든 미수렴 → 점 중간 (미수렴)
                    lo_k = lo(분자) − hi(분모) ;  hi_k = hi(분자) − lo(분모)
     분모만잡음     분자 팔만 팔규칙 ;  미수렴 → 점 중간
                    lo_k = lo(분자) − ln θ ;  hi_k = +∞
     분자만잡음     분모 팔만 팔규칙 ;  미수렴 → 점 중간
                    lo_k = −∞ ;  hi_k = ln θ − lo(분모)
5. 충전마다의 조건을 먼저 본다 (평균은 그 조건이 선 뒤에만 · +∞ 와 −∞ 가 섞인 평균은 내지 않는다)
   다름   모든 lo_k ≥ ln 1.15              그리고  평균_k lo_k ≥ ln 1.3
   같음   모든 k 에서 lo_k ≥ −ln 1.3 · hi_k ≤ ln 1.3   그리고  평균 lo ≥ −ln 1.15 · 평균 hi ≤ ln 1.15
   반대   모든 hi_k ≤ −ln 1.15             그리고  평균_k hi_k ≤ −ln 1.3
   그 밖  중간
```

lo_k ≤ hi_k 라서 다름 · 같음 · 반대는 서로 겹치지 않는다.  한쪽이 열린 충전 (잡음 · 못 닿음) 이 하나라도 있으면 같음은 나오지 않는다.  A 등급 (Δφ) 은 같은 꼴이다: 팔은 Φ_m(F) · Φ_m(A) (P/E 0.4 에서 읽음) · δ = τ = 0.002 · Δφ_k 구간 = [lo(F) − hi(A) , hi(F) − lo(A)] · 문턱은 0.02 · 0.01 · 어느 팔이든 미수렴이면 중간 (§4 단계 3 "A 등급의 해상도").  Δφ_k 자신의 세 값은 보고만 한다.
