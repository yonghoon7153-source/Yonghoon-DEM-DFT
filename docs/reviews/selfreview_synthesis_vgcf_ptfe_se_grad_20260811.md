## §2. 계획서가 어떻게 바뀌었나 (P-항목별 최종 상태)

### P1 (카본 등급 프리셋) — **축소·강화 후 생존**
- MWCNT 두 등급은 `--carbon-grade` 선택지에서 **제외** (SSA 역산 d 4–10 nm = 완전 sub-voxel,
  시딩 시 객체 ×450 인데 `seed_fibres` 에 max_pts 캡 없음, 검증은 순환) → 앵커 CSV 데이터 행으로만.
- 리팩터 반경이 "additives.py+CLI" → **6곳**으로 확장 (_add_meta d/L 기록 · comsol_export 단면
  하드코딩 · 버클창 모듈상수 · dilate-z 곡선 grade 체크 · dispersion 비교 불가 라벨 · 중복상수 상호참조).
- **등급 간 σ_e 비교 금지 라벨** (스탬프 인플레가 등급 간 2.25× 다름).
- SSA "±10% 정합" 은 캘리브레이션이 아니라 **정합 기록** (18.6 = 방법 미상 stated).

### P2 (퍼콜 앵커) — **범위·창-조건부로 재정의 후 생존**
- 1.40× 점앵커 → **평균비 1.40 [CI 1.22–1.60] · 중앙값비 1.61 · 대면적 2D 3.58×** 병기
  (유효 n ≈ 37/25, 자기상관 보정).  "1.4 = 상한" 주장 **철회** (같은 논문이 3.58× 로 반증).
- 스키마 = per-paper lit CSV + `#` 정의 블록 (`zhang2026_dry_cbd_percolation.csv`,
  bielefeld2019 선례, `precision=exact_sourcedata`).
- 물리 T5 추가: **216× AM-우회 전류비** (우리 STEP3 per-AM `je` 와 가장 1:1 인 관측치) +
  "균일도 ≠ 연결성" (우리 dispersion CV 의 σ_e 판별력 없음 실측) 등재.

### P3 (VGCF 상관 배치) — **대폭 약화.  내 권고: 보류(사실상 drop), 최종은 Codex+사용자**
세 렌즈가 각자 다른 방향에서 깎았다:
- 구현 T1: 새 seeder 파라미터 불요 (2-pass self-nucleate 디스패치 + PTFE 공정행 귀속) —
  노브 자체는 **정직해졌다**.
- 통계 D2: 효과크기 앵커가 창-의존 (1.4–3.6).
- ★ 물리 T3: **production vox 0.4 에서 타깃(NN −31%)이 σ 채널에 아예 안 보인다**
  (250 vs 360 nm 연결확률 1.00/1.00).  보이는 격자에선 유령 (절연 간극 도통).
  타깃값 출처도 pair-시계열이라 −31% 정량 전이 불가 — **방향만** 남음.
- 남은 실행 가능형: "vox 0.4 고정 · 다시드(≥12) 평균 · 방향만 보고" (Δσ_e +22%±23% 실측 —
  신호가 시드 노이즈와 동급).  ⇒ **비용 대비 얻는 것이 "방향 한 비트"** 다.
  §7-Q1 이 재정식화됐다: "노브는 정직해졌는데 읽을 수 없는 것 아닌가".

### P4·P5·P6 (하지 않는 것) — **판정 유지** (P6 은 물리 T4 각주: 논문의 실제 레버인 PTFE
피복 차감은 #30 이 원리적으로 못 보고, 시드-레벨 f_PTFE-on-carbon 통계 훅으로만 가능).

### `--se-grad` 계획서 — **이번 3각 리뷰의 대상이 아니었음** (별도 문서, Codex §G 로 회부).
단 이번 리뷰의 교훈 두 개가 그대로 이월된다: ① 읽기 격자를 명시하라 (STEP4 격자 vs STEP3
vox vs MPM dx — se-grad 의 V1–V4 는 STEP4 채널이라 이번 A1 류 혼동 여지가 적지만 명시 필요)
② 사전등록 검증이 공허하지 않은지 (V3 두께-스케일링의 "격차≈0" 판정 기준을 시드 CV 대비로
정량화해야 함).

## §3. ★ 계획서 밖 production 발견 — SR-01 (원장 등록)

물리 렌즈 X3: **현행 STEP3 탄소 채널은 이미 조각난 섬유 위에서 돌고 있다.**
첨가제 점 간격이 MPM dx 에 묶여 있고 (0.7·dx ≈ 0.099 µm) 1-복셀 스탬프가 6-conn 이라,
vox 0.4 에서 10 µm 직선 섬유의 **91.7 % 가 평균 4.3 조각으로 끊긴다** (오블리크 스텝의
코너-크로싱).  동일 설정 **상대비교는 공통모드로 생존** (STEP3 v1 트러스트 규약 그대로)하나,
STEP3 σ_e 에서 "VGCF 퍼콜 망" 을 **절대 해석하는 것은 불가**하다.
- 후속 후보: ① per-fibre stamped-component 수를 STEP3 산출물 메트릭으로 (진단 1줄)
  ② 실제 payload 침대에서 세그먼트-스탬프 vs 점-스탬프 A/B (물리 렌즈 실험은 탄소 단독망 =
  상한 성격이라 실침대 크기 확정 필요).
- `docs/reviews/findings.json` 에 **SR-01 (open)** 로 등록 — Codex RC 시리즈와 같은 원장에서
  추적 (RC6-Q8 교훈: 발견을 큐에서 잃지 않는다).
