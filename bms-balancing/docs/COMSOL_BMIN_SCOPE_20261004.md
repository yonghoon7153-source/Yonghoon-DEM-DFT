## §3 비교 창 120–150 s 의 선택 근거

| 근거 | 초기 시험 창 끝 (5 s) | 이번 창 (120 → 150 s) | 출처 |
|---|---:|---:|---|
| 원장이 정한 다음 공간 검사의 자리 | — | "기울기가 발달한 상태 (120 s 이후 …) 에서 한 번" | SPEC §37-5 L3 (l.3037) · R7 (l.2811) |
| 흑연 입자 — 정전류 구 확산의 준정상 표면−평균 차 도달률 | 13.6 % | 55.1 → 59.8 % | 우리 산술 — SPEC §34-1 (l.2798) 재현식 (30 · 60 · 240 s 에서 31.02 · 41.79 · 70.1 % 를 같은 값으로 재현) |
| 흑연 입자 — 확산 길이 √(Dt) / 반경 | 0.025 | 0.123 → 0.138 | 우리 산술 (D 7.1e−15 m²/s · 반경 7.5 µm — SPEC l.96 · 98) |
| 양극 입자 — 같은 도달률 | 35.0 % | 95.6 → 97.6 % | 우리 산술 (120 s 95.6 % 는 SPEC l.3136 의 값과 같다) |

| 음극 표면 분율의 전극 내 폭 (241 좌표의 최대 − 최소) | 2.51e−5 | 2.70e−4 @120 s · 3.22e−4 @180 s | R480 selected_ranges · 차는 우리 산술 |
| 단자 전압 변화율 | — | 120 → 180 s 평균 +1.42 mV/s (2.81929 → 2.90430 V) | R480 selected_times |

- **초기 시험이 본 것은 입자 표면의 얇은 경계층이다** — 5 s 에 흑연 확산 길이가 반경의 2.5 % 이고, 다섯 비교의 최대가 모두 첫 0.04 s 안에
  났다 (§1). 120–150 s 에는 흑연 입자 안의 농도 분포가 준정상 표면−평균 차의 절반을 넘게 발달했고, 양극 입자는 거의 준정상이며, 전해질 농도
  폭은 480 s 값의 78 % 를 넘었다. 입자 반경 메시가 이 **발달한 분포**에서도 같은 크기의 두 설정 간 관측 차이를 내는지는 초기 시험이 답하지
  않는다 — 이것이 L3 의 물음이고, 가장 민감했던 축이 입자 축이라 (§14: 160 ↔ 320 이 한도의 약 62 %) B-min 이 그 축을 먼저 본다.
- **120 s 에서 시작하는 이유:** L3 가 정한 가장 이른 자리이고, fresh 실행은 0 부터 적분하므로 창이 늦을수록 비용이 늘어난다 (§6 — 320 메시에서
  모의 1 s 당 compile+batch ≈11.7 s).
- **150 s 에서 끝내는 이유:** 한 시각이 아니라 **창**으로 보기 위한 최소 길이다. 요청 격자 (5 s 이후 0.1 s) 에서 301 개 요청 시각을 주며 —
  rtol 시험의 5–30 s 창 (공통 250 시각) 과 비슷한 표본 크기 — 끝 시각 120 s 실행보다 모의 30 s (320 메시 기준 compile+batch ≈ +352 s) 만
  더 든다.
- 이 창은 NORMAL480 저장 범위 안이고, 120 · 180 s 의 표면 분율은 선언된 OCP 표면 범위 안이다 (음극 0.0222–0.0252 ≤ 0.98 · 양극
  0.9181–0.9206 ⊂ [0.2229, 0.9832] — R480 selected_ranges).
- **위 도달률 · 확산 길이는 창을 고르는 근거이지 판정 근거가 아니다** — 조건부 해석해 (고정 재고 · Faradaic 정전류) 의 산술이고, 모델의 공간
  해가 어떻게 바뀌는지를 예측하지 않는다.

- 결과를 본 뒤에는 창 · 한도 · 지표 · 시각 집합을 바꾸지 않는다. 더 보는 분석은 "사후" 라벨을 붙이고 판정에 쓰지 않는다.
- `WITHIN_LIMITS_THIS_WINDOW` 가 뜻하는 것은 "이 창 · 이 표본에서 입자 320 ↔ 640 두 설정 간 관측 차이가 비교 한도 안" 까지다 — L3 의 입자 축
  한 칸이 닫힐 뿐 수렴의 증명이 아니다.

## §7 이 시험이 수용하지 않는 것

- **다른 공간 축** — 물리 메시 (300 ↔ 600) 는 120–150 s 에서도 미검증으로 남는다 (B-std 의 몫 · 이번 아님).
- **480 s 전체 · 다른 창** — 0–120 s · 150–480 s 의 공간 민감도를 이 시험으로 말하지 않는다. 판정 창 밖의 차이는 판정하지 않고 요약에 넣지 않는다.
- **초기 공간 시험 · rtol30 · 기존 0–480 s 분석** — 다시 열지 않는다. §4 의 "나란히" 는 기존 값의 인용일 뿐 그 판정을 바꾸지 않는다.
- 수렴 차수 · 메시 인증 · 1 mV · 1e−4 의 인증선 격상 · 참값 오차 · 실험 타당성 · 유한 σ · 960 s · 장기 운전.
