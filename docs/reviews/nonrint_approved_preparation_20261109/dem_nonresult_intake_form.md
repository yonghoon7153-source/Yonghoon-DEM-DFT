# DEM Q3 — 1저자 제공 비결과 메타·규약 수령 양식

제공자는 **1저자**로 비준됐다. 이번 허용 범위는 빌드 신원, 기존 자격 기록의 메타, 50 kg·0.7/1 µm 비교의 하중 의미/면적/입경/측정 규약에 관한 **메타·규약 문장**이며, 아직 실제 제공 자료는 0건이다. 이 양식은 자료 조회 명령이나 실제 값/원로그 본문 열람 GO가 아니다.

## 4. 50 kg·0.7/1 µm — 선언 규약의 빈 사실표

이미 승인된 비교 목표는 gen2 안에서 **같은 실제 정적 압력·같은 관측 단계**를 비교하는 것이다. 이 양식은 그 비교의 정의를 받으며 압력을 계산하거나 재누르기 캠페인을 시작하지 않는다.

선언값을 제공한 경우에도 그 값은 `DECLARED_METADATA`로만 기록한다. 예를 들어 명목 면적을 받았다는 사실이 실제 힘/압력의 측정·환산 검증이나 같은 정적 압력의 달성을 뜻하지 않는다. 선언/관측 구분이 불명하면 `SCOPE_HOLD`로 두고 정의 문장만 보완한다.
