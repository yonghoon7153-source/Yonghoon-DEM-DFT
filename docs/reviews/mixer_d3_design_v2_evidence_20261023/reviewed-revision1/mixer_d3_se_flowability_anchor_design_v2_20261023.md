## 1. 추정 대상과 주장 범위

대상은 **지정한 접촉·마찰·강성·밀도 세대·CGF·입도 표현·기하·벽 조건에서, 1 g SE 단독 실험과 양립하는 parcel 규모 SE–SE Bo_code 후보 집합**이다. Bo_po = Bo_code / 6.75를 함께 보고한다. 후보 집합은 실제 표면 에너지·실입자 Bo·미지의 참값을 주어진 확률로 덮는 신뢰구간이 아니다.

- T2 동적 안식각과 T1 Hausner 비를 주 보정 조합으로 유지한다. 두 시험의 유효한 후보 집합을 교차한다. T3 흐름 시간/정지와 T2의 다른 속도는 무맞춤 검증에 둔다.
- ρ = γ_NCM/γ_SE는 D4·AFM 층이다. 그러나 시험 벽 값 γ_W/γ_SE = 0.0256ρ 때문에 SE 단독 실험도 지정 ρ·벽 표현에 조건부다. “SE만이므로 ρ와 완전히 분리됐다”는 주장을 하지 않는다.
- μ_s·μ_r·COR·E를 고정한다는 것은 그 값의 타당성을 입증한다는 뜻이 아니다. 두 시험 집합이 겹치면 **모순을 찾지 못했다**고만 말한다. 비어도 마찰 하나가 원인이라고 귀속하지 않는다(PSD·벽·관측·모델 결손도 가능).
- 같은 CGF에서 같은 덱에 후보를 옮기는 데 새 CG 지수를 가정하지 않는다는 뜻만 유지한다. 실험과 parcel의 D/d 차이·응집·정전기·비구형이 모두 등가 Bo 하나로 흡수된다는 보장은 철회한다. 맞지 않으면 조건부 모델이 성립하지 않은 결과다.
- 설계 v1의 문헌표를 새 원문 검증 결과로 재표시하지 않는다. 이번 작업은 기존 정본·코드·해석 반례 대조이며 새 원문 PDF/SI 대조는 하지 않았다.

**보관과 맹검:** S1에서 **보정 자료(T1·보정용 T2)와 검증 자료(T3·검증용 T2 등)의 열람 단위**를 분리한다. 별도 암호화 묶음·키 또는 동등한 접근 통제를 사용하고, 보정 키/권한은 C1 곡선 봉인 뒤, 각 검증 키/권한은 해당 C2 예측 봉인 뒤에만 전달한다. 보정용 키 하나가 검증 평문까지 열 수 있으면 이 순서를 충족하지 않는다. 한 원본 파일에 보정·검증 내용이 함께 있으면 S1에서 누설 없이 분리할 방법을 정하거나 그 검증 자료를 비맹검으로 분류한다.

평문 원자료를 분석자에게 반입하면서 “sha만 봤다”는 순서를 쓰지 않는다. 측정자/보관자가 암호화 원자료를 백업하고 **열람 단위별** 암호문 SHA·측정 시작/종료·SOP 핀·보관 위치·키 보유자·전달/열람 로그를 남기는 방식을 제안한다. 보관자/키 분리·승인자에게 구두 결과를 전하지 않는 규칙도 각 보정/검증 단위에 적용한다. 성립하지 않으면 해당 자료를 비맹검으로 기록하고 확인적 분석 지위를 다시 정한다. SHA와 시각 기록은 무결성·기록 순서를 확인할 뿐, 사람이 값을 몰랐다는 사실 자체를 증명하지 않는다. 구체 보관 방식·역할 담당은 미정이며 외부 보관/전송은 별도 권한이 필요하다.

## 3. 역문제: 기본안은 연속 보간 대신 유한 후보 판정

**설계 선택 V2-Q1:** v1의 “보간 곡선 위 연속 구간의 기하 중심”을 기본 판정에서 사용하지 않는다. 유한한 함수 값만으로 구간 사이의 급변·비단조를 배제할 수 없다. 중점을 몇 번 추가하거나 이웃 차의 절반을 오차항으로 더해도 일반적인 오차 상한이 되지 않는다. 이 선택은 이번 설계 검토·1저자 확인 대상이다.

1. B는 실측 원자료 열람 전에 고정한 **유한한 양의 Bo 값과 ID**의 집합이다. v1의 초기 8점은 후보이며, 끝 간격은 ×3이고 그 앞은 ×√10이다. 추가 세분은 측정값을 모르는 동안 정한 C0/C1 규칙과 예산 안에서만 한다.
2. 각 시험 t와 b∈B에서 기술 완료·계약·관측 정의·불확도·출처 결합을 먼저 확인한다. 하나라도 없으면 해당 점을 `UNASSESSED`로 남긴다. 실패한 점을 조용히 삭제해 촘촘한 곡선처럼 잇지 않는다.
3. 적격 점의 I_t(b), 실측 m_t와 결과 전 정한 대조 폭 A_t(b)를 사용해 S_t = {b∈B: |I_t(b)−m_t|≤A_t(b)}를 계산한다. A의 통계적 의미·단위·상관 처리·반복 수·자유도·다중 후보 처리·경계 동률 규칙은 S3에서 고정한다. v1의 2√(u_exp²+u_DEM²)는 가정/방법을 정하지 않은 채 95% 신뢰도라고 부를 수 없다.
4. 주 결과는 S = S_T1∩S_T2이다. ID·실제 Bo·시험별 상태를 전부 보고한다. 각 시험별 빈 집합과, 둘은 비어 있지 않은데 교집합만 빈 경우를 구분한다. **미평가 점의 유무와 무관하게**, S=∅는 등록한 유한 B 안에서 양립 후보를 찾지 못했다는 뜻이며, B 사이/밖의 연속 Bo나 모델 전체를 기각하는 뜻이 아니다. `UNASSESSED` 점이 있으면 B 자체의 판정도 불완전하다. 낮은 Bo 영역만 평가해 얻은 불일치 역시 그 평가 영역 밖의 해를 배제하지 않는다.
5. 여러 분리된 후보 묶음이 있으면 모두 보고하고 단일 앵커를 내지 않는다. 여기서 묶음은 **등록 격자 인덱스의 이웃 관계**이며 연속 Bo 구간의 연결성을 증명하지 않는다. 적격 여부 미확인 점을 가로질러 묶지 않는다.
6. 후보가 하나면 “등록 격자에서 양립한 후보 1개”이다. 후보가 여러 개면 수치·확장 여부·미평가 점과 전체 후보 집합을 보고한다. 양 끝의 min/max는 단순 외곽 범위이며 그 사이를 전부 수용한다는 뜻이 아니다. 기하 중심을 보정값으로 만들지 않는다.
7. 연속 곡선은 탐색 그림으로 별도 표시할 수 있다. 연속 구간이나 대표 중심을 주장하려면 구간 안 형태·오차를 뒷받침하는 추가 가정과 독립 검증을 새로 등록·검토한다. 유한 격자의 수용도 참 Bo가 그 격자에 있거나 덮였다는 증명이 아니다.

| T3 중도절단 | 최대 관측시간·정지 기준·배출 분율·타이밍 규칙·반복을 먼저 정한다. 정지는 임의의 긴 흐름 시간으로 바꾸지 않는다. 연속 시간과 이진/중도절단 결과는 각각 정한 판정표/모형으로 비교한다. 전 후보가 정지하면 일관성 정보일 뿐 Bo 판별력 있는 검증이 아니다. |
| 검증할 후보 | 기본은 S의 모든 유한 후보에서 예측한다. 양 끝+중심만으로 내부 비단조·정지 전이를 보장하지 않는다. 예측 계산 완료는 검증 실측과의 양립 판정이 아니다. 예산 때문에 부분만 하면 미검증 후보를 남긴다. 검증 뒤에도 S와 보정 시점의 증서를 그대로 보존하며, 검증으로 후보를 탈락시켜 다시 보정하지 않는다. |
| 후보별 검증 상태 | S3에서 후보×필수 검증항목의 대조 규칙·중도절단 처리·상태를 고정한다. 각 칸은 `compatible / incompatible / unassessed`와 이유를 기록한다. 후보별로 필수 항목 하나라도 미평가이면 `unassessed`(이미 확인된 불일치도 원 표에 보존), 모두 평가되어 모두 양립하면 `compatible`, 모두 평가되었고 불일치가 있으면 `incompatible`이다. 통과 폭·유의수준·새 수치는 이 문서에서 정하지 않는다. |
| 집합 수준 검증 집계 | S≠∅일 때 후보별 수 `(n_compatible,n_incompatible,n_unassessed)`와 ID를 보고한다. `all-compatible` = 모든 후보가 양립, `mixed` = 전부 평가했으며 양립/불일치 후보가 함께 있음, `none-compatible` = 전부 평가했으나 양립 후보 없음, `incomplete` = 미평가 후보가 하나라도 있음이다. S=∅이면 이 집합 검증 집계는 적용 대상 없음이며 검증 성공으로 쓰지 않는다. |
| S6 보고 한정 | S3/S6에 위 집계의 표현과 이전 조건을 적는다. `all-compatible`도 등록한 검증 범위에서만 양립한다는 뜻이며 응용 타당성이나 실행 GO가 아니다. `mixed / none-compatible / incomplete`는 그 상태·후보별 근거를 유지해 이전하며 “전체 후보 검증 통과”로 쓰지 않는다. 맞은 후보만 골라 S를 다시 정의하려면 별도 새 분석/등록으로 표시한다. |
| 격자 끝 | 끝 후보가 남거나 미평가 경계가 있으면 범위 제한 표지를 유지한다. 한 번 확장은 미리 등록한 방향·최대 Bo·시드·계약·판정으로만 한다. 위쪽 증분은 실제 세대별 허용 범위에서 잘리며 ×√10을 보장하지 않는다. 확장 후에도 끝이면 **범위 제한 미해소**다. 기본 결과는 유한 후보 집합이며 연속 앵커의 확인/기각 판정이 아니다. |
| 낮은 Bo의 불일치 | 0점/낮은 Bo의 확인된 응답과 실측이 맞지 않으면 **그 조건의 실제 평가 영역 안에서** 불일치한 것이다. 평가하지 않은 높은 Bo나 격자 사이의 해를 배제하지 않는다. “마찰 오류”로 단정하지 않는다. 관측·벽·PSD·마찰을 구분할 추가 설계는 새 등록이다. |
| 응용 이전 | 1 g의 S를 S6에서 정한 변환으로 후보별 전달한다. G가 미확인이면 Bo/G도 미정이다. G=268은 기존 문서의 가정 예시이며 실제 장비 값이 아니다. 전체 후보가 응용에서 같은 예측을 낸다는 증거 없이 중심 한 점만 전달하지 않는다. |
| 선택 NCM·혼합물 | 정성/무맞춤 대조로 유지한다. ρ_flow를 표면 에너지 비로 해석하지 않는다. 코팅 NCM 실패를 D7 피복 표현이나 결합 규칙 하나의 실패로만 귀속하지 않는다. 코팅 두께·자유 SE 차감이 미확인인 팔은 D7 구현 검증이 아니다. |

## 6. 코드·계약의 선행 조건

현재 `scripts/check_contact_validity.py`의 `container_at`은 Drum·Front·Back 외의 Funnel·TapFloor를 실제 호출에서 거부한다. 따라서 “모든 시험을 현재 검사기로 검사한다”는 v1 문장은 적용할 수 없다. T1·T3·T4·주기 T2를 쓰려면 해당 기하·직선 이동·경계 조건을 다루는 계약 검사와 양성/음성 fixture를 ② 회차에서 먼저 검토한다. 미지원 기하를 `PASS`로 생략하지 않는다. T2도 파일 이름만 맞으면 통과한 것이 아니라 실제 STL·움직임·덤프를 검사해야 한다.

SE 단독 시험 덱은 현재 `set_phases(('SE',))` 경로가 없다. AM 타입을 유지하고 개수 0으로 할지 또는 새 타입 모드를 만들지는 시험 기하 코드의 명시적 선택이다. “동일 접촉 블록”은 **지정한 세대·ρ·벽·강성 팔**의 m1–m5·mC·pair/wall 법칙을 실제 되읽어 대조한다. 전체 덱(기하·중력·삽입)이 같은 바이트라는 뜻은 아니다. 드럼 치수는 측정 장치의 입력값으로 고정하며 `plan(n_total)`의 조성 유도 치수를 실험 치수로 대신하지 않는다.

**시드 역할과 예약:** C0 DEV·C1 보정·C2 검증·새 확인 블록의 시드 집합을 S3/S6에 각각 명시한다. v1과 D1/D12의 예약 확인 시드(15485863·86028121·104395301)는 D3 C0·C1·C2에서 사용하지 않는다. `(C0 ∪ C1 ∪ C2) ∩ 예약 확인 시드 = ∅`를 등록과 실행 전 실제 manifest에서 검사하고, 교집합이 있으면 재사용하지 않고 HOLD한다. D3 내부의 역할 간 허용 중복/짝짓기 관계도 결과 전에 정해 기록하며, 역할 이름이 다르다는 이유만으로 독립 표본이라 세지 않는다. 특정 새 시드 값은 여기서 고르지 않는다.

등록·생성기·판독기·계약 검사기·덱·출력·실측 표·열람 기록을 증서로 결합한다. 다른 판 증서/세대·누락 SHA·NaN/inf·빈 표·중복 ID·유니코드 수 토큰·단위 혼동·미등록 값·출력과 맞지 않는 성공 영수증은 시험 먼저 거부해야 한다. 기존 발사 정책에 D3 단계가 없으므로 정책을 우회하지 않는다. 새 정책·코호트는 별도 등록·비준 뒤 만든다. F8 재시도와 D13(초기 허용 누락·후속 ID 집합 불변)의 정확한 적용 시점도 ② 회차의 실제 판독 테스트로 확인한다.
