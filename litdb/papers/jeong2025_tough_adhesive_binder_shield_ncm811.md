## 0. 이 digest 를 읽는 법 — 1저자 지정 읽기축

우리(한양대 황화물 argyrodite 캠페인)의 현재 논문 축은 **양극 CEI** 다: *Nd(+O) 도핑 SE 가 고전압 양극 계면에서 **보호층을 제자리(in situ)에서 만든다***. 이 논문은 **정확히 반대 전략**으로 같은 문제(고-Ni NCM811 안정화)를 푼다 — **밖에서 만든 고분자(binder)를 방패로 씌운다**.

| 보호층이 **어디서** 오나 | 계면에서 **제자리 생성** (SE 가 분해되며 Nd 인산염을 낸다) | **밖에서 합성** 해서 슬러리로 바른다 |

## 1. 한 줄 요약

PVDF 를 **버리지 않고** 개질한다 — ATRP 로 **PAA 를 곁가지로 붙이고(PVDFA)** 분지형 **PEI 로 가교(PVDFA-N#)** 하면, 접착(180° peel `figure-read ≈`41→182 gf mm⁻¹, 4.4×)과 **인성**(`figure-read ≈`1.1→9.0, 8×)이 **동시에** 올라가고, NCM811 반쪽셀이 **300 사이클 80 % · 650 사이클 작동**한다. 후분석은 이 바인더가 단순 접착제가 아니라 **표면 보호막**임을 주장한다: NCM 내부 마이크로크랙 소멸 · Li 금속 위 **Ni 용출 5.4→3.0 ppb**(`figure-read`) · CEI 두께 **절반** · LiF 비 **CF_x:LiF 1:6.7 → 1:0.27**.

⚠ 단 **"보호" 의 두 기전(물리 피복 ↔ 화학 킬레이션)은 이 논문에서 한 번도 분리 실험되지 않는다**, 그리고 그 화학 쪽 근거인 **DFT 9점은 보고량이 정의돼 있지 않다**(§10-②). 인용 가능한 것은 **기계 물성–수명 상관** 까지다.

## 4. DFT / 계산 방법 ★ — **전부 Methods 5줄이 전부다**

- **code**: **Gaussian 16** (고체 주기 DFT 아님 — **분자 클러스터 계산**)
- **기하 최적화**: **B3LYP / 6-311++G(d,p)** + **Grimme D3 (zero damping)**
- **단일점 에너지**: **B3LYP / def2-TZVP** ("for enhanced accuracy")
- **용매 모형**: **CPCM**, 유전상수 **ε = 30.28** (EC/EMC 계 반영)
- **보고량 정의**: `E_b = E_total − (E_A + E_B)` (식 (1)) — A = 바인더 조각, B = TM 이온
- **주기·슬랩·k-point·컷오프·PAW**: **없음** (분자 계산이라 해당 없음) — ⚠ **NCM811 표면을 한 번도 모델링하지 않는다**
- **DFT+U / 스핀 다중도 / 전하 상태**: ⛔ **한 줄도 없다**
- **BSSE(counterpoise) 보정**: ⛔ 없음
- **AIMD / MLIP / MD**: **0**
- **무질서 처리**: 해당 없음 (분자)
- **조각(model fragment) 크기**: ⛔ **명시 없음.** `Fig. 4f` 인셋 그림으로 추정하면 PVDF ≈ VDF **1단위**, PVDFA ≈ 카복실 2개 달린 **수 단위 사슬**, PVDFA-N5 ≈ **수십 원자 다중 작용기 조각**. **세 조각의 크기가 전부 다르다.**

**계산된 값** (전부 `figure-read` — 본문에 숫자로 적힌 것은 N5 의 Mn/Co 둘뿐)

| 이온 | PVDF | PVDFA | **PVDFA-N5** | 출처 |
|---|---|---|---|---|
| **Ni²⁺** | `fr≈` **−0.5** | `fr≈` **−3.6** | `fr≈` **−6.5** | `Fig. 4f` (1.7× 재확대로 재판독) |
| **Mn²⁺** | `fr≈` **−1.5** | `fr≈` **−4.5** | **−7.3** (본문 명시) | `Fig. S14b` |
| **Co²⁺** | `fr≈` **−1.5** | `fr≈` **−5.0** | **−9.5** (본문 명시) | `Fig. S14a` |

+ **ESP(정전기 퍼텐셜) 맵** 3종, 컬러바 **−0.07 ~ +0.07 a.u.** — "전자가 풍부한 영역이 있다" 는 정성 주장에만 쓰인다.

> 🔴🔴 **이 표가 이 digest 에서 제일 중요한 반면교사다.** §10-② 를 반드시 같이 읽을 것. 요약: ① **PVDF 기준값이 이온마다 다르다**(Ni −0.5 vs Mn/Co −1.5) — 같은 C–F 쌍극자인데 3배 차이 ② **Irving–Williams 계열이 역전**됐다(같은 리간드면 Ni²⁺ > Co²⁺ > Mn²⁺ 여야 하는데 Co > Mn > Ni) ③ **스핀 상태 선언이 0줄**인데 Mn²⁺(d⁵)·Co²⁺(d⁷)·Ni²⁺(d⁸)는 전부 열린 껍질 ④ **조각 크기가 서로 달라** 결합자리 수가 다르다 ⇒ **절대값도, 이온 간 순위도 인용 불가.** 살아남는 것은 *"같은 이온에 대해 PVDF < PVDFA < PVDFA-N5"* 라는 **한 이온 안에서의 방향**뿐이고, 그것마저 조각 크기 효과와 분리되지 않았다.

## 5. 결과 — 섹션별 상세 (그림 실독 기준)

### 5.1 분자 설계 (`Fig. 1a–c`)
PVDF 골격 → ATRP 로 poly(tBA) 곁가지 → 산가수분해로 **PAA** → PEI 로 가교. `Fig. 1c` 만화가 역할을 나눈다: **PVDF 골격 = 전기화학 안정성 + 기계 강도** / **PAA 곁가지 = 활물질과의 수소결합 접착** / **PEI 가교 = 인장강도·인성**. `Fig. 1b` FT-IR 의 **1400 cm⁻¹ C–N–C 신규 피크**와 **1640 cm⁻¹ amide/imine** 이 가교 성립의 유일한 분광 증거다(정량 없음).

### 5.2 인장 — **접착기와 인성이 싸운다** (`Fig. 1d–g`) ★
§3b 표. 핵심은 **PVDFA 의 취성 파단**이다: PAA 를 붙이는 순간 인성이 PVDF 의 **1/4** 로 떨어진다. 저자 설명 = 분자간 수소결합이 곁가지 미끄러짐을 막는다. **가교제를 아주 조금(N1, 1 mol%) 넣어도 신율이 2.7 → 19.2 % 로 7배 뛴다** — 저자는 **고분자 가교제가 만드는 물리적 얽힘(entanglement)** 으로 돌린다(ref 39,40). ⚠ 이 해석은 검증 실험이 없다(작은 분자 가교제 대조군이 없다).

### 5.3 전극 접착 (`Fig. 2`) ★
§3c 표. **비단조성이 정보다** — PVDFA(124) → N1(101) **하락** → N2(120) → N5(182). 저자는 "COOH 소모 ↔ 망 형성" 두 힘의 경쟁으로 설명한다. `Fig. 2e–g` SEM 이 이 서열을 형태로 뒷받침한다(균열 多 → 일부 → 0).

### 5.4 수명 — **접착만으로는 안 된다** (`Fig. 3a,b`) ★★
이 논문의 논증 중심. **PVDFA 는 PVDF 보다 접착이 3배인데 수명은 짧다**(`fr≈`243 < 318). 따라서 저자는 **인성** 을 두 번째 축으로 도입하고 `Fig. 3b` 에서 *cycle life vs (toughness, peel strength)* 를 겹쳐 그린다. 그 그림에서 **인성(빨강)은 PVDFA 에서 최저점을 찍고 N5 까지 단조 상승**하는 반면 **peel(파랑)은 PVDFA 에서 이미 높다** ⇒ 저자 결론: *"둘이 **동시에** 수명을 정한다."*

> ⚠ **우리 판정**: 이 데이터는 **"동시" 모델보다 "문턱(threshold)" 모델에 더 잘 맞는다**. PVDFA·N1·N2 셋 다 PVDF 보다 **나쁘고**, 오직 N5 만 이긴다. 즉 **peel·인성이 둘 다 어떤 문턱을 넘어야 비로소 이긴다**는 해석이 가능하고, 5점으로는 두 모델을 가를 수 없다(§10-⑤).

### 5.5 가혹 조건 3종 (`Fig. 3d–j`)
- **고로딩 27–28 mg cm⁻² (≈110 µm)**: PVDF 50 cyc 실패 ↔ N5 >140 cyc. SEM 이 PVDF 전극의 **표면 균열**을 직접 보여준다(`Fig. 3e`).
- **저바인더 2 wt%**: PVDF 는 **사이클 전 펀칭 단계에서 이미 박리**됐고(`Fig. 3h` 인셋 광학사진의 노란 점선), SEM 진공 처리 중에도 상부가 떨어졌다. N5 는 95 µm 균일 단면.
- **55 °C**: N5 의 CE 요동이 확연히 작다. 저자는 고온에서 가속되는 Ni-rich 열화를 **열적으로 안정한 가교 구조**가 막는다고 본다(직접 증거는 없음 — 열분석 데이터 0).
- **풀셀(흑연, n/p 1.1)**: N5 가 220 사이클 내내 앞선다. ⚠ **두 셀 모두 초기 25 사이클에 ≈35 % 를 잃는다**(`fr≈` 2.4→1.7, 2.2→1.6) — 논문은 *"0.1 C 형성 → 0.5 C 전환 때문"* 이라고만 하고 넘어간다(§10-⑨).

### 5.6 후분석 — "방패" 주장의 근거 4종 (`Fig. 4`) ★★
① **구조**(STEM: 비정질+rock-salt ↔ 층상 유지) ② **기계**(FIB-SEM 내부 크랙 ↔ 무크랙) ③ **TM 크로스오버**(ICP-MS, Li 금속 표면) ④ **Li 석출 형태**(덴드라이트 ↔ 치밀).
저자는 ③④ 를 **킬레이션** 으로 귀속시키고 그 근거로 DFT(`Fig. 4f`, `Fig. S14`)를 댄다. ⇒ **화학 기전 주장.**
한편 `Fig. S13` TEM 은 **균일 나노막**을 보여주며 **물리 차단** 을 주장한다. ⇒ **두 기전이 한 논문 안에 병렬로 있고 분리 실험이 없다**(§7c·§10-③).

### 5.7 CEI — 얇고 균일하게 (`Fig. 5`) ★★
§3f 표. 가장 단단한 숫자는 **CF_x:LiF = 1:6.7 → 1:0.27**(본문 명시, 전사 오류 위험 낮음)과 **총 CEI 두께 절반**(`figure-read` 이지만 본문이 "approximately half" 로 확인)이다.
저자 논리 사슬: **LiF 축적 → 저항 ↑ → 용량 유지 ↓**, 그리고 **LiF 생성은 HF 를 동반 → TM 용출 가속**. ⚠ **HF 는 측정하지 않았다** — 이 사슬의 중간 고리가 문헌 인용(ref 59)으로만 채워져 있다.
`Fig. 5f` 모식도가 결론을 그린다: PVDF = 마이크로크랙 + 두껍고 불규칙한 CEI / N5 = conformal 망 + Ni²⁺ 차단 + 부반응 차단 → 마이크로크랙 없음 + 얇고 규칙적인 CEI.

```
        ┌── 물리 축 (피복) ────────────────────────────────┐
PVDFA-N5│  강한 계면 접착 → NCM 위 conformal 나노막(Fig.S13)│

        └───────────────────────────────────────────────────┘
        ┌── 기계 축 (인성) ─────────────────────────────────┐

        │  → 전해질 침투 경로 자체가 안 생김                 │
        └───────────────────────────────────────────────────┘
                     ↓ 셋이 합쳐져
        300 cyc 80 % · 650 cyc · 28 mg cm⁻² · 2 wt% · 55 °C
```

### 7c. 진짜 접점 ② — **전략 대결: 제자리 생성 vs 외부 도포** ★★

> 1저자 지정 질문 "화학적인가 물리적인가 — 갈라 적어라" 에 대한 답.

**갈라 본 결과: 이 논문의 "보호"는 물리 6 : 화학 4 정도이고, 우리와 경쟁하는 것은 화학 쪽 4 뿐이다.**

| | 이 논문의 **물리 축**(피복·차단) | 이 논문의 **화학 축**(킬레이션) |
|---|---|---|
| 무엇을 막나 | 전해질 **분자가 NCM 표면에 닿는 것** | 이미 나온 **TM²⁺ 가 이동하는 것** |
| 근거 | `Fig. S13` TEM 막 · XPS O/Ni ↓ · TOF-SIMS CEI 절반 | `Fig. 4d` ICP-MS · `Fig. 4f`·`Fig. S14` DFT |
| **우리와의 관계** | **보완(complementary)** — 우리 hull 논증은 *"어떤 상이 생기나"* 를 묻지 *"전해질이 닿나"* 를 묻지 않는다. **직교한다** | **약한 경쟁(weak competition)** — 둘 다 "계면의 **화학**이 수명을 정한다" 고 말한다. 단 물리가 다르다: 우리는 **상 안정성**(어떤 화합물이 생기나), 저들은 **이온 포획**(누가 붙잡나) |
| 우리 축으로 이식 가능? | ⚠ **위험** — ASSB 에서 conformal 절연 피복은 **이온 경로를 막는다**([Bielefeld20] 가 정량화한 바로 그 페널티). 액체계에서 공짜인 것이 고체계에선 비싸다 | ⭕ **개념만** — "보호상이 TM 을 붙잡는다" 는 우리 Nd 인산염이 **하지 않는** 일이다. 우리 §E 이중적합성 논의에 *"보호상의 기능은 차단만이 아니라 포획일 수도 있다"* 는 축을 추가할 수 있다 |

**⚠ 액체 vs 고체 — 반드시 적어야 하는 차이 4개**

1. **TM 크로스오버는 액체 고유 실패모드다.** 용매에 녹아 분리막을 건너 음극에 석출한다. **ASSB 에는 용매가 없다** — TM 은 확산(고체상 상호확산)으로만 움직이고 훨씬 느리다. ⇒ `Fig. 4d`·`Fig. 4e`(Li 덴드라이트)는 **우리 계로 옮길 수 없는 증거**다.
2. **피복(coverage)의 의미가 다르다.** 액체는 모든 곳을 적시므로 "덮으면 막힌다". 고체계 SE 는 **점 접촉**이라 '덮는다'는 말 자체가 접촉면적 문제로 바뀐다. **[Kang25우리그룹]** 이 말한 *"기생반응은 불가피하고 **균일성**이 지렛대다"* 가 여기서 갈린다 — 액체에선 균일성이 **차단의 균일성**, 고체에선 **접촉의 균일성**이다.
3. **분해 화학이 다르다.** LiPF₆→LiF+HF 사슬은 **우리 계에 없다**. 우리 산화 onset(2.256 V, S²⁻-limited)은 S 골격 산화이고 F 화학과 무관하다. ⇒ `CF_x:LiF 1:0.27` 은 **개념도 수치도 이식 금지**.
4. **바인더 함량의 대가가 다르다.** 이 논문은 바인더 **10 wt%**(저바인더 실험도 2 wt%)를 쓴다. 황화물 ASSB 복합양극은 보통 **1–3 wt%** 이고 그마저 σ_ion 을 깎는다. **"두껍게 잘 덮어라" 가 우리 계에선 곧장 손해**다.

### 7d. 부수 접점 — DEM/기계 축 (`INDEX_DEM.md` 계열)

우리 DEM 축이 바인더 응집/접착 파라미터를 필요로 하는데, 이 논문은 **프로토콜을 완전히 공개**한다(§3b·§3c 의 시험 조건 전부). 값 자체는 액체계 전극이라 못 쓰지만 **시험 설계는 그대로 베낄 수 있다**:
- 필름 인장: ASTM **D638-M type V**, **10 mm min⁻¹**, n ≥ 5
- 180° peel: **30 mm min⁻¹**, 3M 양면테이프, 롤러 **2.0 kg**
- **SAICAS**: 깊이 **10 µm**, 블레이드 1 mm, shear 45°/rake 20°/clearance 10°, **5 µm s⁻¹ × 200 s**, `P = F_h,avg / w`
⇒ `park2026_thiolene_sbr_binder_assb`·`kang2025_bollard_anchored_binder_dry_electrode` 와 **같은 3종 세트**다. 우리 DEM 캘리브레이션에 쓸 문헌 프로토콜이 이제 3편으로 수렴한다.

### ② 🔴🔴 DFT 결합에너지가 **보고량으로 정의되지 않았다** (`Fig. 4f`, `Fig. S14`) — 가장 큰 하자
네 겹으로 깨져 있다.
1. **스핀 상태 선언 0줄.** Mn²⁺(d⁵)·Co²⁺(d⁷)·Ni²⁺(d⁸) 전부 열린 껍질이고 고스핀/저스핀에 따라 결합에너지가 **eV 급으로** 달라진다. 다중도(multiplicity)를 어디에도 안 적었다.
2. **Irving–Williams 역전.** 같은 리간드 집합이면 **Ni²⁺ > Co²⁺ > Mn²⁺** 순으로 착물이 안정해야 한다(무기화학의 경험칙). 이 논문은 **Co(−9.5) > Mn(−7.3) > Ni(−6.5)** 로 **거꾸로** 나온다. ⇒ 세 계가 **같은 배위환경·같은 스핀 branch 에 있지 않다**는 강한 징후.
3. **기준(PVDF)이 이온마다 다르다.** `fr≈` Ni −0.5 / Mn −1.5 / Co −1.5. PVDF 는 C–F 쌍극자뿐이라 세 이온에 대해 비슷해야 하는데 **3배 차이**가 난다. 기준이 흔들리면 차분도 흔들린다.
4. **조각 크기 미보정.** 세 모델 분자의 크기가 다르다(그림 인셋: 원자 수십 개 차이). 배위 가능한 작용기 수가 다르면 결합에너지는 **당연히** 깊어진다 — **작용기당(per-site) 정규화가 없다**. 이것은 [Han25] 의 "조성 가중" 비판(AN:AMPS 8:1)과 **같은 병**이다.
+ **BSSE(counterpoise) 보정 없음**, **자세 탐색 절차 0**, **오차막대 0**, **바닥상태 확인(frequency) 0**, **NCM 표면 모델 0**(TM 이온이 격자에서 어떻게 나오는지는 계산 밖).
⇒ **인용 가능 한계 = "같은 이온에 대해 PVDF < PVDFA < PVDFA-N5 라는 방향" 까지**, 그마저 조각 크기와 분리 안 됨. **−9.5 eV / −7.3 eV / −6.5 eV 절대값과 이온 간 순위는 인용 금지.**

### ③ ⚠ "보호" 의 두 기전을 한 번도 분리하지 않았다
물리(피복 차단)와 화학(TM 킬레이션)이 병렬로 주장되는데, 둘을 가르는 대조군이 **하나도 없다**. 필요한 대조군: (a) 같은 두께의 **비킬레이팅** conformal 코팅, (b) 킬레이팅기는 있으나 피복이 안 되는 계(예: 용액에 녹인 PAA 소량 첨가), (c) 가교만 하고 COOH 는 없는 PVDF-crosslinked.
⇒ 현재 데이터로는 **"N5 가 좋다"** 까지만 성립하고 **"왜 좋은지"** 는 열려 있다.

### ④ ⚠ `Fig. 4d` ICP-MS 가 본문 서술을 뒷받침하지 않는다
본문 *"Ni, **Mn**, and Co … significantly lower"* ↔ 그림에서 **Mn 은 0.5 vs 0.5 로 동일**. 실제 감소는 **Ni −44 %**(5.4→3.0)와 Co(0.5→0.2)뿐이다.
게다가 **오차막대·반복수(n)가 없고**, 값이 **ppb(용액 농도)** 로만 제시돼 전극 면적·질량으로 정규화되지 않았다 ⇒ **다른 논문과 비교 불가**([Han25] 의 73.9 ppm 과 같은 표에 놓으면 안 된다).

### ⑤ ⚠ `Fig. 3b` 의 "접착·인성이 **동시에** 정한다" 는 5점으로 주장할 수 없다
데이터: PVDF(318) · PVDFA(243) · N1(220) · N2(233) · **N5(658)**. **N5 하나만 크게 이긴다.**
- "동시 영향" 모델이라면 N2(인성 7.2 · peel 120)가 PVDF(1.1 · 41)를 **이겨야** 하는데 진다.
- 데이터는 **문턱 모델**("peel ≳150 **그리고** 인성 ≳8 을 넘어야 비로소 이긴다")과도 똑같이 잘 맞는다.
⇒ **인용 가능 문장은 "접착력만으로는 수명이 설명되지 않는다"(반증) 까지.** "두 물성이 동시에 지배한다"(구성) 는 **인용 금지.**

### ⑥ ⚠ 깊이 축 세 개가 서로 2–3 자릿수 어긋나는데 조정이 없다
| 방법 | 이 논문이 보는 깊이 | 문제 |
|---|---|---|
| XPS 깊이 프로파일 | 0.2 nm **min⁻¹** × 600 s = **≈2 nm** | "in-depth profiling" 인데 CEI 최외곽 2 nm 만 본다 |
| TOF-SIMS | 0.2 nm **s⁻¹** × 3000 s = **≈600 nm** | 같은 CEI 를 **300배 두껍게** 본다 |
| 실제 CEI 통념 | 5–50 nm | 둘 다와 안 맞는다 |
TOF-SIMS 의 수백 nm 는 **복합전극 표면 거칠기**(입자 높이 분포)가 깊이 축에 섞인 결과로 보는 것이 타당하다. **논문은 이 불일치를 한 줄도 언급하지 않는다.**
⇒ **CEI "절반" 은 상대 비교로만 인용**, 절대 두께(300/650 nm) **인용 금지.**
같은 문제: **GITT D_Li⁺ 10⁻⁶–10⁻³ cm² s⁻¹** 는 NCM 통상값(10⁻¹⁰–10⁻¹³)보다 **4–7 자릿수 높다** — 면적·부피 규약이 안 적혀 있어 **절대값 인용 금지**. 코인셀 내부저항 **0.59/0.68 Ω** 도 규약 미기재(면적 정규화 여부 불명).

### ⑦ ⚠ 초기 용량 손해를 수치로 밝히지 않는다

### ⑩ ⚠ `Fig. S12` XRD 는 구조 붕괴와 시료 손실이 섞여 있다
PVDF 사이클 후 패턴은 **(104) 뿐 아니라 (003) 을 포함한 모든 피크가 다 죽었다**(라벨: *"I(003)/I(104) = Not measurable"*). 층상→암염 전이라면 (003)은 줄고 (104)는 남는 식의 **선택적** 변화가 보여야 한다. **전체 강도 붕괴는 측정 지점에서 복합층이 떨어져 나간 것**과 구별되지 않고, 논문 자신이 `Fig. S6` 에서 **PVDF 전극이 분리막에 붙어 박리됐다**고 보여준다.
⇒ SI 서술 *"(104) 피크가 거의 사라졌다"* 는 **과독**. XRD 는 보조 증거로만.

### ⑪ ⚠ 물리 차단 주장의 유일한 직접 증거(`Fig. S13`)를 나는 못 봤다
*"PVDFA-N5 가 NCM811 위에 균일한 conformal 나노막을 만든다"* 는 본문 주장의 근거는 `Fig. S13` TEM 하나다. 나는 이 그림을 **판독하지 않았다** ⇒ **막 두께·균일성·PVDF 대비 차이를 내가 확인하지 않았다.** [Han25] 는 같은 주장에 **≈7 nm** 라는 수치를 줬는데 **이 논문은 두께 수치를 본문에 안 준다** — SI 그림에 있는지도 미확인.

### ⑫ ⚠ 대조군이 PVDF 하나뿐 (분야 관행이지만 여전히 약점)
PAA 단독 · CMC/SBR · 가교만 한 PVDF · 상용 개질 PVDF 어느 것도 없다. `Table S1` 의 문헌 비교는 조건이 안 맞춰져 있다(§3f 경고).

### ⑬ ⚠ HF 사슬이 측정되지 않았다
*"LiF 생성 → HF 동반 → TM 용출 가속"* 이 논문의 핵심 인과 사슬인데 **HF 를 한 번도 재지 않았다**(ref 59 인용으로만). LiF 와 TM 용출의 상관은 보이지만 **인과는 미확립**이다.

- ⚠ **소환값**이다 — `db/properties/canonical_registry.json` 값들과 **같은 표에 놓지 않는다**.
- ⚠ **DFT 는 고체 DFT 가 아니다.** Gaussian 16 분자 계산이고 NCM 표면이 없다. 우리 SDCP/QE 슬랩 계산과 **같은 종류의 양이 아니다**.
- ⚠ `figure-read` 표시된 값은 전부 내가 그림에서 눈으로 읽은 것이다. **±5–10 % 오차를 가정**하고, 원고에 넣을 때는 그림을 다시 확인한다.
- ⚠ 미판독 그림 11장이 있다(§0). 특히 `Fig. S13`(코팅막 TEM)·`Fig. S9`(dQ/dV)는 **본문 주장의 직접 근거**인데 내가 안 봤다.
- ⚠ SI 는 **.docx** 다 — `tools/litdb/extract_figures.py` 가 못 읽어서 `word/media/*` 를 `document.xml` 문단 순서로 매핑해 `fig_S1`–`fig_S14` 를 만들었다. **매핑이 문단 순서 기반이라 100 % 보장은 아니다**(캡션과 그림이 1:1 로 번갈아 나오는 구조여서 신뢰도는 높다). `litdb/figures/<slug>/figures.json` 의 `note` 에 그렇게 적어 뒀다.

## 15. 기법 미니 용어집

| 용어 | 뜻 | 왜 여기 나오나 |
|---|---|---|
| **ATRP** (Atom Transfer Radical Polymerization) | 전이금속(여기선 CuCl/HMTETA) 촉매로 라디칼 농도를 낮게 조절해 사슬 길이를 맞추는 제어 중합 | PVDF 골격 위에 poly(tBA) **곁가지**를 길이 조절해 붙이려고 |
| **PVDFA** | PVDF-*g*-PAA. tBA 를 그래프팅한 뒤 tert-butyl 을 산가수분해해 **–COOH** 로 바꾼 것 | 접착기(카복실산) 도입 |
| **PEI** (분지형 polyethyleneimine) | 1·2·3차 아민이 섞인 가지 많은 고분자 | **고분자** 가교제 — 작은 분자 가교제와 달리 **물리적 얽힘**까지 준다는 것이 저자 논지 |
| **PVDFA-N#** | # = PEI 의 아민기 mol% / VDF 반복단위. 가교밀도 지표 | N1/N2/N5 = 1/2/5 mol% |
| **SAICAS** (Surface And Interfacial Cutting Analysis System) | 경사 블레이드로 전극을 **정해진 깊이까지** 깎으며 수평력을 재는 시험. 180° peel 과 달리 **복합층 내부 응집력**을 본다 | `Fig. 2d`. 우리 DEM 축이 필요로 하는 "집전체 접착 vs 층내 응집" 분리 |
| **180° peel** | 테이프를 180° 로 되접어 벗기며 힘을 재는 시험. **가장 약한 계면**에서 터진다 | `Fig. 2b,c` |
| **Toughness(인성)** | 응력-변형 곡선 **아래 면적** = 파단까지 흡수한 단위부피 에너지. 단위 J m⁻³ (통상 **MJ m⁻³**) | `Fig. 1g`. ⚠ 이 논문 축 표기는 GJ m⁻³ 로 1000배 틀렸다 |
| **CEI** (Cathode–Electrolyte Interphase) | 양극 표면에 전해질 분해로 쌓이는 층. SEI 의 양극판 | 이 논문의 주 관측 대상 |
| **H2–H3 상전이** | 고-Ni 층상 산화물이 고SOC(≈4.2 V)에서 겪는 격자 급수축. **이방적 부피변화 → 마이크로크랙**의 원인 | `Fig. S9` dQ/dV 로 추적 |
| **Rock-salt 상** | 층상(R-3m)이 Ni²⁺↔Li⁺ 양이온 혼합으로 무너져 생기는 Fm-3m NiO 형 상. **Li 전도 막는다** | `Fig. 4a` STEM/FFT |
| **TOF-SIMS depth profile** | 이온빔으로 깎으며 2차이온 질량분석. 깊이축 = 스퍼터 시간 × (가정한) 속도 | `Fig. 5d,e`. ⚠ 거친 표면에선 깊이축이 흐려진다 |
| **CPCM** (Conductor-like PCM) | 용매를 **연속 유전체**로 근사하는 암묵적 용매 모형. ε 만 준다 | 여기 ε=30.28 (EC/EMC). ⚠ **이온의 1차 배위껍질(명시적 용매)이 없다** — 이것이 결합에너지를 과대평가하는 주 원인 |
| **ESP 맵** (Electrostatic Potential) | 전자밀도 등가면 위에 정전기 퍼텐셜을 칠한 그림. 붉은=음전하 풍부 | `Fig. 4f` 인셋. **정성 그림이다 — 정량 인용 불가** |
| **Irving–Williams 계열** | 같은 리간드에 대한 고스핀 3d 금속 착물 안정도 순서: Mn²⁺ < Fe²⁺ < Co²⁺ < Ni²⁺ < Cu²⁺ > Zn²⁺ | §10-② 의 판정 근거. 이 논문은 이 순서를 위반한다 |
| **보고량(estimand)** | *"무엇을 재고 있는가"* 의 형식적 정의. 상태가 여럿이면 선택·집계 규칙이 필요 | 우리 `kb/templates/estimand_card.md` 규율. 이 논문에 없는 것 |
