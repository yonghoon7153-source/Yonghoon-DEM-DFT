# 01. CONTEXT — 왜 이 코드를 만드는가

> 대상: 코딩 에이전트 및 협업자. 물리 배경을 모르는 상태에서도 판단할 수 있도록 작성.

---

## 1. 한 줄 요약

**full-cell 전압 곡선 하나로 LAM_PE와 LAM_NE를 분리할 수 있는가?**
현재 fitting 결과는 두 값이 거의 같게 나오는데, 이것이 진짜인지 **수치적 축퇴(degeneracy)** 인지 판별해야 한다.

---

## 2. 배경 — 세미나 발표 (2026-08-05, 41 slides)

**주제**: high-Ni NCM ‖ Si-graphite 전지의 비선형 SOH 열화 (knee point) 원인 규명

### Part 1 (1~23p) — 실험 진단

| 기법 | 결과 |
|---|---|
| SEM (7p) | 양극 표면 **변화 없음** |
| SEM/EDS (8p) | after-knee Si 입자 구형 상실, O·F가 Si와 동일 위치 |
| 전극 두께 (9p) | after-knee NE만 급증 (~132 µm), before-knee는 증가 없음 |
| XRD (10p) | peak 좌측 shift, 격자 비가역 열화 |
| XPS (11p) | 양극 Ni²⁺/Ni³⁺ 증가 → rock-salt 상전이 |
| ICA (14p) | **~0.4 V SiC peak 소멸** = Si 활물질 손실 직접 증거 |
| DRT (18p) | before-knee PE에서 R_ct·R_diff 증가 |
| DRT (19p) | after-knee NE에서 SEI·CT peak **분리** → Si vs Gr 차이 |
| 3전극 (20p) | 200cyc까지 full-cell cutoff를 **NE가 결정** |

→ **결론: knee의 원인은 음극 Si 손실. 양극은 계면 열화(정도의 문제)**

### Part 2 (24~41p) — 모델링

| p | 내용 |
|---|---|
| 25–26 | P2D/DFN, Si·Gr 별도 입자, SEI(Tafel)·Li plating(BV)·fracture |
| 27 | COMSOL: Si SEI ~150 nm ≫ Gr ~25 nm, LLI는 SEI 지배 |
| 28 | COMSOL: Si LAM ~3.8%, Gr ~0.8%, **NCM ≈ 0%** |
| 29–31 | PyBaMM 도입 (COMSOL은 43cyc에서 계산 부하로 정지) |
| 32 | **열화모드 라이브러리** — 이 프로젝트의 출발점 |
| 33–34 | fitting 코드 개선, 목적함수에 dQ/dV 추가 |

## 3. 핵심 문제 — 22p

### 3.1 현상

fitting 결과 (단위 %):

| 항목 | 100cyc | 200cyc | After knee (300) | Before knee (300) |
|---|---|---|---|---|
| Capacity loss | ~2 | ~5 | ~13 | ~9 |
| **LAM_PE** | ~3 | ~5 | **~13** | ~9 |
| **LAM_NE** | ~2 | ~5 | **~13** | ~9 |
| LLI | ~5 | ~7 | ~17 | ~11 |

`Capacity loss ≈ LAM_PE ≈ LAM_NE` — 세 값이 붙어서 움직인다.

### 3.2 왜 이상한가

Part 1의 모든 정성 데이터가 **NE 편향**을 가리킨다 (7p, 9p, 14p, 19p).
Part 2 모델도 **NCM LAM ≈ 0%** 라고 답한다 (28p).
그런데 정량 결과만 PE/NE 대칭 — 물리적으로 두 전극이 우연히 같은 비율로 죽을 이유가 없다.

> **이것이 세미나에서 지도교수가 직접 지적한 사항이다.**

### 3.3 축퇴(degeneracy)란

> 서로 다른 답들이 목적함수 상에서 똑같이 좋아 보여, 어느 것이 진짜인지 구분할 수 없는 상태.

**비유**: 두 사람이 함께 사서 총 10만원. 영수증에 **합계만** 있으면 (3,7) (7,3) (5,5) 중 무엇인지 알 수 없다.

**수식으로**

```
측정값:  U_full = U_PE − U_NE          ← 관측 1개
미지수:  α_PE, β_PE, α_NE, β_NE        ← 4개
```

α_PE와 α_NE를 같은 방향으로 움직이면 **빼기 구조상 상쇄**되어 `U_full`이 거의 변하지 않는다.
→ RMSE도 변하지 않음 → 최적화 입장에서 (5%, 15%)와 (10%, 10%)의 점수가 동일
→ 목적함수 `J(p)`에 최소점이 뾰족한 골짜기가 아니라 **평평한 골짜기(flat valley)** 가 생김
→ Hessian 고윳값 하나가 0에 근접

### 3.4 원인 후보 (확인 난이도 순)

| # | 후보 | 확인 방법 | 비용 |
|---|---|---|---|
| 1 | **파라미터 축퇴** | 합성 데이터 역검증, 초기값·bound 변경 재실행, Hessian | **낮음 (수일)** |
| 2 | 모양 불변 가정 붕괴 | 더 낮은 C-rate / GITT 기반 pOCV 재측정 | 중간 |
| 3 | 실제 PE 손상 | 단면 SEM, 300cyc XPS·XRD | 높음 (실험) |

**이 프로젝트는 #1을 다룬다.**

## 4. 검증 전략 — 합성 데이터 역검증

### 4.1 원리

정답을 아는 시험문제를 만들어 fitting 코드에 풀린다.

```
[출제]  LAM_PE = 5%, LAM_NE = 15%, LLI = 10%     ← 내가 설정
   ↓    PyBaMM으로 해당 조건의 full-cell 곡선 생성   (32p 라이브러리)
   ↓    fitting 코드에 투입                          (33·34p)
[채점]  출력이 5% / 15%인가?
```

| 결과 | 해석 |
|---|---|
| 5% / 15% 복원 | 코드 정상. 22p 결과 신뢰 가능 |
| 10% / 10% 등으로 뭉개짐 | **축퇴 확정.** 22p 결과 재검토 필요 |

정답을 아는 데이터이므로 해석의 여지가 없고, **추가 실험 없이** 결론이 난다.

### 4.2 왜 코드가 필요한가

기존 코드는 **모드를 하나씩만** 넣어봤다 (32p: LLI만, LAM_NE만, …).
실제 셀은 셋이 **동시에** 일어나므로 조합을 훑어야 한다.

```
LAM_PE  0 ~ 20%  (21단계)
LAM_NE  0 ~ 20%  (21단계)
LLI     0 ~ 20%  (21단계)
──────────────────────────
        9,261 조합  ← 조합마다 곡선 1개 생성 필요
```

여기에 목적함수 4종(pocv / +dvdq / +dqdv / combined)을 곱하면 **약 37,000회 fitting**.

→ 기존 코드의 **순차 for-loop 구조로는 불가능.** 병렬화가 이 프로젝트의 핵심.

## 5. 최종 산출물이 답해야 할 질문

1. 기존 fitting 코드는 어떤 (LAM_PE, LAM_NE, LLI) 조합에서 정답을 복원하는가?
2. 축퇴가 발생하는 영역은 파라미터 공간의 몇 %인가?
3. 22p의 실험 조건은 그 축퇴 영역 **안**에 있는가?
4. 34p의 dQ/dV 항 추가가 축퇴 영역을 얼마나 줄이는가? (X% → Y%)
5. 목적함수 가중치 `w_pocv, w_dvdq, w_dqdv`의 최적 조합은?

**4번이 가장 중요하다.** 이것이 나오면 34p 수정을 "기능 추가"가 아니라
"**축퇴 영역을 X%에서 Y%로 줄였다**"로 정량 보고할 수 있다.

## 6. 이 프로젝트가 **하지 않는** 것

- 축퇴 자체를 없애는 것 — 정보 부족 문제라 알고리즘으로 해결 불가.
  근본 해결은 **3전극 데이터**(20p)로 PE·NE 전위를 따로 측정하는 것.
- 실제 셀의 열화 메커니즘 규명 — 그건 Part 2 COMSOL/PyBaMM 사이클링 쪽 과제.
- 머신러닝으로 LAM 예측 — 축퇴 영역에서는 ML도 못 가른다.
  다만 **불확실성 정량화**(ensemble 분산)로 "여기는 못 믿겠다"를 표시하는 용도는 유효.
