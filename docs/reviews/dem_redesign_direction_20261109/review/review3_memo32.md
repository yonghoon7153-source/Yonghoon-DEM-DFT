## 3. 시킨 확인의 결과

**3-1. MR2-01 · 두 팔 구간의 차.**  뺄셈은 두 팔 구간이 각자 극한을 담으면 늘 극한을 담는다.  그러니 거짓 등급은 팔 구간이 극한을 놓칠 때 (한 팔 안 두 항 · 숨은 느린 항 · 잡음에 가린 표류 · 8 셀 구멍 = ③) 와, 팔 규칙을 아예 건너뛰는 길에서만 난다.  2 회차 반례 둘 → 중간 · 참값 담음 (같음).  새 반례 ⓐ "다른 단 수" (S = B 네 단 잡음 · F = A 세 단 서로 지우는 두 항) → 중간 · 구간 0.0013–0.6028 이 참 0 을 못 담음 (③ 의 꼴 · 진폭을 키우면 거짓 다름).  ⓑ "한 팔 미수렴" → 둘 다 닿은 충전에서는 중간이 맞다.  그러나 "분자만 못 닿음 = +∞" 길은 분모 팔을 보지 않아 미수렴 F 로도 다름이 난다 (MR3-01).

**3-2. MR2-03 · 세 물체 노드 + 미끄럼 경계 칼날.**  칼날 (A 정지 · B (−1, 0.1) · C (0, −0.85) · 붙음에 J_t = 0.25 = µJ_n 정확히): 사후 미끄럼 0 · ②′ 붙음 쪽 통과 · ② 등호 통과.  ε 만큼 미끄럼 쪽으로 넘기면 사후 미끄럼 −ε/2 · J_t +0.25 (맞섬) 라 미끄럼 쪽으로도 통과 — 칼날 양쪽이 이어진다 (허용폭만 등록하면).  틀린 풀이 (J_t −0.25 · J_t 0) 는 칼날에서도 불합격.  남은 것은 시점 · 허용폭 (MR3-06).

**3-3. MR2-05 · W1 꼴.**  탐색 24.0–25.6 % 는 창과 안 겹쳐 ⑤ 가 아니다 → 표지 → 출발점 = 11.5 % 에 가장 가까운 탐색 점 → 걷기가 범위 끝에서 멈춤 → 모두위.  S-연화 가로지름이면 (4-ii) · 모두위면 (4-iii) 실제 모두위 → 둘 다 F 대조 (D-3 · 497).  닫혔다.  창 근처 칼날만 남는다 (MR3-07).

MR2-06 · 검정력 0.083.**  P(A) = 0.0692 (d₂/d₁ 가 위치 −½ · 척도 √¾ 의 Cauchy · `docs/reviews/dem_redesign_direction_20261109/fix/arith3.py` 93 행과 같음) · P(넷이 한결같음) = 1/12 · P(A ∧ 한결같음) ≈ 0.016 → 팔 0.933 → 점 0.660 · 시험 같음 0.287 · G 같음 0.083.  다시 세어 같다 (몬테카를로 80 만 · 0.9326 · 0.658 · 0.285 · 0.081).  다만 이것은 수렴 몫뿐이고 (구간 폭 · 띠 · A 등급 몫 없음), 잡음 ≲ τ/4 · 8 셀 치우침 ≤ τ 일 때만이다 (MR3-02 · 03 · 05).
