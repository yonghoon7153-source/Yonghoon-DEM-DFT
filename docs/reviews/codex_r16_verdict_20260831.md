### 1-3. Q6 반례 2 — block 이 SDCP 를 면제한다

## 2. 내가 틀린 것 (원문 보존)

### 2-1. ⚠⚠ Q2 — "값 봉인 상태에서 등록했다" 는 **봉인의 뜻을 잘못 안 것**

```
00:33  c1bcec0c  원등록 — h0 → Fig 4b 전자 전용
00:38            STEP B 실행 시작
01:28            시나리오 1 DBE payload 생성        ← 디스크에 σ 가 있다
01:49            시나리오 2 SBE payload 생성
02:06  b627425c  §7 추가 — h0 → 이온 규약 span      ← **실행 중, payload 존재**
```

**"봉인" 은 stdout 만 가린다.**  σ 는 payload JSON 에 평문으로 저장된다
(`mpm_webapp_payload.py:2104` · `:2919`).  ⇒ **차폐가 기계적으로 강제된 적이 없다.**
*"아무도 안 열었다"* 는 저자 진술일 수 있어도 blinding 이 아니다.

**PTFE 유비도 성립하지 않는다**: PTFE 등록은 **측정 전에** *"불채택이면 두 규약 병기"* 를
fallback 으로 고정했다.  STEP B 원등록은 *"h0 → 전자 전용"* 이었다.

⇒ 정확한 표기: *"실행 시작 후, 저자가 전도도 출력을 열어보기 전이라고 보고하는 시점에
표시 계획이 개정됐다.  payload 에 값이 평문으로 남아 있었으므로 이것은 **투명한
post-start 표시 결정**이지 사전등록된 분석 결과가 아니다."*
**§4 를 primary 로 복원하고 §7 은 secondary/exploratory 로 내린다.**

### 2-2. 1팔 면제 근거가 **다른 관측량**이었다

내가 인용한 `0.3027 %` 는 **전자 LEAN=2 origin 검사**이고, 원장 자신이 재현성·정밀도
증거로 쓰지 말라고 적어 둔 값이다.  **이온 origin 산포는 미측정**이다.
그리고 **부호 기준에는 여유가 없다** — `R = 1` 은 폭 0 경계다.
RSA 의 `R−1 = −0.284 %` 는 그 전자 산포보다도 **작다**.
⇒ *"30~100배 여유"* 는 틀렸다.

### 2-3. Q4 는 질문 자체가 잘못됐다

동결 문서가 **이미** `0.17` 을 post-hoc nominal 로 격하하고 −26.1 % 잔차를 기록했고
`CALIB_VALIDATED` 도 이미 철회돼 있었다.  **뒤집을 것이 없었다** — 우리 기록을 잘못 읽었다.

### 2-4. *"생산 r=1/3 이 펠릿 창 밖"* 은 ρ 조건부다

Codex 재실행 (x=0.00119, r=1/3): `ρ=1.30 → 3.0717 (+7.40 %, 밖)` · `ρ=1.10 → 3.0000
(+4.90 %, 안)`.  ⇒ `r ≤ 0.2752` 는 **ρ=1.30 프록시 조건부 acceptance span** 일 뿐이다.
ρ 미확정 상태에서 이것으로 production 값을 기각하고 `0.1737` 을 채택하면 안 된다.

### 2-5. ⛔ **equivalence 문장을 쓸 수 없다**

*"이온 손해도 이득도 없다"* · 원고의 *"without disrupting Li⁺ conduction"* — **둘 다 불가**.

⇒ **원고 수정 항목이 하나 늘었다** (이전에 "살아남는다" 고 분류했던 문장이다).
