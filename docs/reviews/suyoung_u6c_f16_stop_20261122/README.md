## 1저자 실행 및 판독

WSL CPU 1개. `GO_SUYOUNG_F8_F16_CONTACT_ONCE` 뒤에 보존된 원 F8 완결 반환과 첫 F16 중단 반환을 차례로 지정한다. 초기 좌표·원 ID·두 입력 해시와 소스 결속을 확인한 뒤 실행 자리를 한 번 확보한다. F8 계산은 최대 1,200초, F16 계산은 최대 1,800초이며 자동 재시도는 0회다. 종료 시 결과 TAR, 화면, SHA256SUMS를 새 반환 폴더에 남긴다.

1. 새 핀의 F8 실행에서 종점·영수증을 확인하고 전체 추적의 바이트를 이전 F8 원 ID와 대조한다. 일치할 때 F16을 시작한다.
2. F16을 초기 상태부터 같은 새 커널로 계산한다. 시간 초과나 접촉 미수렴은 계산 중단으로 기록하고 가능한 범위까지 이전 추적과 비교한다.
3. F16이 유효 종점에 도달하고 처음 0–4,802걸음의 추적 바이트가 이전 자료와 일치하면 등록된 같은 변위 5% 규칙으로 두 새 팔을 비교한다. 원압력 반올림 전 20 × 최대 절대차 ≤ 고운 격자 최대 절대 반력이면 해당 쌍이 기준 이내다. F12–F24는 결측이며 U6(c) 전체와 단계 3은 보류한다. 최초 F16 입력과 중단 결과는 별도 이력으로 보존한다.
