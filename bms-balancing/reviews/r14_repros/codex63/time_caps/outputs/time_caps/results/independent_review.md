# 제안 A 네 조건 수치 비교 독립 검토

네 새 작업만 primary 비교에 사용했다. 기존 축별 결과와 혼합하지 않았다. `work/mesh_axes/analyze_results.py`를 새 `work/time_caps/analyze_results.py`로 복사·확장했고 원래 분석기와 이전 결과는 수정하지 않았다. COMSOL 또는 Java 소스는 실행·수정하지 않았다.

H1000/H0500은 각각 t<0.1초의 최대 step 0.001/0.0005초이며 이후 상한은 0.1초다. 물리 요소는 모두 300개이고 R40/R80은 각 전극 입자 반경 요소 수다. 실제 보관 소스 SHA가 설정·제출 기록과 일치하고 네 native 상태 모두 completed다.

공통 요청 시각 187개가 모든 작업의 저장 해에 정확하고 유일하게 존재한다. [0,1]초 107개와 [0,5]초 187개를 별도로 비교했다. 각 전극의 공통 물리 좌표 241개, domain_id 1/3, 모든 저장 행의 유한값·범위·좌표 일치를 검사했다. COMSOL FE 공간 평가를 사용했으며 Python 공간·시간 보간 또는 근처 시각 대체는 없다. 메모리를 줄이기 위해 모든 profile 행을 검증한 후 비교용 요청 시각만 메모리에 유지했다.

시간 상한 반감에 대한 관측 민감도는 작지만, 같은 상한의 반경 비교는 두 경우 모두 전압 기준을 넘었다. 반경 수렴은 미완이며 모든 비교를 PASS로 바꿀 근거가 없다. 전극 전체 extrema가 같다는 것만으로 profile 일치를 판단하지 않고 동일 위치의 두 값 차이를 직접 계산했다.

반경 비교의 최대 표면 차이는 음극 오른쪽 끝 52 µm에서 발생했다. H1000의 두 표면 x는 0.011840741847120861와 0.011882589301172466, H0500은 0.01184073886082281와 0.011882574283142029이다. 이 위치와 cell voltage 평가에 쓰인 음극 집전체 0 µm를 구분한다.

## 최대 전압 차이 시각의 signed 분해

각 해에서 V=(Eeq_P−Eeq_N)+(etaMid_P−etaMid_N)+(phil_P−phil_N)이며, 표의 모든 열은 **동일 시각의 두 해 차이**다. 서로 다른 시각의 성분 최대를 합산하지 않았다. 모든 값의 단위는 mV다.

| 비교 | 시각 (s) | δ(ΔEeq) | δ(ΔetaMid) | δ(Δphil) | δV |
|---|---:|---:|---:|---:|---:|
| R40 시간 상한 반감 | 0.06 | −0.000194455226 | +0.000001842800353 | −0.0000000715137 | −0.0001926839399 |
| R80 시간 상한 반감 | 0.02 | −0.0014402259731 | +0.000018228240691 | −0.0000004236731 | −0.001422421406 |
| H1000 반경 40→80 | 0.04 | +2.5520266227622 | −0.045788393197023 | +0.0004582878024 | +2.5066965173677 |
| H0500 반경 40→80 | 0.04 | +2.5513010196297 | −0.04577803802097 | +0.0004581056781 | +2.5059810872872 |

두 반경 비교의 최대 시각 자체가 0.04초이므로 위 표가 해당 시각의 분해이기도 하다. 시간 상한 반감 비교의 **0.04초** 값은 다음과 같다(단위 mV).

| 비교 | δ(ΔEeq) | δ(ΔetaMid) | δ(Δphil) | δV |
|---|---:|---:|---:|---:|
| R40, H1000→H0500 | −0.00017855124 | +0.000001919724601 | −0.000000063447 | −0.0001766949627 |
| R80, H1000→H0500 | −0.0009041543725 | +0.000012274900654 | −0.0000002455713 | −0.0008921250432 |

반경 비교의 0.04초 전압 차이는 H1000→H0500에서 0.0007154300805 mV만 변했으며 약 2.506 mV의 차이가 남았다. 실제 상한 적용 확인과 함께 보면 이 실험에서는 초기 시간 상한 반감보다 반경 변경의 민감도가 훨씬 크다는 근거다. 두 수준만으로 참해 오차의 상한이나 모든 시간 구간의 시간 수렴이 입증된 것은 아니다.

`analysis.json`의 각 window에는 `at_maximum_voltage_difference`, `at_0p04_s`, 성분별 개별 최대 시각이 있다. 최대 전압·최대 표면 차이·0.04초의 두 전극 전체 원값과 차이는 각각의 `*_profile_at_*.csv`에 보존했다.

## Runtime·물리 검사와 한계

Runtime readback에서 네 모델 모두 `maxstepconstraintbdf=expr`이며 실제 `maxstepexpressionbdf`가 각 설정의 식과 일치한다. 시간 반감 쌍에서는 해당 표현식만 달라지고 다른 core getter는 같았다. 같은 cap의 반경 쌍은 core getter가 모두 같다. 남아 있는 `maxstepbdf=0.1`은 expr 모드의 적용 상한을 뜻하는 값이 아니라 비활성 const 슬롯이다.

Root의 별도 `../native_steps_summary.json`은 네 조건의 실제 interval cap 검사를 통과로 기록한다. 설정값과 실제 step 검증을 구분하며, 내부 solver가 식을 어느 시점에 평가하는지 추측하지 않는다. 특히 초기 branch는 t<0.1초이고 0.1초 이후에는 완화된 branch다. 이 실험은 후반 전체 시간 오차를 독립적으로 반감한 시험이 아니다.

네 작업은 모든 저장 행에서 전압 항등식, 실제 Eeq/직접 표면 함수, 실제 반응 농도 입력/표면 농도, 총 Li 보존, 표면 조성 범위와 후처리 전해질 양수 검사를 충족했다. 개별 해의 전압 항등식 최대 잔차는 전체에서 7.18e-16 V, 총 Li 최대 상대 변화는 2.62834e-15이다. 실제 Eeq/표면 함수 차이, 반응 입력/표면 농도 차이, eta−etaMid는 모두 CSV 출력 정밀도에서 0이다. 새 네 작업에는 범위 중단이나 비유한값 오류가 없다.

총 Li 보존이나 작은 시간 반감 민감도를 반경 수렴의 대체 근거로 쓰지 않았다. OCP 표·초기 조성·재고를 보정하지 않았다. 실패 분류는 실제 guard/범위 증거가 있을 때만 OCP 관련 미완으로 하도록 유지했다. 이전 범위 실패를 수정하거나 새로운 실패를 무조건 같은 분류로 처리하지 않는다.

최대값은 지정된 시간·공간 표본에서의 최대이며 연속장 전체의 엄밀한 bound가 아니다. t=0은 CDI/consistent initialization 이후다. 후속 계산은 자동 제출하지 않는다.

## 재현·검증

CLI: `work/time_caps/analyze_results.py --jobs outputs/time_caps/jobs.json --configs outputs/time_caps/source_configs.json --contract outputs/time_caps/comparison_contract.json`. 출력은 `outputs/time_caps/results/`에만 기록한다. 네 고정 이름 이외의 작업, 잘못된 cap/메시, 예상 밖 runtime 설정 차이, 공통 시각 누락, 좌표·domain 불일치는 통과 판정을 막는다.

합성 회귀 테스트 11개가 통과했다. 기존 8개 수치 검증에 더해 정확히 네 비교의 구성, 의도된 cap 표현식 차이만 허용하는 검사, 새로운 최대 시각과 0.04초 분해의 구분을 확인했다. 실제 입력 CSV는 수정하지 않았다.
