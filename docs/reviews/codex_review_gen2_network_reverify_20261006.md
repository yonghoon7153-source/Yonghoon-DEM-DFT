### Q4의 CF와 협착-only

같은 탐침에서 CF 증서를 삭제하거나 `I_top=0, conservation_rel=1`로 바꿔도 게시와 τ는 통과한다. CF q는 **0.03926991**로 남는다. 협착-only 증서 삭제도 통과한다. 현재 계약이 FULL에만 걸려 있으므로 의도한 범위대로 동작한 것이다.

**τ의 정의는 FULL만 쓰므로 이 사실로 τ 숫자가 틀렸다고 할 수 없다.** 그러나 진단 열이라고 해서 잘못된 해를 정상 숫자로 발행해도 되는 것은 아니다. 다음처럼 분리한다.

- 계산된 CF·협착-only 값을 보존·보고하면 각각의 수치 증서를 검사한다. `model_over_conduction`은 *모델 해석* 표지이지 수치 증서 면제가 아니다.
- 해당 가지 증서 실패는 그 진단 가지의 NOT_COMPUTED와 사유로 처리한다. 정상 FULL까지 자동으로 폐기할 필요는 없다.
- 비관통·0 저항 수축 미구현처럼 해를 발행하지 않는 경우, 존재하지 않는 수렴 증서를 요구하지 않는다. 숫자 없음과 상태의 일치를 검사한다.
- 전자·열을 이번 τ 인계에서 쓰지 않는 한 전체 채널 게시 계약을 이 라운드에서 재설계할 필요는 없다. 다만 “전체 웹앱 σ가 인증됐다”는 표현은 금지한다.

## 4. 수치 풀이와 GEN2-01의 독립 검산

### Q3 기존 반례와 새 고대비 탐침

```bash
python3 probes/adversarial.py

```

옛 반례는 1 Ω 두 개가 직렬인 경로 30,001개와 B에만 붙은 conductance 10^14의 막다른 간선이다. 참값은 G=**15,000.5**다.

| 풀이 단계 | G 또는 I_bottom | I_top | 보존 잔차 | 내부 상대잔차 | 처리 |
|---|---:|---:|---:|---:|---|
| 첫 CG | 30,001.0 | −3.00010×10^-10 | 0.99999999999999 | 1.73207967484×10^-12 | 거부 |
| spsolve_fallback | **15,000.5** | **−15,000.5** | **0** | **0** | 채택 |

이 반례에서 내부 잔차가 작다는 사실만으로 틀린 전류를 구제하지 않는다. 새 코드는 두 잔차를 실제로 모두 수용 조건에 넣는다. 기존 10^6–10^12 대비도 통과했고, 정상 자유 노드 32,368개 망은 CG G=**34.85358577955638**, 독립 직접해 **34.85358577955665**로 유지됐다.

추가로 두 관통 가지의 정확 G가 1/2+19/20=**1.45**인 망에 강한 막다른 가지와 미소 conductance 가지를 붙였다. 강도 10^9–10^14의 13개 입력에서 채택해의 최악 상대오차는 **1.64427×10^-7**였다. 큰 잔차의 해는 직접해로 넘어갔다. 두 직렬 간선의 고대비 검사에서는 10^16 대비를 잘못된 양수로 받지 않고 `current_conservation_failed`로 거부했다. **이번 탐침에서 새로운 수치 false-green은 찾지 못했다.**

1e-6은 현재 사전 고정된 **보존·잔차 수용 문턱**으로 수용한다. 그것을 임의 망의 σ 상대오차가 1e-6 이하라는 정리로 표현하지 않는다. 내부 상대잔차의 분모가 ‖b‖이므로 큰 항이 작은 물리 전류의 오차를 가릴 수 있고, 조건수·전극 선택·모델 오차는 별개다.

CG에 양의 대각 Jacobi를 쓰고, 일반 ILU는 GMRES에만 쓰는 변경은 타당하다. CG는 행렬과 전처리에 SPD 조건을 요구하고, GMRES는 최종 비전처리 잔차도 검사한다. [SciPy CG 문서](https://docs.scipy.org/doc/scipy/reference/generated/scipy.sparse.linalg.cg.html), [SciPy GMRES 문서](https://docs.scipy.org/doc/scipy/reference/generated/scipy.sparse.linalg.gmres.html). 실행에 사용한 SciPy 버전은 별도 환경 기록에 보존했다.

단, **“실패면 모두 다음 사다리”는 코드와 다르다.** `network_conductivity.py:1116`–`:1121`에서 첫 spsolve/CG가 예외를 던지면 바로 `solve_failed`다. 미수렴·증서 실패는 다음 단으로 가지만 첫 예외는 가지 않는다. 안전한 거부여서 false-green으로 세지 않는다. 이 의도와 가용성 한계를 문서에 맞춰 적을 것. 또한 250k 자유 노드 이하라는 조건이 직접해의 메모리 상한을 보증하지는 않는다. 실제 실행 환경의 자원 실패는 숫자 없이 남겨야 한다.
