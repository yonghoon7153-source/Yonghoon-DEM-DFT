# Li3N(001) on-Li 벌집 지그재그 — 3점 + 곡선 보간 4점

```
Li77 (계산된 min) → Li76 → Li88   ·   끼인각 117°   ·   곡선 길이 4.251 Å
```

on-Li 자리(= Li₂N 면 in-plane Li 바로 위)는 **벌집 배열**이다. 이웃 간 2.107 Å,
그 중점이 N–N 다리, 연속 hop 은 120°로 꺾인다 — 이 표면 adatom 확산의 정석 지형이다.

3점을 지나는 **2차 Bézier** 로 보간한다. 제어점 `P1 = (4B − A − C)/2` 로 잡으면
t = 0 / 0.5 / 1 에서 곡선이 A / B / C 를 **정확히** 통과한다 (꺾인 선분 두 개보다 깔끔).

| t | frac | 최근접 Li (Å) | |
|---|---|---|---|
| 0.000 | (0.8878, 0.1206) | 2.14 | ★ **on-Li — 계산된 min 좌표 그대로** |
| 0.167 | (0.8261, 0.1431) | 2.17 | 곡선 보간 |
| 0.333 | (0.7896, 0.1784) | 2.15 | 곡선 보간 |
| **0.500** | (0.7784, 0.2263) | 2.15 | ★ **on-Li (꺾이는 자리)** |
| 0.667 | (0.7925, 0.2870) | 2.15 | 곡선 보간 |
| 0.833 | (0.8318, 0.3603) | 2.15 | 곡선 보간 |
| 1.000 | (0.8964, 0.4464) | 2.15 | ★ **on-Li** |

최저 기판거리 2.143 Å · 평행이동/회전 없음 (원본 두 구조와 같은 시야) ·
큰 공 1.30 Å(3점) / 작은 공 0.62 Å(보간) · `_nobond_` 는 adatom 결합선 없는 버전.

## 재생성

`zigzag_path(atoms, cell, A, B, C, xis, target=2.15, z_start=<min z>)`
(`tools/neb_diffusion/li3n_hop_frames.py`) → `write_merged`.
A/B/C 는 표면 Li 의 분수좌표: Li77 (0.887775, 0.120635) · Li76 (0.7784, 0.2263) ·
Li88 (0.8964, 0.4464). 반대 방향은 Li44 (0.5541, 0.0875), 끼인각 113°.

## 캡션

첫 점만 계산된 좌표이고 나머지는 자리 기하 + 보간이다. 경로 자체는 물리적이지만
개별 배치를 이완시킨 것은 아니므로, 에너지를 점에 붙이지 않는다.

> The atomic models illustrate the Li-adatom diffusion pathway on Li₃N (001).
