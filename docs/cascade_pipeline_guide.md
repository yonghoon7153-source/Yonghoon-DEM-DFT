## 0. 왜 이걸 만드나 (문제 정의)

황화물 고체전해질(argyrodite Li₆PS₅Cl 계열)은 전도도가 높지만 **산화 안정성과 계면
반응성**이 약하다. 개선 수단 하나가 **미량 도핑/코팅** — 다른 화합물을 소량 섞어
산화 onset 을 올리거나 계면을 보호하는 것이다.

문제는 후보가 많다는 것이다. 어떤 산화물·불화물·염화물을, 어느 농도로 넣을지 —
조합이 수백 가지고, **실험으로 하나 검증하는 데 몇 주**가 걸린다.

그래서 계산으로 먼저 줄인다. 그게 이 캐스케이드다.

| | 주는 것 | 못 주는 것 |
|---|---|---|
| 실험 (합성 + EIS + XRD) | 진짜 값 | 후보당 수 주. 왜 그런지는 안 알려줌 |
| DFT | 왜 그런지 (전자구조·결합·에너지) | 후보당 수 시간–수 일. 큰 셀 불가 |
| MLIP (UMA) | 후보당 수 분 | 절대값 신뢰 못 함. 산화상태·스핀 명시 안 봄 |

**캐스케이드 = 싼 것으로 넓게 훑고, 살아남은 것만 비싼 것으로 다시 본다.**

## 1. 핵심 철학 — 이것 먼저 이해해야 나머지가 보인다

### ① 절대값이 아니라 **순서**를 믿는다

UMA(MLIP)가 내놓는 E, E_young, Δe 는 **절대값을 인용하면 안 된다.** 같은 프로토콜로
계산한 후보들끼리의 **상대 비교·순위**만 유효하다. 계통오차가 공통이라 차이에서
상쇄되기 때문이다.

> 이건 겸손이 아니라 규율이다. repo 의 `CLAUDE.md` 에 명문화돼 있고, 어긴 판정은
> 실제로 철회됐다(§14).

### ② 게이트는 **host 상대 좌표**로 잡는다

"산화 onset 이 4.0 V 이상" 같은 문헌의 **절대 문턱을 그대로 이식하면 우리 풀에서는
0종이 통과한다**(§13). 그래서 우리는 "도핑 안 한 host(2.14 V) 이상"처럼 **기준점을
우리 계 안에 둔다**. 그래야 "좋아졌나/나빠졌나"가 계통오차와 무관해진다.

### ③ **못 하는 것을 먼저 말한다**

파괴인성(K_IC), μm 입자 역학, 공간전하층 정량 — 이 캠페인은 못 한다. 발표에서도
논문에서도 이걸 먼저 말한다. 안 그러면 질문에서 무너진다.

## 3. ★ 풀의 정체 — 47종이 어디서 왔나 (이 절이 제일 중요하다)

### 이게 아니다: 발견 깔때기

문헌의 대형 스크리닝은 이렇게 생겼다.

| 논문 | 출발 풀 |
|---|---|
| Xiao 2019 (양극 코팅) | 104,082 (ICSD + data-mined 치환 신조성) |
| Sendek 2017 (ML 전도체) | 12,831 (MP 2016 스냅샷) |
| Kahle 2020 (HT-AIMD) | 15,855 entries → 4,963 unique |

**우리는 이게 아니다.** "수만 개에서 걸러냈다"고 쓰면 틀린다.

### 이것이다: 조성족 스캔

47종은 **사람이 화학적 사전지식으로 고른 목록**이다.

1. Round 1/2 리뷰어 권장 = oxide 9–12종 (코팅 문헌 근거)
2. "ZrCl₄·LiBr 같은 non-oxide 후보가 많다"는 지적으로 4-카테고리 22종으로 확장
3. `master_batch_273.sh` 로 **91 화합물 × 농도 3점(x = 0.02 / 0.05 / 0.10) = 273 실행**
4. 그중 **ESW·탄성·BVSE 3축이 모두 채워진 47종**이 랭킹 표에 등재 = 이 풀

> ⚠ **91 → 47 은 물리 게이트가 아니라 파이프라인 탈락이다.** 구조 seed 생성 실패 등
> (예: As₂S₃ 3종은 stage-01 에서 `n_structures=0` 으로 정직 종료). 이 44종은
> **"떨어뜨린" 것이 아니라 "판정하지 못한" 것** — 깔때기 숫자에 합산하면 안 된다.

### 그러면 우리 체급은?

| 논문 | 조성 수 | 성격 |
|---|---|---|
| Ong 2013 (LGPS 족 치환) | 11 | 조성족 스캔 |
| **우리** | **47** | **조성족 스캔** |
| Fujimura 2013 (γ-LISICON) | 92 | 조성족 스캔 |
| Sendek 2017 | 12,831 | 발견 깔때기 |
| Xiao 2019 | 104,082 | 발견 깔때기 |

**Ong 11 < 우리 47 < Fujimura 92.** 이 계보로 위치를 잡으면 정직하면서도 문헌적으로
정당하다. 발견 깔때기 흉내를 내는 순간 심사에서 무너진다.

### ★ 그럼 그 사람들은 어떻게 10만 종을 봤나 (제일 많이 받는 질문)

**그들은 10만 종을 계산하지 않았다. 10만 종을 *조회*했다.** 이게 답의 전부다.

Xiao 도, Sendek 도 출발 풀의 물성값을 스스로 계산해서 얻은 게 아니라
**이미 남이 돌려 놓은 DFT 결과(Materials Project · ICSD)를 pymatgen 으로 소환**했다.
E_hull·band gap·형성에너지는 DB 에 있는 열(column)이다. 한 종을 더 보는 한계비용이
**사실상 0** 이라, 12,831 이든 104,082 이든 첫 게이트는 그냥 SQL 질의에 가깝다.

그리고 깔때기는 **비용 피라미드**다 — 싼 게이트를 앞에, 비싼 걸 맨 뒤에 놓는다.

```
Sendek 2017 — MP 2016 스냅샷
  Li 함유                                   12,831
  E_hull = 0                       →         1,472   ← 이 하나가 88.5% 를 지운다
  + gap≥1 eV, V̂_ox≥4 V, 무전이금속  →           317
  + 5-특징 로지스틱 회귀 (P>50%)     →            21
  자체 DFT-MD 1 건 · 자체 실험 0 건.  분류기 훈련셋 = **실측 40종**

Xiao 2019 — ICSD + data-mined
  Li 함유                                  104,082
  방사성 제외 + gap>0.5 eV          →        62,437
  E_hull < 5 meV/atom              →         1,600
  ESW (V_ox≥4.0 & V_red≤2.7)       →           302
  |ΔE_rxt| < 100 meV/atom          →           184
  폴리음이온 산화물만                →            66
  CI-NEB (비싼 계산)                →     **6 종**   → 최종 추천 3 종
```

**진짜 계산은 Xiao 가 6종, Sendek 이 1종에 돌아갔다.** 104,082 중 6 = 0.006%.
"10만 종을 계산했다" 가 아니라 "10만 종에서 6종을 골라 계산했다" 다.

#### 우리와 뭐가 다른가 — 피라미드 vs 직사각형

| | 문헌 깔때기 | 우리 cascade |
|---|---|---|
| 출발 풀의 물성값 | **DB 조회** (한계비용 ≈ 0) | **전부 우리가 계산** |
| 모양 | 피라미드 (뒤로 갈수록 소수·고비용) | **직사각형** (47종 × 3축 전수) |
| 비싼 계산이 돈 대상 | 6 / 104,082 | **47 / 47** |
| 축 | 3–4개, 대부분 한 번 | ESW · 탄성 · BVSE **동시에** |

우리가 47에서 멈춘 건 게을러서가 아니라 **조회할 DB 가 없어서**다. 두 전제가 그들에게
있고 우리에겐 없다.

1. **목표 물성이 DB 에 이미 있다.** 도핑된 아지로다이트의 x=0.05 조성에 대한
   E_hull·V_ox·탄성계수는 어느 DB 에도 없다. 우리는 그걸 만드는 게 일이다.
2. **후보가 구조로 이미 존재한다.** 우리는 구조 자체를 seed 부터 생성해야 한다 —
   §3 의 `91 → 47` 탈락이 정확히 그 지점이다(As₂S₃ 3종 `n_structures=0`).

#### 이 비교를 발표에서 쓰는 법

- ❌ "우리는 47종, 문헌은 10만종" → 직사각형 넓이와 피라미드 밑변을 비교하는 꼴이다.
- ✅ "그들의 **훈련셋 40종**과 우리 **47종**이 같은 체급이다."
  Sendek 의 분류기는 실측 40종으로 학습했다. 우리 47종은 전부 우리가 3축을 다 잰
  것이므로, **라벨 밀도로 보면 우리가 그들보다 촘촘하다.**
- ✅ 결정타 — **Sendek 의 12,831 '전수' 안에 argyrodite 가 하나도 없다**
  (2016 MP 스냅샷 밖). 오늘 상용화를 이끄는 조성이 "전수 스크리닝"에서 통째로
  빠져 있었다는 뜻이고, **DB 스크리닝의 상한은 DB 커버리지**라는 걸 그들 자신의
  결과가 증명한다. 우리처럼 host 를 정하고 파고드는 노선의 존재 이유가 여기다.

> 출처: `litdb/papers/sendek2017_ml_screening_12k_conductors.md`(§3 깔때기 표·§16c 산술
> 모순 감사) · `litdb/papers/xiao2019_cathode_coating_screening.md`(§3 Filter 1–6).

## 4. TIER 1 — MLIP 스크리닝 (무엇을 하고 어디까지 믿나)

**도구**: UMA-s-1p1 (Meta FAIR). 원자 위치를 받아 에너지·힘을 내는 신경망 potential.
DFT 데이터로 훈련돼 있어 **DFT 를 흉내내되 수천 배 빠르다.**

**하는 일**
1. **halogen enumerate** — Cl/Br 자리 배치 경우의 수를 만든다 (argyrodite 는 음이온
   무질서가 본질이라 배치가 하나가 아니다)
2. **Li 부격자 스크린** — Li 자리 점유 조합을 훑어 낮은 에너지 배치를 고른다
3. **500 K Langevin anneal** — 국소 최소에 갇힌 걸 풀어 준다
4. 살아남은 **챔피언 config** 하나를 TIER 2 로 넘긴다

**어디까지 믿나**
- ✅ 배치들 사이의 **순위**
- ❌ 절대 에너지, 절대 탄성계수
- ❌ **산화상태·스핀이 걸린 질문** — UMA 는 전하를 명시적으로 안 본다. 이걸로 두 번
  당했다: 양성자 이동 사건, 표면 Li⁺ 추출 사건 (둘 다 UMA 가 판정할 수 없는 전하분리)
- ❌ **Li₃N 계열** — 2026-06 에 결정론적 편향 판정. 사용 금지

## 5. TIER 2 — DFT 검증 (무엇을 다시 재나)

**도구**: Quantum ESPRESSO (평면파 + pseudopotential).

1. **MLIP EOS 사전스캔** — 대략의 평형 부피 V₀ 를 싸게 찾는다
2. **BM3 EOS 11 부피** — 그 주변 11개 부피에서 DFT 총에너지를 재고
   Birch–Murnaghan 3차 상태방정식을 맞춘다 → V₀, B₀
3. **V₀ 확인 (BFGS)** — EOS 가 준 V₀ 에서 이온 이완이 수렴하는지 확인
4. **k-mesh 수렴** — k점을 늘려도 값이 안 변하는 지점까지

> ⚠ **B₀(EOS) ≠ B_VRH(탄성텐서).** 둘 다 "체적탄성률"이라 부르지만 정의가 다르다.
> EOS 는 정수압 응답, VRH 는 C_ij 를 다결정 평균한 값. 섞어 쓰면 틀린다.

> ⚠ **clamped-ion vs relaxed-ion 탄성**은 2.3–2.9배 차이가 난다. 어느 쪽인지 반드시
> 명시한다.

## 6. TIER 3 — 후처리 (축별 관측량)

| 축 | 도구 | 관측량 | 주의 |
|---|---|---|---|
| 구조 | Voronoi, BVSE | 채널 부피, 이동 장벽 프록시 | **정량·순위는 원본 주기셀 값만** |
| 전자 | DOS, ELF | 밴드갭, 전자 국재화 | 갭은 **fixed-occupation nscf 의 VBM/CBM 고유값만** 인정 |
| 결합 | Bader, ICOHP | 전하 이동, 결합 세기 | ICOHP **부호 주의** (음수가 결합성) |
| 수송 | MLIP-MD | MSD → D → σ | **절대값 인용 금지.** β 게이트 필수 |
| 역학 | C_ij → VRH | E, G, B | UMA 상대값. Pugh B/G 는 금속 휴리스틱 |
| 전기화학 | grand-potential ESW | ox_V, red_V | MP GGA/GGA+U hull 기준 |

### 수송 축의 β 게이트 — 꼭 알아야 하는 것

MSD(평균제곱변위)의 기울기로 확산계수 D 를 뽑는데, **확산 영역이 아닌 구간에서 뽑으면
케이지 진동 기울기를 D 로 착각한다.** 그래서 게이트를 건다:

> **β = d log⟨r²⟩ / d log t ∈ [0.8, 1.2]**

β ≈ 1 이면 진짜 확산(⟨r²⟩ ∝ t), β ≪ 1 이면 갇혀 있는 것이다.

> ⚠ **β(앙상블 평균 MSD) ≠ 평균(시드별 β).** 판정은 **앙상블 평균 MSD 의 β** 로 한다.
> 시드별로 게이트를 걸면 선택 편향이 생긴다.

## 7. G1 — 구조 안정 (도핑이 되기는 하나)

- **지표**: `Δe = E(doped champion) − E(host)`, UMA 상대, **x 3점 평균**
- **문턱**: `mean_x(Δe) < 0`
- **결과**: **47 → 47. 0종 탈락.**

### 💤 이 게이트는 vacuous 다

47/47 이 통과한다는 건 **우리 풀이 이미 그 조건으로 큐레이션됐다는 증거**이지, 우리
스크린의 발견력이 아니다. 깔때기 그림에서 이 단을 "우리가 걸렀다"로 읽으면 안 된다.

---

## 8. G2 — 전기화학 창 붕괴 회피

- **지표**: `window_V = ox_V − red_V` (grand-potential ESW)
- **문턱**: `window_V ≥ 0.05 V`
- **결과**: **47 → 43. 4종 탈락** (Fe₂O₃ · CoO · NiO · MnO)

### ⚠ 이 게이트는 **완전 중복**이다 (unique_kill = 0)

떨어진 4종이 **전부 late-TM** 이라 다음 게이트 G3(산화 onset)에도 똑같이 걸린다.
즉 G2 를 빼도 최종 생존자가 안 바뀐다.

**해석**: 우리 풀에서 "창 붕괴"와 "낮은 onset"은 **같은 화학(후기 전이금속 d-band)의
두 얼굴**이다. 별개 축인 척하면 안 된다.

---

## 9. G3 — 산화 onset 비열화

- **지표**: `ox_V` (V vs Li, grand-potential onset)
- **문턱**: `ox_V ≥ 2.14 V` ← **도핑 안 한 host 의 onset**
- **결과**: **43 → 25. 18종 탈락.** unique_kill = 1 (LaF₃)

### ⚠ 축퇴 주의

**19종의 ox_V 가 정확히 2.14 V 에 축퇴**돼 있다 (S²⁻ 가 산화를 지배해서 도펀트가 뭐든
같은 값이 나온다). 그래서 이 게이트는 **통과/탈락 판정만 유효**하고, **축퇴군 안의
순위는 무의미**하다. 2.140 vs 2.140 을 소수점으로 갈라 순위를 매기면 안 된다.

---

## 10. G4 — Li 수송 유지 (채널 미폐색)

- **지표**: BVSE 기반 `ionic_transport norm ∈ [0,1]` (x = 0.05 단일, 농도 평균 아님)
- **문턱**: `transport_norm > 0.3` (+ blocking < 0.6 게이트)
- **결과**: **25 → 11. 14종 탈락.** unique_kill = **6**
  (Al₂O₃ · B₂O₃ · Cr₂O₃ · CrO₃ · In₂O₃ · Sc₂O₃)

### ★ 여기서 정면 trade-off 가 드러난다

**host 의 onset(2.14 V)을 올려 주는 6종**(B₂O₃ · Cr₂O₃ · Ga₂O₃ · In₂O₃ · Sc₂O₃ · Y₂O₃)이
**전부 G4 에서 탈락한다.**

산화를 막는 것과 Li 를 통과시키는 것이 서로 싸운다는 뜻이다. Xiao 2019 가 Fig 7 에서
보인 "V_ox ↔ Li 함량 내재 trade-off" 의 우리판 대응이다. **이게 이 캐스케이드에서
나온 제일 물리적인 결과다.**

> ⚠ BVSE 는 **정적 기하 프록시**다. 절대 σ·D 로 읽으면 안 된다.

---

## 11. G5 — 기계 (연질 + 연성) — 우리 고유 축

- **지표**: `E_young` (GPa, UMA) ↓ **AND** `G/B` ↓, 둘 다 x 3점 평균
- **문턱**: 로스터 **median** (E ≤ 46.9 GPa, G/B ≤ 0.78)
- **결과**: **11 → 1** (WO₃). unique_kill = 10

### ⛔ 이 숫자를 "최종 승자"로 인용하면 안 된다

세 가지 이유:

1. **문턱이 자의적이다.** G1–G4 는 전부 host 값 또는 기존 db 규약에서 나왔는데
   (새 상수 없음), **G5 만 로스터 median** 이다 — 우리 풀이 바뀌면 문턱이 바뀐다.
2. **그 컷 하나가 최종 숫자를 지배한다.** percentile 을 0.25 → 1.00 으로 훑으면
   최종 생존자가 **0 → 11 전 구간**을 움직인다.
3. **문헌에 대응 게이트가 없다.** G5 는 우리가 추가한 축이라 문헌 대비에 넣으면
   사과와 오렌지가 된다.

> **인용은 G4 까지 끊는다.** 문헌과 나란히 쓸 숫자는 **47 → 43 → 25 → 11** 이고,
> G5 는 그 11종을 기계 축으로 **정렬한 부가 정보**다.

---

## 12. 점수화와 Pareto — 랭킹은 어떻게 나오나

게이트가 boolean 통과/탈락이라면, 랭킹은 **가중합 점수**다.

```
score = 0.30·ox + 0.25·stable + 0.20·soft + 0.15·ductile + 0.10·window
        (각 항은 min–max 정규화)
```

- ⚠ **가중치는 우리가 정한 것**이다. 물리에서 유도되지 않는다. 바꾸면 순위가 바뀐다.
- 그래서 **Pareto front** 를 같이 낸다 — "어떤 가중치에서도 다른 후보에 완전히
  지지 않는" 후보 집합. 가중치 선택에 안 흔들리는 유일한 결론이다.
- 축이 **누락된 후보는 점수 0 이 아니라 랭킹에서 제외**한다. 0 을 주면 "나쁘다"가
  되어 버린다 — "모른다"와 "나쁘다"는 다르다.

---

## 13. 게이트 순서는 결과를 바꾸나 — 실측

**120개 순열을 전수 시험했다.**

- **최종 생존자 집합은 순서 불변.** 게이트가 전부 정적 boolean 이라 당연한 결과다.
- 순서가 바꾸는 것은 **중간 숫자와 "탈락의 공" 배분**뿐이다.
- 즉 **깔때기 그림의 모양은 서사 선택이지 결과가 아니다.**

| 순서 | 근거 | waterfall |
|---|---|---|
| P0 = G1→G2→G3→G4→G5 | Xiao F2→F3→F6 (열역학→전기화학→수송) + 우리 기계 축 | 47 · 47 · 43 · 25 · 11 · 1 |
| P1 = G1→G3→G2→G5→G4 | Sendek "전제조건 먼저, 전도도 마지막" | 47 · 47 · 25 · 25 · 7 · 1 |

### 게이트별 선택압 (standalone kill = 그 게이트만 47종에 걸었을 때)

| | G1 안정 | G2 창 | G3 onset | G4 수송 | G5 기계 |
|---|---|---|---|---|---|
| standalone kill | **0** | 4 | 22 | 27 | 32 |
| unique kill | 0 | **0** | 1 | 6 | 10 |

**Sendek 2017 의 "전제조건 > 전도도" 순위가 우리 풀에서는 역전된다.** 전제조건이 이미
큐레이션으로 소진된 풀에서는 **구속조건이 수송/기계로 이동**한다.

## 14. 무엇을 믿고, 무엇을 안 믿나 (정직한 한계)

### 믿는 것
- 게이트 통과/탈락 **판정**
- 후보들 사이의 **상대 순위** (같은 프로토콜 안에서)
- **trade-off 구조** (§10 의 산화 ↔ 수송)
- **순서 불변성** (전수 확인)

### 안 믿는 것
- UMA 절대값 (E, E_young, G/B, Δe)
- BVSE 를 σ·D 로 환산한 값
- G3 축퇴군(19종) 내부 순위
- G5 median 컷이 만든 최종 1종

### 문헌에 있고 **우리 게이트엔 없는** 축 2개
1. **계면 화학 반응성** (Richards pseudo-binary ΔE_rxt) — 추가 1순위
2. **전자 절연** (우리 계산 gap 전수 부재) — 진단으로만 붙였다

> ⛔ "문헌 게이트를 전부 재현했다"고 쓰면 **틀린다.**

### 문헌 절대 문턱을 이식하면?
- `V_ox ≥ 4.0 V` (Xiao) → **0종 통과**
- `Pugh B/G > 1.75` → **0종 통과**

우리가 host 상대·로스터 상대 좌표를 쓰는 이유의 정량 근거다.

## 15. 철회한 판정들 — 우리가 틀렸던 것

이 절이 있는 이유: **틀린 걸 숨기면 다음 사람이 같은 데서 넘어진다.**

| 무엇 | 왜 틀렸나 |
|---|---|
| 단일시드 이온전도도 1.33× | 멀티시드로 보니 시드 산포 안. 단일시드 판정 금지 규율이 여기서 나옴 |
| DOS-threshold 밴드갭 | fixed-occupation nscf 대비 ~0.3 eV 과소. 고유값만 인정 |
| MSD 전 구간 피팅 | 확산 영역이 아닌 구간 포함 → β 게이트 도입 |
| SDCP 흡착 "더 깊으니 화학결합" | 실제로는 표면 Li⁺ 추출. **에너지가 깊어졌다고 결합이 아니다** |
| SDCP Phase-B 자세 선택 | Li 자리 vs Ni 자리가 **9 meV** 차이 (kT 의 1/3) — 사실상 동전 던지기였다 (2026-08-06) |

**마지막 줄이 이 캠페인의 교훈이다**: 비싼 계산을 걸기 전에 **입력 구조를 먼저 재라.**
Phase-B 는 며칠짜리 DFT+U 인데, 초기 자세의 접촉거리를 몇 초 만에 재보니 애초에
화학결합이 아니었다.

## 16. 한 페이지 정리 (외워둘 것)

1. **47종은 큐레이션된 조성족이다** — 발견 깔때기가 아니다. Ong 11 < 우리 47 < Fujimura 92
1-b. 문헌의 10만 종은 **조회**지 계산이 아니다 — 비싼 계산은 Xiao 6종·Sendek 1종에만
   돌았다. 우리 47종은 **전부 우리가 3축을 다 잰 값**이고, 그들 훈련셋 40 과 같은 체급이다
2. **91 → 47 은 파이프라인 탈락**이지 물리 게이트가 아니다
3. 깔때기: **47 → 47 → 43 → 25 → 11 → 1**
4. **G1 은 vacuous**(풀 큐레이션의 증거), **G2 는 완전 중복**(late-TM 두 얼굴)
5. **문헌 인용은 G4 까지 (11종)**. G5 는 우리 고유 축이라 대비에 못 넣는다
6. **제일 물리적인 결과 = 산화 ↔ 수송 trade-off** (onset 올리는 6종이 전부 수송 탈락)
7. **순서는 최종 집합을 안 바꾼다** (120 순열 전수). 깔때기 모양은 서사 선택
8. **절대값 금지, 상대 순위만**. host 상대 좌표를 쓰는 이유 = 문헌 절대 문턱은 0종 통과
9. **못 하는 것**: K_IC, μm 입자 역학, 공간전하층, 계면 반응성, 전자 절연 전수
10. **비싼 계산 전에 입력을 먼저 재라** (2026-08-06 Phase-B 교훈)
