## 3. 한정

- 합성 행렬 (한 변 298 칸 · 이웃 6 · 난수 전도도) 이다.  실제 침대 (54.7 M 칸 격자 가운데 도체 26.5 M · 접합 간선 · 멤버십 미지수 · 행 길이 고르지 않음) 와 행렬 구조가 다르다 → 절대 시간보다 **비** 로 쓴다.
- 반복 **수** 는 재지 않았다 (정해진 수만 돈다).  C 꼴로 바꿔도 반복 수는 같아야 한다 (같은 연산의 다른 표현) — 실풀이 경로에서 끝까지 비트 같은지는 **시험 전** 이다 (코드 묶음의 시험 먼저 항목).
- CPU 몫 (팔마다 준비 4,567 s · 증서 CPU 약 408 s) 은 이 벤치에 없다.
- 다른 프로세스의 부하는 시각마다 다르다 → 한 번 잰 값은 그 순간의 표본이다.
