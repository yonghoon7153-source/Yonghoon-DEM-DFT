# COMSOL 실험 대응표 v1

2026-10-04. 목적은 **현재 모델의 어느 입력이 실험과 같고, 다르고, 아직 확인되지 않았는지** 구분하는 것이다. 실험 적합·파라미터 보정·정량 타당성 판정은 하지 않는다. 원시 실험 자료를 새로 받거나 읽지 않았다.

근거 약어 SPEC·READY·MPHR·SEM의 고정 커밋, 경로와 줄 범위는 `SOURCE_INDEX.md`에 있다. READY는 2026-09-15 당시 기록이므로, 이후 완료된 보호 시험·480초 진단을 미완으로 되돌리는 데 사용하지 않는다. 아래 모델 값은 확인한 기록과 고정 소스에서 옮긴 값이며 실험 값이 아니다.

## 누설 환산에서 유지할 구분

MPHR L117–124의 과거 저항 표는 `epss=.45, b=1.5`라는 Bruggeman 가정 아래 값이다. 현 NORMAL480의 `NoCorr`에 그대로 옮기지 않는다. 현재 모델을 균일 1D 전도체로 해석할 때의 조건부 정의는 `R_eq=L_sep/(sigma_eff*A_eff)`, `I_leak=Δphi_s,separator/R_eq`다. 이때 전위차는 분리막 양단 고체 전위차이며 단자전압과 자동으로 같지 않다. `A_eff` 역시 국소 Fe 경로의 실제 면적과 같다고 두지 않는다.

실험 저항·누설을 받기 전 σ를 역추정하거나 유한 σ 값을 선택하지 않는다. 오래된 보정 표와 현행 모델 정의를 나란히 남기는 것이 A0의 완료 범위다.

## 자료를 받은 뒤의 순서

A1은 별도 범위로 파일 식별·단위·장비 메타데이터·직전 이력을 확인한다. 내용 접근 전 무엇을 볼지 정하고, 이미 보게 된 결과는 노출 기록에 남긴다. A2에서는 모델 대비 잔차를 보기 전에 대상 셀/단계, 시간 0의 정의, 비교 창, 처리·배제 규칙을 고정한다. 전압이 잘 맞는 구간을 사후 선택하지 않는다.

우선 비교량은 V(t)와 고정 시각 ΔV다. dV/dt를 쓰면 차분/필터·창 길이·끝점·결측 처리와 기기 해상도를 함께 사전 고정한다. 아직 기기 정보가 없어 실험 일치의 수치 문턱을 발명하지 않았다. 시작 상태가 맞지 않으면 “현재 입력과 조건 불일치”로 보고하고, OCP·초기조성·전류 변경은 별도 결정한다.

A0 완료는 대응표와 요청문 작성이다. 실험 일치나 모델 보정 완료가 아니다.
