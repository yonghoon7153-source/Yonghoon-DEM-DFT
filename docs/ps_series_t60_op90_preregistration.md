## 무효 판정의 근거 (운동학적 정지)

`vmax = 0.008·(WALL0−FLOOR)` 이고 플래튼은 `wall_z ≈ WALL0` 에서 출발하므로
`스트로크/초기두께 = N × 0.008` (N = 하강 프레임 수).  실측이 **4·4·4·4·3 정수**로 떨어진다
(0.2 % 이내).  즉 정지 시점을 정한 것은 응력이 아니라 **프레임 수**다.
방증 셋: ① 최종 wallP 가 목표 0.3 GPa 의 1/20~1/100 인데 조성별로 5.7 배 흩어짐(응력 정지면
전부 target 근처여야 함) ② 프레임 5 에 wallP = **−0.049 GPa** = 플래튼 인장 = 동적 반동
③ `[am-jam]` 로그 부재 — `--am-jam` 은 opt-in 인데 킷에 없어 기하 정지도 아니었음.

## 원인 (코드) 및 수정

`mpm3d_compaction.py` scaffold 분기의 정지 판정이 `p + am_skel < target` **순간 비교**였다.
바로 아래 non-scaffold 분기는 같은 이유로 이미 `STOP_HOLD = 3` 연속 프레임을 요구한다
("a big rigid AM hitting the platen spikes wallP for ~1 frame, which froze the platen in the
loose state") — **scaffold 분기만 이 가드가 없었다.**  첫-접촉 스파이크 1프레임에 `reached=True`
가 되고, `--protocol hold` 가 플래튼을 그 자리에 고정한 뒤 응력이 이완해 위 표가 나왔다.
→ 같은 지속-요구를 scaffold 분기에 적용(2026-08-04).  `hard_floor`/`am_jam` 은 기하 정지라
지속-요구 없이 즉시 유지.
