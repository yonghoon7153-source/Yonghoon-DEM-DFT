# U6(a) 설정 ② · 입자쌍의 틈 보정만 켠 개발 계산

① 지금 관문 — U6(a), 설정 ②, 판정 짝 F12·F16. F8·F24도 같은 정의로 보고한다.

② 결과 — 미실행. 판정선은 |Φ_m,12 − Φ_m,16| ≤ 0.005다.

③ 다음 한 걸음 — ①의 네 완주 원곡선 및 설정 ② 고정 소스 신원을 확인한 뒤 ②의 네 격자를 한 번씩 실행한다.

## 바꾸는 것

정본 docs/reviews/dem_redesign_direction_20261109/memo_v3_2.md §3-2는 설정과 순서를 정하고 틈 보정의 구체식은 미확정으로 남겼다. 아래는 **설정 ② 결과를 보기 전에 고정한 개발 구현**이다. ①에서처럼 입자별 장들이 실제로 함께 차지한 노드가 접촉 후보가 된다. 거리 기반 후보 선별(설정 ③)은 끈다.

기존 접촉 법선 n을 왼쪽 물체에서 오른쪽 물체 방향으로 사용한다. 기존 아래판 연산자가 추적하는 입자별 256개 표면점으로 두 물체의 법선 투영 간격 g = min(xᵣ·n) − max(xₗ·n)을 계산한다. 매 걸음의 표면 위치를 사용한다. 양의 간격에서는 두 물체가 한 걸음 동안 그 간격만큼 다가갈 수 있다. 따라서 접촉이 허용하는 최대 법선 접근 속도는 max(g,0)/Δt이다. 법선 제약의 초과분에만 충격량을 주고, 접선은 같은 µ=0.5의 쿨롱 법칙을 적용한다. 음의 투영 간격은 허용 접근 속도 0으로 처리한다. 이 간격은 주어진 법선 위의 지지면 간격이며, 일반 변형 입자의 국소 최근접 거리를 측정하는 값으로 해석할 수 없다.

같은 법선 속도 제약을 두 물체와 다물체 접촉 양쪽에 적용한다. 같은 물질점 시드, 등록 판 속도, 시간 간격, 두 판의 경계, 압력 판독과 보간, 기존 수치 가드를 사용한다. 계수를 피팅하거나 속도를 바꾸지 않는다. 출발 조건은 ①에서 사용한 완주 TAR 두 개와 소스 목록에 결속한다.

## 판정과 반환

아래판 압력이 처음 1.2 MPa를 상향 통과한 두 원표본에서 **판 높이**를 선형 보간한 뒤 Φ_m=ΣA₀/(폭×그 높이)를 구한다. 12·16칸 차가 0.005 이하면 ②를 선택하고, 유효한 차가 0.005를 넘으면 ③으로 간다. 8·24칸 수치는 같은 표의 보고 열이다. 미완료 반환은 보류로 보고하고 다음 설정으로 건너뛰지 않는다. 설정을 고르기 전에는 U6(b)·(c) 수치를 선택에 사용하지 않는다. 설정 ②도 초과한다면 ③을, ③도 초과한다면 ④를 같은 순서로 다룬다. 네 설정이 모두 실패하면 단계 3을 진행하지 않는다.

WSL CPU 1개에서 격자 8·12·16·24를 차례로 실행한다. 팔별 기존 상한은 각 1,800·3,600·5,400·14,400초이며 정리 유예 30초다. 각 팔의 실제 시간과 반환 코드를 보존한다. 자동 재시도는 0회다. 실패 반환을 먼저 보존하고 재시도는 같은 팔에서 최대 한 번만 따로 기록한다. 새 가압은 1저자가 실행한다.
