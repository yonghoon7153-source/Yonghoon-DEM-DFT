## 1. 한 줄 요약

**"입자마다 자기 이웃 n_nb 개 중 *다른 상*의 비율을 세고, 그 비율을 *조성이 정하는 무작위
기대값*으로 나눈 뒤 전 입자 평균한다"** — 이것이 GNN mixing index 다 (Eq. 18–20).
Godlieb 2007 의 이웃지표(Eq. 11)가 **50:50 입자수 비에서만** 1 로 정규화되던 것을,
**임의 조성**(Eq. 18)과 **3종 이상**(Eq. 19–20)으로 확장한 것이 이 논문의 전부이자 기여다.
검증은 **X-ray CT 로 찍은 wood/Delrin 이성분 침대**(9.5·12.7 mm, 밀도비 0.5, 수직날 믹서)에서
Lacey(SD계)·MGMMI(위치계)와 나란히 재는 방식으로 했고, **분리가 육안 확인된 케이스에서
MGMMI 는 0.87 (거의 완전혼합)을 내는데 GNN 은 0.44 를 낸다** = 위치계 지표의 실패를 실측으로
보인 것이 이 논문의 가장 값진 결과다.  ⚠ **DEM 은 한 줄도 없다** — *"can be readily adapted
to ... DEM"* 은 전망 문장이지 실행이 아니다.

### 4.1 Lacey 지수 (SD 계, 대조군 ①)

일반형 (Eq. 1):
```
MixingValue = [ f(σ_o) − f(σ) ] / [ f(σ_o) − f(σ_r) ]
```
`f(x)=x` [Ashton 류], `f(x)=x²` [Lacey], `f(x)=log x` 중 **Lacey 의 f(x)=x² 가 가장 널리 쓰인다**.
본 논문이 쓴 형 (Eq. 2):
```
M_L = (σ_o² − σ²) / (σ_o² − σ_r²)
```
- `σ` = 측정 상태에서 **한 상의 표본별 비율**의 표준편차
- `σ_o` = 가능한 **최대**(완전분리), `σ_r` = 가능한 **최소**(완전무작위)

표본 정의 (Eq. 7–8): 전 부피 `V` 를 **S 개의 등부피 표본**으로 나눈다.
```
V_s^(j) = V / S ,   j = 1 … S
C_A(V_s^(j), t, ω) = N_A(V_s^(j), t, ω) / N(V_s^(j), t, ω) = C_A^(j)
```
평균 개수밀도장 (Eq. 9) 과 전역평균 (Eq. 10):
```
⟨N⟩(V_s^(j), t)   = ∫_{V_s^(j)} n(x,t) dx
⟨N_A⟩(V_s^(j), t) = ∫_{V_s^(j)} n_A(x,t) dx
n̄_A = ∫_x n_A(x,t) dx
```

★ **저자들의 Lacey 비판이 이 논문에서 가장 이론적으로 단단한 부분이다** (p.5):
1. Lacey 는 **통계적 변동성**(같은 표본 부피에서 실현마다 `N_A` 가 흔들림)과 **통계적
   비균질성**(`⟨N_A⟩` 자체가 벽·날 근처에서 다름)을 **구분하지 않고 섞는다**.
2. **Lu & Torquato (J. Chem. Phys. 93 (1990) 3452)** [36] 가 보였듯, 부피평균 체적분율의
   **분산은 측정부피 크기에 PCF(쌍상관함수)를 통해 의존한다** — 측정부피가 PCF 특성길이보다
   작으면 분산이 커지고, 매우 큰 부피에서 점근값으로 간다.
   ⇒ **`σ = f(n)` 이라는 Lacey 의 표현 자체가 비균질계에서는 틀렸을 수 있다** (저자 표현:
   *"it is likely that Lacey's expression for σ = f(n) may be erroneous"*).
3. 전역평균 `C̄_A` 로 정규화하는 순간 **공간 비균질이 전부 씻겨 나간다**.
4. ⇒ Lacey 는 **1-점 통계(평균 개수밀도)와 2-입자 통계(PCF)를 한 식에 섞는다**.

### 4.2 MGMMI (위치/중심 계, 대조군 ②)

방향별 GMMI (Eq. 3):
```
GMMI_xp = [ Σ_1^n (x_p − x_ref)/n ] / [ Σ_1^N (x_t − x_ref)/N ]        (y, z 동일)
```
`x_ref, y_ref, z_ref` = 기준(보통 0), `x_p …` = **p 종 입자**의 위치, `x_t …` = **전 입자**의 위치.
⇒ 분자 = p 종의 평균 위치, 분모 = 전체의 평균 위치.  그 **비율**이 방향별 비균질 척도.

종합 (Eq. 4):
```
MGMMI = 1 − ( |1−GMMI_xp| + |1−GMMI_yp| + |1−GMMI_zp| ) / 3
```
본 논문 구현: 2D 단면에서 재므로 **입자 단면적 A 로 가중**하고, 축대칭 실린더라 **z 방향만**
계산 (Eq. 5–6):
```
GMMI_zp = [ Σ_p^n z_p A_p / Σ A_p ] / [ Σ_t^N z_t A_t / Σ A_t ]
MGMMI   = 1 − |1 − GMMI_zp|
```

★ **저자들이 지목한 MGMMI 의 구조적 결함**: GMMI 는 **두 중심(centroid)의 비율**이라
**완전분리 상태에서도 0 보다 한참 큰 값에 수학적으로 묶인다**(*"mathematically restricted to
minimum values greater than zero, even in fully segregated cases"*).  게다가 수직면 분리
패턴에서는 두 상의 중심과 전체 중심이 **거의 같은 평면**에 놓여 **z 방향으로는 "잘 섞였다"고
보고한다.**  ⇒ 1차 모멘트 지표는 **대칭적 분리 패턴에 구조적으로 눈이 멀었다.**

### 4.3 Godlieb 이웃지표 M_G — GNN 의 모체 (Eq. 11)

```
M_G = (1/N_Total) · Σ_{i=1}^{N_Total} ( 2·n_dif / n_nb )
```
- `M_G` = 혼합지수 · `N_Total` = 전체 입자 수
- `n_nb` = **핵심(core) 입자 주위의 이웃 개수**
- `n_dif` = 그 이웃 중 **core 와 다른 종**의 개수

⇒ 이웃의 **50 %** 가 타종일 때 `M_G → 1`.  **계수 2 가 곧 "50:50 전용"의 흔적**이다.

### 4.4 PCF(쌍상관함수)와의 연결 — 왜 이것이 "접촉 통계"인가

```
ḡ_αβ(r,t) = ∫_x g_αβ(x,r,t) dx                                           (12)
g_AB(r)   = ⟨N_AB(r,Δr)⟩ / [ N_A ⟨n_B V(r,Δr)⟩ ]                          (13)
g_AB|_{r=R_A+R_B} = g^C_AB = ⟨N^C_AB⟩ / [ N_A ⟨N^C_B⟩ ]                   (14)
ḡ_AB(r)   = ∫_{V_mixer} g_AB(x,r) dx                                      (15)

  ḡ^C_AB ⟨N^C_B⟩ / [ ⟨N^C_B⟩ ḡ^C_AB + ḡ^C_AA ⟨N^C_A⟩ ]
        = ⟨N^C_AB⟩ / [ ⟨N^C_AB⟩ + ⟨N^C_AA⟩ ]                              (16)

  (1/N_Total) Σ_{i=1}^{N_Total} (2 n_dif / n_nb)
        ≈ ⟨N^C_AB⟩ / [ ⟨N^C_AB⟩ + ⟨N^C_AA⟩ ]                              (17)
```
- `⟨N_AB(r,Δr)⟩` = A 입자로부터 거리 `r` 의 껍질 `(r, Δr)` 안에 있는 **A–B 쌍의 평균 개수**
- `N_A` = 계 전체의 A 입자 수 · `n_B` = B 의 **개수밀도** · `V(r,Δr)` = 구껍질 부피
- `R_A, R_B` = A·B 반지름 · `Δr` = 껍질 두께 · 위첨자 `C` = **접촉(contact) 에서의 값**

★ **이것이 이 논문의 이론적 핵심 주장이다**: *"Neighbor-based mixing indices are closely
related to the PCF at contact."*  즉 **이웃지표 = 접촉에서의 쌍상관함수를 스칼라로 압축한
것**이다.  ⇒ **우리 사전등록의 `E_XY` 와 같은 족(族)이다** (§7-A 에서 정확한 항등식).

⚠ 그리고 같은 문단이 **한계를 스스로 적는다**:
> *"These neighbor-based mixing indices also **neglect spatial statistical inhomogeneity by
> averaging over all regions of the mixer**"*  ⇒ Eq. 12·15 의 `∫_x … dx` 가 바로 그 평균이다.

### 4.5 ★★ GNN 정의식 — **원문 그대로**

**(a) 불균등 조성 · 이성분 (Eq. 18)**
```
              1     ⎛ N_Total        n_B      N_Total        n_A  ⎞
M_GNN  =  ───────── ⎜ ───────  Σ    ─────  +  ───────  Σ    ───── ⎟
            N_Total ⎝   N_B     N_A   n_nb      N_A     N_B  n_nb ⎠
```
- `Σ_{N_A}` = **A 종 입자 전체에 대한 합**, `Σ_{N_B}` = B 종 전체에 대한 합
- `n_B` = **그 A 입자의 이웃 중 B 종 개수** · `n_A` = 그 B 입자의 이웃 중 A 종 개수
- `n_nb` = 이웃 총 개수 (여기서는 상수 7)
- 논문 해설: *"`n_k/n_nb` = **non-k 형 core 입자의 k 형 이웃 비율**, `N_k/N_Total` = 혼합물
  내 **k 형의 전체 비율**.  `n_k/n_nb` 를 `N_k/N_Total` 로 나눈 것이 그 이웃의 혼합값이다."*
  ⇒ **`N_Total/N_B` 라는 앞계수는 "무작위 기대값의 역수"다.**

**(b) 3성분 (Eq. 19) — ★ 우리가 직접 묻는 항목**
```
          1     ⎛ N_Total      n_B+n_C     N_Total      n_C+n_A     N_Total      n_A+n_B ⎞
M_GNN = ─────── ⎜ ───────  Σ   ───────  +  ───────  Σ   ───────  +  ───────  Σ   ─────── ⎟
        N_Total ⎝ N_B+N_C  N_A   n_nb      N_C+N_A  N_B   n_nb      N_A+N_B  N_C   n_nb  ⎠
```
논문 해설: *"`N_Total/(N_B+N_C)` 는 혼합물 내 **non-A 형 입자의 전체 비율**이고 따라서 각 A
입자의 **non-A 형 이웃의 기대 비율**이며, `(n_B+n_C)/n_nb` 는 그 A 입자의 **실제** non-A 형
이웃 비율이다."*

**(c) 임의 i 종 일반형 (Eq. 20)**
```
          1     ⎛   N_Total          n_nb − n_i ⎞
M_GNN = ─────── ⎜ ───────────  Σ    ─────────── ⎟      (i = 종 인덱스)
        N_Total ⎝ N_Total − N_i  N_i    n_nb    ⎠   ,  바깥 Σ_i
```
- `N_i` = i 종 입자 수 · `n_i` = 그 i 형 core 입자의 **이웃 중 i 형 개수**
- `n_nb − n_i` = **그 core 의 non-i 형 이웃 개수**

⚠⚠ **Eq. 19/20 은 `one-vs-rest` 다** — B 와 C 를 **하나로 뭉쳐 "non-A"** 로 센다.
⇒ **상쌍(pairwise) 정보를 원리적으로 버린다.**  (§7-C 가 이것이 우리에게 치명적인 이유다.)

⚠ **정규화는 *입자수* 기준이다.**  Eq. 20 본문은 *"any number or volume fraction of 'i'
number of species"* 라고 느슨하게 적지만, **식에 들어가는 `N_i` 는 개수**다.  체적분율이
아니다 — 이 구분이 우리에게 471 배 차이를 만든다 (§7-B).

**(d) 값의 범위 — 논문의 주장**
> *"The mixing value thus obtained over all particles ranges between 0 and 1, with M = 0 and
> M = 1 indicating complete segregation and complete mixing, respectively."*

⚠ **이 주장은 증명 없이 적혀 있고, 일반적으로 참이 아니다** (§7-A 에서 상계 공식 유도 + 반증).

### 4.6 이웃(neighborhood) 정의 — **두 규약이 제시된다**

| 규약 | 정의 | 본 논문 사용 | 비용 |
|---|---|---|---|
| **① 고정 k-최근접** | 중심거리 기준 **가장 가까운 n_nb 개**.  본 논문 **n_nb = 7 상수** | ✅ **이것을 썼다** | 싸다 |
| **② 가변 배위수** (Chandratilleke [42]) | core 주위 **정해진 반지름**의 구/원 안에 드는 입자를 **질의(query)** 해 개수와 종을 센다 → 입자마다 배위수가 다르다 | ✗ 언급만 | *"more computationally expensive"* |

**n_nb = 7 의 근거 (원문 그대로)**:
> *"An average number of particles in a neighborhood (n_nb), also called the **coordination
> number**, may be calculated based on the **size ratios** between the particles in the system,
> and many different coordination number values have been suggested in the literature [40].
> Based on the size ratios utilized in the present study, the values of **6 +** have been
> suggested [41] for the average number of neighboring particles; therefore, the **constant
> number of 7** neighboring particles was chosen."*

⇒ ★ **저자 스스로 "n_nb 는 크기비의 함수"라고 적고서 상수 7 을 쓴다.**  그들 계의 크기비가
1 ~ 1.33 이라 문제가 되지 않았을 뿐이다.  ⚠ **감도시험(n_nb 스윕)은 논문에 없다.**

**2D 한정 (원문 그대로)**:
> *"since calculations were performed on **2D cross-sectional slices** extracted from the 3D
> volumetric CT reconstructions, **neighbor particles were only defined in the 2D plane**."*

⇒ ⚠ **3D 배위수(6+, Pinson 의 이성분 *구* 배위수)를 가져와 2D 이웃에 적용했다.**  차원이
어긋난다.  게다가 단면상의 **겉보기 반지름은 입자중심이 절단면에서 얼마나 떨어졌는지에
비례**하는데 (저자들이 MGMMI 에는 면적가중으로 보정했다) **GNN 에는 그 보정을 하지 않았다.**

### 4.7 입자 처리 ★ (우리의 "무질서 처리" 대응칸)

- **DEM 없음.**  입자는 **실물**이고, 상태는 **X-ray CT 로 관측**된다.
- **구(sphere) 전용.**  Fig. 5 모식도도 **등크기 원**으로 그려져 있다.
- **단분산/이분산**: 케이스당 **두 크기**(9.5 · 12.7 mm) = 크기비 **1 / 1.33 / 0.75**.
  ⇒ **다분산(poly-PSD) 시험 없음.**
- **형상 소성 없음 / 접촉 소성 없음** — 애초에 역학 모델이 없다.  이 논문은 **순수하게
  기하-통계 지표**다.  (⇒ frame[5] 로 보면 이 논문은 **transport 도 mechanics 도 아니고
  "구조 기술(descriptor)" 층**에 있다.  우리 DEM 후처리 층과 같은 자리다.)
- 대형 입자(~10 mm)를 쓴 이유 = **CT 에서 개수·종을 정확히 셀 수 있게** 하기 위한 것이라고
  명시.  저자들은 그래서 이 조합이 **파일럿 스케일 · DEM 연구 · 큰 입자 응용**에 유용하다고
  적는다 ([26–29], [44] pebble-bed 원자로).

### 4.8 실험/이미지 처리 (재현에 필요한 실무)

1. CT 재구성 → 수평 단면 추출 → **cropping + contrast enhancement**.
2. **원형 객체 검출**로 입자 위치 식별.
3. **평균 화소강도로 종(species) 배정** — Delrin(밝음) vs wood(어두움).
4. ⚠ **결함 하나와 그 대처**: Delrin 입자 내부에 **기포(air pocket)** 가 있어 X-ray 상에서
   어두운 원형 구멍으로 보이고 → (a) 그 자체가 입자로 오검출, (b) 평균강도를 끌어내려 종
   배정을 틀리게 만든다.  대처 = **크기 필터(평균 직경 ±20 %)** + **hole-fill**(평균보다
   낮은 화소를 구멍으로 식별 → 입자 전체 평균강도로 채움).
5. 결과 **오검출 < 5 %** (수동 검수).

> ★ 우리에게 주는 실무 교훈: **종 배정이 지표보다 먼저다.**  종을 5 % 틀리면 이웃지표는
> 그만큼 1 쪽으로 밀린다 (오배정은 언제나 "타종 이웃"을 늘리는 방향으로 편향).
> ⇒ DEM 에서는 원자타입이 정확하므로 **우리는 이 오차원이 0** = 우리 쪽이 유리한 지점.

## 7. 우리 DEM+MPM 대비 ★★ → `our_dem_baseline.md`

> ⚠ `our_dem_baseline.md` 는 **자리표시(placeholder)** 라 값이 없다.  따라서 아래 "우리" 칸은
> **이 digest 세션에서 `docs/data/real14_{am,se}_scaffold.csv` 를 직접 읽어 계산한 실측**이며,
> 재현 스크립트는 §12 에 있다.  ⛔ **이 값들은 논문의 값이 아니다 — 우리 것이다.**

### 7-A. ★★ 먼저 항등식: **GNN 은 우리 `E_XY` 의 손실 있는 사영이다** (우리 유도)

`f_i = N_i/N_Total`, 모든 입자가 정확히 `n_nb` 개 이웃을 갖는다고 하자.
i 종의 **타종(cross) 링크 수** `m_i^cross = Σ_{p∈i} (n_nb − n_i(p))`, 그 무작위 기대
`m_i^cross,rand = N_i · n_nb · (1 − f_i)`, **one-vs-rest enrichment** `E_i ≡ m_i^cross / m_i^cross,rand`.

Eq. (20) 의 i 항 = `m_i^cross / [(N_Total − N_i)·n_nb]`
              = `m_i^cross / [N_Total(1−f_i)·n_nb]`
              = `f_i · m_i^cross / [N_i·n_nb·(1−f_i)]` = **`f_i · E_i`**. ∎

```
        ★  M_GNN  =  Σ_i  f_i · E_i          (f_i = 입자수 분율,  Σ f_i = 1)

           그리고 쌍(pairwise) 로 풀면
           E_i = Σ_{j≠i} [ f_j / (1 − f_i) ] · E_ij
        ⇒  M_GNN = Σ_i Σ_{j≠i}  [ f_i f_j / (1 − f_i) ] · E_ij
```
- **수치 검증**: 합성 계 5종(이성분 50:50 / 70:30 / 3성분 90:7:3 / 3성분 98.6:1.3:0.1 / 분리계)
  에서 `|M_GNN(Eq.20) − Σ f_i E_i| ≤ 7e-16` = **기계정밀도 일치** (§12 스크립트 ①).
- 이성분 50:50 이면 `M_GNN = E_AB` = **Godlieb Eq. 11 과 동일** (계수 2 의 정체가 이것이다).

★★ **따라서 세 가지가 즉시 따라온다.**
1. **우리 사전등록의 주지표 `E_XY` 가 GNN 을 *포함한다*.**  GNN 을 따로 구현할 필요가 없다 —
   `E_ij` 를 재고 위 가중합을 하면 그것이 GNN 이다.  ⇒ **지표를 바꾸는 것이 아니라 *보고
   형식*을 하나 더 얹는 것**이 맞다.
2. **`M_GNN = 1` 은 "모든 `E_i = 1`" 을 뜻하지 않는다** — 가중평균이 1 이면 된다.
   ⇒ **한 상의 응집과 다른 상의 과분산이 서로 상쇄돼 "완전혼합"으로 읽힐 수 있다.**
   (논문이 쓰지 않은 한계.)
3. **상계**: `E_i ≤ 1/(1−f_i)` 이므로
   ```
   M_GNN ≤ Σ_i f_i/(1−f_i) = Σ_i N_i/(N_Total − N_i)
   ```
   - 이성분 50:50 → **2** (논문의 "0–1" 주장 반증: 완전 교대배열이면 2 가 나온다)
   - 논문 Case 2/3 (70.4:29.6) → **2.80**
   - **우리 `real_14` → 71.86**
   ⇒ ⛔ **"0 과 1 사이" 는 정리가 아니라 *거의 등수비 조성에서만 성립하는 우연*이다.**

## 8. 적용 인사이트 — **구현 사양** ★★

### ① 우리가 실제로 만들 것 = **스칼라가 아니라 입자별 장(field)**
논문의 가치는 Eq. 20 의 **바깥 평균이 아니라 안쪽 커널**에 있다.  입자 `p`(종 `s`)에 대해
```
우리 표기:  v_p  =  ( Z_p − Z_p^same ) / Z_p        (이웃 = 실접촉, Z_p = 그 입자의 접촉수)
            ν_p  =  v_p / (1 − f_s)                  ← 논문의 N_Total/(N_Total−N_i) 앞계수
            (M_GNN = ⟨ν_p⟩ 가 곧 Eq. 20 이다 — 우리는 평균을 *내지 않고* 남긴다)
```
- `ν_p` 를 **입자 좌표에 얹어 3D 렌더** → *"여기는 자기들끼리 뭉쳐 있다(ν 낮음) / 여기는
  타상과 섞여 있다(ν 높음)"* 의 **지도**.  ⇒ **회의 [19] 의 *"어디가"* 에 직접 답한다.**
- ⚠ **논문이 이것을 하지 않았다는 점을 반드시 밝힐 것** — 저자들은 *"the mixing index must
  necessarily eliminate spatial dependencies"* 라고 적고 공간분해는 **Nagawkar [37]** 로
  넘긴다.  ⇒ **우리 기여는 "GNN 을 썼다"가 아니라 "GNN 커널을 공간분해했다"** 이다.
- ⛔ 그리고 `ν_p` 의 **절대값을 혼합도로 읽지 말 것** (§7-B).  **팔 사이 차분장
  `ν_p(A) − ν_p(B)`** 로 보면 크기 편향이 공통모드로 상쇄된다.

### ② **가중 규약을 런 전에 선언해야 한다** (미선언 = 사각지대)
같은 침대에서 AM_P 는 **입자의 0.108 %** 이지만 **접촉의 11.6 %** = **107 배 차이**.
- 입자당 균등 가중(GNN 형) → AM_P 가 거의 안 보인다.
- 접촉당 가중(`E_XY` 형) → AM_P 가 100 배 더 보인다.
⇒ ⛔ **둘은 다른 양이다.**  사전등록 §4 에 **어느 쪽인지 적혀 있지 않다** — 결과를 본 뒤에
고르면 그것이 규율 ⑤ 의 false-green 이다.  ★ **런 전에 `E_XY`(접촉당) 로 못박고, 입자당
버전은 부지표로 병기**할 것을 제안한다.

### ③ ⚠ **새 결함 후보 — 압밀이 `Z` 를 바꾸면 `E_XY` 가 혼합과 무관하게 움직인다**
논문이 인용한 **German 2014 [40]** 의 제목 그대로: *"Coordination number changes during
powder **densification**"*.  우리 `m7` 팔 A/B/C 는 **점착이 다르므로 porosity 가 달라질 수
있고**, 그러면 부분 배위수 `Z_ij` 가 팔마다 달라진다 ⇒ **혼합 상태가 전혀 안 변해도
`E_XY` 가 움직인다.**
⇒ **사전등록 §4 보고창에 `porosity` 와 `Z_i`(상별 평균 접촉수) 를 *같이* 적을 것**을 제안한다
(런 전 추가 가능 — 지표가 아니라 **공변량** 이므로 판정선을 건드리지 않는다).
★ **GNN 커널의 `1/n_nb` 나눗셈이 이 축에서는 오히려 장점**이다 — 입자마다 자기 `Z` 로
나누므로 **균일한 접촉 증가에 1차적으로 둔감**하다.  ⇒ ②의 "부지표로 병기" 가 여기서
값을 한다.

### ④ ★ **검증 설계를 통째로 빌린다 — "정답을 아는 배치"**
논문의 **0 회전 = 알려진 수직면 완전분리** 설계가 핵심이다.  우리도 지표를 믿으려면
**답을 아는 침대 두 개**가 필요하다:
- **null-mixed**: 같은 조성·같은 크기로 **무작위 배치**한 침대 → 무편향 지표라면 `M ≈ 1`,
  `E_XY ≈ 1`.  ⇒ **여기서 우리가 얻은 `E_AM_P-AM_P = 294` 가 곧 크기 편향의 크기**다.
- **null-segregated**: 같은 입자를 **상별로 층/면 분리**해 배치 → 지표의 하한.
⇒ 이 둘이 **지표의 눈금(0 과 1)** 을 우리 계에서 *실측으로* 정의한다.  ⛔ 논문의 0/1 을
우리 계에 옮겨 쓰지 말 것 (§10-⑤).
⚠ 단, 12:1 다분산에서 "무작위 배치"는 자명하지 않다 — **같은 `insert/pack` 시드 절차로
만든 침대들의 앙상블**이 우리가 쓸 수 있는 유일한 정직한 null 이다.

### ⑤ **쓰면 안 되는 지표가 확정됐다 (실측 근거 확보)**
- ⛔ **MGMMI / GMMI / 중심(centroid) 기반 지표 전부** — Fig. 7 에서 **육안 확인된 분리에
  0.87** 을 낸다.  구조적 이유: 두 상의 중심이 같은 평면에 놓이는 **대칭 분리 패턴에 눈이
  멀었고**, 비율 형태라 **완전분리에서도 0 보다 크게 묶인다**.
  ⇒ 우리 침대는 z 방향 층분리가 주 모드라 **정확히 그 함정**이다.
- ⚠ **Lacey 는 패턴을 모르면 진다** — 완전분리 초기상태에 **0.55–0.70** 을 낸다 (분할선
  미정렬).  ⇒ 사전등록이 Lacey 계 CLMI 를 **부지표로만** 둔 것은 옳다.

### ⑥ 인용 가능한 **선례**로서의 가치
우리 `E_XY` 의 *"관측/무작위기대"* 정규화는 우리가 발명한 것이 아니다 — **Nadeem 2023
Eq. 18–20 이 동일 원리의 동료심사 선례**이고, 그 자신이 **접촉에서의 PCF**(Eq. 13–17,
Markutsya 2012 [39]) 로 근거된다.  ⇒ 원고/발표에서 `E_XY` 를 **"ad hoc 비율"이 아니라
문헌 계보가 있는 양**으로 제시할 수 있다.

## 10. 주의 / 한계 (over-claim 방지)

### 논문 자신의 한계 (저자가 적은 것)
- **①** *"These neighbor-based mixing indices also **neglect spatial statistical inhomogeneity**
  by averaging over all regions of the mixer"* — 공간 정보 소멸.  저자가 **Nagawkar [37]** 를
  더 엄밀한 대안으로 가리킨다.
- **②** *"neighbor particles were only defined in the **2D plane**"* — 3D CT 를 찍어놓고
  **2D 단면에서만** 이웃을 정의했다.
- **③** *"a **variable** number of nearest neighbors can also be used … may be more
  computationally expensive"* — 고정 k 는 **비용 때문의 타협**임을 인정.
- **④** *"n_nb … may be calculated based on the **size ratios**"* — 크기 의존을 인정하고도
  상수 7 을 씀.
- **⑤** *"The GNN mixing index though **not color-independent**"* — 입자별 **종 라벨이 반드시
  필요**하다 (우리는 원자타입이 있으므로 무해).
- **⑥** Lacey 쪽 결함을 스스로 적음: *"the fully segregated case may predict a mixed state"*
  (분할선 미정렬), *"the scope of this study is not to optimize the Lacey index procedures"*
  ⇒ **Lacey 비교는 최적화되지 않은 Lacey 와의 비교다** = 다소 유리한 대조군 선택.

### 카드가 추가로 다는 한계 (저자가 적지 않은 것)
- **⑦ ⛔ "0 과 1 사이" 는 틀렸다.**  상계 = `Σ_i N_i/(N_Total−N_i)` = 이성분 50:50 에서 **2**,
  논문 Case 2/3 에서 **2.80**, 우리 침대에서 **71.86**.  논문의 주장은 **거의 등수비
  조성에서만** 성립한다.
- **⑧ ⛔ "M = 0 = 완전분리" 도 도달 불가능하다** — 계면 입자는 언제나 타종 이웃을 갖는다.
  실측: **같은** 수직면 분리 초기조건이 Case 1/2/3 에서 **0.34 / 0.165 / 0.19** 로 읽힌다
  (2 배 산포).  ⇒ **지표의 "0 점"이 조성·크기에 따라 움직인다** ⇒ **케이스 간 절대값 비교
  불가.**  논문은 그래도 세 Fig 을 나란히 놓는다.
- **⑨ ⛔ "statistically robust" 는 근거가 없다** — n_nb 감도·부트스트랩·수렴 시험이 **전무**.
  3 회 반복의 표준오차가 통계의 전부다.
- **⑩ ⛔ "grid-independent" 는 절반만 참** — 표본 bin 은 없앴지만 **n_nb 라는 자유 노브가
  그 자리를 차지**했고, 그 감도를 재지 않았다.  우리 침대에서는 **12 배 이동** (§7-B-i).
- **⑪ ⛔ 3성분(Eq. 19/20)은 *미검증 식*이다.**  전 실험이 이성분.  그리고 **one-vs-rest
  축퇴**(§7-C-1)가 있어 3성분에서 정보를 원리적으로 잃는다.
- **⑫ ⛔ 크기비 최대 1.33 → 우리 12:1 로의 전이는 *외삽이 아니라 붕괴*다** (§7-B).
  부분 배위수가 62 배 산포하는 계에서 입자수-분율 무작위 기대는 성립하지 않는다.
- **⑬ ⛔ 이 논문에 DEM 은 없다.**  *"can also easily be adapted to 3D data, such as those
  generated by DEM"* 은 **전망 문장**이다.  DEM 적용 선례로 인용하지 말 것.
- **⑭ ⚠ 대조군 비교표(Siiriä/CLMI/RSD/Stambaugh …)는 이 논문에 없다.**  비교는 **Lacey 와
  MGMMI 둘뿐**이다.  (다른 카드/리뷰의 표를 이 논문에 귀속시키지 말 것 — 이 digest 중
  텍스트 추출 단계에서 실제로 **다른 논문(Jadidi, DEM 믹서 리뷰)의 표가 섞여 들어왔다가
  제거됐다**.  같은 실수를 반복하지 말 것.)
- **⑮ ⚠ 밀도비 0.5 · ⌀10 mm · 중력 침강 분리** 가 이 논문의 물리다.  **우리는 점착·압밀
  분리**다.  **전이되는 것은 지표 수학뿐이고 값·시간축·기전은 하나도 전이되지 않는다.**
- **⑯ ⚠ 코드·데이터 미공개.**  Eq. 18–20 은 재구현 가능하지만 그들의 수치는 재현 불가.

### frame 위치 (우리 규약)
- **frame[4]**: 이 논문은 **교차검증 상대가 아니다** — 실험 앵커도, DEM 도 없다.
  **지표(descriptor) 층의 방법론 선례**일 뿐이다.  "일치/불일치" 를 말할 대상이 아니다.

## 11. 기술 미니 용어집

| 용어 | 뜻 | 이 논문에서의 지위 |
|---|---|---|
| **혼합지표 3계열** | ① SD 계(표본 추출 후 분산) ② 위치/거리 계 ③ 접촉/이웃 계 | Bhalode & Ierapetritou 리뷰 [5] 의 분류.  GNN = ③ |
| **Lacey index** | `(σ_o²−σ²)/(σ_o²−σ_r²)`.  `f(x)=x²` | 대조군 ①.  **표본 크기·위치·개수에 의존** |
| **MGMMI** | Modified Generalized Mean Mixing Index.  한 종의 **중심**과 전체 **중심**의 비 | 대조군 ②.  **대칭 분리에 눈멀었다** |
| **PCF `g_αβ(r)`** | 거리 `r` 에서 α–β 쌍이 **무작위 기대 대비** 몇 배 있는가 | GNN 의 이론적 뿌리 (Eq. 13).  **`g=1` 이 무작위** |
| **접촉에서의 PCF `g^C_AB`** | `r = R_A + R_B` (두 구가 닿는 거리) 에서의 PCF | Eq. 14.  **= enrichment 와 같은 양** |
| **배위수 (coordination number)** | 한 입자에 접하는 이웃 수 `Z` | 논문은 **상수 7** 로 고정.  우리 침대 실측 **5.29 – 329** |
| **부분 배위수 `Z_ij`** | i 형 입자 주위의 **j 형** 이웃 수 | Pinson [41] 의 주제.  **논문이 인용하고 안 썼다** |
| **one-vs-rest** | "A vs (B+C)" 로 뭉쳐 세는 방식 | Eq. 19/20 의 구조.  **3성분 정보 손실의 원인** |
| **enrichment `E_XY`** | `n_XY / n_XY^random`.  1 = 무작위 | 우리 사전등록 §4 주지표.  §7-A 에서 GNN 과 항등 관계 |
| **percolation (침투) 분리** | 작은 입자가 큰 입자 틈으로 내려가 생기는 분리 | Case 2 에서 밀도와 **협력** → 최악, Case 3 에서 **경쟁** → 최량 |
| **grid-independent** | 표본 bin 을 쓰지 않는다 | ⚠ 이 논문에서는 **n_nb 의존으로 대체**됐을 뿐 |

## 12. 부록 — §7 실측의 재현 (우리 계산, 논문 아님)

> ⛔ 이 절의 모든 수는 **우리가 이 digest 세션에서 계산한 것**이고 논문에 없다.
> 입력 = `docs/data/real14_am_scaffold.csv` (457 행: AM_P 36 + AM_S 421) +
> `docs/data/real14_se_scaffold.csv` (32,832 행), 좌표계 = LIGGGHTS box 단위
> (lateral 0–0.05 = 50 µm ⇒ 1 box unit = 1000 µm), 300 MPa 압밀 완료 스냅샷.

| 검증 | 무엇을 확인 | 결과 |
|---|---|---|
| ① 항등식 검증 | `M_GNN(Eq.20) == Σ_i f_i E_i` | 5 개 합성계에서 `|Δ| ≤ 7e-16` |
| ② 실침대 적용 | 고정 k-NN (k = 4…20) 및 접촉그래프로 Eq. 20 | k=7 → **0.0239** · 접촉 → **14.14** · AM 항은 상수 |
| ③ 3성분 축퇴 | 순수 AM 덩어리 안의 AM_P | Eq. 20 안쪽 항 **0.831** (천장 1.0) vs 실제 SE 이웃비 **0.132** |

★ ②를 **그 자리에서 재현하는 최소 코드** (의존 = numpy + scipy, 리포 루트에서 실행):
```python
import numpy as np
from scipy.spatial import cKDTree
rows=[]
for f in ['docs/data/real14_am_scaffold.csv','docs/data/real14_se_scaffold.csv']:
    for ln in open(f):
        if ln.startswith('#'): continue
        c=ln.strip().split(',')
        if len(c)>=5: rows.append((int(c[0]),float(c[1]),float(c[2]),float(c[3])))
lab=np.array([r[0] for r in rows]); pos=np.array([[r[1],r[2],r[3]] for r in rows])
N=len(lab); tree=cKDTree(pos)

def m_gnn(lab, nbr):                      # Nadeem 2023, Eq. (20)
    k=nbr.shape[1]; tot=0.0
    for sp in np.unique(lab):
        Ni=(lab==sp).sum(); idx=np.where(lab==sp)[0]
        ni=(lab[nbr[idx]]==sp).sum(axis=1)          # 동종 이웃 수 n_i
        tot += (N/(N-Ni))*((k-ni)/k).sum()          # 앞계수 × Σ (n_nb − n_i)/n_nb
    return tot/N

for k in (4,6,7,8,10,12,20):
    _,nbr = tree.query(pos, k=k+1)                  # 자기 자신 제외
    print(k, round(m_gnn(lab, nbr[:,1:]), 4))       # 7 -> 0.0239  (무편향이면 1.0 이어야 한다)
```
