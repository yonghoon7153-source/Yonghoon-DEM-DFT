# Ⓑ AM 자유 표면의 SE 접촉 피복 C(0)

개발용 비 Rint 측정 모듈. 근거는 `docs/reviews/mpm_coverage_interface_design_memo_20261103.md` §4-1·§5, 픽셀 경계 대조는 `scripts/mpm3d_compaction.py`의 고정 MPM 씨앗 래스터다.

`scripts/mpm_coverage_c0.py`에 같은 AM 격자와 씨앗·끝 SE 물질점 수를 주면 AM 두 상 각각의 자유 면·접촉 면 수와 면적(µm²), C(0)(분율)를 반환한다. x,y 이음매를 건넌 AM|SE 면을 별도로 센다. 분모에서 AM|AM과 z 상자 밖 면을 제외한다. 기준 8점 중 4점부터 점유로 친다. 빈 자유 표면과 상 부재는 각각 사유를 담은 null, 피복이 없는 자유 표면은 수치 0이다. AM과 점유 SE가 같은 셀에 있는 입력은 모호하므로 이유를 반환하며 중단한다.

| 입력 | 규약 |
|---|---|
| am_phase | 동일한 고정 scaffold의 3D 정수 배열, 0 = 비 AM, 1·2 = 상 번호. 축 순서 x,y,z |
| end_counts | 같은 격자의 끝 상태 SE 물질점 수, 0 이상 정수 |
| seed_counts | 같은 격자의 씨앗 점 수. 기하를 주는 경우 생략 |
| seed_spheres, n_grid, lateral_origin | 씨앗 격자의 대안. 상자 단위로 변환이 끝난 (x,y,z,r) 행·원 MPM 분해능·측방 주기 영역의 시작 셀을 받는다. 측방은 정사각 crop, z는 전체. 구 합집합에서 AM 셀을 제외하고 8점씩 부여한다 |
| h_um | 스칼라 등방 셀 폭, µm |
| --rigid-am1, --rigid-am2 | 선택 입력. 같은 상의 같은 자유 표면 정의로 구한 강체 해석 분율. 미제공 시 강체 기준·씨앗 치우침은 null |

NPZ 자료 지정은 `python -I -B scripts/mpm_coverage_c0.py INPUT.npz`. 출력은 JSON 한 장이다. 소성 증가 = 끝 − 씨앗, 씨앗 치우침 = 씨앗 − 강체다. 면적은 원 격자 면적이다. 법선 보정, 양의 근접 띠, 구별 번호 운반, 실제 데이터의 키·좌표 변환 결속 및 Rint 연계는 후속 범위다.

로컬 합성 확인은 면 검사 9실패 → 9통과, 씨앗 검사 3실패 → 동일 3통과 및 넓은 구·CLI 대조 1통과다. 작은 침대에서 기존 래스터 함수만 추출해 주기 경계·겹침·순서·z 끝을 포함한 씨앗 점유 배열을 바이트 단위로 대조했다. 엔진·현장 실행 및 실측값 판독은 0건이다.
