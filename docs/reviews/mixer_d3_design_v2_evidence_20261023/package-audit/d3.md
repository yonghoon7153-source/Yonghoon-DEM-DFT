## 정책·범위 대조

- 유한 후보 기본 결과 V2-Q1 및 새 통계·열람·검증 규칙은 미비준 제안이라고 설계 머리·§9·§10, 요청서, 쪽지·README에서 유지한다. 기존 Q1–Q12/“고친 뒤 보내자”를 새 정책 승인으로 전환하지 않는다.
- 미평가 유무와 무관하게 빈 S는 유한 B 안의 결과다. 격자 사이/밖 또는 연속 모델 전체 기각을 주장하지 않는다. 미평가 점은 B 자체의 판정도 불완전하게 한다.
- 후보별 incompatible+unassessed는 incomplete로 요약하더라도 원 불일치를 보존한다. empty S는 not-applicable이며 성공이 아니다. S를 보존하고 검증 후 맞은 후보만 골라 원 분석을 성공으로 바꾸지 않는다. all-compatible도 지정 검증 범위의 양립에 한정하고 응용·실행 GO로 쓰지 않는다.
- C1 보정 봉인/열람과 C2 각 검증 봉인/열람을 다른 단위·키/권한으로 구분한다. 단일 키의 검증 누설, 구두 전달, 분리 불가를 명시하며 암호문 SHA가 인지적 맹검의 증거라고 주장하지 않는다. 접근통제 구현·실물 운영 완료 주장은 없다.
- 예약 시드 15485863·86028121·104395301은 실제 v1의 ID·순서와 D1/D12 역할에 맞는다. 실제 C0/C1/C2 manifest 미사용 또는 교집합 검사 구현은 미확인으로 유지한다. 최초 재확인 보고서의 당시 ‘숫자 출처 미확인’을 삭제하지 않고 확대 입력 부록으로 한정 보충한다.
- 원장 여덟 건은 새 쪽지 안에서 open 등재 제안이다. 문서 지적 해소를 생산 verified나 MXD2-07 종결로 자동 승격하지 않는다.
- 전체 gate·핀 ZIP·외부 발송·새 등록·실측/DEM 실행은 대기/HOLD이며 기존 승인 절차를 낮추지 않는다. 새 커밋은 자리 표시이고 기존 소스 HEAD·콘텐츠 SHA만 근거로 기록한다.

## 별도 이식성 재현

감사자가 `/tmp`에서 명시 repo/draft 인자로 번들의 네 도구를 Python `-I -B`, BLAS 한 스레드로 각각 실행했다. 출력은 공백을 포함한 새 `nonrint-package-audit/d3 replay/`에 보관했다. 네 도구 rc 0, 29/29·25/25·7/7·5/5 재현. 스크립트는 과거 scratch 절대 경로를 입력으로 요구하지 않는다. 원 보고서의 절대 실행 경로와 옛 지문 목록은 과거 provenance로 보존되어 있으며 현재 재생 명령과 구분되어 있다. 이 재생은 새 외부 독립 리뷰나 생산 통계/접근 제어 시험이 아니다.
