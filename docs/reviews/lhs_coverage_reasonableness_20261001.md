## 8. 한계 · 재현

- AM 입자별 값 (`coverage_per_am.csv`) 은 배치 산출에 없다 → legacy · rough 의 AM 단위 클립 수, 상별 v2 클립 수는 직접 셀 수 없다 (침대 수준 · v2 전체만).
- SE 바닥 몰림은 원자 z 분포를 직접 보지 않고 **벽 접촉 수 (SE 바닥 vs 플래튼)** 와 **벽 등급별 피복** 두 독립 지표의 일치 (ρ +0.81) 로 추정했다 — 확인하려면 원 덤프 z 히스토그램.
- 경향 ρ 는 LHS 설계의 교락 (am_pct · d_SE · d_AM 이 한 표본에서 같이 변함) 을 다 풀지 못한다 → 부분ρ 로 SE 비율만 뺐다. 모형 R² 는 경향 강도 참고용이지 예측 모형이 아니다.
- 포화 열의 robust z 는 MAD = 0 이면 정의되지 않는다 (표에 `MAD` 로 표기).
- 역사 코퍼스 대조는 같은 legacy 코드지만 침대 생성 · 크기 · 두께가 달라 동일 조건 대조가 아니다 (E_SE 1.35 만 골라도 치밀도가 다르다).
- 재현: `python3 cr_load.py && python3 cr_checks.py && python3 cr_trends.py && python3 cr_tables.py && python3 cr_report.py` (scratchpad 에서 · 리포는 읽기만).
