원 작성 측 Linux3.11·3.8의 84/84·25/25·33/33·357/357 및 18묶음 통과는 앞선 README의 수령 기록이다. 이번 Windows 재실행 수로 옮기지 않는다. Windows의 fake GPU 시험은 bash 진입 전 21개 통과 뒤 환경 오류로 중단했다. Git 격리 일부 실패는 Windows 소유권 경계로, 전체 suite 통과라 쓰지 않는다. 전체 gate·신호 실험·GPU·엔진·현장 접근을 하지 않았다.

리포 참조 검사는 별도 check_results.json을 따른다. native 실패를 성공으로 바꾸지 않는다. 재현은 환경에 NumPy/SciPy가 있는 상태에서 `python -I -X utf8 -B scripts/test_rint_takeover_boundaries.py` 및 기존 조립 시험으로 가능하다. 양성 비교는 기록을 만들 뿐 과학적 값의 인증이 아니다.
