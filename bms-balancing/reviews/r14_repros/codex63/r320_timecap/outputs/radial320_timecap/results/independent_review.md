# R320 초기 시간 상한 반감 독립 수치 검토

판정: **이번 저장 표본의 R320 H0250→H0125 초기 시간 상한 민감도는 전압 1 mV·표면 조성 1e-4 기준을 충족한다.** 별도 원시 CSV Decimal 재검산도 PASS다. 이는 0.1초 이후 시간 정확도, 참값 오차 또는 전체 수렴의 입증이 아니다.

## 비교 식별과 방법

기존 `Caps300R320H0250`, job `f0db6d080ad04045a2b43dc5a51d89b2`, 소스 SHA `837f8b03ff3381bb1aea6397935d0079b032f5e4aea007b32d1ebf7c40775b2e`를 재사용했다. 새 `Caps300R320H0125`, job `18a00b03e38d4694b9ba30d88e7008f4`, 소스 SHA `8d35be8fab513f5e2def316c4d00e0fdc19983a5dd3bf492f4ffe47a58248be3` 한 건과 비교했다. 계약의 원자적 기준 식별, 소스 설정, job 기록, 실제 job 소스 해시가 일치한다.

물리 요소 300·각 전극 입자 요소 320을 유지하며 초기 cap만 0.00025→0.000125초로 변경했다. 두 식은 각각 `if(t<0.1[s],EARLY[s],0.1[s])` 형태다. CSV의 핵심 runtime getter에서 허용한 cap 식 외의 차이는 없다. 전체 소스·Time/Variables·실제 accepted step의 별도 검토는 [독립 native 감사](../INDEPENDENT_NATIVE_AUDIT.md)에 기록되어 있다.

분석기는 정확한 Decimal 요청 시각 187개와 모든 정확 공통 native 저장 시각의 교집합을 별도로 사용했다. 근접 시각 대체와 시간 보간은 없다. 공간 표본은 COMSOL이 각 domain에서 평가한 고정 좌표 241개/전극이며, N domain 1·P domain 3을 각각 확인했다. Python에서 추가 공간 보간은 하지 않았다. 저장 시각 중복, 누락, 좌표 불일치는 통과시키지 않는다.

## 이전 반경 차이와의 크기 비율

이전 비교는 같은 H0250 조건의 R160(job `15e5d7433a6a4956b820cf6952330735`, 소스 SHA `4b4ff66bca7a161f6acffd5b125ddf695fee95fb82cdb4ded1e8b63391e1e5f0`)→R320(job `f0db6d080ad04045a2b43dc5a51d89b2`)이다. [이전 분석](../../radial320/results/analysis.json)의 경로·SHA를 계약과 검증했고, 원본 boundary CSV에서 최대 0.6170341087208 mV(@0.002초)를 재계산했다. 이전 교집합은 571개로 이번 565개와 구분한다.

이번 시간 반감 최대 / 이전 반경 최대 = **0.002058103442502921**, 즉 **0.2058103442502921%**다. 네 창 모두 같은 비율이며 이 경우 최대 시각도 0.002초로 같다. 따라서 이번 cap 반감의 관측 차이는 이전 반경 차이에 비해 작다. 이는 단순 크기 비율이며 수렴 차수, 참값 오차 또는 시간 영향을 완전히 제거했다는 증명은 아니다. R160H0250→R320H0125라는 혼합 설정 차이를 순수 반경 비교로 만들지 않았다.

## 수치·보호 확인과 독립성

두 native 작업은 completed, compile/batch rc0이며 0–5초를 포함한다. 새 해의 저장 표본에서 최대 전압 항등식 잔차는 6.33e-16 V, 최대 전체 Li 상대 drift는 2.925856033641249e-15, 최소 전해질 농도는 1194.4372136345676 mol/m³다. 실제 반응 입력=입자 표면 농도, Eeq=표면 입력 함수 평가가 두 전극에서 CSV 정밀도상 일치한다. OCP guard는 0이고 표면 범위 검사를 통과했다. 전극별 profile은 기준 142913행(593×241), 새 해 237867행(987×241)이다.

전해질 양수는 **POSTPROCESSING_ONLY**이며 실시간 StopCondition이라고 해석하지 않는다. 기존 OCP·표면 조성 StopCondition, OCP/entropy 외삽 금지와 과거 failed/INCOMPLETE_RANGE_STOP 상태를 변경하지 않았다. 다른 원인의 실패나 누락 CSV를 자동으로 OCP 범위 중단으로 분류하지 않는다. 전체 Li 보존 또는 solver 완료를 수렴 판정으로 대신하지 않는다.

독립 [원시 재검산](raw_arithmetic_recheck.json)은 분석기를 import하지 않고 raw boundary CSV의 Decimal 차분과 exact `(time, coordinate)` profile join을 다시 수행했다. 0–5초 공통 native 표본에서 272330개 전극 좌표 쌍(565×482), 요청 시각에서 90134쌍(187×482)을 대조했다. 최대 차이·시각·위치, 네 창의 성분 분해와 동적 성분 CSV 8행, 이전 반경 최대의 원시 재계산 및 비율이 일치한다.

분석 회귀 테스트 18개가 통과했다. 실제 공통 native 시각에만 있는 피크, 요청 시각 누락, 중복 시각, 좌표/domain 불일치, 단순 extrema로 숨겨지는 pointwise 차이, 다른 창의 최대 시각 합집합, cap 외 runtime 변경, 잘못된 기준 identity를 검사했다. 실제 입력 산술과 테스트 과정에서 COMSOL은 실행하지 않았고, 새 분석 폴더 외의 원본·기존 결과를 수정하지 않았다.

현재 결론은 **동일 R320의 지정된 5초 표본에 대한 초기 시간 상한 반감 민감도**에 한정한다. tighter cap은 t<0.1초에만 적용되고 이후 cap은 두 해 모두 0.1초다. 이후 정확도·참값 오차·전체 반경/시간 수렴은 미입증이다. 추가 계산을 권한 없이 이어서 실행하지 않는다.
