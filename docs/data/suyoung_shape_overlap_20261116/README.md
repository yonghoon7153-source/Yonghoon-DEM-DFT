## 2. 두 정의

물질점은 좌표 자체로는 면적이0이다. 따라서 **물질점 기준**을 면적 가중 중심점 구적 추정으로 명시했다. 같은 NPZ의 x, F_total, reference_area, particle_id를 사용한다.

- 셀 p의 사각형 = x_p + F_total,p × (초기 정사각형의 네 모서리). 현 셀 면적 a_p. 기존 SVG 생산식과 같은 정의이며 시간 보간·재시드·hull 채우기 없음.
- 셀 그림 기준: ID별 사각형 합집합 G_i를 만들고, 서로 다른 i,j의 교집합들을 다시 합집합하여 면적을 센다. 세 입자가 겹쳐도 같은 공간은 한 번 센다. 판/상자로 자르지 않은 전체 그림 셀 기준이다.
- 중심점 기준: 각 x_p를 엄격히 내부에 포함하는 전체 셀 수 k_p와 서로 다른 ID 수 d_p를 센다. **Σ a_p/k_p × 1[d_p≥2]**. 같은 공간의 중복 표본을 보정한 1점 구적이며 교집합 기하의 정확한 대체가 아니다. 경계 위 점은 내부에서 제외한다. 얇은 띠·셀 간극·자기 겹침에서 편향이 가능하다.
- 선 폭 민감도: 같은 셀에 원 SVG stroke/2=0.000125의 바깥 띠(miter limit4)를 더한 교집합. 화면 안티앨리어싱/투명도 픽셀 면적은 아니다.

이 결과는 운반된 물질점·affine 그림 셀의 중첩이다. 이 셀을 실제 입자 자유 표면이라고 가정해 물리 침투량으로 보고하거나, 작은 노드 접촉 잔차를 형상 비관통 증명으로 쓰지 않는다. 이번에는 접촉법칙·계산코드·S/F 압력을 고치지 않았다. 기존 판 응력비 **2.469217025330513**은 원 결과 수령값이며 새 계산값이 아니다.
