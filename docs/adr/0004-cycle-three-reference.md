# ADR 0004 — 유지율과 "초기 쿨롱효율" 의 기준은 3번 사이클

- 상태: 채택 (2026-08-20)
- 관련: `packages/wrdkit/health.py`, `packages/wrdkit/knee.py`

## 맥락

1~2번 사이클은 formation 이다. SEI/CEI 형성과 비가역 상전이로 **설계상** 용량을
잃는다. 실측 파일에서 사이클 1 의 CE 는 93.21 %, 사이클 3 은 99.60 % 였다.

사이클 1 을 기준으로 유지율을 재면 formation 손실과 열화가 섞인다. knee 탐색은
더 나쁘다 — 사이클 1→2 의 기울기(−6.7 %/cycle)가 초기 열화율로 잡히면, 이후
어떤 급감도 "그보다 완만" 해서 knee 가 영원히 안 잡힌다. 실제로 초기 구현에서
그 버그가 났다.

## 결정

- 유지율 기준 사이클 기본값 = **3**. sample 별로 변경 가능.
- "초기 쿨롱효율" 은 **기준 사이클의 CE** 로 보고한다. 관례상 ICE 가 1번을
  뜻하므로, 1번 CE 도 `first_cycle` 로 함께 노출해 혼동을 막는다.
- **knee 탐색은 기준 사이클부터 시작**한다 (`KneeAnalysis.search_start_cycle`).
- 기준 사이클이 파일에 없으면 (예: `_012` 파일이 200 사이클부터 시작) 조용히
  1번으로 떨어지지 않는다. `reference_available=False` 로 표시하고 어떤 사이클을
  대신 썼는지 문장으로 남긴다.

## 결과

실측 파일 기준, 3번 앵커링 전후 비교:

| 기준 | segmented knee | slope_ratio knee | 초기 열화율 |
|---|---|---|---|
| 사이클 1부터 | 23 | **검출 실패** | −0.375 %/cycle |
| 사이클 3부터 | 22 | 13 | −0.081 %/cycle |

초기 열화율이 4.6배 과대평가되던 것이 바로잡혔다.
