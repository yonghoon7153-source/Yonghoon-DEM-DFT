## 4. 열린 사항에 대한 답

**LHS 권고안 여부 — 예.** `docs/collab/codex_to_claude/20261106-0800_lhs-n-preaccess-definitions.md`가 사전 접근 정의와 분리된 실행 결정의 권고안이다. A는 정본 source 선택이 성립할 때 우선, C는 변경 시험·재검토 필요, 실제 값은 명부·열람 규칙 고정 뒤 별도 GO라는 제안이다. 당시 재고 HOLD 문구는 역사로 보존하고, 최신 상태는 **재고 실행에 대한 11-06 1저자 GO 수령 / Rint ② 회차 ③ 발송 뒤 착수 / A/C·값 열람은 별도 비준 대기**로 구분한다. 이번 복원에서는 착수하지 않았다.

**믹서 first8 — HOLD가 맞다.** 비활성 후보의 정적 수용으로 운영 `source_seal.json` 갱신이 완료되지는 않았다. 생성기 단독 부적격 덱 출력, 운영 소스 봉인 갱신·최종 결속 검토, MLA-01–03 외부 재확인, 예약 해제/정책 전환, 실제 binary·MPI·호스트·100k·시간·디스크 자격, 1저자 NP·동시 팔·순서 결정과 실행 GO가 남아 있다. NP20·E0 단독→N0 단독→B1/B2/B3 U/C·이후 최대 2팔은 미비준 권고이며 승인으로 쓰지 않는다.
