## 무엇이 바뀌었나

Phase 1 은 창 고정 + 창내 전역 극값으로 peak/valley 를 잡았다. 곡선이 밀리면
**다른 극값을 잡는다** — LLI 스윕에서 valley 가 3.859 → 3.900(창 상한) →
**3.736 으로 점프**했고 peak 도 lli 0.12→0.14 에서 dq 5.54→8.25 로 갈아탔다.
Phase 1 의 비단조는 그 산물이었다.

Phase 1b 는 pristine 에서 peak/valley 를 고정하고 격자를 BFS 로 퍼지며 **직전
격자점의 극값 전압에 가장 가까운 극값**을 따라간다. 한 걸음 이동이 60 mV 를
넘거나 peak/valley 순서가 뒤집히면 **추적 실패로 표시하고 가지를 끊는다**
(조용히 갈아타지 않는다 — fail-closed).

**교차 검증**: 이렇게 잡은 pristine PVS = **−19.85 Ah/V²**. 세미나 p.8 의
pristine ≈ −20 과 사실상 일치한다. Phase 1 의 −11.3 은 틀린 valley 였다.
valley 의 정체는 "peak 다음 **첫** 국소 최소" 이지 창내 전역 최소가 아니다.

## 발견 2건 (방향성 관측 — 인용 금지 등급)

### ① 우리 모델에서 PVS 가 못 가르는 쌍은 {LAM_PE, LAM_NE} 다

pristine 에서 **∂PVS/∂LAM_PE = −37.4, ∂PVS/∂LAM_NE = −36.8 — 비가 1.014**.
1×3 Jacobian 을 단위벡터로 쓰면 `[0.980, −0.142, −0.140]`. 두 LAM 성분이
소수점 셋째 자리까지 같다. **PVS 는 LLI 를 크게 잡고 두 LAM 을 서로 구별하지
못한다.**

세미나 p.8 은 반대 구조를 보고한다: {LLI, LAM_PE} 가 같은 부호로 묶이고
LAM_NE 만 반대. 즉 **세미나가 말한 degeneracy 쌍과 우리 모델이 보이는
degeneracy 쌍이 다르다.**

이것은 질문 카드 `pvs-sev-lli-lampe-separability` 의 H1(= LLI↔LAM_PE 가 안
갈린다)을 우리 모델 안에서는 **지지하지 않는다**. 대신 새 가설이 필요하다:
**H3 — PVS 가 못 가르는 쌍은 {LAM_PE, LAM_NE} 이고, 그 쌍은 우리 주 프로젝트가
이미 재고 있는 바로 그 축이다.**

### ② LAM_PE 부호 불일치의 유력 원인: LAM type 이 다르다

우리 격자는 `lam_pe_type = "de"` 다 — **delithiated LAM**: 죽은 PE 는 비어
있었다고 보고, 남은 PE 가 재고 전량을 가진다 (`src/modes.py:213-214`,
`pe = pe / (1 - lam_pe)` → 남은 PE 의 stoichiometry 가 **올라간다**).
`li` type 이면 죽은 PE 가 리튬을 물고 죽으므로 반대로 움직인다.

**세미나 슬라이드는 어느 type 인지 인쇄하지 않았다.** LAM_PE 가 PE
stoichiometry 창을 어느 쪽으로 미느냐가 ICA peak 의 이동 방향을 정하므로,
type 이 다르면 PVS 부호가 뒤집히는 것이 자연스럽다. 이것이 확인되면 불일치는
**모델 차이**이지 어느 한쪽의 오류가 아니다.

→ **발표자에게 물어볼 것 (구체적 질문 1)**: p.8 의 P2D LAM_PE 스윕에서 죽은
양극 활물질이 리튬을 **비운 채**(delithiated) 죽는가, **문 채**(lithiated)
죽는가? Birkl 계열 표기로는 LAM_deP / LAM_liP 구분.

## 커버리지 한계 (feature 의 구조적 성질로 기록)

0~12 % 범위에서만 다룬 것과 정합적이다(p.13 parity plot 축 범위).
