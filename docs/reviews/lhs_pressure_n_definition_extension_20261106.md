작성: 2026-11-06. 기준 초안 `fe90b0bd0212da6fba8dffd56991a0b2bbea9615`, 수용 기록/이 가지의 문서 기준 `c3887490e252d1ca6f1246efd4c6c2fa5850cfc3`.

## 2. 코호트와 선행6 겹침 — 값 없이 고정하는 규칙

후속의 첫 작업은 압력·N·porosity·τ를 읽는 것이 아니라, **모집단 목록과 원천 침대 계보를 잇는 명부**를 만드는 것이다. 필수 열은 candidate_case_id, design_family, source_design_id, insertion_seed, original_bed_id, parent_bed_id, restart_lineage_id, source_identity_status, prior6_overlap_status, pairing_status, exclusion_reason다. 신원을 모르면 null/UNKNOWN을 남긴다.

1. 선행6은 이름만 아니라 원 덱/침대 원천/재개 부모의 식별자로 고정한다. 같은 침대를 재개·복사·다른 호스트·다른 이름으로 옮겼거나 같은 원천의 후속 단계면 선행 노출 연결을 유지한다. seed가 같다는 사실만으로 같은 침대로 단정하지 않고, seed가 다르다는 이유로 독립성을 단정하지 않는다.
2. 겹침은 `CONFIRMED_OVERLAP`, `NO_KNOWN_LINEAGE_OVERLAP`, `UNKNOWN`으로 기록한다. 두 번째는 조사한 계보/이름 대응 범위를 함께 명시하며 통계적 독립성 인증이 아니다. 선행6의 식별자가 미수령이면 후속 전부에 대해 UNKNOWN을 유지한다.
3. `CONFIRMED_OVERLAP`은 선행/재열람 설명군으로 보존하고 미열람 확인군에는 넣지 않는다. UNKNOWN도 독립 미열람 확인군이라 부르지 않는다. 별도 값 열람 비준이 있으면 기술적 진단에는 포함할 수 있으나 층/표에서 노출 상태를 표시한다.
4. 전체 후보 목록·원천 중복 묶음·겹침 분류·쌍/층/제외 이유를 값 열람 전에 문서 버전과 SHA로 동결한다. 식별자만으로도 후보가 달라질 때에는 개정 이력을 남긴다. 압력/N/descriptor를 본 뒤 유리한 침대만 빼거나 더하지 않는다.
5. 후보 수, 신원 확정 수, 선행 겹침 수, 겹침 미확인 수, 쌍 배정 수, 각 관측/자격 실패 수를 각각 보고한다. 214를 유효 독립 표본 수로 쓰지 않는다.

권고 명칭은 **“선행 관찰에 의해 동기화된 LHS 압력상태 기술 진단”**이다. 신원과 열람 기록이 확인되기 전에는 “독립 검증”, “완전 미열람 holdout”이라는 표현을 쓰지 않는다.

## 3. 대응쌍·층·제외

### 3-1. 대응쌍

쌍은 결과의 유사도나 관측 N 순위로 만들지 않는다. 설계/제작 계보의 명시적 연결로 만들고 pair_id, 두 case_id, 대비 종류, 고정한 인자, 달라지는 인자, 공유 원천/seed, 독립 단위를 미리 적는다. 짝이 없으면 unmatched로 보존한다. 값 열람 뒤 최근접 이웃이나 가장 큰 ΔN을 골라 짝을 대체하지 않는다.

| 대비 종류 | 사전 조건 | 허용되는 읽기 |
| --- | --- | --- |
| 동일 설계 반복 대비 | 조성/PSD·반경·삽입 영역·목표 로딩·plate 면적·목표압·감쇠/판 속도/이완 규약 동일, 서로 다른 반복/seed와 실제 침대 계보 식별 | N의 실제 산포와 종점 압력의 기술적 동반 변화. seed의 다른 미세구조 효과까지 N 단독 원인으로 분리하지 못함 |
| 얇음/후막 또는 로딩 대비 | 동일 기초 설계의 사전 대응이 있으며 변경한 높이/로딩/입자수 계획과 나머지 고정 인자를 명시 | **N–로딩–두께 공동 대비**. 방향을 기술할 수 있으나 독립 N 효과는 NOT_IDENTIFIABLE |
| 그 외/신원 불명 | 위 비교 가능성을 입증하지 못함 | 쌍 방향 집계 제외, 이유와 원래 후보 ID 보존 |

첫 번째 구성원/두 번째 구성원의 방향은 설계 라벨로 고정한다. `ΔN=N_second−N_first`, `ΔP=P_second−P_first`. 곱의 부호는 순서를 뒤집어도 같지만, 표의 Δ 방향은 일정하게 유지한다. 하나의 침대가 여러 쌍에 쓰이면 별개의 독립 관측으로 세지 않는다. 제3자가 임의의 쌍을 만들 수 없도록 완성된 pair 명부의 SHA가 값 열람 선행조건이다.

### 3-2. 층

층은 최소한 다음을 구분한다. 실제 공통층 값은 아직 채우지 않는다.

- 설계 가족(lhs00/lhsx/lhss), 조성·PSD·AM mono/bimodal 구조, 목표 로딩/삽입 높이 대비 종류.
- 유효 단위/스케일, 압축판 면적·속도·목표압, viscous fix 계수/적용 그룹/이완 중 활성 여부, 접촉/구름 모델과 관련 fix 변경.
- fresh/restart의 **의미 있는 프로토콜 차이**와 공통 원천 계보. 호스트·바이너리·rank는 provenance로 남기고 동일성이 확인되지 않으면 묶어 동일 프로토콜이라 하지 않음.
- 종점 및 이완 완료 규칙, descriptor 프레임 규약, 선행6 노출/겹침 상태.

알려지지 않은 설정을 “같음”으로 합치지 않는다. 압력·N·기공률·τ·완료 성공/실패·관측 두께를 보고 cutpoint를 정해 층을 만들지 않는다. 목표 높이는 설계 인자이고 최종 두께는 관측 결과이므로 구분한다. 층이 작아지거나 쌍이 0개가 되더라도 사후 병합으로 표본 수를 늘리지 않는다. 서로 다른 층의 pooled slope를 주 결과로 내지 않는다.

### 3-3. 제외와 실패 보존

사전 제외는 후보 범위 밖, 명백한 파일/실행 복제(대표 선택 규칙을 계보와 사전 순서로 고정), 비교 규약 불일치에 한한다. 선행6 겹침은 확인군에서만 분리하며 설명군 원자료 행을 삭제하지 않는다.

실행 실패·로그/덱 결손·재개 사슬 불명·이완 미완료·비유한 값·정확 종점 누락·그룹 신원 불명·미퍼콜·음수/0 porosity는 “데이터 삭제” 사유로 자동 사용하지 않는다. 각각 원래 후보 행과 단계별 상태/이유를 남긴다. 이 가운데 해당 추정량의 필수 조건을 충족하지 못하면 그 추정량만 NOT_ESTABLISHED/UNDEFINED로 둔다. 실패 팔을 0, 압력 목표값, 앞 프레임, 마지막 유효값으로 대체하지 않는다. 기존 LHS 배포/거부 지위는 바꾸지 않는다.

## 4. 이완 완료·종점 프레임·압력

**두 종류의 완료를 구분하는 안을 권고한다.**

| 상태 | 필요한 근거 | 허용 명칭 |
| --- | --- | --- |
| RELAXATION_STAGE_COMPLETE | 원 덱/재개 사슬에 고정된 이완 구간을 정상적으로 끝냄, 종료 사건·step/time 연결 및 판 고정/fix 상태 확인 | “등록 이완 구간 종료”, 기계적 평형 인증 아님 |
| EQUILIBRIUM_QUALIFIED | 결과와 독립적으로 비준된 수렴 관측량·창·문턱·지속 규칙 및 실제 충족 증거 | 그 등록 규칙 아래의 이완/평형 적격 |
| NOT_ESTABLISHED | 구간/종료/프레임/사슬을 확인 못 함 또는 기존 수렴규칙이 없음 | 평형을 가정하지 않음 |

현재 원 덱과 선행 수렴규칙이 없으므로 완료 step·시간·허용폭·창 길이는 null이다. **새 평형 문턱 숫자를 발명하지 않는다.** 추천은 먼저 고정 이완 구간 종료 압력을 `P_end`로 진단하고 평형 지위는 별도 표기하는 것이다. 이것은 기존 초안의 자격을 갖춘 `P_relaxed`를 무조건 채우는 것이 아니라, **별도 endpoint 종류를 추가하는 개정 제안**이다. 저자가 이 개정을 비준하지 않으면 기존 P_relaxed는 적격 조건이 확인될 때까지 NOT_ESTABLISHED로 둔다.

종점 규칙:

1. 압축 정지 사건의 step/time을 `stop_event`, 이완 구간 완료를 `relax_end_event`, 기존 descriptor 수확 프레임을 `harvest_event`로 구분한다. 동일하다고 가정하지 않는다.
2. 1차 결합값은 **사전에 지정된 descriptor 프레임과 정확히 같은 run/segment/step/time**의 압력과 N이다. 제안 P_end는 `harvest_event = relax_end_event`인 경우에만 사용한다. 구간 종료 뒤의 다른 프레임까지 “완료 이후”라는 이유로 포함하지 않는다. 과거 descriptor가 다른 단계/시점이면 그 자료는 “종점 불일치”로 남기고 프레임을 사후 교체하지 않는다. 기존 P_relaxed를 택할 경우에는 그 프레임의 독립적인 적격 조건도 필요하다.
3. 프레임 신원은 `(run_id, segment_id, restart_parent, local_step, accumulated_time, frame_hash)`로 연결한다. `reset_timestep`·재개에서 같은 step 숫자가 재사용돼도 같은 시점으로 합치지 않는다. dt가 바뀌면 단순 step×현재dt로 전체 시간을 만들지 않는다.
4. 압력은 **그 프레임의 실측 판 반력과 확인된 면적·단위 사슬**로 정의한다. 입력 목표압·고정750 N·다른 침대 값 대입 금지. 판독 부호/절댓값·area가 입력 고정인지 실제 프레임 값인지를 유효 덱 정의에 묶는다.
5. 해당 압력이 정확한 프레임에 없으면 NOT_ESTABLISHED. 가장 가까운 dump/thermo, 최솟값, 가장 평평한 창, 마지막 “그럴듯한” 값을 대신 쓰지 않는다. 보간은 이번 안에 포함하지 않는다.
6. 기존 출력이 시간 평균이면 instantaneous라고 이름 붙이지 않는다. 등록된 평균 창/구간/가중이 descriptor 사건에 어떻게 대응하는지 별도 종점 종류로 비준하기 전에는 동일 프레임 1차 값으로 합치지 않는다.
7. 종료 직전 고정 진단 창은 **추가 기술보고**일 뿐 1차 프레임을 고르는 도구가 아니다. 창/표본 주기는 실제 덱·출력 주기 정적 확인 뒤, 값 열람 전에 채워 봉인한다. 그 값이 없으면 시간 안정도 보고도 미수집으로 둔다.

## 5. N의 사건·그룹·분모

원 초안의 1차 정의를 보존하면 N은 **적격 종점/descriptor 프레임에서 정의된 감쇠 그룹의 실제 생존 입자 ID 수**다. `N_planned`·템플릿 추정수·전체 corpus 행수와 다르다. phase별 ID 수의 합과 전체 그룹수의 일치를 별도로 확인하고, AM_P/AM_S는 실제 type/밀도/설계 사상으로 판별한다. 2-type의 일반 AM 자리를 열 이름만으로 AM_P로 바꾸지 않는다.

필수로 나눌 칸:

| 칸 | 의미 |
| --- | --- |
| N_planned | 원 덱/계획상 삽입 목표수; 관측 N에 대입하지 않음 |
| N_group_moving / N_group_stop | 사전에 정의한 마지막 이동 사건 및 정지 사건의 적용 그룹 생존수 |
| N_group_relaxed | 기존 정의: 종점에서 식별 가능한 해당 그룹의 실제 생존수 |
| N_phase_counts | 같은 프레임·그룹의 AM/SE 등 상별 실제 수, 겹치는 group은 중복 합산하지 않음 |
| viscous_active_at_endpoint | 해당 종점에 fix viscous가 작동 중인지. 그룹 입자수와 별도 |
| N_reference_relaxed | 마지막 이동 감쇠 그룹의 ID 집합을 고정하고 종점에 살아 있는 ID를 센 **추가 진단값 후보** |

`unfix viscous`는 입자 삭제가 아니다. fix가 꺼졌다는 이유만으로 N_group_relaxed=0 또는 감쇠력=0(모든 감쇠 포함)으로 채우지 않는다. 그룹 정의가 남아 있고 membership가 재구성 가능하면 해당 그룹수를 센다. 종점 그룹 정의 자체가 없으면 UNDEFINED/null, 정의는 있으나 membership 증거가 부족하면 NOT_ESTABLISHED/null, 아직 수집하지 않았으면 NOT_COLLECTED/null이다. N_reference_relaxed로 몰래 대체하지 않는다. reference 추적에는 `(원천 run/침대, 안정된 atom ID)`가 필요하며 ID 재사용·재번호화가 있으면 원천→종점 연결 증거 없이는 생존수로 세지 않는다. 정적 그룹이면 두 수가 같을 수 있지만, 동적/삭제 그룹에서 **reference 수를 주 N으로 선택하는 것은 추가 정의 개정**이므로 별도 비준/이름이 필요하다. 권고는 reference 수를 보조로만 남기고 기존 1차 N을 유지하는 것이다.

검증된 선형 외력이고 해당 fix의 속도 기준계를 확인한 경우에만 fix별 힘 `−Σ_i c_i v_i,z`를 계산한다. 여러 fix가 같은 입자에 작용하면 그 힘 기여는 fix별로 합산하되, 합집합 입자수 N에서는 같은 ID를 중복 세지 않는다. 공통 선형 계수인 한 fix일 때만 `−c_v Σv_z`로 묶을 수 있다. c_v(힘/속도)는 표면에너지 γ와 다른 양이다. N은 힘·압력·독립 처리 인자가 아니다. N/A, N/부피 등의 분모를 추가하려면 그 분모의 입력/관측 지위를 명시하며, 이를 보았다고 N–로딩–두께의 인과 교락이 없어지는 것은 아니다.

## 6. 추정량과 불확실성 — 기본 보고 단위

**기본 단위는 독립 원천 침대/삽입 realization이고, 대비는 사전 pair이며, 프레임·입자·접촉·재개 조각은 표본수 n이 아니다.** 같은 원천을 공유하는 반복/쌍은 같은 lineage block에 묶는다. 같은 seed의 다른 설계라도 독립성을 입증하지 못하면 shared seed/제작 block을 표에 남긴다. 쌍 그래프에서 침대를 공유하는 연결 성분을 독립 pair 여러 개로 세지 않는다.

값 열람 후의 기본 산출은 모든 후보/쌍의 상태표, 각 유효 쌍의 N1/N2/P1/P2·ΔN·ΔP·ΔNΔP 부호, 층·노출·계보별 기술 요약이다. 유효쌍0개·ΔN=0은 방향 일치가 아니며, ΔP의 정확한0은 산술 동률이지 불확실성 내 동등성이 아니다. 기존 방향 범주를 유지하되 **방향 요약과 독립 N 효과 식별 지위를 별도 두 칸**으로 기록한다.

추천 기본안은 **모든 쌍의 점값과 범위, 개별 lineage/층별 표시를 우선하고, 추론적 신뢰구간/유의성 판정은 이번 정의에서 만들지 않는 것**이다. 실제 독립 단위 수·설계가 미확정인 상태에서 t-구간 또는 bootstrap 횟수부터 정하지 않는다. 부족한 반복을 프레임 수나 접촉 수로 부풀려 CI를 만들지 않는다. 숫자 없는 “95% CI 보고 예정”도 완성된 통계 등록으로 적지 않는다. 추론을 추가하려면 값 열람 전에 독립 블록·추정량·재표집/모형·최소 식별 조건·다중 비교 방침을 별도 확정한다.

| 불확실성 종류 | 보고 단위 / 해석 |
| --- | --- |
| 저장/계측 분해능 | 원 출력 자릿수·양자화·힘/면적의 주어진 불확실성. 실제 정보가 없으면 UNKNOWN; ±0으로 쓰지 않음 |
| 시간 변동 | 미리 정한 동일 run/종료 진단 창의 범위·평균/SD 및 창/출력 간격. 자기상관 프레임을 독립 n으로 사용하지 않음 |
| 침대/seed 변동 | 독립 lineage별 pair/침대 점값과 범위, 단위 수 명시. 현재 미수집 |
| 결측/미완료 | 전체 동결 분모와 이유별 수. complete-case 방향은 관측된 쌍에만 한정; 탈락을 무시한 전체 방향 주장 금지 |
| 모형/프로토콜 차이 | 층별 별도 결과와 NOT_IDENTIFIABLE 표시. 통계 오차막대로 흡수하지 않음 |

층 내 기울기/상관을 나중에 내더라도 대응 없는 기술량이며, 층과 계보·노출을 섞은 pooled 결과를 인과효과·보정계수로 쓰지 않는다. 새 분석법을 결과를 본 뒤 주 결과로 승격하지 않는다. 선행6의 기울기를 동등성 창·계수·N 효과 예측으로 쓰지 않는다.

## 7. 원 덱/include/재개 사슬 정적 신원 계약

**현재 값은 전부 미확인이다. 아래는 수령 요구 규약이며 실제 신원 확인 결과가 아니다.** 별도 승인된 정적 입력 수령에서 덱·include·실행 명령/변수·소스 provenance만 받는다. pressure/log/dump 결과를 함께 열지 않는다. 제출자가 계보 정보만 분리해 제공할 수 없으면 그 사실을 미결로 남기며 광범위 원자료 열람으로 대체하지 않는다.

1. case별 원 입력 파일의 경로/파일명·raw SHA-256·바이트 수·수령 출처·코드/바이너리 신원을 기록한다. 템플릿을 실제 case 덱으로 오인하지 않는다.
2. include는 상대 경로 해석 기준·순서·중복 사용·변수 치환/CLI `-var`·환경 의존을 포함한 의존 그래프와 각 원본 hash를 기록한다. `jump`/생성 include/외부 `shell`/조건부 분기가 있으면 적용 경로를 정적으로 확정할 근거가 없을 때 UNRESOLVED다. 실행하여 경로를 알아내지 않는다.
3. 단위·스케일·type→phase·그룹 및 동적 membership·viscous fix/unfix·계수/질량/타입 의존·plate 면적/속도·dt·run/reset_timestep·목표 교차·이완 구간·출력 주기/평균 창의 값을 출처 파일:줄과 함께 연결한다. 같은 파일 내 재정의는 최종 유효 순서를 보존한다.
4. restart chain은 원천→구간별 입력→입력 restart hash→출력 restart hash(알려진 경우) 및 parent 연결의 DAG로 기록한다. 명령/주기 restart 종류·reset step·바이너리/build·rank·세그먼트 fix 재설정 차이를 구분한다. **restart 파일 hash만으로 그 안의 상태/이력 복원 정확성을 인증하지 않는다.**
5. 기존 덱에 `read_restart`가 쓰였다는 것과 실제 그 파일로 실행됐다는 것은 별개다. 정적 선언 연결과 실제 실행 연결의 확인 상태를 분리한다. 실제 완료/적용 증거는 이후 값 열람 규칙 아래 별도 자격 확인 대상이다.
6. 원 덱이 없으면 유사 generator 출력·문서·기존 materializer 사본으로 빈 칸을 채우지 않는다. 기존 template 위치 `lhs00_000`/`lhs00_110`은 요청 후보만 유지하고 이번에 존재를 확인했다고 쓰지 않는다. lhss/lhsx/각 재개 경로는 추측하지 않는다.

완성되는 사전 정의 목록에는 후보/계보·겹침·pair·층·제외·유효 덱 의존 그래프·종점 규칙·N 규약·보고 단위의 각각 버전과 hash가 필요하다. 지금은 그 스키마와 결정안을 고정할 뿐 실제 214개 연결 완료를 주장하지 않는다.
