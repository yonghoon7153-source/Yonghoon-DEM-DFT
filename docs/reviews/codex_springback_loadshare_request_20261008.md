# Codex 요청 — 실험 ↔ DEM 공극 차이 · 되튐 · AM 골격 하중 몫 가설 검토 (10-08 밤 · 발송 = 1저자)

> **한 줄**: DEM ps45 다섯 조성 (PC:SC 0:10 → 10:0) 의 **AM–AM 접촉이 진 수직 하중 몫** (Contribution to σ_zz) 순서가 1저자 랩 **실험 공극** 순서와 다섯 자리 모두 같다.
> 이것을 *"실험 공극이 DEM 보다 큰 까닭의 큰 몫 = 되튐, 그리고 되튐 크기는 AM 골격이 진 하중을 따른다"* 의 근거로 쓸 수 있는지 **깨 보려고** 묻는다.
> 새 DEM 런 · 결과 전 예측 등록 **전에** 묻는다 — 모델 · 코드 변경 요청이 아니고, "실험 검증" 주장도 아니다.

## 3. 가설 (우리 추정 — 검토 대상)

1. 실험 두께 · 공극은 압력을 뺀 뒤 값이고 (미확인), DEM 은 판 아래 구조라 그 차의 큰 몫이 **되튐**이다.
2. 되튐 ≈ 압력을 뺄 때 단단한 **AM 골격이 돌려주는 탄성 변형** (∝ AM 골격이 진 하중 몫 ÷ 골격 강성).  SE 는 실제로 소성으로 눌려 되돌아오지 않는다.
   ⇒ 하중이 SE 쪽으로 가장 분산된 7:3 이 가장 덜 되튀고, AM 골격이 더 많이 지는 두 끝 (10:0 · 0:10) 이 더 되튄다.
3. 크기 산술: 차를 전부 되튐으로 보면 필요한 두께 회복 s = 0:10 9.9 · 3:7 6.3 · 5:5 6.1 · 7:3 4.4 · 10:0 9.5 % (SE 1.86 기준).
   s = f_AM × P ÷ E_skel 로 두면 (P = 300 MPa · f_AM = 위 몫) E_skel = 1.8 · 2.6 · 2.6 · 3.3 · 1.8 GPa — **몫 하나로는 크기가 비례하지 않는다** (s / f_AM 가 두 끝에서 약 1.8 배) ⇒ 두 끝의 골격이 더 무르다는 것까지 가정해야 한다.

## 4. 우리가 이미 아는 한계 (깨는 데 쓰라고 적는다)

- 하중 몫은 **모델 안 값**: SE 만 18 배 연화 → AM:SE 강성비 덱 ≈ 104:1 ↔ 실제 ≈ 7:1 (bazzoun2026 카드 입력 161.5 / 22.1 GPa) → AM 쪽 몫 과대 가능 · 조성 간 방향도 자동 보장 아님 (MV-07).
- **공통 원인**: 같은 충전 기하 (크기비 · SE 가 큰 AM 틈을 채우는 정도) 가 공극과 하중 몫을 같이 만들 수 있다 — 상관이 되튐을 증명하지 않는다.
- 대안 설명: ① PC 2 차 입자 내부 기공이 공극으로 잡힘 (결정 밀도로 계산 시 · 10:0 쪽만 올림) ② 실제 비구형 입자 · SE 응집 → 단일 크기 끝에서 충전이 더 나쁨 ③ 마이크로미터가 거친 표면 꼭대기를 재 두께 과대 (한쪽 방향 오차) ④ SE 밀도 (2.0 ↔ 1.86) — 모든 조성 같이 2.0–2.2 %p.
- 하중 몫의 프레임이 이완 프레임이다 (300 MPa 순간 아님).  실험의 유지 · 언로딩 이력은 모른다.
- DEM 에는 언로딩 · 시간 의존 회복이 없다 · hooke/hysteresis 의 언로딩 강성 (k2) · 잔류 겹침은 되튐 크기에 맞춰 보정된 적이 없다.

## 5. 질문

- **Q1.** 이 순서 일치 (하중 몫 ↔ 실험 공극 Spearman 1.0 · 초과분 0.9) 를 되튐 가설의 근거로 어디까지 쓸 수 있나?  공통 원인 (충전 기하) 과 가를 방법이 n = 5 에서 있나?  같은 순서를 내는 대안을 더 들어 달라.
- **Q2.** 되튐을 설명하는 양으로 **AM–AM 하중 몫 (이완 프레임 · 21 단면)** 이 적절한가 — 300 MPa 순간의 몫 · AM 골격 강성 (AM–AM 접촉 수 · 힘 사슬 길이) · 접촉별 저장 탄성 에너지 Σ F²/(2k) 같은 다른 양이 더 맞나?  SE 만 연화한 강성비가 다섯 조성의 **순서**를 바꿀 수 있는가 (MV-07 의 연장)?
- **Q3.** §3-3 크기 산술 (E_skel 1.8–3.3 GPa · s / f_AM 두 끝 1.8 배) 의 물리 타당성 — 300 MPa 아래 NCM 입자 골격의 유효 강성 범위로 말이 되나?
- **Q4.** 모델 안 직접 시험 설계: 다섯 조성의 마지막 체크포인트에서 판을 들어 올리는 **DEM 언로딩 단계**.  판 속도 · 정지 기준 · 대기 시간 · 무엇을 재나 (판 간격 · 원자 최대 높이 · ε) · 연화 E · hooke/hysteresis 언로딩이 크기를 어떻게 왜곡하나 · 그래서 **순서만** 판정한다면 등록 문안 (예: 조성별 되튐 순서 ↔ AM–AM 하중 몫 순서 Spearman ≥ 0.8 = 지지) 이 적절한가.
- **Q5.** 실험 쪽 판별 설계: 조성별 하중 중 두께 (프레스 변위 · 장비 변형 보정) ↔ 뺀 뒤 두께 · 반복 수 · 정밀도 — 이 가설과 대안 ①–③ 을 가르려면 무엇을 더 재야 하나 (예: PC · SC 분말 피크노미터 밀도).
- **Q6.** 보고 문장: 지금 단계에서 쓸 수 있는 문안 (예: *"실험 공극은 DEM 보다 4–7 %p 높고, 그 차이의 조성 순서가 DEM 에서 AM 골격이 지는 하중 몫의 순서와 같다 — 언로딩 되튐 가설과 정합 (검증 전)"*) 의 과장 여부.
