   (§8 의 5). 이 키가 fetch 에 필요한지는 관측하지 않았습니다.
6. fetch 단계는 기록 git 까지 시스템 · 사용자 설정을 읽지 않습니다. identity · run 단계는 v5 와 같이 읽습니다 (§8 의 6).
