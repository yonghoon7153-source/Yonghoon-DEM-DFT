## R1. 🔴 **같은 질문에 우리가 두 번 답했고, 정반대다** (최우선)

### 배경 — 게이트

MLIP-MD(UMA-s-1p1, Langevin NVT, 200 ps, dt 2 fs, 저장 0.1 ps)로 Li 확산계수를 낸다.
MSD 를 **창 2–50 ps** 에서 **자유절편** 직선 맞춤: `MSD = c + m·t`, `D = m/6`.
인용 게이트는 log-log 기울기 `β = dlogMSD/dlogt` (같은 창)가 **[0.8, 1.2]** 안일 것.

### 판본 A (2026-08-11) — "게이트는 정상 작동했다"

귀무를 **케이지 없는 순수 브라운 운동**으로 만들었다:

```python
sigma = sqrt(2 * D_A2_ps * dt_ps)
steps = rng.normal(0, sigma, (n_frames-1, n_li, 3))   # 스텝 독립
pos   = cumsum(steps)                                  # MSD(0)=0, 절편 없음
beta  = polyfit(log t, log msd, 1)[0]
```

n_Li 27 · 2001 프레임 · dt 0.1 ps · D 1.5e-5 cm²/s · 400회:

| 창 [ps] | β 중앙값 | 5–95 % | **β<0.8 비율** |
|---|---|---|---|
| **2–50** | 1.006 | 0.86–1.14 | **1.0 %** |
| 50–200 | 1.004 | 0.76–1.26 | 10.5 % |

**결론 A**: 창 2–50 에서 이상적 확산은 β<0.8 을 1 % 밖에 안 밟는다 → 관측된 0.58–0.79 는
**진짜 sub-diffusion 이고 탈락 8건은 정당하다.**

당시 우리가 스스로 적은 의심: *"귀무가 너무 깨끗하다 — OU 케이지 성분(진폭 ~0.5 Å,
상관시간 ~1 ps)을 얹으면 1 % 가 5 %, 10 % 로 커지나?"* **이 질문에 회신을 못 받았다.**

### 판본 B (2026-08-26) — "게이트는 동전던지기다"

그 의심을 우리가 직접 재봤다. 이번엔 귀무에 **실측 절편 c 를 넣었다** —
즉 `MSD = c + 6Dt` 인 계, **D 가 기울기에서 정확히 회수되는 의미에서 완벽히 Fickian** 한 계다.

창 2–50 · n_Li 27 · prod 200 ps · **1000회** · seed 12345 · **절편 c = 2.0 Å²**:

| n_hop(200 ps) | D [cm²/s] | c/MSD@50 | β 중앙값 | β 5–95 % | **거짓탈락 %** | 5 % 거짓탈락을 주는 임계 |
|---|---|---|---|---|---|---|
| 3.0 | 2.25e-6 | 22.8 % | 0.502 | 0.385–0.619 | **100.0** | 0.385 |
| 8.4 ← LPSOCl 600 K | 6.30e-6 | 9.57 % | 0.715 | 0.582–0.842 | **84.6** | 0.582 |
| **13.9** ← modelc·b2o3 600 K | 1.043e-5 | 6.01 % | **0.800** | 0.676–0.928 | **50.0** | 0.676 |
| 20.0 | 1.50e-5 | 4.25 % | 0.853 | 0.708–0.981 | 25.8 | 0.708 |
| 30.0 | 2.25e-5 | 2.88 % | 0.888 | 0.754–1.028 | 14.2 | 0.754 |

절편 c = 4.0 Å² 면 같은 n_hop 13.9 에서 β 중앙값 **0.682**, 거짓탈락 **94.7 %**.

**결론 B**: 우리 실제 운영점(홉 13.9, 절편 2 Å²)에서 고정문턱 0.8 은 **거짓탈락 50 %** —
동전던지기다. LPSOCl 600 K 의 관측 β **0.615** 는 그 조건의 귀무 중앙값(절편 4 Å² 기준 0.58)
**보다 오히려 높다** ⇒ 탈락이 아니라 정상이다. **게이트를 폐기하고** (c, m)·홉 수·다중 창
c-추세로 간다.

### ⚠⚠ 내가 의심하는 것 — **판본 B 가 순환논증 아닌가**

이게 이번 요청의 핵심이다.

우리 repo 의 판별 규칙은 이렇다 (여러 문서에 박혀 있다):

> · c 가 창 따라 **상수** + m 상수 + β 만 1 로 올라감 → **케이지 절편**. D 인용 가능.
> · c 가 창 따라 **커지고** m 이 떨어지며 β 가 모든 창에서 그대로 → **진짜 sub-diffusion**.

그런데 **판본 B 의 귀무는 c 를 상수로 고정해서 만든다.** 즉 *"케이지다"* 라는 답을
**구성 단계에서 가정하고** 그 위에서 "그러니 β 가 낮은 건 정상"이라고 결론낸 것 아닌가?

- 만약 c 가 진짜 케이지 진폭(빠른 진동, 즉시 포화)이면 → 판본 B 가 맞고 β<1 은 인공물이다.
- 만약 c 가 **아확산의 증상**(창 따라 자라는 절편)이면 → 판본 B 는 검정하려는 것을
  귀무에 넣은 것이고 **무효**다.

**요청 (R1)**:
1. 판본 B 가 순환인가? 순환이라면 **c 를 가정하지 않고** 같은 질문을 검정하는 설계는 뭔가?
2. 반대로 판본 A(절편 0)가 **비현실적으로 후한** 귀무라는 우리 판단은 맞나?
   고체 MSD 에서 절편 0 인 귀무가 정당한 경우가 있나?
3. 두 판본을 가르는 **결정적 관측**은 뭔가? 우리 후보는 *"c 를 창 따라 재서 상수인지 보는 것"*
   인데, 그건 표본 잡음이 커서(단일 시간원점 sd(c) 가 iid-OLS 표준오차의 **10–40배**)
   실무에서 안 갈린다. 더 나은 게 있나?
4. 문헌 표준은 β 문턱을 **안 쓴다**(He/Zhu/Mo 2018 = 확산 이벤트 수 · Kahle/Marcolongo/
   Marzari 2020 = 창 스캔 + 자동수렴 + D<1e-8 floor). 우리가 β 를 **버리는 것 자체**는
   맞는 방향인가, 아니면 β 를 고쳐 쓸 방법이 있나?

## R3. 유한크기 — **두 진단이 반대 방향을 가리킨다**

LPSOCl 600 K 를 작은 셀(최소 수직폭 **5.67 Å**)과 3×3×1(**17.02 Å**, 558원자)로 돌렸다.

| | 작은 셀 | 3×3×1 |
|---|---|---|
| MTO β̄ | 0.76 | **0.81** |
| MTO 시드별 β | 0.79 / 0.77 / 0.73 (sd 0.031) | 0.81 / 0.80 / 0.81 (sd **0.006**) |
| **창 스캔** β (2-50 → 50-200) | **0.76 → 0.98** | **0.81 → 0.87 정체** |
| 같은 스캔의 c 변화 | **−64 %** | **+128 %** |

| MTO 기울기 m [Å²/ps] | 0.481 | 0.703 (**1.46×**) |
| 시드별 D 평균 | 7.53e-6 | 1.279e-5 (**1.70×**) |

**엇갈림**: 게이트 창만 보면 작은 셀이 나빠서 *상자가 원인*처럼 보인다

그런데 **창 스캔은 반대**다 — 작은 셀은 늦은 창에서 β 0.98 로 회복하고 c 가 **줄어든다**
(우리 규칙상 **케이지 절편, D 인용 가능**). 큰 셀은 0.87 에서 멈추고 c 가 2.3 배로 커진다
(**아확산 무늬**).

우리 후보 읽기(미검증): 5.67 Å 주기가 홉을 자기 이미지와 **동조**시켜 인위적으로 Fickian
처럼 보이게 하고, 큰 셀은 그 구속이 풀려 느린 모드가 드러난 것. 그렇다면 **β 가 낮은 쪽이
아니라 높은 쪽이 가짜**다.

**D 는 1.64–1.70 배 움직인다** (Welch p ≈ 0.004). 대안가설은 배제했다: 3×3×1 은 정확한
9× 타일링(재이완 없음, 조성·밀도 동일) · 늦은 창(100–200 ps)에서도 m 비 1.57× 유지 ·
시드 D 비겹침. **기전은 미확정.** 초판의 Yeh–Hummer 설명은 **철회**했다 —
YH 는 운동량 보존 유체역학에서 유도되는데 우리는 **Langevin**(비보존)이고 고체 골격에
점도가 정의되지 않으며 L=5.67 Å 는 이온과 자기 이미지가 1–2 배위권이라 어떤 1/L 점근론의
유효범위도 아니다.

2점 1/L 외삽(참고값): `D(L) = D∞ − A/L` → D∞ ≈ 1.53e-5, **작은 셀 −49 % · 3×3×1 도 −16 %.**

**요청 (R3)**:
1. 두 진단이 엇갈릴 때 **어느 쪽을 믿나?** 게이트 창인가 창 스캔인가 — 판정 규칙을 달라.
2. "작은 상자가 인위적 Fickian 을 만든다"는 읽기가 물리적으로 말이 되나?
   **주기 이미지와의 홉 동조**를 검정할 관측량이 있나 (예: van Hove 자기부분의 이미지 거리 peak)?
3. Langevin + 고체에서 D 의 유한크기 보정에 **쓸 수 있는 이론**이 있나? 1/L 이 아니면 뭔가?

## R4. NEB 대조군에 **3주**를 쓸 것인가 (실무 판단)

Li₃Nd c→c 홉 장벽의 **셀 수렴 확인**용으로 3×3×3 NEB(`v2_cc333`)를 돌리고 있다.
2×2×2 대조군은 이미 수렴했고 **Ea = 0.229 eV (CI 켜짐)**.

같은 계의 다른 경로(c→b)는 **it83** 에 수렴했다. 그 앵커를 쓰면 **~23일**,
낙관적으로 봐도 **4–6일**. Li₃Nd 는 **금속**이라 SCF 가 스미어링으로 느리고,
GPU(A6000 48 GB)를 UMA-MD 2건과 나눠 쓰고 있다(47.5/49.1 GB 점유).
