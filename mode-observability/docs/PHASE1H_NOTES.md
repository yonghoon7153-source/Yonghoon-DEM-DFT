# Phase 1h — Mohtat 의 컷오프 등식은 **우리 null 을 못 본다** (그리고 12.04° 는 점이 아니라 띠다)

**정본은 `mode-observability/results/phase1h/` 의 CSV 다.** 아래 숫자는 사본이며
인용 근거가 아니다. 재현: `python3 mode-observability/phase1h_mohtat_cutoff.py`

## ⚠ 먼저 — 무엇을 읽었고 무엇을 못 읽었나

`[11] Mohtat et al. 2019` (*J. Power Sources* 427, 101–111, "Towards better
estimability of electrode-specific state of health: Decoding the cell expansion")
는 Lin & Khoo 2024 가 `[인쇄]` "use Fisher information to quantify the parametric
identifiability" 로 인정한 **선행자**이고, Lin 이 `[인쇄]` "has been incorporated
in PyBaMM" 이라 적은 편이다.

**원전 PDF 는 확보하지 못했다.** Elsevier 유료이고 이 실행 환경의 egress 정책이
`api.semanticscholar.org`·`docs.pybamm.org` 등을 막는다(실측: CONNECT 403 ·
`EGRESS_BLOCKED`). 그러므로 이 라운드가 흡수한 것은 **논문이 아니라 그 모델의
구현본**이다:

```
pybamm 26.7.1.0
  models/full_battery_models/lithium_ion/electrode_soh.py
    class _ElectrodeSOH(_BaseElectrodeSOH):
        pybamm.citations.register("Mohtat2019")
  CITATIONS.bib  @article{Mohtat2019, ... Journal of Power Sources, 427, 101--111}
```

그 docstring 이 모델을 그대로 인쇄한다 (`[코드]`, 전사):

```
Q_Li  = y_100·Q_p + x_100·Q_n
V_max = U_p(y_100) − U_n(x_100)
V_min = U_p(y_0)   − U_n(x_0)
x_0   = x_100 − Q/Q_n
y_0   = y_100 + Q/Q_p
```

미지수 `(x_100, y_100, x_0, y_0, Q)` 5개 · 식 5개 → `(Q_Li, Q_n, Q_p)` **3개**가
주어지면 결정된다. Lin 이 Ah 축 자유도를 `(Q̂^Li, Q̂⁻, Q̂⁺)` **3개**라 한 것과
같은 수다. (Lin 은 "파라미터 4개 + 제약 1개 → 3", 구현본은 "양 5개 − 등식 2개
→ 3" 으로 **장부가 다르지만 답이 같다.** 어느 쪽이 Mohtat 자신의 표기인지는
원전을 못 읽어 판정할 수 없다.)

## 사전 — Mohtat 좌표 ↔ 우리 창 좌표

`src/curves.py` 의 `windowed_curve` 정의 `U_PE(x) = f_PE_ref((x − β_PE)/α_PE)`
에서 바로 나온다. reference 창을 `[0,1]` 로 잡은 단위에서:

| Mohtat / PyBaMM | 우리 창 좌표 | 비고 |
|---|---|---|
| `y_0 − y_100 = Q/Q_p` | `1/α_PE` | `α_PE` = 전극용량/셀용량 (fitting.py 헤더) |
| `x_100 − x_0 = Q/Q_n` | `1/α_NE` | |
| `y_100` | `−β_PE/α_PE` | |
| `x_100` | `−β_NE/α_NE` | |
| `V_max = U_p(y_100) − U_n(x_100)` | **`U_full(x_norm = 0)`** | ← `g₁` |
| `V_min = U_p(y_0) − U_n(x_0)` | **`U_full(x_norm = 1)`** | ← `g₂` |
| `Q_Li = y_100·Q_p + x_100·Q_n` | `src/inventory.py` 의 `n_Li = y0·C_PE + z0·C_NE` | ↓ |

**마지막 줄이 이 라운드의 부수입이다.** `src/inventory.py` 의 LLI 유도

```
LLI = 1 − r·[ w_PE·α_PE + w_NE·α_NE + κ·(β_NE − β_PE) ]
```

는 **Mohtat 의 `Q_Li` 식을 "reference 창" 정규화로 옮긴 것**이고, 그때 나오는
`(w_PE, w_NE, κ)` 가 바로 **"전극 전체" 정규화와 "셀 창" 정규화를 잇는 환산
상수**다. 그리고 `reference_inventory()` 는 그것을 **셀 기하에서 직접 계산한다**
(`F·A·c·vf·L/3600`). Phase 1f·1g 가 막힌 자리가 정확히 그 환산이었다.

`[해석]` **단서이지 해결이 아니다.** `inventory.py` 가 계산하는 것은 *재고*
(`c_init`)이고 Phase 1f 가 필요한 것은 *총용량* (`c_max`)이다. 같은 한 줄에서
`c_init → c_max` 로 바꾸면 나올 것으로 **보이지만 이 라운드에서 재지 않았다.**
다음 순서에 둔다.

## 실측 1 — 컷오프 등식은 우리 참값에서 **정확히는 성립하지 않는다**

격자 1023 조건(noise = 0)의 관측 구간 양 끝 전압:

| | 범위 | 폭 |
|---|---|---|
| `g₁ = U_full(x=0)` | 4.0516 ~ 4.1786 V | **127.0 mV** |
| `g₂ = U_full(x=1)` | 2.5289 ~ 2.5825 V | **53.6 mV** |

설정 컷오프는 4.2 / 2.5 V (`configs/base.yaml`)다. 유한 전류 pOCV 라 양쪽에
과전압만큼 못 미치고, **그 못 미치는 양이 열화 조건에 따라 100 mV 넘게 달라진다.**

`[해석]` 그러므로 "컷오프 등식" 을 **등식으로** 얹으면 우리 격자에서는 그 자체로
**100 mV 급 모델 오차**를 도입한다. Phase 1e 가 창 좌표에서 "정보를 지운다" 고
판정한 것 위에, 좌표와 무관한 **둘째 대가**가 있다.

## 실측 2 — Lin 의 예언과 그 예언이 깨지는 자리

Lin 의 2-자유도 정리는 `LLI = LAM_PE = LAM_NE = x` 위에서 SOC 정규화 곡선이
**통째로** 불변임을 말한다 — 양 끝점도 포함해서. 그러므로 이상적인 셀이라면

```
∇g · (1,1,1)/√3 = 0        즉  ∠ = 90.00°
```

이어야 한다. 실측 (전방차분 H = 0.02, Phase 1c/1g 와 같은 스텝):

| 동작점 | | `∇g` (V/단위) LLI·LAM_PE·LAM_NE | `∇g·(1,1,1)/√3` | ∠ to (1,1,1) | ∠ to `u_min` |
|---|---|---|---|---|---|
| **pristine** | `g₁` | 0.383 · −0.145 · −0.335 | −0.0558 | **83.95°** | 86.85° |
| | `g₂` | 0.935 · −0.681 · −0.030 | +0.1293 | **83.59°** | 81.40° |
| **22p 근방** | `g₁` | 0.121 · −0.066 · −0.158 | −0.0597 | **73.51°** | 71.62° |
| (0.16, 0.12, 0.12) | `g₂` | −0.065 · −0.327 · −0.024 | −0.2397 | **44.16°** | 48.23° |

**pristine 에서는 예언이 맞는다** — 83.95°·83.59° 로 90° 에서 6° 남짓 떨어져
있을 뿐이고, 그 6° 가 곧 "유한 전류 + 복합 음극" 의 몫이다.

**22p 근방에서는 깨진다.** `g₂` 가 `(1,1,1)` 에서 **44.16°** 다. 만방단 전압은
그 동작점에서 null 방향에 대해 **분명히 무언가를 말한다.**

## 실측 3 — 그런데 말해도 **판정을 바꾸지 못한다**

두 끝점을 관측에 얹었을 때 (곡선 288점 + 끝점 2개):

| 동작점 | σ_min | σ_min (끝점 추가) | 변화 | 조건수 |
|---|---|---|---|---|
| pristine | 0.6893 | 0.7110 | **+3.16 %** | 18.24 → 17.76 |
| 22p 근방 | 0.6627 | 0.7021 | **+5.95 %** | 16.31 → 15.40 |

`[해석]` `∇g₂·u_min = −0.2225` 는 곡선 1점당 평균 감도 0.0391 의 **5.7배**로
개별 점으로는 확실히 유용한 점이다. 그런데 288점의 합 앞에서 2점은 2점이라
**σ_min 이 6 % 오르고 끝난다.** 축퇴는 그대로다.

**그리고 그 두 점은 애초에 새 관측이 아니다** — 우리가 이미 맞추는 그 곡선의
양 끝일 뿐이다. 즉 Mohtat/Birkl 계열이 "제약" 으로 얹는 정보는 **전곡선 적합에
이미 들어 있고**, 그것을 등식으로 승격시키는 데서 얻는 것은 없다.

## 실측 4 — Phase 1c 의 한계 (a) 를 닫고, **새 한계 하나를 연다**

Phase 1c 는 `[인용]` "(a) 22p 동작점에서 `J` 를 다시 잡으면 방향이 회전할 수
있다 — 국소 분석의 한계" 라고 신고했다. Mohtat 의 도구가 Fisher, 곧 본성상
국소량이므로 이 자리에서 같이 쟀다.

```
 (LLI, LAM_PE, LAM_NE)     H        ∠     조건수   u_min
       (0.00,0.00,0.00)  0.02   12.04°    18.24   [0.6619 0.6372 0.3949]
       (0.00,0.00,0.00)  0.04   18.62°    10.43   [0.7313 0.6148 0.2953]
       (0.04,0.04,0.04)  0.02   13.51°    16.71
       (0.08,0.08,0.08)  0.02   13.02°    16.83
       (0.12,0.12,0.12)  0.02   15.16°    15.17
       (0.16,0.16,0.16)  0.02   14.81°    15.12
       (0.16,0.12,0.12)  0.02    4.61°    16.31   [0.5686 0.5225 0.6354]
       (0.12,0.16,0.08)  0.02    9.00°    13.69
       (0.08,0.12,0.16)  0.02    7.45°    21.41
   H = 0.02: ∠ 범위  4.61° ~ 15.16°   (중앙 12.53°)
   H = 0.04: ∠ 범위  7.18° ~ 21.89°   (중앙 19.56°)
```

**① 한계 (a) 는 닫혔다 — 방향은 회전하고, 회전 방향은 Lin 쪽이다.**
대각선 위(`x,x,x`)에서는 12~15° 로 안정적인데, **비대각 동작점에서 오히려 각이
작아진다.** 특히 22p 근방 (0.16, 0.12, 0.12) 에서 **4.61°** 다.

`[해석]` 즉 **22p 의 축퇴는 Lin 의 닫힌 형태 축퇴와 사실상 같은 방향이다.**
pristine 에서 잰 12.04° 보다 오히려 더 가깝다. 22p 문제에 Lin 의 정리를 적용할
근거가 pristine 근방 분석보다 **강해진다.**

**② 새 한계 — 12.04° 는 점이 아니라 띠다.** 같은 pristine 에서 스텝을 0.02 →
0.04 로만 바꿔도 각이 **12.04° → 18.62°** 로 움직인다. 전방차분이 수렴하지
않았다는 뜻이고, 격자 간격이 0.02 라 **더 작은 스텝은 이 자료로 못 잡는다.**

`[해석]` 그러므로 앞으로 방어할 문장은 **"12.04°"** 가 아니라

> 우리 격자에서 잰 최소 감도 방향은 Lin 의 `(1,1,1)/√3` 와 **이 측정의 분해능
> 안에서 같다** — 동작점·스텝을 훑으면 약 **5° ~ 22°** 범위에 놓인다.

이다. Phase 1c 는 스텝 의존성을 신고하지 않았다. **여기서 신고한다.**

## 판정

1. **Mohtat 의 컷오프 등식은 우리 좌표에서 축퇴를 못 푼다.** pristine 에서는
   Lin 의 예언대로 null 에 거의 직교하고(84°), 22p 에서는 직교가 깨지지만
   (44°) 그래도 σ_min 을 6 % 올리는 데 그친다.
2. **그 등식은 참값에서 정확히 성립하지도 않는다** (끝점 전압이 조건에 따라
   127 mV / 54 mV 흔들린다). 등식으로 얹으면 그만큼이 모델 오차가 된다.
3. **Phase 1e 와 합치면**: 창 좌표에서는 정보를 지우고(강한 쌍과 1.5°), 모드
   좌표에서는 못 보는 방향을 못 본다. **두 좌표계 모두에서 이 처방은 우리
   문제를 개선하지 않는다.**
4. **22p 의 축퇴 = Lin 의 축퇴** (4.61°). 이것이 실질적 소득이다.

## 이 판정이 말하지 않는 것 (경계)

1. **원전을 안 읽었다.** 여기 대조한 것은 PyBaMM 구현본이다. Lin 이 전하는
   "4 파라미터 + 제약 1개" 와 구현본의 "등식 2개" 중 어느 쪽이 Mohtat 자신의
   표기인지 판정하지 않는다 (둘 다 Ah 축 자유도 3 으로 귀착하는 것만 확인).
   **Mohtat 의 Fisher 분석 자체는 여전히 미독이다** — Lin 이 그것을 선행자로
   지목한 이상 이 항목은 **닫히지 않았다.**
2. **PyBaMM 의 `ElectrodeSOH` 를 우리 파라미터셋으로 실제로 풀지 않았다.**
   위 사전(dictionary)은 `windowed_curve` 정의에서 유도한 것이고, 복합 음극
   (`electrode_soh_composite`) 경로로 독립 검산하지 않았다.
3. **`inventory.py` ↔ Phase 1f 환산은 단서일 뿐이다** — `c_init`(재고) 대
   `c_max`(총용량) 의 차이를 아직 안 메웠다.
4. **국소·한 화학·한 격자.** 그리고 실측 4 가 보여 주듯 **스텝에도 매여 있다.**
5. `g₁`·`g₂` 는 관측 구간 `[0, 1]` 끝에서 보간한 값이지 **셀이 실제로 컷오프에
   닿은 순간의 전압이 아니다.** Phase 1g 가 쓴 트림 구간 `[0.02, 0.98]` 과 달리
   여기서는 끝을 살렸다 — 그 차이가 위 127 mV 폭에 일부 섞여 있을 수 있다.
