### R2-01 [P1 · 증거] 비교하지 않은 RMSE까지 “전부 일치”로 인증한다

위치: `bms_balancing/verify.py:648`, `:654`, `:660`, `:693`; 회귀 빈틈 `matlab/tests/test_compare_bisect.py:81`.
재현: `harness_r2_port_repros.py`의 `comparator_probes()`.

정상 16앵커·8행·4개 RMSE CSV를 기준으로 다음 상태를 각각 만든다.

| 입력 변화 | 실제 출력 |
|---|---|
| 마지막 행 하나 삭제 | `MATLAB 7 vs Python 8` 경고 뒤 **`rmse 28개 … 전부 일치`** |
| 한 행의 `a_PE += .05`, 그 행 RMSE 네 개를 모두 9로 | 격자 불일치 경고 뒤 **`rmse 32개 … 전부 일치`** |
| 한 행 RMSE 네 개를 `nan`으로 | 해당 행을 `적힌 자리수 안`으로 처리하고 **전부 일치** |

첫 경우에는 행 수가 같은 분기 안에만 비교 loop가 있어 **RMSE를 하나도 비교하지 않는다**. 둘째는 건너뛴 행을 성공 수에 넣는다. 셋째는 NaN 비교가 false가 되어 차이 누적값이 0으로 남는다. 함수는 세 경우 모두 정상 반환한다.

기존 회귀는 “격자가 어긋났다”라는 경고가 있는지만 확인해서, 같은 출력의 정반대 성공 판정을 놓친다. 제공된 실제 MATLAB CSV가 이 상태였다는 주장은 아니다. **검증기의 성공 판정이 전수 비교의 증거가 되지 못한다**는 발견이다.

최소 종결 조건: 필요한 schema·행·parameter identity·유한값의 완전성을 먼저 확인하고, 실제 비교 완료한 셀만 센다. 누락/불일치/판정불가를 결과값과 CLI 종료 코드로 구분한다. 세 반례에서 성공 문장이 나오지 않아야 한다. 구형 부분 schema를 지원하더라도 부분 검증이라고 표시해야 한다.

### R2-03 [P1 · 기존 A3 미종결] γ profile은 여전히 실패한 optimizer 결과를 적합으로 저장한다

위치: `bms_balancing/verify.py:896`; 정상 실행 경로 `scripts/run_states.sh:144`.
재현: `harness_r2_port_repros.py`의 `profile_failed_result_probe()`.

`multistart()`의 성공 필터는 적용됐지만, `cmd_profile()`의 별도 loop는 `finite(r.fun)`만 본다. 실제 목적함수로 되평가한 값과 `success=False`, iteration-limit 상태를 반환하는 optimizer 대역을 넣었다. 참조/자유 적합은 성공하게 두고 profile의 네 호출만 모두 실패시켰다.

```text
profile optimizer 실패: 4/4
완료 적합처럼 저장한 행: 2
두 행 objective/best: 1.00001025
두 행 LAM_NE: -16.6666666667%
출력에 optimizer 실패 상태: 없음
```

이 점들은 별도 검증된 **실현 가능한 하한 증인**으로는 사용할 수 있다. 그러나 고정 γ에서 최소화를 완료한 값이라고 취급하거나, 문턱 밖이라는 이유로 그 γ를 배제하는 근거로 사용할 수는 없다. 따라서 이 지적은 feasible witness를 무조건 버리라는 요구가 아니다.

최소 종결 조건: profile minima의 채택 정책을 공통화하고 γ별 수렴/미완 상태를 저장한다. 모든 시도가 실패한 행을 완료 profile로 쓰지 않는다. 기존 profile 산출의 수렴 상태는 재실행 전까지 미확인으로 표시한다. 기존 A3 회귀에 `cmd_profile()` 실행 경로를 추가한다.

### R2-05 [P1 · 상태 식별성] min/max 외곽 범위가 겹쳐도 가능한 값은 겹치지 않을 수 있다

기존 경계 안에서 `a=p[0]`, 기준 `a_PE=1.2`, 양쪽 용량 1, `best=1`, `tol=.01`로 다음 두 함수를 실제 extrema/profile 구현에 넣었다:

```python
def f_A(p):
    return 1 + 400 * min((p[0]-1.04)**2, (p[0]-1.36)**2)

def f_B(p):
    return 1 + 400 * min((p[0]-1.16)**2, (p[0]-1.24)**2)
```


### R2-06 [P1 · 정규화] 8.0배는 재계산되지만 “tolerance 교란을 벗긴 값”이 아니다

위치: `FINDINGS.md:667`~`:681`; `tests/test_review_findings.py:1290`~`:1321`.
재현: `harness_r2_inference_repros.py --root TARGET --case normalization`; 실제 산출 계산은 `--case display`에도 포함.

`J(x)=b+100x²`이면 상대 1% 집합의 반폭은 `sqrt(.01*b/100)`이다. 같은 곡률에서:

| b | 반폭/b |
|---:|---:|
| 0.30 | 0.01825742 |
| 0.75 | 0.01154701 |

“보정” 후 비가 **0.63245553**으로 남는다. 이 이차 형태에서는 `/sqrt(b)`가 같아지지만 일반 목적함수에는 그것도 보장되지 않는다. 같은 상대 1% 집합을 가진 `J`와 `10J`도 `/best` 값은 10배 달라진다.

추가 연속함수 반례는 상대 문턱에서 raw 10배, `/best` 6.6667배인데, 공통 excess loss `.005`에서 폭의 비가 **0.2배**로 역전된다. 이는 실제 셀의 역전을 측정한 것이 아니라, 저장된 best와 폭 하나로 문턱 효과를 제거할 수 없다는 반례다.

실제 산출을 재계산한 값:

```text
최대 반폭끼리의 raw 비:                10.52223085
반폭/best를 각자 계산한 뒤 최대값의 비:  7.96898381
반폭/sqrt(best)의 비:                   9.83494220  (이차근사 예시일 뿐)
```

최소 종결 조건: 8.0배는 임의 재척도화의 기술값으로만 표기하고 교란 제거 주장을 철회한다. 그 주장을 유지하려면 공통 scale·공통 excess-loss 문턱 또는 tolerance sweep에서 폭을 직접 평가한다. `/sqrt(best)`로 분모만 바꾸는 것은 종결이 아니다.

### R2-07 [P1 · 원인 배제] 조작 강도의 근거인 측정 NE는 실제 목적함수가 소비하지 않는다

두 행은 관측값에 대한 **논리적으로 가능한 완성**이고 실제 실험 결과가 아니다. 같은 관측이 “효과 없음”과 “차이 전체가 효과”를 모두 허용하므로, 파우치 이동/원통형 격차를 “대체가 설명한 인과적 몫 0.5~5.2%”라고 부를 수 없다. 이것은 이미 신고한 U3(물성과 계측 품질 미분리)보다 앞선 문제다.

최소 종결 조건: “**파우치의 pristine 고정 실험에서는 원통형의 큰 폭이 재현되지 않았다**”로 한정한다. 대체를 배제했다고 한 모든 전달 문서를 고친다. 배제를 유지하려면 소비한 PE/도함수 축의 개입 강도와 셀×대체 상호작용을 검증하거나 원통형의 상태별 반쪽전지 대조가 필요하다.

### R2-08 [P1 · 표현력/인과] 적합된 γ의 작은 이동을 γ family의 표현력 한계로 읽는다

위치: `scripts/ne_shape.py:158`~`:165`, `:216`~`:219`; `FINDINGS.md:1100`~`:1107`.
재현: `harness_r2_shape_repros.py`의 `gamma_realized_is_not_capacity()`.

실제 `Blend`로 pristine/대상 음극을 각각 γ=.15/.45에서 생성한다. 용량은 같다. 보고된 full-cell 적합 γ 쌍으로 .15/.16을 입력하면 변경 없는 `ne_shape.main()`이 다음을 낸다:

```text
측정 변화:                 53.41711175 mV
선택된 적합 γ의 변화:       1.76062467 mV
보고 비율:                  0.03295994 (3.296%)
실제 허용 γ=.45의 재현오차:  0.0 V
그런데 실제 출력: “γ가 표현할 수 있는 것보다 훨씬 크게 변한다”
                 “그 차이는 a_NE·b_NE로 … 그것이 곧 LAM_NE”
```

완전히 표현 가능한 데이터에도 동일한 부족 판정이 나온다. **실제로 선택한 두 γ가 만든 변화량**과 **family가 표현할 수 있는 최대 범위/최소 잔차**는 다르다. U9의 방향 미검만 보완해서는 닫히지 않는다.

뒤의 인과 연결도 항등식이 아니다. 실제 `degradation_modes()`에서 용량과 `a_NE`를 고정하고 `b_NE`만 -.01 바꾸면 **LAM_NE=0**, LLI=-.0095238095(분율)가 나온다. 잔차가 반드시 `a_NE`로 이동한다는 보존식은 없다.

최소 종결 조건: 3~16%를 “선택된 적합 γ 쌍의 변화 진폭/측정 변화 진폭”으로 한정한다. 표현력 한계를 유지하려면 측정 곡선을 대상으로 γ를 적합해 달성 가능한 잔차를 검증해야 한다. LAM_NE로 누출된다는 주장은 모양 오차를 추가/제거하는 통제 재적합에서 parameter·잔차 변화를 별도로 측정해야 한다.

### R2-09 [P1 · 산술/경계 인과] `<1.20`이면 음수가 불가능하다는 문장은 원표의 식으로도 깨진다

위치: `FINDINGS.md:795`~`:824`; `scripts/audit97.py:83`~`:88`, `:167`~`:174`; `out/bms97/exp6_halfcell_source.csv:6`, `:9`.

기록된 `005C-step` 기준을 고정하면:

```text

음수 시작 임계값 a_NE_ref*c_ref/c = 1.1774195233937699
```

다섯 행의 영점은 1.17742~1.19622로 다르다. 최댓값 약 1.196을 모든 행의 필요 임계값처럼 쓰면 안 된다. 모든 행을 비음수로 강제하려면 **기준 적합을 고정한다는 조건에서** 그 최솟값 이하의 상한이 필요하다.

97행이 정의식을 재현한다는 사실은 유지된다. 그것은 기록된 parameter가 만드는 부호의 산술이다. optimizer가 왜 그 값을 골랐는지나 경계를 바꿔 양쪽을 재적합한 결과까지 증명하지 않는다. 위 숫자도 재적합 결과라고 주장하지 않는다. 정확히 같은 -18.9%가 줄어든다는 자명한 산술과 “음수 불가/경계 인과 종결”은 구별해야 한다.

최소 종결 조건: 행별 임계값과 고정-reference 조건을 표시한다. “5/5 대상 상한 접촉”이라는 관측 및 부호 식은 유지하고, “인과가 닫혔다”는 결론은 경계 변경 재적합 없이 확정하지 않는다.
