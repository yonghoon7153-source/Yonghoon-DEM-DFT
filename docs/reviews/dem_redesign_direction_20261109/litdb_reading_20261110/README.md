## 4. 한계 (쓰기 전에 읽는다)

- **표본 밖 항목은 대조하지 않았다.** 위 표의 "본 항목" 밖은 카드와 맞춰 본 적이 없다.
- 종합 문서의 줄 번호 (L…) 는 읽은 때의 카드 줄이다. 카드가 그 뒤 바뀌면 줄이 밀린다 (예: zunker2025 카드가 출판본 보강으로 길어졌다 — 그 보강이 종합 문서의 그 카드 항목 값에 주는 영향은 확인하지 않았다).
- card_problems.md 는 배치 01–40 기준이라 배치 41 · 42 절이 없다. insights_merged.md 소개 글의 "몫 3 = 20–39" 는 실제로 20–42 다.
- 검증이 "가벼운 것" · "빠진 무게 있는 줄" 로만 적은 것은 고치지 않았다 (APPLIED.md 5 절).
- 카드 문제는 기록만 했다 (1저자 11-10). 카드는 고치지 않았다.
- 2D 숫자를 3D 로, 다른 재료의 값을 LPSCl 값으로 옮기지 않는다. 기준 (순수 SE 기공률 10–13 % · 진밀도 1.64) 은 이 정독으로 바꾸지 않는다 (작업 지시서 5 절).
