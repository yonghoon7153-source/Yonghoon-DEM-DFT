## ⑤ `lhs00_009` — 유일한 진짜 이상치

φ_SE **0.3064** 로 문턱 한참 위이고, **같은 φ_SE 인 형제 20건이 전부 뚫리는데 혼자 막혔다.**

⇒ **두께 방향으로 AM_P 가 2.7개, RVE 폭으로 3.3개**뿐이다.  φ 가 아니라 **유한크기
corner** 다.  설계 자신이 `thin+n_am_p_low` 로 표시해 뒀다.
⚠ 솔버가 노드 **59,616개**를 만들고도 관통 성분을 못 찾았다 — *"입자가 없다"* 가 아니라
*"벽에서 벽까지 잇는 SE 사슬이 없다"* 다.
⬜ **확인 필요**: 이것이 물리인가, 아니면 원장의 열린 P1 `L2-04`(*"벽에 닿지 않는 입자

경계 규칙이 이미 결함으로 등재돼 있으므로 이 케이스는 그 축의 **실물 후보**다.
확인은 `solve_network` 의 진단 인쇄(`bottom=… top=… components reaching bottom/top`)를
`lhs00_009` 에서 한 번 보면 된다 (원자료가 저자 기계에 있다).

## 이것이 S3 에 주는 것

1. **이온 `B_ch` ≤ 102** — 판정 정의역이 정해졌다 (최종은 봉인이 정한다).
2. **ρ 는 판정을 구속하지 않는다** (3 % 차단의 20만~42만배 아래) — 그러나 그 ρ 는
   **가장 취약한 설계점**에서 나온 값이므로 *"코호트 전체가 그만큼 안정적"* 이 아니라
   *"최악에서도 그만큼"* 이다.
3. **퍼콜 경계 케이스가 이온 `B_ch` 안에 있다** (`lhs00_020` σ = 3.8e-11).  S3 의
   `median(|Δ|)` 은 중앙값이라 그런 꼬리에 지배되지 않지만, **그 케이스의 Δ 자체**는
   따로 볼 값이다.
⬜ **미확인**: 봉인의 `OLD_NONE` 25건이 여기 25건과 **같은 집합인가**.  다르면 봉인과 ρ 가
다른 데이터를 본 것이고, 러너의 `measured_by_channel` 검사가 그때 막는다.
