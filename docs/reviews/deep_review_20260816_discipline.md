## ① 쌍대응 통계 — hypot SE 는 과대(보수적), h1 은 두 방식 모두 생존

**재현.**  16개 값(a0~a7 = 이동 없음/z/y/yz/x/xz/xy/xyz; CL-33 원자료)에서:

```
SBE 평균 0.072651  se 0.000148     DBE 평균 0.073835  se 0.000141
비(평균의 비)      1.016294   (원장 1.0163 ✓)
쌍별 비 평균       1.016296   (두 추정량 소수 5자리 일치)
Pearson ρ(SBE,DBE) = +0.9628   (a2 가 양쪽 최저 — 격자 위상 공유의 예상대로)
SE_hypot (sdcp_gain_verdict.py:108-109 방식)      = 0.2784 %p   (원장 0.28 ✓)
SE_paired (쌍별 비 sd/√8)                          = 0.0550 %p
SE_delta (공분산 포함 델타법)                       = 0.0551 %p   (쌍별과 일치 — 검산)
```

**판별.**  h0(판정기 방식이 비의 SE 를 과소평가해 성급한 판정 위험) vs
h1(과대평가 = 보수적).  ρ>0 이면 델타법의 `−2ρ(se_S/m_S)(se_D/m_D)` 항이 SE 를
깎으므로 독립 가정 hypot 은 **위로** 튄다 — 실측 ρ=+0.963, hypot/paired = **5.1배**.
⇒ **h1(보수적) 확정.**  §5-2 게이트(SE>1.17→HOLD, `sdcp_gain_verdict.py:111-114`)는
과잉-HOLD 방향으로만 틀릴 수 있고, h0/h1 선택 자체는 점추정 비(§5-3~5)로만 결정되므로
**판정 뒤집힘 경로가 없다**.  hypot 이 과소평가하는 유일한 시나리오는 ρ<0 인데, 같은
격자 위상을 공유하는 shift 쌍에서 물리적으로 개연성이 없고 실측으로도 배제된다.

**판정 생존 확인.**
- hypot: SE 0.278 ≤ 1.17 통과 · 비 1.0163 ≤ 1.025 → **h1**.  h0(1.05)와 11.9σ 분리.
- paired: SE 0.055 통과 · 같은 비 → **h1**.  h0 와 **60.3σ**, 경계 1.025 와 15.6σ 분리.
⇒ **양쪽 모두 h1.**  쌍대응은 결론을 바꾸지 않고 **강화**한다.

**뉘앙스 (원장 서술 주의).**  paired SE 로는 관측 1.0163 이 h1 점예측 1.015 에서
**2.3σ** 떨어져 있다 (hypot 기준 0.5σ).  §5 는 구간(≤1.025)으로 판정하므로 결정은
불변이지만, "관측이 h1 예측과 일치" 류의 점-일치 서술은 hypot 기준에서만 성립한다 —
CL-32 의 "h1 예측 1.015 와 0.002 차" 는 사실 서술이라 무방하나, 앞으로 점-일치를
증거로 격상하지 말 것 (h1 의 지수 1.15 자체가 3점 적합, prereg §2 스스로 인용 금지).

**§5 를 사후에 바꾸지 않고 기록하는 법.**  §5 의 "8팔 표준오차" 는 런 전 커밋된
코드(`3a7ab13e`)의 hypot 이 조작적 정의다 — **이번 판정의 등록 통계량은 hypot 이 맞고,
사후에 paired 로 재판정하는 것이 오히려 추정량 사후 교체(위반)다**.  옳은 기록:
(i) CL-33 verdict 에 부록 한 단락 — "쌍별 SE 0.055 %p (hypot 의 1/5.1, ρ=0.963);
판정 동일, 분리 4.3σ→60σ 로 강화"; (ii) 판정기에 `se_ratio_paired_pct` 를 **보조
출력**으로 추가(게이트는 불변); (iii) **v3 이후 사전등록은 쌍별 SE 를 게이트로 등록**
(shift 팔은 설계상 쌍이다).  판정문·문턱·순서는 손대지 않는다.

## ③ CL-34 "최대 39 %" 상계 — 산술은 맞고 **논증이 무너진다** (HIGH)

**재현.**  26,796,815 − 26,501,282 = **295,533** ✓ (구-DBE 대 점-DBE 도체 셀).
115,555 / 295,533 = **0.3910** ✓.  vox 0.15 에서 참부피/vox³ = 0.014137/0.003375 =
**4.1887 셀/입자**; 138,988 입자 × 4.1887 = 582,185 셀; 점 셀(≤138,988)을 빼면
무-중첩 정당 후보 **≥443,197 셀** — 관측 증가 295,533 은 그 66.7 % 로, **정당한 구
부피만으로도 전액 설명 가능**하고 동시에 PTFE 오염이 커도 설명 가능하다 = 이
숫자들만으로는 분리가 안 된다.  (주: RVE 파일 `docs/data/sdcp8_v04.json` 의
`n_sdcp: 5659` 는 20 µm RVE 의 입자수다 — 실침대 138,988 과 혼동 금지.)

**결함 3중.**
1. **점수 ≠ 셀수.**  PTFE 는 phase 4 = **폴리라인 선분 스탬프**다
   (`step3_sigma.py:333` `POLYLINE_PHASES = (2, 4, 6)`; 러너가 `--stamp segment`,
   `sdcp_gain_vox015_8arm.sh:111`).  점유 셀수는 점수 115,555 가 아니라 선분
   래스터 셀수이고, 점 간격이 MPM dx(~0.6 µm)에 묶여 vox 0.15 의 ~4배이므로
   (`step3_sigma.py:255-257` 의 자체 진술) 셀/점 > 1 이 개연적이다.  셀/점 ≥ 2.56
   이면 상계는 min(셀수, 295,533)/295,533 = **100 % 로 포화 = 무정보**.  실측 없이는
   39 % 도 100 % 도 말할 수 없다.
2. **dof 원장은 σ-치환 채널을 못 본다.**  결함 코드에서 SDCP 구는 PTFE 만이 아니라
   **이미 도체인 셀**(VGCF sid 3 σ 78.54 · SWCNT sid 8)도 σ_SDCP = 250
   (`mpm_webapp_payload.py:460` 기본, `:925` σ 표)으로 덮는다 — 도체→도체라
   **n_dof 는 0 변화**인데 σ_e 는 오른다.  즉 "증가 셀의 39 %" 는 결함 효과의
   상계가 원리적으로 아니다.  (수정판 `step3_sigma.py:307-313` 은 구 스탬프를 상
   루프의 phase-5 자리에서 찍어 점 스탬프와 같은 우선순위 — PTFE/SWCNT 가 덮는다.)
3. **셀수 → σ_e 다리 부재 (자기 규칙 D).**  PTFE 셀은 정의상 탄소망 협착부에
   놓인다 (#31 PTFE 브릿지) — 셀당 σ_e 레버리지가 비전형적으로 크다.  세는 양으로
   귀결(가짜 이득 몫)을 상계하려면 bridge 가 필요한데 없다.  그런데 CL-34 는
   `kind: measurement_record` 라 검사기 규칙 C/D 스캔이 **면제**된다
   (`check_method_discipline.py:616-617`) — ⑤ 참조.

**판별 검사.**  h0(39 % 는 유효 상계) vs h1(상계 없음)은 GPU 없이 갈린다:
같은 DBE 침대에 `rasterize` 만 결함판(`c0a9dcc8`)/수정판(`fb77dc76`) 두 번 돌려
`sid==7`(PTFE)·`sid==8`(SWCNT)·상별 셀수 diff 를 세면 잠식 셀수가 **정확히** 나온다

**정정문 판정.**  "최대 39 %" 는 **철회하고 "대조 팔 전까지 상계 없음"** 으로 적는

## 종합

SBE 재사용 · 팔-동질성 게이트 · manifest bridge_um 등록.
