# 믹서 D3 측정 전 SOP·열람 절차 초안 검토 요청 (2026-11-04)

**결과 0건. 문서 초안의 범위·순서 검토만 요청한다. S1/S3/S6 등록·실측·C0/DEM·응용 실행 GO 요청이 아니다.**

대상은 `docs/reviews/mixer_d3_measurement_sop_draft_20261104.md`다. 11-04 오후 1저자의 “측정 전 SOP·열람 절차 초안만” 승인에 따른 문서이며 장비·시료·측정자·원자료 보관자는 1저자가 정한다. 수치·담당·경로의 미정 상태를 새 등록값으로 바꾸지 않았다. 이번 작성에서 시험·계산·기계 실행·실측 원자료 열람을 하지 않았다.

## 기존 근거와 요청 범위

- 설계 v2: `docs/reviews/mixer_d3_se_flowability_anchor_design_v2_20261023.md` §2–6.
- reader 계약: `docs/reviews/mixer_d3_candidate_reader_contract_20261024.md`. V2-Q1–Q4 정책은 이미 비준되었으며 그 사실을 되돌리지 않는다. 실제 조건·통계·시드·등록은 별도다.
- 10-27 외부 판정: `docs/reviews/codex_mixer_d3_review_20261027/codex_review_mixer_d3_20261027.md`. 입력 조건부 reader GO를 SOP 승인이나 통계·맹검·물리 타당성으로 확대하지 않는다.

검토할 내용은 기존 정책을 실제 측정 전 동결·보관·열람 절차의 빈칸과 순서로 옮긴 문서가 그 한계를 지키는지다. 새 구현의 정확성·실제 접근 통제 작동·역사적 시드 미사용·장비 자격·실험 결과는 이번 문서로 검증할 수 없다. 원장 종결이나 기존 finding의 verified 전환을 요청하지 않는다.

## 검토 질문

1. 장비·시료·담당·보관자와 Bo 격자·폭·반복·G·시드·측정 파라미터가 미정으로 남아 있으며, 이 초안 자체를 S1 또는 S3 등록으로 오독할 문장이 없는가?
2. S1의 실측 시작 전 동결과 S3의 실측값 비공개 조건이 분리되어 있는가? 이미 측정·열람한 자료를 사후에 맹검/사전등록으로 바꾸는 경로가 없는가?
3. 보정과 검증 열람 단위가 분리되고, C1 곡선·실패/결측 점 봉인 뒤 보정 열람, S 전체 후보의 해당 C2 예측 봉인 뒤 검증 단위별 열람이라는 순서가 유지되는가? 키·권한·구두 결과·혼합 원본의 누설 경계가 충분한가?
4. 기술 실패·관측 정의 불가·미지원·미평가가 보존되고, 검증으로 S를 몰래 줄이거나 `all-compatible`을 실행 GO로 바꾸지 않는가? reader의 출처 결합을 원자료 추출·통계 정당성의 증명으로 확대하지 않는가?
5. 예약 확인 시드와 C0/C1/C2 분리, 실제 manifest 검사와 역사적 미사용 증명의 차이, 미측정 기계시간과 일정 위험이 드러나는가?
6. 초안 §6의 사용자 확정 피복 정의가 S6 이후 별도 Claude 응용 계약의 경계로만 기록되어 있는가? 이를 D3 SE 단독 앵커의 관측량·접촉법칙·파라미터에 강제로 적용하거나 피복/P1 구현을 수행했다고 읽힐 부분이 없는가?

이 문서는 요청 준비본이다. 자기 판정·외부 GO를 기입하지 않는다. 리뷰 핀은 codex/mixer-1104의 게시 커밋이며 전달 ZIP의 PIN.txt에 전체 SHA를 넣는다. ZIP의 소스는 그 핀의 blob 그대로다. 발송 순서는 1저자가 정한다. 사용자 우선순위 Rint② → DEM → 나머지를 유지한다. 검토 의견이 수용되더라도 실제 입력 확정·S1/S3/S6 동결/등록·실측 및 기계 실행 승인은 별도로 남는다.
