## 0. 왜 이것을 봤나

심층 리뷰 ③ 이 CL-34 의 "최대 39 %" 상계를 무너뜨리면서 이렇게 적었다 —
**"dof 원장은 SDCP 가 VGCF 를 σ-치환하는 채널(dof 불변 · σ_e 상승)을 원리적으로 못 본다."**

도체 셀 수(dof)만 세면 그 채널이 안 보인다: SDCP 가 이미 도체인 VGCF 셀 위에 찍히면
셀 수는 그대로이고 **그 셀의 σ 만** 올라간다.  상별로 갈라 세면 보인다.

계기는 사용자가 kgy 에서 `VOXES="0.4 0.3 0.25" sdcp_phase_ledger.sh` 를 다시 돌린 것이다.
그 런은 이미 잰 격자였지만 **SBE 의 상별 셀 수**를 처음으로 냈고, 그것이 이 차를 가능하게 했다.

## 1. 표 (SBE − DBE, 상별 셀 수)

`밀려난 셀` = SBE 에 있던 그 상의 셀 수 − DBE 의 그 상의 셀 수.
`우연 기대` = SBE 에서 그 상의 부피분율.  `enrich` = SDCP 몫 / 우연 기대.

| vox | SDCP 셀 | ←SE | ←VGCF | ←AM_S | ←pore |
|---|---|---|---|---|---|
| 0.40 | 132,368 | 60,157 (45.4 %, 1.52) | **52,643 (39.8 %, 1.57)** | 15,582 (11.8 %, 0.28) | 3,986 (3.0 %, 1.17) |
| 0.30 | 135,770 | 77,875 (57.4 %, 1.54) | **34,034 (25.1 %, 1.61)** | 14,773 (10.9 %, 0.25) | 9,088 (6.7 %, 1.73) |
| 0.25 | 137,033 | 82,778 (60.4 %, 1.54) | **25,090 (18.3 %, 1.64)** | 13,586 ( 9.9 %, 0.23) | 15,579 (11.4 %, 2.03) |
| 0.15 | 138,455 | 82,873 (59.9 %, 1.51) | **9,967 ( 7.2 %, 1.72)** | 9,784 ( 7.1 %, 0.16) | 35,831 (25.9 %, 2.17) |
| 0.15 구 | 573,943 | 331,391 (57.7 %, 1.46) | **40,279 ( 7.0 %, 1.67)** | 58,387 (10.2 %, 0.23) | 143,886 (25.1 %, 2.10) |

⚠ **합계 = SDCP 셀 수는 항등식**이다 — 두 침대의 격자 총 셀 수가 같으므로 자동으로 성립한다.
**전사 검사**로만 쓴다 (10건 전부 통과: 상별 합 = 격자 총 셀 수).  물리 증거가 아니다.

⚠ SBE 와 DBE 는 **따로 압밀한 다른 침대**다.  차에는 래스터 overwrite 뿐 아니라
"SDCP 가 자리를 차지한 채로 압밀돼 VGCF/SE 가 다르게 놓인" 몫도 섞인다.
정확한 서술은 **"SDCP 가 덮었다"** 가 아니라 **"SDCP 가 있는 침대에서 이 상이 이만큼 적다"** 다.

## 2. 무엇이 격자 불변이고 무엇이 아닌가

**enrichment 는 거의 평평하다** — SE 1.52 / 1.54 / 1.54 / 1.51, VGCF 1.57 → 1.72,
AM_S 0.28 → 0.16.  표현 부피가 18.1배 변하는 내내 그렇다.

⇒ **SDCP 의 자리 선호는 구조적 사실이고 격자 불변**이다:
SE 자리에 우연보다 ~1.5배 자주 앉고, **AM 내부는 피한다** (0.16~0.28).

⇒ 격자와 함께 크게 움직인 것은 **몫**이지 선호가 아니다.  VGCF 몫이 39.8 → 7.2 % (5.5배)
움직인 이유는 **VGCF 자신의 표현 부피가 25.4 → 4.2 % 로 줄었기** 때문이다.
이것은 **DR3-06 (VGCF = 1-셀 굵기 관, 표현부피가 격자 불변이 아니다) 의 직접 증거**이기도 하다.

## 3. σ-치환 강도 — 이득과 같이 움직인다 (⚠ 인과 아님)

섬유만 직경-보존 재척도를 받는다: `σ_VGCF = 100·π·0.15²/(4·vox²)`.
입자인 SDCP 는 재척도를 **안 받는다** (250 고정) ⇒ **대비 자체가 vox 의 함수**다 (DR3-05).

| vox | VGCF 몫 | σ_VGCF (S/cm) | σ_SDCP/σ_VGCF | 강도 = 몫×대비 | 측정 이득 | 이득/강도 |
|---|---|---|---|---|---|---|
| 0.40 | 39.8 % | 11.04 | 22.6× | **9.00** | +42.15 % | 4.68 |
| 0.30 | 25.1 % | 19.63 | 12.7× | **3.19** | +16.21 % | 5.08 |
| 0.25 | 18.3 % | 28.27 |  8.8× | **1.62** | +8.49 % | 5.24 |
| 0.15 |  7.2 % | 78.54 |  3.2× | **0.23** | +1.63 % | 7.11 |

log-log 기울기 **0.884**, R² **0.9992** — 39배 구간에서 거의 비례한다.

⚠⚠ **이것은 인과가 아니다.**  n=4 이고 움직인 노브가 **vox 하나뿐**이라, vox 에 단조인 두 양은
무엇이든 이렇게 붙는다.  경쟁 채널도 전부 vox 에 단조다 — 가짜 상호연결(CL-24) ·
SDCP 표현부피 18.1배(CL-25) · SE 점 스탬프 충전도(DR3-07).
⇒ **"크기가 맞는 후보 기전"** 이지 측정된 기여가 아니다.

**왜 VGCF 에만 이 지표를 붙이나**: 재척도를 받는 상이 VGCF 하나다.  AM_S 를 밀어내는 것도
큰 σ 상승이지만(σ_AM ≪ σ_SDCP) 그 **대비는 격자 불변**이고 몫도 11.8 → 7.1 % 로 1.7배뿐이라
이득의 26배 스윙을 만들 수 없다.  VGCF 만 몫(5.5×)과 대비(7.1×)가 같은 방향으로 곱해진다.

## 4. 판별 팔 (CL-44, prereg v3 §4b — 런 전 등록)

**노브를 vox 에서 σ 로 갈아야** 갈린다.  `--step3-sdcp-yield-to-vgcf` = SDCP 가 이미 VGCF 인
셀에는 안 찍고 **양보**한다.  양보한 셀은 **여전히 도체**(VGCF σ)라 연결성이 안 끊기고
"부피" 채널은 그대로 남는다 ⇒ **σ 업그레이드 채널만** 꺼진다.

`G = R − 1`, 기준 0.1263 (arm 0).  **h0** (σ-치환이 원천) G = 0.030 · **h1** (새 부피가 원천)
G = 0.110 · 분해능 0.020.  중간대는 `MIXED`.
음성 대조: SBE 는 phase-5 가 0 개라 **no-op** 이어야 한다 (셀 단위 동일).

```
STEPS="5" bash ~/dem-sk/scripts/sdcp_next_1234.sh      # GPU 2 솔브
```

가드 — 진단 팔이 생산 팔과 섞이면 판정기가 **HOLD** 로 잡는다
(매니페스트 `sdcp_yield_to_vgcf` + 고정-인자 게이트, `sdcp_gain_verdict --selftest` ⑫⑬).
규약 불변 회귀 = `step3_sigma --selftest` 의 `sdcp-yield-default` (기본값이면 셀 단위 동일).

⚠ **이 팔은 생산 규약이 아니다.**  실물에서 SDCP 는 탄소 위에 코팅되므로 그 셀의 σ 가 오르는
것 자체는 물리다.  문제는 **그 크기가 격자의 함수**라는 것이지 존재가 아니다.

## 5. CL-33/34 에 대한 함의 — 유리한 방향

vox 0.15 구 스탬프(현재 헤드라인 측정 +12.3 %)에서:

- VGCF 몫 **7.0 %** · σ 대비 **3.2×** → 강도 **0.22** = vox 0.4 의 **1/41**.
- 구 스탬프 추가 435,488 셀의 출처: **SE 57.1 % · pore 24.8 % · AM_S 11.2 % · VGCF 7.0 %**
  ⇒ **81.9 % 가 절연 → 도체 전환** (새 도체 부피) 이고 VGCF 재활용은 7 % 뿐이다.

⇒ +12.3 % 의 대부분은 σ-치환으로 설명되지 않는다.
⚠ 그렇다고 **검정이 된 것은 아니다** — prereg v2 는 점 스탬프에 대해 등록됐고, 구 스탬프
수치는 **측정 서술**이다 (prereg §7).  판별은 CL-44 가 한다.
