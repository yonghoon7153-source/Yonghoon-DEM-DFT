바탕은 cf81ed8a70fd, 가지는 codex/suyoung-fixed-return-1123이다. 첫 커밋 ceeca0f90d82는 원자료 판독기·회귀·그림 원본·결과·해석을 담았다. 둘째 커밋은 같은 물리 경로에서 정지 시간을 연장하는 WSL 블록 원본과 시험, 이 쪽지다. 전체 SHA·순서·stable patch-id는 인계 ZIP의 HANDOFF.md에 있다. 1저자 반입 결정 뒤 두 커밋을 순서대로 cherry-pick -x 한다.

원 TAR 및 화면 SHA256을 수령 기록과 대조했다. 격자별 가압 CSV 4개가 분기점까지 기존 바이트와 같았다. 마지막 두 구간에서 아래판 평균 차이가 +0.03292 MPa 커졌다. 두 판 격자 차이의 반합과 반차로 나누면 각각 +0.00053, +0.03239 MPa다. 마지막 구간의 평균 입자 병진 운동에너지도 두 격자 모두 증가했다. 구간과 관측량 정의는 docs/reviews/suyoung_fixed_height_return_20261123/readback_ko.md에 있다.

연장판은 정지 F12 4,800걸음·F24 9,600걸음, 각 팔의 총 상한 2,400초·7,200초, CPU 1개다. 이전 반환에는 재시작용 전체 상태 배열이 없어 시드부터 다시 진행한다. 기존 정지 끝에서 격자마다 CSV 5개 전체와 가압 분기 상태의 해시를 대조한 뒤 같은 메모리 상태에서 연장한다. 초기 4구간과 추가 12구간 각각의 양판 반력·전체 운동량 변화·병진 운동에너지를 기록한다. 개발 결과 한 건이 가압 자격이나 후속 실행을 승인하는 규칙은 두지 않았다.

시험은 반환 판독 합성 5/5, 연장 경계·시간창 합성 11/11, WSL 블록 모의 실행 5/5다. 저자 반환의 재판독과 모의 입력만 실무 창에서 수행했다. 공유 기록 제안은 “판 정지 뒤 아래판 격자 차이는 둘째 구간 +0.00650 → 마지막 +0.04677 MPa, 평균 병진 운동에너지도 재상승. 정지 평형 미확인, U6(c)·단계 3·3D HOLD. 다음은 같은 높이 정지 연장 1회”다. 외부 Git 참조 예외 추가는 없다.
