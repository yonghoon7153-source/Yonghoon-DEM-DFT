Q-A 비용 근거는 원 README §4-3의 수령 메타다. 고유 기하 열쇠6, 기존 건설122(팔74+봉인원천48), SBE 4,038–4,040초는 기존 실측, DBE 약11,850초는 추정이다. 이번에 다시 재지 않았고 총 소요시간을 확정하지 않았다. 지원 환경 수와 재사용 가능한 독립 증거를 정한 뒤 비용표를 고정한다. 원장은 직접 수정하지 않는다.
