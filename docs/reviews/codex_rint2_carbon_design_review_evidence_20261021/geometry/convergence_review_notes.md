## 결론

- A/B/C는 기존 `info=0`보다 좋은 **경험적 검증 묶음**이나, 모든 새 망의 상대 σ 오차 ≤ `1e-4`를 증명하는 수렴 증서는 아니다. 실제 첫 CG 해와 실제 이어 풀기를 사용해 세 항이 모두 통과하고 오차가 `1e-4`를 넘는 양의 저항망을 얻었다.
- 따라서 설계 §6의 **합성 표에서 닫힘**은 인정하되 **일반 수치 정확도 보장으로 닫힘**은 반대. 수정은 임의의 rtol/불균형 숫자 재조정이 아니라 목표량(단자 전도도) 오차를 구속하는 검증으로 해야 한다.
- R의 `R_j→∞` 바닥은 정확한 미퍼콜 σ=0일 수 있다. 모든 판정 해에 상대 σ 변화와 상대 판 전류를 요구하는 문장은 이 경우 정의되지 않는다. 구조적 0 전용 증서가 필요하다.

## CONV-01 — 같은 전역 norm으로 다시 푸는 C는 독립 정확도 증명이 아니다

**권고 심각도:** P2 수치 계약. 새 생산의 `≤1e-4` 수치 보증을 출하 조건으로 삼는다면 그 조건은 열림. 실침대의 큰 오차, 기존 원고 숫자 오류, 1–10% 편향을 입증한 것은 아니다.

대상:

- `docs/reviews/rint_carbon_additive_design_v1_20261020.md:377–385`: A/B/C와 봉인 규칙.
- 같은 파일 `:385`: 판 전류 불균형 분리 구간이 비면 B를 진단으로 내려 A+C만 증서로 삼는 규칙. 이때 독립성이 더 약해진다.
- `scripts/step3_conv_cert.py:75–115`: 실제 인증기. A는 전역 norm 기준 정지 표지를 받고 B는 두 판 합계만 비교하고 C는 같은 solver에 같은 우변을 넣어 warm start한다.
- `scripts/step3_sigma.py:477–534`, `:2191–2215`: 실제 첫 CG/판 전류/재풀이 배선.

### 실제 CG가 만든 반례 (보고의 주 반례)

망은 아래판–양의 저항 11개 직렬–위판과 아래판에만 붙은 하나의 막다른 노드다. 자유 노드 11개(직렬 내부 10개 + 막다른 1개), 모든 g>0, SPD. 직접해를 기준으로 삼지 않고 정확한 직렬 공식 `G*=1/Σ(1/g_k)`을 사용한다. 탐침 코드에 모든 g를 고정했다.

| 항목 | 값 |
|---|---:|
| 최대 g / 최소 g | 1270.447780941764 / 1.92731315261053e-9 (코드 단위) |
| 정확한 단자 G | 1.6475350536519418e-9 |
| 생산 `_solve_cg`, x0 없음, rtol=1e-12 | 1.6472243400696e-9 |
| 정확한 G 대비 상대 오차 | −1.88593002408699e-4 = −0.0188593002409% |
| 첫 CG info / 반복 | 0 / 10 |
| 실제 전역 잔차 `||Lφ-b||/||b||` | 2.761381473905492e-16 |
| 판 전류 불균형 | 9.147795533580172e-5 (<1e-4) |
| rtol=1e-14 재풀이 info / 추가 반복 | 0 / **0** |
| 재풀이 상대 ΔG | 0 |
| 인증기 | `pass_a=pass_b=pass_c=ok=True` |

재풀이가 0회인 이유는 잘못된 명령이나 mock이 아니라, SciPy CG도 같은 `||b||`로 이미 잔차가 충분히 작다고 판단하기 때문이다. 재풀이 판 불균형을 추가로 검사해도 같은 값이라 이 반례는 통과한다. 처음 φ를 수작업으로 만든 예가 아니다.

그런데 같은 φ의 모든 간선 소산 `Σg(Δφ)^2`는 `1.647535053652368e-9`이고, 단위 전류 직렬 흐름의 쌍대 하한은 정확한 `1.6475350536519418e-9`다. 상·하한 상대 폭은 **2.5868196473766147e-13**인데 게시하려는 판 전류 G는 그 아래에 있다. 단자 전류의 큰 항끼리 뺄셈/전역 정지 norm이 오차를 만든 사례이며, 전압장이 크게 틀렸다는 주장과 다르다.

**한정:** 대비가 6.59e11인 소형 합성 망이다. 등록 R은 Rj를 ×100으로 확장하고 상한을 별도로 제한하지 않지만, 이 예를 실제 SBE/DBE 격자에서 추출한 것은 아니다. 따라서 보편 증서 주장은 반박하고 실침대 오차 크기는 유보한다. 이 실험을 근거로 기존 결과를 소급 철회하지 않는다.

**도달 가능성 QA:** 이 막다른 성분을 생산 가지치기가 먼저 없애는 것은 아니다. `carbon_junction.py:1494–1511`은 `kept_c = bot_c | top_c`(합집합)로 남기고 `thr_c`(교집합)는 별도로 센다. `step3_sigma.py:2032–2044`도 같은 규칙이다. 따라서 한쪽 판에만 붙은 SPD 성분은 solve에서 살아 있다. 다만 본 수치망을 복셀/섬유 좌표로 역설계하여 raster부터 생성한 것은 아니다.

두 번째 실제 CG 예도 파일에 있다(23 내부+막다른 1개): 오차 +5.12087249355e-4, A/B/C 통과, 재풀이 후 +5.45995005262e-4. 그 예는 재풀이 판 균형을 따로 확인하면 떨어지므로 주 반례로는 위 11자유도 예를 쓴다.

### 최소 변경 방향 (새 임의 문턱을 제안하지 않음)

1. A/B/C는 유지해도 되지만 이름을 경험적 수렴 검사로 제한한다. 합성 3시드/두 꼴에서의 성능과 모든 형상/접합 대비에서의 정확도 보장을 분리한다.
2. 이미 목표한 `1e-4`를 단자 목표량에 연결한다. 예: ΔV=1인 수동망에서 임의 전압 φ의 에너지 `U=Σg_e(Δφ_e)^2`는 G의 상한이다. 내부 KCL을 정확하게 만족하는 단위 단자 전류 q의 `R_q=Σq_e²/g_e`는 R의 상한이므로 `1/R_q≤G≤U`. 이 폭과 게시값의 위치를 검사하는 primal/dual 증서, 또는 동등한 목표량 오차 추정·검증을 등록할 수 있다. 구현상의 부동소수 보수 처리와 q의 KCL 확인은 별도 시험 대상이다.
3. 한쪽 판에만 연결된 무전류 성분은 해석적으로 제거/상수화할 수 있고, 성분/블록별 residual을 보는 것도 도움이 된다. 이것만으로 일반 증명이라고 부르지는 않는다. 제거 정책은 물리 변경이 아니어도 시험/봉인이 필요하다.
4. 좁은 한 분포로 rtol과 εI를 정하고 같은 표로 성능을 주장하지 말고, 경로 길이·접합 대비·소수 관통 통로·한쪽판 막다른 성분·극한 Rj를 포함한 고정 stress 집합을 분리한다. 이는 경험적 적용 범위를 넓히는 것이지 증명의 대체가 아니다.

## CONV-02 — 바닥 σ=0은 수렴 실패가 아니다

**권고 심각도:** P2 설계 완결성. 등록 사다리 과잉차단 방지.

- `rint_carbon_additive_registration_R_draft_20261020.md:66`: 첫 바닥은 VV 간선을 없앤 Rj∞. 위아래 관통 성분이 전혀 없어도 물리적으로 유효한 σ=0일 수 있다.
- 같은 문서 `:76`, `:189`: ABC 하나 실패면 사다리 정지/미게시.
- 설계 `:380`: 모든 판정 해에 상대 변화 검사.
- `step3_conv_cert.py:81`, `:96`: Ib=0 및 σ=0은 infinity로 설정되어 B/C 실패한다.
- `step3_sigma.py:2179–2184`: S2에서 no-through 조기반환은 `cg_info=0,resid=0,unconverged=False,σ=0`이지만 conv_cert 없음. 현 구현으로 어떤 상위 소비자가 통과시키는지는 별도 구현 리뷰 사항이다. 여기서는 문서 계약의 경로 누락을 지적한다.

정확한 두 노드 반례: `L=diag(1,1), b=(1,0), φ=(1,0)`, 첫 노드는 아래판만, 둘째는 위판만. 정확한 KCL·σ=0에도 실제 인증기는 `pass_a=True,pass_b=False,pass_c=False`를 낸다.

**최소 조건:** `VALID_ZERO_TOPOLOGY`와 `POSITIVE_SOLVED`를 분리. 전자는 실제 조립 그래프에서 양 판에 연결된 성분이 없고 그 그래프/경계/축약/절단 지문이 맞음을 증명한다. 전자는 상대 σ 오차를 만들지 않고 바닥값 0으로 사다리에 들어가야 한다. near-zero 값을 임의 절단해 0으로 만드는 처방은 아니다. CG 실패를 0으로 돌리는 것도 아니다.
