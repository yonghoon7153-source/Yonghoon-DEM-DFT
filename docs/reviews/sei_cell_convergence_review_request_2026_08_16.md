## 1. 발단 — 왜 여기까지 왔나

`li3nd` c→c 장벽 **0.229 eV** 는 계산 품질이 좋다: CI 정상(`CI_scheme=auto`), 정·역 대칭
**23 μeV**, 경로 오차 0.039 < 0.05 eV/Å, 끝점 독립 이완. `db/properties/sei_neb.json` 에서
**8건 중 유일하게 `citable: true`** 다.

그런데 db 규약이 절대값 인용을 막고 있다:

> ⚠ jellium 보정은 유한 셀 근사다 — 절대값은 셀 수렴 확인 뒤 인용할 것. **상 사이 비교**가 이 값의 용도다.

셀 수렴을 확인하려고 3×3×3(`sei_neb_v2_cc333`)을 보다가 세 가지가 연달아 나왔다.

## 2. 발견 ① — `--min_l` 이 이미지 거리를 안 재고 있었다

`build_neb_inputs.py` 는 **격자벡터 길이**로 슈퍼셀 배수를 골랐다:

```python
L = at0.cell.lengths()
rep = tuple(max(1, int(np.ceil(a.min_l / x))) for x in L)
```

그런데 공공–공공 주기 상호작용을 정하는 건 벡터 길이가 아니라 **주기면 사이 수직 거리**다:

```
d_i = V / |a_j × a_k|
```

비직교(fcc 원시) 셀에서 둘은 크게 다르다. 실측:

| 상 | 슈퍼셀 | 벡터 길이 | **실제 이미지 거리** | `--min_l 10` |
|---|---|---|---|---|
| li3nd | 2×2×2 (31원자) | 10.37 Å | **8.47 Å** | 통과 ✅ (실제로는 미달) |
| li2s | 3×3×3 (80원자) | 12.10 Å | **9.88 Å** | 통과 ✅ (실제로는 미달) |
| li3nd | 3×3×3 (107원자) | 15.56 Å | 12.70 Å | — |

**같은 규칙을 통과한 두 상의 실제 이미지 거리가 1.17배 다르고, 둘 다 목표 10 Å 에 미달이다.**

수직 폭 기준으로 바꾸면 `--min_l 10` 에서 li3nd 는 **3×3×3 이 강제**된다 (2×2×2 는 8.47 로 미달).
즉 cc333 은 "추가 확인" 이 아니라 **원래 필요했던 셀**이다.

### 요청 사항 (1)

- 기본 기준을 `perp` 로 바꾼 판단이 맞나? (`--min_l_basis vector` 로 옛 동작 보존)
- **이미 돈 계산의 지위**: li2s(9.88 Å)·li3nd 2×2×2(8.47 Å)를 어떻게 표기할지.
  우리 안은 "기록으로 남기되 `min_perp_width_A` 를 meta·db 에 실어 미달임을 명시".
  재계산 강제까지 갈지는 판단을 구한다.
- 아직 안 돈 v3 4종(li2o·li3p·li3po4g·licl)은 새 기준으로 가면 된다 — 이건 이견 없다고 본다.

## 3. 발견 ② — cc333 끝점이 미수렴이고 구조가 표류했다

두 끝점 relax 가 각각 **16h41m** 돌고 `The maximum number of steps has been reached` 로 끝났다.

| | 값 |
|---|---|
| 마지막 `Total force` | **0.018 Ry/au = 0.46 eV/Å** |
| `forc_conv_thr` | 1.0d-3 (문턱의 **18배**) |
| 마지막 3스텝 | 0.0181 → 0.0179 → 0.0176 (**진동**, 하강 아님) |
| `Total SCF correction` | 2e-5 (SCF 잡음 아님) |

그리고 구조가 표류했다:

| | 이완 전 (`relax.in`) | 이완 후 (`relax.out`) |
|---|---|---|
| 홉 거리 | **3.667 Å** (= 결정학적 c–c) | **4.203 Å** |
| 2위 변위 | **0.000 Å** | **1.240 Å** |

k-점은 범인이 아니다 — 두 셀의 k-간격이 같다 (10.37×3 vs 15.56×2 → 둘 다 0.0321 Å⁻¹).
자유도가 93 → **321** 인데 `nstep` 이 그대로 50 이었던 게 유력하다.

**실측 0.33 h/스텝.** 321 자유도면 200~300 스텝이 현실적 → 전이완 완주에 **GPU 8~12일**.

## 4. 대응 — 고정셸 중점법 (`symmetric_saddle.py`)

비용을 세 가지로 줄였다.

1. **대칭 홉이라 끝점은 하나만** 재면 된다 (E_ini = E_fin 이 대칭으로 보장). −33%
2. **원거리 원자 고정.** 우리가 재려는 건 이미지 상호작용의 셀 의존성이고, 공공에서 먼 원자는
   두 셀 다 이상 격자 위치라 사실상 같다. 자유도 321 → ~100.
3. 2×2×2 대조군도 **같은 고정 규약**으로 다시 잰다 (31원자라 쌈).

→ 3×3×3 약 **53 h (2.2일)**, 대조군 포함 **65 h**.

### 안장점을 찾지 않는 근거

이 홉은 대칭이라 안장점이 경로 중앙에 **대칭으로 결정**된다. 실측 증거: 2×2×2 ccpath 에서
CI 가 값을 **1 μeV** 만 바꿨다 (`no-CI 0.228980 → CI 0.228981`) — 안장점이 이미 중점 이미지
위에 있었다는 뜻이다. 그래서 중점에 뛰는 원자를 고정하고 나머지를 이완하면 그게 안장점이다.

### 입력을 `relax.in` 에서 만드는 이유

`relax.out` 은 표류한 구조(§3)라 승계하면 안 된다. `relax.in` 의 이상 좌표(홉 3.667,
나머지 변위 0.000)에서 새로 시작한다.

### 요청 사항 (2)

- **전제가 성립하나**: "대칭 홉 → 안장 = 중점" 을 CI 1 μeV 로 근거 삼은 것.
- **고정셸이 만드는 편향**: 원거리 이완을 버리므로 절대 장벽이 전이완보다 약간 높게 나온다.
  우리 주장은 "그 편향이 두 셀에서 같은 방향이라 **차이**에는 대부분 상쇄된다" 인데,
  이건 논증이지 측정이 아니다. 반경을 두 값(예: 5·7 Å)으로 돌려 편향의 반경 의존성을
  보이는 게 맞나?
- **대조군 규약**: 2×2×2 전이완 0.229 와 3×3×3 고정셸 값을 직접 비교하면 안 되고, 2×2×2 도
  같은 고정셸로 다시 재야 한다고 봤다. 동의하나?

## 7. 우리가 하지 않은 것 (명시)

- 셀 수렴을 **측정하지 않았다.** 현재 근거는 논증뿐이다: Li₃Nd 는 금속이고 공공이 중성이라
  하전 결함 이미지 정전기가 없고, 남는 탄성·Friedel 은 ~1/r³ 이라 8.47 → 12.70 Å 에서
  0.30배로 준다. **데이터 점이 하나뿐이면 "수렴" 은 주장이지 측정이 아니다.**
- 비대칭 홉(li3nd c→b)에는 이 도구를 못 쓴다. 그건 full NEB 이 필요하다.
- 고정셸 값과 전이완 값을 섞지 않는다 — 규약이 다르다.
