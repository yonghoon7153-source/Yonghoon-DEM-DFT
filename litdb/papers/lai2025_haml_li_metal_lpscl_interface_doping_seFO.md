## 1. 한 줄 요약

**AIMD ↔ MLP 학습 ↔ MLP-MD 를 MTP 의 외삽등급(γ)으로 스위칭하며 반복하는 하이브리드(HAML)로 Li|Li₆PS₅Cl 계면을 300 K 에서 528 ps–1 ns 까지 밀었고(순수 AIMD 대비 23–46× 절감), Se·F·O 도핑이 계면반응 "속도"를 올려 보호층을 더 빨리 만든다고 주장한다** — 방법론(가속 프로토콜·비용 표)은 재현 가능하고 값어치가 크지만, **도핑 주장 자체는 자기 SI(Fig. S14)와 어긋난다**(반응이 네 계 모두 ~20 ps 에 끝나고 차이가 거의 없다).

## 4. HAML 프로토콜 해부 ★ (우리가 가져올 레시피)

### 4.1 사이클 구조 — 무엇이 무엇을 낳나

```
Geometry Optimization
   ↓
┌─→ AIMD  ────────────────► (마지막 구조) ──┐
│      ↓ (궤적 = 학습데이터 추가)            │
│   MLP Training (MTP 재학습)                │
│      ↓                                     │
│   MLP-MD (LAMMPS, γ 감시)                  │
│      ↓ γ ≥ γ_break 이면 즉시 중단          │
│   (마지막 구조) ───────────────────────────┘  ← 다음 AIMD 의 시작 구조
│      ↓
└── "Reach Time?" No → 위로 / Yes → 종료
```

원문 그대로: *"In each cycle, the final configuration from AIMD serves as the initial configuration for MLP-MD, while the final configuration from MLP-MD becomes the initial configuration for AIMD."* (Fig. 1c)

**핵심 설계철학** (우리가 배울 지점): AL 은 "모르는 곳을 찾아다니는" 전략이라 고에너지·고분산 구성을 우선 뽑고, 그게 **실제 반응 경로와 어긋난다**(sampling bias). HAML 은 반대로 **AIMD 가 실제 경로를 직접 걸어가고 MLP 는 그 경로 위에서만 배운다.** 그래서 "구성공간 탐색"을 아예 안 한다 — 한 번의 시뮬레이션 안에서 끝난다(one-shot, in situ).

### 4.2 전환 판정 기준 = **MTP 외삽등급 γ (Maxvol)**

- MLP-MD 매 구성마다 **extrapolation grade γ** 계산 (MTP 의 Maxvol/D-optimality 기반, ref 44·45).
- **γ < γ_break** → MD 계속 / **γ ≥ γ_break** → **MD 즉시 중단** → AIMD 로 복귀 (Fig. 1c 오른쪽 박스).
- **γ_break = 10** (Li|고체전해질) / **20** (Li|액체전해질). 본문 Methods 명시.
- 즉 **시간 기준도 사건 기준도 아니고 "모델이 자기가 모른다고 말할 때"** 가 전환점이다. ⇒ 이게 HAML 의 전부라고 해도 된다.

> ⚠ Discussion 에서 저자들이 직접 인정: *"the break threshold may need to be set as small as possible for certain systems to maintain simulation accuracy"* — γ_break 는 **튜닝 파라미터**이고, 어떻게 정했는지(수렴 테스트 등)는 **미기재**.

### 4.6 ★ 비용 검산 — "20배 이상"은 무엇 대비 무엇인가

#### 4.6.1 자기정합성: 통과 ✅
Table S1–S5 의 `h/ps` 열은 전부 `CPU h ÷ 시뮬 ps` 와 소수 둘째 자리까지 맞는다 (예: 70.82/528.06 = 0.1341 → 표기 0.13; 60.80/16 = 3.80 ✓; 85.97/550.10 = 0.1563 → 0.16 ✓). Fig. 2 의 꺾은선도 이 비율과 일치. **표 자체는 조작·반올림 오류가 없다.**

#### 4.6.2 "AIMD" 행은 무엇인가 — 두 해석과 그 귀결
전 계에서 `HAML CPU > AIMD CPU` 이고 여유가 8–23 % 다:

| 계 | HAML h | AIMD h | 차이 (= MLP 학습+MD 몫) |
|---|---|---|---|
| 액체 | 234.37 | 180.52 | 53.85 h (23 %) |
| LPSC | 70.82 | 60.80 | **10.02 h (14 %)** |
| Se | 85.97 | 76.69 | 9.28 h (11 %) |
| F | 39.99 | 32.92 | 7.07 h (18 %) |
| O | 40.54 | 32.94 | 7.60 h (19 %) |

⇒ **"AIMD 행 = HAML 안에서 실제로 돌아간 AIMD"** 로 읽으면 전부 앞뒤가 맞는다. 그러면:

- **AIMD 가 궤적에서 차지하는 비율**: LPSC **3.0 %**(16/528) · Se 2.9 % · F 3.6 % · O 3.3 % · 액체 5.8 %
- **AIMD 가 CPU 에서 차지하는 비율**: LPSC **86 %** · 액체 77 %
- ⇒ **가속비의 이론 천장 = 1/(AIMD 궤적 비율) ≈ 33×** (LPSC). 실측 28.4× 는 그 **86 %** — 나머지 14 % 를 MLP 학습·MD 가 먹는다.

> ⭐ **우리가 가져갈 설계식**: `가속비 ≈ 1 / (AIMD 궤적 비율) × (1 − MLP 오버헤드)`. AIMD 를 궤적의 3 % 로 억제하면 ~30×, 10 % 로 쓰면 ~9× 밖에 안 된다. **비용을 결정하는 건 MLP 가 아니라 "AIMD 를 얼마나 안 돌리느냐"다.**

#### 4.6.3 ⛔ 내부 모순 하나 (Table S2)
528 ps → 1034 ps 로 **연장**했다면서(본문 *"we extended the simulation time from 528 ps to 1 ns"*):
- HAML CPU: 70.82 → 85.82 (**+15.00 h**)
- AIMD CPU: 60.80 → 79.96 (**+19.16 h**)

**AIMD 증가분이 전체 증가분보다 크다** — AIMD ⊂ HAML 이면 불가능하다. ⇒ 둘 중 하나: (a) 1 ns 는 연속이 아니라 **별개 런**이거나, (b) 숫자 하나가 틀렸다. 어느 쪽이든 §4.6.2 의 해석이 흔들린다. **가속비 수치를 인용할 땐 "저자 보고값"이라고 못 박아야 한다.**

#### 4.6.4 CPU 시간의 단위 해석 (벽시계 vs 코어시간)
"Total CPU Time Used (h)" + "96 cores" 는 모호하다. 코어시간이라면 AIMD 3.80 h/ps ÷ 1000 step/ps ÷ 96 core = **0.14 s/step 벽시계** — 112원자 520 eV VASP 로 물리적으로 불가능하다. 벽시계라면 **13.7 s/step (= 365 코어시간/ps)** — 타당하다. ⇒ **벽시계 시간으로 읽어야 한다.**
- 논문 전체 계산량 ≈ 487–558 h 벽시계 × 96 코어 = **약 4.7만–5.4만 코어시간**. (5개 계 × 280–1034 ps)

### 4.8 similarity analysis method — 정의·입출력·우리 사용 가능성

SI Note 2 원문 요지:
1. **SOAP** (Smooth Overlap of Atomic Positions) 로 각 국소 원자환경을 고차원 벡터로 인코딩
2. 두 구조의 SOAP 벡터 사이 **코사인 유사도** (0–1)
3. 선행 자기 논문(Lai, *Small* 2023, anode-free Li/Cu)에서 쓰던 것을 "정량화용으로 개선"

**입력**: 구조 2개(원자좌표·종). **출력**: 스칼라 1개.
**우리 사용 가능성**: ✅ **가능하고 값싸다.** `dscribe` 의 SOAP + numpy 코사인이면 끝이고 DFT 가 전혀 안 든다. **우리 기존 UMA-MD 궤적(modelC / b2o3 / LPSOCl)에 그대로 걸 수 있다.**
**⚠ 두 가지 함정**:
- 하이퍼파라미터(r_cut·n_max·l_max·σ) 미기재 → **절대값은 논문과 비교 불가**. 우리 계 안에서의 *상대비교*로만 써야 한다.
- 값이 0.84–0.97 로 **압축돼 있다.** 계면이 완전히 아모포스화된 구조(Fig. 4d)조차 0.93 이 나온다 — Li 금속 슬랩(112 중 ~60원자)이 결정성을 유지해서 평균을 끌어올리기 때문이다. ⇒ 쓰려면 **계면 영역 원자만 골라서** 계산해야 의미가 있다. (논문은 그렇게 했는지 안 밝혔다.)

### 4.9 계면 모델 재구성 — 논문이 안 준 것을 우리가 역산

SI Note 1 은 절차를 준다: MP 벌크(Li = **mp-51**, Li₆PS₅Cl = **mp-985592**) 이완 → pymatgen 으로 (100) 절단 → **VASPKIT** 로 계면 조립(간격 3.5 Å, mismatch 최소·원자수 최소) → 이완 → MD. 그런데 **슬랩별 원자수가 없다.**

우리 역산 두 갈래 (둘 다 완전히는 안 맞는다 — 그래서 §12 에 남긴다):
- **화학량론 갈래**: Li₆PS₄.₇₅**Se₀.₂₅**Cl 에서 Se 가 정수 1개가 되려면 S 자리가 20개 = **4 f.u. (52원자)** 필요 → Li 금속 60원자 (= 6층 × 10). 112 ✓. F 도핑 Cl₀.₅F₀.₅ 도 4 f.u. 에 F 2개로 딱 맞는다 ✓.
- **결합수 갈래**: Fig. 4e 의 P–S 결합수 8, Fig. S15a 의 P–S 평균 CN ≈ 3.9 → **P 원자 ≈ 2개** (8/3.9). 4 f.u. 라면 16 이어야 한다.
- **정합 해석**: 4 f.u.(P 4개)인데 **0 ps 시점에 이미 PS₄ 절반이 깨져 있다** — 절단면이 PS₄ 를 자르거나 이완 중에 P–S 가 2.3 Å 밖으로 벌어진 것. Fig. 4c("0 ps") 스냅샷에서 위쪽 계면이 **MD 시작 전부터 무너져 있는 것**과 일치한다.
- ⇒ **"0 ps" 는 이미 반응이 시작된 구조다.** 유사도의 "before relax" 기준선이 필요한 이유이기도 하고, 동시에 그 기준선이 **이완효과 + 반응효과를 섞어버리는** 이유이기도 하다.

### 5.1 액체계 Li \| LiFSI/DME (Fig. 3) — 방법 시연

### 5.5 "moderate structural instability 가 계면 안정화에 긍정적" — 근거 감사 ★

이게 초록·Discussion 의 반직관적 핵심 주장이다. 근거 사슬을 그대로 펴면:

```
① 도핑계가 0 ps 유사도가 더 낮다 (Fig. 5e: 0.844–0.887 vs 0.933)
      ↓ (해석) "도펀트가 native equilibrium 을 흐트러뜨린다 = structural perturbation"
② 그 불안정성이 초기 SEI 형성 속도를 높인다 (Fig. 5f, S14, S15)
      ↓ (해석) "빠른 초기 반응 = passivation layer 를 빨리 세운다"
③ ⇒ "moderate lattice instability 는 계면반응 속도를 조절하는 유효 전략"
```

**감사 결과**:
- ①은 **측정된 사실**이지만 값 차이가 0.05–0.09 이고, 기준 구조를 바꾸면 순위가 바뀐다 (§3.4).
- ②는 **Fig. S14 로 반증된다** (§5.4). Fig. 5f 의 무도핑 Li–S 막대 하나가 이 인상을 만든다.
- ③의 "protective layer" 는 **이 시뮬레이션으로 검증 불가능하다** — 아래 참조.
- 게다가 **"빨리 반응한다"에서 "안정한 보호층이 된다"로 넘어가는 논리적 다리가 없다.** 논문은 이걸 문헌 인용(ref 60 Arnold F-doped, 61 Wu O-doped, 62 Golov, 63 Kim SeS₂)으로 메운다 — **자기 계산이 아니다.**

> ⛔⛔ **결정적 한계**: SSE 슬랩이 **~10 Å (1 유닛셀)** 두께인데 **20 ps 만에 통째로 분해된다** (Fig. 4d). 부동태화(passivation)란 *"SEI 가 자라다가 그 뒤의 전해질을 보호하며 멈춘다"* 인데, **보호받을 전해질이 남아 있지 않은 모델에서는 정의상 관측 불가능하다.** 여기서 관측된 "포화"는 부동태화가 아니라 **연료 소진**이다. ⇒ 초록의 *"facilitating the formation of a more stable interface protective layer"* 는 **이 계산이 지지할 수 없는 주장**이다.

### 5.6 결정면 이방성 (계산 없음, 문헌 인용)

본문 후반은 Golov & Carrasco (ref 58)를 인용해 Li(110)|LPSC(110), Li(111)|LPSC(111) 이 (100)/(221) 보다 **분해가 빠르다**(표면에너지가 높아서), Li(111) 은 Li 이동장벽이 낮다고 서술한다. **이 논문 자신의 계산이 아니다** — 자기 모델은 (100)|(100) 하나뿐이다. 인용할 때 출처를 Golov 로 돌려야 한다.

**기준점**: Lai 실측 **112 원자, PBE-D3, 520 eV, Γ-only, 1 fs → 3.80 h/ps 벽시계 (96 코어 Xeon 9242) = 365 코어시간/ps**. HAML 로 궤적 300 ps 를 뽑는 데 필요한 AIMD 는 **~3 % = 9–10 ps**.

DFT MD 는 대략 N³ 로 커진다 (N=원자수):

| 우리 대상 | 원자수 (추정) | 배율 (N/112)³ | AIMD 코어시간/ps | **HAML 300 ps 총량 (코어시간)** | 96코어 노드 벽시계 |
|---|---|---|---|---|---|
| Li\|LPSCl (재현용 기준선) | 112 | 1.0 | 365 | **≈ 3,900** | ≈ 41 h |
| Li\|**LPSOCl** (우리 62원자 SSE + Li 60) | 122 | 1.29 | 471 | **≈ 5,000** | ≈ 53 h |
| Li\|**b2o3** (우리 128원자 셀 + Li 60) | 188 | 4.73 | 1,726 | **≈ 18,400** | ≈ 191 h (8일) |
| 4계 비교 캠페인 (무도핑/O/Cl-rich/B₂O₃) | — | — | — | **≈ 30,000–35,000** | **≈ 13–15일 (96코어 전용)** |

**우리 기계별 현실성**:
- **KISTI neuron (Slurm)**: 유일하게 위 스케일이 맞는 곳. 단 **walltime 수 시간 제한** → AIMD 를 10 ps 단위가 아니라 **0.5–1 ps 청크로 쪼개 체인 제출**해야 한다. HAML 은 원래 사이클 단위로 끊기니 **구조적으로 궁합이 좋다**(사이클 = 잡 하나). QOS 제출 제한(scancel 직후 재제출 금지) 때문에 **체인 스크립트에 sleep 가드 필수**.
- **gabia (A6000 48 GB, QE-GPU + UMA)**: ⭐ **의외로 HAML 에 제일 잘 맞는다.** 우리 규율상 **pw.x 와 UMA 동시 실행 금지**인데, **HAML 은 원래 DFT 와 MLP-MD 를 번갈아 돌린다** — 동시 실행이 필요 없다. 단 단일 GPU 라 112원자 Γ-only 벽시계가 96코어 노드의 2–5배로 늘어날 위험 → **300 ps 한 계에 4–9일 연속 점유**. 현실적으로 **1개 계만** 가능.
- **kgy (RTX3090 24 GB)**: 112원자 Γ-only QE 는 VRAM 이 빠듯하다. **MTP 학습·LAMMPS MLP-MD 전용 노드**로 쓰는 게 맞다 (CPU 작업이라 GPU 안 씀).

> ⚠ **이 표는 Lai 의 VASP 수치를 N³ 로 늘린 추정이다.** 우리 QE 셋업의 실제 s/step 은 다르다 (PP·컷오프·믹싱이 다름). **첫 할 일은 Li\|LPSCl 112원자 셀에서 pw.x MD 10스텝 벽시계를 재보는 것** — 그 한 숫자면 위 표 전체가 우리 값으로 갱신된다. (코드 수정 아님, 측정만.)

### 9.3 ★★ UMA 로 대체 가능한가 — **판정: 절반도 안 된다. 단, 용도를 좁히면 쓸 수 있다**

HAML 은 **계 전용 MTP 를 그 자리에서 학습**한다. 우리는 **사전학습 UMA-s-1p1(omat)** 을 쓴다. 셋을 나눠 판정한다.

**① 정확도 — △ (검증 안 됨, 경고등 둘)**
- 2026-08-19 실측: UMA 는 DFT 이완 구조를 잘 지킨다 (modelC **+0.92 %**, b2o3 −0.00 %) → **평형 근처 PES 는 믿을 만하다.**
- 그러나 **단일 경로 NEB 장벽 0.528 eV** vs 실험 0.2–0.35 → **장벽을 과대평가**한다. 계면 반응은 결합 절단 = 전이상태 지형이 전부다. **장벽을 부풀리는 모델은 반응을 과소평가한다** — 즉 "우리 계면은 안정하다"는 **틀린 안심**을 줄 수 있다. 방향성 있는 편향이라 더 위험하다.
- ⛔ **Li₃N 금지 판정(2026-06)이 그림자를 드리운다.** 이 계면의 **주 생성물이 Li₃P** 다 (Fig. 4e, Fig. S9e). Li₃P 는 Li₃N 과 같은 **Li-rich 프닉타이드**(둘 다 좁은 갭·이온성-금속성 경계)다. UMA 가 Li₃N 에서 결정론적 편향을 보인 계열이면 **Li₃P 에서도 의심해야 한다.** ⇒ **UMA-MD 로 이 계면을 돌리기 전에 Li₃P 벌크 검증(격자·형성에너지·힘 RMSE)을 먼저 해야 한다. 이건 타협 불가.**

**② 신뢰도 게이트 — ⛔ 이게 결정적이다**
HAML 의 전부는 **γ (외삽등급)** 다. "모델이 자기가 모른다고 말할 때 DFT 로 되돌아간다." **UMA 에는 이에 해당하는 신호가 없다** (단일 모델, 앙상블 없음). 대안 셋:
- (a) **앙상블/committee** → UMA 는 한 모델이라 불가 (여러 체크포인트를 쓰면 상관이 너무 높다)
- (b) **주기적 DFT 단일점 검증** — 프레임 N개 뽑아 힘 RMSE. **사후(post-hoc)라 궤적을 못 되돌린다.** 이미 망가진 궤적을 확인만 할 뿐
- (c) **물리 위생 감시** — 에너지 드리프트, 최소 원자간거리, 배위수 급변. 싸고 즉시 가능하지만 **화학적 외삽은 못 잡는다**
⇒ **UMA-MD 는 "언제 틀렸는지 모르는 채로 300 ps 를 도는" 것**이다. HAML 의 절반은 정확도가 아니라 **이 게이트**다.

**③ 비용 — ✅ 압도적으로 UMA 승**
UMA-MD 는 DFT 가 0 이다. 300 ps 를 몇 시간에 뽑는다. HAML 은 4,000–18,000 코어시간.

**종합 판정**:

| 용도 | UMA 단독 | 판정 |
|---|---|---|
| "어느 도펀트가 계면을 더 빨리 깨나" **정성적 순위** | 가능 (단, Li₃P 검증 후) | ⚠ **조건부 가능** |
| 반응 **산물 동정** (Li₃P/Li₂S/LiCl/Li₃PO₄) | 위험 — Li₃P 편향 미확인 | ⛔ **DFT 검증 필수** |
| 반응 **속도/장벽** 정량 | 장벽 과대평가 편향 | ⛔ **금지** |
| 계면 **에너지·전자구조** | UMA 는 전자구조 없음 | ⛔ (별도 DFT) |
| **논문에 쓸 주장** | 게이트 없음 = 반증 불가 | ⛔ |

**⇒ 권고 경로 (HAML 의 정신만 가져오고 비용은 낮춘다)**:
```
UMA-MD 로 300 ps 궤적 여러 개 싸게 생성  (탐색)
   ↓ 궤적에서 층화표집(반응 전/중/후) 30–50 프레임
QE 단일점 DFT → 힘 RMSE / 에너지 오차 측정   (검증, ~수백 코어시간)
   ↓ RMSE 가 나쁜 구간이 있으면
그 구간만 짧은 AIMD (0.5–1 ps) → 필요하면 MTP 를 그 구간 전용으로 학습
```
이건 HAML 의 축소판이고, **우리 자원으로 실제로 가능하다.** γ 대신 "층화 DFT 검증"이 게이트 역할을 한다 — 사후지만 없는 것보단 낫다.

### 10.1 HAML(하이브리드) vs 파인튜닝+증류(single-shot) — 어느 쪽이 우리에게 싼가

| 축 | **HAML (Lai)** | **파인튜닝+증류 (Zhang, 카드 없음 — 개념 기준)** |
|---|---|---|
| DFT 예산 | 궤적의 ~3 % 를 AIMD 로 (300 ps 당 ~10 ps = 10,000 스텝) | 소량 ab initio 데이터로 사전학습 모델을 파인튜닝 (원리상 **수백~수천 구성**) |
| 언제 DFT 를 쓰나 | **시뮬레이션 도중, 반복적으로** | **시뮬레이션 전, 한 번** |
| 불확실도 게이트 | **있음 (γ)** — 궤적이 새면 즉시 멈춘다 | **없음** (증류된 NEP 도 단일 모델) |

| 우리 스택 적합성 | LAMMPS+MTP 새로 깔아야 함 | ⭐ **우리가 이미 사전학습 모델(UMA) 스택** — 파인튜닝이 자연스러운 연장 |
| 우리 자원에서의 총비용 | 300 ps 한 계에 **4,000–18,000 코어시간** | 파인튜닝 데이터 생성이 **한 번**이라 훨씬 쌈 (수백~수천 코어시간 추정) |

**한 문단 결론**: **평형 근처 물성(전도도·탄성·구조)이 목표면 파인튜닝+증류가 압도적으로 싸다** — 우리 UMA 스택 위에 그대로 얹히고 DFT 를 한 번만 쓴다. **그러나 계면 분해처럼 "학습셋에 없는 화학이 시뮬레이션 도중에 생겨나는" 문제는 파인튜닝으로 못 막는다** — 무엇을 미리 넣어야 할지 알 수 없기 때문이다. 여기서 HAML 의 γ 게이트가 값을 한다. ⇒ **우리 로드맵: 벌크·수송 = 파인튜닝/증류 노선, 계면 반응 = HAML 노선.** 둘을 섞을 수도 있다(파인튜닝된 UMA 를 HAML 의 초기 MLP 로 쓰면 초기 사이클의 비싼 AIMD 를 줄인다 — 이게 Lai 자신이 Discussion 에서 *"integrating HAML with universal large atomic models"* 라고 예고한 다음 단계다).

## 12. ★ 주의 / 한계 / 비판

**① ⛔ Fig. 5f 의 무도핑 Li–S 막대가 자기 SI 와 모순 (가장 큰 문제)**
0 ps 와 280 ps 막대가 **픽셀 단위로 동일**(둘 다 top y=346 px). 같은 논문 Fig. 4e 는 528 ps 에 144, Fig. S14c 는 **20 ps 에 이미 ~150**. "무도핑은 반응 안 하고 도핑만 반응한다"는 그림의 핵심 인상이 **이 막대 하나**에서 나온다. 데이터 재현 불가(비공개)라 오류인지 다른 정의인지 확정할 수 없다 — **그래서 이 논문의 도핑 결론은 인용 불가**로 둔다.

**② ⚠ 도펀트 농도가 서로 다른데 나란히 비교한다**
Se 0.25/f.u. (S 의 5 %) · O 0.25/f.u. (S 의 5 %) · **F 0.5/f.u. (Cl 의 50 %)**. SI 는 이 값들이 *"minimum doping levels achievable within the given supercell"* 이라고 솔직히 밝힌다 — **물리가 아니라 셀 크기가 정한 농도**다. 10배 차이 나는 농도의 세 도펀트를 "누가 더 반응성이 큰가"로 줄 세우는 건 성립하지 않는다.

**③ ⚠ Fig. S15 의 "average CN" 은 물리적으로 불가능한 값을 담고 있다**
Li–(S,Se,O) CN 이 Se 계 **17–19**, O 계 **15–16**. Li–S 배위수 상한은 Li₂S 의 8, 기하학적 상한도 ~12 다. **17 은 배위수가 될 수 없다.** 가장 그럴듯한 해석: **종별 CN 을 더한 값**이다 (Li–S CN 9.6 + Li–Se CN ~8 = 17.6 ✓; O 계 9.6 + 5.5 = 15.1 ✓; F 계는 패널 d 에서 Li–Cl 6.2 + Li–F 5 = 11.2 ✓). 그렇다면 **도핑계가 높아 보이는 건 화학이 아니라 항이 하나 더 더해진 것**이다. 원자 1개짜리 종(Se·O)의 per-atom CN 이 20개짜리 S 의 CN 과 동등한 무게로 더해진다. **정규화 정의가 미기재라 확정 불가** — 하지만 어느 해석이든 이 그림으로 "도핑이 배위를 늘린다"고 말할 수 없다.

**④ ⛔ 부동태화(passivation)를 관측할 수 없는 모델로 부동태화를 주장한다**
SSE 슬랩이 ~1 유닛셀(≈10 Å)인데 20 ps 만에 통째로 분해된다 (Fig. 4d). 보호받을 전해질이 남지 않는다. 관측된 "포화"는 **부동태화가 아니라 연료 소진**이다. 진짜 부동태화를 보려면 SSE 를 최소 3–4배 두껍게(원자수 3–4배 = 비용 27–64배) 해야 한다. **이건 방법의 한계가 아니라 모델의 한계**이고, HAML 로도 못 푼다.

**⑤ ⚠ Li 금속을 포함한 셀에 Γ-only k-mesh**
Li(100) 슬랩은 **금속**이다. ~10 Å 셀에 1×1×1 k-mesh 는 E_F 근처 상태를 심하게 과소표집한다 → 전자밀도·힘에 계통오차. 최소 2×2×1 이 상식이다. 게다가 **그 힘으로 MTP 를 학습**하므로 오차가 MLP 에 그대로 각인된다. (Wu 2026 과 같은 병.)

**⑥ ⚠ NVT + 고정 셀로 부피가 늘어나는 반응을 돌린다**
Li₆PS₅Cl + Li → Li₃P + Li₂S + LiCl 은 부피가 늘어나는 반응이다. 셀을 고정한 NVT 에서는 **압력이 쌓이는데 압력·응력을 한 번도 보고하지 않는다.** 우리 기계 축(C)에서 SEI 팽창은 핵심 변수인데, 이 계산은 그걸 구조적으로 못 본다.

**⑦ ⚠ 무질서 처리 없음**
mp-985592 단일 배열을 그대로 자른다. argyrodite 의 S²⁻/Cl⁻ 4a/4c 무질서는 계면 반응성에 직접 영향을 준다(어느 음이온이 표면에 노출되나). SQS·enumerate 없이 단일 배열 하나로 네 계를 비교하면, **도펀트 효과와 배열 효과가 분리되지 않는다.** 시드/배열 반복도 없다 (계당 궤적 1개).

**⑧ ⚠ 통계 없음**
계당 **궤적 1개**, 시드 반복 0. 유사도 0.933 vs 0.887 같은 차이에 오차막대가 없다. 우리 규율(멀티시드 판정, 단일시드 1.33× 철회 사례)로 보면 **판정 불가 등급**이다.

**⑨ ⚠ Table S2 내부 모순** (§4.6.3) — 528 ps→1 ns 연장 시 AIMD CPU 증가분이 총 증가분보다 크다.

**⑩ ⚠ 재현 불가** — 데이터·코드·학습셋·MTP 파라미터·SOAP 하이퍼파라미터·슬랩 원자수 전부 비공개/미기재 (§4.5 의 10개 항목).

**⑪ ✅ 반대로 인정할 것**: 비용 표는 산술적으로 깨끗하고(§4.6.1), 300 K 시간척도는 충분하며(§4.7), 벌크 전도도 검증(Fig. S10)은 정직하다(자기 AIMD 문헌값이 크게 틀렸다는 걸 그림에 같이 넣었다). **방법론 논문으로서의 값어치는 도핑 결론과 무관하게 살아 있다.**

## 13. 기법 미니사전

- **HAML** (hybrid AIMD + MLP): AIMD 와 MLP-MD 를 사이클로 번갈아 도는 방식. AIMD 는 학습데이터 공급 + 경로 안내, MLP-MD 는 가속. Goddard 그룹의 **HAIR**(DFT-ReaxFF 하이브리드, ref 43)에서 착안.
- **MTP** (Moment Tensor Potential, Shapeev 2016): 국소환경을 모멘트 텐서 M_{μ,ν} 로 기술하고, 그 축약 스칼라 basis 의 **선형회귀**로 에너지를 낸다. 선형이라 학습이 빠르고 **D-optimality 기반 불확실도(γ)를 공짜로 얻는다** — 이게 신경망 MLIP 대비 결정적 장점.
- **extrapolation grade γ / Maxvol**: 현재 구성의 basis 벡터가 학습셋이 span 하는 볼록체 밖으로 얼마나 나갔는지를 재는 수. γ=1 이면 학습셋 안, 크면 외삽. **Maxvol** 은 최대부피 부분행렬을 찾는 알고리즘으로 이 값을 싸게 계산한다.
- **γ_break**: MLP-MD 를 중단시키는 임계 γ. Lai: 고체계 10 / 액체계 20.
- **distribution shift**: MD 가 진행되며 구성분포가 학습셋에서 멀어지는 현상. 반응계에서는 필연 (반응 전 화학종이 반응 후엔 없음).
- **direction bias** (저자 용어): AL 이 "정보량 큰" 구성을 찾다가 실제 반응 경로가 아닌 방향으로 샘플링이 쏠리는 것.
- **SOAP**: 원자 주변 밀도를 구면조화+가우시안 기저로 전개해 회전불변 기술자를 만드는 방법. 두 구조의 SOAP 벡터 코사인 = 구조 유사도.
- **Nernst–Einstein**: σ = n q² D / (k_B T). Haven 비 1 가정 (상관효과 무시) — 우리 규율과 동일.
- **PS₄³⁻ 해체의 지문**: P–S RDF 2.1 Å 피크 소멸 + Li–P 2.5 Å 피크 등장 (Li₃P) + Li–S 2.47 Å 피크 강화 (Li₂S). RDF 세 장이면 SEI 조성을 말할 수 있다.
- **자유음이온 자리 (4a/4c)**: argyrodite 에서 PS₄ 밖에 있는 S²⁻/Cl⁻ 자리. Li 케이지에 둘러싸여 있고 Li 확산에 직접 관여. **PS₄ 안의 S(16e)와 화학이 완전히 다르다.**
