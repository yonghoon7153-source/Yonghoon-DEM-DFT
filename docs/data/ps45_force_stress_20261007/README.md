- 평균 법선력 = full_metrics `fn_<쌍>_mean` (`dem_analysis_core.calc_contact_force_distribution` · 덱 축척 환산 µN = F_deck × 1e6/scale) · 접촉 수 = `area_<쌍>_n`.
  AM–AM 접촉 수 = 8,970 · 5,794 · 3,878 · 2,208 · 733 = 입자–입자 접촉 전체 (553,453 · 558,388 · 558,496 · 562,646 · 535,427) 의 **1.62 · 1.04 · 0.69 · 0.39 · 0.14 %** (0:10 → 10:0).
  ⚠ 정정 10-07: 앞 판 *"0.39 % (7:3) – 1.6 % (0:10)"* 은 최소를 7:3 으로 잘못 적었다 — 최소는 10:0 (0.14 %) · 원장 `SELF-93`.
- 힘 몫의 분해 (같은 full_metrics 값의 산술): **힘 몫 = 접촉 수 몫 × (그 묶음의 평균 법선력 ÷ 전체 접촉의 평균 법선력)** — 전체 평균 = 73.5 · 66.6 · 61.7 · 59.0 · 48.5 µN.
  예 7:3 AM–AM: 0.39 % × (2,556 ÷ 59.0 = 43.3 배) = 17.0 %.  쌍별 평균 법선력은 조성에 거의 무관하다 (SE–SE 29–36 · SC–SC 1,333–1,501 · PC–PC 6,247–7,475 µN) ⇒
  조성에 따른 힘 몫의 변화는 주로 **접촉 수** 에서 온다 (관찰 · 모델 안).  PC–PC 3:7 = 접촉 41 개 (평균이 흔들릴 수 있다 · full_metrics 에 표준편차 없음).
- ⚠ 각주 필수: **"접촉 힘 합의 몫 — 판 하중 분담 아님"** (판 반력 분율로 검증된 양이 아니다 · 하중 분담 두 규약은 CLAUDE.md f_AM 절).
- ⚠⚠ **10-07 — 힘 몫 (크기 합) 은 보존량이 아니다**: 같은 하중이 직렬 접촉 수만큼 여러 번 세어진다 (real14 크기 합 = 단면 하중의 12.19 배).  하중을 누가 지나 = **단면 하중 몫** (`docs/data/ps45_plane_load_20261007/` · real14 AM–AM 74.0 % ↔ 크기 합 몫 33.0 %).  아래 해석 문장의 *"SE 망이 힘 경로의 중심"* 은 크기 합 기준이라 하중 기준으로는 틀릴 수 있다 (real14 SE–SE 하중 몫 3.2 %) — ps45 단면 하중 몫을 재기 전까지 쓰지 않는다 (`SELF-95`).
- 해석 (모델 안 · 크기와 강성 효과를 떼지 않음 — 1저자에게 보고한 문장 · ⚠ 위 표지): 단단하고 큰 활물질끼리의 소수 접촉이 힘의 큰 몫 (힘 사슬) · PC 가 많을수록 활물질 접촉이 줄어 SE 망이 힘 경로의 중심 · 7:3 = AM–AM 몫 최소 · PC ≈ SC 응력 (가장 치밀한 조성과 같은 자리).
