# 영상 레퍼런스 (1저자 11-24)

> 1저자 11-24 *"앞으로 영상 만들때 이 영상들 레퍼런스로 만들어줘 / 보이스같은것들도"*.
> 영상 (발표 · 설명 · 시뮬레이션 영상) 을 만들기 **전에** 이 문서를 본다 — 구성 · 화면 · 자막 · 음악 · 보이스를 아래 레퍼런스에 맞춘다.
> ⚠ 이 환경 (클라우드 세션) 은 영상을 보거나 소리를 들을 수 없다 · 11-24 youtube.com 접속도 안 됐다 (이름 풀이 실패 · 네트워크 허용 목록 밖으로 보임).
> 그래서 아래 칸은 **1저자가 준 설명 · 화면 캡처 · 대본 · 보이스 이름** 으로만 채운다.  채우지 않은 칸을 짐작으로 채우지 않는다 (규율 ⑥ 과 같은 꼴).

- 레퍼런스 보이스 = ⬜ 사람 녹음인지 · TTS 라면 도구 · 목소리 이름 · 말 빠르기 (1저자)
- 이 환경에서 쓸 수 있는 TTS = ⬜ 확인 전 — 바깥 TTS 서비스는 네트워크 허용과 키가 필요하다 (키는 채팅에 붙이지 않는다 · 세션 자격 증명 양식으로).

## 영상을 만들 때 순서

1. 이 문서를 읽고, 빈 칸이 있으면 먼저 1저자에게 묻는다 (짐작으로 정하지 않는다).
2. 레퍼런스의 구성 (장 길이 · 자막 꼴 · 전환) 에 맞춘 대본 초안 → 1저자 확인.
3. 화면 (그림 · 3D · 애니메이션) → 보이스 (레퍼런스 보이스) → 자막.
4. 렌더 → 1저자 확인 → 고침.
- 그림 · 글자 원칙은 `docs/report_making_principles.md` 와 CLAUDE.md 의 논문 · 그림 · 발표 원칙을 따른다.
