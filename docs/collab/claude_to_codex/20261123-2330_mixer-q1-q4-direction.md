## 하지 않는 것

- '코팅이 좋다' 를 새 결과로 쓰지 않는다.
- 소재 비교 (LPSCl ↔ LPSCl1.6) 는 두 SE 의 AFM 값 전에 돌리지 않는다 (1저자 Q2).
- 사다리 · 공정 축 · 코팅 DEM 은 등록 + 1저자 GO 전에 발사하지 않는다.
