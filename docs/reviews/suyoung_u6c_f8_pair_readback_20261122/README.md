# 수영 F8 가압에서 입자 번호 순서의 영향

설정 ①, 원판 49개, 지름당 8셀(F8), 마찰계수 0.5의 개발 대조다. 1저자가 WSL CPU 1개에서 같은 배치와 판 운동을 유지하고 입자 번호를 원 순서와 역순으로 부여해 각각 한 번 가압했다. 한 팔의 물질점 수는 9,653개다. 결과는 아래판 힘을 폭으로 나눈 응력(MPa)으로 제시한다. 판 변위 *u*는 초기 판 높이에서 현재 높이를 뺀 무차원 값이다.

## 동일 변위에서의 결과

| 관측 | 이전 접촉 처리 | 수정 후보 |
|---|---:|---:|
| 네 곡선 공통 구간에서 번호 순서 간 최대 절대차 | 0.09084028877528416 MPa | 7.771561172376096 × 10⁻¹⁶ MPa |
| 그 최대차가 처음 나온 변위 *u* | 0.11100328595220721 | 0.10844684663936854 |
| 이전 최대차 위치에서 원 ID / 역순 ID 반력 | 1.10965834 / 1.20049863 MPa | 0.98036267 / 0.98036267 MPa |
| 원 ID / 역순 ID가 1.2 MPa에 처음 도달한 걸음 | 2,578 / 2,475 | 2,659 / 2,659 |

공통 구간은 *u* = 0–0.11100328595220721, 원표본 2,476개다. 네 변위 격자가 이 구간에서 일치해 보간 없이 대조했다. 수정된 두 팔만 끝까지 비교하면 *u* = 0.11925565145330064까지 2,660개 표본이다. 이때 최대차는 8.881784197001252 × 10⁻¹⁶ MPa다. 같은 걸음에 멈췄고 기존 수치 허용치 안에서 일치했다. 압력값은 1,572개 표본에서 비트가 다르다. 한 배치의 결정적 번호 대조이며 시드 반복에 따른 오차는 미측정이다.

곡선 자체도 이동했다. 같은 번호 순서에서 이전·수정 곡선을 비교한 최대 절대 변화는 원 ID에서 0.12943545 MPa, 역순 ID에서 0.22013596 MPa다. 이 자료로 실험값과의 일치나 이동 방향의 물리적 타당성을 판단할 수 있는 독립 참조값은 없다. 기존 최대 격자차의 고정 변위 *u* = 0.11562281664031926에 이전 역순 팔은 도달하지 않았다. 그 변위에서 네 곡선 비교값은 결측이다.

그림 `docs/reviews/suyoung_u6c_f8_pair_readback_20261122/f8_pair_pressure.png`의 왼쪽은 각 팔의 실제 정지점까지, 오른쪽은 네 팔 공통 구간만 그렸다. 오른쪽 세로축은 같은 변위의 원 ID 반력에서 역순 ID 반력을 뺀 값이다. 반력 차이는 두 번의 관측을 직접 뺀 값이다.

## 신원과 판독

- 계산 핀 `2cf17b1df57396ef01505a72641e01b19629bed5`. 반환 SHA256 `9dbf1dda91de65ecdf83c37497b8be34e9a77c6868512d97b2b4a2a438c0a69b`, 화면 SHA256 `d7cc44e1476b151e34e92c541e6cee8f9ee7e6d9dcb3ce6c6ceb5eb3fc3dd70b`.
- 원 ID와 역순 ID 모두 TARGET_BRACKETED, 각 계산·판독·명령 rc 0. 계산기 기록 시간은 각각 154.56초·150.15초다.
- 이전 두 팔은 순서대로 입자쌍을 처리한 기존 개발 코드의 반환이다. 수정 두 팔은 동시 마찰 접촉 후보 전체를 적용했다. 이 네 곡선으로 228걸음 보완 하나만의 효과를 분리하지 않는다.
- 수정 원 ID의 앞 145개 표본은 145걸음 수집 때와, 앞 228개는 228걸음 중단 때와 각각 바이트가 같다. 이 두 중단 시도는 완결된 추가 반복에 포함하지 않는다.
- 내부 사전 점검에서 세 입자의 6가지 번호 순열은 후보의 물체별 속도가 같았다. 고착과 양방향 미끄러짐을 두 ID 순서로 대조한 14개 관측에서 이전 코드와 비트가 같았다. 별도 해석식·운동량·에너지 대조도 통과했다. 정확한 양·음 전환점은 독립 검토의 두 입자 관측 36개 중 4개에서 확인했다.
