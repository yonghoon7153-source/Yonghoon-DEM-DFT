## ㈜엘앤에프 — 저가 친환경 전구체 + 단결정 합성
- **탄산 공법** 전구체: 수산화 대비 생산량 +20%, 암모니아 정제·알칼리 세정 불필요. 단 소입경 제조 난이(저온 반응 유리), 유기첨가제로 구형도 균일화.
- 소성온도 최적화 → 균일 단결정(Sample D), **방전용량 200.4 mAh/g**. (Sample B/C는 응집·미분 多)

## KETI — 건식 전극 제조 & 전기화학 평가
### 소재
- 단결정 NCM 3종 (XRD 층상 α-NaFeO₂, 불순물 무): **NCM_1**(자체구입 Ni78/Co17/Mn4 EDS, 5.0µm, 응집·표면불순물),
  **NCM_2**(L&F Ni81/Co14/Mn4, 3.3µm, **매끈**), **NCM_3**(L&F Ni86/Co7/Mn6, 3.1µm, 표면 물질).
  → 실험 매핑: No.1=NCM_2, No.2=NCM_3 (`05_ISSUES_AND_FIXES.md` #5).
- **LPSCl** catholyte ~1µm, **σ_ion 2.0 mS/cm** (500 MPa 가압, 60 MPa 체결).
### 건식 공정 (무용매)
- LPSCl가 극성 용매와 반응·분해 → 건식 공정 필수. PTFE(MW 50만) 섬유화로 전극 형성.
- AM 80 wt% 고정, 로딩 **28.3 mg/cm²**. PTFE 함량 변화:
  - **0.2 wt% → 전극 미형성** (PTFE 부족). **≥0.5 wt% → 프리스탠딩 형성** (균열 없음), 2.0%까지 가능.
### 전도도 (`../../db/electrochemistry/ptfe_conductivity.csv`)
- **σ_e = 0.04–0.05 mS/cm** (PTFE 무관 — 도전재 지배). Al/양극/Al, 50 mV.
- **σ_ion**: 0.5% → 0.062, 1% → 0.057, 2% → 0.019 mS/cm. SUS/Li/SE/양극/SE/Li/SUS, 200 µA, SE ref 2 mS/cm. PTFE 2%서 SE-SE 접촉↓로 급감.
### 셀 / 성능
- 셀: PEEK 몰드 ⌀13mm, LPSCl 0.15g 50 MPa → 전극 13mm 500 MPa → Li-In 60 MPa 체결. -50℃ 노점 드라이룸, 30℃.
- **0.1C 용량(NCM_1, PTFE별)**: 0.5% 230.5/198.7, 1% 225.9/194.2, 2% 227.9/196.8 (충/방전 mAh/g). 0.1C는 함량차 작음.
- **율속(0.5% PTFE)**: 1C에서 **NCM_2 150 > NCM_3 135 mAh/g**. 표면 잔류물이 율속 저하 → 표면구조가 성능 지배. 고율 후 0.3C 복귀 시 회복 → 가역적(구조열화 아님).

## 한양대 — 전기화학-기계 모델 + 임피던스 디커플링
- 후막 bimodal 복합양극 기공율 산출(NCM·LPSCl 진밀도): fam↑·대립↑ → 기공↑.
- 대립 다결정(무작위 배향 1차입자, GB 저항) vs 소립 단결정(배향 지배) 구조차 반영 전기화학-기계 연성 모델 구축(7종).
- 설계변수(면용량·fam·P:S·σ_ion/σ_e)별 Li 농도·플럭스·응력·계면박리 정량 분석 (상세 → `02_KICKOFF_DIGEST.md` 결과 동일).
- TLM 기반 이온/전자/계면 저항 디커플링 기법 확립, cycle 전후 기여도 정량.
- 모델정합도 평가법: 3전극 0.2C↑ 충방전 프로파일 vs 모델, RMSE, **60℃**.
