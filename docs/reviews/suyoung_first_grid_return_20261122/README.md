# 수영 U6(c) 첫 격자쌍 · 수정 커널 F8–F16

**F8·F16 모두 가압을 완주했다. 같은 변위의 아래판 압력 오차는 80.86%로, 개발 자료에서 등록 기준 5%를 초과했다.** F12–F24는 미측정이다. 설정 ①을 유지하며 U6(c) 자격과 단계 3은 HOLD다.

## 가압 결과

입자 지름당 셀 수가 8과 16인 두 격자에서 같은 49개 원판의 초기 배치, 원 ID, 마찰계수, 판 속도와 접촉 커널을 사용했다. 공간 격자를 두 배로 세분하면서 물질점 수는 9,653개에서 39,053개로 늘고 시간 간격은 절반이 됐다. 결과는 이 조합에 대한 개발 계산 각 1회다. 반복에 따른 불확실성은 미측정이다.

공통 구간은 *u* = 0–0.11925565다. 판독은 두 팔이 실제로 도달한 변위 원표본의 합집합에서 각 곡선을 선형 보간했다. 이 구간 끝에서 차이가 가장 컸다. 최대 절대차 0.53665760 MPa를 공통 구간의 F16 최대 절대 반력 0.66369911 MPa로 나누면 0.80858568이다. 5,319개 비교점 중 3,614개가 5% 폭(0.03318496 MPa)을 넘었다. 이 점들은 한 번의 연속 계산에서 얻은 표본이다. 등록식은 `docs/reviews/suyoung_u6c_force_rule_20261122/README.md`에 있다.

## 첫 초과와 이전 커널 대조

첫 초과는 *u* = 0.01208702447, F16 539걸음에서 관측됐다. F16은 0.01144339 MPa이고, 같은 변위의 F8은 269·270걸음 사이를 보간한 0.04504276 MPa다. 직전 공통 표본의 차이는 0.03283081 MPa, 첫 초과 표본의 차이는 0.03359937 MPa다. F8 전체 추적과 F16의 0–4,802걸음은 앞 반환과 바이트가 일치했다. 따라서 4,803걸음의 3체 접촉 보완을 거치기 전부터 이미 두 곡선에 차이가 있었다.

별도 사후 대조에서 순차 접촉을 쓰던 이전 완주 F8·F16과 이번 두 곡선을 모두 포함하는 공통 구간(*u* ≤ 0.11562282, 5,157점)을 구했다. 같은 구간에서 최대 격자 차이는 이전 0.56597733 MPa, 이번 0.45340952 MPa다. 커널 변경 전후의 같은 격자끼리 보면 최대 이동은 F8에서 0.12943545 MPa, F16에서 0.00001034 MPa였다. 이전 두 곡선은 `docs/reviews/suyoung_u6c_wall_return_20261122/README.md`, 네 곡선 대조 수치는 `docs/reviews/suyoung_first_grid_return_20261122/historical_joint.json`에 기록했다. 실제 시료에 더 가까운 곡선을 정할 독립 기준값은 없다.
