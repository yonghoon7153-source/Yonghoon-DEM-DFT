## 3. 질문

- **Q1 초안 1 판정 반영** — 쪽 글이 `K50Y4-02` 최소 문구 · `K50Y4-03` 9쪽 · 수정 계획 §2 #1–#12 를 담는가.  넘친 문장 · 빠진 한정어.
- **Q2 `K50Y4-01` 프레임 규칙** — 비교 프레임 = 이완 끝 같은 step 세트 (러너 소비자 시험 9/9 · 같은 step 요구 · contact · mesh 결손 · step 엇갈림 · 머리 TIMESTEP ≠ 이름 거부) · 압력 도달 순간 = NOT_AVAILABLE 표기가 판정문 §4 최소 해결을 채우는가.  "같은 상태" 부분은 Q3 로 넘긴다.
- **Q3 `KG50-20` (새 P1 · 추정)** — 이완 낙폭 144.4 · 20.4 · 9.3 MPa 를 affine 감쇠 저항 어림 γ·N·v/(2A) = 168.5 · 22.4 · 7.7 MPa (덱 상수 γ 0.5 · v 0.01 · A 0.0025 · N = 정지 때 원자 수) 와 대조해 *"정지 판정 300 MPa 에 감쇠 저항이 섞였고, 판이 멈추면 사라진다"* 고 추정했다.  (a) 이 추론이 성립하는가 · 다른 설명 (D1 이완 첫 1,000 step 의 운동에너지 0.065 · 원자 5 개 소실 · 판 압력 최저 112 MPa 뒤 156 으로 회복) (b) 이번 보고의 처리 — 우리 기본 = D1 을 모든 그림에 두되 D1 의 접촉 · 피복 · 수송 · 입자 응력 값마다 *"끝 판 압력 156 MPa"* 표지 + 판정 보류 · ε_sphere 도 *"정적 압력이 다른 상태에서 굳은 값"* 한정 (1저자 결정 대기 — 쪽 글 머리 표지) — 충분한가, 아니면 D1 을 접촉 · 수송 그림에서 빼야 하는가 (c) 최소 직접 확인 방법 (예: 마지막 압축 체크포인트에서 정지 step 까지 덤프를 켜고 다시 돌려 γΣv_z 를 센다 = 별도 실행 승인).
- **Q4 D0.7 압축** — 덱 계획 N 488,291 → 어림 488 MPa > 목표 300 MPa.  감쇠 저항만으로 정지 판정이 날 수 있다면 D0.7 압축 (NP 56 · 5–6 일 추정) 을 지금 덱으로 내는 것은 비교 가능한 상태를 만들지 못한다고 본다 (추정).  (a) 압축 본 제출을 보류하는 것이 맞는가 (b) 덱 처방 방향 (정지 판정을 정적 압력으로 · 감쇠 계수 · 판 속도 · 정지 뒤 감쇠 끈 상태에서 재가압 등) 중 등록 · 재검토에 올릴 후보 — 이번에 정하지 않는다 · 방향만.
- **Q5 그림** — (a) 축 범위를 자료에서 정하고 모든 값 · 값 글이 축 안에 있는지 보는 자동 검사 (b) 진단 그림 `diag_relax_drop_vs_N` 의 정의 · 표기 (*"어림 γNv/(2A) (affine 가정)"*) (c) 3쪽 겹침 문턱 그림을 예비로 돌림 (d) 5쪽 f(1)/f(3) = Hertz · Physics 두 값과 손익분기 2.217 의 *"판정 보류"* 표기.
