# ADR 0010 — 北方領土는 그리지 않는다

- 상태: 채택 (2026-09-28)
- 관련: `scripts/build-geo.mjs` (`HOKKAIDO_ID`, `NORTHERN_TERRITORIES`), `tools/og-card.mjs`, 체크리스트 #84

## 맥락

지도 원본(地球地図日本, 国土地理院)은 北方領土(国後島 · 択捉島 · 色丹島 · 歯舞群島)를 일본 영토로 그린다. 그래서 첫 화면의
北海道 오른쪽 위에 섬들이 길게 붙어 있었고, 링크 미리보기 카드(`public/og.png`)의 작은 지도에도 들어 있었다.

톡방 피드백(우파파): 러시아가 실효 지배하고 영토 분쟁 중인 곳이라 "넣기도 빼기도 애매하다 — 독도를 저 지도에 표시해 놓은 느낌",
"의도적으로 넣은 건지 물어본 것". 사용자: "제가 배운 것도 없는 부분이니까 우선 빼놓고 만드는 게 좋을 것 같아요."

## 결정

1. **北方領土는 그리지 않는다.** `build-geo.mjs` 가 北海道의 폴리곤 중 중심이 145.5°E 동쪽 · 43.3°N 북쪽인 것을 뺀다
   (根室 앞의 작은 섬 ユルリ · モユルリ(43.2°N)는 남는다). 지도 · 링크 카드 · 北海道 확대 범위(bbox)가 모두 이 데이터를 쓰므로 한 곳만 고친다.
2. 정치적 판단이 아니라 **배우는 지도의 범위 결정**이다: 사용자가 배운 적 없는 지역이고, 흔히 보는 일본 지도도 빼고 그리는 경우가 많다.
   넣기로 다시 정하면 `NORTHERN_TERRITORIES` 필터만 지우면 된다.
3. 지도 출처 표기(地球地図日本)는 그대로 — 데이터를 가공했다는 뜻이지 원본의 범위를 그대로 옮겼다는 뜻은 아니다.

## 결과

- 北海道의 오른쪽 위가 根室半島 · 知床半島에서 끝난다. 北海道를 열었을 때 확대 범위가 조금 커진다.
- 링크 미리보기 카드를 다시 만들어(`node tools/og-card.mjs`) `og.png?v=` 를 올렸다 — 카톡은 미리보기를 한동안 기억하므로 `nihon share` 의 캐시 초기화 절차.
