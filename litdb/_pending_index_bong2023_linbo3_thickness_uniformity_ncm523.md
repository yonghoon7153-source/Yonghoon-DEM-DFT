**6. ⛔ 이식 안 된다 / 인용 금지**

1. ***"LiNbO₃ 는 ≥9 nm 여야 한다"*** — **문턱이 측정된 적 없다**(두께·균일도 교락). 저자도 *"might not be the optimum"*, "≈18 nm" 는 **Ohta[26] 의 LiCoO₂ 데이터에서 끌어온 추정**이라고 명시.
2. ***"균일도를 정량화했다" / "피복률 X %"*** — **정량 지표 0**. AES 색 지도뿐이고 문턱이 **5 nm**다.
3. ***"두꺼운 코팅은 수송 대가가 없다"*** — R3 는 **분리되지 않은 합**이다(§H 두 번째 행 참조).
4. **σ ≈ 2 mS/cm 를 SE 물성으로** — **벤더 스펙**, 이 논문 측정 아님.
5. **σ_e 를 셀 전극의 전자전도로** — **VGCF 없는 다른 펠렛**에서 쟀다.
6. **XPS % 를 절대 분해량으로** — 영역 내 **상대 면적분율**이고 `P₂Sₓ` 가 before/after 에서 **다르게 분류**된다.
7. **Nb-3 의 Li₂S 27 % 를 "SE 불순물"로** — **7→27 % 로 늘었다**. 불순물은 안 는다(저자 귀속이 자기 데이터와 충돌).
8. **`Fig. 6` 패널 문자를 캡션대로** — **캡션이 틀렸다**(실제 a=S2p-before / b=S2p-after / c=P2p-before / d=P2p-after).
9. 우리 유도값(§3)을 **논문 보고값처럼** — 전부 **(우리 유도, 논문 미보고)** 로 표기.
