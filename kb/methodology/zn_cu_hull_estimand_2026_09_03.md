# 보고량 카드 — Cu–Zn convex hull (Zn ALZIB C1 후속)

> ⛔ **계산 전에 채운 카드다.** 리뷰에 보내는 것은 번들이 아니라 아래 §1–3 이다.
> §3 이 통과해야 잡을 던진다. 결과를 보고 §4 게이트를 고치지 않는다.
>
> ⚠ **수계 Zn 계다. 우리 황화물 SE 수치와 같은 표에 놓지 않는다** (인수인계 §2 금지).

---

## 0. 왜 이걸 하는가 — C1 이 남긴 자리

C1 상 지문표(`db/properties/zn_cu_phase_fingerprint_2026_09_03.{csv,json}`)가
**43° ± 1° 안에 8개 상이 1.47° 폭으로 겹친다**는 것을 확정했다. Cu–Zn 간격은 **0.097°** 다.
회절 기하가 강제하는 것이라 분해능으로 못 푼다.

C1 스코프 정정(인수인계 §2)이 이미 판정했다 — **DFT 격자상수로 이 간격을 가르려는 것은 틀렸다**
(DFT 격자 오차 ~1 % = 2θ 0.3–0.4° ≫ 0.097°). 실험 문헌 격자상수가 더 정확하다.

그래서 **DFT 가 실제로 기여할 수 있는 자리는 hull 하나**다: 겹치는 후보들 중 **어느 것을
애초에 후보에서 뺄 수 있는가**.

---

## 1. 무엇을 원하는가 (한 문장)

> 43° 겹침 영역의 Cu–Zn 상 후보 중, **열역학적으로 너무 불안정해서 피크 귀속 후보에서
> 뺄 수 있는 것이 있는가.**

⚠ 원하는 것은 **"무엇이 생기는가" 가 아니다.** 그건 이 계산이 답할 수 없다 (§3, §5).

## 2. 그것을 재는 양 (식으로)

상 `p` 하나마다 하나씩:

```
E_hull(p) = E(p)/atom − E_hull_line(x_Zn(p))      [eV/atom]
```

- `E(p)` : 상 `p` 의 전 에너지 (UMA-omat 단일점, 이완된 구조)
- `E_hull_line(x)` : 같은 방법으로 만든 Cu–Zn 이성분 convex hull 의 조성 `x` 에서의 값
- 참조 상태 = **같은 방법으로 계산한 fcc Cu · hcp Zn** (끝점)

**보고량은 스칼라가 아니라 상별 벡터** `{E_hull(p)}` 다. 집계하지 않는다 —
집계하면 "어느 상" 이라는 질문이 사라진다.

대상 상 (43° 창 + 진단창 31–39° 에 걸리는 것 전부):

| 상 | 조성 | 왜 |
|---|---|---|
| Cu | fcc | 끝점 · 기판 |
| Zn | hcp | 끝점 · 전착물 |
| CuZn (β′) | B2 | 43.282° — Cu(111)·Zn(101) 사이에 끼는 그 상 |
| Cu₅Zn₈ (γ) | I-43m, 52원자 | 발표자가 "suggest" 만 한 합금 후보 |
| CuZn₅ (ε) | | 진단창 37.94° |
| Cu₂O | | 진단창 36.42° — 산화물 오염 후보 |
| ZnO | | 진단창 31.77/34.42/36.26 |

> ⚠ Cu₂O·ZnO 는 Cu–Zn 이성분 hull 위에 없다 (O 가 들어간다). **별도 3성분 hull 이 필요**하고
> 이번 판에서는 **하지 않는다** — §5 에 "미포함" 으로 명시한다.

## 3. 🔴 이 계에서 이 양이 **잘 정의되는가** — 여기가 본체다

이건 흡착 계산이 아니라 **스크리닝**이라 템플릿 §3 의 여섯 물음(전자상태 모듈)을 그대로 쓰지
않는다. 템플릿 지시대로 **이 계산 종류의 위험요인으로 바꿔** 채운다.

| 물음 | 답 | 근거 |
|---|---|---|
| **① 0 K hull 이 상온 안정성인가?** | **아니다.** 이게 제일 큰 위험이다. | β-CuZn 은 **무질서 bcc 로 고온에서 안정**하고 β′(B2 규칙상)은 저온상이다. 0 K hull 은 배치 엔트로피를 아예 안 본다. γ-brass 는 0 K 바닥상이라 이 문제가 덜하다. |
| **② 전착이 평형 과정인가?** | **아니다.** | 전기화학 전착은 과전압으로 구동되는 **속도론** 과정이다. hull 위 상도 생길 수 있고, hull 아래 상도 안 생길 수 있다. ⇒ hull 은 **생성 예측이 아니다.** |
| **③ UMA 가 금속 Cu–Zn 에 검증돼 있나?** | **모른다. 이 판의 최대 불확실성.** | UMA(omat)는 우리 repo 에서 **LPSCl 계 MD 로 검증**됐고 **Li₃N 에는 금지**돼 있다(2026-06 결정론적 편향). 금속 금속간화합물은 **둘 다 아닌 영역**이다. ⇒ §4 에 외부 대조 게이트를 건다. |
| **④ 어느 구조를 쓰는가 (admissible state 여럿)** | **MP 엔트리 구조 그대로.** 우리가 손으로 만들지 않는다. | γ-brass 52원자 basis(I-43m 4개 Wyckoff)를 검증된 출처 없이 만들면 그 자체가 틀린 값이 된다 (C1 이 이미 강도를 `null` 로 둔 이유). MP 는 검증된 Wyckoff 를 준다. **같은 조성에 MP 엔트리가 여럿이면 그 조성의 최저 하나**를 쓰고, 그 선택을 산출물에 적는다. |
| **⑤ 끝점과 대상이 같은 방법인가?** | **예 — 전부 UMA-omat 단일점.** | `--mode uma` 가 우리 구조와 MP 경쟁상을 **한 방법으로** 다시 계산한다. `--mode mp` 는 MP 에너지와 섞여 QE-vs-MP 혼합이 된다 — 쓰지 않는다 (b2o3 선례). |
| **⑥ 자성이 문제인가?** | **아니다.** Cu·Zn 둘 다 비자성(d¹⁰). | Nd·Ni 계와 달리 자기 basin 이 여럿이 아니다. 이 축은 이 계에서 위험이 아니다. |

**판정 규칙 (회신 N)** 적용: admissible state 가 여럿인가 → **구조 선택**에서만 여럿이고,
집계 규칙을 ④에 **명시**했다 (조성별 MP 최저 · 선택을 기록). 스칼라가 아니라 **상별 벡터**로
보고하므로 "무엇으로 집계하나" 문제가 애초에 생기지 않는다.

⇒ **§3 판정: 이 보고량은 정의된다.** 단 ①②가 그 **의미를 좁힌다** — §5 가 그 범위다.

## 4. 검증 게이트 — 결과를 보기 전에 정한다

| # | 게이트 | 기준 | 어기면 |
|---|---|---|---|
| G1 | **끝점 재현** | fcc Cu · hcp Zn 이 hull 위(E_hull = 0)에 있다 | 끝점이 안 서면 hull 자체가 무의미 — **전량 폐기** |
| G2 | **외부 대조 (UMA 신뢰도)** | γ-Cu₅Zn₈ 과 β′-CuZn 이 **둘 다 E_hull ≤ 50 meV/atom** | 넘으면 UMA 가 이 계에서 못 쓴다는 뜻 — 실험상태도(둘 다 실재하는 평형상)와 어긋난다. **hull 인용 금지**, DFT 로 재계산해야 함 |
| G3 | **구조 출처** | 모든 경쟁상이 MP 엔트리 (손으로 만든 basis 0개) | 하나라도 손제작이면 그 상 **빼고** 다시 |
| G4 | **판정 바닥** | 상 간 차이 **50 meV/atom 미만은 "차이 없음"** 으로 읽는다 | b2o3 선례가 MLIP 오차를 "수십 meV/atom 가능" 으로 기록 — 그보다 촘촘한 순위를 주장하지 않는다 |

⚠ G2 는 **양성 대조**다. 답을 아는 계(실험적으로 존재하는 두 상)로 방법을 먼저 시험한다.
이게 통과 못 하면 나머지 숫자는 볼 필요가 없다.

## 5. 무엇을 주장할 것인가 / 무엇은 주장하지 않는가

**나오면 말할 수 있는 것**
- "상 X 는 0 K hull 에서 Y meV/atom 위에 있다" (같은 방법 안에서의 상대 위치)
- G2 를 통과했다면: "43° 창의 Cu–Zn 후보 중 **열역학적으로 배제되는 것은 없다/있다**"
  — 즉 **피크 귀속 후보 목록을 좁힐 수 있는가**에 대한 답
- 진단창(31–39°) 설계에 이 결과를 반영: 어떤 상을 굳이 안 찾아도 되는가

**나와도 말하지 않을 것**
- ⛔ "이 상이 **생긴다** / 안 생긴다" — 전착은 속도론이다 (§3 ②)
- ⛔ "상온에서 안정하다" — 0 K hull 이다 (§3 ①)
- ⛔ 상 간 순위를 50 meV/atom 보다 촘촘하게 (§4 G4)
- ⛔ 절대 형성에너지를 **문헌값과 나란히** — UMA 절대값이지 DFT 가 아니다
- ⛔ Cu₂O·ZnO 에 대한 어떤 hull 진술도 (3성분 hull 미수행 — §2)

**이 값과 한 표에 놓으면 안 되는 것**
- 우리 황화물 SE 의 어떤 hull 값도 (b2o3 37.5 meV/atom 등) — **다른 계·다른 캠페인**
- C1 지문표의 2θ 값 — 그건 **실험 문헌 격자상수** 기반이다. hull 은 DFT 이완 격자를 쓴다.
  ⛔ **DFT 격자를 지문표로 역수입 금지** (인수인계 §2 정정: 2θ 오차 0.3–0.4° ≫ 0.097°)

## 8. ⛔ 이 카드가 **못 하는 것**

- 계산이 맞는지는 안 본다. **질문이 성립하는지만** 본다.
- 통과했다고 결과가 옳은 게 아니다 — 옳을 **자격**이 생길 뿐이다.
- ZHS(Zn₄SO₄(OH)₆·xH₂O) 는 이 카드 밖이다. 수화수 `x` 가 미정이라 조성이 안 정해지고,
  hull 에 넣으려면 그것부터 정해야 한다. C1 지문표의 ZHS 행(PDF #00-039-0690)과는 **별개 작업**이다.
