## 1. AREA-12 — 항등식은 살아남는다

위치: 면적 선택·clamp `network_conductivity.py:335`, sim→µm `:279`, cap `plastic_coverage.py:361`.

L=max(A_H,A_L), U=min(A_T,A_V), C=πR²라 하면,

```text
min(max(L, min(U, 2C)), C)
  = max(min(L,C), min(U,C))
  = min(max(L, min(U, C)), C).
```

Lo=C와 A_tabor=A_volume=C도 이 등식 안에 들어간다. 양의 같은 scale이면 min(r₁,r₂)·scale=min(r₁·scale,r₂·scale)이므로 생산의 R_min 대응도 맞다. **cap 외에 하한·거부 정책·단위·재료식·ψ를 바꾸면 이 증명은 적용되지 않는다.** 유한한 양의 물리 입력, overflow/underflow 없는 영역에 한정한다.

실제 `film_area_from_overlap → build_network → solve_network` 대조: r=.5/6 µm, δ=.2 µm, native A=.04 µm², scale=1000.

| 경로 | Rc 전→후 | R_total 전=후 | σ_eff/σ_bulk 전=후 |
|---|---:|---:|---:|
| Physics | 0→0 | 4.0385566809568445 | 0.004761792578385452 |
| Hertz | 4.4311346272637895→동일 | 8.469691308220634 | 0.002270539566430720 |

전압·전류도 같았다. Hertz 가지는 335행에서 native contact_area를 선택하므로 Physics cap이 활성 저항에 들어가지 않는다. 이온·전자·열의 mode별 생산 및 both 출력에서도 이 구분이 유지된다. no_delta, import fallback, 탄성 조기 반환은 cap 전환을 타지 않는다. 실제 경계 시험에서도 반례가 없었다.

20,000점 감사는 면적 변화 3,112건, 설명 안 되는 a_eff 차이 0, ψ 분기 차이 0을 재현했다. 다만 bitwise/ULP 분해는 이 환경에서 19,944/56으로 저자 숫자와 1건 다르다(최대 1 ULP). 이를 플랫폼 독립 봉인으로 쓰지 않는다. 양수 log-uniform δ 스윕은 δ≤0·정확 동률·fallback을 시험하지 않으므로 별도 경계 시험이 필요하다.

**σ 불변을 모든 출력 불변으로 확대하지 말 것.** 같은 함수 실행에서 R_Maxwell은 0.7071067811865475→1.0, A_used 계열은 절반으로 변한다. 현재 Physics σ의 활성 항은 아니지만 진단 필드는 변한다. A_surface 동결과 A_transport 노출 시 필드 의미를 분리해야 한다.

## 2. AREA-09 — estimand는 맞는 계열이다. 정량 정확도는 별도다

### 문헌 대조

Yovanovich 등(1998) p.171 식(10)–(11)은 R_total=R_c+R_1D로 분해하고, R_1D에 각 층의 길이/(kπb²)와 외부 경계 저항을 둔다. 따라서 **bulk를 빼는 것 자체가 잘못된 estimand는 아니다.** 이번 코드는 외부 경계 저항 없는 양측 tube의 합을 계산한다. 대칭 기하의 두 반쪽을 연결한 문제와 문헌의 1-D 성분 제외 정의가 대응한다. 단, source의 isothermal/isoflux 조건과 유한 길이를 구분해야 한다.

Yovanovich(1982) p.86 식(1)–(3)은 두 측 저항을 더하고 ψ를 **곱한다**. 같은 페이지는 단순 ψ=(1−a/b)^1.5의 조건을 0<a/b≤0.3으로 적는다. 따라서 큰 s까지의 "참값"이라는 표현은 안 된다.

독립 기준해가 정당화하는 것은 **그 기하를 전제한 ψ 배치 오류를 분리해 시험하는 S3**다. b=r_min, 구 입자의 경계, 실제 전류 patch가 그 원통과 같다는 것까지 정당화하지 않는다. 재적합·등록된 지수 변경의 승인도 아니다.

### 스냅과 이산화

`constriction_reference.py:151`의 축대칭 환상 면을 실제 조립해서 읽었다. s=.3, nr300에서 열린 면적은 **0.28274333882308145=πa_eff²**다. x-y Cartesian 원판의 계단 근사 문제가 아니다. a_eff=k·dr에 대한 원판 면적은 정확하고, ψ와 Holm에도 같은 a_eff가 들어간다. 요청 a의 양방향 최근접 스냅과 flux 이산화 오차를 혼동하면 안 된다.

기본 nr300/nz600/L4의 **dz/dr=4**다. bulk 해는 z선형이라 거의 정확해도 aperture edge 오차는 상쇄되지 않는다. 145행의 "이산화 오차가 상쇄"는 bulk 성분에만 한정해야 한다.

- s=.05, nr120, L2, a_eff 고정, nz=240/480/960:
  R_c=**10.312428841112 / 9.911849459591 / 9.774496269339**.
- s=.3, nr120, dz=dr 고정, L2→4:
  R_c=**0.993695104997→0.993695393434**.
  이 점의 길이 효과는 작지만 이를 모든 s의 오차 상한으로 삼지는 않는다.
- s=.9, L2, dr=dz, nr=120/240/480:
  R_c/(ψR_H)=**0.6115386104 / 0.5941293742 / 0.5854742837**.

큰 s에서 세분화가 비를 1로 올리지 않고 더 내린다. 따라서 "현재 수치해의 과소가 전부이며 세분화하면 ψ근사와 일치할 것"이라는 설명은 이 경로에서 지지되지 않는다. 큰 s의 ψ근사 오차라는 해석이 강해지되, 위 표는 엄밀한 연속해 오차 경계는 아니다.

## 3. AREA-11 — 16/9는 맞지만 "실측 오차 16/9"가 아니다

### P2-R2-07 — 계수비·수치해 오차·영향 쌍이 섞였다

위치: 기준해 검사 출력 `:314`, σ_AM 반경 의존 `network_conductivity.py:111`, min 선택 `:402`.

양의 유한 σ₁,σ₂, 동일 a와 동일 ψ>0에서

```text
R_min / R_series
= [ψ/(2a minσ)] / [ψ(1/σ₁+1/σ₂)/(4a)]
= 2 maxσ/(σ₁+σ₂) ∈ [1,2).
```

이것은 재료 계수의 비다. 현 생산의 역수 ψ까지 포함한 전체 오차 상한이 2라는 뜻은 아니고, ψ=0에서는 이 저항비 자체가 0/0이다.

실제 기준해(s=.1,nr200,nz400,L3,σ=1:8):

| 양 | 값 |
|---|---:|
| R_c 수치해 | 2.532536059406427 |
| ψ·R_H, 직렬식 | 2.401354598190363 |
| ψ·R_H, min식 | 4.2690748412273125 |
| 수치해/직렬식 | 1.0546281091992498 |
| 수치해/min식 | 0.5932283114245780 |
| min식/수치해 | **1.6856916312685766** |

(수치해/직렬식)/(수치해/min식)=**16/9**는 공통 수치해가 소거되어 정확하다. 수치해를 999로 바꿔도 같은 16/9다. **독립 검증은 직렬비가 1에 가까운 정도와 격자 수렴이고, 16/9 일치 자체는 아니다.**

"전자 AM_P–AM_S만"도 틀렸다. 실제 build_network에서:

- AM_P6µm–AM_S2µm: σ_rel=.16139047779640892/1, min/series=**1.7220737023733361**.
- **AM_P6µm–AM_P2µm**: σ_rel=.16139047779640892/.5, min/series=**1.5119661282874150**.
- generic AM–AM: σ_rel=1/1, 해당 차이 없음.

같은 AM_P도 반경이 다르면 영향받는다. 실제 코퍼스에 그런 쌍이 몇 개인지는 별도 census이며 여기서는 미측정이다.

minσ를 **고정된 직렬 기준에 대한 보수적 저항 시나리오**로 유지할 수는 있다. 하지만 "협착이 연한 쪽에 있다"만으로 양쪽 반공간의 저항을 모두 minσ로 바꾸는 식이 유도되지는 않는다. 연한 쪽에 국소층을 두려면 그 형상·두께·σ·경계조건이 필요하다. 반대로 직렬식도 해당 두 반공간/공통 patch 모델의 식이지 모든 실제 구 접촉의 참값은 아니다.

열의 `k_weight:341`는 별개다. 정상 AM+SE thermal 경로에서는 σ_rel=1이고 AM–SE 가중은 이미 조화평균이다. q=k_AM/k_SE=5.714285714285714, k_weight=1.702127659574468이고,

```text
1/(2 k_weight a) = (1/q+1)/(4a).
a=1에서 양쪽 모두 0.29375.
```

따라서 이번 minσ 보정을 열에 다시 얹으면 이중 보정 위험이다. 이것은 열 bulk 모델 전체에 대한 승인도 아니다. 정상 SE-only 이온 경로의 σ_rel=1/1에는 AREA-11 계수 문제가 없다.

| 3.5% | 0% | BOTH_REJECTED |
| 3.5% | 4% | **h0: 실질적으로 안 움직인다** |
| 7% | 8% | **h0** |

산문은 반대로 "ρ>3%이면 h0가 사라진다"고 한다. 산문을 우선하는 fail-closed 구현은 위 h0를 차단할 수 있다. 따라서 **현재 판정기가 false-green을 냈다고 주장하는 것이 아니다. 동일 등록에서 표를 구현한 것과 산문 guard를 구현한 것이 다른 결론을 낸다는 새 P1 명세 결함**이다.

ρ 아래 변화를 "구분하지 못한다"는 논리는 가능하다. 그러나 그 라벨은 **미식별**이지 "실질적으로 안 움직인다"가 아니다. 숫자 불확실성이 클수록 무효과 구간을 넓혀서는 안 된다.

권고: 과학적 3%/10%는 고정하고 수치 불확실성 상태를 분리한다. ρ>3이면 최소한 h0를 발행하지 않는 명시적 우선 규칙을 둔다. 더 강하게 d±오차 구간으로 판정하려면 그 오차가 실제 bound라는 근거부터 필요하다. 현재 ρ는 오차 상한이 아니라 수치 민감도 진단이다.

반복 두 번의 0은 재현성이지 정확도가 아니다. tol을 한 번 조였는데도 0이라는 것 역시 기하·단위·이산화 오차를 배제하지 않는다. `NC:669`는 tol/atol 분기와 fallback을 갖고 있어 "tol 10배"만으로 실행 규약도 확정되지 않는다. solver 경로·라이브러리·실제 rtol/atol·수렴 상태·비교 분모·채널별 ρ를 먼저 명시해야 한다. 이번 리뷰는 ρ=0을 실측했다고 주장하지 않는다.

### P2-R2-02 — 상태 분류 완료와 전체 중앙값 식별은 다르다

위치: OK/OLD_ZERO/REFUSED `:275`, 분류 완료 조건 `:279`.

14건 OK의 |Δ|=0, 16건 REFUSED라 하자. 모든 행은 분류됐지만 전체 30건의 중앙값은 미정이다. 미정 값이 모두 0이면 중앙값 0, 모두 100%이면 중앙값 100%다.

문서는 REFUSED를 버리지 말라고 이미 적었으므로 "반드시 OK만으로 판정하도록 지시했다"는 비판은 부당하다. 정확한 결함은 **그 혼합 상태에서 무엇을 판정할지 아직 정의하지 않았다는 것**이다. 전체 상대차 판정은 보류하거나, 사전 정의된 미정값 sensitivity가 결론을 가르지 못할 때만 제한적으로 발행해야 한다. OLD_ZERO는 상대차 estimand 밖이므로 별도의 절대차 결과 및 대상 집합을 명시한다. OK subset 중앙값에 전체 코호트 라벨을 붙이면 안 된다.

### 중앙값 분산과 S2 개정

고정된 30건의 기술 통계가 목적이라면 표본추론용 SE를 억지로 붙일 필요가 없다. n, 가운데 두 순서통계량(15·16번째), IQR, 전 케이스 Δ, 수치 민감도를 보고한다. leave-one-out 변화는 영향 진단이지 모집단 신뢰구간이 아니다. 더 넓은 설계 모집단을 추론하려면 의존·층화에 맞춘 별도 추론 규약이 필요하고, 30건 iid bootstrap을 자동 적용하면 안 된다. **S3 미실행 상태에서 중앙값 분산을 수치로 만들어 낼 수는 없다.**

S2 하향 예상 `:326`은 cap-only 항등과 양립하지 않는다. **v2를 지우지 말고 v3 amendment에서 지식 획득 시점과 증명을 기록해, S2를 solver 불변 음성대조로 바꾸는 것이 맞다.** 항등식으로 예정된 0을 독립적 물리 효과 측정으로 포장하지 않는다. 하한 거부·면적 단위 수정을 함께 넣을 경우에는 별도 전환이다. S3의 상향은 가설로 남길 수 있으나, 0<ψ≤1e−4 cutoff에서 옛 0이 양수로 바뀌는 분기는 반대 방향도 허용한다.

### P2-R2-05 — geom 면적을 절반으로 바꿔도 전체 selftest PASS

위치: geom `:361`, "전 결속" 주장 `:1030`, 핀 목록 `:1033`.

7핀의 binding은 hertzian/tabor/elastic/volume 네 종류다. **transition은 regime이지 binding이 아니다.** 새 volume 핀은 실제 volume 변이를 잡았다. 또 별도 검사⑦에는 liggghts가 있으므로 "검사 전체에 liggghts가 없다"는 지적은 하지 않는다. 그러나 geom 수치 핀은 없다.

실제 생산 한 줄을 격리 메모리에서 2π→π로 바꾼 뒤 전체 selftest는 **PASS, rc=0**. r₁=.5e−6m,r₂=6e−6m,δ/R*=.5의 함수 출력은

```text
1.5707963267948965e−12 → 7.853981633974483e−13 m²
binding=geom → geom,  A 비=0.5
```

로 변한다. 2π→4π도 PASS인데 A 비=**1.6858090504450243**이다. **표면 채널 불변을 selftest만으로 증명할 수 없다는 반례**다. 이 변이가 현재 σ까지 움직인다는 주장은 아니다(§1 clamp가 가릴 수 있다). geom legacy 핀과 binding/regime 별도 coverage 목록을 추가하는 것이 해제 조건이다.

### 반경 역산·lens 경계

정상 .5:6µm는 안전하다. R_min−R*=.038461538461538436이고 실제 역산은 (.5,6.000000000000004)다. SI 호출도 정상이며 lens 대조 상대차는 약 1e−14였다. 분리/내포의 조각별 식은 정상 영역에서 연속이다. (.5,6)의 δ=1 전후는 V=**0.5235987755982988**로 연결된다.

### P2-R2-08 — tabor 삭제 구간 대부분은 이미 s=1로 clamp된다

위치: 요청서 `:99`, 실제 clamp `network_conductivity.py:407`.

실제 함수를 이분법으로 계산한 rSE=.5/rAM=6µm, scale1000, ligg_area=0의 경계:

| 사건 | δ (µm) |
|---|---:|
| ψ≤1e−4로 Rc가 잘리기 시작 | **0.10233796105337613** |
| raw A=πR², clamp s=1, ψ=0 시작 | **0.10263267566977693** |
| geom binding 시작 | **0.16291921732451498** |

δ=.12에서는 **binding=tabor지만 s_raw=1.1244022243753902, clamp 후 s=1**이다. 따라서 ".10234–.16292 전체에서 s<1"은 REFUTED다. floor만이 양수를 지우는 s<1 구간은 앞의 두 경계 사이뿐이다. 이 δ 구간 폭을 코퍼스 접촉 분율로 환산해서는 안 된다.

δ=.10250에서는 ψ=3.019643452804513e−5이고 코드 Rc=0이다. 같은 a에 제안 ψ·Holm을 평가하면 **3.0225744413183944e−5**다. 이는 floor가 모델의 양수를 지운다는 반례이지, 그 수가 실제 구의 정답이라는 증거는 아니다.

- **동일 원통에서 a=b**: 절연 격막이 사라져 R_total−R_bulk=0인 것은 맞다. 숫자 0 자체를 오류의 증거로 삼았던 일반론은 철회해도 된다.
- **생산에서 clamp로 s=1**: a=b가 독립 측정된 것이 아니다. A_surface를 원판으로 읽어 강제로 만든 값일 수 있다. 구 접촉 모두의 "참값 0"이라고 면책하면 안 된다.
- **floor-only와 clamp-zero**: binding=geom/tabor로 나누지 말고 s_raw·s_clamped·ψ·floor_only로 구분해야 한다.
- **(1−s)^−3**: 역수식/곱식의 모델내 비로는 정확하다. 모든 실제 접촉의 참값 대비 오차라는 표현은 철회해야 한다.
