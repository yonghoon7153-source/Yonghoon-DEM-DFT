# 수영 U6(c) F8 마찰 다중 접촉 개발 후보

## 1. 가압 전에 고정한 질문

같은 원판 49개의 번호만 뒤집었을 때 F8 판 반력 차이가 얼마나 줄어드는지 측정한다. 기존 원 번호·반전 번호 결과는 `docs/reviews/suyoung_u6c_order_return_20261122/README.md`에 있다. 두 팔이 모두 기록한 마지막 변위 0.11100329에서 원 번호 1.10965834 MPa, 반전 번호 1.20049863 MPa였다. 원 번호 − 반전 번호의 공통 구간 최대 절대차는 0.09084029 MPa였다.

새로 계산할 것은 후보의 F8 원 번호와 반전 번호 두 팔이다. 수정 전 두 궤적과 수정 후 두 궤적의 **네 팔 공통 구간**에서 전후 번호 차이를 계산한다. 같은 번호에서 계산법을 바꿨을 때 반력 곡선 자체가 얼마나 움직였는지도 함께 적는다. 공통 구간 밖의 변위는 미도달로 둔다. **번호 의존성·격자 수렴·실험 일치 여부는 각각 별개의 질문이다.** ⑥의 격자 대조 5%는 기존 분모와 표본 규칙을 따른다.

## 2. 접촉 갱신

기존 함수는 세 물체 이상이 한 노드를 공유할 때 ID로 쌍 순서를 정하고, 먼저 처리한 쌍의 결과 속도로 다음 쌍을 계산했다. 후보 `scripts/suyoung_multicontact_dev.py`는 한 노드의 모든 쌍이 같은 시점의 속도에서 출발해 법선·접선 충격량을 함께 갱신한다. 접촉면이 열리면 충격량은 0, 닫히면 법선 충격량은 압축 방향이고 접선 충격량 크기는 마찰계수 × 법선 충격량 이하다. 두 물체만 만나는 노드는 원 함수의 단일 쌍 계산을 사용한다.

여러 접촉의 반복 해법은 노드별 잔차를 검사한다. 어려운 노드에서는 열림·고착·미끄러짐 조건을 가정한 선형식을 풀고 원래 마찰 접촉식의 잔차를 다시 확인한다. 허용 오차를 만족하는 속도를 찾지 못하면 계산을 중단한다. 이 후보는 검토용 어댑터에서만 선택한다. 원 F8의 격자·질량 문턱·법선 정의·시간 간격·마찰계수 0.5·판 속도·1.2 MPa 중단점은 같은 조건으로 유지한다.

## 3. 개발 판독

1. 같은 세 물체의 번호 6가지에서 같은 물체의 출구 속도를 비교한다. 두 물체의 고착·미끄러짐·분리, 운동량·에너지, 무마찰 동시 법선 기준도 검사한다.
2. 세 접촉이 **모두 미끄러지는** 사례는 정방향·역방향 회전 속도와 양의 법선 충격량을 먼저 주고 입구 속도를 역산했다. 번호 6가지와 저장 순서 2가지에서 계산된 출구 속도를 이 정해진 답과 대조한다. 시험 허용 오차 2 × 10⁻⁸은 이 단위 크기 합성 속도에만 적용한다.
3. 실제 F8 판독에서는 두 후보 팔의 종점·같은 변위에서의 반력 차이·네 팔 공통 구간의 길이를 함께 기록한다. 후보의 번호 차이가 작아도 ⑥의 두 격자 쌍 자격과 실제 물리 타당성은 따로 확인해야 한다. U6(c)와 단계 3의 판정은 보류다.

## 4. 1저자 WSL 실행

이전 벽 관측 TAR와 번호 반전 TAR를 이 순서로 전달한다. 실행 블록에 고정 핀과 소스가 들어 있다. `CHECK_ONLY`는 두 입력의 해시와 실행 환경을 확인한다. `GO_SUYOUNG_F8_FRICTION_PAIR_ONCE`는 WSL CPU 1코어에서 후보의 원 번호 → 반전 번호 순서로 각각 한 번 실행한다. 과거 F8 원 번호 팔은 약 98초, 반전 팔은 약 93초였고 새 해법의 전체 가압 시간은 미측정이다. 팔당 계산 예산 570초·종료 상한 600초, 판독 상한 120초다.

첫 팔이 실패하면 둘째 팔은 시작하지 않는다. 부분 반환에는 실행된 팔의 로그·오류와 그때까지의 궤적을 남긴다. 성공·부분 반환 모두 화면의 RETURN_DIRECTORY에서 `suyoung_friction_result.tar.gz`, `screen.txt`, `SHA256SUMS`를 전달한다. 자동 재시도는 0이다.
