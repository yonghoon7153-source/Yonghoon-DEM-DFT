# ADR 0005 — Knee 는 기준 하나로 정하지 않는다

- 상태: 채택 (2026-08-20)
- 관련: `packages/wrdkit/knee.py`

## 맥락

"용량이 급감하는 지점" 은 문헌에서도 정의가 갈린다. EOL 임계 통과, 두 직선의
교점(Bacon–Watts), 최대 곡률, 기울기 비. 같은 데이터에 대해 서로 다른 답을 준다.
실측 파일에서 넷은 각각 사이클 36.1 / 22 / 19 / 13 을 가리켰다 — 전부 틀리지
않았고, **다른 질문에 답하고 있다.**

## 결정

기준 하나를 고르지 않는다. 넷 다 계산해서 전부 보여 주고, 하나를 primary 로
제시하되 **왜 그것인지 문장으로 남긴다** (`KneeResult.reason`).

| 기준 | 답하는 질문 |
|---|---|
| `threshold` | EOL(기본 80 %) 을 언제 넘었나 |
| `segmented` | 두 직선으로 볼 때 꺾이는 지점은 어디인가 |
| `slope_ratio` | 열화율이 초기 대비 k배가 된 시점은 언제인가 |
| `curvature` | 곡선이 가장 심하게 휘는 지점은 어디인가 |

primary 우선순위: `segmented` → `slope_ratio` → `threshold` → `curvature`.
가속을 직접 재는 기준이 조작자의 질문에 가장 가깝고, 임계 통과는 셀이 충분히
늙어야만 답이 나오기 때문이다.

**열화가 실제로 가속되지 않으면 knee 를 보고하지 않는다.** `segmented` 는
기울기 비가 1.5배 미만이면 미검출로 처리하고 이유를 적는다. 선형 열화 셀에
가짜 사이클 번호를 주지 않는다.

## 결과

- 사용자가 랩 관례에 맞는 기준을 고를 수 있다. UI 에서 전환된다.
- 기준끼리 크게 어긋나면 그 자체가 정보다 (열화가 완만하거나 노이즈가 크다).
- 대가: 화면이 복잡해진다. primary 를 크게, 나머지를 접어서 보여 준다.

## 구현 메모

`segmented` 는 Bacon–Watts 의 `tanh` 근사 대신 **모든 후보 절점을 훑는 정확한
연속 조각선형 회귀**로 풀었다. 힌지 기저 `[1, x, max(x−b, 0)]` 에 최소자승을
걸면 절점마다 닫힌 해가 나온다. 비선형 최적화가 필요 없어 scipy 의존이 없고,
지역 최소에 빠지지 않는다.
