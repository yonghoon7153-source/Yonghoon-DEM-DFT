# 강한 점착 조건에서 B2-U와 B2-C의 두 번째 회전 비교

**P-0 조건부 예측의 두 부호 모두 일치했다.** 같은 초기 배치에서 활물질(AM)의 고체전해질(SE) 대비 입력 점착비를 0.1에서 1로 올리면, 군집에 속한 SE는 1.815%p 줄고 AM에 순간 접촉한 SE는 4.004%p 늘었다. 두 분율 모두 분모는 전체 SE 99,158개다. 같은 SE가 두 지표에 동시에 들 수 있다.

| 등록 지표 | B2-U 평균 | B2-C 평균 | C−U | 좌표 반올림에 따른 C−U 범위 | C−U의 프레임 간 SD |
|---|---:|---:|---:|---:|---:|
| 크기 2 이상 SE 군집에 속한 SE | 74.076% | 72.261% | −1.815%p | −1.856 ~ −1.773%p | 1.151%p |
| AM_P 또는 AM_S에 순간 접촉한 SE | 10.993% | 14.997% | +4.004%p | +3.912 ~ +4.108%p | 0.952%p |

각 팔의 프레임 간 SD는 군집 U 2.405%p·C 2.382%p, AM 접촉 U 1.058%p·C 1.057%p다. 좌표 범위는 각 팔에서 저장 좌표의 반올림으로 가능한 접촉을 다시 센 관측기의 하한·상한으로부터 C 하한−U 상한, C 상한−U 하한을 구했다. 이 범위에서도 등록한 두 방향이 유지된다. 시간 표본의 표준편차는 100개 대응 프레임에서 분모 99로 계산했다. 독립 초기 배치는 한 쌍이며 시드 간 산포는 미측정이다.

시드 32452843, Fr 0.0827, SE–SE 명목 Bo_code 21.244에서 두 번째 회전 134–233번 100장을 같은 step으로 대응했다. 프레임별 정수 SE 수에서 반올림 전 평균차를 재계산했고, 기등록 산술과 분수로도 일치했다. 점착 0 회전 N0의 군집 몫 38.435%에 대해 U는 약 +35.641%p, C는 약 +33.826%p다. B2 두 끝의 결과만으로 중간 점착비에서의 단조성이나 임계점은 미확정이다.

**벽 한정.** U→C에서 SE–AM·AM–AM과 함께 AM–벽 점착도 변하므로, 벽 근처 AM 재배치 경로는 배제 못 함. 두 AM–벽 쌍의 명목 힘은 약 √10배가 됐다. AM 순간 접촉은 해당 프레임의 기하학적 겹침을 센 것으로, 지속 부착·피복 면적·실물 코팅은 별도 측정 대상이다.

양팔의 원 TAR 두 개씩을 반환 해시와 대조하고, 보고 TAR 안의 제출·회수 영수증과 종료 전후 실행 환경을 재확인했다. U의 원 관측 JSON은 등록 SHA256인 128d0c0dc67ead931dbc4a68ccf5c1508e7d02bcacc1db3f921010ba72dee2c2와 일치했다. C의 원 TAR에서 234개 예정 덤프의 정확한 이름, 실제 실행 덱·메타데이터·잡 종료를 대조했다. C 원 덤프를 같은 모듈 9개·같은 E0 기준 프레임(1,121,000 step)으로 판독했다. 두 팔에서 34번 기준 장면을 따로 썼고, 평균에는 134–233번만 썼다. 관측에 사용한 C 덤프 101개의 경로·step·SHA는 원 관측 JSON에 남았다.
