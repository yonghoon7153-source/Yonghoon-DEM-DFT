## Adaptive fixture vs circular validation

Selecting an exact boundary input from measured raw q is legitimate fixture construction for testing the publication policy. It does not independently validate solver accuracy: it intentionally accommodates a small numerical displacement in the solver's conductance. E1's exact equality largely verifies the selected premise, while E2/E3/E4 and independent E5 test the production/consumer decisions at fixed mathematical target values.

The independent probe uses the previous review's explicitly disclosed **diagnostic** area `.500000001001` and box_y `.7281737983380614 / .7281737983380615 / .7281737983380616`, leaving box_x unchanged. All three raw q values are exact and the unchanged E1–E4 assertions pass there. This is labelled a derived positive control, not the submitted 30/30 result, and no source fixture is edited.

Probe negative controls alter only function objects in the probe process, then restore them; no threshold constants or production files change. Results:

| Negative control | E0 search | Detection |
|---|---|---|
| Producer `>=` instead of `>` | exact targets found | E2 and E4 fail |
| Producer comparing rounded q | exact targets found | E1/E3/E4 fail; E4 reports prerequisite failure instead of calling restore |
| Producer guard disabled | exact targets found | E1/E2/E3/E4 fail |
| Consumer guard disabled | exact targets remain | E4 and independent E5 fail |

Thus the search does not conceal these four relevant production-policy regressions. This is not a claim that the test detects every solver error.
