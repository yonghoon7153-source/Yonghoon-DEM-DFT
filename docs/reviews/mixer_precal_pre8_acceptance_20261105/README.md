## 3. 원본 증거와 재포장 누락 구분

받은 원본 ZIP은3,052,006 B, SHA256 `9d82c14919a3137fd3be1248a75ad404c1cc6a6b419bc25c5f2dcb03e764b16d`다. `external/`에 ZIP·판정 원문·범위 JSON·선택 원자료를 바이트 그대로 보존했다. 원본 ZIP의 해시 목록143항목은 일치했다.

**외부 ZIP의 input/에는89개 snapshot 중88개가 들어 있다.** 빠진 것은 과거 `bundle_validation.json` 한 파일(279 B)이며, 외부의 원 검토 기록은89파일/106포장 해시 대조를 보고한다. 이번 실제 수령에서는88 snapshot·105포장 항목을 직접 확인했다. 빠진 메타데이터는 보관 중인 원 제출 ZIP과 수용 Git 핀에서 동일함을 확인해 `recovered_from_original_submission/`에 별도로 보존했다. 받은 ZIP이나 그 input/을 고쳐 완전한 원본이었다고 표시하지 않았다.
