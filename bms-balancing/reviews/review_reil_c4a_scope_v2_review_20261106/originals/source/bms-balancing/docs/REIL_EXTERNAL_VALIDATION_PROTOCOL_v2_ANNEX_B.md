## §1 RV2A-N1 — 수치 수용 증인을 정확 집합 증인과 구분

### 1-1. 허용치의 뜻 (A 129–132 대체)

선형 제약의 `1e-10` 과 목적 문턱의 `1e-9` 는 **사전 선택한 계산 수용 규칙**이다. 정확한 집합의 소속을 보존한다는 보증이 아니다 —
경계 판정은 이산적이라 작은 양의 위반도 정확한 집합의 안 / 밖을 바꾼다 (위 반례). float 좌표를 정확한 유리수로 바꾸는 것은 그 위반을
정확히 **잴** 뿐 없애지 않는다. 목적별 실제 계산 오차의 상계는 확인하지 않았다 (실행 0). A 의 "어떤 상태도 바꿀 수 없다" · "목적 계산의
반올림 (상대 ~1e-15) 보다 충분히 크고" 는 보증으로 쓰지 않는다. 수용 경계 값 자체 (`1e-10` · `1e-9`) 는 그대로 두고 결과를 본 뒤
바꾸지 않는다.

### 1-2. 증인의 두 등급 — 주장이 서는 정확한 집합 기준 (A 123–126 보충)

기록 점마다 **원 좌표** (float 그대로) 와 **제약별 정확 잔차** (상자의 좌표마다 · G · 프로파일 등식 `h_k(x) − t` · 명목 τ 상자의 좌표마다
— 정확 유리수 · 단위는 A §2-2 그대로) 를 남긴다. 반환점은 여전히 고치지 않는다 (clip · 투영 없음). 수용 (`witness = valid`) 은 A
그대로다 — 잔차가 모두 `1e-10` 이하 · 넘으면 `invalid:INFEASIBLE_RETURN`.

등급은 **그 증인이 받치는 주장의 정확한 집합**에 대해 매긴다 (모두 정확 유리수 비교):

| 주장 | 정확한 집합 |
|---|---|
| 점 추정 · Ĵ (A §1-1) | 영역 A (상자 · G) |
| 개별 양립 (좌표 k) | 영역 A 且 `|h_k(x) − t_k*| ≤ τ` — **실제 h_k(x)** 로 본다 (격자 t 가 아니다) |
| 동시 양립 | 영역 A 且 `‖h(x) − h*‖∞ ≤ τ` |
| 프로파일 `충족` · WIDE | 영역 A — 투영값은 실제 h_k(x) 로 보고한다 (격자 t 는 탐색 장치) |

| `feasibility_class` (주장마다) | 조건 |
|---|---|
| `exact_feasible` | 그 정확한 집합 안 — 해당 잔차가 모두 ≤ 0 |
| `numerically_accepted` | 해당 잔차 중 하나라도 0 초과 (모두 `1e-10` 이하) — 정확한 집합 밖일 수 있다 |

- 프로파일 등식 잔차 `h_k(x) − t` 는 **기록하되 등급을 정하지 않는다.** k = LII 의 d_N 소거는 float 식이라 이 잔차가 반올림 크기로 0 이
  아닌 것이 보통이다 — 그것으로 등급을 매기면 LII 프로파일의 모든 증인이 일괄로 `numerically_accepted` 가 된다 (우리 재독에서 찾음). 주장은
  격자 t 가 아니라 실제 h_k(x) 위에 선다 — 재검토의 "프로파일 t 와 실제 h(x) 가 어긋나는 경우" 는 이렇게 다룬다: 실제 h_k(x) 가 주장의
  구간 경계를 반올림만큼 넘으면 그 주장에 대해 `numerically_accepted` 다.

### 1-3. 주장의 등급 · 라벨 (A §7 · 417 보충)

- **양립** (개별 k · 동시 각각): 근거 증인이 하나라도 그 주장에 대해 `exact_feasible` 이면 그 증인으로 `COMPATIBLE`. 근거 증인이 **모두**
  `numerically_accepted` 이면 그 주장은 `COMPATIBLE (수치 경계 의존)` 이고 `UNRESOLVED` 를 병기한다 — 정확한 집합의 무조건 COMPATIBLE 로
  승격하지 않는다.
- **발견 폭** `WIDE`: 두 `충족` 증인의 **실제 h_k(x) 차 (정확 유리수) 가 2τ 초과**이고 두 증인이 모두 영역 A 에 대해 `exact_feasible`
  일 때만 무조건 `WIDE` (A §3-7 의 "서로 2τ 넘게 떨어진 충족 격자점 둘" 을 실제 투영값으로 잰다). 하나라도 `numerically_accepted` 이면
  `WIDE (수치 경계 의존)` + `UNRESOLVED`.
- **라벨:** 부가 축에 `선형 제약 경계` (= `numerically_accepted` 증인에 기대는 상태) 를 더한다. 목적 문턱의 `경계 근접` (A §2-2 —
  `|T − J| ≤ 1e-9`) 과 **서로 대체하지 않는다** — 다른 라벨이고 함께 붙을 수 있다.
- **P0 불변:** P0 의 정확한 `PRIOR_INCOMPATIBLE` 은 어떤 수치 수용 증인으로도 뒤집지 않는다. 그 (행 · τ · 영역) 의 동시 양립 탐색은 A
  §3-4 대로 돌리지 않고, 다른 탐색의 반환점이 그 τ 상자에 `numerically_accepted` 로 들어와도 동시 양립 증인으로 세지 않는다.
- 상태표에는 등급별 증인 수 (`exact_feasible` · `numerically_accepted`) 를 함께 싣는다.

### 2-2. 프로파일의 시작 (A 219 · 221–222 대체)

- "시작은 정확히 4" → **명목 4** (s1 · s2 · Sobol 2) · 실제 수를 격자점마다 기록한다.
- s1 = x̂⁽⁰⁾ (Phase A 최적 유효 증인 — 단위가 UNFIT 이 아니면 반드시 있다).
- s2 의 대체 사슬: 안쪽 이웃의 최적 유효 증인 → 안쪽으로 걸어가 처음 만나는 유효 증인 → (없거나 중심점이면) Phase A 의 두 번째 유효
  증인 → **그것도 없으면 (Phase A 유효 증인 1 개) `시작 부족 (s2)`** 를 적고 셋으로 돈다.
- Sobol 2 는 고정 배열이라 언제나 있다. 시작점 둘이 정확히 같으면 A 226 대로 뒤의 것을 다음 대체 후보 (Phase A 의 다음 유효 증인) 로
  바꾸고, 후보가 바닥나면 `시작 부족 (중복)`.
- 복제 · Sobol 추가 추출 · 남는 예산의 다른 점 · 단위 전용 · 숨은 추가 시작 없음.

### 2-3. 동시 양립의 시작 (A 232–233 대체)

- 명목 16 = **가용 상위 `min(4, n_valid)`** (Phase A 유효 증인 J 순 · 같으면 실행 번호 순 · m_P · m_N 을 P · N 으로 자른 점 · d 는 그대로)
  \+ **고정 Sobol 12**. `n_valid` = 그 단위 Phase A 유효 증인 수 (0 이면 단위 UNFIT — A §2-3).
- `n_valid < 4` 이면 그 차이를 `시작 부족 (Phase A 증인)` 으로 기록하고 적은 수로 돈다 — 복제 · Sobol 추가 추출 · 다른 단위 예산 전용 없음.
- 자른 뒤 같은 좌표가 된 증인은 다음 순위 유효 증인으로 바꾸고 (프로파일과 같은 규칙), 후보가 바닥나면 `시작 부족 (중복)`.
- Sobol 12 = Sobol 16 점 (2 의 거듭제곱) 중 앞 12 — **결정적 선택일 뿐이며 그 12 점에 16 점 Sobol 의 균형 성질을 주장하지 않는다**.

## §3 RV2A-N3 — cutoff 격자점 교차는 격자 index 로 (A 298–301 대체)

격자 `(Q_j, V_j)` (j = 0 … 999) · cutoff c 마다 다음 순서로 판정한다.

1. **평탄 거부:** `V_j = c 且 V_{j+1} = c` 인 구간이 하나라도 있으면 그 x 의 H4 목적은 **비유한** (A 그대로 — 먼저 본다).
2. **격자점 교차:** `V_j = c` 인 j 마다 교차 하나 — 정체성 = **격자 index j** · 위치 = `Q_j` 그대로 (보간식을 계산하지 않는다). 부호가
   바뀌지 않는 접촉 (`V_{j−1}` 과 `V_{j+1}` 이 c 의 같은 쪽) 도 한 번 센다.
3. **내부 교차:** 양 끝 어느 쪽도 c 가 아니고 `(V_j − c)(V_{j+1} − c) < 0` (엄격한 부호 변화) 인 구간 j 마다 교차 하나 — 정체성 = 구간
   (j, j+1) · 위치 = 선형 보간 `Q_j + (c − V_j)(Q_{j+1} − Q_j)/(V_{j+1} − V_j)`.
4. **유일 교차 수** = (2) 의 격자 index 수 + (3) 의 구간 수. 같은 격자 index 는 정의상 한 번만 센다 — float Q 의 비교로 합치지 않는다.
   정확히 1 이 아니면 비유한 (A 그대로).
5. 원시 기록은 (2) · (3) 의 항목 목록 (index 또는 구간 · 위치) 이다. 새 Q 허용치 · 더 촘촘한 격자는 두지 않는다. span · s 는 A 그대로
   (Q_a · Q_b = 위 위치값).

## §4 수용 범위의 문구 (재검토 Q2 · Q4 · Q5 — A 의 뜻을 좁힌다)

- **공통 갱신 (A §1-1):** "문턱을 조이기만 한다" 는 **같은 최종 저장 점 집합**에 옛 · 새 문턱을 적용해 비교할 때 (분모 양수 범위) 의
  성질이다. 탐색 중 점을 더하며 보는 상태의 단조성이나, 문턱 유지 대안보다 보편적으로 낫다는 뜻이 아니다. 최소가 0 이 된 상대 판정은 A
  §1-2 의 UNFIT 분기를 따른다.
- **최종 ρ 판독 (A §1-3):** 결합 단위의 **모든 유효 기록 점**의 `(J_V, J_D)` 쌍을 저장하고 최종 분모로 전부 다시 비교한다 — 잠정 ρ 의
  최저점 하나나 ρ 값만 남기지 않는다. 결합 탐색은 잠정 분모에 최적화된 것이라 최종 분모에서의 탐색 충분성을 보장하지 않는다.
- **독립 풀 (A §1-1):** 방법별 발견 최소다 — "모든 관측점의 최소" 나 전역 최소라고 부르지 않는다. 결합이 더 낮은 단일 목적값을 본 경우는
  A 대로 따로 보고한다.
- **H4 ray (A §4-6):** ray 를 만들기 전 기준 증인 x̂_s 의 식별을 보존하고, 공통 갱신으로 최종 최소가 바뀌어도 ray 를 다시 만들지 않는다.
- **COBYQA 옵션 (A §3-1):** `feasibility_tol` 1e-12 · `final_tr_radius` 1e-6 은 반환 유효성 · 목적 오차 · 전역 해 정확도의 보증이
  아니다 — 증인 판정은 §1 의 독립 규칙이 한다. 판 고정과 실제 전달 옵션 대조는 C6.
- **`Fraction(float)` (A §2-5):** 저장된 이진 float 값을 정확히 나타낼 뿐, 원 물리량이나 십진 명목값의 무오차를 증명하지 않는다.
- **ν = 0.01 V (A §4-3):** 사전 선택한 운영 수용 폭이다 — 근거 있는 실험 오차 상계가 아니고 P0 관측 뒤 넓히지 않는다. "이완 구간을
  거른다" 는 이 폭 밖인 경우의 규칙일 뿐 모든 이완 상태를 판별한다는 보증이 아니다.
- **H4 대조 (A §4-4 · §4-5):** R1–R3 · 대칭 `1e-9 V` · 음성 `D_abs > 1e-6 V` 는 사전 선택한 **구현 대조**다. 실제 곡선에서 통과하는 후보가
  있는지는 미확인이다. A §4-5 의 "비평탄 곡선에서 0 이 아님이 알려져 있다" 는 수학적으로 0 이 아니라는 뜻이지 `1e-6 V` 초과의 보장이
  아니다 — 실패를 실측 가설의 반증이나 특정 구현 결함으로 단정하지 않는다.

## §5 이 문서가 아닌 것

실행 · P0 · 비용 측정 · 맞춤 · 설치 · 구현의 승인이 아니고, 결과도 우리 축퇴 결론의 근거도 아니다. GATE89 · PyBaMM 고정 라운드와
무관하다 (게이트 차수 밖). v2 · 부속 A · 직전 두 회신은 바이트 그대로 보존한다. 문서 조건이 닫혀도 C1-core · 판 · 환경 고정 · P0 ·
비용 측정 · 실행의 별도 사용자 승인과 E3b 미등록은 그대로다.
