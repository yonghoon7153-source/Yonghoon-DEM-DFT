- 사슬이 원장에 쓰는 때는 셋뿐이다: 항목 (`--stage ledger --add`) · 시작 기록 (시도 시작) · 결과 줄 (시도 끝 또는 `--stage recover --ledger`).  풀이 도중에는 원장을 건드리지 않았다 (새 시험 D1b 의 관찰 — 원장이 없는 동안 사다리가 끝까지 돌았다).

## 2. 선택지

### (가) 원장 이어달리기 — 한 번에 한 기계만 원장을 쓴다

- 꼴: 쓰는 원장 사본은 한 기계에만 있다.  넘길 때 = 가진 기계에서 `git bundle create <묶음 파일> --all` → 묶음 파일을 받는 기계로 옮김 → 받는 기계는 처음이면 `git clone <묶음 파일> <원장 자리>`, 전에 가졌던 사본이 있으면 `git pull --ff-only <묶음 파일> <가지>` → 보낸 기계의 사본은 세워 둔다 (이름을 바꿔 사슬이 쓰지 못하게).
- 두 갈래:
  - (가-1) 겹치지 않음 — 시도 하나 (항목 → 시작 → 결과 줄) 가 다 끝난 뒤에만 넘긴다.
  - (가-2) 시작 뒤 넘김 — 시작 기록이 커밋된 뒤 원장을 넘긴다.  끝난 사슬은 결과 줄을 쓰지 못하고 rc 3 으로 끝난다 → 원장이 돌아온 뒤 `--stage recover --out <시도 폴더> --ledger <원장>` 이 결과 줄을 쓴다.

| 칸 | (가-1) 겹치지 않음 | (가-2) 시작 뒤 넘김 |
|---|---|---|
| 두 기계가 동시에 단위를 도는가 | 못 돈다 (한 번에 시도 하나) — 벽시계는 한 대와 같다 ([Q9] 192 줄 220.2 – 318.8 h [추정]) · 두 대 어림 110.1 – 159.4 h ([Q9] 193 줄 [추정]) 는 동시에 도는 것을 전제한다 | 돈다 |
| 사슬이 기계적으로 막는 것 | 받은 원장이 덧붙이기만이 아님 · 병합으로 숨긴 판 (제약 1) · 옮긴 시도 폴더의 바이트가 결과 줄과 다름 · 시도 폴더가 빠짐 · 한 항목에 폴더 둘 (`ATTEMPT_LEDGER_MISMATCH`) · 두 사본에 각각 쓴 뒤 섞음 (갈라짐 — 시도 폴더의 attempt.json ≠ 원장 항목 `ATTEMPT_LEDGER_MISMATCH` · 시작 커밋이 조상이 아님 `ATTEMPT_ORDER_MISMATCH`) | 왼쪽 전부 + 결과 줄 없는 시도를 입력으로 쓰기 (`ATTEMPT_LEDGER_MISMATCH` "결과 줄이 없다 · recover 먼저" · [사슬] 5338) · 같은 대상의 다음 항목 (`ATTEMPT_ORDER_MISMATCH`) · 옮긴 폴더에서의 recover (rc 3 · 제약 12) |
| 운영 규칙으로만 지키는 것 | "한 번에 한 기계만 쓴다" 그 자체 (보낸 쪽 사본을 세워 두는 것) — 사슬은 자기 앞의 사본이 가장 새 것인지 모른다 · 넘기는 수단 · 넘긴 기록 (언제 · 어느 커밋) | 왼쪽 전부 + 끝난 사슬의 rc 3 을 "원장이 없어서" 로 읽는 것 (화면 이름이 진짜 대조 실패와 같다 — `ATTEMPT_LEDGER_MISMATCH` · "원장 잠금 파일을 못 연다") · recover 를 그 기계 · 그 바탕 · 같은 부팅에서 돌리는 것 (다른 부팅이면 운영자 확인 표지 · [R] 641) |
| 새 시험이 실제로 보인 것 | D3 — 12 단위를 세 바탕에 돌아가며 · 원장을 15 번 넘김 (묶음 → clone 또는 `pull --ff-only` · 보낸 쪽 세워 둠) → 합치기 → 원장 판정 → 다시 판정 통과 · 결과 전 멈춤 뒤 다른 기계가 이어받음 (D3b) · 자원 멈춤 뒤 같은 기계 재실행 (D3g) · 원장 = 한 줄 역사 (D3c) · 원장 저장소를 폴더째 복사해도 같다 (D6a) · 갈라진 원장은 거부 (D6j) | D1b — 사다리 P0 (kgy) 시작 뒤 원장을 gabia 로 넘김 → P1 (gabia) 완주 → 끝난 kgy 사슬 rc 3 (요약은 남음) → 원장이 돌아온 뒤 recover 가 결과 줄 (by recover) → 그 사다리가 뒤 단계 · 판정에서 채택됨 · D3h — 단위 하나도 같은 꼴 (kgy 단위 시작 뒤 원장을 gabia 로 → 그 사이 gabia · v100 의 단위가 원장에 들어가 끝남 → kgy 사슬 rc 3 → 원장이 kgy 로 돌아온 뒤 recover → 합치기가 그 단위를 채택) |
| 새 시험이 못 보인 것 | 실제 두 기계 · 실제 전송 (끊김 · 파일 손상) · 사람이 옛 묶음을 받는 실수 | 12 단위 전부를 이 꼴로 (사다리 하나 · 단위 하나만 봄 · 두 러너가 정말 같은 때 도는 것은 사다리 한 번뿐) · 원장이 떠난 사이 그 기계가 재부팅된 경우 (recover = 미확인 → 운영자 확인 표지) · 보낸 쪽 사본을 세워 두지 않아 끝난 사슬이 옛 사본에 결과 줄을 쓴 경우 (갈라짐 — D6j 와 같은 부류로 잡힐 것 [추정 · 시험 없음]) |
| 사람 손이 드는 곳 | 넘길 때마다: 묶음 만들기 · 옮기기 · 받기 · 보낸 쪽 세워 두기 (12 단위면 적어도 기계가 바뀌는 횟수만큼 · 새 시험 = 15 번) · 시도 폴더 · 사다리 폴더를 합치는 기계로 복사 | 왼쪽 + 단위를 시작할 때마다 원장이 그 기계에 있어야 한다 (시작 기록) · 끝난 시도마다 원장이 돌아온 뒤 recover 한 번 |

- "사슬이 기계적으로 막는 것" 칸 가운데 새 시험이 직접 본 것은 "새 시험이 실제로 보인 것" 칸과 보고의 음성 대조 표에 적힌 것뿐이다.  나머지 (병합으로 숨긴 판 · 시작 커밋이 조상이 아님 · 결과 줄 없는 시도를 입력으로 · 같은 대상의 다음 항목) 는 사슬 코드를 읽은 것이다 — 갈라진 원장에서는 앞 검사 (attempt.json ≠ 원장 항목) 가 먼저 잡아 `ATTEMPT_ORDER_MISMATCH` 는 새 시험에 나오지 않았다.
- 변이 확인 (보고의 변이 표 M10): attempt.json ↔ 원장 항목 대조를 꺼도 갈라진 원장은 둘째 방어선 (폴더 요약 sha) 에서 같은 멈춤 이름으로 거부됐다.

### (나) 두 기계가 닿는 공용 git 저장소 — 쓰기 전 받고 쓴 뒤 올린다 (빨리 감기만)

| 칸 | 내용 |
|---|---|
| 꼴 | 기계마다 원장 사본 · 쓰기 전 `pull --ff-only` · 쓴 뒤 올리기 (빨리 감기만 받는 공용 저장소) |
| 두 기계가 동시에 단위를 도는가 | 돈다 (두 기계가 같은 때 원장에 쓰지 않는 동안) |

### (다) 나누지 않는다 — 한 기계가 원장과 예측 전부

| 칸 | 내용 |
|---|---|
| 꼴 | 원장은 한 기계에만 · 예측 = 한 기계 예측 한 번 ([K] 529–531 줄) 또는 12 단위를 한 기계에서 |

## 3. 새 시험이 돈 꼴 (권고안 기준 · 1저자 비준 전)

| 무엇 | 새 시험에서의 꼴 | 문서 |

| 사다리 폴더 | 돈 기계에서 다른 기계들로 바이트 복사 (같은 상대 자리 `ca1_ladder_<법칙>/attempt_<n>`) | 옮기는 법 = 문서에 없음 ([계획] 266 줄) |
| 단위 시도 바탕 | `ca1_units/attempt_<n>` (이름은 시험이 지었다) | 이름 = 문서에 없음 ([계획] 268 줄) |
| 합치는 기계 | kgy (다른 기계의 시도 폴더는 `ca1_units_from_<기계>/` 로 바이트 복사) · 이동 대조에서는 gabia 에서도 합침 | 어느 기계 = 문서에 없음 ([계획] 273 · 305 줄) |
| 한 기계 예측과의 비교 | 따로 원장 (사다리 둘 뒤에서 갈라 낸 사본) — 제약 9 | [R] 622 |

## 4. 권고 (한 줄)

- (가) 원장 이어달리기를 등록 문장으로 삼고, 두 기계를 동시에 돌릴 것이면 (가-2) 의 흐름 (끝난 사슬 rc 3 → 원장이 돌아온 뒤 recover 가 결과 줄 · 보낸 쪽 사본 세워 두기) 을 명령 문서에 정상 흐름으로 적은 뒤 쓴다 — (나) · (라) 는 사슬이 모르는 받기 · 올리기 · 호스트 사이 잠금에 기대므로 권하지 않는다.
