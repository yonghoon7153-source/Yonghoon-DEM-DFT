# Official site map and live audit

## 공식 구조를 그대로 가져올 부분

공식 `docs/myst.yml` 기준 정보 구조는 아래야.

```text
Home
├─ Quickstart
├─ AI/ML Models & Usage
│  ├─ UMA / changelog / concepts
│  ├─ Common Tasks
│  ├─ Tutorials
│  └─ Generative Models
├─ FAIR Chemistry Papers
├─ Organic Molecules
├─ Heterogeneous Catalysis
├─ Leaderboard
├─ Inorganic Materials
├─ MOFs for Direct Air Capture
└─ Learn More
```

우리 webapp도 이 탐색 순서는 최대한 유지해. 대신 공식 사이트에 없는 `Our LPSCl Use`, `Local Validation`, `Decisions & Limitations`, `Source & Provenance`를 덧붙이는 게 핵심이야.

## 현재 사이트 QA

| Check | Result | Meaning |
|---|---:|---|
| MyST TOC pages | 64 | 목차에 들어간 공식 페이지 |
| HTTP 200 | 64 / 64 | 주소는 모두 열림 |
| Tracked Markdown outside TOC | 2 | 소스는 있지만 live route는 404 |
| Rendered execution errors | 3 | HTTP 200이지만 첫 code cell이 실패 |
| Unique internal links checked | 83 | live page 본문 링크 |
| Broken internal targets | 19 | nested legacy path, missing asset, malformed mail link 등 |
| `/autoapi/` | 404 | 현재 live autogenerated API reference 없음 |

실행 오류 페이지는 formation energy, phonons, elasticity야. 세 페이지 모두 `quacc.recipes.mlp` import 실패가 HTML 안에 렌더돼 있어. 따라서 webapp에는 `available_documentation`과 `example_execution_status`를 별도 필드로 보여줘야 해.

TOC 밖 두 페이지는 다음이야.

- `docs/catalysts/datasets/oc20_slabs.md` → `/oc20-slabs/` 404
- `docs/core/common_tasks/benchmark.md` → `/benchmark/` 404

## Sitemap 주의

`sitemap.xml`은 HTTP 200이고 64개 URL을 갖지만 모든 `<loc>`가 `http://localhost:3000`이야. `robots.txt`도 localhost sitemap을 가리켜. 그러므로 다음 갱신 때 sitemap을 source of truth로 삼으면 안 돼.

```text
docs/myst.yml -> source_path -> production host substitution -> HTTP verification
```

이 흐름이 정본이야.

전체 page-level 결과는 [site_pages.json](../../db/knowledge/fairchem/site_pages.json), broken-link 결과는 [live_link_audit.json](../../db/knowledge/fairchem/live_link_audit.json)에 있어.

## 우리 webapp의 첫 화면

공식 홈페이지처럼 domain을 먼저 보여주되, 카드마다 아래 네 줄을 붙이는 편이 좋아.

```text
Official scope
Pinned model/task/version
Local validation
Allowed use / caution
```

공식 페이지를 iframe이나 복사 HTML로 싣지 말고, 우리 typed DB를 렌더한 뒤 pinned source link를 열어주는 구조가 안전해.
