## 한 줄 요지

Boukamp(1995)의 선형 KK 검정(lin-KK: 시정수를 고정한 Voigt 회로의 저항만 선형으로 맞춤)은
RC 개수 M 을 사람이 정해야 해서 과소·과대적합으로 판정이 뒤집힌다. 이 논문은 맞춘 저항 가운데
음수의 비중 μ = 1 − Σ|R_k<0| / Σ|R_k≥0| 가 처음으로 c = 0.85 아래로 떨어질 때까지 M 을 1 씩
늘려, M 을 자동으로 정한다. 합성 데이터에서 그렇게 고른 M 은 이론적 최적 M 과 일치했다.

## 알고리즘

논문의 정의다. **[우리]** 는 논문이 비워 둔 곳을 우리가 채운 부분이다.

1. **입력**: 측정점 N 개, Z_i = Z_Re,i + j·Z_Im,i, ω_i = 2π·f_i. 실측 리튬이온 데이터에서
   논문은 3 kHz 위(유도성 아티팩트)를 버리고 시험했다. (p. 23)
2. **모델** (식 9): Ẑ(ω) = R_ohm + Σ_{k=1..M} R_k / (1 + jω·τ_k).
   물리적으로 의미가 있거나 측정 대역이 전체 스펙트럼보다 좁으면 직렬 C 를, 유도성 효과가 있으면
   직렬 L 을 더한다. 실측 리튬이온에는 둘 다 넣었다. (p. 21, 23)
3. **피팅 방식** (식 13·14)
   - real-fit: J = Σ_i [(Z_Re,i − Ẑ_Re,i)/|Z_i|]².
   - complex-fit: J = Σ_i [(Z_Re,i − Ẑ_Re,i)/|Z_i|]² + [(Z_Im,i − Ẑ_Im,i)/|Z_i|]².
   - |Z_i| 는 **측정값**의 크기다. 모델에 C 가 있으면 허수부만 맞추는 방식은 쓰지 않는다. (p. 22)
4. **M = 1 에서 시작** ("충분히 작은 값, 예: M = 1"). (p. 26)
5. **시정수** (식 10–12): τ_1 = τ_min = 1/ω_max, τ_M = τ_max = 1/ω_min,
   τ_k = 10^( log τ_min + (k−1)/(M−1) · log(τ_max/τ_min) ), k = 2..M−1. log 는 상용로그다.
   **[우리]** M = 1 에서는 식이 정의되지 않으므로 τ 하나를 정해 둔다(예: τ_max). (p. 21)
6. **선형 최소제곱**: τ 는 고정하고 R_ohm, R_1..R_M (그리고 1/C, L) 만 푼다. R_k 의 부호는
   제약하지 않는다.
   - **[우리]** 설계행렬은 식 9·13·14 에서 유도했다.
     - 실수 행 [1, 1/(1+(ω_iτ_k)²)] / |Z_i|, 목표 Z_Re,i/|Z_i|.
     - 허수 행 [0, −ω_iτ_k/(1+(ω_iτ_k)²)] / |Z_i|, 목표 Z_Im,i/|Z_i|.
     - C 는 허수 행에만 −1/(ω_i·|Z_i|) 열(변수 1/C), L 은 허수 행에만 ω_i/|Z_i| 열(변수 L)을 더한다.
     - real-fit 은 실수 행만, complex-fit 은 두 행을 쌓아 푼다.
7. **μ = 1 − Σ_{R_k<0}|R_k| / Σ_{R_k≥0}|R_k|** (식 21). RC 저항만 더하고 R_ohm 은 뺀다. (p. 25)
8. **μ < c (c = 0.85)** 이면 멈추고 M* = M 으로 둔다. 아니면 M ← M + 1 로 늘려 5 로 돌아간다.
   (p. 26, 그림 9)
9. **잔차** (식 15–16): M* 에서 Δ_Re,i = (Z_Re,i − Ẑ_Re,i)/|Z_i|, Δ_Im,i = (Z_Im,i − Ẑ_Im,i)/|Z_i|
   를 % 로 주파수에 대해 본다. real-fit 이면 Ẑ_Im 은 맞춘 실수부로 **예측한** 허수부다. (p. 22)
10. **판정**: 전 대역에서 잡음 수준이면 KK 를 만족한다(유효). 크거나 계통적인 잔차가 있으면 그
    대역이 무효다. **논문은 잔차 수치 기준을 주지 않는다.** (p. 23)

## 핵심 내용

- KK 관계는 선형·시불변·인과 시스템에서만 성립한다. 따라서 KK 위반은 회로가 아니라 데이터
  자체의 결함(비선형, 드리프트 등)을 뜻한다. (p. 20)
- 적분식을 직접 계산하면 0 과 ∞ 쪽 데이터가 없어 외삽 문제가 남는다.
  - 측정모델 방식(Agarwal·Orazem)은 R 과 τ 를 다 맞추는 비선형 문제라 초기값·국소해 문제가 있다.
  - Boukamp 의 lin-KK 는 τ 를 고정해 선형 문제로 바꿨다. (p. 21)
- 이 논문이 고치는 약점은 M 을 사용자가 정해야 한다는 점이다. 그래서 과소·과대적합이 생기고
  판정이 모호하거나 틀린다. (p. 21)
- 가중치는 측정 |Z| 에 비례한다. 잔차도 측정 |Z| 대비로 실수부·허수부를 따로 정의한다. (p. 22)
- 모델에 C 가 있을 때 허수부만 맞추면, RC 몫의 저주파 허수부가 C 로 새어 실수부 오차가 된다.
  그래서 논문은 이 방식을 제외했다. (p. 22)
- **과소적합**: 잔차가 커서 KK 를 만족하는 스펙트럼도 무효로 판정된다. 예: 떨어진 RC 셋을
  M = 2 로 맞출 때. (p. 23)
- **과대적합**: 잡음까지 맞춘다.
  - real-fit 은 유효한 스펙트럼을 무효로 판정한다. 그 오차 모양은 기생 인덕턴스와 닮는다.
  - complex-fit 은 오류까지 재현해 무효를 유효로 판정한다. 저주파 점이 성긴 드리프트
    스펙트럼 IS3b 가 유효한 IS2 처럼 보였다.
  - complex-fit 에서는 작은 오류가 실수부·허수부에 번져 덜 보인다. (p. 23)
- 합성 데이터에서는 잡음 없는 허수부와 비교한 예측오차 χ²_Im = (1/N)Σ[(Z_Im − Ẑ_Im)/|Z|]² 가
  최소인 M 이 최적이다. 실측에서는 이상적 허수부를 몰라 이 값을 계산할 수 없다. (p. 24)
- 이상적 스펙트럼은 주파수에 대해 진동하지 않는다. τ 를 고정한 RC 직렬은 음의 R_k 가 있어야만
  진동한다. 그래서 음의 저항 비중 μ 로 과대적합을 잡는다. (p. 25)
- μ 는 과소적합 영역에서 ≈1 이고, 과대적합이 시작되면 0 으로 떨어진다(그림 7). (p. 25)
- 잡음 세 수준 × 10년당 1–12 점의 합성 스펙트럼 **모두**에서 μ-최적이 이론 최적과 일치했다.
  잡음이 클수록 RC 가 적다(그림 8 판독: 강·중·약 잡음에 10년당 약 2·3·4개). (p. 25–26)
- 10년당 RC 수가 10년당 점 수보다 많으면 명백한 과대적합이다. (p. 26)
- c 는 설계 변수이고 0.85 를 권한다. (p. 26)
- 결과: IS1a 는 유효, IS3b 는 무효로 맞게 판정했다. (p. 26–27)
  - IS3b 의 μ-최적은 M = 16(10년당 2.4)이다.
  - '가장 성긴 구간 점 수보다 조금 적게' 고르는 직관적 방식(10년당 6개, 총 40개)은 μ = 0.02
    이고 잔차가 훨씬 덜 드러난다.
  - 평가 한 번에 1 초 미만이 걸렸다.
- 드리프트 실험: 13.5 h 측정 중 챔버를 25→15 °C 로 선형 변화시켰다(10 mV, SOC 80 %). (p. 23)
  - 잔차는 저주파 끝에 몰린다. 그림 10 오른쪽 판독: Δ_Re ≈ +6 %(≈1 mHz),
    Δ_Im ≈ −9 %(최저점), 약 0.1 Hz 위로는 ≈0. (p. 26)
- 합성 시험 스펙트럼 IS1 은 1 µHz–10 MHz 에서 만들었다. (p. 22–23)
  - 회로: R1 = 100 Ω, R2 = 200 Ω ∥ C3 = 0.8 µF, R4 = 500 Ω ∥ Warburg(Y0 = 0.4 mS·s^0.5).
  - 잡음 표준편차: |Z|/1000(IS1a), |Z|/100(IS1b), |Z|/10000(IS1c).
  - 과소적합 예는 M = 6, 과대적합 예는 M = 104. 둘 다 거짓 무효였다.
- 식 번호 (20)·(21) 이 두 번씩 쓰였다. 뒤쪽 참조의 (20) 은 χ²_Im, (21) 은 μ 를 가리킨다.
  (p. 22, 24, 25)

## 우리 코드에 대한 함의

**어디에 넣나.** CLAUDE.md 순서를 따른다.
1. ADR 을 쓴다.
2. `packages/wrdkit/src/wrdkit/eis/kk.py` 에 순수 함수를 둔다. numpy 만 쓴다
   (`np.linalg.lstsq`; scipy 불필요) [boukamp-lin-kk-manual-m].
3. 테스트를 붙인다.
4. `audit.py` 에 **회로와 무관한** 스펙트럼 검사(예: `audit_spectrum`)를 추가한다.
5. API, 화면 순으로 붙인다.

KK 는 스펙트럼의 성질이므로 맞춤(fit)마다가 아니라 스펙트럼당 한 번 계산해 둔다.

**입력 준비.**
- 고주파 유도성 구간은 기존 `inductive_mask` 로 빼거나 직렬 L 을 넣는다. 논문은 3 kHz 위를
  버리고 L 도 넣었다. 뺀 점 수는 보고한다 [optional-series-c-l].
- `blocking_verdict` 가 blocking 이면 직렬 C 를 넣고 complex-fit 을 쓴다
  [cost-complex-fit, imag-fit-discarded-with-capacitor].
- τ 범위는 실제로 시험한 대역의 최소·최대 주파수로 정한다. `Spectrum` 은 정렬돼 있지 않을 수
  있다 [tau-distribution].

**정해진 값.**
- c = 0.85 [mu-threshold-c]. M 은 1 부터 1 씩 늘리고, μ < c 에서 멈춘다 [m-selection-procedure].
- 부호 제약이 없는 최소제곱을 쓴다. NNLS 를 쓰면 μ 가 늘 1 이라 기준이 먹통이 된다
  [no-oscillation-negative-r].
- 상한은 논문에 없다. **[우리]** M ≤ 사용 점 수로 두고, 상한에 닿으면 `None` 과 이유를
  돌려준다(CLAUDE.md 규칙 4) [params-exceed-points].

**잔차 문턱은 논문에 없다** [no-numeric-residual-threshold]. audit.py 의 `MEAN_MISFIT_LIMIT`
처럼 우리 근거를 주석에 단 상수로 두고, 이 논문을 출처로 달지 않는다.
- 참고용 우리 재현(논문 아님): 합성 IS1, 10년당 10점.
  - μ 로 고른 M 은 잡음 1 %·0.1 %·0.01 % 에서 10년당 ≈2·3·3.9개로, 그림 8 과 맞았다.
  - 그때 max|Δ| 는 잡음 표준편차의 약 4배였다(0.1 % → ≈0.44 %, 1 % → ≈3.6 %).
- 그러니 문턱은 잡음 수준에 맞춰야 한다. 크기만 보지 말고 **저주파 쪽에 같은 부호로 이어지는
  계통적 잔차**를 함께 봐야 드리프트와 잡음이 갈린다 [drift-shows-at-low-frequency].
- 상수는 랩 실측 스펙트럼(fit.py 주석의 6개)으로 보정한다.

**스펙트럼마다 보고할 것.**
- 선택: M*, M*/decade, μ(M*), c, 피팅 방식(real/complex), 직렬 C/L 포함 여부.
- 대역: 사용 점 수 N, f_min–f_max, 뺀 유도성 점 수.
- 잔차: max|Δ_Re| 와 max|Δ_Im|(%)와 각각의 주파수, 잔차 RMS, 저주파 끝 몰림 비율
  (`edge_misfit` 방식).
- 그래프용: μ(M) 궤적과 잔차 배열(그림 10 같은 그래프).
- 판정과 이유 [residuals, mu-definition, example-is3b-mu-result].

**Finding 코드 제안.**
- `kk_residual_low_frequency` (check): 저주파 계통 잔차가 있다. 드리프트·시간변화를 의심하고,
  회로 맞춤의 하한 주파수를 제안한다.
- `kk_residual` (check): 중간 대역이나 전 대역 잔차.
- `kk_high_frequency` (note): 배선 인덕턴스로 보인다. **M 이 μ 로 정해졌을 때만** 이렇게
  말한다. 과대적합 잔차도 인덕턴스처럼 보이기 때문이다 [over-fitting].
- `kk_not_judged` (note): 점이 모자라거나, 상한에 닿았거나, 아래 조기 정지에 해당한다.

**해석 규칙.**
- KK 통과인데 `misfit_everywhere` 가 뜨면 데이터가 아니라 회로 문제다.
- KK 가 실패한 대역이 있으면 그 대역에서 정한 파라미터(저주파 확산, blocking 꼬리)를 먼저
  의심한다 [kk-requires-lti-causal].

**단위 테스트 앵커.**
- IS1 픽스처: 표 1 값, 1 µHz–10 MHz, 고정 seed [example-is1-synthetic].
- M = 6·104 로 고정하면 잔차가 크고, μ 로 고르면 작다. 그림 10 판독으로 IS1a 는 M ≈ 37
  [example-is1a-under-over-fit].
- 잡음별 10년당 ≈2·3·4 [mu-optimum-validated].
- 드리프트 픽스처: 느린 파라미터 변화에 저주파 점을 솎는다. μ 로 고른 M 은 저주파 잔차를
  드러내고, 조밀하게 고정한 M 은 그것을 가려야 한다
  [example-measured-li-ion, example-is3b-mu-result].

**주의 — 우리 검증, 논문에 없음** (JSON `conflicts` 넷째 항목). KK 를 만족하는 합성 스펙트럼
(1 MHz–10 mHz, 10점/decade)에서 μ 가 **너무 일찍** c 아래로 떨어져, 틀린 '무효'가 나온 경우가
셋 있었다.
- real-fit 으로 단일 아크(이상적 RC 또는 n = 0.8–0.9 ZARC)를 맞추면 M = 4 에서 멈추고,
  잔차가 60–76 % 다.
- complex-fit 이라도 이상적 RC(n = 1)면 M = 7 에서 멈추고, 잔차가 약 19 % 다.
- 참 저주파 유도성 루프(RL 병렬, 아크의 5–40 %)가 있으면 M = 3–7 에서 멈추고, 잔차가
  18–27 % 다. 참 유도성 루프는 Voigt 표현에서 **음의 R** 이라 μ 가 과대적합으로 읽는다.

그래서 다음을 권한다.
- complex-fit 을 기본으로 한다.
- M*/decade 가 작은데(예: < 1.5) 잔차가 크면, M 을 몇 개 더 늘려 본다. 잔차가 잡음 수준으로
  떨어지면서 μ 가 다시 c 위로 오르면 '무효'가 아니라 `kk_not_judged` 로 적는다.
- 저주파 유도성 점이 있는 스펙트럼에는 μ 기준을 그대로 적용하지 말고 그렇다고 적는다.

## 우리 코드와 어긋나는 것

없음. 다만 헷갈리기 쉬운 차이가 셋 있다.
- `audit.misfit` 은 |Z_fit − Z|/|Z| 하나(= √(Δ_Re² + Δ_Im²))로 보고, 논문은 Δ_Re·Δ_Im 을
  따로 본다. 모순은 아니다. KK 보고에는 둘을 따로 싣는다.
- audit.py 의 3 %/10 % 는 회로 맞춤용 랩 경험치다. KK 문턱으로 옮겨 쓰면서 이 논문을 근거로
  달면 안 된다. 논문에는 수치 기준이 없다.
- `inductive_mask` 는 저주파 유도성 점(드리프트 포함)을 '셀의 측정'으로 남긴다. 남기는 것은
  맞다. 다만 KK 관점에서 드리프트 점은 시불변 조건을 어긴 데이터다. 그것이 화학적 인덕턴스인지
  드리프트인지 가르는 것이 KK 검사의 몫인데, 바로 그 경우에 μ 기준이 흔들린다(위 주의).
