## 7. 밝힐 것

1. **n1_b 는 검토자 반례 밖이다.** 같은 N1 결함의 ρ 파 변형이다 — 지금 코드는 ρ 파 하나가 중지되면 리스트 내포가 끊겨 뒤 ρ 가 미분류로 남는다. "모든 계획 행의
   분류" 를 닫으려고 같은 범위에 넣었다.
2. **ρ 선행 조건의 정의를 명시했다:** 앞 파가 전역 중지 없이 끝남 · 두 단일 목적 Phase A 완료 · 분모 유한 양수. 중지 뒤에는 의존 둘이 완료여도 ρ 를 돌리지 않고
   같은 범주 (`NOT_RUN:RHO_PRECONDITION`) 로 적는다. 새 범주는 만들지 않았다.
3. **`plan_counts` 의 완료 근거는 단계 A 가 기록한 완료 대조 사건이다.** 그 사건은 저장 행과 봉인 배열로 `phase_a_complete` 를 돌린 결과다. 봉인 배열을 인자로 받아
   다시 대조하는 길은 택하지 않았다 — 기존 c_7 의 호출 꼴 `plan_counts(store)` 를 지키려는 것이다. 판정 관문 (`rho_wave` · `_unit_state`) 은 지금처럼 행에서 다시
   대조한다. 그 대신 중지 경로에서도 1 파 완료 대조를 기록하도록 바꿨다.
4. **N2 정정은 중심 · 순회에만 한다.** 개별 양립의 격자점 소속 (`compat_individual` 의 `grid_t` = 등록 정확 분수) 은 그대로 둔다. 이유:
   - 명목 ± τ 점은 구간 끝점으로 등록된 점이다. 저장 float 로 판정하면 반올림이 끝점을 구간 밖으로 밀 수 있다.
   - 주장 등급은 증인의 실제 h_k 로 따로 정한다 (B §1-2 끝: 0 < 초과 ≤ 1e-10 → numerically_accepted).
   - **검토자 판단을 묻는다 (Q2).**
5. **N3 의 설계 선택 셋:** (a) NARROW_FOUND 의 부가 라벨은 고려한 증인 전부에서 · (b) 경계 행 LII 의 제약 절단은 증인이 없어도 · (c) `width` 의 `row` 는 선택
   키워드 (기존 l_2 가 row 없이 부른다 · 그때는 제약 절단을 붙이지 않는다). `_read_unit` 은 언제나 row 를 넘긴다.
