## 0. 결론 먼저 — 우리 질문에 대한 답

**한 문장**: 같은 NMC532 · LPSCl · Super P 조성 (활물질 80 wt%) 을 **무바인더 손혼합 펠릿 · NdBR 습식 슬러리 · PTFE 건식 반죽 (밀대로 접고 펴기 5 회)** 세 경로로 만들고, 셀에 넣어 누른 뒤 단면 SEM 에서 "활물질 둘레 중 SE 로 덮인 몫" 을 화상 처리로 재면 **30.6 · 33.3 · 67.2 %** — 건식만 두 배 — 이고 (p.2), 0.1 C · 60 °C 방전 용량이 같은 순서를 따른다 (**139.4 · 152.4 · 169.0 mAh g⁻¹**, 액체 전해질 코인셀 181.1, p.4).  저자는 이것을 "전단이 연성 황화물 SE 를 변형시켜 덮는다" 로 해석하고, COMSOL 2D 단일 입자 모델로 피복이 낮으면 **입자 안 고체 확산 거리**가 길어져 고율에서 이용률이 떨어짐을 보인다 (p.5–6).  **복합 전극 σ_ion 은 재지 않았고**, 모델은 SE σ (0.2–5 mS cm⁻¹) 에 무감하도록 꾸며져 있다 (p.6) — 우리 접촉망 수송 축과는 직교한다.

## 1. 한 줄 요약

황화물 전고체 양극의 건식 공정 (PTFE 섬유화 반죽 + 밀대 압연) 이 습식 (NdBR · 부틸 뷰티레이트) · 무바인더 손혼합 펠릿보다 좋은 이유를 **"피복률 (coverage)"** 하나로 설명하려는 논문.  단면 SEM 을 화상 처리해 활물질 둘레 중 SE 로 덮인 몫을 재니 건식 67.2 % · 습식 33.3 % · 펠릿 30.6 % (p.2) — 저자 해석 = 건식의 전단이 연성 LPSCl 을 변형시켜 활물질을 감싼다 (p.2 · Fig 1).  60 °C · 0.1 C 방전이 피복 순서 (169.0 > 152.4 > 139.4 mAh g⁻¹) 를 따르고, 건식은 율속 · 수명에서도 용량이 가장 높다 (Fig 5).  습식의 높은 계면 저항은 용매가 아니라 **바인더가 활물질을 덮은 탓** (용매 노출 SE 의 XRD · XPS · σ 대조 — S10–S12), 펠릿의 낮은 용량은 피복 20 % 미만 입자가 많아서 (S13) 라고 본다.  COMSOL 2D 단일 입자 모델 (피복 10–100 %, 덮이지 않은 호를 공극으로) 은 0.2–0.5 C 에서는 피복과 무관하게 거의 다 쓰이지만 1 C 부터 30 % 이하 피복 입자에 농도 기울기가 생기고, 5 C 에서 10 · 30 · 50 · 70 % 피복이 100 % 대비 12 · 45 · 72 · 91 % 만 쓴다 (p.6) — 입자 반지름을 2 µm 로 줄이면 10 % 피복도 다 쓰인다 (S18).

## 4. ★ 방법 — 측정 사슬 · 입자 처리

### 4-1. 측정 사슬
분말 (NMC532 · LPSCl · SP) → 세 경로 (손혼합 펠릿 / NdBR 슬러리 캐스팅 · 80 °C 진공 건조 / PTFE 반죽 · 85 °C 가열 · 밀대 압연 · 접기 5 회) → ⌀13 mm PEEK 셀에서 LPSCl 분리막 (103 MPa) 위에 전극 가압 (517 MPa [우리 산술]) → Li-In 음극 · 볼트 적층압 → 형성 3 회 → (i) 2.8 V 에서 EIS · DRT (ii) 0.1 C 방전 용량 (60 °C) (iii) 새 셀 GITT (iv) 율속 · 수명 (25 · 60 °C) / 별도로 단면 SEM (이온 밀링) → 화상 처리 → 입자별 피복 → 평균 · 분포 / 별도로 LPSCl–BB 안정성 / COMSOL 단일 · 다입자 모델 (피복 10–100 % · C-rate 0.2–5 C).
- ⚠ SEM 단면이 **셀에서 꺼낸 시료**인지, 같은 압력으로 따로 누른 시료인지 [미확인] (Fig 2 의 분리막 쪽 줄무늬 층이 보여 셀 시료로 보인다 [추정]).

### 4-2. ★ 입자 처리 (우리 축 언어로)
- **실험**: 실제 분말 — LPSCl 은 연성 (*"ductile sulfide solid electrolyte"*) 으로 전단 · 가압에서 **진짜 형상 소성** (건식 단면에서 NMC 를 감싸는 SE 막, Fig 2b) · NMC 는 단면에 균열 (펠릿 · 건식 큰 입자 일부) [판독].  "전단" 은 장비가 아니라 **손 반죽 + 밀대 압연 + 접기 5 회** (S1 사진).
- **모델**: 입자 1 개 (또는 6 개 줄) 의 2D 원 · 둘레의 일부를 공극 (절연) 으로 지정 — **입자 형상 · 접촉 · SE 망 없음** · 피복은 입력.
- 우리 대응: DEM = 강체 구 + 접촉 겹침 (δ 대리) · 혼합 DEM 에도 SE 소성은 없다 · MPM (물질점법) = 압축 중 SE 형상 소성 (혼합 전단 없음) ⇒ **전단으로 SE 가 펴져 덮이는 기전은 우리 두 모델 어디에도 없다** — 코팅 · 피복 상태는 우리 쪽에서 **입력**이지 결과가 아니다 (PTFE 카드 §4-7 과 같은 결론).

### 4-3. 기법 미니 용어집
- **피복률 (coverage, 이 논문)** = 2D 단면에서 활물질 둘레 중 SE 로 덮인 길이 몫 (공극이 아닌 몫).  우리 `coverage_AM_*` (접촉 원판 면적 ÷ AM 표면) · PTFE 카드 3D 피복 (NCM 표면 복셀 중 LPSCl 이웃 몫) 과 정의가 다르다 (§7-2).
- **DRT** = 임피던스를 이완 시간 분포로 풀어 과정별 저항을 가르는 법 · 주파수 구역 배정은 문헌 관례 (refs 41 · 42).
- **GITT** = 정전류 펄스 뒤 휴지로 과도 전압 − 정상 전압 (분극) 을 읽는 법.
- **SPM** (single-particle model) = 전극을 입자 하나로 대표하는 전기화학 모델 · 이 논문은 2D 로 펴서 둘레 일부를 막았다.
- **clumped / spaced** = 덮이지 않은 호가 한 덩어리 (뭉침) / 여럿으로 흩어짐 (S14).
- **CCCV** = 정전류 뒤 정전압 충전.
- **SOL** (state-of-lithiation) = 입자 안 리튬 농도 ÷ 최대.

### 7-2. ★ 피복 정의 대조 — 같은 낱말 · 다른 양
1. **차원**: 그들 = 2D 단면의 **둘레 길이** 몫 / 우리 = 3D **면적** 몫.  등방 무작위 단면이면 둘레 길이 몫의 기댓값 = 표면적 몫 (입체해석학 S_V ↔ L_A 관계) 이라 평균끼리는 비교할 수 있다 [추정 — 이 논문은 언급 안 함].  단, 입자별 값은 단면 위치 (적도 ↔ 극) 에 따라 흔들려 **분포 폭은 2D 가 더 넓다** [추정].
2. **"덮임" 의 판정**: 그들 = 빨강 (공극) 이 아닌 둘레 → AM–AM 맞닿음 · 카본 · 바인더 면이 "덮임" 에 들어가는지 [미확인] — 들어간다면 **SE 접촉만 센 우리 값보다 체계적으로 높다** [추정].  우리 Hertz 원판 (18 %) 은 탄성 접촉 반경 안만 · 기하 0.14 µm 띠 (49 %) 는 "거의 닿음" 까지 센다.
3. **화소 규칙**: SEM 가장자리 밝기 (edge effect) 가 "둘레 (노랑)" 를 만든다 — 판정 문턱이 [미확인] 이라 건식 Fig 2b 의 **42.0 % 표지 입자**처럼 주위에 빨강이 거의 안 보이는데 42 % 인 경우를 원문만으로 재현할 수 없다 [판독 · 추정].
⇒ **할 일**: 우리 침대에서 "그들 정의" 판을 하나 **추가**해 (기존 정의는 그대로) — (a) 2D 단면 둘레 몫 (b) AM–AM 면 포함 / 제외 두 판 (c) 입자별 분포를 20 % 구간 막대로 (S13 형식) — real_14 · ps45 에서 계산하면, 펠릿 (바인더 없음 · 우리 조성 띠) 의 30.6 % · "20 % 미만 입자 21 %" 가 첫 외부 대조점이 된다 (계산 = 결과 전 등록 뒤).

### 7-3. ★ 이종기술 논지 (`docs/hetero_thesis.md` 비준 블록 2026-10-05) 와의 관계
- **P1 (비코팅 · 혼합 시간 · SE–SE 응집)** · **P2 (코팅하면 응집이 사라진다)**: 이 논문은 **시험하지 않는다** — 코팅 팔도 혼합 시간 열도 없다.
- **P3 (혼합 상태 차이 → 압축 뒤 SE 경로)**: 정황만 — S5 · S6 (가압 전, 습식 = SE 덩어리 ↔ 건식 = 고른 SE 망) 과 Fig 2 (가압 뒤 피복 31–33 ↔ 67 %) 가 "혼합 · 성형 상태가 압축 뒤 SE–AM 접촉을 바꾼다" 의 실험 사례.  그러나 **σ_ion 을 재지 않아 "3D 이온 경로" 고리는 비어 있고**, 비교한 두 상태는 코팅 ↔ 비코팅이 아니라 **습식 ↔ 건식 (바인더 · 용매 · 성형 동시 변화)** 이다.
- **프레이밍**: 이 논문의 설명 축 = 피복 → 고체 확산 → 이용률 = 논지의 **"하지 않는 말" (계면 면적 · 보호막)** 쪽.  10-02 #55 의 *"coverage 가 아니라 건식 믹싱 분산"* 과 정면으로 다른 축 ⇒ 논지 문장의 근거로는 (i) 공정이 SE 분포 · 접촉을 바꾼다 (ii) 피복 측정 방법 — 두 가지만 빌리고, "피복 → 이용률" 기전은 빌리지 않는다.
- **KETI 단서**: §0 ① — 소속은 맞고 내용은 안 맞는다.  단서의 내용 ("코팅 → 혼합 응집 감소 → 분산") 에 가장 가까운 문장은 이 논문 ref 45 (Kim J. 2023 AFM, 한양대 · KICET · 고려대) 의 초록이다.  ⇒ 1저자 확인 질문: *"10-02 에 말한 KETI 논문이 Lee D. 2024 (Nat. Commun., KETI Seung Ho Choi · KyungSu Kim 교신) 인가, 다른 KETI 논문인가 — 그 문구가 있던 논문은 Kim J. 2023 (AFM) 쪽일 수 있다"*.  (메인 리포 `docs/project_ceramic_catholyte_singlecrystal.md` 의 과제 공동1 "KETI (최승호)" 와 이 논문 교신 "Seung Ho Choi (KETI)" 가 같은 사람인지는 [미확인] — 논문은 로마자만 인쇄.)

### 7-4. ★ "같은 총 SE 에서 코팅 상태" 실험 (`docs/mixer_paper_pipeline_draft_20261013.md` 집중 변수 V1 코팅 상태 · V2 혼합 시간 · V3 SE 함량) 에 주는 것
1. **성형 공정이 피복을 두 배 바꾼다** — 같은 17 wt% SE 에서 습식 33 → 건식 67 %.  우리 실험이 건식 PTFE 시트라면 시트 성형 (반죽 · 접기 · 압연) 이 비코팅 팔의 SE 를 이미 펴서 덮을 수 있다 (PTFE 카드: PTFE 0.2 wt% 가 in situ LPSCl 코팅) ⇒ **코팅 효과의 실측 크기는 성형 뒤에 작아질 수 있다** [추정].  설계: 코팅 · 비코팅 두 팔 모두 **같은 성형** + 성형 **전** 분말 시점의 EDS · 피복을 따로 (이 논문 S5 · S6 이 "가압 전" 선례, 분말 시점은 없다).
2. **무바인더 대조**: 이 논문의 손혼합 펠릿 (바인더 없음) 이 공정 효과와 코팅 효과를 가르는 대조군 꼴 — 우리 DEM 침대 (바인더 없음) 와도 1:1 이다.
3. **피복 측정 규약을 미리 적어 둘 것**: 이 논문이 빠뜨린 것 = 화소 규칙 · 문턱 · 단면 수 · 입자 선택 · 평균 방식 (개수 / 둘레 가중) · AM–AM 면 처리 — 결과 전에 정하지 않으면 31 vs 33 % 같은 차이가 정의 안의 차이가 된다 (§3-2 의 산술).
4. **σ_ion 은 대칭셀로 따로**: 이 논문은 복합 σ_ion 이 없다 — 우리 대칭셀 계획 (`docs/symmetric_cell_ionic_plan_20261013.md`, NCM : LPSCl 81.6 : 18.4 · 300 MPa · 순수 LPSCl 기준 펠릿) 이 바로 그 공백을 메운다.  순수 LPSCl 펠릿 σ₀ 는 성형 · 분말에 따라 0.8 (이 논문, 347 MPa) 처럼 우리 σ₀ 보고 기준 1.5 보다 낮을 수 있다 → 같은 성형 · 측정 조건의 기준 시료 필수.
5. **코팅이 SE 를 얼마나 쓰나**: 이 논문은 코팅 실험이 아니라 정보 없다 (→ 같은 묶음의 건식 코팅 논문들).

### 7-5. frame[5] — 어느 반쪽을 가졌나
- **가진 것**: 공정 (습식 · 건식 · 펠릿) → 압축 뒤 2D 피복 · SE/카본 분포 (정성) · 전기화학 (용량 · 율속 · 분극 · EIS/DRT) · 단일 입자 고체 확산 모델.
- **없는 것**: 3D 구조 · 접촉망 · SE 이온 망 수송 (σ_ion · tortuosity) · 공극률 · 두께 · 입경 · 혼합 모델 · 피복의 반복 통계.  ⇒ 우리 DEM (접촉망 수송 · 패킹 · 혼합) 과 MPM (형상 소성) 둘 다에 "공정이 피복을 바꾼다" 는 **실측 대조 지표** 하나 (피복 분포) 를 준다.

## 8. ★★ 우리 연구에 주는 insight (번호마다: 논문이 보인 것 → 우리에게 뜻 → 할 일)

**8-1. KETI 단서 — 소속 일치 · 내용 불일치.**
- 논문: 교신 KETI 2 인 (S. H. Choi · K. Kim) · 코팅 → 분산 문구 없음 · ref 45 (Kim J. 2023 AFM) 초록에 "SE 코팅층 → 전극 전체 SE 고른 분포" 문장.
- 뜻: 읽기 목록 B2-4 의 "KETI 소속 미확인" 은 **해소 (KETI 맞음)** · "단서 = 이 논문" 은 **미해소** — 내용 기준으로는 Kim J. 2023 이 더 가깝다.
- 할 일: 1저자에게 §7-3 의 질문 한 줄.  답이 오기 전까지 논지 §6 의 단서 서지는 *"KETI 논문 단서 — 후보 Lee D. 2024 (소속 일치 · 내용 불일치) · 내용 후보 Kim J. 2023 (KETI 아님)"* 로 둔다 (논지 문서는 이 카드가 고치지 않는다).

**8-2. 피복률의 첫 실측 대조점 — 단, 정의를 맞춘 판으로만.**
- 논문: 바인더 없는 손혼합 펠릿 (NMC/SE 81.2 wt%) 30.6 % · 20 % 미만 입자 21 % · 건식 67.2 % (S13 분포).
- 뜻: 우리 DEM 은 바인더 · 혼합 전단 없는 "펠릿" 쪽이다 — 우리 Hertz 18 % · 기하 띠 49 % 의 **사이**에 실물 펠릿 31 % 가 있다.  건식 67 % 는 강체 구 DEM 이 못 가는 영역 (MPM 소성 Tabor 띠 74 % 근처) [추정 · 정의 다름].
- 할 일: §7-2 의 "그들 정의 판" (2D 둘레 · AM–AM 포함/제외 · 20 % 구간 분포) 을 real_14 · ps45 에 추가 — 결과 전 등록.

**8-3. 공정 (전단) 이 조성보다 크게 피복을 바꾼다 — 우리 모델은 그 공정 축을 못 그린다.**
- 논문: 같은 조성에서 습식 → 건식 33 → 67 % (×2) · SE 함량 +1.5 wt% (펠릿) 는 오히려 피복이 낮다.
- 뜻: 우리 coverage 는 조성 · 입경 · 압력의 함수로만 나온다.  혼합 · 성형의 전단 소성 (SE 가 펴짐) 은 DEM · MPM 어디에도 없다 → 실험 피복과 맞추려 할 때 **그 차이를 접촉 법칙 (E 연화 · Stage-E) 으로 메우면 안 된다** (frame[4] — 공정 효과를 재료 매개변수로 흡수하는 순환) [추정].
- 할 일: 코팅 · 성형 상태는 **입력** (LC 팔의 같은 γ 표면 · 이미 덮인 표면의 시드) 으로 둔다는 기존 방침 유지 — 이 논문은 그 방침의 실험 쪽 이유.

**8-4. 작은 입자는 피복에 둔감 — 우리 바이모달에서 피복이 중요한 것은 큰 NMC (PC) 쪽.**
- 논문 (모델): R 2 µm 는 10 % 피복도 5 C 까지 완전 이용 (S18) · R 5 µm 는 5 C 에서 10–30 % 만 약한 기울기 (S17) · R 10 µm 는 1 C 부터 기울기 (Fig 4).
- 뜻: 우리 SC (반지름 2 µm) 는 이 모델 기준으로 피복과 거의 무관 · PC (4.5 µm) 는 R 5 µm 경우와 가깝다 [추정 — 그들의 D_s 미기재라 절대 C-rate 경계는 옮길 수 없다].  ps45 의 기전 (*"작은 NCM 이 많을수록 SE 가 그 표면을 덮는 데 쓰여 SE–SE 길이 끊긴다"* — 대칭셀 계획 §2) 과 합치면: **SC 표면을 덮는 데 쓰인 SE 는 이용률 이득이 작고 이온 망만 깎는다** — 코팅 · 분산 설계가 SE 를 PC 표면과 SE–SE 망 쪽으로 보내야 한다는 가설 [추정].
- 할 일: STEP4 (BV + 구형 확산) 에 상별 (PC · SC) 반응 면적 · 피복을 다르게 주는 감도 팔이 가능한지 코드부터 확인 [미확인] (PC · SC 분리 자체는 `--am-split-um` · `--d-s-poly/--d-s-sc` 로 있다 — 메인 CLAUDE.md 2026-07-21) → 결과 전 등록 · D_s 는 우리 문헌 밴드.

**8-5. 같은 피복이라도 덮이지 않은 곳이 뭉쳤나 흩어졌나가 이용률을 바꾼다.**
- 논문: 흩어진 공극 (spaced) 이 뭉친 공극보다 이용률이 높다 (5 C 30 % 피복 ≈2.9 vs 1.68 mAh cm⁻² [판독]) · SEM 상 공극은 뭉쳐 있다.
- 뜻: 우리 coverage 는 **몫**만 낸다 — 덮이지 않은 면의 군집 (가장 긴 연속 미피복 호 · 미피복 패치 크기) 이 고체 확산 거리를 정한다면, 같은 coverage 의 두 침대가 다른 이용률을 낼 수 있다 [추정].
- 할 일: AM 표면점 기반 coverage 계산에 "최대 미피복 패치 크기" 지표를 추가 후보로 (이종기술 P3 의 SE 경로 지표와 별개 · 원장 등록 뒤).

**8-6. 순수 LPSCl 펠릿 σ₀ 의 실측 한 점 — 0.8 mS cm⁻¹ @ 347 MPa, 상대밀도 ≈84 %.**
- 논문: 32 mg · ⌀6 mm · 1 TON · 725 µm · 304.9 Ω → 0.8 mS cm⁻¹ (25 °C) · 용매 노출 0.7.
- 뜻: 우리 σ₀ 보고 기준 1.5 mS cm⁻¹ (CLAUDE.md 2026-10-12 고정, 문헌 LPSCl 펠릿 1.0–2.2) 보다 낮은 펠릿 실측 — σ₀ 는 분말 · 성형 · 측정에 따라 두 배 가까이 갈린다 [우리 산술 · 추정].  용매 노출 −23 % 를 "negligible" 이라 쓴 판단도 참고 (§10).
- 할 일: 대칭셀 계획의 기준 시료 (순수 LPSCl 펠릿) 에 **질량 · 두께 · 가압 · 측정 압력**을 모두 기록 — 이 논문처럼 두께로 상대밀도를 거꾸로 낼 수 있게.

**8-7. DRT 주파수 구역은 전체 셀 기준 관례 — 대칭셀 TLM 에 그대로 옮기지 않는다.**
- 논문: Warburg 10⁻³–10⁻¹ · SE–음극 10⁻¹–10¹ · SE–양극 10¹–10⁴ · SE 입계 10⁴–10⁶ Hz (refs 41 · 42).
- 뜻: 전자 차단 대칭셀 (Li/LPSCl/전극/LPSCl/Li) 은 음극이 없고 TLM 의 이온 레일이 주인공 — 구역 배정이 다르다 (`malifarge2017_tortuosity_symmetric_cell_impedance_tlm` · `comparison_vs_ours_DEM.md` J 절).
- 할 일: 대칭셀 해석 규약에 주파수 구역을 **결과 전**에 적어 두기 (이 논문 구역은 참고만).

## 9. 인용 가능 문장 (deck/paper용 — 표지 그대로)
- "In a direct comparison of hand-mixed binder-free pellets, NdBR wet-processed and PTFE dry-processed NMC532–Li₆PS₅Cl cathodes of the same nominal composition, Lee et al. (*Nat. Commun.* 2024) report that the dry process roughly doubles the 2D cross-sectional SE coverage of the active material (67.2 % vs 30.6 % and 33.3 %)."
- "Their single-particle COMSOL model is insensitive to the SE ionic conductivity (0.2–5 mS cm⁻¹) by construction; it addresses solid diffusion inside the cathode particle, not ion transport through the SE network."
- 국문: *"같은 조성 (활물질 80 wt%) 에서 건식 공정이 활물질의 SE 피복률을 습식 · 무바인더 펠릿의 약 두 배로 올린다 (2D 단면 화상 처리, Lee 등 2024) — 다만 바인더 · 용매 · 성형이 함께 바뀌어 '전단' 효과만 떼어 낸 값은 아니다."*

## 10. 주의/한계 (over-claim 방지 · 원문 비판)
1. **피복 측정 재현성**: 화소 판정 규칙 · 문턱 · 소프트웨어 · 단면 수 · 입자 선택 · 평균 방식 [미확인] · 오차 없음 · Fig 2b 의 42.0 % 입자처럼 그림만으로 납득하기 어려운 표지가 있다 (§7-2).
2. **평균 방식에 따라 펠릿 ≈ 습식 판정이 갈린다**: S13 구간으로 본 개수 평균은 펠릿 35.3 · 습식 41.7 % (보고 30.6 · 33.3) [우리 산술 · 판독] — 보고 평균이 둘레 가중이라면 그 사실이 원문에 없다.
3. **교란**: 세 전극은 바인더 종류 (없음 · NdBR · PTFE) · SE 함량 (18.5 · 17 · 17 wt%) · 용매 (없음 · BB · 없음) · 성형 (가압만 · 캐스팅 · 반죽 + 가열 85 °C + 압연) 이 동시에 다르다 — 제목의 "shear force effect" 는 분리된 변수가 아니다 (저자도 결합 효과라 인정, p.4).
4. **"피복 ↔ 용량 상관"** 은 조건 3 개 (+ 액체 100 % 가정) · 0.1 C · 60 °C · 셀 2–7 개다 · 율속 · 수명의 셀 수는 [미확인].
5. **모델 재현 불가**: D_s · c_max · α · 평형 전위 값이 없다 · L_pos 25 µm · T 333 K · cs0 · C_dl 이 "tuned" · V 의 겉보기 밀도 2.73 g cm⁻³ (§3-6) · "Depth 36.378 m" 는 단위 그대로 인쇄.
6. **모델의 SE σ 무감은 결과가 아니라 설계**: 양극 두께를 입자 하나로 줄여 SE 망 수송을 일부러 없앴다 (p.5) — "SE σ 는 중요하지 않다" 로 일반화하면 안 된다.
7. **"negligible"**: 용매 노출 LPSCl 의 σ 0.8 → 0.7 (재계산 0.841 → 0.650, −23 %) 를 무시할 만하다고 적었다 (p.4 · S12).
8. **1 C 정의가 셋** (170 · 174.5 · 180 mA g⁻¹, §3-10) · 모델 "capacity retention" 은 같은 C-rate 의 100 % 피복 대비 비 (보통 뜻과 다름).
9. **율속 · 수명 셀이 서로 다르다**: 같은 0.5 C · 25 °C 의 펠릿이 율속 93.6 · 수명 첫 회 75.3 mAh g⁻¹ (§3-8).
10. **60 °C 고율에서는 펠릿 ≥ 건식** (1 C 78 vs 76 % · 3 C 68 vs 61 mAh g⁻¹) — 초록의 *"superior rate capability"* 는 25 °C 및 60 °C 저율에서만 무조건 성립.
11. **액체 대조군**: 조성 (PVDF 94:3:3) · 음극 (Li 금속) · 셀 형식이 달라 "피복 100 %" 기준으로서의 등가성이 약하다 · 고율에서 오히려 낮다 (S23).
12. **재료 정보 결손**: NMC532 · LPSCl · PTFE · NdBR 의 공급처 · 입경 · 분자량 · NMC 피복층 · 전극 두께 · 공극률 [미확인] — 우리 조성 띠와 같아도 입경 대조가 안 된다.
13. **용어 충돌**: 논문의 "MPM" = multi-particle model — 우리 MPM (물질점법) 과 섞지 않는다.
