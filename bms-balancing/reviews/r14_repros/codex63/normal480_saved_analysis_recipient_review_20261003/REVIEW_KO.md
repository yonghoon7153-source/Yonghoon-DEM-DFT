# NORMAL480 저장 결과 분석 수신 검토

2026-10-03. **판정: ACCEPTED_SAVED_ANALYSIS_0_480. 차단 결함 없음.** 0–480초 저장 자료의 전압 분해·시간 변화·선택 공간 프로파일 분석과 7쪽 PDF를 한정 수용한다. 이는 기존 480초 실행 수용에 덧붙이는 분석 수용이며, 전체 수렴·정상 gate INCOMPLETE를 바꾸지 않는다. 새 계산 승인도 없다.

## 확인한 범위

분석 ZIP의 28 payload와 manifest에 대해 정확 집합·크기·SHA-256·CRC·중복/대소문자 충돌·경로/링크를 확인했다. 별도 PDF는 ZIP 속 PDF와 바이트가 같다. 동봉된 이전 수신 리뷰 4개 파일도 검토자 보존본과 정확히 같다.

수용된 native ZIP 자체 SHA와 분석에 사용한 20개 원자료/소스 파일의 바이트 식별을 재대조했다. 받은 분석기·검증기·Java를 실행하거나 import하지 않고, 검토자가 작성한 별도 코드로 원 CSV를 읽어 Decimal 50자리 산술을 수행했다. 이 정밀도는 원자료의 물리 정확도를 뜻하지 않는다.

- 6개 원 시간표와 TIME_SERIES의 5,740시각이 정확히 같고 엄격 증가하며, 시작 0초·끝 480초다.
- TIME_SERIES의 56열, 321,440개 숫자 필드를 원자료에서 직접 대조하거나 재계산했다.
- 7개 구간 분해, 42개 전극별 기여, 112개 secant 변화율과 8개 주요 시각을 대조했다. 전체 구간·최근 120초 행은 앞 구간들과 겹치므로 합산하지 않는다.
- N/P 원 프로파일의 행 수는 각 1,383,340행이다. 전체 파일을 읽되 이번 재대조 대상은 8시각 × 2전극 × 241좌표 = 3,856행이다. 좌표·domain·단위 변환과 같은 좌표의 표면−입자평균 차가 모두 맞는다. 모든 나머지 프로파일을 다시 수치 감사했다고 주장하지 않는다.
- Java는 텍스트로만 읽어 평균 분율·Li·반응·누설 및 경계 Eeq 정의를 확인했다. 단위 read-back과 B020 선행 요약의 식별·차이도 맞는다.

## 해석과 PDF 판정

PDF 7쪽을 검토자 환경에서 Poppler 105 dpi로 렌더해 전부 확인했다. 글자·단위·부호·범례·표가 읽히고, 눈에 띄는 잘림이나 데이터와 반대되는 표시를 발견하지 않았다. 그래프 생성 소스도 정적으로 확인했다. 저장 시각을 직접 연결하며 smoothing/시간 보간으로 새 값을 만들지 않는다. 모든 PDF 벡터 점을 역산했다는 주장은 하지 않는다.

“N 경계 Eeq 하락이 가장 큰 양의 기여”는 부호를 포함한 대수적 분해로 맞다. 개별 phiL 이동의 큰 상쇄를 유지하고, 그것을 독립 물리 원인이나 인과 비중으로 부르지 않은 점도 적절하다. 기존 경계 Eeq와 direct_Eeq_surface 출력의 일치는 현재 모델 정의의 정합성이지 OCP 표의 실험 타당성 증명이 아니다.

최근 120초에 전압·평균 조성 변화가 남아 있으므로 정상상태 도달이나 향후 평탄화를 판정하지 않은 것은 타당하다. **정상상태 도달, 시간/공간 수치 수렴, 물리 타당성은 서로 다른 질문**이다. 정상상태 미확인이 이번 저장 분석 또는 한정 진단 실패를 의미하지도 않는다.

표본 guard=0, 작은 수지 잔차와 prefix 동등성을 연속 시공간 양수성·전체 수렴·실험 정확도로 확대하지 않았다. 보고서와 의사결정안의 한계 문구를 수용한다.

## 보존과 남은 경계

제출자의 선택 보존 기록은 23개 before/after가 같다. 이 23개 식별을 수신 측에 있는 native ZIP·이전 리뷰 ZIP·20개 입력·B020 요약과 연결했다. 이것은 제출자 PC의 현재 MPH·prefs·전체 프로세스를 직접 확인한 것이 아니다. 수신 원본 PDF·ZIP은 검토 전후 SHA가 같다.

이번에는 분석 전달물과 데이터 의미를 검토했다. 제출자의 분석 실행 전 과정·사후 포장 예산을 독립 OS 관측으로 감사한 것은 아니다. 이를 위해 완료된 native 검토나 분석을 재실행할 필요도 없다.

COMSOL/JVM/launcher·받은 시험/분석 코드 실행 0, 원본 수정 0, 외부 발송 0. 실효 정책·실제 코어 UNVERIFIED, 전체 수렴·정상 gate INCOMPLETE, 기존 실패/pending/원복·생성 영수증 recipient=null·OCP 외삽 금지·TIME_CAPS 원인 미확인·후보C 보류는 불변이다.
