## 1. 정의

**한 방향 순차 연계 (one-way sequential handoff)**: DEM 이 활물질과 전해질을 300 MPa 까지 누른 **끝 상태**를 MPM 에 넘기고, MPM 은 그 활물질을 **움직이지 않는 장애물**로 둔 채 **전해질만 다시 누른다**.  MPM 의 결과는 DEM 으로 돌아가지 않는다 (되먹임 없음).

- 결합 (coupling) 이 아니다 — 두 모델이 같은 시간 루프에서 힘을 주고받지 않는다.
- MPM 은 압축 과정 전체를 계산하지 않는다 — DEM 끝 상태에서 시작하는 짧은 재압축이다.

## 3. 이름 규칙 (원고 · 보고 · 덱 · 웹앱 문구)

| 쓴다 | 쓰지 않는다 (이유) |
|---|---|
| "DEM → MPM 한 방향 순차 연계" · "DEM 끝 골격 위에서 전해질만 다시 누른 MPM" | "DEM–MPM 결합 (coupling)" · "DEM–MPM 연성 해석" (힘을 주고받지 않는다) |
| "두께 비교" 에는 정지 규약 · f 출처를 함께 적는다 (생산 킷 = 정지 규약이 정함 · FAM 서보 = f 를 빌림 · 독립 = f = 0 팔뿐) | "DEM 과 MPM 의 기공률이 일치 · 교차검증" (같은 고체 부피를 넣었으니 맞는다 · `CDX-16`) |
| "두께에서 정해지는 기공률" | "MPM 이 예측한 기공률" (독립 예측처럼 읽힌다) |
| "MPM 소성 피복 (DEM 골격 위)" · "소성 증분 = 소성 − 기하" | "MPM 피복" 만 단독으로 (기하 몫이 DEM 것임이 가려진다) |
| "MPM 격자 위 복셀 전도도 (계면 저항 없음 · CONTACT_FREE)" | "MPM 이 수송까지 독립 검증" (기하 · 계면 모두 조건부) |
| "MPM 은 압축 끝의 재압축 구간만" | "MPM 이 압축 전체를 계산" · "가압부터 탈압까지 MPM" (지금 방식에는 없다 — [DEM 우선 (수영)] 재설계의 목표) |

- 예전 기록 · 덱의 같은 문장은 고쳐 쓰지 않는다 (역사 기록).  새로 쓰는 문서부터 이 규칙을 따른다 — 원고 · SI 를 고칠 때 이 표로 훑는다.

## 5. [DEM 우선 (수영)] 과의 관계

이 문서의 "물려받음" 칸 (활물질 위치 · 접촉망 · 전해질 양과 시작 자리 · f) 과 "없음" 칸 (탈압) 을 **계산으로 바꾸는 것**이 재설계의 목표다.  재설계 결과를 보고할 때는 칸마다 무엇이 물려받음에서 계산으로 바뀌었는지를 이 표에 대어 적는다.
