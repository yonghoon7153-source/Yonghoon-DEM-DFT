## 0. 한 줄 요약 (발표의 척추)

**"지금까지 쌓은 DFT 경험으로, 도펀트 *전구체*를 계산이 먼저 고르는 스크리닝을 만들고 있다 — 이렇게 돌렸고, 지금 이것이 돌고 있고, 다음엔 이것을 돌려 실험에 넘긴다."**

이번 발표는 결과 보고가 아니다. 보고하는 것은 세 가지다.
- 시뮬레이션을 **어떻게** 돌렸나
- 지금 **무엇이** 돌고 있나
- **무엇을 위해서** 돌리나 (목적)

순위·우열 같은 결론은 말하지 않는다.

## 2. 장별 — 핵심 한 문장 · 말할 거리 · 넘어가는 말

### 1. 표지 (0.5 분)
- "오늘은 DFT·MLIP 기반 도펀트 스크리닝의 **진행 상황과 계획**을 말씀드리겠습니다."

### 2. Background — 지금까지의 DFT (2.5 분)
**핵심**: 여러 계를 계산하면서 쌓은 방법들이 이번 스크리닝의 단계가 되었다.
- 칸마다 한 줄씩만 말한다 (그림 자리는 채우는 중).
  - 기준선 Li₆PS₅Cl: 밴드갭, EOS, 탄성
  - Nd/O: 밴드 엣지, −ICOHP, CEI — 실험팀과 협업
  - B₂O₃·O 도핑: EOS, BVSE, MLIP-MD
  - h-BN@VGCF: Li 흡착·이동 NEB, 층수 효과
  - Li₃N·Li₂S: SEI 성분의 Li 이동 장벽 (NEB, 셀 수렴)
  - 계면 접착: DEM 접촉 입력
  - SDCP: 스핀 상태별 흡착
- 맨 아래 파란 줄로 이어 간다: *"EOS·탄성 → 기준 계산, BVSE → Li 지형, MLIP-MD 프로토콜 → 수송 단계, 대권위 상도 → 안정창, 계면 에너지 → 계면 반응성"*
- ⚠ 숫자는 말하지 않는다. 특히 **접착에너지 값, li2s(소셀 유리) 수송값은 절대 말하지 않는다** — 칸에도 숫자가 없다.
- ➜ "이 경험을 바탕으로 지금 하고 있는 일이 다음 장입니다."

### 3. Overview — 목적 · 끝난 것 · 도는 것 · 다음 (1.5 분)
**핵심**: 목적은 **계산이 전구체를 고르게 하는 것**, 그것도 **선택 규칙을 먼저 정해 두고**.
- 끝난 것:
  - 89/91 전구체를 배치 열거하고 MLIP 로 완화 (3,615 구성)
  - DFT EOS
  - 안정창 재계산
- 도는 것:
  - MLIP-MD 수송 비교 (12/40 런)
  - DFT 탄성상수
- 다음:
  - 바닥상태 상으로 계면 반응 다시 보기
  - 선택 규칙 → 짧은 목록 → DFT 검증 → 실험
- 아래 파란 줄을 그대로 읽는다: *"지금 기술자(descriptor)는 탐색용이고, 도펀트 순위는 아직 내지 않는다."*
- ➜ "왜 여러 축을 같이 봐야 하는지부터 보겠습니다."

### 4. Introduction — 결합된 실패 모드 (1.5 분)
**핵심**: 전기화학 열화와 기계 열화가 엮여 있어서, 한 축만 고치면 다른 축이 나빠질 수 있다.
- Kang et al., Chem. Commun. 2026 그림으로 설명한다 — 양극 산화 분해, 음극 환원, 균열·접촉 손실.
- ➜ "그래서 여러 축을 한꺼번에 거르는 스크린이 필요한데, 선행 연구는 무엇을 바꿔 가며 거렀는지 보겠습니다."

### 5. Prior work — 선행 스크린이 바꾼 것 (1.5 분)
**핵심**: 선행 스크린은 **원소 하나를 자리 하나에** 넣거나 **호스트 없이 화합물만** 걸렀다. 우리는 **전구체 화합물 하나가 양이온·음이온 자리 두 개를 동시에** 채운다.
- 표를 읽는다:
  - Miara: 가넷, 원소 하나 · 자리 셋
  - Lee: argyrodite, 원래 화학식의 원소
  - Xiao: 호스트 없음, 코팅 화합물
  - 이번 작업: 전구체 화합물 · 89/91 · 역학 축은 DFT 기준 + MLIP 기술자 (관문 아님)
- 아래 '관련 스크린' 은 이름만 짚는다: Sendek 2017 · Kahle 2020 · Jung 2026 · Park 2026 · Muy 2025.
- ➜ "그 전구체 후보가 어떤 것들인지 보겠습니다."

### 6. Candidate set — 91 전구체 · 7 음이온족 (1 분)
**핵심**: +1~+6 양이온과 O²⁻~I⁻ 음이온을 짝지은, **실제로 존재하는** 화합물만 골랐다. 89/91 을 계산했다.
- As₂S₃ 는 유효한 배치가 안 나왔고, AlI₃ 는 기술자 세트가 불완전했다. **미완이지 탈락이 아니다.**
- 아래 줄을 짚는다: 전구체 공치환 선례 — CuCl · MgF₂ · ZnO · La₂O₃ · Nd₂O₃.
- ➜ "이 후보들을 어떤 순서로 계산했는지 한 장으로 보겠습니다."

### 7. Workflow — 시뮬레이션 흐름과 상태 (2 분)
**핵심**: 8단계이고, 단계마다 엔진(MLIP / DFT / 상도표 자료)과 상태가 다르다.
- 1–4 (끝): 배치 열거 → MLIP 완화 3,615 → 짧은 담금질 681 → BVSE (구조 지표)
- 5: EOS 는 끝, Cᵢⱼ 는 GPU 에서 계산 중
- 6: 안정창 재계산 (9–10 월)
- 7: 계면 반응성 다시 보기 예정
- 8: Li 수송 MD 진행 중 12/40
- 색으로 상태를 보여 준다: 초록 = 끝, 파랑 = 진행, 주황 = 재계산, 회색 = 예정.
- ➜ "1–3 단계를 조금 자세히 보겠습니다."

### 8. Configuration sampling — 배치 표본과 MLIP 완화 (1.5 분)
**핵심**: 자리를 가정하지 않고 **전하 균형이 맞는 배치를 전부** 만들어 완화했다. 그리고 짧은 담금질로 가까운 국소 최소에서 빼냈다.
- 왼쪽 열지도: 9개 자리 쌍이 모두 쓰였고, 합계 3,615 이다 (CSV p08).
- 오른쪽 도식: 500 K · 50 ps 담금질 뒤 다시 완화한다.
- ⭐ 아래 파란 줄이 중요하다: *"같은 전구체의 구성끼리 차이가 서로 다른 전구체 사이 차이만큼 큰 기술자가 있다 → 그래서 기술자는 탐색용이고 순위용이 아니다."*
- ➜ "MLIP 결과의 기준이 되는 DFT 계산을 보겠습니다."

### 9. DFT reference — EOS · 탄성상수 (1 분)
**핵심**: MLIP 기술자를 잡아 줄 DFT 기준점이다.
- Birch–Murnaghan EOS: B₀ 26.2 GPa (Li₆PS₅Cl) · 21.7 GPa (Li₅.₄PS₄.₄Cl₁.₆). 부피는 **f.u. 당**으로만 비교한다 (−4.3 %).
- 탄성상수 Cᵢⱼ 는 GPU 에서 계산 중이다. 숫자는 아직 말하지 않는다.
- 그래프는 Origin 으로 다시 그린다 (CSV p09 = 적합 곡선; DFT 원점 8·11 개는 레포에 없다).
- ➜ "다음은 안정창과 계면 반응성입니다."

### 10. Stability window · interfacial reactivity (2 분)
**핵심**: 대권위(grand-potential) 상도표로 Li 화학퍼텐셜을 전압으로 훑는다. **Li 교환 없이 분해되는 전압 구간**을 안정창으로 정의해서 89종을 다시 계산했다.
- 예시로 호스트를 든다: 1.717 V ~ 2.140 V, 폭 0.423 V (MP 상 · 0 K · CSV p10).
- 이전 정의는 창 폭을 과대평가했다. 그래서 정의를 통일해 다시 계산했다.
- 창이 없는 조성은 '창 없음' 으로 기록한다.
- 오른쪽 그림: Sundar 2025 의 방식을 인용한다 — 같은 상 자료로 Li₆PS₅Cl · Li · 양극과의 반응에너지를 본다.
- 우리 산물 분석은 **바닥상태 기준 상(E_hull = 0)으로 다시 하는 중**이다.
- ➜ "이제 지금 돌고 있는 수송 계산입니다."

### 11. MLIP-MD 수송 — 설계 (2 분)
**핵심**: 질문은 하나다. **전구체 음이온(Al₂O₃ vs Al₂S₃)이 Al 도핑 Li₆PS₅Cl 의 Li 확산을 바꾸나?**
- 왼쪽 상자 둘: 같은 호스트 구성 · 같은 부피에서 음이온만 다르다 → 보고량은 **D(Al₂O₃)/D(Al₂S₃)** (상대량).
- 오른쪽 표:
  - UMA · NVT Langevin · 1000 K · 생산 400 ps · MSD 맞춤 2–50 ps
  - 204 원자 · 공통 부피
  - 시작 구성 10 × 전구체 2 × 시드 2 = 40 런
- ⭐ **분석 계획은 돌리기 전에 고정했다.**
  - 확산 영역 점검: 부분창 기울기비 0.8–1.2 · D 흩어짐 ≤ 10 % · Li 홉 ≥ 50 · 골격 유지
  - 그 다음 로그비에 동등성 검정 (여유 ±ln 1.5)
- 이 장에서 '절대 전도도' 는 말하지 않는다.
- ➜ "왜 1000 K 인지, 지금 어디까지 왔는지, 한계는 무엇인지 보겠습니다."

### 12. 수송 — 온도 선택 · 진행 · 한계 (2 분)
**핵심**: 600 K 파일럿은 확산 영역에 못 들어갔다. 그래서 **미리 정한 파일럿 규칙으로** 1000 K 를 골랐다. 결과는 **상대적이고 조건 한정**이다.
- 600 K 파일럿 (40 런 · 200 ps): Li 는 런당 약 4,000 번 홉했는데, MSD 가 2–100 ps 에서 끝내 선형이 되지 않았다 → **확산계수를 보고하지 않았다** (UMA · 이 셀 · 이 부피).
- 온도 선택: 800 K 는 점검 탈락, 1000 K 는 통과.
- 진행 막대: 12/40 런 · 101/461 GPU-시간 (10-12 기준 · **발표 전에 watch 로 갱신**) · 10월 21일께 끝날 것으로 본다 → **40 런이 다 끝나면 한 번만** 분석한다.
- 오른쪽 Jung 2026 Fig. 5b: 1300 K 에서 맨 아래인 물질이 700 K 에서는 맨 위다 → **고온의 순서가 상온으로 그대로 옮겨지지 않는다.**
- 한계 둘:
  - 셀 ≈ 1.6 nm 는 MLIP 수송의 벌크 하한 ~2 nm (Phuthi 2026) 보다 작다.
  - 고온 순위는 상온과 다를 수 있다.
- ➜ "그래서 다음에 무엇을 하는지입니다."

### 13. Plan — 다음 단계와 목적 (1.5 분)
**핵심**: 수송 판정을 한 번 하고 → 세 축을 인용 가능하게 만들고 → **선택 규칙을 먼저 정한 뒤** 짧은 목록을 실험에 넘긴다.
- 지금 ~ 10월 말: 40 런을 끝내고 한 번 분석한다. 결과 네 경우(차이 / 동등 / 미정 / 기준 미달)마다 다음 일을 **분석 전에** 적어 둔다.
- 1–2 달:
  - 바닥상태 상으로 계면 반응 산물을 다시 본다.
  - 정정된 정의로 안정창 표를 만든다.
  - 기준 조성의 DFT 탄성상수를 마친다.
- 그 다음: 선택 규칙 → 짧은 목록 → DFT 검증 → 실험팀과 합성·평가.
- 방법 개선:
  - 더 큰 셀 (≥ 2 nm)과 더 긴 런 (≥ 0.3 ns)
  - 미세조정 MLIP
  - 앙상블 불확도
  - 전하중성 결함 열역학으로 실제 농도 추정
- 파란 줄을 읽는다: *"목표는 전구체를 고르는 스크린, 선택 규칙은 미리 정한다."*

### 14. Summary (0.5 분)

## 3. 말하지 않는 문장 (원장 규율 · 질문에 끌려가도)

- "○○ 도펀트가 제일 좋다" 같은 순위, Top-N, 점수 지도의 우열 — 승인된 순위는 0건이다.
- "47종을 끝냈다", 47→43→25→11 같은 깔때기 숫자.
- x002/x005/x010 을 농도로 말하기. "3,615 개의 설계" 라고 말하기 (3,615 는 생성된 구성 수다).
- 옛 안정창 숫자. 예: "다섯 개가 0.05 V 미만", 호스트 0.898 V.
- 계면 산물 통계. 예: "693 반응 중 69 % 금속 산물" (HOLD).
- 수송 숫자 전부: v5/v6 의 D · 비 · Ea, v7 중간값, 절대 전도도.
- 수송 서술 셋:
  - "600 K 에서 Li 가 확산하지 않는다" → 대신 "MSD 가 선형이 되지 않아 확산계수를 정의하지 않았다".
  - "레시피 효과가 없다"
  - "1000 K = 확산이 시작되는 온도" → 대신 "미리 정한 점검을 통과한 온도".
- 탄성 modelc_2x 숫자 (아직 판정 전).
- 접착에너지 값, li2s(소셀 유리) 수송값 — 어떤 장에서도.
- Nd 를 이 스크리닝으로 사후 정당화하는 말 (Nd 는 협업 트랙이고, 지금 스크린은 어떤 도펀트도 고르지 않는다).

## 4. 예상 질문과 짧은 답

| 질문 | 답 |
|---|---|
| 그래서 어떤 도펀트가 제일 좋은가? | 아직 순위를 내지 않는다. 같은 전구체의 구성끼리도 기술자가 크게 흩어지는 축이 있어서, 지금 값은 탐색용이다. 선택 규칙을 먼저 정하고 짧은 목록을 DFT 로 확인한 뒤 고른다. |
| 왜 1000 K 인가? 상온과 다르지 않나? | 600 K 에서는 200 ps 안에 확산 영역에 못 들어갔다. 온도는 결과를 보기 전에 정한 파일럿 규칙으로 골랐다. 결론은 1000 K · 이 셀에 한정된 상대 비교다 (Jung 2026 Fig. 5b 에서도 고온과 저온의 순서가 뒤집힌다). |
| 셀이 작다 — 유한크기 효과는? | 1.6 nm 는 Phuthi 2026 이 제안한 ~2 nm 하한보다 작다. 그래서 같은 셀 · 같은 부피에서 두 전구체를 비교하는 상대량만 낸다. 큰 셀은 다음 단계 방법 개선에 넣었다. |
| 전도도(σ)는 왜 안 내나? | Nernst–Einstein 으로 σ 를 내려면 Haven 비를 가정해야 하는데, 실제로는 1 이 아니다 (Marcolongo 2017). 그래서 추적자 확산계수의 비만 낸다. |
| 안정창 정의는 왜 바꿨나? | 문헌처럼 'Li 교환 없이 분해되는 구간' 으로 통일했다. 이전 정의는 창 폭을 넓게 잡았다. 그래서 89종을 다시 계산했다. 결과는 MP 상 기준 0 K 열역학이고, 반응 속도나 부동태를 뜻하지 않는다. |
| MLIP 를 믿을 수 있나? DFT 검증은? | 구조와 상대에너지는 MLIP 로 거르고, EOS · 탄성은 DFT 로 기준을 잡는다. 최종 짧은 목록은 DFT 로 검증한다. 수송은 절대값이 아니라 같은 조건의 비만 쓴다. |
| 실험과는 어떻게 연결되나? | 선택 규칙 → 짧은 목록 → DFT 검증 → 실험팀 합성·평가. 계산이 고르고 실험이 확인하는 순서다. |
| 예상 일정은? | 수송 40 런은 10월 21일께 끝난다 (GPU 를 나눠 쓰면 늦어진다). 계면 · 안정창 표 · 탄성은 1–2 달. |

## 6. 용어 — 화면에 쓴 말 (분야 용어)

| 화면 | 뜻 |
|---|---|
| MLIP / universal MLIP (UMA) | 기계학습 원자간 퍼텐셜 · 범용 모델 |
| grand-potential phase diagram | 대권위 상도표 — Li 화학퍼텐셜을 전압으로 훑는다 |
| stability window (no Li exchange) | Li 교환 없이 분해되는 전압 구간 |
| tracer diffusivity ratio | 추적자 확산계수의 비 (상대량) |
| diffusive-regime checks | MSD 가 선형(확산) 구간인지 미리 정한 점검 |
| equivalence test (margin ±ln 1.5) | 두 값이 1.5 배 안에서 같다고 말할 수 있는지 보는 검정 |
| analysis plan fixed before the runs | 사전 고정 분석 계획 (결과 보고 규칙을 바꾸지 않는다) |
| start configurations / seeds | 시작 구조(Li·공공 배열) / 속도 난수 |
