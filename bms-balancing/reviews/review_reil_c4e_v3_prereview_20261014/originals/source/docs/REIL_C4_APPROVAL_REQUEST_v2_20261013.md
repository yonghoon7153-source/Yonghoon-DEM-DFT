4. **감시 · 기록 보완 (C4-N2 · N3) — 필수 합성 사례:**

     간격을 기록하고, 성공 여부와 무관하게 공백을 검사한 뒤 마지막 유효 시각을 갱신한다.
   - 조회 뒤 현재 시각으로 마감을 검사한다. 마감 뒤에는 새 작업을 시작하지 않는다.

     하위 경로만 허용한다. Git 상태 원문을 분류 결과와 따로 보존한다. 모호한 경로 표기는 자체 산출로 간주하지 않는다.
