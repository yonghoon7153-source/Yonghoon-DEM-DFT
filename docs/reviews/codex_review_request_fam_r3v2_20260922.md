## 1. 공격해 주기 바라는 점
1. **판정축**: 두께 하나로 충분한가.  ε_sphere 를 게이트에서 뺀 이유(솔리드 부피가 씨앗으로 고정 ⇒ 두께의 산술)가 맞는가.
2. **±3 % 창**: 사전값의 근거가 약하다.  DEM 두께의 프레임 산포를 어떻게 재야 정당한가.  더 좁거나 넓어야 하나.
3. **규약 (a)/(b) 둘 다 팔로**: (b) = (a) + 0.5·share_AM–SE 라는 항등식이 4압력 침대에서 ±0.0005 로 성립했다.
   두 팔이 **같은 정보**를 두 번 재는 것은 아닌가 — 아니면 AM–SE 몫의 배분이 곧 물리적 질문인가.
