# reference cell 실행 계획

## 이 문서가 무엇인가

[[reference-cell-500-600-mahg]] · [[operating-stack-pressure-floor]] ·
[[dc-polarization-conductivity-separation]] 세 곳에 흩어져 있던 **"다음에 무엇을 하는가"** 를
한 장으로 모은 것이다. 근거는 digest 23편이고, **각 줄이 왜 그 순서인지와 무엇으로 판정하는지**
를 함께 적었다.

⚠ **이것은 지도이고 정본이 아니다.** 실험 수치의 정본은 **실험 노트와 원 데이터**다
(루트 `CLAUDE.md` 하드룰 4). 여기 적힌 우리 숫자는 사본이며 인용 근거가 아니다.
그리고 **아직 한 줄도 실행되지 않았다** — 이 페이지는 처방이고 측정 기록이 아니다.

## 왜 이 순서인가 — 두 원칙

1. **셀을 적게 쓰는 것부터.** 1·2단계는 **셀을 거의 쓰지 않거나 한 셀을 재사용**한다.
   수명 실험을 먼저 돌리면 분모와 운전 조건이 정해지지 않은 데이터가 쌓인다.
2. **분모를 가장 먼저 확정한다.** digest 23편 중 **8편이 이론용량을 초과**해 보고하고, 우리
   목표 500–600 자체가 **1전자 천장 583 을 걸친다**. **"이용률" 이라는 말이 성립하려면 분모가
   먼저 있어야 한다** → 0단계.

## 실행 순서

### 0. 분모를 확정한다 — 셀 2개, 활물질 없음

| | 내용 |
|---|---|
| **무엇** | **(a)** `LPSCl : AB = 80 : 20` 대조셀 (활물질 없음) **(b)** 첨가제를 검토한다면 `LiI : LPSCl : AB` 도 |
| **왜** | 우리 SE 가 내는 용량을 빼지 않으면 Li2S 이용률을 계산할 수 없다. digest 23편 중 **이 셀을 돌린 논문은 둘뿐**(Cronk 2026 · Wang XinXu 2026)이고 **후자는 대조 전압창이 자기 활성화 컷오프를 덮지 못했다** |
| **★ 조건** | **활성화 컷오프까지 올려서** 돌린다. 그리고 **하한도 우리 운전 하한까지 내린다** — Hao 2025 는 전압창 0.8–2.6 V 에서 `[도표]` 용량의 **28–43 %가 1.2 V 아래**에서 나왔다 |
| **판정** | 여기서 나온 mAh g⁻¹(composite) 가 **모든 이후 셀에서 빼야 할 양**이다. 외부 눈금: `[재현]` Wang Daiwei 2025 **4–6 %** · Gao 2024 **28–52 mAh g⁻¹(composite)** |
| 비용 | 셀 2개, 수명 불필요 |
| 가르는 것 | **H4(단위 착시)** |

### 0-b. 같은 시료로 분광 대조도 찍는다 — 비용 거의 0

★ **`[재현]` 우리 30:50:20 양극은 총 황의 58.8 %가 LPSCl 에서 온다**
(LPSCl M = 268.37, S 59.73 wt% → 29.9 wt% vs Li2S 유래 20.9 wt%).
→ **S 2p XPS 나 S K-edge XANES 를 찍으면 신호의 과반이 활물질이 아니다.**

| | 내용 |
|---|---|
| **왜** | 이 함정에 **세 편이 빠졌다** — Kim JT 2023(SE 황 42 %, 차감 없음 → Li2S2 어깨 귀속이 무너졌다) · Hao 2025(40.1 %) · Feng 2026(58.0 %, **우리와 거의 같다**) |
| **어떻게** | 0(a) 의 `LPSCl + AB` 시료를 **같은 조건·같은 날**에 함께 찍어 배경으로 쓴다 |
| 가르는 것 | 모든 분광 귀속의 전제 |

### ★ 0-c. 우리 복합분말을 그대로 XRD 에 건다 — 셀을 쓰지 않는다 (2026-10-02 추가)

| | 내용 |
|---|---|
| **무엇** | **우리 one-step 복합분말**(셀로 만들기 전)을 XRD 에 걸어 **LiCl(200) / LPSCl 피크비**를 본다. 가능하면 **혼합 시간 3점**(½ / 표준 / 2배)과 **손혼합 대조 1점** |
| **왜** | `leej2025_…`(*Science* 388, 724)가 **2000 rpm 5 h UHS 혼합 중 LPSCl 에서 할로겐이 분리되어 LiCl 층이 생긴다**고 보였다. **우리 LPSCl 은 전량이 밀링을 겪는다** → **이미 생기고 있을 가능성**이 있다 |
| **판정** | 나오면 우리 **"밀링이 SE 를 망가뜨린다"(H2b) 서사의 일부가 "이미 일어난 계면 설계"** 가 된다. 안 나오면 우리 밀링이 **그 문턱 아래**라는 뜻이다 — 그 논문의 **400 rpm·1 h 대조에서는 분리가 전혀 없었다** |
| 비용 | **셀 0개, 하루.** 분말만 있으면 된다 |
| 가르는 것 | **H2b 의 두 항**(SE 벌크 전도도 하락 vs 계면상 생성) 중 우리 쪽에서 어느 것이 일어났는가 |

★ **같이 할 것**: **Raman 의 PS₄³⁻ 위치**(425 vs 418 cm⁻¹)를 혼합 시간별로 본다 — `park2026` 이
**밀링 없이 접촉만으로도** 425 → 418 cm⁻¹ 를 보였으므로, 두 논문이 같은 축에서 만나는지 알 수 있다.
⚠ 다만 **두 현상은 기전이 다를 수 있다** — `park2026` 은 **Li2S(환원제)** 계이고 `leej2025` 는
**S8/Se/Te(산화제)** 계다.

### 1. 압력-EIS 스윕 — 셀 1개, (압력 × 온도) 2×2

| | 내용 |
|---|---|
| **무엇** | 압력 **0 / 1 / 3 / 5 / 10 / 15 / 30 MPa** 에서 EIS. **복귀 구간**(올렸다 내리기)을 넣어 가역성까지 본다. 온도 **상온 / 60 °C** 두 번 |
| **왜** | 문헌 운전압이 **0–200 MPa** 로 흩어져 베껴 쓸 수 없고, **포화 압력이 전극계마다 5–15 MPa 로 움직인다.** 압력에 근거가 없으면 이후 모든 비교가 흔들린다 |
| **왜 2×2** | **압력 하한이 온도와 독립이 아니다**(P5). Feng 2026 이 `[인쇄]` "practical stack pressure 를 유지한 채 접촉을 확보하려고 60 °C 를 골랐다" 고 적고 뒤에서 **상온이 장기적으로 낫다**고 자인한다 |
| **판정** | 저항이 평탄해지는 압력이 **우리 셀의 포화점**이다. 그 아래로는 가지 않는다. 복귀에서 저항이 안 돌아오면 **비가역 접촉 손실**이다 |
| 비용 | **셀 1개 반나절 × 온도 2** |
| 가르는 것 | **운전 조건 결정** + [[operating-stack-pressure-floor]] P1–P5 |

★ **기본값은 "압력으로 해결" 쪽이다.** 온도를 올려 접촉을 보상하는 쪽이 장기적으로 불리하다는
것은 Feng 2026 자신의 자인이다.

### 2. DC 분극 — σ 를 세 칸으로 나눠 잰다

프로토콜 전문은 [[dc-polarization-conductivity-separation]]. 요점만:

| | 내용 |
|---|---|
| 전자용 셀 | **`Cu ¦ 시료 ¦ Cu`** (재질을 적는다) |
| 이온용 셀 | **`Cu ¦ Li–In ¦ LPSCl ¦ 시료 ¦ LPSCl ¦ Li–In ¦ Cu`** |
| **인가 전압** | **전자 ±20 mV · 이온 ±40 mV, 각 6점 다점 스캔, 각 1 h** — ★ **1 V 를 쓰지 않는다**(황화물 SE 안정창을 넘겨 **분해 전류를 전자 전류로 읽는다**) |
| **★ 시료를 둘로** | **(i) 분말 단독 펠릿**(활물질 입자 칸) **(ii) 복합양극 펠릿**(퍼콜레이션 칸) — **같은 재료에 대해 둘 다** |
| 스윕 | **AB 10 / 20 / 30 wt%** × **밀링 이력**(one-step / two-step) |
| 반복 | **n ≥ 3**, s.d. 를 적는다 (문헌 9편 **전부 오차막대가 없다**) |
| 두 셀 통일 | **성형압·두께를 같게** 만들고 그 값을 적는다 |

**왜 두 칸을 다 재는가**: Hong 2026 이 같은 재료 변경에서 **입자 칸 > ×8500 인데 복합체 칸은
×1.36** 이었다 — **입자 개선이 탄소 퍼콜레이션 고원에 묻힌다.** Hao 2025 · Feng 2026 은
입자 칸만 재서 성능을 설명했고, 그 설명이 성립하는지 확인할 길이 없다.

| 판정 | 뜻 |
|---|---|
| AB 함량에 따라 복합체 σ_e 가 **거의 안 변한다** | 우리는 **고원 위**다 → H2a 약화, AB 를 늘릴 이유가 없다 |
| **변한다** | 고원 아래다 → H2a 살아 있고 AB 함량이 지렛대다 |
| **밀링 이력**에 따라 σ_Li⁺ 가 변한다 | **H2b** — 밀링을 겪은 LPSCl 이 superionic 이 아니다 |

⚠ **수명까지 같이 본다.** σ_e 에 **상한이 관측됐다**(Wang Daiwei 2025 의 MIEC30 은 첫 방전이
가장 높은데 5사이클에 퇴화) — 첫 충전만 보면 최적점을 넘긴 것을 못 본다.
⚠ 측정 펠릿이 운전 전극보다 **수십 배 두껍다** → **절대값이 아니라 조성 간 비(ratio)로만** 쓴다.

### 3. 컷오프 스윕 — 상한과 하한 둘 다

| | 내용 |
|---|---|
| **상한** | **3.0 / 3.3 / 3.6 V vs Li/Li⁺.** Zhang(3.0, 활성화 미완) ↔ Lee(3.62, 초과 용량)의 충돌을 우리 셀에서 가른다 |
| **★ 하한** | 우리 운전 하한을 **함께 스윕**한다. Hao 2025 에서 용량의 **28–43 %가 1.2 V 아래**였고, Kim JT 2023 은 하한을 내리며 920 → 1300 mAh g⁻¹(S) 로 부풀렸다 |
| **왜** | H1 의 재정의판 — **"활성화를 끝내는 전위가 SE 가 견디는 전위보다 높은가."** 사다리 14편 중 **그것을 해낸 논문은 0편**이다 |
| **판정** | 각 컷오프의 첫 충전량에서 **0단계 대조셀 몫을 뺀다.** 상한을 올려야만 활성화가 끝나면 H1 확정 |
| 가르는 것 | **H1** |

### 4. 집전체만 바꾼다 — n=3

| | 내용 |
|---|---|
| **무엇** | 우리 표준 셀에서 **양극 집전체만** bare Al ↔ 탄소 코팅 Al. **75 MPa 와 1단계에서 정한 포화압** 두 조건 |
| **왜** | Park 2026 이 **조성·SE·탄소·대극·성형압·온도를 전부 고정하고 집전체 표면만** 바꿔 10 MPa 상온 **350사이클 78 % vs 10사이클 붕괴**를 보였다. 그리고 **pristine 에서는 셋이 사실상 같고(3.7 %) 차이가 사이클 뒤에만** 생긴다 |
| **판정** | 차이가 크면 **H5b(집전체 계면)**, 없으면 **H5a(양극 내부)**. **처방이 완전히 다르다** — 후자는 조성·입도·성형압, 전자는 **박 교체로 하루** |
| 비용 | 셀 6개 (이 위키 **최초의 n>1 압력 데이터**가 된다) |
| 가르는 것 | **H5a vs H5b** |

### 5. 비용 0 — 셀을 만들 때마다 그냥 적는 것

- **첫 충전 전후 셀 높이**를 다이얼 게이지로 한 번. Qu 2025 의 `[인쇄]` 14–20 µm 수축(그 절반이
  Li2S 첫 충전 한 번)은 LVDT 없이도 보인다.
- **구속 방식**: 정압(스프링·로드셀)인가 **정용적(볼트)**인가. 볼트면 **10사이클 후 재조임 +
  전후 EIS**. ⚠ Qu 2025 는 정용적 셀 압력이 첫 사이클들에 **−0.60 MPa** 빠지는 것을 보였다 →
  **"10 MPa 에서 350사이클" 같은 수는 초기 체결값**이다.
- **초기 10–20 사이클 용량 추세의 부호.** 올라가면 **활성화가 첫 충전에 끝나지 않는다**
  (Gao · Hong · Hao 세 편에서 관측). ⚠ 다른 후보는 **SE 분해물의 전기화학적 활성화**이고
  부호만으로는 못 가른다.

## 모든 셀에 공통 — 기록 체크리스트

이 표의 빈칸이 곧 문헌이 빠뜨린 칸이다 ([[composite-cathode-mixing-routes]]).

**밀링·혼합**: 장비·모델 · 용기 재질·부피 · **볼 재질·지름·개수** · **총 투입량**(가장 빠지기
쉬운 칸 — 어떤 논문은 볼 질량·지름·용기까지 적고 이것만 빠뜨려 BPR 이 계산되지 않았다) ·
**BPR**(문헌 23편 중 **4편만** 적는다) · rpm · **순 밀링 시간과 on/off 주기** ·
**★ 밀링 후 XRD 로 확인한 상**(= 반응이 일어났는가 — 밀링이 합성 반응기일 수 있다) ·
분위기 · 단계 수와 각 단계의 조성.

**셀**: 성형압과 시간 · **운전 구속압과 그 압력이 유지값인지 초기 체결값인지** · 구속 방식 ·
셀 형식·면적 · 온도(숫자로) · 로딩과 **그 로딩의 질량 기준** · 음극 조성과 **N/P**.

**N/P 계산식** (Feng 2026 에서 `[재현]` 복원): `음극 호스트 두께 × 공극률 × 0.534 g cm⁻³ ×
3861 mAh g⁻¹ ÷ 양극 면적용량`. ★ **분모는 반드시 실측 면적용량으로 쓴다** — 이론용량을 쓰면
N/P 가 1.03 으로 보이지만 실측으로는 1.40 이다.

## 숫자를 적을 때의 규율

1. **비용량에 분모를 항상 붙인다** — `(S)` / `(Li2S)` / `(composite)`.
   환산 **(Li2S) = (S) × 0.69783**. ⚠ **활물질이 Li2S 가 아니면 환산하지 않는다**
   (Li2SexS1−x 같은 고용체는 분모가 다르고 천장도 내려간다).
2. **이용률은 두 천장으로 병기한다** — `2e⁻ 기준 X % (1e⁻ 기준 Y %)`.
   2e⁻ **1672 (S) / 1166 (Li2S)** · 1e⁻ **836 / 583**.
   ★ **우리 목표 500–600 이 1전자 천장 583 을 걸친다** — "절반쯤 활성화" 와 "1전자를 거의 다
   쓴 상태" 가 같은 수로 보인다 ([[capacity-normalization-li2s-vs-sulfur]]).
3. **전압에 기준전극을 항상 붙인다.** ★ **`vs Li–In` 값은 환산하지 않는다** — 이 위키에
  오프셋의 근거 raw 가 없다(+0.62 V 의 유일 출처인 LSV 가 SI 미확보). 환산하면 `[재현]` 과
  가정을 명시한다.
4. **"overpotential" 을 그대로 옮기지 않는다.** **활성화 전위**(평형 대비 개시)와 **ΔV**(충·방전
   전압 간격)는 다른 양이고, 문헌에서 **두 편이 ΔV 를 과전압이라 불렀다.**
5. **CE > 100 % 는 좋은 신호가 아니다.** anode-free 로 가면 **음극 Li 이 양극으로 넘어오는** 뜻일
   수 있다. 넘는 만큼을 **Li 재고 손실로 가정**하고 적는다.
6. **"개선 배수" 를 쓰기 전에 대조군을 본다** — (a) 같은 공정을 겪었는가 (b) **대조군 CV 에
   피크가 있는가.** 없으면 그 배수는 **전극 결함의 크기**다. 문헌의 pristine Li2S 첫 방전이
   `disputed` 로 **110배 흩어져 있고**, 그 산포는 Li2S 물성이 아니라 **전극 레시피**로 읽힌다.
7. **n 과 오차를 적는다.** 문헌 23편이 거의 전부 n=1 이다 — 우리가 n=3 을 적으면 그것만으로
   비교 가치가 생긴다.

## 어느 단계가 어느 가설을 가르는가

| 가설 | 가르는 단계 |
|---|---|
| **H1** 활성화 제한 (완료 전위 > SE 산화 전위) | **3** (+ 0 으로 SE 몫 차감, 5 로 사이클 추세) |
| **H2a** 전자 퍼콜레이션 | **2** (AB 10/20/30 × 두 칸) |
| **H2b** 밀링이 SE 를 깎았는가, 계면상을 만들었는가 (2026-10-02 에 둘로 쪼갰다) | **0-c** (XRD·Raman, 셀 0개) + **2** (밀링 이력 축) |
| **H3** 입자 제한 | **2 의 밀링 축** + 입도·XRD 기록 |
| **H4** 단위 착시 · SE 리독스 | **0 · 0-b** (+ 활물질만 바꿔 초과분을 면적용량으로 보는 교차검증 — [[capacity-normalization-li2s-vs-sulfur]]) |
| **H5a / H5b** 양극 내부 vs 집전체 계면 | **4** (+ 5 의 셀 높이) |
| **H6** 전자수 제한 (1전자 천장) | **3** + 충전 종료 전극 **S 2p XPS**(0-b 의 배경 차감 필수) |
| 운전 압력 하한 | **1** |

## 한계·불확실성

- **한 줄도 실행되지 않았다.** 각 단계의 "판정" 은 예상이고 관측이 아니다.
- **0단계가 분모를 완전히 닫지는 못한다.** Feng 2026 에서 **풀셀이 반쪽셀보다 큰** 초과가
  나왔고 그것은 SE 가 아니라 **음극 Li 재고가 양극으로 넘어온 것**으로 읽힌다 — 즉 초과 경로가
  최소 둘이다. 0단계는 SE 몫만 잡는다.
- **2단계의 절대값을 다른 논문과 비교할 수 없다** (측정 펠릿 두께, 문헌의 인가 전압 미기재).
- **1단계의 2×2 는 (압력, 온도) 평면의 두 점일 뿐**이다. 하한이 곡선이면 두 점으로는 모양을 모른다.
- 목표 문구가 미결이다 — **"첫 사이클 500–600" 인지 "N 사이클 뒤 500–600" 인지.**
  Feng 2026 의 pristine 대조셀이 20사이클에 667 까지 갔다가 **165사이클에 ≈190 으로 붕괴**했다.
  이것은 **사용자가 정할 사항**이고 정해지면 3·4단계의 수명 길이가 바뀐다.
