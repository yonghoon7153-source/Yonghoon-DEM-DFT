## 1. 한 줄 요약

ETH 취리히의 Ziegel 과 오르후스 대학의 Kiderlen 은 Kiderlen–Rataj 의 점근 정리 — **격자 간격 t → 0 에서 2×2×2 배치 (B, W) 의 출현 수 N_t 는 평균적으로 t⁻² ∫ h_(B,W)(n) S₂(Z, dn) 처럼 행동한다** (h = "그 배치를 가르는 평면들의 띠 폭", S₂ = 표면 넓이 측도) — 를 써서, 배치 수의 가중합이 넓이를 재는 **오차를 h-함수의 선형결합과 상수 1 의 최대 편차로 정확히 묶는다**. 정보를 가진 배치 102 개 (쌍둥이 동일시 58 부류, 5 형) 의 h-함수가 펼치는 공간은 **50 차원**이고, 구면을 96 개 지지 삼각형으로 나눠 볼록 최적화하면 **점근 최악 상대오차의 최솟값 0.0398 (3.98 %)** — 이것이 2×2×2 국소 추정기의 **최선**이다. 기존 가중치는 7.3 % (Lindblad 2005 · Schladitz 2006) · 12.8 % (Lindblad–Nyström 2002). 최적 가중치는 2-매개변수 (r, s) 족이고 등방 물체에 대해서는 **+0.66 … +1.23 % 의 편향**을 갖는다 (원하면 C(s) 로 나눈다). 같은 배치 수로 **표면 넓이 측도 (법선 분포)** 를 50 매개변수 모형 (이산 · 조각 상수) 으로 추정해 **이방성을 정량**한다 (회전 타원체 0.9/1.1/1.1 의 이방성이 뚜렷이 보임).

## 4. 방법 ★
- **대상 집합**: compact 이고 **gentle** (경계의 축소 법선다발 측도 유한 + 거의 모든 경계점에서 안·밖 양쪽에 접하는 열린 공이 있음) — 볼록체 · 볼록 고리의 위상적 정칙 집합 · 양의 도달 집합의 일부 합집합을 포함 (p. 66).
- **디지털화**: Gauss — Z ∩ t(U + Z³), U 는 단위 정육면체 균일 무작위 (**평행이동만 무작위**, 회전은 아님). 점근 항등식은 **부피 문턱 디지털화에도 성립**하므로 확장이 "즉시" 라고 적는다 (p. 65).
- **Theorem 2.1**: lim_{t→0+} t^{−(d−1)} E N_t = ∫ h_(B,W)(n) S_{d−1}(Z, dn), h_(B,W) = (h(B ⊕ W̌, ·))⁺ (지지함수의 양수부) — 기하적 의미: 법선 u 의 평면 중 B 와 W 를 가르는 것 (u 가 B 에서 멀어지는 쪽) 들의 **띠 폭**. 정보 배치 = 가르는 초평면이 있는 경계 배치 · 비정보 배치는 점근적으로 무시 가능.
- **h-함수 계산**: 보이는 꼭짓점 (Lemma 2.1, Algorithm 1) → h = min_i ⟨p_i, ·⟩⁺ (형 1·5 는 3 개, 형 2·3·4 는 4 개의 보이는 꼭짓점) · 지지 = 구면 삼각형/사각형 (`Fig. 1–5`, `Table 1`).
- **가중 최적화**: H_λ(u) = Σ λ_j h_j(u) 가 1 에 가깝게 — 상대 최악오차 ≤ ‖H_λ − 1‖_∞ (식 9–10). 지지 삼각형마다 H 는 선형 → 볼록 함수 G 의 최소 (Lemma 5.1) → 두 종류 삼각형 (`Fig. 6`) 에서 수치 최소.
- **형 1 처리**: 점근적으로 중복이라 기본 가중 0 · Proposition 4.2 로 형 1 에 양의 가중을 주고 다른 가중을 줄이는 1-매개변수 족 (식 15) — 점근 오차 불변.
- **입자 처리 칸**: 전지 아님 — 대상은 연속 집합 하나의 디지털화. 다중 라벨 (세 입자가 만나는 곳) 은 다루지 않는다.

## 7. 우리 DEM+MPM 대비 ★★

### 7-1. (a) 최선 한계가 말해 주는 것
- 우리 쪽 "면 세기" (STEP4 `A_face` · r1 막 · 면 걷기) 는 **가중 없는 형-무관 세기**라 이 계열의 맨 아래다: 평면 하나에서 L1 = 1–√3 배 (`lindblad2005_…` §3-3). 2×2×2 가중을 쓰면 **어떤 가중으로도** 점근 최악 3.98 % 아래로는 못 간다 — **국소 배치만 보는 한** 의 한계다.
- ①′ CNC 는 이 한계 밖에 있다: 접점마다 **해석 원판 넓이**를 알고 총량을 맞추므로 총량 편향 0 (`lindblad2005_…` §7-2). 이 논문의 한계는 **해석 넓이를 모르는 계면** — MPM 변형 뒤 SE–SE · AM–SE 접촉면, 실침대 면 걷기의 절대 넓이 — 에 적용된다.
- 해석 법선을 아는 계면 (AM 구) 은 면마다 1/L1(n) · \|n_k\| 가중으로 한계보다 나은 정확도를 얻는다 (`lindblad2005_…` 표 C — 0.9998–1.0000 @ r/h 40) — **법선 정보가 추가 정보**이기 때문 (이 논문의 한계는 배치 수만 쓸 때).

### 7-2. (b) 진단에 넣을 때의 함정 (pilot)
- 큰 구에서 등방 편향 **+0.64 % (r 0, s 1.6631) · +1.24 % (r 1, s 1.7452)** 가 나와야 정상 (C(s) 재현 = 구현 검증) — pilot ✓ (`lindblad2005_…` 표 A).
- **작은 구 (r/h < 3) 에서 r = 0 선택은 무너진다**: pilot −14 % (r/h 1.67) · −40 % (1.0) · −86 % (0.625). 작은 구는 형 1 (c₁) 이 지배하는데 (`lindblad2005_…` `Fig. 11`) r = 0 은 형 1 에 가중 0 을 준다. r = 1 은 반대로 +6 … +57 % 과대. ⇒ 이 가중치는 저자 말대로 *"good or very good resolution"* 전용 — 우리 SE (r/h 0.6–10) 에는 Lindblad 가 안전하다.

### 7-3. (d) MPM 피복 메모에 주는 것
- **부피 문턱 디지털화**: 메모 §4-1 측정 격자의 SE 셀 판정 (점 수 n/8 ≥ ½) 은 Gauss 가 아니라 부피 문턱 부류다. 이 논문은 점근 항등식이 부피 문턱에도 성립한다고 적는다 (p. 65) — 단 **가중치 값이 그대로 옮는지는 보이지 않았다** (n/a).
- **이방성 census**: 메모의 면 걷기 피복 비율은 피복 영역의 방향이 분모와 같을 때만 상쇄된다 (`lindblad2005_…` 표 C: 극 모자 −9.1 % · 띠 +7.1 %). AM 은 해석 법선이 있어 직접 셀 수 있지만, **변형된 SE 표면** 이나 실측 FIB-SEM 영상처럼 법선을 모르는 경우 이 논문의 조각 상수 모형 (50 칸) 이 **배치 수만으로** 법선 분포를 준다 — 압축축 (z) 쪽 접촉 몰림을 검사하는 도구.

## 8. 적용 인사이트 (내 연구에 어떻게)
- ① **"국소 배치로는 최악 4 % 아래 불가"** — 넓이 정확도 목표를 정할 때의 바닥. 그 아래가 필요하면 법선 정보 (해석 · 추정) 나 참값 정규화 (CNC) 가 있어야 한다.
- ② **진단의 구현 검증 상수**: 큰 구 C(s) = 1.0066 / 1.0094 / 1.0123 — 경우 분류·가중 적용 버그를 잡는 기준 (pilot 이 0.02 %p 안에서 재현).
- ③ **등방 불편이 필요하면 C(s) 로 나눈다** — 이 가중치는 최악을 줄이는 대신 등방 평균에 +0.7–1.2 % 를 남긴다 (Lindblad 는 반대로 등방 불편 · 최악 7.3 %). **우리 침대 (입자 방향 무작위) 는 Lindblad 쪽 기준이 맞다.**
- ④ **법선 분포 census** — 피복 비율 · STEP4 반응면 비율이 방향 상관으로 치우치는지 미리 검사.

## 9. 인용 가능 문장 (deck / paper 용)
- (EN) *"For surface-area estimators based on weighted counts of 2×2×2 voxel configurations, the asymptotically optimal weights give a worst-case relative error of 3.98 %, which is the best possible for this class; previously published weights reach 7.3 % (Lindblad 2005; Schladitz et al. 2006) and 12.8 % (Lindblad & Nyström 2002) (Ziegel & Kiderlen, Image Vis. Comput. 28, 64, 2010)."*
- (KR) *"2×2×2 배치 가중 넓이 추정기의 점근 최악 상대오차는 최선이 3.98 % 이며 (Ziegel & Kiderlen 2010), 기존 가중치는 7.3 % 와 12.8 % 이다."*

## 10. 주의 / 한계 (over-claim 방지) ★
1. **점근 (t → 0) 결과** — 유한 해상도에서는 *"시뮬레이션이 시사"* 할 뿐 (p. 65 · `Fig. 7` 최대 1.5 % @ r/t 10). 우리 작은 SE (r/h < 3) 에는 성립하지 않는다 (pilot).
2. **평행이동만 무작위** (회전 고정) 가정 — 그 아래서는 *"배치 수 기반 불편 추정기가 없어 보인다"* 고 적는다 (p. 64). 회전까지 무작위인 Lindblad 2005 의 MVUE 와 기준이 다르다.
3. 최적 가중치는 **등방 물체에서 +0.66 … +1.23 % 편향** (C(s)) — 불편이 필요하면 나눠야 한다.
4. (r, s) 의 자연스러운 선택은 없다 — 형상 정보가 있으면 비슷한 형상으로 시뮬해 고르라고 권한다 (p. 74). 구 최적 (0, 1.6631) · 원기둥 최적 ≈ (1, 1.7452) 이 다르다.
5. **이진 · 단일 집합** — 다중 라벨 · 3중선 · 접촉하는 두 물체의 계면은 다루지 않는다.
6. 법선 분포 시뮬은 구와 회전 타원체 하나 (t = 0.02) — *"not very general"* (저자).
7. pilot 수치는 scratch 1 회 계산 — 원문 수치가 아니다.

## 11. 용어 미니-글로서리
- **배치 (B, W)**: 2×2×2 격자점의 검은 (물체) / 흰 (배경) 분할 · **정보 배치** = 둘을 엄밀히 가르는 평면이 있는 경계 배치.
- **h-함수**: 법선 u 방향으로 B 와 W 를 가르는 평면들의 띠 폭 — 배치 수 기대값 = t⁻² ∫ h dS₂.
- **표면 넓이 측도 S₂(Z, ·)**: 법선이 집합 A 안에 있는 경계 부분의 넓이 — 정규화하면 **rose of normal directions** (법선 분포).
- **gentle 집합**: 이 정리가 성립하는 약한 정칙 조건의 집합 족.
- **쌍둥이 (twin)**: 중심 반사 + 흑백 교환으로 같은 h-함수를 갖는 배치 쌍 · n_j = 부류 안 배치 수 (1 또는 2).
- **λ̄ⁱ (r, s)**: 형 i 의 최적 가중 · s = 형 5 가중 축 · r = 형 1 로 옮기는 몫.
- **C(s)**: 단위 구에서의 점근 추정/참 — 등방 정규화 상수.
- **부피 문턱 디지털화**: voxel 부피의 반 이상이 물체면 검은 voxel (Gauss = 중심 판정 과 다른 규칙).
