# v0.3 — 코팅 · 실제 장비(Thinky) · van der Waals 로 다시 세우기 (2026-09-20)

> 코팅은 침대의 유동성을 회복시킨다. Thinky(268 G) 는 코팅 없이도 유동한다. **그리고 우리는 혼합도를 아직 잰 적이 없었다.**

## 쉬운 판

세 가지를 한 번에 했다. ① AM 표면을 황화물 SE 로 코팅하면(표면 물성이 SE 가 됨) 응집체가 풀려
**자유 유동으로 돌아온다**. ② 실제 공정 장비는 60 rpm 드럼이 아니라 **Thinky 자전·공전 믹서(약 2000 rpm, 268 G)** 라는 것을
확인해, 중력을 올리는 대신 Bo 를 1/268 로 낮춰 같은 무차원 물리로 맞췄다 — Thinky 조건에선 코팅 없이도 유동한다.
③ 응집력의 기원을 **van der Waals 분산력(표면에너지 γ, Hamaker 상수)** 으로 명시하고, 문헌(`hare2026`, NMC622 · CGF 200)에서
`Bo ≈ 3` 앵커를 찾았다. 우리 모델은 JKR 이 아니라 SJKR 이므로 γ 를 직접 넣지 않고 **Bo 로 앵커**한다.

그런데 이 시점에 1저자 질문 *"우리가 보고 싶은 걸 볼 수 있는 거야?"* 로 큰 구멍이 드러났다:
침대를 **처음부터 균일 혼합 상태로 삽입**하고 회전시켰기 때문에, 지금까지 잰 것은 유동성(응집 여부)이지
**혼합도가 아니었다**. 이것은 v0.6 에서 고친다.

## 자세한 판

- 코팅 `C1`: AM 쌍 CED 를 SE-SE 값으로 **덮어쓴다**(입자 크기·질량 불변 → `Bo` 는 따라 나온다). 결과 `Bo` 0.0235. 등록 검정은 `E1` 대비 h0(0.57·SE)이나 `E4→C1` 로는 범위의 85 % 회복, `core_frac` ×1/24.
- 고-G: 1저자 정정 — 영률 1e7 은 임의 연화가 아니라 **스케일 팩터**(압축 덱이 `P/E` 를 보존). 중력을 올리면 `Π₁ = ρaR/E` 가 5.7e-6 → 1.5e-3 로 실제(5.4e-10)에서 **멀어진다** ⇒ `Bo` 만 1/G. `T1`(Thinky, Bo 0.079) 1.527 · `T2`(볼텍스 45 G, Bo 0.472) 1.750 · `E4` 2.016 — 단조.
- vdW 재정박: `hare2026` γ 0.25 J/m² → Bo 3.0, `frankenberg2024` Γ 0.0045 → Bo 3.3. γ 는 55배 달라도 Bo 는 같은 대역 ⇒ 전이 대상은 **Bo**. ⚠ 우리는 SJKR 이라 γ 를 못 넣고 `MIX-07` 로 등재.
- `MIX-08`(P1): 삽입이 `insert/pack … once` 로 5 상을 한꺼번에 무작위 배치 → t=0 이 이미 완전혼합(셀별 AM 분율 sd 0.0383). **혼합도는 잰 적 없음.** 이 이전의 모든 결론은 유동성 축으로 라벨을 고쳤다.
