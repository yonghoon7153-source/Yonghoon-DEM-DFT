# 보정 전 믹싱 첫8 준비·관측 연결 — 독립 반박 요청

**이번은 새 구현 단위다.** 수용된 초안/NOTE01의 반복 문구 확인이 아니다. 저자 Q1–Q4 채택에 따라 첫8의 정적 준비와 관측 연결을 구현했다. 고정 리뷰 핀은 ZIP의 PIN.txt이며 작성 측은 종결하지 않는다. 실제 연구 결과0건·호스트 접근/실행·활성 발사 등록 없음, 전체 HOLD.

2. N0/E0의 영 점착·삽입·0/2바퀴·공통 재료/시간 계약이 별도로 검증되는가? 옛 schema1 등록 주장을 가져오거나 Bo0를 표준 GM에 허용하는 우회가 없는가? 준비 PASS를 STL·바이너리·실제 MPI·동역학 자격으로 올리지 않는가?
3. `scripts/mixer_precal_observe.py`가 해시한 덱·메타·덤프·로그 bytes에서 같은 데이터를 읽고, 실제 인쇄 반경·타입·프레임/기하·E0를 결속하는가? 파일·목록·의존 소스 변경, 메타 위조, 중복/결손/격자 밖 프레임에서 값이 남는 반례를 찾아 달라.
4. D13 총누락≤10·ID1..N·후속 ID/type/radius 보존과 계획/관측수 병기가 맞는가? 새 상별 상한 없이 관측 상별 차이를 보존하는가? E0는 같은 기하/세대/seed의 균일·영점착·0회전이어야 하며 N0나 옛 E0로 대체할 수 없는가?
5. 군집·“믹서 판독 전용 AM–SE 접촉 부착”·기존 M이 한정대로 계산되는가? SE 공통 분모/타입별 중복, 세 격자·n_min20·실제 반경, 자기t0/E0분모·원분산/QC·비유한/미정의 상태를 확인한다. 피복·이론 분모·통계 유의성·실물 코팅 효과로 확대하지 않는다.
6. fresh 로그 오류/재개/부재/중단·잘못된 완료 행은 TECH이며 contact/M을 내지 않는가? 로그 조건 일치를 프로세스 종료·rank·같은 실행·체크포인트 이력의 인증으로 과장하지 않는가? 현재 제출·큐 계획 없이 D0.7 종료 후·저자 승인 후 조건을 유지하는가?

## 2. 시험과 증거 읽기

직접 시험은 `scripts/test_mixer_precal_prepare.py`, `scripts/test_mixer_precal_observe.py`다. 생성·판독 대상은 메모리 덱/작은 합성 덤프이며 LIGGGHTS를 실행하지 않는다. 표준 라이브러리·numpy·scipy가 있는 환경에서 해당 Python 파일을 실행한다. `scripts/check_all.sh`와 `.github/workflows/discipline.yml`에 두 시험을 연결했지만 전체 게이트를 이번에 통과했다고 주장하지 않는다.

준비기는 실제 고정 옵션의8개 덱과3짝을 정적으로 대조한다. 관측의 작은 덤프 시험은 준비 binding을 명시적으로 mock하며, 한 회전 wiring 시험은 cell_stats도 mock한다. 이 경계와 모의 없는 입력 결속 확인의 범위는 `docs/reviews/mixer_precal_first8_preparation_20261104/evidence/validation_summary.json`에 적는다. 단위시험 개수와8조건·3짝을 합산하지 않는다.

최초 시험 먼저 로그는 모듈 부재 import 실패(시험0건)다. 이후 내부 반례2건은 실행된 assertion 실패로 별도 보존했다: 해시→파일 재열기 사이의 교체/복귀, ERROR 로그의 값 반환. 수정 뒤 rawbytes 파싱·fresh 완료 로그 조건을 도입했고 원 반례와 새 직접 시험을 함께 보존했다. 내부 점검은 독립 종결이 아니다. Source SHA가 다른 중간 검토 결과를 최종 소스 전체 검증으로 세지 않는다.

마지막 보완은 명시적5열 thermo와 각 run 누적 endpoint의 결속이다. 그 시험의5개 실패 subcase를 보존했고 최종 관측20개·준비14개가 각 Python3.8/3.11에서 통과했다. 실제 로그 호환성 및 모의 없는100000입자 양성 전체 경로는 미검증이다. 파서 의존성인 `make_mixer_resume.py`도 소스 해시에 포함하지만 재개 기능은 실행하지 않는다.

## 3. 유지할 경계

기존 D2·M·접촉·D3 생성/판독기, 수용된 초안/NOTE01/D3 SOP, 옛 확인18런, 예약seed와 공유 기록 넷은 변경하지 않았다. MXD2R는 별도 외부 재확인 대기다. 이 새 관측 연결을 검토하되 그 외부 판정을 임의로 대신하지 않는다.

이번 요청은 실제 ibb/WSL·연구 계산·슬럼·재시도·원자료 열람·등록·실험·배포·Claude 통합·원장 종결을 포함하지 않는다. 새 P1/P2/P3가 있으면 재현 조건·최소 수정·대상 핀을 남기고, 없으면 **첫8 정적 준비·합성 관측 연결 범위**만 수용 여부를 판정한다. 물리 실행 GO는 별도다. 발송·진행 순서는1저자, Rint② 우선.
