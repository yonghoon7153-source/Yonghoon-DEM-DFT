# ADR 0003 — 마스코트는 실제 ご当地キャラ 이고, 그림은 권리 범위 안에서만 쓴다

- 상태: 채택 (2026-09-27)
- 관련: `data/mascots.json`, `src/mascots/art.ts`, `docs/CHECKLIST.md` #16

## 맥락

첫 판은 "쿠마모토에 곰" 같은 오리지널 캐릭터였다. 하지만 이 지도의 재미는
**진짜** 캐릭터 — くまモン, ぐんまちゃん, ひこにゃん — 를 만나는 데 있다 (비준: 2026-09-27).
문제는 권리다. 캐릭터 그림은 각 자치체·단체의 저작물이고 규정이 제각각이다.
くまモン 은 개인의 비상업 이용(개인 블로그·SNS)에 신청이 필요 없고 `©2010熊本県くまモン`
표기를 요구한다. 다른 캐릭터는 신청이 필요한 경우가 많다.

## 결정

1. 마스코트 데이터는 **실제 캐릭터**로 한다. 47개 県 각각 공식(県 또는 県 관광기관) 1개 +
   전국구로 유명한 비공식 캐릭터 몇 개(`extra: true`).
2. 그림은 두 종류를 구분해 둔다.
   - `official`: 규정상 비상업·개인 이용이 허용된 공식 일러스트. 반드시 `credit` 을 함께 표시.
   - `likeness`: 우리가 그린 닮은꼴. "공식 그림이 아님" 을 도감에 표시하고 공식 링크를 단다.
3. 공식 사이트에 접근할 수 없는 환경에서는 우선 닮은꼴로 채우고, 규정을 확인한 것부터
   공식 그림으로 바꾼다. 어느 쪽인지는 `data/mascots.json` 의 `art` 필드가 말한다.
4. 상업 이용은 하지 않는다. 사이트 하단과 도감에 "各キャラクターの権利は各自治体・団体に帰属" 를 적는다.

## 결과

- 지도가 진짜 지역 캐릭터 도감이 된다.
- 그림 교체가 데이터 한 줄(`art`)로 추적된다.

## 보완 (2026-09-27) — 사용자가 고른 대체 그림 `standin`

사용자가 공식 그림 대신 다른 그림을 **골라서** 줄 수 있다 (예: かながわキンタロウ 에 いらすとや 의 금태랑 —
"귀여워서 골랐다, 이걸로"). 이때는 세 번째 종류로 적는다.

- `art: "standin"`, `credit` 은 **그 그림의 출처** (예: `いらすとや`). 권리자(県)의 ©를 붙이지 않는다.
- 화면에는 「그림: <출처> (공식 그림 아님)」 과 공식 페이지 링크를 함께 보인다.
- 반입은 `npm run mascots:import <폴더> --standin "<출처>"`. 나중에 공식 그림을 넣으면 크레딧이 기본값으로 바뀐다.
- 대체 그림은 사용자가 명시적으로 고른 경우에만 쓴다. 공식처럼 보이는 그림이 공식이 아닐 때 조용히 넣지 않는다.

## 보완 (2026-09-27) — 숨은 친구 `secret`

사용자 요청으로 みきゃん 은 두 버전: 평소엔 みきゃん, 이스터에그로 ダークみきゃん (愛媛県 공식 악역).
`"secret": "<host id>"` 인 마스코트는 host 가 튀어나왔을 때 그림을 세 번 톡톡 누르면 나타난다.
찾기 전에는 친구들 줄에 안 보이고, 図鑑에는 「？？？ 숨은 친구」로만 있으며 그 칸을 눌러도 host 가 나온다.
host 를 만난 뒤에는 「힌트: <host> 톡톡톡」 을 보여 준다. 숨은 친구도 도감 총수(54)에 들어간다.
