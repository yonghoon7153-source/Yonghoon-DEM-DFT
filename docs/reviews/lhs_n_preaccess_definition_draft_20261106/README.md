## 2. 코호트와 선행 여섯 침대

후보 명부는 `lhs00_000`–`lhs00_129`, `lhsx_001`–`lhsx_064`, `lhss_001`–`lhss_020`으로 고정한다. 라벨 생성은 설계 범위를 적는 일이며 자료를 스캔한 결과가 아니다. 기존 적격성·거부·HOLD를 먼저 상속한다. 특히 lhs00_123 INCLUDE와 lhsx_026 HOLD를 이 초안으로 바꾸지 않는다. 후보 214개를 수용된 214개로 쓰지 않는다.

선행 여섯 침대는 지금 ID가 없으므로 빈 여섯 식별 슬롯만 둔다. 각 후보에 대해 (i) 같은 물리 침대/실행의 별칭·복사, (ii) 같은 체크포인트의 조상·후손 또는 공유 생산 런, (iii) 공유 난수 스트림/seed 계보, (iv) 별개 생산 계보임이 입증됨, (v) 미확인을 구분한다. 파일 해시가 다르거나 case 이름이 다르다는 사실만으로 (iv)를 주지 않는다. 같은 seed 숫자는 독립 스트림 근거가 없으면 의존 가능으로 묶고, 다른 seed 숫자도 공유 restart를 배제하지 못한다.

겹침과 값 노출은 **별도 축**이다. 압력/N뿐 아니라 가설을 정하는 데 쓰인 porosity·τ·두께 등의 열람 이력도 작성자/판정자/시점/목적으로 남긴다. 여섯 침대와 비중복이어도 기존 LHS 결과를 보았다면 독립 미열람 검증이 아니다. 주 코호트는 아래 우선순위로 **한 번만** 부여한다. 각 축의 true는 확인된 사실, false는 반대 사실의 문서 입증, unknown(null)은 미확인이다. 기록 부재를 false로 바꾸지 않는다.

1. `EXPOSED_CONTEXT`: 선행 겹침·의존 계보·관련 결과 노출 중 **하나라도 확인된 true**이면 우선 부여한다. 다른 축이 unknown이어도 이 주 분류를 유지하며, 확인 사실과 미확인 축은 각각 보존한다. 기존 설명·탐색 자료로 남기고 독립 미열람 검증 분모에서 제외한다.
2. `UNRESOLVED_CONTEXT`: 확인된 true가 **없고** 세 축 중 하나라도 unknown이면 부여한다. 별도 보류·기술 집합이며 독립 미열람 집합이라고 부르지 않는다.
3. `PROSPECTIVE_CANDIDATE`: 세 축 모두 verified false, 즉 선행 비중복·별개 생산 계보·관련 결과 미열람이 모두 문서로 입증된 경우에만 부여한다. 여전히 설계·정적 신원·기존 적격성·종점 검증이 필요하고 독립성이 인증된 것은 아니다.

주 코호트별 분모는 서로 배타적이다. 예를 들어 노출 true·계보 unknown은 EXPOSED 한 건이며 UNRESOLVED에 중복 집계하지 않는다. 그 후보의 계보 unknown 표지는 지우지 않으며 부가 플래그 집계는 주 코호트 분모와 구분한다. 이 우선순위는 Q1 비준 대상 권고이며 이번 수정으로 활성화하지 않는다.

실제 식별·계보·노출 명부를 결과 열람 전에 고정하고 해시를 붙인다. 확인 불가를 “없음”으로 채우지 않는다. 소급해서 과거 노출을 없애거나 선행 여섯을 검증 집합에 재사용하지 않는다. 독립 미열람 후보가 0이면 그대로 0이며, 필요 시 기존 노출 집합의 기술 분석으로 연구 질문을 축소하는 별도 저자 결정을 받는다.

## 3. 층·대응쌍·제외

### 층과 계획 축

일차 제안은 **계획 삽입 높이/부피 배율 차이**에 대한 기술 대비다. 실제 N이나 압력으로 정렬·매칭하지 않는다. 삽입 높이를 바꾸면 N·고체량·두께가 함께 바뀔 수 있으므로 독립 N 처치가 아니다. 기존 다양한 조성 LHS를 억지로 짝짓지 않는다.

정확 일치 층 키: (1) 설계 모계·조성/질량분율·상/type 사상·PSD·재료/접촉 물성, (2) 경계/판 면적/가로 영역/중력/목표압·목표 도달 알고리즘, (3) 판 속도 **계획**·감쇠 법칙/그룹/계수·단위/스케일/dt, (4) PHASE 4 계획 길이·고정판/재개 의미·출력 간격·종점 규칙, (5) 생산·난수 반복 블록. 동적 감쇠 그룹은 같은 선택 규칙을 요구하며 실제 멤버 수는 매칭에 쓰지 않는다. 압축 종료의 관측 step·최종 두께·N·압력은 매칭 키가 아니다. 계획 배율만 선언된 차이로 허용한다. 그 밖의 정적 차이는 별도 층 또는 NOT_ESTABLISHED다.

정적 원자료에서 키를 확정할 수 없으면 층을 만들지 않는다. 부동소수점 근접 허용폭이나 결과를 보고 만든 bin은 없다. 단위가 다른 표기는 변환 근거와 정확한 원 표기를 함께 고정해야 같은 키로 인정한다.

### 대응쌍 고정 절차

각 적격 코호트·정확 층·생산/난수 반복 블록 안에서 계획 배율 오름차순으로 정렬한다. 같은 배율의 복수 후보는 정적 설계의 반복 식별자로 나눈다. 그 식별자가 없으면 임의 case 선택 없이 `AMBIGUOUS_REPLICATE`로 보류한다. 서로 다른 배율의 인접 후보를 겹치지 않게 (1,2), (3,4)… 짝짓고, 홀수로 남는 후보는 UNPAIRED로 보존한다. ID 사전순은 출력 순서만 결정하며 동률 해결로 좋은 결과를 고르지 않는다. 같은 관측의 복사본은 반복이 아니며 원본 alias 명부에서 중복을 제거한다.

각 쌍은 계획 배율 큰 쪽 − 작은 쪽으로 방향을 고정한다. 실제 ΔN의 부호가 예상과 달라도 뒤집지 않는다. 명부에는 두 case/반복 ID·층 키·대비 축·출처·제외 사유·해시를 적고 값 열람 전에 봉인한다. 값 열람 뒤 한쪽이 기술적으로 불성립하면 그 쌍을 이유와 함께 미평가로 남기며 **남은 후보로 다시 짝짓지 않는다**. 원 계획쌍 수/평가쌍 수/미평가 사유를 함께 보고한다.

허용 제외/보류: 기존 부적격/HOLD, 노출·중복 정책, 정적 신원/단위/계보 미확정, 층 불일치, 모호한 반복, 프로토콜 미완료, 정확한 종점 프레임 부재, 중복/소실 입자 ID·비유한 입력·설명 안 된 입자 손실·동적 그룹 재구성 불가. 입력 고유의 적법한 삭제/삽입은 계획/실현 사슬로 설명하고 다른 프로토콜과 섞지 않는다. 유한한 큰 값·예상 반대 부호·낮은 압력·불리한 porosity/τ 때문에 제외하지 않는다. 유효한 0도 결측으로 바꾸지 않는다. 사유와 분모를 보존하며 기존 배포 행을 삭제하지 않는다.

### 판정 범위

평가 가능한 쌍마다 실제 ΔN, ΔP_Rend, 곱의 부호를 기술한다. ΔN=0은 N 대비 없음, ΔP=0은 정확 산술 동률이며 압력 동등성 증거가 아니다. 평가쌍이 없으면 평가 지위는 `NOT_ESTABLISHED`, 집계 산술 방향은 `NOT_IDENTIFIABLE`이며 방향 일치가 아니다. 불확실성 구간이 0을 걸치면 수치 부호와 별개로 `SIGN_UNRESOLVED`를 병기한다. 자료 없는 구간도 확실한 부호로 해석하지 않는다.

집계 범위는 결과 열람 전에 정한 같은 코호트·층·대비 유형의 고정쌍 묶음이다. 그 안에서 평가 가능한 고정쌍을 E, 그중 ΔN=0인 쌍을 Z, **ΔN≠0인 쌍만**을 방향 적용집합 D로 둔다(E=Z ⊔ D). v0의 DIRECTION_* 문장을 이번 초안에 적용할 때는 다음 배타 규칙을 권고한다. v0 역사 파일은 바꾸지 않으며, 이 명료화도 Q2 비준 전에는 활성 정책이 아니다.

1. **D가 비면** 집계 산술 방향은 `NOT_IDENTIFIABLE`이다. E도 비면 평가 지위는 별도로 `NOT_ESTABLISHED`, 사유는 `NO_EVALUABLE_PAIRS`다. E가 있으나 모두 zero-N이면 사유는 `NO_NONZERO_N_CONTRAST`다. 공집합에 all 조건을 적용해 방향 태그를 만들지 않는다.
2. D가 비어 있지 않고 모든 ΔN·ΔP_Rend<0이면 `DIRECTION_CONSISTENT`다.
3. D가 비어 있지 않고 모든 ΔN·ΔP_Rend>0이면 `DIRECTION_OPPOSITE`다.
4. 나머지는 `DIRECTION_MIXED_OR_TIED`다. **D 안의 ΔP_Rend=0**도 이 분기에 포함한다. Z의 0은 집계 tie에 넣지 않는다.

원 계획쌍·평가쌍·미평가쌍·zero-N쌍·방향 적용쌍의 수와 ID를 함께 보고한다. 계획=평가+미평가, 평가=zero-N+방향 적용의 분모 관계를 보존한다. Z의 개별 ΔN·ΔP_Rend와 모든 평가 행은 그대로 남기며 집계 제외를 자료 삭제·재매칭으로 쓰지 않는다. (0,+2),(+1,−1)의 가상 두 쌍은 DIRECTION_CONSISTENT이고 zero-N 한 쌍을 별도로 보존한다. 이는 실제 관측값이나 효과 추정이 아니다.

N이 고체량/두께/조성과 분리되지 않으면 독립 N 효과 지위는 별도 `NOT_IDENTIFIABLE`로 둔다. 집계 산술 방향·독립 N 효과 지위·`SIGN_UNRESOLVED`를 서로 다른 필드로 보고한다. 일부 미평가가 있으면 관측된 적격 부분집합의 기술일 뿐 전체 후보의 방향 판정으로 확장하지 않는다. 외부 0.8×10⁻³ 기울기 보정·압력 동등성 통과·감쇠 인과 인증은 하지 않는다.

가상 경계표와 두 지적 한정 재확인 요청은 `../lhs12_clarification_recheck_20261108/`에 있다. 실제 값·명부는 채우지 않았다.

## 4. 이완 완료와 종점 — 제안하는 범위를 명시

**권고: 첫 분석은 물리 평형 판정이 아니라 `P_Rend_MPa`(등록된 이완 프로토콜 종점 판압)로 한정한다.** 이는 v0의 미확정 이완 완료 조건을 물리 인증 없이 채우는 변경이 아니라, 이름·해석 범위를 명시적으로 좁히는 새 제안이다. 비준 전에는 v0를 대신하지 않는다. 물리 평형 종점이 꼭 필요하면 별도 평형 관측량·허용폭·지속시간을 먼저 설계하고 이 분석은 NOT_ESTABLISHED로 둔다.

`PROTOCOL_COMPLETE_NOT_EQUILIBRIUM_CERTIFIED`에는 다음이 모두 필요하다:

1. 실제 원 덱/재개 사슬에서 목표 도달 뒤 고정판 PHASE 4의 시작 사건·예정 종료·dt 및 run 길이가 유일하게 정해진다. 벽의 설정만 아니라 해당 구간의 고정 조건과 예기치 않은 fix/속도 변경 부재를 확인한다. 값에 따라 종료를 바꾸는 분기면 별도 규칙 비준 전 보류한다.
2. 예정 PHASE 4 전체가 정상 완료했다는 실행/출력 증거가 있고, 조기 종료·치명 오류·설명 안 된 입자 손실·모호한 재개 중첩이 없다. B7의 목표압 마지막 판정 줄이나 scheduler rc0 하나로 대신하지 않는다.
3. **계획 종료 프레임 = 기존 수확 프레임 = atom/contact/mesh/판힘 프레임**이 같은 실행 계보/PHASE/시간에 정확히 결속된다. 숫자 step만 같다고 같은 사건은 아니다. 재개/reset_timestep은 segment ID·local step·누적 물리 시간 대응표를 요구한다.
4. 관측 종점은 예정 종료 한 프레임이다. 마지막으로 남아 있는 프레임·가장 안정/최저 압력·목표에 가까운 프레임·최근접 보간으로 대체하지 않는다. 기존 수확이 다른 시점이면 그 쌍은 미평가로 남기고 수확 값을 소급 변경하지 않는다.

프로토콜 길이는 서로 다른 실제 원 덱에서 임의로 채우지 않는다. 정적 확인 후 같은 예정 길이·dt·출력 규칙끼리만 층을 만든다. 물리 평형으로 부르는 숫자 문턱은 이번에 만들지 않는다. 정해진 시간 완료가 속도/감쇠 0 또는 평형을 뜻하지 않는다.

보조 안정성 기술 창은 **계획 PHASE 4 시간의 마지막 1/5에 포함되는 예정 출력 프레임 전부**로 제안한다. 이는 사전 선택한 보고 관례이며 물리 상수/통과 기준이 아니다. 첫 경계는 구간에 포함되는 최초 예정 프레임, 마지막은 정확 종점이다. 예정 프레임이 빠지면 창은 NOT_ESTABLISHED이며 부분 창 평균을 내지 않는다. 두 프레임 미만이면 변화/범위는 NOT_OBSERVABLE이다. 새 출력을 만들거나 임의 프레임으로 채우지 않는다. 후속 승인 때 압력 범위·종점 간 차이를 보고할 수 있으나 여기서는 값·결과 0건이다. 평균 비율과 비율 평균을 혼용하지 않으며 감쇠 companion의 순간 같은 사건 비율을 이 창 평균으로 바꾸지 않는다.

압력은 동일 사건의 실제 판힘 성분/부호와 유효 판면적, 확인된 필드별 단위 변환으로 정의한다. 명목 750 N/300 MPa와 기존 `pressure_MPa` CONST를 분모·실측압으로 대체하지 않는다. P_stop·P_Rend·목표압은 별도 열이다. 절댓값 판압과 부호 있는 감쇠 비율도 별도다.

## 5. N과 불확실성의 단위

N_Rend는 그 종점에서 **실제 감쇠 fix 그룹에 속한 DEM 입자의 고유 정수 ID 개수**다. mesh/wall 객체는 제외한다. planned/삽입 수, 정지 시점 수, 종점 수, 상별 수, 전체 입자 수를 구분한다. 질량분율을 개수분율로 바꾸지 않는다. type 사상은 실제 덱에 결속한다. 동적 그룹/삭제/삽입은 같은 프레임에서 membership을 복원할 증거가 없으면 NOT_ESTABLISHED다. ID를 float로 반올림하거나 중복을 조용히 버려 N을 만들지 않는다.

감쇠 fix가 여러 개면 그룹별 수와 중복을 먼저 분리하며 임의 합산하지 않는다. 공통 균일 선형 외력 F=−c_v v가 확인될 때만 −c_vΣv_z를 쓴다는 기존 companion 제한을 유지한다. 타입/질량별 계수·접촉 dashpot은 다른 정의가 필요하다. N 자체는 순힘/소산/평형 지표가 아니다. 반대 속도 상쇄로 순힘이 0이어도 움직임과 소산은 남을 수 있다.

**권고 불확실성 단위는 독립 생산·재개·난수 계보 블록**이다. 공유 restart/생산자/난수 스트림으로 연결된 case는 한 의존 블록에 둔다. 한 침대의 원자/접촉/여러 프레임은 반복 표본 수가 아니다. 동일 seed 숫자의 독립 사용 여부를 입증 못 하면 보수적으로 같은 의존 가능 블록이며, 근거 없는 유효 자유도를 만들지 않는다.

첫 보고는 기술 범위로 한정한다: (i) 사전 고정 쌍의 개별 ΔN·ΔP와 적격/결측, (ii) 같은 대비 유형·층 안에서 블록별 개별값/범위와 쌍 수, (iii) 블록 간 값 전체와 블록 수/최소–최대. 범위는 신뢰구간이 아니다. 서로 다른 대비 크기를 한 평균으로 섞지 않고, p값·회귀 유의성·표준오차·신뢰구간·독립 N 효과 추정은 이번 제안에 없다. 블록 하나면 반복성 불확실성 추정 불가라고 쓴다. 미래 통계 추론은 값 열람 전 별도 계획/비준이 필요하다.

출력 정밀도·단위/면적·수치/모델·표본 변동의 불확실성을 분리한다. 원 출력 형식과 반올림 방식이 확인된 경우에만 결정적 표시 오차 경계를 전파하고, 모르면 UNKNOWN이다. 이것을 물리 오차/확률 신뢰구간으로 쓰지 않는다. 입자 수의 제곱근으로 물리 불확실성을 줄이지 않는다. 유효한 정수 N의 카운트 불확실성과 membership/손실의 신원 미확정을 혼동하지 않는다.

## 6. 원 덱 신원·후속 열과 실행 경계

원 덱/의존 include/변수/재개 사슬의 정확한 동결 항목과 현재 확인 한계는 `source_identity.md`에 있다. 현재 저장소 소스 바이트 신원은 `source_manifest.json`에 기록한다. 그것은 실제 실행 입력 파일 신원 대신이 아니다. 실제 신원 슬롯은 null이며 제안한 규칙만으로 채우지 않는다.

후속 companion은 기존 porosity(구체 sphere-sum/clipped/union 정의), 두께, geometric τ와 transport τ, 접촉/CN·상 분율·Hertz/physics/H12 등 각각에 **동일 실행/프레임·압력 상태 자격·정의·노출 이력**을 연결한다. descriptor 값 자체와 기존 압력 CONST·적격 상태를 덮어쓰지 않는다. 압력 비교 미확정은 조성만의 설명에 한계가 있다는 뜻이며 descriptor 계산 오류 판정은 아니다. 최초 열람 범위는 판압/N/신원 및 사전 승인된 진단 창으로 좁히고 downstream 값 재열람은 별도 권한으로 둔다.

순서는 정적 신원/노출 메타데이터 준비 → 승인된 무값 재고 → A/C·코호트/쌍/종점/불확실성 명부 비준·고정 → 최소 값 열람 별도 GO다. 어느 단계도 앞 단계의 수용만으로 자동 진행하지 않는다. 저자 선택은 `author_decisions.md`, 새 독립 검토 범위는 `review_request.md`, 공유 기록 제안은 `ledger_proposal.json`에 있다.
