구현은 `scripts/suyoung_u6b_dev.py`다. `scripts/suyoung_u6_first_dev.py`와 `scripts/dem_suyoung_sf2d_dev.py`의 고정 소스 바이트를 확인하고 기존 advance를 사용한다. 원판 번호는 보관한 채 S에서는 P2G/G2P용 격자장 키에만 0을 전달한다. 매 시각의 아래판 반력을 판독하며 별도 이동 평균을 적용하지 않는다. 새로운 run의 trace·결과와 이전 반환의 trace SHA256은 비교 JSON에 연결된다.

고정된 두 기존 F trace의 해시 출처는 `docs/reviews/nonrint_returns_cd_20261120/repeat/author_comparison.json`이다. 동일한 두 반환을 새 계산 횟수에 넣지 않는다. 팔별 출처는 `11-20-fixed-repeat`와 `new`로 구분한다. 종합 DEVELOPMENT_READBACK도 개별 목표·팔의 UNCONVERGED·신호 또는 잡음 상태를 그대로 보존한다.
