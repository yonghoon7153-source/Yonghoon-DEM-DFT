## §2 내 주장 (원문 · 시간 순)

### 2-1 첫 설명 (철회됨)

> *"DEM은 SC 쪽에서 공극률을 높게 예측합니다.  이는 알려진 모델 한계 때문입니다.  SE를 1 µm 단단한 구로 고정했습니다.  그래서
> AM이 작아질수록(9 → 4 µm) 틈을 덜 채웁니다.  SC가 많으면 AM–AM 골격이 하중을 받아 SE가 덜 눌립니다.  실제 황화물 SE는 눌리면
> 소성 변형으로 좁은 틈까지 흘러 들어가므로 이 효과가 작습니다."*
>
> 덱 문장 제안: *"PC가 많은 조성에서 DEM과 실험 공극률은 1 %p 안에서 맞는다.  SC가 많아질수록 DEM이 높게 예측하는데, 이는 SE 소성
> 유동이 없는 DEM의 한계다 (실험은 반복 측정 중)."*

### 2-2 정정표 (1저자에게 보낸 원문)

| 내가 한 말 | 상태 (내 판정) | 근거 |
|---|---|---|
| DEM이 SC 쪽에서 실험보다 공극률이 높다 | △ 숫자는 맞지만 차이는 미확정 | DEM 0:10 19.2 % 대 실험 15.5–16.7 %.  같은 PC only 가 20.7 % 와 16.5 % 로 4 %p 갈린다.  5:5 의 1.4–1.7 %p 차이는 이 편차 안 |
| DEM 입자는 구 모양 그대로 | ✅ 사실 | 강체 구 · 접촉 겹침만 · SE 탄성계수를 낮춰 실험 공극률에 맞춘 상태 |
| 크기 PC 9 · SC 4 · SE 1 µm, 실험 PC 12 µm | ✅ 사실 | 실험 SC · SE 크기는 모른다 |
| *(배위수 행 — 이번 범위 밖 · §5)* | | |
| "그래서 SC 쪽 차이는 SE 소성 유동이 없는 DEM 의 한계" | ❌ 미검증 추론 | 반대 증거: MPM (소성 SE) 에서 SC 많을수록 같은 φ 에 응력 1.87× |

정정된 결론 (원문 요약): 어느 쪽이 맞는지 · 원인 둘 다 모른다 · 후보 = 실험 편차 · 다결정 PC 내부 공극 · 크기 차이 · 모델 한계 ·
확인 순서 = 실험 반복 측정 → 실험 SC · SE 크기로 DEM 재계산 → 그래도 남으면 모델 한계.
대체 덱 문장: *"PC가 많은 조성은 실험과 1 %p 안에서 맞고, SC가 많은 조성은 차이가 있다.  원인은 실험 반복 측정과 입자 크기 대조로
확인 중이다."*  COMSOL: *"실험 평균이 나오면 실험값 · 그 전에는 PC 쪽은 DEM 구 부피 합 값"*.

### 2-3 요청서를 쓰며 내가 다시 찾은 과장 (1저자에게 아직 일부만 알림)

1. **"PC 가 많은 조성은 실험과 1 %p 안"** — 10:0 실험 두 값 (16.5 · 20.7) 중 **하나에만** 맞는다 (DEM 15.8 vs 20.7 = 4.9 %p) ·
   **7:3 은 실험값이 없다**.  대체 덱 문장과 COMSOL 권고에 그대로 들어가 있다.
2. **"DEM 에도 혼합 이득이 있다 (7:3 최소)"** (첫 설명 단계) — union 16.49 vs 10:0 16.90 = 0.41 %p · 조성마다 침대 1 개 · 시드 산포
   미측정 ⇒ 이득 주장 불가.
3. **"같은 정의 = DEM 구 부피 합"** — 실험 두께가 압력 해제 뒤 값인지 모르고 (DEM 벽 간격은 판 고정 이완 상태 · 해제 아님 —
   springback 차이) · 실험 진밀도가 DEM 밀도 (AM 4.8 · SE 2.0 g cm⁻³) 와 같은지 모른다.  질량 → 부피 환산이 다르면 같은 wt % 라도
   고체 부피가 다르다.
