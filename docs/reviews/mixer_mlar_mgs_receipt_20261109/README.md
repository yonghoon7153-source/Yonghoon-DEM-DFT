## MLAR 포장 정정

`mlar_receipt.json`에 누락 멤버의 전체 ZIP 상대 경로와 기대 해시를 기록했다. 외부 목록 189/189는 맞지만 `package/SHA256SUMS`의 128항목 중 127개만 확인되므로 전체 PASS가 아니다. 존재하는 원 요청 128파일의 변경·추가도 없다. 누락은 내용 판정을 철회하거나 새 코드 결함을 선언하는 것이 아니다.

반박 창에 `mlar_repack_request.md`를 전달한다. 고정 원 요청에서 누락 파일을 그대로 복원하고 외부 해시 목록을 갱신한 새 신원의 ZIP을 받으면 된다. 이 창은 원 ZIP을 수정하거나 정정 독립 증거인 것처럼 새 ZIP을 만들지 않았다. 코드 변경·시험 재실행 요구도 아니다.

## 한정과 다음 단계

MLAR는 MLA-01 잔여 경로이므로 독립 P1 두 건으로 중복 계상하지 않는다. MLA-02/03의 기존 한정 수용은 유지한다. 제출 후 런 실패의 자동 캠페인 HOLD 전파는 없으며 승인 운영자의 감시·후속 파동 중단이 필요하다. 예약 자동 해제·재시도 권한은 생기지 않는다. 문자 차단을 현장 Slurm 파서·POSIX/Lustre·실패 복구 자격으로 확대하지 않는다. 역사 archive 자산 불일치의 최초 원인 미확정과 최초 stderr 미보존도 그대로 남는다.

MGS의 100 하위형 관측 거부·hook 0회, 10/10·34/34는 독립 보고서의 결과다. 이번 수령 창은 재실행하지 않았다. 관측 수·메서드·전후 반복을 합산하지 않는다. 정상 덱 텍스트 보존은 생성기 SHA를 포함하는 메타 신원이나 운영 봉인 갱신이 아니다.

두 원 증거에는 외부 위치·주소가 있어 리포에 넣지 않는다. 신원·해시·한정 판정만 기록하고 원바이트는 외부 인계 묶음에 보존한다. 운영 재봉인·최종 묶음·현장 자격·NP·동시 팔·순서·1저자 실행 GO는 별도다. 전체 HOLD 유지.
