## 요청문 본문 (초안 v2)

---

**제목:** COMSOL 미세단락 모델의 실험 대응을 위한 자료 요청 (부탁드립니다)

규진팀께,

저희는 규진팀의 COMSOL 미세단락 모델을 다시 구성해, 정상 조건 (단락 전도도 ≈ 0) 에서 0.1C 정전류 충전의 처음 480 초를 계산해 두었습니다.
이 모델이 실제 셀을 얼마나 나타내는지 확인하려면 모델의 입력 · 조건을 실험과 한 줄씩 대조해야 합니다. 그런데 지금 저희에게는 α·β 적합 결과
네 파일 (ref1 · ref2 · PE1 · PE5) 에 관한 간접 검토 기록만 있고, 해당 원본 파일과 원 측정 곡선은 아직 확보하지 못해 대조를 시작하지 못하고
있습니다. 아래 자료를 부탁드립니다. 우선 정상 셀 한 개의 자료부터 받아도 충분합니다.

**꼭 필요한 것**

1. **원 측정 기록** — 대상 셀의 시간–전압–전류 (가능하면 시험 단계 번호 · 온도) 원 기록. 적합 결과 파일 이름의 `0.1C_12h__charge` 시험
   그 자체입니다. 정상 셀 1 개 이상, 가능하면 같은 제작 묶음의 단락 셀 1 개. 장비에서 내보낸 원본 파일과 CSV 변환본, 샘플링 간격 · 시각 기준
   (시간 0 의 뜻) · 단위 · 전류 부호 · 사용 기기를 함께 부탁드립니다.
2. **시험 조건과 직전 이력** — "0.1C · 12 h" 에서 12 h 가 어느 단계 (충전 · 휴지 등) 인지, CC / CV / 방전 / 휴지의 순서, cutoff 전압 · CV 종료
   전류, 직전 단계 (방전 하한 2.7 V 도달 여부 · CV 유지 여부) · 휴지 시간, 충전 시작 직전의 개방 전압과 온도.
3. **셀 구성** — 셀 형식 (코인 · 파우치 등) · 셀 ID · cycle · 제작 묶음 · 전극 겹침 면적 (모델은 1.53938 cm² 로, 지름 14 mm 원판으로 보입니다)
   · 전극별 두께 · 적재량 (mg/cm² · 단 / 양면 기준) · 활물질 비율 · 공극률 · 분리막 · 전해질 조성 · **0.1C 계산에 쓰신 기준 용량**.
4. **정상 / 단락 셀의 구분** — 단락 셀을 만든 방법 (Fe 삽입 위치 · 양 · 처리) 과 단락으로 판정한 기준 (전압 강하율 · 누설 전류 · 저항 측정),
   그리고 적합 결과 네 파일 (ref1 · ref2 · PE1 · PE5) 이 각각 어떤 셀 · 조건 · cycle 인지.

**있으면 좋은 것**

5. **적합 결과 원 XLSX 네 개**와 적합에 쓰신 전압 / 전극별 half-cell 개방 전압 곡선 (측정 온도 · 충전 / 방전 방향 · 용량 · 조성 좌표의 정의 포함),
   α·β 적합 코드 또는 정의 문서. `c_lit` · LAM · LLI 가 뜻하는 물리량과 단위도 부탁드립니다.
6. 온도 기록 · 반복 셀 · 같은 셀의 다른 C-rate 시험.
7. 원 모델의 비교값 3.0524 V 가 어떤 계산 결과 (dataset · solution · 시점 · 무부하 / 부하 상태) 의 값인지와, 그에 대응하는 실험 셀 · cycle ·
   시작 상태.

없는 항목은 "없음 / 미확인" 으로 표시해 주셔도 됩니다. 빠진 값을 맞춤으로 추정해 채우려는 요청이 아닙니다.

**받은 자료의 취급**

- 파일은 받은 그대로 보존하고, 파일마다 이름 · 크기 · sha256 을 기록합니다. 보내실 때 sha256 과 셀 ID ↔ 파일 대응표를 함께 적어 주시면
  대조가 쉽습니다.
- 자료는 모델 입력 · 조건의 대응 확인과, **비교 전에 미리 정해 둔** 구간 · 지표의 비교에만 씁니다. 모델 파라미터를 자료에 맞추는 일
  (fitting) 은 하지 않습니다. 첫 단계는 모델과 실험의 조건이 같은지부터 표로 정리하는 것입니다.
- 원자료는 공개 저장소에 올리지 않고 식별 정보만 남깁니다. 자료를 공유하실 수 있는 경로와, 내부 분석 · 공동연구 전달 · 논문 공개의 허용
  범위를 함께 알려 주세요.
