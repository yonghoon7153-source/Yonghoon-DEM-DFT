docs/reviews/nonrint_offline_casebooks_20261114/lhs_o1_receipt_plan.md §2–3과 docs/reviews/nonrint_contract_preparation_20261114/lhs_o1_synthetic_check.md를 이어간다. 기존 명령 SHA2026d61bb920599ca95870b62b8aee9ed3345f288da21ed4ff090a0064e0b8a3 보존. 이번 새 parser/명령/WSL 실행0·실제 수령0. 아래10행은 미실행 수령 설계 사례다.

| 사례 | 받을 지위 | 다음 |
|---|---|---|
| 정상11키와 별도 실제rc0 | 현재 신원 한정 수령 | 과거 실행 신원 NOT_ESTABLISHED 유지 |
| 내부10키만 전달 | 미완료 | 바깥 command_rc와 실제rc를 추정하지 않음 |
| 11키 중 command_rc0, 실제rc 미수령 | 미완료 | 문자열0만으로 완료 승격 안 함 |
| 같은 별칭의 다른SHA | 다중 현재 관측 | 앞 관측 보존, 원실행 사용본을 고르지 않음 |
| 다른 별칭의 같은SHA | 별개 선언 신원 | 같은 run/계보로 합치지 않음 |
| bytes0·빈파일SHA·그 밖 정상 | 현재 빈 바이트 관측만 | 유효 덱/정본 후보 인증 아님 |
| 같은 hash·길이, 관측 시각만 다름 | 두 관측 | 실행 시각 또는 수정 이력 증명 아님 |
| 날짜꼴은 맞지만 달력상 불가 | 미완료 | 현재 시각으로 보정하지 않음 |
| 추가키/원로그 본문/결과값 포함 | 범위 밖 전달로 보류 | 내용 확대 열람 없이 허용 메타만 새로 받기 |
| execution_identity_status 또는 값GO를 양성으로 바꿈 | 범위 모순 | 현재hash로 권한/과거 신원 대체 금지 |

## 2. 두 번 hash의 잔여 한계

두 해시가 다르면 불일치를 잡지만 사이에 A→B→A로 바뀌거나 읽는 동안 원자성이 없으면 같은 관측 두 번만으로 불변 구간을 증명하지 못한다. 지금 명령에 잠금·snapshot 구현을 덧붙이지 않는다. 현재 신원 좁은 O1 결과를 실행 당시 덱/include/재개 사슬 신원으로 승격하지 않는 것으로 범위를 유지한다. 실제 로그·정본/구간·A/C·명부/쌍·종점/필드·담당/노출·동결·값GO는 별도다.
