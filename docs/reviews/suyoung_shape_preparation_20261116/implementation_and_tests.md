# 형상 출력 구현·시험 명세

## 1. 관측 위치

대상 로컬 파일은 `scripts/dem_suyoung_sf2d_dev.py` 하나와 새 `scripts/test_dem_suyoung_shape_output.py`다. 시도4 DONE 전에는 둘 다 커밋·push하지 않는다. 현재 소스/시험 SHA256은 같은 폴더 `local_preparation_receipt.json`에 있다. 이는 코드 실행 핀이나 독립 판정이 아니다.

1. `initial_state`의 물리 상태는 그대로 생성. 출력 옵션이 켜졌을 때만 별도 관측자에 X·ID 사본과 단위 `F_total`을 만든다.
2. 기존 `step`은 P2G→경계/접촉→G2P→탄성 상태 투영→좌표 갱신을 그대로 수행한다. 기존 trace/평균 계산도 그대로 둔다.
3. 완료된 step 뒤 관측자가 `C`를 읽어 총 지도를 운반한다. `C`는 현재 MLS/APIC 커널이 쓰는 affine 속도 계수다. 이 수치 이력으로 만든 국소 affine 셀이며, 격자 수렴 또는 정확한 연속체 경계의 증명은 아니다.
4. 관측자만의 출력에 실제 step·`dt*step`·판 위치·현재 상태를 기록. 기본 저장 step은 0·1·120·240·…·1200(12프레임). 마지막 step을 항상 포함한다.
5. NPZ는 숫자 배열만이며 `allow_pickle=False`로 읽는다. SVG 꼭짓점은 현재 x와 `F_total`에서 직접 생성한다. 색은 원 입자 ID0–3에 고정. 시간·좌표 보간 없음.
6. 팔 종료 시 압력 전 이력·프레임 해시·완료 manifest를 작성. 하나라도 실패하면 CLI 요약은 INCOMPLETE, 비는 null. 부분 자료는 보존한다.

### 기본값 보존

출력 옵션을 빼면 관측자를 만들지 않는다. `seed_disks`, `stencil`, `stress`, `plastic_project`, `pair_impulse`, `contact`, `boundary`, `initial_state`, `step`, `ratio`의 AST는 바탕과 동일하다. 기존 trace와 평균 정의는 바뀌지 않았다. source_sha256와 실행시간은 코드 보완에 따라 달라지므로 바이트 동일 주장 대상이 아니다.

## 3. 실행 초안 계약

| 항목 | 초안 |
|---|---|
| 기계·코어 | 1저자 WSL·CPU1. OMP/OPENBLAS/MKL/NUMEXPR=1 |
| 입력 | 기존 절차적4원판, grid32·1200 step·dt0.0005·속도0.15·마찰0.20; 새 물성값 없음 |
| 신원 | DONE 뒤 고정40자리 실행 핀 + 소스 tar SHA256 + 전체 파일 manifest. 미커밋 덮어쓰기 불허 |
| 시간 | 내부 팔600초 + 팔별 외부 timeout600초에 TERM,10초 뒤 KILL. 패키지 검사/묶기 시간은 별도 |
