## 2. 권고안 전제와 기존 결정

Q-M1-1의 중복 구현 제외와 Q-M1-5의 반박 창 GO + 1저자 별도 GO·최종 ZIP 전달 시점은 **기존 경계이며 새 질문이 아니다**. Q-M1-2는 S1/cohort·분모·관측 단계의 사전 고정, Q-M1-3은 D3 탐색·보정/검증의 등록·노출 분리, Q-M1-4는 가상 호출의 시도별 rc·full output·hash·scratch 결속 계획이라는 **권고안 전제**다. 미결정 믹서 Q2/Q3/Q5를 승인받았다고 쓰지 않는다.

진단 JSON은 실제 영수증이 아니라 빈칸 서식이다. 가상 사례 C1–C4는 계획만 있으며 실제 reader·engine·전체 selftest를 실행하지 않았다. 후속 새 반례가 생기면 고정 반례 → 수정 전 실패 → 최소 수정 → 같은 시험 → 고정 핀·반박 검토 순서를 따른다.
