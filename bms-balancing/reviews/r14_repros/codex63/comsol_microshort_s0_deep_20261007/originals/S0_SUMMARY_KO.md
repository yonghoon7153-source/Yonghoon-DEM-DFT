# Microshort S0 — 5분 요약

2026-10-07 · **S0 완료 / S1 조건부 권고 / 실제 계산 미승인**

## 이제 물리 질문으로 넘어갈 수 있다

지금까지의 0–480초·rtol·입자격자 결과는 거의 누설이 없는 모델의 계산/수치 점검이었다. 다음에 볼 것은 **외부 전류를 끈 상태에서 내부 누설이 N의 리튬을 P로 옮기고, 그에 따라 전압이 얼마나 변하는가**다. 전압만 내려갔다고 단락을 입증하지 않고 누설전류·전극별 재고·총량 보존을 함께 확인한다.

## 요청서에서 바로잡은 핵심

- 현재 소스는 분리막 `epss=.55`, `NoCorr`다. 옛 설계의 `epss=1`이나 Bruggeman 환산표를 적용하지 않는다.
- 누설비 `r=.01`은 **0.001C, 1시간에 정규화 용량 0.1%**다. 요청서의 1%는 10배 크다.
- 유한 누설과 전위차가 있으면 엄밀한 평형이 아니다. **같은 균일 농도에서 시작하는 자기방전 초기값 문제**로 설계한다.
- 누설 자체는 이 모델에서 새로운 LLI가 아니라 Li 이동이다. 기존 LLI/LAM 입력은 그대로 유지된다. 재충전으로 SOC를 채울 수 있어도 단락이 없어진다는 뜻은 아니다.

## 제안 실험과 계산 전 예측

외부 전류0, xN=.445, 같은 총 Li에서 xP≈.581151656, 1시간 휴지. 원 OCP 표의 축약 산술로 얻은 예측이며 **COMSOL 결과가 아니다**.

|---:|---:|---:|
| 1e−20 기준 | 사실상 무시할 크기 | 사실상 무시할 크기 |
| 1.7e−8 | 0.096mV | 0.0101% |
| 1.7e−7 | 0.962mV | 0.1011% |

강한 한 단계 더(1.7e−5)는 약10%를 이동시켜 첫 사다리에서 제외한다. 1mV는 연구 표시 기준 제안이지 기존 수치오차나 실험 검출한계가 아니다. 실제 분류에는 같은 σ의 수치 대조가 필요하다.

## 비용 때문에 바로 실행하지 않는다

기존 `.1초 cap + 모든 step 저장`을 유지하면 1시간에 약47GB·compile/batch 약10.6시간이라는 거친 외삽이다. 새 후보는 **401개 요청시각 + 요청시각 저장 + 후기 step 상한 완화**를 제안한다. 같은 저장 구조라면 MPH 약0.52GB 시나리오지만 성능 보장은 없다. RAM peak는 미확인이다.

다음 순서는 **오프라인 실행 연결/변경부 검증 → 별도 승인한 짧은 저장정책 대조 → 비용 재확인 → 별도 승인한 1시간 σ 사다리**다. 정책의 세 축을 분리하려면 짧은 대조 최대4본, 주 사다리4본이며 숫자 대조는 별도다. 한 번에 전부 승인하지 않는다. 제안 상한은 실행당 native7200초/전체9000초/출력6GiB이며 실제 완료 예측이 아니다.
