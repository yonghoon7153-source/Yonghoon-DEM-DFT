# WSL30 정본 및 §5 압력 자격 · 열람 전 동결 초안

1저자 결정 대기. 30건의 출처가 확인돼 11-18의 NONE_KNOWN을 현재 상태에서 갱신한다. 11-18 회신 원문과 B7의 과거 복수 로그 REFUSED를 보존한다. 이 제안에서 열람한 실제 압력·도달 판정은 0건이다.

## 정본과 명부

A 경로를 제안한다. lhs00_100부터 lhs00_129까지 각각 log.liggghts의 유일한 LIGGGHTS 배너에서 같은 파일의 실행 종료까지가 한 구간이다. log.txt는 같은 실행의 화면 사본으로 보존한다. 두 로그를 합치거나 결과에 따라 정본·구간을 바꾸지 않는다. 명부의 run1은 케이스 안에서 유일한 실행을 지칭하는 별칭이다. 실행 바이너리를 가리키는 식별자가 아니다.

11-24 원 확인서 2개와 작성 도구의 SHA256을 대조했다. 두 보고서의 SHA는 roster.json에 보존했다. 작성 도구는 순서대로 04f1c4bdd49396b3e8c1d24837443d3d7afe26155888eb53bb024b769828e782, 0ff5b548a645e2811ede1b06b25e15fa4a50b88d2b77d43eefe2db0820a8f60b이다. 실무 창은 출처 확인서를 09-19 코호트·11-18 명부와 대조했다. 원로그 현장 검사는 1저자의 관측이다.

| 증거 | WSL30에서 확인된 범위 |
|---|---|
| 실행과 사본 | 각 로그 배너 1개, 화면 쪽 Finished! 1개. 30/30에서 압력 출력 줄 목록 전체가 같은 순서로 같고, 화면 줄 약 99.9%가 정본에 같은 순서로 있다. 끝 시각의 근거는 두 파일 수정시각 차 0–1초다. |
| 첫 검사 CHECK 30건 | 첫 도구는 비어 있지 않은 덱의 128줄 전부가 되풀이돼야 OK를 준다. 100줄이 원문 그대로 되풀이됐다. 후속 확인에서 빠진 28줄의 위치가 30/30 같고 여러 줄 명령의 구성으로 설명된다. 줄을 결합한 뒤 명령 바이트까지 같음을 시험한 것은 아니다. 화면·정본 전용 줄까지 같은 분류 서명은 19/30이다. 1저자는 나머지 화면 차이를 경고로 설명했다. 원 확인서의 CHECK를 그대로 보존한다. |
| 출처와 하베스트 | 실행마다 덱·atom 해시가 코호트와 같다. 하베스트 step은 두 로그의 정수 선두 출력행에서 30/30 발견됐다. 1저자는 thermo 행이라고 확인했다. 첫 도구 자체는 thermo 머리글까지 검증하지 않는다. 실행 파일 해시·배너 버전 본문·목표 도달은 여기서 확정할 수 없다. |

명부 roster.json은 각 케이스의 정본·대조 역할, 예상 B7 출력 줄 수와 끝 공백을 정리한 목록의 SHA256 앞 12자리, 덱 이름·전체 SHA, 하베스트 step 및 atom 이름·전체 SHA를 묶는다. 줄 목록의 12자리는 원 도구가 남긴 비교 지문이다. 전체 정본 파일 SHA는 GO 뒤에 기록한다. 순서는 100–129로 고정한다. 누락·불일치·미도달 행도 분모 30에 남긴다. 이는 케이스별 압력 자격 명부로, 시드 독립성·N 효과의 분석 쌍은 배정하지 않는다.

## 끝점과 필드

| 항목 | 동결안 |
|---|---|
| §5의 압력 끝점 | 같은 실행의 가압 루프에서 실제로 출력한 마지막 Current Pressure 줄. 명령 echo를 제외한다. 이 줄의 current·Target과 해시가 맞는 덱의 target_press를 B7로 대조한다. 더 이른 최대압이나 이완 마지막 압력을 대입하지 않는다. |
| 단위·판정 | 원 B7의 같은 덱 단위 비교 current ≥ Target, 덱/로그 목표 일치·유한값·루프 형태 조건을 유지한다. MPa 표시는 원 press_units의 ×1000. WSL30 자격에는 설계 목표 300 MPa, 인계기의 허용폭 10⁻⁶ MPa, reached와 덱·로그 지문을 함께 본다. B7의 자체 상태와 §5 보류 사유는 따로 남긴다. |
| 하베스트 끝점 | 명부에 고정한 정확한 step과 atom 지문을 사건 기준으로 보존한다. 가압 루프 마지막 판정과 이완 뒤 하베스트는 다른 사건이다. PHASE4 일정 종료·동시각 판힘·면적을 연결해야 얻는 P_Rend, 평형 여부, 감쇠 그룹 N, 후반 1/5 진단은 이번 값 열람 대상에서 제외한다. |
| 허용 필드 | 기존 B7 열 case, schema, status, why, deck, deck_sha256, target_press_deck, target_mpa, log_file, log_sha256, n_press_lines, last_press_deck, last_press_mpa, max_press_mpa, reached, lines_after_last. max는 B7의 참고 출력이다. 부가 메타는 run_segment·harvest_step·정본/줄 목록 지문·pressure_check·결측 사유, 명부/읽기 핀·승인 식별자·열람 담당·시작/종료 UTC·반환 해시다. |
| 입력과 보존 | 1저자 로컬 WSL의 해당 덱과 정본만 읽기 전용. log.txt와 atom은 이미 받은 출처 근거를 쓴다. 원 자료는 1저자 보관. 1저자가 새 반환 폴더의 ZIP·SHA를 실무 창에 전달한다. 원로그·덱 본문을 공개 리포에 옮기지 않는다. |
| 실패 | 정본 경계·덱 지문·압력 줄 목록·하베스트 표지·읽기 전후 지문 불일치는 보류·사유. 유한한 마지막 압력이 목표 미만이면 NOT_REACHED, B7 거부는 REFUSED로 보존한다. 다른 로그 선택, 수동 TSV 결합, 결손 제외나 목표 미확인 예외는 적용하지 않는다. |

**승인 및 후속 순서.** 먼저 1저자가 이 범위를 동결하고 WSL30 §5 값 열람 1회에 명시적으로 GO를 준다. 실행 블록은 GO 뒤에만 사용한다. Codex는 반환 30행과 출처를 재판독한다. WSL30 결과와 별도로 §5 전체에는 lhs 130·lhsx 64·lhss 20의 기록이 각각 필요하다. 다음은 수송 tortuosity τ²의 출처·상태·단위 점검(√τ²와 기하학적 경로비를 구분), 그 뒤 194+20 배치 봉인·다시 읽기와 전달본 독립 검토를 거쳐 v1.3 배포를 결정한다. 이번 GO에 τ 열람이나 배포를 묶지 않는다.
