**반박 창에 물을 세 가지**

1. A3 원 위치에서 같은 파일·바이너리·수정 판독기로 검산한 사실을 최종 생산 사전 점검이 확인하는가? 경로·결속·신원 하나만 바꾼 합성 반례로 실제 거부 단계와 반환 코드를 적어 달라.
2. A4의 값이 정해진 역사 ⓡ 1건, A3의 작은 RT 왕복, B의 두 고정 출력을 각각 어떤 선행 조건에 쓸 수 있는가? 등록의 해당 절과 미확인 항목을 적어 달라. 새 RJ의 ⓣ와 실제 탈압 데이터는 이후 관측이다.
3. 고정 운영 후보에서 새 잡의 증서 재사용·덮어쓰기·엉뚱한 체크포인트·빈 셀 등으로 발사 경계를 건너뛸 수 있는가? P1 또는 알려진 한계의 관련 판정 항목과 허용 범위를 명시하고, 이번 핀의 발사 준비 상태를 결론으로 달라.
