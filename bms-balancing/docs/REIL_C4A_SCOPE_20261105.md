## 2. 수치 경고 확인 (정적 · 새 실행 0)

- **어디서:** `util_LFP.py` (받은 고정 바이트 `3c19e45e…`) 의 `dVdQ_hc` (130–155 행) 가 평가마다 `np.gradient` 넷을 계산한다 — `dVdQ_PE_hc` · `dVdQ_NE_hc`
  (Q 가 좌표 · 141 · 143 행) 와 `dQdV_PE_hc` · `dQdV_NE_hc` (V 가 좌표 · 152 · 153 행). 좌표에 같은 값이 이어지면 (LFP 의 평탄한 전압 구간에서 V 가 반복되는 등)
  간격 0 의 나눗셈이 된다. stderr 에는 numpy 내부 위치 (`_function_base_impl.py` 1317 · 1318 — 비균등 간격 계수) 만 찍혀 호출 줄은 없다. 평가 안의
  `np.gradient` 는 이 넷뿐이고 (자료 쪽 109–110 · 125–126 행은 자료 추출 때 한 번), 경고 수 (21,896,160 / 평가 1,501,500 ≈ 평가당 14.6) 는 평가마다 나는 쪽과
  맞는다.
- **목적값 경로:** `objective_fun` (157–236 행) 은 `dVdQ_hc` 의 반환 가운데 `Q_PE_hc_ad` · `Q_NE_hc_ad` · `VPE_hc_sim` · `VNE_hc_sim` 만 쓴다 (178–196 행).
  기울기 배열 넷은 쓰지 않는다. f3 · f4 의 dV/dQ 는 `np.diff` 로 만든 `dVdQ_sim` (208–210 행 · 고유 Q 점) 과 자료 추출 때 만든 `dVdQ_exp` 다.
- **기록:** E1-3 의 66 행 모두 `n_nonfinite` 0 · `n_nonfinite_any_of_4` 0 · `F_nonfinite_count` 0 — 평가 1,501,500 회에서 목적값 넷의 비유한 0.
- **판단:** 경고는 목적값에 닿지 않는 버려지는 배열에서 난다 (정적 읽기 + 기록된 비유한 0). 이것은 수렴 · 적합성의 증거가 아니다. util 을 고치지 않고 (받은
  고정 바이트 · 봉인 대상), C4-A 실행기도 같은 경고 수를 기록만 한다.
- **다른 진단 (기록만 · 해석 안 함):** `n_out_eval_any` 1,169,477 / 1,501,500 — 평가의 약 78 % 에서 자료 Q 점 일부가 반쪽 전지 구간 밖이었다 (util 184–185 행의
  외삽 · 채움값). C4-A · C4-B 의 해석에서 함께 볼 항목으로 넘긴다.
