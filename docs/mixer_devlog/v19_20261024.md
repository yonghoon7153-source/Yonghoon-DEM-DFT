# v1.9 — D3 유한 후보 판독기 · 사용자 비준 반영 (2026-10-24)

> 1저자가 “계속 진행”, “다 비준이야”로 D3 v2의 제시된 설계 정책을 비준했다. 유한 후보 집합과 후보별 검증 상태를 계산하는 코드를 추가했다. 실제 실험·DEM 런과 장비/통계 값 입력은 아직 없다.

## 쉬운 판

실험과 맞을 수 있는 후보를 한 점으로 임의 요약하지 않고, 입력한 격자의 후보 전체를 남긴다. 두 보정 시험에서 각각 맞는 후보를 구해 교집합을 보고한다. 자료가 없거나 관측을 정의할 수 없는 점은 미평가로 보존한다.

검증 시험에서 일부 후보만 맞아도 전체가 통과했다고 쓰지 않는다. 후보마다 필수 검증의 양립·불일치·미평가를 기록하고, 보정 때 얻은 후보 집합은 그대로 둔다. 평탄하지만 유효한 관측은 후보 판정에 쓸 수 있으나 식별 능력이 확인됐다고 하지 않는다.

입력 폭·불확도·실물 조건은 공급자가 명시해야 한다. 입력 파일과 출처 파일의 SHA-256은 실제 바이트로 대조한다. 해시 일치가 실험의 타당성·사전등록·맹검을 증명하지는 않는다. **개발 단계이며 실행 GO나 새로운 실측 결과가 아니다.**

## 자세한 판

- `scripts/mixer_d3_candidates.py`: T1/T2 유한 grid 교집합, `UNASSESSED`, grid 이웃 묶음과 범위 제한, 후보×필수항목 및 `all-compatible / mixed / none-compatible / incomplete` 집계. 빈 후보 집합의 검증은 `not-applicable`.
- scalar는 명시된 `|prediction−experiment| ≤ width`, 범주형은 등록된 라벨의 exact-match만 지원한다. 폭·통계 방법·시드·장비 수치를 자동 선택하지 않는다.
- 실제 제공된 C0/C1/C2 manifest에 한해 예약 확인 시드와 미선언 역할 중복을 거부한다. 역사적 시드 미사용은 인증하지 않는다.
- CLI: `python3 -I scripts/mixer_d3_candidates.py --contract /absolute/path/contract.json --observations /absolute/path/observations.json --out /absolute/path/new-result.json`.
- 회귀: `python3 -I scripts/test_mixer_d3_candidates.py`. 보정 81조합과 검증 81조합은 서로 다른 합성 상태 공간이다. 기존 전체 gate 수에 합산하지 않는다.
- 형식·한정·재현: `docs/reviews/mixer_d3_candidate_reader_contract_20261024.md`와 `docs/reviews/mixer_d3_candidate_reader_evidence_20261024/README.md`.

비준된 것은 제시된 V2-Q1–Q4 설계 정책이다. 미정 장비·실측·격자·반복·판정 폭·G·등록과 실제 기하/덤프 판독 검증은 남아 있다. 이전 v2의 미비준 문구는 10-23 당시 상태로 보존하며 이번 사용자 비준을 과거로 소급하지 않는다.
