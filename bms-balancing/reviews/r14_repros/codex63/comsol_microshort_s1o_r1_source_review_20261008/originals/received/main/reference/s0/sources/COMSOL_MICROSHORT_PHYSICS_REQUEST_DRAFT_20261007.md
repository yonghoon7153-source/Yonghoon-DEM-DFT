## §0 왜 이 요청인가 — 지금까지 한 것과 안 한 것

사용자 (2026-10-07): "comsol 은 그러면 이제 microshorts 관련된걸 좀 파보면 안되나? … 지금까지 한거는 오 돌아가네 그런 느낌인거 같아서".

맞는 진단이다. 지금까지 확보한 것은 모두 **정상 셀** (분리막 전자전도 σ_short 1e−20 S/m · `NoCorr` — CORR 행 14) 의 수치 건전성이다:
0–480 s 저장 해와 분석 (SPEC §39 · §40) · rtol 민감도 (§41) · 120–150 s 입자 격자 민감도 (§68 · §69). **유한 σ — 모델이 존재하는 이유인
"미세단락이 있을 때 무엇이 달라지는가" — 는 한 번도 계산하지 않았다** (SPEC §37-4 질문 1 · §37-5 L7 · PLAN §0).

원장이 열어 둔 질문 (SPEC §37-4) 을 이번 요청의 출발점으로 삼는다:

1. 미세단락 신호를 **어느 구간에서** 보는가 — 충전 중 전압 · CV 전류 꼬리 · **휴지 전압 감쇠** 중 무엇.
2. 그 신호가 나오는 프로토콜은 무엇인가 (원 설계 SPEC §4-5: CC → CV 4.25 V → **12 h 휴지 · "휴지 감쇠 관측 (다음 단계) 이 이 구간을 쓴다"**).

## §1 연구 질문 (모델 안의 질문 · 실험 주장 아님)

| # | 질문 | 왜 중요한가 |
|---|---|---|
| Q1 | **휴지 감쇠:** 같은 시작 상태에서 휴지할 때, σ_short 를 바꾸면 단자 전압 감쇠 속도 dV/dt 가 어떻게 달라지는가. 정상 (σ 1e−20) 의 완화 (relaxation) 와 단락의 자가방전을 **언제부터** 구별할 수 있는가 | 실제 미세단락 판별의 표준 신호는 휴지 중 전압 강하다. 원 설계가 겨냥한 관측량 |
| Q2 | **충전 중:** 같은 σ 사다리에서 0.1C 충전 곡선은 얼마나 달라지는가. 휴지에서는 보이는 σ 가 충전 중에는 안 보이는가 | §37-4 질문 1 의 직접 답 — "어느 구간에서 볼 것인가" |
| Q3 | **내부 상태:** 누설 전류가 분리막을 지날 때 두 전극의 리튬 재고 · 표면 조성 · 전해질 전위는 어떻게 움직이는가. 단락은 리튬을 **잃는가 (LLI)**, 아니면 두 전극 사이로 **옮기기만** 하는가 (가역 자가방전) | "미세단락 ↔ 저용량 (LLI · LAM)" 혼동을 가르는 물리. 우리 열화 축퇴 연구와 직접 이어진다 |

## §3 S0 에서 Codex 에게 요청하는 것 (계산 0 · 정적 읽기 · 산술 · 후보 작성)

1. **σ 가 들어가는 자리:** 현재 NORMAL480 모델 (Java · MPH 구조) 에서 `sigma_short` 가 어디에 어떻게 들어가는지 (분리막 영역 · `NoCorr` · `epss 1` — SPEC §4-4),
   값을 바꾸는 것 외에 다른 변경이 필요한지. 1e−20 → 유한값으로 바꿀 때 초기화 (CDI) · 전위 기준 · 해의 강성 (stiffness) 에 예상되는 영향.
2. **휴지 실험의 시작 상태 (Q1):** 충전 과도 구간 없이 **균일 평형 상태에서 바로 휴지** (전류 0) 로 시작할 수 있는가 — 예: 표 안 균일 평형으로
   정한 중간 SOC 한 점 (OCP 표 안 · 외삽 없음 · 표 안 상한 4.18556 V 아래 — SPEC §34-1). 할 수 있다면 그 상태를 정하는 방법과 근거 · 할 수 없다면
   대안 (예: 기존 0–480 s 해의 끝에서 이어 휴지 — 이 경우 정상 / 단락이 같은 이력을 가져야 한다).
3. **σ 사다리 제안:** 실험 저항에서 σ 로 역산하지 않는다 (CORR §2 — 면적 · 길이 · 보정 대응 미확정). 대신 **모델 내부의 무차원 비** 로 사다리를 정하는 안을
   검토해 주기 바란다 — r = (공칭 누설 전류 밀도) / (0.1C 전류 밀도) = (σ · Δφ_s,sep / L_sep) / 2.5036 A/m².
   L_sep 25 µm (SPEC l.71) · Δφ_s,sep ≈ 3.7 V 로 두면 (추론 · Δφ_s,sep 는 단자 전압과 같지 않다 — CORR §2) σ ≈ r × 1.7e−5 S/m →
   r = 1e−3 · 1e−2 · 1e−1 · 1 이면 σ ≈ 1.7e−8 · 1.7e−7 · 1.7e−6 · 1.7e−5 S/m (추론). 휴지 중 r = 1e−2 는 공칭 0.01C 자가방전 — 1 시간에 SOC ≈1 %
   (추론). 사다리 값 · 개수 · 이 비의 정의가 적절한지, 모델에서 실제 누설 전류를 어떻게 읽을지 (분리막 고체 전류 적분) 를 제안해 달라.
4. **관측량 정의 (결과 전에 고정할 후보):** 휴지 — V(t) · dV/dt (차분 · 창 길이 · 끝점 규칙까지) · 누설 전류 I_leak(t) · 두 전극 평균 / 표면 조성 ·
   Li 재고 (전극별 · 전해질) · 보존 검사. 충전 — 기존 W0–W4 창 · M1–M3 지표 (CORR §3-2 · §3-3) 를 그대로 쓸 수 있는지. **수치 차이 기준선:**
   유한 σ 와 정상의 차를 해석하려면 그 차가 같은 설정의 수치 민감도보다 커야 한다 — 기존 관측 차이 (rtol 0–30 s µV 급 · 입자 격자 120–150 s 0.000345 mV ·
   이른 시각 0.308 mV — SPEC §41 · §68) 와 어떻게 나란히 놓을지 (이것들은 오차 바닥이 아니다 — SPEC §42-3).
5. **비용 · 저장 정책:** 휴지는 수십 분 – 수 시간이 필요하다. 현 저장 정책 (요청 격자 0.1 s) 그대로는 0.1C 전체가 벽시계 ≈5 일 · MPH ≈440 GB 로
   외삽됐다 (SPEC §37-6 · 추론). 휴지 실험에 맞는 **요청 격자 · 저장 정책** (예: 로그 간격) 과 그 정책이 기존 정책과 같은 답을 주는지 확인하는 방법
   (SPEC §37-5 L1), 그리고 S1 의 실행당 예상 벽시계 · 디스크 (기존 실행의 실측 비용을 근거로).
6. **후보 준비 (실행하지 않음):** S1 을 위한 후보 Java 변경부 (σ 매개변수화 · 휴지 시작 상태 · 저장 정책 · 출력 필드) 와 변경부 한정 정적 검증 계획.
   지금까지와 같은 순서 — 후보 → 변경부 검증 (별도 승인) → 수신 검토 → native (별도 승인) → 수신 검토.
7. **한계 명시:** 1D 균질 σ 는 분리막 전 면적에 고르게 퍼진 누설이다 — 실제 미세단락 (국소 Fe 입자 경로 · SEM l.59 · 68) 의 국소 전류 집중 · 발열 ·
   경로 성장은 표현하지 못한다. 등온 (298.15 K). 이 한계 아래에서 Q1–Q3 의 답이 무엇을 말할 수 있고 무엇을 말할 수 없는지 한 단락.
