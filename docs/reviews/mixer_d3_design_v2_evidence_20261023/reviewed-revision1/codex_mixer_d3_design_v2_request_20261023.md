## 2. 증거와 재현

증거 폴더 = `docs/reviews/mixer_d3_design_v2_evidence_20261023/`.

```bash
python -I docs/reviews/mixer_d3_design_v2_evidence_20261023/d3_v2_counterexamples.py --repo .
python -I docs/reviews/codex_mixer_d3_design_request_evidence_20261021/d3_precheck_numbers.py
```

- 첫 명령은 29개 해석 반례·산술 관계를 검사해 JSON을 출력한다. 검증한 29개가 PASS라는 뜻이며 **v2 생산 판독기 29개 회귀 PASS**가 아니다. 생산 판독기/시험 기하는 아직 없다.
- 두 번째 명령은 기존 10-21 검산을 현 트리에 재실행한다. 생성기 함수·실제 `container_at` 호출·세대별 계획 계산만 하며 DEM/LIGGGHTS는 실행하지 않는다.
- 수치 출처 = 출력의 소스 SHA와 HEAD, `SOURCE_SHA256SUMS`·`MANIFEST.sha256`. 고친 트리에서 소스 SHA가 달라지면 이전 출력을 새 코드 검증으로 재사용하지 않는다.
- 새 보장 반례: 양 끝+중점에서 0인 삼각 봉우리는 내부에서 10; 단조 계단의 직선 오차는 이웃 차 절반을 넘음; 벽 응답 w(1−w)의 양 끝은 0·내부는 0.25; 끝/중심 세 점은 내부 이진 전이를 놓침. 모두 가정 예시이며 등록 수치가 아니다.
- 실제 원문 PDF/SI, 장비, SE 단독 처리량, 탭/깔때기 문법, D3 실측·시뮬레이션은 이번에 검증하지 않았다.

## 4. 판정 형식과 남은 자료

D3K-01–17 및 새 반례마다 동의/반대·P1/P2/P3·최소 반례·해결/한정을 적어 달라. 새 통계 합격선·장비값·실험 시드·반복 수를 리뷰어가 대신 비준하는 것은 요청하지 않는다. 현재 빈칸은 v2 §9에 있다.

독립 사전 공격 리뷰는 이 요청서의 구현자 설명 대신 문서 diff와 근거 파일을 보고, 특히 “후보 전체”, “미평가”, “조건부”, “측정 전”, “동일”, “검증”이라는 말의 실제 범위를 공격해야 한다. 그 결과와 전체 게이트 출력이 붙기 전 발송 상태는 **HOLD**다.
