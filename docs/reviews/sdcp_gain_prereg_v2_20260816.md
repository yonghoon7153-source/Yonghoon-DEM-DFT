## 1. 판별 창 (v1 §1 과 동일)

생산 STEP3 는 SDCP 를 **입자당 셀 하나**로 찍는다.  표현 부피가 격자에 따라 달라진다:

| vox (µm) | 0.4 | 0.3 | 0.25 | **0.15** |
|---|---|---|---|---|
| `V_rep/V_true` | **4.53** | 1.91 | 1.11 | **0.239** |

점-스탬프 부피가 **정확해지는 지점이 vox = 0.2418 µm** (`vox³ = π/6·d³`).  생산 격자 0.25 는
그 바로 옆이고, **그 아래로 가면 SDCP 는 과소표현**된다 ⇒ 두 가설이 **반대 방향**으로 갈린다.

★ v1 이후 얻은 **통제 RVE 증거** (CL-31, crop 고정 · 8 팔, `docs/data/sdcp8_v*.json`):

| vox | `V_rep/V_true` | 이득 **참 구** | 이득 **점-스탬프** |
|---|---|---|---|
| 0.4 | 4.42 | 6.11 % | **26.08 %** |
| 0.3 | 1.89 | 5.12 % | 9.84 % |
| 0.25 | 1.10 | 5.53 % | **6.06 %** |

**참 구 이득은 5~6 % 로 평평하고 점-스탬프 이득만 26 → 6 % 로 무너진다.**  이것은 실침대
판정의 **선행 증거**지 판정 자체가 아니다 (합성 SDCP 배치 · 압밀 전 기하 — CL-31 은 hold).

## 4. ★ origin 수 — **고친 수치로 다시 계산한다** (v1 대비 유일한 실질 변경)

crop 을 고정하고 8 팔 factorial 로 다시 잰 위상 잡음 (`docs/data/sdcp8_v*.json`):

| vox | 0.4 | 0.3 | 0.25 |
|---|---|---|---|
| origin 폭 (점-스탬프 팔) | **4.66 %** | 3.61 % | 4.08 % |

(v1 은 오염된 값 2.4~5.8 % 를 썼다.  Codex 가 전수로 재면 vox 0.4 에서 8.10 % 라고 했는데,
그것도 crop 이 움직인 값이다.  **crop 을 고정하면 4.66 %** 다.)

정규표본 8 개의 range ≈ 2.85σ ⇒ 팔당 **σ ≈ 4.66/2.85 = 1.64 %**.

| N | 팔 SE | 비 SE (×√2) | 판별간격 3.5 %p 를 |
|---|---|---|---|
| 4 | 0.82 % | 1.16 % | 3.0σ |
| **8** | **0.58 %** | **0.82 %** | **4.3σ** |
| 16 | 0.41 % | 0.58 % | 6.1σ |

⇒ **8 팔 full factorial `{0, h/2}³` 를 쓴다** (4.3σ).  v1 의 결론(8 팔)은 유지되지만
**근거 수치가 바뀌었다** — v1 은 "4 팔은 1.7σ 로 부족" 이라 했는데 고친 값으로는 4 팔도
3.0σ 다.  그래도 8 팔을 쓰는 이유: 3σ 는 여유가 없고, 실침대 잡음이 RVE 보다 클 수 있다
(첨가제·압밀 기하가 더 복잡하다).  8 팔은 이미 CLI 로 가능하다
(`--step3-origin-shift`, 2026-08-16 신설).

**적응 규칙 (v1 에서 유지)**: 실측 8 팔 표준오차가 **1.17 %p** 를 넘으면 → **판정 보류**,
origin 을 16 으로 늘린다.  결론을 먼저 내지 않는다.

## 5. 실행 계약

```
런 A: SBE @ vox 0.15, origin {0, h/2}³ = 8 팔   (h = 0.15 → shift ∈ {0, 0.075})
런 B: DBE @ vox 0.15, origin {0, h/2}³ = 8 팔
  · 그 외 **모든** 인자 고정: 같은 침대 dump · 같은 코드 SHA · 스탬프 segment ·
    같은 σ 표 · **`--step3-bridge-um` 를 명시**(기본 1.2·vox 는 격자마다 달라진다 —
    CL-22 의 결함을 반복하지 않는다) · 같은 plate band
  · 각 payload 가 자기 위상을 기록한다 (`manifest.origin_shift_um`, 2026-08-16 신설)
보고: 16 개 σ_e 값 **전부** + 팔별 평균 + 비 + 8 팔 표준오차 + 각 런의 cg_info/resid.
      하나도 빼지 않는다.
```

**판정 순서** (결과를 보기 전에 고정):
1. 미수렴 팔(`cg_info ≠ 0`)이 하나라도 있으면 → **판정 보류** (Codex CDX-R2-02 의 교훈).
2. 8 팔 표준오차 > 1.17 %p → **판정 보류**, origin 16 으로.
3. 비 ≥ 1.05 → h0 채택, h1 기각.
4. 비 ≤ 1.025 → h1 채택 ⇒ **SDCP 전자 이득은 원고에서 철회**한다.
5. 1.025 < 비 < 1.05 → **둘 다 기각**, 제3 기전 조사.

## 6. 이 검사가 증명하지 못하는 것 (v1 §6 유지 + 추가)

- **이온 축은 안 다룬다.**  σ_ion 비의 부호 반전은 별건이다.
- **VGCF 는 안 갈린다** — Ø0.15 µm 라 vox 0.15 에서도 **1 셀**이다.  h0 가 채택돼도
  "이득이 물리다" 를 **완전히** 증명하지는 않는다 (SDCP 축만 닫는다).
- **실침대 상별 부피 원장**은 여전히 필요하다 (`count(sid)·vox³` vs 레시피) — §1 의 배수는
  단입자 산술이라 셀 충돌·overwrite 를 포함하지 않은 **상한**이다.
- **post-MPM 기하의 수송 해상도 규칙은 아직 없다** (Codex CDX-R2-03; CL-30 은 hold).
  이 런은 **한 격자에서의 규약 대조**이지 격자 수렴 증명이 아니다.
