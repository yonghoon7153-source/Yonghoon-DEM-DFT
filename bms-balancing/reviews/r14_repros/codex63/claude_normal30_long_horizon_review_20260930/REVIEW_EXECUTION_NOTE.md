# 검토 실행·출처 메모

2026-09-30. 전달 자료는 해석 검토이며 원 COMSOL 실행 결과나 실행 승인 파일이 아니다.

- 검토자 작성 `review_arithmetic.py`를 번들 Python의 `-I -B -X utf8`로1회 실행했다. 전달된 Java/Python/PowerShell은 실행하지 않았다.
- 실제 검토자 도구 반환: chunk `226ae4`, exit_code0, wall_time1.5959278초. 스크립트 내부 산술·파일 확인 시간은1.4849999999860302초다. 둘은 같은 시간 범위가 아니다.
- 이 문서는 해당 반환을 읽고 작성한 후속 메모이며, 별도 원시 OS 감사 로그가 아니다. 원래 COMSOL30초의 도구 반환과 혼동하지 않는다.
- CSV9개는 이전 수신 검토의 콘솔 CSV 해시 식별과 현재 바이트를 대조했다. 선택 원문16개 전후 식별은 같았다. 기존 MPH 자체는 이번에 열지 않았다.
- 문서에 참조한 COMSOL 공식자료와 구 확산 논문을 웹으로 확인했다. 구 확산 논문은 preprint다. 공식 시간 스텝 문서의 기본 초기 step 설명을 이 모델의 고정 초기 step이 풀렸다는 증거로 사용하지 않았다.
- P의60–102% 문제는 같은 좌표와 전극평균을 혼동한 해석 차이다. 기존30초 CSV·수용 판정·소비자를 변경할 필요가 있는 실행 오류로 분류하지 않았다.
- 한 모드 맞춤 창·고정 유속 구 확산·선형 비용·고정4.2V 누설은 각각 별도 가정의 산술이다. 새 시뮬레이션 결과 또는 합격 기준으로 표시하지 않았다.
- 현재 검토자 code/ZIP은 자동 실행 지시가 아니다. 외부 송신·실제 승인 활성화·COMSOL/JVM/native 계산·정책 변경은 하지 않았다.

별도 검토자 ZIP에는 요약·회신·작업 요청 초안·산술 JSON·선택 원문 식별·검토자 코드·받은 Claude 문서 사본을 넣었다. 30초 원시 대형 CSV/MPH는 재포장하지 않는다. ZIP만으로 원시 CSV 전체 재검산이 가능한 자기완결 패키지가 아니다.
