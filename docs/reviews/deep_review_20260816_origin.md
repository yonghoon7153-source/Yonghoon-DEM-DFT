## 1. ★ σ_eff 정규화 면적 결함 — **확정** (공격 지점 1)

`step3_sigma.py:535`:
```python
sigma_eff = max(0.0, I * (z_plate - z_b) / (nx * ny * vox * vox))
```
분모 면적이 **격자 전체**다.  origin 이동은 `_lo3 = -osh` · `_hi += osh`
(`mpm_webapp_payload.py:908,912`) 라 `n = ceil((hi-lo)/vox)` (`step3_sigma.py:207`) 가
**이동한 축마다 셀 하나를 늘린다** (원격 로그 334→335 와 정합; T2 로 기전 재현).
침대는 그대로인데 분모만 늘면 σ 는 축당 `n/(n+1)` 만큼 낮아진다.

**판별 (h0: 전 팔 동일 / h1: 측면 이동 팔만 n/(n+1))**:
- **T1** (분모 격리): 같은 sid 에 빈 x-열 1개 패딩 → 솔브계가 동일(빈 열은 dof 0)하므로 I 는
  비트 동일이고 남는 것은 분모뿐.  실측 비 **0.97297297 = 36/37 소수 8자리** → **h1**.
- **T2** (payload 프로토콜 전체): `rasterize` 를 `lo=-s, hi+s` 로 그대로 통과시키되, 기둥
  도체의 스탬프 셀집합이 팔간 동일하도록 좌표를 설계 (도체셀 6,084 네 팔 모두 동일 실측).
  x팔 0.97297297 · y팔 0.97297297 · xy팔 0.94667641 = (36/37)² — **h1 정확 적중**.
- **T3/T8** (반대 극한): 침대가 박스를 **꽉 채우면** 가장자리 반셀이 점-스탬프로 부풀어
  도체 폭도 +1셀이 되고 σ = 1.00000000 로 **정확 상쇄**된다.

⇒ 실침대의 측면 이동 팔은 **[−1/n, 0] = [−0.299 %, 0] 의 축-상관 계통항** 위에 있고, 크기는
침대가 측벽 반셀 스트립을 얼마나 채우는지에 달려 **팔 데이터만으로는 결정 불가**다.  이것이
결함의 본질이다 — origin 앙상블은 "격자 위상만 바꾼다" (`mpm_webapp_payload.py:894-896` 주석)
고 주장하지만 실제로는 **정규화 면적도 함께 바꾼다**.  SE 매트릭스(이온망)는 압밀 침대라
벽까지 차 있어 상쇄 쪽, 전자망(VGCF/AM)은 벽에서 희박해 무상쇄 쪽으로 기울 것이나 이는
추론이지 측정이 아니다.

**실측 8팔 factorial 분해 (T5; ln σ 주효과, %)** — "보정" = 상한 가정(무상쇄) ×(nx·ny)/334²:

| | x | y | z | xy | 폭(range/min) |
|---|---|---|---|---|---|
| SBE raw | +0.115 | −0.775 | +0.452 | +0.301 | **1.84 %** |
| SBE 보정 | +0.414 | −0.476 | +0.452 | +0.301 | 1.84 % |
| DBE raw | +0.219 | −0.671 | +0.300 | +0.469 | **1.77 %** |
| DBE 보정 | +0.518 | −0.372 | +0.300 | +0.469 | 1.62 % |

- 보고된 "폭 1.84/1.77 %" 는 range/min 규약으로 **재현**된다 (CL-33 수치 = 원자료와 자기일관).
- **인공물 몫**: 축당 −0.299 % (상한).  폭 기준으로는 0~0.15 %p (≤8 %) — 폭은 y-효과
  (−0.7 %)와 xy 교호가 지배하므로 **"위상 폭 ~1.8 %" 라는 크기 서술은 생존**한다.  그러나
  8팔 **평균은 상한 기준 −0.298 % 계통 오염**이므로, 앙상블 평균 σ_e 를 절대값으로 인용할
  때는 이 항을 오차예산에 넣어야 한다.  축별 귀속(x/y/z 어느 위상이 민감한가)은 0.3 % 아래에서
  신뢰 불가.

## 2. 비(比)에서의 소거 — **사전등록 h1 판정은 생존한다** (공격 지점 2)

같은 팔의 SBE/DBE 는 같은 스캐폴드 박스(case 260714_145738_778fa4)라 격자 모양이 같고,
§1 의 면적 인자는 **팔별로 곱해지는 공통 인자**이므로 팔별 비에서 정확히 소거된다.

- 팔별 DBE/SBE: 1.01712 · 1.01507 · 1.01629 · 1.01459 · 1.01680 · 1.01408 · 1.01806 ·
  1.01834 — **8팔 전부 [1.0141, 1.0183] ⊂ (< 1.025 = h1 채택선)**.  팔간 폭 0.42 %
  (원 σ 폭 1.8 % 의 ¼ 이하 = 공통모드 소거의 실측 증거).
- 판정기 규약(`sdcp_gain_verdict.py` — 평균의 비 + 독립 quadrature se)으로: 비 1.016294,
  상한-보정을 걸어도 **1.016295 (차 1.6e-6)**.  se 재현 0.278 %p (CL-33 의 0.28 ✓).
- 짝지은(paired) se 는 **0.056 %p** — 판정기의 독립-가정 se 0.278 %p 는 5배 보수적이다
  (결함 아님; h1 분리가 실제로는 더 강하다는 뜻).

⇒ §1 의 결함은 **판정 h1 을 뒤집지 못한다**.  단서 하나: DBE 고유 상(SDCP·PTFE)의 벽면
분포가 SBE 와 달라 상쇄가 2차에서 깨질 수 있으나, 그 크기는 가장자리 한 층 부피비
(~1/334 × 상분율) 스케일로 팔별 비 폭 0.42 % 안에 묻힌다.

## 3. z-이동 — "L 불변 = σ_eff 규약 유지" 는 절반만 참 (공격 지점 3)

`mpm_webapp_payload.py:937` 이 `_zt3, _zb3 = _ztop + s_z, s_z` 로 두 평면을 같이 밀어
L 은 불변이다 — 여기까지는 옳다.  그러나 **T3z**: 꽉 찬 슬랩을 z-이동하면 바닥·꼭대기
반층이 점-스탬프로 부풀어 재료 경로가 +1층 되고, L 은 고정이므로 σ = **36/37 정확**
(−1/(N+1)).  실격자 상한 −1/491 = **−0.204 %** (바닥은 플로어-압밀이라 팽창 확실, 꼭대기는
crown 이라 부분).  관측 z 주효과 +0.45/+0.30 % 는 부호가 반대 = 위상 잡음이 지배하지만,
z 팔도 자기 계통항을 가진다는 사실은 남는다.

**플레이트 접촉수 요동** (원격 a0 13,328/12,709 → a1 8,789/17,599): T4 다공 침대에서
재현 방향 확인 — 접촉수 bot +34 %/top +54 % 요동에 σ 는 +6.3 % (nz 29 소격자; 접촉수
요동의 ~1/8).  기전: band 안의 `g = σ·vox²/max(dist, vox/2)` (`step3_sigma.py:513-514`)
거리가중이 새로 들어온 먼 접촉에 작은 g 를 주어 완충한다.  실격자(nz 490)에서 z-효과가
0.45 % 에 그친 것과 정합 ⇒ **접촉수는 시끄러운 진단이지 σ 붕괴 신호가 아니다** (h0).
단, `solve_sigma_z` docstring 의 "capped 1.4·vox" (`step3_sigma.py:394-395`) 는 **코드에
없다** — `:420` 은 `band = vox + 0.10` 뿐이라 vox 0.15 에서 band = 0.25 µm = **1.67·vox**
로 두 층에 닿는다.  문서가 약속한 캡이 구현에 없는 문서-코드 불일치 (어느 쪽이 의도인지
결정 필요; 요동 크기의 배경이기도 하다).

## 5. 파급 — RVE origin 앙상블(CL-30 · prereg §4 근거수치)은 더 굵게 오염돼 있다

`step3_transport_resolution.py:78`: `n = round(L/vox) + (1 if sh.any() else 0)` — **어느 한
축이라도 이동하면 세 축 모두** +1셀인 정육면체 격자를 만든다.  vox 0.4 · L 20 이면
분모 면적항이 (50/51)² = **−3.88 %** — z-만 이동한 팔조차 측면 빈/반채움 열 2개를 얻는다.
게다가 `:110` 의 `solve_sigma_z(sid, sig, vox)` 는 z 평면을 안 넘겨 플레이트가 점유층에
**스냅**된다 — payload 가 "×2.8 잔차 요동" 때문에 금지한 규약이다 (`step3_sigma.py:411-413`).
⇒ prereg §4 의 "origin 폭 4.66 % → 팔당 σ ≈ 1.64 %" 는 순수 위상 잡음이 아니라
[면적항 + 플레이트 스냅 + 위상]의 합이다.  실측 8팔의 실현 잡음은 range 1.84 %/2.85 ≈
**0.65 %/팔** — 캘리브레이션의 ~2.5배 아래.  영향 방향은 보수적(잡음 과대 → 팔 수 과다
요구)이라 판정은 무해하나, **1.64 % 를 위상 잡음 상수로 재인용하지 말 것**.
