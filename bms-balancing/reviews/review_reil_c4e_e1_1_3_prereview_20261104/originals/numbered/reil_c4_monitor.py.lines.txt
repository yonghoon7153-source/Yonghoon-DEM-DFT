1: """REIL C4 감시 · 기록 (C4 v2 §4-4 · 사전 검토 C4-N2 · C4-N3 보완 · 상태 문서 §39 C4-0a).
2: 
3: C5 의 `reil_c5_pilot.orchestrate` · `disk_sample` · `split_dirty` 는 **고치지 않는다** (실행된 증거). C4 실행기는 이 모듈을 쓴다. 고친 것 셋:
4: 
5: 1. **공백 검사** (C4-N2) — 표본이 *도착한* 시각으로, 성공 여부와 무관하게 마지막 유효 표본 (없으면 감시 시작) 과의 간격을 본 뒤에야 마지막
6:    유효 시각을 갱신한다. 늦게 도착한 성공 표본도 공백을 덮지 못한다. None · 예외 · 첫 표본 지연을 따로 적는다. 예외는 기다리지 않는다.
7: 2. **마감** (C4-N2) — 표본 수집 뒤 현재 시각으로 마감을 다시 본다. 작업자도 절대 마감 시각을 받아 **마감 뒤에는 새 작업을 시작하지 않는다**.
8: 3. **산출량 · 소유 경로** (C4-N3) — 본체 · 래퍼 · 임시 · 최종 기록의 소유 루트를 미리 열거해 합산한다 (겹친 루트는 한 번). 최종 쓰기 뒤에 같은
9:    루트 집합으로 다시 잰다. 경로는 정확 일치 또는 구분자 뒤 하위 경로만 소유로 본다. Git 원문은 분류와 따로 남기고, 따옴표 · 이름 바꿈처럼
10:    모호한 줄은 소유로 보지 않는다.
11: 
12: C4-0a 결과 검토 (2026-10-13) 의 한정 보완 셋:
13: 
14: - **N2** — 최종 기록은 마지막 쓰기 · 재읽기 · 해시 · 용량 조회 **뒤** snapshot 하나로 시간 한도를 판정하고 그 값을 그대로 반환한다. 넘으면
15:   파일 · 해시는 보존하고 미완 (`RECORD_INCOMPLETE`) 이다.
16: - **N3** — 느릴 수 있는 조회 (RSS · 디스크) 뒤와 정상 종료 직전에 두 감시기의 freshness 를 확인한다 (`Watch.stale`). 확인은 표본이 아니라서
17:   마지막 유효 시각을 바꾸지 않는다.
18: - **N4** — 구조 오류의 `partial` (이미 모은 계수) 을 작업자 경계 너머 부모까지 보낸다. 그 작업은 여전히 중단 (`STARTED_INTERRUPTED`) 이다.
19: 
20: C4-E (v3 §3 · 상태 문서 §66) 의 선택 인자 하나:
21: 
22: - **`stop_rule`** — 기본값 None 이면 지금과 같은 동작이다. 주면 매 tick (RSS 표본 · freshness 확인 뒤) 에 `rule_snapshot` 으로 부른다
23:   (원점 t0 의 상대 시각 · 작업자 start 사건 · 완료 행의 wall / n_eval / termination · progress · 계획 — X · F · G 없음). 문자열이면 전역
24:   중지 사유 · 예외 · 형식 오류는 우리 구조 오류 (사유 원문 · `apply_rule`). 규칙은 상태를 바꾸지 않는다 (done 우선 분류 그대로).
25:

237: def supervise(tasks, ctx, task_fn, *, n_workers, limits, t0, clock=time.monotonic, rss_fn=None, disk_fn=None,
238:               out_roots=(), free_path=".", tick=1.0, disk_every=5.0, stop_rule=None) -> dict:
239:     """작업 → 작업자 배정은 `task["worker"]` 로 고정. 표본 감시 (Watch) · 마감 · 전역 중단 → 소유 작업자만 종료.
240:     `stop_rule` (C4-E) 은 매 tick RSS 표본 · freshness 확인 뒤에 부른다 — 기본값 None 이면 부르지 않는다."""
241:     import multiprocessing as mp
242:     mpc = mp.get_context("fork")
243:     q, stop = mpc.Queue(), mpc.Event()

245:     deadline_abs = t0 + float(limits["measure"])
246:     rss_fn = rss_fn or rss_bytes
247:     disk_fn = disk_fn or (lambda roots: disk_sample(roots, free_path))
248:     ev = {"started": {}, "done": {}, "worker_start": {}, "worker_end": {}, "worker_deadline": {}, "structural": []}
249:     rss_w = Watch("메모리", limits["rss_gap"], clock() - t0)      # 표본 시각은 원점 기준 상대값
250:     disk_w = Watch("디스크", limits["disk_gap"], clock() - t0)
251:     reason = None
252: 
253:     def fresh(now):
254:         """두 감시기 freshness 확인 (C4-0A-N3) — 확인만 · 유효 시각을 바꾸지 않는다."""
255:         return rss_w.stale(now) or disk_w.stale(now)

257:     def handle(msg):
258:         kind, key, payload = msg
259:         if kind in ("start", "done", "worker_start", "worker_end", "worker_deadline"):
260:             ev["started" if kind == "start" else kind][key] = payload
261:         elif kind == "structural":
262:             ev["structural"].append({"task_id": key, **payload})
263: 
264:     def drain(timeout=0.05):
265:         while True:
266:             try:
267:                 handle(q.get(timeout=timeout))
268:             except queue.Empty:
269:                 return True
270:             except Exception:  # noqa: BLE001 — 강제 종료 뒤 깨진 메시지 → 기록 미완
271:                 return False

273:     procs = {w: mpc.Process(target=worker_loop, args=(w, [t for t in tasks if t["worker"] == w], ctx, task_fn, q, stop,
274:                                                        shared_prog, deadline_abs), daemon=True) for w in range(n_workers)}
275:     if clock() >= deadline_abs:
276:         reason = f"단계 경계 — 측정 마감 ({limits['measure']} s) 전에 시작하지 못했다"
277:     else:
278:         for p in procs.values():

282:         try:
283:             handle(q.get(timeout=tick))

285:             pass

288:             reason = f"구조 오류: {s.get('type')} ({s.get('origin')} · {s.get('stage')}) {s.get('message')}"[:400]
289:             break

294:                 and w not in ev["worker_deadline"]]

332:             if reason is None:
333:                 reason = fresh(clock() - t0)                          # 느린 디스크 조회 뒤 — RSS 감시기 freshness (C4-0A-N3)

371: def _dump(obj) -> bytes:
372:     return (json.dumps(_jsonable(obj), ensure_ascii=False, sort_keys=True, indent=1) + "\n").encode("utf-8")

375: def final_record(out_dir, parts: dict, *, roots, limit_bytes, clock=time.monotonic, t0=0.0, limit_s=float("inf")) -> dict:
376:     out_dir = Path(out_dir)
377:     state, files, problems = "COMPLETE", {}, []
378:     for name, obj in parts.items():
379:         if clock() - t0 > limit_s:
380:             state = "RECORD_INCOMPLETE"
381:             problems.append(f"최종 기록 단계 경계 {limit_s} s 초과 — {name} 부터 쓰지 않았다")
382:             break
383:         data = _dump(obj)
384:         try:
385:             (out_dir / name).write_bytes(data)
386:             back = (out_dir / name).read_bytes()
387:         except OSError as e:
388:             state = "RECORD_INCOMPLETE"
389:             problems.append(f"{name} 쓰기 실패: {type(e).__name__}: {e}")
390:             break
391:         if back != data:
392:             state = "RECORD_INCOMPLETE"
393:             problems.append(f"{name} 다시 읽은 바이트가 다르다")
394:             break
395:         files[name] = hashlib.sha256(back).hexdigest()
396:     after = output_bytes(roots)
397:     snap = clock() - t0       # 마지막 쓰기 · 재읽기 · 해시 · 용량 조회 뒤 snapshot 하나 — 시간 판정과 반환에 같은 값 (C4-0A-N2)
398:     violations = []
399:     if snap > limit_s:
400:         violations.append("time")
401:         problems.append(f"최종 snapshot {snap:.3f} s > 기록 한도 {limit_s} s — 파일 · 해시는 보존하고 미완으로 둔다")
402:         if state == "COMPLETE":
403:             state = "RECORD_INCOMPLETE"
404:     if after > limit_bytes:
405:         violations.append("size")
406:         problems.append(f"최종 쓰기 뒤 산출 {after} B > 상한 {limit_bytes} B — 성공으로 종결하지 않는다")
407:         if state == "COMPLETE":
408:             state = "OUTPUT_LIMIT_EXCEEDED"
409:     return {"record_state": state, "files": files, "problems": problems, "output_bytes_after": after,
410:             "output_roots": [str(r) for r in roots], "final_snapshot_s": snap, "limit_violations": violations}
