## 3. Q-V2-2 — p7·9·12·15의 해석 조건

### p7: 22 GPa는 수용, 다만 E와 K를 구분

**22는 옛 24를 다시 이름 붙인 숫자가 아니다.** 고정 `CLAUDE.md:1403`에 이미 DFT `E_VRH=22.06 GPa`, 정본 Bazzoun 카드 `:21/:30`에 DEM 입력 `E_SE=22.1 GPa`가 있다. 따라서 `our DFT E_VRH`와 `literature DEM input`으로 구분한 현재 사용은 적절하다. Bazzoun의 입력값을 우리 시편의 독립 실측이라고 바꾸지 않는다.

MPM의 `E=1.53 GPa, ν=0.49`에서 **K=E/[3(1−2ν)]=25.5 GPa**이고 비교 대상 DFT EOS **B0=26.23 GPa**다. 이것은 22.06의 영률 E와 다른 물리량이다. 이번에는 DFT 원텐서/EOS 원출력에서 재계산하지 않았으므로 ‘DFT 계산 자체 재검증’이 아니라 **기존 기록·물리량·인용 지위 대조**다.

SEM-07의 핵심인 σy=0.30의 보정 선택, 순수 SE 10%/300 MPa의 **미출판 랩 보정 표적**, 문헌 귀속 철회, 시험한 대안으로 한정한 설명은 닫혔다. 다음 좁은 손질은 남는다.

- **SEMV2-05 / P1:** p5 notes와 생성기 `:371`의 `Bulk modulus reference ≈22 GPa = ... E_VRH`를 `Young’s modulus reference: our DFT E_VRH = 22.06 GPa`로 교체. K/B0는 별도 26.23 GPa라고 쓴다. 화면 수치를 바꿀 필요는 없다.
- **SEMV2-06 / P1:** p7 첫 행의 `σy 0.05–0.30 GPa`는 [8]이 보증하는 독립 물성 범위처럼 읽힐 수 있다. 새로 확인된 출처·시험법이 없으므로 화면에서 삭제하는 것이 간단하다. 보정 스윕 지위와 선택값 0.30은 위·아래에 이미 있다. 이 지적은 22 GPa 자체나 보정 선택 전체를 다시 HOLD시키는 것이 아니다.

첫 행 권장:

> LPSCl reference: E ≈22 GPa (our DFT E_VRH; literature DEM input 22.1 GPa [8]).

### p7·5·14: 단어 수를 기계적인 합격선으로 쓰지 않음

## 7. 증거 묶음 안내

`evidence/input_manifest.json`은 파일 해시와 실제 변경 장을, `pptx.json`/`all_slide_text.txt`는 본문·notes·미디어·좌표를, `pdf_text.json`/`renders/`는 제공 PDF의 별도 추출·렌더를 담는다. `recheck_proof.json`은 CSV 불변·G3/G5a 이미지 동일성·코호트 계수·자리 표시 개수를 기록한다. `arithmetic_rerun.txt`는 저장된 Phase A·단면 하중·LHS 수치를 독립 산술한 결과다. `references/`는 본 판정의 직접 근거 사본과 핀/해시 목록으로 연결된다.

재현 도구 `inspect_recheck.py`, `verify_delivery.py`는 입력 파일과 앞 검토의 고정 사본을 읽는다. 단독 배포판에서 앞 검토 폴더가 없으면 재실행 환경이 완전하지 않으므로, 동봉 JSON/TXT와 원근거 사본을 확인한다. 재현 도구가 DEM/MPM/전도도 솔버를 실행하는 일은 없다.
