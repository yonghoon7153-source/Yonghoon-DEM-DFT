# ADR 0028 — 전고체 복합전극은 아크가 아니라 전송선이다

- 상태: 채택 (2026-08-26)
- 관련: ADR 0019(EIS 는 독자 섹션), ADR 0026(확산 꼬리),
  `packages/wrdkit/src/wrdkit/eis/circuit.py:transmission_line`

## 맥락

전고체 프리셋이 `R0-p(R1,CPE1)-p(R2,CPE2)-Ws3` 계열이었다. 아크 둘과 확산
꼬리 하나. ADR 0026 에서 실측 21스윕으로 W→Ws 를 갈아 끼웠지만, 그것은 **꼬리
모양**을 고친 것이지 회로가 옳다는 뜻은 아니었다.

랩이 실제로 쓰는 모델은 PyEIS 의 전송선(`TL_IE_W_2`, i-e connection 을 붙인
랩 자체 확장)이다. 그리고 그 편이 물리적으로 맞다:

**복합전극은 표면이 아니다.** 이온은 기공/고체전해질을 따라(`Ri`), 전자는 활물질과
도전재를 따라(`Re`) 흐르고, 반응은 **가는 도중에** 두께 전체에 퍼져 일어난다.
그래서 고주파의 45° 짧은 꼬리와 저주파의 `R_ion/3` 절편이 나온다 — 둘 다 이
기하에서 나오는 것이지 어떤 R-CPE 조합에서도 나오지 않는다. 아크 회로로 맞추면
숫자는 떨어지지만 그 숫자가 무엇의 저항인지 말할 수 없다.

## 결정

### 1. `TL` · `TLR` 두 원소를 회로 언어에 넣는다

```
Z = (Re·Ri)/(Re+Ri) · [1 + 2λ/sinh(1/λ)] + λ·(Re²+Ri²)/(Re+Ri) · coth(1/λ)
λ = sqrt(Z_계면/(Re+Ri))
```

Bisquert (J. Phys. Chem. B 104, 2000) 의 일반해이고, **PyEIS 1.0.10 의
`cir_RsTL` 과 항별로 대조**해 옮겼다. 두께는 1 로 두고 레일을 **총량(Ω)** 으로
받는다: 식에는 곱만 들어가므로 두께를 따로 두면 스펙트럼이 정할 수 없는 수가
하나 느는 것뿐이다.

- `TLR` — 계면이 `Rct ∥ CPE`. 파라미터 다섯.
- `TL` — 계면이 `CPE ∥ (Rct + 유한확산 W)`, `Z_W = Wr·coth(x)/x`,
  `x = (Wt·jω)^Wn`. PyEIS `cir_RsTL_1Dsolid` 와 같은 구성이다. 파라미터 여덟.

검증은 세 가지로 고정했다: 전자 레일을 0 으로 두면 고전 해
`sqrt(Ri·Z)coth(sqrt(Ri/Z))` 와 1e-8 이내로 같고, 저주파 절편이 정확히
`R_ion/3` 이고, 13 파라미터짜리 합성 스펙트럼을 되맞추면 전부 5 % 이내로
돌아온다.

`sinh` 는 |x|>710 에서 넘친다. 고주파 끝은 `coth→1`, `1/sinh→0` 으로 끊어
계산한다 — 안 그러면 고주파 절반이 NaN 이 되고, 그 NaN 은 "안 맞았다" 와
구분되지 않는다.

### 2. 전고체 프리셋을 갈아 끼운다

`(전고체, 풀셀)` 과 `(전고체, 하프셀)` 의 첫 회로가
`L1-R0-p(R1,CPE1)-TL1` 이다 — 랩 스크립트와 같은 구성이다: 배선 인덕턴스,
직렬 저항, 보정용 R-CPE, 그리고 전송선. **아크 회로는 뺐다.**

`(전고체, 대칭셀)` 은 임시다. 랩의 대칭셀 모델을 아직 못 받았고, 이온 블로킹
대칭셀은 반응이 없어 전송선이 아니라 아크 둘 + 블로킹 꼬리가 맞다 — 전도도를
내는 그 측정이다. 그래서 둘 다 두되 note 로 갈라 두었다.

### 3. 옮기지 못한 것

랩 코드의 `W0 · a · b` 는 계면 Warburg 의 세 수인데, `cir_TL_IE_W_2` 자체를
아직 못 봤다. 값의 생김새(W0=0.24 Ω, a=0.75, b=98.6 s)가 PyEIS 의
`R_w · n_w · time_const` 와 맞아떨어져 그렇게 옮겼지만 **확인한 것은 아니다.**
`Cib/Nib/Ribb/Cibb/Nibb` 와 `Ceb/Neb/Rebb/Cebb/Nebb` — 두 레일의 **경계
임피던스**("i-e connection" 이 그것이다) — 는 넣지 않았다. 랩 fit 에서 전부
0/vary=False 라 이번 데이터에는 영향이 없다.

## 결과

- 전고체 셀의 기본 회로가 이온 저항·전자 저항·계면을 **이름으로** 낸다.
- DRT 가 넓게 나오는 것이 설명된다: 전송선은 이완 시간이 하나가 아니라 띠다.
  봉우리가 아니라 언덕이 정상이고, 그 사실을 DRT 패널이 적는다.

## 안 한 것

- **두께를 파라미터로.** `Ri·L` 만 관측되므로 두 수로 나누면 하나는 임의다.
  두께는 이미 셀/측정의 입력값으로 있고, 전도도 계산은 그것을 쓴다.
- **액체 전해질 프리셋 변경.** 액체 쪽 복합전극도 전송선이 맞지만, 랩의 실측과
  절차서가 아크 회로로 돌아가고 있다. 근거가 생기면 그때 바꾼다.
