# 저장소 경로 반입 기록

반입 전 docs 44개의 모든 원 바이트와 당시 outer/nested manifest를 원래 저장소 상대 경로로 original-package-docs.zip에 보존한다. 원 manifest의 docs 멤버는 그 ZIP에서 대조하며, source/literature 지문이 가리키는 외부 Git 소스와 문헌은 이 docs ZIP 밖에 있으므로 각 기록의 원 source pin으로 대조한다. 최종 review ZIP의 선택 소스 문맥은 별도 selected_paths 기준이다.

이 폴더의 provenance와 diff는 반입 경로/현행 지문 문맥만 설명한다. 원본 ZIP은 다시 쓰지 않는다. 독립 검토/계산 결과를 새 실행 또는 GO로 승격하지 않는다.

최초 REVIEW의 설계 인용은 원 검토 SHA 24fda5535c511aa5d8930d2971003122180046519c693c2e55dcdec3fde39373와 일치하는 original-draft를 가리킨다. reviewed-revision1 또는 최종 설계로 바꾸지 않았다.
