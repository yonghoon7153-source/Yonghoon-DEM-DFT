# T12R-01 오프라인 계약 수정 인계

외부 T12 검토는 P1/P2 분리·52관측해석·ULPRI-01/02 좁은종결을 수용했고, 누락객체 promisor의 자동fetch를 P2 T12R-01로 지적했다. 이번 수정은 snapshot Git자식의 명시적 lazy-fetch금지와 상주회귀에 한정한다. 소비자키트·params·P2등록·물리판정선을 고치지 않는다.

[재확인 요청](../../reviews/dem_gen2_t12r_offline_recheck_request_20261026.md), [새 증거](../../reviews/dem_gen2_t12r_evidence_20261026/README.md), [범위 영수증](../../reviews/dem_gen2_t12r_evidence_20261026/scoped-review-receipt.json)을 함께 본다. 로컬수정은 claimed fixed이며 외부재확인은 대기다. 과거HOLD와 무조건offline문구는 역사기록으로 보존하고 새날짜정정과 구분한다.

현재 검증 Git은2.52.0이다. 전역 --no-lazy-fetch를 지원하지 않으면 조회전에 거부한다. 다른플랫폼/옛Git을 검증했다고 쓰지 않는다. 직접52·오프라인회귀·소스거부8·변이13은 공용155와 별도근거다. 전체게이트와 최종실제원격핀은 완료뒤 후속증거/PIN으로 확인한다.

외부§6A-D는 실제사실/등록→생산자-소비자양음성→실제R-a/S0자격→통합트리검증의 후속수용조건이다. 새P2구현이나 A1–A5/Q1–Q16 재선택이 아니다. 통합CI는 과거고정핀회귀와 실제통합소비자검사를 구분해야 한다. 이번직접PASS를 미래통합트리PASS로 옮기지 않는다.

물리T12 NOT_RUN/physical_ready=false, G2mass·omega동일성 미인증, 실측결손 유지. 범용P1GO·세대2설계전체GO·WSL/연구계산·Claude통합은 승인하거나 수행하지 않았다. 기존제출핀/ZIP은 보존한다.
