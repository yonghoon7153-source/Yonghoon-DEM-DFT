### DEM 세대 2

1. **Q1 — 다음 비활성 준비 범위:** 등록 선택표와 live 관측·경계 기록·ULPR 계약을 어떤 순서의 후속 묶음으로 구체화할까요?
   **권고:** T5/T11 정량 선택표와 T12 입출력 계약을 먼저 맞추고, 후속 구현은 세 연결별 시험·고정 핀 검토로 나누며 gate 정지를 유지합니다.
2. **Q2 — 결과 전 등록 수치 (선택안 준비 뒤):** T5 표본/반복/coverage·실패확률, T11 강성/지연/주기·창·예산, 힘 수지/관통 관측의 정량 기준을 어떤 근거와 적용 범위로 고정할까요?
   **권고:** 합성 상수를 실제 값으로 이식하지 않고 선택지·근거·보류 칸을 제시한 뒤 1저자가 결정하며, 완결 등록/자격 없이 PASS로 올리지 않습니다.
3. **Q3 — 실제 사실의 담당·범위:** 빌드·기존 자격 기록의 신원/출처 메타와 50 kg의 하중 정의·면적·입경/측정 규약을 누가 어떤 범위로 제공할까요?
   **권고:** 비결과 신원·규약의 출처/담당/수령 범위를 먼저 지정하고 실제 자격 값은 Q4의 별도 승인에 두며, 0.7/1 µm 비교는 같은 실제 정적 압력·관측 단계의 gen2 설계에 둡니다.
4. **Q4 — 작은 자격 수행 (고정 계획 준비 뒤):** T0·이력·재개·dt/2와 실제 관측이 필요한 자격을 어느 빌드/fixture·자원·중단 조건으로 제한할까요?
   **권고:** 그 범위의 반박 창 GO와 1저자 별도 GO를 받은 작은 자격만 수행하고, 증거 수용 뒤 통합/운영 봉인·생산 실행 GO를 별도로 심사합니다.

### LHS
