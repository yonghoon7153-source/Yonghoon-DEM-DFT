# 수영 U6(c) F8 조밀 표본 반환 판독

## 1. 시간 간격과 초기 표본을 맞춘 뒤 남은 차이

1저자 WSL에서 F8 격자에 F16의 초기 물질점 39,053개를 배치하고 F16 시간 간격을 사용했다. 49개 원판의 물질점 좌표·ID·부피 해시 3개가 고정 신원과 일치했다. 5,289걸음, 644.36초에 중단 압력 1.2 MPa에 도달했다. 새 팔과 판독기는 모두 rc 0이었다. 아래 값은 설정 ① 가압 시 아래판 힘을 판 폭으로 나눈 개발 반력이다.

| 지정 변위에서 차례로 바꾼 조건 | 반력 (MPa) | 앞 조건에서 감소 (MPa) |
|---|---:|---:|
| 원 F8, 물질점 9,653개 | 1.200856 | — |
| F8, 시간 간격만 절반 | 1.170890 | 0.029966 |
| F8, 같은 반걸음에 F16 물질점 39,053개 | 1.115017 | 0.055873 |
| 원 F16, 같은 시간 간격·같은 물질점 | 0.634878 | 0.480139 |

주 비교 변위 `u=0.11562281664031926`에 네 팔이 모두 도달했다. 세 변화량의 합은 0.565977 MPa다. 이번 대조 직전의 0.536012 MPa를 분모로 하면 F8의 물질점 표본을 바꾼 몫은 10.42%, 같은 물질점과 시간 간격에서 격자를 바꾼 몫은 89.58%다. 고정 규칙의 기존 F16 최대 반력 0.634878 MPa를 분모로 하면 지정점 잔차는 75.63%다. 이 한 점의 조건부 분해는 격자·벽·접촉·전송 이력의 보편적인 기여율을 정하지 않는다.

## 2. 다른 변위와 자격 판정

F8 반걸음·F8 조밀 표본·F16이 모두 존재하는 구간은 원 주 비교점을 지나 `u=0.11640768835917337`까지다. 이 세 팔의 5,192개 변위를 모두 조사했다. 그 구간에서 F8 반걸음과 F16의 최대 반력 차이는 마지막 지점의 0.557232 MPa였다. 같은 지점에서 표본 변경 차이 0.064196 MPa와 같은 표본의 격자 차이 0.493036 MPa가 이를 구성했다. 각 성분에 대해 서로 다른 위치에서 구한 최댓값을 더하지 않는다.

기존 U6(c) ⑥ 판정용 F8↔F16은 89.15%, F12↔F24는 19.11%다. 두 쌍 모두 5% 초과, U6(c) 자격과 단계 3 보류. 이번 조밀 표본 팔은 원인을 좁히는 개발 대조로 기록한다.

## 4. 초기 상태에서 격자가 만드는 차이

39,053개 위치·ID·부피가 일치하는 원판을 그대로 놓고 두 격자의 원래 보간 함수로 질량을 보냈다. 시간은 전진하지 않았다. 같은 노드에 활성 물체장이 여럿 들어오면 고정 계산기의 접촉 후보가 된다. 이 셈에서 후보 쌍은 한 번씩만 센다. 실제 충격량은 접근 속도와 법선 등에 따라서 정해진다.

| 초기 배치 | F8 격자 | F16 격자 |
|---|---:|---:|
| 축 방향으로 이웃한 후보 쌍 | 84 | 84 |
| 대각 방향으로 이웃한 후보 쌍 | 72 | 0 |
| 세 물체 이상의 장이 함께 있는 격자 노드 | 72 | 0 |
| 후보 쌍에서 원판 표면 사이의 최대 초기 간격 (원판 지름 단위) | 0.4191 | 0.00345 |

첫 걸음의 윗판 제약 위치에 배정된 초기 질량도 F8에서 F16의 1.38배다. F16의 이 질량과 판 속도로 구한 첫 윗판 충격량은 원 관측값과 계산 단위로 2.12 × 10⁻²² 차이였다. 초기 노드에 올라간 질량이나 후보 쌍 수만으로 이후 반력 차이의 원인을 확정할 수 없다.

## 5. 입자 번호 순서 대조

고정 접촉 함수는 한 노드에 세 장 이상이 있을 때 숫자 ID 순서로 쌍을 정렬해 네 번 순회한다. U5(c) ⑤의 개발 진단으로 인공 노드의 물리 상태를 고정한 뒤, 세 물체에 번호를 붙이는 여섯 순서를 비교했다. 결과 속도를 원 물체 순서로 되돌린 뒤 같은 물체의 최대 속도 차이를 구했다. 두 물체 대조는 0, 대칭 삼각형은 0.346, 비대칭 삼각형은 0.413이었다 (계산 속도 단위). 고정 ID로 자료 행 순서만 뒤집은 대조는 모두 0이었다. 두 삼각형의 국소 순서 의존성이 49개 원판의 판 반력을 바꾸는지는 별도 관측이다. 임의 노드의 속도 차이에 판 반력의 5% 한계를 적용하지 않는다.

다음 개발 대조는 원 F8 팔의 초기 좌표·질량·물질점 행 순서·시간 간격·격자·마찰과 중단 조건을 고정하고 물질점이 지닌 원판 번호만 `i → 48 − i`로 일괄 변경한다. F8 원 궤적은 기존 벽 관측 반환을 재사용한다. 지정 변위 `0.11562281664031926`에서 원 F8 − 번호 반전 F8의 부호 있는 판 반력 차이를 본다. 미도달한 경우 해당 칸은 비워 두고 두 팔의 공통 변위에서 최대 절대차와 그 위치의 부호를 보고한다. 번호 반전 한 번은 여러 순열 가운데 한 개발 대조다. U6(c) 판정용 두 격자 쌍과 단계 3의 지위는 §2를 따른다.
