## 0. 왜 이 순서인가

직전 상태: 실침대 구 스탬프 8팔이 σ_e 비 **1.123191** (+12.3 %, 쌍대응 SE 0.098 %p).
그런데 리뷰가 두 가지를 지적했다 —

- **DR3-05**: 직경-보존 σ_VGCF 는 `100·πd²/(4·vox²)` 라 **vox 의 함수**다
  (0.15 → 78.5398 · 0.125 → 113.097 · 0.10 → 176.715).  σ_SDCP 는 250 고정이므로
  격자를 조이면 **탄소 백본 대비 SDCP 의 상대 전도도가 2.25배 같이 바뀐다**.
  ⇒ 격자 스윕이 재료계수 스윕과 섞인다 (CL-19 가 retired 된 것과 같은 구조).
- **DR3-06**: VGCF 는 1-셀 굵기 관이라 **기하도** 격자 불변이 아니다 (표현부피 7.2배 변동).

⇒ **4(격자 스윕)를 먼저 돌면 해석할 수 없다.**  2 가 σ 축을, 1 이 SDCP 부피 축을 먼저
닫아야 4 의 이동에서 그 몫을 뺄 수 있다.  3 은 그와 별개로 CL-31 격차의 원인 후보를
실침대에서 직접 가른다 (통제 RVE 에 VGCF 팔을 붙이는 것보다 싸고 안전 — DR3 리뷰 ② §8).

## 1. STEP 1 — 상별 부피 원장 (CPU, 솔브 없음)

`VOXES="0.125 0.1" sdcp_phase_ledger.sh` → `cells_by_sid` · SDCP 표현부피/참부피 · 실측 dof.

**이 단계는 가설검정이 아니라 계측이다.**  두 가지를 준다:
- 4 의 메모리 예산을 **추정이 아니라 실측 dof** 로 (DR3-08: 첫 병목은 VRAM 이 아니라 호스트 RAM).
- SDCP 표현부피비.  vox 0.15 에서 **0.986** 이었다.  0.125/0.10 에서도 0.98–1.00 이면
  h1(prereg v2)의 기전 변수는 이미 수렴한 것이고, **4 에서 R 이 움직인다면 그 원인은
  SDCP 부피가 아니다** (σ_VGCF 또는 VGCF 기하).

⚠ STEP 1 이 4 를 **불필요하게 만들 수는 없다** — 부피가 수렴해도 R 이 수렴했다는 뜻은
아니다.  다만 4 의 결과를 어느 축에 귀속할지를 미리 좁힌다.

## 2. STEP 2 — σ_VGCF 축만 이동 (GPU, arm 0 만) → **CL-39**

같은 침대·같은 격자(vox 0.15)·같은 origin(0,0,0)·같은 브리지(0.48)·같은 구 스탬프(Ø0.30).
**σ_VGCF 만** 78.5398 → 113.097 S/cm (×1.4400, = vox 0.125 의 직경-보존 값).

- **2a** 기준점을 σ_VGCF = 78.5398 로 **새 코드에서 다시 찍는다** = 이번 수정(게이트 예외형·
  매니페스트 필드·방어 기본값)이 수치에 무영향임을 확인하는 회귀.
  **등록 예측**: σ_e(SBE, arm 0) = **0.07302** S/cm.  어긋나면 수정이 수치를 건드린 것이므로
  **4 로 넘어가지 않는다.**
- **2b** σ_VGCF = 113.097 로 같은 두 팔.

**측정량** `ΔR = |R(113.097) − R(78.5398)|`, R = σ_e^DBE / σ_e^SBE (arm 0 쌍대응).
| | 예측 |
|---|---|
| **h0** — R 은 σ_VGCF 에 불변 (비가 재료계수를 소거한다) | ΔR = **0.000** |
| **h1** — R 은 σ_VGCF 를 따라 움직인다 | ΔR = **0.020** |
| 분해능 | 0.005 |

**사전 방향 예상 (등록)**: **R 은 내려간다.**  근거 — 망은 VGCF 지배이고(옛 원장 소산분담
92.5 %) σ_e^SBE ∝ σ_VGCF^~0.86 (CL-11 실측 지수 0.858)인데 σ_SDCP 는 250 고정이다.
백본이 좋아질수록 고정-σ SDCP 다리의 한계 기여가 줄어 비가 1 쪽으로 눌린다.
⚠ **크기는 등록하지 않는다** — 0.4 %~3.6 % 범위의 어림만 있고 그것은 예측이 아니다.

**쓰임**: `dR/dlnσ_VGCF ≈ ΔR / ln(1.44)` 를 4 의 vox 0.125 팔에서 **빼고** 읽는다.

## 3. STEP 3 — VGCF 를 전기적으로 죽인다 (GPU, arm 0 만) → **CL-40**

`--sigma-vgcf 0`.  VGCF 셀은 그대로 스탬프돼 **부피를 막고**(`_cond_ph` 가 phase 2 를 항상
포함) 도체만 아니게 된다.  나머지는 전부 동일.

**측정량** `G = R − 1` (arm 0 의 이득 초과분).  기준 `G(baseline) = 0.1263` (2a).
| | 예측 |
|---|---|
| **h0** — SDCP 이득은 VGCF 와 **무관**하다 (AM↔AM 등 다른 경로) | G = **0.126** |
| **h1** — SDCP 이득은 **VGCF 사이를 잇는 것**이다 | G = **0.030** |
| 분해능 | 0.02 |

**둘 다 기각되는 경우도 실재한다**: VGCF 가 죽으면 SDCP(σ 250)가 유일한 고전도 상이 되어
G 가 **0.126 을 크게 넘을** 수 있다.  그때는 `BOTH_REJECTED` 로 적고 "SDCP 의 역할이
백본 유무에 따라 질적으로 달라진다" 로 서술한다 — **h0 쪽으로 반올림하지 않는다.**

**왜 이것이 항목 ②(RVE 에 VGCF 팔 추가)보다 나은가**: RVE 에 VGCF 를 넣으면 선분 스탬프의
표현부피가 vox 에 7.2배 변동하는 **새 인공물**을 들여온다(DR3-06).  실침대에서 σ 만 0 으로
두면 기하는 완전히 그대로고 **새 코드가 0 줄**이다.

⚠ 부수 산출: σ_e(SBE, σ_VGCF=0) 은 AM 골격만의 바닥이다 (옛 base ≈ 5.7e-4 S/cm 대조).

## 4. STEP 4 — 격자 스윕 vox {0.125, 0.10} × 8팔 × 2침대 → **CL-41**

구 스탬프 Ø0.30 (게이트 `d/vox ≥ 2` 라 **0.25·0.2 는 원리적으로 불가** — 스윕은 고운 쪽뿐).
`LEAN=1` 로 불필요 솔브 4종 차단.  σ_VGCF 는 **직경-보존 규약 그대로** 둔다 (생산 규약을
바꾸지 않는다 — 대신 2 의 감도로 사후 보정).

**측정량** `ΔR_geo = |R(0.125) − R(0.15)| − |ΔR(STEP 2)|` (σ 몫을 뺀 순수 격자 이동).
| | 예측 |
|---|---|
| **h0** — 구 스탬프 비는 격자에 안정하다 | ΔR_geo = **0.000** |
| **h1** — σ 몫을 빼도 계속 움직인다 (VGCF 기하 등) | ΔR_geo = **0.030** |
| 분해능 | 0.010 |

**라벨 (런 전 확정)**: 이 스윕이 h0 로 나와도 **"격자 수렴 증명"이라 쓰지 않는다.**
두 점(0.15, 0.125)뿐이고 세 번째(0.10)는 메모리에 걸릴 수 있으며, VGCF 1-셀 관 기하는
어느 격자에서도 참값이 아니다.  쓸 수 있는 문장은 **"이 규약에서 vox 0.15↔0.125 사이
비의 이동이 0.010 미만"** 까지다.

⚠ **vox ≤ 0.125 팔의 σ_ion · τ_pore · BV 반응면 · STEP4 격자는 인용 금지** (DR3-07):
SE 점 스탬프의 점밀도가 λ 3.0 → 1.72 → 0.88 로 떨어져 미충전이 ~5 % → ~18 % → ~42 % 가 된다.
**σ_e 는 무해**하다 (전자 σ 표에서 SE 와 기공이 둘 다 0.0 이라 동등).

## 5. 판정 순서 (코드가 사전등록이다)

1. `sdcp_gain_verdict.py` 의 fail-closed 게이트를 **먼저** 통과해야 한다 —
   미수렴 팔 0 · 수렴 정보 존재 · 중복 origin 없음 · 고정 인자 일치 **및 기록 존재**
   (`vox` `bridge_um` `fibre_stamp` `sdcp_stamp`; 2026-08-18 신설).
2. STEP 2a 재현 실패 → **전체 중단**.  수정이 수치를 건드린 것이다.
3. 각 단계의 관측을 위 표의 h0/h1 예측과 대조.  |관측 − 예측| 이 분해능의 2배를 넘는 쪽을
   기각한다.  둘 다 기각되면 `BOTH_REJECTED` 로 적는다.
4. 어느 단계든 결과를 본 뒤 **문턱·분해능·측정량을 바꾸지 않는다.**
