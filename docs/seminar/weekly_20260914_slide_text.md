## ⛔ 슬라이드에 쓰면 안 되는 것

- **옛 SDCP σ_e 이득 백분율 일체** — 격자 미수렴으로 철회됐고 인용 금지다.
  ⚠ **여기 그 숫자를 다시 적지 않는다** (선례가 이 자리에 적었다가 `--ban-sweep` 에
  걸렸다).  정본 등록부 = `docs/reviews/claims.json` 의 `quotation_ban`.
  ⚠ **2026-08-06 자 "SDCP 도입 시 전자 전도도 증가" 슬라이드가 바로 이 트랙**이다 —
  그 슬라이드/그림을 이번 보고에 재사용하지 말 것.  살아남는 것은 **방향뿐**
  (SDCP = 도체 부피 추가 → σ_e 증가 방향, 주 원천은 새 도체 부피).  **크기는 인용 불가.**
- *"격자 수렴했다 / resolution validated"* — 미수렴이고 보고값은 그 축에서 하한이다.
- 협착저항 감사의 미완 판정을 **"확정"으로** — 전부 HOLD.  ✅ 대신 *"결함 규명 → 재측정
  궤도"* 로 쓴다.

## 예상 질문 대응

| 질문 | 답 |
|---|---|
| 왜 판정이 다 HOLD 인가 | 이번 주는 감사로 **결함을 규명**한 주다.  판정은 사전등록한 재측정으로만 낸다 — 성급한 숫자를 안 내는 것이 규율이다. |
| Phase A 결과는 언제 | 계산 진행형.  미수렴 구간은 값을 안 내므로 격자 수렴 확인 후 판정한다. |
| 지난 SDCP σ_e 슬라이드는 | 이득 **크기**는 격자 아티팩트로 철회.  **방향**(도체 부피 증가)만 유효하고 **수치 인용은 불가**하다. |
| 협착저항 "삭제"가 결과를 얼마나 바꾸나 | 재측정(S3)으로 정량화 중.  현재는 영향 **간선 비율**(이온 20.7 %·열 26.9 %)만 실측했고, σ 변화량은 사전등록 런에서 낸다. |
