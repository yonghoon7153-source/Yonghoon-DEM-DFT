- `Bo ≈ 0.5` 를 **Thinky 의 경계**로 — 드럼(충전율 9.8 %·Fr 0.083)에서 잰 값이고 `Bo` 정의도 문헌과 다르다.
- 코팅 효과를 **900배 한 벌**로 — 앵커 기준 128배와 나란히 (§22-4 두 벌 규칙).
- ps 스윕의 σ — 5런 중 완주 0, 압력 목표 0.30 에 미달.

## 예상 질문 대응

- *"Phase A 결과는 언제?"* — 영수증 3개 → 어댑터(`--code-sha-missing-ok` 이유 문자열 기록) → 판정.  문턱 근처면 `code_sha` 살려 재실행(1.5~2일), 멀면 한정어로 보고.
- *"코팅이 필요하다는 결론인가?"* — 유동성 축에서는 **아니오**(Thinky 면 불요).  코팅의 값이 있다면 믹싱 축이고 그게 지금 도는 런이다.
- *"PTFE 는 들어가 있나?"* — 조성·밀도만.  마찰·점착·변형·피브릴화는 미표현 — 이 모델에서 PTFE 는 수동 필러라고 적는다.
- *"LAMMPS 로 안 가나?"* — 간다, 보고 뒤.  JKR(문헌과 같은 `Bo` 정의) + 결합 사슬 + 병렬을 얻지만 피브릴화 자체는 그래도 못 만든다.
