## 봉인과 발사 결정

권고는 수정 핀 `9fd6aa9d3bee`에서 만든 143파일과 A5 러너를 고정해 **운영 봉인만 승인**하는 것이다. 키트 목록의 SHA256은 `26bdbdc05ba3f6c71a0b042ebd13adb64b38271c1889a894898a4ccf55322f1d`다. 점검에 성공한 것은 원위치에서 이 신원의 후보이다. 영수증의 `field_launch_authorized=false`를 유지한다. 두 차례 SSH 인증 실패는 1저자 보고에 따른 접속 전 사건이며, 사전 점검 중복 실행으로 세지 않는다.

고정 키트에 보존된 과거 제출 래퍼는 구 러너를 호출하고 동시 실행 검사를 완화한다. 다음 단일 잡용 외부 블록은 **A5 러너만 호출**하고 원래 동시 실행 검사를 유지해야 한다. 실제 복원에서 읽을 10-14 이력 원판정의 신원과 `HIST_VERDICT`, 기존 RJ 디렉터리·기준 파일·반환 및 조건부 선택 파일을 보존할 새 쓰기 위치를 먼저 대조한다. 그 뒤 새 RJ 1잡 발사 GO를 별도로 묻는다. 역사 잡 323957은 재실행하지 않는다. 새 RT1/RT2·연속성·복원 증서·탈압 결과는 아직 없다.
