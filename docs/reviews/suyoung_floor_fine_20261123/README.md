# 수영 2D · 아래판 후보 완주 판독과 12칸·24칸 진단

## 완주 반환

1저자가 WSL에서 F8·F16을 한 번씩 실행했다. 8칸은 2,719걸음(170.7초), 16칸은 6,589걸음(837.9초)에 처음 1.2 MPa에 도달했다. 제출한 완주 TAR와 화면의 SHA256이 일치했다. 두 팔의 앞 270/540걸음 CSV가 짧은 가압 반환과 바이트 단위로 같고, 이후 궤적·종료 영수증으로 원래 판독 결과를 재현했다. 종료 시점을 정렬하는 대신 양쪽이 도달한 **같은 판 변위**에서 압력을 비교한다.

| 관측 (개발 자료) | 값 |
|---|---|
| 후보 16칸 첫 양의 아래판 반력 | 569걸음, 판 이동량 입자 지름의 0.127598배, 0.00102177 MPa |
| 후보 양쪽이 모두 누른 표본 | 공통 5,439점 중 4,870점 |
| 후보 8칸과 16칸 최대 차이 | 판 이동량 1.219466 지름에서 1.202653 − 0.674937 = 0.527716 MPa. 해당 지점은 양쪽 원표본 |
| 후보의 고정 분모 대비 최대 차이 | 79.5114%. 고정 분모 0.6636991103 MPa의 5% = 0.03318496 MPa |
| 수정 전후 네 곡선을 똑같은 변위 구간에 제한 | 5,319점. 최대 차이 0.536658 → 0.445038 MPa (80.8586% → 67.0542%) |

짧은 계산에서 후보 16칸이 끝까지 0이었던 이유는 첫 반력보다 29걸음 일찍 끝났기 때문이다. 완주 시 두 격자가 아래판을 함께 누르는 동안에도 차이가 컸다. 2D 자격 U6(c)·단계 3·3D는 보류한다. 수치만으로 어느 곡선이 물리적 정답인지는 정해지지 않는다.

## 교수님 보고 그림

수정 전후를 같은 축에 그리고 각 곡선의 실제 끝을 유지한다. 5% 띠는 등록된 고정 분모에 대한 ±0.03318496 MPa로, 각 쌍의 공유 변위까지만 표시한다. 세로 점선은 두 팔이 공유한 구간의 최대 차이이며 수정 전후 패널의 끝 변위는 다르다. CSV 18,513행은 보간하지 않은 네 원곡선이다. 실제 PNG와 CSV는 인계 ZIP의 weekly_full/에 담는다. 그림 생성기와 판독기는 docs/reviews/suyoung_floor_fine_20261123/render_full_weekly.py 및 docs/reviews/suyoung_floor_fine_20261123/read_full_return.py다.

## 다음 팔을 돌리는 목적

같은 입자별 속도장, 아래판 표면, 마찰 커널과 물리 경계를 사용해 F12·F24에서 격자 차이가 어느 정도 남는지 본다. 8·16칸 완주를 반복하지 않는다. 12칸의 원래 물질점은 21,609개, 24칸은 87,857개다. 원 생성기에서 얻은 위치·번호·부피의 해시와 각 격자의 시간 간격을 실행 전에 확인한다.

WSL CPU 1개로 F12(최대 3,600초) 다음 F24(최대 14,400초)를 각 한 번 실행한다. 시간은 계산 예산이며 초과 시 종료를 위한 유예가 각 30초다. 종료는 1.2 MPa 첫 도달 또는 원래의 높이 한계이고, 두 사유를 구분한다. 걸린 시간·원 궤적·접촉 수지·중단 사유·해시를 반환한다. 판독은 두 팔의 공통 변위에서 원표본 합집합과 양쪽 양압 부분을 각각 계산하고 고정 분모와 실제 미세 격자 최대값을 모두 기록한다.

12·24칸 차이가 5%를 넘으면 두 해상도 쌍 모두에서 불일치가 남았음을 기록한다. 5% 안이면 이번 미세 격자 쌍의 해당 변위 범위에서만 기록한다. 8·16칸의 기존 초과는 두 경우 모두 남는다. 시간 초과·불완전 반환은 수치 판정을 보류한다.
