## §0 왜 하는가

우리 연구 둘 (`degradation-degeneracy` — PyBaMM 합성 truth 의 LLI/LAM 맞춤 축퇴 · `bms-balancing` — 규진팀 α·β 창 맞춤
`[a_PE, b_PE, a_NE, b_NE, γ_Si]` 가 데이터로 정해지는가) 은 참값을 아는 **합성** 곡선이나 참값을 **모르는** 실측 곡선만 다뤘다. REIL
자료는 그 사이 — **실측 곡선 + 설계 참값** — 이다. 같은 4 변수 구조 (질량 배율 `m_P · m_N` = 우리 a · 오프셋 `d_P · d_N` = 우리 b) 라
우리 식별성 측정 (근최적 집합) 을 그대로 얹을 수 있다.

## §3 모형 · 추정 · 근최적 집합 (고정)

| 항목 | 고정값 |
|---|---|
| forward model | 그들 `objective_fun` · `dVdQ_hc` (x = `m_P · m_N · d_P · d_N` · 건강 매개변수 `m_P · m_N · LII = (m_P·max_q − (d_P − d_N))/max_q`) — **우리 모형이 아니다**. 이 실험이 재는 것은 "우리 식별성 측정이 실측 + 참값에서 무엇을 말하는가" 이지 우리 forward model 의 정확도가 아니다 |
| E3 추정 | 그들 `run_optimization` 그대로 (단일 목적 = GA 20 회 seed 0–19 · pop 50 · 100 세대 / 2–3 목적 = NSGA2 pop 50 · 100 세대 · seed 1 / 4 목적 = NSGA3 das-dennis 8 분할 · 100 세대 · seed 1) · 상자 `xl = [0.6, 0.5, 0.005, 0.0]` · `xu = [1.1, 1.1, 0.5, 1]` |
| H1–H4 기본 추정 | 결정적 다중 시작 국소 최적화 — 시작점 = Sobol 수열 64 점 (`scipy.stats.qmc.Sobol` · scramble · seed 0) 을 상자에 펼친 것 · 방법 L-BFGS-B → Nelder–Mead 다듬기 · 최적 = 최소 목적값. 그들 GA/NSGA 결과는 대조로만 |
| 상자 | **두 개를 둘 다 보고한다:** 그들 상자 (E3 와 같음) · 넓힌 상자 `m_P, m_N ∈ [0.3, 1.5]` · `d_P, d_N ∈ [−0.5, 1.5]`. 참값 m_P 0.64 · m_N 0.56 이 그들 하한 (0.6 · 0.5) 에 가깝다 — 그들 상자에서 폭이 **상자에 잘리면** 그것은 자료가 정한 폭이 아니다 (활성 경계는 결과마다 표시) |
| 근최적 집합 | `S(ε) = {x : J(x) ≤ J* + ε}` · J = 목적값 (V–Q 는 RMSE [V] 로 환산해 적는다) · 매개변수별 극값 = **제약 최적화** (SLSQP · 다중 시작 16 · min/max h(x) s.t. J(x) ≤ J* + ε) — 무작위 표집 금지 (`bms-balancing/README.md` 측정 §2: 무작위 표집은 폭의 하한일 뿐이었다) |
| ε 규칙 (사전 고정) | (i) 잡음 기준: 완전지 곡선의 고주파 잔차 RMS `σ_v` — 맞추기 **전에** 셀마다 계산 (보간 전 원 측정점의 V(Q) 를 Savitzky–Golay 3차 · 창 21 점으로 평활하고 원 곡선과의 차의 RMS) → `ε_noise = 2 σ_v` (RMSE 단위) · (ii) 폭 **곡선**: ε ∈ {0.5, 1, 2, 5, 10} mV RMSE 상승 전부 보고. 판정 (§4) 은 (i) 로만, (ii) 는 "폭이 문턱의 함수" 임을 보이는 그림 (`bms-balancing/README.md` 측정 §4 교훈 — 문턱 8→12 mV 에서 LAM_NE 폭 7.25→17.38 %p) |
| 목적별 상대 문턱 (H3) | dV/dQ 목적 (f4) 에는 mV 단위 ε 가 맞지 않는다 → 모든 목적에 상대 문턱 `S_rel(δ) = {x : J(x) ≤ (1 + δ) J*}` · δ ∈ {0.01, 0.05, 0.1, 0.2} 곡선 보고 · H3 판정은 δ = 0.1 (사전 고정) · H2 의 주 판정은 V–Q 의 잡음 기준 ε (위) |
| H4 형상만 | 용량 열을 각 셀의 Q_max 로 나눠 SOC 로 바꾼 곡선에 같은 추정 · 근최적 집합. 예측 (사전 기록): 형상만이면 (m_P, m_N, LII) 가 공통 인수 하나만큼 정해지지 않는다 → 근최적 집합이 그 방향으로 상자 끝까지 열린다 |

## §4 판정 (사전 고정 — 결과를 보기 전에)

**참값 불확실성:** 설계 참값은 명목값이다 (원판 면적비 0.64 = (12/15)² · 0.56 ≈ (12/16)² · LII 는 리튬화 상태 시트와 곱). 장전량 · 타발 ·
리튬화 편차는 저장소에 없다. 그래서 허용 오차 두 단계를 **둘 다** 보고한다: **엄격 ±0.02** · **느슨 ±0.05** (절대 · 1.0 기준).

| 셀 · 매개변수마다 | 판정 |
|---|---|
| 참값 ∈ S(ε_noise) 且 폭 ≤ 2 × 허용 오차 | **식별 + 무편향** — 이 화학 · 자료에서 방법이 작동 |
| 참값 ∈ S(ε_noise) 且 폭 > 2 × 허용 오차 | **식별 불가 (축퇴)** — 우리 축퇴 논지의 실측 지지 |
| 참값 ∉ S(ε_noise) 且 폭 ≤ 2 × 허용 오차 | **편향** — 모형 오차 (C/20 곡선 ≠ OCP · 셀 편차 · 명목 참값 오차) · 축퇴 증거로 쓰지 않는다 |
| 참값 ∉ S(ε_noise) 且 폭 > 2 × 허용 오차 | 편향 + 축퇴 — 둘 다 적는다 |

- 집계: 11 셀 × 3 매개변수 × (엄격 · 느슨) × (그들 상자 · 넓힌 상자) × 목적 셋 (H3) 의 판정 수를 **전부** 표로. 고르지 않는다.
- H1 은 점 추정 오차를 같은 허용 오차로 적되, H2 판정보다 앞세우지 않는다 (점이 맞아도 집합이 넓으면 우연이다).
- H3: 목적 사이에서 판정 칸이 바뀐 셀 · 매개변수를 센다. H4: 예측 (한 방향 열림) 이 맞는지 — 맞지 않으면 그대로 적는다.
- **사후 변경 금지:** ε 규칙 · 허용 오차 · 상자 · 시작점 · 목적 조합은 결과를 본 뒤 바꾸지 않는다. 바꾸고 싶어지면 그 분석은
  "탐색 (사전 등록 밖)" 표시로 따로 적는다.
- 성공 · 실패의 뜻: 이 실험의 "성공" 은 표가 채워지는 것이다. 어느 칸이 많든 결론은 그 분포다 — "식별" 이 많으면 축퇴 논지의
  반례 (이 화학 · 이 자료에서), "축퇴" 가 많으면 지지, "편향" 이 많으면 이 자료로는 둘을 못 가른다.
