다시 만들기와 한계

python lottery/fetch_data.py       # 동행복권에서 받기 · 검증 (요청 2번)
python lottery/build_results.py    # 분석 · 약 6~8분
lottery/webapp/lotto.sh            # 이 화면

원본이 검증 규칙(회차 연속, 추첨 요일, 번호 범위, 1회 기준값, 판매액 × 확률 = 5등 당첨자 수 — 가격 구간 합계와 회차마다, 총 당첨자 = 1~5등 합, 등수별 총액 = 1인당 × 인원)을 하나라도 어기거나, 새로 받은 목록이 가진 기록보다 회차가 줄었거나 옛 회차 값이 바뀌었으면 받기가 멈추고 기존 파일을 건드리지 않는다.

한계 — 1등 기대 수령액은 최근 52회 평균과 인기도 모델로 낸 세전 추정이다. 과거 1등 조합 · 같은 간격 수열 · 4개 이상 연속 같은 극단적 모양은 실제 당첨번호에 거의 없어 데이터로 추정할 수 없으므로 생성기에서 규칙으로 뺀다. 1~87회는 게임 가격이 2,000원이었고 4등 비율이 어긋나 인기도 모델에서 뺐다.
