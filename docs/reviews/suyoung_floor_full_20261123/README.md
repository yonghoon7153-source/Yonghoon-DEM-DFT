## 다음 개발 가압

후보 물리, 입자 초기 위치·번호, 각 격자 시간 간격 및 가압 속도를 지난 짧은 가압과 같게 유지한다. 1저자 GO 한 번으로 WSL CPU 1개에서 F8·F16을 각 1회 실행한다. 이전 반환에 재시작용 입자 상태가 없어 양쪽을 처음부터 적분한다. 새 궤적의 처음 270/540걸음이 이전 반환 CSV와 바이트 단위로 일치해야 그 뒤 구간을 쓴다.

원래 가압 종료 조건은 아래판 압력 1.2 MPa의 첫 도달 또는 다음 걸음의 판 간격이 초기 간격의 75% 미만이다. 시간 초과, 물리 계산 중단, 영수증 불일치는 부분 반환으로 처리한다. 각 격자의 첫 양의 반력과 두 격자가 모두 누르는 표본을 따로 기록한다. 두 팔이 실제로 도달한 공통 변위에서만 비교한다. 5% 비교는 고정 분모 0.6636991103 MPa(절대 차이 약 0.033185 MPa)를 쓰며, 이번 공통 변위에서 16칸이 낸 최대 압력도 함께 남긴다.

F8–F16 완주 반환 뒤 같은 후보의 F12–F24를 따로 판단한다. 후보의 U6(c) 자격·단계 3·3D는 HOLD다. 이 묶음에서 1저자가 요청받는 계산은 F8·F16 두 팔뿐이다.
