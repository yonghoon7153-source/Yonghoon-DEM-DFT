## ① 재현이 판정문보다 나빴다 (`AREA5-06`)

Codex 는 *"변이를 새 HEAD 에도 커밋한 것으로 모사하면"* 통과한다고 했는데, **기준을 안
옮겨도** 둘 다 초록이었다.

```
대조군 (변이 없음)   rc=0 ✓18 ✗0
r_min→r1            rc=0 ✓18 ✗0   ← HEAD 를 안 옮겨도 통과
min(σ)→σ₁           rc=0 ✓18 ✗0   ← 마찬가지
```

이유: ⑦f 픽스처가 `r1=0.5 < r2=6` **한 순서뿐**이라 `r_min` 이 우연히 `r1` 과 같고,
**열 채널뿐**이라 `σ_rel` 이 전부 1.0.
