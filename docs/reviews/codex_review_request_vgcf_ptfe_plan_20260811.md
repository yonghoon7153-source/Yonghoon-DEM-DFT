## §A. 배경 (30초)

사용자가 Nature Energy 2026 (Zhang·Meng·Franco, 건식전극 아키텍처) 을 주며 물었다 —
*"우리 MPM 첨가제 부분에서 이 논문 참고해서 코드를 짜야 되는 것 아닌가?"*

논문은 **PTFE 가 VGCF 를 감아 끌어당겨 전자망을 만든다**는 것을 CGMD 로 보이고,
그 길이 스케일이 45–360 nm 다.  우리 MPM 복셀은 **~140 nm** 다.

계획서의 결론: **재료 파라미터 층위(P1·P2)는 하고, 형상 층위(P4·P5)는 하지 않는다.

## §B. ★ PDF 없이 **지금 검증 가능한** 것 (여기부터 보면 된다)

논문 PDF 는 리포에 없다 (세션 업로드본).  그래서 리뷰가 **내 산술과 논리를 재현**할 수 있도록
계산을 전부 옮겨 적는다.  아래는 전부 리포 안 값 + 초등 산술이라 **독립 재계산 가능**하다.

### B-1. 비표면적 정합 (계획서 §2 의 근거)
원기둥 섬유: `SSA = 측면적/(부피·ρ) = πdL / ((πd²/4)L·ρ) = 4/(d·ρ)`

```
d = 100 nm = 1e-7 m,  ρ = 2.0 g/cm³ = 2.0e6 g/m³   (ρ 는 우리 additives.DENS['VGCF'])
SSA = 4 / (1e-7 × 2.0e6) = 4/0.2 = 20.0 m²/g       ← 논문 stated 18.6 대비 +8 %
d = 150 nm (우리 현행 additives.VGCF_D)
SSA = 4 / (1.5e-7 × 2.0e6) = 13.3 m²/g             ← 논문 18.6 대비 −28 %
역산: 18.6 을 주는 d = 4/(18.6 × 2.0e6) = 1.075e-7 m ≈ 108 nm
```
**확인 요청 (Q-B1)**: 이 식과 결론이 맞는가?  특히 *"논문 실측 SSA 가 매끈한 원기둥
가정과 8 % 안에서 맞으므로 우리 `seed_fibres` 의 원통 표현이 건전하다"* 는 추론이
과한가?  (VGCF 는 실제로 표면 흑연층·결함이 있어 실측 SSA 가 기하값보다 **높아야**
자연스러운데 오히려 7 % 낮다 — 이게 문제인가, 측정 방법(BET vs 기하) 차이로 넘길 일인가?)

### B-2. 해상도 게이트 (계획서 §0 의 근거)
우리 규칙: `d_h/dx ≳ 3.5` (CLAUDE.md 2026-08-07, 실측 근거 = 좁은 침대 +23.8 % vs
넓은 침대 +4.0 % @ 128→288 정밀화).  production dx ≈ 0.14 µm.

```
VGCF ⌀ 100 nm  → 100/140 = 0.71 셀
PTFE RoG 45 nm →  45/140 = 0.32 셀
섬유간 250 nm  → 250/140 = 1.79 셀
섬유간 360 nm  → 360/140 = 2.57 셀
250 nm 을 3.5 셀로 풀려면 dx ≤ 250/3.5 = 71 nm  → n_grid 2 배
```
**확인 요청 (Q-B2)**: 이 게이트를 **σ_e 채널에 적용하는 것 자체**가 정당한가?
규칙은 **MPM 기계적 SE 응력**에서 세운 것이고, 나는 초안에서 그 **부호를 σ_e 로
그대로 옮기는 실수를 했다가 스스로 정정**했다 (계획서 §0 "⚠ 정정" 블록).
정정 근거 = `scripts/step3_sigma.py:rasterize()` 가 sub-voxel 첨가제를 **1-복셀로 스탬프**
하고 docstring 이 "Neck AREA is thereby quantized to ~vox² — a documented v1 limit" 라고
스스로 적는다 → 단면이 **넓어지므로** σ_e 는 **과대**평가 쪽.  응력과 **반대 방향**.
**이 정정이 맞는지 확인해달라.**  (틀렸다면 계획서 §0·§4-P3·§6 세 곳을 되돌려야 한다.)

## §D. 리뷰가 답해줬으면 하는 질문

**Q1 (가장 중요). P3 을 빼는 것이 맞는가?**
P3 = "PTFE 가 VGCF 를 끌어당긴다" 를 **형상이 아니라 섬유 중심의 배치 상관**으로만 넣는 것.
배치 통계는 µm 스케일이라 복셀로 표현되지만, **그 효과를 읽는 창구(σ_e)가 미해상**이다.
⇒ *측정할 수 없는 것을 모델에 넣는 것* 아닌가?  계획서는 "두 해상도에서 부호를 먼저
측정한 뒤에만 수치를 인용" 으로 방어하는데, 그 방어가 충분한가 아니면 **아예 빼는 게** 맞는가?

**Q2. VGCF 기본 등급을 바꿔야 하는가?**
현행 `VGCF_D, VGCF_L = 0.15, 10.0` (AR 67, 주석 = Showa Denko VGCF-H) 는 실재 제품이고
**우리 코퍼스 전체(n≈85–165 케이스)가 그 위에 서 있다**.  기본값을 논문의 AR>200 로 바꾸면
코퍼스 재-run 이 필요하다.  계획서 제안 = **프리셋 추가 + 기본값 유지**.
이것이 옳은가, 아니면 "우리 σ_e 폼이 잘못된 형상 위에서 fit 됐다" 는 더 큰 문제인가?
(참고: σ_e Stage 22.5 는 LOOCV 0.9531 로 닫혀 있고 CLAUDE.md 가 **폼 변경 금지**를 명시한다.)

**Q3. P2 앵커를 `f_perc` 검증에 쓰는 것이 정당한가?**
차이가 세 겹이다 — (i) 액체계 CBD(카본+바인더) vs 우리 SE-포함 전극, (ii) PFIB 실측
세그멘테이션 vs 우리 시드 구조, (iii) 2D 슬라이스 분율 vs 우리 3D 연결성.
계획서는 "배수 1.40 의 **크기 감각**만" 으로 제한하는데, 그것조차 과한가?

**Q4. PTFE 측 §F1 앵커를 이 논문이 메우는가?**
내 판단은 **아니다** — 논문 CGMD 의 PTFE 는 **섬유화 *이전*** (~1 µm 입자, SI Fig S3)이고
우리 `PTFE_D, PTFE_L = 0.25, 40.0` 은 **섬유화 *이후*** 다.  단계가 다르다.
동의하는가?  (동의한다면 §F1 의 PTFE 항목은 계속 열어둔다.)

**Q5 (보너스). 내가 놓친 것이 있는가?**
특히 — 이 논문의 **"카본 SSA 를 줄여 카본↔전해질 전자전달을 억제"** 설계원리를 우리
**#30 `carbon_se_area_um2`(카본↔SE 촉매 분해)** 와 같은 모양으로 읽는 것(계획서 §5-P6)이
정당한 유비인가, 아니면 반응 상대가 달라(액체 전해질 vs 고체 SE) 성립하지 않는가?
