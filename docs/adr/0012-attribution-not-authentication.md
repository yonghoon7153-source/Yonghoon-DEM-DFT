# ADR 0012 — 이름은 기록이지 신원 확인이 아니다

- 상태: 채택 (2026-08-21)
- 관련: `apps/api/app/actor.py`, `apps/api/app/db.py`,
  `apps/web/src/lib/who.ts`, ADR 0011

## 맥락

서버를 하나로 모으고 나니(ADR 0011) 곧바로 다음 질문이 생겼다 — **이거 누가
올렸지, 이 질량 누가 바꿨지.** 셀 하나의 질량은 그 셀의 모든 mAh/g 를 정하므로,
"이 값 맞아?" 의 첫 단서는 언제나 "누가 마지막으로 건드렸나" 다.

여기서 로그인을 붙이고 싶어진다. 붙이면 안 된다.

이 랩에서 실제로 하는 질문은 **"누가 바꿨어"** 이지 **"네가 너임을 증명해라"**
가 아니다. 둘은 다른 문제이고, 뒤쪽을 푸는 장치는 앞쪽에 대해 아무 것도 더
해 주지 않으면서 비용만 낸다 — 아무도 필요로 하지 않는 비밀번호는 공유되는
비밀번호, 포스트잇에 적힌 비밀번호, 셀이 도는 새벽 두 시에 잠기는 비밀번호가
된다.

## 결정

**이름 하나. 검증하지 않는다.**

- 브라우저가 처음 열릴 때 한 번 묻고 `localStorage` 에 둔다. 기계마다 한 번씩
  묻는 것이 맞다 — 실험실 공용 PC 와 자기 노트북은 다른 사람이 쓴다.
- 모든 요청에 `X-Workbench-User` 헤더로 실려 간다. **퍼센트 인코딩해서** —
  HTTP 헤더 값은 ASCII 범위의 바이트만 담을 수 있어서, 한글 이름을 그대로
  넣으면 요청이 브라우저를 떠나기도 전에 거절된다. 이 랩의 이름은 대부분
  한글이므로 이게 빠지면 기능 자체가 없는 것과 같고, 증상은 "저장이 안 돼요"
  로만 보인다.
- **이름이 없어도 전부 동작한다.** 기록이 "이름 없음" 으로 남을 뿐이다. 20 MB
  짜리 파일을 올리려는 사람을 이름 안 적었다고 막는 것은 도움이 아니다.

### 기록은 자동으로 남는다

`created_by` / `updated_by` 를 쓰는 것도, 활동 기록 한 줄을 남기는 것도
**라우터가 아니라 SQLAlchemy flush 리스너**가 한다 (`db.py`). 새 엔드포인트는
생기는 순간부터 기록되고, 아무도 "여기서도 기록해야 한다" 를 기억할 필요가
없다. 기억에 맡기면 언젠가 한 종류의 편집만 기록에서 빠지는데, **그 구멍은
보이지 않는다** — 목록은 멀쩡해 보이고 그 한 줄만 없다. 변경 알림을 미들웨어에
둔 것과 같은 이유다 (ADR 0011).

리스너는 두 단계로 나뉜다. 무엇이 바뀌었는지는 flush **전**에만 읽을 수 있고,
새 행의 id 는 flush **후**에만 존재한다. 한 곳에서 다 하려다 모든 "추가" 기록의
id 가 비었고, 셀별 기록 조회가 그것을 조용히 찾지 못했다.

### 무엇을 기록하지 않는가

- **사이클 행.** 사람이 한 편집이 아니고, 업로드 한 번에 만 개가 생긴다.
  사건은 업로드 쪽이다.
- **파서가 채운 필드.** 장비 모델·펌웨어·타임스탬프·디코딩한 스케줄. 이것까지
  세면 업로드 한 번이 두 사건으로 읽히고, 두 번째 줄은 아무도 건드리지 않은
  필드 아홉 개를 나열한다. Run 에서 사람이 바꾸는 것은 `sample_id`,
  `cycle_offset`, `cycle_offset_source` 뿐이다.
- **같은 값을 다시 저장한 것.** SQLAlchemy 에게 무엇이 실제로 움직였는지
  물어본다. 세면 목록이 "아무 일 없음" 으로 가득 차고 진짜 편집이 묻힌다.

## 결과

- 셀 화면에 "마지막 수정 · 누가 · 언제", 파일 카드에 "올림 · 누가 · 언제",
  프리셋 목록에 저장한 사람, 대시보드에 최근 활동 12줄.
- 지워진 것도 기록에 남는다. 그때 이름을 함께 저장하기 때문이다 — 조인해서
  가져오면 지워진 순간 읽을 수 없게 되는데, 찾는 것이 정확히 그때다.
- **누구든 아무 이름이나 댈 수 있다.** 사설망의 실험실 장비로서는 맞는 거래다.
  이것이 바뀌는 순간은 이 앱이 랩 네트워크 밖으로 나갈 때이고, 그때 필요한 것은
  여기 비밀번호 컬럼이 아니라 앞단의 진짜 인증이다.

## 대안

**비밀번호 로그인**: "누가 바꿨어" 에 대해 더 나은 답을 주지 않으면서, 계정
관리·재설정·잠김을 통째로 들여온다. 세 사람이 쓰는 실험실 도구에 붙일 물건이
아니다.

**OS 사용자 이름 자동 감지**: 물어보지 않아도 된다는 장점이 있다. 브라우저는
그것을 알려 주지 않고(당연히), 알려 준다 해도 공용 PC 에서는 `lab-pc` 하나로
전부 뭉뚱그려진다.
