이번 반복으로 고정 초기 배열·소스·CPU 조건의 수치 재현성을 확인했다. 다른 시드나 초기 배치의 민감도, 시료 간 산포 및 연속체 해에 대한 오차는 미측정이다. 결과의 지위는 `WITHIN_DEVELOPMENT_BAND`, 반환의 `selected_setting=null`, `u6_qualified=false`다.

메모 §3-2·§4의 선택 규칙은 F의 Φ_m만으로 처음 기준을 만족하는 설정을 고른다. **권고는 설정 ①(틈 보정·거리 판정 모두 끔)을 후속 U6(b)·(c)의 개발 대조에 고정하는 것**이다. U6(b)는 같은 출발에서 양쪽 팔이 모두 도달한 같은 Φ_m의 응력을 8·12·16·24셀에서 대조하고, U6(c)는 사전에 정한 표본과 허용폭으로 다물체 접촉 위반과 ID·장 순서의 영향을 확인한다. 이번 동일 조건 반복이나 별도의 네 원판 형상 관측으로 이 두 자격을 충족한 것으로 세지 않는다. 근거 문서는 `docs/reviews/dem_redesign_direction_20261109/memo_v3_2.md`와 `docs/reviews/suyoung_u6_repeat_20261120/README.md`다.
