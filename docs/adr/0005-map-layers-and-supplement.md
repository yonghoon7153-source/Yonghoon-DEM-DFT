# ADR 0005 — Canva 지도의 디테일은 레이어로, 빈 県은 「보충」으로, 사진은 검색으로

- 상태: 채택 (2026-09-27)
- 관련: `data/places.json` · `data/mountains.json` · `data/supplement.json`, `src/map/layers.ts`, ADR 0002 · 0003,
  체크리스트 #28 · #31–#34

## 맥락

전수조사(PDF 글줄 837 · 그림 161 · 링크 19)를 해 보니 마인드맵 칸의 글자는 전부 옮겨져 있었지만,
사용자가 **지도 위에** 적은 것이 사이트에서 사라져 있었다 —
- 県 이름 위의 읽기(ふりがな),
- 빨간 점과 「松江市(まつえし)」 같은 도시 이름,
- 다리 색깔 선,
- 섬 이름(北海道本島…), 23区 읽기, 隠岐諸島 메모,
- 산맥 학습지와 그 위의 메모(うみかぜ(雪↑), 香川県 水不足).

사진 84장은 규칙 6 으로 넣지 않았고, 메모가 없는 県 13곳은 빈칸이었다.

## 결정

1. **県 라벨 기본값은 ふりがな** — 漢字 위에 작은 かな (Canva 지도처럼). 漢字 · かな · 한글 모드는 그대로.
   저장 키를 `labelMode.v2` 로 바꿔 모두 새 기본값에서 시작한다.
   (9차 요청부터는 아무것도 저장하지 않는다 — 새로고침하면 ふりがな · 기본 레이어 · 図鑑 0 · 스티커 없음으로 시작.)
2. **지도 레이어 세 개**를 버튼으로 켜고 끈다 (비준: 레이어 버튼).
   - 도시: ◎ 県庁所在地 47 + ● 내가 적은 도시.
   - 다리: 本州↔四国 3노선.
   - 산맥: 학습지 번호 그대로 22개.
   데이터는 `places.json` · `mountains.json` (좌표는 [경도, 위도], 沖縄는 인셋 이동값을 더한다).
   - 선은 지도 공간에 그려서 확대와 같이 움직인다.
   - 점·번호·이름은 화면 공간에 그리고 県 이름과 겹치지 않게 놓는다.
   - 도시 이름은 확대(k ≥ 2.1)했을 때만, 23区는 k ≥ 9, 섬 이름은 전국 화면에서만.
3. **산맥 모드**는 초록 선 + 번호 (비준).
   - 켜면 패널에 번호표가 열리고 県 색이 옅어진다.
   - 「이름 가리기」로 외우기 연습을 한다.
   - 번호를 누르면 그 산맥으로 간다.
   - `#sanmyaku` 로 바로 연다.
   - 선은 능선을 따라 **대략** 그린 것이라고 화면에 적는다.
4. **보충 메모는 `supplement.json` 에 따로** (비준: 「✦ 보충」).
   - `notes.json` 은 사용자의 목소리라 섞지 않는다 (규칙 2).
   - 메모가 없는 県에만, 점선 칸과 「Claude 가 채운 메모 · 내 마인드맵 아님」으로 보인다.
   - 사용자가 그 県에 메모를 쓰면 저절로 숨는다.
5. **사진은 `photo` 표시 + 📷 이미지 검색** (비준).
   - 사진 자체는 권리를 모르므로 넣지 않는다 (규칙 6).
   - 사진이 붙어 있던 칸을 PDF 위치로 찾아 `photo: true` 또는 검색어를 적는다.
6. PDF 에 **그림으로만 남은 링크 카드**(관광 가이드, YouTube 2개)는 주소를 찾아 `url` 로 되살린다.
7. **방위**: 캔바 지도처럼 北(きた) 위 · 南(みなみ) 아래 · 西(にし) 左(ひだり) 왼쪽 · 東(ひがし) 右(みぎ) 오른쪽.
   지도는 늘 북쪽이 위라서 화면 가장자리에 고정한다 (`places.json` 의 `compass`, 라벨 모드를 따른다).
8. **인셋**에는 沖縄 본섬 무리만 — 大東諸島는 함께 옮기면 鹿児島 끝에 그려져서 宮古 · 八重山처럼 뺀다.
9. **東京23区 팝업** (9차 요청): 캔바의 도쿄 페이지처럼 23구 지도에서 구를 누르면 그 구의 칸이 뜬다.
   칸은 notes.json 의 구 박스를 이름으로 찾아 쓰고(두 번 적지 않음), 패널의 도쿄 트리는 구마다 「+N칸」으로 접는다.
   구 경계는 地球地図日本(dataofjapan/land)의 23구만 잘라 `data/raw/tokyo23.geojson` → `nihon geo`.

## 결과

- Canva 지도의 정보 대부분이 사이트 지도에 다시 보인다.
  - 전국 화면: 점과 섬 이름.
  - 확대하면: 도시 이름.
- 원본의 오타 읽기(はなばた 등)는 사용자에게 물어서만 고친다.
  - 七夕 는 비준을 받아 たなばた 로 고쳤다.
  - 表参道 おもてさんど 는 아직 물어보는 중이다.
- 레이어 데이터는 좌표를 사람이 고칠 수 있는 JSON 이고, `nihon check` 가 좌표 범위·중복·県 이름을 검사한다.
