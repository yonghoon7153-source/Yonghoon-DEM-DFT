## 2. 음성 (TTS)

- **공개판 = Typecast** (스킬의 목소리 · 방식 · 빠르기 한 값).  API 키는 리포 · 채팅에 두지 않는다 — 클라우드 환경의 네트워크 비밀로만 (1저자가 넣는다).  예산 = 대본 글자 × 3 (기본 · 1저자 승인으로만 늘림) · 원장 = 편마다 하나 (자동 · 수동 · 실패 호출 모두 누계 · 재시작 · 끝말 바꿈에도 이어 씀).
- **내부판 = 로컬 TTS 만** — 내부 대본 · 숫자는 어떤 바깥 서비스 (TTS · 받아쓰기) 에도 보내지 않는다.  목소리 복제 없음.
  - XTTS-v2 (Coqui · **CPML = 비상업** → 내부판 전용) · 한국어가 외국인 억양으로 들린다 (1저자 11-25) — 내부 · 본인 보기용으로만.  문장이 잘리는 일이 있어 (음절/s > 7 · 봉우리 비 낮음) 자동으로 다시 만든다 · 시드 = 문장 글에서.
  - **MeloTTS-Korean (MIT) = 내부판 기본** (1저자 11-25 청취 — 빠르기 1.2 · 문장 통째 합성 · 화자 하나) · 도구 `docs/avi/tools/avi_melo.py` · torch 는 XTTS 가상환경 것을 빌려 쓴다 (설치 기록 = 스킬 S6).  XTTS-v2 = 예비.
  - 모델 · 가상환경은 리포 밖 (`<작업 폴더>`) · 모델 파일 sha256 기록 · 실행은 오프라인.  도구가 찾는 자리 = 환경 변수 (`AVI_XTTS_MODEL_DIR` · `HF_HOME` · `NLTK_DATA` · `AVI_MELO_SRC`) · 없으면 tools 폴더 기준 상대 경로.
- 클라우드 환경에서 처음 설치할 때 필요한 바깥 호스트 (11-25 기준 · 허용 = 1저자 승인): 모델 = huggingface.co 와 그 CDN · CPU torch = download.pytorch.org · MeloTTS 소스 = github.com (git 받기).
