# 대칭셀 이온전도도 — 조성 권고와 모델 예측 (2026-10-13 · 실험 전 기록 · 1저자 비준 대기)

1저자 10-13: *"이온전도도 관련해서 경향성이 맞는지 봐야돼서 대칭셀 같은걸 만들어야될거 같은데 어떤 조성으로"*.
목적 = 모델의 σ_ion **조성 경향** (큰 : 작은 NCM 비율) 을 실험으로 확인한다.  이 문서는 실험 결과가 나오기 **전에** 모델 값과 읽는 법을 적어 둔다 (결과 0 건).

## 1. 1차 조성 — 모델 침대와 1:1 (권고)

랩 사양표 (09-14) 다섯 조성 = 모델 ps45 침대 (`dem_scripts/ps_sweep_6mah_20260914/README.md` · 실험 공극을 잰 그 조성).

| 항목 | 값 |
|---|---|
| NCM : LPSCl | **81.6 : 18.4 wt%** · 탄소 · 바인더 없음 (모델 침대에 없다) |
| 큰 NCM (PC) : 작은 NCM (SC) 질량비 | **0:10 · 3:7 · 5:5 · 7:3 · 10:0** |
| 입경 (모델) | PC 9 µm · SC 4 µm · LPSCl 1 µm (실험 분말의 D50 이 다르면 알려 주시면 그 크기로 침대를 다시 만든다) |
| 성형 · 면용량 | 300 MPa · 6 mAh/cm² (모델 두께 ≈ 111 µm) |
| 반복 | 조성마다 펠릿 3 개 (Bazzoun 2026 도 조성마다 3 개) |
| 기준 시료 | **순수 LPSCl 펠릿** (같은 성형 · 측정 조건) — σ₀ 를 재서 f = σ_eff/σ₀ 와 절대값 대조에 쓴다 |

- 시간이 없으면 **0:10 · 5:5 · 7:3** 세 조성 + 순수 LPSCl.  모델이 예측하는 단조 상승 (1 → 1.39 → 1.52 배) 을 가장 적은 시료로 시험한다.
- 둘째 축 (SE 함량) 은 첫 결과를 본 뒤 정한다 (§5).

## 3. 읽는 법 (결과 전에 적어 둔다)

| 결과 | 뜻 |
|---|---|
| 0:10 < 5:5 < 7:3 이고 7:3/0:10 비가 펠릿 산포 (3 개 SD) 보다 크다 | 모델의 **경향**을 지지 |
| 순서가 뒤집히거나 비가 산포 안이다 | 모델의 경향과 어긋남 — 기전 (표면 덮임) 이나 접촉 모형을 다시 본다 |
| 경향은 맞고 크기가 작다 | 크기 과대 — 랩의 이전 결과가 이쪽을 시사한다 (아래) |
| 7:3 ↔ 10:0 차 | **판정하지 않는다** — 모델의 차 (6.6 %) 가 시드 산포 안이다 |

- 랩 이전 실험 (Kang & Shin 2025 · 정본 카드 `kang2025_toughened_bimodal_nca_lzo`): 단봉 3 µm → 바이모달 3+10 µm NCA, NCA:LPSCl:Super P 72:27:1 · 400 MPa 에서 R_ion 67.4 → 59.8 Ω·cm².  같은 질량 기준 이온 저항 비 = 실험 0.887 ↔ 모델 0.623 (0:10 → 7:3).  SE 함량 · 입경 · 탄소 · NCM↔NCA 가 달라 직접 대조는 아니다.  이번 실험은 모델과 같은 조성이라 그 차이를 가를 수 있다.

## 4. 측정 조건 권고

- 셀: 랩이 Kang 2025 에서 쓴 **대칭셀 EIS + TLM** 그대로 (R_ion · R_ele 를 같이 맞춘다).  탄소가 없어도 NCM 이 전자를 나르므로 (모델 σ_e 0.4 > σ_ion 0.06–0.09 mS/cm) 이온만 따로 보려면 전자 차단 구성 (양쪽 LPSCl 층 + In/Li–In · Ketter 2025) 이 더 직접적이다.
- 기록: 성형압 · **측정 중 스택 압력** · 온도 (25 °C) · 시료 질량 · 가압 중 두께와 놓은 뒤 두께 → 공극률.
- 모델 상태 = 300 MPa 압축 뒤 판 고정 이완 (놓기 전) 이다.  셀이 허락하면 가압 상태에서도 한 번 재면 모델과 같은 상태가 된다 (압력 단계마다 두께 · 임피던스를 잰 방법 = Miß 2026 · 정본 카드 `miss2026_insitu_conductivity_porosity_pressure_compaction` · 단일상 분말).
- 절대 f 대조에는 모델 쪽 순수 SE 망 기준 (τ 명명 규약 결정 ④ · 보류) 이 필요하다.  조성 사이 **비**는 정규화와 무관하다.

## 5. 둘째 축 (선택) — SE 함량

- 같은 입경에서 SE 함량을 바꾼 P:S 시리즈는 모델 값이 아직 없다 → ibb 에서 침대를 새로 만든다.
- 생성기 = `scripts/make_ps_sweep_decks.py --am-mass …`.  ⚠ SE 25–27 wt% 면 입자 20 만 개가 넘어 `maxattempt` 를 7,600 이하로 내려야 한다 (int32 넘침 · 원장 PS-01) → 부분 삽입 위험이라 **삽입만 먼저 시험**한다.
- 참고 (옛 세대 · 다른 입경): AM:SE 90:10 P:S 시리즈는 σ_ion 이 6:4 에서 정점 뒤 10:0 에서 7.7 배 떨어졌다 (`docs/a9_50_ps_sweep_vs_bimodal266.md`) — SE 가 적으면 P:S 효과의 모양이 달라질 수 있다.  인용용이 아니라 설계 참고.
