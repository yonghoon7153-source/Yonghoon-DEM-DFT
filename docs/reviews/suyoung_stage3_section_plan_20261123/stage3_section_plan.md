# 수영 단계 3 초안 · 압축 중 전해질이 어느 공극을 채우는가

2026-11-23 · 2D 벤치마크와 후속 논문 그림의 설계 · 단계 3 실행 보류

11-13 세미나에서 교수님이 지적한 둥근 단면은 단단한 구로 계산한 DEM 결과를 잘라 본 그림이다. 다음 그림은 같은 SE 입자를 느슨한 충전부터 따라간다. 중심의 이동만으로 설명되는 빈틈 감소와, 입자 자체의 영구 변형이 공극을 메운 부분을 독자가 구별할 수 있어야 한다. 오늘 받은 교차 판독은 아래판 반력의 격자 의존성을 진단했다. 단계 3의 계산 조건과 그림 배치를 먼저 정리한다.

## 1. 어느 계산이 어느 그림을 뒷받침하는가

| 순서 | 고정할 조건 | 낼 그림과 판독 | 넘어갈 조건 |
|---|---|---|---|
| 2D 시작 전 | 설정 ①에서 같은 커널, 같은 입력, 원 변위 표본과 하단 반력. U0·U1·U2·U5·U6·U7·U8의 2D 증거와 미확인 칸을 함께 둔다. | 첫 5% 초과 앞뒤의 격자 교차표, 완주 곡선과 누락 해상도. | 현 커널 F8–F16은 80.8586%로 기준 초과. F12–F24 미측정. 고친 후보에서 ⑥ 두 쌍과 U6(c)의 나머지 등록 조건을 확인하고 단계별 GO를 받는다. |
| 단계 3a | 독립 초기 충전 3개. 한 충전의 기하·재료·판 속도·판독 정의를 공유하는 S, F(µ=0.5), F(µ=0). | 같은 질량 기준 충전율 Φ_m=0.84·0.90·0.95에서 아래판 응력, SE 형상, 공극 면적을 나란히 표시한다. 판정비는 S/F(µ=0.5). | 필수 점 도달 여부와 격자 오차를 함께 판독한다. F(µ=0)의 문헌 띠에는 메모의 Φ_d를 적용한다. |
| 단계 3b | 느슨한 충전에서 무른 재료만 있는 경우(κ=1)와 무른 상 면적 분율 κ=0.2인 강체 혼합을 구분한다. 각 조건의 독립 충전 3개를 결과 전에 고정한다. | κ=1에서는 중심 이동·회전·이웃 교체와 공극 면적을 같이 본다. κ=0.2에서는 움직이는 강체를 둔 A와 F를 비교하고 P/E=0.4의 충전율 차를 읽는다. | 필수 상자 비교 실패, 미도달, 질량·침투 위반은 원 메모의 기술 실패·미정 규칙대로 표시한다. 3c의 배위수는 보조 보고다. |
| 후속 논문용 단면 | 2D 판정 뒤 단계 4의 3D 순수 SE, 이어서 복합체와 해당 상태의 탈압 자격을 확인한다. | 실제로 계산한 3D 체적을 사전에 지정한 평면으로 잘라 SE·AM·공극 경계를 그린다. 측정 상태가 맞는 실험 단면을 나란히 둔다. | 형상·재료·측정 상태를 확인하고 1저자가 논문 그림 채택을 결정한다. 2D 중간 산출물에는 ‘2D 개발 단면’으로 표기한다. |

정본 메모 §4 단계 0·2·3과 부록 D의 판정·격자 규칙을 사용한다. 단계 3의 조밀 충전에서는 Q13 치우침 신호에 따른 12·16·24·36셀 사다리와 판정 세 단 16·24·36을 기록한다. U6(c) ⑥의 8–16·12–24셀 비교는 별도 접촉 시험이다. 해상도 사다리나 같은 조건의 결정적 반복을 독립 충전 수에 더하지 않는다.

## 2. 단면 한 장을 어떻게 읽을 것인가

| 패널 | 실물 또는 계산에서 사용할 자료 | 함께 보여 줄 수치 |
|---|---|---|
| A · 초기 | 고정 시야의 초기 SE 입자 ID, 중심 및 물질점 위치. 같은 입자는 모든 패널에서 같은 색. | 초기 고체량·측정 영역·길이 눈금. |
| B · 가압 | 같은 충전의 가압 프레임에서 실제 물질점과 운반된 재료영역으로 경계를 복원. 초기 공극 한 곳을 결과 전에 표시해 같은 위치를 확대. | 같은 Φ_m에서 S와 F의 아래판 응력, 공극 면적, 서로 다른 ID 사이 겹침 면적. 공극은 합집합 면적으로 계산한다. |
| C · 재배열과 변형 | 입자 중심·회전만 옮긴 참조 윤곽과 실제 윤곽을 함께 표시. 관측용 전체 변형 지도와 현재 위치를 보존. | ID별 면적·주축비 변화, 비아핀 변위와 이웃 교체. 격자 폭·재구성 방법에 따른 차이는 별도 표기. |
| D · 하중 상태와 잔류 형상 | 같은 입자 이력에서 정지 이완, 판 상승, 분리 후 저장된 프레임. 전체 탈압 자격과 상태가 맞는 실험이 준비될 때 논문용 잔류 단면을 작성. | 프레임 번호·판 위치·반력·분리 시각 및 잔류 공극. 가압 상태의 실험과 탈압 뒤 실험을 별도 행으로 둔다. |

세 충전의 개별값을 보이고 오차막대가 충전 간 산포인지 격자오차 구간인지 범례에 쓴다. 모든 패널은 같은 시야·길이 눈금·상 색·공극 정의를 쓴다. 단계 3의 2D 면적 기공과 3D 체적 기공은 차원을 표시한다. 실험 비교에 필요한 것은 시료 ID·조성·입경, 압력 이력과 측정 시점, 배율과 픽셀 눈금, 관측 위치와 분할 규칙을 아는 SEM 원단면이다. 실험 이미지와 측정법은 이번 묶음에서 미수령이다. 해당 칸은 실험 대기 상태로 둔다.

## 3. 1저자 결정 위치

오늘 교차 반환으로는 단계 3 계산을 열 수 없다. 다음 개발 판단은 같은 저장 스냅샷에서 응력을 전달하는 아래판 인접 층과 대상 마스크의 지지를 비교해, 위치·부피와 응력장의 어느 항을 한 번에 분리할 수 있을지 결정하는 것이다. 반력 자격의 분모·5% 선과 필수 해상도 쌍은 그대로 쓴다. 실제 다음 계산, 3D 단면 작성 및 논문 배포는 각 단계에서 1저자 GO를 받는다.
