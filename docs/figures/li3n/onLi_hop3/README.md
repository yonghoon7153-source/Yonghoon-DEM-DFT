# on-Li → (Li 넘고) → (N 넘고) → on-Li — 격자 등가 hop 6.32 Å (그림 전용)

```
python3 tools/neb_diffusion/li3n_hop_frames.py --onLi --steps 3 --ride 2.15 \
  --min <min.vesta> --ts <ts.vesta> --ghost_r 0.62 --end_r 1.30 \
  --key_xi 0,0.3333,0.6667,1.0 --xi 0,0.1667,0.3333,0.5,0.6667,0.8333,1.0 \
  --outdir docs/figures/li3n/onLi_hop3 --merge      # 필요시 --no_bonds
```

| ξ | 지나는 곳 | 높이 (시작 대비) |
|---|---|---|
| 0.00 | ★ **on-Li** (계산된 최소점 xy) | +0.00 Å |
| 0.33 | ★ **Li 바로 위** | +0.77 Å |
| 0.67 | ★ **N 바로 위** | +1.00 Å |
| 1.00 | ★ **on-Li** (격자 등가) | +1.62 Å |

경로상 최근접 기판 원자 거리는 전 구간 2.150 Å (관통 없음).

## ⚠ 끝점이 +1.62 Å 떠 있다 — 고정 기판의 한계

기판은 **시작 자리에서 이완된 한 장**이다. 그 자리에선 in-plane Li 가 adatom 에 눌려
0.95 Å 내려가 있어 adatom 이 낮게 앉는다. 반면 도착 자리의 Li 는 눌리지 않은 채
**위로 0.65 Å 부풀어 있어**, 같은 접촉거리(2.15 Å)를 지키려면 adatom 이 그만큼 떠야 한다.

- 선형 추세를 빼서 높이를 맞춰봤더니 반대쪽이 기판을 파고들었다 (최근접 0.54 Å). 폐기.
- `--ride` 값을 바꿔도 상승량은 1.62 Å 로 동일하다 (양 끝 제약이 같이 움직이므로).
- 짧은 hop 일수록 덜하다: **steps=1 (2.11 Å) +0.77 Å · steps=2 (4.21 Å) +1.00 Å · steps=3 +1.62 Å**

즉 한 장의 기판으로 두 자리를 동시에 표현할 수 없다. 남은 선택은 (a) 그대로 두고 상승을
감수하거나, (b) 도착 자리의 Li 를 표시용으로 눌러 내리거나(기판 좌표 편집 — 별도 승인 필요),
(c) 그 자리를 실제로 이완시키는 것(계산).

## ★ 표시용이다

시작점 xy 만 계산된 값이다. 나머지 위치·높이는 전부 기하로 준 것이고 에너지를 붙이면 안 된다.
