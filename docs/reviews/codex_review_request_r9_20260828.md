## Q1 [P1] ★ — **A1 의 판정 규칙이 R8 이 무효화한 표준오차 위에 서 있다**

개정 A1 §2 가 등록한 것:
```
정본 = 쌍대응 산술평균  R̄ = (1/8) Σ_i R_i ,  SE(R̄) = sd(R_i)/√8  (ddof=1)
```
A1 §3 이 그 위에 델타법으로 `SE(A)` 를 세우고, A1 §4 가 판정선을 이렇게 걸었다:
```
A − 1.96·SE(A) ≥ 0.70  → h1
A + 1.96·SE(A) < 0.30  → h0
구간이 0.30~0.70 안에 온전히 → BOTH_REJECTED
구간이 문턱을 걸침 → INDETERMINATE_PRECISION
```

그런데 **같은 날 R8 Q1** 이 이렇게 판정했고 우리는 그것을 Table S3 에 적용했다:
> 8팔은 같은 침대의 완전한 `{0,½}³` factorial 이지 독립 복제가 아니다.  완전 factorial 은
> 7개 비상수 대비가 8점을 **전부 소모**하므로 **복제 기반 오차 자유도가 0** 이다.
> ⇒ `sd/√8` 은 표준오차가 아니다.  `±` · 95 % CI **철회**.

⇒ **A1 §4 의 네 줄이 전부 그 SE 를 쓴다.**  R8 을 Table S3 에만 적용하고 A1 에는 적용하지
않았다 (A1 이 R8 보다 몇 시간 먼저 쓰였고, 그 뒤 대조하지 않았다).

**묻는다**:
1. A1 §4 를 **지금** 고치는 것이 정당한가?  `A` 자체는 blind 이지만 그 **구성요소 절반**
   (vox 0.15 두 런)은 봤다.  이것이 "결과를 보고 규칙을 고친다" 에 해당하는가?
2. 대안 중 무엇이 옳은가 — 또는 넷 다 틀렸나?
   - (a) 구간 게이트를 버리고 **점값 + 관측 범위**로 판정 (`A` 가 0.70 이상/0.30 미만/사이)
   - (b) origin 을 유한 모집단으로 보고 `A` 를 **오차 없는 측정값**으로 선언, 판정선은 그대로
   - (c) 8 origin 을 **재표본**(bootstrap over origins)해 구간을 만든다 — 유한 모집단에
     부트스트랩이 정당한가?
   - (d) 판정 자체를 포기하고 `A` 를 서술값으로만 보고
3. ⚠ **어느 쪽이든 문턱 0.30/0.70 은 건드리지 않는다**는 우리 원칙이 유지되는가?
   구간을 없애면 사실상 문턱의 의미가 바뀌는 것 아닌가 (경계에서의 처리가 사라진다)?
4. A1 §4 의 `INDETERMINATE_NO_GRID_EFFECT` (`|ΔR̄(off)| < 3·SE(ΔR̄(off))`) 도 같은 SE 를
   쓴다.  분모가 잡음인지 판별하는 이 게이트는 **무엇으로 대체하나**?
