## 3. ★★ 펠릿 전자 보정 = **하지 않는다** (2026-09-02 판단, 사용자 질의로 확정)

기존 기각 기록 (`pellet_calib_freeze_20260825.md` ⑥):
> 천장 프로브 (σ_e_sdcp = 3.0e-4, t = 10⁴ ≈ ∞): σ_e = **5.157×10⁻⁸ = 이득 1.719×** vs 요구 **5.1×**.
> Bruggeman EMT t→∞ 예측 1.78× 와 정합 = **포화 확인**.
> 기각된 것은 **"비겹침 RSA 형상 + 현행 voxel stamp 가 만든 접촉 위상"이라는 모델 클래스**다.

**추가 GPU 런(형상 정합화)을 제안했다가 철회한 근거 셋:**

1. **펠릿은 애초에 `σ_SDCP` 에 둔감하다.**  σ→∞ 도 1.719× 에 머문다 ⇒ 250 이든 ∞ 든 같은 답.
   둔감한 측정으로는 보정할 수 없다.  형상을 바꿔 민감하게 만들면 **미지수 둘(접촉 정도 + σ_SDCP)에
   측정값 하나** = 부정정 ⇒ 보정이 아니라 **적합**이 된다.
2. **물리가 다르다** (사용자 지적).  펠릿 SDCP ≈ **14.6 vol%** 로 절연 매트릭스를 **혼자** 가로질러야
   하고(자체 퍼콜 필요), 전극 SDCP ≈ **1 vol%** 로 **이미 도체인** NCM·VGCF 망에 얹힌다(퍼콜 불필요).
   두 부피분율은 **퍼콜 문턱의 반대편**이다 ⇒ 문턱을 건너 파라미터를 이식하는 것이고, 이 리포가
   SE 응답곡선 전이에서 이미 실측 기각한 부류다.
3. **같은 질문을 이미 옳은 기하에서 묻고 있다** — closure 스윕의 `C₂ = σ_SDCP/σ_VGCF` 축이
   **전극 기하 그대로** 그것을 묻는다.  펠릿 런은 더 나쁜 기하에서의 중복이다.

⇒ **펠릿 기각은 보정이 아니라 한계 서술로 남는다.**  원고 문구는 기존 그대로:
> *"현재 비겹침 RSA 펠릿 RVE 는 압착 펠릿의 SDCP 접촉망을 포함하지 않아 관측된 +SDCP 전자
> 증강을 재현하지 못했다."*

⇒ `σ_SDCP = 250` 은 **미보정으로 남는다** (펠릿=둔감 · 전극=퍼콜 불요 ⇒ 어느 기하도 못 잰다).
★ 가장 간단한 길 = **SDCP 단독 압착 펠릿 DC 분극** 1건 (지금 있는 건 전부 혼합물이라 구조가 섞였다).
  공저자께 물어볼 것 — 이미 있을 수도 있다.

★★ **펠릿 기각이 전극 결과를 훼손하지 않는다** (세션 중 제 과잉 서술 정정): 전극에서 SDCP 는
혼자 전도할 필요가 없으므로 펠릿의 실패 모드가 작동하지 않는다.  CL-44 h1("이득의 주원천 =
새 도체 부피, σ 치환 아님")과 같은 그림이다.
