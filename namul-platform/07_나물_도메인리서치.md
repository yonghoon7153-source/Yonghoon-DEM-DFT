# 나물 도메인 리서치 — 발표·사업에 쓰는 전문 지식 (2026-10-30 웹 검색)

> 나물로의 도감·AI 셰프·상인 비서·리스크 대응에 그대로 쓰는 지식만 모았다. 각 항목 끝에 **사업 반영**을 적었다.
> 확인 범위: 검색 결과 요약까지 확인했다. 기사 원문은 세션 네트워크 정책으로 열지 못한 곳이 있어, 수치는 발표 전에 원문 대조를 권한다. 의학적 효능 표현은 의도적으로 뺐다.

## 1. 나물의 분류

| 기준 | 분류 | 예시 | 비고 |
|---|---|---|---|
| 나는 곳 | 산나물 | 취나물, 곰취, 두릅, 고사리, 곤드레(고려엉겅퀴), 산마늘(명이), 고비 | 가이드북들은 산나물·들나물·해조류나물·재배나물로 장을 나눈다 |
| | 들나물 | 냉이, 달래, 씀바귀, 돌나물, 쑥 | 도시 하천변 야생 나물은 농약·중금속 오염 우려로 채취 자제 권고 |
| | 재배나물 | 시금치, 콩나물·숙주(기른 나물), 참나물(재배), 배추, 가지·오이·호박 | 연중 공급, 동네 매장 주력 품목 |
| 먹는 법 | 생채 | 달래, 씀바귀, 돌나물, 참나물, 취나물, 더덕 | 날로 무침 |
| | 숙채 | 냉이, 고사리, 두릅, 다래순, 원추리 | 데치거나 볶아 숨을 죽인 뒤 무침. 독성분 있는 나물은 반드시 데침 |
| | 묵나물 | 참나물, 고사리, 취나물, 두릅, 쑥, 고비 (데쳐 말림) | 늦가을~초봄 이용, 정월대보름 묵은나물 |

**사업 반영**: 도감을 '나는 곳 × 먹는 법' 두 축으로 태그. 묵나물 꾸러미로 겨울 비수기 대응.

후보 논문 링크 (검색 요약에서 수치와 논문의 1:1 매칭은 확인하지 못함): [JAKO202209461026883](https://koreascience.kr/article/JAKO202209461026883.pdf) · [JAKO201626360542267](https://koreascience.kr/article/JAKO201626360542267.pdf) · [JAKO201412837595147](https://koreascience.kr/article/JAKO201412837595147.pdf) · [데침 시간과 비타민·무기질](https://koreascience.or.kr/article/JAKO200531935934774.page)

**사업 반영**: 안전 처리가 먼저다. 고사리·두릅·원추리처럼 독성분이 있는 나물은 충분히 데치거나 삶고 우려내는 처리를 우선하고(§3), 그 밖의 나물에만 '짧게 데치기'를 권한다(시금치 40초·참나물 30초 등). 데침 시간은 품목·판매 상태(생·삶음·건조)별로 확인된 값만 보여 주고, 확인되지 않은 시간은 자동으로 만들지 않는다(프로토타입은 도감 값이 있는 품목만 매장 데침 옵션 허용). 영양 수치를 쓸 때는 성분 DB 원값만 인용, 효능 주장 금지.

## 7. 발표에서 쓰는 한 줄 (전문성 포인트)
- "나물은 나는 곳에 따라 산나물·들나물·재배나물, 먹는 법에 따라 생채·숙채·묵나물로 나뉩니다."
- "고사리·두릅·원추리는 독성분이 있어 반드시 데쳐 먹어야 하고, 원추리는 독초 여로와 헷갈립니다. 그래서 나물로의 AI는 야생 식물의 식용 여부를 판단하지 않습니다."
- "2023년에는 중국산 고사리 56톤이 국산으로 섞여 급식에 납품됐습니다. 원산지 신뢰가 곧 경쟁력입니다."
- "올여름 시금치 값은 폭염으로 한 달 새 68% 올랐습니다. 수요 예측이 필요한 이유입니다."
