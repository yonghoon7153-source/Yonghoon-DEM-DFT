## §3 비교 사양 v1 — 결과를 보기 전에 고정

### 3-0. 순서 규칙

- **A1 (자료 식별) 에서는 모델과의 차를 계산하지 않는다** — 형식 · 단위 · 시각 기준 · sha256 · 대응표 칸만 채운다. 모델 곡선과 겹쳐 그리지 않는다.
- 비교 (A3) 는 이 사양 — 또는 A1 의 **사실** (단위 · 샘플링 · 단계 구조 · 기기 사양) 때문에 결과를 보기 전에 고친 v2 — 이 커밋된 뒤에만, 한 번 한다.
  고치면 새 판으로 내고 옛 판을 보존하며 사유를 적는다.
- 결과를 본 뒤에는 구간 · 정렬 · 지표를 바꾸지 않는다. 더 보는 분석은 "사후" 라벨을 붙이고 아래 분류에 쓰지 않는다.
- 비교는 **기존 저장 해 (NORMAL480 0–480 s) 만** 쓴다 — 새 solve 가 필요해지면 별도 준비 · 승인 (이 사양 밖).

### 3-1. 정렬

| 항목 | 고정 |
|---|---|
| 시각 원점 t = 0 | 충전 단계 시작 — 충방전기의 단계 시작 기록이 있으면 그것, 없으면 충전 방향 전류가 공칭 0.1C 전류의 50 % 이상이 된 첫 샘플. 시간 이동 맞춤 없음 |
| 전류 | 실측 I ÷ 실측 전극 면적 (없으면 A_cell 1.53938 cm²) → A/m² 로 환산해 모델 2.5036 A/m² 와 나란히 기록. 모델 전류 · 용량을 실측에 맞춰 바꾸지 않는다. 부호: 충전 = 양 (READY l.55) |
| 전압 | 오프셋 · 배율 보정 없음. 모델 V = 경계 4 (z = 121 µm) − 경계 1 (z = 0) (SPEC §10-1 l.436) · 실측 V = 기기의 셀 단자 전압 그대로 |
| 시각 맞춤 | 모델의 **정확 저장 시각**에서 비교한다 — 모델은 보간하지 않는다. 실측은 같은 단계 안의 앞뒤 두 샘플로 선형 보간하고, 두 샘플 간격이 공칭 샘플링 간격의 2 배를 넘으면 그 시각은 결측 (채우지 않는다) |
| 시작 상태 경로 | **경로 S:** 충전 직전 OCV 가 모델 시작 평형 2.1653 V 와 ±20 mV 안 **그리고** 직전 이력이 식별됨. **경로 D:** 그 밖 — 프로토콜대로 방전 하한 2.7 V 근처에서 시작했다면 여기다 (SPEC §37-4 질문 3). ±20 mV 는 자료 · 결과와 무관하게 지금 고른 값이고, 경로는 자료의 **이력 · OCV** 로 정한다 (비교 결과로 정하지 않는다) |

### 3-2. 구간

모델 저장 해의 범위 안에서만 — **W0 [0, 5] · W1 (5, 30] · W2 (30, 120] · W3 (120, 240] · W4 (240, 480] s** (저장 결과 분석과 같은 창 —
SPEC §39-5). 480 s 이후의 실측은 이번 비교에 쓰지 않는다 (모델 해가 없다 · 960 s 없음).

### 3-3. 지표

| 지표 | 정의 |
|---|---|
| M1 점 차 | ΔV(t_k) = V_model(t_k) − V_meas(t_k) · t_k ∈ {5, 30, 60, 120, 240, 360, 480} s (모델 정확 저장 시각 — R480 의 selected_times 와 같은 시각). t = 0 은 쓰지 않는다 (모델의 t = 0 은 CDI 초기화 뒤) |
| M2 구간 기울기 | 창 W1–W4 마다 할선 (V(끝) − V(시작)) / (끝 − 시작) — 모델 · 실측 각각과 그 차 |
| M3 0–5 s 상승 | V(5 s) − V_start · 모델 V_start = 시작 평형 2.1653333265 V → 모델 값 2.3521763195 − 2.1653333265 = **186.843 mV** (R480 selected_times · SPEC l.297–301 — 우리 산술) · 실측 V_start = 충전 직전 OCV |
| 함께 적는 것 | 실측 불확도 U_V (기기 전압 정확도 — A1 에서 사양서로 고정) · 결측 시각 · 실측 전류 / 모델 전류 비 |

### 3-4. 분류와 허용되는 문장

- **경로 S:** 지표마다 \|차\| ≤ U_V 이면 "불확도 안", 넘으면 "불일치 조사 대상". 수치 설정 간 관측 차이 (§1 행 17) 를 이 문턱에 더하지 않는다 —
  그것은 오차 바닥이 아니다 (SPEC §42-3).
- **경로 D:** M1 · M3 의 차는 "시작 상태 차 포함" 으로만 기록하고 모델 오차로 해석하지 않는다. M2 (기울기) 만 진단으로 본다. 정량 대응은 시작
  상태를 맞춘 새 solve (별도 준비 · 승인) 뒤로 미룬다.
- 첫 결론으로 쓸 수 있는 문장은 "어느 입력이 실측과 **맞고 / 다르고 / 확인할 수 없는가**" 와 위 분류까지다. "모델이 실험과 맞는다" · "OCP 를
  바꿔야 한다" 는 쓰지 않는다 (SPEC §40-2 · S2 l.2854).

## §4 A1 에서 하는 일 (자료가 온 뒤 · 비교 아님)

자료마다 sha256 · 출처 · 라이선스 · 셀 ID 를 남기고 (원자료는 저장소에 넣지 않는다 — 지금까지 원본 파일 · 규진팀 자료 · 결과 ZIP 을 두지
않은 것과 같다: SPEC l.12–13 · l.3236), 대응표의 실험 칸 · 상태를 채우고, 단위 ·
환산을 검사하고 (I / A → A/m² · 적재량 → Q_el · C_lit0_ref1 정합), 시작 상태 경로 (§3-1) 와 U_V 를 정한 뒤, 사양 v1 을 그대로 쓸지 v2 로 고칠지를
**비교 전에** 정한다.
