## 0. ⭐⭐ 확정 실측 — 게이트가 거꾸로 작동한다

gabia `00_preflight/preflight_report.json` **273/273** 전부 같은 값:

```
UMA-이완 baseline  V/atom = 27.478 Å³      E/atom = −3.6898 eV
                      입력 CIF 20.705 대비  +32.71 %
                      실험 Li₆PS₅Cl 18.43 대비  +49.1 %
```

⇒ `screen_dV_over_V0` 는 **49 % 부푼 기준에 대한 상대값**이다. 절대 밀도로 환산하면:

| | dV | → V/atom | 실험 대비 |
|---|---|---|---|
| 최대 팽창 | +14.6 % | 31.48 | **+70.8 %** |
| 중앙 (kept 대표) | −13.3 % | 23.81 | **+29.2 %** |
| 게이트 경계 | −25.0 % | 20.61 | +11.8 % |
| **dropped 중앙** | −26.8 % | 20.11 | **+9.1 %** |
| 최대 수축 | −33.1 % | 18.39 | **−0.2 %** ← 실험 밀도 |

**게이트가 떨어뜨린 100개의 범위는 18.39–20.61 Å³/atom** — 실험 밀도에서 +12 % 까지다.
남긴 것들의 중앙은 23.81 (+29 %) 이다.

> 실험 밀도 −10 %~+15 % 구간(16.6–21.2 Å³)에 든 구조 **197개 중 100개(51 %)를
> 현행 게이트가 탈락시켰다.** 게이트는 **물리적 밀도에 도달한 쪽을 골라서 버린다.**

**B₂O₃ plain**: 중앙 dV −29.13 % → **19.47 Å³/atom**. 우리 DFT `b2o3_relaxV0` 는
**19.034**. 차이 **+2.3 %**. ⇒ *"cascade 의 B₂O₃ 는 무너진 게 아니라 밀도를 유일하게
맞춘 것이었고, 그래서 탈락했다."* 1저자 최초 질문("우리 b2o3 DFT 는 어떻게 살아남았나")의
최종 답이다.

**⚠ 위험도**: preflight 의 통과 문턱이 35 % 인데 실측이 **32.71 %** 다. 2.3 %p 차로 통과했고,
그 문턱은 v4.5.5 에서 **5 % → 35 % 로 넓힌 것**이다(사유 주석: "false-failed on every UMA
cascade"). 즉 검사가 신호를 잡았는데 문턱을 옮겨 통과시켰다.

## 1. 수정 항목 (우선순위 순)

### P0-A. 기준 셀 — 왜 27.478 인가부터 가른다 (수정 전 진단)

UMA 는 **DFT 이완된** `modelC`(19.42) 를 +0.92 %, `b2o3_relaxV0` 를 −0.00 % 로 놔둔다.
같은 계열인데 canonical Li₆PS₅Cl 만 +32.7 % 부푼다. 후보:

1. **Li 배열** — `lpscl_F43m_24G_canonical.cif` 는 Li 를 **24g 에 완전 정렬**시킨 셀이다.
   실제 argyrodite 는 48h/24g 부분점유 무질서다. 정렬된 Li 는 Li–Li 반발이 커서 UMA 가
   벌릴 수 있다. **기준만 anneal 을 안 받는다**(Stage 04 는 winner 만 anneal).
2. **입력 셀** — 입력 CIF 자체가 a=10.2493 로 실험(9.859)보다 이미 **+12.4 %** 다.
   출처 미확인 (`fetch_mp_structure.py` 는 mp-985592 를 **준안정 다형**이라 스스로 적어 놨다).
3. **UMA task** — `omat` 로 돌린다. `omc`/`oc20` 등 다른 task 나 다른 체크포인트에서
   같은 셀이 어떻게 되는지 안 봤다.

**가르는 판 (싸다)**:
```
(a) canonical CIF 를 500 K/50 ps anneal → 재이완 → V/atom
(b) Li 무질서 셀(48h 부분점유 realization) 3개를 UMA 이완 → V/atom
(c) 실험 격자(a=9.859)로 스케일한 셀을 고정셀 이완 → 에너지 비교
(d) modelC(19.42) vs canonical(27.48) 을 같은 조건에서 나란히
```
⇒ (a)/(b) 가 19 근처면 **정렬-Li 인공물**, 그대로 27 이면 **UMA 편향**.

### P0-B. 게이트를 절대 밀도로 바꾼다

현행 `|dV| ≤ 0.25` 는 (i) 기준이 틀렸고 (ii) 이름과 하는 일이 다르다
(깨진 구조를 안 잡는다 — 대안 A/B 와 교집합 **0행**, `cascade_volume_gate_review.json`).

제안 — 셋을 **따로** 쓴다. 하나로 뭉치지 않는다.
```
G_shape   : 각도 편차 > 5° 또는 축비 > 1.25        → 이완 실패 (78행)
G_resid   : 종내 |dV − median| > 6·MAD             → 씨드 이상치 (111행)
G_density : |V/atom − V_ref(조성)| 가 과도          → 물리 밀도 이탈
            V_ref 는 **UMA 기준이 아니라** 조성별 참조(우리 DFT EOS V0 / MP hull 상)
```
`--max_dv` 를 없애지는 말고 **기본값을 끄고**(`--max_dv none`) 위 셋을 켠다.

### P1-A. `Li_24g` / `Li_48h` 중복 제거

`substitute_struct.find_host_indices_for_site()` 가 두 라벨에 **같은 Li 전체**를 돌려준다
(자기 docstring이 인정). 330쌍이 좌표까지 동일, |Δde| 중앙 1.5e-06 eV/atom.
winner 681 중 **66 슬롯이 둘 다 뽑혀 132행**이 중복 계산됐다.

수정 후보:
- (권장) `HOST_SITES` 에서 `Li_48h` 를 **빼고** `Li` 하나로 통일 + 마이그레이션 노트.
- 또는 입력 CIF 에 Wyckoff 메타데이터를 실어 진짜로 가른다 (pymatgen `SpacegroupAnalyzer`
  로 24g/48h 를 판정 — 정렬 셀에서는 48h 가 비어 있을 수 있음).
- 어느 쪽이든 **`LITERATURE_SITES` 의 `['Li_24g','Li_48h']` 표기도 같이 정리**.

### P1-B. `li_mobility_score` 가 파일에 안 들어간다 → 랭킹 30 % 사망

`bvse_proxy.py` 가 JSON 을 **먼저 쓰고**(267–273) 점수를 **나중에** 계산한다(278–282).
CSV 에서 **0/3,615**. `combine_rankings.py` 는 전부 None 인 열을 상수 0.5 로 정규화한다.
지문: `combined_score` 3,615행 **전부** `[0.1500, 0.8500]` (= 0.4·0+0.3·0+0.15 … 0.4+0.3+0.15).

⇒ **모든 챔피언(`rank_combined==1`)이 안정성+영률 둘로만 뽑혔다.**

수정: (1) 점수 계산을 write 앞으로 옮긴다. (2) `normalize()` 가 전열 결측이면
**0.5 를 조용히 돌려주지 말고 실패**하게 한다(또는 가중치를 재정규화). (3) 회귀 시험 추가.
⚠ 고치면 **챔피언이 바뀐다** — 47/90종 리더보드·계면·ESW 를 다시 돌려야 한다.

### P1-C. Type C 스윕이 조용히 3/4 소실

`halide_rich_swap()` 의 ValueError 가 try 밖 + `compound_summary.json` 을 루프 **끝에** 쓴다
⇒ 뒤쪽 조합 하나가 죽으면 **앞에서 만든 구조까지 버려진다**. `|| true` 가 에러를 삼킨다.
결과: Cl 과잉 0.4/0.6/0.8 이 **MgO·ZnO 에만** 있다(O 1개라 S_4a 가 3개 남음).
M₂O₃ 9종은 0.2 만. 44 조합 중 **17개만** 존재.

수정: (1) 각 (site, seed) 를 개별 try 로 감싼다. (2) summary 를 **증분 저장**한다.
(3) `|| true` 대신 실패를 로그에 남기고 카운트한다. (4) S_4a 잔여 자리를 **미리 검사**해
불가능한 조합은 사유와 함께 skip 한다.

### P1-D. `--method cluster` 는 실행된 적이 없다

`run_compound_batch.sh:174` 가 `--method cluster` 를 넘기는데
`substitute_compound.py:578` argparse `choices=['spread','random','first']` 가 막는다
(`select_substitution_sites` 자체는 cluster 지원). CSV 중복 name **0건**이 증거.
⇒ "Type A cluster (전구체 국소배위)" 10종 × 3농도 전멸.
수정: choices 에 `cluster`, `near_cation` 추가 + 스모크 테스트.

### P3. 우리 쪽에서 같이 볼 것

- **cascade BVSE ≠ 우리 BVSE**: `bvse_proxy.py` 는 Li–S R0 **1.94**(b **0.40**) ·

  `migration_volume_fraction` 도 "BVS∈[0.8,1.2] 격자점 비율"이지 채널 % 도 퍼콜레이션도 아니다.
  → `convention_check.py` 에 **교차인용 금지** 규칙을 넣을 후보.

- `run_md_sigma.py`(미실행)는 창이 `fit_start:끝`(50 ps)·prod 50 ps 로 우리 규약

- preflight 이 스스로 적기를, UMA 가 Nd₂O₃/Al₂O₃/MgO 에 ΔE/atom **−0.5~−0.9 eV** 를 주는데
  문헌은 ±0.03 eV — **20~30배**. 허용범위를 넓혀 통과시켰다. ΔE 축의 절대값 인용 금지.

## 2. 발표(세미나)에 즉시 반영해야 하는 것

11장 대본을 오늘 아침 한 번 고쳤는데, 이 실측으로 **또 바뀐다**:

- ⛔ "25 % 넘어간 것은 구조가 무너진 것" → **틀렸다.** 탈락 100개는 18.4–20.6 Å³/atom,
  즉 **실험 밀도에 가장 가까운 것들**이다.
- ⛔ "게이트가 독립적으로 일한다" 는 **에너지 축과 직교한다**는 뜻으로만 유효하다.
  "무너진 구조를 잡는다" 는 주장은 못 쓴다.
- ✅ 쓸 수 있는 정직한 문장: *"이 스크린의 부피 축은 MLIP 이완이 도달한 셀을
  **MLIP 자신의 host 셀**에 대해 잰 것이고, 그 host 는 실험 격자보다 크다.
  그래서 이 축은 절대 밀도 판정이 아니라 상대 지표로만 쓴다."*
- 10장 `step2_site_grid` 의 *"9칸이 전부 채워져 있다"* → **6칸 진짜 + 3칸(Li 48h) 복사본.**

## 이 카드가 말하지 않는 것

- **왜** UMA 가 canonical 셀만 32.7 % 부풀리는지 — P0-A 미실행.
- 게이트를 바꿨을 때 챔피언이 어떻게 바뀌는지 — 하위 축 재계산이 필요하다(계산 붙음).
- 다른 MLIP(MACE·SevenNet 등)에서 같은 셀이 어떻게 되는지 — 안 봤다.
- 이 문제가 `dualx_v23` 등 **다른 캠페인**에도 있는지 — 확인 안 했다.

# 3. 자기 리뷰 (2026-08-19 밤) — 위 목록의 **정정 4 · 신규 2**

1저자 지시로 위 작업지시서를 스스로 되짚었다. 아래가 codex 에 넘길 **최종본**이다.

## 3-1. ⭐ 신규 P1-E — **무치환(no-op) 구조가 후보 풀에 들어가 있다**

```
Li2S   90행 중 60행 : |de| < 1e-6,  dV = 0.0000
LiCl   30행 전부    : |de| < 1e-6,  dV = 0.0000
                       조성 Li24 P4 S20 Cl4 = **호스트 그 자체**
```

`substitute_compound` 에서 Li→`Li_24g` 와 Cl→`Cl_4d` 는 **무연산**이다(같은 원소를 같은
자리에 다시 넣는다). 전하 잉여도 0 이라 공공·침입도 없다. ⇒ 생성된 셀이 base 와 **동일**하고
UMA 가 같은 최소점으로 이완하니 `de = 0.000000`, `dV = 0.0000` 이 정확히 나온다.

전체 3,615행 중 **90행(2.5 %)** 이 이름만 도펀트인 호스트다. **어디까지 갔는지 실측했다**:

```
anneal 18행 · EOS 17행 · elastic 18행 까지 갔다  (GPU 를 호스트 셀에 썼다)
**rank_combined == 1 (챔피언) : 3행**   ← 무치환 호스트가 슬롯 챔피언이 됐다
무치환 조합: Li2S@(Li_24g|Li_48h)×(S_16e|S_4a) 각 15행 · LiCl@(Li_24g|Li_48h)×Cl_4d 각 15행
```

⇒ 적어도 세 (도펀트, 농도) 슬롯의 **대표 구조가 도핑 안 된 호스트**다. 그 행이 그대로
ESW·계면·리더보드로 흘러갔다. (Li2S@Cl_4d 30행은 S→Cl 이라 **진짜 치환**이다 — 구분할 것.)

**수정**: 생성 직후 `composition == base_composition and max|Δpos| < tol` 이면
**사유를 남기고 버린다**(조용히 버리지 않는다). `--allow_noop` 로만 통과.

> ⛔ 그리고 이것이 §6b 의 "null 대조" 가 아무것도 증명하지 못한 이유다 —
> **대조군이 대조가 아니라 원본이었다.** 대조를 세울 때 "화학적으로 비슷" 이 아니라
> **"실제로 무엇이 바뀌었나"** 를 조성으로 확인했어야 했다.

## 3-2. ⭐ 신규 P1-F — **기준만 anneal 을 안 받는다**

winner 는 Stage 04 에서 500 K/50 ps anneal 을 받는데 **baseline 은 Stage 02 의 단순 이완**
그대로다. `rank_anneal.py` 도 `pre['baseline_e_per_atom']` 을 그대로 쓴다. 비대칭이다.

가설: 기준의 Li 배열이 나쁘면 **모든 Δe 가 계통적으로 음수**가 된다 → preflight 이 기록한
*"UMA 는 Nd₂O₃/Al₂O₃/MgO 에 ΔE/atom −0.5 ~ −0.9 eV 를 주는데 문헌은 ±0.03 eV"* 의 일부를
설명할 수 있다.

⚠ **과잉연결 주의**: 기준은 자기 UMA 최소점에 이완돼 있으므로 **부피 팽창 자체가 Δe 를
음수로 만들지는 않는다.** 부피 문제와 Δe 문제를 한 원인으로 묶으려던 내 첫 충동은 틀렸다.
둘은 **따로** 검증한다 (anneal 한 기준으로 Δe 재계산 → 얼마나 움직이나).

## 3-3. P0-A 정정 — **결정적 대조를 빠뜨렸다**

우리에겐 **같은 조성·같은 원자수의 DFT 이완 셀**이 이미 있다:

| | 파일 | n | a (Å) | V/atom | 평균 P–S |
|---|---|---|---|---|---|
| cascade BASE | `lpscl_F43m_24G_canonical.cif` | 52 | 10.2493 | 20.705 | 2.082 |
| **우리 DFT** | `comp1_V0_k444.cif` | 52 | 10.0551 | **19.550** | 2.072 |

PS₄ 기하가 사실상 같고 **격자만 +1.9 %(a) / +5.9 %(V)** 다.
⇒ **P0-A 는 UMA 로 `comp1_V0_k444.cif` 를 이완시키는 한 판이면 갈린다.**
19.5 근처면 canonical 특유의 문제, 27 근처면 UMA 가 이 조성 자체를 부풀리는 것.

# 4. ⭐⭐ 신규 P0-C — **깔때기 구조 자체**가 문제다 (1저자 질문, 2026-08-19 밤)

## 4-1. 선발 기준과 평가 기준이 다르다 — 78 %를 **상관없는 잣대**로 버렸다

Stage 03 은 `min de_per_atom_vs_baseline`(이완 에너지) **하나로** 3,615 → 681 을 만든다.
그런데 우리가 최종적으로 랭킹하는 축은 산화창·탄성·수송이다. 그 둘의 상관 (681행):

```
r(screen_de, 영률 E)        +0.230      r(screen_de, BVS 프록시)   +0.170
r(screen_de, B0)            +0.287      r(screen_de, 이동부피)     −0.317
r(screen_de, Pugh G/B)      +0.107      r(screen_de, anneal ΔE)   +0.675 ← 같은 에너지 계열
```

⇒ **r² 1–10 %.** 선발 잣대가 최종 목적함수의 분산을 거의 설명하지 못한다.

(에너지끼리는 0.675 로 잘 맞는다 — 즉 Stage 03 은 "에너지가 낮은 것"을 잘 골랐다.
문제는 **우리가 에너지로 순위를 매기지 않는다**는 것이다.)

## 4-2. 대표를 바꾸면 답이 바뀐다 — 슬롯내 산포 ≈ 종간 산포

같은 (도펀트, 농도) 슬롯 안 후보들끼리의 산포를, 종 사이 산포와 비교했다:

| 축 | 슬롯내 표준편차(중앙) | 종간 표준편차 | **잡음/신호** |
|---|---|---|---|
| 영률 E | 4.089 GPa | 5.427 GPa | **0.75** |
| B0 | 1.473 GPa | 2.727 GPa | **0.54** |
| 이동부피 | 0.005 | 0.010 | **0.49** |
| BVS 프록시 | 0.012 | 0.014 | **0.88** |

⇒ **같은 종의 다른 배열을 대표로 뽑으면 물성이 종간 산포의 절반~9할만큼 움직인다.**
슬롯내 상대폭은 영률 중앙 **20.3 %**(최대 509 %), B0 17.1 %.
*종을 고르는 것과 배열을 고르는 것이 구분되지 않는다.*

## 4-3. 후보가 많은 종이 유리하다 (best-of-N)

```
r(후보 수, 챔피언 점수) = +0.349   (89종)
후보  3개 → 챔피언 점수 중앙 0.700

```

그리고 4-1 의 중복(Li_24g/Li_48h)이 **일부 종에 공짜로 뽑기 2배**를 준다.

## 4-4. `combined_score` 는 애초에 종간 비교가 안 되는 값이다

`combine_rankings.normalize()` 는 **그 캐스케이드 안에서만** min-max 정규화한다.
게다가 결측을 **조용히 0.0 으로** 만든다:

```python
return [float(x) if not np.isnan(x) else 0.0 for x in norm]
```

⇒ 하위 단계에 못 간 구조는 그 축이 **0 점**이 된다(제외가 아니라 0 점).
그래서 `combined_score` 는 물성 점수인 동시에 **"이 구조가 파이프라인을 끝까지 갔나"**
를 부분적으로 재는 값이다. 실제로 비-winner 의 상한은 0.4·1 + 0 + 0.15 = **0.55**,
winner 의 상한은 **0.85** — 챔피언 점수의 관측 범위 [0.550, 0.850] 와 정확히 일치한다.

## 4-5. 반대로, **문제가 아닌 것** (과잉 경보 방지)

- 부피 게이트로 **통째로 사라진 base_species 는 없다**(B₂O₃ plain 변형만 30/30).
- 챔피언은 **항상 Stage 03 winner 다** — 구조적으로 보장된다(비-winner 상한 0.55 < 0.85).
- 우리가 발표하는 `cascade_v23_ranked.csv` 의 점수식은 **종간 공통 척도**로 repo 에서
  다시 계산한다. 척도 자체는 건전하다. 문제는 그 식이 먹는 **행**이 위 방식으로 뽑혔다는 것.
- `build_screening_funnel.py` 의 G1–G5 는 스스로 *"발견 깔때기가 아니라 재표현"* 이라고
  선언하고 `pool_provenance` 를 들고 다닌다. 그 장치는 정직하게 작동한다.

## 4-6. 수정안 — **재계산 없이** 대부분 고쳐진다

우리는 이미 **681개 winner 전부**에 anneal·BVSE·EOS·elastic 값을 갖고 있다
(종당 평균 7.6개). 그러니:

1. **챔피언 하나 대신 종별 분포로 보고한다** — 평균 ± 폭, n. GPU 0시간.
2. 랭킹 표·그림에 **`n_candidates` 를 같이 싣고**, 종간 막대에 **슬롯내 산포를
   오차막대로** 그린다. 위 잡음/신호 0.49–0.88 이 그림에서 바로 보이게.
3. 선발이 꼭 필요하면 **최종 목적함수와 같은 잣대로** 뽑는다(지금은 에너지로 뽑고
   산화창·탄성으로 순위를 매긴다). 또는 **선발하지 말고 전부 들고 간다**.
4. `normalize()` 의 결측 → 0.0 을 **결측 유지 + 가중치 재정규화**로 (P1-B 와 같은 수정).
5. 문구: *"이것은 종의 순위가 아니라 (종, 임의로 뽑힌 대표 배열)의 순위다"* 를 명시.

⚠ 3·4 를 적용하면 **챔피언이 바뀐다** → 계면·ESW 재계산이 붙는다. 1·2 는 안 붙는다.
**1·2 를 먼저 하고 3·4 는 codex 리뷰에서 비용과 같이 판단한다.**

## 5-1. ⛔ §4-2 "잡음/신호" 는 **틀린 프레이밍**이다

슬롯 안 후보들이 씨드만 다른 줄 알고 "노이즈" 라고 썼다. 실측:

```
후보 2개 이상 슬롯 255개 중
  후보가 **같은 (자리, 음이온자리)** 인 것 :   0개   ← 씨드만 다른 경우는 없다
  자리가 서로 다른 것                    : 255개   ← 전부 구조적으로 다른 배열
```

⇒ **슬롯내 산포는 측정 잡음이 아니라 실제 구조 다양성이다.** 정확한 진술은:

> 종 하나가 단일 물질이 아니라 **자리 배열의 가족**이고, 랭킹이 그 가족을 한 숫자로 뭉갠다.
> 그리고 그 대표를 **에너지로** 뽑아서 **산화창·탄성**으로 순위를 매긴다(§4-1, r² 1–10 %).

수치는 그대로 유효하다(영률 슬롯내 σ 4.089 vs 종간 5.427). 해석만 바꾼다 —
**"랭킹이 잡음을 본다" 가 아니라 "랭킹이 가족 중 임의의 한 명을 종의 대표로 세운다"** 다.
이게 오히려 더 방어 가능한 진술이고, 12장이 이미 반쯤 말하던 것과 정확히 맞는다.

⚠ 그리고 Li_24g/48h 중복(§3-1)을 걷어내면 실질 조합 수가 줄어든다:

```
b2o3   케이지 28 · Li 58 → 케이지당 2.1   ← 케이지 개념이 묽다
```
b2o3 는 자유 음이온이 많아 "케이지" 가 argyrodite 의 3–6 Li 와 다르다.
막지 않되 **케이지당 Li 를 같이 찍고**, 그 계의 intra/inter 구분은 약하게 해석한다.

⚠ 음성시험도 한 번 잘못 짰다 — *P 를 빼면 PS₄ 가 깨진다* 고 생각했는데 남은 P 는 여전히
4배위다. **결합한 S 를 빼야** 깨진다. 고쳤고 양쪽(깨진 것 차단 / P 제거 통과)을 다 시험한다.

# 6. ⭐⭐⭐ 최종 판정 (2026-08-19 심야) — **27.478 은 미수렴이었다. 피해는 Stage 02–03 에 국한된다.**

## 6-1. 원인 확정 — fmax 0.05 가 58 스텝에서 멈췄다

```
canonical, 무섭동, fmax 를 조여 가며:
  fmax 0.05  → 27.478 Å³/atom  ( 58 스텝)  잔류압력 +0.186 GPa  ← cascade 설정
  fmax 0.01  → 20.442          (1124 스텝)            −0.007
  fmax 0.002 → 20.415          ( 917 스텝)            −0.001    ← 진짜 최소점
```

**UMA 의 실제 Li₆PS₅Cl 최소점은 20.415 Å³/atom** — 우리 DFT 19.55 대비 **+4.4 %**,
MLIP–DFT 정상 범위다. ⇒ **UMA 는 이 계에서 이상하지 않다.**

씨드 산포(§5-4)도 전부 fmax 0.05 에서 잔류압력 −0.06~−0.23 GPa 를 남기고 멈춘 것들이다:

```
rattle 0.01, seed 0/1/2/3 → 20.562 / 24.787 / 25.018 / 23.610   (폭 19 %)
```
**다분지가 아니라 "언제 멈췄나" 의 산포다.** §5-4 의 "카오스적 다분지" 읽기는 **철회**한다.

대조가 결정타 — DFT 구조는 완벽 재현된다:
```
comp1 + rattle 0.05, seed 0/1/2 → 19.567 / 19.568 / 19.567   (폭 0.0 %)
```

### ⛔ preflight 주석이 버그를 은폐했다

> *"UMA 가 LPSCl 을 25–35 % 부풀린다(Wang 2025 sulfide PES softening)"* → **틀렸다.**
> *"v4.5.5 fix: was 5 % → false-failed on every UMA cascade"* → **5 % 문턱이 맞았다.**
> 모든 cascade 에서 걸린 이유는 **모든 baseline 이 실제로 미수렴이었기 때문**이다.
