# 순차 재검증 조정 원본

이 폴더의 JSON은 외부 조정기·실행 승인 당시 준비 확인·플랫폼 관측 원본을 바이트 그대로 보존한다. 과거 런타임 경로·PID는 관측 당시 값이며 현재 실행 중임을 뜻하지 않는다. [조정 결과](controller.json), [시작 기록](launch.json), [시작 전 조건](ready-proof.json), [플랫폼 관측](platform-baseline.json)을 따른다.

원 병렬 큐가 끝나고 다른 네 트랙의 실제 push 영수증이 준비된 뒤, 살아 있는 작업 게이트가 없음을 확인하고 같은 후보·같은 전체 검사·같은 시간 제한으로 D3를 단독 재실행했다. 원 실패를 지우거나 시간 제한을 늘리지 않았다.
