# 미팅 2026-06-25 — 이종기술 회의

> 원본: `../sources/2026.06.25_이종기술회의_노트.docx` + 성능평가 PDF `../sources/2026.06.25_건식전극제작_성능평가.pdf`.

## 1. 목적 / 조건
- 대상: **No.1 / No.2 / Poly**, 조성 **AM:SE:VGCF:PTFE = 80:18:1:1**.
- **면용량 2 타겟팅**, 롤프레스 사용, **프라이머 코팅 집전체** 사용.
- 기본 성능 데이터 도출 목적 (~6/29).

## 2. 실험 순서 (요약)
1. Thinky container 4개 건조 후 사용, 분해셀 세척·건조, 지그·파우치 확보.
2. AM:SE:VGCF = 1.6 g : 0.36 g : 0.02 g (2 g base) → No.1 1개 / No.2 1개 / Poly 2개.
3. 핸드믹싱 → 1st Thinky (2개씩) → PTFE 0.02 g 약하게 핸드믹싱 → **ball mill 200 rpm 1시간**.
4. ball mill 중 롤프레스 최적화 + 프라이머 코팅 집전체 5×5 준비.
   - No.1: 0.0209 g, 0.12 mm / 10pi 프라이머코팅 집전체 무게 0.0046 g.
5. No.1/No.2 2nd Thinky → 롤링하며 면용량 2 타겟. Poly는 Thinky rpm 500/1000, 2500/3000 변화 확인.
6. 대칭셀용 10pi(면용량 2) 별도 도우 확보.
7. 셀 제작 (각 5개씩): **대칭셀 10pi 1, 율특셀 13pi 1, 수명셀 13pi 3**. (13pi 8개 + 10pi 2개 몰드/지그/파우치)
8. 율특 0.1C 3cycle, 수명 0.1C 2cycle, 3개 중 1개 30분 상온 방치 후 임피던스 2회. 셀 12시간 체크.

## 3. 추후 진행
- Poly Thinky rpm 변동 무효 시 → 2nd Thinky 생략, ball mill 2시간 대체.
- In-Li 대신 **Li only** 도 고려.
- **3:7, 5:5, 7:3 대칭셀 데이터(이온전도도)** 확인.

## 4. 교수님 디스커션 (방향)
1. **박막/후막 모델링으로 전극 설계 변수별 영향성 분석** → 후막 성능결정인자 확인 및 디자인 설계.
2. 에너지밀도 고려, 변수별 최적화 방향 결정 → **문제정의→문제해결 논리구조** (모델링 활용).

### 과제 필수 항목 (2차년도)
1. **소재 분석** (No.1, No.2, 대립=우리소재): 저항분석, 수명평가, 율속평가, **GITT 완료**.
2. **DEM 복합양극 미세구조 모델링**: 바이모달 조성별 기공도 및 영향성 예측.
3. **전기화학 모델링**: 박막→후막, 전극 설계인자별.

### 현재 모델링 계획
1. 실험으로 전압프로파일·이온전도도 확인.
2. DEM으로 대립/소립·전해질 함량별 기공도 확인.
3. (1)+(2) 결합 → **P2D 모델**(빠른 파라미터 스윕) → 성능결정인자·내부 반응거동 이해.
- 현황: (1)(2) 러프 결과로 P2D 환경 구축 완료. 7월초: P2D synthetic 데이터 + **ML 도입**(설계인자 교호작용 회귀).
- 추후: 3D 전기화학-기계 ↔ DEM 결합 모델링.

### 논문 계획 (초안)
1. 데이터분석↔후막: 실험/PDE로 기본 거동 확보 → ML로 설계인자 영향성 → 후막 설계원리 도출.
2. (우재형 스타일) 후막 모델링_윤태영: 실험 → 3D 모델링(기계 중점) → 반응 균일성·기계열화 해결 다층구조 설계.

## 5. 롤프레스 운용 메모 (장비)
- 핫플레이트로 가열 상태에서 롤프레스 (열 준 상태 필수). 집전체 깔고 전극 올림.
- 처음 600에서 시작, 1회당 2번씩, 열 주며 50씩 내리며 방향 바꿔 반복. 퍽퍽해지면 10–20씩.
- 알루미늄 두께 15 (프라이머 16). 천천히 통과. 종료 시 양쪽 700 맞추고 끔.
