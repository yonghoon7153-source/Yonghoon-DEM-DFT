## ① fig4b_sigma_conventions.png

```
■ SDCP 도입 시 전자 전도도 증가 — 모델이 실험을 괄호로 가둠
   •  SBE → DBE:  72 → 81 mS/cm (+12 %)   또는   54 → 71 mS/cm (+31 %)

   •  절대값도 문헌과 같은 자릿수 (34 / 39–65 mS/cm)
```

## ③ ion_r_sensitivity.png

```
■ 이온 전도도 — SDCP 물성이 미지, 그 영향 범위를 확정
   •  SDCP 자체의 이온 전도도는 실험에서 하나로 안 정해짐 (해석 모델 따라 9배 차)
   •  그 값을 0 ~ 최대까지 바꿔가며 계산 → 전극 이온 전도도 변화는 **3 % 이내**
   •  SBE 대비 DBE 가 높은지 낮은지는 판정 불가 (차이가 그 안에 묻힘)
   •  전자 전도도는 이 값에 **전혀** 영향받지 않음 → ①의 결론과 독립
```

## ⛔ 슬라이드에 쓰면 안 되는 것

- **옛 세대 수치 일체** — 원고 v6 본문·Table S3 의 σ 쌍과 접점 수, 그리고 그것들에서
  파생된 이득 백분율.  ⚠ **여기 그 값을 다시 적지 않는다** (이 문서 초판이 금지 목록에
  적었다가 `--ban-sweep` 에 5건 걸렸다 — 금지 목록도 문서다).
  정본 등록부: `docs/reviews/claims.json` 의 `quotation_ban`.
  대체값은 이 문서 ①③④ 의 수치를 쓴다.
- *"이온 전도도가 유지된다 / 손해가 없다"* — 등가성을 사전등록하지 않았다.
  ✅ 대신 *"영향 범위가 3 % 이내"* · *"방향은 아직 판정 못 했다"*
- *"격자 수렴했다"* — 미수렴이고 보고값은 그 축에서 하한이다.

## 예상 질문 대응

| 질문 | 답 |
|---|---|
| 왜 σ_e 값이 두 개인가 | 절연 바인더를 격자에 그리는 방식 두 가지를 **둘 다** 보고한다.  어느 쪽이 참인지 정하지 않았고, 실험값이 그 사이에 든다. |
| 이온은 왜 결론이 없나 | SDCP 자체의 이온 전도도가 실험에서 하나로 역산되지 않는다(해석 모델 따라 9배).  그 전 구간에서 전극 값 변화가 3 % 이내라 방향이 안 갈린다. |
| 이온이 미지인데 전자 결론은 믿을 수 있나 | 같은 계산에서 전자 결과가 **비트 단위로 동일**하다 — 이온 파라미터가 전자망에 들어가지 않는다. |
