## 2. 이종기술 D3 탐색 등록 초안 연결

기존 탐색 안 = `docs/reviews/mixer_precal_exploration_registration_draft_20261104.md` §§1–5. 측정 SOP = `docs/reviews/mixer_d3_measurement_sop_draft_20261104.md` §§1–5. 둘의 정본·옛18런·예약 시드는 고치지 않는다.

| 초안 필드 | 채울 내용 | 현재 처분 |
|---|---|---|
| 분석 지위 | 보정 전 탐색·미보정·개발 자료·판정 아님 | 기존 표지 유지 |
| 팔/순서 | 기존 B×r×U/C 후보 및 정착/회전 기준; 먼저 E0 pilot 자격 | 기존 제안값 그대로 참조; 이번 활성 manifest 없음 |
| 예측 | 같은 짝의 SE군집 감소/부착 증가 방향은 사전 기대일 뿐 | 실패·반대·불명확을 그대로 기록; 성공 보장 없음 |
| 필요한 자격 | D2 메타·타입/반경/ID·원자수·프레임·정밀도, 현행 reader schema 제약 연결 | 코드 조사·합성 자격 후 별도 핀 반박 필요 |
| 출력 | 군집·부착·M의 개발 표, 정의/분모·실패/미정의 상태 | T1/T2 실측으로 이름만 바꿔 D3 reader에 넣지 않음 |
| 실측 보정 | S1/S3·보정/검증 열람 분리·T1/T2/T3 역할 | 실측 없음; 임의 실험값·폭·불확도 입력 금지 |
| 시드/비용 | 탐색·보정·검증 집합 및 이력, CPU·시간·중단/회수 | 미정; 예약 확인 seed와 겹치면 HOLD |
| 관문 | 등록 동결·자격·검토·1저자 GO | 이번 초안은 어디도 열지 않음 |

첫 실행 후보를 고르는 근거는 E0 한 팔의 자격 수용과 고정 탐색 계약이다. 순수 SE 랩 공극10–13%를 이종기술의 혼합 지표 목표나 복합 재맞춤 규칙으로 가져오지 않는다.
