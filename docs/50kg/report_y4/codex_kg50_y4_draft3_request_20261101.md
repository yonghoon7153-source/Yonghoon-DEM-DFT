- 왼쪽 = 1저자 50kg 계획 덱 v1 7 장 (4차년도 개발 계획) 의 3D 그림 (Random packing → Compression → Composite cathode · 입자 넣기부터 · 그림 안에 이름 셋 · "300 MPa" 가 픽셀로 있음) — media 바이트 그대로 (렌더 · 자르기 없음 · 618 × 310 px · 덱 4.50 × 2.2573 in) · 출처 (덱 sha256 · 장 · 도형 id) · 그림 sha256 = `docs/50kg/report_y4/figs/p0_plan3d/README.md` + 그 위 글머리 셋 · 아래 단계 글 1 × 3 표 (시트 3판 글 · 표 머리 줄 = 그림 이름이라 화면에 안 씀) · 오른쪽 = 2D 모식 계산의 가압 상태 한 장으로 그린 접촉 모델 (`p0_contact_model_labeled`) + 식 넷 2 × 2 표 · 2판의 2D 절차 그림 (`p0_process_*`) = 쓰지 않음.
