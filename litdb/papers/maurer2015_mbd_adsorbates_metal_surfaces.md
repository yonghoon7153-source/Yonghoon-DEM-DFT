## 1. 한 줄 요약

pairwise 분산 보정은 금속 차폐까지 넣은 vdW^surf 조차 Ag(111) 위 흡착을 **과결합**시킨다. 원자마다 양자 조화진동자(QHO)를 두고 쌍극자 결합을 **전 차수**로 푸는 MBD 를 얹으면
흡착에너지가 **Xe −23 % · PTCDA −29 % · 그래핀 −37.5 %** 줄고 평형 높이가 **+0.05 ~ +0.18 Å** 는다. 실험이 있는 두 계(Xe, PTCDA)에서는 MBD 가 실험 범위 안으로 들어온다.
감소 폭은 흡착물이 **넓게 비편재된 분극 응답**을 가질수록(그래핀) 크다.

**동기** (p. 2–3)
- 반국소 DFT 는 금속 전자구조는 잘 주지만 장거리 상관(분산)이 없다 → 안정 흡착 구조를 아예 못 찾기도 한다.
- pairwise DFT-D/TS 는 분산을 넣지만 금속 흡착에서 **과결합**한다 — 기판 안의 다체 상관과 쿨롱 차폐 때문이다 (ref 30).
- vdW^surf 는 금속 C6 를 차폐로 재규격화해 기하를 크게 개선했지만 **에너지 과결합이 남는다** (ref 31). 조밀한 단층·다층에서는 다체 효과가 더 커질 것이다.
- vdW-DF 계열은 비국소 상관을 2체 적분으로 넣는다. 초기판의 교환 불일치로 과소결합이 있었고 vdW-DF-cx 에서 고쳐지는 중이다.

**질문**: MBD 를 얹으면 금속 위 흡착의 에너지 · 높이 · 진동 · 분극률이 실험에 더 가까워지나?
**답**: 세 계 모두 결합이 줄고 높이가 늘며, 실험 있는 두 계에서 개선된다. 그래핀은 실험이 없어 다른 계산법들 사이의 위치로만 판단한다.

### E_ads 정의 — 세 계가 다르다
- **Xe** (Eq. 4): `E_ads = E_Xe/Ag − (E_Ag + E_Xe)`, E_Xe = **고립 기체 원자** → 단층 횡결합 포함.
- **PTCDA** (Eq. 7): `E_ads = ½ [E_PTCDA/Ag − (E_Ag + E_PTCDA)]`, E_PTCDA = **주기경계 PTCDA 단층** → 횡결합 제외 = 단층|Ag 계면의 (미이완) 분리에너지.
- **그래핀** (Eq. 8): `E_ads = [E_Gr/Ag − (E_Ag + E_Gr)] / N_C`. ⚠ **E_Gr 가 2.54 Å 변형 시트인지 2.46 Å 평형 시트인지 미기재.**
- Xe · PTCDA 는 *"모든 항이 미이완계"* 라고 명시 (p. 5, p. 8). 그래핀은 기하를 최적화했다고 적었으나 참조 상태의 이완 여부는 불명.

### 진동수 (p. 6–7)
`E_ads(d) = α₁ e^(−α₂ d) − C₃ / (d − Z₀)³ + E_ML` (Eq. 5) 로 각 결합곡선을 맞추고, 최소점 곡률 k_e 에서 `E_vib = ħ √(k_e / m_Xe)`. E_ML ≈ 단층 형성에너지.

### 분극률 (p. 7)
`Δᾱ⁰(∥/⊥) = ᾱ⁰_Sys − (ᾱ⁰_Ag + ᾱ⁰_Xe)` (Eq. 6) — 전체계 분극률에서 두 부분(주기경계 Xe 단층, 깨끗한 슬랩)의 합을 뺀 차. 대칭상 평행 두 성분이 같다.

## 5. 결과 — 섹션별 상세 (그림 실독 포함)

### 5.1 MBD 방법 (Sec. II, p. 3–5)
- 출발점: ACFDT 상관에너지 (Eq. 1) + Dyson 형 차폐식 χ_λ = χ₀ + χ₀(λv + f_xc)χ_λ (Eq. 2). RPA 는 f_xc = 0.
- 착상: χ₀ 를 **원자마다 하나의 3차원 QHO(Drude 입자)** 응답의 곱으로 근사한다 → 결합된 QHO 계의 상관에너지를 쌍극자 근사 안에서 **정확히** 푼다.
  상관에너지 = 상호작용 QHO 와 비상호작용 QHO 의 **영점에너지 차**. 이는 **같은 QHO 집합의 RPA-ACFDT 상관에너지와 동등**하다 (p. 4, ref 55).
- QHO 파라미터: `α_p(iω) = α_p[n] / (1 + (ω/ω_p[n])²)` (Eq. 3), TS 방식으로 DFT 밀도에서 뽑는다 → 혼성 · 단거리 XC 효과가 들어간다.
  단거리는 가우시안 전하 쌍의 쿨롱으로 재규격화 (ᾱ_p, ω̄_p). DFT 와 이중계산을 막는 **range-separation 매개변수 β 하나**를 범함수별로 한 번 맞춘다 (정답셋에 거의 무관하다고 저자는 말한다).
- 초기 χ₀ 는 국소지만 결과 응답은 **완전 비편재** → pairwise 보다 금속의 비국소 응답에 가깝다 (p. 5).
- 금속용 조정: QHO 는 갭이 있어 금속 응답을 정확히 못 준다 → **vdW^surf 의 재규격화 "atom-in-a-bulk" 파라미터로 초기 QHO 를 매개변수화** (p. 5).
  ⇒ 이 논문의 MBD 는 **차폐된 Ag 파라미터 위에 얹은 다체 결합**이다 (세 줄 경고 ①).
- 구현: FHI-aims · VASP · Quantum ESPRESSO · CASTEP · ADF + 독립 코드 (p. 4, ref 62).

### 5.2 Xe / Ag(111) — 분산이 주인 계 (Sec. III.A, p. 5–7, `Fig. 1` `Fig. 2`)

  두 곡선 간격은 최저점 ≈ 0.046 → 5.6 Å 에서 ≈ 0.013 eV 로 줄지만 0 은 아니다 → *"다체 효과가 ~5 Å 넘어서도 남는다"* (p. 6) 와 일치.

  저자는 RPA 쪽이 f_xc 무시 · plasmon-pole 근사 · 기판과 흡착물 응답을 따로 계산한 점 때문에 감소를 과대평가했을 수 있다고 본다 (p. 6).
- 진동: 실험 2.8 meV 에 MBD 가 더 가깝다 (3.0 / 3.3 vs 3.8 / 4.0 meV) (p. 7).
- **`Fig. 2` 실독**: y = Δᾱ⁰ (bohr³) −2.0–4.0, x = 3.0–8.0 Å, HSE+MBD. 빨강(⊥)은 3.1 Å 에서 **figure-read ≈ +3.95 bohr³** → 5.5 Å 부근 0, 파랑(∥)은 3.1 Å 에서 **≈ −1.8 bohr³** → 4.5 Å 부근 0.
  평형(≈ 3.57 Å) 에서 ⊥ ≈ +1.4 · ∥ ≈ −0.5 bohr³ (figure-read). 4.6–5.1 Å 에서 두 성분이 다 **약간 양수 (≈ +0.07–0.12, figure-read)** 인데 본문은 이 작은 부호 전환을 언급하지 않는다 (사소).
  본문 서술(평행 감소 · 수직 증가, 4.5 Å 아래에서 결합, 7.5 Å 넘으면 0)과 일치.

### 5.3 PTCDA / Ag(111) — 공유 + 분산 (Sec. III.B, p. 7–9, `Fig. 3` `Fig. 4`)
- PTCDA = 무수물 머리 2 + 방향족 골격. Ag(111) 위 **조밀 herringbone**, 말단 O 는 공유결합, 골격은 분산으로 붙는다 (p. 7).
- 기존 pairwise · RPA 모두 E_ads 가 실험 추정의 상단 쪽이다. vdW^surf 는 금속 차폐를 넣었는데도 과결합하고, **차폐를 빼면 (azobenzene/Ag(111) 사례, ref 31) 에너지 · 높이 과대가 더 커진다** (p. 8).
  남은 편차의 원인 후보 = 다체 분산 부재 + 반국소 교환.
- MBD: E_ads 2.50 → 1.77 eV, 높이 2.89 → 2.94 Å. 고차 상관과 분자간 분극이 r⁻⁶ 쌍 분산을 상쇄한다 (p. 8).
- **`Fig. 4` 실독**: x = 2.0–6.5 Å, y = −3.0–1.0 eV, PBE+vdW^surf 파랑 · PBE+MBD 초록, 곡선당 계산점 ~14개 (2.36–6.36 Å, figure-read).
  파랑 최저 **figure-read ≈ −2.50 eV @ ~2.87 Å**, 초록 **≈ −1.77 eV @ 2.9–3.0 Å** → Table II 와 일치.
  2.36 Å 에서 파랑 ≈ +0.25 · 초록 ≈ +0.62 eV (둘 다 반발 영역). 두 곡선 차는 최저점 ≈ 0.73 eV → 2.36 Å 에서 ≈ 0.37 eV 로 준다 (본문: *"range-separation 길이에 다가가면 다체 기여가 작아진다"*).
  먼 쪽은 5.35 Å ≈ 0.05 · 6.35 Å ≈ 0.02 eV (figure-read) → 본문 *"~6.0 Å 넘어서야 두 곡선이 붙는다"* 와 일치.
  초록 우물이 넓고 곡률이 작다 → 진동수 감소 · 비조화 증가 (p. 8).
- **`Fig. 3` 실독**: 회색 Ag 위 PTCDA (검정 C · 빨강 O · 흰 H). 점선 셀 안에 분자 하나가 온전히 있고 모서리에 회전된 두 번째 분자 — herringbone 2분자 셀. 모식도라 높이 정보는 없다.
- 다른 방법과 비교 (p. 9): RPA · vdW-DF 보다 **작은 E_ads · 작은 평형거리**. vdW-DF 계열의 높이 과대는 알려진 문제이고 vdW-DF-cx 에서 일부 해소됐다.
  MBD 높이는 실험의 0.1 Å 안. HSE 와 결합하면 Xe 처럼 −0.07 Å 개선을 기대한다 (p. 9).
- 한계 자인 (p. 9): 평면 PTCDA 단층 · 미이완 슬랩이다. 완전 이완하면 분자 뒤틀림으로 높이가 더 좋아질 것이다.

### 5.4 그래핀 / Ag(111) — 확장 나노구조 (Sec. III.C, p. 9–11, `Fig. 5` `Fig. 6` `Fig. 7`)
- 탄소 나노구조는 **분극 응답이 크게 비편재 · 집단적**이라 유효 C6 가 탄소 물질마다 크게 다르다 (ref 88) → 차폐와 다체 기여가 클 것으로 예상 (p. 9).
- 셀 선택 이유: 다른 연구(refs 20, 89)와의 비교 + 계산량 (p. 9). 셀이 작아서 표면 요철로 인한 그래핀 buckling 은 크지 않다.
- 결과: vdW^surf 72 → **MBD 45 meV/C** (본문 *"over 38 %"*), 높이 3.05 → **3.23 Å** (+0.18). Xe · PTCDA 보다 높이 변화가 **크다** — 금속–그래핀 다체 효과가 분산을 강하게 차폐하기 때문 (p. 9).
- **흑연 층간 대조** (p. 9): PBE+MBD 흑연 층간 결합 **48 meV/C** (ref 39) ≈ 45 → *"나노구조 탄소의 다체 효과 기술이 일관적"*.
- **`Fig. 5` 실독**: 주황 C 벌집 + 회색 Ag 구 (큰 것 = 최상층). 점선 평행사변형 = 그래핀 2×2 = Ag (√3×√3)R30° 셀.
  점선 윗변이 같은 줄의 C 3개(양끝 + 가운데)를 지나므로 **그래핀 격자상수 2개 = √3 × Ag 최근접거리** 임을 그림으로 확인했다. 셀 안 탄소 8개. registry 는 이 한 배치뿐이다.
  (⚠ `figures.json` 의 캡션이 *"…in a"* 에서 잘렸다 — 원문은 *"in a √3×√3 surface unit cell"*.)
- **`Fig. 6` 실독**: (a)(b) 평면도 = 측방 모드, 파랑 화살표가 면내이고 고립(a)과 흡착(b)이 **거의 같다**. (c)(d) 측면도 = 수직 모드, 고립(c)은 화살표가 **거의 순수 수직**인데 흡착(d)은 **기울고 불균일**하다

- 모드 에너지 (p. 10): 측방 모드 −1.7 meV, 수직 모드가 분산에너지에 ~32 meV → 분산의 주 기여 모드를 짚을 수 있다.

  오른쪽: 깨끗한 Ag(111)(초록)은 ≈ 12.3 eV 부터 시작하는데 흡착계의 Ag pDOS(자홍)는 **≈ 10–11.6 eV** 에 새 봉우리 (본문 *"~11.5 eV"*) → 혼성으로 기판 모드가 아래로 이동. 본문과 일치.

- 다른 방법 대비 (p. 10–11, `Table III`): vdW^surf 는 비국소 범함수 · RPA 보다 E 가 크고 높이가 작다. MBD 는 optB86b-vdW-DF 와 **같은 범위**다.

  *"방법 간 남은 산포는 과제이고 실험 기준값이 필요하다"* (p. 11).

### 5.5 결론 (Sec. IV, p. 11–12)
- Xe: 결합세기 변화는 작지만, 계 크기와 pairwise 법 개발에서 영족원소가 한 역할을 생각하면 의미 있다. 가장 흥미로운 것은 분극률 텐서의 **강한 이방화**.
- PTCDA · 그래핀: 과결합 20 · 27 meV/원자 감소, **29 % · 25 %**, 높이 +0.1 · +0.2 Å (⚠ §10-1).
- 남은 과제: MBD 가 **KS 퍼텐셜에 되먹임되지 않는다** → 흡착물 준위의 Fermi 준위 정렬은 여전히 반국소 수준이고, 자기상호작용 오차와 공유결합 같은 단거리 문제는 남는다.
  쌍극자 대신 감쇠 쿨롱, 원자당 QHO 여러 개로 확장하면 체계적으로 개선할 수 있다.
- 요지: 분자 · 유한갭 물질용으로 만든 MBD 가 국소 QHO 에서 출발했는데도 상호작용으로 비편재 응답을 만들어 금속 흡착을 개선한다.

## 6. 논증 흐름 / 메커니즘 종합

1. 금속 흡착 = 금속의 비편재 상태(정적 상관) + 흡착물–기판 장거리 요동(동적 상관). 반국소 DFT 는 앞의 것, 파동함수법은 뒤의 것에 강하다.
2. pairwise 분산은 금속 흡착을 과결합한다 → 원인은 기판 내 다체 상관 + 쿨롱 차폐.
3. 차폐는 vdW^surf 가 C6 재규격화로 **pairwise 안에** 넣었다 → 기하는 좋아졌지만 에너지 과결합이 남는다.
4. 남은 것 = **다체(pairwise 너머)** → MBD@vdW^surf 로 넣는다.
5. 결과: 분산 우세 계(Xe)는 작게, 공유 + 분산(PTCDA)은 중간, 비편재 확장계(그래핀)는 크게 줄어든다. 높이는 전부 늘고 우물은 넓어진다.
6. 분극률 · 고유모드로 *왜* 줄어드는지 해석한다 (수직 분극 증가 → 차폐, 흡착물–기판 혼성 모드).

**(b) 허용 폭 — 두 종류를 섞지 않는다**

  ⇒ **계획의 수치 문턱보다 한 자릿수 크다.** 헤드라인은 *"PBE+D3(BJ) 에서의 W"* 로 **모델 조건부**여야 하고, 모델 불확도는 별도 줄로 적는다 (수치 문턱으로 흡수할 수 없다).
- 🔴 **"저/고 접착 구간" 경계 0.3 J/m² 가 방법 산포 한가운데 있다.** 분산 포함 7개 중 **5개가 0.3 위**이고, MBD (0.26) · vdW-DF (0.19) 는 아래다.
  ⇒ Ag|흑연을 *"저 접착 구간"* 으로 부를지가 **분산 모델에 달려 있다.** 구간 라벨에도 방법을 붙인다. 계획이 이미 *"0.3 / 1 은 구간이지 기전 판정이 아니다"* 라고 적었으니 여기에 *"경계 근처면 모델 의존"* 을 더한다.
  자릿수(≲ 0.5 vs ≳ 1 J/m²) 판정은 모든 방법에서 같다 — **DEM 의 자릿수 목표에는 영향이 없다.**

**(c) 분산 모델 민감도 — pairwise D3 vs vdW^surf vs MBD**
- 이 논문에 **D3 수치는 0건**이다 (세 줄 경고 ②). 비교는 §6 사다리의 ②→③ 칸뿐이다:
  vdW^surf → MBD 에서 **−23 % (Xe) · −29 % (PTCDA) · −37.5 % (그래핀)**, 높이 **+0.05 ~ +0.18 Å**, 우물 폭 증가 (Xe E_vib **−21 % PBE · −17.5 % HSE**).
- 금속 차폐 자체(①→②)는 수치가 없다. 정성 서술만 있다: *"차폐를 빼면 과대가 더 커진다"* (p. 8, azobenzene).
  ⇒ **D3(BJ) 는 ①에 가깝다 — 이 논문의 논리를 따르면 vdW^surf 보다도 과결합 쪽일 위험**이 있다. 크기는 모른다.
- **비교가 되려면 더 돌릴 것** (전부 작은 계):
  1. **그래핀 2×2 / Ag(111) (√3×√3)R30°, PBE+D3(BJ)** — 이 논문과 **같은 기하**: Ag 6층, a_Ag 4.14 Å (그래핀 2.535 Å), 최하층 고정 이완, d = C 평균 − 첫 기판층, E_ads/N_C (Eq. 8), 참조 그래핀 = **같은 변형 격자** 명시.

### 7-3. SDCP/PTFE 흡착 (C-12) — 다체 보정의 부호 · 크기 ★

⛔ 이 분해를 기전 주장으로 쓰지 않는다 (원장 금지 조항). ⛔ 이 값들을 이 논문의 결합에너지와 같은 표에 두지 않는다 (C-12 사전등록 금지 조항).

1. **부호 — 일관된다.** 이 논문 세 계 모두 pairwise → 다체에서 **결합이 줄고 높이가 는다.** 우리 브리프 §3-5 의 D4 → D4+ATM (3체 선두항) 교체도 같은 부호다 (PTFE −0.75 → −0.66 eV, **−12 %**).
   ⇒ *"pairwise D3(zero) 의 −0.79 는 다체 효과를 넣으면 작아지는 쪽"* 이라는 방향은 두 근거가 같다.
2. **크기 — 옮기면 안 된다는 증거가 이 논문 안에 있다.**
   - 원자당 감소 (20 · 27 meV/원자, p. 11) 를 옮기면 PTFE 32원자 × = **0.64–0.86 eV** — PTFE 의 D3 항 전체 (−0.823, 원자당 ~26 meV) 를 **지운다.** 말이 안 된다 → 원자당 이식은 무효.
   - 비율 (−23 ~ −38 %) 은 **금속 + 차폐 파라미터 위** 값이다. ATM (선두 3체만) 의 −12 % 보다 2–3배 크지만, 그 차이가 "ATM 이 부족해서" 인지 "금속이라서" 인지 이 논문으로는 **가를 수 없다.**
3. **시나리오** (⚠ 가정 — 인용 · 원장 등록 금지. C-12 의 지위를 그대로 물려받는다). 분산항만 이 논문의 감소율만큼 줄인다고 가정하면 (요약자 계산, 전자항 PTFE +0.032 · SDCP −0.388 고정):

   | 분산항 감소율 f | PTFE (eV) | SDCP (eV) | D (eV) |
   |---|---|---|---|
   | 0 (D3 zero 그대로) | −0.791 | −0.955 | −0.164 |
   | 0.227 (Xe 비율) | −0.604 | −0.826 | −0.222 |
   | 0.375 (그래핀 비율) | −0.482 | −0.742 | −0.260 |

   - **PTFE 크기**: 금속 수준의 다체 감소를 가정해도 **−0.48 ~ −0.60 eV** 다 — Kang 2025 의 −0.09 eV 와는 여전히 자릿수가 다르다.
     ⇒ 브리프의 *"PTFE −0.79 는 계산 실수가 아니라 분산이 모은 크기"* 는 **다체 보정 아래서도 자릿수로는 유지**되고, 절대값은 **~0.3 eV 모델 의존**이다.
   - **D 방향**: 같은 비율이면 D 가 오히려 **더 음수**다 (분산이 PTFE 쪽을 더 돕기 때문). 이 논문의 비율 폭 (0.227–0.375) 을 **가장 불리하게 엇갈려** 줘도 (SDCP 0.375 · PTFE 0.227) **D ≈ −0.14 eV**.
     D = 0 이 되려면 **SDCP 의 분산만 29 % 줄고 PTFE 는 0 %** 여야 한다 — 이 논문의 흡착물 간 폭 (15 %p) 보다 크다.
4. **실제로 재려면**: MBD 는 VASP · QE 에 구현돼 있다 (p. 4). 같은 C-12 기하(UMA 이완 · DFT 단일점)에서 **MBD 단일점 교체**가 가장 싸다.

## 10. 비판 — 이 논문의 약한 곳 ★

### 10-1. 결론이 자기 표와 어긋난다 (두 곳)
- 그래핀 감소율: `Table III` (72 → 45) = **37.5 %**, 본문 p. 9 *"over 38 %"*, 결론 p. 11 *"~25 %"*. 세 수가 다 다르다. 원자당 27 meV 는 표와 맞는다.
- PTCDA 높이 증가: `Table II` (2.89 → 2.94) = **+0.05 Å** 인데 결론은 *"about 0.1 Å"*. (그래핀 +0.18 → "0.2" 는 맞다.)
- ⇒ **인용은 표에서** 한다. 결론 문장을 그대로 옮기지 않는다.

### 10-2. 실험 기준이 약하다
- 그래핀/Ag(111): 실험 **0** → 이 계에서는 45 가 72 보다 "맞다" 는 근거가 없다. 다른 계산법 사이의 위치 비교뿐이다.
- PTCDA: E_ads 실험이 없다 → **1.4–2.1 eV 는 저자 추정**이다. 추정 사슬의 "33–66 %" 에서 상한 66 % 는 인용된 두 Au(111) 쌍에서 재현이 안 된다 (2.0/1.5 = 1.33 · 2.6/1.7 = 1.53, 요약자 계산).
  상한을 53 % 로 두면 범위는 ≈ 1.4–1.9 eV 가 되고, MBD 1.77 은 여전히 그 안이다.
- 에너지 · 높이 · 진동 실험이 다 있는 계는 Xe 뿐이다.

### 10-3. 기하 처리가 계마다 다르다
- Xe · PTCDA = 강체 미이완 스캔, 그래핀 = 최적화. PTCDA 완전 이완은 결합을 **+0.36 eV (+14 %)** 바꾼다 (p. 9) — MBD 감소 (−0.73 eV) 의 절반 크기라 무시할 양이 아니다.
- registry 스캔이 없다 (세 계 모두 한 배치).
- 그래핀의 k 점 · 진공이 미기재다. 참조 그래핀 격자 (Eq. 8 의 E_Gr) 도 미기재다.
- 본문은 2.54 / 2.46 Å 를 *"intramolecular carbon bonds"* 라 부르지만 이것은 **격자상수**다 (C–C 결합은 ~1.42 Å, 일반 지식).

### 10-4. "MBD 의 개선" 이 무엇에 대한 개선인가
- MBD 는 **vdW^surf 파라미터에서 출발**한다 — 개선은 "차폐 pairwise → 다체" 한 칸이다. 순수 TS 나 D3 대비가 아니다.
- β 는 분자 데이터셋 (유한 갭) 에 맞춘 값을 금속 흡착에 그대로 썼다. 금속용 검증은 이 세 계뿐이다.
- MBD 가 KS 퍼텐셜에 되먹임되지 않는다 (저자 인정) → 전하 이동 · 준위 정렬이 있는 계 (PTCDA 의 O–Ag) 에서는 한계가 있다.

### 10-5. 방법 산포 서술이 느슨하다
- `Table III` 의 다른 행은 **다른 논문 · 다른 코드 · 다른 격자**다. 한 표에 놓고 "같은 범위" 라 말하는 것은 느슨하다.
- (cRPA+EXX) 78 meV/C 에 대한 수렴 비판은 저자의 추측이다 — 검증 계산이 없다.

## 11. 적용 인사이트 (우리 연구에 어떻게)
1. **Ag|흑연 W 는 "PBE+D3(BJ) 조건부" 로 라벨한다.** 분산 모델 폭 (0.16–0.26 J/m²) 이 수치 문턱 (0.01–0.10) 보다 한 자릿수 크다 — 모델 불확도를 수치 수렴으로 가리지 않는다.
2. **Xe/Ag(111) 19원자 대조 잡**을 흑연 대조 옆에 둔다 — 이 논문이 가리키는 유일한 실험 발판이고, 계획의 Ag 쪽 D3(BJ) 가 실험 대비 어느 쪽으로 치우치는지 알려 준다.
3. **그래핀 2×2 / Ag(111) (√3×√3)R30° 26원자 D3(BJ)** 로 `Table III` 에 우리 방법을 한 행 추가한다 — 문헌 산포 안에서 우리 위치가 정해진다.
4. **0.3 J/m² 구간 경계는 Ag|흑연에서 모델 의존**이다 — 구간 라벨에 방법을 붙인다.
5. **Ag|C 와 C|C 의 비가 1 근처** (MBD 0.94) — DEM 이 "어디가 먼저 끊기나" 를 물으면 한 방법 안의 비로만 답한다.
6. **PTFE C-12**: 다체 보정은 **|E_ads| 를 줄이는 쪽**이고 D 의 방향은 오히려 강화한다. 절대 크기는 ~0.3 eV 모델 의존이다. QE 의 ATM 기본값을 확인한다.

- 문헌 수치는 **소환값**이다 — 우리 db 절대값과 같은 표에 두지 않는다. 특히 C-12 E_ads (고정기하 · 한 자세 · 게이트 미통과) 를 이 논문의 결합에너지 옆에 두지 않는다 (C-12 원장 금지 조항).

## 14. 기법 용어 미니사전
- **pairwise 분산 (DFT-D, TS)**: 원자쌍마다 −C6/r⁶ (감쇠 포함) 을 더한다. 3체 이상은 없다.
- **TS (Tkatchenko–Scheffler)**: C6 · α 를 DFT 밀도에서 원자 환경에 맞게 뽑는 pairwise (Hirshfeld 부피 — 일반 지식).
- **vdW^surf**: TS + 금속 기판 원자의 C6 · α · R_vdW 를 기판 유전응답 (Zaremba–Kohn) 으로 **차폐 재규격화**. 여전히 pairwise.
- **MBD (many-body dispersion)**: 원자마다 QHO 하나, 쌍극자–쌍극자로 결합된 전체계의 영점에너지 차를 **정확히** 푼다 → 모든 차수의 다체 항 + 차폐 + 이방성. 같은 QHO 계의 RPA 와 동등.
- **ATM (Axilrod–Teller–Muto)**: 3체 분산의 선두항. D3 · D4 에 선택적으로 붙는다. MBD 를 결합 세기로 전개했을 때의 3차 항에 해당한다 (일반 지식).
- **range-separation β**: DFT (단거리) 와 MBD (장거리) 의 이중계산을 막는 감쇠 길이 계수. 범함수마다 한 번 맞춘다.
- **ACFDT**: 응답함수로 상관에너지를 쓰는 정확한 식 (Eq. 1). RPA 는 f_xc 를 0 으로 둔 근사.
- **QHO / Drude 입자**: 전자 구름을 조화진동자로 본 모형 — 분극률 α 와 특성진동수 ω 로 정해진다.
- **XSW (X-ray standing wave)**: 기판 브래그 반사로 만든 정상파로 흡착 원자의 높이를 원소별로 재는 실험 (PTCDA 2.86 ± 0.01 Å).
- **TPD**: 온도 프로그램 탈착 — 탈착 온도에서 흡착에너지를 추정한다.
- **cRPA+EXX**: RPA 상관 + 정확 교환. 이 논문에서는 문헌값으로만 나온다.
- **E_ML**: Eq. 5 의 상수 — 단층 형성에너지 근사.
