# F16의 세 입자 접촉 중단 판독

설정 ①의 F16 개발 팔은 4,802걸음을 기록하고 4,803걸음의 노드 16810에서 중단했다. 이 노드에는 입자 세 개와 접촉 후보 세 쌍이 있었다. 질량 최댓값/최솟값은 6,469.30이었다. 허용오차는 속도 단위 1.7582883733092162e-12다.

| 확인 | 결과 |
|---|---|
| 원 반복 512회에서 멈춘 충격량 | 잔차/허용치 2.11531694e7. 같은 이진64 입력을 십진 70자리로 평가해도 같은 크기 |
| 독립 보존 노드 탐침 | 세 쌍의 면 후보를 직접 열거. 원 판정식과 운동에너지 한계를 만족하는 해를 정해진 순서의 34번째 면에서 찾음 |
| 중단 원인 | 추정 [고착, 음의 접선 한계, 음의 접선 한계]에서 [양의 접선 한계, 열림, 고착]으로 세 쌍을 동시에 바꿔야 발견되는 해. 세 입자의 기존 검색은 두 쌍 변경과 순수 해제만 포함 |
| 수정 후보 | 최후의 혼합 변경 검색을 세 입자에도 적용. 이전 38개 뒤 11개를 더 검사한 49번째에서 해 발견. 후보 충격량의 원 잔차 2.77556e-17, 독립 십진 70자리 6.98298e-18, 운동에너지 한계 충족 |
| 번호·저장 순서 | 입자 ID 6순열 × 저장 정·역에서 복원한 물체별 속도 비트 일치 |
| 면 검색의 범위 | 세 입자 마찰 64면·무마찰 8면, 네 입자 마찰 4,096면·무마찰 64면 무중복. 다섯 입자는 기존 436면·56면과 동일. 특이 선형계는 면별 최소제곱 대표 하나를 검사 |
| 회귀 | 4,803걸음 회귀 6개에서 수정 전 3실패·오류 0 → 수정 후 6/6. 기존 145걸음 6/6, 228걸음 5/5, 고착·미끄러짐 15/15는 별도 집합 |

단일 노드 해가 존재한다. 이번 중단을 재료의 변형 불능이나 F16의 물리적 불안정으로 해석할 근거는 없다. 수정 뒤 전체 F16 하중 경로와 F8/F16 5% 비교는 미측정이다. 기존 F8의 출력은 앞선 커널 SHA에 귀속한다. 새 커널의 개발 비교는 같은 실행 소스로 완료한 F8 원 매핑과 F16을 결과 전 고정한 규칙에 따라 판독한다.

독립 계산은 고정된 `docs/reviews/suyoung_u6c_step145_20261122/analyze_stop_node.py`의 `look_for_witness`와 `evaluate_impulse`를 사용했다. 이 함수는 원래의 이진64 계수에서 가능한 면별 충격량을 구한 뒤, 충격량·Coulomb 판정 및 운동에너지 한계를 십진 70자리로 별도 계산한다. `docs/reviews/suyoung_u6c_node145_20261122/check_faces.py`로 풀이기가 실제 선택한 충격량도 같은 기준에 대조했다. 탐색 순서와 선형계 구성이 달라 34번째와 49번째는 각각 해당 탐침 안에서의 번호다. 필드 시간 전진은 0회다.
