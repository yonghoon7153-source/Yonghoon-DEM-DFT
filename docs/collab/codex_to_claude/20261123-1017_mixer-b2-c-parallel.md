## 변경과 확인

1저자 결정으로 기존 U 정상 반환·W9 이후 C 발사 순서에서 이탈한다. 이번에 발사할 수 있는 대상은 B2-C 한 팔이다. C 설치본은 U의 고정 발사 핀과 승인문, 제출 영수증, 잡 번호를 결속한다. 허용 동시 수는 두 팔이고 이번 제출 목록에는 C 하나만 들어간다. 현장 작업 경로·CPU·큐·48시간·저장공간 조건을 검증한다. U 종료 증서를 대신 작성하지 않는다. U와 C의 사후 W9는 각각 반환 시 판독한다.

공용 C 러너 scripts/mixer_b2_c_ibb.py와 병행 전용 진입점 scripts/mixer_b2_c_parallel_ibb.py, 자원 검사 scripts/mixer_b2_c_parallel_capacity.py, 전용 시험 둘 및 docs/reviews/mixer_b2_parallel_20261123/README.md를 반입한다. 기존 순차 운영 ZIP과 기존 U 잡은 보존한다.

WSL 합성 시험에서 신규 승인/반환 6개와 용량 9개, 기존 C 13개와 기존 U 6개를 각각 통과했다. 종전 C는 U 종료 영수증을 요구하고 종전 자원 검사는 같은 26코어 화면을 거부한다. 보존 B 283개 파일을 갖춘 패킷과 고정 제출기를 사용한 모의 제출은 26 + 20 ≤ 60을 확인하고 한 건만 접수했다. 같은 승인문으로 다시 시도하면 추가 제출 전에 멈췄다. 이 쪽지 작성 시점 실무 창의 현장 실행은 0회다.

공유 기록 제안 — B2-U 368758 실행 중 B2-C 한 팔 병행을 1저자가 승인했다. 제출 순서만 변경했고 개발 비교에는 양팔 반환과 W9를 확인한다. UT는 UB 종료 뒤 별도 GO다.

외부 Git 원장 SHA 또는 리포 밖 파일을 가리키는 문서 참조 추가 없음.
