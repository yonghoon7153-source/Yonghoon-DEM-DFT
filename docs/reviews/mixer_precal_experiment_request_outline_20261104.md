# 보정 전 믹싱 지도 → 실험 승인 요청 뼈대 (2026-11-04)

**결과0건. 미작성 결과 칸을 갖는 문서 뼈대이며 외부 발송·실험 신청·장비/시료/사람 배정은 하지 않았다.** 탐색안은 `docs/reviews/mixer_precal_exploration_registration_draft_20261104.md`다. 실제 실험 승인은 1저자가 요청한다.

## 1. 승인 요청의 질문

“모델의 SE–SE 절대 응집 세기와 γ_A/γ_S의 어느 조건에서 군집·부착이 달라지는가, 우리 분말이 그중 어디에 놓이는지 가를 최소 관측은 무엇인가?” 현재는 지도 결과가 없어 차이가 난 조건·최적 조건·요청 시료 수를 채우지 않는다.

| 지도에서 나중에 채울 것 | 요청서에 붙일 증거 |
|---|---|
| 평가한 모든 B×r×U/C 및 실패/미평가 칸 | 덱/물성 가정/출력/판독기 핀과 해시, 원값·해상도·QC·정착 상태, 탐색 선택 이력 |
| 관측이 갈리는 표본 조건·갈리지 않는 조건 | 단일 seed 개발 대비와 불확실성 한정. 격자 사이 상도·유의성·실물 효과 크기로 확대하지 않음 |
| 모델 자격 밖/비식별 영역 | 계약 실패, 미지원 판독, 두 축/벽/마찰 교락. 실험이 기존 모형을 지지하지 않을 가능성도 명시 |

## 2. 우리 위치를 가를 관측과 범위

| 목적 | 관측·요청 범위 | 한계와 시점 |
|---|---|---|
| B축(절대 응집 수준) | SE 단독 **T1 Hausner 비 + T2 동적 안식각**. 지도 후보 B의 모델 응답을 가르는 분해능·반복 설계가 필요. 실제 각도/밀도비 범위는 시험 기하·예측 곡선 전에는 미정. | 기존 D3 S1 SOP 동결/열람 절차 그대로. 혼합 지도 값은 T1/T2 보정 곡선을 대신하지 않음. 지정한 벽·r·마찰·PSD 조건의 유한 Bo 후보 집합이며 물성 참값 한 점 아님. |
| r축(상대 접착) | 코팅 전후 NCM·SE의 **IGC 유효 표면 에너지**, 또는 AFM의 **NCM–SE / SE–SE 떼는 힘 비**와 NCM–NCM 대조. r 후보0.10–0.50 및 동일화 대리1을 가르는 범위를 목표로 검토. | 0.31/0.39는 모델 기하 비교값일 뿐 장비 합격선 아님. 힘비1의 양쪽을 실제 프로브 곡률·표면상태·하중/이력과 함께 분해해야 함. JKR/기하평균이 맞지 않으면 관측비를 γ 비로 강제 환산하지 않음. |
| 응답의 독립 검증 | 기존 D3 **T3 흐름 시간/정지**, 다른 속도 T2. 필요시 코팅/비코팅의 SE 분포 SEM-EDS·입도/응집체 크기를 짝지어 비교하는 후속 제안. | T3를 보정값에 맞추거나 정지를 임의 긴 시간으로 대체하지 않음. SEM-EDS는 2D 표본이며 DEM3D 접촉 군집과 직접 같은 양이 아님; 새 관측 계약 필요. |
| 벽·표면의 교락 | 사용 벽 재료·거칠기·표면상태 기록, 필요시 별도 벽 접착/흐름 대조 | 현재 γ_W/γ_SE=0.0256r는 조건부 가정. SE 단독 시험이라고 r/벽과 독립이라 부르지 않음. |

D3만으로 두 축을 동시에 유일하게 식별한다고 약속하지 않는다. IGC/AFM/DFT가 준비되지 않으면 r별 조건부 Bo 후보를 유지하고 “우리 위치”를 범위/집합 또는 미식별로 보고한다. 지도와 실측이 안 맞으면 맞는 후보만 남기거나 마찰·벽을 사후 조정하지 않고 별도 새 분석·등록으로 남긴다.

## 3. 1저자 승인 단계에서 채울 칸

- 목적과 모델 분기: **지도 결과 대기**.
- 필요한 장비·분말 로트/상태·시료량·측정자·원자료 보관자·예산/일정: **미정, 지금 선정하지 않음**.
- 실제 관측 범위·분해능·반복/날 효과·실패/결측 기준: **측정 시작 전 S1 동결본에 구체화**. 기존 수용 SOP를 이번에 수정하지 않음.
- 보정/검증 자료 분리·보관/열람 권한·봉인/전달/열람 기록: **수용된 SOP와 NOTE01 준수**. 지도 열람 이력과 실측 열람 이력은 따로 기록.
- 승인할 다음 행위: 장비/시료 준비, 실측, DEM 보정, 확인 블록을 한 번의 포괄 GO로 묶지 않고 실제 요청 범위를 명시.

허용 요청 문장: “미보정 지도에서 이 모델 조건들의 예측이 갈렸다면, 우리 분말이 어느 조건과 양립하는지 가르기 위해 위 관측을 요청한다.” 지금은 조건부 뼈대만 있으며 갈렸다는 결과나 실제 실험 승인을 기입하지 않는다. Rint② 우선 및 1저자의 발송·진행 순서를 유지한다.
