## 4. Q2 — grid_t와 실제 h_k를 분리하는 해석

**현재 읽기를 두 단계로 한정해 수용한다. N2 수정과 모순되지 않는다.**

1. 등록 탐색점 선택: v2 184행의 명목 ±τ 구간은 등록 정확 분수 식별값 `grid_t`로 선택한다 (`compat_individual:803`, `_read_unit:914`). 끝점 등록과 float 반올림으로 인한 우연한 탈락을 구분한다. 부속 A 213–218행의 float 변환·중복 제거·순회 규칙은 그대로다.
2. 주장 등급: 부속 B 65·74–77행대로 실제 저장 float 좌표에서 계산한 정확 h_k와 영역 잔차를 쓴다 (`compat_individual:805`, `_claim_grade:754–758`). 격자 식별이 구간 안이라는 이유로 실제 증인까지 exact_feasible로 올리지 않는다.

실제 h_k가 정확 경계를 넘지만 사전 수치 수용 한도 안이면 numerically_accepted다. 그런 증인만 받치는 양립은 B 81–88행의 `COMPATIBLE (수치 경계 의존)` + `UNRESOLVED` + `선형 제약 경계`를 유지한다. 수용 한도를 넘는 점을 이 해석으로 되살리지 않는다. τ=0도 같다.

따라서 grid_t는 등록 탐색점 식별, 실제 h_k는 증인과 주장의 투영값이다. 결과표에서 둘을 혼용하지 않는다. 반환점 clip/반올림, τ 확대, 배열 재생성, 결과에 맞춘 등록 변경을 허용하는 해석이 아니다. 부속 C도 이 수치·판정 규칙을 바꾸지 않는다.

- 실제 착수 경로가 신뢰한 MANIFEST SHA·P0·정확 배열 파일 집합과 실제 소비 바이트를 결속해야 한다. NPY+INDEX를 함께 바꾸는 경우도 적응 봉인·목적·optimizer 전에 거부하는 대조와 경로를 승인안에 고정한다. 과거 건조 결과나 INDEX 내부 해시만으로 다음 실행의 배열 인증을 대신하지 않는다. Sobol 재생성 요구가 아니다.
- H4가 도달 가능한 범위를 요청할 때에는 원시 교차·후보 탈락 이유·선택점·ΔJ·음성 D_abs/구간의 저장 계약을 먼저 정한다. C4-E에서 H4를 명시적으로 제외한다면 이 의무는 H4를 포함하는 후속 승인 경계에 남긴다.
- C4-E의 E3a 범위, 비용 측정의 용도, 조기 중지·reserve·단일 시간 원점, 시작/종료 HEAD와 작업 트리 파일 목록, lock/배열/P0 식별, 부분·중단 결과 보존, 최종 전달 시간 경계를 고정한다. C4-A는 E3a 완료 증거와 입력 계약, C4-B는 등록 탐색·최종 판독·배열 인증·중단 집계를 별도로 확인한다. E 승인을 A/B 포괄 승인으로 쓰지 않는다.

이번 결과에서 명시적으로 인계할 보고 정의는 `run_units ≠ 완료 단위`, UNFIT은 완료 단위에만, support와 전체 grades의 집계 차이, 등록 grid_t와 실제 h_k의 차이다. 기존 세 조건을 구체화하는 것으로, 추가 임의 시험이나 연구 leg를 새로 요구하는 것이 아니다.

ray 미구현/도달 중지, H4 gate, ν·seed·기존 배열 불변, 기존 실패·누락·승인 이탈 기록은 유지한다. 실제 실행 여부는 사용자가 다음 승인안을 보고 따로 결정한다.

## 7. 검토 방법과 인계

검토자는 제공된 코드·시험을 실행/import하지 않았고 Python·최적화·Sobol·COMSOL/JVM·설치·환경 재구축·REIL xlsx/pkl/노트북 개봉은 0회다. 읽기 전용 저장소 조회, 텍스트 검토, 자체 PowerShell 해시/JSON/텍스트 패치/회신 포장만 수행했다. 외부 메시지나 저장소 변경도 하지 않았다.

검토 도구 이력: 잘못된 소스 경로 한 건의 조회가 404여서 이전 파일 색인으로 경로를 바로잡았다. 자체 해시 감사 도구의 첫 호출은 PowerShell byte 배열 형식/ComputeHash overload 오류로 중지되어 도구 인수형만 정정한 뒤 바이트 감사를 완료했다. 분담 검토의 자체 조회에도 문법 오류 1회가 있어 조회식만 정정했다. 모두 수신 코드의 기능 실패나 대상 재시험이 아니며, 무오류 검토 수행으로 주장하지 않는다.

`CLAUDE_REPLY_KO.md`는 REIL C4-0b2 보완을 수행한 쪽에 전달할 짧은 회신, `DECISION.json`은 한정 판정과 비승인 경계다. `basis/`에는 이전 검토의 원문·판정·반례를 바이트 그대로 보존한다. 새 ZIP의 해시 봉인은 이번 검토자가 받은 자료와 회신의 무결성 확인이지 향후 실행 authorization 파일이 아니다. 여기서 검토를 마친다.
