## 2. 조성 축 — `pdd` 는 질량분율이다

`lhs00_110` 이 결정적이다: `rAM = rSE` 라 개수분율 = 부피분율인데 헤더는 `0.80/0.20`,
실측은 **둘 다 0.625/0.375**.  밀도(`ρ_AM 4800` · `ρ_SE 2000`)를 넣으면 0.625 가 정확히
나오고 3-type 교차검증도 1.5 % 안이다.

$$\varphi_{AM}=\frac{\rho_{SE}\,w}{\rho_{AM}-(\rho_{AM}-\rho_{SE})w},\qquad w = 1-\texttt{pdd\_SE}$$

⚠ **원자료 receipt 는 아직 없다** (Codex Q4).  두 케이스의 원 header·dump·type별 count 와
해시를 붙이는 것이 해제조건 ⑧ 이고, **제출 전에 닫는다.**

### 4-1. 1차 관측량 = **퍼콜레이션 여부** (이진)

미퍼콜은 축퇴가 아니라 **이 영역의 물리 그 자체**이고, Stage 22.5 에 없는 것이 문턱항이다.
⇒ 버리는 점이 없어 생존자 편향이 사라진다.

**`perc_i` 규약 (봉인)**:

| | |
|---|---|
| 그래프 | AM 입자 = 노드, **표면 간극 ≤ 0** 인 쌍 = 간선 (기존 코퍼스 접촉 정의와 동일) |
| 방향 | **z 만** (집전체↔분리막 축).  x·y 는 주기경계라 방향 정의가 다르다 |

### 4-2. 보고하는 추정량

1. **퍼콜레이션 곡선** `P(perc=1 | φ_AM)` — **Firth 벌점 로지스틱**(primary) ·
   일반 MLE **병기**.  **`φ_c ≡ P = 0.5`** 와 프로파일-우도 95 % 구간.
   ⚠ `0.5` 는 문턱의 **정의**(대칭점)라 자유도가 없다.
   ★ Firth 가 primary 인 이유: 0 과 1 이 다 관측돼도 **완전·준완전 분리**면 일반 MLE 가
   발산해 `φ_c = −a/b` 가 **존재하지 않는다**.  발산했을 때 무엇을 보고할지를 **결과를 보고**
   정하는 것을 막는다.  분리가 없으면 두 추정이 거의 같다.
2. **`σ_e(φ_AM)` 곡선** — 퍼콜된 케이스만, 기존 130점과 같은 축에 겹쳐 그린다.
3. **Stage 22.5 외삽 오차** `d = log10(σ̂/σ)`, `σ̂` 는 **계수 재적합 없이** 외삽.
   φ_AM 에 대해 **곡선으로** 보고한다 — 중앙값 하나로 접지 않는다.

### 4-3. 적합 corpus

**신규 64점이 primary.**  통합 194점은 **보조로 병기**한다.
★ 기존 130점은 nuisance 규약이 다르다 (`r_SE` 절단 규약 · 종류 균형이 이번과 다르다).
합치면 φ_AM 효과에 **배치 효과**가 섞인다.  상단 정보가 아까워 보조로 남기되, 둘이 다르면
**그 차이 자체를 보고**하고 어느 쪽도 사후에 고르지 않는다.

| 미완주 (큐·OOM·크래시) | 제외하되 **수와 사유를 보고**.  다른 이유로는 점을 빼지 않는다 |

### 4-5. 유한크기 — **influence sensitivity** (검증 아님)

`n_AM` 이 세 자릿수 넘게 벌어진다.  `rP` 6~7 µm 인 mono 점은 50 µm 상자에 3~4개 폭뿐이라
퍼콜 여부를 상자가 정할 수 있다.

⛔ **하한을 걸지 않는다** — 기존 130점도 `L/d ≈ 3.3` 까지 내려가므로, 확장에만 걸면 두 배치의
크기 영역이 달라져 φ_AM 효과와 유한크기 효과가 **교락**된다.

**둘 다 보고한다**: (i) 완주 전체 · (ii) `n_AM` 하위 **10 %** 제외.
빠지는 점은 **CSV 에 이미 확정돼 있다** (`--verify` 가 출력한다).
⚠ 실측 개수가 나와도 **절단 대상을 재정의하지 않는다** — 설계값 기준 하위 10 % 로 고정한다.
(v1 은 요청서가 "고정", 본문이 "실측 후 재정의" 라 충돌했다.  **고정**으로 정한다.)

⚠⚠ **이것을 "유한크기 검증" 이라 부르지 않는다** (Codex Q2).  절단 6점은 크기만 바꾸는 것이
아니라 morphology 혼합과 φ 지지구간을 **동시에** 바꾼다.  두 추정이 가깝다고 유한크기 오염이
작다고 판정할 수 **없다**.  진짜 검증은 같은 조성·같은 입자분포를 **여러 상자 크기**에서
반복하는 matched L-scaling 배치가 필요하고, 이 배치는 그것이 **아니다**.
