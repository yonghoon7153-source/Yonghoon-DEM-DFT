흑연 해석해가 네 시각 모두 관측과 맞는 것은 **이 짧은 구간에서 균일 유속 근사와 정합적**이라는 뜻이다 — 일정 D 는 소스에서 따로 확인되며, 네 시각의 일치만으로 반응 분포의 유일성이나 이후 전극 거동을 입증하지 않는다 (해석해 비교는 모델 내부 대조이지 실험 검증이 아니다) [R1]. 이 구간 전압 변화는 N Eeq 하락이 대부분이다 — 20→30 s 분해: −N Eeq +59.817 mV · P Eeq +0.181 · 과전압 차 −1.132 · 전해질 전위차 +1.201 · 합 +60.068 mV (검토자 산술). 어느 입력에 가장 민감한지는 추론이지 민감도 시험 결과가 아니다. 표면 x 1e-4 ≈ 6.27 mV 는 **현재 20→30 s 의 같은 선형 OCP 구간에서 다른 항을 고정했을 때의 국소 설명**이지 전역 환산식이 아니다 — ΔV 와 Δx 는 둘 다 독립 기준으로 유지하며, 어느 하나를 빼거나 바꾸지 않는다 [R5].

**② 장기 주장에서 보류할 곳 — 4.25 V CV → 0.01C → 휴지의 표 안 완주는 미입증이다** [R2]. 현 고정 재고 · OCP 의 표 안 균일 평형 상한은 **4.1855615 V** 다 (xP 0.2228930343 · xN 0.8976699175 · 298.15 K · 표 매듭 184 검사 — 검토자 산술 · §8-2 와 일치). 4.25 V 와의 64.44 mV 차에는 비균일 표면 조성의 평형전위 차와 기타 분극이 함께 관여하므로 특정 과전압 하나로 두지 않는다. 0.01C 는 0 전류가 아니고, 전류를 끈 뒤 단자 전압은 표 안 평형으로 이완할 수도 있다 — 그래서 평형 상한만으로 "CV 꼬리와 그 뒤 모든 휴지는 표 밖" 이라고 단정하지 않는다. **실제 경로 · 표면 범위와 종료 시 분극을 확인하기 전 휴지 구간의 장기 예측 주장을 보류한다.** 정전류를 계속 유지한다고 가정하면 양극 평균의 표 하한 도달은 ≈9.556 h, 균일 유속 준정상 근사의 표면 선행은 ≈66.7 s 다 — 가정의 산술이지 실제 도달 시각이나 안전 여유가 아니다. 과거 범위 실패 (preflight 에서 OCP 표면이 표 밖으로 나간 계산이 `Nonfinite` → job failed → `INCOMPLETE_RANGE_STOP` 로 끝남, §9-5) 와 OCP 외삽 금지는 유지하며, **외삽은 현재 허용 옵션이 아니다**. 결정 거리: (i) 실측 반쪽셀 OCP 확보 · 교체 (§3 M3 과 함께) (ii) 표 안 부분 충전 · 휴지의 별도 진단 설계 — (A) 주장을 먼저 볼 수 있다 · 실험 프로토콜과 다르다는 것을 이름에 드러낸다 (iii) Vmax 변경 (실험 0.1C_12h 프로토콜과 달라짐). 무엇도 우리가 고르지 않는다.

## 보충 (2026-09-30 · 60 s 준비본 검토 뒤) — 물리적 해석과 연장 때 관측량별 위험 징후

> 60 s 준비 단계의 `CLAUDE_UPDATE_KO.md` 요청 ("물리적 해석과 향후 연장 시 관측할 전압 · 전극 표면/평균 분율 · 전해질 극값 · Li 수지의 위험 징후") 에 대한 답이다. **새 허용치 · 자동 장기 GO 가 아니고 실행 승인도 아니다.** 저장소 기록은 `bms-balancing/docs/COMSOL_REBUILD_SPEC.md` §33-4 (커밋 `3cfd8b698`, 원문 불변) 와 §34 (정정표) 이고, 이 절도 §34 의 정정을 적용한 판이다 [R#]. handoff 작업자에게 갈 승인 문안 (`NEXT_CODEX_REPLY_KO.md`) 에는 우리가 더할 것이 없다.


아래 기대값과 징후는 **결과를 읽을 때의 판단 재료**다. 판정 기준은 33-1 의 불변 기준뿐이며, 여기 숫자로 PASS/FAIL 을 정하지 않는다. 이미 수용된 인계 · 입력 시험의 반복을 요구하지 않는다.

**① 물리적 해석 — 0–60 s 는 "흑연 OCP 가장자리에서 올라오는" 과도 구간이다.**

- **시작 상태**: 음극 평균 x 0.0117 · 평형 전압 2.165 V 로 **프로토콜 자신의 방전 하한 2.7 V 보다 깊다** (§8-3). 원본 모델의 시작 전압 3.0524 V 와도 다르다 — §3 M3 (라이브러리 OCP ↔ 적합에 쓴 반쪽셀 곡선) 과 같은 뿌리로 본다 (우리 해석). 실험의 시작 상태는 이 기록에 없어, 처음 수 분의 급한 전압 상승 (0–30 s 에 2.23 → 2.54 V) 에 대응하는 실험 구간이 있는지는 확정하지 않는다 — 실험 대조는 불일치를 찾는 데는 쓸 수 있고, 정량 예측 타당성은 별개다 [R2].
