## R2-2. Q2 — Claude 봉투 `1.07–1.11` **철회**.  세 이유 전부 확인

1. **격자가 다르다** — 소산분담 ~1 % 는 CL-41 **vox 0.125** 팔인데 그것을 **vox 0.15** 의 `R=1.1232` 에 얹었다.  같은 geometry 의 국소 기울기가 아니다.
2. **플레이트 항 누락** — 아래 R2-3.  보고된 분담이 총미분이 아니다.
3. **"σ 내리면 w 커진다" 는 정리가 아니다** — 병렬형 `G=a+bσ` 는 감소, 직렬형 `G=(a+b/σ)⁻¹` 은 증가.  옛 vox 0.4 스윕은 **그 geometry 의 관찰**일 뿐이다.

산술 재현 (`R' = 1.1232·3^(−w̄)`):

| 목표 R' | 필요 w̄ | 국소 1 % 의 |
|---|---:|---:|
| 1.11093 | 1.000 % | 1.0배 |
| **1.11** | 1.076 % | 1.1배 |
| **1.07** | **4.417 %** | **4.4배** ← 근거 없음 |

⇒ 1차 시나리오 **`R' = 1.11093`** 하나만 남고 그것도 봉투가 아니다.
**인용 가능한 것**: *"σ_SDCP 를 낮추면 R 은 비증가 (Rayleigh 단조성); 크기 미확정."*
닫는 법 = 최종 규약·같은 mask 에서 DBE 만 `σ_SDCP = {250, 144.338, 83.333}` (로그 중점 포함) + 250 부근 ±1 % 유한차분.  SBE 는 SDCP 가 없어 재실행 불요.

## R2-3. ★ 신규 — `phase_current_share` 가 **자기 docstring 의 항등식을 만족하지 않는다** (CDXR2-1)

Codex 가 플레이트 누락을 지적했고, Claude 가 그 위에 두 가지를 더했다:

**(i) docstring 자기모순.**  그 함수는 *"이 분담은 변분(포락선) 정리로 `w_a = ∂ln σ_eff/∂ln σ_a` 와 **같은 양**"* 이라고 **단언**한다.  포락선 정리가 그 항등식을 주려면 σ_a 에 비례하는 **모든** conductance 가 합에 들어가야 하는데, 솔버의 플레이트 커플링 `g = σ·vox²/max(dist, vox/2)` (`:549-564`) 이 σ 비례인데도 빠져 있다.

**(ii) 같은 결함의 2회차.**  Codex #7 (2026-08-12) 이 이미 **주기 seam 면쌍 누락**을 잡았다 — seam 지배 격자에서 소산의 **22.9 %** 가 통째로 사라졌었다.  실패 양식이 **동일**하다: σ 비례 conductance 를 합에서 빠뜨림.
⇒ 개별 수정이 아니라 **불변식**이 필요하다: 솔버가 L 에 넣는 모든 σ 비례 항이 분담 합에도 들어간다는 것을 **유한차분 대조 회귀**로 강제.

**영향**: CL-41 의 "SDCP 1 %" 는 미상 크기만큼 **과소**다.  2026-08-24 에 "인용 금지, CL-44 를 쓰라" 로 정정해 둔 것이 **한 겹 더** 정당화된다.

## R2-4. ★ 신규 — `--fibre-dia` 가 raster 에 **배선돼 있지 않다** (CDXR2-2)

argparse help 자신이 *"so the **viewer** renders thickness"* 라고 적어 뷰어 전용 설계임을 밝힌다.  raster 호출(`:1085-1095`)에 dia 인자가 **없고**, 실제 `np.load` 는 solve **뒤**(`:2040-2044`)이며 길이 불일치 시 경고 후 `dia=None` 으로 **조용히 계속**한다.

⇒ **S1 (a) 의 선행조건이 바뀐다**: "게이트 분리 + zero-DOF" 만으로 안 되고, **직경 소스를 solve 전으로 옮기고 hard-error 로 봉인**하는 것이 먼저다.
⇒ `capsule` 은 동작하는 enum 으로 두면 안 된다 — **예약값 + 선택 시 `unsupported_protocol` nonzero abort**.
