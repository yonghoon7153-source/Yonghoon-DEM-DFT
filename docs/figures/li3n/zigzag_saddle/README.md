# min → **계산된 saddle** → on-Li, 꺾인 7점 (3점 + 곡선 보간 4점)

`zigzag7/` 은 중간점을 on-Li 자리(Li 정중앙)로 썼는데, **계산된 saddle 은 그 Li 에서
0.50 Å 비껴 있다.** 그래서 렌더가 달라 보였다. 여기서는 중간점에 **계산된 saddle 좌표를
그대로** 넣는다.

| t | frac | |
|---|---|---|
| 0.0 | (0.887775, 0.120635, 0.446500) | ★ **min — 계산값** |
| 0.5 | (0.750001, 0.250006, 0.455211) | ★ **saddle — 계산값** |
| 1.0 | Li88 (0.8964, 0.4464) / Li44 (0.5541, 0.0875) | ★ on-Li |

| 파일 | 끼인각 | 곡선 길이 |
|---|---|---|
| `..._Li88_*` | **103°** | 4.64 Å |
| `..._Li44_*` | 100° | 4.70 Å |

3점 중 **2점이 계산값**이고 보간 4점만 기하(2차 Bézier, t=0/0.5/1 이 세 점을 정확히 통과).
평행이동 없음 — 원본 두 구조와 같은 시야. `_nobond_` 는 adatom 결합선 없는 버전.

## 참고

t=0.5 의 최근접 Li 가 1.69 Å 로 짧게 나오는데, 이는 **TS 의 adatom 좌표를 min 의 기판에**
얹었기 때문이다 (TS 자기 기판 기준으로는 2.22 Å). 한 장의 기판으로 두 배치를 함께 그리는
이상 생기는 차이이고, 렌더에서는 결합거리대의 겹침으로 보인다.
