# MCP 스킬 — 커넥터 · 플러그인 절 (초안 · 1저자 11-25)

> 1저자 11-25: "mcp skill 항목에 관련해서 다른 계정으로 할때 mcp 연결하라고 적어놔줘용".
> 커넥터 · 플러그인은 claude.ai **계정에 붙는다**. 다른 계정 (다른 사람 · 새 계정 · 다른 조직) 으로 일할 때는 일을 시작하기 전에 그 계정에서 아래를 먼저 연결 · 설치한다. 리포 · 가지를 옮겨도 따라오지 않는다.

## 연결 · 설치할 것
| 종류 | 이름 | 쓸 곳 | 주의 |
|---|---|---|---|
| 플러그인 | Research Desk | 참고문헌 실재 · 인용 뒷받침 확인 (규율 ⑥) · 논문 노트 · 비교 · 비평 · 관련 연구 초안 | 로컬 `reference-lookup` 만 쓴다 · `reference-lookup-hosted` (research-desk-checker.fly.dev) 는 연결하지 않는다 (참고문헌 목록 · 원고 문장이 외부 서버로) · litdb 정본 카드가 우선 |
| 플러그인 | watch-video | 영상을 장면 그림 · 받아쓰기로 (AVI 레퍼런스 영상 · 장면 점검) | 로컬에서 돈다 · URL 받기는 환경에 따라 막힐 수 있음 |
| 커넥터 | Gmail · Notion | 메일 · 노트 (지금 연결됨) | — |
| 커넥터 | Google Drive | 파일 주고받기 (다운로드 폴더 대신) | 미공개 자료 폴더 권한 확인 |

| 커넥터 | Hugging Face | 모델 · 논문 · 데이터 검색 (한국어 TTS · SEM 분할 모델) | 모델 라이선스 확인 |
| 커넥터 | SciSpace | 논문 검색 · 근거 표 | AI 요약 칸은 원문 PDF 로 다시 확인 (규율 ⑥) |

## 쓰지 않는 것
- YouTube 커넥터 — 서비스 종료 (1저자 11-25).
- AI 이미지 · 영상 생성 플러그인 — 유료 크레딧 · 과학 그림 · 데이터 이미지에 맞지 않음.
- research-superpowers — 세션 시작 훅이 세션 동작을 바꿈.
- 외부 서버에서 그려 주는 도식 커넥터 (Mermaid Chart 등) — 미공개 내용 유출.
- code-review 플러그인 — 같은 기능이 이미 있음.

## 확인
- 연결 · 설치 뒤 `ListConnectors` · `ListPlugins` 로 붙었는지 본다.
- 새로 켠 플러그인은 새 세션부터 보일 수 있다.

## 기존 스킬 올리기 (1저자 11-25 · 12-01 할 일)
- 붙은 커넥터 · 플러그인 (alphaXiv · SciSpace · Hugging Face · Google Drive = BML 공유 드라이브 · Research Desk · watch-video · Gmail · Notion) 으로 우리 스킬 (AVI · 주간보고 생성 · litdb 논문 에이전트 · DEM1 · wiki · 보고자료 원칙) 의 어디를 낫게 할지 목록 → 1저자 확인 → 적용 (시험 먼저).
- 적용한 방법은 이 MCP 스킬에 "스킬마다 붙이는 법" 으로 적어, 다른 가지 · 다른 계정에서도 같은 꼴로 붙인다 (계정이 다르면 커넥터 · 플러그인부터 연결).
