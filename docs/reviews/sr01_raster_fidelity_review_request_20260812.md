# 적대 리뷰 요청 — STEP3 첨가제 래스터 충실도가 우리 결론들을 얼마나 흔드는가

**날짜** 2026-08-12 · **성격** 외부(Codex) + 내부 3각 동시 · **왜 지금** 오늘 실측으로
래스터 결함의 크기가 처음 정량화됐고, 그 크기가 예상을 크게 벗어났다.  이미 **밖으로 나간
결과(SDCP 원고)** 가 같은 경로를 탄다.

> 이 문서는 **자기완결**이다 (리포를 모르는 리뷰어도 판정할 수 있게).  모든 수치는 출처를
> 달았고, **실측**과 **추론**을 구분해 표기했다.  추측으로 수치를 만들지 말 것 — 모르면
> "모른다 + 무엇을 재면 알 수 있다" 로 답할 것.

---

## 1. 시스템 (판정에 필요한 최소 배경)

전고체 배터리 복합 양극의 다중물리 파이프라인.  이 리뷰가 다루는 부분만:

- **STEP3** = MPM 압밀로 얻은 **상(phase) 복셀 격자**(생산 기본 vox **0.4 µm**) 위에서
  유한체적 Kirchhoff 저항망을 풀어 두께방향 유효 전도도를 낸다:
  이웃 전도 복셀 쌍마다 컨덕턴스 `g = 조화평균(σ_a,σ_b)·(면적/거리)`, 각 복셀에 전류 보존,
  아래 집전판 φ=1 / 위 φ=0, CG (rtol 1e-8).  → `σ_e_eff`, `σ_ion_eff`, `κ_eff`,
  그리고 **소산 분담(dissipation share)** = 총 저항손실 중 각 상(相)에서 난 몫(%).
  ⚠ 솔버는 **6-face(면 공유) 연결**만 전도로 본다.  대각선으로만 닿은 복셀은 **절연**이다.
- **첨가제**: VGCF(탄소섬유, σ~1e3 S/cm) · SuperP(카본블랙 체인) · SDCP(혼합전도성 고분자) ·
  PTFE(절연 바인더) · SWCNT.  AM(활물질 NCM) σ~5e-3 S/cm, SE(황화물) 전자 절연.
- **문제의 코드**: 섬유 첨가제는 점열(polyline)로 시딩되는데, STEP3 가 그 점들을
  **1-복셀 점 스탬프**로 구웠다.  섬유가 복셀 대각선을 지나면 연속한 두 점이 **면을 공유하지
  않는 대각 셀**에 찍혀, 6-face 솔버에서 **전기적으로 끊긴다**.
  선택지: `--step3-fibre-stamp point`(**기존 기본값**) vs `segment`(같은 fid 점열을 경로로
  보고 Amanatides–Woo supercover 로 순회 → 연결이 구성상 보장).

### 기하 측정 (선행, 실측)
실침대에서 섬유의 **68.5–86.4 %** 가 **2.6–3.4 조각**으로 끊긴다 (킷마다 다름).
⇒ 기하는 확정.  그러나 **"끊긴다" → "σ_e 가 얼마나 틀리다"** 로 가는 다리는 없었다:
끊긴 섬유가 애초에 백본이 아니었으면 σ_e 는 안 움직이고, 반대로 조각들이 여분 경로/부피
인플레를 만들어 **과대평가**일 수도 있었다.  자체리뷰와 외부리뷰가 각각 부호를 **추론**했다가
**서로 반대 결론**에 닿은 자리다.

## 2. 오늘의 실측 (SR-01) — 부호와 크기

같은 압밀 베드 위에서 **래스터만** 바꾼 A/B (교란변수 0: 같은 `se_dump.npy`·`fibre.npy`,
같은 코드·같은 backend·같은 rtol).  킷 `kit_ps_7_3` (VGCF **1 wt%** + PTFE 1 wt%), GPU, 60 °C.

| | arm A (point) | arm B (segment) | Δ |
|---|---|---|---|
| **σ_e_eff** | 0.005122 | **0.1833** S/cm | **×35.79 (+3,479 %)** |
| 소산 share **VGCF** | **4 %** | **95 %** | — |
| 소산 share AM_S / AM_P | 39 / 57 % | 3 / 3 % | — |
| σ_ion_eff | 0.001982 | 0.001835 S/cm | −7.4 % |
| κ_eff | 1.963 | 2.01 W/m·K | +2.4 % |
| n_dof 전자 / 이온 | 2,713,168 / 1,597,970 | 2,786,279 / 1,553,369 | +2.7 % / −2.8 % |

**해석(우리)**: 점 스탬프가 탄소망을 전도 백본에서 사실상 지우고 전류를 AM 골격으로
우회시켰다.  σ(VGCF)/σ(AM) ~ 2e5 이므로 백본 부활 시 두 자릿수 도약이 정합.

**부수 실측**: 같은 arm A 를 CPU 와 GPU 로 각각 돌려 σ_e/σ_ion/κ 가 **인쇄 자릿수까지 동일**
(0.005122 / 0.001982 / 1.963) → backend 교체는 수치 무해(측정으로 확인, 더는 가정 아님).

**⚠ 이 베드의 한계**: 플래튼이 목표 300 MPa 도달이 아니라 **갭 산술로 멈춘** 문서화된 결함
(wallP 0.0148 GPa vs 목표 0.3; 준정적 게이트 V/c_P 0.428 위반 = 관성 혼입).
⇒ **절대값 인용 금지, 비(Δ)만 유효.**  두 팔이 같은 베드라 Δ 는 공통모드로 살아남는다.

## 3. 위험에 놓인 기존 결과 — SDCP 원고 (2026-07, 이미 외부 공유됨)

같은 STEP3 솔버, 같은 vox 0.4 µm, **VGCF 3 wt% 섬유 포함**, 그리고 그 시점에는
`--step3-fibre-stamp` 자체가 없었다 ⇒ **점 스탬프 확정**.

**헤드라인**: 총 첨가제량 4 wt% 고정에서 PTFE 절반을 SDCP 로 치환
(SBE: VGCF/PTFE = 3/1 → DBE: 3/0.5/0.5) 하면
- **σ_e 1.975 → 3.002 S/cm = +52.0 %**
- σ_ion +5.6 % · BV 반응면 +18 % (425,349 → 503,915 면) · R_geom −34 %
- "상쇄 축 없음" (전자 이득이 이온 희생을 동반하지 않음)

**주장하는 기전 (원고 §3)**: SDCP 는 **병렬 도체가 아니라 계면 브리지**다 —
"VGCF망의 **비싼 접합부**들을 값싼 다리로 이어 다른 구간(VGCF)의 저항 구조 자체를 바꿨다".
근거로 든 것:
- 소산 분담 **VGCF 92.5 / SDCP 7.3 / AM 0.2 %** (σ_SDCP=250) — **분담이 작은데 이득이 큼**
  = 브리지의 지문 (병렬 도체였다면 이득이 ~10 % 스케일이어야 함)
- EMT(유효매질) 상한의 **13.3×**
- 접점 +19.3 % (AM당 433→517) · **carbon clusters ×2.7 (3,172 → 8,644)**
- SDCP 분산 D=1.13 (랜덤급 균일)

**보조 실측**: σ_SDCP 스윕 {15/50/150/250/1500} → σ_e 이득 {+0.8/+25.8/+45.5/+52.0/+63.4 %}
(강한 σ_SDCP 의존 · 최악에서도 무손해 · 분담은 역행 = 직렬 시그니처).
2C CCCV: σ_e +52 % 가 ΔV 9 mV·용량 0.7 %p 로 압축 (이온-제한 시그니처).

## 4. 판정해 달라는 질문

### Q1 (핵심) — SDCP 의 **+52 %** 가 점-스탬프 아티팩트에 의존하는가?
논리적 우려: **SDCP 의 가치가 "접합부 다리 놓기"인데, 점 스탬프는 접합부를 인공적으로
만들어낸다.**  다리 놓을 자리를 결함이 제공했다면 이득은 부풀려진다.
반대 증거: SDCP/DBE 의 **VGCF 소산 분담 92.5 %** 는 오늘 arm B(정상, 95 %)와 같은 자리이고
arm A(붕괴, 4 %)와 정반대다 ⇒ 그 침대의 탄소 백본은 **작동하고 있었다**.
차이 후보: VGCF **3 wt%**(SDCP) vs **1 wt%**(오늘 킷) — 3배 부하면 조각나도 퍼콜 유지.

⚠ 우리가 **모르는 것**: `carbon clusters 3,172`(SBE, 순수 VGCF)는 조각남의 지문이지만
**개수는 크기 분포를 말하지 않는다** — "거대 덩어리 1 + 먼지 3,171" 인지 "고만고만한 3,172
섬" 인지 구분 못 한다.  92.5 % 분담은 전자를 시사하나 증명은 아니다.

→ **묻는 것**: (a) +52 % 가 살아남을까, 줄까, 늘까?  방향과 대략의 크기, 그리고 **왜**.
(b) 우리가 가진 수치들 중 이 판정을 **실제로 가르는** 것은 무엇인가 (우리가 잘못된 지표를
보고 있지는 않은가).  (c) 재실행 없이 기존 산출물에서 끌어낼 수 있는 결정적 증거가 있는가.

### Q2 — 다른 첨가제 결론들은?
같은 점 스탬프를 탄 다른 결과들: SuperP(체인) · SWCNT(sheath) · PTFE(절연이라 전자망 무관?) ·
그리고 **소산 분담 자체**를 근거로 삼은 모든 논증.  어디까지 오염됐다고 보아야 하는가.
특히 PTFE 는 절연이라 전자망에 안 들어가는데, **이온망·부피 잠식**을 통해서는 영향이 있는가
(오늘 측정에서 σ_ion −7.4 %, 이온 dof −2.8 % 였다).

### Q3 — 오늘의 ×35.8 을 얼마나 넓게 말해도 되는가?
1 킷 1 베드, rate-오염 베드, 60 °C, VGCF 1 wt%.  이 배수를 다른 조성/부하로 옮기는 것은
분명히 과하다.  **어떤 표현이 정직한 상한/하한인가?**  그리고 배수가 **VGCF 부하의 함수**
라는 가설(1 wt% 붕괴 / 3 wt% 생존)을 검증할 최소 실험 설계는?

### Q4 — 우리 방법론의 결함
오늘 우리는 두 번 틀렸다.  (i) arm A 중간값 "VGCF 4 %" 를 **안심 신호**로 읽었는데,
그 4 % 자체가 결함의 크기였다 (결함을 재는 실험에서 중간값이 이미 결함의 산물).
(ii) SDCP 위험을 확인 전에 과장했다가 92.5 % 를 보고 내렸다.
→ **이런 종류의 자기기만을 구조적으로 막는 장치**로 무엇을 넣어야 하는가?

### Q5 — 파이프라인 일반
vox 0.4 µm 는 VGCF 직경(~150 nm급) **아래를 해상하지 못한다**.  선분 스탬프는 연결을
보장하지만 **단면적은 여전히 복셀 크기로 양자화**된다 (1 복셀 = 0.4 µm).
⇒ 선분 스탬프도 σ_e 를 **과대평가**할 여지가 있는가?  (섬유가 실제보다 굵게 구워짐)
이 방향의 편향은 얼마나 되며, 어떻게 경계지어야 하는가?

## 5. 참고: 이 리포가 이미 채택한 규율 (판정 시 존중해 주길)

- **날조 금지(§F1)**: 앵커 없는 값은 훅만 두고 `ASSUMED` 라벨.  모르는 값은 null + 이유.
- **DEM 과 MPM 을 서로 보정하지 않는다** — 각자 실험에만 보정, 수렴=교차검증, 발산=정량화된
  모델 한계.
- **clamp/lock 으로 결과를 맞추지 않는다** (조작).  대신 regime-gate + 두 모델 불일치를
  유효성 증명서로 노출.
- 과압축은 porosity 가 아니라 **접촉면적 5-regime 의 min(caps) 천장**에서 잡는다.
- 등급: 절대값 인용 가능 = A, 상대비교 전용 = B (rate-오염·미수렴·외삽 시 B).

## 6. 답변 형식

각 질문마다: **판정**(한 줄) → **근거**(우리 수치 인용, 실측/추론 구분) → **반대 증거**
→ **이것을 확정할 최소 실험**(GPU 시간 추정 포함).  마지막에 **가장 위험한 단일 항목** 하나를
고르고 이유를 적어 달라.  동의만 하는 답변은 가치가 없다 — **틀린 곳을 찾아 달라.**
