## 1. 한 줄 요약

흑연의 **자기수축(self-retraction)** — 기저면 비틀림 입계로 붙은 두 단결정 플레이크를 초윤활 상태에서 옆으로 밀어내면, 새 자유면을 만드는 비용 때문에 원위치로 되돌아가려는 힘이 생긴다 — 을 이용해, 그 되돌림 힘과 균형을 이루는 전단력 F_app 를 플레이크 폭 B 로 나눠 **Γ = F_app / B** 로 벽개에너지를 **직접** 쟀다. 비정합 쌍결정에서 **0.37 ± 0.01 J/m²** (50 시료 · 한 변 2–9 μm · φ 16–54° · 22–198 °C 에서 온도·각도 무관 · 대기 중). 이상 AB 값 **0.39 ± 0.02 J/m²** 는 여기에 이론적 대각 비틀림 입계에너지 σ₀ ≈ 22 mJ/m² 를 더한 **합성값**이다.

### 4-1. 정의 (본문 p.2·p.6 + Supplementary Note 1)

### 4-2. 관계식

- **정확**: γ = CE(AB)/2 · Γ(φ) = 2γ − σ(φ) · σ(0) = 0 · σ(φ ≥ φ_c) ≈ σ₀ = ⟨γ_GSFE⟩ (강체 · 비정합).
- **근사 (ref 47 인용 — 논문 안에 유도 없음)**: BE ≈ 0.85 CE · CE ≈ 0.85 EE.

### 4-3. 🔴 EE = 0.46 J/m² 는 환산 방향이 의심스럽다 (우리 판단)

- **쌍가산(pairwise) 층간 모형**으로 보면: n 층 떨어진 두 층 사이 면적당 결합을 w(n) 이라 할 때 BE = Σₙ w(n) (층당), EE = Σₙ w(n) (표면 한 층이 아래 모든 층과), CE = Σₙ n·w(n) (벽개면을 가로지르는 거리 n 쌍이 n 개). ⇒ **EE ≈ BE < CE**. 논문의 BE ≈ 0.85 CE 는 이 틀과 맞지만 **CE ≈ 0.85 EE (즉 EE > CE) 는 반대 방향**이다.
- **논문 SI 의 같은 출처 쌍도 전부 CE > EE 다**: Zacharia (TDS) EE 0.32 · CE 0.37 → CE/EE = **1.16** · Chakarova-Käck (vdW-DF) EE 0.29 · CE 0.31 → **1.07** (우리 산수).
- ⇒ **0.46 은 인용 보류.** ref 47 (Gould et al., *J. Chem. Phys.* 139, 224704, 2013) 원문으로 부등호 방향을 확인하기 전에는 쓰지 않는다. 0.20 은 문제없고, 0.33 은 방향은 맞지만 **이론 계수를 거친 환산값**이다.
- 우리 사전등록 카드의 **S33(3\|3 가르기 = CE 형)** 과 **M41(그래핀 1장 떼기 = EE 형, 기판 4층)** 이 이 방향을 계산 안에서 보여 준다. 단 D3 2체는 쌍가산이라 EE < CE 가 **거의 구조적으로** 나온다 — 독립 검증은 아니다.

### 4-4. 문헌 값을 옮길 때 체크리스트

1. **type** (2SE / EE / BE / CE) 부터 — 같은 J/m² 라도 BE ≈ 0.85 CE 면 15 % 차다.
2. **적층** (AB / 비정합 / turbostratic / AA) — AB 대비 비정합은 σ₀/0.39 ≈ **5.6 %**, AA 는 γ_peak/0.39 ≈ **14 %** 낮다 (강체 GSFE 기준, 우리 산수).
3. **면적당 vs 원자당** — 원자가 한 층인지 두 층인지.
4. **이중층 그래핀 vs 흑연** — 이중층 값은 흑연 계면에너지를 ~15 % 과소 (본문 Methods, ref 47 근거).
5. ⚠ **이 논문도 섞는다**: 서론은 기존 범위를 "0.14–0.72" 라 했는데 0.14 는 Kis 의 **SE**(2SE 0.28 의 절반)다. Discussion 은 "0.19–0.72 (or 0.43 ± 0.29)" 라 했는데 **0.43 ± 0.29 는 0.14–0.72 의 중점 ± 반폭**이다 (우리 산수 — 0.19–0.72 면 0.455 ± 0.265). 그리고 그 범위를 "cleavage energies" 라 불렀지만 표 안에는 BE·EE·2SE 가 섞여 있다. 이론 범위 "0.03–0.51 (0.27 ± 0.24)" 는 산술이 맞는다.

## 5. 방법 ★

### 5a. 실험 — 자기수축으로 벽개에너지 재기

**원리 (본문 p.2, `Fig. 1a,b`)**
- 초윤활 비틀림 계면에서 위 플레이크를 x 만큼 밀면: 자유면 **2Bx** 가 새로 생기고 입계 **Bx** 가 사라진다 → **ΔG = (2γ − σ(φ)) B x = Γ(φ) B x > 0**.
- 되돌림 힘 **F_ret = −dG/dx = −Γ(φ) B** (산일 무시). 준정적 loading·unloading 에서 F_app 가 F_ret 와 균형 → **Γ(φ) = F_app / B**.
- 가장자리 길이는 밀어도 그대로라 모서리 에너지는 힘에 안 들어간다 (우리 해석).
- 폭 B 는 SEM (FEI Quanta FEG 450) 으로 잰다.

**시료·장치 (p.2)**
- HOPG 메사 (ref 29·31 방식 · 반응성 이온 식각). 한 변 2–9 μm, 높이 ~1 μm. 메사 안에 표면과 평행한 입계가 메사 전체를 가로지르는 경우가 흔하다.
- FT-S100 힘 센서를 마이크로매니퓰레이터(Kleindiek MM3A)에 **고정**, 시료는 세라믹 히터 위 **XYZ 스테이지**(XMT XP-611). 탐침 끝이 위 플레이크 옆면을 밀고(그냥 밀어 붙인 접촉), 스테이지가 아래를 **~25 nm/s** 로 옮긴다. 전부 광학현미경(Zeiss Axio Scope.A1) 아래.
- ⚠ `Fig. 1c` 에 **진공 챔버**가 그려져 있고 캡션도 *"control the temperature and vacuum"* 인데, **보고된 데이터는 전부 대기(ambient)** 다 (§10-⑨).

**곡선 해석 (`Fig. 2`)**
- loading: (I) 탐침 탄성 변형 → (II) 식각으로 생긴 **가장자리 화학결합 파단** (날카로운 스파이크) → (III) **평탄부 F_app = −F_ret** (초윤활, 새로 드러나는 면은 오염 전이라 기울기 0).
- unloading: (i) 탐침 탄성 해제 → (ii) **오염 마찰 F_cf** — 되돌아오는 플레이크 가장자리가 흡착물을 빗자루처럼 밀어내며 쌓이니 후퇴 거리에 비례해 커진다 → (iii) 원위치 복귀 (loading (I) 과 겹침).
- **산일 에너지** = loading (III) 와 unloading (ii) 사이 면적 ÷ (평탄부 폭 w × 폭 B) (캡션 정의 — §10-⑪).
- 온도를 올리면 흡착 평형 농도가 줄어 unloading 이 loading 에 붙는다 → **동적 마찰은 무시 가능, 되돌림은 ~100 °C 이상에서 초윤활**, loading 은 전 온도에서 초윤활 (평탄·온도 무관).

**비틀림각 φ 재기 (p.4, `Fig. 3b` 삽도)** — **lock-in 효과**: 위 플레이크를 돌려 자기수축이 사라지는 각(정합 AB, 미끄럼 장벽 = 이론 전단강도)까지 필요한 회전각이 곧 φ.

**통계** — 평균 Γ 는 50 시료. `Fig. 3a` 는 3 시료 × 5회 (s.d.), `Fig. 3b` 는 11 시료 × 5회 (s.d.).

### 5b. 이론 — APNGB (anisotropic Peierls–Nabarro grain boundary) 모형

**틀** — 쌍결정 = 반무한 두 흑연 결정이 공통 (0001) 면에서 [0001] 축 회전으로 만난다. 입계에너지 = **양쪽 결정의 탄성 변형에너지** + **계면 misfit 에너지**(= GSFE 로 기술, 정상 결합이 끊긴 만큼). 계면의 disregistry(어긋남) 에 대해 총에너지를 최소화한다. fcc Al·Cu·Ni 의 (111) 비틀림 입계에서 원자 계산과 잘 맞았고(ref 43·44), 층간이 층내보다 훨씬 약해 전위핵이 넓은 흑연에서는 더 정확할 것이라고 저자들은 본다.

**입력은 둘뿐** — ① 이방성 탄성상수 (실험, `Table S3`) ② GSFE.

**GSFE 함수형 (본문 p.6 — 렌더한 원식 그대로)**. 여기서 φ·ψ 는 **변위**다 (비틀림각 φ 와 같은 글자 — 논문 표기). `Fig. S2` 축으로 보면 φ ∥ [11-20] (zigzag, 주기 a0), ψ ∥ [1-100] (armchair, 주기 √3·a0) 이다 (우리 판독).

```
γ(φ,ψ) = c0
  + c1 [ cos(2π/a0·(φ + ψ/√3)) + cos(2π/a0·(φ − ψ/√3)) + cos(4πψ/(√3·a0)) ]
  + c2 [ cos(2π/a0·(φ + √3ψ)) + cos(2π/a0·(φ − √3ψ)) + cos(8πψ/(√3·a0)) ]   ← 인쇄 그대로 (§10-①: 셋째 항은 cos(4πφ/a0) 여야 대칭)
  + c3 [ cos(2π/a0·(2φ + 2ψ/√3)) + cos(2π/a0·(2φ − 2ψ/√3)) + cos(8πψ/(√3·a0)) ]
  + c4 [ sin(2π/a0·(φ − ψ/√3)) − sin(2π/a0·(φ + ψ/√3)) + sin(4πψ/(√3·a0)) ]
  + c5 [ sin(2π/a0·(2φ − 2ψ/√3)) − sin(2π/a0·(2φ + 2ψ/√3)) + sin(8πψ/(√3·a0)) ]
c0 = −3(c1 + c2 + c3)        # 원점 = 완전 ABAB 에서 γ = 0
```
- 독립 매개변수 5개 (c1–c5). cos · sin 항은 셀 평균이 0 이므로 **셀 평균 ⟨γ⟩ = c0** — 이것이 곧 σ₀ 다 (우리 확인).
- sin 항(c4·c5)이 AB 에서 한쪽(적층결함)과 다른 쪽(AA)을 가른다.

**맞춤 조건 (Methods · `Fig. S2`)** — C44 (AB 최소점의 기저면 전단 곡률) + GSFE 4점:

| 점 | 뜻 | `Fig. S2` 위치 (가로 [1-100], 세로 [11-20]) | 값 (mJ/m²) |
|---|---|---|---|
| AB | 완전 ABAB (원점) | 네 모서리 · (√3a0/2, a0/2) | 0 |
| **γ_peak** | 지형 최대 = **AA** | (√3a0/3, 0) · (√3a0/3, a0) · 등가점 (5√3a0/6, a0/2) | **53.9** |
| **γ_sf** | 적층결함 ABAB\|CACA | (2√3a0/3, 0) · (2√3a0/3, a0) | **0.85** |
| **γ_sp** | armchair 방향 불안정 적층결함 (안장점) | SF 와 다음 AB 사이 (figure-read ≈ 0.85·√3a0) | **9.4** |
| **γ_sp′** | zigzag [11-20] 방향 불안정점 = AB 에서 zigzag 로 a0/2 | (√3a0, a0/2) | **29.0** |

**값의 출처와 오차 (Methods)**
- γ_sp · γ_sp′ · γ_peak = 저자들의 *"최근"* **ACFDT-RPA 이중층 그래핀** 계산 — **인용 번호가 없다**. 이중층은 흑연 계면에너지를 ~15 % 과소평가한다(ref 47)며 오차 **~15 %** 로 둔다.
- γ_sf 는 오차 **~100 %** — *"LDA 가 분산력을 못 그려서"* 라는 설명으로 보아 LDA 값으로 읽힌다 (출처 명시 없음). 너무 작아 입계에너지에 영향이 없다.
- GSFE 전체 평균 오차 ~15 % → σ₀ 오차 < ~5 mJ/m².
- ⚠ `Table S4` 가 RPA 원값인지 15 % 를 보정한 값인지, **층간거리를 고정했는지 registry 마다 이완했는지** 논문이 밝히지 않는다.

**결과 해석 (p.5)**
- 작은 각: 입계 = 2D 전위망. 나선전위가 **부분전위로 해리**해 거의 삼각형 망 — 교대 삼각형이 ABAB\|ABAB (완전) 과 ABAB\|CACA (적층결함) 영역. 전위핵(초록) 폭 **w ≈ 3 nm**, 교차점(빨강)이 misfit 최대.
- 전위 간격 d ≈ b/φ 가 핵 폭 w 와 같아지는 **φ_c ≈ b/w ≈ 3.7°** 에서 핵이 겹친다 → 그 이상은 **두 강체 결정의 비정합 접촉**이고 에너지는 거의 전부 misfit → **GSFE 전체 평균 = σ₀ ≈ 22 mJ/m²**. 60° − φ_c 도 같다 (60° 회전 = 에너지가 아주 작은 쌍정).
- 금속(fcc (111))은 σ(φ) 가 30° 근처까지 계속 오르는데, 흑연은 약한 층간 결합 · 강한 층내 결합 때문에 **몇 도 안에서 포화**한다 — 이것이 **측정 Γ 가 16–54° 에서 각도 무관**인 이유.

### 5c. 우리 재구성 — SI 수치만으로 σ₀ ≈ 22 mJ/m² 가 다시 나오나 (우리 산수 · 논문에 없음)

- 가정 (논문 미기재): a0 = 2.46 Å · 층간 d = 3.35 Å · SP 는 SF→AB 중점 · AB 곡률 ∂²γ/∂u² = C44/d = **150.7 mJ m⁻² Å⁻²**.
- **대칭형(c2 셋째 항 = cos 4πφ/a0)으로 풀면**: c1…c5 = −5.755, −1.495, −0.328, −11.250, −1.040 mJ/m² → **c0 = ⟨γ⟩ = 22.74 mJ/m²** (격자 수치 평균도 22.74). 최소 0 (AB) · 최대 **53.90 (AA)** · SF→AB 경로 최대 9.49 (중점에서 0.035 a_CC 이탈) · zigzag 경로 최대 29.0 (중점) · 곡률 등방. ⇒ **논문 "≈ 22" 와 `Fig. 4a` 수평선(figure-read ≈ 22.4)을 재현한다.**
- **인쇄된 식 그대로 풀면**: c0 = 20.70 이고 곡률이 방향에 따라 갈린다 (∂²γ/∂φ² = 76.3 vs ∂²γ/∂ψ² = 150.7 mJ m⁻² Å⁻²). 육방 대칭이면 기저면 전단 곡률은 등방이어야 하므로 **인쇄 식은 오식**으로 판단한다 (§10-①).
- C44 조건을 빼고 c3 = 0 으로 4점만 맞추면 c0 = 21.75 (그때 함의 C44 = 4.19 GPa).
- ⇒ **σ₀ 는 맞춤 세부에 둔감하다 (20.7–22.7 mJ/m²) — Γ 로는 0.5 % 안.** 계산 스크립트는 세션 스크래치에만 두었다 (repo 에 올리지 않음).

### 7c. registry 세 점에서 σ₀ 를 뽑는 법 — 논문 GSFE 로 미리 시험 (우리 산수)

- **2성(two-star) 푸리에 보간** (AB = BA 대칭, SF 비대칭 0.85 mJ/m² 무시): ⟨γ⟩ ≈ **¼·ΔE_AA + ¾·ΔE_SP** (ΔE_X = W(AB) − W(X)) ⇔ **W_inc ≈ (W_AA + 3·W_SP)/4**. 사전등록 카드 §5 의 식과 **같다** (독립 유도로 확인).
- 논문 GSFE 에 넣으면: ¼·53.9 + ¾·9.4 = **20.5 mJ/m²** vs 논문 ≈ 22 · 우리 5-매개변수 재구성 22.7 → σ₀ **−7 ~ −10 %**, Γ 로는 **0.4–0.6 %**. 같은 보간이 zigzag 점을 27.4 로 예측 (논문 29.0).
- **1성**(AA 만 → (2·W_AB + W_AA)/3): 18.0 mJ/m² (−18 ~ −21 %). SP 만 쓰면 28.2 (+24 ~ +28 %). ⇒ **AB · SP · AA 세 점이 최소 집합**이다.
- 카드의 절단 민감도 진단(2성 ↔ 1성 차)에 대한 사전값: 논문 GSFE 에서 σ₀(2성) − σ₀(1성) = 20.5 − 18.0 = **2.5 mJ/m²**, 2성의 실제 절단 오차는 우리 재구성(22.7) 기준 **2.2 mJ/m²** (논문 "≈ 22" 기준이면 1.5) → 이 진단은 크기를 제대로 잡는다. 1성 일관성 비 r = (W_AB − W_SP)/(W_AB − W_AA) 는 논문 GSFE 에서 9.4/53.9 = **0.174** (1성 순수 푸리에면 1/9 = 0.111).
- ⛔ 고대칭점 **개수 가중** 평균 ((2·AB + 3·SP + 1·AA)/6 = **13.7**)은 틀린 평균이다 — σ₀ 는 변위 공간의 **면적 평균**이다.
- ⚠ **이완 편향 (우리 판단 · 논문 밖)**: 사전등록 카드는 registry 마다 z 를 이완한다. 실제 비정합 계면은 층간거리가 **하나**다. "각 registry 의 최소를 평균" ≤ "공통 거리에서의 평균의 최소" 이므로 **registry 별 이완 W 를 평균하면 W_inc 를 과대(σ₀ 를 과소) 평가하는 쪽**이다. 크기 어림: ½·(C33/d)·Var_u(d_u) — C33 = 36.5 GPa (`Table S3`), d = 3.35 Å 면 C33/d ≈ 1.09 J m⁻² Å⁻² 라, registry 간 층간거리 산포(표준편차)가 0.05 Å 면 ≈ 1.4 mJ/m², 0.1 Å 면 ≈ 5 mJ/m². 카드가 registry 별 이완 층간거리를 기록하므로 결과 뒤에 이 항을 사후 어림할 수 있다.
- 넷째 registry 가 필요해지면 SF(AB 와 0.85 mJ/m² 차 — D3 수치 잡음 이하일 것)보다 **γ_sp′ 점(AB 에서 zigzag 로 a0/2)** 이 2성 보간 검증에 쓸모 있다 — 1저자 결정 사항 (카드는 셋으로 봉인했다).

### 7e. 이 digest 가 찾은 기존 기록의 어긋남 (고치는 것은 메인 세션 몫)

1. **계획서의 0.37 / 0.39**: `kb/projects/wad_lpscl_agc_vgcf_plan_2026_09_23.md` §흑연 대조(L185)는 기준을 **0.39 (AB)** 로 적었는데, 단계 표(L381)는 아직 *"문헌 소환값 ~0.37 J/m² 와 비교"* 다 (09-28 인입 줄 L189 와 사전등록 카드는 이미 옳게 나눴다 — L381 한 줄만 남았다). 이 digest 판단: **AB registry W_sep ↔ 0.39**, **registry 평균 ↔ 0.37**.

## 10. 비판 / 한계 ★

① **GSFE 식 인쇄 오류.** 본문 p.6 의 c2 괄호 셋째 항이 **cos(8πψ/(√3·a0))** 로 c3 괄호의 항을 반복한다. 이러면 c2 괄호가 대칭 별(star)이 아니게 되고, 우리 재구성에서 기저면 전단 곡률이 방향에 따라 2 배 갈린다(76.3 vs 150.7 mJ m⁻² Å⁻²). **cos(4πφ/a0)** 로 두면 곡률이 등방이 되고 σ₀ 22.7 이 재현된다 (§5c). 발표된 σ₀ 에는 영향이 없어 보인다 — 식을 옮겨 쓸 사람만 조심하면 된다.

② **0.39 는 측정이 아니다.** 측정 각도가 전부 포화 영역(16–54°)이라 실험은 σ(φ) 를 가를 수 없다. σ₀ 는 전적으로 이론이다. 불확도가 작아서(< 0.005) 실용상 문제는 작지만, Discussion 의 *"should be considered definitive"* 는 과장이다.

③ **GSFE 입력의 출처가 불투명하다.** *"our recent ACFDT-RPA calculations"* 에 인용 번호가 없고, 코드 · k · cutoff · **층간거리 규약**이 없다. `Table S4` 가 RPA 원값인지 15 % 보정값인지, γ_sf 가 어디서 왔는지(LDA 로 읽힐 뿐) 밝히지 않는다.

④ **환산 계수 BE ≈ 0.85 CE · CE ≈ 0.85 EE 는 유도 없이 ref 47 인용이다.** 특히 **EE 방향은 쌍가산 틀과 SI 문헌 쌍 둘 다와 반대**다 (§4-3) → EE 0.46 인용 보류.

⑤ **범위 서술이 스스로 어긋난다.** 서론 0.14 vs Discussion 0.19 · "0.43 ± 0.29" 는 0.14–0.72 의 중점 ± 반폭 · BE · EE · 2SE 를 한데 모아 "cleavage energies" 라 부름 (§4-4 ⑤).

⑥ **`Table S2` 분류 문제.** ref 12 (Ortmann 2006, 제목상 semi-empirical DFT-D) 를 vdW-DF 로 분류했고, 그 값 0.51 (EE) 은 Note 의 "vdW-DF 11–13 → EE 0.29–0.32" 와 모순이다. Savini 0.43 ± 0.02 (turbostratic) 는 표에서 EE, Note 에서 BE 다.

⑦ **GF1/GF2 라벨 혼동.** 캡션 *"GF1 (blue), GF2 (grey)"* ↔ 그림 (GF2 = 파랑, 위) ↔ 본문 *"upper flake GF1 was stationary"* 와 *"upper graphite flake (GF2 blue)"*. 측정 논리엔 영향 없다.

⑧ **교차참조 오류.** *"the elastic energy is negligible over this angle range — Fig. 3a"* 는 `Fig. 4a` 여야 한다.

⑨ **대기 중 측정 · 진공 대조 없음.** *"insensitive to impurities from the atmosphere"* 의 근거는 "loading 은 새 표면을 만든다" 는 논리와 온도 무관성이지 진공 대조가 아니다 (`Fig. 1c` 에 진공 챔버를 그려 놓고도). 삽도 산일 에너지는 190 °C 에서도 0.01–0.03 J/m² 로 0 이 아니다 → *"~100 °C 이상에서 되돌림도 초윤활"* 은 근사다.

⑩ **불확도 표기.** ±0.01 이 s.d. 인지 s.e. 인지 없다 (figure-read 산포는 s.d. ≈ 0.01 과 맞는다). 계통오차 — D-LFC k 의 ±1.5 % 만으로 Γ 에 ±0.006 J/m² (우리 산수), 여기에 B 측정 오차와 탐침 각도가 더해진다 — 가 ±0.01 에 들었는지 불명이다. figure-read 감도 0.68–0.69 vs 본문 0.659 μN/V (~4 %) 는 판독 오차일 수 있어 판정 보류로 남긴다.

⑪ **산일 에너지 정규화가 모호하다.** 캡션 정의(면적 ÷ w·B)로 `Fig. 2b` 를 읽으면 ≈ 0.08–0.09 J/m² (`Fig. 2a` 22 °C 는 ≈ 0.19) 인데, `Fig. 3a` 삽도의 같은 온도대 값은 0.015–0.075 다. ÷ 2wB (새 표면 두 장)로도 여전히 약간 크다 — 정규화 정의가 다르거나 시료가 다르다 (논문 미기재). CE 에는 영향 없다.

⑫ **부분전위 b ≈ 0.2 nm.** 흑연 기저면 Shockley 부분전위는 a0/√3 ≈ 0.142 nm (a0 = 2.46 Å), 완전전위는 0.246 nm 다. b = 0.142 면 φ_c ≈ 2.7°, 0.246 이면 4.7° (우리 산수) — "몇 도 안에서 포화" 결론은 그대로다.

⑬ **`Fig. 4a` 삽도 색막대 상한 7 mJ/m²** vs AA 중심 53.9 — 설명 없음.

⑭ **통계의 층.** 평균 0.37 은 50 시료이지만, 온도 의존(3 시료)과 각도 의존(11 시료)은 작은 표본이다. 각도는 시료마다 하나라 "각도 효과" 와 "시료 간 차" 가 분리되지 않는다 (둘 다 0 이라 결론엔 무해).

## 11. 적용 인사이트 ★

1. **C\|C 대조는 두 줄로 낸다**: W_sep(AB) ↔ **0.39** (측정 + RPA σ₀) · W_inc = (W_AA + 3·W_SP)/4 ↔ **0.37** (순수 측정). 두 번째 줄이 RPA 없이 실험과 붙는 유일한 경로다.
2. **DEM 탄소–탄소 접촉의 w 앵커는 0.37 (비정합)** — 입자 회전이 임의면 87 % 가 비정합 영역이다. 0.37 대비 AB 값(0.39)을 넘기면 ~5 % 과대, AA 값(강체 GSFE 로 0.39 − 0.054 ≈ 0.34)을 넘기면 ~9 % 과소다 (우리 산수).
3. **registry 효과(σ₀/Γ ≈ 5.6 %)는 분산 모델 차이보다 작다.** 허용대 0.31–0.47 이 ±20 % 인데 σ₀ 는 그 1/4 쯤이다 → 대조의 합격/불합격을 가르는 것은 registry 가 아니라 **분산 모델 · 두께 · 끝점**이다.
4. **이 논문 CE 는 반무한 · 완전분리 양**이다 → V2 교훈(8 → 10 Å +0.0136) + 이중층 → 흑연 ~15 % (ref 47) 때문에 **두께 수렴(ΔW ≤ 0.02)과 끝점 ≥ 10 Å 는 필수**다. 카드가 둘 다 봉인했다.
5. **실험 Γ 는 다체 효과를 다 품었다** → 대조 표에 2체와 +ATM 을 **둘 다** 적는다.
6. **registry 별 이완 평균은 W_inc 를 과대 쪽으로 민다** (§7c) — 카드가 기록하는 층간거리로 사후 어림 한 줄을 붙이면 좋다.
7. **인용 규율**: 0.37 = *"incommensurate bicrystal, measured"* · 0.39 = *"ideal AB, measurement + APNGB/RPA"* · 0.33 = *"derived"* · **0.46 = 보류**.
8. **남은 정리 (메인 세션 몫)**: 계획서 L381 의 "~0.37 과 비교" (L185·L189 와 어긋남) · Maurer 48 meV/C 의 BE/CE 혼용 가능성이 남은 자리 (계획 L157 · §J-43 · `maurer2015` digest — 카드는 결과 전 보강에서 철회) · EE 0.46 (카드는 보류 표시 완료).

## 12. 인용 가능 문장 (영문 초안)

- "The basal-plane cleavage energy of graphite, measured directly with the self-retraction method, is 0.37 ± 0.01 J m⁻² for incommensurate (twisted, 16°–54°) bicrystals and is independent of temperature (22–198 °C) and twist angle (Wang et al., *Nat. Commun.* 2015)."
- "The ideal AB-stacked value, 0.39 ± 0.02 J m⁻², adds a Peierls–Nabarro estimate of the large-angle twist-boundary energy (≈22 mJ m⁻², the average of an ACFDT-RPA-based generalized stacking-fault energy) to the measurement; it is a measurement-plus-theory value."
- "Because randomly oriented carbon particles meet almost exclusively at incommensurate twist angles, we compare the registry-averaged DFT separation energy with the directly measured incommensurate value (0.37 J m⁻²), and the AB-registry value with 0.39 J m⁻²."
- ⚠ (조건부) "Using the conversion factors quoted by Wang et al., the basal surface energy is 0.20 J m⁻² and the interlayer binding energy ≈0.33 J m⁻²." — **EE 0.46 은 쓰지 않는다.**

- ⛔ 0.37 과 0.39 를 "graphite cleavage energy" 한 이름으로 섞지 않는다 — **적층(비정합 / AB)** 을 붙인다.
- ⛔ 0.39 를 "측정값" 이라 부르지 않는다 — "측정 + 이론(σ₀)".
- ⛔ **EE 0.46 인용 보류** (§4-3).
- ⛔ BE · EE · 2SE · CE 문헌값을 같은 열에 두지 않는다 — type 을 붙인다.
- ⛔ 이 논문 값을 우리 Ag\|그래핀 V2 (0.435 / 0.449) 와 같은 줄에 두지 않는다.
- ⛔ "RPA 가 0.39 를 재현" 같은 문장 금지 — RPA 결합에너지는 이 논문에 없다.
- ⛔ 흑연 값을 아지로다이트 물성 4축(A–D)에 넣지 않는다.
- ⚠ HOPG · 평탄 기저면 · 깨끗한 새 표면 · 대기 조건이다 — 실제 입자 접촉의 실효 w 는 더 작을 수 있다.
- ⚠ σ₀ 는 RPA 이중층 기반(~15 %)이지만 Γ 로는 ≈ 1 % 불확도다.

## 14. 기법 용어 미니사전

- **자기수축 (self-retraction)**: 초윤활 계면으로 붙은 흑연 플레이크를 옆으로 밀었다 놓으면 저절로 원위치로 돌아오는 현상. 밀린 만큼 드러난 두 면의 표면에너지가 되돌림 힘이 된다 (Zheng 2008).
- **초윤활 (superlubricity)**: 두 결정 격자가 서로 어긋나(비정합) 원자 요철이 상쇄되어 미끄럼 마찰이 거의 0 인 상태. 같은 방향(정합)이면 요철이 맞물려 장벽이 생긴다.
- **lock-in**: 위 플레이크를 돌려 정합(AB) 방향에 맞으면 미끄럼이 갑자기 잠기는 현상. 거기까지 돌린 각이 원래 비틀림각이다.
- **비틀림 입계 (twist grain boundary)**: 두 결정이 계면에 수직인 축 둘레로만 돌아 만난 입계. 흑연 (0001) 에서는 층 사이 하나가 곧 입계다.
- **정합 / 비정합 (commensurate / incommensurate)**: 두 격자가 공통 주기를 갖는지. 무작위 각도로 만나면 사실상 비정합이고, 계면 에너지는 모든 상대 위치(registry)의 **면적 평균**이 된다.
- **GSFE (generalized stacking fault energy)**: 두 강체 반쪽을 한 면에서 평행이동할 때의 에너지 지형. 흑연에서는 AB(최소) · SP(안장) · AA(최대) · SF(적층결함, 거의 최소) 가 지형의 이정표다.
- **registry**: 두 층의 상대 위치 (AB · SP · AA …). DFT 의 작은 주기 셀은 registry 하나만 볼 수 있다.
- **Peierls–Nabarro 모형 / APNGB**: 계면의 어긋남을 연속 변위장으로 두고 "양쪽 탄성에너지 + 계면 misfit(GSFE)" 을 최소화하는 모형. APNGB 는 이를 이방성 탄성과 비틀림 입계로 넓힌 것.
- **부분전위 · 전위핵 폭**: 작은 각 비틀림 입계는 나선전위 망이고, 흑연에서는 전위가 두 부분전위로 갈라진다. 층간이 약해 핵이 ~3 nm 로 넓다 → 몇 도만 돌려도 핵이 겹쳐 비정합 한계에 닿는다.
- **ACFDT-RPA**: 단열 연결 요동-산일 정리 + 무작위 위상 근사로 상관에너지를 계산하는 방법. 분산(vdW)을 원리적으로 포함해 층상 물질 결합의 고정밀 기준으로 쓰인다 (QMC 와 함께).
- **D-LFC**: 반자성 열분해흑연 판을 자석 위에 띄운 횡방향 힘 보정기. 고유진동수와 질량으로 스프링상수를 정하고, 알려진 변위로 알려진 힘을 준다.
- **HOPG**: 고배향 열분해흑연. c 축은 잘 정렬되고 면내 방향은 결정립마다 무작위 — 그래서 결정립 사이 계면이 자연스러운 비틀림 입계가 된다.
- **모아레 주기**: 각 φ 만큼 돈 두 격자가 만드는 맥놀이 무늬 주기 ≈ a0 / (2 sin(φ/2)). 1° 면 ≈ 14 nm, 16° 면 ≈ 0.9 nm.
