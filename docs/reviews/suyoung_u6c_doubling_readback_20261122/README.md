# 두 배 해상도에서의 아래판 반력 개발 대조

11-22에 기존 자료를 후처리하는 방법을 기록하고 아래 곡선 차이를 계산했다. 11-21 반환 TAR의 SHA256은 `a3877d077b56d74877a04215e06135bc3217b5c0f055bf0061a9ba93fcf49f00`이고 설정은 ①이다. 비교 대상은 그 반환에 포함된 입자별 장 F의 두 배 해상도 쌍 전부, F8–F16과 F12–F24다.

1. 각 궤적에서 0번째 판 높이와 현재 높이의 차이 u = h₀ − h를 사용한다. u의 단위는 계산 길이 단위다. 아래판의 반력을 같은 판 폭으로 나눈 열 bottom_pressure_E에 10 MPa를 곱해 아래판 응력으로 표시한다.
2. 두 곡선이 모두 가진 구간 [0, min(u₁끝, u₂끝)]에서 양쪽의 실제 u 표본을 합쳐 오름차순으로 정렬한다. 양 끝을 포함하고 같은 u는 한 번만 센다.
3. 합쳐진 각 u에서 두 곡선을 각각 인접 두 기록 사이에서 선형 보간한다. 평활과 외삽을 하지 않는다. 그 점의 차이는 성긴 격자 응력에서 고운 격자 응력을 뺀 값이다.
4. 차이의 최솟값·최댓값·최대 절댓값을 MPa로 보고한다. 최대 절댓값이 같은 점이 여러 곳이면 가장 이른 u를 쓴다. 양끝·내부에 따로 취사선택하는 가중치는 없다. 구간 사이에서 차이가 선형이므로 최대 절댓값은 합친 u 중 한 곳에 있다.
5. 양쪽 원 표본 수, 공통 구간의 각 표본 수와 합집합 점 수, 공통 구간 끝의 차이(MPa), 각 궤적의 마지막 변위와 두 마지막 변위의 차이(성긴 격자−고운 격자)를 함께 기록한다. SHA256으로 궤적·팔 영수증·앞 요약을 대조한다.

이 방법은 두 계산의 전체 가압 경로가 어디에서 얼마나 다른지 보기 위한 개발 후처리다. 5% 판정에 필요한 오차 분모 및 표본 규약은 사전 등록되지 않았다. 백분율이나 자격 판정을 산출하지 않는다. U6(c) 상태는 HOLD다.

## 공통 변위에서의 실제 차이

| 해상도 쌍 | 공통 변위 끝 (계산 길이) | 비교점 수 | 성긴 쪽−고운 쪽의 최솟값 (MPa) | 최댓값 (MPa) |
|---|---:|---:|---:|---:|
| F8 ↔ F16 | 0.115623 | 5,157 | −0.051003 | +0.565977 |
| F12 ↔ F24 | 0.149021 | 9,969 | −0.022417 | +0.192548 |

두 쌍 모두 공통 구간의 끝에서 절대차가 가장 컸다. 두 쌍의 공통 구간 길이가 다르므로 위 두 최대차에서 수렴률을 산출할 수 없다.

재판독에는 Python 3.11 이상과 이전 8·12·16·24셀 TAR 원본을 사용한다. 아래 명령의 두 인자는 각각 보존된 입력 TAR와 새로 만들 JSON 파일 경로다. 같은 폴더의 `test_doubling.py`는 실제 계산 없이 선형 보간·내부 극값·공통 끝점·잘못된 좌표를 점검한다.

```sh
python3 -I -B docs/reviews/suyoung_u6c_doubling_readback_20261122/doubling.py "$PRIOR_TAR" "$NEW_JSON"
```
