3548:     reader 도 **파일 안**을 보지 않았다. 그래서 원장 pin 을 A 로 그대로 둔 채
3549:     B 가 만든 세 파일을 넘기면 A+B generation 이 만들어졌다 — 봉인은 "무엇을
