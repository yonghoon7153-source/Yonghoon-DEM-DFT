## 1. Phase A — "도전재를 늘리면 전자가 더 잘 흐르나" 판정 완료 ✅

**무엇을 물었나.**  탄소섬유 도전재 VGCF 를 1 → 2 → 3 → 4 wt% 로 늘리면 양극의 전자 전도도(σ_e)가 계속 커지는가 — 그리고 그
**순서**가 계산 조건을 바꿔도 유지되는가.  격자 한 칸의 크기(0.15 · 0.20 · 0.25 µm) 셋 × 격자를 살짝 밀어 놓는 위치(origin) 8 곳 ×
조성 4 = 96 팔 + 음성대조 8 팔 = **104 팔**.

**결과 (09-21).**  **ORDER-ROBUST** — 이웃한 조성끼리 비교한 **72 쌍 전부**에서 순서가 한 번도 뒤집히지 않았다.  같은 입력을 다시
돌리면 똑같은 답이 나온다(재현 오차 0.00000 %).  09-22 에 판정 산출물(판정문 · 영수증 · 104 팔 JSON)을 리포에 넣고 판정기를 다시 돌려도
같은 답이었다.

**반드시 같이 적는 한정어 셋.**
① 판정한 것은 **순서뿐**이다 — "몇 % 오른다" 는 판정 대상이 아니다(증분 % 는 기술 보고용).
② 음성대조는 **한 칸**(격자 0.15 µm · 1 wt%)에서만 했다.
③ 96 팔은 어떤 코드 버전으로 돌았는지의 기록(`code_sha`)이 비어 있다(09-18 셸의 git 고장, 원장 `PASL-03`) — 같은 입력의 재실행이
똑같은 답을 낸 것(0.00000 %)으로 경험적으로 메웠다.

**왜 중요한가.**  지난 주에 규약을 벗어나 돌아 무너졌던 캠페인(96 팔이 PTFE 규약을 빠뜨림)을 되살려 **끝을 낸 판정**이다.

## 2. VGCF 의 "뻣뻣함" 기본값 10 → 100 GPa, 그리고 재현 실험 등록

- **발견 (09-25~26, 원장 `CL-93`).**  VGCF 섬유가 얼마나 뻣뻣한지(영률)를 **10 GPa** 로 두고 있었는데, 이 값은 06-24 에 **출처 없이**
  고른 모델 값이었다.  문헌 카드는 흑연화 VGCF 에 이보다 훨씬 큰 값을 준다.
- **영향을 먼저 쟀다.**  한 팔에서 1 / 10 / 100 GPa 로 바꿔 보니 σ_e 가 10 GPa 대비 **0.25 % 이하**로만 움직였다 → 결과에 거의 영향이
  없는 "2차 입력".
- **결정 (09-26).**  앞으로의 새 계산은 **100 GPa** (새 세대 표지).  이미 낸 결과(Phase A 등)는 **10 GPa 로 계산했다고 밝혀 두고** 그대로 쓴다.
- **재현 실험 사전등록 (09-26).**  100 GPa 로 104 팔을 모두 다시 + 같은 GPU(kgy)에서 10 GPa 대조 32 팔.  물음 셋 — 순서 판정이
  그대로인가 · 영률 자체의 영향(±1.0 % 안인가) · 같은 조건 재압착의 잡음(±0.5 % 안인가).
- **진행 (09-27).**  압착 단계(MPM) 침대 8 개 통과 — 10 GPa 대조는 예전 결과와 소수 셋째 자리까지 같았다.  전도도 단계(STEP3)는 경로
  문제로 한 번 멈췄다가 10:10 재발사.  **결과는 아직 없다.**

## 3. 문헌 실험값과 절대값 대조 (Lee 2025) — "자릿수는 맞는다" ✅

**무엇을 했나.**  우리 모델의 전자 전도도 **절대값**을, 같은 재료계 양극을 실제로 눌러 만들어 잰 문헌값(Lee 2025, *Nat. Commun.*,
34 mS/cm)과 **같은 첨가제 조성**(VGCF 3 wt% · PTFE 0.5 wt%)으로 처음 비교했다.  압착 침대 2 개(09-22) → 전도도 계산 16 팔(09-23) →
판정(09-23 밤, 판정선을 먼저 커밋한 뒤 개봉).

**결과.**
- 모델 **70.53 mS/cm** (8 팔, 변동 0.5 % 미만) → 모델 ÷ 실험 **R = 2.074**.
- 사전등록한 구간: **0.5 ~ 2 = "밴드 안"(2배 안)** · 0.1 ~ 0.5 와 2 ~ 10 = **"자릿수 정합"(10배 안, Tier 1)**.
- R 이 2 를 **3.7 % 넘었다** → 판정은 **자릿수 정합(Tier 1)**.  결과를 본 뒤 판정선을 옮기지 않으므로 "2배 안에 든다" 는 문장은 **쓸 수
  없다**.  (런 전에 적어 둔 예상 1.5 ~ 2.5 에는 들었다.)
- 둘째 지표 **Q = 0.840** (PTFE 를 0.5 → 1 wt% 로 늘릴 때의 σ_e 비, 우리 생산 조성 59.28 mS/cm) → 런 전 예상(≈ 0.85) **적중**.
  문헌 곡선(0.44)보다 평평한 이유는 모델의 PTFE 가 **섬유 중심선 한 칸의 절연체**일 뿐이라 입자 표면을 덮는 효과가 없고, 이 격자에서
  실제 PTFE 부피의 0.40 ~ 0.41 만 차지하기 때문이다.
- **남은 것**: 공동연구자 실측과의 대조(대조 B)는 데이터 대기 — 판정선만 등록돼 있다.

## 6. 믹서 — "활물질을 코팅하면 가루가 더 잘 섞이나" ⏳

**무엇을 묻나.**  활물질 알갱이 표면을 고체전해질로 코팅하면(= 알갱이끼리 덜 달라붙으면) 가루가 더 잘 섞이는가.  39 각형 회전 드럼에
가루를 **층으로 나눠** 넣고(아래 활물질 · 위 나머지) 8 바퀴 돌리며, 섞인 정도를 **Lacey 혼합지수 M**(0 = 안 섞임 · 1 = 무작위로 완전히
섞임)으로 잰다.  달라붙는 세기는 **Bond 수 Bo**(점착력 ÷ 무게)로 나타낸다.

**조건(팔).**  `L0` 점착 0(음성대조) · `LB1/2/3` 점착 사다리 탐색 · `LA` "무코팅" 대리(내부 기준점 Bo_code 3.0, 시드 3) · `LC` "코팅" 대리
(활물질끼리 점착 거의 0, 시드 3) · `E0` 무작위로 넣고 돌리지 않은 기준(시드 3).  → 측정 10 런 + 기준 3 런 = 13 런(WSL).

- **09-21~22 사전등록.**  판정선과 저자 결정 둘을 **M 을 한 번도 계산하기 전에** 커밋했다 — R-3: 헤드라인을 "코팅" 이 아니라 "활물질끼리
  점착을 거의 끈 경우" 로 다시 정의 · R-4: `LA` 의 "문헌 앵커" 라벨 철회("내부 기준점" 으로).  ⚠ 런 13 개는 이 결정 **전에** 먼저 띄웠다 —
  사전등록 머리말 위반이었고 문서에 그대로 적혀 있다.

- "Wang 2020, *J. Power Sources* 470" · 3.0 mS/cm 의 옛 "단결정" 라벨 · 50 mS/cm 의 "문헌값" 라벨 — 모두 인용 금지 등록.
- "Minnmann 이 순수 SE 공극률 10 % 를 보였다" — 그런 실험값은 없다(`SELF-52`, 인용 금지 대상으로 정정 예정).
- 믹서를 **"코팅하면 더(덜) 섞인다"** 로 — 판정이 없다.  작은 차이를 **"효과 없음 · 동등"** 으로도 쓰지 않는다(판정 전, 쓸 수 있는 말은
  "분리되지 않음" 뿐이다).  `LH` 의 어떤 수치도 — 한 번도 돌리지 않았다.
- 믹서 검사 도구가 **"검증됐다"** 고 — Codex 3 라운드 HOLD 이다.
- 순수 SE 세 침대의 공극률을 결론처럼 — 넷째가 끝나야 판정이 선다.
- d_h 접힘의 **기울기 값**을 물리 상수로 — 비수렴이라 하한이고, 뜻이 있는 것은 R²(접히는가)뿐이다.
- **"MPM 을 300 MPa 까지 누르면 된다"** — 이미 반증됐다(위 10 절).

## 예상 질문 대응

- *"그래서 코팅하면 잘 섞이나?"* — 아직 모른다.  판정은 8 바퀴를 다 돈 뒤의 값으로만 나온다.  게다가 "코팅" 은 실제 코팅 공정이 아니라
  **점착을 낮춘 대리 실험**이다.
- *"Lee 대조는 성공인가 실패인가?"* — 자릿수는 맞았다(모델이 실험의 약 2.07배).  "2배 안" 에는 3.7 % 모자라 못 들었다.  2배쯤 큰 이유의
  후보는 모델의 PTFE 가 입자 표면을 덮지 못한다는 것이다(3 절 Q).
- *"원고 숫자가 틀렸는데 결론도 바뀌나?"* — 크기는 3배 이상 줄었지만 "SBE 가 DBE 보다 전류가 더 몰린다" 는 순서는 그대로다.
- *"지어진 인용은 어떻게 생겼나?"* — 04-29 코드 주석에 원문 확인 없이 들어간 출처가 여러 문서로 퍼졌다.  그래서 이제는 원문(SI 포함)을 본
  문헌 카드에서만 서지를 가져온다.
- *"VGCF 값을 바꿨으면 예전 결과는 다 틀린 건가?"* — 아니다.  영향이 0.25 % 이하로 작다는 것을 먼저 쟀고, 예전 결과는 "10 GPa 로 계산"
  이라고 밝혀 두고 쓴다.  확인용 재현 실험이 돌고 있다.
- *"시뮬레이션이 왜 자꾸 멈추나?"* — PC(WSL) 재시작 · 외부 정지 · 클러스터 제출 설정 오류였다.  멈춘 런은 **처음부터 다시 돌리지 않고**
  체크포인트에서 잇는다 — 이번 주에 그 절차를 스크립트와 세 관문으로 고정했다.
- *"Codex HOLD 가 세 번이면 캠페인이 틀린 건가?"* — 아니다.  HOLD 는 **판정 도구**가 가상의 나쁜 경우를 못 거른다는 뜻이고, 실제 런에서
  결함이 났다는 주장이 아니다.  도구를 고칠 때까지 그 도구로 결정을 내리지 않을 뿐이다.

| origin | 격자를 침대 안에서 살짝 밀어 놓는 위치 — 결론이 격자 배치에 기대지 않는지 보는 강건성 검사 |
| 사전등록 | 결과를 보기 전에 판정 기준을 문서로 고정해 커밋하는 것 |
| 봉인 | 결과를 내는 설정값을 미리 고정해 몰래 바뀌지 않게 하는 규약 |
| exact replay | 같은 입력 · 같은 코드로 다시 돌려 같은 답이 나오는지 확인 |
| ORDER-ROBUST | "조성이 늘면 값이 커지는 순서" 가 모든 조건에서 안 뒤집힌다는 판정 |
| Tier 1 · 자릿수 정합 | 모델 ÷ 실험이 10배 안 (0.1 ~ 10) — "밴드 안" (2배 안) 보다 느슨한 단계 |
| HOLD | 검토자가 "아직 이 도구 · 결과로 결론을 내리거나 다음 단계로 가면 안 된다" 고 내리는 판정 |
| 원장 | 결함(`findings.json`) · 주장(`claims.json`)을 번호로 관리하는 목록 — 철회된 숫자는 인용을 막는다 |
| Lacey 혼합지수 M | 칸별 성분비의 분산을 무작위 혼합의 분산과 비교한 값 (0 = 안 섞임 · 1 = 완전히 섞임) |
| Bond 수 (Bo) | 점착력 ÷ 알갱이 무게 — 크면 잘 뭉치고 작으면 잘 흐른다 |
| Popoviciu 한도 | 0 ~ 1 사이 값의 분산은 1/4 을 넘을 수 없다는 부등식 — 문턱이 원리적으로 닿을 수 있는지 미리 잰다 |
| 층상 투입 | 가루를 처음부터 섞지 않고 층으로 나눠 넣는 것 — "돌리면 섞이는가" 를 물을 수 있게 한다 |
| 체크포인트 재개 | 멈춘 계산을 저장된 중간 상태에서 이어 돌리기 (처음부터 다시 돌리면 이미 쓴 계산 시간이 사라진다) |
| sphere · union 공극률 | 입자 부피를 그냥 더하면(sphere) 겹침을 두 번 세어 음수까지 나온다 — 겹침을 한 번만 세는 정확한 계산이 union |
| d_h | 채워야 할 빈 공간 부피 ÷ 활물질 표면적 (= 채널 폭) — 서로 다른 침대를 한 축으로 접어 비교하는 데 쓴다 |
| 동결선 | 새 데이터를 보기 전에 옛 데이터로 미리 얼려 둔 예측선 — 새 결과를 여기에 대고 채점한다 |
| 하중분담 f | 누를 때 활물질 골격이 전체 압력 중 얼마를 떠받치나 |
| VGCF · PTFE · SDCP | 탄소섬유 도전재 · 절연성 바인더 · 원고 주제인 도전성 고분자 첨가제 |
