## 3. 해석 · 한정

1. **기공도 R² 0.990 · MAE 0.41 %p 는 설계 5 노브만으로 도달 가능한 수준이다** — 우리 GPR 0.980 · 0.54 %p.  누설을 의심할 근거는 없다 (입력 열은 미확인).
   추정 잡음 0.33 %p 는 비슷한 침대를 시드만 바꾼 산포 (2mAh_real_9 · 3 시드 ±0.31 %p · 구 부피 합 기공도 — 다른 침대 · 다른 규약이라 **크기 비교용 참고값**) 와 같은 수준 ⇒ MAE 를 더 줄이는 것은 시드 잡음 맞추기다.
2. **합친 R² 는 두 묶음 차이가 끌어올린다** — 기공도 분산의 35 % 가 묶음 사이 · 합친 모델의 64 행 R² 0.55 (기공도 5.4–9.4 %).  묶음별 R² · MAE 를 따로 봐야 한다 (README §5-3 · 130↔64 이동 성능).
3. **굴곡도 = `tortuosity_SE_wall` = Tortuosity (기하학적)** — 기하 최단경로 길이 / 그 쌍의 z 중심 간격 (README §4).  **수송 tortuosity factor 가 아니다** ⇒ P2D · COMSOL 의 Tortuosity 칸 (τ² 형 = tau2 · CLAUDE.md τ 명명 규약) 입력으로 쓰면 안 된다.  수송 값은 망 배치 (Codex 10-05 HOLD) 뒤.
   SHAP 범위 (+2.3) 가 관통 행 평균 1.58 · 최대 4.15 와 맞아 **빈칸 24 를 뺀 것**으로 보인다 (미확인) — 그렇다면 굴곡도 회귀는 관통 행만의 가지다.  SE 5 wt% 는 21 중 19 가 경로 자체가 없다 ⇒ 최적화에 굴곡도 회귀만 쓰면 경로 없는 영역에 유한한 τ 를 예측한다 → **관통 분류를 먼저** (README §5-2 B).
4. **CN 의 "SE 입경 · 소립 AM 입경" 1 · 2 위는 한 기하 효과다** — AM 한 개 표면에 SE 가 붙을 자리 수 = 크기비².  설계만으로 만든 개수 가중 크기비² 하나가 log CN 변동의 81 % · SE 함량을 더하면 98 %.  `am_se_cn_mean` 은 **개수 가중**이라 개수가 많은 소립 AM 이 좌우한다 (반경² 가중 = `am_se_cn_surface_weighted` · 다른 estimand).  SHAP 방향은 우리 순위 상관과 모순 없음.
5. **적격성 HOLD 121/194** — DEM 산출물 에뮬레이터 (`model_descriptor`) 로는 쓸 수 있으나 실제 전극의 물리 결론이면 HOLD 포함 · 제외 민감도를 함께 (README §3-7).  SE 많은 쪽 (64) 결론은 62/64 HOLD 행에 기댄다.
6. 표기 (슬라이드): 3 쪽 "EM 기반" → DEM · 4–6 쪽 제목 "방사형 양극재 미세구조 최적화" 는 이 데이터 (이중 입경 PC+SC NCM + LPSCl 복합양극 · DEM) 와 다름 · 5 쪽 "SE 입도이" · MAE 단위 %p · "DEM Porosity" = `porosity_union_exact_pct` (union).
