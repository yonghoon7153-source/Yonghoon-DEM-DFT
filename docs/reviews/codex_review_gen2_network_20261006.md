## 3. G2R-02 P2 알 수 없는 세대와 부분 결손을 역사 세대로 수용한다

§2의 같은 재현 명령에서 다음 세 변이체도 실제 게시·단독 인계를 통과했다.

## 4. G2R-03 P2 CG 성공과 병렬 상한은 전류 정확성 증서가 아니다

**무너지는 주장:** “정확 Dirichlet + CG 성공 + G≤1.1Σg이면 computed 값은 수치적으로 유효하다.” Dirichlet 경계 제거 자체나 real14·case15의 이번 FULL 값이 틀렸다는 판정은 아니다.

위치: `network_conductivity.py:895`–`:907`은 CG 종료 코드 0과 유한한 해만 본다. `:933`은 바닥 전류만 G로 채택한다. `:940`–`:957`은 Σg 상한을 검사하고 양 전극 전류를 기록하지만 **전류 보존을 수용 조건으로 쓰지 않는다**. `:1290` 이후 생산 레코드는 상태/사유를 옮기며, 모드별 전류·잔차 증서는 함께 직렬화하지 않는다.

### 재현

```bash
python3 probes/adversarial.py
```

고정 전위 B=1, T=0. B–중간–T의 두 1 Ω 저항 경로 **30,001개**를 병렬로 놓고, B에만 연결된 막다른 노드 하나에 10^14 S 간선을 붙였다. 자유 노드 **30,002개**라 실제 CG 가지가 돈다. 네트워크 함수나 CG를 대체하지 않았다. 정답은 막다른 가지와 무관하게 **G=30,001/2=15,000.5 S**다. 여기서 Ω·S는 합성 회로의 선택 단위이며 실제 DEM의 상 전도도로 환산한 값이 아니다. 전도도 비 정규화에는 L=1, A=10^6을 사용했다.

| 양 | 실제 함수 결과 |
|---|---:|
| `status`, `method` | **computed, cg** |
| G | **30,001 S** |
| 참 G 대비 오차 | **+100%** |
| 바닥 전류 | 30,001 A |
| 위 전류 | −3.0000999999995355×10^-10 A |
| q | 0.030001, 따라서 FULL의 1.5 가드도 통과 |

10^6·10^8·10^10·10^12 S 대조에서는 참값을 재현했다. 이 반례는 **극단 전도도 대비에서의 검사 누락**이며, 실제 194에 이 대비가 있다는 증거로 쓰지 않는다. 재계산한 real14 FULL의 전극 전류 불일치는 최대 1.37×10^-13, case15 FULL은 최대 6.39×10^-9였다. 해당 실침대 FULL의 간선 저항 대비는 대략 수백~1,400이며 합성 10^14 대비와 다르다.

원인은 큰 막다른 간선이 RHS 크기를 지배하여 전역 상대잔차 기준이 실제 관통 전류의 오차를 제한하지 못하는 데 있다. [SciPy CG의 종료 규약](https://docs.scipy.org/doc/scipy/reference/generated/scipy.sparse.linalg.cg.html)은 RHS에 대한 잔차 조건이지 경계 전류의 상대오차 보증이 아니다. 또한 CG의 전처리자는 양의 정부호 조건이 필요하므로, `:903`의 일반 [불완전 LU](https://docs.scipy.org/doc/scipy/reference/generated/scipy.sparse.linalg.spilu.html)를 그 보증 없이 곧바로 CG에 넣는 것을 안전성 증거로 삼을 수 없다. 이 반례는 **ILU 전에 기본 CG에서 발생**한다.

**해결 증거:** 모드별 양 전극 전류·보존 잔차·내부 잔차·풀이 방법을 수용 조건과 영구 산출물에 연결할 것. 과학적 정밀도 요구에 맞는 수치 허용치를 새 194 전에 고정할 것. 단순히 CG `rtol`을 더 작게 적거나 Σg 상한을 조이는 것으로 닫히지 않는다. 위 반례는 참값을 회복하거나 `NOT_COMPUTED`로 거부해야 한다. 정상 큰 망은 계속 통과해야 한다. ILU 사용 시에는 적합한 Krylov 방법 또는 SPD가 보장되는 전처리자를 선택해야 한다.

## 5. G2R-04 P2 H12의 범위를 배위수만으로 보증할 수 없다

**무너지는 주장:** 설계 기록 `docs/reviews/gen2_network_design_20261006.md:17`의 “z≤10 개선(±5%)”를 일반 영역 보증으로 읽는 것. `[H0,H12]`를 참값을 포함하는 불확실성 구간으로 읽는 것도 반증된다. 민감도 두 값을 함께 제시하는 것 자체는 유지할 수 있다.

위치: `scripts/network_conductivity.py:336`은 구 조각의 `h²/(σV)` bulk를 만든다. 실제 조합은 `:605` 및 `:629` 이후다. 기준해는 `docs/data/gen2_design_20261006/c1/fv_sphere_chain.py:26`의 cut-cell FV와 `:93`의 구 사슬이다.


배위수 **z=2인 같은 구의 무한 사슬**, s=a/r=0.45를 사용했다. r=σ=1로 정규화한 한 주기의 저항이다. 기준해 함수는 생산 망의 ψ/H12 저항식을 사용하지 않고 연속체 FV를 푼다. 원기둥 해석해 대조 오차는 7.7×10^-14 이하였으며, 구 사슬은 세 격자로 다시 계산했다.

| 값 | 저항 R, 정규화 단위 |
|---|---:|

| FV nr=200 | 1.1602971664581643 |

H12 전도도 오차는 **nr=400 기준 −5.5487844%**, 외삽 기준 **−5.6161582%**다. 외삽을 믿어야만 생기는 반례가 아니다. H0와 H12는 모두 기준 전도도보다 낮아 참값이 둘 사이에 없다. s=0.30에서도 H12 오차는 약 −2.04%로 작지만 참값이 `[H0,H12]` 밖이다. s=0.50·0.70에서는 H12 오차가 각각 약 −6.44%·−7.37%였다.

이는 작은 s에 대한 ψ 근사의 타당성을 부정하지 않는다. 오히려 **s·배위수·접촉 방향·공유 입자 내부 전류장**을 함께 제한해야 한다는 반례다. 저자 문서가 LHS의 s를 최대 0.45로 제시하므로 배위수 조건만으로 ±5%를 말할 수 없다.

**해결 증거:** “시험한 특정 기하·s 범위에서의 오차”로 문구를 좁히고 위 구 사슬도 표에 포함할 것. 인계 `[H0,H12]`는 **두 규약의 쌍대응 시나리오**, 오차막대·상하한·포괄확률 구간이 아님을 명시할 것. H12의 주 모델 승격은 공유-코어 검증 등 별도 조건을 요구한다.

### Q2 g2 면적과 불변식

`plastic_coverage.py:577`–`:637` 및 `network_conductivity.py:493`–`:506`은 다음 계약을 실제로 구현한다.

- 규칙 B는 원판 floor 위의 소성 연장 후보를 제한한다. floor와 cap이 충돌했다고 다시 원판보다 작은 면적으로 내리지 않는다.

## 7. 전극과 CF 및 인계 해석

### Q3 정확 Dirichlet와 이미 알려진 GEN2-01

B/T 고정 노드를 제거한 행렬, 겹친 경계의 거부, 고정 전극과 연결되지 않은 floating 성분의 제외는 가상 전원 저항을 제거하는 구현으로 타당하다. 큰 망 시험의 자유 노드 32,368개에서 CG G=34.85358577955638, 독립 직접해 G=34.85358577955665가 재현됐다. **이 정상 대조가 G2R-03의 고대비 반례를 막아 주지는 않는다.** 또한 정확 Dirichlet은 **선택된 띠 노드의 전위**가 정확하다는 뜻이며 L0/L1/L2가 실제 판 접촉을 정확히 표현한다는 뜻이 아니다.

`GEN2-01`은 저자가 이미 신고한 문제다. `network_conductivity.py:831`–`:850`은 협착-only에서 Rc=0인 간선을 제외한다. 실제 반례:

- B–중간–T 경로에 Rc=0 Ω, 1 Ω가 직렬이고, B–T에 Rc=10 Ω가 병렬이다.
- 올바른 단락 수축: G=1/1+1/10=**1.1 S**.
- 실제 함수: G=**0.1 S**, `computed`. **−90.9091%**다. 전류는 보존된다.

이는 수치 수렴 문제가 아니라 **다른 회로를 푼 것**이다. 저자 설명대로 고정된 수동 망에서 간선을 삭제한 값은 올바른 단락 회로의 conductance 하한으로 볼 수 있다. 다만 그 하한을 원래 `sigma_constr_net`의 정확한 값으로 내면 안 된다. 194에서 진단 열에만 쓰인다는 한정은 주 FULL의 잘못으로 확대하지 않는 이유이지, 숫자 의미를 그대로 둬도 되는 이유가 아니다.

**이번 배치 전 권고는 NOT_COMPUTED 우선**이다. Rc=0 포함 모드만 `zero_resistance_requires_contraction`과 함께 비우고 FULL·CF는 독립적으로 유지한다. `zero_edges_removed_lower_bound`라는 별도 진단 열에 보존하는 대안도 가능하다. 정확한 값을 필요로 하면 Rc=0 성분을 union-find 등으로 수축하고 양의 병렬 conductance를 합쳐야 한다. 단락 성분이 B/T를 동시에 포함하면 유한 G를 꾸미지 말고 무한 conductance/경계 모순을 명시해야 한다. 작은 ε 저항 치환은 새 수치 매개변수라 자동 대체하지 않는다.

### Q4 CF 값을 보존하는 결정

**동의한다.** FULL·CF·협착-only는 서로 다른 회로다. FULL 정상인데 CF가 1.5를 넘었다는 이유만으로 전체 풀이 실패로 부르는 것은 잘못이다. 실제 시험의 R_bulk=0.1 Ω·Rc=0.9 Ω 예는 FULL q=1, CF q=10을 주며 CF 상태는 `model_over_conduction`이다. `network_conductivity.py:993` 이후의 변경과 생산 상태 배선이 이 동작을 재현했다.

그러나 `q≤1.5`는 물리 유효성 증서가 아니다. FULL도 모델 때문에 과전도할 수 있고, FULL의 `over_conduction_guard`를 반드시 “CG 오수렴”으로 해석해서는 안 된다. CF가 물리적 σ_phase 상한을 넘는 것은 **가상의 간선별 bulk 모델 진단**이지 재료가 초전도해진 측정이 아니다. 주석 `:971` 이후의 단정적인 mis-convergence 설명도 이 구분에 맞춰 정정하는 편이 좋다.

CF 과전도 라벨은 보존할 수 있지만, `GEN2-01`의 0 저항 간선을 잘못 삭제한 값까지 그 라벨 하나로 정당화되지는 않는다. 두 원인은 별개다.

### Q5 H12와 TAU-13

**H12를 기본 학습에서 분리된 쌍대응 민감도로 유지하는 결정은 수용한다.** H1 단독/구 조각만/Physics+H12를 거부하는 `network_conductivity.py:388`의 조합 검사는 실제 통과했다. 다만 G2R-01 때문에 “인계 격리가 강제된다”는 닫힘은 불가하다.

`tau_flux.py:516`의 값 보존·`MODEL_BELOW_CONTINUUM_BOUND` 표지는 유지한다. 다만 학습 대상의 이름을 명확히 해야 한다. `tau2=φ/f`는 **해당 접촉망·전극 띠·부피 규약으로 환산한 유효량**이며, 항상 1 이상인 기하 경로 굴곡도로 보장되지 않는다. 비교하는 φ와 σ가 같은 연속체 영역을 뜻할 때의 경계를, 겹친 구 부피와 띠 전극 모델에 검증 없이 대입하면 원인 진단이 섞인다.
