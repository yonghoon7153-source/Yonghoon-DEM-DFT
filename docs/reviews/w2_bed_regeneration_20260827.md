# W2 침대 재생성 — 무엇이 바뀌었나 (측정, 2026-08-27)

목적: Table S3 를 새 첨가제 탄성계수 세대(`ADD_E_SET_20260818` — PTFE 0.30→1.80,
SDCP 23.6→9.00 GPa)로 재생성하기 위해 SBE·DBE 침대를 다시 압밀했다.  이 문서는 **그 재압밀이
실제로 무엇을 바꿨는지**를 잰 기록이다.  CL-56("침대 앵커 주의")이 여태 정성 경고였던 것을
숫자로 바꾼다.

## 1. 먼저 잘못 읽을 뻔한 것 — porosity 일치는 증명이 아니다

08-12 침대와 08-27 침대가 **소수점까지 같은 값**을 냈다:

| | SBE | DBE |
|---|---|---|
| 08-12 | porosity 7.86 % · wall_z 1.385 · 72.53 µm | 7.37 % · 1.385 · 72.53 µm |
| 08-27 | porosity 7.86 % · wall_z 1.385 · 72.53 µm | 7.37 % · 1.385 · 72.53 µm |

이것을 "침대가 안 바뀌었다 = W2 는 no-op" 으로 읽으면 **틀린다**.  scaffold 런에서
`porosity = 1 − solid/(area·(wall_z − FLOOR))` 이고 `solid` 는 씨앗 시점에 고정된 상수다.
두 런이 **같은 프레임에서 멈추면** porosity 는 산술적으로 같을 수밖에 없다.
⇒ 이 지표는 **판별력이 없다**.  (리포가 이미 배운 형태의 재현 — 일치를 증명서로 쓰면 순환이다.)

⚠ 정지가 기하로 결정된다는 것 자체는 별개의 기지 결함이다 (트랙 ② 플래튼 운동학 정지).
frame 5 의 `wallP ≈ 2.55 GPa` 는 target 0.30 의 8.5배이고 (`V/c_S = 1.94` = 플래튼이 전단파보다
빠르다) 정착 `wallP` 는 0.006~0.012 GPa = target 의 **2~4 %** 다.  ⇒ 절대 porosity 7.4~7.9 %
(실험 앵커 ~15.6 %)는 **과압축**으로 라벨해야 한다.  SBE·DBE 가 같은 속도·같은 정지 위치라
**비(ratio)에서는 공통모드로 상쇄**된다.

## 2. 판별력 있는 검사 — 점군 자체를 본다

`se_dump.npy` 는 SE 뿐 아니라 **전 MPM 점군**(첨가제 포함)이고 `phase.npy` 가 상을 구분한다
(`mpm3d_compaction.py:3583,3596`).

```
SBE se_dump.npy   815,072,300 bytes 양쪽 동일 (= 점 개수 동일)
  08-12  md5 d1b759720e7e3c80
  08-27  md5 8e53a0d57e9b1609     ← 다르다
```

⇒ **침대는 실제로 바뀌었다.**

## 3. 얼마나, 그리고 **어느 상이** 바뀌었나

점별 대응(67,922,681 점, 30만 균등 서브샘플), box→µm 환산 68.86 µm/box
(같은 런의 frame 0→5 에서 Δ두께 3.03 µm / Δwall_z 0.044 box 로 유도):

| phase | E 가 바뀌었나 | med 변위 | p95 | n (서브샘플) |
|---|---|---|---|---|
| 1 SE | 아니오 (1.53 고정) | 0.0003 µm | 0.0018 | 291,702 |
| 2 VGCF | **아니오** (10.0 고정) | 0.0003 | 0.0015 | 7,259 |
| 4 PTFE | **예** (0.30 → 1.80) | **0.0009** | **0.0108** | 1,039 |

전체: med 0.0003 µm · p95 0.0018 · max 0.0579 · 안 움직인 점 0.07 %.

★ **이것은 잡음이 아니다 — 음성 대조가 붙어 있다.**  SBE 에서 E 가 바뀐 상은 PTFE 하나뿐인데
**그 하나만** 3배(med)·6배(p95) 더 움직였고, E 가 안 바뀐 VGCF 는 SE 와 구분되지 않는다.
수치 잡음이라면 상별로 갈릴 이유가 없다.  ⇒ 새 E 세트가 압밀 물리에 실제로 들어갔다.

정합성 확인: 서브샘플 상 비율 PTFE 1,039/300,000 = 0.346 % × 67.9 M ≈ 235 k =
로그의 `PTFE 235,046 pts`.  SDCP(phase 5)는 SBE 에 **없다** — 대조 침대이므로 정상.

## 4. 그래서 Table S3 에 무슨 뜻인가

생산 격자 vox 0.15 µm = 150 nm 기준으로:

- p95 1.8 nm = **복셀의 1.2 %**
- max 58 nm = 복셀의 0.39
- SDCP 구 Ø300 nm 중심 이동 = 지름의 0.3 %

⇒ **침대 재생성만으로는 σ_e 비가 팔간 SE(0.1~0.35 %p)보다 작게 움직일 것으로 예상한다.**

⚠ 이것은 사전등록이 **아니다** — 판정선이 아니라 기대치 서술이다 (prereg §7 을 피하려고
명시한다).  W4 결과를 이 기대에 맞춰 재해석하지 않는다.

**W4 는 그대로 필요하다.**  W4 의 목적은 침대 교체가 아니라 **PTFE 스탬프 ON(centerline)**
이라는 규약 변경이고, 그쪽은 크다 (CL-49 실측: SBE σ_e 73.0 → 54.6 mS/cm, −25 %).
⇒ W4 에서 표가 크게 움직이면 그 원인은 **스탬프여야 하고**, 아니면 다른 무엇이 바뀐 것이다.

## 5. CL-56 정량화 (부수 소득)

"세대가 다른 침대를 섞지 말 것" 이 여태 정성 경고였는데, 이제 **섞였을 때의 기하 차이가
생산 복셀의 1.2 % (p95)** 라는 숫자를 갖는다.  ⇒ 세대 혼용은 여전히 금지하되(라벨 오류는
라벨 오류다), **그것이 만드는 σ 편차의 크기 상한**을 처음으로 말할 수 있다.

## 부록 — 남은 관측

- SBE payload 는 `pore-τ = None` 증거 게이트에서 정지 (closed-from-top 99.99 %).
  기지 현상 DR3-07/08 이고 **W4 와 무관**하다: 8팔 러너는 `se_dump.npy` 만 읽고
  (`sdcp_gain_vox015_8arm.sh:388`) `LEAN=2` 가 `--no-pore` 를 포함한다 (`:218`).
- `top% = -842` 같은 음수 진단값이 로그에 보인다 — 별개 항목, 미조사.

## 부록 B — 근접 사고: `latest_run` 우선순위 (2026-08-27, 안 터짐)

8팔 러너의 침대 선택은 **두 단계**다 (`sdcp_gain_vox015_8arm.sh:386-389`):

```bash
if [ -e "$KIT/latest_run" ]; then RUN="$(cd "$KIT/latest_run" && pwd)"
else RUN=""; for d in "$KIT"/run_*; do [ -f "$d/se_dump.npy" ] && RUN="$(cd "$d" && pwd)"; done
fi
```

`latest_run` 심링크가 **글롭보다 우선**한다.  그런데 오늘 두 압밀은 payload 단계에서
실패했다 (pore-τ 게이트).  킷이 `latest_run` 을 **성공 시점에만** 갱신한다면 그 심링크는
08-12 침대를 계속 가리켰을 것이고, W4 8팔이 전부 **옛 침대**로 돌았을 것이다 —
매니페스트는 새 규약(`_sph` · `_ptscenterline`)을 적고 격자는 옛 침대인 상태로.
A 트랙을 무효화한 것과 **정확히 같은 부류**다: 요청한 것과 실제로 쓰인 것이 다른데 로그가 조용하다.

실제로는 글롭 폴백이 최신을 골랐고 (SBE·DBE 둘 다 `..._20260827_...`), 사고는 안 났다.

⚠⚠ **정정 2026-08-28 — "아예 없어서 무사했다" 는 틀렸다.  링크는 실재한다.**
A2 3런을 위해 V100 에 킷을 옮기며 최상위를 처음 들여다보고 알았다:

```
kit_SBE/latest_run -> /home/ubuntu/sdcp/kit_SBE/run_VGCF3_PTFE1_20260812_204806_75857
                       ^^^^^^^^^^^^                          ^^^^^^^^  옛 침대
```

kgy 에는 `/home/ubuntu/` 가 없어 **끊어진 링크**이고, `[ -e ]` 는 심링크를 따라가므로 실패한다
⇒ 글롭 폴백 ⇒ 08-27 침대.  결과는 같지만 **위험의 성격이 다르다**:

| 옛 서술 | 실제 |
|---|---|
| 링크가 **없다** — 누가 새로 만들어야 위험해진다 | 링크가 **있고 끊어져 있다** — **경로가 생기기만 하면 되살아난다** |

★ 그리고 그 경로가 **바로 V100 의 홈**이다 (`/home/ubuntu`).  킷을 그 기계로 옮길 때 이
심링크를 함께 보냈다면 거기서는 링크가 **살아나** 러너가 **옛 침대**를 집었을 것이다 —
매니페스트는 새 규약을 적고 격자는 08-12 침대인 상태로.  A 트랙을 무효화한 것과 같은 부류다.
실제로는 `--exclude 'latest_run'` 으로 빼서 보냈고, V100 에는 08-27 런 하나뿐이라 글롭이
모호하지도 않다.

⇒ **규칙**: 킷을 다른 기계로 옮길 때 `latest_run` 은 **보내지 않는다**.  옮긴 곳에 침대가
하나면 글롭이 곧 정답이고, 둘 이상이면 **손으로 확인한 뒤** 링크를 새로 건다.

**규칙**: 8팔 런 시작 2분 안에 **선택된 침대 경로**를 확인한다 (OUTDIR 태그·스탬프 안내와 함께
3종 세트).  ⚠ 러너가 선택한 RUN 을 **로그에 안 찍는다** — 지금은 손으로 재현해서 봐야 한다.
러너가 그것을 스스로 출력하게 만드는 것이 후속 항목이다 (미착수).
