근거: `p1_g2c_mpi_stage2_registration_20261112.md` §§5–9, 개발 핀 `c559766bb506`, 앞 수령 `results_20261116/`, 이번 `metadata_20261116/`. 전체 자격 통과 표가 아니라 다음 구현·시험을 가르는 목록이다. 기존 네 계산을 반복하지 않는다.

소비자와 시험을 준비할 때의 입력 계약: 원 산출물을 읽기 전용으로 받고 `metadata 원문 SHA + 장부 원문 SHA + 각 OUT archive/compare JSON SHA + 실행 핀 + 대조기/MPI/덱 신원`으로 결속한다. 원 결과가 내용 판정을 이미 포함한 사실을 보존하며, 이후 만든 감사 도구가 과거 런을 사전등록 실험으로 바꿔 쓰지 않는다.

이번에는 위 미확인 경로의 코드를 작성/실행하지 않았다. 시도4 DONE까지 scripts/ 및 고정 가지 동결을 유지한다. 다음 고정 구현·소형 시험 이후 필요한 현장 자격 블록만 1저자에게 제공한다. A RT 문법 fixture와 실제 RJ는 앞 `docs/reviews/p1_g2cp_mpi_development_20261116/results_20261116/next_steps.md` §3 순서 그대로이며, 새 ibb 계산 명령을 이번 메타 수령만으로 발급하지 않는다.
