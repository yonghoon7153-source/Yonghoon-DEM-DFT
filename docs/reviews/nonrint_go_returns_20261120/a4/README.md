# A4 · 7:3 S0의 접촉 연속성 사전 셈

**A4 ⓡ PASS.** 잡 323957이 남긴 7:3 침대의 S0(step 3,200,000)에서 원 접촉 덤프와 복원 직후 접촉 덤프를 비교했다. 1저자가 WSL에서 기존 파일 네 개를 읽어 얻은 개발 자료다. 기준은 `docs/reviews/dem_unloading_ps45_prereg_20261009.md` §15-5b·§15-9 ⑥′다. 등록 문서는 이전 샌드박스를 본 뒤 이 문턱을 택했다는 이력을 공개한다. 이번 사전 셈의 수치를 보기 전에 문턱이 고정됐다.

| 등록 기준 | 반환에서 다시 확인한 값 | 판정 |
|---|---|---|
| S0 무순서 쌍 집합 일치 | 원본·복원·교집합 각각 562,605쌍, 누락·추가·일관 중복 0 | PASS |
| 전역 W ≤ 0.05 | 0.00000777052304046 · 문턱까지 0.04999222948 | PASS |
| 쓰기 당시 격자 6×4×1의 모든 칸에서 안쪽 하중 쌍 ≥100 | 24/24칸, 최소 15,164쌍 (x=1, y=2), 하한보다 15,064쌍 많음 | PASS |
| 위 칸 각각 W_c ≤ 0.5 | 최대 0.00000137981079130 (x=4, y=2), 문턱까지 0.49999862019 | PASS |

칸 번호는 0부터 센다. 접선력 변화량의 크기가 원 접선력 크기의 절반을 넘은 쌍(reset-like)은 685개, 전체 쌍 수의 0.121755%였다. W는 이 685쌍이 원 접선력 **크기의 합**에서 차지한 비율(무차원)이다. 전역 0.000777052%와 쌍 수 기준 0.121755%는 분모가 다르다. 앞선 11-02 같은 파일의 집계에서도 562,605쌍·685개였다. 상대 접선력 변화의 중앙값과 95백분위는 상대 허용 10⁻¹² 안에서 일치했다.

**전역 W가 최대 W_c보다 큰 이유.** 칸별 집계에는 두 끝이 모두 같은 칸 안에 있는 하중 쌍 476,040개만 들어간다. 전역에는 다른 칸을 잇는 86,551쌍과 경계 위치가 애매한 원자 2개에 걸린 14쌍도 들어간다(14는 쌍 수 차로 계산). 전역은 이 세 집합의 원 접선력 합으로 가중한 비율이다. 모든 안쪽 칸 비율이 전역보다 낮으므로 나머지 두 집합을 합친 가중 비율은 전역보다 높다. 반환에는 두 집합 각각의 하중합이 없어 어느 쪽이 차이를 얼마나 만들었는지는 추정할 수 없다.

## 수령·해석 범위

- 수령 폴더의 SHA256SUMS 4/4와 명령 rc 0을 확인했다. 두 덤프·쓰기 로그·원 덱의 전달 해시를 과거 기록 및 실행 핀 `851bfd571`의 소스와 대조했다. 판독 모듈을 해당 핀의 바이트와 헤더 수정으로 복원해 SHA256이 같은지도 확인했다. 두 원덤프는 1저자 WSL에서 전후 검산했다. 수령 측에서는 반환 JSON에서 24개 좌표의 유일성·표본수·전역 및 칸별 수치를 다시 판정했다. 근거는 `docs/reviews/dem_unloading_rj_g2c_cause_20261102/ibb_result_20261102.json`, `docs/reviews/codex_p1_ps73_identity_20261026/identity-receipt.json`, `docs/reviews/p1_rt_fixture_readback_return_20261120/README.md`다.
- 이 결과는 원래 파일로 값이 정해진 7:3 ⓡ의 사전 점검 1건이다. 실제 RT 경로 ⓣ, 다른 침대, 탈압 물리와 이력 전부의 복원은 미확정이다. 물리 비교에는 같은 시료의 고체 부피·면적과 하중별 또는 제거 후 지정 시점 두께가 필요하다.
- A3은 367546 원 위치 재판독 20/20, 원 잡은 FAILED 2:0이다. B의 두 최초 내용 판정은 366288·366290으로 고정돼 있고 `registered_conclusions_adoptable=false`다. A4는 새 RJ 시도 수에 들어가지 않는다. A5 다음 준비는 생산 후보에서 원 위치 재판독을 사전 점검에 결속하고 키트 후보 전체를 고정하는 것이다.
