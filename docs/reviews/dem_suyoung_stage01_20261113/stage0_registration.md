## 2. 측정점과 팔 매핑

아래 수는 메모 §4 단계3의 기존 계획값이다. 이번에 계산·적합·비준한 값이 아니다.

| 시험/목적 | 팔 | 독립변수와 필수점 | 판독 | 지위 |
|---|---|---|---|---|
| 3a 응답 비교 | S / F(µ0.5) | Φ_m=0.84,0.90,0.95 | 같은 Φ_m의 바닥 벽 응력 비 R | 판정 |
| 3a NZ22 정합 | F(µ0) | Φ_d=0.90,0.95 | 정본의 고정 문헌 기준 대비 응력 비 | 정합 띠; Φ_m은 보고만 |
| 3b κ1 응답 비교 | S / F(µ0.5) | Φ_m=0.86,0.90,0.94 | 바닥 벽 응력 비 R | 판정 |

| 3b κ0.2 덧규칙 | A(µ0.5) / F(µ0.5) | P/E=0.4 | Δφ=Φ_m(F)−Φ_m(A) | 판정; φmax 적합은 보고만 |
| 3b 정합 | F(µ0), κ1/κ0.2 | P/E=0.25 / 0.4 | Φ_d, 정본 CB20 띠 | Φ_m·CB22 대조값은 보고만 |
| 3c 배위수 | F만, µ0/0.5 | 정본의 두 속도 규약 | Z 차 | 보고만, 갈림 제외 |

같은 충전 ID를 해상도·팔 사이에서 유지한다. 필수 집합 = 등록한 시험 × 팔 × 충전 × 해상도 × 측정점/판독 종류다. 3a의 하중 중 판독에 단계4의 300 MPa 서보/판 고정 이완을 잘못 붙이지 않는다. Φ_m과 Φ_d를 번갈아 골라 통과시키지 않는다.

## 3. 판정 순서와 실패 기록

1. 등록·신원·필수 필드가 없으면 NOT_REGISTERED/IDENTITY_MISMATCH로 보류한다. 승인이나 합격으로 기본 처리하지 않는다.
2. 수치 실패·입력 불능·비유한 값·실행 중 안전 불변식 위반이면 TECHNICAL_FAILURE이며 유한 잔여값도 완료 결과로 승격하지 않는다. 어느 물리 등급보다 기술 실패가 먼저다.
3. 상한 중단으로 목표점 미도달이면 해당 점 목표 응력은 미확정이다. Φ_cap은 중단 위치 보고용이며 목표 응력의 한쪽 경계를 만들지 않는다. 해당 점 중간, 해당 F 띠 점 미정; 다른 점의 독립 경보는 보존한다.
4. 잡음 분류·버리는 점·수렴/구간·등급·시험/전체 갈림은 정본 §4 단계3 및 부록D 순서를 따른다. 이 초안은 새 판정기를 만들지 않는다. 누락을 잡음으로 보거나 유효 충전 수를 줄여 평균을 만들지 않는다. 등록된 잡음 제외는 까닭과 원 ID를 남기는 별도 규칙이다.
5. 필수 상자 비교점의 누락·중복·신원 불일치·실패·비유한 값은 미완전이다. 허용된 재시도 뒤에도 미완전이면 F-비교미확정으로 F 채택을 막는다. 실패를 빼고 평균·차를 계산하지 않는다.
6. U6(c)의 보고 자체는 합격이 아니다. U5(c) 여덟 의무·해상도·순열·허용폭 등록이 완전해야 하며 위반/누락이면 단계3 및 해당3D F 판정을 막는다.
7. 재시도는 정본이 허용한 해당 경우만 별도 등록한다. 모든 실패에 공통 자동 재시도1회를 부여하지 않는다. 결과 뒤 새 충전 추가·사다리 선택·판독 변경으로 통과를 만들지 않는다.

## 4. 동결 전에 필요한 완전성

registration_template.json은 DRAFT_NOT_FROZEN, scientific_run_count=0이다. 미확정 핵심 칸이 하나라도 있으면 freeze_record는 null이다. 실제 동결 기록에는 정확한 코드·입력·프로필·환경·필수 집합·검토 핀을 연결한다. 동결 뒤 변경은 원 기록을 고치지 않고 새 ID로 사유와 비교 범위를 남긴다. 이 문서 작성·push는 동결 승인이나 실행 GO가 아니다.
