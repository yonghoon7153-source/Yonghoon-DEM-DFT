### 2-1. 탐색 격자·손실·동점·도달불가 (전부 결과 전 고정)

- **노브 ①** `--step3-ptfe-block-um` = `b` ∈ {0, 0.06, 0.12, 0.17, 0.24, 0.30, 0.36} µm
  (⚠ `b` 는 EDT 라 **복셀로 양자화**된다 — 연속 최적화가 아니다)
- **노브 ②** `--sigma-ion-sdcp` = `r·q`, `r` ∈ log-grid `[0.01, 1.0]` 15점
- **손실** = `max_i |log(σ_pred,i / σ_target,i)|` (두 표적의 **최악값**.  합이 아니다 —
  합은 한쪽을 희생해 다른 쪽을 맞추는 것을 허용한다)
- **합격** = 두 표적 **모두 ±5 %** 안
- **동점** = 손실이 1e-6 안에서 같으면 **`b` 가 작은 쪽** (덜 개입하는 쪽)
- **도달불가** = 표적이 인접한 두 격자점 **사이**에 있으면 → **`UNREACHABLE` 로 보고하고
  가까운 쪽을 고르지 않는다.**  브래킷 두 값을 적는다.
  ⚠ 구 동결이 정확히 여기서 걸렸다 — 목표 formation factor 0.2717 이
  `0.4251@0.12` 와 `0.2008@0.17` 사이였고 선택값 0.17 은 표적 대비 **−26.1 %** 였다.
  그것을 "보정 성공" 으로 적으면 안 된다.

### 2-2. 시드 4개가 재는 것 / 못 재는 것

⇒ SE(log10) 를 "전체 불확실성" 으로 쓰지 않는다.  ρ 감도 3점은 **따로** 보고한다.

## 3. 이식 단위 — **단일 불변량은 없다** (D-3)

세 후보가 배타적이 **아니다**:

```
0.62/3.57 = 0.173669      (동결 계의 상대비 r)
0.62/3.00 = 0.206667      (생산 q 에 절대값을 그대로 옮긴 경우)
0.173669 × 0.003 = 0.000521008   (생산 q 에서 r 을 보존한 경우)
```

고정 격자·BC 의 선형 FV 에서 **모든 상을 같은 배수로 바꾸면 σ_eff 도 같은 배수**이므로
정규화된 응답의 자연 변수는 **`r`** 이다.  ⇒ *표현이 완전히 같다는 조건에서만*
`0.000521` 이 `0.00062` 보다 일관된 재척도다.

⚠⚠ **그런데 펠릿→전극에서 표현이 바뀐다.**  같은 표적(2.86/3.57)을 Maxwell–Garnett
형상으로 역산하면 `r = 0.01837` (σ = 6.56e-5) 로, RSA 역산의 `0.1737` 보다 **9.45배 작다.**
두 전도상이 함께 수송할 때 intrinsic contrast 와 microstructure 효과는 **엄밀히 분리되지
않는다.**

⇒ **계약 단위는 튜플이다**:

```
(q, r, T_ref, morphology, raster/stamp, vox, BC, plate_rule)
```

- `0.000521` 은 **provisional prior (smoke 전용)** 로만 쓴다.
- **최종 8팔 값은 production-convention 에서 `r` 을 다시 식별한 뒤** 정한다.
- 어느 숫자도 *"이식된 물성"* 으로 적지 않는다.

## 4. 식별 가능성과 holdout (D-2)

### 4-1. 지금 데이터로 무엇이 식별되나

| 관측량 | `∂y/∂σ_ion(SDCP)` | 쓸 수 있나 |
|---|---|---|
| Fig 2f 펠릿 이온 3점 | **≠ 0** | ✅ 유일한 직접 앵커 |
| Fig 2i 펠릿 전자 3점 | **= 0** | ❌ 전자축 (표가 분리돼 있다) |
| Fig 4d SSRM | **= 0** | ❌ 전자 관측량 |
| Fig 4c `R_ele` | 조건부 | ⚠ raw 스펙트럼에서 `R_i` 를 분리해야 한다 |
| Fig 4b | — | ⛔ **우리가 예측할 대상** — 앵커로 쓰면 순환 |

⇒ **Fig 2f 두 표적 · 노브 둘 = 정확결정.**  holdout 이 **없다.**

### 4-2. 그래서 지금 주장할 수 있는 것

> **`pellet-calibrated prospective electrode prediction`**

`electrode-validated` 는 **쓰지 않는다.**  이 문구를 §6 판정과 원고 양쪽에 강제한다.

### 4-3. holdout 을 얻는 길 (택일, 둘 다 아직 없음)

- **ⓐ 조성 2×2** — PTFE {0.5, 1.0 wt%} × SDCP {0, 0.5 wt%}, AM·VGCF 고정, SE 가 질량 보상.
  SDCP=0 두 조건으로 `b` 식별 → SDCP 있는 **한** 조건으로 `r` 식별 →
  **남은 SDCP 조건을 prospective holdout 으로 유지**.  가능하면 SDCP 2 농도로 dose-response.
  ⇒ **새 실험 측정이 필요하다** (측정 요청 항목).
- **ⓑ Fig 4c raw 스펙트럼** — 보고된 `R_ele` 가 아니라 **전자차단 조건의 `R_i`**.
  회로/TLM · 주파수 범위 · weighting · 두께/면적 · 압력/온도 · bounds ·
  synthetic parameter-recovery 를 **결과 전에** 등록해야 쓴다.

⚠ *"생산 규약으로 다시 만든 펠릿 coupon"* 은 raster/BC 전이 문제를 줄이지만 **그 자체는
여전히 calibration 이다.**  별도 SDCP 전극 관측량이 남아야 validation 이다.

## 5. 온도 계약 (P1)

- **모든 D13 런은 25 °C.**  `--temp-c` · `--ea-ion-ev` · `--allow-mixed-t-ionic` 를
  **base argv 에서 금지**한다 (있으면 abort).
- 근거: payload 는 `--sigma-ion-se` 를 **T_ref 값**으로 받아 온도 보정한다.  60 °C 면
  `0.003 → 0.0143553` 이고 SDCP/SE 비가 `0.1737` 이 아니라 **0.04319** 가 된다.
- **영수증이 기준값과 적용값을 분리해야 한다** — 지금 러너는 기준 입력을 적용값 키
  `sigma_ion_se_S_cm` 에 쓴다.  그것을 고치기 전에는 D13 을 돌리지 않는다.

## 6. 판정선 (결과 전 등록)

| | 조건 | 판정 |
|---|---|---|
| **보정 성공** | 두 이온 표적 **모두 ±5 %** 안 | `CALIBRATED` |
| **도달불가** | 표적이 격자 인접점 사이 | `UNREACHABLE` + 브래킷 (가까운 쪽 선택 **금지**) |
| **보정 실패** | ±5 % 밖이고 도달불가도 아님 | `FAILED` — **그 자체가 결과다** |

**예측 (노브 없음, v1 §3-2 유지)**: 같은 펠릿의 **전자 3점** (0.30 / 0.12 / 1.53 ×10⁻⁷ S/cm).
남은 자유 노브는 `--sigma-sdcp` **하나**뿐이라 3표적 = **2 자유도 과결정**.
- **h1**: 세 점 모두 ±30 % 안 → 예측 성공
- **h0**: 하나라도 **2배** 밖 → 예측 실패
- 사이 = `INDETERMINATE`
