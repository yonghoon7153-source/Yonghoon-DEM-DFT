## 해석과 아직 못 정한 실제 값

Q1–Q5는 비활성 정의 제안의 선택이다. 실제 후보/쌍 명부·선행 여섯 식별·노출 이력·원 덱/계보/계수·예정 시간/출력 규약이 채워지고 독립 반박 검토·1저자 비준을 받기 전 완성된 사전등록은 아니다. Q3는 기존 v0의 미정 평형 요건을 통과로 바꾸지 않으며 이름·분석 범위를 좁히는 제안이다. Q4의 블록 범위는 신뢰구간이 아니다. 정확 일치 쌍이 없으면 결과를 보기 전부터 억지로 만드는 대신 미식별로 남긴다.

Q6: 기존 재고 명령은 바이트 그대로다. LPI-A01의 최초 audit 원인은 여전히 미확정이며, regex/디렉터리/파일시스템 시간 상한도 미해결이다. 현재 독립 수용은 Windows 모의 범위이며 실제 WSL/ibb 자격이 아니다. 향후 자격 시험은 과학 값이 없는 고정 POSIX fixture에 한정하고, 실제 호스트에서 무한 대기/부분 JSON/rc2 시 자동 재시도하지 않는 중단·회수 절차와 예산을 먼저 합의한다. 이번에는 새 wrapper·timeout 값·명령·실행을 만들지 않았다. WSL30 성공을 전체214 성공으로 쓰지 않는다.

Q7: A는 원 실행의 canonical log.liggghts를 출처/재개 사슬로 사전 선택하는 경로이며 좋은 압력 줄이 있는 로그를 고르는 일이 아니다. 선택 후도 B7이 REFUSED면 유지한다. C는 중복·재개 사슬 소비자 변경이며 B7 핀/등록 변경과 새 시험/외부 검토가 필요하다. 기존 봉인 폴더에 덮어쓰기·손으로 TSV 합치기·REFUSED 삭제는 어느 선택도 아니다.
