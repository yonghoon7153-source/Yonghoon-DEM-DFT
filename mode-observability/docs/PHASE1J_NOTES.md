# Phase 1j — 환산을 세웠다. **12° 는 전류와 무관하다** (이번엔 단서 없이)

**정본은 `mode-observability/results/phase1j/` 의 CSV 다.** 아래 숫자는 사본이며
인용 근거가 아니다. 재현: `python3 mode-observability/phase1j_normalization_bridge.py`

## 무엇이 막혀 있었나

Phase 1f 와 1g 가 **같은 하나의 미제**로 수렴해 있었다 — 두 `x` 정규화 사이의
환산이 없다는 것. `build_reference_interps("halfcell")` 은 **전극 전체**를
`[0,1]` 로, `"grid"` 는 **셀이 실제로 쓰는 창**을 `[0,1]` 로 정규화한다.

## ① 환산은 이미 저장소 안에 있었다 — 봉인된 두 캐시의 양 끝

Phase 1h 는 `src/inventory.py` 를 단서로 지목했는데, **더 곧바른 자리가 있었다.**
셀의 화학량론 창은 **완충·완방 두 상태**가 못 박고 있고 둘 다 봉인돼 있다:

| 끝 | 어디 |
|---|---|
| 완충 (100 % SOC) | `configs/base.yaml` 의 `baseline.{pe_init_conc, ne_*_init_conc}` |
| 완방 (0 % SOC) | `.cache/discharged_state/a8e262f7d6aa4beb.json` (`source_digest ea35ff4f39b97489`) |

각 전극의 `*_max_conc` 로 나누면 **전극 전체 좌표에서 본 셀의 창**이 나온다.
NE 는 복합이라 `src/halfcell.py:143` 과 **같은 용량 가중 평균**을 쓴다
(`z = (q_gr·x_gr + q_si·x_si)/(q_gr+q_si)`).

```
PE   y₁₀₀ = 0.269999   y₀ = 0.926088   창 폭 0.656090   → 전극의 65.61 % 만 쓴다
NE   z₁₀₀ = 0.970083   z₀ = 0.003112   창 폭 0.966970   → 전극의 96.70 % 만 쓴다

s_창_PE = (y − 0.269999) / 0.656090
s_창_NE = (0.970083 − z) / 0.966970          (방전방향 정렬 — grid 규약과 같다)
```

`[해석]` **이 비대칭 하나가 Phase 1g 의 C 판이 왜 튀었는지를 설명한다.** 양극은
전극의 2/3 만 쓰는데 `"halfcell"` 정규화는 그 전체를 `[0,1]` 로 눌러 넣는다.
그래서 (a) `LAM_PE` 감도가 `1/0.656 ≈ 1.52` 배로 부풀고, (b) 재구성이 **셀이 안
가는 34 %** — `u_pe` 가 5.68 V 까지 가는 가파른 구간 — 을 평가한다. 음극은 96.7 %
라 거의 온전하다. Phase 1g 가 **`LAM_PE` 열만 8.38 → 50.17 로 6배 뛰고 NE 는
10.71 → 10.98 로 거의 안 움직인다**고 적은 것과 방향이 맞는다.
(다만 6배 중 1.52배 말고 **나머지를 정량으로 쪼개지는 않았다.**)

## ② 검산 — 환산이 맞으면 재구성이 실제 곡선과 겹쳐야 한다

pristine 을 각 reference 로 재구성해 실제 reference 곡선과 뺐다 (288점):

| reference 판 | 평균 \|Δ\| | 최대 \|Δ\| | 양수 비율 |
|---|---:|---:|---:|
| `grid` (창 정규화·유한전류) | 0.0 mV | 0.0 mV | — |
| `halfcell` (전극 전체) — **Phase 1g 의 C** | **175.3 mV** | **475.2 mV** | 95 % |
| ★ **셀 창 재정규화** (이번 판) | **18.7 mV** | **53.9 mV** | **100 %** |

`grid` 행의 0.0 은 결과가 아니라 **항등식**이다 (그것이 곧 그 곡선이다).

`[해석]` **마지막 행의 "100 %" 가 판정이다.** 288점 **전부**에서 재구성한 무전류
OCV 가 측정 pOCV 보다 **위**에 있다. 0.05 C 방전이면 측정 전압이 평형보다 낮아야
하므로 **부호가 한쪽으로 완전히 몰린 것은 과전압의 서명**이고, 크기 18.7 mV 도
그 C-rate 에 맞다. 즉 **남은 차이는 좌표 오차가 아니라 물리다.**
반면 기각된 `halfcell` 판은 175 mV·475 mV 에 부호도 95 % 로 섞여 있다 — 그것은
과전압으로 설명되지 않는다.

> **⚠ 2026-09-04 Phase 1k 소급 경고 — 이 판은 `modes_to_params()` 를 통과한다.**
> 그 함수는 `src/fitting.py` 헤더가 **"역함수 — 테스트·진단용, 'paper' 규약"** 이라
> 못 박은 것이고, 그 규약의 합성 격자 평균 |오차| 는 **0.128**(production 이 쓰는
> `"derived"` 는 **0.012**). 게다가 **production 에는 모드→창 사상이 아예 없다** —
> 창 좌표를 직접 맞추고 모드는 사후 변환으로 얻는다.
> 그러므로 **아래 절대 각도에는 그 규약의 몫이 섞여 있다.** 이 라운드는 그것을
> 신고하지 않았다 — 여기서 신고한다.
> **비교는 살아남는다**: 같은 규약·같은 스텝에서 reference 만 바꾼 짝(B ↔ D)은
> 규약의 몫이 약분된다. 약해지는 것은 **층을 건너는** 비교(시뮬 A ↔ 대수 D)다.
> (`docs/PHASE1K_NOTES.md` 경계 2)

## ③ 그래서 null 방향 — Phase 1g 가 못 닫은 절반을 닫는다

같은 창 대수, 같은 관측 구간, **reference 만 바꿔서**:

| 판 | reference | 전류 | 열 노름 (V/단위) | 조건수 | `u_min` | ∠(1,1,1) |
|---|---|---|---|---:|---|---:|
| **B** | 격자 (PyBaMM 유한전류) | 있음 | 18.50 · 8.38 · 10.71 | 8.69 | [0.545, 0.451, 0.707] | **10.56°** |
| ★ **D** | **셀 창 평형 OCP** | **없음** | 17.98 · 9.03 · 10.27 | 10.37 | [0.549, 0.418, 0.724] | **12.54°** |

```
B → D  (전류를 **완전히** 뺀다)    10.56° → 12.54°    Δ +1.98°
```

그리고 Phase 1g 의 A → B 와 이으면 사슬 전체가 이렇다:

```
A  PyBaMM 전 시뮬 · 유한 전류        12.04°
B  순수 창 대수 · 유한전류 reference  10.56°   (A→B  −1.48°)
D  순수 창 대수 · 무전류 reference    12.54°   (B→D  +1.98°)

A → D 순변화  **+0.50°**
```

## 판정 — Phase 1g 의 자기 한계 ①을 **철회한다**

Phase 1g 는 이렇게 신고했다:

> `[인용]` "B 판에도 동역학이 남아 있다. reference 곡선 자체가 PyBaMM 유한 전류
> 산물이다. … 그래서 **'12° 가 전류와 무관' 이 아니라 '모드→곡선 경로의 동역학과
> 무관'** 이 정확한 문장이다."

**그 한계가 닫혔다.** D 판의 reference 는 전류가 **어디에도 없는** 평형 반쪽전지
OCP 이고, 그것으로 갈아 끼워도 각이 12.54° 다 — 시뮬 원본의 12.04° 와 **0.50°**
차이다. 그러므로 이제 쓸 수 있는 문장은

> **12° 기울기는 전류와 무관하다. 창 모델의 구조에서 온다.**

이고, Phase 1f 가 Phase 1e 의 한계 ②를 철회했던 것과 같은 형태의 **한계 철회**다.

`[해석]` 남은 후보는 **음극 제한**과 **양극이 전극의 65.6 % 만 쓴다는 비대칭**
둘이다. `u_min` 이 `LAM_PE` 쪽으로 가장 작게 기울어 있는 것(0.418)이 후자를
가리키지만, **둘을 갈라 재지는 않았다.**

## 이 판정이 말하지 않는 것 (경계)

1. **Phase 1f 는 이것으로 안 열린다.** 여기서 세운 환산은 **우리 셀의** 것이고,
   Birkl 이 필요로 하는 것은 **그의 셀의** 창 상수다 (그의 Table 5 는 전극 전체
   좌표, 식 (7)–(10) 은 셀 창 좌표). 그 두 상수는 여전히 인쇄돼 있지 않고
   참고문헌 **[33]** 이 필요하다. **1g 는 닫혔고 1f 는 안 닫혔다.**
   다만 새 길이 하나 생겼다 — Birkl 의 **구조**(식 7–10 의 형태)를 그의 상수가
   아니라 **우리 환산**으로 우리 좌표에 얹는 것. 그건 다음 라운드다.
2. **18.7 mV 를 과전압이라고 부른 것은 부호와 크기에 근거한 것이지, 과전압
   모형으로 계산해 맞춘 것이 아니다.** 다른 계통 오차가 같은 부호로 섞여 있을
   가능성을 배제하지 않았다.
3. **한 동작점(pristine)·한 스텝(H = 0.02)·한 화학.** 그리고 Phase 1h 가 잰
   스텝 의존성(각이 4.61°~21.89° 에 흩어진다)이 여기도 그대로 걸린다 —
   **+0.50° 라는 차이는 그 산포보다 훨씬 작다.** 그것이 이 판정을 **강하게**
   만든다(전류를 빼도 각이 산포 안에서 안 움직인다)는 읽기와, 그 산포 때문에
   **0.50° 자체는 의미를 못 준다**는 읽기가 **둘 다 옳다.** 여기서 주장하는 것은
   앞쪽뿐이다.
4. **완방 캐시가 정본이다.** `configs/base.yaml` 의
   `_original_hardcoded_do_not_use` 값(36.7 / 3446.3 / 58439.9)은 **쓰지 않았다** —
   캐시의 실측값(36.6497 / 3446.0842 / 58439.8739)을 읽었다. 우연히 거의 같지만
   그 상수는 "사용 금지" 로 표시된 것이다.
