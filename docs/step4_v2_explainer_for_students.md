# STEP4-v2 충방전 시뮬레이션 — 처음 보는 사람을 위한 해설서

> 대상: 이 프로젝트를 처음 접하는 대학원생.  전기화학 기초(전지 = 산화/환원 + 이온/전자
> 분리 수송)만 안다고 가정하고, 우리 시뮬레이션이 **무엇을, 왜, 어떻게** 계산하는지

## 0. 한 문장 요약

**실제 3D 전극 미세구조(입자 1,271개, 계면 50만 개) 위에서 "정전류를 만들 전압을 찾고
→ 각 계면의 반응 분배를 풀고 → 그만큼 입자들을 리튬화하고 → OCV가 내려간 만큼 전압이
내려가는" 루프를 돌려, 방전곡선 V(Q)를 미세구조로부터 직접 계산한다.**

상용 툴(COMSOL P2D/DFN)과의 차이는 하나다: 그들은 전극을 균질한 스펀지로 뭉개고 반응
분포를 이론 파라미터로 가정하지만, 우리는 DEM/MPM이 만든 **진짜 구조** 위에서 반응
분포가 **매 스텝 계산 결과로 나온다**.  그래서 "어떤 입자가 소외되는가", "배선이 나쁘면
어디부터 무너지는가" 같은 질문에 답할 수 있다.

## 1. 무대 — 복셀 전극이란

우리 파이프라인의 앞 단계들이 무대를 만든다:

| 단계 | 하는 일 | 산출물 |
|---|---|---|
| STEP1 (DEM) | 분말 압축 시뮬 — AM/SE 입자의 실제 위치·반경 | 입자 좌표 |
| STEP2 (MPM) | SE의 소성 변형 압밀 + 첨가제(VGCF/PTFE/SDCP) 시딩 | 압밀 침대 |
| STEP3 (복셀화) | 0.4 µm 격자로 래스터화 → 전도망 풀이 | σ_e, σ_ion, 전류밀도 장 |
| **STEP4 (이 문서)** | **그 위에서 시간전개 충방전** | **방전곡선, SOC 장, 반응분포** |

STEP4가 받는 격자(`step4_grid.npz`)에는 복셀마다 "여기는 AM / SE / VGCF / SDCP / 공극"
이라는 딱지와, 어떤 입자에 속하는지(입자 id)가 붙어 있다.  전형적 크기:

- 자유도(전위 미지수) ≈ **290만 개** (전자 전위 + 이온 전위)
- AM 입자 **1,271개**, AM|SE 반응 계면(Butler–Volmer 면) **~50만 개**
- 전극 두께 72.5 µm, 면적용량 ≈ 3.1 mAh/cm²

두 개의 "도로망"이 있다는 게 핵심 그림이다:

```
   분리막(위)  ← Li⁺ 는 여기서 들어옴
   ┌─────────────────────────┐
   │  이온망: SE(+SDCP)       │   ← φ_i (이온 전위)가 정의되는 곳
   │     ↕ 50만 개 BV 계면    │   ← 여기서 이온↔전자 "환승"
   │  전자망: AM+VGCF+SDCP    │   ← φ_e (전자 전위)가 정의되는 곳
   └─────────────────────────┘
   집전체(아래) ← e⁻ 는 여기서 나감
```

방전 전류는 **릴레이**다: Li⁺가 분리막에서 이온망을 타고 내려오고, 전자가 집전체에서
전자망을 타고 올라가서, 어느 AM|SE 계면에서 만나 "AM 속의 Li"가 된다.  총 전류는 두
망에서 같아야 한다(직렬) — 다른 것은 **어디서 만나느냐(반응 분포)** 뿐이다.

### BV 면은 어떻게 정해지나 (`step4_dyn.py` CellSystem)

반응이 일어나려면 같은 표면 요소에 **전자 접근**(AM 내부)과 **이온 접근**(SE/SDCP)이
동시에 있어야 한다.  그래서 BV 면의 정의는:

> **AM 복셀(sid 1·2)과 이온전도 복셀(sid 6=SE, 5=SDCP)이 축 방향으로 맞닿은 복셀 면** —
> 단, 양쪽 모두 각자의 판-연결(percolating) 성분에 속할 때만.

- 3축 × 양방향으로 인접쌍을 훑어 면마다 (전자쪽 셀, 이온쪽 셀, **AM 입자 id**, 면 중점
  µm 좌표)를 기록한다.  면적은 균일하게 A_face = vox² = 0.16 µm².
- **AM|SDCP 면도 반응 면이다** (SDCP가 이온을 나르므로) — DBE의 반응면 +18%
  (425,340 → 503,915)가 바로 "SDCP가 이온-소외됐던 AM 표면을 반응 가능하게 만든" 효과.
- 고립 SE 주머니에 붙은 면은 자동 제외(판-연결 조건) → 세는 것은 "기하 접촉"이 아니라
  **반응-접근 가능(reaction-accessible) 계면**이다.  BV 면이 하나도 없는 입자 = dead AM.
- 정직한 주의: 구를 0.4 µm 복셀로 래스터화하면 표면이 계단이 되어 축-정렬 면적 합이
  매끈한 구 표면적보다 ~1.5× 크다(staircase 인자).  같은 래스터화를 쓰는 SBE↔DBE
  **상대 비교에서는 상쇄**되고, 절대 비교(pybamm 트윈)에서는 캐비엇으로 명시한다.

## 2. 방전 한 스텝의 해부 — 6단계 루프

시뮬레이션은 아래 여섯 단계를 시간 스텝마다 반복한다.

### ① 목표 전류 (정전류 운전)

1C에 해당하는 총 전류 I_target을 고정한다 (유도는 §3).  실험의 "정전류 방전기"와 같다.

### ② 전압 탐색 — 우리가 돌릴 수 있는 손잡이는 V뿐

장비도 우리도 전류를 직접 꽂을 수 없다.  제어 가능한 것은 집전체 전위 V_app이고,
전류는 그 결과다.  그래서 "V를 얼마로 두면 I_target이 나오나?"를 수치적으로 찾는다
(단조함수라 괄호법/Illinois가 안전; 로그의 `ev 6~8` = 이 탐색에 쓴 전압 후보 수).

### ③ 전위장 풀이 — 두 도로망 + 50만 환승역

후보 V마다 다음 연립계를 Newton 반복으로 푼다:

- 전자망: ∇·(σ_e∇φ_e) = (계면에서 나가는 전류)
- 이온망: ∇·(σ_ion∇φ_i) = (계면으로 들어오는 전류)
- 각 계면(면 f)에서 **Butler–Volmer**:

  η_f = φ_e − φ_i − U(x_surf)  (과전위 = 전자·이온 전위차에서 열역학 전위를 뺀 것)

  i_f = i₀(x_surf) · [e^(α_a F η_f /RT) − e^(−α_c F η_f /RT)]

BV가 지수함수라 문제 전체가 비선형이 되고, 그래서 Newton 3~4회 + 각 회 CG(켤레기울기)
선형 풀이가 필요하다.  Newton의 잔차(로그의 `잔차 1e-08`)는 "키르히호프 전류 보존이
얼마나 정확히 만족됐나"이다.

### ④ 리튬 삽입 — "방전"의 실체

계면 전류 i_f = **그 자리에서 Li⁺가 AM 표면에 박히는 속도**다.  면별 전류를 입자별로
합산해 각 입자의 표면 유입 플럭스 J_p로 바꾼다.  여기서 **반응 불균일**이 태어난다:
배선(전자·이온 접근성) 좋은 입자는 전류를 많이 받아 빨리 리튬화되고, 소외된 입자는
느리다.  이 분배는 가정이 아니라 ③의 **풀이 결과**다.

### ⑤ 입자 내 확산 — 코어-셸

표면에 박힌 Li은 입자 안으로 확산해 들어간다.  입자마다 반경 방향 20겹 셸의 확산
방정식(구면 좌표, D_s = 3×10⁻¹⁴ m²/s)을 풀며, 표면 농도 x_surf가 코어보다 앞서
나간다.  이 표면-코어 격차가 **확산 과전압 η_diff**의 근원이고, 뷰어의 "입자 SOC
코어-셸" 모드가 이 장(field)을 그대로 보여준다.

### ⑥ 전압이 내려가는 이유

다음 스텝의 셀 전압은 대략

  **V ≈ U(x_surf) − η_kin − η_ohm(이온·전자)**

인데, 방전으로 x_surf가 커질수록 열역학 전위 U(x)가 낮아진다(NMC의 OCV 곡선).  그래서
곡선이 미끄러져 내려온다.  1C 기준 총 분극 ≈ **46 mV**(시작점; 성분 분해는 §4 — 전기화학
리뷰로 재계산 확정 2026-07-17), 0.5C ≈ 21 mV.  나머지 하강은 전부 OCV가 내려온 것이다.

### 시간폭 dt는 안전장치이자 물리 신호

dt는 "가장 빨리 움직이는 입자 표면의 Δx_surf가 스텝당 0.02를 넘지 않게" 자동 조절된다.
그래서 **배선이 나쁜 전극(SBE)은 소수 핫입자가 빨리 달려 dt가 조여지고(17 s), 브리징이
잘 된 전극(DBE)은 전류가 고르게 나뉘어 dt가 넉넉하다(86 s)** — 시간폭 자체가 반응
불균일의 지표가 된다.

## 3. 1C 전류는 어떻게 정해지나 — 손으로 정한 숫자 0개

**1C의 정의**: 전극의 전체 용량을 정확히 1시간에 빼내는 전류.

$$I_{1C} = \frac{F \cdot c_\mathrm{max} \cdot |x_{100}-x_0| \cdot V_\mathrm{AM}}{3600\ \mathrm{s}}$$

| 인자 | 값 | 어디서 왔나 |
|---|---|---|
| F | 96,485 C/mol | 패러데이 상수 |
| c_max | 63,104 mol/m³ | NMC811 최대 Li 농도 — pybamm Chen2020에서 **기계 추출** (수기 입력 0) |
| \|x₁₀₀−x₀\| | 0.854 − 0.264 = 0.590 | 실사용 stoichiometry 창 (0→1 전부 못 쓰는 이유: 구조 안정성·전압 창) |
| V_AM | 1,271개 구의 총 부피 | DEM 실좌표·실반경 |

이 RVE에서 I_1C = 8.303×10⁻⁸ A → 면적으로 나누면 **3.07 mA/cm²** = "면적용량
3.07 mAh/cm² ÷ 1 h".  교차검증: 부피용량 F·c_max·Δx/3600 = **998 mAh/cm³** ≈ 문헌
감각(200 mAh/g × 4.8 g/cm³ = 960)과 정합.

C-rate는 관례상 **자기 용량 기준**이다 — 그래야 "1C = 1시간"이 모든 전극에서 성립한다.
(두 전극을 같은 mAh/cm² 축에 겹칠 때는 이 1~2% 용량 차가 곡선 비교를 미세 오염시킬 수
있어, 원고 figure의 정규화 방식은 별도 검증을 거친다.)

## 4. 전압 곡선 읽는 법 — 분극의 성분들

측정되는 V와 열역학 OCV의 차이가 **분극(polarization)** 이고, 성분별 자릿수 감각이
중요하다.  아래는 1C·이 전극 기준, **독립 transmission-line(TL) 재계산으로 검증된 값**
(전기화학 리뷰 2026-07-17 — 시뮬 관측과 1.4 mV 이내 일치):

| 성분 | 크기 (1C) | 결정 인자 |
|---|---|---|
| 반응 과전압 η_kin | 시작 **~24 mV** → 전선 완화 후 ~17 mV | i₀(=2 A/m²)와 **반응면적**(BV 면 수); asinh(i/2i₀) |
| 이온 옴 강하 η_ion | **~20 mV** | σ_ion ~2×10⁻⁴ S/cm; 반응대가 분리막 쪽 L/ν≈30 µm에 몰려 L/3보다 짧은 경로 |
| 전자 옴 강하 η_e | **~6 µV** | σ_e ~2–3 S/cm (이온보다 10⁴× 좋음) |
| 상태 선행(확산+불균일) | 중반부터 **~20 mV** | 전류가중 ⟨U(x_surf)⟩가 U(x̄)보다 낮음 — 입자 내 표면 선행 + 입자 간 이용률 분산 |

합계: 1C 시작 분극 SBE **46 mV** / DBE **41 mV** (U(x₀)=4.2920 V 기준).

**SBE↔DBE 전압 갭(초기 4.7 mV)의 성분 분해** — TL 원-knob 감도:

| 성분 | 기여 | 몫 |
|---|---|---|
| **반응면 +18%** (SDCP가 만든 AM\|SDCP 면) | **3.6 mV** | **78%** |
| 이온 σ +5.6% | 1.0 mV | 22% |
| 전자 σ +52% | 0.002 mV | ~0% |

여기서 중요한 직관 세 개:

1. **같은 전류라도 이온이 나르면 비싸다.**  η ∝ J/σ 인데 σ_ion이 σ_e보다 4자릿수
   작으므로, 옴 손실은 사실상 전부 이온 몫이다.
2. **저율 V-곡선 갭의 주범은 σ_e가 아니라 "반응면 +18%"다** (위 표).  σ_e +52%의 발현은
   (i) 반응 분배의 균일화 — SBE는 최열점 입자 표면이 평균의 **5–8배** 속도로 달려 dt가
   조여지고, DBE는 1.4배 수준(적응형 dt 4–5× 차이의 정체) — 와 (ii) 고율속·후막에서의
   여유다.  "σ_e +52% → V-갭"으로 직결해 쓰면 리뷰어가 암산으로 반박한다.
3. **⚠ 반응면 기여의 전제**: AM\|SDCP 면의 i₀가 AM\|SE와 같다(2 A/m²)는 §F1 훅 위에
   서 있다.  원고에는 i₀(AM\|SDCP) 민감도 스윕을 함께 제시할 것.

**⚠ 로그의 `eta_diff_mean`을 "확산 분극"으로 인용하지 말 것** — 입자 비가중 평균이라
전류가중 확산 분극(~7 mV)을 ~7× 과소평가하고 입자 간 분산은 아예 못 본다 (개선 예정).

## 5. 이 숫자들을 왜 믿을 수 있나 — 4중 감사 장치

시뮬레이션은 매 스텝 스스로를 검사한다 (로그의 각 스텝 라인에 그대로 찍힘):

| 장치 | 무엇을 확인 | 합격선 |
|---|---|---|
| **쿨롱 정합** | 흘린 전류의 적분 = 들어간 리튬 양 (x̄가 이론값과 일치) | 소수 4자리 일치 |
| **에너지 감사 (E-bal)** | 투입 전력 = 옴 발열 + 반응열 + 저장 (모든 항 명시 합산) | ~10⁻⁵ (수치 바닥) |
| **KCL** | 입자별 전류 합 = 총 전류 | ~10⁻⁵ |
| **노이즈 바닥 자가교정** | float64 반올림 한계를 실측해 경고선을 그 위에만 설정 | 런 시작 시 1회 |

"E-bal 1.6e-05"라는 한 줄은 "이 스텝의 여섯 단계가 에너지를 만들지도 없애지도 않았다"
는 도장이다.  이 감사가 기계정밀도로 닫히지 않으면 스텝 자체가 거부된다.

## 6. 자주 나오는 질문 (FAQ)

**Q1. 방전과 충전을 둘 다 선택하면 이어지나?**
아니다 — 각 런은 독립이고 각자 올바른 초기상태에서 시작한다 (방전은 완전충전 x₀에서,
충전은 완전방전 x₁₀₀에서).  현재 모델에는 이력 물리(SEI 성장, 접촉 변화)가 없어서
이어 돌려도 곡선이 같다.  진짜 연속 사이클은 이력 물리가 들어올 때 의미를 갖는다.

**Q2. 집전체(C-SUS 프라이머)는 어떻게 들어가나?**
전극 바깥의 직렬 면저항 R_int로 들어간다 (측정 앵커: bare-Al 46, C-SUS 30 Ω·cm²).
정전류 방전에서는 V_term = V − I·R_int 라는 **상수 평행이동**이라 재실행 없이 후처리로
세 시나리오(ideal/bare/C-SUS)를 모두 얻는다.  단, 실물 C-SUS의 역할(계면 열화 억제 등)
중 모델은 "값의 크기"와 "기하 접촉 몫(R_geom 이중솔브)"만 반영한다.

**Q3. pore-τ가 "—"인 이유는?**
이 전극(공극률 ~7%)의 공극은 고립 기포라 위-아래를 관통하지 않는다.  τ = ε/D_rel에서
D_rel = 0이면 정의 불가 → 정직하게 "—".  오히려 "액체 전해질이면 침투가 불가능한
전극"이라는 전고체 서사의 근거다.  (ASSB의 Li⁺ 수송은 SE 접촉망 σ_ion이 담당한다.)

**Q4. 전류밀도 컬러바의 "집중계수 ×N ⟨J⟩"란?**
그 지점의 |J|가 평균 관통 전류밀도의 몇 배인가다.  선형해라 인가 전압과 무관한 구조
고유량이고, 운전 국소값 = 집중계수 × 면적전류밀도(mA/cm²).  집중계수가 **내려가는
것**이 좋은 신호다(전류가 넓게 분산 = 병목 해소).

**Q5. 왜 이렇게 느린가?**
매 스텝이 "290만 미지수 × 50만 비선형 계면"의 Newton-CG 풀이 × 전압 탐색 수 회이고,
풀곡선은 그런 스텝 수백 개다.  COMSOL이 분 단위로 도는 것은 균질화 1D 모델(격자점
~100개) 얘기고, 같은 3D 미세구조-해상 문제는 상용 툴로도 이 무게다.  빠른 공학 곡선이
필요하면 짝으로 두는 pybamm 균질화 트윈(초 단위)을 쓰고, 미세구조가 곡선에 새기는
차이(전극 비교)는 이 솔버만 할 수 있다.

**Q6. "자유도 290만"이 무슨 뜻인가?**
솔버가 매 풀이마다 동시에 결정하는 미지수(전위 값)의 개수다.  전자망 복셀마다 φ_e
하나(≈193만), 이온망 복셀마다 φ_i 하나(≈99만) — SDCP 복셀은 두 망에 다 속해 2개.
복셀마다 "들어온 전류 = 나간 전류" 방정식이 하나씩 붙어 미지수 수 = 방정식 수의
연립계가 되고, CG가 이것을 푼다.  292만 노드짜리 회로의 모든 노드 전압을 알아내는
문제라고 생각하면 된다 — 이 해상도가 계산 무게와 (복셀 전류 지도, 입자별 반응 분배
같은) 정보량을 동시에 정한다.

**Q7. 면 반응전류 애니메이션에서 빨간 띠가 위→아래로 내려가던데?**
**반응 전선(reaction front)의 행진**이다.  σ_ion ≪ σ_e라 이온 접근성이 희소 자원 →
반응이 분리막 쪽 침투깊이 **L/ν ≈ 30 µm** (ν≈2.4–2.6, TL 해석과 일치)에 몰려 시작 →
그 표면들이 리튬화되며 국소 U가 내려가 구동력을 잃음 → 전류가 더 깊은 "신선한"
입자들로 이동 → 전선이 집전체 쪽으로 스윕.  1D porous-electrode 이론(반응분포 δ)의
3D 실계산판이고, 같은 깊이 안에서 입자마다 색이 다른 것(배선 차이)은 1D가 원리적으로
못 보여주는 부분이다.

**Q8. SOC 코어-셸 뷰에서 색이 다 균일해 보이는데?**
두 이유가 겹친다: (i) 저율/초반엔 입자 간 편차가 실제로 작고(0.5C는 준평형 — 곡선이
OCV에 붙는 이유와 같음), (ii) 기본 색 스케일이 전체 창(x 0.26→0.85) 기준이라 ±0.02
수준의 편차가 안 보인다.  legend의 **"동적 스케일(프레임 p5–p95)"** 체크박스를 켜면
현재 프레임 기준으로 색을 펴서 입자간·코어-셸 미세 편차가 드러난다 (절대 비교엔 끄기).
1C·SBE처럼 불균일이 큰 조건에서는 절대 스케일에서도 편차가 보인다.

**Q9. `step4_viz_*.json`은 어디서 여나?**
서버 업로드가 아니다 — payload 업로드 카드는 `mpm_payload.json` 전용이라 거부한다.
3D 뷰어를 열고 View Mode에서 STEP4-v2 모드를 고르면 legend에 나타나는
**"📂 step4_viz.json 선택"** 버튼으로 연다 (브라우저가 직접 읽음).  ▶ 재생/🎞 프레임
PNG(SI 무비용)와 표면 반응전류의 COMSOL식 표면 필드 모드도 거기에 있다.

**Q10. 초기 전압이 왜 OCV보다 ~46 mV 낮은가 (1C)?**
U(x₀=0.2638) = **4.2920 V** (Chen2020 폐형식; 199점 export 표도 0.03 mV 이내 재현).
관측 시작 V(SBE) 4.2463 → 분극 45.7 mV = η_kin 24 + η_ion 20 + η_e 0.006 (TL 재계산,
§4).  ⚠ 교훈: 한때 U(x₀)를 4.2808로 잘못 읽어 "분극 ~30 mV"로 서술했었다 — 4.2808은
x=0.2674에서의 U다.  OCV 앵커는 반드시 export CSV의 np.interp(x₀)로 검산할 것.

## 7. 로그 한 줄 읽기 (치트시트)

```
step  30 t=  975.0s [cc] V=4.0100 I=8.302e-08 x̄=0.4237 ηkin=17.0mV E-bal 1.6e-05 KCL 7.3e-06 (ev 8, dt 17s)
```

| 토큰 | 뜻 |
|---|---|
| `step 30` | 30번째 시간 스텝 |
| `t=975.0s` | 시뮬레이션 경과 시간 (1C 풀방전 = 3600 s) |
| `[cc]` | 정전류 구간 (`[cv]`면 정전압 홀드) |
| `V=4.0100` | 셀 전압 (집전체 기준, R_int=0이면 터미널 전압과 동일) |
| `I=8.302e-08` | 실제 전달 전류 [A] — 목표와의 미스는 별도 감시 |
| `x̄=0.4237` | 평균 리튬화 stoichiometry (쿨롱 정합 검산 대상) |
| `ηkin=17.0mV` | 전류가중 평균 반응 과전압 |
| `E-bal`, `KCL` | 에너지·전류 보존 감사 (§5) |
| `(ev 8, dt 17s)` | 이번 스텝의 전압 후보 평가 횟수, 채택된 시간폭 |
