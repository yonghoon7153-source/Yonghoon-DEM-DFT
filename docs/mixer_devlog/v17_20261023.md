# v1.7 — D2 입력·벽 규칙·기록 정정, 새 런은 미등록 (2026-10-23)

> D2 개발 덱의 벽 규칙과 밀도·점착 기록을 검사했다. 새 확인 블록과 실험 앵커는 아직 등록되지 않았다.

## 쉬운 판

D2 덱을 만들 때는 **밀도 세대**, **비코팅 NCM의 표면에너지 비 ρ**, **SE–SE 점착 수준 Bo**를 함께 적는다.
벽은 비준된 규칙 `γ_W/γ_SE = 0.0256 × ρ`를 따른다. 같은 ρ 세계에서 코팅 기준 팔은 NCM 표면 비를 둘 다 1로 바꾸고 벽과 SE는 유지한다.

너무 작은 입력이 계산 중 0으로 사라지거나 팔 이름이나 설명의 CR/LF가 덱 명령이 되는 경로를 막았다. ASCII 십진수 입력을 변환 전에 검사한다.
D2 기록은 **개발·미등록**으로 표시한다. 기존 고-Bo 등록을 새 D2 팔의 등록 근거로 표시하지 않는다.

**남은 일** — 밀도 세대와 D2 규칙을 읽는 덱 비교·되읽기·스모크, 새 셀·코호트·관문 정책, D3 실험 앵커와 독립 검토가 남아 있다.
이 변경으로 확인 런이나 배포가 허가되는 것은 아니다. 이전 캠페인의 해석과 동결 상태는 유지한다.

## 자세한 판

v1.6의 CLI 예에는 필수 밀도 세대가 빠졌고 직접 벽 값을 쓰는 옛 예가 남아 있었다. 새 개발 덱의 예:

```bash
python3 -I scripts/make_mixer_deck.py --out <새 개발 폴더> \
  --n-total 100000 --cgf 151.4 --revolutions 2 \
  --stiffen-se 20 --hold-bo-pairwise --dens-gen lab20261014 \
  --gm-gamma AM_P=0.3,AM_S=0.3 --gm-wall-ncm 0.3 --gm-bo-se 0.73
```

이 예의 `ρ=0.3`, `Bo=0.73`은 회귀 시험 입력이며 실험 보정값·스캔 수준·등록된 런이 아니다.
같은 세계의 코팅 기준은 `--gm-gamma AM_P=1,AM_S=1`만 바꾸며 `--gm-wall-ncm 0.3`을 유지한다.

- 실제 덱과 메타 발행에는 `--gm-wall-ncm`이 필수다. 직접 벽 값만으로 덱을 쓰는 경로는 거부한다.
- 활성 NCM 상의 표면 비는 모두 비코팅 `ρ` 또는 모두 코팅 기준 `1`이어야 한다. 기존 AM_P+SE 두 상 구성도 유지한다. 별도 표면에너지 모델을 자동 승인하지 않는다.
- 산술 helper의 일반 기하평균 계산과 실제 덱 발행의 비준 규칙 검사를 구별한다.
- D2 메타는 `mixer_deck_meta/2`, `registered: null`, `development_contract: D2-geomean/unregistered`이다. 기존 팔의 메타 형식은 유지한다.
- 명목 F₀를 덱의 인쇄된 CED·영률·포아송비·반경·밀도·중력 명령으로 독립 계산해 입력 Bo와 대조한다. 힘 척도의 일치는 실제 SJKR 동역학 전체의 불변성을 뜻하지 않는다.
- lab 세대에서도 기존 되읽기·비교·스모크가 새 D2 물리 계약을 검증한다고 읽으면 안 된다. `MXD2-01`은 열려 있다.
- D3의 밀도별 정적 겹침 숫자 정정(`MXD2-07`)과 새 확인 블록은 후속 설계·등록 단계다.
