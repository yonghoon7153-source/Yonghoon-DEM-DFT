# 수영 2D에서 단계 3으로 가는 조건
2026-11-25 · 개발 자료 · 후속 등록 개정 초안 · 기존 결과 열람 후 작성 · 신규 계산·실험 결과 0건 · 1저자 비준 전

**결정 제안.** 같은 충전율에서 한 속도장(S)과 입자별 속도장(F)의 압력이 구별되는지 먼저 판단한다. 두 모델 모두에서 나타난 아래판 압력의 격자 오차는 따로 명시한다. 현재 36칸(Q13)·단계 3·3D는 모두 보류다.

## 왜 0.84와 0.90에서 구간이 비었나
**0.84**에서는 12→16→24칸으로 갈 때 두 팔의 압력이 계속 낮아졌지만, 뒤쪽 로그압력 변화가 앞쪽의 S 4.26배·F 3.04배였다. 등록 A의 0.5–1.1배 범위를 벗어나고 B의 변화 허용폭 0.02도 넘는다. **0.90**에서는 두 팔 모두 압력이 조금 오른 뒤 크게 내려갔다. A의 같은 부호 조건과 B의 허용폭을 벗어나며 8칸 치우침·잡음 신호가 함께 켜졌다. 압력비 구간은 각 팔의 구간을 구한 뒤 로그값을 빼야 한다.

**최소 추가 자료**는 Q13 별도 승인 시 설정 ② S36·F36 한 팔씩이다. 12칸을 증인으로 쓰고 기존 16·24칸을 재사용한다. 옛 36칸은 설정 ①이고 S의 아래판도 다르다. F32·F48은 등록한 36칸을 대신할 수 없다. 두 점 모두 기존 16→24 변화만으로 새 사다리에서도 B는 성립하지 않는다. 36칸에서 A(같은 부호, 변화비 0.29–0.75)가 양팔에서 성립할지 확인할 수 있다. CPU 1개 어림은 S 4.15시간, F 2.82시간이다.

## 개정 문장과 단계 3의 짧은 경로
**현행 → 제안.** 현행은 U6(b) 미수렴을 단계 3 전에 보고하고, U6(c)는 ⑥을 포함해 위반 하나라도 있으면 중단한다. 후속 2D 등록에서는 “⑥ 미통과를 S·F 공통의 압력 한계로 병기하고, 단계 3의 격자 조건은 U6(b)의 도달 가능한 공통점에서 양팔 압력 구간을 확정하는 것으로 한다”를 제안한다. 원 ⑥의 5%·분모·표본·미통과 기록, 설정 ②, U5·3D 자격 기준은 유지한다. 개정안 비준과 Q13 비용 승인은 별개다.

**나머지 문.** 설정 ②의 조밀 입력은 ① 침투, ②·②′ 마찰 한계·방향, ③ 접촉 에너지, ④ 선·각운동량, ⑤ 순열, ⑦ 물체 신원의 위반 수와 유효 분모를 모아야 한다. U7은 가압 중 옆으로 벗길 때 F와 늘 붙는 F의 견인력, 12·16칸 분리 시점 대조다. U8은 하강판보다 빠른 노드의 일방향·양방향 충격량(0·−1)과 같은 충전율의 반력 대조가 필요하다. 판 상승·분리 관측과 일방향 벽 단위 시험은 있으나, 두 정식 판정은 미확인이다. 기존 증거부터 대조하고 결손만 보완한 뒤 U0·U1·U2·U5까지 확인해 1저자가 단계 3을 결정한다.

**2D 판별력.** 한 배치의 24칸 점비는 각각 1에서 3.85%, 0.88% 떨어져 있다. 현재 자료는 그 차이를 격자 오차와 분리하지 못한다. 올린 사다리에서도 구간이 열려 있으면 ‘이 배치·이 범위에서 구별하지 못함’으로 보고한다. 다른 모델(작은 상자의 입자별 유한요소 대조 등)은 1저자 선택이다.
