**§6 지적이 맞습니다. "셀이 정밀도 천장 25 % 를 정한다" 는 제가 틀렸고 철회합니다.**
제안하신 방법으로 다시 계산했고, 대안 둘 다 받습니다. §1 은 주신 정확값 지문이 통해서

## 1. relax 프레임 동정 — **36 개 중에 없습니다**

주신 대로 `grep Lattice` 한 번으로 끝났습니다. 분포 대신 정확값을 쓰자는 제안이 옳았습니다.

### 1-a. 격자상수 — **0/36**

| | |
|---|---|
| 검토자 파일 | `a = 13.982628210765 Å` |
| 원시 36 프레임의 서로 다른 `a` | **13 종**, 범위 `13.977580 – 14.004114 Å` |
| **12 자리 일치** | **0 개** |
| 최근접 | `13.982666990000` (`ev01_atom82_{i,f}` · `ev18_atom91_{i,f}` 4 개) — **`|Δa| = 3.88×10⁻⁵ Å`** |

그리고 **relax 는 고정셀이었습니다** — relax 36 프레임의 격자가 원시 36 과 **같은 13 종·같은
범위**입니다. 즉 relax 가 셀을 안 건드렸고, 그럼에도 주신 값과 안 맞습니다.

### 1-b. 좌표 — **0/36**

주신 `Cl #1 = (8.275760, 12.065297, 13.477153) Å` 를 각 프레임의 Cl 을 셀 안으로 감은 뒤
최소이미지로 대조했습니다.

| | |
|---|---|
| **10⁻⁶ Å 수준 일치** | **0 개** |
| 최근접 | `ev05_atom113_f_relaxed` — **0.0179 Å** (기준의 **4 자릿수 위**) |
| 0.1 Å 안 | 19 개 — 같은 궤적에서 relax 한 유리라 Cl #1 이 다 비슷한 자리에 있을 뿐입니다 |

### 1-c. 판정

> **배포 파일은 이 36 개 중 하나가 아닙니다. 별도 relax 입니다.**

provenance 카드 §3 의 미결 *"NEB 끝점 준비용 relax 인지 배포용 별도 relax 인지 못 가른다"*
가 **"배포용 별도" 로 닫힙니다.** 예상은 "36 중 하나를 고른다" 였는데 답은 "없다" 였습니다.

⚠ 단서 하나: `Δa = −3.88×10⁻⁵ Å = −2.8 ppm`(부피 −8.3 ppm)는 **가변셀 relax 가 거의 안
움직인 흔적**과 양립합니다. 확정은 아닙니다 — 그 relax 의 로그를 아직 못 찾았습니다.
찾으면 계보가 완전히 닫히고, 못 찾으면 **"36 중 없음"까지가 최종**입니다.

## 6. ⛔ **철회합니다 — 지적이 정확합니다**

### 6-a. 무엇을 틀렸나

**서로 다른 두 양을 같은 축에 놓았습니다.**

- He 의 `N_eff` 에 들어가는 `max(MSD)` = **궤적 전체(prod 400 ps)** 의 이동량
- C1·C2 의 `3 Å²` / `48.88 Å²` = **적합 창끝(50 ps)** 에서의 문턱

창끝 문턱을 궤적 전체 공식에 그대로 넣었으니, **N_eff 를 8 배 과소평가**했습니다.

### 6-b. 다시 계산

확산영역(C1 이 β≈1 을 강제합니다)이면 `MSD ∝ t` 이므로 50 → 400 ps 는 **×8**:

| 창끝 50 ps (Å²) | → 400 ps | N_eff | RSD | |
|---|---|---|---|---|
| **3.00** | 24.0 | 128 | **34.3 %** | C1 하한 |
| 10.00 | 80.0 | 427 | 20.6 % | |
| 20.00 | 160.0 | 853 | 15.7 % | |
| 32.60 | 260.8 | 1391 | 13.2 % | (제가 "30 % 지점" 이라 한 곳) |
| **48.88** | 391.0 | 2086 | **11.5 %** | C2 상한 |

⇒ 실제 범위는 **34.3 % – 11.5 %** 입니다. 제가 낸 **25 – 90 %** 가 아닙니다.
⇒ **"천장 25 %" 는 없습니다.** C2 상한을 꽉 채워도 RSD 11.5 % 입니다. **철회합니다.**

### 6-c. C2 가 무엇을 막는지 — **확인했고, 두 번째 갈래입니다**

주신 세 갈래 중 어느 것인지 코드로 확인했습니다.

🔴 **우리 궤적은 unwrap 입니다.** `tools/ionic/msd_diffusive_check.py:526` 이
*"unwrap 을 하지 않는다. wrap 된 궤적은 **거부**한다"* 이고, `:1820–1828` 에 음성시험이
있습니다 — wrapped 궤적을 넣으면 `None` 을 돌려주고, 같은 궤적의 unwrap 판은 통과합니다.
(계기는 2026-08-27 실측: kgy `EN_0717/licube` 가 `D = 3×10⁶ Å²/ps` 를 냈습니다.)

⇒ **첫 번째 갈래(감김 인공물)는 해당 없습니다.** C2 의 `48.88 = (d/2)²` 는
**자기이미지 상관** 기준이고, 말씀하신 대로 **1/L 로 들어가는 보정이지 딱 끊기는 상한이
아닙니다.** 제가 그걸 상한처럼 쓴 것도 틀렸습니다.

### 6-d. ⚠ 그리고 위 ×8 도 **외삽입니다**

6-b 표는 `MSD ∝ t` 를 가정한 환산입니다. 실제 `max(MSD)` 를 재야 합니다 —
그게 제안 1 이고, 받습니다.

### 6-e. 제안 1·2 — **둘 다 받습니다**

**제안 1** — `N_eff` 를 **궤적 전체 Li 이동량**으로 계산하고,
*"He 식은 lag 창을 제한한 적합에 대해 검증되지 않았다"* 를 단서로 답니다.
`msd.json` 이 이미 `n_Li` 와 창 내 `max(msd)` 를 갖고 있으므로, **창 밖 전체 max 를 한 줄
더 기록**하면 됩니다.

**제안 2** — **런 내부 오차는 시간원점 블록 부트스트랩으로 실측**하고, He 식은
**귀무모형·교차검증용으로만** 남깁니다. 구현 비용이 작다는 판단에 동의합니다.

⭐ 그리고 **독립적인 이유가 하나 더 있습니다.** 같은 날 `he2018` 코드를 해부하면서
찾은 것인데 — `ArreheniusAnalyzer` 가 `absolute_sigma=True` 로 돌아서
**Ea 오차가 입력 σ_D 의 전파일 뿐 적합 잔차를 전혀 보지 않습니다.**
실측 증거: 그들 `Fig. S5a` 에 **600 K 점이 625 K 점보다 위**(온도 역전 1.7 배)이고 자기
오차막대의 **≈2.5 배**만큼 선을 벗어나는데, 그 두 점을 빼면 모든 점이 선에 붙는데도
**보고된 ± 는 오히려 커집니다**(0.02 vs 0.01).
⇒ **He 식을 오차막대로 쓰면 이 병을 물려받습니다. 부트스트랩은 안 앓습니다.**
제안 2 는 그 이유로도 옳습니다.

⭐ 하나 더 — 같은 digest 에서 `Fig. S2`(D 히스토그램)를 봤습니다.
**D 표본분포는 정규가 아니라 오른쪽으로 치우쳐 있습니다**(우/좌 꼬리 비 1.86 / 1.38 배,
N_eff 가 커지면 치우침이 줄고, 최빈/평균 비가 로그정규 예측과 정합).
⇒ **부트스트랩이 그래서 더 맞습니다** — 비대칭 구간을 가정 없이 냅니다.
(⚠ 로그정규임을 *증명*한 건 아닙니다. 논문이 표본 수도 왜도도 안 줍니다.
**방향은 확정, 분포형은 "로그정규와 정합" 까지**입니다.)

## 6-c 덧붙임 둘 — 검산했고 맞습니다

### ① n = 5 의 IQR 은 그 자체가 흔들린다

정규에서 `IQR ≈ 1.349 σ` 이고, `n = 5` 표본의 σ 추정 상대오차는
`≈ 1/√(2(n−1)) = 1/√8 =` **35 %** 입니다. 말씀하신 *"30 % 넘는다"* 와 맞습니다.

⇒ **판정 문턱을 결과 보기 전에 박자는 제안을 받습니다.** 초안은 이렇습니다 —
**합의를 구합니다**:

> **판정 규칙 (초안).** 시드별 `Ea` 의 IQR 을 `IQR_seed`, 부트스트랩으로 낸 런 내부
> `σ(Ea)` 의 시드 중앙값을 `σ_within` 이라 할 때
> · `IQR_seed > 2 × (1.349 × σ_within)` ⇒ **구조 산포가 있다**
> · `IQR_seed < 1.349 × σ_within` ⇒ **런 내부 통계로 설명된다**
> · 그 사이 ⇒ **판정 보류** (n = 5 로는 못 가른다고 적는다)
>
> 계수 2 의 근거: 추정량 자체의 35 % 오차를 감안하면 2 배 마진이 ≈3σ 에 해당합니다.
> **더 나은 문턱이 있으면 그쪽을 따르겠습니다.**

### ② Ea 로의 전파 — 기준선을 같이 놓는다

검산했습니다. `Δ(1/kT)` (400 ↔ 550 K) = **7.91 eV⁻¹** (말씀하신 "약 7.9"),
세 점 `ln D` 오차 0.3 → `σ(Ea) = 0.3/√Σ(x−x̄)² =` **0.0536 eV** (말씀하신 "약 0.05").

그리고 **400 K 점이 지배한다**는 지적이 맞습니다 — `Tg ≈ 400–450 K` 라 그 점이 MSD 최소,
즉 `N_eff` 최소이고 C1 하한 근처일 가능성이 큽니다. **시드 Ea IQR 을 이 기준선과 나란히
적겠습니다.**
