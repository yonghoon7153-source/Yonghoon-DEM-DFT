## 1. 한 줄 요약

**"양극 2차 입자의 *내부* 미세구조(방사형 grain 배열 + 중심 seed 영역)를 5개 기하 인자로
모수화하고, LHS 로 2,500개를 자동 생성 → COMSOL 멀티피직스(전기화학 + 기계) 자동 실행 →
11개 descriptor 데이터셋 → TabPFN 대리모델 → SHAP 로 인자 영향 분해 → 4목적 Pareto 최적화"**
가 전체 서사.  **결과보다 파이프라인 자체가 산출물**이다 (발표자도 "방법적인 부분이 되게
괜찮아 보이고 … 설계 인자에 대해 이렇게 머신러닝을 써서 양극 전체 구조를 바꾼 논문은 없다"
고 말한다).

## 4. 물리 모델

### 4-1 결정학 · 기계 (p5)
- **격자상수 vs Li stoichiometry** (Chem. Mater. **2018**, 30, 1155−1163): 탈리튬 시 a축 수축,
  c축은 산소 반발로 먼저 **증가**하다 층상 붕괴 시작 후 **급격히 수축**.  Ni 함량이 높을수록
  c축 변화가 커진다 ⇒ NCM96(Ni 96 %)을 쓴 이유.
  ★ 이것을 **화학 변형(chemical strain)의 이방성 소스**로 넣는다 — 이전 코팅 논문에서는
  "정해진 부피 변화만" 넣었던 것을 정밀화한 지점 (녹취 03:00).
- **탄성 강성 텐서** (Extreme Mechanics Letters **2023**, 58, 101920), trigonal:
  `C11 = 194.89 · C12 = 133.74 · C13 = 11.85 · C14 = 8.61 · C44 = 74.14` GPa.
  ⚠ **`C33` 은 판독 불가** — 덱 텍스트 레이어에서 `C33 = 11.85` 로 나오는데 이는 C13 과
  같은 값이라 **추출 아티팩트로 의심**된다 (trigonal 에서 C33 ≠ C13 이 일반적).
  **인용 금지 · 발표자 확인 필요.**

### 4-2 전기화학 실험 모수화 (p6–7)
- **셀**: Li ‖ NCM96 half-cell, 30 °C.  `NCM96 : PVDF : Super P = 94 : 3 : 3 (wt%)`,
  로딩 6.9 mg cm⁻², 전극밀도 3.0 g cc⁻¹, 면적용량 1.5 mAh cm⁻².
- **0.1C formation**: 초기 방전용량 **234.2 mAh g⁻¹**, 초기 쿨롱효율 **92.7 %**.
- **dQ/dV**: H1–M · M–H2 · **H2–H3** 상전이 식별 → 모델 모수화.
  (녹취: Ni 함량이 올라갈수록 4.2 V 부근 H2→H3 plateau 가 길어지고 거기서 용량이 많이 나온다.)
- **GITT** (0.05C, 10 min pulse / 50 min rest) → **SOC 의존 D_Li**.
  녹취: 현재 4.2 V 까지 확보, **4.5 V 까지 확장 중**.  목표는 pOCV + (가능하면) 상 개수.
- **EIS** (x = 0.5 in Li_xMO₂) — **half cell 과 symmetric cell 둘 다**:

  | | Half cell | Symmetric cell |
  |---|---|---|
  | R_ct (Ω) | 2.23 | 1.79 |
  | active surface area (m² g⁻¹) | 0.8 | 0.8 |
  | **reference i₀ (A m⁻²)** | **1.83** | **2.28** |

  등가회로: `R_bulk` + (`CPE_CEI` ∥ `R_CEI`) + (`CPE_cathode` ∥ `R_ct`) + `W_warburg`.
  ★ **symmetric cell 을 만든 이유**(녹취 06:45): half cell 은 음극(Li) 기여가 겹쳐 R_ct 를
  **정확히 분리하기 어렵다** → 반쯤 충전한 전극 2장을 스페셜 박스에서 대칭셀로 조립해 분리.
  ⚠⚠ **`active surface area 0.8 m² g⁻¹` 은 이 소재의 측정값이 아니다** (녹취 07:19):
  예전 SDI 과제에서 **수은 압입법**으로 여러 양극을 잰 것들의 **평균**을 가져다 쓴 것이다.
  발표자 본인이 명시.  ⇒ i₀ 는 그 가정 위의 값이므로 **다른 소재로 옮길 때 반드시 재측정**.

`σ_particle` · `σ_seed` · `σ_radial` (von Mises 평균) ·
`Damage_particle` · `Damage_seed` · `Damage_radial` (grain-boundary damage 평균).

**중심부·seed 영역**에서 크다.

### ★ 대리모델 성능의 계통적 차이 (이 발표의 가장 이식성 높은 관찰)
**전기화학 descriptor 는 잘 맞고, 기계 descriptor 는 잘 안 맞는다.**
발표자 설명(녹취 14:20): 전기화학 시뮬은 **mesh-dependent 하지 않아** 뾰족한 기하나
메시 오차에 둔감한데, 기계 시뮬은 **메시에 의존**해 같은 설계라도 값이 흔들린다.
2,500개까지 늘린 것도 그 성능을 확보하려던 것인데 **여전히 전기화학보다 떨어진다**.

> ⇒ **우리에게 직결되는 경고**: 대리모델의 상한은 **바탕 시뮬레이션의 수치 재현성**이다.
> 우리 σ_e 는 격자 수렴이 확인되지 않았고(`claims.json` CL-41) 격자를 조이면 값이 계속
> 움직인다 — 그 축에 대리모델을 씌우면 **격자 잡음을 학습**하게 된다.
> 우리 ML 이 σ 삼중항을 **의도적으로 타깃에서 뺀** 결정(CLAUDE.md "σ 는 스케일링법칙
> 소관")이 이 관찰로 **독립 지지**된다.

⚠ **용량 이득은 +0.5 % 로 작다.**  이 최적화의 실질 성과는 **이질성 −39 % · damage −65 %**
= 수명/기계 축이지 용량 축이 아니다.  헤드라인을 용량으로 잡으면 과대 서술이 된다.

> ⇒ 이 §8 은 축별로 갈라 쓴다.  **§8-B(DFT)는 지금 비어 있고, 채울 때 §8-A 를 건드리지 않는다.**

### §8-A — DEM/MPM 축 (**적용됨**, 2026-08-25)

| 발표의 요소 | 우리 상태 | 판정 |
|---|---|---|
| LHS 설계공간 샘플링 | `scripts/ml_design_loop.py` 에 Sobol 이 이미 있다 | **이미 있음** |
| descriptor 당 하나씩 대리모델 | `ml_design_structure.py` 가 이미 타깃별 | **이미 있음** |
| parity + OOF CV | nested CV·선택편향·PI 커버리지까지 이미 더 엄격 | **우리가 앞섬** |
| **SHAP 중요도 히트맵** | **없었다** | **★ 이식 완료** |
| **다목적 Pareto + hypervolume** | 없었다 (D-최적 배치제안만 있었다) | **★ 이식 완료** |
| TabPFN | torch + 사전학습 체크포인트 필요 | **벤치마크로만** (아래) |

**구현**: `scripts/ml_shap_pareto.py` (selftest 31/31) + 웹앱
`/predictor/structure/shap` · `/predictor/structure/pareto` + 예측기 페이지 패널.

**우리가 그대로 베끼지 않은 두 곳** (그 자리가 이 방법의 약점이라):

1. **근사 SHAP → 정확 Shapley.**  발표는 배경 32개로 근사했다.  우리 자유노브는 **6개**뿐이라
   **2⁶ = 64 연합 전수 열거**로 오차 0 이다.  (샘플링 SHAP 은 분산이 보고되지 않는 것이 보통이라
   "이 인자가 저 인자보다 크다" 를 잡음과 구분할 수 없다.)
2. **상관된 특징에 SHAP 을 걸지 않는다.**  발표 질의응답(녹취 32:19)에서 정확히 이 지적이
   나왔다 — *"이 체크는 사실 서로 리니어리티가 없는 [인자]에 적용해야 의미가 있는 분석이잖아요.
   D50 이라거나 AR 이라거나 이런 게 서로 리니어리티가 없다고 할 수 있는 존재들인가"* — 답은
   *"지금 넣었던 것 상에서는 이렇게 다 독립적으로 아마 있을 거고"* (**미확인**).
   우리 `DESIGN_FEATURES` 13개 중 **7개는 자유노브 6개의 대수적 함수**라 거기 걸면 한 노브의
   기여가 자기 유도량들로 쪼개진다 ⇒ **자유노브에만** 건다.  그리고 **노브 상관을 재서 경고**한다.
   ★ **실측: 우리 코퍼스는 `d_am × rve` r = 0.581 로 경고가 실제로 뜬다** — 그 쌍의 기여 분해는
   인용하지 않는다.  (발표 쪽도 같은 검사를 하면 뭔가 나올 가능성이 있다 — 제안할 가치 있음.)

**우리가 추가로 넣은 계약** (발표에는 없는 것):
- **물리 경계**.  최적화기는 경계 밖 점을 *선호*한다 (`f_perc 103 %` 가 100 % 보다 좋아 보인다).
  실제로 우리 첫 실행이 **f_perc 103.2 %를 최적해로 골랐다**.  ⇒ 경계 밖 점을 **버리지 않고
  세어 표시**하고, **추천(균형점)은 경계 안에서만** 고른다.  (점추정을 자르지 않는 것은
  `structure_predictor` 의 기존 규약 — "경계를 넘으면 숨기면 안 되는 실패다".)
- **HV % 의 기준점을 출력에 적는다.**  발표는 "100 % 로 수렴" 이라 쓰는데, HV % 는 **자기가 정한
  상자**의 % 라 기준점 없이는 뜻이 없다.  우리는 nadir/utopia 를 표본에서 한 번 정해 고정하고
  출력에 적으며 *"다른 표본과 직접 비교하지 말 것"* 을 붙인다.
- **REJECT 판정 타깃을 목적으로 못 삼는다** · 노출금지 열(`use_porosity_pct`) 차단 ·
  외삽 게이트 점을 표시.

**TabPFN 은 왜 벤치마크로만인가**: 배포 추론이 **numpy 전용**이어야 한다 (sklearn 이 없어서
예측기 페이지가 영구 "Not Trained" 였던 이력).  TabPFN 은 torch + 체크포인트가 필요하고,
우리가 쓰는 **Laplace 사후 PI · leverage 외삽 게이트**를 주지 못한다.
⇒ **WSL 에서 성능 상한 확인용**으로만 (우리 nested CV 와 **같은 척도로** 비교할 것 —
GPR 경로의 `CV_R²` 는 max-of-6 낙관 + 스케일러 누수라 나란히 놓으면 안 된다, CLAUDE.md).

**첫 실행 결과** (우리 코퍼스, 정확 Shapley, 설명점 48 · 배경 24):
`thickness ← loading 79.0 %` · `mpm_dg_mean ← loading 100 %` ·
`phi_se ← am_pct 76.7 %` · `se_of_solid_pct ← am_pct 77.1 %` ·
`tau ← rve 35.3 % + loading 30.9 %` · `f_perc ← am_pct 41.2 % + d_se 26.9 %` ·
`mpm_plastic_gain ← ps_frac 32.2 % + am_pct 31.4 % + d_se 29.1 %`.
★ `f_perc` 의 분해가 CLAUDE.md 가 이미 적어 둔 **"f_perc 가 유일한 강 교호작용 신호 —
d_se×am_pct · d_se×rve · am_pct×rve = 퍼콜레이션 문턱 + 유한크기 스케일링"** 과 같은 인자를
지목한다 = **독립 방법의 교차확인**.

### §8-B — DFT 축 (**아직 비어 있음 — 예약**)

이 발표에는 DFT/원자스케일 요소가 **없다** (문헌 격자상수·강성 텐서를 **입력으로 받아 쓸 뿐**
계산하지 않는다).  ⇒ 지금 DFT 축으로 넘어오는 것은 없다.

나중에 DFT 섹션에서 관련 자료가 오면 **여기에 쓰고**, §8-A 와 코드 양쪽을 건드리지 않는다:
- 코드 쪽 분리 장치는 이미 있다 — `scripts/ml_shap_pareto.py` 의 `DOMAINS` 레지스트리.
  `dem_structure` 만 등록돼 있고 `dft_material` 은 **예약만** 돼 있어 호출하면 **오류**다
  (selftest `D-2`/`D-4` 가 상주 검증).  DFT 축이 오면 **새 `DomainSpec` 을 추가**하며,
  노브·타깃·번들 경로가 통째로 갈리므로 두 축이 섞일 경로가 없다.
- ⚠ 잠재 접점 하나: 이 발표가 **문헌에서 가져다 쓴** 이방성 강성 텐서(EML 2023)와 격자상수
  (Chem. Mater. 2018)는 **DFT 로 낼 수 있는 양**이다.  우리 DFT 축이 NCM 계로 확장되면
  그때 이 카드의 §4-1 이 **비교 대상**이 된다 — 그 전에는 아니다.
