# LPSOCl 600 K 상자 크기 — D 는 1.65× 눌렸고, β 탈락의 원인은 아니다 (STO 잣대)

> 🔎 **2026-08-18 Fable 교차리뷰 반영판.** 초판의 "상자는 β 의 원인이 아니다" 는
> **과주장**이었다 — Δβ̄ = −0.02 ± 0.08 (1σ) 은 대효과(≥0.15)만 배제하고 소효과(~0.1)는
> 못 배제하며, repo 에 이미 있던 반대 방향 증거(작은 셀 **MTO β = 0.70**, 1시드,
> `kb/questions/lpsocl_low_beta_mechanism.md`)를 초판이 인용하지 않았다.
> 판정 ①은 강도를 낮췄고, 판정 ②(D 1.65×)는 리뷰가 통계·대안가설 배제까지 확인했다.
> confidence: ① medium · ② high (frontmatter 는 보수적으로 medium).

`lpsocl` 600 K 의 β 게이트 탈락이 **상자 탓인지** 시험하려고 3×3×1(558원자·3시드·200 ps)을
돌렸다. 답: **게이트 탈락의 원인은 아니다 (STO 잣대·대효과 배제).** 그런데 시험하다
**더 큰 것**이 나왔다 — 같은 상자 확대가 STO β̄ 는 안 건드리고 **D 를 1.65 배** 올린다.

## 1. 실측 (같은 잣대 — STO 곡선 · 시드평균 · 창 2–50 ps)

| | 작은 셀 | 3×3×1 | 비 |
|---|---|---|---|
| 최소 수직폭 L | 5.67 Å | 17.02 Å | 3.00× |
| 유한크기 여유 — **자기** MSD@50 / (d/2)² | **3.15× 초과** | **0.58× 여유** | — |
| **β̄** (시드평균 곡선) | **0.82** | **0.80** | **−0.02 ± 0.08 (1σ)** |
| 시드별 STO β (산포 주의) | 0.96 / 0.83 / 0.71 | 0.81 / 0.73 / 0.87 | sd 0.125 / 0.070 |
| 절편 c [Å²] | 1.36 | 3.15 | 2.3× |
| 기울기 m [Å²/ps] | 0.467 | 0.768 | — |
| MSD@50ps [Å²] | 25.3 | 41.7 | 1.65× |
| **D** (m/6) | **7.78e-6** | **1.280e-5** | **1.64 ± 0.14 (1σ)** |
| 시드별 D | 7.42 / 8.91 / 7.04 e-6 | 1.286 / 1.169 / 1.383 e-5 | 비겹침, Welch p≈0.004 |

(유한크기 여유율은 **그 셀 자신의 MSD** 로 잰다 — 초판·watch 의 "0.36×" 는 큰 셀 여유를
작은 셀 MSD 로 나눈 값이라 후했다. 자기 MSD 기준 0.58×, 결론 불변.)

**D 출처 검산**: 저장된 `D_Li_cm2_s` 평균과 도구가 창 2–50 에서 다시 맞춘 `m/6` 이
양쪽 셀 모두 **0.1% 안에서 일치**한다 (7.790 vs 7.783e-6 · 1.279 vs 1.280e-5).
`fit_window_ps` 가 파일에 안 적혀 있었는데, 이 일치가 **창 2–50 이었음을 사후 증명**한다.

## 2. 판정 ① — β 게이트 탈락의 원인은 상자가 아니다 (STO 잣대 · 대효과 배제)

사전에 선언한 규칙은 `β̄ ≥ 0.80 → 상자가 원인 확정` 이었다. 3×3×1 이 0.80 이니
글자대로면 통과다. **그런데 대조군이 0.82 다.** 규칙의 전제("작은 셀이 더 낮다")가
깨졌으므로 규칙을 적용하면 안 된다.

```
유한크기 위반 3.15× → 0.58× 로 없앴는데  STO β̄ 0.82 → 0.80  (−0.02 ± 0.08)
```

**이 측정이 말할 수 있는 것과 없는 것** (리뷰 A):
- 배제됨: 0.615→0.8 급 **대효과** (Δ ≥ 0.185 는 2.5σ 배제). 옛 앙상블의 게이트
  탈락(β 0.615)이 상자 때문이라는 가설은 죽었다.
- 배제 안 됨: **~0.1 급 소효과.** Δβ̄ 오차(±0.08)가 그걸 볼 판정력이 없다.
  그리고 정확히 그 크기의 반대 증거가 있다 — 작은 셀 **MTO β = 0.70**
  (mto_pilot s2, 1시드) vs 3×3×1 MTO β̄ **0.81 ± 0.01** (시드 산포 0.80–0.81).
  같은 추정량(MTO)으로 짝지으면 상자가 β 를 +0.1 움직였을 가능성이 살아 있다.
  단 1시드·다른 런 세트라 확정이 아니다 → 확정은 **작은 셀 600 K MTO 3시드** (5절).

### 실무 결론: modelc·b2o3 를 큰 셀로 다시 돌리지 않는다 (조건 명시)
셋 다 같은 5.67 Å 상자다. **셋을 같은 상자에 두는 쪽**이 맞다 — 비대칭 가감은 Ea
비교를 통째로 깨뜨린다(캠페인 규약). ⚠ 단, "같은 상자 = 공정" 이 성립하는 조건은
**유한크기 인자 f_i(T) 의 T-기울기가 계 간 공통**일 때다. f 는 상자만이 아니라 그 계의
D(위반비)에 걸리고, modelc 600 K 는 MSD@50 ~33 Å² 로 lpsocl(25.3)보다 위반이 더 심하다.
'+90 meV' 주장이 강할수록("lpsocl 동역학이 다르다") 이 공정성 가정은 약해지는 구조다.
→ 싼 스팟체크: **modelc 3×3×1 @600 K 3시드** — f 가 계 간 비슷한지 실측 (5절 3순위).

## 3. 판정 ② — 대신 D 가 1.64 ± 0.14 배 움직인다 (이게 더 큰 문제)

STO β̄(곡선의 **모양**)는 그대로인데 m(곡선의 **기울기**)만 1.65 배다. 관측 자체는
리뷰(B)가 대안가설 배제까지 확인했다:
- **무질서/결함 농도 차이 아님** — 3×3×1 구조는 정확한 9× 타일링(재이완 없음,
  `db/structures/lpsocl_relaxV0_3x3x1.xyz` provenance). 조성·배치·밀도 동일.
- **평형화 과도현상 아님** — 늦은 창(100–200 ps)에서도 m 비 **1.57×** 유지.
- **통계 요행 아님** — 시드 D 비겹침, Welch t=5.94, p≈0.004. **비 1.64 ± 0.14 (1σ).**

기전은 **미확정**이다. 초판이 붙인 "Yeh–Hummer 꼴" 은 철회한다(리뷰 B) — YH 는
운동량 보존 유체역학(주기 이미지 backflow)에서 유도되는데 우리 MD 는 **Langevin**
(운동량 비보존)이고 고체 골격엔 점도가 정의되지 않는다. L=5.67 Å 는 이온과 자기
이미지가 1–2 배위권이라 어떤 1/L 점근론의 유효범위도 아니다. 후보 기전:
**이미지 동기화**(홉이 주기 이미지와 강제 동조) · **경로 위상 제약**(퍼콜레이션 채널이
5.67 Å 주기에 통약) · **제약 해제**(큰 셀만 3배 주기 파장의 이완 모드 허용).

2점 1/L 외삽 — **참고값이지 인용값이 아니다**:

```
D(L) = D∞ − A/L   →   D∞ ≈ 1.53e-5
  작은 셀  D∞ 대비 −49 %
  3×3×1    D∞ 대비 −16 %      ← 큰 셀도 아직 수렴 안 했다
```

⚠ 점 두 개로 법칙 하나를 가정한 값이고, **1/L 이라는 함수형 자체가 이 계에서
미검증**이다(위 기전 후보들은 1/L 을 보장하지 않는다). 세 번째 셀 없이 쓰지 않는다.

## 4. 그래서 '+90 meV' 는?

먼저 상태 확인(리뷰): '+90 meV' 의 출처는 **옛 ladder 앙상블**
(`db/properties/lpsocl_md_arrhenius.json`: lpsocl Ea 0.287±0.024 vs modelc 0.197±0.032)
이고, 그 앙상블의 600 K 가 β=0.615 게이트 탈락이라 JSON 에 이미
**"게이트 통과 전까지 Ea 인용 보류"** 가 박혀 있다. 즉 이 발견으로 새로 깨진 게 아니라
**원래 보류였던 것에 보류 사유가 하나 더** 붙은 것이다.

판돈의 크기(리뷰 C 검산) — Ea 는 ln D 의 기울기라 억제가 T-무관하면 상쇄되는데:

```
1.645× 가 600 K 에만 있고 800/1000 에 없으면:  Ea −68 meV → +90 이 +20 meV 로 붕괴
억제가 T 와 함께 커지는 극단이면:              Ea +58 meV → +148 meV
```

confound 폭이 주장과 같은 자릿수 — **시험 없이 인용 불가가 맞다.**
판별력: 시드 3개 비율의 SE(lnR) ≈ 0.09–0.13 → 600↔1000 두 점으로 ΔEa 편향을
2σ 에서 33–41 meV 까지 검출. 최악 시나리오(−68)는 3–4σ 로 잡힌다.

## 6. 곁가지 — 도구 fail-open 두 건 (같은 날 수정)

`msd_diffusive_check.py` 가 이 판정 도중에 두 번 거짓말했다.

1. **못 잰 런을 통과로 셌다.** MSD 배열이 없으면 `continue` 로 건너뛰고 `bad` 에도
   안 넣어서, β 를 하나도 못 쟀는데 총평이 `✅ 3개 전부 확산 영역 — D/Ea 인용 가능`
   이었다. → `unmeasured` 를 따로 세고 ✅ 를 막는다.
2. **"MSD 배열 없음" 이 오진이었다.** 작은 셀은 `msd_Li_A2`/`times_ps` 를 갖고 있었고
   없는 건 `msd_Li_A2_mto` 뿐이었다. 처방이 정반대인데(전자는 `--mto` 만 빼면 끝,
   후자는 재계산) 같은 문구로 뭉갰다. → 두 경우를 갈라 찍는다.

`--selftest` 신설, 12건 중 **8건이 음성 경로**.
이 두 건이 없었으면 "작은 셀은 못 잰다" 로 결론 내고 하루를 버렸다.

## 7. 방법 교훈 — STO ↔ MTO 를 섞어 비교하면 안 된다 (그리고 STO 통일은 차선일 뿐)

같은 3×3×1 을 두 방식으로 재면:

| | 시드별 β | 시드평균 β̄ |
|---|---|---|
| STO (단일 시간원점) | 0.81 / 0.73 / 0.87 | 0.80 |
| MTO (다중 시간원점) | 0.81 / 0.80 / 0.81 | 0.81 |

시드 산포 0.73–0.87 은 **물리가 아니라 시간원점 하나로 잰 잡음**이었다.
MTO 로는 세 시드가 0.80–0.81 로 붙는다. STO↔MTO 가 ±0.2 씩 **양방향으로** 널뛴
실측도 이미 있다(mto_pilot: lpsocl/600 s2 0.90→0.70, modelc/700 0.68→0.90 —
questions 카드).

⇒ 잣대 통일 원칙은 옳지만 **STO 통일은 차선**이다(리뷰 E). 이 카드의 β 비교가 전부
STO 인 것은 작은 셀 옛 런에 프레임이 없어 MTO 소급이 불가했기 때문이고, 그 통일이
**기존 MTO 증거(작은 셀 0.70)를 가리는 효과**를 냈다. 도구 규율은 "확정은 MTO 로만" —
따라서 이 카드의 판정 ①은 작은 셀 600 K MTO 3시드(5절 1번)가 나올 때까지 **잠정**이다.

## 이 카드가 말하지 않는 것

- **1.64× 가 온도에 상수인지** — 600 K 한 점뿐이다. 4·5절이 그 시험이다.
- **D∞ 절대값** — 2점 외삽 + 함수형(1/L) 미검증. σ 절대값은 애초에 인용 금지(CLAUDE.md).
- **modelc·b2o3 의 유한크기 인자** — 재보지 않았다. lpsocl 의 1.64× 를 그들에게
  이식하면 안 된다 (f 는 그 계의 D 에 걸린다 — 2절 조건).
- **왜 LPSOCl 만 β 가 낮은가** — 대효과가 상자 탓이 아니라는 것까지만. 기구 분해는
  `kb/questions/lpsocl_low_beta_mechanism.md` 가 담당한다 (홉 7.3/이온 문턱 미달,
  (B) 멱함수 vs (C) 느린 전이 미판별 — 800 ps 연장이 결정 실험).
- **1.64× 의 기전** — 관측은 확실, 이름은 미정 (3절. YH 는 철회).
- 작은 셀 β̄ 로 캠페인이 써 온 **0.77 의 출처** — 이 명령으로 재현되지 않는다
  (같은 3시드·같은 창·STO 로 0.82). **재구성 가설**(리뷰 F): 시드별 STO β 중
  (0.83+0.71)/2 = **0.770 정확 일치** — s2(0.96) 완료 전 2시드 시점의 "시드 β 평균"
  (곡선평균 β̄ 규약 위반)이었을 개연성. kgy 로그 타임스탬프로만 검증 가능, 가설로만 둔다.
  어느 경우든 **어디에도 인용 금지**.
