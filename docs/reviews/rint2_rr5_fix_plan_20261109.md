## 1. Q1 — Q6 보장 범위 = (가) 지금 범위 유지 + 한정 명시 (코드 무변경)

- 근거: 1저자 11-09 처분 기준 (CLAUDE.md 사전 공격 규칙 ⑤ — 정직한 흐름에서 틀린 결과를 받아들이는 것만 고친다 · 손으로 고친 · 서로 어긋난 기록은 멈춤 확인 + 한정).  판정문 §6-2 반례 = 복사된 L01 payload 한 파일을 일부러 바꾼 것 · 정상 copytree · 디스크 부족만으로 생긴다는 증거 없음 (판정문 §6-2 끝 문단).
- 수용 문장 (GO 조건 자리) = 판정문 §5 의 좁힌 문장 그대로:
  > PC14-02/03, RR4-01 및 PC15-01–06의 지정 수정은 고정 코드와 합성 입력 범위에서 수용한다. 원천 미확인은 결과 기록을 보류하고, 확인된 결속 모순은 재개 불가로 기록한다. 이 수용은 요약 없는 시도의 이미 복사된 prefix 무결성 전체, 실제 호스트·I/O·프로세스 자격 또는 등록 R 캠페인 GO를 인증하지 않는다.
- 한정 (등록 R §10-5 한정 목록과 같은 자리로 읽는다): **요약 없는 재개에서 이미 복사된 앞 런과 원천 사이의 불일치는 잡지 못한다** (손으로 고친 복사본 · 비트 손상 등 · 정직 흐름의 복사 실패는 생산자 `_copy` 예외 = 실패 처리).
- 바꾼 곳: CLAUDE.md 사전 공격 규칙 ⑤ 끝 (옛 "GO 조건 두 문장 = Codex 회차 ⑤ Q6" 취소선 + 이 처분).  코드 · 시험 무변경.
- (나) (요약 없는 재개에서도 원천상 완료된 prefix 의 launch/end · payload 를 원천에 대조) = 하지 않음 · 그 부류까지 보장이 필요해지면 그때 새 고침 (시험 먼저 · 정상 중단 대조 · rerun=None · 첫 새 런 미시작 · 3 시도 effective 원천 회귀 = 판정문 §6-2 둘째 선택지).
