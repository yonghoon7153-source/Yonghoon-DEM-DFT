## 4. 브래킷 (§3 완주 후 확정)

PTFE 를 격자에 어떻게 다루느냐가 이득의 크기를 **2.5배** 바꾼다.  두 규약이 실험을 사이에 둔다:

```
PTFE 미표현 (§3, 측정 예정)   <   실험 대칭셀 +23.1 %   <   PTFE 차단 +30.78 % (§2)
```

⚠ **양쪽 다 하한이다** — 서로 다른 이유로:
- **PTFE 미표현**: PTFE 를 아예 안 그리므로 SBE 가 받아야 할 벌점이 0 이다.
- **PTFE 차단**: 복셀은 **부피 점유**만 본다.  Lee 2025 가 실측한 PTFE 0.5→5 wt% 의
  σ_e 3,000배 붕괴는 **표면 코팅** 효과라 복셀이 원리적으로 못 본다 (CL-46/49).
