# SDCP 예비 최종 보고서 (2026-08-03)

자가도핑 전도성 고분자(SDCP, S-PEDOT 계) — 분자 확정부터 계면 결합까지 전 트랙 현황.
**예비**인 이유: Phase-B DFT+U 복합체 2건이 실행 중이고, 그 기반이 되는 슬랩 기하에
미해결 이상(§6)이 있다.

상태 표기: ✅확정 / 🔶잠정(방법 한계 명시) / ⏳진행 / ⛔보류·철회

---

## 0. 한 줄 요약

**실물 SDCP는 자가도핑(–SO₃⁻/폴라론) 상태이고**(분광 3중 확정), **그 도핑이
① 폴라론을 백본으로 비편재시키고**(n=3에서 백본 몫 50% 돌파) **② Li⁺ 자리 지형을
3배 평탄하게 만들며**(호핑 경로 형성) **③ 양극 표면에 더 세게 붙는다**(방향성 확정,
절대값은 DFT+U 대기). 곁사슬의 산성 H는 상온에서 표면 격자 O로 넘어가고(MD),
전지 내 operando 형태는 SO₃Li 로 수렴한다.

## 1. 분자 확정 ✅

| 항목 | 값 | 방법 |
|---|---|---|
| 단량체 | C₁₁H₁₆O₆S₂ (v7c) — EDOT 코어 + ether 링커 + alkyl-술폰산 | ORCA r²SCAN-3c opt+freq |
| neutral S–O | 1.46 / 1.47 / **1.66** Å (긴 결합에 O–H 0.97) | 최적화 실측 |
| doped S–O | **1.495 / 1.498 / 1.496 Å 완전 등가** | 최적화 실측 |

| O–H BDE | 4.24 eV | r²SCAN-3c |

**neutral↔doped 차이는 술포네이트 H 하나뿐**이고, 그 하나가 아래 모든 차이를 만든다.

## 2. 분광 판정 — 실물은 자가도핑 ✅

독립 증거 4종이 같은 결론:

| # | 증거 | 데이터 |
|---|---|---|
| ① | **IR에 O–H 부재** (음성) | 계산 neutral만 3624 cm⁻¹; 실험 FTIR(400–4000 전구간) 부재 |
| ② | **Raman 1062 = νs(SO₃⁻)** (양성) | 3-등가 SO₃의 대칭 신축은 doped 에서만 뚜렷 |
| ③ | **IR 1133/1178 재배정** | Raman 이 심판: 1133 = C–O–C 에터(Raman-약), 1178 = νas(SO₃) |
| ④ | **기하 + 스핀** (분광 독립) | S–O 3-등가, 스핀 3-O 분산, ⟨S²⟩ 0.755 |

판정 논리: O–H 는 IR-강 / Raman-약이므로 **판정의 정본은 FTIR**. "Raman 이 3400에서
끊겨 판단 불가"라던 구 보고의 한계는 해소됐다.

도핑 시점: **산화 중합 = 중합 + 도핑 동시**. "도핑 안 된 SDCP"를 거치지 않으므로
pristine 시료가 doped 스펙트럼을 주는 것이 자연스럽다.

## 3. 올리고머 — 폴라론 비편재 (bi / tri) ✅

ORCA r²SCAN-3c Opt, Löwdin group spin. **핵심은 사슬이 길어질수록 폴라론이
곁사슬을 떠나 백본으로 옮겨간다는 것.**

| n | 계 | SO₃ 라디칼 몫 | 백본(ring) 몫 |
|---|---|---|---|
| 1 | 단량체 | 65 % | 35 % |
| 2 | 이량체 | 62.3 % | 32.6 % |
| 3 | 삼량체 **말단** 도핑 | 54.6 % | 39.8 % |
| 3 | 삼량체 **내부** 도핑 | **42.3 %** | **50.1 %** |

- **n=3 내부 도핑에서 백본 몫이 50%를 넘는다.** π 계가 커질수록 폴라론이
  백본-지배로 바뀐다 — 전도성 백본이라는 서사의 직접 증거.
- **이량체**: SO₃⁻ 결함이 A 고리에 있는데도 백본 몫이 두 고리에 거의 균등
  (A_ring 17.4 vs B_ring 15.2, 비 0.87) → n=2 에서 이미 π-비편재 성립.
- **삼량체 내부 도핑**: A_ring 14.0 ≈ C_ring 14.9 대칭, B_ring 21.3 최대
  → 결함 고리 중심 + 대칭 날개.
- **삼량체 말단 도핑**: 이웃 B_ring 15.3 > 숙주 A_ring 13.9 > 원거리 C_ring 10.6.
  **단순 거리감쇠가 아니다** — 스핀이 사슬의 **π 허브**(공액 이웃이 둘인 가운데 고리)를
  선호한다. 같은 허브 효과가 내부 도핑에서 B_ring 이 최대인 이유이기도 하다.
- 검산: E(neutral) − E(doped) = 0.654 Eh ≈ E(H 원자 0.500 Eh) + O–H BDE 4.2 eV ✓

> ⚠ B_SO₃ = 0.0 은 **설계상 그런 것**(B 쪽 술포네이트는 SO₃H 로 양성자화된 닫힌 껍질).
> 대칭 깨짐이 아니다 — 비편재는 고립된 곁사슬이 아니라 **π 네트워크(고리)를 따라간다.**

## 4. Li⁺ 지형 — 도핑이 호핑 경로를 만든다 ✅

기체상 단량체 + Li⁺, ORCA r²SCAN-3c (eV):

| 자리 | neutral | doped | Δ(d−n) |
|---|---|---|---|
| SO₃ O,O-이좌 | −2.508 | −3.278 | −0.770 |
| 곁사슬 ether O | −2.878 | −2.930 | −0.052 |
| EDOT O,O-킬레이트 | −1.606 | **−3.363** | −1.758 |

**핵심 지표는 절대값이 아니라 자리간 편차**: doped **0.43 eV** vs neutral **1.27 eV**
(3배 평탄). doped 는 근등가 O-자리 사다리(SO₃⁻ → ether-O → EDOT-O)를 제공해
**연결된 Li⁺ 경로**가 되고, neutral 은 ether 단일 우물에 갇힌다(trap형·절연적).

> 구 보고의 "neutral 은 Li 이 작용기를 **피한다**" → **"한 자리에 갇히고 경로가
> 끊긴다"**가 정확. 결론은 같고 메커니즘이 정교해졌다.
> ⚠ 캐비엇: 기체상 단량체 + 맨 Li⁺. **차이/편차만 인용**하고 절대값은 인용하지 않는다.
> 실제 장벽은 NEB 필요(미실시).

## 5. 산성 H 의 거취 — 정적 판정과 MD 판정이 갈렸다 ✅(재해석)

### 5.1 정적 스크린 (0 K, UMA) — "전구체 없음"
클린 슬랩 6배향 전부에서 산성 O–H 0.98–0.99 Å 온전, **H 반경 3.5 Å 안에 표면 O 전무**
(이완이 O–H 를 표면 반대로 돌린다). 하이드록실화 모델에서도 0/6, 역방향(표면 OH → 분자 O)도
최근접 2.43 Å 로 임계(2.2) 미달.

### 5.2 MD (300 K, UMA Langevin) — "그런데 넘어간다"

| 모델 | 사건 | 판정 |
|---|---|---|
| 하이드록실 패치 + sulfdown_r90 | **t = 0.66 ps 에 산성 H → 격자 O 전달**, 새 표면 OH 생성, SO₃⁻ 잔류. 발열·5 ps 내 비가역 | 상온에서 실제로 일어남 |
| **클린 슬랩 대조군** + sulfonate_down_r0 | **t = 1.62 ps 에 전달 재현.** 단 분자 재배향이 깊은 우물로 떨어지며 **600–1500 K 자기가열** 후 발생 | 채널은 **존재**하나 **상온 자발성은 미입증** |

**통합 판정**: OH 패치는 채널의 **필요조건이 아니다**(클린 격자 O 도 받는다). 그러나
**상온 접근성은 다르다** — 하이드록실화는 300 K 에서 0.66 ps, 클린은 인공 가열 후.

> ★ **정적 판정의 재해석이 이 절의 핵심이다.** "전구체 없음"은 **열역학적 거부가 아니라
> 운동학/접근의 문제**였다. 병목은 받는 쪽의 염기성이 아니라 **만남(encounter)** 이고,
> 0 K 이완이 O–H 를 표면 반대로 돌려 놓은 것이 그 만남을 막고 있었을 뿐이다.

**공통 계통오차 (양쪽 런 모두)**: ① 슬랩 완전 고정 → 포논 열싱크 없음 → 발열 과장
(자유원자 35–44개에 에너지가 갇힌다) ② UMA 전하분리 한계 → 발열 크기 신뢰 불가.
→ **최종 심판은 before/after 스냅샷의 DFT 단일점 ΔE** (미실시).
→ 개선안: 다음 MD 는 **슬랩 최상층을 풀어** 열싱크 + 표면 응답을 준다.

### 5.3 H↔Li 교환 에너지학 ✅
| 량 | 값 | 뜻 |
|---|---|---|
| DPE (SO₃H → SO₃⁻ + H⁺) | +14.17 eV | 맨 양성자 비용 (문헌 ~14.0 ✓) |
| **LCA (SO₃⁻ + Li⁺ → SO₃Li)** | **−6.76 eV** | 비면 Li⁺ 를 잠근다 |
| 교환 (맨 H⁺ 기준) | +7.42 eV | = DPE − LCA (검산 통과) |
| EA (radical + e⁻ → anion) | +3.67 eV | 자가도핑형 ↔ SO₃⁻형 연결 |

양성자 수용처만 있으면 교환은 성립: **물 1개(PA 7.16)로 +0.26 eV(본전), 물 2개(PA 8.37)로
−0.95 eV(내리막)**. → **곁사슬의 일생**: 합성 직후 H-form(조성) → 대기 수분에 이온화
(IR O–H 부재) → 전지 내 **operando = SO₃Li**.
**부가 이득**: SO₃H 잔존 시 황화물 SE 산-공격(H₂S) 우려 → SO₃Li 화가 그 위험을 제거하고
Li⁺ 정거장을 하나 더 준다.

## 6. 계면 결합에너지 — 진행 + 미해결 ⏳⛔

### 6.1 계층 구조 (사용자 질문 "relaxation 은 이걸로" 에 대한 답)
```
분자 기하   ORCA r²SCAN-3c opt+freq   ← 완화 담당. §1 의 v7c 지문이 여기서 나옴
자세 탐색   UMA (슬랩 완전 고정, FIRE fmax 0.05)   ← Phase-A. 자세를 완화하고 순위를 냄
재채점      DFT+U 단일점 (PBE+U, AFM)              ← Phase-B. 기하는 안 건드림
```
즉 **완화는 ORCA(분자) + UMA(자세) 가 하고, DFT+U 는 순수 재채점**이다. DFT 수준 복합체
완화는 하지 않는다(130원자 DFT+U BFGS = 단일점의 수십 배). E_bind **차분**은 양쪽이
같은 근사를 쓰므로 상쇄가 잘 되고, **절대값**은 이 근사의 제약을 안고 간다.

### 6.2 Phase-A (UMA) 🔶
doped 는 화학흡착(−4 ~ −5 eV), neutral 은 O-배위(−2 ~ −2.7 eV) — **방향성은 확고**.
단 1위였던 doped `chelation_r90` (−5.196 eV) 는 **주기이미지 샌드위치로 철회**
(티오펜 S ↔ c 를 넘은 이미지 슬랩 O 1.506 Å = 결합거리 → 한 표면이 아니라 두 표면 몫).
현행 자세: doped `sulfonate_down_r90` (−4.693), neutral `chelation_r0` (−2.733).

### 6.3 Phase-B (DFT+U) ⏳
| job | E (Ry) | 상태 |
|---|---|---|
| mol_doped | −518.39271250 | ✅ 수렴. 원장값과 **소수 8자리 일치**(Δ 5e-8) |
| mol_neutral | −519.68310308 | ✅ 수렴. Δ 8e-8 |
| slab | −10563.23044425 | ✅ 수렴 (`!` 줄). 2개월 plateau 를 밀도 승계 재시작으로 돌파 |
| complex_neutral / complex_doped | — | ⏳ 실행 중 |

- **plateau 원인 귀속 정정**: "이 계는 원래 안 잡힌다"(8-01)는 **부분 철회**. 원인은 계가
  아니라 **Broyden 혼합 이력**이었고, `startingpot='file'` 로 이력을 비우고 재시작하니
  30 iteration 에 수렴했다. 처방: *수렴시켜 → 죽여 → 밀도 물려 재시작*.
- Ni 시드: |Ni| = **1.020 μB** = 저스핀 Ni³⁺ (d⁷, S=1/2) ✓ 물리적으로 옳다. AFM 합 0.000.
- 기하 검증 통과: 흡착 O–Ni **1.887 Å**(doped) / **1.940 Å**(neutral) = Ni–O 결합거리;
  진공 너머 6.611 / 8.184 Å → **7월 샌드위치 철회 사유 해소**.

### 6.4 ⛔ 미해결 — 슬랩 기하 이상 (보고서 채택 전 필수 확인)
`db/structures/sdcp_phaseB_slab_c40.vasp` 및 `sdcp_phaseB_slab.vasp` 를 완전탐색한 결과:

| 측정 | 값 | LiNiO₂ 기대값 |
|---|---|---|
| 셀 전체 최단 원자간 거리 | **2.878 Å (Ni–Ni)** | **1.94 Å (Ni–O)** 여야 함 |
| Ni–O 최단 | 3.667 Å | 1.94 Å |
| Li–O 최단 | 3.428 Å | 2.10 Å |
| Ni–Ni / O–O | 2.878 Å ✓ | 2.878 Å ✓ |
| (104) 층간격 | 2.039 Å ✓ | d(104) = 2.039 Å ✓ |
| 체적/원자 | 21.5–25.7 Å³ | 8.48 Å³ (**약 3배 희박**) |

**격자 상수와 층간격은 정확한데 Ni–O 결합이 하나도 없다.** 어떤 결정을 어떻게 잘라도
Ni–O 결합이 전부 사라지지는 않는다. `extract_scf_slab.py` 는 `scf_u62.in` 을 **선별 없이
그대로 복사**하므로, 이상이 있다면 그 상류(`scf_u62.in` 자체 또는 그것을 만든 경로)에 있다.

**확인 절차(미실시)**: gabia 에서 `reference_dft_v2/scf_u62.in` 에 같은 검사를 돌린다.
- scf_u62 가 Ni–O ≈ 1.94 → repo 의 슬랩 파일이 그 사이에서 손상. 재추출 후 Phase-B 재실행.
- scf_u62 도 3.667 → **기준 슬랩 자체 문제**. 이 슬랩 위의 모든 DFT+U 결과가 재검토 대상.

> 이 확인이 끝나기 전에는 **§6.3 의 Phase-B 절대 에너지·E_bind 를 인용하지 않는다.**
> §1–5(분자·분광·올리고머·Li⁺ 지형·H 거취)는 이 슬랩과 무관하므로 **영향 없음**.
