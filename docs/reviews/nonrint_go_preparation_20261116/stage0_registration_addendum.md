## 3. DRD-01을 닫기 위해 제출할 근거와 닫지 못하는 것

원 DRD-01은 “12·16셀의 등급 일치 = 응력비 수렴”이라는 규칙이다. 정본 부록D와 등록 S07/S08에 연결해 다음 증거를 내야 한다.

| 증거 | 결과 전에 정할 기대 | 현재 |
|---|---|---|
| 원 반례 R(n)=1.10+3.36/n | 앞 두 등급만 보고 확정하지 않음; 세 해상도·오차/차수·경계 검사를 빠뜨리면 실패하는 직접 회귀 | 계획; 이번 재실행 없음 |
| 수치 판독 구현 | S·F 각각 및 짝 ln R, Δφ에 같은 오류/구간 원칙. 정본에서 지정한 계열·수치 문턱·비수렴 분류 보존 | 코드 핀·구현 자격 미완 |
| 독립 공격 | 경계 바로 양쪽, 같은 등급이지만 계속 변하는 열, 비단조/차수 미확정, 결측·비유한·잡음·상한 중단 | 합성 시험 목록; 기대 결과를 먼저 고정 |
| 등록한 2D 결과 | 세 충전·해상도·팔·필수점이 완전하고 오류구간이 선언한 등급 안에 들어오는지 확인 | 실행·결과0 |
| 외부 처분 | 원 규칙과 반례에 대한 구현·등록 범위 종결 가능 여부를 별도 반박 창이 판단 | 미요청·미수령 |

**요청할 좁은 종결 범위**는 등록한 2D 판정 절차에서 등급 일치만으로 수렴을 선언하는 결함과 그 구현 누락이다. 유한 합성 사례나 2D 결과가 **보편 수렴·3D·생산 규모·물리 자격**을 증명하지 않는다. 원장 DRD-01 전체 처분은 남는 범위를 명시한 외부 판정 및 Claude의 원장 반영 전까지 open으로 둔다. 문서 종결 수령이나 이 등록 초안만으로 닫지 않는다.

## 4. 다음 작은 연결과 공유 정의

다음 구현 후보는 기존 S/F 준비의 **독립 수치 판독 계약/합성 입력 검사**다. 운영 MPM·공유 payload·입자 번호/피복 정의를 바로 고치지 않는다. 수치 프로필이 미확정인 동안에는 결과 전 입력 형식·실패/결측 표·시험 벡터 준비까지만 진행할 수 있다. 함수가 정본 규칙을 구현할 고정안이 준비되면 시험 먼저→구현→사전 공격→별도 핀 반박을 따른다.

피복·번호 승계의 실질 정의가 필요해지면 Claude와 먼저 합의한다. 데이터 수집/임시 리포트 제작을 이유로 Rint 공유 소스에 작은 수정부터 넣지 않는다.
