# `pdd` = 질량분율 — 원자료 receipt (2026-08-29)

> Codex 해제조건 **⑧**.  사전등록 v2 §2 가 기대는 판정의 **재현 가능한 근거**다.
> 그전까지 이 판정은 `lhs_ext_design.py` 의 selftest 가 **코드 상수로 다시 대조**하는
> 형태였고 (`MEASURED`), 그것은 독립 재현이 아니다 — 상수가 틀렸으면 검사도 같이 틀린다.

## 0. 무엇을 가리는가

LIGGGHTS 입력 헤더의 `pdd` 가 **개수분율 · 부피분율 · 질량분율** 중 무엇인가.
`fix particledistribution/discrete` 의 가중치 해석이 여기 달려 있고, 틀리면
`φ_AM` 사상이 통째로 어긋나 **확장 창이 엉뚱한 자리에 선다.**

## 1. 결정적 케이스 — `lhs00_110`

```
# lhs00_110: mono_AM_S (2-type) | LHS design
# rAM=0.001 rSE=0.001 | pdd AM=0.8000 SE=0.2000
# volfrac=0.250627 | E_se=0.135e7 (고정) | seed=11059
```

★ **`rAM = rSE = 1.0 µm`** — 반지름이 같으므로 **개수분율 = 부피분율**이다.
⇒ 두 해석이 **같은 예측**을 내고, 실측 하나로 **둘을 동시에** 기각할 수 있다.

실측 (`post_lhs00_110/atom_2980000.liggghts`, N = 19,894):

| type | n | count_frac | vol_frac |
|---|---|---|---|
| 1 (AM) | 12,434 | **0.625013** | **0.625013** |
| 2 (SE) | 7,460 | 0.374987 | 0.374987 |

| 해석 | 예측 | 판정 |
|---|---|---|
| 개수분율 | 0.800 / 0.200 | ⛔ 기각 |
| 부피분율 | 0.800 / 0.200 | ⛔ 기각 |
| **질량분율** (ρ_AM 4800 · ρ_SE 2000) | **0.625000 / 0.375000** | ✅ **소수 다섯째 자리 일치** |

$$\frac{0.80/4800}{0.80/4800+0.20/2000}=0.625000\quad\text{vs 실측 }0.625013$$

## 2. 교차검증 — `lhs00_000` (3-type, 반지름이 다른 경우)

```
# lhs00_000: bimodal (3-type) | LHS design
# rP=0.0055 rS=0.0005 rSE=0.001 | pdd AM_P=0.5100 AM_S=0.3400 SE=0.1500
# volfrac=0.222984 | E_se=0.135e7 (고정) | seed=10007
```

실측 (`post_lhs00_000/atom_2425000.liggghts`, N = 45,030):

| type | n | count_frac | vol_frac | 질량 해석 예측 | 상대차 |
|---|---|---|---|---|---|
| 1 (AM_P, r 5.5 µm) | 46 | 0.001022 | **0.427959** | 0.421488 | **+1.54 %** |
| 2 (AM_S, r 0.5 µm) | 39,719 | 0.882056 | **0.277629** | 0.280992 | **−1.20 %** |
| 3 (SE, r 1.0 µm) | 5,265 | 0.116922 | **0.294412** | 0.297521 | **−1.04 %** |

개수 해석이면 부피분율이 **0.9977 / 0.0005 / 0.0018** 이어야 한다 — AM_P 가 고체의
**99.8 %** 인 양극은 성립하지 않는다.  ⛔ 기각.

⚠ 1~1.5 % 잔차는 **삽입 통계**다 (개수가 정수이고, 큰 입자 46개는 한 알이 2.2 %).
`lhs00_110` 이 다섯째 자리까지 맞는 것과 정합적이다 — 거기는 입자가 19,894개로 균질하다.

## 3. 결론

**`pdd` 는 질량분율(wt%)이다.**  전극 조성을 적는 자연스러운 규약 그대로이고,
`fix particledistribution/discrete` 가 mass-based 로 받고 있다.

⇒ 사전등록 v2 §2 의 사상이 성립한다:

$$\varphi_{AM}=\frac{\rho_{SE}\,w}{\rho_{AM}-(\rho_{AM}-\rho_{SE})w},\qquad w=1-\texttt{pdd\_SE}$$
