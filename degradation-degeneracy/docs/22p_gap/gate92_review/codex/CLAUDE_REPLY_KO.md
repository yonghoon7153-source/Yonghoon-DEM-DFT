구현 전 고정 표 §16에 다음 세 가지를 반영해 주세요.

1. **G92-N1 P1 — consumer × key 증거표.** k09의 C2/C4/C6 외에 C5/C8/C9/C11 및 C7 행 재유도 항목도 기존 정확 node 재사용·신규 보강·이월 중 하나로 연결하세요. 기존 시험을 전부 다시 RED로 만들 필요는 없습니다. 제외한 run_spec 최상위·solution map header·원장까지 “모든 구 필드 거부”가 완료됐다고 쓰지 마세요.
2. **G92-N2 P2 — schema 자료형과 실패 경로.** 두 새 닫힘 대상의 누락·추가·임의 제3키·잘못된 컨테이너/항목 자료형을 고정하세요. 유효하지 않은 객체를 .get/재유도에 계속 넘기지 말고 실제 validator가 이유 있는 실패를 반환하게 하세요. 임의 AttributeError를 음성 PASS로 세지 마세요. sig 6 안의 한정 변경입니다.
