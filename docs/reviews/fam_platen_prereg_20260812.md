# 사전등록 — 플래튼 정지 수정(③) × AM 하중분담(②) 검증 런

**작성 2026-08-12, 결과 0 건 상태에서 기록.**  정본 진단: `docs/mpm_platen_kinematic_stop_defect.md`
(rev1–rev6, 적대리뷰 6차).  이 문서는 **새 진단이 아니라 그 처방의 실행 계약**이다.

> ★ 왜 사전등록이 필수인가 (정본 §19): 정지를 고치면 베드가 **9.4 %** 로 무너지는데
> 실험은 **15.6 %** 다.  그 상태에서 f_AM 을 "15.6 이 나올 때까지" 돌리면, 사고로
> 상쇄되던 것을 **의도적으로 맞춘 것**으로 바꾼 것뿐이고 frame[4](DEM↔MPM 상호보정 금지)
> 정면 위반이다.  **f_AM 을 먼저 뽑고 → 예측을 등록하고 → 그 다음 실행한다.**  순서를
> 뒤집는 순간 순환이다.

## 0-1. 관례 규약 (이 캠페인 전체에 강제)

**모든 porosity 는 `ε_sphere` 로 보고한다** (DEM 정본과 직접 비교 가능).  MPM union 관례로
읽은 값은 반드시 `ε_sphere = ε_MPM − 1.251 %p` 로 환산해 병기한다.
근거: 정본 §31 — 이 1.251 %p 를 안 맞춰서 "+1.2 %p converged model-trust bound" 와
se-dump 헤드라인 "15.93 ✓ (real 15.6)" 이 **두 오차의 상쇄**였음이 드러났다.
⇒ **관례를 섞은 비교는 이 캠페인에서 자동 무효.**

## 1. 강제 순서 (정본 §19 방어선 3)

> 결합을 늘리기 전에 **결합 없는 길**을 먼저 시험한다.

```
R1    정지 수정 + 감속, f_AM **없이**  → 이 모델의 정직한 준정적 극한을 측정
        ★ R2.5 누산기는 측정 전용이라 **R1 과 같은 런에 얹어** 같이 나온다 (추가 비용 0)
R2    AM-as-material 재시험            → 결합 0 으로 되는지 (되면 f_AM 불요)
R2.5  MPM 이 f_AM 을 **스스로 측정**    → DEM 0.847 은 투입값이 아니라 교차검증 상대가 된다
R3    f_AM 수입                        → 위가 전부 실패했을 때만, 이중 사전등록으로 채점
```

R1 을 건너뛰고 R3 로 가면 "9.4 % 를 15.6 % 로 만드는 노브"를 돌린 것이 된다.

## 2. R1 — 결합 없는 준정적 극한 (진단)

**목적**: 정본 rev4 §22 의 외삽(9.4~9.5 %)을 **직접 측정**으로 확정/반증.

```bash
# real_14 scaffold, n_grid 384, hold, 정지수정 + 감속, f_AM 없음
python3 scripts/mpm3d_compaction.py <기존 real_14 인자> \
  --stop-freeze-probe --platen-mach 0.01 \
  --allow-unconverged-servo            # ← 거부 게이트를 진단 목적으로만 통과
```
⚠ `--allow-unconverged-servo` 는 **진단 전용**이다.  이 팔의 산출물은 코퍼스에 넣지 않는다
(SE-only 판독을 전체 target 과 겨루는 범주 오류가 그대로 남아 있으므로).

### 사전등록 R1
| # | 예측 | 반증되면 |
|---|---|---|
| R1-a | 정착 porosity(ε_sphere) **8.0 ~ 10.5 %** | rev4 §22 의 3중 일치가 우연 — 사다리를 다시 봐야 함 |
| R1-b | 정착 wallP 가 target 0.3 GPa 의 **1/2 이하**에 머문다 (SE-only 판독이므로) | SE 단독이 target 을 지탱한 것 → §28(b) 범주오류 진단이 틀림 |
| R1-c | 스트로크 ≠ N×0.008 (운동학적 정지 서명 소멸) | 정지 수정이 작동하지 않음 |
| R1-d | `descend_probe_route = 'quasistatic'` 이 **1회 이상** 기록 | rev5 §26 의 "프로브가 정지 판독을 한 적 없다"가 감속 후에도 유지 → 정지 기준 재설계 필요 |

★ R1-d 가 핵심이다.  rev5 실측에서 11개 창 중 **0개**가 `settle_is_quasistatic` 를 통과했다.
감속(ⓒ)이 그것을 고치는지가 여기서 처음 시험된다.

## 3. R2 — AM-as-material 재시험

**왜 다시 하나** (정본 §19 방어선 3): CLAUDE.md 의 AM-freeze 4 근거 중 ②
"mobile-rigid AM → force-chain over-shielding 36–41 %" 가 **의심스럽다** — "높은 공극률에서
target 도달했다고 주장하며 멈춤"은 정확히 운동학적 정지의 서명이고, 그 진단이 **같은 내려찍는
플래튼 아래서** 내려졌다.
⚠ 단 2D CORRECTION 1 이 force chain 의 일부를 soft-bulk 아티팩트로 이미 규명하고 ν=0.49 로
고쳤으므로 **전부가 이 결함 탓이라 단정하면 안 된다.**

### 사전등록 R2
| # | 예측 | 반증되면 |
|---|---|---|
| R2-a | 준정적 플래튼 하에서 mobile-AM 의 porosity 가 **36–41 % 밴드 밖**으로 내려온다 | over-shielding 이 플래튼 결함과 무관한 진짜 현상 → AM-freeze 근거 ② 유지 |
| R2-b | R2-a 성립 시 porosity 가 **12 ~ 18 %** (실험 15.6 을 포함하는 창) | 성립하면 **f_AM 불요** = 결합 0 경로 성공 |
| R2-c | n_grid ≥ 384 에서 CFL/OOM 로 못 돌면 그 사실을 결과로 기록 | (AM-freeze 근거 ③ 재확인) |

## 3-5. ★ R2.5 — **f_AM 을 수입하지 말고 MPM 이 재게 한다** (2026-08-12 추가)

**계기**: R3 는 f_AM 을 DEM 에서 **수입**한다 — 그래서 §19 의 순환 방어선이 필요했고, 베드마다
값이 달라 옮길 수 없고, 두 규약(AM-AM 접촉망 vs phase virial) 중 어느 것이 맞는지도 미검증이다.
그런데 **정보가 없어서가 아니라 버려지고 있었다**: `am_mask` 셀은 `grid_v[I]=0` 으로 영점화되고
그때의 z-운동량이 사라진다.  플래튼은 **정확히 같은 양**(Σ m·Δv)을 두 줄 아래에서 반력으로 읽는다.

**구현** (`mpm3d_compaction.py`, 2026-08-12): 영점화 **직전**에 그 운동량을 누산
(`amf_dn`/`amf_up`, 플래튼과 **같은 정규화** `/(dt·area)`).  프레임마다
`AMr = |am_dn|−|am_up|` 와 `f_AM_mpm = |AMr|/(|AMr|+|wallP|)` 를 출력.
⚠ **측정 전용** — 영점화 동작은 그대로라 물리는 불변.  (⚠ 비트 동일을 **주장하지 않는다**:
병렬 원자연산이 하나 늘어 부동소수 리덕션 **순서**가 바뀔 수 있다.  리포는 이미 "같은 옛
바이너리 2회 실행에서도 4째자리 차" 를 기록해 두었다 — 그 수준의 차이는 예상 범위다.)

**무엇이 달라지나**

| | R3 (f_AM 수입) | R2.5 (MPM 이 측정) |
|---|---|---|
| DEM 파라미터 | 1개, 베드마다 다름 | **0개** |
| 순환 위험 | 실재 (방어선 필요) | **소멸** |
| DEM f_AM 0.847 의 지위 | 투입값(노브가 될 위험) | **예측 대상** = frame[4] 교차검증 |

**⚠ 세 가지 한정 (넘겨 읽지 말 것)**
1. ⓐ(동결 프로브)·ⓒ(감속)를 **대체하지 않는다** — 하강 중엔 이 값에도 관성이 섞인다.
   **정착 후 값만** 채점 대상.
2. 얼린 AM 은 절대공간에 못박혀 하중을 **흡수만** 하고 전달하지 않는다.  이 값을 플래튼에
   더하는 회계가 옳으려면 **AM 골격이 바닥까지 퍼콜**해야 한다 → **검사 항목으로 병기**.
3. DEM f_AM 은 **AM-AM 접촉망** 하중 몫, 이것은 **SE→AM 전달** 몫이다.  **같아야 할 의무가
   없다** — 어긋나면 그것이 frame[5] 경계(연속체는 접촉망 하중경로를 못 본다)의 정량화다.

### 사전등록 R2.5 (결과 0 건 상태에서 기록)

| # | 예측 | 해석 |
|---|---|---|
| R2.5-a | 정착 `f_AM_mpm` ∈ **[0.75, 0.95]** | DEM 0.847 과 정합 → **교차검증 성립**.  f_AM 수입(R3) **불요** |
| R2.5-b | `f_AM_mpm` < 0.60 | 연속체가 하중경로를 다르게 본다 → frame[5] 경계 정량화.  R3 는 여전히 필요하나 **어느 규약도 그대로 못 쓴다** |
| R2.5-c | `f_AM_mpm` > 0.95 | SE 가 거의 아무것도 안 진다 → 판독 의심(또는 베드가 AM 에 잼) — 회계 재검토 |
| R2.5-d | **회계 검사**: 정착 시 `|AMr| + wallP` 가 target 0.3 GPa 의 **±30 %** 안 | 성립하면 "AM 이 나머지를 진다" 가 **측정으로** 확인.  크게 미달이면 흡수-전달 가정(한정 2)이 깨진 것 |
| R2.5-e | 하강 중 `f_AM_mpm` 이 정착값과 **크게 다르다** | 정상 — 관성 오염의 직접 관측이고, ⓒ(감속) 효과의 계기가 된다 |

⚠ 창을 결과 본 뒤 옮기면 무효 (§7).

### 사전등록 R3 — **이중 등록** (정본 §34)
어느 쪽이 나와도 정보다.  **채점 전에 관례를 통일**한다 (§0-1).

| 분기 | 정지 porosity (ε_sphere) | 해석 |
|---|---|---|
| **(a)** | **13.9 ~ 14.2 %** (= MPM관례 15.2~15.4) | 측정 f_AM 0.847 이 관례-혼합 기준으론 맞지만 **공통 관례로는 ~1.5 %p 과압축** |
| **(b)** | **15.3 ~ 15.8 %** (= MPM관례 16.6~17.1) | f_AM 0.847 이 **과소** — 실제 하중분담이 더 크다 (DEM 두께에서 멈추려면 f_AM ≈ 0.93 필요) |

측정값이 아니다.  (b) 가 나오면 **"측정 f_AM 이 과소하다"를 결과로 보고**하고, 왜 과소한지
(AM-SE 접촉 몫의 배분 규약?) 를 **DEM 쪽에서** 따로 측정해 답한다.

## 7. 이 사전등록이 무효가 되는 조건

- 결과를 본 뒤 예측 창을 넓히거나 옮기면 무효.  창을 바꾸려면 **새 문서에 이유와 함께** 다시 등록.
- 관례를 섞어 채점하면 무효 (§0-1).
- f_AM 을 porosity 결과에 맞춰 조정하면 무효 (§4 경고).
