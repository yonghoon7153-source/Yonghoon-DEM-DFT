## 보낼 글 (그대로 붙여 넣는다)

**[DFT → DEM] Ag–C 점착일 요청 회신 — 계산 0 건, 구조 검증부터 시작합니다**

요청 잘 받았습니다. 두 리뷰(내부 · Codex)를 거쳐 설계를 고쳤고, **본 계산은 아직 안 걸었습니다.** 먼저 착수 전 질문 셋에 답하고, 요청서와 달라지는 점과 확인할 것을 적습니다.

**① 이미 가진 LPSCl 슬랩·종단·표면에너지**
- **옛 LPSCl|NCM 파이프라인의 숫자는 기준으로 못 씁니다.** 수정본의 "기존 isolated slab W_ad 와 나란히" 의 전제가 깨졌습니다.
  - 정방 SE 셀을 육방 NCM 셀에 변형 없이 접어 넣었습니다(원자 겹침).
  - v6 러너의 NCM 은 R-centering 이 빠져 **LiNiO₂ 가 아닙니다** (Ni 주변 O 0개).
  - 출판 표의 comp1 1.277 은 20 시드 중 **5개를 골라낸** 값입니다.
  - "실험 0.18–0.32 J/m²" 는 실제로는 AFM **aJ**(에너지) 값을 J/m² 로 잘못 옮긴 것입니다.
  - 원장의 옛 γ_SE(comp1 1.21 J/m²)는 UMA 비정질 표면 값이라 역시 쓰지 않습니다.
- **새 SE 슬랩**은 comp1 입방셀(001)을 **PS₄ 를 안 끊는 위치**에서 자릅니다.
  - 단순 절단은 PS₄ 48개 중 8개를 끊습니다.
  - 허용되는 절단은 두 틈뿐이고, 한쪽 면은 **S 바깥**, 반대쪽 면은 **Li·PS₄ 바깥**이 됩니다.
  - 그래서 요청서의 **"S 쪽"은 바로 되지만 "Cl 쪽"은 comp1 으로는 안 나옵니다** (절단 창에 Cl 이 없습니다).
- **SE 자체의 이상 벽개 문턱** (문헌 · PBE · vdW 없음, Pustorino 2025): 같은 (100) 면의 화학량론 벽개가 **≈ 0.47 J/m²**, (110) 은 **0.37 J/m²** 입니다.
  - ⚠ 트랙 문서 §6 의 "Pustorino 0.20 J/m² = LPSCl 벽개 에너지" 는 **대칭 비화학량론 슬랩의 2γ(화학퍼텐셜 조건값)**입니다. 벽개 문턱으로 쓰면 SE 를 2배 넘게 약하게 잡습니다.

**② P1 두 계면의 계산량·일정** — 약속은 첫 프로브를 잰 뒤에 드립니다. 순서만 먼저 알려드립니다.
1. 구조 빌더·검증 (좌표·배위·조성) — CPU, 며칠
2. 불변성·가산성 대조 (UMA) — 분 단위
3. LPSCl|Ag registry 20개 (UMA) — GPU 수 시간 (GPU 가 비는 대로)
4. DFT 검증 — **미리 고정한 5개**, 848원자급 단일점. repo 견적은 점 하나에 ~48 h 라 프로브로 실측한 뒤 예산을 잡습니다
5. Ag|흑연 — 분산 없는 MLIP 를 건너 **DFT+D3 로 직접**. 작은 셀이라 쌉니다

**③ 대표 모델보다 나은 선택**
- **LPSCl 종결**은 두 방식 중 하나입니다. 1저자 결정 대기입니다.
  - (가) S 바깥·Li 바깥 **대칭 슬랩 두 장** — 면마다 쌍극자 없이 따로 잽니다
  - (나) 화학량론 **비대칭 한 장** — 쌍극자 보정이 필요합니다
- **Ag|흑연 셀**은 Ag 격자상수에 따라 답이 뒤집힙니다. √3 셀이 a 4.086 Å 에서는 −1.7 % 인데, PBE 4.16 Å 에서는 −3.4 % 로 요청서 3 % 를 넘습니다. **DFT 단계의 Ag 격자를 먼저 재고** 셀을 고릅니다 (회전 셀은 0.3–0.5 %).
- **흑연 대조 기준**은 이상 ABAB 벽개 **0.39 ± 0.02 J/m²** (Wang et al. 2015) 로 합니다. 0.37 은 비정합 쌍결정 값이라 다른 양입니다.

**요청서와 달라지는 점**
- **주값** = 정해진 기하·셀·전자상태 규칙에서의 **DFT(PBE+D3(BJ)) 고정기하 W_sep** 입니다 (UMA 로 만든 기하 위 DFT 값).
  - 848원자를 DFT 로 이완한 열역학적 W_ad 는 규모상 못 냅니다. "UMA 이완 슬랩 + DFT 단일점" 값은 내되 그 이름표를 붙입니다.
- **"D3 끈 값"** = 같은 기하에서 D3 항만 뺀 값입니다. D3 없이 이완하면 물리흡착 계면은 떨어져 나가서 값이 정의되지 않습니다.
- **D3 3체 항**: QE 는 기본으로 3체 항(ATM)을 켭니다. 요청서의 "D3(BJ)" 관례(2체)에 맞춰 끄고 ATM 은 따로 보고하는 쪽을 제안합니다.
- **"물리흡착 급 / 화학결합 급" → "저·고 접착 구간"** (0.3 / 1 J/m²). 크기로 기전을 판정하지 않습니다.
  - Giovannetti 2008: 같은 계산에서 **화학흡착인 Pd 가 ≈ 0.52 J/m²** 입니다.
  - ⚠ 트랙 §6 설계 결론 3 정정: Maurer 2015 의 45 meV/C 는 논문 셀 밀도로 **0.26 J/m²** 입니다 (0.28 은 평형 그래핀 밀도로 환산한 값). 더 중요한 건 분산 방법 7개가 **0.19–0.45 J/m²** 로 흩어진다는 점입니다 — 0.3 경계를 가로지르므로 *"mJ/J 판별에는 영향 없음"* 은 맞지 않습니다. Ag|흑연 값은 **"PBE+D3(BJ) 조건부"** 로 드립니다.
  - Giovannetti 원문 용어는 "physisorption" 이 아니라 **"weak bonding"(LSDA)** 입니다.
- **MLIP(UMA) 절대값은 넘기지 않습니다** (정본 repo 규칙). 넘기는 것은 DFT 값과, 같은 프로토콜 안의 비입니다.
- **NCM 대비**는 정상 LiNiO₂ 를 새로 짓고 자기 상태 정책을 정한 뒤 **조건부 비**로만 드립니다. 옛 NCM 숫자와 AFM 실험값을 곱하는 방식은 쓰지 않습니다.

**CSV 에 추가할 열** — 방법 표지(D3 2체/ATM) · 기하 출처(UMA) · d_eq · 양쪽 일함수 · ΔV · 표본 종류(UMA 20 / DFT 검증 5) · 집합 표지(`intermixed` · `PS4-topology-changed`).

**확인 부탁드립니다**
1. **DEM 입력 연결**: 트랙 §3 의 JKR pull-off F = 1.5πR·w 에서 **w = 우리 W (면적당 점착일, J/m²)** 로 받으시면 됩니다. γ 가 아닙니다 — 같은 두 면이면 W = 2γ 입니다. 헤드라인을 고정기하 W_sep 으로 받아도 되는지, 이완 W_ad 가 꼭 필요한지 알려 주세요.
2. **LPSCl 종결**: "S 쪽"은 그대로 갑니다. "Cl 쪽" 대신 **"Li·PS₄ 쪽"**(Cl 은 두 번째 층)으로 받아도 될까요? 아니면 음이온 자리바꿈 변형을 만들어야 할까요?
3. **P2·P3**(LPSCl↔탄소 · 리튬화 LiAg)를 지금 범위에 넣을지요.
