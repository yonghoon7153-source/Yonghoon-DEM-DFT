# RB-01 고체량 맞춤 — 실험자에게 받을 원측정 목록

요청자·수령 담당 = 1저자. 같은 시료 ID로 아래 원측정을 묶어 받는다. 현재 수령값은 전부 미정이며 이 문서에서 값이나 실험 순위를 만들지 않는다.

| 받을 것 | 함께 받을 메타 | 답 칸 |
|---|---|---|
| 시료별 질량 | 건조/가압 전후 구분, 집전체·용기 tare, 저울 분해능, 조성/배치 | 미수령 |
| 눌린 유효 면적 | 지름 또는 가로·세로, 면적 정의, 금형 안/밖, 단위·측정 오차 | 미수령 |
| 두께 원측정 전체 | 같은 시료·위치·반복 번호·각 원값, 측정 기기/분해능, 선별 여부와 제외 이유 | 미수령 |
| 가압 및 두께 측정 압력 | 최대 압력, 하중 제거 뒤 경과 시간, 측정 중 작은 하중/압력, 50 kg의 힘/질량 표현 구분 | 미수령 |
| 공극 정의와 계산 입력 | 닫힌/열린/전체 공극, 상별 진밀도 출처, 질량분율, 포함/제외 상, 식·단위 | 미수령 |
| SEM 원본 | 압축되지 않은 원본, 스케일 보정, 배율, 단면 방향/위치, 같은 시료 연결, 전처리 | 미수령 |
| 보관자와 이력 | 원본 보관자·측정자·시각·기기, 재가공본/원본 구분, 제공 범위 | 미수령 |

대조 준비: 실험 고체량/면적 `C_exp = (Σ_i m_i/ρ_i)/A`와 DEM의 sphere 기준 `C_DEM = ΣV_sphere/A`를 각각 정의한다. 같은 단위·영역·상 포함 규칙·시료에서 먼저 대조한 뒤에만 두께/공극 차를 해석한다. 혼합 밀도는 성분 질량과 진밀도를 통해 계산하며 단순 산술 평균으로 바꾸지 않는다. `h(1−ε)`는 ε가 독립 측정인지 같은 질량·두께로 역산한 것인지 구분한다. 같은 입력으로 얻은 두 값을 독립 검증으로 세지 않는다.

DEM의 union 공극은 겹침 감소로 달라질 수 있으므로 Δε_union을 회복률로 환산하지 않는다. 기존 선별 3회의 흩어짐을 전체 시료 재현성으로 쓰지 않는다. 근거: docs/reviews/dem_unloading_ps45_prereg_20261009.md §1-2·§6-2(e)·§7-5. RB-01 종결·실험 검증 주장 없음. 50kg Love–Weber 응력은 다시 그리지 않는다.
