# 검토 절차와 도구 경계

검토자 작성 audit_archive.py, audit_data.py, audit_context.py만 실행했다. 이들은 수신 ZIP/CSV/JSON/PDF 및 이전 검토의 보존본을 읽는 코드다. 제출된 .py/.java는 텍스트 자료로만 취급했다. Poppler 렌더는 원본 PDF를 수정하지 않는다.

첫 원문 표시 명령은 Windows cp949 콘솔이 µ 문자를 출력하지 못해 중단됐다. UTF-8 출력으로 다시 읽었다. 이 오류는 표시 명령의 인코딩 문제이며 분석 계산/COMSOL/제출 자료 실패가 아니다. 출력 파일이나 원본 변경은 없었다.

B020 SUMMARY 경로 탐색 중 과거 다른 게이트의 격리 fixture 디렉터리 일부에서 접근 거부가 출력됐다. 권한을 변경하거나 해당 디렉터리를 재시도하지 않았다. 발견된 관련 B020 검토본의 정확 경로만 읽었다.

PDF·스프레드시트 지침에 따라 원자료 정의/단위/계산을 추적하고 PDF 7쪽을 실제 렌더로 확인했다. 문서 작성 지침에 따라 수용 사실, 해석 한계, 후속 제안을 구분했다. 원 보고서 수정이나 정책/파일 권한 변경은 없다.
