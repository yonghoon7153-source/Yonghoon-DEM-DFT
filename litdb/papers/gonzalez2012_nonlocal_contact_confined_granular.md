## 0. TL;DR — 7줄 판정 (읽기 전에 결론부터)

1. **무엇**: 한 입자에 걸린 **모든 다른 접촉력**이 각 접촉면의 변형에 기여하도록 Hertz를 확장한
   **닫힌형(closed-form) 해석 정식화**. 결합은 힘이 아니라 **여분의 접근량(approach) `g_NL`** 로 들어간다
   → 계보상 **변위(겹침) 보정 계열 = non-binary 축**.
   ⚠ **Giannis 2021 이 대조군으로 삼은 "strain-based multi-contact model" 은 이 논문이 아니라 Brodu 2015 다**
   (§10.2 — digest 도중 정정). 이 논문은 Giannis 의 **참고문헌 [24]**.
2. **자유 파라미터 = 0.** 보정 상수가 하나도 없다. 입력은 E, ν, R, 접촉 배치(각도 θ)뿐.
   `g_NL → 0` 이면 **정확히 Hertz로 환원**된다.
   ★ 같은 축의 두 경쟁 모델은 **prefactor 를 하나씩 갖는다** (Brodu **γ**, Giannis **β**)
   → **이 논문이 "맞춰서 맞은 것"이 원리적으로 불가능한 유일한 행**이다.
3. ⚠ **탄성 전용.** 초록 그대로 *"elastic spheres in the absence of gravitational forces, adhesion or friction"* —
   **소성·점착·마찰·중력 전부 없음.** 논문 §5가 소성·유한변형·bonding을 **미래 과제로 명시**한다.
   ⇒ 우리 300 MPa 소성 압밀에 **그대로 쓸 수 없다.**
4. ⚠⚠ **부호가 우리 기대와 반대다.** 비국소 항은 접촉을 **더 뻣뻣하게** 만든다
   (같은 겹침에서 힘 ↑, 같은 힘에서 겹침 ↓). 우리 18× 연화는 **더 무르게** 만드는 처방이므로
   **이 논문은 우리 연화의 대체재가 아니라 반대 방향이다.** 정직하게 말하면 이 물리를 넣으면
   우리는 **연화를 더 해야 한다** (18× → ~22×, 우리 유도 §10.4).
5. ★ **그럼에도 우리에게 값진 것 3개** — 전부 **전달(transport)/네트워크** 축이지 porosity 축이 아니다:
   (a) 같은 겹침에서 **접촉반경이 커진다** `a = √(R*(g+g_NL))` → Holm 컨덕턴스 ↑ (우리 유도, §10.5);
   (b) **2차·3차 접촉 개시가 앞당겨진다** (BCC 정수압 ρ_R 0.95 vs Hertz 1.04) → 같은 밀도에서 배위수 Z ↑;
   (c) **겹침 0에서도 하중을 받는 접촉이 생긴다** (식 13–14, Algorithm 1 line 8) → 우리 δ>0 접촉검출이
   **접촉을 놓치고 있을 수 있다**.
6. ★ **밀도 무관·크기 무관**: 불일치 Δ는 **ε(변형)과 ν(포아송비)에만** 의존하고 **E와 입자크기에는 무관**
   (식 17–18, 논문 명시). ⇒ 고무(E=1.85 MPa, R=1 cm)에서 잰 것을 **LPSCl(E=24 GPa, R=0.5 µm)로 옮길 수 있는
   드문 문헌 결과**. 단 ν와 ε이 같아야 하고 **탄성 영역 안이어야** 한다.

## 1. 한 줄 요약

Hertz 접촉역학은 "각 접촉은 반무한 탄성체 위의 독립 사건" 이라고 가정하는데, **구속된(confined) 입상계**에서는
한 입자에 여러 접촉력이 동시에 걸려 입자 전체가 **메조스코픽하게** 변형하므로 그 가정이 깨진다.
이 논문은 **중첩원리 + Boussinesq 원거리 해**로 그 결합을 **해석적 닫힌형**으로 쓰고
(`P(g) = n_H (g + g_NL)^{3/2}`, `g_NL = Σ w(P_i, θ_i)`), Tatara 고무구 실험 + 자체 FEM 으로 검증한 뒤,
격자·무질서 입상계 압밀에서 Hertz 대비 **40 %(2D 10 % 변형) ~ 200 %(BCC 완전압밀) ~ 50 %(무질서 침대)** 의
불일치를 보인다. **자유 파라미터 0, 탄성 전용.**

## 4. ★★★ 이론 — 식 수준으로 (요청 항목 #1)

### 4.1 Hertz의 "독립 접촉" 가정이 정확히 어디서 깨지는가

Hertz 이론의 전제(논문 §2, Johnson 1985 인용):
1. 선형탄성·등방·매끈한 구,
2. 법선 접촉력만,
3. **접촉면 크기가 물체 치수·곡률반경보다 훨씬 작다** → 각 접촉을 **반무한 탄성 반공간(half-space)**으로 대치.

⇒ 3번이 성립하면 접촉변형은 **접촉면 근방에 국소화**되고 **같은 입자의 다른 접촉력을 교란하지 않는다.**
이것이 입상계 문헌에서 **independent contacts** 라 부르는 제약이다.

**이 논문이 깨는 지점은 정확히 3번**이다. 반공간으로 대치하는 대신, **유한한 구**를 유지하고
"중심에서 지지된 구에 국소 접촉응력이 걸린 경계값문제(BVP)"를 푼다 (Fig 1c).
그러면 **접촉면에서 멀리 떨어진 표면점도 유한하게 변위**하며, 그 변위가 **다른 접촉면의 적합조건에 들어간다.**

> ⚠ **깨는 것 / 안 깨는 것** 구분:
> - **깬다**: 접촉 간 **독립성**(=결합 도입), 반공간 근사(원거리 항).
> - **안 깬다**: 접촉면 안의 **압력 분포는 여전히 Hertz(구면분포)** 로 두고, 접촉면 안의 변위도 식 (1)의
>   Boussinesq/Hertz 반공간 해를 쓴다. 근거로 Zhupanska(2011) 정해가 *"Hertz의 구면 접촉압력 분포는
>   비교적 큰 접촉면적까지도 정확하다(a/R < 0.40 에서 p_m 오차 < 6 %)"* 고 보인 것을 인용한다.
> - **안 깬다**: 입자 형상은 여전히 **구**다. 미변형 구관(spherical cap) 프로파일을 급수 첫 항으로 잘라
>   `R₁ − √(R₁²−r²) ≈ r²/2R₁` (식 6) 로 쓴다 — **기하는 끝까지 구다** (⇒ 우리 3층 지도 (3) SHAPE 소성 아님).

### 4.2 단일하중 BVP의 두 가지 근사 (§2.1 + Appendix)

목표: Fig 1c의 문제(= 중심에서 집중력 P로 지지된 탄성구에 국소 접촉응력) 의 **효율적 닫힌형** 해.

**접촉면 안** (0 ≤ θ ≤ arcsin(a/R)) — Hertz/Boussinesq 반공간 해:
```
u_z(θ) = [3P(1−ν²) / (8 a³ E)] · (2a² − R² sin²θ)        … (1)
p_m = 3P / (2πa²)   (구면분포 최대압력)
```

**접촉면 밖** (arcsin(a/R) < θ ≤ π) — **Case I** (논문이 채택):
반무한체 Boussinesq 해에서 **원점에 접하는 반지름 R 의 구형 부분체 B_Sph(R)** 만 떼어내고,
바깥 재료를 **평형 표면 견인력(surface traction) q = −t(n)** 으로 대치한다.
```
q(θ) = P/(8πR²) · ( −3 sin(θ/2) ,  (1−2ν)/[2 tan(θ/2)(1+sin(θ/2))] − (3/2) cos(θ/2) )   … (2)/(23)
                     └ q_z ┘        └───────────────── q_r ─────────────────┘
‖q‖ / p_m = O(a²/R²)      … (25)   ⇒ 표면 견인력은 접촉응력보다 훨씬 작다
```
그 구의 표면 법선변위:
```
u_n(θ) = [(1+ν) / (4πRE)] · P · [ −2(1−ν) − 2(1−2ν) sin(θ/2) + (7−8ν) sin²(θ/2) ] / sin(θ/2)   … (3)/(24)
```
(변위 기준틀은 Boussinesq 해의 것 — `u_n(π) → 0 as R → ∞`.)

**Case II** (Appendix, 비교용): 접촉압력을 점하중이 아니라 **구면분포 `p(r) = p_m √(1−r²/a²)`** 로 두고
**Love(1929) 퍼텐셜 해**(Newtonian 퍼텐셜 V + Boussinesq 로그 퍼텐셜 ψ)로 같은 절차를 수행.
식 (26)–(29) 가 그 전개. **결론: Case I 이 Case II 와 정확도가 동등하면서 더 효율적** (Fig A2) → Case I 채택.

**정확도 검증**: Zhupanska(2011)의 **정해**(구의 축대칭 일반해 + dual series → **2종 Fredholm 적분방정식** 수치해,
반공간 대치 없음)와 a/R = 0.233, ν = 0.50 에서 비교 → Fig 2 / Fig A2 에서 **"매우 잘 일치"**.
같은 그림에서 **전통 접촉역학(=Hertz, 접촉면 밖 변위 0 취급, 점선)** 은 명백히 어긋난다.

### 4.3 ★ 비국소 결합식 — 여기가 심장 (§2.2)

두 구 (R₁,E₁,ν₁), (R₂,E₂,ν₂) 가 z축 방향 등가 유효력 P 로 눌린다.
접촉면 안의 점 r 이 만족해야 하는 **적합조건(compatibility)**:

```
g = [R₁ − √(R₁²−r²)] + [R₂ − √(R₂²−r²)] + w₁(r) + w₂(r) − Σ_{k=1,2} Σ_{i=1}^{NP_k} w^{P_k^i}(r)     … (4)
    └────────── 미변형 구관 기하 ──────────┘   └ 국소 접촉압력 변위 ┘   └★ 비국소 항 (다른 모든 접촉력) ★┘
```
- `g` = 두 입자 **질량중심 사이의 z-방향 상대변위**(= DEM 의 겹침 δ 에 해당).
- `w_k(r)` = 국소 접촉압력에 의한 변위 ← 식 (1) 을 `w(r) = u_z(arcsin(r/R))` 로 평가.
- `w^{P_k^i}(r)` = **입자 k 에 작용하는 다른 모든 집중력 `P_k^i` 가 이 접촉면에 유발하는 비국소 메조 변형**.
  **중첩원리(superposition)** 로 더한다 (Fig 1b: 하나의 탄성정역학 문제를 4개의 단일하중 BVP로 분해).

**핵심 근사**: `w^{P_k^i}(r)` 을 **접촉면 전체에 걸쳐 하나의 상수값**으로 놓는다 — z축을 따라 유발되는 법선변위,
즉 식 (3) 을 그 힘의 각도 `θ_k^i` 에서 평가한 값:
```
w^{P_k^i} ≈ [(1+ν_k) / (4π R_k E_k)] · P_k^i · [ −2(1−ν_k) − 2(1−2ν_k) sin(θ_k^i/2) + (7−8ν_k) sin²(θ_k^i/2) ] / sin(θ_k^i/2)   … (5)
```
`θ_k^i` = 그 집중력과 (해당 접촉의) z축 사이의 각도.

식 (6) 으로 구관을 `r²/2R` 로 절단한 뒤 평형해를 풀면 **닫힌형**:
```
g = (P / n_H)^{2/3} − g_NL                                                  … (7)
a³ = (3P/4) · [ (1−ν₁²)/E₁ + (1−ν₂²)/E₂ ] · (1/R₁ + 1/R₂)^(−1)              … (8)
1/n_H = (3/4) · [ (1−ν₁²)/E₁ + (1−ν₂²)/E₂ ] · (1/R₁ + 1/R₂)^(1/2)
g_NL  = Σ_{k=1,2} Σ_i w^{P_k^i}                                              … (9)
```
그리고 상대변위로 명시화하면 **이 논문의 최종 힘-변위 법칙**:
```
★★  P(g) = n_H · (g + g_NL)^{3/2}                                           … (10)
```

**⇒ 결합의 정체**: Hertz `P = n_H g^{3/2}` 에서 **접근량 g 를 `g + g_NL` 로 치환**한 것.
`g_NL` 은 **다른 접촉력들의 크기와 각도**의 함수 → 이 접촉의 법칙이 **다른 접촉의 상태에 의존**한다.
`g_NL → 0` 이면 **정확히 Hertz** (논문이 강조하는 성질).
Hertz 는 "탄성접촉이 **질량중심 상대위치만으로** 결정되고 하중배치와 무관"하지만,
비국소는 **"각 구의 하중배치에 의존"** 한다 (Fig 3 중간 vs 오른쪽).

**⇒ 비선형 연립계**: `g_NL` 이 접촉력 P 의 함수이고 P 가 다시 `g_NL` 의 함수 → **고정점 반복(fixed point)**
으로 푼다. 초기값 `g_NL = 0` (= Hertz).

### 4.4 ★ 각도 가중함수 W(θ, ν) — **부호가 바뀐다** (우리 유도, 논문 특례 2개로 검증)

식 (5) 를 `w = W(θ,ν) · P / (4πRE)` 로 쓰면
```
W(θ, ν) = (1+ν) · [ −2(1−ν) − 2(1−2ν) s + (7−8ν) s² ] / s ,     s ≡ sin(θ/2)
```
**검증**: 논문 자신의 두 특례와 정확히 일치한다 —
- θ = π (정반대 극): `W = (1+ν)(3−2ν)` → 식 (11) `g_NL = Σ_k F(1+ν_k)(3−2ν_k)/(4πR_kE_k)` 와 **일치 ✓**
- θ = π/2 두 개(횡하중): 합 `(1+ν)(3√2 − 4 − 4√2ν + 8ν)` → 식 (14) 와 **일치 ✓**

**ν = 0.37 (LPSCl, Bazzoun) 에서 수치 평가** (우리 계산):

| θ | 45° | 60° | **≈77.6°** | 90° | 135° | 180° |
|---|---|---|---|---|---|---|
| W(θ, 0.37) | **−3.105** | **−1.397** | **0 (부호전환)** | +0.760 | +2.533 | **+3.096** |

★★ **해석 — 이게 이 논문의 가장 미묘한 물리다**:
- **θ 가 큰 접촉(반대편, 힘사슬로 관통하는 접촉)** → `W > 0` → `g_NL > 0` → **더 뻣뻣하게**.
- **θ 가 작은 접촉(같은 쪽 이웃)** → `W < 0` → **더 무르게**.
- 부호전환각 θ\* (우리 계산): **ν=0 → 88.2°, 0.20 → 83.6°, 0.30 → 80.4°, 0.37 → 77.6°, 0.46 → 71.3°, 0.50 → 70.5°.**

⚠ **그러면 왜 논문의 모든 배치에서 결과가 뻣뻣한 쪽(Δ > 0)으로만 나오나?**
우리 판단: **평형 구속** 때문이다. 접촉 ea 를 볼 때, 입자 a 의 **나머지 힘들의 합력은 반드시
`−P^{ea} n^{ea}` 방향**(= θ 가 큰 쪽) 이어야 한다. 즉 "다른 접촉들"은 구조적으로 큰 θ 에 편중된다.
⇒ **Δ > 0 은 격자 배치의 우연이 아니라 평형에서 오는 계통적 편향**이다.
(참고 — 등방·등력 가정의 입체각 평균 `⟨W⟩ = 2(1+ν)[−2(1−ν) − (1−2ν) + (7−8ν)/3]` 은
ν=0.5 에서 **정확히 0**, ν<0.5 에서 **음수**(ν=0.37 → −0.475)다. 즉 **접촉 배치가 등방이면 순효과가
사라지거나 뒤집힌다** — 이 효과는 **보편 배수가 아니라 배치(anisotropy) 의존**이다. 우리 bimodal
AM-rich 침대처럼 작은 SE 가 큰 강체 AM 사이에 끼인 배치는 1D 사슬과 각도분포가 전혀 다르므로
**Δ 를 그대로 옮겨 쓰면 안 된다**.)

> 위 표·부호전환각·등방평균은 **우리 유도**다(식 (5) 대입). 논문에 그 표는 없다.
> 다만 논문 자신의 식 (11)·(14) 특례를 정확히 재현하므로 **대수적으로 검증된 유도**다.

### 4.5 두 개의 시사적 특례 (§2.2, Fig 4)

**(a) Tatara 극한 — 2구 축방향 압축** (Fig 4 왼쪽). `P₁¹ = P₂¹ = F`, `θ₁¹ = θ₂¹ = π`:
```
g_NL = Σ_{k=1,2} F(1+ν_k)(3−2ν_k) / (4π R_k E_k)                             … (11)
```
힘 F 를 3회 연속 반복(iteration)하면:
```
F = n_H g^{3/2} + O(g²)
F = n_H g^{3/2} + (3n_H²/2n_NL) g² + O(g^{5/2})
F = n_H g^{3/2} + (3n_H²/2n_NL) g² + (21n_H³/8n_NL²) g^{5/2} + O(g³)         … (12)
   (n_NL ≡ F/g_NL)
```
**첫 반복(g_NL = 0)이 Hertz** 이고, **추가 항이 전부 양(+)** → **Hertz보다 뻣뻣**.
Fig 4 캡션이 직설적으로 적는다: *"two elastic spheres in compression behave **stiffer** than Hertz theory predictions."*
논문은 이것이 **Tatara(1989)가 얻은 바로 그 식**임을 확인한다 (각주 1: *"3항에 아마도 오타로 보이는 오류를 제외하면"*).

**(b) ★ 겹침 없이 생기는 접촉** (Fig 4 오른쪽). 네 개의 횡하중 `P₁¹=P₁²=P₂¹=P₂²=F`, 모두 `θ = π/2`:
```
P = (n_H / n_NL^{3/2}) · F^{3/2}   ,   g = 0                                  … (13)
1/n_NL = Σ_{k=1,2} (1+ν_k)(3√2 − 4 − 4√2 ν_k + 8ν_k) / (4π R_k E_k)          … (14)
```
**즉 질량중심이 전혀 접근하지 않았는데(g=0) 압축 접촉력 P > 0 이 존재한다.**
논문: *"Hertz theory predicts P = 0 for this configuration, regardless the value of F."*
물리: 횡하중이 구를 옆으로 눌러 **포아송 팽창으로 z-극이 서로 닿는다.**

★★ **우리에게 직격**: 우리 Kirchhoff 망은 **기하 겹침 δ > 0** 으로 접촉을 센다.
이 논문은 **δ = 0(또는 음의 갭)에서도 하중을 받는(=전도하는) 접촉이 존재**한다고 말한다.
실제로 Algorithm 1 line 8 의 활성 판정은 `if g^ea + ᵏg^ea_NL > 0` 이다 — **g < 0 인 쌍도 활성이 될 수 있다.**
반대로 Fig 12 는 **압축성이 큰 재료의 close-packed 배치에서는 수평 이웃 사이에 틈(gap)이 생긴다**고
예측한다 → **양방향 모두** 우리 접촉검출과 어긋날 수 있다.

### 4.6 구현 (§2.3, Algorithm 1)

**자료구조**: **단체복합체(simplicial complex) X** — 꼭짓점 `E₀(X)` = 각 입자의 질량중심,
간선 `E₁(X)` = **"있을 법한(plausible)" 접촉쌍 상호작용** (Fig 5 왼쪽).
⚠ **"plausible" 의 판정 기준(컷오프)은 논문에 없다.** 그런데 §4.5(b) 처럼 겹침 0에서도 접촉이 생기므로
**기하 접촉보다 넓은 후보 집합이 필요**하다 → 사실상 **숨은 구현 선택**이다 (§9 자유 파라미터 감사 참조).

**알고리즘** (그대로 옮김, 기호만 정리):
```
Require {g^ea}, TOL, simplicial complex X
1  Error ← TOL ; k ← 0 ; {⁰g^ea_NL} ← {0}
2  while Error ≥ TOL do
3     for ea ∈ E₁(X) do                              # 모든 접촉쌍
4        if g^ea + ᵏg^ea_NL > 0 then                 # ★ 활성 판정 (겹침 0 이하도 가능)
5           P^ea ← n_H^ea (g^ea + ᵏg^ea_NL)^{3/2}    # 식 (10)
6           for eb ∈ INCIDENT(ea) do                 # ea 에 인접한 모든 접촉쌍
7              ᵏ⁺¹g^eb_NL ← ᵏ⁺¹g^eb_NL + w^eb_ea     # 식 (5)
8        Error ← ‖ᵏ⁺¹g_NL − ᵏg_NL‖ ; k ← k+1
9  for ea ∈ E₁(X) do                                 # 수렴한 g_NL 로 전역력 조립
10    if g^ea + ᵏg^ea_NL > 0 then  F ← ASSEMBLE(ea, P^ea)
11 return F
```
`INCIDENT(ea)` = 간선 ab 에 인접한 간선들 = **입자 a 에 걸린 다른 접촉 + 입자 b 에 걸린 다른 접촉**
(Fig 5 오른쪽이 정확히 이 그림).

**비용**: 안쪽 이중 루프가 `N_c × (인접 간선 수)` → **O(n̄ N_c)** 오버헤드.
논문 주장: *"기존 코드에 이 정식화를 구현하는 데 필요한 유일한 수정"*.

## 6. 결과 — 배치별 수치 (§4)

### 6.1 주기 균질 입상결정 (§4.1) — 불일치의 닫힌형

정의:
```
Δ = [ P(g) − n_H g^{3/2} ] / (n_H g^{3/2})       … (16)      (분자: 비국소 − Hertz)
ε = g / 2R          (1D·2D 정방·3D 입방)
ε = g / (√2 R)      (π/4 회전 배치)
ε = g / (√3 R)      (close-packed 배치)
```
**1D 사슬**:
```
Δ_1D = (1/2π)·[(3−2ν)/(1−ν)]·ε^{1/2} + (7/24π²)·[(3−2ν)/(1−ν)]²·ε + O(ε^{3/2})      … (17)
```
**2D/3D**: 이축·삼축 하중이 `O(ε^{5/4})` 항을 새로 넣지만 **앞 두 항은 그대로**:
```
Δ_2D,3D = (1/2π)·[(3−2ν)/(1−ν)]·ε^{1/2} + (7/24π²)·[(3−2ν)/(1−ν)]²·ε + O(ε^{5/4})   … (18)
```

★★ **논문이 이 식에서 뽑는 3줄 (§4.1, stated)**:
1. Δ 는 **ε 과 ν 에 강하게** 의존한다.
2. Δ 는 **E(영률)와 입자 크기와 무관**하다.
3. Δ 는 **격자의 차원 배치에는 약하게만** 의존한다 (1D ≈ 2D ≈ 3D — Fig 8 수치와 정합).

⚠ **Δ ∝ ε^{1/2} = ε=0 에서 기울기 무한** → **문턱이 없다.** "작은 변형에서는 Hertz 가 맞다"가 아니라
"작은 변형에서 **오차가 가장 빨리 자란다**"가 맞다. Fig 7 본문도 *"Hertz theory predictions depart from
experimental observations at **very small deformations**"*.

- **회전(π/4) 2D 격자** (Fig 11): 비압축(ν→1/2)에서 **불일치가 더 크다**; 반대로 **매우 압축성인 재료(ν→0)는
  회전 배치에서 비국소 효과에 덜 민감**하다.
- **close-packed 2D** (Fig 12): 역시 비압축에서 크고 압축성에서 작다. ★ **압축성 비드의 close-packed 배치에서는
  수평 이웃 사이에 틈이 생긴다**고 비국소가 예측 (Hertz 는 그런 예측 자체가 불가).
- **초기 구속 ε₀ = 4 %** (Fig 13): ★★ **다른 모든 배치와 달리 오차가 소변형에서 `O(ε^{1/2})` 이 아니고,
  ε = 0 에서 이미 유의하게 크다.** 즉 **이미 눌려 있는(preloaded) 침대**에서는 비국소 오차가
  "0에서 출발해 자란다"가 아니라 **처음부터 상수 offset 으로 존재**한다. 논문은 이 다른 거동 때문에
  Fig 14 로 별도 FEM 검증까지 했다.

### 6.2 BCC 입상결정 압밀 (§4.1 후반, Figs 15–17)
```
ρ_R = π√3 / [ 8 (1−ε_x)(1−ε_y)(1−ε_z) ]      … (19)      (미변형 ρ_R = 0.68)
정수압: ε_x = ε_y = ε_z      /      다이: ε_x = ε_y = 0, ε_z ≠ 0
```
- BCC 압밀 중 **2차 접촉이 활성화**되고, 다이 압밀에서는 고밀도에서 **3차 접촉까지** 활성화 →
  계가 **점점 더 뻣뻣해지고 고밀도 도달에 큰 하중이 필요**해진다. 논문: *"the accurate prediction of the onset
  of second and third contacts relies on the ability of the model to account for nonlocal mesoscopic-deformation effects."*
- **정수압** (Fig 16): 비압축(ν→1/2)에서 Δ 가 **먼저 곡률이 바뀌고 그 다음 ρ_R > 0.95 에서 급증** — 원인은 **2차 접촉 형성**.
  2차 접촉: **비국소 ρ_R = 0.95 (ν=0.45) vs Hertz ρ_R = 1.04 (모든 ν)**. Δ 세로축 범위 0–200 %.
- **다이** (Fig 17): Δ 곡선에 **ρ_R ≈ 0.78 부근의 꺾임점(corner point)** — 역시 2차 접촉.
  **비국소 0.780 (ν=0.45) vs Hertz 0.786**. **3차 접촉은 비국소 ρ_R = 0.96**. Δ 세로축 0–250 %.
  Fig 17 왼쪽은 **횡(transversal) 반력**도 함께 그린다 (= 다이 벽응력).

### 6.3 무질서 이종 입상계 (§4.2, Figs 18–19) — **우리에게 가장 관련 있는 계**
- 조성·크기·다이는 §3.2 표 참조 (2종, 125개, 1×1 mm², ρ_R,0 = 0.42).
- **★ 두 국면(regime) 분리** (논문 stated): 
  - **다짐(consolidation) 국면** — 상대밀도가 **입자 변형이 아니라 재배열(rearrangement)** 로 올라간다.
    **Hertz 와 비국소가 "비슷한 변형 패턴"을 예측** (Fig 18 오른쪽, ρ_R=0.56 스냅샷에 재배열이 뚜렷).
  - **압밀(compaction) 국면** — 다짐이 끝나면 상대밀도를 더 올리려면 **기계적 압밀**이 필요하고,
    이때부터 **메조 변형 효과가 지배적이 되어 Hertz 가 비국소에서 이탈**한다.

★★ **이 두 국면 분리가 우리 판정의 핵심 근거다** — 우리 300 MPa 침대는 **압밀 국면**이지 다짐 국면이 아니다.

## 8. Post-processing ★

- **무엇을 계산해 내놓나**:
  - 힘-변형 곡선(`P/πR²` vs 변형 %) — 단일 구 및 격자.
  - **횡반력(lateral / transversal reaction)** — Hertz 가 0 으로 놓는 양.
  - **불일치 지표 Δ** (식 16) — 비국소 대 Hertz 의 상대차. 이것이 논문의 **주 정량 지표**.
  - **상대밀도 ρ_R** (식 19) — BCC 는 단위셀 변형에서 해석적으로, 무질서 침대는 다이 부피/고체부피로.
  - **2차·3차 접촉 개시 상대밀도** — Δ 곡선의 곡률변화/꺾임점으로 판독.
- **도구**: 논문에 코드명 없음. 접촉 정식화는 자체 구현(Algorithm 1), FEM 은 Lagrangian 유한요소
  (Zienkiewicz & Taylor 인용, **상용 패키지명 미기재**), 초기패킹은 **탄도증착**(Jullien & Meakin 1989).
  ⇒ **소프트웨어 스택은 n/a.**
- **수치화 방식**: Δ 를 ν 의 **밴드**(ν ∈ (0, 0.50) 또는 (0, 0.44))로 그려서 **재료 무관 상한/하한**을 보인다.
  E 와 크기가 소거되므로 **한 장의 그림이 모든 재료·모든 입경을 덮는다** — 우리가 배울 만한 표현법.
- **통계/앙상블**: 무질서 침대는 **125 입자 · 실현(realization) 1개**로 보인다 (복수 시드 언급 없음).
  ⇒ **추세 전용**, 통계적 오차막대 없음.

### 10.4 ★★★ 치밀영역 과강성을 고치는가? → **아니다. 부호가 반대다.** (요청 항목 #4)

**증상 정의부터 정확히**:
- **우리 증상**: real E_SE = 24 GPa 로 두면 300 MPa 에서 **겹침이 부족해 실험 porosity 에 도달하지 못한다**
  = 압밀 관점에서 **너무 뻣뻣**. 처방 = **E 를 18× 낮춤** (= **더 무르게**).
- **이 논문이 고치는 증상**: **Hertz 가 하중을 UNDER-predict** 한다 = **너무 무르다**.
  처방 = `g → g + g_NL` (= **더 뻣뻣하게**). Fig 4 캡션·식 (12) 양의 고차항·모든 Δ > 0 이 이를 확인.

**⇒ 같은 증상이 아니다. 정반대다.**
변위제어 압밀에서 접촉이 뻣뻣해지면 **같은 밀도에서 응력이 더 빨리 올라가** 목표압(300 MPa)에 **더 낮은
밀도에서 도달한다** → **porosity floor 가 올라간다.** 우리는 floor 를 **내리고 싶다.**

**⇒ 정직한 결론 (우리에게 불리한 판정)**:
> 비국소 탄성을 우리 DEM 에 넣으면 **18× 연화를 대체하기는커녕, 연화를 더 해야 한다.**

**크기 추정 (우리 유도, order-of-magnitude)**:
같은 겹침에서 힘이 `(1+Δ)` 배가 되므로, 거시응답을 유지하려면 전치인자 `n_H ∝ E*` 를 `1/(1+Δ)` 로 낮춰야 한다.
우리 pure-SE @300 MPa 의 ⟨δ⟩ ≈ **직경의 11 %** (CLAUDE.md, Cronau overlap 11–12 %) 이므로 ε ≈ 0.11,
ν = 0.37 → Δ ≈ **23 %(하한)**:
```
E_eff : 1.35 GPa → 1.35/1.23 ≈ 1.10 GPa      lumping : 24/1.35 = 17.8×  →  24/1.10 ≈ 21.9×
```
⚠ 이 숫자의 단서 (전부 인정할 것):
1. **우리 hooke/hysteresis 는 지수 3/2 가 아니라 ~선형**이라 지수 사상이 정확하지 않다.
2. ε = 0.11 은 논문이 명시한 유효범위 **ε < 10 % 를 살짝 넘는다**.
3. 절단급수는 **하한**이다 (§6.1 경고) → 실제 Δ 는 더 클 수 있고, 그러면 연화도 더 필요하다.
4. 침대 수준 응답에는 **재배열**이 섞여 있어 단일접촉 논증이 그대로 성립하지 않는다.
5. **복합 침대의 SE 접촉은 AM 에 차폐되어 ε 이 훨씬 작다.** 정본 `giannis2021_*` §7-4 는 CLAUDE.md 의
   "overlap 1.75 %" 를 **δ/d = 0.0175** 로 읽는다 → 그 값이면 Δ ≈ 8.2 % → **lumping ≈ 19×**.
   ⚠ **규약 미대조 (열린 항목)**: 같은 CLAUDE.md 가 그 케이스의 `⟨δ⟩ = 0.0739 µm` 라고 적고 SE 직경이 ~1 µm 이므로
   산술로는 **δ/d ≈ 7 %** 가 나온다 (Δ ≈ 18 % → lumping ≈ 21×). **두 읽기가 4배 다르다** —
   `overlap %` 가 길이 규약인지 부피 규약인지 **코드에서 확인해야 한다.** 두 카드가 같은 가정을 공유하므로
   틀리면 **둘 다 틀린다.**
⇒ **인용 형태는 "연화 배수는 이 축에서 하한이다"** 까지. **21.9× 라는 숫자를 헤드라인으로 쓰지 말 것.**

★★ **독립 수렴 (2026-08-25)**: 정본 `giannis2021_stress_based_multicontact_dem.md` §7-3/§7-4 가
**완전히 다른 정식화(응력기반 MC-stress)로 같은 결론에 도달**했다 —
*"MC-stress 를 지금 우리 LIGGGHTS 에 넣으면 연화가 줄지 않고 **늘어난다** — 18× → **20–55×**(pure-SE) /
**18–24×**(복합)"*, 그리고 *"`elasto_plastic_feasibility.md` §1 경로 B 의 '과강성' 서술은 **부호가 틀렸다**"*.

당연하다, 이 논문은 **prefactor 가 없어** 크기를 키울 자유도가 없고, 그들 밴드의 폭은 **β 1.65–5.17 의 폭**이다.
⇒ ★★ **두 개의 독립 계보(변위 기반 / 응력 기반)가 부호와 크기대역 모두에서 일치한다** =
**"우리 18× 는 하한" 이라는 문장이 단일 문헌 의존이 아니다.** 원고에서 이 두 카드를 함께 인용할 것.

**그렇다면 이 논문이 치밀영역에서 실제로 고치는 것은 무엇인가** — **위상(topology)이다**:
- **2차 접촉 개시를 ρ_R 1.04(불가능) → 0.95 로 당긴다** (정수압 BCC). 다이에서는 0.786 → 0.780,
  **3차 접촉은 ρ_R 0.96**.
- 우리 관심영역(**ρ_R ≈ 0.85, porosity 15 %**)은 **다이 2차 접촉(0.78) 위, 3차(0.96) 아래**에 정확히 놓인다.
  ⇒ **닿는다.** 단, 그 계는 **탄성 BCC 고무**다.
- 무질서 침대(Fig 19)의 축 범위(ρ_R 0.4–0.9, 0–600 MPa)도 **우리 조건을 덮는다** — 역시 탄성 유기분말.

### 10.5 ★★ 우리에게 진짜 쓸모 있는 부분 — 전달(σ) 축 (우리 유도)

식 (8) 에 식 (10) 을 대입하면 **접촉반경의 닫힌형**이 나온다:
```
a³ = (3P/4)(1/E*)R*  ,   P = n_H(g+g_NL)^{3/2} = (4/3)E*√R* (g+g_NL)^{3/2}
⇒  a = √( R* (g + g_NL) )        (Hertz 는 a = √(R* g))
⇒  a / a_Hertz = (1 + g_NL/g)^{1/2} = **(1 + Δ)^{1/3}**
```
(마지막 등식: `1+Δ = (1+g_NL/g)^{3/2}`.) **이 두 줄은 우리 유도**이며 논문에 이 형태로 적혀 있지 않다.
그러나 식 (8)·(10)·(16) 의 **대수적 귀결**일 뿐이라 새로운 가정이 없다.

**Holm 접촉저항 `R = 1/(2σ r_c)` → 컨덕턴스 ∝ r_c** 이므로:

| Δ (조건) | a/a_Hertz | 접촉면적 배수 | Holm 컨덕턴스 배수 |
|---|---|---|---|
| 6.1 % (ε=1 %, ν=0.37) | ×1.020 | ×1.040 | **+2.0 %** |
| 14.7 % (ε=5 %) | ×1.047 | ×1.096 | **+4.7 %** |
| 23.1 % (ε=11 %, 우리 pure-SE) | ×1.072 | ×1.149 | **+7.2 %** |
| 50 % (논문 무질서 침대) | ×1.145 | ×1.310 | **+14.5 %** |
| 200 % (논문 BCC 완전압밀) | ×1.442 | ×2.080 | **+44 %** |

★ **우리 σ_ionic 스케일링 법칙과의 정합**: 우리 폼은 `cov^{1/2}` 를 쓰는데
접촉면적이 `(1+Δ)^{2/3}` 배면 `√cov` 는 `(1+Δ)^{1/3}` 배 = 위 표의 컨덕턴스 배수와 **정확히 같다.**
즉 이 보정은 우리 폼에 **곱셈 인자 하나**로 깨끗이 들어간다 — 새 항을 만들 필요가 없다.

⚠ **단, 이걸 곧바로 σ 에 곱하지 말 것.** 세 가지 이유:
1. **Stage-E 가 이미 소성 접촉면적을 위로 밀고 있다** (Tabor + volume). 두 보정은 **다른 물리**이지만
   `min(caps)` 천장(`network_conductivity.py:240-264`)이 이미 걸려 있어 **이중계상 위험**이 실재한다.
2. 이 Δ 는 **탄성** 값이다. 접촉이 항복하면 압력이 H 로 캡되어 면적 관계가 바뀐다.
3. Δ 는 **배치 의존**(§4.4)이라 접촉마다 다르다 — 침대 평균 하나로 곱하면 분포를 지운다.

### 10.8 우리 프레임과의 정합 (frame [1]–[5])

- **frame [1]/[2]**: 이 논문은 **강체-구 DEM 계열**의 **탄성 정밀화**다. 형상소성이 없으므로
  **frame[1] LIMITS 를 그대로 물려받는다** — porosity floor 를 소성으로 깨는 능력이 없다.
  실제로 **~20 % 강체구 floor 아래로 가는 어떤 메커니즘도 이 논문에 없다.**
- **frame [4] (cross-fit 금지)**: 이 논문은 **DEM 도 MPM 도 아닌 제3의 해석 기준**이라
  우리 어느 쪽과도 **cross-fit 위험이 없다** — 순수한 외부 자(ruler)로 쓸 수 있다.
  그리고 **자유변수 0** 이라 "맞춰서 맞은 것"이 원리적으로 불가능하다. ★ 이 성질이 이 논문의 가장 큰 값이다.
- **frame [5] (분업)**: 이 논문이 소유한 절반 = **역학(힘-변위·벽응력)**. 빠진 절반 = **전달 σ 전부**
  (이온·전자·열 어느 것도 계산하지 않는다) + **형상 morphology** + **소성**.
  ⇒ **frame[5] 재확인**: 2012년 JMPS 급 접촉역학 논문조차 σ 를 내지 않는다.

## 11. 적용 인사이트 — 우리가 실제로 할 수 있는 것

### ① ★★★ **DEM 재실행 없이, 기존 덤프만으로 Δ 를 측정한다** (최우선, 비용 거의 0)
우리는 이미 접촉력 네트워크를 갖고 있다 (`pair/gran/local` contact dump 또는 atom dump).
접촉 ea 마다 **양쪽 입자의 다른 접촉력 P_i 와 각도 θ_i** 를 뽑아 식 (5) 로 `g_NL` 을 한 번만 계산하면,
- **Δ 의 분포** (평균이 아니라 히스토그램) — 우리 침대가 논문의 어느 배치에 가까운지;
- **`a/a_Hertz = (1+Δ)^{1/3}` 분포** → 우리 Holm 망 σ 의 보정 상한;
- **`g + g_NL > 0` 인데 `g ≤ 0` 인 쌍의 개수** = **우리가 놓치고 있을 수 있는 접촉 수**;
- **AM-쉴딩된 SE 접촉 vs pure-SE 접촉**의 Δ 차이 (= 배치 의존성의 우리-특이 측정).
이건 **후처리 한 번**이고 LIGGGHTS 코드를 한 줄도 안 고친다. **사전등록해서 돌릴 것.**
⚠ **판정선은 런 전에 등록**하고, 결과가 나오면 "Δ 는 이 침대에서 x % 이며 그것은 σ 를 y % 올린다" 는
**측정 서술**로만 쓴다 (보정 적용은 별건, §10.5 의 이중계상 경고 참조).

### ② ★★ **연화 배수는 이 축에서 하한이다** — 원고 문장 하나
지금까지 18× 는 "필요한 만큼" 이었지 "충분한 만큼" 이 아니었다.
비국소 탄성이 실재한다면(Tatara 실험 + FEM 이 지지) **우리가 빠뜨린 뻣뻣함이 있고**,
그것을 넣으면 **연화를 더 해야 한다**. ⇒ 원고에서 18× 를 방어할 때
*"이 값은 비국소 탄성 결합을 무시한 하한이다"* 라고 **한 줄 붙이면 방어가 강해진다** (약해지지 않는다).

### ③ ★★ **2·3차 접촉 개시를 우리 침대에서 재고 문헌 값과 대조**
논문은 BCC 라는 **이상 격자**에서 정수압 0.95 / 다이 0.780 / 3차 0.96 을 준다.
우리는 무질서 다분산 침대라 값 자체는 다를 것이다. 하지만 **"압밀 곡선의 꺾임 = 새 접촉 배위의 활성화"**
라는 **판독법**은 그대로 쓸 수 있고, 우리 **Heckel P_y = 138 MPa 무릎**의 물리적 해석 후보가 하나 늘어난다
(기존 해석: 탄성→소성 전이. 새 후보: **2차 접촉 활성화**). ⇒ **두 후보를 구분하는 실험 설계 가치.**

### ④ ★ **다짐/압밀 국면 분리를 우리 압력 sweep 에 도입**
논문 §4.2: **재배열 지배 구간에서는 Hertz 와 비국소가 같고, 변형 지배 구간에서 갈라진다.**
⇒ 우리 다압력 런(100/200/300/600 MPa)에서 **재배열 지표**(입자 변위 vs 겹침 증가의 비)를 뽑아
어느 압력에서 국면이 바뀌는지 표시하면, **어느 압력 구간의 결과가 접촉법칙에 민감한지**를 미리 알 수 있다.
낮은 압력 결과는 접촉법칙 선택에 **둔감**할 것이다 — 이건 우리 결론의 **강건성 논거**가 된다.

### ⑤ ★ **횡반력(벽응력)** — f_AM 하중분담 트랙에 새 각도
Hertz 는 단일 구속 구에서 **횡반력을 0 으로 준다**. 실제로는 유한하고 FEM 이 확인했다 (Fig 8, 14, 17).
우리 `f_AM` 운용규약 두 개(contact-network-only vs phase-virial)는 **접촉망 응력의 배분**을 다투는데,
비국소 항은 **접촉력 자체를 바꾸므로** 그 배분도 바꾼다. ⇒ **f_AM 불확실성 구간에 항목 하나 추가.**

### ⑥ **Harthong 2009 를 위시리스트에** — 이 논문의 **소성판**
논문 §1 이 인용: *"Harthong et al. (2009) fitted, from finite-element simulations of simple periodic lattices,
contact laws that account for **nonlocal-deformation effects during high-density compaction of elasto-plastic
particles**."* (Int. J. Solids Struct. 46, 3357–3364).
⇒ **비국소 + 소성 + 고밀도** = 우리가 실제로 필요한 조합. **litdb 미보유. 확보 1순위 후보.**
⚠ 단 그쪽은 **FEM 에서 fitting** 하므로 자유변수가 있고 격자별 case-by-case 특성화가 필요하다
(이 논문 §1 이 그 한계를 지적한다).

**★ 같이 확보할 것 — Brodu, Dijksman & Behringer (2015), *Phys. Rev. E* 91, 032201** (= Giannis 의 "MC-strain").
이 논문과 **같은 변위-보정 축의 유일한 경쟁 모델**인데 **litdb 미보유**다.
확보하면 축 B 가 **세 점(자유변수 0 / γ / β)** 으로 완성되어, "결합을 얼마나 물리에서 유도했나" 를
**정량 비교**할 수 있다. 보너스로 **광탄성 하이드로겔 구 패킹 실측 데이터**(Barés 2020 [50] 포함)가 딸려 있어
**다입자 접촉력망 검증 앵커**가 생긴다 — 이 논문에는 없는 것이다.

### ⑦ **Mesarović & Fleck 2000 카드에 한 줄 추가**
우리는 이미 `papers/mesarovicfleck2000_dissimilar_elastoplastic_indentation.md` 를 보유.
이 논문 §1 이 그것을 **비국소 선행 연구**로 인용한다: *"studied elasto-plastic spheres and concluded that
the **assumption of independent contacts only holds in the early stages of compaction**."*
⇒ 그 카드에 **"독립접촉 가정의 유효구간을 소성 구에 대해 명시한 최초 문헌"** 이라는 각도가 빠져 있으면 보강.

## 12. LIGGGHTS 이식 가능성 (요청 항목 #6) — **냉정한 평가**

**논문 주장**: *"this is the only modification required for implementing the nonlocal contact formulation
in existing codes"*, 오버헤드 **O(n̄ N_c)**.

**우리 판단 — 주장보다 어렵다. 세 가지 구조적 마찰이 있다.**

| # | 문제 | 왜 LIGGGHTS 에서 비싼가 |
|---|---|---|
| 1 | **한 타임스텝 안의 수렴 반복** | LIGGGHTS 힘 계산은 이웃 리스트를 **1회 통과**하는 구조다. `while Error ≥ TOL` 은 **매 스텝 이웃리스트를 여러 번 통과**하게 만든다. 반복마다 `g_NL` 을 **MPI reverse+forward comm** 해야 한다 (고스트 입자의 접촉이 필요) |
| 2 | **입자별 접촉 리스트 + 각도** | pair 스타일은 쌍 단위라 "이 접촉에 인접한 다른 접촉들"을 자연히 갖고 있지 않다. `fix` 로 per-particle 접촉 배열을 쌓아야 하고, 그 배열이 **고스트 영역까지** 필요 → **halo 확장** |
| 3 | **`plausible` 간선 집합** | 겹침 0 접촉이 가능하므로 후보 쌍이 **기하 접촉보다 넓다** → cutoff/skin 을 키워야 하고 그만큼 이웃 수가 는다 |

**실용 경로 (우리 권고, 3단계 — 뒤로 갈수록 비쌈)**:
- **P0 — 후처리 진단 (권고 시작점, §11 ①)**: 시뮬레이션은 그대로, **덤프에서 `g_NL` 을 사후 계산**만.
  코드 변경 **0**, 비용 **1회 O(n̄ N_c)**. 우리가 실제로 얼마나 영향받는지 먼저 잰다.
- **P1 — 명시적 1-반복 근사**: 이전 스텝의 `g_NL` 을 그대로 쓰고 스텝당 **딱 1회**만 갱신
  (명시적 DEM 은 Δt 가 작으므로 사실상 수렴한다). `while` 루프 제거 → 구조 훼손 최소.
  비용: 힘 커널이 **~2n̄ 배** (우리 Z ≈ 6–10 → 힘 루프 **1자릿수** 증가; 힘 커널이 전체의 일부이므로
  **총 ~3–10× 느려짐**으로 추정). ⚠ **이 배수는 우리 추정이고 논문에 벽시계 수치가 없다** (§3.5 n/a).
- **P2 — 완전 구현**: `while` 수렴 + halo 확장 + `g+g_NL>0` 접촉 생성/소멸. C++ 개발 수 주 이상.
  ⚠ **접촉 생성/소멸이 반복 안에서 일어나면** 에너지/모멘텀 보존과 접촉 이력(hysteresis 상태)이 꼬인다 —
  우리 hooke/hysteresis 는 **이력 변수**를 갖고 있어 특히 위험. **P2 는 지금 권하지 않는다.**

**⇒ 권고: P0 만 즉시. P1 은 P0 결과가 "Δ 가 유의하다"고 나올 때만. P2 는 보류.**

## 13. 인용 가능 문장 (deck/paper 용)

- "Gonzalez and Cuitiño (JMPS 2012) removed the classical *independent-contacts* restriction of Hertz theory by
  superposing the nonlocal mesoscopic deformations that every other contact force induces at a given contact
  interface, yielding a **parameter-free** closed-form law `P(g) = n_H (g + g_NL)^{3/2}` that reduces exactly to
  Hertz when `g_NL → 0`."
- "Their discrepancy measure depends only on the deformation and the Poisson's ratio — **not on Young's modulus
  or particle size** — which is what makes their rubber-sphere calibration transferable in principle to a
  micrometric sulfide electrolyte."
- "Because the nonlocal coupling **stiffens** the contact (up to ~40 % at 10 % deformation for ν → 1/2, and ~200 %
  near full compaction of a BCC lattice), the effective-modulus softening we apply to reproduce experimental
  porosity is, on this axis, a **lower bound**: including nonlocal elasticity would require *more* softening,
  not less."
- "The nonlocal formulation predicts load-bearing contacts at **zero centre-to-centre approach** (their Eq. 13),
  a configuration for which Hertz theory returns exactly zero force — a direct warning that overlap-based
  contact detection can undercount the conducting network in a confined bed."
- ⚠ **금지**: 이 논문을 "소성 압밀 모델" 로 인용하지 말 것. **탄성 전용**이며 저자들이 소성을 미래 과제로 명시한다.

## 14. 주의 / 한계 (over-claim 방지)

1. **탄성 전용.** 소성·점착·마찰·중력·점탄성·bonding 전부 없음 (초록·§1·§5 에서 3회 반복 명시).
   우리 300 MPa 압밀에 **직접 적용 불가**.
2. **부호가 우리 필요와 반대.** 뻣뻣하게 만든다. **연화의 대체재가 아니다.**
3. **소재 전이 제한.** 검증은 **고무구 1개**(E=1.85 MPa), 침대는 **유기 제약분말 유사**(E 7/19 GPa).
   **배터리 소재·황화물 SE·NMC 없음.** 무차원량(ν, ε, ρ_R)으로만 옮길 것.
4. **다입자 실험 검증 없음.** 125-입자 계산은 **실현 1개**로 보인다. 오차막대 없음 → **추세 전용**.
5. **식 (17)/(18) 은 절단급수** — ε ≳ 5 % 에서 **하한**이다 (논문 §5 요약값 40 % vs 급수 25 %).
   그 급수를 물리상수처럼 인용하지 말 것.
6. **Δ 는 배치 의존이고 부호가 바뀔 수 있다** (우리 유도 §4.4: θ < θ\* ≈ 70–88° 접촉은 **무르게** 만든다).
   **하나의 보편 배수로 취급 금지.** 특히 bimodal AM-rich 침대의 SE 접촉 각도분포는 1D 사슬과 다르다.
7. **접촉면 안의 압력분포는 여전히 Hertz 가정**이다. 접촉면적이 매우 커지면(a/R ≳ 0.4) 그 가정 자체가 흔들린다
   (Zhupanska 의 6 % 오차 진술은 a/R < 0.40 조건부).
8. **`a = √(R*(g+g_NL))` 와 `a/a_Hertz = (1+Δ)^{1/3}`, 각도 가중표, θ\*, 등방평균, ν별 Δ 표는 전부 우리 유도**다.
   논문에 그 형태로 적혀 있지 않다 (단 식 (11)·(14) 특례로 대수 검증됨). **stated 로 인용하지 말 것.**
9. **정적 해석만.** 동적 확장을 *"straightforward"* 라고 적었지만 **수행하지 않았다**.
   우리 LIGGGHTS 는 명시적 동역학 → 관성·감쇠와의 상호작용은 **미검증 영역**.
10. **소프트웨어/비용 수치 부재.** 코드명·반복횟수·벽시계 시간 전부 **n/a**.
    §12 의 "3–10× 느려짐" 은 **우리 추정**이지 논문 값이 아니다.
11. **⚠ 정정 이력 (지우지 않고 남김)**: 이 카드의 초안은 *"이 논문 = Giannis 가 말한 strain-based multi-contact
    model"* 이라고 판정했는데 **틀렸다**. 정본 `giannis2021_stress_based_multicontact_dem.md` 확인 결과
    그 baseline 은 **Brodu 2015 (PRE 91, 032201)** 이고, 이 논문은 Giannis 의 **참고문헌 [24]** 로만 등장한다 (§10.2).
    **계보 축(non-binary) 분류는 맞았고, "어느 논문이 그 이름표를 받았나"가 틀렸다.**
    ⚠ Brodu·Giannis 관련 서술은 전부 **우리 다른 카드 경유**다 — 두 원문 모두 미열람. **Brodu 2015 는 litdb 미보유.**
12. **그림 digitize 0.** 이 세션에 렌더 도구가 없었다. Fig 10–13, 16–17, 19 의 곡선값은 **읽지 않았다** —
    필요해지면 PDF 를 렌더해 별도 digitize 할 것.

## 15. 기술 용어 미니 사전 (이 카드를 처음 읽는 사람용)

| 용어 | 뜻 | 이 논문에서 |
|---|---|---|
| **independent contacts** | 한 입자의 각 접촉이 서로 영향을 주지 않는다는 가정 | **이 논문이 깨는 대상** |
| **nonlocal (비국소)** | 어떤 점의 응답이 그 점 근방만이 아니라 **먼 곳의 하중**에도 의존 | 접촉면 변형이 **반대편 접촉력**에 의존 |
| **mesoscopic deformation** | 접촉면(micro)보다 크고 침대(macro)보다 작은 **입자 한 개** 스케일의 변형 | `g_NL` 의 물리적 정체 |
| **Boussinesq 해** | 반무한 탄성체 표면의 **집중력**에 대한 고전 해 | 접촉면 **밖** 변위의 출발점 (식 3) |
| **Love (1929) 퍼텐셜 해** | 원판 위 분포압력에 대한 반무한체 해 (Newtonian + 로그 퍼텐셜) | Case II 의 출발점 (식 26–29) |
| **Fredholm 적분방정식 2종** | `φ(x) = f(x) + λ∫K(x,y)φ(y)dy` 꼴 | Zhupanska 정해가 귀착하는 형태 |
| **dual series equation** | 혼합 경계조건(접촉/무하중)을 급수 두 벌로 쓰는 기법 | Zhupanska 정해의 도구 |
| **superposition (중첩원리)** | 선형계에서 여러 하중의 해 = 각 해의 합 | **비국소 결합의 유일한 정당화 근거.** ⇒ **비선형(소성)이면 무너진다** |
| **simplicial complex** | 꼭짓점+간선(+…)으로 된 조합 위상 구조 | 입자=꼭짓점, 접촉쌍=간선 (Fig 5) |
| **incident edges** | 한 간선과 꼭짓점을 공유하는 간선들 | "이 접촉에 영향 주는 다른 접촉들" |
| **fixed point iteration** | `x ← F(x)` 를 반복해 해를 찾는 방법 | `g_NL` 이 P 에, P 가 `g_NL` 에 의존하므로 필요 |
| **ballistic deposition** | 입자를 하나씩 떨어뜨려 붙이는 패킹 생성법 | 무질서 침대 초기조건 (ρ_R = 0.42) |
| **relative density ρ_R** | 고체부피 / 전체부피 (= 1 − porosity) | 식 (19). BCC 미변형 0.68 |
| **die compaction** | 측벽 고정, 한 방향만 압축 (= 우리 cold-press BC) | Fig 15/17 |
| **hydrostatic compaction** | 세 방향 동일 압축 | Fig 15/16 |
| **neo-Hookean** | 고무류의 대표적 초탄성(hyperelastic) 구성식 | FEM 재료 (식 15) |
| **EAM (embedded-atom method)** | 원자계 퍼텐셜 = pair 항 + many-body 항 | 논문 §5 가 든 개념적 유비 |
| **θ\* (부호전환각)** | `W(θ,ν) = 0` 인 각도 | **우리가 도입한 용어** — ν=0→88.2°, 0.5→70.5° |
