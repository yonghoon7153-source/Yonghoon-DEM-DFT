# 수영 U6(c) 아래판 반력 진단 · 1저자 WSL 블록

동일 입력·설정 ①의 F8과 F16에서 과거 궤적에 저장하지 않은 벽 관측을 새로 남긴다. 두 해상도 모두 아래판 반력에 접촉 처리 전후의 벽 충격량이 어떻게 더해지는지 대조한다. 대상은 판 변위에 따른 격자 차이의 원인 진단이다. 5% 판독과 개발 자료의 지위는 `docs/reviews/suyoung_u6c_force_rule_20261122/README.md`를 따른다.

| 운영 항목 | 고정 내용 |
|---|---|
| 입력 | 49개 원판, 설정 ①, 기존 계산기·재료·적분기 소스. 원 핀 `6bdfac91520c868b5036071e6d60464972727f49`. 같은 F8·F16의 원래 아래판 반력 궤적 SHA256을 각각 확인한다. |
| 환경 | 1저자 WSL, CPU 한 코어, 수치 스레드 1, Python 3.12.3 및 NumPy 2.5.2. 자체 포함 TXT에 소스·커밋을 결속한다. |
| 시간 | F8 한 번 뒤 F16 한 번. 앞 F8 실행은 약 2분, F16은 약 12분이었다. 새 벽 관측을 포함한 시간은 미측정. 상한은 각각 10분·30분, 마지막 판독은 별도로 약 2분 상한. |
| 1회 실행 | `CHECK_ONLY`는 소스 해시·환경·두 진입점만 확인한다. `GO_SUYOUNG_WALL_ONCE`에서만 한 번의 자리를 확보한다. 계산 결과가 원 궤적과 다르거나 한 팔이 실패·시간초과·중단하면 다음 팔을 실행하지 않는다. 자동 재시도 0회. |
| 반환 | 화면의 새 RETURN_DIRECTORY에 suyoung_wall_result.tar.gz, screen.txt, SHA256SUMS를 만든다. TAR에는 F8/F16의 trace.csv·result.json, 새 wall.csv·observer.json과 완성 시 wall_summary.json을 보관한다. 중간 종료 시 확보한 부분을 같은 방식으로 회수한다. |

연결이 끊기거나 반환 상태가 불분명하면 최초 화면에 표시된 WORK·RETURN_DIRECTORY 또는 1회 영수증을 확인한다. 실행 토큰을 반복하지 않는다.

고정 템플릿은 `docs/reviews/suyoung_u6c_wall_observer_20261122/run_wsl.in`, 모의 시험은 `docs/reviews/suyoung_u6c_wall_observer_20261122/test_operator.py`에 있다. 모의 시험은 전용 임시 폴더와 가짜 관측기를 사용한다.

## 반환에서 가를 것

각 걸음의 첫 번째 아래판 충격량은 입자 간 접촉 처리 직전, 두 번째는 직후의 실제 벽 함수 반환이다. 두 값을 더해 시간 간격과 판 폭으로 나누면 원래 반력이 복원돼야 한다. 도구는 이 관계를 매 걸음 확인한다. 윗판 속도 제한으로 생긴 아래 방향 충격량과, 속도 제한을 받은 양의 질량 장·노드 항목 수도 함께 저장한다. 한 물리 노드에 여러 입자 장이 있을 수 있다.

판독기는 F8·F16의 공통 변위 구간에서 **총 반력의 격자 차이가 가장 큰 같은 위치**를 찾고, 그 위치의 차이를 첫 번째와 두 번째 아래판 처리의 부호 있는 성분으로 나눈다. 각 성분의 서로 다른 최댓값을 더하지 않는다. 이미 알려진 0.565977 MPa의 차이에 두 아래판 처리가 얼마나 기여했는지 가르는 진단이며, 5% 자격과 궁극적인 물리 원인은 별도다.
