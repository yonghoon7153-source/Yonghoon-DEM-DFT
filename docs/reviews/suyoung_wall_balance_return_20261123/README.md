## 윗판 처리 후보를 고른 이유

첫 걸음의 입자는 정지해 있고 지시된 윗판과 수송 전 입자 표면 사이에 틈이 있었지만 기존 격자 윗판은 하향 충격량을 가했다. 전체 관측 구간에서 같은 부호의 틈(코드 길이 1e−12 초과)과 하향 충격이 함께 나타난 걸음은 F12 8회, F24 61회다. 그때의 하향 충격량 합은 각 팔의 전체 윗판 하향 충격량 중 0.1612%, 2.4856%다. 각 걸음에는 입자 자체의 속도도 있다. 따라서 모든 해당 걸음의 충격이 잘못됐다고 판정할 수 없고, 이 백분율을 아래판 격차의 원인 비중으로 쓸 수 없다.

윗판 후보는 아래판과 같은 재료 표면 마커를 이용한다. 이번 걸음 끝의 윗판 높이까지 입자가 실제로 접근하는 경우에만 수직 충격을 가한다. 기존 아래판·입자 간 마찰·옆판·초기 입자·시간표를 유지해 윗판 규칙 하나의 효과를 비교한다. 후보와 기존 이력의 압력은 각 격자의 같은 판 변위에서 비교한다. 우선 1,139개 합집합 표본의 최대 차이와 앞의 두 원표본 쌍을 확인한다. 짧은 비교에서 차이가 작아져도 완주 구간과 U6(c)의 다른 검사가 남는다. 큰 차이가 유지되면 입자 사이 운동량 전달을 다음 분리 대상으로 둔다. 표면 관통·충격량 불일치·시간 초과가 있으면 실패 시점까지 보존한다.
