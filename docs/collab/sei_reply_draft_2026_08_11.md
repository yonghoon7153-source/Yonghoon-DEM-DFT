## ② 형성(안정) 전위 창 — V vs Li/Li⁺

Materials Project 전체 엔트리 위에서 grand-potential 위상도로 계산한 **열역학적 안정
전위 구간**입니다 (μ_Li 스캔, thermo=GGA/GGA+U 고정, 0.05 V 격자).

| 상 | 안정 창 [V] | 창 위쪽(산화측) 분해 산물 |
|---|---|---|
| Li₂O | **0 – 2.85** | Li₂O₂ |
| Li₂S | **0 – 2.10** | LiS₄ |
| LiCl | **0 – 4.25** | Cl₂ |
| Li₃P | **0 – 0.85** | LiP |
| Li₃PO₄ (β·γ 동일) | **0.70 – 4.15** | Li₄P₂O₇ + O₂ |
| LiNdO₂ | **안정 창 없음** — 전 구간 준안정 | (아래 설명) |

- LiNdO₂ 는 닫힌 껍질 기준 hull +0.008 eV/atom 로 **어느 전위에서도 hull 위에 있지
  않습니다.** 다만 분해 구동력이 최소 **+0.011 eV/atom (0 V)** 로 매우 작아, 실용적으로는
  "경계선 준안정" 으로 읽는 것이 맞습니다 (kT_room ≈ 0.026 eV).
- 읽는 법: 이 값은 **"이 전위 밖에서는 열역학적으로 존재할 수 없다"** 는 뜻이지, 창 안에서
  빨리 생긴다는 뜻이 아닙니다 (속도론 아님).
- ⚠ 에너지는 MP(PBE/PBE+U + MP 보정) 값입니다 — 한 DB 안에서 일관되므로 **상들 사이
  비교**에 쓰시고, 저희 QE 갭 값과 섞어 절대 비교하지 마시길 부탁드립니다.
- 창 아래(환원측) 분해 산물 표가 필요하시면 말씀 주세요 — 같은 위상도에서 뽑아 드립니다.

## ③ 밴드갭 — 6종 완성 (LiNdO₂ 가 저희 자체 계산으로 갱신됐습니다)

QE PBE, vc-relax 후 **fixed-occupation nscf 의 VBM/CBM 고유값**입니다 (DOS 판독 아님).

| 상 | gap [eV] | 비고 |
|---|---|---|
| LiCl | 6.26 | |
| Li₃PO₄ γ | 5.82 | β 는 5.91 (다형체가 결론을 안 바꿈) |
| Li₂O | 4.99 | |
| **LiNdO₂** | **3.70** | **신규 — 자체 계산** (아래 방법 주석) |
| Li₂S | 3.44 | |
| Li₃P | 0.71 | 6종 중 전자 절연이 가장 나쁜 상 |

- ⚠ PBE 갭은 넓은 갭 절연체에서 30–50% 계통 과소평가됩니다 — **절대값보다 순위**로
  읽어 주세요. 실험값과 나란히 놓지 마시길 부탁드립니다.
- LiNdO₂ 방법 주석: 이전 회신에서는 MP 값(4.21 eV)을 소환해 드렸는데, 이번에 Nd 4f 를
  core 로 두는 frozen-4f PP(QE PSLibrary, z=11)로 **자체 계산**했습니다 (3.70 eV).
  같은 PP 로 검증: Nd₂O₃ 3.95 (MP 3.81, +3.6%) · Nd₂S₃ 0.77 (MP 0.76, +1.3%).
  Nd 상의 PP 계열이 Li 계 5종과 달라, 표 안 비교는 유효하되 그 사실을 명시해 둡니다.

## ① Li⁺ 확산 장벽 — 정직한 상태 보고

이전에 산출했던 NEB 값(Li₂S 0.27 eV 등)은 **저희 내부 검증에서 두 가지 프로토콜 결함**
(공공 전하 규약 오류 · 끝점 미이완)이 발견되어 **철회했습니다.** 결함을 수정한
프로토콜(끝점 이완 → no-CI 수렴 → CI 재시작, V_Li⁻ 규약)로 재계산을 준비 중이며,
검증 게이트를 통과한 값만 6종 순서대로 다시 보내드리겠습니다.

참고로 BVSE 같은 정적 프록시로 대체하지 않는 이유: 이 6종이 화학계(산화물·황화물·
염화물·인화물)를 넘나들어 결합원자가 파라미터가 계마다 달라, **계 사이 장벽 비교가
성립하지 않습니다.** 그래서 NEB 이 유일한 경로이고, 그만큼 시간이 걸립니다.
