# 수영 2D S/F — 첫 CPU 개발 계산

1저자 11-16 Q3·Q4와 후속 지시: 등록 완성을 선행 관문으로 두지 않고 첫 작은 CPU 계산을 준비한다. **개발 자료**, 실제 물리 자격·논문 수치가 아니다. 고정 공유 MPM/Rint 코드는 수정하지 않는다.

## 1. 한 코드의 두 팔

새 모듈 `scripts/dem_suyoung_sf2d_dev.py`: NumPy CPU, 같은 네 합성 원판·소속 ID·물질점·질량·정규화 구성식·P2G/G2P·판/벽. S는 속도장 1개, F는 원판별 장 4개. 재료와 격자·판 움직임을 두 팔 사이에서 바꾸지 않는다. 기존 `scripts/mpm2d_plastic.py`의 quadratic MLS/APIC·corotated stress·log strain projection 방향을 참고했으며 그 파일을 고치거나 import해 실행하지 않는다.

F 접촉은 공유 지지 노드의 질량 기울기 법선과 비탄성 Coulomb 충격량, 4번 순차 투영이다. 이는 첫 개발 구현으로, 조밀 다물체 최종 마찰 일·순서 불변·기하학적 닿음 검출의 자격을 완료한 것이 아니다. 최대 잔여 접근속도·퇴화 법선 수를 출력한다. S에 명시적인 입자간 접촉 법칙이 없다는 것과 기하학적 분리 불가능을 같은 말로 쓰지 않는다.

## 2. 기본 블록과 회수

| 항목 | 설정/산출 |
|---|---|
| 기계 | 1저자 로컬 WSL, CPU 1, GPU·kgy 미사용 |
| 크기 | 32×32 셀, 네 합성 원판, S/F 각각 1200 step |
| 재료/시간 | 정규화 E=1, nu=0.30, yield=0.02, rho=1; dt=0.0005, 판 속도0.15, 마찰0.20 |
| 예상 | 수분 예상(전체 개발 계산 미측정); 팔당 600초·블록 전체 1500초 상한 |
| 회수 | INPUT.json, S_trace.jsonl, F_trace.jsonl, SUMMARY.json, stdout/stderr, rc, 전달 소스/핀 |
| 첫 숫자 | 마지막 20% step의 판 반력 기반 평균 압력 S/F 및 그 비·두 팔 소요시간·Linux 프로세스 최대 RSS |
| 단위 | 정규화된 2D 단위. MPa·실제 SE 재료값으로 환산하지 않음. 메모리 peak는 두 팔을 순차 실행한 전체 프로세스 값 |
| 종료 | 비유한·역전/극단 변형·격자 이탈·이동 한도·시간 상한은 중단/미완료. F 압력이 0 또는 매우 작으면 비는 null |

두 팔의 입력 상태 해시가 같은 한 초기 상태를 재생성한다. 새 출력 폴더만 허용하고 기존 결과는 덮지 않는다. 자동 재시도 없음. 유효한 두 팔 결과를 받은 뒤 동일 변위에서 반력 부호·질량·면적·접촉 잔여를 먼저 확인하고 비를 해석한다. 기준값·이전 실측값을 현재 합성 개발 값과 바로 비교하지 않는다.

이번 네 원판·재료는 작은 개발 입력이다. 순수 SE 기공률10–13%·진밀도1.64의 재현, 큰 침대·수렴·탈압·DRD-01 종결 계산을 수행한 것이 아니다. 등록·반박을 이 첫 실행의 새 관문으로 두지 않으면서, 해당 연구 주장으로도 승격하지 않는다.

## 3. 시험

새 합성 시험 9/9: partition/gradient, 두 물체 충격량의 운동량/에너지/Coulomb 경계, 분리 중 무충격, 판이 끌어당기지 않음, 항등 응력/소성 투영 부피, 한 장 S/F 완전 동일, 번호/질량, 영분모, 4step CLI/덮어쓰기 거부. 마지막 항목은 작은 합성 시험이며 기본 1200step 개발 계산을 대신하지 않는다. 여러 시험 내부 관측을 합산하지 않는다.

남는 한계 = 지지 격자 접촉의 조기 접촉, 순차 다물체 투영의 순서·잔여, 정규화 미보정 재료, 격자/dt 수렴·탈압 자격 미완료. 출력에 해당 표지와 registered_conclusions_adoptable=false를 남긴다. 공유 입자 번호·피복 정의나 payload를 이번 모듈의 정본으로 바꾸지 않는다.
