# 수영 2D · 아래판 인접층 판독과 3D까지의 다음 결정

## 저장한 네 장면에서 확인한 것

기존 교차 반환의 F8 269·270걸음과 F16 538·540걸음에 같은 높이 눈금을 적용했다. 아래판 위치는 0.15, 미세 격자 폭 h는 1/160이다. 이번 판독의 대상은 첫 번째 아래판 노드 처리에서 응력이 전달한 압력 성분이다. 여덟 개의 입자 상태·격자 조합 합계는 이전 교차표와 일치했다. 판독기는 두 반환 TAR와 원 스텐실 소스의 SHA256을 확인한다.

첫 5% 초과 바로 뒤(270/540걸음), 원래 F8·F16 상태에서 얻은 이 성분의 차이는 +0.033303 MPa였다. 1–1.5h 층이 +0.021602 MPa, 2–3h 층이 +0.018442 MPa였고 더 가까운 층에서 상쇄가 있었다. F8 입자 상태를 고정한 채 읽는 격자와 하향 마스크를 함께 바꾼 경우, +0.019610 MPa 차이 중 +0.018442 MPa가 2–3h 층에 있었다. F16 자체 격자의 이 층에서 기여한 점은 0개다. 이는 특정 순간·응력 성분·투영 조건의 결과다. 전체 아래판 반력의 최대 차이는 기존 두 완주 곡선 기준 80.8586%다.

별도 평벽 합성 대조에는 양쪽 격자에 같은 점 3,072개와 정렬한 평면, 벽 이하 모든 기하 노드를 썼다. 일정 수직 압축응력에서 응력 전달분은 두 격자 모두 9.0625 MPa였다. 깊이에 선형으로 변하는 응력을 주면 정해가 예측한 +0.25625 MPa 차이를 재현했다. 성분의 부호와 격자 폭 민감도를 검산하는 대조다. 이 계수를 실제 반력 보정에 쓰지 않는다.

## 다음 개발 계산 · 같은 시간과 충전에서 격자 차이 확인

기존 물리 소스와 설정 ①, 같은 마찰·재료·판 경로로 **80격자 F8의 두 짧은 대조**만 계산한다. 두 팔 모두 F16 시간 간격으로 540걸음까지 간다. 첫 팔은 F8 원래 물질점, 둘째 팔은 F16 원래 물질점의 좌표·부피·ID를 쓴다. 같은 코드로 이미 마친 F16과 기본 F8은 고정 교차 반환의 관측을 읽는다.

| 같은 판 변위에서 차를 내는 순서 | 조건 하나를 바꾸는 의미 |
|---|---|
| 기본 F8 − F8(작은 시간 간격, F8 점) | 같은 격자·점에서 시간 간격 효과 |
| F8(작은 시간 간격, F8 점) − F8(작은 시간 간격, F16 점) | 같은 격자·시간 간격에서 초기 물질점 배치·부피 효과 |
| F8(작은 시간 간격, F16 점) − 기본 F16 | 같은 시간 간격·초기 점에서 격자 효과. 이후 입자 궤적은 각 격자에서 발달한다. |

비교할 표본은 원래 F8의 0–270걸음과 이에 맞는 짝수 F16 걸음(271쌍)이다. 각 변위에서 세 **부호 있는** 차의 합이 원 F8–F16 차를 복원하는지 확인한다. 특히 첫 초과 전후 269·270을 보고한다. F16의 홀수 539걸음을 이 계산에서 같은 시각의 F8 실측으로 부르지 않는다. 개발 대조에서 시간 간격 또는 초기 점 효과가 크면 해당 조건부터 통제하고, 그것들을 맞춘 뒤에도 격자 차가 크면 아래판 경계 처리와 입자–격자 운동량 전달을 수정 후보로 다룬다. 효과가 상쇄되거나 시간에 따라 순서가 달라지면 단일 원인으로 정하지 않는다. 중단·미도달·원자료 결속 실패는 미완료로 회수한다. 짧은 구간으로 자격을 판정하지 않는다.

## 3D 진입 조건과 담당

1. Codex 실무가 위 대조를 판독하고 근거 있는 최소 수정 후보를 시험한다. 반박 창에는 고정 후보와 수정 전후 같은 판정표를 보낸다. 이번 진단에 대한 Claude의 별도 지시를 기다릴 필요는 없다.
2. U6(c) ⑥은 같은 후보로 F8–F16, F12–F24 각각의 완주 곡선에서 원 표본·원 분모·5% 기준을 검사한다. U6(c)의 다른 접촉 조건과 나머지 2D 자격도 각각 판정한다.
3. 1저자 GO 뒤 단계 3에서 독립 초기 충전 3개로 S/F를 대조한다. 정본 메모의 판정에 따라 3D 경로를 정한다. 단계 4는 순수 SE 3D다. 순수 SE 실험 기공률 10–13%와 진밀도 1.64의 측정 조건을 맞춘다. 이후 복합체와 지정 단면을 같은 하중 상태의 실험과 대조한다. 3D 자원은 Rint 일정과 조율한다.
