# D2 결합 규칙의 벽 값 γ_W/γ = 0.0256 — 왜 이 값인가 (2026-10-14)

> 1저자 10-14 비준 *"권고대로 (가)로 하자 근데 그냥 따라하지말고 0.0256이어야만 하는 이유를 확실하게 파악하고 정리해놔"*.
> 결론부터: **0.0256 = (γ_pw/γ_pp)² = (0.04/0.25)²** — Hare et al. 2026 이 보정한 *입자–벽 / 입자–입자* 접착 에너지 비 0.16 을
> D2 기하평균 규칙에 넣으면 벽 재료의 표면에너지 비로 **정확히** 이 값이 나온다.  JKR 당김힘 규약 (γ ↔ w = 2γ · 3/2 ↔ 3) 과 무관하다.
> 단 세 가정 위에 서 있다 (§4) — 그중 하나 (벽을 어느 상에 묶나) 는 γ_NCM/γ_SE ≠ 1 인 런에서 값이 달라지므로 1저자 결정으로 남긴다 (§5).

## 2. 유도

1. **JKR 의 γ 는 짝마다 주는 접착 에너지다.**  표준 JKR 은 δ = a²/R* − √(2πwa/E*) (w = Dupré 접착일).  EDEM 꼴 √(4πγa/E*) 과 맞추면 **w = 2γ** —
   EDEM 의 γ 는 상호작용 짝 (입자–입자 · 입자–벽) 마다 따로 넣는 값이다.  ⇒ w_pw / w_pp = γ_pw / γ_pp = **0.16**.
   ⚠ 당김힘 상수 (F = (3/2)πwR* = 3πγR*, 카드 산술은 (3/2)πγR*) 의 2 배 모호성은 **같은 규약끼리의 비에서 약분**된다 — 0.16 은 규약과 무관하다.
2. **D2 기하평균 규칙** (1저자 10-14 D2 (가)): 재료마다 γ 를 두고 W_ij = 2√(γ_iγ_j).  같은 재료 W_pp = 2γ_p · 벽 W_pW = 2√(γ_pγ_W).
   ⇒ W_pW / W_pp = √(γ_W/γ_p).
3. 둘을 같게 놓으면 √(γ_W/γ_p) = 0.16 ⇒ **γ_W/γ_p = 0.16² = 0.0256**.
   (Hare 의 단위로 쓰면 γ_p = 0.25 · γ_W = γ_pw²/γ_pp = 0.0064 J m⁻² — 이 **절대값** 0.0064 는 옛 권고의 **비** 0.0064 와 우연히 같은 숫자일 뿐 뜻이 다르다.)
4. **검산 — 당김힘 비**: 같은 크기 구–구 R* = r/2 · 구–벽 R* = r ⇒ F_pW/F_pp = (W_pW/W_pp)·(R*_pW/R*_pp) = 0.16 × 2 = **0.32**.  Hare 의 단분산 입자에서도 0.32 이고,
   우리 생성기 (γ_W/γ_SE = 0.0256) 의 SE–벽 F₀/SE–SE F₀ = 2√0.0256 = **0.32** — 같다 (셀프테스트 GM⑥).
5. **SJKR 쪽 대응**: LIGGGHTS 벽 면적 π(ri² − r²) = π(2riδ − δ²) ≈ 2πR*δ (R* = ri) — 생성기가 F₀ 를 맞출 때 쓰는 소겹침 면적 2πR*δ 와 같은 꼴이다 (구–구도 a² ≈ 2R*δ).
   ⇒ `area_ratio = 1` 인 평면 접촉에서 벽 F₀ 를 R* = r 로 맞춘 것이 실제 SJKR 벽 힘과 같은 근사 수준이다.

## 3. 왜 0.0064 가 아닌가

- 옛 벽 규약 (`WALL_CED_DIV = 6.25^(1/3)` · 생성기 주석 *"hare2026 은 JKR γ_pw/γ_pp = 1/6.25 = 힘비 1/6.25"*) 은 **에너지 비를 당김힘 비로 읽었다** — 벽 짝의 R* 가 두 배라는 것을 빠뜨렸다.
  그 읽기를 기하평균에 넣은 것이 0.0064 (당김힘 비 0.16 · 에너지 비 0.08) 다 ⇒ **Hare 가 보정한 벽 접착의 절반**이고 근거 문헌이 없다.
- 옛 덱이 실제로 낸 비 (soft 영률 · 같은 γ 세계): SE–벽 / SE–SE **0.162** (Hare 0.32 의 0.51 배) · AM–벽 / AM–AM **0.4516** (Hare 의 1.41 배 — AM 은 E* 비도 다르다) — 원장 `MIX-12`.
  옛 런의 판정 · 개발 문장은 바꾸지 않는다 (층상 = 등록된 무분리 범주 · 개발 자료 = AM–벽 공동 개입 B 기록).

## 5. 남은 결정 — 벽을 어느 상에 묶나 (γ_NCM/γ_SE = ρ ≠ 1 인 런에서만 값이 달라진다)

- Hare 의 입자는 **비코팅 NMC 622** 다.  글자 그대로 옮기면 **γ_W = 0.0256 × γ_NCM(비코팅)** ⇒ 생성기 단위 (γ/γ_SE) 로는 **γ_W/γ_SE = 0.0256 × ρ**.
- **같은 γ 기준 런 (ρ = 1 · 코팅 세계)** — 파이프라인이 새 규칙으로 먼저 다시 돌릴 런 — 에서는 두 방식이 같고 **0.0256 이 정확**하다.
- ρ ≠ 1 에서 벽을 SE 에 묶으면 (0.0256 고정) "SE–강철 = NMC–강철" 이라는 근거 없는 가정이 하나 더 든다.  NCM 에 묶으면 Hare 재료 그대로이고,
  같은 세계 (같은 ρ) 의 코팅 · 비코팅 두 팔은 **같은 벽**을 쓴다 (코팅은 NCM 표면만 바꾸고 강철 · SE 는 안 바꾼다).
- ⇒ 권고: **벽 = 비코팅 NCM 에 묶는다** (γ_W/γ_SE = 0.0256·ρ · ρ = 1 이면 0.0256) · 최종은 D3 에서 우리 드럼 벽 재료로 벽 시험 (경사판 등) 을 하면 그 보정으로 바꾼다.
- 생성기는 지금도 `--gm-gamma-wall` 을 **명시**로만 받는다 (숨은 기본값 없음) — 이 결정은 등록 문안에서 값으로 적는다.
