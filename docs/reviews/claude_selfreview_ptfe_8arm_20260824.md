## Part 1 — 요청서 자체의 오류 (자기-적대에서 잡힘)

### F-A. §10-3 "코드 기본값이 실측의 15배" 는 **과잉주장**이다

MG 역산을 오차 전파까지 다시 돌렸다 (σ_m 3.57 · φ_SDCP 0.14598 · 실측 2.86):

| σ_i (mS/cm) | 예측 | 실측 대비 |
|---|---|---|
| 0 | 2.841 | −0.6 % |
| **0.066** | **2.860** | **0.0 %** |
| 0.30 | 2.924 | +2.2 % |
| 0.60 | 3.00 | +5.0 % |
| **1.0 (코드 기본)** | **3.098** | **+8.3 %** |

점추정 0.066 은 맞다.  그러나 **역산의 배제력이 약하다**: 펠릿 측정오차 ±5 % 를 주면
허용 밴드가 **σ_i ∈ [0, 0.60]**, ±8 % 면 **[0, 0.96]** 이다.  절연 극한 근방에서 σ_eff 가
σ_i 에 아주 둔감하기 때문이다 (MG 의 β 가 −0.5 근방에서 포화).
⇒ **정직한 서술**: "점추정 ≈ 0.07, 상한 ≈ 0.6 (±5 % 가정), 기본값 1.0 은 배제 경계선"
— "15배 틀렸다" 가 아니라 **"기본값이 데이터가 선호하는 값의 상단 끝에 있고,
0 과 구분되지 않는다"** 다.  등록한다면 **밴드**로 (질문 10-3-b 의 답은 우리 스스로 "밴드").

### F-B. §12-1 이 **CL-11 을 오인용**했다 — 그건 σ_VGCF 감도지 σ_SDCP 가 아니다

요청서: *"CL-11 은 σ_SDCP ÷9 에 σ_e 가 지수 0.858 로 반응한다고 했다 — 작지 않을 수도."*
**틀렸다.**  CL-11 은 **σ_VGCF** ÷9.054 → σ_e ÷6.617 이다 (CLAUDE.md SR-01 절 원문).
σ_SDCP 의 감도는 변분 항등식으로 따로 있고 **한계가 이미 측정돼 있다** — N-4 참조.
⇒ §12-1 의 "작지 않을 수도" 캐비엇은 **삭제**되어야 한다.  실제로는 작다 (~1 %).

### F-C. §12-3 "AM|SE 계면저항" 은 **스코프가 틀렸다**

CAM|SE 계면의 지배적 저항(문헌)은 **전하이동(R_ct)** 이고, 그것은 σ 솔브가 아니라
**STEP4 (BV + R_int)** 의 소관이다 — 이미 모델에 있다 (`--step4-r-int`, kim2025 앵커).
순수 σ 읽기에서 실제로 빠진 계면은:
- **SE|SE 입계** — σ_grain 에 lumping 되는데 **규약이 갈라져 있다** (STEP3 입력 3.0 vs
  Bazzoun 펠릿 1.02, CL-26 이 이미 지적한 그 이중계산)
- **탄소|탄소 접촉저항** — 복셀 융합이 삭제, σ_VGCF=100 lumping 으로 흡수 (CL-47)
- 탄소|AM 접촉
⇒ 질문 12-3-a/b/c 는 이대로 Codex 에 가면 **엉뚱한 것을 쫓게 만든다**.  σ_ion 비에 대한
공통모드 논의는 SE|SE 입계 규약(비에서는 상쇄)으로 옮겨야 맞다.

## Part 2 — 신규 발견 (요청서에 없던 것)

### N-1. ★★ `1e-16` 보다 나은 답이 코드에 이미 있다 — **σ=0 스탬프** (질문 5-1 · 10-2-c 의 답)

`step3_sigma.py:447` — `cond = sig > 0`.  **σ=0 인 셀은 dof 에서 아예 빠진다.**
즉 PTFE 를 σ=0 으로 찍을 수만 있으면:
- 조건수 문제 **원천 소멸** (1e18 대비 자체가 없어짐 — §5 의 걱정 전부 해소)
- 물리적으로 정확 (절연체 = 망에서 제거)
- prereg v3 STEP 3 형 미수렴 위험 0

막는 것은 딱 한 줄이다 — `mpm_webapp_payload.py:1016`
`_cond_ph = (2,3,5,6,4) if a.sigma_ptfe > 0 else (2,3,5,6)` 이 **"찍는다"와 "σ>0"을 묶어놨다**.
⇒ **행동**: 게이트 분리 (`--stamp-ptfe` 플래그 신설).  `1e-16` 은 그 게이트를 여는 우회로였을
뿐이고, 분리하면 폐기 가능.
⚠ 단 **이번 8팔은 1e-16 으로 돌려야 한다** — arm 0 이 1e-16 이고, σ=0 은 **n_dof 가 달라져**
매니페스트/판정기 고정-인자 게이트와 충돌한다.  σ=0 전환은 별도 팔에서 arm 0 만 다시 돌려
1e-16 과 수치 동등(상대 ~1e-6)을 확인한 뒤 **다음 세대 규약**으로.

### N-2. ★★ PTFE 는 직경이 **분포**다 — "튜브 스탬프" 는 애초에 성립하지 않는다 (질문 11-2-a 의 답)

`additives.seed_fibres(vol_conserve=True)` — PTFE 는 **정부피 인발**로 시딩된다:
d_i ∝ √(V_i/L_i), 굵은 stub 부터 가는 strand 까지 **두 독립 산포의 곱**.  실측 기록도 있다
(CLAUDE.md: *"VGCF Ø min=med=max=1.0, cv=0 — 퍼지는 것은 PTFE"*).
⇒ "Ø0.25 캡슐 스탬프" 는 잘못된 목표다.  per-fibril d_i 가 필요하고 가는 꼬리는 **어떤
실행가능 vox 에서도 sub-voxel** 이다.
**더 근본적으로 — 절연체에는 부피가 옳은 불변량이 아니다.**  도체(VGCF)는 부피 오차를 σ 로
보상할 수 있었지만(직경-보존), 절연체가 결과에 기여하는 것은 부피가 아니라 **절단 위상**
(어느 탄소-탄소 교차를 끊는가)과 **절단 폭**이다.  1-셀 스탬프는 절단 위상은 대체로 맞게,
절단 폭은 **vox 로** 그린다.
⇒ 질문 11-2-b 의 답: 튜브 스탬프를 만들지 말고, 1-셀 선분으로 두되 **절단-폭 아티팩트를
CPU 원장으로 정량**하고 부호를 등록하라 (N-3).

### N-3. ★★★ 사용자 수렴 가설의 **부호 분석** — 가능하되, 그것은 상쇄다 (질문 11-3/11-4 의 답)

격자를 조일 때 두 채널의 부호:

| 채널 | 조이면 | R 에 | 
|---|---|---|
| VGCF 가짜 상호연결 소실 (현행 후보) | 가짜 접촉 ↓ | **R ↑** (관측된 +) |
| **PTFE 절단 폭 축소 (신규, PTFE-on 에서만)** | 절단 폭 = 1셀 = vox ↓ → 차단 약화 → 양쪽 σ ↑, PTFE 2배인 SBE 가 **더** 회복 | **R ↓** |

⇒ PTFE-on 규약에서 R(h) 가 평평해지는 것은 **기전적으로 실제 가능**하다 — 사용자 직관이
맞다.  그러나 그것은 두 아티팩트의 **부호 상쇄**이지 수렴이 아니다.
**판별은 솔브가 아니라 CPU 원장으로 갈린다** (요청서 §11-5 의 세 검사가 정확히 이것):
세 격자에서 ⓐ VGCF 접합 수의 격자 의존이 PTFE-on 에서 실제로 줄었는가
ⓑ PTFE 가 끊는 도체 셀 수가 격자에 어떻게 비례하는가 (예측: ≈ vox 에 선형 = 절단 폭).
ⓑ 가 vox-선형이면 "평평한 R" 은 상쇄로 **정량 귀속**된다 — 수렴 주장 불가가 **증명**된다.
⇒ 질문 11-4 판정표는 유효하되 3행이 바뀐다: "PTFE 규약 수렴" 단독으로는 기전 증거가 아니고
**원장 ⓐⓑ 와 함께**만 읽는다.

### N-4. σ_SDCP 불확실성(필름 vs 펠릿)의 영향은 **~1 % 로 유계**다 (질문 12-1 의 답)

변분 항등식 w = ∂ln σ_eff/∂ln σ_SDCP = **줄손실 분담** ≈ 1 % (생산 격자, CL-41 정정에서
확정한 바로 그 양이다 — "전류 분담" 으로는 오답이지만 **이 용도로는 정답**이다):
σ_SDCP ÷2 → Δσ_e(DBE) ≈ −0.7 % · ÷3 → −1.1 %.
⇒ 250 이 펠릿값(접촉저항 포함 유효값)이어도 **비 R 에 미치는 영향 ≈ 1 %**.
🔴 → 🟡 로 강등하되, **Table S2 라벨은 여전히 고쳐야 한다** ("Assumed" → 측정 대상을 명기).
숫자 재실행은 불요.

### N-5. ★ 안 B 의 이온 비에 **진짜 미지의 사전예측**이 있다 (질문 10-4-ⓑ 의 답)

PTFE 스탬프 + σ_i(SDCP) 앵커를 **동시에** 켜면 이온 비(현행 0.99272)에 **반대 방향 두 힘**:
- PTFE 스탬프: SBE 가 이온 차단 부피 2배 → σ_ion(SBE) ↓↓ → **비 ↑**
- σ_i(SDCP) 1.0 → ~0.07: DBE 의 SDCP 상이 이온-준사망 → σ_ion(DBE) ↓ → **비 ↓**
합의 부호가 봉투 계산으로 **안 갈린다** (차단 부피 산술: SBE 여분 PTFE 0.227 a.u. vs
DBE SDCP 0.385 a.u.×준사망) = **등록 자격이 있는 미지**.  h0/h1 을 부호로 걸 수 있다.
⇒ 안 B 는 "값 측정" 이 아니라 **검정 하나를 품을 수 있다** — §3-3 의 답이기도 하다.

### N-6. §3 규율 질문의 깨끗한 논거 — **팔은 결정론이다** (질문 3-1/3-2 의 답)

origin 8팔은 표본추출이 아니라 **관례로 고정된 유한 모집단의 결정론적 계산**이다.
arm 0 을 본 것이 arm 1~7 의 값을 **물리적으로 바꿀 수 없다**.  편향이 들어올 유일한 통로는
**사후 팔 선별**이므로: ① arm 0 포함 (버리면 그것이야말로 선별) ② 실패 팔 발생 시 드롭이
아니라 **fail-fast 전체 중단** (질문 5-3: 현행 러너 거동 유지가 맞다) ③ 보고 통계(쌍대응
+비대응 둘 다)를 런 전에 고정.  이 세 줄이 측정 계약의 전부다.
질문 5-2 (팔-폭 등록): "생산 0.68 % 보다 크다" 는 무정보 — 대신 **인용 게이트**를 등록하라:
*"쌍대응 SE ≤ 0.5 %p 면 분해 지분(44/56)에 오차막대를 달아 인용, 초과하면 정성 서술만"*.

## Part 5 — 종합 권고 (한 문장 + 사다리)
