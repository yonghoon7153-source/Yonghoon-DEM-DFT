**1저자 WSL 회신.** 전달 TXT는 기억하거나 이미 관리 중인 비결과 출처의 종류와 별칭을 입력받아 새 임시 폴더에 회신 JSON 한 장을 쓴다. 연구 폴더를 인수로 받지 않으며 파일 검색이나 내용 읽기는 없다. O2는 기존 done 기록의 작성·관리 경위를 알고 있을 때, O3는 별도 보관 기록이 이미 알려진 때의 *후보*다. 복수 후보는 범위가 다른 경우 별도 회신할 수 있다. 해당 여부와 일부 항목을 모르면 UNKNOWN을 그대로 둔다. 작성자·도구·시기의 의미·복사 또는 수정 이력·case/run 연결 설명은 대화에 **비결과 메타**만 덧붙인다. 나중에 만든 목록을 실행 당시 영수증으로 승격하지 않는다.

**수영 인계표.** `tau2_ion_*`은 수송 tortuosity T = φ_SE,mc·σ₀/σ_eff, `tau_ion_*`은 √T, `tortuosity_SE_wall`은 기하학적 경로비다. 압력은 B7 거부 이력 및 결측 사유를 보존한다. `wsl30_access_plan.tsv`는 접근 전 준비표이며 실제 값, 정본 구간, 적격성 판정 또는 분석 명부를 담지 않는다. 최종 배포는 production194와 supp20의 독립적인 배치 증거를 요구한다. WSL30으로 두 배치 또는 ibb184의 상태를 대신 채우지 않는다.
