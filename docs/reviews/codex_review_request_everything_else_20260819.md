## §C. 코팅 트랙 ⓪단계 — 리뷰 판정을 **실측이 뒤집었다** (CL-52)

착수 전 코드리뷰가 *"코퍼스 ⟨δ⟩ ≈ 0.0739 µm 인데 코어 접촉엔 δ ≥ 2t = 0.5 µm 가 필요하므로
스위치가 **영구 OFF**"* 라고 판정했다.  기존 접촉 덤프 4개로 검증했다 (GPU 불요).

### C-1. 평균으로 문턱을 논한 것이 틀렸다

AM–AM δ 분포 (정정값, n=3,033): med **0.0670** · p99.9 **0.6807** · **max 0.9679 µm**
— 같은-침대 중앙값의 **14배**까지 뻗는다.  문턱 통과는 **꼬리**가 정한다.

| 쉘 t | 코어 접촉(δ ≥ 2t) 비율 |
|---|---|
| 0.05 µm | 34.4 % |
| 0.10 µm | 11.9 % |
| 0.25 µm | 0.96 % |
| 0.50 µm | 0 % |

⇒ **So 2022 규약(t=0.25)에서는 리뷰가 맞다.  그러나 "영구 OFF" 라는 일반 진술은 틀렸다.**

### C-2. 압력 분해 — So 기전이 재현된다

네 덤프가 곧 4압력 세트였다 (phase-virial f_AM 이 CLAUDE.md 실측 0.726/0.768/0.794/0.763 과
소수 셋째 자리까지 일치 ⇒ **추측이 아니라 실측 대조로** 압력을 식별).

t = 0.10 µm 에서 코어 접촉 비율 **1.4 → 4.2 → 8.1 → 22.9 %** (P100 → P600, 17배),
**모든 쉘에서 strict 단조** (⚠ 정정값 — 초판은 P300/P600 part2 가 0줄로 읽힌 절단 모집단이었다.
fable 리뷰 F1 이 비전파를 잡았고, 원본 문서·원장까지 재계산 반영 완료).

### C-3. AM 백본 σ_e — "접촉 수 ≠ σ_e" 의 답

코어 접촉만 남긴 AM 망을 **실제로 풀었다** (`run_decomposition(mode='electronic')`).
σ/σ₀:

| P (MPa) | t=0.02 | t=0.05 | t=0.10 | t=0.15 | t=0.25 |
|---|---|---|---|---|---|
| 100 | 0.777 | 0.413 | 0.145⚠ | ⛔ 끊김 | ⛔ 끊김 |
| 200 | 0.848 | 0.616 | 0.463 | 0.268⚠ | 0.101⚠ |
| 300 | 0.917 | 0.601 | 0.385 | 0.149⚠ | 0.094⚠ |
| 600 | 0.939 | **0.830** | 0.493 | 0.318 | **0.158** |

⚠ = **경계 인공물 후보** (최대 연결성분의 z-스팬 < 침대높이의 80 %) — **σ 값 인용 금지,
방향만**.  (2026-08-20 정정: 이 플래그가 원본 분석과 coating §8 · CL-52 에는 있는데 이
요청서 표로 옮길 때 빠져 있었다 — 리뷰어가 다섯 셀을 유효값으로 읽게 돼 있었다.)

★ **P600/t=0.25 는 접촉의 1.9 % 만 남는데 σ 는 15.8 % 를 유지**하고 스팬 97 % 로 실퍼콜이다.
살아남는 접촉이 δ 가 가장 큰 **AM_P–AM_P 힘사슬**(med 0.183 · max 0.968 µm, 정정값)이라 불균형하게 중요하다.

### C-4. A3 대가 — bimodal 이 조용히 바뀐다

코어-쉘을 **반경 R+t 단일구**로 넣으면 LIGGGHTS 가 질량분율→개수를 `ρ·(4/3)πr³` 로 만들므로
개수가 `(1+t/R)³` 만큼 준다.  `r_AM_P 5.0` vs `r_AM_S 2.5 µm` 라 **AM_S 가 2배 민감**:

| t | AM_P 개수 | AM_S 개수 |
|---|---|---|
| 0.05 | −2.9 % | **−5.8 %** |
| 0.10 | −5.8 % | **−11.1 %** |
| 0.25 | −13.6 % | **−24.9 %** |

⇒ **P:S 가 조용히 바뀐다** = 우리 Furnas dip·패킹 트랙의 설계 변수를 건드리는 것.

### C-5. 우리 결론

**t ≈ 0.05 µm 가 두 제약이 겹치는 창** (개수 편차 ≤ 5.8 % ∧ 코어 접촉 34 % ∧ σ/σ₀ 0.41–0.83).
t ≥ 0.15 는 **B1 ①(SE 좌표 편향, 새 phase 없이)** 가 옳다.

> **Q-C1**: 이 "창" 논증이 성립하는가?  특히 **서로 다른 두 축(기하 규약 오염 · 전달)의
> 허용치를 곱해서** 창을 만든 것이 정당한가?

> **Q-C2**: §C-3 표는 **코팅 없는 침대 좌표를 고정**하고 간선만 필터한 것이다.
> 실제로 쉘을 씌우면 패킹이 바뀐다.  이것을 "자릿수 선별(screen)" 로만 라벨하는 것이
> 충분한가, 아니면 **결론으로 쓸 수 없다**고 해야 하는가?

> **Q-C3**: ⚠ 이 표는 **AM 백본 단독**이다.  실제 침대는 VGCF 가 전자의 **87–88 %** 를 나른다
> (CL-41 상별 몫).  ⇒ 전체 σ_e 의 코팅 민감도는 이보다 **훨씬 작을 것**이다.
> 그렇다면 §C-3 은 **무엇에 쓰이는 수인가**?  우리는 "AM 백본이 끊기는지" 의 답으로만
> 쓰려는데, 그 용도가 정당한가?

## §F. MPM / 유효전도도 사용가능성 — 경계가 맞는가

정리 문서: `docs/report_mpm_and_sigma_usability_20260819.md`.  핵심 주장 4개:

1. **scaffold MPM 의 porosity 는 독립 정보가 아니다** — `solid_vol` 이 씨앗 시점에 고정되므로
   porosity ≡ f(wall_z).  속도 사다리에서 14.38 → 12.76 → **11.08 %** 로 수렴하지 않고,
   정직한 준정적 답은 **ε_sphere 1.13 %**(실험 15.6 %) ⇒ **14.5 %p 과압축**.
   (⚠ 정정 2026-08-20: 이 줄의 초판은 `~9.4 % / ~6 %p` 였다 — 2026-08-12 R1 완주로 이미
   반증된 값이 낡은 CLAUDE.md 블록에서 복사돼 있었다.  prereg §11-1 · CL-04 가 정본.)
   옛 "1.2 %p = 구성모델 신뢰한계" 는 **관례 오프셋 1.251 %p**(ε_sphere vs union)와 일치해 철회.
2. **MPM 의 반증 가능한 산출물은 응력-정지 두께 하나**다 (29.95 vs 실측 30.28 µm).
3. **σ_e 상대비가 결론이고 절대값은 자릿수까지** — SBE 73 mS/cm 가 문헌 펠릿(34 · 38.6–65.2)과
   같은 자릿수, PTFE 스탬프 시 54.6 으로 밴드 안, 실험 대칭셀 +23.1 % 가 우리 두 규약 사이.
4. **"DEM↔MPM 일치 = 타당성 증명" 은 hold 모드에서 순환** (씨앗이 정답을 인코딩).

> **Q-F1**: 1·2 가 맞다면 **scaffold MPM 을 계속 쓸 이유가 무엇인가**?
> 우리 답은 "형상·응력장·공극충전 기전 + 정지 두께" 인데, 그것이 **논문 한 절을 지탱하는가**?

> **Q-F2**: 3 의 "자릿수까지" 라벨이 리뷰어에게 **방어 가능**한가?
> 특히 σ_VGCF 100 S/cm(유효 망 상수) 위에서 얻은 절대값을 문헌 펠릿과 비교하는 것이
> **범주가 맞는 비교**인가?
