## 2. RIMP-01 · P2 — 기울어진 MMS의 경계 반 셀이 계면 저항을 건너뛴다

**위치:** `scripts/rint_t2_dev.py:185–192`, 특히 190–192. 해석 정정 위치: `docs/data/rint_t2_dev_20261013/README.md:53–55`.

경계 조립은 항상 `g_b = 2 σ_cell h`를 쓰고 경계면의 제조해 값을 우변에 넣는다. 그러나 셀 중심과 경계면 중심이 계면의 반대편이면 그 **반 셀 길이에도 두 상과 계면막이 존재**한다. 현재 식은 그 전위 점프를 순수 bulk 전도도로 직접 잇는다. 기존 개발 사다리 자체에서 발생하며 변이 입력이 필요 없다.

| 축별 법칙 사례 | 기존 최대 전위 오차 | 최대 오차 셀 | 중심의 u (µm) | 경계면의 u (µm) | tie 셀 |
|---|---:|---|---:|---:|---:|
| θ=15°, n=64 | 0.537675585605 | (23,63) | −0.001439240068 | +0.001795997996 | 0 |
| θ=30°, n=16 | 0.503808452664 | (3,15) | −0.014711431703 | +0.010288568297 | 0 |
| θ=45°, n=128 | 0.444291021686 | (0,127) | ≈−1.11e−16 | +0.004419417382 | 128 |

**독립 대조:** 내부 행렬·정확 경계값·오차의 정답은 그대로 두고, 계면을 가로지르는 경계 연결만 다음으로 바꿨다.

`g_b = h² / (d_cell/σ_cell + d_boundary/σ_boundary + 10⁴ r_face)`

여기서 `d_cell+d_boundary=h/2`, 두 거리는 평면 교차 위치에서 계산하고, `r_face`는 비교 중인 동일한 축별/L1 법칙을 사용했다. 길이는 µm, σ는 S/cm, r은 Ω·cm²이며 `10⁴`는 현 FV 코드의 단위 사슬과 같다. 이것은 **원인 분리를 위한 경계 대조**이지 완성된 생산 교정이나 독립 기준해 인증이 아니다.

| 축별 사례 | 기존 L2 오차 → 대조 | 기존 최대 오차 → 대조 |
|---|---|---|
| 15°, n64 | 0.01306318860 → 0.0004495112904 | 0.5376755856 → 0.006475555385 |
| 30°, n16 | 0.04096008793 → 0.003087791839 | 0.5038084527 → 0.01633704071 |
| 45°, n128 | 0.003835149728 → 0.0009205293577 | 0.4442910217 → 0.005660516619 |
| 45°, n128, 평면 +0.001 µm 이동 | 0.003883094200 → 0.0009823643239 | 0.4439262878 → 0.004030350534 |

전위 오차는 제조해에 부여한 전위 단위다. 마지막 행은 tie가 **0개**다. 또한 기존 45°에서 tie 셀만 오차 계산에서 빼도 최대 오차는 **0.117248996295**로 남는다.

**무너지는 결론:** “0.44 plateau는 계면 위 셀의 점 판정 한계”라는 충분한 원인 진단. 원점 이동·tie 배제만으로 고칠 수 없다. 현 기울기 사다리를 D11 선택이나 D12-V 수치 근거로 직접 승격해서도 안 된다.

**무너지지 않는 것:** θ=0의 정확 이산 시험, 개발 실행 자체의 허용, 기울기 법칙을 비교해야 한다는 설계. 별도 θ=0, β=3, n16 대조는 최대 오차 `8.881784197001252e−16`, L2 `2.723647616275778e−16`이었다.

**최소 수정·해결 증거:** 경계에서 상/막 교차를 다루는 계약을 먼저 정하고, tie 없는 15°·30° 반례와 이동된 45°를 회귀로 추가. 경계 교정 뒤 사다리를 다시 개발 측정. T2 정식 검증에는 전위뿐 아니라 등록한 flux·에너지, 원점·3D·tie 규약을 포함할 것.

재현: `python -B probes/rrm_probe.py` → `evidence/rrm_probe.json`.

## 3. RIMP-02 · P2 — 조인 관문이 손상·미인증 입력을 PASS로 승격한다

**위치:** `scripts/rint_iface_join.py:176–180`, `200–206`, `337–338`, `350–358`, `432–441`; 상자 읽기 `142–143`, 비교 `316–318`. 가져오는 진단 함수: `scripts/lhs_descriptor_harvest.py:637–657`.

### 3-1. 실제 덤프 한 칸씩 변조

real14 접촉 덤프 **22행, ids 1·201**에서 각각 독립 변조했다. 원본 pos1.x=0.0250327 sim, δ=0.000199496 sim, A=1.8247e−6 sim²다.

| 독립 변조 | 실제 조인 결과 |
|---|---|
| pos1.x → NaN | PASS · 거부 사유 없음 |
| δ → NaN | PASS · 거부 사유 없음 |
| A → NaN | PASS · 거부 사유 없음 |
| A → −1.8247e−6 sim² | PASS · 검사된 면적 660→659 · 음수 거부 없음 |

NaN에 대한 `abs(잔차)>허용치` 비교는 실패를 발생시키지 않는다. 면적 진단 함수는 음수·미인증 행을 `beyond`에서 제외한다. 새 관문은 `beyond==0`만 읽어 **진단에서 제외된 행을 인증 통과로 취급**한다.

비유한값이 아닌 반례도 있다. 반경 0.001 sim 두 구, 중심 거리 1e−9 sim, δ=0.001999999 sim일 때 실제 원판은 **3.141592653589008e−6 sim²**다. 면적을 **100 sim²**로 적어도 `tested=0, uncertified=1, beyond=0, PASS`다. “포괄 밖 0”은 “전 행 인증”과 다르다.

### 3-2. 상자 identity에서 기울기 소실

`BOX BOUNDS xy xz yz ...`인 두 덤프에 atom xy tilt=0.001 sim, contact xy tilt=0.002 sim을 주고 앞의 두 경계 열만 같게 두면 `box_equal=true`, PASS다. 파서가 tilt와 상자 형식 정보를 버린 뒤 비교한다.

현 범위를 직교 상자로 제한한다면 **기울어진 상자 헤더를 명시적으로 거부**하면 된다. 이 리뷰가 삼사정계 지원을 새로 요구하는 것은 아니다.

작은 합성 입력으로 **조인 → 실제 ledger → plan(join=…) → iface_require_quantitative**까지 호출했다. 위 NaN·음수·상자 변이들은 이 소비 경로에서도 거부 없이 통과했다. 실제 전도도 생산은 실행하지 않았다.

**무너지는 결론:** 현 G-geo/G-frame의 PASS가 유효한 수치·지원 상자·전 행 면적 인증을 뜻한다는 주장. 제공된 정상 real14/case15 데이터가 손상됐다는 주장은 아니다. 현재 면적 원천이 scaffold라 이 반례만으로 실제 σ가 틀렸다고도 할 수 없다.

**최소 수정·해결 증거:** 관문 입구에서 필수 필드·유한성·반경/상자 길이 양수·정확 정수 identity·지원 상자 형식을 검사. 음수/비유한/미인증 면적은 명시 거부 또는 미인증 상태로 남기고 PASS와 분리. 기존 봉인 진단 helper를 느슨하게 고치는 대신 새 소비자에서 엄격한 조건을 붙일 수 있다. 위 변이 각각이 해당 사유로 실패하고 정상 두 침대는 유지되는 회귀 필요.

부수 파서 주의: step `2060000.9`도 `int(float(...))` 때문에 2060000으로 줄어 통과한다. ID/type도 같은 변환이다. 이는 malformed 입력 경화 항목이며 위 유효 형식 반례와 구분한다.

## 4. RIMP-03 · P2 — 면적 포괄 검사에 기록한 유효숫자 S가 전달되지 않는다

**위치:** `scripts/rint_iface_join.py:106`, `206`, **437**; `scripts/lhs_descriptor_harvest.py:164`, `450`, `545`, `637–651`.

조인은 `S=max(6,실측)`와 면적 반폭을 계산하지만, 면적 helper 호출에 전달하지 않는다. helper는 여전히 고정 `AREA_CHECK_SIGFIG=6`이다.

**전 행 16자리로 균일 출력한 반례** — 혼합 포맷의 문제가 아니다.

- 반경 0.001 sim, 중심 거리 0.0015 sim, δ=0.0005 sim.
- 참 원판 A=`1.3744467859455347e−6 sim²`.
- +1 ppm 변이 A=`1.374448160392321e−6 sim²`.
- 16자리 포괄=`[1.3744467859455032e−6, 1.3744467859455659e−6] sim²`.
- 더 넓은 생산 산술 오차 여유 `1.67859784936371e−20 sim²`를 더해도 변이는 포괄 밖이다.
- 실제 조인은 atom/contact S=16, `tested=1, beyond=0, PASS`. 실제 계획·정량 관문도 통과.

**최소 수정·해결 증거:** 지원하는 파일/필드 정밀도를 같은 포괄 계산으로 전달하거나, 인증된 6자리 생산 포맷만 지원한다고 명시하고 다른 형식은 거부. 고정 helper를 바꾸는 경우 기존 봉인 영향은 별도 처리해야 한다. 현재 정상 6자리 자료가 틀렸다는 결론은 아니다.

별도 한정: “관측된 최대 자리수”는 균일 `%g` 생산 포맷의 증명이 아니다. 수치가 같은 한 토큰 `0.0250327 → 0.02503270000000000`만 바꾸면 atom 쪽은 위치 불일치 7행, contact 쪽은 위치 21행·δ 일관성 **99,113/106,563행**이 생겼다. 균일 포맷 보증을 계약으로 두거나 혼합 포맷을 거부할 것. `%g`는 끝의 0을 생략하므로 단순한 토큰별 자리수로 바꾸는 것도 답이 아니다.

재현: `python -B probes/join_synthetic.py`; 포맷 한정 탐침은 `python -B probes/join_global_precision.py`.

**위치:** `scripts/rint_rrm_reference.py:293–302`, `318–321`, wrapper `328–340`; NaN의 후속 효과 `scripts/step3_sigma.py:354–356`.

기존 A 픽스처를 그대로 썼다. R=1 µm, δ=0.167 µm, h=0.1 µm, bridge=0.7 µm, r=1e−3 Ω·cm². owner 면 152개=안 35·부분 32·밖 85. 참 원판 `0.5027420037705035 µm²`, 가중합 `0.5027420037705037 µm²`. 정상은 film 67개·cut 85개다.

| 계획 | `rrm_check` | wrapper 풀이 σ (S/cm) |
|---|---|---:|
| 정상 | 위반 없음 | 0.003334457143882423 |
| cut 85행만 삭제 | `film_off_outside` 85개 — 정상 거부 | 거부 |
| 위 삭제 + 기록의 resolve_k 4→5 | **위반 없음** | **0.0040840140889134725** |
| 위 삭제 + 기록의 r table 비움 | **위반 없음** | **0.0040840140889134725** |
| cut 유지 + film 67개의 rface=NaN | **위반 없음** | **0.0037299595666211234** |

resolve_k/r table 변이는 검사기가 그 접점을 “대상이 아님”으로 건너뛰게 한다. 같은 인자로 새 planner를 정상 호출하면 거부될 조건인데, 검사기는 그 거부가 실제로 기록돼 있는지 재검증하지 않는다. NaN 비교도 위반을 만들지 않으며, solver의 `r>0` 분기를 타지 않아 해당 면의 bulk 연결이 남는다. NaN 반례는 `unconverged=False`, 잔차 `6.2089744354216986e−15`였다. 작은 잔차는 틀린 조립을 구제하지 않는다.

**한정:** 정상 `rrm_plan`이 이 유한 입력에서 NaN을 만든다는 주장이 아니다. 행 지문은 리포의 N9 변이 시험과 같이 의도적으로 다시 계산했다. E5의 우발 변조 검출과 별도로 **독립 의미 검사**의 판별력을 시험한 것이다. 공격자 인증 문제로 확대하지 않는다.

**최소 수정·해결 증거:** 유한·비음수 rface 검사(등록된 r=0 경로는 허용), 기대 접점 집합과 적격성/거부의 재계산, 메타데이터 변경으로 검사 집합을 비울 수 없는 계약. 기존 행만 지운 변이뿐 아니라 위 복합 변이도 wrapper에서 거부해야 한다.

일반 생산 관문이 RRM을 모르고 N9를 RRM wrapper에서 맡는 구조 자체는 시험 전용 격리와 정합한다. 이미 공개된 “generic solver에 직접 변이를 주면 받음”을 새 결함으로 세지 않았다. **모든 RRM 실행이 고쳐진 wrapper를 지나야 한다.**

재현: `python -B probes/rrm_probe.py`.

## 6. RIMP-05 · P2 — 계획의 물리 격자 간격이 솔버 인자에 봉인되지 않는다

**위치:** `scripts/step3_sigma.py:1841–1842`의 guard 호출, `1597`, `1616–1617`; 계획은 `1486`에 vox를 보관하지만 조립 `2009`는 솔버의 vox를 사용한다.

**계획 사전을 수정하지 않은 반례다.** R=1 µm AM_S 두 개, 중심 z=1·2.98 µm, sid=10×10×20, h=0.2 µm, r=1e−3 Ω·cm² 계획을 만든 뒤 **같은 sid·같은 계획**을 h=0.4 µm 솔버에 전달했다.

- film 16면, 자유도 1,072.
- 계획 A=`0.06251769380643697 µm²`, 기록된 순수 막 G=`6.251769380643698e−7 S`.
- h=0.4 호출은 거부 없이 풀이. 실제 조립 면적을 사용한 순수 막 G=`2.5007077522574787e−6 S` — 기록의 **4배**.
- 결과에는 여전히 vox=0.2 µm와 옛 A가 실린다. 잔차 `2.6821546712579842e−15`.
- 중심·반경·h를 모두 2배 해 **정상 재생성한 계획**은 위 불일치 호출과 σ=`0.0021331551689598217 S/cm`가 정확히 같지만, A·G를 올바르게 4배로 기록한다.

따라서 단순히 정당한 크기 환산의 차이가 아니다. **크기를 바꾼 문제를 풀면서 옛 기하를 증서로 붙이는 호출이 허용**된다. sid 바이트 지문만으로 물리 격자가 같음을 보증하지 못한다.

**최소 수정·해결 증거:** solver의 유한 양수 vox를 plan guard에 전달해 조립 전에 일치 검사. 같은 배열·같은 계획·다른 vox 음성 대조와 정상 재생성 계획 양성 대조를 상주 시험으로 추가. 이 결함은 RINTV-01/02 소유권 규칙의 닫힘을 뒤집지는 않는다.

재현: `python -B probes/owner_vox_mismatch.py`.

## 7. RIMP-06 · P3 — RRM 반환 기록에 이전 CNC 수치가 라벨 없이 남는다
