## 0. 이 digest 를 읽는 법 — 왜 우리에게 필요한가

논문의 줄거리는 단순하다: **"HOMO 를 ML 로 예측 → S=O 가 HOMO 를 낮춘다 → S=O 4개짜리 후보 셋 → DFT LUMO 까지 보고 BDTT 선정 → 파우치 45 °C 유지율 24.71 → 82.73 %"**. 우리는 액체 전해질을 안 하니 첨가제 자체는 관심 밖이다. 이 편에서 가져갈 것은 넷이다.

| # | 가져갈 것 | 왜 우리에게 | 어디서 |
|---|---|---|---|
| ① | **공개 데이터셋으로 ML 주장을 직접 다시 재 본 사례** | 우리 cascade 예측기 감사(§J-4·§J-8·§J-11)의 체크리스트를 *남의 공개 데이터*에 실제로 돌려 본 사례다. 결과는 *"규약 함정은 있는데 크기는 작다 — 대신 '비선형 GBR 이 필요하다' 는 주장이 무너진다"* | §5 · §9-1 |
| ② | **엑셀 머리말 단위 오기 판정** | `HOMO (Hartree)` 열은 **eV** 다(1440/1440 산술 증거). `LUMO (Hartree)` 열은 형식만 Hartree 꼴이고 **값 수준이 재현되지 않는다 → 미확정**. 남의 데이터셋을 받아 쓸 때의 검사 순서 표본 | §5-1 |

## 1. 한 줄 요약

PubChem 에서 뽑은 **황 2개짜리 C/H/O/S 분자 1440종**의 B3LYP HOMO 를 결합 개수 서술자 23개로 회귀(GBR, 시험 R 0.847)하고 SHAP 으로 **"S=O 가 HOMO 를 낮춘다"** 를 끌어낸 뒤, 그 원리로 **손으로 만든 후보 3종**(BDTD·BDTT·TDT)을 DFT HOMO/LUMO 로 가려 **BDTT**(4,4′-bi-1,3,2-dioxathiolane 2,2,2′,2′-tetraoxide = 에틸렌 설페이트 이량체)를 고르고, 1 wt% 첨가로 **1 Ah LNMO‖AG 파우치 3.5–4.85 V · 1 C · 45 °C · 500 cycle 유지율을 24.71 % → 82.73 %** 로 올렸다고 보고한다. 기전은 *"BDTT 는 용매화에 안 끼고(NMR·MD), 흑연에만 약하게 붙어(E_ads −0.039 vs LNMO +0.124 eV) 먼저 환원돼 S-rich·얇은 SEI 를 만들고, 그것이 Mn crosstalk 를 막는다(ICP Mn 2284.1 → 538.4 ppm)"*. ⚠ 산화 쪽 검증(양극 LSV·4.85 V 부유전류)은 없고, 흡착에너지는 상태 선언 없는 단일 배치다.

### 5-5. 하전종 52 행 — 계산 상태 미선언

- **이가 음이온(알짜 −2) 52 행**(설폰산염·카복실산염 등) + 전하 분리 중성 3 행. 분자식 열은 **52 행 전부 전하를 지운다** (`C6H4O8S2-2` → `C6H4O8S2`).
- 이 52 행의 HOMO 는 중앙 **−7.47 eV** 로 중성과 같은 대역이다. **기체상 이가 음이온이라면 불가능하다** — 대조 계산: 에탄-1,2-디설핀산염 전하 −2 기체상 HOMO **+2.63 eV** · LUMO **+6.73 eV** (데이터 HOMO −8.231). 같은 골격을 **전하 0(전자 2개 제거)** 으로 돌리면 HOMO −7.48 · LUMO −6.43 eV.
- ⇒ 이 행들은 **전하 0 으로 계산됐거나(전하를 잃은 분자식과 정합) 암묵 용매로 계산됐다** — 어느 쪽이든 **논문에 없다**. Hartree 판독 LUMO 최저 4 행(−8.09 ~ −7.43 eV)과 HOMO–LUMO 갭 최소 4 행(0.36–0.50 eV)이 전부 이 이가 음이온이다. **라벨 3.6 % 가 상태 미정의 값**이다.

3. 🔴 **"GBR 이 SVR 보다 낫다" 는 재현되지 않는다** — 같은 격자·같은 CV 로 SVR 0.884 vs GBR 0.877. 논문의 R 차 0.024 는 **분할 한 번의 흔들림(±0.02) 안**이다.
4. 🔴 **"GBR 이 복잡한 비선형 관계를 잡는다" 는 근거가 약하다** — 선형 회귀가 R 0.846 / MAE 0.277 로 GBR(0.877 / 0.243)과 0.03 차다.

6. **후보 예측 재현** (20 시드 GBR, RDKit 서술자): **BDTD −8.06 ± 0.12 · BDTT −8.93 ± 0.17 [−9.18, −8.40] · TDT −8.69 ± 0.19 eV** — 논문(−7.97 · −8.78 · −8.70)이 전부 이 안에 든다. ⚠ 그러나 **BDTT 와 TDT 의 예측 차(논문 0.08 eV)는 시드 흔들림(±0.17)·MAE(0.26)보다 작다** — ML 은 두 후보를 가르지 못한다. 실제로 가른 것은 DFT **LUMO** 다.
7. BDTT 의 서술자 최근접 이웃(L1)은 알킬 (비스)황산 수소 에스터들이고 HOMO **−8.67 ~ −9.08 eV** — 예측값이 그 동네 평균이다.

### 6-2. 후보 3종 → BDTT (`Fig. S1` · `Fig. S2`)
- *"이 원리에 따라 대표 분자 3종을 **구성했다(constructed)**"* — 라이브러리를 훑어 순위를 낸 것이 아니다. 세 분자는 데이터셋에 없다.
- 예측 HOMO (`Fig. S1`): −7.97 / −8.78 / −8.70 eV. DFT (`Fig. S2`): HOMO −7.99 / −8.91 / −8.89 · LUMO −1.08 / −1.00 / −0.28 eV. ML–DFT 차 0.02–0.19 eV.
- 본문은 이 일치를 *"모델의 신뢰성과 예측력을 더 보여준다"* 고 쓰지만, **n = 3 이고 셋 다 MAE(0.26) 안**이라 그 이상을 말하지 않는다.
- 선정은 결국 **"BDTD 보다 HOMO 가 낮고, TDT 보다 LUMO 가 낮다"** — HOMO 차 0.92 eV(BDTD 대비), LUMO 차 0.72 eV(TDT 대비) (우리 산수).

### 6-3. LSV — 환원 쪽만 (`Fig. S3`)
- **Li‖스테인리스** 반전지, 3.0 → 0 V 음극 주사(1 mV s⁻¹, SI). 전류는 A 단위(면적 미정규화).
- 본문: *"BDTT 전해질은 **≈2.0 V 에서 뚜렷한 환원 전류 개시** — 대조군은 더 낮은 전위에서야 분해 신호."*
- 🔴 **그림은 그렇게 보이지 않는다**: 두 곡선은 3.0–2.0 V 에서 겹치고, 빨간 상자(≈2.0–1.8 V) 안에서 BDTT(파랑)가 아주 조금 위에 있다가, **≈1.9 V 에서 역전해 ≈0.6 V 까지는 오히려 대조군(주황) 전류가 더 크다**. 색 마스크 픽셀 판독 (`figure-read ≈`): 1.95 V 파랑 5.8×10⁻⁵ > 주황 4.6×10⁻⁵ A · 1.85 V 주황 7.9×10⁻⁵ > 파랑 6.6×10⁻⁵ · 1.6 V 1.9×10⁻⁴ vs 1.4×10⁻⁴ · 1.1 V 3.9×10⁻⁴ vs 3.1×10⁻⁴ · 0.8 V 5.4×10⁻⁴ vs 5.0×10⁻⁴ A. BDTT 가 앞서는 구간은 **≈0.1 V 폭 · 10⁻⁵ A 급**이다. "뚜렷한" 개시도 "대조군은 더 낮은 전위에서야" 도 그림으로 지지되지 않는다.
- ⛔ **산화 쪽 LSV 는 없다.** HOMO 로 세운 "cathode-stable" 을 직접 재는 실험(양극 주사·4.85 V 정전위 부유전류)이 이 논문에 **0 건**이다 (§9-2).

### 6-4. XPS — S 가 어디 있나 (`Fig. S4`)
- BDTT 파우치를 화성 후 분해: **AG 표면 S 2p 강함**(두 이중선), **LNMO 표면 거의 평탄**.

### 6-5. 파우치 (`Fig. 2a,b`) — 수치는 §3c
- 20 °C: 차이 작다(83.28 vs 86.60 %) — 저자도 *"제한적 개선"*.

### 6-7. 용매화 — NMR + MD (`Fig. 3`) — 수치는 §3e
- 논리: ⁷Li·¹⁹F 이동 없음 → BDTT 가 Li⁺–PF₆⁻ 배위·용매화 껍질을 안 바꾼다 → **"자유 상태(free-state)"** 로 떠 있다가 계면에서 직접 반응. MD 가 Li⁺–BDTT 배위수 ≈0 으로 그것을 "확인". 종합 문장은 *"NMR 과 MD 를 합치면 … Li⁺–용매 배위도, Li⁺–PF₆⁻ · PF₆⁻–용매 상호작용도 안 바뀐다"* 이다.
- 저자는 FEC 2.3 · DMC 1.2 · TTE 0 을 *"전형적인 국소 고농도 전해질 구조"* 라 부른다 — ⚠ (FEC+DMC)/Li⁺ ≈ 5.4 (우리 산수)는 고농도라기보다 **보통 농도 + 희석제**다.
- ⚠ 판정은 §13: 1 wt% 첨가제는 NMR 평균 이동에 원래 둔감하고, MD 는 BDTT 없는 대조 상자가 없으며 390 K · 첨가제 ≈2 배 농도다. **Li⁺–PF₆⁻ RDF 는 그림에 없다** — "Li⁺–PF₆⁻ 가 안 바뀐다" 의 MD 쪽 근거는 제시되지 않았고, "안 바뀐다" 는 비교 대상(무첨가 MD)이 없어 MD 로는 원리적으로 말할 수 없다.

### 6-8. 흡착 (`Fig. 4`) — 수치는 §3f · 판정은 §9-3
- `Fig. 4a` 제목 **"BDTT adsorption on LNMO (001)"**, E_ads = +0.124 eV, 화살표 "Repel". 초기 구조: BDTT 가 세로로 서서 아래 고리 O 가 표면 회색 원자(Ni 로 보임)·초록 Li 옆에 있다. **최종 구조에서도 고리 O 가 표면 Li(초록)에 결합선으로 이어져 있다** (원본 2배 확대 판독) — "반발" 화살표는 만화이고 분자가 떨어져 나간 기하가 아니다. 표면 최상층 O 도 흐트러져 있다.
- `Fig. 4b` **"BDTT adsorption on AG"**, E_ads = −0.039 eV, "Attract". 흑연 **2층**, 분자는 기울어진 채 표면에서 떨어져 있고(최종에서도 S=O 가 표면을 향한 채 수 Å 위), 납작하게 눕지 않았다.
- 같은 그림이 초록 TOC 그림으로도 쓰였다 (`Fig. 4b` 부분).

### 6-9. DRT + TOF-SIMS (`Fig. 5`) — 수치는 §3d·§3g
- DRT 서술의 핵심은 **"τ1 = 옴 저항(Rs)"** 인데, 순수 옴 저항은 이완시간이 없어 DRT 에 봉우리로 나타나지 않는다 — τ1(log τ ≈ −3, ≈160 Hz 대역, 우리 산수)은 접촉/SEI 류 과정이다. 본문도 같은 문단에서 그것을 *"SEI 의 내부 저항"* 으로 읽는다 — **용어가 섞였다**.
- TOF-SIMS 는 3D 렌더 12개뿐이다(깊이 프로파일 곡선 없음).

### 6-10. SEM/EDS · TEM (`Fig. S6`–`S8`) — 수치는 §3g
- 본문은 S 지도를 *"`Fig. S6(a)` 가 BDTT, `Fig. S6(b)` 가 대조"* 라고 지목한다 — **캡션·그림상 (a)는 대조군 SEM, BDTT S 지도는 (e)** 다 (§13-A).
- TEM: 음극 SEI 가 BDTT 쪽에서 ≈2.5 nm vs ≈7.3 nm, 양극 CEI 는 ≈9.6 vs ≈9.4 nm (`figure-read ≈`). 각 1장씩이고 통계 없음.

### 6-11. ICP Mn
- 음극 질량 대비 Mn **2284.1 → 538.4 ppm**. 본문: *"조밀한 S-rich 초기 계면이 강한 장벽으로 이동 TM 의 석출·촉매 전파를 막아 crosstalk 열화를 근본적으로 완화."*
- ⚠ **어느 셀(20/45 °C · 몇 cycle)의 음극인지 없다.** 45 °C 500 cycle 이라면 대조군은 rollover 후 셀이라 Mn 이 많은 것이 원인인지 결과인지 가를 수 없다.

### 6-12. 저자 자신의 한계 문장 (p.I)
*"이 작업은 양극 산화에 취약한 후보를 걸러내는 **빠른 HOMO 기반 분류**에만 집중했다. 앞으로는 LUMO 를 타깃으로 음극 우선 피막 형성 첨가제를 거르고, HOMO–LUMO 갭으로 고전압 안정 용매를 찾겠다."* — ML 이 LUMO 를 안 다뤘다는 것을 저자도 인정한다.

### 9-2. HOMO 를 산화안정성 대리로 — 어디까지 검증했나

1. **양이 다르다.** 고립 분자 기체상 HOMO(Koopmans 류 근사)는 **전해질 속 산화전위**가 아니다. 빠진 것: 용매화·이온쌍(Li⁺ 배위나 음이온 착물은 궤도 준위를 크게 옮긴다) · 이온화 후 구조이완(수직 vs 단열) · 전극 표면 촉매 효과 · 반응 경로(산화 후 개환·SO₂ 방출 같은 화학 단계). B3LYP 의 −HOMO 는 이온화 에너지보다 대개 2–3 eV 작다(범함수 의존) — 절대값이 아니라 같은 수준끼리의 **순위**만 뜻이 있다.
2. **논문이 한 검증 = 0 (산화 쪽).** `Fig. S3` 은 **환원 주사뿐**이다. 양극 쪽 근거는 ① `Fig. 2d`·`Fig. S5c,d` LNMO‖Li EIS 겹침(화성 직후 · 첫 충전 후) ② `Fig. S4b` LNMO 표면 S 신호 없음 ③ `Fig. S8` CEI 두께 동일 — 셋 다 **"BDTT 가 CEI 에 *고체로* 남지 않았다"** 까지만 말한다. 산화돼 **녹는 생성물·기체(SO₂ 등)로 빠졌는지**는 못 가른다. 4.85 V 에서의 부유전류·가스 분석·전해질 사후 NMR 이 없다.
3. **우리 축과의 관계** (§B — 축 이름을 붙인다): 우리 "산화안정성" 은 **축 B① = 0 K grand-potential 분해 onset (층①, S²⁻-limited)** 이다 — 결정 고체의 열역학 상평형 양이다. 분자 HOMO 와는 정의·계·상태가 전부 다르다. `zhu2015_esw_grand_potential_origin` 이 이미 *"Goodenough HOMO–LUMO 창은 전자 준위 기반, 우리는 중성 Li 평형 기반"* 으로 갈라 놓았다. `gao2026_sib_electrolyte_ai_review` §4b 의 LUMO↔ESW 혼용과 같은 함정이다. ⛔ **"HOMO 가 낮다 = 산화안정" 문장을 우리 원고에 축 이름 없이 옮기지 않는다.**
4. 저자에게 공정하게: 분자 첨가제 분야에서 HOMO/LUMO 1차 선별은 관행이고, 저자 스스로 *"rapid HOMO-based triage"* 라고 물러선다(§6-12). 문제는 그 뒤의 **실험 검증이 산화 쪽을 비워 둔 것**이다.

## 11. 적용 인사이트 (내 연구에 어떻게)

- ① **남의 공개 ML 데이터셋을 받으면 이 순서로 본다**: 머리말 단위(산술 지문) → 숨은 선택 필터(원소·개수 분포) → 중복·서술자 충돌 → 서술자 재계수 → 하전·상태 → 기준선(선형·단변수) → 분할 규약 바꿔 재현. DFT 대조 계산을 빼면 전부 표 하나로 도는 검사이고, 이 편에서 **넷(단위 오기 · S₂O≥4 필터 · 서술자 오류 · SVR=GBR)이 나왔다**. 우리 cascade 감사(§J-8 T3-a/b)의 "싼 기술자만의 R² · Dummy/선형 사다리" 를 미루지 말아야 할 이유가 하나 더 생겼다 — *기준선이 없으면 "비선형 모델이 필요했다" 는 문장이 공짜로 통과한다.*
- ② **"산화안정성" 은 항상 축 이름과 함께** — 분자 HOMO(이 편) · 고체 grand-potential onset(우리 B① 층①) · 탈리튬화 골격 유지(층②) · 동역학 LSV onset 은 다른 양이다. 이 편은 *HOMO 로 설계하고 산화 실험은 안 한* 사례로 인용할 수 있다.
- ③ **회신 N 규칙의 외부 실례 확보** — 자성 산화물 위 단일 E_ads(+0.124 eV)로 기전을 세운 편. SDCP 관련 리뷰 답변에서 *"왜 우리는 한 자세 값을 인용하지 않나"* 를 설명할 때 쓸 수 있다 (트랙: SDCP = 사용자 1저자). ⛔ 우리 숫자와는 나란히 놓지 않는다 — 우리 C-12 값은 원고·SI·슬라이드 게재 자체가 금지다.
- ④ **황화물 계로 옮길 때의 진짜 질문은 HOMO 가 아니다** — BDTT 는 DTD(에틸렌 설페이트) 이량체이고, `deng2026_…` 은 **DTD 가 LPSC 표면 S²⁻ 를 개시제로 개환중합**된다는 것을 보였다. 즉 고리 황산염은 황화물 SE 앞에서 **친핵 개환 반응성**이 먼저다. 누군가 "BDTT 류를 황화물 전지 첨가제·코팅으로" 라고 하면, 이 편의 "cathode-stable" 은 전이되지 않는다 — 물을 것은 S²⁻ 와의 반응이다.
- ⑤ 데이터셋 HOMO 열(eV · B3LYP/6-31+G(d,p) 로 ±0.26 eV 재현)은 S₂ 유기분자 HOMO 벤치마크로 재사용 가능하다. **LUMO 열은 쓰지 않는다.**

### 13-C. 방법 한계 (중요도 순)
1. **ML 은 스크리닝이 아니다** — 후보 3종을 손으로 만들었고 ML 은 그 셋을 가르지 못한다(BDTT–TDT 예측차 0.08 eV < MAE 0.26). 선택은 DFT LUMO 가 했다. 제목·초록 과대표현.
2. **산화 쪽 검증 0** — HOMO 대리, 산화 LSV·부유전류·가스·사후 전해질 분석 없음.
3. **E_ads 보고량 미정의** (§9-3) — 자성·산화환원 기판, 상태 선언 0, 자세 1, vdW 미기재, 리튬화 슬랩.
4. **데이터셋 품질** — HOMO 머리말 단위 오기 · LUMO 열 재현 불가 · 숨은 S₂O≥4 필터 · 중복 36 그룹(라벨 폭 최대 1.26 eV) · 서술자 계수 오류(비방향족 37 %) · 이가 음이온 52 행 상태 미정의.
5. **ML 비교 주장** — GBR > SVR 은 시드 흔들림 안, 선형 기준선이 거의 같다(우리 재현).
6. **MD** — 390 K(실험 20/45 °C) · 첨가제 ≈2 배 농도 · 5 ns · BDTT 10 분자 · 대조 상자 없음 · Li⁺–PF₆⁻ RDF 미제시.
7. **NMR** — 1 wt% 첨가제에 대한 평균 이동은 원래 둔감 · ¹⁹F 는 PF₆⁻ 이중선 창만.
8. **전기화학 통계** — 셀 수·오차막대 없음. 45 °C 의 큰 차이는 대조군 rollover 가 만든다.
9. **DRT** — 방법 미기재, "τ1 = 옴 저항" 개념 혼용, 색축 포화.
10. **TOF-SIMS·ICP** — 장비·조건 미기재, ICP 시료 조건 없음.
11. **COI** — 특허 출원 중.

### 13-D. ⛔ 인용 금지
- E_ads **+0.124 / −0.039 eV** 를 어떤 우리 흡착에너지(SDCP 포함) 옆에 놓는 것 — 상태·방법이 정의되지 않았다.
- XLSX **LUMO 열**을 eV 로든 Hartree 로든 수치로 쓰는 것.
- XLSX **HOMO 열**을 "Hartree" 로 읽는 것 (eV 다).
- 이 논문의 HOMO 를 우리 **ESW / 산화 onset(축 B①)** 과 같은 문장에 축 이름 없이 놓는 것.
- R **0.847** (또는 0.85) 를 우리 cascade 의 LODO·그룹 CV 숫자와 같은 표·같은 슬라이드에 놓는 것 (§J-8 규율 — 다른 자).
- "GBR 이 SVR 보다 우월" · "비선형 관계 포착" — 우리 재현으로 지지되지 않는다.
- "BDTT 는 양극에서 산화되지 않는다(실험 확인)" — 산화 실험 없음.
- 45 °C 유지율 대비를 셀 수 없이 "재현성 있는 개선" 으로.
- 우리 재분석 숫자(§5)를 논문 값처럼 — 항상 "(우리 재분석)".

## 14. 기술 미니 용어집

| 용어 | 한 줄 설명 |
|---|---|
| **HOMO / LUMO** | 가장 높은 점유 / 가장 낮은 비점유 분자궤도의 에너지. 분자 첨가제 분야에서 "HOMO 낮음 = 산화 어려움 · LUMO 낮음 = 환원 쉬움" 의 1차 근사로 쓴다. 범함수·기저·용매·상태에 따라 수 eV 움직이는 **근사적 지표**다 |
| **Hartree (Eₕ)** | 원자 단위 에너지. 1 Eₕ = 27.2114 eV. Gaussian 은 궤도 에너지를 Hartree 로 소수 5자리까지 찍는다 — 이 지문으로 §5-1 을 판정했다 |
| **GBR (gradient boosting regression)** | 얕은 결정트리를 하나씩 더해 이전 잔차를 줄여 가는 앙상블. 하이퍼파라미터: 트리 수(n_estimators) · 학습률 · 최대 깊이 |
| **SVR (support vector regression)** | 오차 ε 안은 벌점 없이 두고 커널로 비선형 관계를 맞추는 회귀. C = 정칙화, γ = RBF 커널 폭 |
| **GPR** | 가우스 과정 회귀 — 이 논문에는 **없다** (캡션 오기) |
| **Pearson R / MAE / RMSE / MAPE** | 선형 상관계수 / 평균 절대오차 / 제곱평균제곱근 오차 / 평균 절대 백분율 오차. R 은 R² 가 아니다(0.847 → R² ≈ 0.72) |
| **5-fold CV · 격자탐색** | 학습셋을 5등분해 번갈아 검증하며 하이퍼파라미터 조합을 고르는 절차. 성능 추정이 아니라 **선택 도구**로 쓰였다 |
| **무작위 vs 골격(scaffold) 분할** | 무작위는 비슷한 분자가 학습·시험에 갈라져 들어간다(낙관). Murcko 골격 분할은 같은 고리 뼈대를 한쪽에만 둔다(새 화학계에 대한 일반화) |
| **SHAP** | 협력게임 이론의 Shapley 값으로 각 서술자가 개별 예측을 기준값에서 얼마나 밀었는지 나누는 방법. 상관된 서술자 사이에서 배분이 임의적일 수 있다 |
| **서술자 충돌** | 서로 다른 분자가 같은 서술자 벡터를 갖는 것 — 결합 "개수" 서술자는 이성질체를 구분 못 한다 |
| **LSV (linear sweep voltammetry)** | 전위를 한 방향으로 쓸며 전류를 재는 법. 여기서는 Li‖스테인리스에서 음극 방향(환원)만 |
| **EIS · Nyquist** | 작은 교류로 임피던스를 재 실수(Z′)–허수(−Z″) 평면에 그린 것. 고주파 반원 ≈ 계면 피막 저항 |
| **DRT (distribution of relaxation times)** | 임피던스를 이완시간 분포 γ(τ) 로 풀어 겹친 과정(접촉·SEI·전하이동·확산)을 시간척도로 가르는 법. 순수 옴 저항은 봉우리가 없다 |
| **TOF-SIMS** | 이온빔으로 표면을 깎으며 튀어나온 이차이온 질량을 재는 깊이 분석. 반정량 |
| **RDF g(r) · 배위수 N(r)** | 기준 입자 주위 거리 r 의 상대 밀도 / 그것을 적분한 이웃 수. 첫 봉우리 뒤 N(r) 의 고원이 1차 배위수 |
| **IHP (inner Helmholtz plane)** | 전극 표면에 직접 흡착한 종이 놓이는 전기이중층의 가장 안쪽 면 |
| **LHCE (국소 고농도 전해질)** | 소량의 용매화 용매에 염을 진하게 녹이고 비용매화 희석제(TTE 등)로 묽힌 전해질 |
| **crosstalk** | 한 전극에서 생긴 부산물(용출 TM 이온·산화 조각)이 전해질을 건너 반대 전극의 계면을 바꾸는 현상. LNMO 에서는 Mn 용출 → 흑연 위 석출이 대표적 |
| **rollover** | 사이클 후반 용량이 갑자기 가속 감소하는 현상 (전해질 고갈·Li 석출 등) |
| **E_ads (흡착에너지)** | E(슬랩+분자) − E(슬랩) − E(분자). 음수 = 흡착이 유리. 자성·산화환원 기판에서는 **어느 전자 상태끼리 뺐는지**가 정의의 일부다 |
| **admissible state / 보고량 정의** | 우리 회신 N 규칙 — 물리적으로 정당한 해가 여럿인데 고르는 규칙이 없으면 스칼라 하나는 정의되지 않는다 |
