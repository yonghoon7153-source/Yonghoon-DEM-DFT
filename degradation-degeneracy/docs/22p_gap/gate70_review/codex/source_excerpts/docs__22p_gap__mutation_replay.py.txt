6965:     안 나타나야 물었다.

6967:     남은 한계: report 자체를 위조하면 통과한다. 그러나 그것은 "아무 것도 안 하고
6968:     숫자만 적는 것" 과 다른 주장이고, report 는 committed·diffable 이다.
6969:     """
6970:     want = set((EXPECT.get(name) or {}).get("fail") or ())
6971:     if not want:
6972:         return None
6973:     def _failed(phase):
6974:         f = pathlib.Path(rep_dir) / f"{name}.{phase}.json"
6975:         try:
6976:             data = json.loads(f.read_text(encoding="utf-8"))
6977:         except (OSError, json.JSONDecodeError):
6978:             return None
