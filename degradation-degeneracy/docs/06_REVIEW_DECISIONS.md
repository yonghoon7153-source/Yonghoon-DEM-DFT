### F4 — "degeneracy 지표가 평평한 골짜기를 체계적으로 과소 측정한다"  → **부분 수용 (기록만)**

| | |
|---|---|
| 지적 | (a) `agree_tol=1e-3`이 J~0.1–0.3 스케일에서 너무 엄격해, 물리적으로 구분 불가한(5 mV 노이즈 대비) 두 해가 "다른 J"로 분류됨 → `p_spread=0`이 "골짜기 없음"이 아니라 "자로 안 쟀음"을 의미. (b) adaptive 조기 종료로 조건마다 검정력이 다름 |
| 판단 | 지적 타당. 다만 **편향 방향이 "과소"** 라 우리 최종 주장("degeneracy가 존재한다")을 **보수적으로** 만드는 쪽이다. 결론을 부풀리는 오류가 아니므로 실행 재개 사유는 아님 |

### F15 — "reference만 완충 시작, 열화군은 완방 프레임 → lli→0 극한 불연속 가능"  → **유보 (PLAUSIBLE 등급 유지)**

| | |
|---|---|
| 지적 | 열화 조건은 완방→CC 4.2 V→rest→방전 경로인데 reference는 `overrides={}`라 완충 baseline에서 시작한다. CC 종지(CV 없음)가 baseline 완충점과 정확히 일치하지 않으면 **전 격자에 공통 β 오프셋**이 생긴다 |
| 판단 | 리뷰어도 PLAUSIBLE로 등급했고, 실측 오차(~1%p) 안에 흡수된 수준으로 보임. 지금 단계에서 결론을 바꾸지 않음 |
| 확정 실험 | `lli=1e-4` 같은 **극소 열화 sanity 조건 1개**를 격자에 추가해 실행하고, 그 조건의 α·β가 reference(α=1, β=0)에 연속적으로 수렴하는지 확인. 불연속이 있으면 그 크기가 공통 오프셋의 크기다 |
| 언제 | Phase 5 진입 전 (조건 1개라 수 초) |

## 4. 리뷰가 확인해준 것 (반박 불필요)

- α = (1−LAM)/r, β 부호 규약, `inventory.py`의 LLI 유도 — **전부 정확**
- 상수 w_PE=0.2909 / w_NE=0.7091 / κ=0.7057 — manifest 실측치와 일치
- `to_modes_halfcell`의 Δ(테이블 구간) 약분 — LAM·LLI 모두 성립.
  잔존하는 것은 **범위 오프셋**뿐이고 ocp 테이블(≈[0,1])에서 1e-4 수준으로 무시 가능
  (단 sim 테이블이면 ε≈2.2 Ah로 크게 틀림 → F11로 가드 추가함)
- truth 라벨 lli와 fitting LLI가 같은 정의 (de-type 격자에서)
- 불능 조건 924개 → 3993−924=3069 계산 재현
- `"Battery negative electrode bulk open-circuit potential [V]"`는 pybamm 소스상
  **흑연(primary) 단독**이지만, LAM_NE가 Gr·Si vf를 같은 비율로 줄이므로
  평형 사상이 모든 셀에서 동일 → affine 관계 보존. 규약 정합 확인
