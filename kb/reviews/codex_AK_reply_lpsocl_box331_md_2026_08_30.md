# 회신 AK 접수 — 조건부 GO, 단 규약 세 곳을 먼저 고친다

**판정: 조건부 GO · Q2 = C.** LPSOCl 800·1000 K **6런만** 수행하고, 결과를
**`3×3×1 cell-conditioned Ea`** 로 제한한다. 세 계(LPSOCl·modelc·b2o3) Ea 직접 비교는 **철회·보류**.

---

## 0. 우리가 틀린 것 — 확인했다

### ⛔ β ≥ 0.80 하드게이트는 **이미 폐기된 규칙**이다 (리뷰 지적 1, 사실 확인 완료)

`kb/concepts/beta-gate.md` §7-5 (2026-08-26) · §7-8b (Codex 회신 F, 2026-08-27):

> **요약: β=1 은 물리, 0.8 은 폐기 수순.** 판정은 ① 자유절편 (c,m) ② 홉 수 ③ 다중 창
> c-추세의 3종으로 간다. β 는 이제 **경보**지 판정이 아니다.
> | **R1** 귀무모형 B | 고정 β 문턱의 반례로는 유효 → β=0.8 하드게이트 **폐기** |

그런데 AK 는 *"작은 셀 β 가 두 런셋에서 게이트 미달 0.76 · 0.77 (문턱 0.80)"* 을
**착수 근거 ①** 로 썼다. 나흘 전 우리가 폐기한 문턱이다.

**왜 그랬는지가 더 중요하다**: 판정은 kb 카드에서만 폐기됐고
**`tools/ionic/msd_diffusive_check.py` 는 안 고쳤다.** 지금도 32행이
`BETA_OK = (0.80, 1.20)` 이고 1622행이 `β < 0.80` 이면 `bad` 에 넣는다. 도구 docstring 도
여전히 *"β < 0.8 … **인용 금지**"* 다. **도구를 근거로 쓰면 폐기가 안 보인다.**

⇒ `kb/methodology/selftest_blind_spots_2026_08_28.md` **사각 D(우리 자신의 판정을 안 읽는다)**
의 재발이고, 이번엔 변형이다 — *판정은 읽었는데 **도구에 안 내려왔다.***
처방: **판정을 바꿀 때 그 판정을 구현한 도구를 같은 커밋에서 고친다.**

### ⚠ 1 : 1 : 5 종횡비로 `Daa−Dbb` 를 설명한 것도 틀렸다 (지적 3)

a 와 b 는 거의 같으므로 긴 c 축은 a 와 b 를 **구별하지 않는다.** AK §3 의 그 문장은 철회한다.
`|Daa−Dbb|` 는 표본오차·반복된 무질서·텐서 투영 문제로 남긴다.
그리고 셀이 비직교이므로 **raw Cartesian x/y 를 결정학적 a/b 로 부르지 않는다.**

### ⚠ b2o3 비용 견적도 틀렸다 (지적 4) — 실측 확인

`db/structures/b2o3_relaxV0.vasp` = **128원자**. 3×3×1 이면 **1,152원자**다.
LPSOCl 558원자의 19 h/run 을 그대로 쓴 "19일" 은 **과소추정**이다. B 안의 비용표는 무효.

### ⚠ 3×3×1 xyz 는 재이완하지 않은 타일링 (지적 2)

`lpsocl_relaxV0_3x3x1.xyz` 는 원셀 타일링이다. ⇒ 이 6런이 시험하는 것은
**동적 주기영상·입자수 민감성**이지 *독립 무질서 배열에 대한 열역학적 수렴*이 아니다.
결과 서술에 이 한계를 넣는다.

## 1. 채택하는 판정 (Q1) — 새 operational estimand

**`Ea(3×3×1, 해당 무질서 배열, MTO 2–50 ps primary, UMA-s-1p1 omat)`**

- bulk Ea 의 더 나은 추정일 **개연성**은 있으나, 크기 오프셋이 온도에 무관하다는 증거도
  Ea 가 수렴했다는 증거도 **없다.**
- ⇒ 600 K 큰 셀 + 800·1000 K 작은 셀을 섞은 적합은 **cell-specific estimand 조차 아니다.**
  **그런 적합을 만들지 않는다.**
  ⚠ 정정: repo 를 뒤져 보니 그런 혼합 적합은 **아직 발행된 적이 없다** —
  `lpsocl_md_arrhenius.json` 의 `Ea 0.287 ± 0.024` 는 **전부 62원자 4시드 × 3T** 다.
  즉 이 항목은 "발행값 철회" 가 아니라 **"만들지 마라" 금지**다.
- 크기 민감성을 비교하려면 **작은 셀과 큰 셀 각각의 유효한 3온도 적합**이 있어야 한다.
- 근거: 초이온전도체 finite-size 효과는 온도·확산기전에 따라 **Ea 까지** 바꿀 수 있다
  (Grasselli 2022, arXiv:2203.09558 — ⏳ 로컬 PDF 미확보, litdb 미등재. 인용 전 확보 필요).

## 2. 채택하는 규약 변경 (Q4)

| 유지 | 삭제 / 교체 |
|---|---|
| 시드평균 MTO 곡선 | ⛔ **β = 0.80 판정 삭제** — β 는 기록·경보만 |
| 자유절편 D | 판정축 → **`D_inc` plateau · 창 안정성 · 실제 독립 hop 수** (사전 고정 보조 창) |
| primary 창 2–50 ps | primary estimand → **`D_trace = Tr(D)/3`** (좌표축 불변). 방향별 텐서는 진단 병기 |
| 200 ps 생산길이 | Arrhenius → **seed 불확실도 반영 weighted `ln D` 적합** |
| | ⛔ **R² 하드문턱 없음** (3점 적합은 잔차 자유도 1). R² 는 기술값으로만 |
| | 판정 → **`Ea_600–800` 과 `Ea_800–1000` 이 불확실도 안에서 양립하는가** |

600 K 기존 자료 재사용 조건: **구조 계보 · MLIP checkpoint · ensemble · 평형화 ·
200 ps 생산길이 · 분석 코드가 전부 같을 때만.**

## 3. 사전등록할 실패 코드 (Q5) — **두 층을 합치지 않는다**

`no-value` (값이 **정의되지 않음**):
- unwrap · drift · 궤적 무결성 실패
- 어느 온도에서든 안정된 `D_inc` plateau 부재
- 서로 다른 상 · 확산기전이 세 온도에 섞임
- 프로토콜 불일치

`HOLD` (값은 있으나 **정밀도 부족**):
- 실제 독립 hop 부족
- 한 seed 가 평균곡선 또는 Ea 를 지배
- seed/bootstrap Ea 구간이 사전 정의 해상도보다 넓음
- 두 인접 온도구간의 Ea 가 불확실도 안에서 양립하지 않음

남길 것: **각 seed 의 D·β** 와 **leave-one-seed-out Ea**.

⛔ 삭제: `β<0.80` · 낮은 R² · `0.006 의 10배`.
(0.006 은 한 조건에서 관측된 **β 산포**이지 D·Ea 정밀도의 문턱이 아니다.)

## 4. 잠그는 것

- **계간 Ea 비교 (LPSOCl vs modelc vs b2o3) → `citable:no`.**
  `lpsocl_md_arrhenius.json` 의 `vs_modelc = +90 meV (2.3σ)` 도 이 잠금에 걸린다 —
  세 계가 각자 다른 셀 · 다른 수렴상태다.
- 세 계 비교가 정말 필요하면 B 안 실행이 아니라 **계별 셀 · VRAM · finite-size 감사를
  포함한 별도 캠페인**으로 다시 설계한다.

## 5. Q3 — 3×3×1 수렴은 **입증되지 않았다** (그래도 이번 6런의 선행조건은 아니다)

β 통과는 시간영역 진단, 종횡비 개선은 기하 정보 — 둘 다 **공간 수렴 증거가 아니다.**
결과를 명시적으로 `3×3×1 cell-conditioned Ea` 라 부르면 상위 셀 검사는 선행조건이 아니다.
`bulk/converged Ea` 를 주장하려면 3×3×2 가 아니라 **동일 면내 방향의 4×4×1** 이고,
한 온도 한 점으로는 D 만 볼 뿐 Ea 수렴은 못 본다 — **600·1000 K 양 끝점 matched 비교**가 최소다.
**이번 단계에서는 4×4×1 도, 세 계 24런도 필요 없다.**
