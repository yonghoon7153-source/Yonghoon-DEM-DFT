# 전기화학 안정성 창(ESW) — 전압별 분해 staircase 완전 해설
### 처음 보는 대학원생용 · comp1(Li₆PS₅Cl) / modelc(Li₅.₄PS₄.₄Cl₁.₆) 예제

> **이 문서가 답하는 질문**
> "고체전해질 Li₆PS₅Cl이 **전압에 따라 어떤 물질로 분해되는가**"를 계산한 계단(staircase) 표 —
> 처음 보면 뭐가 뭔지 모른다. 이 문서는 **그 표가 무엇이고, 왜 그렇게 생겼고, 어떻게 읽는지**를 바닥부터 설명한다.

---

## 1. 큰 그림 — 왜 전해질 "안정성"이 문제인가

배터리 구조: **음극(anode, 낮은 전압)  ―  전해질  ―  양극(cathode, 높은 전압)**.

- 전해질은 배터리가 작동하는 **전압 범위 전체(≈ 0 ~ 4+ V)** 에 노출된다.
- 그런데 대부분의 고체전해질, 특히 황화물 argyrodite Li₆PS₅Cl은 이 전압 범위에서
  **열역학적으로 불안정** — 즉 **더 낮은 에너지의 다른 물질들로 분해되고 싶어 한다.**
- **분해 자체가 무조건 나쁜 건 아니다.** 분해산물이 **안정하고 전자를 안 통하는 막**
  (passivation layer = SEI, Solid-Electrolyte Interphase)을 만들어 **더 이상의 분해를 막으면** OK.
  반대로 산물이 전자를 통하면(전도성) 분해가 **계속** 진행 → 배터리 열화/사망.
- 따라서 **"어느 전압에서 무엇으로 분해되나"** 를 아는 것이 안정성 설계의 핵심이고,
  그걸 그린 게 바로 이 **staircase(계단 그림)** 이다.

---

## 2. 핵심 통찰 ① — "전압"은 곧 "Li의 화학포텐셜"

이 그림을 이해하는 **가장 중요한 한 가지**:

> **전극 전압 V(vs Li/Li⁺)는 그 지점에서 Li 원자가 얼마나 "있고 싶어 하는지"(화학포텐셜 μ_Li)를 정한다.**
>
> $$\mu_{Li}(V) = \mu_{Li}^{\circ}(\text{금속 Li}) - eV$$

직관:
- **V = 0 V** (금속 Li와 접촉, 음극) → μ_Li **최대** → **Li가 넘쳐난다 = Li-rich** → Li가 전해질로 **밀려 들어감(환원)**.
- **V 높음** (양극, 예: 3~4 V) → μ_Li **낮음** → **Li가 빠져나가고 싶어함 = Li-poor** → 전해질에서 Li가 **뽑혀 나감(산화)**.

즉 전압을 바꾸는 것 = **전해질 주변 Li 저장소의 "압력"을 바꾸는 것**. 높은 전압은 Li를 빨아내는 진공펌프,
낮은 전압은 Li를 밀어넣는 공기펌프라고 생각하면 된다.

---

## 3. 핵심 통찰 ② — 왜 "그냥 에너지"가 아니라 "grand potential"인가

전해질은 전극(=Li 저장소)과 **Li를 주고받는다.** 이렇게 **입자(Li)를 저장소와 교환하는 계**의 평형은
그냥 에너지 E가 아니라 **grand potential(대포텐셜) Φ** 를 최소화해서 찾는다:

$$\Phi = E_{\text{tot}} - \mu_{Li}\, N_{Li}$$

- $E_{\text{tot}}$ : 그 상(phase) 조합의 총에너지 (DFT 0 K).
- $\mu_{Li}$ : 위에서 전압으로 정한 Li 화학포텐셜.
- $N_{Li}$ : 그 조합에 든 Li 개수.

**왜 이렇게?** Li를 저장소에서 하나 가져오면 계의 에너지는 오르지만($+E$) 저장소에서 그만큼
$\mu_{Li}$ 를 "지불"받는다($-\mu_{Li}$). 그래서 **Li를 넣는 게 이득인지 손해인지**는 $E$ 가 아니라
$E - \mu_{Li}N_{Li}$ 로 판단해야 한다. (열역학의 grand-canonical 앙상블.)

**계산 절차 (한 문단 요약):**
각 전압 V(→ μ_Li)마다, 가능한 **모든 분해산물 조합**(원소 비율은 보존)에 대해 Φ 를 계산하고
**Φ가 가장 낮은 조합**을 고른다. 그게 그 전압에서 "실제로 존재할" 상들이다. 전압을 쭉 쓸면
이 "최저-Φ 조합"이 **어떤 전압에서 툭툭 바뀐다** → 그 바뀌는 지점들이 **계단(staircase)** 이 된다.
(수학적으로는 조성-μ 공간의 **convex hull**; Mohnsen/Ceder·Zhu 류의 grand-potential 상평형도.)

---

## 4. staircase 읽는 법 — 세 구간

계단은 크게 **세 영역**으로 나뉜다:

| 전압 | μ_Li | 무슨 일이 일어나나 | 대응하는 실제 위치 |
|---|---|---|---|
| **낮음 (→ 0 V)** | 높음 (Li-rich) | **Li 삽입 = 환원.** 모든 원소가 최대로 리튬화 → **Li₃P + Li₂S + LiCl** | **음극**(Li 금속) 접촉면 SEI |
| **OCV (≈ 1.7 V)** | 중간 | Li 순교환 0. **중성 자가분해** → Li₃PS₄ + Li₂S + LiCl | 개방회로(그냥 두면 생기는 분해) |
| **높음 (> 2.1 V)** | 낮음 (Li-poor) | **Li 추출 = 산화.** 음이온이 산화 → 폴리설파이드→S→…→Cl 산화 | **양극**(고전압) 접촉면 |

**각 줄(=계단 한 칸)이 뜻하는 것:** "이 전압에서 전해질(+ 또는 − 몇 개의 Li)이 → 오른쪽 산물들로
분해되는 게 열역학적으로 가장 안정하다"는 **화학반응식**. 왼쪽에 `+ n Li`가 있으면 **환원(Li 흡수)**,
오른쪽에 `+ n Li`가 있으면 **산화(Li 방출)**.

## 5. comp1(Li₆PS₅Cl) 한 줄씩 따라가기 (worked example)

```
0.00 V:  Li₆PS₅Cl + 8 Li → Li₃P + 5 Li₂S + LiCl        ← 음극(Li 금속) SEI
1.24 V:  Li₆PS₅Cl + 5 Li → 5 Li₂S + LiCl + P
1.72 V:  Li₆PS₅Cl       → Li₃PS₄ + Li₂S + LiCl          ← OCV 자가분해(중성)
2.14 V:                 → Li₃PS₄ + 0.25 Li₂S₈ + LiCl + 1.75 Li   ← 첫 산화(S²⁻→폴리설파이드)
2.36 V:                 → 0.5 P₂S₅ + 0.375 Li₂S₈ + LiCl + 1.75 Li
3.06 V:                 → 0.5 P₂S₅ + LiCl + 1.5 S + 5 Li
3.33 V:                 → 0.5 P₂S₅ + 0.5 S + SCl + 6 Li  ← Cl 산화는 맨 마지막
```

- **0.00 V** — 금속 Li가 옆에 있으니 Li가 8개나 **밀려 들어와** 모든 걸 최대로 환원:
  P⁵⁺→P³⁻(**Li₃P**), S는 **Li₂S**, Cl은 **LiCl**. = 음극에서 실제로 생기는 SEI 조성.
- **1.24 V** — Li를 조금 덜(5개) 받아 P가 원소 P로. (환원 정도가 약해짐.)
- **1.72 V (OCV)** — Li 교환 없이 **전해질 스스로** Li₃PS₄ + Li₂S + LiCl로 쪼개짐.
  이게 "그냥 놔뒀을 때"의 분해 = 전해질이 **원래 metastable**(준안정)하다는 뜻.
- **2.14 V (산화 onset)** — 여기서부터 **Li가 빠져나가기 시작**(오른쪽 +1.75 Li).
  **S²⁻가 폴리설파이드(Li₂S₈)로 산화** = **첫 산화**. 이 전압이 **산화 안정성의 한계**.
- **2.36 → 3.06 → 3.33 V** — 전압 올릴수록 산화 심화: P₂S₅ 생성, 폴리설파이드→원소 S,
  마지막에 **Cl⁻까지 산화(SCl)**. **Cl이 가장 늦게 산화** = 산화에 제일 강한 원소.

---

## 6. 안정성 창(ESW) — 이 그림의 결론

- 전해질이 **진짜로 안정한(=분해 안 하는)** 구간은 **OCV 근처의 좁은 창**뿐이다.
- **환원 한계**: 대략 1.7 V 아래로 가면 Li가 들어와 분해(음극쪽 불안정).
- **산화 한계(onset)**: **2.14 V** 넘으면 S²⁻가 산화돼 분해(양극쪽 불안정).
- 따라서 **안정 창 ≈ 0.4 ~ 0.9 V 수준으로 매우 좁다**, 그리고 **그 한계를 정하는 건 S²⁻**
  ("**S²⁻-limited**"). 황화물 전해질의 고질적 약점: 황이 쉽게 산화된다.
- **실전 함의**: 배터리는 0~4 V로 도니까 전해질은 **양쪽 전극에서 다 분해된다.**
  그래서 **분해산물이 좋은(전자 안 통하는) 막을 만드느냐**가 관건 →
  passivation 잘 되면 사용 가능, 안 되면 계속 분해. (도핑·코팅의 존재 이유.)

## 7. comp1 vs modelc — 뭐가 같고 뭐가 다른가

```
modelc (Li₅.₄PS₄.₄Cl₁.₆):
0.00 V:  + 8 Li → Li₃P + 4.4 Li₂S + 1.6 LiCl
1.72 V:        → Li₃PS₄ + 0.4 Li₂S + 1.6 LiCl
2.14 V:        → Li₃PS₄ + 0.1 Li₂S₈ + 1.6 LiCl + 0.7 Li   ← 산화 onset 동일(2.14V), Li 0.7만(comp1은 1.75)
3.33 V:        → 0.5 P₂S₅ + 0.7 LiCl + 0.9 SCl + 4.7 Li
3.39 V:        → 0.459 P₂S₅ + 0.082 PCl₅ + 1.188 SCl + 5.4 Li  ← modelc만의 고전압 Cl 산화
```

- **산화 onset이 2.14 V로 동일** → **창의 한계는 조성(Cl 함량)에 거의 무관**, **S²⁻가 지배**하기 때문.
  (Cl을 늘려도 산화창이 안 넓어진다 = 중요한 결론.)
- **다른 점**: modelc는 산화 onset에서 **Li를 0.7만 추출**(comp1은 1.75) — Li·S 양이 적어서.
  그리고 고전압에서 modelc는 **PCl₅ 같은 Cl 산화상**이 더 나온다(Cl이 많으니).
- **한 줄**: **할로겐 조성(Cl↑)은 산화창을 못 넓힌다** — 창은 S가 정하고, Cl은 맨 마지막 방어선일 뿐.

---

## 8. 이게 실제 배터리에서 뜻하는 것

- **음극쪽(낮은 전압)**: 전해질이 환원 → Li₃P·Li₂S·LiCl. 이 중 **Li₃P는 전도성이라 위험**,
  Li₂O/LiCl류는 절연(passivation). → 음극 SEI 조성 관리가 중요.
- **양극쪽(높은 전압)**: 전해질이 산화 → 폴리설파이드·S·P₂S₅ 등 → 계면저항↑, 용량 손실.
- **passivation이 열쇠**: 분해는 피할 수 없으니, **산물이 wide-gap 절연막**이면 분해가 멈춘다.
  → 이게 **Nd₂O₃ 같은 산소 도핑**의 존재 이유(분해산물을 Li₃PO₄·Li₂O 같은 wide-gap로 유도).
  (연결: `kb/results/nd2o3_O_effect_transfer_2026_06_24.md` — 전도성 누설상 vs 절연 passivation상.)

## 9. 이 계산은 어떻게 만드나 (방법 요약)

1. **원소 상평형 데이터** 준비: Li–P–S–Cl(–O) 계의 모든 알려진 상들의 DFT 총에너지
   (Materials Project 등 + 자체 DFT).
2. 각 전압 V → μ_Li = μ°_Li − eV 로 변환.
3. 그 μ_Li에서 전해질 조성을 보존하는 **모든 분해산물 조합**의 grand potential Φ 계산.
4. **Φ 최소 조합** = 그 전압의 안정 분해산물. (convex hull / linear programming.)
5. V를 쓸며 최소-Φ 조합이 바뀌는 지점 = **계단**. 산화/환원 onset·창 폭이 여기서 나옴.
   (도구: `pymatgen`의 grand-potential phase diagram / interface reactivity; 우리 레포는
   `tools/oxidation/` 계열.)

## 10. 주의점 / 한계 (반드시 알아둘 것)

- **0 K, 순수 열역학**: 온도·엔트로피·**속도론(kinetics) 없음**. "분해될 수 있다"이지
  "즉시 분해된다"가 아니다. 실제로는 kinetic하게 metastable하게 버티는 경우 많음.
- **passivation은 이 그림에 없음**: staircase는 "무엇으로 분해되나"만 말하고, 그 산물이
  실제로 막을 만들어 분해를 멈추는지는 **별도 분석**(산물의 band gap·전자전도성)이 필요.
- **정확도는 DFT 상 데이터에 의존**: 빠진 상이 있으면 창이 틀릴 수 있음.
- **OCV·onset 값은 functional(PBE 등)·μ 기준에 민감** — 절대값보다 **경향·비교**로 인용.

## 용어집

| 용어 | 뜻 |
|---|---|
| **화학포텐셜 μ_Li** | Li 원자 하나를 넣거나 뺄 때의 에너지 변화. 전압으로 조절됨. |
| **grand potential Φ** | 입자를 저장소와 교환하는 계의 "에너지". Φ = E − μN. 이걸 최소화. |
| **OCV** | Open-Circuit Voltage. 전류 안 흐를 때 전해질이 스스로 분해되는 지점. |
| **ESW** | Electrochemical Stability Window. 전해질이 안정한 전압 범위. |
| **SEI** | Solid-Electrolyte Interphase. 전극/전해질 계면에 생기는 분해산물 막. |
| **passivation** | 분해산물 막이 전자를 차단해 **더 이상의 분해를 막는** 것. |
| **폴리설파이드** | Li₂Sₓ (x>1). S²⁻가 산화되며 생기는 중간체. |
| **S²⁻-limited** | 산화 한계를 **황이 정한다**는 뜻(황이 제일 먼저 산화). |
| **convex hull** | 여러 상 조합 중 에너지 최저 경계면. 안정상 판정에 씀. |
