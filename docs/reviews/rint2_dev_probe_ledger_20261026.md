# Rint ② 개발 탐침 사전 원장 — ⑥ SBE 값 봉인 숫자 탐침

- 근거 = Codex 회차 ① 판정 §10 (`docs/reviews/codex_review_rint2_rr_round1_20261026.md` — "⑥ 을 별도 개발 탐침 사전 원장에 넣거나 명시적 예외로 등록") · 수정 계획 `docs/reviews/rint2_rr1_fix_plan_20261026.md` Q5 (가) · 1저자 10-26 *"권고대로해"*.
- 지위 = **결과 0 건** · 첫 시도 전에 이 원장을 커밋한다 (결과 전 커밋).  아래 ⬜ 칸은 첫 시도 전에 채워 다시 커밋한다.
- Q9 설계 §3-5 의 "원장 밖 킷 풀이 금지" (개정 4 · 1저자 10-24 Q1 · Q7) 와의 관계 = 이 원장에 등록된 ⑥ 만 그 금지의 예외다 (Q9 개정 5 · §10).  다른 SBE · DBE 킷 풀이는 그대로 금지.

## 1. ⑥ 이 무엇인가 (등록 R §11 ⑥ · §2-1)

- 실침대 SBE 에서 전처리 · maxiter · 시간 상한을 정하기 위한 **반복 · 메모리 · 비용 탐색**.  등록 R §11: "숫자 탐침 (σ 봉인 · 반복 수 · 잔차 · 판 전류 불균형 · 시간만)".
- 순서 (등록 R :536 · 1저자 10-22 Q2) = S0 단계 1 (SBE 기하) → s_min 개발 단계 → **⑥** → Codex 요청 (기하 + ⑥ 의 실침대 반복 수) → 세 숫자 → 계획 하나 봉인 → S0 단계 2 (DBE) → R 런.
