## 3. 방법 — 내보냄 (렌더 · 자르기 없음)

- 이름 상자 셋 · 화살표 · "300 MPa" 가 모두 그림 하나의 픽셀 안 → media 파일 바이트를 그대로 꺼냈다 (다시 저장 · 렌더 · 자르기 없음 · 덱 media sha256 = 이 파일 sha256).
- 찾기: 덱의 글 (XML 전부) 에 "Random packing" · "Compression" · "Composite cathode" 가 없다 (글이 그림 픽셀 안) → 그림을 열어 보고 7 장 "그림 214" 를 골랐다 · 같은 sha256 그림은 덱에 하나뿐 · 6 장 (3차년도 요약) 의 비슷한 자리 그림은 2D 구조 설계 그림 (다른 그림).
- 확인: LibreOffice 로 덱을 PDF 로 렌더해 7 장을 눈으로 봤다 — 그림 위에 겹친 도형 · 글 없음 (확인용 · 렌더 파일은 리포에 안 넣음).
- 다룬 방식: 업로드 파일을 리포 밖 새 빈 폴더에 복사 · `python3 -I` (python-pptx · zipfile — 절대 경로 · `..` 멤버 거부: 176 멤버 중 0 건) · LibreOffice headless (그 폴더에서 · 따로 만든 `-env:UserInstallation` 프로필).
