## 2. 완료와 남은 것

이번 완료는 정책을 등록 칸·입출력 계약·보류 조건에 연결한 것이다. 실제 충전 manifest나 합격 수치를 동결한 것이 아니다. JSON은 null을 남긴 초안이며 실행기가 읽을 설정 파일이 아니다. 새 계수·새 합격선·연산자 변경을 만들지 않았다. 메모의 제안값은 계획 근거로만 옮겼고 승인된 실행값이라는 표지를 붙이지 않았다.

1저자에게 다음에 받을 최소 묶음: 충전 생성 규약과 씨앗3개/ID, 코드·구성식·경계 핀, 수치/단위 시험 허용폭 프로필, CPU/스레드/메모리 상한, 자료 접근 범위, 동결 승인. 그 전에 Codex가 채울 수 있는 것은 비결과 코드 신원·문서 매핑·합성 시험 설계다. 실제 coords·로그·결과는 요청하지 않는다.
