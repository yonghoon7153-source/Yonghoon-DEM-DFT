# 검토자 인계 자료

먼저 REVIEWER_REPLY_KO.md를 읽고, 근거는 REVIEW_KO.md를 확인하세요. NEXT_LIMITED_VALIDATION_DIRECTIVE_KO.md는 사용자가 채택할 다음 작업 승인 초안이며 이 묶음의 수신 자체는 실행 승인이 아닙니다.

reference/는 수신 원문의 선택 사본입니다. 코드·검증 계획·검토자 도구를 자동 실행하지 마세요. 검토자 도구는 원본 ZIP/이전 수신 자료의 로컬 경로에 의존하므로 이 ZIP 단독 재실행 패키지가 아닙니다. 큰 기준CSV/MPH/과거 전체 기록은 포함하지 않습니다.

이번 수신 검토는 ZIP 무결성·봉인·소스 역치환·기준 자료 식별과 실패/소비 분기의 정적 대조입니다. 후보 기능 시험·native1198·30초 연장은 수행하거나 승인하지 않았습니다. 정적 발견 두 건과 다음 승인 범위를 실측 시험 결과와 구분하세요.

REVIEW_PACKAGE_MANIFEST.json은 이 검토 묶음의 payload 식별입니다. REVIEW_DELIVERY_RECEIPT.json은 ZIP 밖의 검토자 생성 기록이며 원 준비본의 생성 영수증이나 수신 확인 값을 수정한 것이 아닙니다.
