# 07. LAM / LLI — 열화모드 정의

> 이 프로젝트의 모든 축(`--lli`, `--lam-pe`, `--lam-ne`)이 무엇을 뜻하는지,
> 코드에서 어떻게 구현되고 어떻게 역추정되는지를 한 곳에 정리한다.
> 수치는 전부 이 저장소의 `Chen2020_composite` baseline 실측값이다.

---

## 0. 한 줄 정의

| 모드 | 무엇을 잃는가 | 활물질은? | 리튬 재고는? |
|---|---|---|---|
| **LLI** | 순환 가능한 **리튬** | 멀쩡함 | **감소** |
| **LAM_PE** | **양극 활물질** | 감소 | (de면 유지 / li면 동반 감소) |
| **LAM_NE** | **음극 활물질** | 감소 | (de면 유지 / li면 동반 감소) |

셋 다 **분율(0~1)**로 표기한다. `--lli 0.13` = LLI 13%.

## 1. LLI — Loss of Lithium Inventory (리튬 재고 손실)

### 물리

셀 안에서 양극↔음극을 **왕복할 수 있는 리튬의 총량**이 줄어드는 것.
활물질은 그대로인데 셔틀할 리튬만 없어진다. 주된 원인:

- **SEI 성장** — 음극 표면에서 전해질이 분해되며 리튬을 소모해 피막으로 고정
- **리튬 플레이팅** — 금속 리튬이 석출되어 전기화학적으로 죽음 (급속충전·저온)
- 전해질 분해, 가스 발생

### 정의

$$\mathrm{LLI} = 1 - \frac{n_{\mathrm{Li}}}{n_{\mathrm{Li,ini}}}$$

`n_Li` = 양극에 있는 리튬 + 음극에 있는 리튬 (상태와 무관한 보존량).

**이 셀의 실측값**: 완충 상태에서 PE 2.358 Ah + NE 5.748 Ah = **총 재고 8.105 Ah**.
가용 용량(5.720 Ah)의 **1.42배**다 — 재고 전부가 왕복하는 게 아니라
전극 stoichiometry 창 안에서 움직이는 부분만 용량이 된다.

### 코드에서 (`src/modes.py`)

모든 저장소의 초기 농도에 `(1−lli)`를 곱한다.

```python
ne1 *= (1 - lli);  ne2 *= (1 - lli);  pe *= (1 - lli)
```

> ⚠ 음극에만 곱하면 안 된다. 완방 프레임에서는 재고 대부분이 양극에 있어
> 음극만 줄이면 전체 재고의 ~0.1%만 빠져 **사실상 아무 일도 안 일어난다.**
> 모든 저장소를 같은 비율로 줄여야 전체 재고가 정확히 `lli` 비율만큼 감소한다.
> (CHANGELOG Phase 3 참조)

## 2. LAM — Loss of Active Material (활물질 손실)

### 물리

전극 활물질 자체가 **전기화학적으로 죽는 것**. 남은 물질은 멀쩡하지만 양이 준다.

- 입자 균열 (충방전 부피변화 누적)
- 전기적 단절 (도전재 네트워크 이탈, 바인더 열화)
- 전이금속 용출, 표면 상전이(rock-salt)
- 저항성 피막(CEI) 피복

### 정의

$$\mathrm{LAM_{PE}} = 1 - \frac{C_{\mathrm{PE}}}{C_{\mathrm{PE,ini}}}, \qquad
\mathrm{LAM_{NE}} = 1 - \frac{C_{\mathrm{NE}}}{C_{\mathrm{NE,ini}}}$$

`C` = 그 전극의 **총 용량** (∝ 부피분율 × 최대농도 × 두께).

**이 셀의 실측값**

| | 총용량 | 가용용량 대비 |
|---|---|---|
| 양극 (NMC811) | **8.732 Ah** | ×1.527 |
| 음극 (Gr+Si) | **5.925 Ah** | **×1.036** ← 용량 제한 전극 |
| └ 흑연 | 4.947 Ah | |
| └ Si | 0.978 Ah (NE의 16.5%) | |

**음극 제한(NE-limited) 셀**이다. 양극은 1.5배 과설계라 여유가 크다.
→ 이것이 이 프로젝트의 핵심 난점이다. **양극 활물질이 조금 줄어도
전체 용량은 거의 안 변하므로, LAM_PE는 full-cell 곡선에 흔적을 거의 남기지 않는다.**

### 코드에서

```python
# LAM_PE
ov[P_PE_VF]  = b.pe_vf * (1 - lam_pe)              # 활물질 부피분율 감소
ov[P_PE_POR] = b.pe_porosity + b.pe_vf * lam_pe    # 죽은 자리는 공극이 됨

# LAM_NE — Gr·Si를 같은 비율로 줄인다 (모델링 선택)
ov[P_NE1_VF] = b.ne_primary_vf   * (1 - lam_ne)
ov[P_NE2_VF] = b.ne_secondary_vf * (1 - lam_ne)
ov[P_NE_POR] = b.ne_porosity + (b.ne_primary_vf + b.ne_secondary_vf) * lam_ne
```

부피 보존: 활물질이 사라진 자리는 **공극(전해질)** 으로 채워진다.

## 3. li / de 구분 ★ — 죽을 때 리튬을 안고 죽는가

같은 LAM이라도 **활물질이 어떤 상태에서 죽었느냐**로 결과가 달라진다.
32p 그림의 **자물쇠 아이콘**이 이 구분이다.

| 접미사 | 뜻 | 리튬 재고 | 곡선에 나타나는 것 |
|---|---|---|---|
| **`_de`** (delithiated) | **빈 상태**로 죽음 | **보존** | 용량만 축소 (shrinkage) |
| **`_li`** (lithiated) | **리튬을 품은 채** 죽음 | **동반 손실** | 축소 + 이동 (shrinkage + shift) |

### 왜 이게 곡선을 다르게 만드나

`_de`면 죽은 물질이 갖고 있던 리튬이 없으므로, **남은 활물질이 기존 재고를 전부 떠안는다**.
그래서 남은 물질의 농도가 올라간다 — 코드에서 `/(1−lam)` 보정이 그것이다.

```python
if lam_pe_type == "de":
    pe = pe / (1 - lam_pe)      # 죽은 PE는 비어 있었음 → 남은 PE가 재고 전량 보유
```

`_li`면 리튬이 물질과 함께 나가므로 농도 보정이 없다 — 대신 LLI가 동반된다.

> 현재 격자(`grid_fine.yaml`)는 **`de` 전용**이다. `--lam-pe-type both`로 li를 켜면
> **참값 라벨 `lli`가 더 이상 총재고 손실과 같지 않게 되므로** 라벨 정의부터
> 다시 해야 한다 (docs/06_REVIEW_DECISIONS.md §3).

## 4. 곡선에서 어떻게 보이나 (32p)

full-cell 전압 = 양극 전위 − 음극 전위. 각 모드는 두 반쪽셀 곡선을
**서로 다른 방식으로 어긋나게** 만든다.

| 모드 | PE 곡선 | NE 곡선 | 그림에서 |
|---|---|---|---|
| LLI | — | **평행이동(shift)** | 두 곡선의 정렬이 어긋남 |
| LAM_NE | — | **압축(shrink)** | NE 창이 좁아짐 |
| LAM_PE | **압축(shrink)** | — | PE 창이 좁아짐 |

**그런데 full-cell은 이 둘의 차만 관측된다.** 서로 다른 (LLI, LAM_PE, LAM_NE)
조합이 거의 같은 full-cell 곡선을 만들 수 있고 — 그것이 이 프로젝트가 검증하는
**degeneracy**다.

## 5. 어떻게 역으로 추정하나 (α·β)

측정된 full-cell 곡선에서 모드를 뽑는 표준 방법(21p, Birkl 2017)은
**pristine 반쪽셀 곡선을 늘이고(α) 밀어서(β) full-cell을 재구성**하는 것이다.

$$U_{\mathrm{PE}}(x) = f_{\mathrm{PE,ref}}\!\left(\frac{x-\beta_{\mathrm{PE}}}{\alpha_{\mathrm{PE}}}\right), \qquad
U_{\mathrm{full}} = U_{\mathrm{PE}} - U_{\mathrm{NE}}$$

- **α** = 전극 용량 / 셀 용량 비 → **압축(LAM)** 을 담당
- **β** = 창의 시작점 → **이동(LLI)** 을 담당

역환산 (r = Q_degraded/Q_reference):

$$\mathrm{LAM} = 1 - \alpha\,r, \qquad
\mathrm{LLI} = 1 - r\left[w_{\mathrm{PE}}\alpha_{\mathrm{PE}} + w_{\mathrm{NE}}\alpha_{\mathrm{NE}} + \kappa(\beta_{\mathrm{NE}}-\beta_{\mathrm{PE}})\right]$$

유도와 상수(w_PE=0.291, w_NE=0.709, κ=0.706)는 `src/inventory.py`에 있다.

> ⚠ **α는 열화율이 아니다.** α=1은 "열화 없음"이 아니라 "LAM = 용량손실"을 뜻한다.
> 33p 원본의 `lb=[1.00,…]`가 이 지점을 하한으로 못 박아서, 최적화가 하한에 붙으면
> 자동으로 `LAM_PE ≈ LAM_NE ≈ 용량손실`이 나온다 — 22p의 결과 패턴과 정확히 같다.

## 6. 흔한 오해

**❌ "용량이 13% 줄었으니 열화가 13%다"**
용량손실은 세 모드의 **합성 결과**이지 어느 하나가 아니다. 같은 13% 손실이
LLI 13%일 수도, LAM_NE 13%일 수도, 여러 조합일 수도 있다. **그걸 가르는 것이
이 프로젝트의 목적이다.**

**❌ "LAM_PE + LAM_NE + LLI = 용량손실"**
더하기가 성립하지 않는다. 음극 제한 셀에서 LAM_PE는 1.5배 여유 안에서는
용량에 거의 영향이 없고, 반대로 LLI는 거의 1:1로 용량을 깎는다.
**어느 모드가 용량을 지배하는지는 셀 설계(과설계 배수)에 달려 있다.**

**❌ "α < 1이면 열화, α > 1이면 회복"**
α는 셀 용량으로 정규화된 비율이라 용량이 줄면 α가 커진다. §5의 경고 참조.

**❌ "LAM_NE는 흑연만"**
이 셀의 음극은 Gr+Si 복합이고, `lam_ne`는 **둘을 같은 비율로** 줄인다.
Si가 NE 용량의 16.5%를 차지한다. Si만 선택적으로 죽는 경우는 현재 모델 범위 밖.

---

## 7. 이 프로젝트에서의 의미

22p 실험 결과는 `LAM_PE ≈ LAM_NE ≈ 13%, LLI ≈ 17%`였다.
**LAM_PE와 LAM_NE가 거의 같게 나온 것**이 의심의 출발점이다 —
양극과 음극이 우연히 같은 비율로 죽었을 수도 있지만,
**fitting이 둘을 구분하지 못해서 같은 값을 뱉었을 수도** 있다.

이 저장소는 PyBaMM으로 **정답을 아는 곡선 3,069개**를 만들고,
기존 fitting 코드가 그 정답을 복원하는지 채점해서 어느 쪽인지 가린다.
