# D2 소비자 요청서 사전 점검 (2026-10-24)

작성 대상은 `codex_mixer_d2_consumers_request_20261024.md`와 증거 묶음이다. 기준은 `486a57cf58d3e0d93ef79be6aae50968929099c0`, 반입 코드는 `consumers-v3.patch`의 네 파일이다.

- 사용자의 전체 비준은 제시된 설계·정책 방향에 적용했다. 반복 비준 대기로 남기지 않는다. 실제 S1 숫자·코호트·정책 구현·등록·실물 입력의 미완성과 구별한다.
- 개발 readback/D2 pair/계획수만 claimed_fixed 하위 범위로 제안한다. MXD2-01 전체를 verified/closed로 바꾸지 않는다. 구 등록 모드와 공유 파일은 수정하지 않았다.
- 원래 세 제한을 핀의 소비자로 재현하고 실제 덱 계획의 gen1/lab 차이를 기록했다. API 부재 시험 red와 이 물리·계약 반례를 구분했다.
- 독립 v1의 명령 생명주기 반례를 시험 먼저 재현한 뒤 수정했다. 중력 벡터·일관 밀도·천장 검출의 시험 공백과 수정 이력도 보존했다.
- 신규 13메서드·작성자 19변이·구 소비자 회귀·독립 보고·웹앱 v18 렌더를 별도 범위로 기록한다. 조합 수를 고유 덱 수나 실제 런 수로 합산하지 않는다.
- 실제 시뮬레이터·장비 실행은 0건이다. 모든 새 개발 출력은 registered=null 및 execution_authorized=false다. 실물 기하·입자 관측·접촉 증서·정착 해제·확인 런의 인증으로 사용하지 않는다.

패키지 파일 해시는 증거 manifest와 대조한다. 최종 자기 SHA는 commit 후 ZIP 바깥 PIN에 기록하며 본문에 미리 만들지 않는다. 새 쪽지에는 공유 원장 수정 제안 JSON 원문을 포함한다.
