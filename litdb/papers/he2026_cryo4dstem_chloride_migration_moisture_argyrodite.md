## 0. 이 digest 를 읽는 법

이 원고의 축은 **산화가 아니라 수분(가수분해)** 이다. 우리 4축 명명으로는 **B④ moisture** 이고, DFT 부분은 **B⑤ 기전 서술 + 방법 감사 대상** 이다.
*"Cl-rich 가 불리하다"* 를 이 논문으로 인용할 때는 **반드시 "수분 노출에서"** 를 붙인다 — B①(ESW 산화 개시)과는 다른 화학이다.

조성 쌍은 `[Zuo]` 와 **똑같다**: **Cl1.0 = Li₆PS₅Cl = 우리 comp1 명목 조성** · **Cl1.5 = Li₅.₅PS₄.₅Cl₁.₅ ≠ 우리 modelc (Li₅.₄PS₄.₄Cl₁.₆)**. Cl1.5 는 `[Adeli]` 고용한계(x = 0.5)의 끝점이고, 우리 modelc 는 그 한계 **너머**다. 이 둘을 같은 것으로 쓰지 않는다.

논문의 역설은 이것이다 — *"Cl 을 늘리면 반응성 높은 자유 S²⁻(4a/4d)가 줄어드니 수분에 더 강해야 하는데, 왜 더 빨리 무너지나?"*
논문의 답: **표면에서 물이 Li/Cl 를 LiCl 계 산물로 빼내고 → 생긴 Cl 결핍(공공)이 안쪽으로 번지며 → 골격이 비정질화하고 → 팽창·균열이 물길을 더 연다** (연쇄 붕괴 *cascading failure*). Cl1.5 는 Cl 이 움직이기 쉬워서(DFT 장벽 1.3 vs 3.2 eV) 이 고리가 빨리 돈다는 주장이다.
⚠ 이 역설은 *"반응 개시 자리 = 자유 S²⁻"* 모형 안에서만 역설이다. `[Kim26Moist]` DFT 는 개시 자리를 **PS₄ 안의 S(16e)** 로 놓는다 (`Esub` −2.915 vs 자유 S −2.535 eV/O) — 그 모형이면 자유 S²⁻ 가 줄어도 개시가 줄 이유가 없다 (§7c).

## 1. 한 줄 요약

1000 ppm H₂O (이슬점 −20 °C, 25 °C 에서 RH 3.2 %) 노출에서 **Li₅.₅PS₄.₅Cl₁.₅ 는 30 분 만에 투영 면적의 20.8–31.3 % 만 아지로다이트로 남고 44.9–47.2 % 가 비정질 분류** (Li₆PS₅Cl 은 63.2–75 % 잔존 · 비정질 18–35.5 %, 입자 2개씩)이고, STEM-EDS/EELS 로는 **Cl 이 표면으로 몰린 껍질 + Cl 결핍 비정질 내부** 가 보인다. 저자는 이것을 **"표면 반응이 끌어낸 Cl⁻ 바깥쪽 재분배 → 공공 축적 → 격자 붕괴 → 물 침투" 의 되먹임** 으로 해석하고, DFT 로 Cl1.5 의 4a–4d 경로 장벽(**1.3 eV**)이 Cl1.0 의 4a–4a 경로(**3.2 eV**)보다 낮다고 보탠다. 대책으로 DFMS(실란) 표면처리가 −40 °C 이슬점 7 h 노출에서 σ 유지율을 **21 → 36 %** 로, 노출 후 셀의 0.33 C 150 사이클 유지율을 **99.9 %** 로 만든다고 보고한다.

⚠ 단 **DFT 장벽은 관측 시간척도를 설명하지 못한다** — 298 K 에서 1.3 eV 는 3 h 동안 자리당 **N ≈ 1.1×10⁻⁵ 회** 홉이다 (§3h · 논문도 *"cannot account for the observed redistribution timescale"* 라고 자인). 그리고 **3 h 에서 결정질 LiCl(+수화물)은 오히려 Cl1.0 이 34.5–40.2 %, Cl1.5 가 0–1.9 %** 다 (§3d · 본문이 다루지 않는다).

### 4c. 4D-STEM 데이터 처리 (방법 기여의 본체)
1. **전처리**: 타원 왜곡 보정 → 직진빔 중심 정렬 → **웨이블릿 잡음 제거**.
2. **학습 라이브러리**: 후보 상 CIF 로 **멀티슬라이스 시뮬레이션**, 넓은 방위 범위 → 실험과 같은 역공간 좌표·샘플링·검출기 기하로 사상.
3. **Sim2Real 스타일 전이 망**: 실험의 잡음·확산 배경·비탄성·세기 변동을 시뮬레이션에 입히되 **브래그 위치와 라벨은 보존** (데이터 증강).
4. **CNN 분류기** 학습 → 실험 패턴에 적용 → **우세 결정상 1개/픽셀** (여러 상이 겹치면 가장 두드러진 브래그 특징의 상).
5. **결정도 지수** C = I_cryst / (I_cryst + I_resid): 직진빔 2D super-Gaussian 적합 → 중심빔 제외 마스크 → 빈 프레임 평균 배경 차감 → 템플릿 기반 브래그 디스크 검출 → 디스크 자리에 파라메트릭 커널 합 = I_cryst → 음이 아닌 잔차 = I_resid. **상대 비교 전용** (절대 결정 부피분율 아님).

### 5.1 벌크 in situ — "Cl1.5 가 먼저 무너진다" (`Fig. 1a,b` · `Fig. S2` · `Fig. S3` · `Fig. S4`)

Cl1.0 은 1 h 미만에서 (222) 가 안 움직이지만 **PS₄³⁻ 띠는 Cl1.0 도 425 → 417 cm⁻¹ 로 이동** 한다(`Fig. S4` — 속도만 0.22 vs 0.34 cm⁻¹ min⁻¹). ### 5.2 cryo-4D-STEM 워크플로 (`Fig. 1c` · `Fig. S5` · `Fig. S6`)
황화물은 전자빔에 비정질화된다(`Fig. S5`, 미독). 저자는 −177 °C 에서 전류·체류를 골라 **55 e⁻ Å⁻²** 에서도 상동정에 충분한 회절을 얻었다고 하고, `Fig. S6` 을 근거로 *"no detectable additional amorphization"* 이라 쓴다.
⚠ 실독: `Fig. S6` 은 **서로 다른 입자 셋** 에 서로 다른 조건(0.022 nA·2 ms / 0.044·1 / 0.044·2)을 건 것이다. 가장 낮은 선량의 (a) 는 **브래그 점이 전혀 없다** — 그것이 S/N 부족인지, 그 입자가 원래 비정질/다른 방위인지 이 그림으로는 가를 수 없다. **같은 영역의 누적 선량 시리즈(브래그 세기 vs 선량)** 가 없으므로 "빔 손상 없음" 의 직접 증거가 아니다 (§10-②).

### 5.3 "심하게 열화된" Cl1.5 한 입자 (`Fig. 1d–g` · `Fig. S7`)
투영 면적: Li₃PS₄ **35 %**(표면 아래 고리) · LiOH·H₂O **20 %**(투영 중심) · Li₃PO₄ **16 %** · LiCl·H₂O **9.1 %** + LiCl **3.8 %**(바깥) · 잔존 Cl1.5 **8 %** · Li₂S **4.6 %**(고리) · LiOH **3.5 %** (합 100 %). 노출 시간은 **적혀 있지 않다**.
⚠ 실독 두 가지: ① `Fig. 1g` 의 대표 "Exp." 패턴 중 **Li₃PO₄ 는 직진빔 + 확산 후광뿐** 이고 뚜렷한 브래그 점이 안 보인다(16 % 의 근거 패턴). 다른 여러 상의 대표 패턴도 **한 줄짜리 계통열** 이라 비슷한 d 를 가진 상끼리 갈리기 어렵다. ② `Fig. 1e` 의 **입자 바깥 검은 진공에도 색 점이 흩어져 있다** — 진공 픽셀이 분율 분모에 들어가는지 Methods 에 없다. 그리고 ③ 투영 지도의 "중심" 은 **위·아래 표면을 같이 통과한 기둥** 이라 "LiOH·H₂O 가 중심에 있다" 는 "내부" 가 아니라 "투영 중심" 이다 (논문도 *projected* 를 붙인다).

### 5.4 시계열 — 두 조성의 길이 갈린다 (`Fig. 2` · `Fig. S14` · `Fig. S17`) ★
- **Cl1.0 30 min**: 잔존 **75 %**, 열화는 가장자리(Li₃PO₄ 6.5 · 비정질 18 · Li₃PS₄ 0.3). 30 min 에 이미 표면 Li₃PO₄ 가 있다 → 저자는 *"rapid local conversion 과 정합하지만 반응 순서의 직접 증거는 아니다"* 라고 스스로 선을 긋는다.
- **Cl1.0 3 h**: **잔존 0 %**. 바깥→안쪽 **대략 층상**: LiOH 7.9 · LiOH·H₂O 3.9 · **LiCl 15.7 · LiCl·H₂O 18.8** · Li₂S 4.9 · Li₃PS₄ 23.6 · Li₃PO₄ 17.7 · 비정질 7.1 %.
- **Cl1.5 30 min**: 잔존 **20.8 %**, **비정질 44.9 %** (표면·내부 모두 결정도 지수 낮음). LiCl 7.0 % 는 **입자 바깥에 붙은 덩어리**(`Fig. 2e` 실독 — 회색 몸통 왼쪽 위의 보라색 엽). 저자 해석: *"잔존 표면 격자의 Cl 점유가 늘어난 게 아니라, 골격에서 빠진 Cl 이 LiCl 석출물로 모인 것"*. ⚠ 실독: 같은 지도의 **LiOH 5.8 % 픽셀은 대부분 입자 윤곽 밖(배경)에 흩어진 점** 이다 (`Fig. 2e` LiOH 패널 확대) — 배경 픽셀이 분율 분모·분자에 들어간다면 이 칸은 상이 아니라 잡음이다.
- **Cl1.5 3 h**: **잔존 0 %**, **비정질 52.2 %** 가 표면 근처에서 깊은 내부까지. Li₃PS₄ 13.3 → **33.8 %** + 일부 결정도 회복(`Fig. S16`, 미독) → 비정질 티오인산염이 Li₃PS₄ 로 재결정한다고 해석.
- **형상** (`Fig. S14`): Cl1.0 은 가장자리 팽창·면 소실, Cl1.5 는 투영 최대폭 **1102.2 → 1623.6 (30 min) → 1648.9 nm (3 h)** (+50 %, 라벨) + 내부 공극·파편화. ⚠ 30 min · 3 h 영상은 윤곽이 같은데(같은 입자) 미노출 영상은 윤곽이 크게 다르다 — 같은 입자 추적인지 본문에 명시가 없다. 같은 입자를 노출 사이사이 다시 찍었다면 **앞 세션의 누적 선량** 이 뒤 세션의 교란 변수가 된다.
- 🔑 **3 h 에서 두 조성 모두 잔존 0 %** 다. "Cl1.5 가 더 빨리 소비된다" 는 **30 min 지도에서만** 보이고(입자 크기 교락 §3d), 3 h 의 차이는 **산물이 결정질(Cl1.0) 이냐 비정질(Cl1.5) 이냐** 다.

### 5.5 원소 재분배 — Cl 껍질과 결핍 하부 (`Fig. 3` · `Fig. S23` · `Fig. S25` · `Fig. S27`) ★
`Fig. 3a–c` 의 Cl 고리는 시간이 갈수록 뚜렷하다. 부분 열화 단결정 입자의 표면→중심 선 스캔(`Fig. 3d–f`)은 **#1 LiCl 표피 → #3 Cl 결핍 비정질 → #4–#6 결정 내부** 를 한 줄에 보여준다 — **같은 입자에서 회절(구조)과 EDS(조성)를 겹친** 이 논문에서 가장 설득력 있는 그림이다. 반대쪽 표면도 같은 순서라 우연이 아니다 (`figure-read`).
EELS(`Fig. 3g`)에서 O 는 바깥에 몰리고 비정질 내부엔 약하다 → 저자: *"바깥 반응층 수준의 O 혼입은 내부 장거리 질서 소실에 **필요하지 않다**"* → 내부 붕괴는 Cl 결핍·결함 축적이 이끈다는 해석. `Fig. S27` 은 LiCl 단위 하나를 뺀 Cl1.5 셀에서 Li/Cl 공공 옆 PS₄ 가 일그러지는 모형도(4a → 4d → 4a 경로)이고, 캡션이 *"does not independently establish the migration rate"* 라고 스스로 한정한다.
⚠ 실독: O-K 최대는 Li-K·Cl-L 최대 띠보다 **바깥** 이다(§3e). 그 최외곽은 HAADF 에서 어둡고 Li 도 낮다 — O 풍부·Li 빈약한 최외곽이 무엇인지(인산염·황산염·탄소막·극저온 얼음 오염) 대조 없이 정할 수 없다.

### 5.6 NMR — 티오인산 망은 살아 있다 (`Fig. S28`)
Cl1.5 노출 후 **P₂S₇⁴⁻ (5.36 %)** 가 새로 생기고 Cl1.0 에는 없다 → P–S–P 연결이 남은 = *"티오인산 골격이 완전히 분해된 게 아니라 재조직"* 의 근거로 쓰고, 탈황된 PS₄ 의 축합으로 생긴다고 본다(`Fig. S29`, 미독). §3f 의 환경 분율 이동(평균 Cl 이웃 2.96 → 3.13, *우리 산수*)은 본문에 없다.

### 5.7 H₂S — 빨리 끝나느냐, 오래 끄느냐 (`Fig. S30` · `Fig. S31`)
본문: Cl1.0 = 높은 초기 봉우리 후 급감, Cl1.5 = 낮은 초기 속도 + **지속** — *"Cl1.0 의 빠른 초기 가수분해 vs Cl1.5 의 장기 열화"*. 그림의 라벨: **총량은 Cl1.5 가 2.34× 많다** (11.88 vs 5.07 cm³ g⁻¹). HCl 은 검출 안 됨 → 재분배된 Cl 은 응축상(LiCl 계)에 남는다고 본다. ⚠ `Fig. S32` 캡션의 *"relatively weak initial H₂S signal"* 은 Cl1.5 가 5 min 에 이미 ≈170 ppm 인 `Fig. S30` 과 어울리지 않는다 (`figure-read`).

### 5.8 Cl 이동 기전 + DFT (`Fig. 4a–e` · `Fig. S33`–`S35`) ★
서사(p.20–22): Cl1.5 는 Cl 이 **4d 를 우선 점유**하고(Adeli) Li 공공이 많아 **국소 배치 유연성** 이 크다 → 표면 Li⁺ 와 H₂O 가 LiCl 계 산물을 만들며 **표면에 Cl 결핍** → **Cl 화학퍼텐셜 구배가 바깥쪽 재분배를 구동**, 격자 왜곡이 음이온 자리 간 **공공 매개 홉** 을 돕는다.
- **CI-NEB**: Cl1.0 4a–4a **3.2 eV** vs Cl1.5 4a–4d **1.3 eV**. 저자 스스로: *"relative energetic comparisons … they alone cannot account for the observed redistribution timescale"* · *"the migration barrier … does not by itself determine the net direction"* · `Fig. S33` 캡션 *"comparative descriptors of pathway accessibility rather than … absolute room-temperature diffusion rates"*. 그런데 같은 캡션 끝은 *"the calculations **establish** that the anion configuration of Cl1.5 offers a substantially more favorable kinetic pathway"* 로 다시 세게 닫는다.
- **정전위** (`Fig. 4d`, `Fig. S34`): Li/Cl 추출 + LiCl 석출 모형에서 표면 전위가 더 양 → 음이온 Cl⁻ 를 바깥으로 끄는 정전 구동력이라는 해석. `figure-read`: 'After' 곡선은 Z₄ₐ(≈2.9 Å)에서 내려가고 Z₄d(≈5 Å)에서 올라간다. 화살표는 Z₄d → Z₄ₐ.
- **이완**: Cl 제거가 P–S 일부를 늘리고(최대 +0.033 Å) S–P–S 각을 5° 비튼다 → *"chloride vacancies perturb the local argyrodite framework"*.
- **되먹임 고리**: 팽창·공극·파편화 → 물길 → 가수분해·Li/Cl 추출·재분배 가속.

### 5.9 DFMS 처리 (`Fig. 4f` · `Fig. S36` · `Fig. S37` · `Table S2`)
개시 표면 반응을 막으면 Cl 화학퍼텐셜 구배가 약해진다는 논리. 드라이룸(−40 °C 이슬점) 7 h 뒤 EDS 에 Cl 편석 없음, σ 유지 21 → 36 %, 건조 회복 53 → 64 %, 처리 대가 σ 4.50 → 3.34.
⚠ 같은 −40 °C · 7 h 조건의 **무처리 EDS 대조가 없다**. Cl 껍질이 보였던 무처리 지도는 전부 **1000 ppm (−20 °C 이슬점)** 이다. *우리 산수* (ppm·h 를 거친 노출량으로): 처리 시료 ≈127 ppm × 7 h ≈ **890 ppm·h** vs 무처리 3 h 지도 3000 ppm·h (×0.3) · 30 min 지도 500 ppm·h. "처리하면 편석이 안 생긴다" 와 "물이 덜 왔다" 를 이 설계로는 가를 수 없다.

### 5.10 셀 (`Fig. 4g` · `Fig. S38`)
미노출 Cl1.5 셀: 0.1 C 첫 가역 ≈207 mAh g⁻¹, 0.33 C 170 사이클 뒤 172. 노출 무처리 셀: 용량은 낮고 **정규화 유지율은 오히려 높다** → 저자는 *"Cl 풍부 표면 열화산물의 부분 부동태화"* 를 들되 *"further evidence is required"* 라고 단다. 노출 처리 셀: 0.33 C 시작점 대비 **150 사이클 99.9 %**, 무처리 노출 셀보다 용량↑·분극↓. ⚠ `figure-read`: 처리 셀의 0.33 C 용량은 처음 ≈40 사이클 동안 **≈175 → ≈179 로 오르고** 그 뒤 내려온다 — 99.9 % 는 그 오르내림의 결과다. 처리 셀은 **미노출 셀보다 ≈13 mAh g⁻¹ 낮게 시작** 해 170 사이클에서 미노출 셀과 같은 값에 닿는다. 조성당 셀 1개(오차막대 없음).

### 7b. 축 정리 — 이 논문이 우리 어느 상충에 붙나
- 논문 자체 문구: *"a halogen-dependent trade-off between transport optimization and **moisture tolerance**"* (p.4). 이것은 **B④ (수분)** 상충이다.
- 우리 cascade 쪽 경고는 **'산화 안정 ↔ 수송 상충'** 깔때기 발견이고, 그것이 blocking 지표(4 Å 안 Li 비율 · S·Cl 안 셈) 탓일 수 있다는 경고 제안이 미결이다 (`kb/projects/handoff_2026_10_02_evacuation.md` §4). **이 논문은 그 산화 상충을 지지하지도 반박하지도 않는다** — 축이 다르다. 겹치는 것은 *"Cl↑ → σ↑ 이면서 다른 안정성 축↓"* 라는 **부호 모양** 뿐이다.
- 같은 모양의 외부 사례가 하나 더 있다: `[Zhang26ODry]` 건조 O₂ 1 h σ 유지 Li₆PS₅Cl 76.1 % vs **Li₅.₄PS₄.₄Cl₁.₆ 49.4 %** (우리 modelc 명목 조성). ⇒ **B④(대기) 축에서는 "Li₆PS₅Cl 승" 이 두 편에서 같은 방향** 이다. ⛔ 이 둘을 B①(ESW) 문장으로 옮기지 않는다 — 우리 ESW 산화 개시는 comp1 = modelc **2.256 V** 로 같다(S²⁻-limited).

### 7c. 개시 자리 — 이 논문의 '역설' 을 우리 이웃 digest 로 다시 읽으면
- 논문의 역설 전제: Cl 이 늘면 **자유 S²⁻ (4a/4d)** 가 줄어 수분 반응 자리가 준다.
- `[Kim26Moist]` (comp1 그 조성 · 표면 DFT): **첫 반응 자리 = PS₄ 의 S(16e)**, 자유 S 는 PS₄ 가 O 로 바뀐 뒤 **2차 활성화 자리**. `[Hyun25Han]`: 가수분해 구동 = PS₄ S 의 **E_F 근처 비결합 3p** lone pair.
- ⇒ 이 두 편의 그림이면 **자유 S²⁻ 가 준다고 개시가 줄지 않는다** — "역설" 은 할로겐 기전 없이도 일부 풀린다. ⚠ 세 편 다 우리 계산이 아니다. 우리 수분 반응 계산은 0 건이므로 **어느 쪽이 맞다고 우리가 판정하지 않는다**.

### 7d. cascade v7 와의 경계
- v7 카드(`db/properties/cascade_estimand_card_v7_probe_2026_10_01.json`)의 보고량은 **UMA 의 조건부 Li 수송 차이 D_rel(P1/P2; V_common, T\*)** 이고, §2b 가 *"S/Cl 반자리 무질서 셀은 이 카드 밖"* 이라고 못박는다. 이 논문의 주 변수(Cl 4a/4d 배치·Cl 공공)는 정확히 그 **카드 밖** 이다.
- D_rel v6 은 방법상 무효로 닫혔다(`cascade_d_rel_closed_2026_10_01.json`, 자격 0/40). 이 논문의 어떤 수도 그 마감의 재개 조건이 아니다.

### 7e. CEI (Nd 계면 · 실험 쪽 1저자 트랙)와의 접점
- 노출 무처리 셀의 *"정규화 유지율이 더 높다 → Cl 풍부 표면 산물의 부분 부동태화?"* 는 저자 스스로 증거 부족이라 한 **가설** 이다. CEI 페이지에 근거로 옮기지 않는다 (복합양극 조성·코팅도 n/a).

## 10. 비판 — 이 논문의 약한 곳 ★

① **DFT 장벽이 관측 현상의 속도를 못 낸다 — 10 차수.** 298 K · ν₀ 10¹³ s⁻¹ 가정에서 1.3 eV 는 3 h 동안 자리당 **1.1×10⁻⁵ 회**, ≈100 nm 재분배에는 **≈5.5×10⁴ 회** 가 필요하다 (*우리 산수* — 필요한 장벽 ≲0.7 eV). 저자도 시간척도를 설명 못 한다고 자인하지만, `Fig. S33` 캡션 끝과 결론(*"lowers the calculated migration barrier and may facilitate vacancy-mediated lattice destabilization"*)은 그 장벽을 기전 근거로 다시 쓴다. ⇒ 우리 규율(D-2026-09-27)로는 *"Cl1.5 에서 Cl 이동이 쉽다"* 를 이 장벽으로 쓰지 않는다. 시간척도와 맞는 후보는 저자가 나열만 한 **물 매개 · 표면/결함 · 비정질 영역 경로** 다 — `Fig. S23` 5 h 의 균열 따라 늘어선 Cl 이 그쪽을 가리킨다.

② **"빔 손상 없음" 의 증거가 약하다.** `Fig. S6` 은 서로 다른 입자 셋이고 같은 영역 누적 선량 시리즈가 없다. 55 e⁻ Å⁻² 는 가장 굵은 스텝(10 nm) 기준이고 2.67 nm 스텝이면 ≈770 e⁻ Å⁻² 다(*우리 산수*). 지도별 선량이 없다. 이 논문의 핵심 관측량이 **"비정질 분류 면적"** 이라 빔 비정질화가 섞이면 결과 방향과 같은 쪽으로 오염된다.

③ **30 min 핵심 대비의 입자 크기 교락.** `Fig. 2` 의 Cl1.5 30 min 입자는 ≈0.24–0.28 µm, Cl1.0 은 ≈0.5 µm (`figure-read`). 표면에서 시작하는 열화면 작은 입자가 같은 시간에 더 많이 소비된다. `Fig. S17` 쌍(둘 다 ≈0.5 µm)에서도 방향은 남지만 격차가 준다. 조성당 n = 2, 크기 통제·분포 없음.

④ **3 h 결정질 LiCl 이 서사와 반대다.** LiCl + LiCl·H₂O 투영 분율: Cl1.0 **34.5 / 40.2 %** vs Cl1.5 **1.9 / 0 %** (두 입자씩 같은 방향). 결론의 *"Cl1.5 … formation of LiCl-containing surface precipitates"* 는 30 min 지도(7.0 / 6.6 %)에서만 성립하고, 3 h 에는 Cl 껍질(EDS)이 **결정질 LiCl 로 동정되지 않는다**. Cl 이 비정질 Cl 상·결정 크기 이하 상·분류 후보 밖의 상에 있다는 뜻인데 다루지 않는다. Cl1.5 의 Cl 이 1.5 배 많다는 점까지 넣으면 더 이상하다.

⑤ **Cl1.0 DFT 모형이 자기 참고문헌과 어긋난다.** Cl1.0 에 4a–4a 경로만 있다는 것은 4d 가 전부 S 인 정렬 모형이라는 뜻이다. 그 문장에 붙은 **ref 48 = `[Kraft]` 는 Li₆PS₅Cl 의 Cl 이 4d 에 ~62 % 있다고 쓴다**. 실제 Cl1.0 에도 4a–4d 경로가 있다. ⇒ 3.2 vs 1.3 eV 는 **조성 효과 + 경로 효과(≈6.9 vs ≈4.2 Å) + 정렬 모형 선택** 이 한데 섞인 수다. 같은 4a–4d 경로를 Cl1.0 에서 계산해야 조성 효과가 분리된다.

⑥ **NEB 자체의 기록이 부족하다.** 셀 크기·원자 수·전하 상태·이미지 수·스프링·수렴 전부 미기재. `figure-read` 로 Cl1.0 은 이미지 3개에 **라벨 3.2 eV vs 그려진 최대 ≈3.5 eV**, Cl1.5 는 **끝점이 ≈0.6 eV 위** 다 (4d 쪽이 준안정 → 장거리 수송의 유효 장벽은 1.3 eV 아래로 안 내려간다). x 축 단위 없음. 단일 관용 셀로 보이며(`figure-read`) 그러면 공공 농도 1/4–1/6 · 이미지 간 상호작용이 크다. "DFT 입력은 요청 시" 라 검산할 수 없다.

⑦ **정전위 논증은 정량도 규약도 없다.** `Fig. 4d` 세로축에 숫자가 없다. '표면 모형' 인데 z 범위가 0–10 Å 이고 `Fig. S34` 에 진공이 안 보인다(`figure-read`). 부호 규약도 미기재인데, `Fig. S34` 의 음 등치면이 원자핵을 감싸는 모양은 전자 퍼텐셜에너지 규약으로 보이고(*추정*) 그 규약이면 "더 양 → Cl⁻ 를 끈다" 의 방향이 뒤집힌다. 그리고 근본적으로 **공공이 이웃 음이온을 정전적으로 끄는 것은 모든 공공의 일반 성질** 이라, 장거리 바깥쪽 수송의 방향 근거가 되지 않는다 — 저자도 방향은 화학퍼텐셜 구배가 정한다고 썼다.

⑧ **P–S "골격 불안정화" 의 크기가 작고 대조가 없다.** 최대 +0.033 Å (1.6 %)와 각 5° 는 어느 이온결정에서나 공공 옆에서 나오는 국소 이완 크기다. **Cl1.0 에서 같은 계산이 없어서** 두 조성의 차이를 설명하지 못한다. 2.00 Å 에서 시작하는 세로축(`Fig. 4e`)이 변화를 시각적으로 키운다.

⑨ **NMR 의 다른 절반을 말하지 않는다.** Cl1.5 노출 후 PS₄ 주변 환경이 Cl 쪽으로 이동했다(ClS₃ 13 → 6.27 %, Cl₃S 25.84 → 34.2 % · 평균 Cl 이웃 2.96 → 3.13, *우리 산수*). 벌크 평균에서 "Cl 결핍 내부" 신호가 아니다. 선택적 소모로 설명 가능하지만 논문은 P₂S₇⁴⁻ 만 쓴다. Cl1.0 은 성분 % 를 아예 안 적었고 NMR 노출 조건도 없다.

⑩ **O-K 와 Li/Cl 최대의 위치가 다르다.** `Fig. 3g` 에서 O 최대는 Li·Cl 최대 띠보다 바깥 최외곽이다(`figure-read`). 본문은 같은 자리처럼 쓴다. 최외곽 O 의 정체(인산염·황산염·탄소막·극저온 얼음 오염)를 가를 대조(빈 탄소막·미노출 시료 EELS)가 없다. 내부 "O 약함" 도 *"within the detection limits of EELS"* 이고 한계값은 없다.

⑪ **H₂S 정량이 재현되지 않는다.** 명시 조건(20 mg · 6 mL min⁻¹)으로 곡선을 적분하면 라벨의 ≈1/4 이다(*우리 산수*). Cl1.0 꼭대기는 센서 포화로 보이고, 두 측정의 시간 길이가 다르다(≈55 vs 128 min). 본문은 **총량 2.34×** 를 말하지 않고 *"lower initial rate"* 만 강조한다 — 총량은 Cl1.5 가 크다.

⑫ **DFMS 증명의 대조군이 비어 있다.** 무처리 Cl 편석 지도는 1000 ppm, 처리 지도는 −40 °C 이슬점(≈127 ppm) 7 h — 노출량이 ≈0.3 배다(*우리 산수*). 같은 조건 무처리 EDS 가 없다. 건조 회복 후 절대 σ 는 **무처리가 높다** (2.4 vs 2.1). 처리층의 화학(Si–O–Si · CF₂H)은 도식뿐이다. 셀은 조성당 1개이고 **미노출+처리 셀** 이 없어 처리 자체의 효과(σ −26 %)를 가를 수 없다.

⑬ **본문–SI 교차참조 오류.** ⓐ p.6 의 `Fig. S2` ↔ `Fig. S3` 역할이 뒤바뀌었다(§5.1). ⓑ `Fig. S17` 캡션의 패널 문자 배정(a,c,e = Cl1.0)이 그림(a–c = Cl1.0, d–f = Cl1.5)과 다르다. ⓒ Methods 의 EELS 는 S-L·P-L·Li-K 만 적는데 그림에는 Cl-L·O-K 가 있다. ⓓ `Table S1` 마지막 열 머리-값 불일치.

⑭ **분류기 검증이 없다.** 멀티슬라이스 학습 → Sim2Real → CNN 이라는 설계는 좋지만 정확도·혼동행렬·기각 기준·독립 검증 세트가 없다. 후보 상 목록에 **P₂S₇ 계·Li₂SO₄·원소 S·Li₂S₂** 가 없는데 NMR 은 P₂S₇⁴⁻ 를 보고한다 — 후보 밖 상은 가장 가까운 후보나 '비정질' 로 갈 수밖에 없다. 그러면 '비정질' 52–80 % 의 일부는 **분류 후보 밖의 결정상** 일 수 있다. 입자 마스크도 기술되지 않았는데, `Fig. 1e` 와 `Fig. 2e` 에서는 **진공 배경에도 상 라벨이 찍혀 있고** `Fig. 2e` 의 LiOH 5.8 % 는 대부분 그런 배경 점이다 (`figure-read`).

⑮ **"내부 비정질 = Cl 결핍이 원인" 의 인과 방향이 열려 있다.** 저자도 시간 순서를 못 풀었다고 인정한다. 양성자화·탈황으로 먼저 무질서해진 영역이 Cl 을 못 붙잡는 역방향도 같은 스냅숏을 준다(§6).

## 12. 적용 인사이트 ★

1. **"Cl-rich 는 수분에 약하다" 가 두 독립 편에서 같은 방향이다** (이 논문 1000 ppm H₂O · `[Zhang26ODry]` 건조 O₂/CO₂). modelc 를 제조성(드라이룸)까지 말할 때는 **B④ 단서** 를 달아야 한다 — 단 Cl1.5 ≠ modelc(Cl1.6) 이고 둘 다 실험이라 우리 원장 값과 섞지 않는다.
2. **우리 B④/B⑤ 공백의 계산 질문이 하나 더 구체화된다** — *"표면에서 LiCl 단위 하나를 뺐을 때 이웃 Cl 이 4a↔4d 로 들어오는 장벽이 comp1 과 Cl-rich 에서 같은 경로로 얼마나 다른가"*. 할 거라면 보고량 카드(`kb/templates/estimand_card.md`)에 **경로 동일 · 전하 상태 · 셀 크기(≥ 2×2×2 또는 그 대용) · 무질서 배치([Adeli]/[Kraft] 점유) · 홉 수 검산 문턱(~0.7 eV)** 을 결과 전에 적는다. ⚠ 이것은 계획이 아니라 이 논문이 남긴 빈칸의 기록이다.
3. **홉 수 검산 규칙의 교과서적 사례.** "더 낮은 장벽 = 더 접근 가능" 이 차수로 10¹⁰ 모자란 경우 — 1.3 eV 를 상온·시간 단위 현상의 기전으로 쓰면 안 된다는 것을 우리 원고·발표에서 짚을 때 이 편을 쓸 수 있다 (같은 계보: `[Cao26USF]` `[Wu26LiSRev]` 감사, `comparison_vs_ours.md` §J-52 · §J-55).
4. **4D-STEM 결정도 지수 C = I_cryst/(I_cryst + I_resid)** 는 우리 MD 유리/결정 판별(소셀 유리 트랙)과 이름이 비슷하지만 **실험 회절 패턴의 브래그/비브래그 세기 비** 다. 개념만 참고하고 값은 섞지 않는다.
5. **표면 개질 계보 3번째 = 실란(DFMS)** — `[Qian26]` 데칸산(39 % RH) · `[Deng26PS]` 폴리설페이트(13 % RH) · 이 편 실란(−40 °C 이슬점 ≈0.4 % RH). **습도 사다리가 서로 다르다** — 유지율을 한 표에서 순위 매기지 않는다.
6. **"균열면에 Cl 이 모인다" (`Fig. S23`)** 는 우리 DEM·파괴 쪽 이야기(입자 파쇄가 새 반응면을 연다)와 같은 그림이다 — 화학 열화와 기계 파쇄의 되먹임이라는 **서술 틀** 만 가져올 수 있다.

## 13. 인용 가능 문장 (영문 초안)

- "In an unpublished cryo-4D-STEM study at 1000 ppm H₂O (dew point ≈ −20 °C), Li₅.₅PS₄.₅Cl₁.₅ retained only 20.8–31.3 % argyrodite-classified projected area after 30 min, versus 63.2–75 % for Li₆PS₅Cl (two particles per condition), with Cl-enriched surfaces and Cl-depleted amorphous subsurfaces (He *et al.*, manuscript)."
- "The same work reports the Cl-rich composition as the better ionic conductor (4.5 vs 2.3 mS cm⁻¹ at room temperature) but the less moisture-tolerant one, releasing 2.3 times more H₂S in total — a transport–moisture trade-off that is distinct from oxidative stability."
- ⚠ (조건부) "The reported CI-NEB chloride-migration barriers (3.2 eV for a 4a–4a path in an apparently ordered Li₆PS₅Cl model; 1.3 eV for a 4a–4d path in Li₅.₅PS₄.₅Cl₁.₅) compare different pathways, and at 298 K even 1.3 eV corresponds to ~10⁻⁵ hops per site within 3 h (ν₀ = 10¹³ s⁻¹ assumed); room-temperature Cl redistribution over ~100 nm therefore requires surface-, defect- or water-mediated transport."
- "Silane (DFMS) surface treatment raised conductivity retention after 7 h at a −40 °C dew point from 21 % to 36 %, at the cost of a 26 % lower initial conductivity (4.50 → 3.34 mS cm⁻¹)."

## 14. 주의 / 한계 (인용 규율)

- ⛔ **축을 붙인다.** "Cl-rich 가 약하다" 는 **수분 노출(B④)** 문장이다. ESW·산화(B①)·CEI(B③) 문장에 섞지 않는다.
- ⛔ **1.3 / 3.2 eV 를 Cl 수송 속도·접근성의 근거로 단독 인용 금지** — 홉 수 검산과 차수 모순(§3h), 서로 다른 경로, 정렬 모형. 쓸 거면 홉 수 한 줄과 "different pathways" 를 같은 문장에.
- ⛔ **4D-STEM 면적분율을 벌크 상분율로 인용 금지** (논문 자신도 금지). 입자당 1 지도, 조성·시간당 n = 2.
- ⛔ **Cl1.5 ≠ modelc (Cl1.6).** 같은 조성으로 쓰지 않는다.
- ⛔ **우리 MD(Li 수송, UMA)와 같은 표 금지** — 종(Li vs Cl)도 방법(MLIP-MD vs CI-NEB)도 다르다.
- ⛔ **"99.9 %" 는 노출+처리 셀의 0.33 C 시작점 대비** 다 — 미노출 셀보다 낮게 시작한다는 것을 같이 적는다.
- ⛔ **DFMS 의 "Cl 편석 억제"** 는 −40 °C 이슬점 시험이고 같은 조건 무처리 대조가 없다.
- ⚠ **H₂S 절대값(5.07 · 11.88 cm³ g⁻¹)은 재현 안 된다** — 비(2.3×)로만.
- ⚠ **정전위 `Fig. 4d` 는 정량 인용 불가** (눈금 없음 · 부호 규약 미기재).
- ⚠ **미출판 원고** — 심사 전 수치가 바뀔 수 있다. 인용 시 "unpublished manuscript" 표기.
- ⚠ `lee2025_halide_segregation…` 과의 연결은 **현상의 이름(할라이드가 격자를 떠난다)** 까지만 — 그 편은 li2s 트랙(외부 1저자, 해석 잠정)이라 수치를 가져오지 않는다.

## 15. 기법 용어 미니사전

- **4D-STEM**: 수 nm 로 좁힌 전자빔을 시료 위 격자점마다 멈추고 **회절 패턴 전체** 를 찍는다. 실공간 2 차원 × 역공간 2 차원 = 4 차원 데이터. 픽셀마다 "여기는 무슨 결정이 어느 방향으로" 를 알 수 있다.
- **cryo (−177 °C)**: 황화물은 전자빔에 쉽게 비정질화된다. 냉각하면 원자 이동이 느려져 손상 문턱 선량이 올라간다.
- **선량 e⁻ Å⁻²**: 단위 면적에 쏟아진 전자 수. 빔 손상의 1차 척도. 스텝이 프로브보다 작으면 프로브가 겹쳐 실제 선량이 커진다.
- **NBED / CBED**: 나노빔·수렴빔 전자회절. 여기서는 수렴 반각 0.6 mrad 의 거의 평행한 나노빔이라 회절점이 원판(Bragg disk)으로 찍힌다.
- **멀티슬라이스 시뮬레이션**: 결정을 얇은 층으로 잘라 전자파의 전파를 층마다 계산해 회절 패턴을 만드는 표준 계산법. 여기서는 CNN 학습용 라벨 데이터를 만든다.
- **Sim2Real 스타일 전이**: 깨끗한 시뮬레이션 패턴에 실험 특유의 잡음·배경만 입히는 생성 모델. 점 위치(=결정학)는 그대로 둔다.
- **우세상 지도 (dominant-phase map)**: 픽셀마다 가장 강한 브래그 특징의 상 하나만 칠한 지도. 여러 상이 겹친 픽셀의 소수상은 지워진다.
- **결정도 지수 C**: 패턴 세기 중 브래그 점에 속한 몫. 1 에 가까우면 결정, 0 에 가까우면 확산 산란(비정질·무질서·비탄성·잡음). 절대 결정분율이 아니라 **같은 조건 데이터끼리의 상대 비교** 용.
- **HAADF-STEM**: 고각 산란 전자로 만든 영상. 원자번호와 두께에 민감해 무거운·두꺼운 곳이 밝다.
- **STEM-EDS / EELS**: 전자빔이 내는 특성 X선(EDS) 또는 전자가 잃은 에너지(EELS)로 원소를 본다. Li 는 EDS 로 거의 못 보고 EELS **Li-K (≈55 eV)** 로 본다. Cl-L ≈200 eV, S-L ≈165 eV, P-L ≈132 eV, O-K ≈532 eV.
- **투영 (projected)**: 투과전자 영상은 두께 방향을 다 더한 그림자다. 지도 "중심" 픽셀은 입자 위·아래 표면도 지나간다.
- **³¹P MAS NMR**: P 핵의 화학적 환경을 본다. 아지로다이트에서는 PS₄ 주변 4 개 음이온 자리(Cl/S)의 조합(Cl₄ · Cl₃S · Cl₂S₂ · ClS₃)이 봉우리를 가른다. P₂S₇⁴⁻ 는 두 PS₄ 가 S 하나를 공유한 이량체.
- **4a / 4d 자리**: 아지로다이트 F-43m 의 음이온 자리. 한쪽이 주로 Cl, 다른 쪽이 주로 '자유' S²⁻ (PS₄ 에 안 묶인 S) 인데, Cl 이 섞여 들어가는 정도가 **자리 무질서** 다 (Li₆PS₅Cl ~62 %, Cl1.5 에서 더 큼). 논문마다 4c/4d 라벨이 원점 설정에 따라 다르다.
- **CI-NEB**: 처음·끝 구조 사이에 이미지를 줄지어 놓고 용수철로 이어 최소에너지 경로를 찾는다. 가장 높은 이미지를 안장점으로 밀어 올리는 것이 climbing image. 이미지가 적으면 곡선 모양·최대점이 거칠다.
- **홉 수 검산**: Γ = ν₀·exp(−Ea/kT) 로 초당 홉 횟수를 차수만 잡는 것. 10¹³ s⁻¹ 은 가정이다. 확산계수가 아니라 "이 장벽으로 이 시간에 몇 번 뛸 수 있나" 를 본다.
- **평면평균 정전위**: 3 차원 퍼텐셜을 xy 평면에서 평균해 z 의 함수로 그린 것. 슬랩이면 진공에서 평탄해져 일함수 기준이 된다. 부호 규약(φ 냐 전자 에너지 −eφ 냐)을 적어야 "양/음" 이 무슨 뜻인지 정해진다.
- **이슬점 · ppm · RH**: 1 atm 에서 1000 ppm H₂O = 수증기 분압 101 Pa = 이슬(서리)점 ≈ −20 °C = 25 °C 에서 RH 3.2 %. 드라이룸 −40 °C 이슬점 ≈ 127 ppm (≈0.4 % RH). 배터리 공장 기준은 보통 −40 ~ −60 °C.
- **DFMS**: (difluoromethyl)trimethylsilane, Me₃Si–CF₂H. 물과 만나 Si–O–Si 망을 만들 수 있는 실란. 여기서는 SE 입자 표면 소수성 부동태층의 전구체로 쓴다.
