## 4. 고친 뒤 남는 한정 (본문에 적은 자리)

- 세 단 수치 오차 구간은 추정이다.  두 항 오차가 서로 지우면 극한을 놓친다 (단계 3 "해상도와 수치 오차" 의 손 반례 · 8 셀 런을 같이 적는 까닭).
- 숫자 (δ · 여유 · 배수 · 자격 숫자 · 등급 경계 · 마찰 0.5 · 대조 항목의 띠) 는 모두 봉인 전이다 (§5 Q7).
- F 대조를 여는 조건은 비준 전이다 (§5 Q6).  24 셀 단의 비용과 CPU 처리량은 재지 않았다 (§5 Q8 · §4-2).
- 3b 의 Φ_d 고정은 CB22 의 측정 면적 근거에 기대고 CB20 의 정의는 [미확인] 이다 (단계 3 · 3b).
- U5 (c) ③ 은 속도 기반 접촉을 전제한다 (벌칙력 구현이면 바꿔 등록).
- 색칠의 안전은 실행 중 검사가 인증한다.  K 와 메모리는 산술이다 (단계 1).
- σ_y* 는 작은 상자에서 자격을 확인한 조건부 보정값이다.  최종 상자의 12 셀은 확인할 수 없다 (단계 4).
- D2 · D3 의 읽기는 랩 표준의 원측정 (측정 상태 · 입경) 전까지 둘이다 (§5 Q9).
- 단계 5 의 판정과 신호 규칙은 따로 등록한다 (판정문 228 행).
- TH26 의 원문 제목과 LA25 의 영문 제목은 [미확인] 이다 (부록 C).
- 3.1 에서 온 카드 값은 다시 대조하지 않았다.  zunker2025 칸만 출판본 판 카드로 다시 봤다 (부록 B 끝 줄).
