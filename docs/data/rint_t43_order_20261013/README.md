## 3. 읽는 법 · 한정어

- **바뀌는 것은 혼합 종류 (AM_S · AM_P) 렌즈 셀의 라벨뿐** — 이 침대 · 격자에서 브리지 셀의 sid 변화 0 · AM 마스크 변화 0 (RINTV-02 꼴의 격자 경계 반올림 뒤집힘은 관측되지 않았다 —
  그 반례는 일부러 경계에 놓은 합성 셀이다).  case15 는 AM 종류가 하나 (AM_P) 라 sid 가 안 바뀐다 (pid 만).
- **σ_OFF: 파일 순서 π₀ 가 다른 일곱 순서보다 모두 크다 (−0.086 % … −0.338 %).**  real_14 scaffold 는 AM_P 36 행이 먼저 · AM_S 421 행이 뒤다 (실측) — π₀ 에서는 바뀌는 294 셀이
  전부 나중 행 AM_S (sid 1 · σ 0.010) 가 되고 역순에서는 전부 AM_P (sid 2 · σ 0.005) 가 된다 (실측 · π₁) — 그래서 파일 순서가 σ_OFF 를 위쪽으로 고정한다 (기전은 이 실측까지 · 다른 침대는 σ 안 잼).
  ⚠ 생산 침대의 입력 순서 = 덤프 행 순서 · 생산 덤프도 AM_P 가 먼저인지는 **확인 안 함**.
- 크기의 뜻: AM-only 침대 · vox 0.4 에서 legacy OFF σ 의 행 순서 의존 = 최대 0.34 % (합성 혼합 쌍 반례 4.74 % 보다 한 자릿수 작다).  첨가제 · SE 가 있는 생산 침대 · vox 0.15 · 다른 침대의 σ 크기는
  **이 컨테이너에서 재지 않았다** (등록 §2 — 생산 기계 몫).  셀 비율은 vox 0.15 에서 더 크다 (real_14 6.7e−4 · kit 2.8e−4) — σ 영향은 미측정.
- pid (입자 번호 · je 입자별 전류) 는 같은 종류 렌즈 · 같은 종류 쌍 브리지 (soft = (i, j) 의 j) 에서도 바뀐다 — v3 §1 의 "je 정의 그대로 (의도한 분리)" 범위 · 크기 = 위 표.
- 틀 한정 (T4-1 과 같음): 생산 MPM 프레임과 원점 위상 미확인 · 비주기 · dilate_z 1 · 첨가제 없음 — 통계 대표성만.
