## Q1. β 게이트의 귀무분포 — 내 결론이 너무 센가?

### 배경

MLIP-MD(UMA-s-1p1, Langevin NVT, 200 ps, dt 2 fs, 프레임 저장 0.1 ps)로 Li 확산계수를 낸다.
MSD 를 **창 2–50 ps** 에서 직선 맞춤해 `D = slope/6`. 인용 게이트로 log-log 기울기

```
β = d log MSD / d log t   (같은 창)
```

를 재서 **β ∈ [0.8, 1.2]** 만 통과시킨다 (β≈1 = Fickian).

### 실측 — 21런 중 8런 탈락

계는 62원자 셀에 **Li 27개** (b2o3 만 128원자 / Li 58). 시드 3개씩.

| 계 | 600 K | 700 K | 900 K |
|---|---|---|---|
| b2o3 | — | 0.96 / **0.74** / 0.88 | 1.06 / 0.90 / 0.92 |
| lpsocl | 0.96 / 0.83 / **0.71** | **0.74** / **0.74** / 0.85 | **0.78** / **0.70** / 0.86 |
| modelc | — | **0.58** / 0.93 / 0.81 | 0.87 / **0.79** / 0.84 |

⚠ 탈락한 8런의 **창끝(50 ps) MSD 는 24.7 ~ 137.6 Å²** 다. 즉 이온은 많이 움직였다.
(우리 통계부족 게이트는 MSD < 3 Å² 이고, 전부 그 위다.)

### 내가 한 검정

"β 0.74 는 임계 0.80 바로 아래니까 표본이 적어서 생긴 잡음 아닌가" 를 의심해서,
**케이지가 0 인 이상 브라운 운동**을 같은 조건으로 만들어 같은 추정기로 β 를 쟀다.

합성 방법 (`tools/ionic/beta_null_test.py`):
```python
D_a2_ps = D_cm2_s * 1e4                      # cm²/s → Å²/ps
sigma   = sqrt(2 * D_a2_ps * dt_ps)          # 축당 스텝 표준편차
steps   = rng.normal(0, sigma, (n_frames-1, n_li, 3))   # ← 스텝이 서로 독립
pos     = cumsum(steps)                      # 원점 = 첫 프레임 (단일 시간원점)
msd     = (pos**2).sum(-1).mean(-1)          # 이온 평균
β       = polyfit(log t, log msd, 1)[0]      # 창 안에서
```

n_li 27 · n_frames 2001 · dt 0.1 ps · D 1.5e-5 cm²/s · 400회:

| 창 [ps] | β 중앙값 | 5–95 % | **β < 0.8 비율** |
|---|---|---|---|
| **2–50** | 1.006 | 0.86–1.14 | **1.0 %** |
| 10–50 | 1.013 | 0.78–1.22 | 7.8 % |
| 25–100 | 1.008 | 0.77–1.26 | 10.5 % |
| 50–200 | 1.004 | 0.76–1.26 | 10.5 % |

(n_li 58 로 하면 2–50 에서 0.0 %, 50–200 에서 5.0 %.)

### 내 결론 (검증해 달라)

> 창 2–50 에서 이상적 확산은 β<0.8 을 1 % 밖에 안 밟는다. 관측된 0.58–0.79 는 전부
> 5퍼센타일 아래다 → **표본 부족이 아니라 진짜 sub-diffusion 이다.** 게이트는 정상 작동했고
> 탈락 8건은 정당하다.
>
> 부수: 창 50–200 에서는 이상적 계도 10 % 가 β<0.8 이므로 **늦은 창의 β 로 '구제' 판정을
> 하면 안 된다.**

### ⚠ 내가 의심하는 점 — 여기를 봐 달라

내 귀무모형이 **실제보다 너무 깨끗해서** 1.0 % 가 과소평가일 수 있다. 두 가지가 빠져 있다:

1. **스텝 간 상관이 없다.** 실제 MD 프레임은 속도 자기상관·케이지 진동 때문에 연속
   프레임이 상관돼 있다. 합성은 완전 독립 가우시안이다.
   → **유효 표본 수가 실제보다 많다** → β 분포가 좁게 나온다.
2. **이온 간 상관이 없다.** 실제 셀에서는 운동량 보존, 상관 홉핑(correlated/collective
   hopping), 공통 질량중심 드리프트가 있다. 합성 이온 27개는 완전 독립이다.
   → 같은 방향의 편향. 특히 CoM 드리프트는 **모든 이온에 공통**이라 이온 평균으로
   안 지워지고 MSD 에 t² 항을 얹는다.

**요청**:
- 위 두 편향의 **방향과 대략의 크기**를 판단해 달라. 예컨대 Ornstein–Uhlenbeck 케이지 성분
  (진동 진폭 ~0.5 Å, 상관시간 ~1 ps)이나 공통 드리프트를 얹으면 β 의 5–95 % 폭이
  얼마나 벌어지나? 1 % 가 5 %, 10 % 로 커지나?
- 만약 실질적으로 커진다면 **내 결론을 어떻게 고쳐 써야 하나?** 지금 문장은
  "진짜 sub-diffusion 이다" 인데, "표본 잡음만으로는 설명이 안 된다" 정도로 낮춰야 하나?
- 더 나은 귀무모형이 있나? (예: **같은 계의 통과한 런에서 블록 부트스트랩**으로 귀무를
  만드는 쪽이 합성보다 정직한가? 그러면 "통과한 런" 을 귀무로 쓰는 순환이 생기나?)
- **더 근본적으로**: MSD 크기가 24–138 Å² 인데 β<0.8 인 상태를 물리적으로 뭐라고
  불러야 하나? "케이지" 는 분명 아니다(많이 움직였다). 이질적 동역학(빠른/갇힌 부분집단)
  이라는 해석이 맞나, 아니면 다른 이름이 있나?

## Q2. 셀 확대 사다리 — 1시드로 '단조 증가'를 주장할 수 있나?

### 배경

같은 캠페인의 다른 계(comp1, Li₆PS₅Cl 52원자/Li 24)는 **시간으로는 못 닫혔다**:

| T | 200 ps β | **1600 ps β (8배, 같은 시드)** |
|---|---|---|
| 600 K | 0.64 | **0.37** ← 더 나빠짐 |
| 800 K | 0.31 | 0.61 (미달) |
| 1000 K | 0.69 | **0.97** ✅ |

그래서 남은 가설을 "**62원자 셀에 Li 24개라 표본이 없다**" 로 잡고, **셀 확대 사다리**를 건다:

| 셀 | 원자 | Li | β |
|---|---|---|---|
| 1×1×1 | 52 | 24 | **0.64 (기준선, 기존 런)** |
| 2×1×1 | 104 | 48 | ? |
| 2×2×1 | 208 | 96 | ? |
| 2×2×2 | 416 | 192 | ? |

전부 **600 K · prod 200 ps · 시드 1개(seed 2)** · 창 2–50 고정. 총 ~22 GPU-시간.
타일링이 밀도를 안 바꾼다는 건 코드가 검산한다 (n_Li 2.3608e22 cm⁻³ 불변).

### 판정 규칙 (내가 코드에 박아 둔 것)

- β 가 Li 수에 따라 **단조 증가**하고 192에서 ≥0.80 → 가설 성립. 원인은 통계였다.
- β 가 0.65 언저리에서 **평평** → 가설 기각. 셀 확대도 답이 아니다 → MSD 를 접고
  **홉 통계**(hop counting)로 간다.

### ⚠ 내가 의심하는 점

1. **칸당 시드 1개로 '단조'를 말할 수 있나?** 같은 조건 시드 산포가 얼마인지가 관건인데,
   위 21런 표를 보면 같은 (계, T) 안에서 β 가 예컨대 lpsocl T900 은 0.78/0.70/0.86 —
   **폭 0.16** 이다. 사다리에서 기대하는 신호(0.64 → 0.80, 폭 0.16)와 **같은 크기**다.
   그러면 1시드 사다리는 **신호와 잡음이 구별 안 되는 설계** 아닌가?
   → 칸당 2~3시드로 가야 하나? 그러면 비용이 2~3배(22 h → 44~66 h)다.
   → 아니면 **양 끝만(1×1×1 과 2×2×2) 3시드씩** 재는 게 같은 비용에 더 결정적인가?

2. **기준선 0.64 가 다른 런에서 왔다.** 사다리는 새 스크립트·새 OUTROOT 인데
   기준선은 예전 comp1_seeds 런이다. 프로토콜은 같다고 적혀 있지만
   (UMA-s-1p1/omat, Langevin, dt 2 fs, friction 0.02, equilib 5 ps, prod 200 ps, 창 2–50),
   시드가 같은지도 확실하지 않다. **기준선을 사다리 안에서 다시 재야 하나?**
   (1×1×1 을 같은 스크립트로 한 번 더 = +3 GPU-시간.)

3. **가장 걱정되는 것 — 기각 조건이 틀렸을 수 있다.**
   만약 진짜 물리가 "이질적 동역학(빠른 Li + 갇힌 Li)" 이라면, 이온을 8배로 늘려도
   **β 는 안 오른다**(더 정확하게 측정될 뿐 여전히 <1). 그런데 내 규칙은 그걸
   "가설 기각 = 셀 확대도 답이 아니다" 로 읽는다.
   → 그 경우 **β 가 안 오르는 것이 오히려 물리를 확인해 준 것**인데, 내 규칙은
     그걸 실패로 부른다. 규칙을 어떻게 고쳐야 하나?
   → 구별하는 방법이 있나? (예: β 의 **산포**가 이온 수에 따라 줄어드는지를 같이 보면,
     "값은 그대로인데 산포만 줄었다" = 진짜 물리, "값도 산포도 그대로" = 뭔가 다른 문제,
     로 갈릴까?)

## Q3. BVSE 논증 — 내가 부호를 거꾸로 봤나?

### 배경 (원고에 들어갈 문장의 근거)

Bond-valence site energy:
```
BVS(r) = Σ_j exp[(R₀ − r_j) / b]        b = 0.37 Å
BVSE   = (BVS − 1)²                      (Li⁺ 이상 원자가 = 1)
softBV R₀:  Li–S 2.105 · Li–Cl 2.249 · Li–O 1.466 Å
```

우리 실측에서 **역전**이 있다:

| 계 | BVSE 장벽 | σ (MD·Nernst–Einstein) |
|---|---|---|
| LPSCl1.6 | 높음 | 높음 |
| **LPSOCl (+O 치환)** | **더 낮음 (좋아 보임)** | **더 낮음 (나쁨)** |

### 내가 쓴 설명 (검증해 달라)

> R₀(Li–O) = 1.466 Å 로 S·Cl(2.105·2.249)보다 훨씬 짧다. Li–O 는 짧은 거리에서 BVS = 1 을
> 만족하므로 **O 주변에 BVSE 가 낮은 우물이 생긴다** → 경로 최고점을 낮춘다(BVSE 개선).
> 그런데 그 깊은 우물이 곧 **트랩**이라 홉 빈도가 떨어진다 → σ 는 나빠진다.

### ⚠ 내가 의심하는 점

**부호가 거꾸로일 수 있다.** R₀ 가 짧다는 건 BVS 가 거리에 따라 **더 빨리 떨어진다**는
뜻이기도 하다. 통상 격자 거리(Li–O 실제 배위 거리 ~2.0 Å)에서는

```
exp[(1.466 − 2.0)/0.37] = exp(−1.44) ≈ 0.236
exp[(2.105 − 2.4)/0.37] = exp(−0.80) ≈ 0.451     (Li–S, 실제 ~2.4 Å)
```

즉 **O 하나가 기여하는 원자가가 S 하나보다 작다.** 그러면 O 주변에서 BVS 가 1 에
도달하려면 배위수가 더 많아야 하고, 거리가 더 짧아야 한다. 이게 "깊은 우물" 이 되는지
"오히려 under-bonding 이라 BVSE 가 높아지는지" 가 나는 확신이 안 선다.

**요청**:
- 위 BVSE 정의에서 **R₀ 를 줄이면 최소 BVSE 자리가 어디로 가고 우물이 깊어지나 얕아지나**를
  정량적으로 보여 달라. (예: 배위수 4, 등거리 r 인 단순 모형에서 BVS(r)=4·exp[(R₀−r)/b] 로 놓고
  BVSE(r) 를 R₀ = 1.466 vs 2.105 에 대해 그려 비교.)
- 내 설명이 틀렸다면, **LPSOCl 의 BVSE↓ / σ↓ 역전을 어떻게 설명해야 하나?**
  대안 후보: ① 경로 병목의 기하가 바뀐 것(O 가 작아서 통로가 넓어짐) ② BVSE 가 강체격자라
  O 도입으로 커지는 격자 완화 차이를 못 봄 ③ 캐리어/연결성 효과 ④ R₀ 계열이 달라
  **애초에 계 사이 비교가 성립 안 함**.
  ④ 가 맞으면 원고에서 "역전" 이라는 표현 자체를 빼고 "비교 불가" 로 써야 한다.

⚠ 이 답이 원고 문장을 결정한다. **틀린 설명을 그럴듯하게 쓰는 것이 최악**이니
확신이 없으면 없다고 말해 달라.

## Q4. MTO 는 β 의 기댓값을 못 올리나? · 판정바닥의 ddof

### Q4-a. MTO (다중 시간원점)

우리 MSD 는 지금 **단일 시간원점**이다(원점 = 첫 프레임). 다중 시간원점(MTO)
```
MSD(τ) = ⟨|r(t₀+τ) − r(t₀)|²⟩_{t₀, ions}
```
을 붙이면 같은 MD 에서 표본이 늘어난다.

위 21런에 MTO 가 (사고로) 안 들어갔는데, 나는 **"MTO 가 있었어도 이 8건을 못 살렸다"**
고 판단했다. 근거: *MTO 는 β 추정의 **분산**을 줄이지 **기댓값**을 올리지 않는다.*

**⚠ 이 주장이 하중을 받는다.** 검증해 달라 —
cage→diffusion 크로스오버가 있는 계에서, 시간원점을 평균하면 log-log 기울기의
**기댓값 자체**가 바뀌나? (내 직관: MSD(τ) 곡선 자체는 정상 과정이면 원점에 무관하므로
기댓값은 안 바뀐다. 다만 실제 궤적은 정상성이 완전하지 않고, 특히 **첫 프레임이
평형화 직후**라면 단일 원점 MSD 가 계통적으로 편향될 수 있다 — 우리는 equilib 5 ps 후
prod 를 시작한다.) 이 예외가 실질적인가?

### Q4-b. 판정바닥의 ddof (SDCP 자리 선호)

별개 축이지만 같은 종류의 문제다. UMA 흡착에너지로 "이 분자 조각이 Li 자리를 좋아하나
Ni 자리를 좋아하나" 를 판정한다. 같은 자세로 짝지은 대조쌍을 **방향(down_dir) 단위로 접어**
방향별 중앙값 `dl` 을 얻고, 그걸로 판정한다.

```python
floor  = max(0.030, np.std(dl))          # ⚠ np.std 기본 ddof=0 (모집단)
med    = np.median(dl)
se_med = 1.2533 * np.std(dl) / sqrt(n)   # 정규분포 중앙값의 점근 표준오차
margin = abs(med) - floor
# margin < se_med 면 MARGINAL(판정 보류)
```

실제 데이터 (eV):

| 케이스 | dl (방향별 중앙값) | n |
|---|---|---|
| ptfe_c10 freeze 1.00 | −0.014, 0.010, 0.034, 0.045, 0.050 | 5 |
| ptfe_c10 freeze 0.85 | −0.008, 0.013, 0.031, 0.045, 0.045 | 5 |
| ptfe_dimer freeze 0.85 | 0.008, 0.016, 0.017 | 3 |

내 계산 (ddof=0):

| 케이스 | 중앙값 | std | 바닥 | 마진 | se_med | 판정 |
|---|---|---|---|---|---|---|
| c10 f1.00 | +0.034 | 0.0239 | 0.030 | **+4.0 meV** | ±13.2 | MARGINAL |
| c10 f0.85 | +0.031 | 0.0203 | 0.030 | **+0.8 meV** | ±11.3 | MARGINAL |
| dimer | +0.016 | 0.0040 | 0.030 | −14.0 meV | — | 미해결 |

**요청**:
1. `np.std` 를 **ddof=1** 로 바꾸면 `floor` 와 `se_med` 가 둘 다 커진다. 위 세 케이스의
   판정이 바뀌나? 어느 쪽이 방법론적으로 옳은가?
2. `se_med = 1.2533·σ/√n` 은 **정규분포 중앙값의 점근** 표준오차다. n = 3~5 에서 써도 되나?
