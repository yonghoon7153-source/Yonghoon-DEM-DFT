# v0.8 — 용어를 필드 규약으로 통일 + 주간보고 요약 그림 (2026-09-21)

> 모델·수치는 그대로. "끈적함 / 덩어리 / 눈금" 을 **van der Waals 응집력 · 응집체 · 평가 셀**로 바꾸고, 교수님 보고용 요약 그림(a·b·c)을 얹었다.

## 쉬운 판

> ⚠ **세대 표지 (2026-09-27 · Codex HB-01)** — 이 판은 **09-21 재설계 (3 상 · 소재 지름 · 벽 타입 · ÷135 영률 · 절대 Bo) 이전의 옛 덱** 기록이다.  수치 · 그림은 현 캠페인의 것이 아니다 — 현 정본 `docs/reviews/mixer_layered_prereg_20260921.md`. 여기 나오는 *"Bo 3.0 = 문헌 앵커 (hare2026)"* 는 **철회된 라벨**이다 (R-4, 09-22 — 코드 Bo 와 문헌 pull-off Bo 는 규약이 달라 현 `LA` 는 내부 기준점 Bo_code 3.0 = Bo_po 0.444).

이 페이지의 쉬운 판까지 포함해 표현을 필드 용어로 통일했다. 응집의 기원은 **van der Waals 분산력**이고(정본 §19),
모델에서는 SJKR 접촉 부착력으로 표현하며, 크기는 Bond 수 `Bo = 응집력 / 입자 무게` 로 문헌 앵커에 건다
(hare2026 NMC622, Bo ≈ 3). 코팅은 AM 표면 물성을 SE 로 치환하는 것이라 Bo 0.02 로 떨어진다.

요약 그림: (a) 코팅 전 AM(Bo 21)은 응집체가 드럼과 함께 강체 회전, (b) SE 코팅(Bo 0.02)은 자유 유동,
(c) 층상 투입 후 8 rev 의 Lacey 혼합지수 — 평가 셀을 입자 스케일로 조이면 무코팅만 응집체가 남는다.

## 자세한 판

> ⚠ **세대 표지 (2026-09-27 · Codex HB-01)** — 이 판은 **09-21 재설계 (3 상 · 소재 지름 · 벽 타입 · ÷135 영률 · 절대 Bo) 이전의 옛 덱** 기록이다.  수치 · 그림은 현 캠페인의 것이 아니다 — 현 정본 `docs/reviews/mixer_layered_prereg_20260921.md`. 여기 나오는 *"Bo 3.0 = 문헌 앵커 (hare2026)"* 는 **철회된 라벨**이다 (R-4, 09-22 — 코드 Bo 와 문헌 pull-off Bo 는 규약이 달라 현 `LA` 는 내부 기준점 Bo_code 3.0 = Bo_po 0.444).

- 용어 대응: 끈적함 → **응집력(van der Waals 기원 부착력, SJKR)** · 덩어리 → **응집체(agglomerate)/플러그** · 흐른다 → **자유 유동** · 섞이나 → **혼합도(Lacey M)** · 눈금/칸 → **평가 셀**. 정본 §19 의 규약(2026-09-20, 1저자 지시 *"끈적이라는 얘기를 없애고 반데르발스로 접근"*)을 웹 페이지에도 적용.
- 물리 근거: 건조 세라믹 분말의 응집 = vdW 분산력(모세관력은 드라이룸에서 억제, 정전기는 정량 곤란). `γ ≈ A/(24π z₀²)`. LIGGGHTS-PUBLIC 엔 JKR 이 없어 SJKR(`F = CED·A`)이며 γ 를 직접 넣지 못한다 ⇒ 앵커는 Bo 로만 (`MIX-07`: Bo 정의가 문헌 JKR pull-off 와 달라 O(1)).
- 코팅 배수: 앵커 Bo 3.0 → 0.0235 = 1/128, E4 Bo 21.2 → 1/900 (§22-5 의 두 기준).
- 그림 출처: `docs/figures/mixer_summary_20260920.png` — 침대 그림은 v0.2·v0.3 과 같은 프레임, 막대는 §26 의 3시드 판정값.
- 그림 정정: v0.4 의 `ladder_HR_vs_Bo.png` 는 두 패널이 x 축을 공유해 위 패널의 로그축이 선형으로 덮여 점들이 왼쪽에 뭉쳐 있었다(표시 결함, 수치 무관) — 축을 분리해 다시 그렸다. `mixing_v07.png` 는 라벨만 필드 용어로 바꿨다.
- 바뀌지 않은 것: 수치 · 판정 · 한정어(저-G 드럼 · PTFE/VGCF 수동 필러 · Bo 정의 O(1) · 절대 M 은 셀 간 비교 불가).
