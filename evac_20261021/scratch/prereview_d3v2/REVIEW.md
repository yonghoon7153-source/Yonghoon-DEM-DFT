## 4. 못 본 것과 이유

1. 실제 DEM (C0 · C1) — 런 0 · 이 리뷰는 규칙 논리와 참조 구현만 시험했다 (기울기 · u · 띠 = [가정 예시]).  옛 드럼 선례 (MIX-06 · 07 · 09 · 10) 의 이 덱 재현도 C0 몫.
2. 원문 PDF — 카드 [판독] 값은 카드 본문까지만 대조 (litdb 정본 `93f55d1ef`).
3. LIGGGHTS 문법 (벽 점착 0 · 탭 · 깔때기 · 주기 + 회전 메시) — ibb 바이너리 시험 전.
4. OPENBLAS 경로 차 (Haswell ↔ AVX-512) — 탐침 전부 순수 파이썬 (`math` · `random`) 이라 해당 없음.
5. 원장 자기일관 검사기 · `check_doc_refs` · `check_all.sh` — 메인 게이트 몫 (규칙상 안 돌림).  대신 인용 경로 존재 (p17) · SHA 조상 관계만 직접 봤다.
6. 요청서가 "메인이 덧붙인다" 고 한 D2 수정 (`MXD2-01`–`06`) — 이 판에 없음.
7. 정전기 (CQ15) · CG 한계 (CQ14) — 판단 질문이라 반례 대상 아님.
