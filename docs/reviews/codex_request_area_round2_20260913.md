## 1. `AREA-12` — S2(면적 cap 전환)는 솔버에 항등이다 [P1, 내가 열었다]

**주장**: `network_conductivity.py:395` 의 clamp `a_eff = min(a_contact, r_min_real)` 가 이미
`a ≤ R_min ⟺ A ≤ πR_min²` 을 강제하므로 `plastic_coverage.py:289` 의 cap 을 `2π → π` 로 바꿔도
`a_eff` 가 안 바뀐다.  산술 증명은 계약 §7-3, 실측은 `scripts/audit_transport_cap_equivalence.py`
(무작위 20,000: `A_physics` 15.56 % 변화 · 설명 안 되는 `a_eff` 차이 0 · ψ 분기 차 0).

**공격해 달라**:
- 증명의 두 경우 분기(`A' ≥ πR²` / `A' < πR²`)에 구멍이 있는가.  특히 `Lo = max(A_hertz, A_ligg)` 가
  **정확히 `πR²`** 인 경계, `A_tabor == A_volume == πR²` 동률.
- `r_min_real`(`:386`, µm) 과 `R_min_sim`(`:296`, sim) 이 **같은 양**이라는 전제 — `scale` 이
  둘 사이에서 일관되는가.  `no_delta` · `hertzian_fallback` 경로는 사다리를 안 타는데 그 경로가
  `a_eff` 를 다르게 만들 수 있는가.
- `contact_mode='hertzian'` 은 clamp 가 **없다** (`:394` 조건).  거기서 S2 가 무엇을 바꾸는지를
  내가 답하지 않았다 — 그 가지의 σ 가 생산 어디에 쓰이는지 포함해서.
- 감사의 무작위 분포가 **경계 사례를 못 만드는** 방향으로 치우쳐 있는가.

## 2. `AREA-09` STEP 4 — ψ 는 곱한다 (독립 기준해) [원장 `L2-01` 갱신]

**주장**: 축대칭 flux tube(반지름 b=1, 길이 2L, 가운데 절연 격막에 반지름 a 구멍)를 유한체적으로
풀어 `R_c = R_total − R_bulk` (`R_bulk` 는 격막 없는 런으로 **측정**)를 잰 결과, nr=600 에서
`R_c/(ψ·R_H)` 의 기하평균 `|ln 비|` 가 `s≤0.3` 1.0296 / `s>0.3` 1.1618 이고 `R_c/(R_H/ψ)` 는
1.4200 / **29.9924**.  `scripts/constriction_reference.py`, 원자료
`docs/data/constriction_reference_20260913_nr{300,600}.txt`.

**공격해 달라**:
- **estimand**: `R_total − R_bulk` 가 문헌의 "constriction resistance" 와 같은 양인가.  문헌
  유도가 `R_bulk = 2L/(σπb²)` 를 **빼는** 규약인지, 아니면 반무한 tube 의 spreading 만 따로
  정의하는지.  유한 L 이 남기는 오차(검사 ⑤ 는 L/b 2→4 에서 불변이라 했다).
- **구멍 스냅**: `a_eff = k·dr` 로 격자 면에 맞춘 것이 `ψ(a_eff)` 와 `R_H(a_eff)` 둘 다에 일관되게
  들어갔는가.  스냅 자체가 계단 구멍의 유효 반지름을 **과대/과소** 하는가 (작은 s 의 +4 % 가 정말
  이산화인가, 아니면 스냅 편향인가).
- **판정 통계량**: 기하평균 `|ln 비|` 를 두 구간으로 나눈 것이 결론을 유리하게 만드는가.
  s 격자를 다르게 잡으면 뒤집히는가.
- **우리 코드와의 대응**: 기준해의 `b` 는 1 이고 코드는 `b = r_min` 이다.  기준해가 가른 것은
  "flux tube 안에서 ψ 를 어디에 두는가" 이지 "우리 접촉이 flux tube 인가" 가 아니다 — 내가 이
  경계를 계약 §7-4 에 적었는데, **그 경계 안에서도** 결론이 코드 수정(S3)을 정당화하는가.
- 큰 s 에서 수치해가 `(1−s)^1.5` 보다 **작다**(s=0.9 에서 0.597).  이것이 근사 오차라는 내
  해석 대신, 유한체적이 s→1 에서 `R_c` 를 체계적으로 **과소** 하는 이산화 효과일 가능성.
- 검사 ③ 의 밴드 0.7~1.3 이 **판별력이 있는가** (2π 배는 잡았지만 1.3 배 오류는 못 잡는다).

## 3. `AREA-11` — 이종쌍 `min(σ)` 는 직렬식 대비 최대 2배 과대 [P2, 내가 열었다]

**주장**: 참값 `R_c = ψ/(4a)·(1/σ₁+1/σ₂)`, 코드 `ψ/(2a·min σ)`, 비 `2σ₁σ₂/(σ_min(σ₁+σ₂)) ∈ [1,2)`.
기준해 검사 ⑧(σ 1:8, 양쪽 σ 를 다르게 푼 flux tube)이 `min` 규약 **1.778배 과대** = 16/9.
생산 영향 = 전자 모드 `AM_P–AM_S` 뿐 (`sigma_AM_relative`), r=6 µm 에서 1.722배.

**공격해 달라**:
- `min(σ)` 가 *"협착이 연한 쪽 재료 안에 있다"* 는 **모델 선택**으로 방어되는가 (주석 *"conservative"*).
  그렇다면 직렬식이 "참값" 이라는 내 표현이 과한가.
- 1.778 = 16/9 일치가 **정확**한가 (이산화 잔차 ~1.05 가 곱해져 있는데 어떻게 정확히 맞았나 —
  `직렬비 1.0546 · min비 0.5932`, `1.0546/0.5932 = 1.7778`.  비의 비라서 이산화가 상쇄된 것인지 확인).
- `sigma_rel` 이 이온·열에서 1.0 이라는 내 범위 서술 — `k_weight`(열, `:335-343`)가 같은 자리에서
  **또 다른** 재료쌍 규약을 쓰는데 그것과 `min(σ)` 가 겹치거나 충돌하는가.

## 4. 사전등록 v2 (계약 §5-v2) — 반증 가능한가

- **코호트가 S0 를 본 뒤 정의됐다.**  "데이터 가용성이 강제했다" 는 변명이 성립하는가.
  S0 를 본 사람이 코호트 규칙을 적는 것 자체가 오염인가 — 그렇다면 남는 절차는 무엇인가.
- `ρ` 프로토콜 (같은 입력 2회 → 0 이면 tol 10배 조여 재측정).  결정론적 코드에서 `ρ` 가 0 이면
  `max(3 %, 0)` 이라 v1 과 같아진다 — 이것이 **"분해능 5 %" 철회의 실질**이 있는가.
- `median(|Δ_i|)` 가 주 지표.  30 케이스가 같은 LHS 에서 나왔다 — 중앙값의 **분산**을 무엇으로
  적을 것인가를 내가 안 적었다.
- ⑧ 의 부호 예상 분리 (S2 하향 / S3 상향).  S2 가 항등이면 "하향" 예상은 **의미가 없다** —
  v2 를 다시 고쳐야 하는가, 아니면 S2 행을 삭제하는 것이 사후 수정인가.

## 5. `L1-01` · `L1-02` 계측 (값 불변)

- `radii_from_rstar_rmin(R*, R_min)` — `R_min == R*` 근처(`r_max → ∞`)의 수치 불안정.
  `den <= 1e-15·R_min` 문턱이 실제 침대(r_SE 0.5 ↔ r_AM 6 µm, `R_min − R* = 0.038`)에서 안전한가.
- `lens_volume` 의 세 영역(분리 / lens / 내포) 경계에서 연속인가.  내가 검사한 것은 내부점뿐이다.
- `plastic_coverage.py` 물리 분기가 여전히 `legacy_v_overlap` 을 쓴다는 내 주장 — `A_final`
  불변 핀 5개가 **결속 5가지를 전부 덮는가** (`volume` 결속 핀이 없다: hertzian·tabor·elastic·
  transition 뿐).  volume 이 결속하는 핀이 없으면 ⑨ 는 L1-02 자리를 **안 본 것**이다.
  → **이 요청서를 쓰다 발견해 바로 고쳤다**: volume 결속 핀 2개(동일 반경 · SE↔AM)를 계측
  추가 전 코드에서 실측해 추가 (7핀).  그래도 공격해 달라 — 핀이 덮지 못하는 결속 조합이
  또 있는가 (`liggghts` 결속 핀도 없다: `ligg_area=None` 으로만 찍었다).
- 합성 스윕의 `cap_conflict 55.3 %` — 이 숫자를 원장에 적은 것이 (코퍼스 아님이라 표시했어도)
  나중에 인용 누수를 만들 위험.  적지 말았어야 하는가.

## 6. `SELF-28` 해석 하향

*"올바른 배치에서 `s→1` 이면 참값이 0 이므로 `R_c=0` 삭제는 그 자체로 물리 오류가 아니다"*.
- `s = a/r_min = 1` 은 **원판이 작은 구의 대원**이라는 뜻이다.  그 기하에서 flux-tube 근사
  자체가 성립하는가 — 성립하지 않으면 "참값 0" 은 근사 밖 외삽이다.
- `geom` 결속의 13.84 % 가 **전부** `s = 1` 인 것은 맞지만, 그 직전 구간(`tabor` 가 먼저
  넘는 δ=0.10234~0.16292)은 `ψ ≤ 1e-4` 로 삭제되면서 `s < 1` 이다 — 거기서는 참값이 0 이 아니다.
  내가 "삭제 자체는 오류가 아니다" 를 **두 구간에 같이** 적용한 것이 과한가.
