2. **새 RJ 발사 준비** — 고정 키트의 역사 Slurm 래퍼는 구 러너를 호출하고 동시 엔진 검사를 우회하도록 작성됐다. 새 발사 블록은 A5 전용 러너를 직접 호출하며 NP6·입력 신원·동시 실행 검사를 유지해야 한다. 해당 발사 블록은 별도 키트 밖에서 확인하고, 기존 143파일을 그대로 둔다.
