## 1. 한 줄 요약

300 MPa 로 압축한 복합 양극 DEM 침대 5 개 (큰 활물질 : 작은 활물질 = 10:0 · 7:3 · 5:5 · 3:7 · 0:10) 의 입자 좌표와 공극률입니다.
COMSOL 에서 구를 **겹친 그대로 합쳐** 형상을 만들면, 그 형상의 공극률은 아래 **union** 값과 같아야 합니다.

- **union** = 입자 겹침을 한 번만 센 빈 부피 비율입니다.  상자 [0, 50 µm) × [0, 50 µm) × [0, 두께) 안에 무작위 점 400 만 개를 뿌려 어느 구에도
  안 든 비율로 쟀습니다 (x · y 주기 반영 · 통계 오차 ±0.02 %p).
- **구 부피 합** = 웹앱 기본값입니다.  입자 부피를 그냥 더해 겹친 부분을 두 번 세므로 union 보다 약 1.5 %p 낮습니다.
- COMSOL 형상 검산에는 **union** 을 쓰십시오.  보고서에 두 값을 같이 적을 때는 이름을 붙여 구분해 주십시오.
- 조성마다 침대 1 개 (시드 1 개) 입니다.  같은 조성을 다시 쌓았을 때의 산포는 재지 않았습니다.

- **atom 파일** (LIGGGHTS 텍스트 덤프): 열 `id type x y z radius vx vy vz …`.  type 1 = 큰 활물질 · 2 = 작은 활물질 · 3 = 전해질.
- ⚠ **단위: 덤프 값 × 1000 = µm.**  시뮬레이션이 길이를 1000 배로 키워 돌았습니다 (반지름 4.5 µm 가 덤프에 `0.0045` 로 적힘).
- **mesh 파일** = 위 플래튼 (평판) STL.  z 좌표 × 1000 = 두께 (µm).  바닥은 z = 0 평면입니다.
- **contact 파일** = 접촉 쌍 목록 (`id1 id2 … delta …`).  형상에는 필요 없고, 겹침 깊이 (delta) 를 볼 때만 씁니다.

## 5. COMSOL 형상을 만들 때 주의할 점

1. **주기 경계**: x · y 경계를 가로지르는 입자는 좌표가 한 번만 있습니다.  경계에서 반지름 거리 안의 입자는 x ± 50 µm · y ± 50 µm 복제본을 더한 뒤
   상자로 잘라야 공극률이 맞습니다 (위 union 값이 이 방식입니다).
2. **입자 겹침**: 압축 대리로 입자가 조금씩 겹쳐 있습니다 (겹친 부피 ≈ 상자의 1.5 %).  합집합을 하면 접촉부에 가는 목이 생겨 메싱이 어려울 수 있습니다.
   반지름을 줄이거나 목을 채우는 식으로 형상을 바꾸면 공극률이 달라지니, 바꾼 규칙과 바뀐 공극률을 같이 기록해 주십시오.
3. **벽 밖 부분**: 바닥 (z < 0) 아래나 플래튼 위로 나간 입자 부분은 잘라냅니다.
4. **검산**: 만든 형상의 고체 부피분율이 `1 − union/100` 과 ±0.1 %p 안에서 맞는지 먼저 확인해 주십시오.  맞지 않으면 1 · 3 번을 먼저 의심합니다.
5. **입자 수**: 전해질이 약 15.9 만 개라 전체를 하나의 CAD 형상으로 만들기 어려울 수 있습니다.  부분 영역을 잘라 쓸 경우 어느 영역인지
   (x · y · z 범위) 를 알려 주시면 그 영역의 union 공극률을 따로 재 드리겠습니다.

## 6. 이 자료가 말하지 않는 것

- DEM 입자는 모양이 변하지 않는 구입니다.  실제 전극의 소성 변형은 **겹침으로 대신** 표현했습니다.
- 여기에는 전도도 · 굴곡도 값이 없습니다.  필요하면 같은 케이스의 웹앱 분석 결과를 따로 드리겠습니다.
- 같은 조성의 반복 침대가 없어 조성 간 차이 (예: 7:3 과 10:0 의 0.4 %p) 의 산포는 모릅니다.
