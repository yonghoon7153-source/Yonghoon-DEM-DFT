# 탄소성 반구–강체평판 접촉의 유한요소 연구 — Jackson & Green (J. Tribology 2005)

> slug `jacksongreen2005_fem_elastoplastic_hemispherical_contact` · DOI `10.1115/1.1866166` · type `FEM (continuum, single-contact)` · PDF `JacksonGreen_2005_JTribol_FEM_ElastoPlasticHemisphericalContact.pdf` · digested `2026-06-26` · status ✅
>
> ★ WISHLIST Tier-0 #7 (탄소성 접촉역학 정전). **Kogut–Etsion 2002 (KE)의 정밀화판** — KE의 *불연속·재료무관* 영역식을 *전 영역 연속 + 재료의존* 으로 교체. ★★ 핵심: **평균 접촉압(=경도 H)은 Tabor가 가정한 상수 3σ_y가 아니라, 변형 기하(a/R)·재료(e_y=σ_y/E')에 따라 진화한다**(H_G/σ_y: 작은 접촉 2.84 → a=R 에서 1). 이는 Mesarović–Fleck(2000)의 유한변형 p_m-하강과 같은 메시지의 **반구↔강체평판판(KE 직계)**이며, **우리 Stage-E·H-cap의 "p_m≈H 상수" 가정에 대한 정밀화 caveat**이다.

## 1. 한 줄 요약
탄성-완전소성(elastic-perfectly-plastic) 반구를 강체 평판에 누르는 단접촉을 ANSYS(=ABAQUS 동일확인) 축대칭
J2-FEM으로 임계간섭 아래(탄성 Hertz)부터 완전소성을 한참 지나서(ω*=110+)까지 풀어, **완전소성 평균 접촉압
= 경도 H가 통념(Tabor H≈3σ_y, Abbott–Firestone P/AS_y=3)처럼 상수가 아니라 변형 접촉기하 a/R 및 재료물성
(σ_y/E')에 의존해 진화함**(`H_G/σ_y = 2.84[1−exp(−0.82(a/R)^{−0.7})]`, a/R→0 에서 2.84, a/R=1 에서 1)을
규명하고, 접촉면적·접촉력·평균압을 전 영역에서 **연속**인 반경험식(평균오차 0.94–1.3 %)으로 적합해
**Kogut–Etsion 2002 모델의 두 불연속(ω*=6, ω*=110 절단)을 제거한** 단접촉 탄소성 정전(canonical reference).

## 4. 시뮬레이션 방법 ★
- **code / version**: **ANSYS**(상용 FEM, axisymmetric 2D) — **ABAQUS로도 동일결과 교차확인**. KE[4]도 ANSYS를
  썼으나 본 연구 메시는 **자릿수(orders of magnitude) 더 조밀**(수렴 강제). DEM·MPM 아님 — 순수 연속체 단접촉 FEM.
- **구성식**: **elastic-perfectly-plastic** (탄성-완전소성, 경화 **없음**). **von Mises** 항복기준으로 항복 결정.
  (cf. Mesarović–Fleck 는 멱법칙 경화 m=3/5/∞ — 본 논문은 m=∞(완전소성)만, 단 반구↔강체평판 기하.)
- **재료 파라미터**: E=200 GPa, ν=0.32 **고정**, 항복강도 σ_y 5종(0.210·0.5608·0.9115·1.2653·1.619 GPa,
  전형 엔지니어링 steel 범위). 무차원군 e_y = σ_y/E' (= 0.00105–0.0081). **강(steel) 밖 더 넓은 물성은 자매편
  [28]에서 확장확인.**
- **bond/binder 모델**: 없음 (단접촉).
- **MPM/continuum**: 본 논문이 곧 continuum FEM. readout = 접촉반경(접촉 끝 절점 위치)→접촉면적 A,
  반구 base 절점 반력→접촉력 P, 그리고 평균압 P/A. servo/hold 개념 없음 — **변위제어 압입**(base 절점을
  간섭 ω 만큼 이동, 강체평판 접근). force-control 대비 수렴 빨라 채택.
- **전달 솔버**: 없음 (역학 전용; frame[5] = 역학 절반).
- **입자 처리** ★ (DEM판 "무질서 처리"의 연속체 대척점): **반구를 진짜 형상소성으로 변형**시킴 — 표면 절점이
  접촉으로 차례로 닿으며 접촉반경 증가, FEM이 소성흐름·구형프로파일·부피보존(ω*>22서 ν_eff→0.5)을 직접 해석.
  즉 **(3) SHAPE 소성** 층위(우리 MPM과 같은 부류)이지, DEM δ-overlap 프록시가 **아니다**. 단 — **단일 접촉
  + 강체평판(reverse asperity)** 만(패킹·다체 X, 이질 2구도 X).
  - PSD 아님(단일 반구 R). 강체평판 = "작은 asperity ↔ 큰 평면" 또는 "변형구 ↔ 강체 평면" 이상화.
- **도메인/RVE / mesh / seeds / 압력범위**:
  - 축대칭 mesh(Fig 2): 사각4절점·8절점 요소, 최종 **11,101개 요소**, **100개 접촉요소**. 메시 ×2 반복정밀화 →
    접촉력·면적이 1 % 미만 변동까지(수렴). 접촉요소 강성도 자릿수 증가시켜 1 % 수렴. 각 간섭서 **≥30개 접촉요소
    접촉**(최대 접촉반경 오차 3.3 %).
  - 접촉요소 강성 ≈ 탄성모듈러스 × 특성길이(≈접촉반경). Lagrange multiplier로 침투 ≤요소폭의 1 % 강제.
    축대칭 BC(반구 base 절점 고정)는 절점 x-방향 자유 허용 대비 면적 <3 %·하중 <1 % 차이만(Saint-Venant).
  - 간섭범위 ω* = 0 ~ 110+ (탄성 → 표면항복 ω*≈8 → 완전소성 ω*≈75 → 그 너머). 초기엔 작은 간섭, 수렴 후 증가.
- **특이사항/튜닝**: 구의 **구형 프로파일**(포물선 근사 가능하나 직접 사용). 접촉을 **변위제어**(force-control보다
  수렴 빠름). 적합곡선의 선두계수를 멱함수로 자유화(AF가 정확해 아니므로 합리적). **Quicksall et al.[28]**이
  강 외 물성으로 결과 재확인.

## 6. Post-processing ★
- **무엇**: (i) 접촉면적 무차원화 A* = A/A_c (Hertz 임계면적으로); (ii) 접촉력 P* = P/P_c; (iii) 간섭 ω* = ω/ω_c;
  (iv) **평균 접촉압/항복강도 P/(A·σ_y)** 를 ω* 와 **a/R 두 축**으로 플롯 → 재료의존이 a/R로 흡수됨을 발견;
  (v) **경도 진화한계 H_G/σ_y(a/R)** 추출 → Weibull 적합(eq 17); (vi) 연속 반경험식 적합(면적 eq12-14, 힘
  eq18-22) — KE의 ω*=6 불연속 제거; (vii) 표면항복·완전소성 간섭(ω*≈8, ≈75) 탐색; (viii) Johnson 실험 대조.
- **도구**: ANSYS(주) + ABAQUS(교차확인). 면적은 접촉 *요소 개수* 로 셈(이산 메시 → 고유오차, FEM 산포 주원인).
  반력은 base 절점에서. 자체 후처리 + 멱함수/Weibull 적합.
- **수치화·플롯·기록**: 모든 그림에 Hertz·AF·KE·ZMC 기준선을 깔고 FEM 점이 어디서 갈라지는지로 영역 판정.
  H_G/σ_y(a/R) 적합은 a/R≤0.412 데이터로(이 범위 밖 주의). 적합 통계오차(면적 1.3 %·힘 0.94 %)를 명시 보고.

## 핵심 물리: 경도는 상수가 아니다 (이 논문의 뼈대)

### (1) 통념과 그 균열
고전 접촉역학은 완전소성 평균 접촉압 = **경도 H ≈ 상수 ≈ 3σ_y**(Tabor 1951[11])로 가정한다. Abbott–Firestone(AF)
모델[9]은 접촉을 구 끝 *절단(truncation)* 으로 근사해 `A_AF = 2πRω`, `P_AF = 2πRωH`, 즉 P/(A·σ_y) = 3 의
**수평선**으로 본다. Kogut–Etsion(KE) 2002[4]·Chang–Etsion–Bogy(CEB)[5]·Zhao(ZMC)[6] 모두 이 H 상수
(2.8–3σ_y)를 채택한다.

### (2) FEM이 보는 것 — 경도의 진화 (Fig 5,6,7)
Jackson–Green은 5재료(σ_y 0.21–1.62 GPa)를 전 간섭에서 풀어, **P/(A·σ_y)가 단일 상수 3에 도달하지 않고**:
- 큰 간섭(ω*≫1)에서 **재료마다 다른 값**(약한 Mat.1 ≈2.8, 강한 Mat.5 더 낮음)으로 흩어진다(Fig 5,8).
- 이 재료의존이 **변형 접촉기하 a/R 로 다시 플롯하면 한 한계곡선으로 수렴**한다(Fig 6):
  **H_G/σ_y = 2.84·[1 − exp(−0.82·(a/R)^{−0.7})]** (eq 17, Weibull 형).
  - **a/R → 0**(작은 접촉): H_G/σ_y → **2.84** (Williams 이론값 2.83 과 거의 정확히 일치).
  - **a/R = 1**(접촉반경 = 구반경): H_G/σ_y → **1**.

### (3) 왜 변하나 — 기하의 변신 (Fig 7)
물리적 이유: 간섭이 커지면 접촉기하가 변한다. a/R → 0 일 땐 날카로운 구 끝 → 구속압(constraint)이 높아 경도
≈3σ_y(Tabor). a/R → 1 로 가면 접촉이 **"변형 뭉툭봉(deformable blunt rod) ↔ 강체평판"** 에 가까워져, 측면
구속이 사라지고 단축압축처럼 → 평균압 = σ_y(H_G/σ_y=1). 그 사이(0<a/R<1)는 **3 > H_G/σ_y > 1** 로 연속
하강. 즉 **경도는 재료물성이 아니라, σ_y/E' 와 변형기하 a/R 에 함께 의존하는 진화량**(Tabor의 "강도만의 함수
H=3σ_y" 를 정면 반박). eq 19 는 이를 ω* 의 함수로 다시 쓴 형태(a/R 를 ω* 로 대입).

### (4) 연속·재료의존 반경험식 — KE 불연속 제거
KE 모델[4]은 영역식이 **두 곳에서 불연속**(ω*=6 기울기, ω*=110 절단)이고 **재료무관**(σ_y/E' 안 들어감)이다.
Jackson–Green은 진화경도 H_G 를 박아 **전 영역 연속**·**재료의존** 식을 만든다:
- **접촉면적**: `A_F* = ω*` (ω*≤1.9), `A_F* = ω*·(ω*/1.9)^B` (ω*≥1.9), **B = 0.14·exp(23·e_y)** (eq 12–14).
  → 재료(e_y=σ_y/E')가 지수에 들어감. 평균오차 1.3 %, 최대 4.3 %. AF모델을 **지나서 계속 증가**(절단 안 함).
- **접촉력**: 진화경도 H_G 로 보정한 AF식 (eq 18–22), 평균오차 0.94 %, 최대 3.5 %.
- 천이점 ω_t* = 1.9(KE의 6 대신). KE 불연속(ω*=6) 제거.

### (5) 검증 — Johnson 구리 실험 (Table 2)
Johnson[25]의 구리구(σ_y 265.5 kPa, E 115 GPa) vs 강체평판 실험과 대조: 현 모델 **최대 10.9 % 차이**, 단
**최대(완전소성)하중서 1.7 %** (a/R=0.204, 예측 P/(A·σ_y)=2.61). KE(같은 점서 AF 가정 → 2.8)는 10.2 %.
즉 **경도진화가 실제 물리** — 큰 변형서 경도가 3 미만이라는 FEM 예측이 실험과 더 잘 맞음.

### (6) 부수 발견 — 소성흐름의 부피보존 전이 (Fig 9)
접촉끝 절점의 반경변위는 ω*<22 에서 **음**(탄성 Poisson 압축, ν<0.5, 부피 감소), ω*>22 에서 **양**(소성흐름이
부피보존, ν_eff→0.5, 변형이 구 기하를 따라감). 즉 **완전소성서 부피보존 등체적 흐름** — 우리 MPM J2 부피보존
흐름의 단접촉 대응. (우리가 죽인 *볼륨 cap*(입자 부피수축)과 반대 — 형상소성은 부피보존.)

### 7.2 ★★ 경로 A (항복캡 접촉법칙)의 정밀화 — KE → JG
`elasto_plastic_feasibility.md` **경로 A** = real E + 항복캡으로 18× 연화 제거. 그 캡의 KE 모델을 JG가 정밀화:
- So 2021의 H-cap(F_th=2/3·H·A_con)·KE 영역식은 **H=상수**(2.8–3σ_y)를 쓴다. JG는 그게 **a/R(접촉크기)에
  따라 진화**(2.84→1)함을 보였다 → **항복캡 DEM을 설계할 때 H를 상수로 박지 말고 H_G(a/R) 로 진화**시키면
  더 정확. eq 17·19 가 그 함수형.
- 단 — **실용적으로는 작은 a/R(우리 대부분 접촉)서 H_G≈2.84σ_y ≈ 상수**이고, 큰 a/R(치밀 압밀)에서만 하강.
  So 2021이 (다른 소재로) H 상수캡으로도 상대밀도 0.98 도달 → **상수캡도 1차근사로 충분**, JG는 그 **2차
  정밀화(큰 변형 보정)** 를 줌. ⇒ 경로 A 우선순위는 유지하되, 치밀영역서 H_G(a/R) 보정 옵션 추가.

### 7.3 ★★ Stage-E(Tabor+volume) "p_m≈H 상수" 가정의 정밀화 caveat — 우리의 핵심 적용점
우리 Stage-E 소성 접촉면적은 **평균압 ≈ H ≈ 3σ_y(상수)** 를 가정(So 2021 F_th=2/3·H·A_con). JG는 이 가정의
**유효범위와 보정량**을 준다:
- **a/R 가 작은 접촉**(우리 300 MPa 평형서 대부분; 작은 SE가 큰 AM에 점접촉): H_G/σ_y ≈ **2.84** ≈ 3 →
  **Stage-E H 상수가정 거의 정확**(오차 ~5 %). 이게 우리 대부분 접촉의 좋은 소식.
- **a/R 가 큰 접촉**(치밀 압밀·큰 overlap, a/R→0.2–0.4): H_G/σ_y 가 **2.84 미만으로 하강**(eq17 계산값:
  a/R=0.2 → **2.61**, 0.3 → **2.42**, 0.4 → **2.24**, 즉 2.84 대비 −8 / −15 / −21 %). →
  **Stage-E가 H를 상수 3으로 쓰면 평균압을 과대평가 → 같은 접촉력에 면적을 과소평가**(P=A·H 에서 H↑면 A↓).
  즉 **치밀·큰접촉서 Stage-E 면적(따라서 coverage·σ)을 과소평가**할 수 있다.
- ⇒ **판정**: 우리 Stage-E의 H=3σ_y 상수가정은 **작은 접촉(대부분)서 정당**(H_G≈2.84), **큰 접촉(치밀,
  a/R≳0.2)서 H를 ~10–20 % 과대**평가 → 면적 과소. 정밀화 시 **eq17 H_G(a/R) 로 a/R-의존 H 대입** 가능
  (우리 실접촉 a/R 분포를 뽑아 적용). ⚠ 단 eq17 적합범위 **a/R≤0.412** — 그 밖은 외삽 주의.
- ⚠ 방향 주의: **Mesarović–Fleck**(이질 2구)은 *작은 σ_y(무른)·작은 접촉서 아직 완전소성 전 → Stage-E
  과대평가* 라 했고, **JG**(반구↔평판)는 *큰 a/R서 H 하강 → Stage-E 면적 과소평가* 라 한다. 둘은 **다른
  메커니즘의 다른 끝**(MFleck=완전소성 *도달 여부*, JG=완전소성 *내부의 H 진화*)이므로 **둘 다 점검** 필요.
  종합: 작은접촉·무른σ_y(아직 탄소성) → MFleck 보정 / 큰접촉(완전소성이나 H 진화) → JG 보정.

## 10. 주의/한계 (over-claim 방지)
- **단접촉 연속체** — 패킹·다체·전달 없음. 우리 §7은 *접촉 구성식 기준*(특히 경도진화)으로만 사용.
  frame[5] 역학-절반. **다체셀(Mesarović–Fleck B2 같은)조차 없음** — 독립접촉 한계밀도도 못 줌.
- **반구 ↔ 강체평판** (reverse asperity) — 우리 AM–SE는 *이질 양변형구*. JG는 "변형구↔강체평판" 극한
  (작은-SE↔거의-평면-큰-AM)으로만 직접 대응. 양변형 이질접촉은 **Mesarović–Fleck**(자매 digest)이 다룸.
- **소재 무관(무차원)** — LPSCl 절대값 없음. §7.3의 H_G(a/R) 보정량은 우리 실접촉 a/R 분포에 의존 → **a/R
  분포를 직접 뽑아야** 정량 판정. eq17 적합범위 **a/R≤0.412** 밖은 외삽.
- **digitized 값**(평균압 peak 2.8/Mat.5 더 낮음, Fig5/6 곡선)은 Fig에서 읽은 **추세값**(±) — stated 천이군
  (ω_t*=1.9, 표면항복 ω*≈8, 완전소성 ω*≈75, 경도식 계수 2.84/0.82/0.7, B 지수)과 구분.
- **elastic-perfectly-plastic(무경화)** — 경화 효과 없음(자매편[28]이 일부 확장). LPSCl은 거의 무경화라 적용
  OK이나, 경화재료엔 Mesarović–Fleck(m=3/5)이 더 일반적.
- **무마찰·sliding 없음** — 저자도 "향후 strain hardening·tangential loading 필요" 명시(결론). 우리 SE-AM
  마찰(μ~0.4)은 무시 — 법선 법칙으로 충분하다는 (자주 쓰는) 근사.
- **구 가정** — 비구형 입자 효과 없음(우리 공통 한계). 단 단접촉이라 PSD·다분산 이슈는 R 정규화로 흡수.
- ⚠ **JG = 단접촉 SHAPE 소성(우리 MPM 부류)이지 DEM 패킹 모델 아님** — "JG로 porosity/dip을 본다"는
  과대해석 금지. 그건 DEM/de Larrard 영역(frame[5]). JG의 가치는 **경도진화 → Stage-E H-cap caveat** 한 점.
- ⚠ **방향 혼동 금지**(§7.3 말미): MFleck "작은접촉·무른σ_y → 완전소성 전 → Stage-E 과대" vs JG "큰접촉 → H
  진화하강 → Stage-E 면적 과소" — *다른 끝의 다른 보정*. 둘 다 점검.
