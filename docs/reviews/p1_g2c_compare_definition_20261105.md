### 0-2. "같음" 의 두 뜻 (Q6-1 · 2 — 결과 전 고정)

- **값 같음** = 무순서 쌍 키 (작은 id, 큰 id) · 방향 바뀐 행 (id1 > id2) 은 pos 두 묶음 맞바꾸고 force · force_normal · force_tangential 9 열 · shear 3 열 부호 반전 · 주기 표지 · deltaMax 그대로 · torque 는 같은 방향 행만 · `%.17g` 글자에서 읽은 float 가 정확히 같음 (−0 = 0 · 비유한 = 읽기 문제) · 원자 = id 별 11 값 (type 포함) 같음 · 쌍 · id 집합 같음 · TIMESTEP · 상자 같음 (쌍 · 원자 덤프 둘 다) · 중복 키 0 · **토큰 꼴** = R 덱 `dump_modify` 그대로 (쌍 30 열 `%.17g` · 원자 id · type `%d` · 나머지 `%.17g`) 이고 숫자 토큰 = ASCII · 밑줄 없음 — 꼴이 아니면 값 같음 = 계산 못 함 (6 자리 `%g` 는 끝자리 차이를 글자로 지운다 · 11-11 G2CPR-04 · §3 판정은 꼴을 보지 않는다 = 키트 식 · 숫자 토큰 ASCII 규칙만 키트보다 엄격 = 거부 쪽).
- **바이트 같음** = 덤프 파일 (쌍 · 원자 각각) sha256 같음 — 행 순서 · 방향 · 글자 꼴까지.  값 같음과 **따로** 예측하고 따로 맞음 / 틀림을 적는다 (Codex: 원시 덤프 바이트 동일성은 행 순서까지 포함한 별도 검증 가설).
- 등록 판정 (§3) 은 둘 다 아니다 — 허용폭 판정 그대로 (PASS · FAIL · NOT_COMPUTED).
