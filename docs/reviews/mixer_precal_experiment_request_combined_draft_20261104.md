# DEM 통합 실험 관측 요청 — 지도 이후용 초안 (2026-11-04)

**결과0건·미발송.** 기존 수용된 보정 전 지도→실험 승인 뼈대를 보존하며 11-04 밤 첨언의 Ⓐ 원측정 빈칸을 추가한 별도 초안이다. 장비·시료·사람은 지금 선정하지 않는다. 기존 D3 SOP와 열람 규칙은 바꾸지 않는다.

## 1. Ⓒ 지도에서 요청할 관측

지도 결과 뒤 평가 조건·실패/미평가 칸·교락·식별 불가 범위를 붙인다. SE 단독 T1 Hausner 비/T2 동적 안식각은 지정한 조건에서 B 후보를 좁히고, IGC/AFM의 상대 표면/떼는 힘 관측은 gamma 비와 가정을 구분한다. 관측 범위·분해능·반복·시료 수는 지도와 실제 기하를 확인한 다음 측정 전 S1에서 결정한다. 이 단계의 실제 장비·분말 로트·측정자·원자료 보관자는 **미정**이다.

## 3. 한 번의 요청과 단계별 승인

1저자가 위 Ⓐ와 Ⓒ 질문을 모아 실험 쪽에 한 번에 요청한다. 제출 전에 같은 시료를 실제로 공유할 수 있는지, 다른 시료면 어떤 대응만 가능한지 구분한다. 보정/검증 자료 분리·순차 C2·열람 기록은 기존 SOP대로 유지한다. 요청서 발송, 실측, 보정, 확인 블록, DEM 실제 실행은 서로의 자동 승인이 아니다. 현재는 빈 초안만 준비했다.
