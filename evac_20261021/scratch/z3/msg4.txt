Rint 2 Z3 R run chain: real contract, ARM_LIST origin, limit markers, sid_off, EXPECT_BACKEND

rint_r_chain.py aligned with the Z3 runner / payload API:
- limit runs: env CJUNC_RJ=inf / 0 unchanged; expected receipt request and manifest protocol now carry the
  canonical markers rj_limit 'inf' (R_j_ohm null) / 'zero' (R_j_ohm 0.0) via LIMIT_MARK (= ca_ext_cjunc.RJ_LIMITS).
- origin check (registration R 3-3, 4-2) = one ARM_LIST=1,2 run (a0 = the confirm / corner value, not re-run);
  the old ARMS=3 workaround and a0_replay_exact are gone; > threshold still runs ARMS=8.  Runner.run takes an
  arm count or an arm tuple; OUTDIR suffix _arm<N>_arml<list> (= runner forced suffix); receipt arm_list checked;
  replay compares the arm list; ARM_LIST scrubbed from the parent env.
- sid fingerprint: off-grid sid_off required and equal to the junction registry sid; comparison groups are
  kit + raster + origin (sid_group), so shifted origin arms no longer stop with SID_GRID.
- EXPECT_BACKEND constant (gpu, the runner default) passed to the runner env, the receipt check and check_arm.
- CG iteration counts (main, continuation) in the public arm record and the run line (number-probe field, not sigma).
