## 2. 다시 만들기

```bash
python3 -P docs/50kg/report_y4/build_kg50_report_y4.py --render --selftest --template <계획 덱.pptx>   # 1쪽 그림 → 덱 → 검사 → 렌더
python3 -P docs/50kg/report_y4/build_kg50_report_y4.py --determinism                                   # 임시 폴더에 두 번 · 바이트 대조
python3 -P docs/50kg/report_y4/figs/make_fig_p2_aux.py --log D3=<kg50_d3_b50_s1 log.liggghts> --log D2=<kg50_d2_b50 log.liggghts>
```

- `-P` = 사용자 site 패키지 (matplotlib 의 dateutil) 가 필요해서 (`-I` 는 그것까지 뺀다).  python-pptx 1.0.2 · matplotlib 3.11.2 · numpy 2.4.6 에서 확인.
- `--template` 은 리포 밖 계획 덱을 **python-pptx 로 읽기만** 한다 (그림 · 장 내용 · 내장 글꼴은 가져오지 않는다 — 1저자 규약: 원본은 리포 밖).
- 2쪽 보조 그림은 로그가 있어야 다시 그린다 — 생성기는 커밋된 `figs/p2_aux_compaction.png` 를 쓰고 sha256 을 `figs/p2_aux_meta.json` 과 대조한다.
