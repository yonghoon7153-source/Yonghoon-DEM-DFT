# 비 Rint 상시 요청서 — Codex 실무 창이 혼자 돌게 (2026-11-10 · Claude)

1저자 11-10: *"codex 실무가 독립적으로 돌아야되는거 계속 요청서를 부탁해요 / 계속 hold 잖아"*.
**이 문서가 상시 요청서다.**  다음 할 일은 이 문서에서 스스로 고른다.  새 요청서를 기다리지 않는다.  이 문서를 바꾸는 것은 1저자 · Claude 다.

## 1. 기다리지 않는 규칙

1. 할 일 순서 = §3 목록 위에서 아래.  한 항목이 끝나면 쪽지 하나를 `docs/collab/codex_to_claude/` 에 남기고 바로 다음 항목으로 간다.
2. 1저자 결정이 필요한 칸은 질문 (Q) 과 권고 한 줄을 쪽지 머리 표에 적고, 문서 · 합성 시험 준비는 **권고안을 전제로 계속한다**.  전제를 쓴 자리마다 "권고안 전제 (Qn)" 표지를 단다.  답이 다르면 그 부분만 되돌린다.
3. 반박 창 판정을 기다리는 동안에도 다음 연결 · 다음 항목을 **새 가지에서 준비한다**.  반입은 판정 뒤 Claude 가 한다.  판정이 앞 연결을 고치라 하면 그것부터 고치고, 뒤 가지는 그 위로 다시 얹는다.
4. 반입을 기다리지 않는다.  새 가지는 최신 작업 가지 또는 자기 앞 가지 위에서 시작하고 쪽지에 바탕 커밋을 적는다.
5. 작업 가지 = 1저자가 알려 주는 가지.  11-10 서브 세션이 끝나면 본 세션 가지 `claude/stoic-knuth-NObVQ` 로 돌아간다 (`docs/handoff_return_to_stoic_knuth_20261110.md`).

- 현장 실행 (WSL · ibb · kgy · gabia) · 실제 값 · 로그 · 원자료 열람 · 발사 · 배포 · 운영 봉인 · MPI · Slurm = 1저자 GO 와 해당 범위의 반박 창 GO 뒤.
