## 직접 실행과 수의 뜻

- 고유 문서 회귀: 12메서드.
- 초기 독립 검토: 후보 12/12였지만 약화9 생존, 되돌림4 검출.
- 보강 재확인: 같은 기존 변이13/13 검출; 추가2/2 검출; 모두 오류0.
- 내부 두 지적의 새 문서 요구를 먼저 넣었을 때 12메서드 중 2실패·오류0 → 해당 문구 수정 후 통과.
- 변이 수, 메서드 수, 전후 반복은 합산하지 않는다. 이 시험은 알려진 문구 퇴행을 막는 유한 검사이며 임의 산문의 의미·미구현 코드·현장 동작 인증이 아니다.

내부 원본 결과는 internal_mutations_before.json / internal_mutations_after.json에 보존했다. mutation_check.py는 독립 하네스의 경로를 인자로 받고 새 보고서만 만들도록 포장한 재현본이다. 공격 사례·단언은 유지한다. 원 하네스 해시 및 변경 범위는 evidence_summary.json에 적었다. 원 기록을 덮지 않았다.
