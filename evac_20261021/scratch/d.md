### 1-3. 통합 계획 §1 "σ* 재보정 고리" ↔ Q5 — 한 문장 정리

> **다음 세대 (`p3ca`) 에서 묶음 σ*_VGCF 는 손잡이가 아니다 — σ_VGCF 는 Endo 단섬유값으로 고정되고 (Q5), 현 세대 σ* 0.347 (SBE) · 2.618 (DBE) 가 맡던 "접점 물리를 한 스칼라에" 의 역할을 R_j,0 하나가 넘겨받는다.**

- 통합 계획 §1 의 *"σ*_VGCF 가 바뀐다 (오를 것)"* 는 이 뜻으로 읽는다 (계획 문장 정정 후보 · 계획 문서는 이 커밋에서 고치지 않는다 · §10 N8).  "SBE 재보정" = R_j,0 재보정이다.
- 현 세대 σ* 값은 현 세대 표에만 있다 — 다음 세대 값과 한 표에 섞지 않고 (§7), 맞추지도 않는다 (R §1).

### 1-4. 통합 계획 Q1 의 문장 충돌 — 정리

- Q1 질문 문장은 *"PTFE · SDCP 법칙 = 독립 자료로 결과 전 고정 (원고 펠릿 9:1 + Lee 2025 투여곡선 · SI 재확인 뒤)"* 이고, 비준된 권고 문장은 *"Lee 2025 투여곡선은 보정이 아니라 두 번째 holdout 후보"* 다.  비준 = 권고대로 → 이 설계는 **Lee 2025 투여곡선을 법칙 고정에 쓰지 않는다** (holdout 후보 · 이 등록 판정 밖 · R §4-3).
- 이 설계에서 "독립 자료로 고정" 의 뜻 (네 조각):
  1. PTFE 면 연산자 = **손잡이 없음** — 지름 = Lee 2025 EES 문헌값 · 불투과 가정 · 채널 플래그 (Q7).
  2. 원고 펠릿 LPSCl:PTFE 9:1 (이온 3.57 → 0.97 mS/cm · `docs/reviews/sdcp_ion_calib_prereg_20260825.md` §1–2) = 그 고정된 연산자의 **사전 점검** (§3-7 S1-P · 맞추지 않는다 — R18 의 "0.97 에 다시 맞추면 calibration").
  3. PTFE–접합 법칙 = 앵커 없음 → 두 끝 P0 · P1 = R 의 **"PTFE 법칙 밴드"**.
  4. SDCP = 앵커 없음 → c 두 끝 (Q9) · 원고 펠릿 LPSCl:SDCP 9:1 = 비퍼콜 점검 (v0 = 구성상 no-op · §5-4).

## 3. S1 — PTFE 면 개구율 연산자 (Codex R18 Q6)

### 3-1. 식 · 단위

- 캡슐 C_i = {x : dist(x, s_i) ≤ r_P} — s_i = PTFE 경로 i 의 중심선 선분 (MPM phase 4 점 · `fibre.npy` 경로 fid · kind = 경로 · 끊기 = 선분 스탬프와 같은 gap_tol 규칙 (`_fibre_segment_ijk` 892 행)) · r_P = d_P / 2.
- 면 f (셀 a · b 사이 h × h 정사각형) 의 **열린 면적분율** α_f = 1 − (1/K²) Σ_q 1[x_q ∈ ∪_i C_i] (x_q = 면 위 K × K 중점 구적점) · α_f ∈ {0, 1/K², …, 1} · 무차원.
- 면 컨덕턴스 g_f = α_f · g0_f (g0 = 조화평균 · 코드 단위 σ·h · `couple` 2052 행) — 불투과 PTFE (R18 Q6) · 막 직렬 항 없음.
- **지름 법칙**:
  - (가) **주** = 모든 경로 d_P = 0.248 µm (rope · [카드] Lee 2025 EES Fig. S2c) · 중심선 길이 = MPM 처방 그대로 — 시더가 `PTFE_D` 0.25 · `PTFE_L` 40 으로 **개수**를 정했으므로 (`CL-67`) 캡슐 부피 ≈ (0.248/0.25)² × (1 − 0.103) ≈ 0.88 V_true (추정 · −10.3 % = 상자 밖 잘림 · 초안 additive brief §1) → S0 가 실측.  "부피 보존 길이" = 이 뜻 (시더의 부피 처방 길이를 그대로 쓴다 · 지름을 부피에 맞춰 다시 고르지 않는다).
  - (다) **민감도만** = 경로 정준 키의 해시로 13 % 를 Ø0.248 · 87 % 를 Ø0.048 (카드 개수비) — 중심선 그대로라 표현 부피가 (가) 의 약 0.16 배 [우리 산술] = 부피 밴드 밖 → 부피 보정 표현이 아니다 → **보고만 · 판정 표지에 쓰지 않는다** (부피 보존 두 집단은 재시딩이 필요 = v1).
  - (나) 시더 d_i (77 배 분포) = 안 쓴다 (Q6).
- **같은 물체 안 면 면제** ('자르기' 인공물 방지 — 두 고체는 겹칠 수 없으므로 그 겹침은 표현 인공물): ⓐ 같은 AM 입자 (pid 같음 ≥ 0) ⓑ 같은 탄소 상끼리 (3|3 · 4|4 · 8|8 — 축방향은 물리상 면제 · 접합은 S2 의 P-junc 법칙이 맡는다) ⓒ SDCP 끼리 (5|5).
- α 를 거는 면 = 전자 채널의 다른 sid 면 (AM|탄소 · AM|SDCP · 탄소|SDCP · AM_S|AM_P) · 같은 sid AM 의 다른 pid 면 (AM–AM 목) / 이온 채널의 SE|SE · SE|SDCP 면 (SE 는 입자 번호가 없는 연속체 — 캡슐 자리 = PTFE 가 SE 를 밀어낸 자리).
- 판 결합: v0 는 α 를 걸지 않는다 (판 쪽 면을 캡슐이 가로지르는 기둥 수만 기록) — 한계 (§3-5 · §10 N10).
- 연결성: α = 0 면 = 절단 (E3 일반화 — 실제 간선 그래프로 떠 있는 성분 가지치기 · 사방 α = 0 셀 = 고립 · 수 기록).

### 4-1. 식 · 단위 · 기하

## 5. S3 — SDCP 접점 수정자

### 5-1. 식

- 근접 a_j ∈ {0, 1}: VV instance j 의 최근접점 ↔ 가장 가까운 SDCP 1 차 입자 표면 거리 ≤ tol_sj → 1 (중심 = MPM phase 5 점 · r_s = 0.15 µm · 새 DBE 침대의 1 µm 덩어리도 0.30 µm 1 차 입자의 모임 — 등록 v2 §2).
- **R_j′ = R_j,0 · (1 − c · a_j)** · c ∈ {0, 1} (Q9 두 끝): c = 0 = **"젖음 효과 없음"** · c = 1 → 근접 instance 의 R_j′ = 0 → 같은 그래프의 정확한 축약 (J6) = **"젖음 상한"** 의 정의.
- 같은 뜻의 병렬 표현: G′ = G/(1 − c) — **새 간선 없음** (통합 계획 §1 의 "SDCP 경유 병렬 항" 은 v0 에서 이 꼴로만 · SDCP 셀을 거치는 새 간선 = v1 · §10 N5).
- ⚠ "젖음 상한" ≠ 옛 융합 (면 인접만 · 반셀 저항 있음) — 같은 T 위상에서 R_j → 0 이다 (Rayleigh 순서는 같은 그래프에서만 서므로 이 정의를 쓴다).
- AM–AM 접점의 ①′ r_type 수정 = 이 등록에서 안 씀 (①′ 끔 · 생산 HOLD).
