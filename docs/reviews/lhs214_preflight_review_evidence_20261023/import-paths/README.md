# 반입 경로 정정과 원문 보존

최초 docrefs 검사에서 증거 폴더 기준 축약 경로가 공개 보고서와 감사 보고서의 실제 위치에서는 해소되지 않았다. `original-package-docs.zip`은 반입 전 docs 65개 전체를 원래 저장소 상대 경로 이름과 바이트 그대로 보존한다. 당시 원 manifest와 그 멤버도 모두 들어 있어 별도 폴더에 풀어 원본 문맥을 확인할 수 있다. 공개 반입판은 실제 증거의 저장소 루트 경로와 그 설명 문장만 정정했다. 발견 사항·숫자·판정·한정은 바꾸지 않았다. `provenance.json`과 두 diff가 원문 및 반입판 신원을 연결한다. 원본 불변에 관한 기존 감사 진술은 반입 전 스냅숏의 상태이며 현재 공개본과 혼동하지 않는다.
