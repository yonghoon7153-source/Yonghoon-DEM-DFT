## 2. 결정 질문 (권고 = 첫 줄)

**Q1 (RCA-03 · P1) 같은 섬유의 비연속 재방문이 한 dof 로 합쳐지는 문제**
- (가) **권고** — 멤버십 열쇠를 `(cell, fid, branch)` 로 넓힌다: branch = 그 셀을 지나는 **연속된 경로 구간** (호 길이 구간) 마다 따로.  같은 셀 · 다른 branch 사이는 연결하지 않고, 자기 접합 규칙 (s ≥ s_min 이면 R_j 간선 · s < s_min 이면 같은 가닥 연속) 으로만 잇는다.  시험 먼저 = Codex 반례 (R 5 → 2 Ω) 가 5 Ω 으로 · 같은 셀 · 다른 셀 자기 접근 · R_j→∞ · c=1.
- (나) 정량 입구에서 비연속 같은 셀 재방문을 거부 (빠름 · 실침대 빈도가 높으면 정량이 멈춘다).
- (다) 굽힘 제한을 입구 계약으로 (MPM 경로가 그 제한을 지키는지 따로 보증해야 함).
- 어느 쪽이든 S0 에 재방문 census (셀 수 · 섬유 수 · s 분포) 를 먼저 보탠다.

**Q2 (RCA-04 · P1) 포트 동률 규칙이 경로 반전에 의존**
- (가) **권고** — 방향 무관 기하 정준 규칙: 후보 셀 중심의 접점까지 거리 → 같으면 셀 정수 좌표 사전식 최소 (경로 열 번호 안 씀).  시험 = 경로 반전 · 공선 세분 · fid 재명명에서 포트 · 행렬 · σ 비트 같음 (무작위 점 섞기와 구별).
- (나) 접점 노드를 새로 두고 양쪽 후보로 접근 저항 연결 (더 물리적 · 구현 큼 · 노드 수 늘어남).

**Q3 (RCA-05 · P1) 긴 접촉 = 한 포트 집중 (lumped) 의 오차**
- (가) **권고** — 분산판을 v0 로 당긴다: 접촉 구간을 따라 k = ceil(L_c / L_par) 개의 간선 (각 G_j,0 = 1/R_j,0 · 총 = 길이 법칙 그대로 · 새 손잡이 없음) · 대표점 하나의 P1 / c 표지 대신 **간선마다** PTFE 덮임 · SDCP 근접 판정.  시험 = Codex 5 노드 회로 (분산 1.366 S 재현 · 왼쪽 / 중앙 집중과 구별) · L_c = L_par 에서 옛 점 접합과 비트 같음.
- (나) lump 유지 + 적용 범위 (L_c / λ 무차원비) · 분산 기준 대비 오차 허용 · 실패 처분을 판정 전에 등록 + 필수 대조 시험.

**Q4 (RCA-06 · P1) `SV_DOMINANT` 소산 가드가 지배 우회를 놓침**
- (가) **권고** — 지표를 `SV_local_dissipation` (진단) 으로 이름 바꾸고 dominance 보증 문장 철회 · 정량 해석의 조건 = **등록된 반사실 대조** (같은 침대 · 같은 R_j 에서 SV 융합 면을 끊은 판 vs 그대로 · 단자 G 비 보고) · 비가 크면 `SV_DEPENDENT` 표지 (판정 문장 제한).
- (나) 공동 점유 / SV 간선 역할 분리 표현을 지금 구현 (큼 · 일정 영향).
