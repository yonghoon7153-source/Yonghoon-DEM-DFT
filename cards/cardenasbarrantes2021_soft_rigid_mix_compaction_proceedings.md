## 무른·강체 원판 혼합의 압밀은 단일 입자 응답과 연결성으로 정해진다

> 강체와 무른 원판 혼합의 등방 압밀은 단일 입자 압축 법칙과 배위수 증가 법칙을 묶은 식 하나로 기술되고, 거시 적합 변수는 φmax 하나다. (L33 · 140–141)

### 요점

1. 강체 원판과 비압축 neo-Hookean 원판을 섞은 1500 입자 2D 집합체를 NSCD로 jammed 상태에서 등방 압축했다. (L31–32)
2. φ는 φmax로 포화하고 K는 φmax에서 발산하며, Z − Z0 = ξ(φ − φ0)^α가 κ와 μ에 무관하게 성립해 φmax만 맞추는 압밀식 (5)가 나왔다. (L32–33 · 140)
3. 2D, 초탄성, 등방 압축의 학회 단편이라 수치는 모체 PRE 2020을 정본으로 삼고, 이 판에서는 시작 상태 표만 가져다 쓸 수 있다. (L11 · 222)

### 학회 단편의 위치

강체 입자와 무른 입자를 섞은 입상체가 압축될 때 충전률이 어떻게 오르는지를 미시역학으로 설명하려는 연구다. 원문은 Powders and Grains 2021 학회에 낸 4 쪽짜리 발표 단편이다. 검토 측은 같은 저자가 같은 계산과 이론을 PRE 2020에 낸 논문을 줄인 판으로 본다. (L2 · 6–7 · 50 …)

검토 측은 이 판에만 있는 것을 세 가지로 꼽는다. 첫째는 시작 상태의 φ0와 Z0를 κ, μ별로 적은 Table 1이다. 둘째는 변형 원판의 FE 메시 삽도가 든 스냅숏이고, 셋째는 식 (5)와 Platzer 모델을 한 그림에 겹친 비교다. (L7–9)

### 계산 방법

계산은 2D 비정칙 접촉 동역학(NSCD)을 LMGC90으로 돌려 했다. 접촉은 비관통과 건조 마찰 법칙을 따른다. 강체 원판 1500개를 무작위로 놓고 부드럽게 압축해 jammed 상태를 만든 뒤, 부피 κVp만큼을 무른 원판으로 바꿨다. (L84–85 · 112–115)

무른 원판은 92개 삼각형 요소로 나눈 비압축 neo-Hookean 재료이고 ν = 0.495다. 마찰계수 μ는 0.0과 0.2 두 가지를 썼다. 경계에 등방 압력 P를 준정적으로 단계별로 올렸고, 벽 속도를 제어해 관성수 I를 매 단계 10⁻⁴보다 훨씬 작게 유지했다. (L85–87 · 116–117)

- 그림 — Fig. 1: κ = 0.5, μ = 0.2 시료를 서로 다른 두 압력에서 보여 준다. 삽도에서 무른 원판 하나를 나눈 FE 메시를, 회색 입자에서 강체를 보면 된다. (L153)

### 시작 상태 표

Table 1은 압밀식의 입력인 시작 상태를 κ와 μ별로 적었다. φ0는 0.805–0.815, Z0는 3.3–3.7 범위다. μ = 0에서 φ0는 κ가 클수록 0.815에서 0.807로 아주 조금 낮아진다. (L34 · 64 · 68 …)

검토 측은 φ0가 마찰에 거의 무관하다고 읽는다. 또 μ = 0에서 Z0가 3.4–3.6으로, 원판에서 마찰이 0으로 갈 때 기대하는 4보다 낮다고 지적한다. 그 이유와 rattler 포함 여부는 확인되지 않았다. (L76–78)

- 그림 — Table 1: φ0 행과 Z0 행을 μs 값별로 나란히 비교하면 된다. 본문은 이 표를 Tab. 2로 부르지만 실제 표는 이것 하나다. (L156 · 223)

### 거동과 압밀식

원문은 압축할수록 φ가 φ0에서 φmax로 점근하고, 체적탄성률 K가 φmax 근처에서 발산한다고 적었다. 원문은 이를 공극이 사라져 집합체가 연속적인 강체처럼 행동하기 때문이라고 설명한다. 배위수는 Z − Z0 = ξ(φ − φ0)^α를 따르고, ξ ∼ 5.1, α ∼ 0.5는 κ와 μ에 무관하다. (L32 · 134 · 136–138)

압밀식 (5)는 입상 응력 텐서로 압력을 배위수와 접촉량으로 쓰고, 단일 입자의 상자 압축 법칙을 붙여 만든다. 단일 입자 법칙의 상수는 b ≃ 0.14이고, 메시 해상도는 Ne = 92에서 968까지 바꿔 시험했다. Z0, φ0, b, ξ, α는 초기 상태와 단일 입자에서 정해지고 거시 자료에 맞추는 것은 φmax(κ) 하나다. (L120–121 · 124–125 · 139–140)

- 그림 — Eq. eq5: 중괄호 안이 배위수 진화 법칙, 로그 항이 단일 입자 법칙에서 온 부분이다. 적합 변수는 φmax(κ)뿐이다. (L125 · 140)

### 믿을 수 있는 범위

검토 측은 그림 2에서 식 (5)와 Platzer 모델이 같은 φ(P) 곡선을 둘 다 잘 따른다는 점을 짚는다. 그래서 φ(P) 곡선 적합만으로는 모델을 가를 수 없다고 본다. K(φ), Z(φ), φmax(κ) 같은 2차 관측량까지 맞춰야 판별된다는 판단이다. (L24–25 · 154 · 185)

검토 측은 이 판을 학회 단편으로 보고, 상세 방법과 수치는 PRE 2020을 정본으로 삼는다. 표 번호 불일치, 초탄성 입자의 무차원 상수 b를 yield stress라 부르는 점, 모체 논문을 인용하지 않는 점도 지적한다. 결과는 2D 원판, 초탄성, 등방 압축, 크기비 없음이라는 조건에 묶여 있다. (L122 · 222–224 · 226)

- 그림 — Fig. 2: 파선이 식 (5), 점선이 Platzer 모델의 예측이다. 두 예측선이 시뮬레이션 점을 얼마나 비슷하게 따르는지 보면 된다. (L154)

### 용어 풀이 (논문에 없는 일반 설명)

- **NSCD(비정칙 접촉 동역학)**: 접촉을 비관통 조건과 마찰 법칙으로 직접 풀어 다입자 운동을 계산하는 접촉 동역학 기법이다.
- **neo-Hookean**: 큰 변형에서도 가역적으로 되돌아오는 고무 같은 초탄성 재료를 기술하는 구성식이다.
- **배위수 Z**: 입자 하나가 평균적으로 맞닿은 이웃 접촉의 수로, 집합체의 연결성을 나타낸다.

### 우리 연구에 주는 뜻

- 강체를 우리 NCM, 무른 입자를 우리 SE로 놓고 보면 혼합 압밀을 입자 해상으로 푼 재설계 후보 B(NSCD + FE)의 실례이고, φ(P), K(φ), Z(φ)라는 공통 검증축을 준다. (L21–22)
- 우리 재설계는 느슨한 packing에서 출발하므로, 출발 상태를 φ0, Z0, 겹침, 준비 방식으로 결과 전에 기록하는 Table 1 형식을 빌린다. (L177 · 203)
- 우리 후보 비교 그림은 φ(P)에 K(φ), Z(φ)를 한 세트로 묶고, 이 판의 2D 값은 우리 3D로 옮기지 않는다. (L178 · 204)

### 읽을 때 조심할 것

- 2D 원판, 평면변형률, 초탄성, P/E 무차원 결과라서 절대값은 실제 소재로 옮기지 않는다. (L11)
- 학회 단편이므로 수치 인용은 가능하면 PRE 2020에서 하고, 이 판에서는 Table 1만 가져온다. (L222)
- Table 1의 Z0는 rattler 포함 여부가 확인되지 않았으므로 인용할 때 정의가 미확인임을 함께 적는다. (L77 · 225)
- 원문이 b를 yield stress라 부르지만 초탄성 입자의 무차원 비례상수이므로 소성 모델의 항복응력과 혼동하지 않는다. (L121–122 · 189)
