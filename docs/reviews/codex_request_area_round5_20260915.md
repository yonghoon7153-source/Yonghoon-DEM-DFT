## 2. 무엇을 했는가 (사실만)

### 2-1. 전환이 **소스 문자열 치환**으로만 존재했다

**기본값이 도입 전 코드와 비트 동일함을 두 방식으로 쟀다:**

### 2-2. 계약이 등록해 놓고 **없던 핀**을 채웠다

§C 의 등록 문구는 *"floor **위·아래·clamp 경계**를 각각 핀한다"* 인데 실제로는 **위 둘만**
있었다.  게다가 floor 대조 좌표 `δ = 0.2 µm` 는 **실제로는 clamp** 라 (`s_raw ≥ 1`)
**floor-only 영역을 한 번도 시험한 적이 없었다** — 4라운드 `R4-08` 이 지적한 그대로다.

| 핀 | 좌표 | 상태 | S3 효과 |
|---|---|---|---|
| ⑦ 활성 | `δ = 0.02 µm` | `ψ > 1e-4` | `Rc_new/Rc_old = ψ²` |
| ⑦d floor_only | `δ = 0.1025 µm` | `s < 1` 인데 `ψ ≤ 1e-4` | `0 → 0` |
| ⑦e clamp_zero | `δ = 0.2 µm` | `s_raw ≥ 1` ⇒ `a_eff = r_min` ⇒ `ψ = 0` | `0 → 0` (**항등**) |

`δ = 0.1025` 는 `R2-08` 이 실측한 floor-only 띠 **0.102338 ~ 0.102633** 안이다.

### 2-3. `R4-08` 의 두 맹점을 oracle 로 닫고 **변이로 확인**했다

판정문이 적은 원인은 *"솔버가 돌려준 ψ 를 기대식에도 쓴다 ⇒ 잘못 바뀐 ψ 가 기대값을 같이
움직인다"* 였고, 두 변이가 13/13 초록이었다.

⑦i 신설 — ψ 를 **기하에서 독립 계산**해 두 배치의 식을 각각 못박는다:

```
s = a_eff / r_min                     (a_eff 는 생산 plastic_coverage 의 A 에서)
ψ_oracle = (1 − s) ** 1.5             (감사가 직접 계산.  솔버에서 받지 않는다)
legacy : Rc · ψ_oracle == R_Maxwell
곱셈   : Rc == R_Maxwell · ψ_oracle
```

`R_Maxwell` 은 솔버가 이미 돌려주므로 **재료·채널 계수는 재구현하지 않는다** — ψ 만 oracle 이다
(판정문이 요구한 *"고정 기하에서 s 와 ψ 를 독립 계산하는 작은 oracle"*).  활성 간선 **8** 건.

**변이를 실제로 돌려 확인했다** (주장이 아니라 측정):

```
baseline                18/18 PASS
floor 1e-4 → 0          15/18 · ⑦d ⑦f ⑦i FAIL   ← 4라운드에서 못 잡던 것
ψ 지수 1.5 → 1.0        15/18 · ⑦d ⑦f ⑦i FAIL   ← 4라운드에서 못 잡던 것
clamp 제거              18/18 PASS               ← ⚠ 여전히 안 잡힌다 (§4-1)
```

## 4. 검토 요청

### 4-1. **⑦i 의 oracle 이 정말 무는가** (핵심)

1. `clamp 제거` 변이가 **여전히 18/18 초록**이다.  우리 판단은 *"구멍이 아니라 진짜 no-op"*
   이다 — 근거: `a > r_min` 이면 clamp 없이도 `ψ = max(1 − a/r_min, 0)^1.5 = 0` 이라 같은
   floor 분기로 가고, `a ≤ r_min` 이면 두 식이 같다.  **이 추론이 맞는가?**
   틀리면 우리 검사에 구멍이 있는 것이다.
2. ⑦i 가 `R_Maxwell` 을 솔버에서 받는다.  `R_Maxwell` 자신이 오염되면 두 식이 **같이**
   움직여 4라운드와 같은 부류의 자기참조가 되는가?  (우리 판단: `R_Maxwell` 은 `a_contact`
   와 σ·k 만 쓰고 ψ 를 안 쓰므로 ψ 축과 독립이다.  이 분리가 실제로 성립하는가?)
3. **oracle 이 못 잡는 변이를 더 찾아 달라.**  특히 `a_eff` 산출 경로 · `psi > 1e-4` 비교의
   부등호 방향 · `max(..., 0.0)` 제거 · 채널별 `k_weight` 경로.

### 4-2. **§3 의 크기 주장이 맞는가**

*"S3 는 삭제분의 99.436 % 를 안 건드린다"* 는 `R2-08` 의 `clamp_zero` 비율 + ⑦e 의 한 좌표
핀에서 나왔다.  ⚠ **한 픽스처의 한 좌표**다.  코퍼스 전체에서 `clamp_zero` 접촉이 정말
양쪽 배치에서 모두 0 인지는 **산술로만** 주장했다 (`ψ = 0` ⇒ 두 식 모두 0).
이 일반화가 성립하는가, 아니면 반례가 될 수 있는 경로가 있는가?

### 4-3. **러너의 거부·수용 경계**

1. `rc=2`(허가 안 됨) 와 `rc=3`(측정이 공허)의 **구분이 옳은가.**  특히 `ERROR` 가 있을 때
   판정을 발행하지 않는 것이 `R4-01` 의 교훈과 정합하는가.
2. `SEAL_CONTRADICTED` — `B_ch` 로 봉인됐는데 런에서 `σ_old` 가 0/비유한이면 **조용히
   재분류하지 않고** rc=3 으로 멈춘다.  이것이 옳은 처리인가, 아니면 `A` 의 미정값 규칙
   (하한 0 · 상한 +∞ 순서통계 경계)으로 **흡수해야** 하는가?  ⚠ 우리는 흡수하지 않기로
   했는데, 그 선택이 *"결과를 보고 정의역을 줄이는"* 반대 방향의 조작이 될 수 있는가?
3. `n_active_old` 와 `n_active_new` 가 갈리면 **그대로 적어 올린다** (조용히 하나를 고르지
   않는다).  그런데 **갈리면 어떻게 해야 하는지는 안 정했다** — 계약이 정해야 하는가?
4. 봉인 시각이 창 밖이면 런을 거부한다.  ⚠ 그런데 **봉인 도구 자신이** 창 밖 쓰기를 이미

## 6. ⬜ **봉인 전에 아직 안 닫힌 것** — 우리가 먼저 신고한다

**ρ 가 확정이 아니다.**  ρ 는 판정식 `d ≥ 2ρ` 에 직접 들어간다.

- 초판 `ρ = 0.000000 %` 는 **철회**됐다 (`SELF-31`) — scipy ≥1.12 의 정지 조건은
  `max(rtol·‖b‖, atol)` 이고 생산이 rtol 을 안 넘겨 **기본 rtol 1e-5** 가 판정한다.
  안 걸리는 손잡이(atol)를 조여 나온 **거짓 0** 이었다.
- 재실측은 **×0.1 (rtol 1e-6) 까지만** 돌았다.  사다리 **×0.01 · ×0.001** 이 미실행이고
