# ADR 0006 — 프론트엔드는 React + TypeScript + uPlot

- 상태: 채택 (2026-08-20)
- 관련: `apps/web/`

## 맥락

화면이 그려야 하는 것: 사이클당 수천 점의 전압–용량 곡선을 여러 개 겹쳐서,
확대/축소하며, 축 단위를 바꿔 가며 본다. 나중에 EIS Nyquist, DRT, dQ/dV 가
같은 틀에 들어온다.

## 결정

- **React + TypeScript + Vite** — 타입이 단위(mAh vs mAh/g) 혼동을 컴파일 타임에
  잡는다. 이 앱에서 가장 흔한 버그 종류다.
- **uPlot** — 45 KB, 수십만 점을 부드럽게 그린다. Plotly(3 MB+)나 ECharts 대비
  훨씬 가볍고, 축·눈금·범례를 직접 통제할 수 있어 Origin 스타일에 맞추기 쉽다.
- 서버에서 **LTTB 로 축약**해서 보낸다. 브라우저로 148k 점을 보내지 않는다.

## 결과

- 사이클 20개 겹쳐도 즉시 그려진다.
- uPlot 은 선언적이지 않아 래퍼(`components/Plot.tsx`)가 필요하다. 한 번 쓰고
  계속 재사용한다.
- Nyquist/DRT 도 같은 래퍼로 그린다 (산점도 + 로그축).
