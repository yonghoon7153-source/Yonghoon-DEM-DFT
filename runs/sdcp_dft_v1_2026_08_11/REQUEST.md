## 1. 무엇을 묻는가

**분자가 표면의 Li 자리에 앉을 때와 Ni 자리에 앉을 때, 어느 쪽이 더 안정한가.**

MLIP(UMA)로 조각 4종 × 구속 2종 = 8개 조합을 훑었는데 **7개에서 두 자리를 구별하지 못했다**.
UMA 는 Ni 의 산화상태·스핀을 보지 않아서 이 질문에 원리적으로 약하다. 그래서 DFT+U 로 넘긴다.

**요청의 산출물은 각 쌍 안의 ΔE 하나다.** 절대 흡착에너지가 아니다(그건 기준상태를 더 계산해야 한다).

각 "쌍"은 **같은 분자 방향·같은 roll·같은 gap 으로 시작한 Li-top / Ni-top 두 끝점**이다.
쌍 안에서만 빼야 계 오차가 상쇄된다.

| `ptfe_c10/fib04_r270__Litop__afm_net4` | | | Li-top | 알짜 +4 | |

⚠ UMA ΔE 는 **참고용**이다. 우리 결과와 같은 표에 놓지 말 것 — 순위용 값이다.

**왜 두 쌍을 보내나 (ptfe_c10)**: 5개 자격쌍 중 4개는 Li 가 낮고(+0.013…+0.052),
**1개(fib05/r270)만 Ni 가 낮다**(−0.037). 게다가 산포가 거의 전부 Ni 쪽에서 온다
(Li 끝점 폭 0.007 eV vs Ni 0.085 eV). 중앙값 대표(fib04/r270)와 반대 부호(fib05/r270)를
둘 다 재야 **"Li 우세"가 실재하는지 방향 표본의 산물인지** 갈린다.

## 3. 계산 조건 (INCAR 에 이미 들어 있음 — 바꾸지 말 것)

쌍 안의 두 잡은 **모든 설정이 같아야** 한다. 하나라도 다르면 ΔE 가 무의미해진다.

### POTCAR
라이선스 때문에 넣지 않았다. **POSCAR 6번째 줄의 원소 순서대로** 붙여 달라
(예: `Li Ni O C F`, SDCP 잡은 `Li Ni O S C H`). 각 폴더의 순서가 다를 수 있으니 폴더별로 확인 바란다.
권장: `PAW_PBE` — `Li_sv` `Ni_pv` `O` `S` `C` `F` `H`. 다른 걸 쓰면 **어떤 걸 썼는지 알려 달라**
(쌍 안에서 같기만 하면 ΔE 는 성립한다).

## 4. 예상되는 어려움 (미리 알려 드립니다)

**U = 6.2 를 처음부터 넣으면 자기상태가 무너질 수 있다.**
우리가 2026-08-03 에 겪었다 — iteration 70 근처에서 총자화가 0 → +2.58 로 튀고 정확도가 10 Ry 로 발산했다.
그때는 U 를 0 → 6.2 로 단계적으로 올려(U-ramp) 해결했다.

이번 입력은 `ICHARG=2` 로 새로 시작하므로 바로 될 수도 있지만, **NELM 안에 안 붙으면**
U-ramp(예: U = 0 → 3 → 6.2, 각 단계 `ICHARG=1` 승계)를 써 주시고 **그 사실을 알려 달라**.
쌍 안의 두 잡에 **같은 절차**를 적용하는 것만 지켜지면 된다.

크기: 226–227 원자(슬랩 192 + 분자 32~34), 이완.

## 5. 자기 초기값이 2개인 이유 (가장 중요)

`afm_balanced`(알짜 0)와 `afm_net4`(알짜 +4) 두 초기값으로 **같은 구조를 두 번** 돌린다.

Ni 자기 배열이 Li-top 끝점과 Ni-top 끝점에서 **다르게 수렴하면 ΔE 가 통째로 오염된다.**
그래서 각 끝점마다 두 초기값 중 **더 낮은 쪽**을 취하고, 그 둘로 ΔE 를 만든다.

⚠ `afm_net4` 라는 이름은 실제 알짜값이다. Ni 48개를 전부 ±2 로 두면 총합이 `4k−96` 이라
**4 의 배수만 가능**하다 — 흔히 쓰는 "net2" 는 이 구성에서 만들 수 없다.

## 6. 돌려주실 것

폴더 구조 그대로, 잡마다:

- `OUTCAR` (gz 압축 가능) — **원자별 모멘트가 들어 있어야 한다** (`LORBIT=11`)
- `OSZICAR` — 수렴 이력
- `CONTCAR` — 최종 구조
- `INCAR` · `KPOINTS` · `POSCAR` — 실제로 쓴 것 (바꾸셨으면 바꾼 채로)
- 쓰신 POTCAR 종류 (파일 말고 이름만)
- U-ramp 등 절차를 바꾸셨으면 그 내용

추가 계산은 필요 없다. 깨끗한 슬랩·고립 분자는 이번 요청 범위 밖이다
(절대 흡착에너지를 낼 때 따로 요청드리겠다).

## 7. 우리 쪽 수용 기준 (참고 — 받은 뒤 우리가 확인할 것)

1. 쌍 안의 두 잡이 **같은 설정·같은 절차**로 수렴했나
2. 각 끝점에서 두 자기 초기값 중 **더 낮은 쪽**을 취했을 때 최종 자기 배열이 서로 비슷한가
3. 최종 구조에서 분자가 **여전히 원래 자리(Li / Ni)에 있나** — 자리가 바뀌면 그 쌍은 폐기
   (MLIP 단계에서 실제로 두 쌍이 서로 자리를 바꾼 사례가 있었다)
4. ΔE 가 **자기초기값 편차 + k 이동 + 30 meV** 를 넘는가
5. 원자별 모멘트와 LDAU 점유행렬을 눈으로 확인하기 전까지 결론은 **조건부**다
