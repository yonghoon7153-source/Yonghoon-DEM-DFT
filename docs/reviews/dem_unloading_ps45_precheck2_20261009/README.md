- ④ 화면 값 줄의 몫은 소수 둘째 자리 — 등록 기대 "소수 넷째 자리" 대조는 아래 명령으로.

```bash
# ibb · 읽기 전용 (JSON 열 개를 읽어 한 줄씩) — 출력 그대로 붙여 넣는다
cd ~/ps45_unload_pre_20261009 && sha256sum ~/ps45_unload_pre_20261009_plane.tgz && python3 - plane_ps_*/plane_load.json <<'EOF'
import json, sys
for p in sys.argv[1:]:
    R = json.load(open(p))
    for l in R['order']:
        r = R['cases'][l]
        c = list((r.get('contribution_sigma_zz_pct') or {}).items())
        s = r.get('sigma_zz_planes_mean_mpa')
        a = r.get('alpha') or {}
        vf = a.get('volume_frac_window') or {}
        lw = 100 * a['alpha_zz']['AM'] * sum(v for k, v in vf.items() if 'AM' in k) if a.get('status') == 'OK' else None
        print(l, r['status'], f"σzz {s:.4f}", f"보존 {r['conservation_max_over_min']:.4f}", f"평형 {r['balance_residual']:.3e}",
              ' · '.join(f"{k} {v:.4f}" for k, v in c), f"| 절대 AM–AM {c[0][1] * s / 100:.4f} MPa",
              f"| LW AM 몫 {lw:.4f}" if lw is not None else '| LW -', '|', '; '.join(r.get('why', [])) or '-', '|', R.get('code_sha256', '')[:16])
EOF
```
