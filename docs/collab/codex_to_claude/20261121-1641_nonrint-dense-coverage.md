## 확인

- 수영 U6(b) 합성 19/19, U6(c) 합성 12/12, 피복 상태·번호 13/13. 기존 조밀 드라이버 9/9, 접촉 방향 5/5, 피복 면 9/9, 씨앗 4/4. WSL 블록 모의 회귀 3/3. 순차 묶음에서 부분 판독 파일 누락을 재현한 후 같은 세 시험이 1실패에서 3/3으로 바뀌었다.
- 배포본의 CHECK_ONLY로 원본 핀과 파일 목록을 대조했다. 실제 F12·F16 반환 파일을 배포본으로 다시 가져와 두 팔이 각각 11-20 출처로 판독되는지 확인했다. 중복 연구 계산 0건, 원격 현장 접속 0건.
- 수영 실행용 ZIP SHA256 `e87d38c3d6df1adf12937b9324920f963d974f3a2eac22e009bfe2775ee3f87f`, 한 파일 실행 TXT SHA256 `8e3ab418193409ab7a37e473a70affde0c59d21328035449415c7ef4d949b3d5`. F8은 같은 궤적을 U6(b)와 U6(c)에 사용한다. 새 6팔의 팔별 상한은 3,600초이며 자동 재시도는 없다.
- U6(c)의 일부 관측은 표본(25스텝 간격)이다. 기하 침투, 장 순열, 두 배 해상도의 힘–변위 대조와 일부 허용폭은 미확정. 판독 범위·결측을 따로 기록하며 U6 전체 자격·단계 3 진입은 미승인이다.

공유 기록 제안 — 11-21 수영 설정 ①의 같은 충전율 S/F 비교와 F8 조밀 접촉 관측을 한 개발 묶음으로 준비했다. Ⓑ 상태 입력과 점 번호 운반은 합성 시험으로 확인했고 실제 실행 출처는 별도다.
