# 사전등록 — SDCP 전도도 판별 팔 (σ_SDCP = 0, **런 전**)

> ⛔ **런 전에 쓰였다.**  아래 예측·문턱·판정규칙은 결과를 보고 바꾸지 않는다.
> 바꿔야 할 이유가 생기면 **새 사전등록**을 쓰고 이것을 superseded 로 표시한다.

---

## 1. 왜 — DBE 는 두 가지가 **동시에** 바뀐다

```
SBE   PTFE 1.0 wt%
DBE   PTFE 0.5 wt%  +  SDCP 0.5 wt%
       ↑ 절연체 감소       ↑ 도체 추가
```

이득 `R = 1.3078` 이 **어느 쪽에서 오는지 아직 못 갈랐다.**

⚠ **CL-44 와 다른 질문이다.**  CL-44 는 `--step3-sdcp-yield-to-vgcf`(SDCP 가 VGCF 셀을
양보 = **부피 유지, 겹침만 제거**)로 *"σ-치환 채널"* 을 껐고 이득이 6.4 %만 줄었다.
이 런은 **σ 자체를 0** 으로 두어 SDCP 의 **전도 기여 전체**를 없앤다.
⇒ CL-44 는 *"기존 도체를 대체하는 몫"*, 이 런은 *"도체이기 때문에 생기는 몫 전부"* 다.

⚠ closure 스윕의 `C₂` 축은 `σ_SDCP = 2.5` 까지만 내려간다 (×1/100) — **0 은 안 덮는다.**

★ 원고와의 짝: SI **S11**(PTFE 0.5 wt% 만 넣은 분말) · **S12**(그 전극의 사이클)가
*"PTFE 0.5 만으로는 부족하다"* 를 실험으로 보인다.  이 런은 그 조건에서 **전자 축이 어떻게
되는지**를 낸다 — 상보성 주장의 정량 근거.

---

## 2. 설계

**팔**: 같은 DBE 침대 · `PTFE_STAMP=centerline` · `vox 0.15` · 구 스탬프 Ø0.30 ·
**8 origin 쌍대응** · `SIGMA_SDCP_OVERRIDE=0`.

**대조**: 기존 커밋 팔을 그대로 쓴다 (재실행 없음) —
`docs/data/w4_ptfe_centerline_20260827` 의 SBE·DBE 8팔.

| 팔 | 조성 | σ_SDCP | 출처 |
|---|---|---:|---|
| **SBE** | PTFE 1.0 | — | 기존 (R 기준선) |
| **중간** | PTFE 0.5 + SDCP 0.5 | **0** | **이 런 (신규)** |
| **DBE** | PTFE 0.5 + SDCP 0.5 | 250 | 기존 |

### 2-1. ⚠ 중간 팔이 무엇인지 **정확히** 적는다 (프레이밍 오류 정정)

중간 팔은 *"PTFE 를 절반 뺀 것"* 이 **아니다.**  바인더 총량은 SBE 와 같고 **모양만 다르다**
(PTFE 섬유 절반 + SDCP 구 절반, 둘 다 전자 절연).  게다가 밀도가 달라
(PTFE 2.20 · SDCP 1.30 g/cm³) 같은 wt% 라도 **부피가 다르다.**

⇒ 따라서:

| 차이 | 무엇을 재는가 | 지위 |
|---|---|---|
| **`R_DBE − R_중간`** | **순수 σ_SDCP 기여** — 기하가 **바이트 동일** | ★ **이 런의 값** |
| `R_중간 − R_SBE` | PTFE 감소 + SDCP 부피 점유 + 모양이 **섞임** | 참고값, 인과 귀속 금지 |

⛔ 두 번째를 *"절연체 제거 효과"* 로 부르지 않는다.

## 3. 판정 (**런 전 등록**)

보고량:

```
f = (R_DBE − R_중간) / (R_DBE − 1)        ← 이득 중 σ_SDCP 가 설명하는 몫
```

기준값: `R_DBE = 1.307820` · `R_SBE = 1.000000` (정의상) · `R_DBE − 1 = 0.307820`

| 결과 | 판정 | 쓸 수 있는 문장 |
|---|---|---|
| `f > 0.80` | **CONDUCTIVITY-DOMINATED** | *"이득은 거의 전부 SDCP 가 도체이기 때문이다"* |
| `f < 0.30` | **GEOMETRY-DOMINATED** | *"이득의 대부분이 σ 가 아니라 기하에서 온다"* — ⚠ CL-44 와 함께 재해석 필요 |
| 0.30 ≤ `f` ≤ 0.80 | **PARTIAL** | 두 몫을 **나란히** 보고, 어느 쪽도 주된 원천이라 하지 않는다 |

★ **`R_중간 < 1` 도 가능하다** — 불활성 SDCP 구가 빼낸 PTFE 보다 더 막을 수 있다.
그 경우 `f > 1` 이 되고, 이는 *"SDCP 의 전도가 자기 부피 점유 손해까지 메우고도 남는다"* 는
뜻이다.  **정상적인 결과로 취급하고 그대로 보고한다.**

⛔ 결과를 보고 `f` 의 문턱을 바꾸지 않는다.
⛔ origin SD 와 팔 사이 폭을 합치지 않는다 (한 침대의 완전 factorial — 표준오차 아님).

## 4. 예상 위험 (런 전 기록)

**⚠ 조건수** — `σ_SDCP = 0` 은 SDCP 셀을 **비전도**로 만든다.  사전등록 v3 STEP 3 이
`σ_VGCF = 0` 에서 `cg_info=30000` 으로 죽은 전례가 있다.

★ 다만 이 런은 위험이 낮다고 본다 (**런 전 판단**): VGCF 는 **전자 골격**이라 0 으로 두면
망이 끊기지만, SDCP 는 0.5 wt% 라 **VGCF/NCM 골격이 그대로 남는다.**  게다가 PTFE 가 이미
생산 기본값에서 `σ = 0` 으로 돌고 있어 **기계가 검증돼 있다.**

⛔ 그래도 수렴 안 하면 **숫자를 내지 않는다.**  `--step3-maxiter 200000` 을 주되,
그것으로도 안 되면 **미수렴으로 보고**하고 끝낸다 (일부만 AMG 로 재실행 금지).

## 5. 이 런이 **답하지 않는 것**

- **격자 수렴** — vox 0.15 고정.
- **PTFE 규약 선택** — centerline 고정, 사전등록 판정 *"채택 안 함"* 은 그대로.
- **σ_SDCP 의 참값** — 이 런은 0 과 250 **두 점**이고 보정이 아니다.
- **기계적 상보성** — 섬유망 형성·응집력 판독기가 파이프라인에 없다 (S10–S12 는 실험 소관).

## 6. 실행 (⚠ **3×3 스윕이 끝난 뒤**)

⛔ 스윕이 도는 동안 시작하지 않는다 — GPU 가 하나이고, 러너가 도는 중에 워크트리를 건드리면
`RCPT|code_sha|differ` 로 팔이 버려진다 (2026-09-02 실측 사고 3).

```bash
REQ=2038ef41
git -C ~/dem-mt merge-base --is-ancestor $REQ HEAD \
  || { echo "ABORT — 코드가 $REQ 보다 뒤진다"; exit 2; }

cd ~/sdcp && nohup env VOX=0.15 SDCP_SPHERE_D=0.30 ARMS=8 LEAN=2 \
  PTFE_STAMP=centerline \
  SIGMA_SDCP_OVERRIDE=0 \
  P2_EXTRA="--step3-maxiter 200000" \
  bash ~/dem-mt/scripts/sdcp_gain_vox015_8arm.sh > /tmp/sdcp_inert.log 2>&1 &
```

디렉터리 태그는 `_sd0` 가 붙는다.  ⚠ `SIGMA_AM_S_OVERRIDE` 는 **주지 않는다**
(기본값으로 돌아야 기존 SBE·DBE 와 대조된다).

**비용**: 같은 침대 재사용 ⇒ step3 재솔브 8팔 ≈ **5시간**.  새 DEM/MPM 불필요.
