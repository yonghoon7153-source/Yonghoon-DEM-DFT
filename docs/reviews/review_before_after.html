  1. caps 의 뜻 — 전체 접촉면적의 한계인가 추가로 퍼진 막의 한계인가 — 정해지기 전에는 cap_conflict 5.24 % 를 값으로 바꿀 수 없다 (L1-01).

  3. flux-tube b — 현행 b = r_min 은 배위수 Z ≈ 4 가정이다. 2r/√Z 로 갈지 — 별도 축, S3 와 섞지 않는다 (AREA-09 7-1c).
