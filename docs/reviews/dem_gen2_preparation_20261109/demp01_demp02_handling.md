# DEMP-01/02 생산자 처리 계약

이 문서는 원 결함을 막기 위한 구현·모의 시험 요구다. 원장 종결 판정·실제 침대 자격이 아니며 원장 상태를 바꾸지 않는다. 정본 계획 §2·§5 및 §12와 T12 준비 문서가 우선한다.

## DEMP-01: 감쇠와 정적 압력 분리

1. 준비·압축·서보·R-a·언로딩의 전역 점성 감쇠를 독립 필드/단계 전환으로 다룬다. 압축 값을 생략해 준비 값으로 자동 상속하지 않는다. 준비 γ는 충전 생성의 수치 이력이고, 접촉법의 법선/접선 소산과 전역 `fix viscous`는 다른 항이다.
2. 압축 γ는 실제 `-gamma*sum(v_z)` 저항 몫으로 자격화할 대상이다. 정본의 2%는 등록 때 확정할 과거 어림이며 이번 실제 합격선이 아니다. 합성 예의 γ/속도/허용 몫을 실물 등록값으로 쓰지 않는다. 부호·단위·원자 집합·창·목표 힘을 함께 기록한다.
3. 정적 300 MPa는 `F_top/A`의 목표 압력을 뜻한다. 압축 중 첫 힘 도달 또는 큰 점성 저항으로 목표에 도달한 것을 정적 결과로 인정하지 않는다. 창 평균/각 표본 압력, 병진·회전 KE, 중력·저항·관성 및 판·바닥·절단면의 힘 수지, 물리 시간, 추가 유지와 보존을 함께 확인해야 한다. 미제공 실제 수치 문턱은 null로 남긴다.
4. R-a는 판 고정 상태에서 서보 끝의 정적성을 재확인한다. 정본의 목표 대비 ±1%/이완 강하 ≤1% 요구와 S1(표류)·S2(KE)·S3(힘 수지)를 함께 적용한다. 관측이 없거나 하나가 불충족이면 S0를 만들지 않는다. 등록된 1회 서보 연장 이외의 자동 재시도는 허용하지 않으며 이번 초안은 그 실제 재시도를 실행하지 않는다.
5. KE 하나 또는 값이 줄었다는 사실만으로 CONVERGED를 주지 않는다. 상태와 덱 표지는 제어용이고 원 궤적을 독립 재판독해야 한다. 예산 소진은 NOT_CONVERGED, 구조/신원 파손은 실패다.

정본의 300 MPa와 비준된 R-a 요구는 유지한다. 반면 새 실제 강성·시간창·γ_comp·압력 오차 예산·정적 자격 결과는 만들지 않는다. E_SE는 보정 유효값이고 E*는 미정이다. 같은 정적 압력 입경 비교에서 50 kg를 면적·하중 정의 없이 목표 압력으로 치환하지 않는다.

## DEMP-02: 판 통과와 보존

기준 재고는 단계 경계의 완전한 고정 ID·type·radius·mass 및 상별 개수·질량이다. 현재 총수 하나가 같아도 ID 교체·종류 교체·질량 손실은 통과시키지 않는다. 기준이 없거나 행 누락·중복 ID·비정수 식별자·비유한 좌표/반경/질량·비양수 반경/질량·파손된 판 기하가 있으면 결과에서 제외해 정상 표본으로 만들지 않고 실패로 둔다.

| 관측 | 의미 | 거부/보존 규칙 |
|---|---|---|
| 판 위/바닥 아래 중심 | 고정 좌표 규약에서 경계를 건넌 중심 수 | 원자 ID·상·시점을 기록; 손실/교체 없이 현재 완전 재고와 대조 |
| 구의 경계 절단 | 중심이 안쪽이어도 구 부피가 판/바닥을 넘을 수 있음 | 중심 통과와 구 절단을 구분; 실제 겹침 허용/접촉 모델 문턱은 등록 전 null |
| 판 메시/평면 | 실제 면·정상 방향·판/바닥 z·면적·PBC와 결합 | 단순 수평면 합성 guard를 실제 삼각 메시 자격으로 확대하지 않음 |
| 수·질량 보존 | 총수+상별 수+ID/type/radius/mass 신원 | 설명 안 되는 손실/치환은 실패; 개수 허용 범위만으로 AM 손실을 승인하지 않음 |
| 경계 사이 이동 | 경계 샘플은 그 시점의 상태만 보임 | 창 사이 통과 후 복귀를 놓칠 수 있음. 실제 기록 주기/연속 검출 증거 없이 “경로 전체 무통과” 주장 금지 |
| 분리 | 판 접촉의 유효성·창 완전성까지 포함 | 무효/결손 관측을 접촉 0으로 치환하지 않음; 두 유효 무접촉 창 전에 판/벽 삭제 금지 |

압축·서보·R-a·언로딩에 같은 판 메시·벽 fix가 남아야 한다. move fix 교체와 mesh/wall fix 재생성을 혼동하지 않는다. 판을 재생성해 이력을 잃는 변경은 정적 lint와 실제 이력 fixture의 별도 대상이다. 지오메트리 guard의 합성 성공으로 실제 바이너리에서 판 뚫음이 해결됐다고 선언하지 않는다.

## S0/T12 인계

S0는 R-a 끝의 정확한 step와 원 atom/pair/wall/mesh/restart/state에 결합한다. ID/type/radius/mass/상 재고·속도/회전·접촉 이력·물성·중력·단위·정수 시간창을 보존해야 한다. 파일 이름·hash만 맞거나 P1 침대 이름을 재사용하는 것은 P2 소비 자격이 아니다. P1 r8 머리와 P1 중력을 P2에 덮지 않는다. 현재 T12=NOT_RUN·physical_ready=false를 유지한다.
