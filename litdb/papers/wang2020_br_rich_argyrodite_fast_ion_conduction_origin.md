## 0. 이 digest 를 읽는 법 — 왜 우리에게 걸리나

**논문의 질문**: Br 을 과잉으로 넣은 Li₆₋ₓPS₅₋ₓBr₁₊ₓ 에서 전도도가 왜 오르나 — "기원(origin)" 을 원자 단위로 보이겠다.

**논문의 답 (저자 서사)**: Br 이 늘면 케이지 중심 자리(4d)에 Br⁻ 가 앉는 비율이 늘고(³¹P NMR 로 P 주변 4d 배치 5종을 분해), 그중 **1S3Br**(P 주변 4d 넷 중 S 1 · Br 3) 배치가 "가장 빠른 점프" 를 준다 → 그 분율이 x 와 함께 늘어 전체 점프율이 오른다. 동시에 Li 가 **24g** 자리로 재분포하고(⁶Li NMR), 추적자 교환이 24g 가 전도 경로임을 보인다.

**우리에게 걸리는 이유 셋**:
1. **우리 modelc = Li₅.₄PS₄.₄Cl₁.₆ = 이 계열의 x = 0.6 (Cl 판)** 이다. 이 논문의 x = 0.6 Br 시료는 ³¹P 로 4d-Br **71.7 %** 이고, 우리 modelc 셀은 4d-Cl **60 %** (화학량론 최소값) · 4a-Cl 100 % 다. 이 논문의 "기원" 논리가 우리 modelc 해석에 옮겨지는지가 핵심이다 (§7d).
2. 논문이 쓰는 그림 — **0 % 4d 할로겐 = 케이지 고립 · 50 % = 연결 · 100 % = 다시 고립** — 은 우리 comp1 (4d-Cl 0 %) 과 comp2 (Li₆PS₅Cl₀.₅Br₀.₅) 무질서 앙상블 d = 0 / 0.5 / 1.0 과 **같은 축**이다. 우리 MLIP-MD 결과가 이 그림과 같은 모양을 보인다 (§7c 5–7행 · 방향만).
3. 우리 db 의 판정 문장 *"VACANCY is the robust conductivity lever"* (`db/properties/comp2_md_arrhenius.json` `physics_verdict`) 와 이 논문 계열(+He 2023 리뷰)의 *"4d 배치가 기원"* 이 **서로 다른 레버를 지목한다**. 둘 다 교란돼 있다 — 이 논문은 x(공공)와 4d-Br 이 공선이고, 우리 comp1→modelc 쌍은 공공 · Cl 량 · 4d-Cl(0→60 %)이 한꺼번에 바뀐다 (§7d).

**근거 강도 한 줄 판정 (§6 에서 전개)**: σ↑·Ea↓ 측정과 ³¹P 기반 4d-Br 증가는 **실측**이다. "1S3Br 이 최적" 은 **de Klerk 의 Cl·450 K 표값을 곱해 만든 모형의 산물**이라 순환적이고, "24g 가 전도 경로" 는 **⁶Li 두 성분 분해와 추적자 교환의 물리 해석에 구멍**이 있다 (§10-B). 즉 **상관은 보였고 인과는 보이지 않았다.**

## 1. 한 줄 요약

고상 합성(수동 혼합 → 300 °C 12 h → 펠릿 450–550 °C 12 h 진공 소결)한 Li₆₋ₓPS₅₋ₓBr₁₊ₓ 에서 총 이온전도도가 **≈5.5 → 10.2 mS cm⁻¹ (21 °C, x = 0 → 0.5–0.7)**, Ea 가 **0.227 → 0.178 eV** (log σ 아레니우스, 20–120 °C)로 좋아지고, ³¹P MAS NMR 은 4d 자리의 Br 분율이 **37 → 72 %** 로 늘며 P 주변 배치가 이항(무작위) 분포를 따른다고 보인다. 저자는 이를 de Klerk 의 배치별 점프율과 곱해 **"1S3Br 배치 분율이 전체 점프율을 정한다"** 고 결론하지만, 그 점프율은 Cl·450 K 차용값이고 x 와 4d-Br 이 공선이라 **배치 효과를 공공 효과와 분리하지 못했다**.

**동기 (서론)**
- Li₆PS₅X 의 전도도는 4d 자리 S²⁻/X⁻ 혼합에 크게 좌우된다는 것이 기존 설명이다: Li₆PS₅I 는 4d 에 I 가 0 (I(4d) = 0), Li₆PS₅Br·Cl 은 Br(4d) 43 %·Cl(4d) 63 % (Rayavarapu 2012, ref 16), σ 는 I 4.6×10⁻⁷ · Br 7.2×10⁻⁴ · Cl 7.4×10⁻⁴ S cm⁻¹ (refs 6, 8, 16 소환값).
- 24 Li/cell 이 24g·48h 에 부분 점유하며 점프는 doublet · intracage · intercage 세 종류 (de Klerk 2016, ref 15). 4d 점유가 Li 분포를 바꾸고 그것이 수송을 정한다는 것이 작업 가설이다.
- 할라이드/S 무질서를 키우는 기존 방법은 P 자리 양이온 치환 (Ge-I argyrodite, Kraft 2018, ref 10). 이 논문은 **음이온 쪽(Br 과잉)** 으로 같은 일을 하겠다는 것.

**질문**: (i) Br 과잉이 σ 를 얼마나 올리나 (ii) 4d 의 Br/S 배치를 국소적으로 셀 수 있나 (³¹P) (iii) 그 배치와 Li 분포(24g/48h)가 σ 와 어떻게 묶이나 (iv) 어떤 Li 자리가 실제로 전도에 쓰이나 (추적자 교환).

## 5. 결과 — 절별 상세 (그림 실독 포함)

### 5.1 구조 · 상 (`Fig. 1`, `Fig. S1`, `Table S1`)
`Fig. 1a` 는 이상적 질서 구조(4d = S, 4a = Br)를 그리고, 저자는 S²⁻ 0.184 nm · Br⁻ 0.196 nm 반경이 비슷해 4a/4d 교환이 생긴다고 설명한다. PS₄ 의 S(16e)는 강한 공유결합이라 치환이 드물다. `Fig. 1b` Rietveld (R_wp 7.27 %) 차곡선은 최강 피크 두 개(≈25.5°, ≈30°)에서 눈에 띄는 잔차를 남긴다 (figure-read). x = 0–0.5 는 입방 유지 · 격자 선형 팽창(`Fig. 1d`). 저자는 *"enlarged ion diffusion channels"* 가능성을 말하지만 +0.24 % 팽창에 대한 정량 연결은 없다. x = 0.7 · 0.8 은 LiBr 공존(`Fig. S1`), x = 0.7 은 *"x = 0.5 와 구조·기능이 비슷하고 Li 분포만 조금 다르다"* 며 이후 논의에 포함한다.

### 5.2 전도도 (`Fig. 2`)
`Fig. 2a` Nyquist 는 21 °C 에서 x 가 커질수록 스파이크가 왼쪽(작은 R)으로 이동한다 (≈128 → 55 Ω). `Fig. 2b` 는 **x = 0.5 와 0.7 이 같은 10.2 mS cm⁻¹** 로 고원을 이룬다 — "x = 0.7 이 최고" 는 그림으로는 x = 0.5 와 구분되지 않는다. `Fig. 2c` 아레니우스는 x = 0.5 와 0.7 의 점이 전 온도에서 겹치고(120 °C 에서는 0.5 가 근소하게 위), Ea 는 0.183 (0.3) · 0.188 (0.5) · 0.178 (0.7) 로 **0.01 eV 안에서 비단조** — 오차 없이 순위를 말할 수 없다. x = 0 은 120 °C 와 20 °C 끝점이 직선 아래로 처지는 약한 곡률이 보인다 (figure-read).

### 5.3 ⁶Li NMR 과 24g 분율 (`Fig. 3`, `Fig. S3`, `Table S3`)
저자는 1.62 / 1.59 ppm 두 성분을 24g / 48h 로 지정하고, 지정 근거로 "Li 를 24g 에만 · 48h 에만 둔 두 비완화 구조의 GIPAW 계산에서 24g 의 이동이 더 크다" 를 든다 (`Fig. S3`). x 가 커지면 24g 성분이 37 → 50 % 로 커지고(`Fig. 3c`), 저자는 이를 *"Br⁻ → S²⁻ 치환이 부른 Li 점유 무질서 증가 — 정적·동적 둘 다"* 로 읽는다. 전체 선 이동(`Fig. 3b`)은 계산과 잘 맞는다. **실독 소견**: `Fig. 3a` 의 모든 x 에서 보이는 것은 **봉우리 하나**이고, 성분 분리는 선 모양 비대칭을 두 성분으로 맞춘 결과다. 봉우리는 x 가 커질수록 오른쪽(작은 ppm)으로 이동하고, x = 0.5 에서 가장 넓다 (x = 0.6·0.7 은 다시 좁아진다).

### 5.4 ⁷Li T1 (`Fig. 4`)
T1 과 σ 를 한 그림에 겹쳐 둘 다 x 와 함께 오른다는 것을 보인다. T1 은 x = 0.6 → 0.7 에서 평탄(192.5 ms 두 점), σ 는 0.5 → 0.7 에서 평탄. x = 0.5 → 0.6 에서 T1 은 +14 % 인데 그 구간 σ 는 측정점이 없다.

### 5.5 ³¹P NMR — 배치 다섯 종 (`Fig. 5`)
P 의 두 번째 배위권 4d 네 자리를 S/Br 이 채우는 다섯 배치(4S · 3S1Br · 2S2Br · 1S3Br · 4Br)를 P1–P5 다섯 성분으로 지정한다. 저 Br 에서도 무질서가 크고, P1(4S)은 전 시료에서 분해되며 x 와 함께 준다. 이항식(eq 3)으로 예측한 분율과 실측이 맞으니 *"Br⁻/S²⁻ 는 4d 를 통계적으로 무작위하게 점유한다"* 가 결론이다. 1S3Br · 4Br 는 x 와 함께 증가, 4S · 3S1Br 는 x = 0.3 → 0.5 에서 급락, 2S2Br 은 변화가 작다. **실독 소견**: x ≤ 0.1 스펙트럼은 93.3 ppm 의 날카로운 P1 외에는 넓은 덩어리라 다섯 성분 분해가 사실상 모형 의존이다. 성분 위치는 고정되지 않았다(§3d). **31P 성분 지정을 받치는 계산(배치별 ³¹P GIPAW)은 없다** — 4Br 쪽으로 갈수록 이동이 작아진다는 단조 가정만으로 지정했다. P 에서 4.98 Å 에 있는 **4a 이웃 6개**(4d 4개는 4.32 Å)의 S/Br 효과는 고려하지 않는다.

### 5.6 ⁷⁹Br QCPMG (`Fig. S2`)
⁷⁹Br(스핀 3/2)는 사중극자 상호작용이 커서 신호가 수천 ppm 으로 퍼지고 T2 가 수 µs 라, QCPMG 로 감도를 얻고 분해능을 버린다. 지정 기준시료 Li₅.₇PS₄.₇IBr₀.₃: I 는 4a 를 강하게 선호하니 Br 이 4d 로 밀려나 **4d 성분이 커진다** (`Fig. S2a` 맨 위 스펙트럼의 넓은 스파이클릿 외피가 실제로 가장 크다 — figure-read). 4a 는 고대칭 자리라 사중극자가 약해 날카롭다 → ≈100 ppm 부근 스파이클릿 = Br(4a), 나머지 = Br(4d). `Fig. S2b` 가 ³¹P 와 ⁷⁹Br 의 4d-Br 분율을 비교한다 (§3d 표).

### 5.7 점프율 모형 (`Fig. 6`, `Table S4`, `Table S5`)
배치마다 "율속 점프"(장거리 확산에 필요한 세 점프 중 가장 느린 것)가 다르다는 de Klerk 의 그림을 받아, eq 5 로 R_overall 을 만들고 σ 와 양의 상관을 보인다(`Fig. 6a`). *"순수한 x = 0.7 시료라면 더 높았을 것 — 소량의 불순물이 σ 를 조금 낮췄다"* 로 x = 0.7 에서의 어긋남을 처리한다. `Fig. 6b` 에서 1S3Br 분율과 R_overall 이 나란히 가니 *"1S3Br 배치가 전체 점프를 정하는 주요인"* 이라 결론하고, *"4d 의 70 % Br 점유가 최고 σ 를 준다"* 와 정합한다고 쓴다.

### 5.8 AIMD (`Fig. 7`)
1×1×1 셀에 4d-Br 0 · 25 · 50 · 75 · 100 % 를 만들었다고 쓰지만 **보여 준 것은 0 % 와 50 % 의 500 K Li 밀도 등가면 두 장**이다. `Fig. 7a` (0 %): 각 케이지 안에 48h 쌍(doublet)과 intracage 연결만 있고 **케이지 사이 밀도가 없다** → intercage 점프 부재 = 국소 확산. `Fig. 7b` (50 %): 케이지가 이어진 3D 망. 저자는 *"50 % 모형에서 intercage 가 두드러지고 doublet 은 준다 → 저 Br 에서는 intercage 가, 고 Br 에서는 doublet 이 율속"*, *"100 % Cl/Br 점유에서는 doublet 이 극히 드물어져 케이지가 다시 끊긴다"* 고 쓴다 — **100 % 의 데이터는 제시되지 않았고 문장도 "Cl/Br" 로 de Klerk 결과와 섞여 있다.** 등가면 값 · 궤적 길이(">100 ps") · 점프 수 · D · MSD 없음.
- **관측창 (D-2026-10-05-md-observation-window 의 거울상 적용)**: "0 % 에서 intercage 점프 없음" 은 유한 궤적의 부재 관측이다 — Ea_max ≈ kT·ln(ν₀ t) = **0.30 eV** (T = 500 K · t = 100 ps · ν₀ 10¹³ s⁻¹ **가정**) · Li 24개 자리를 더하면 + kT·ln 24 → **≈0.43 eV**. 즉 "고립" 은 *"그 셀에서 intercage 장벽이 ≈0.3–0.4 eV 보다 높다"* 까지만 말한다.

### 5.9 추적자 교환 (`Fig. 8`)
⁶Li 호일 사이에서 100 회 순환한 뒤 ⁶Li 신호가 두 성분 모두 커지나 24g 가 더 커졌다(×4.37 vs ×1.88) → *"24g 자리가 이온 전도에서 더 자주 방문된다"*. 이 방법은 Hu 그룹이 **고분자–세라믹 복합 전해질**에서 상(phase)별 경로를 가르던 기법(refs 31–34: LLZO-PEO, LGPS-PEO)이다 — 거기서는 상들이 공간적으로 떨어져 있어 서로 교환하지 않는다.

### 5.10 결론 문장 (stated)
① 4d 의 Br⁻/S²⁻ 혼합을 Br 총량으로 "강제" 했다 ② 최고 11 mS cm⁻¹ (25 °C) · 0.18 eV ③ ³¹P·⁷⁹Br 이 혼합을 독립적으로 탐침 ④ 1S3Br 분율이 전체 Li⁺ 점프율에 큰 영향 → 4d 30 % S · 70 % Br 인 Li₅.₃PS₄.₃Br₁.₇ 이 최고 σ ⑤ 24g 분율이 σ 와 양의 상관, 추적자 교환이 24g 가 전도에 *"instrumental"* 임을 확인 ⑥ 조성·구조 엔트로피 증가로 이온 이동이 빨라지는 현상은 다른 계에도 있다.

### 7d. 🔑 이 논문의 "기원" 논리가 우리 modelc 로 옮겨지나 — 항목별 판정

| 논리 고리 | modelc (Cl, x = 0.6) 로 이식 | 근거 |
|---|---|---|
| ① 4d 에 할로겐이 앉으면 케이지가 이어진다 | **✅ 정성적으로 옮겨진다** | de Klerk(Cl 원전) · 이 논문 `Fig. 7` (Br) · 우리 comp2 d-스캔(UMA, Cl/Br) 세 갈래가 같은 방향. modelc 는 4d-Cl 60 % 라 이 레버가 켜져 있다 |
| ② "1S3X 가 최적(75 %)" | **⛔ 숫자로는 안 옮겨진다** | 최적 % 는 방법 의존 (de Klerk 75 % · `jun2022`/`kim2024` 계열 25–50 % · `kb/concepts/ordered_vs_disordered.md` §4). 그리고 아래 ⑤ |

**modelc 서사에 쓸 수 있는 형태 (권고 문장 — 결정은 사용자)**: *"In modelc, the stoichiometry forces 60 % of the cage-center (4d) sites to hold Cl⁻; literature AIMD (de Klerk 2016; Wang 2020) and our composition-fixed comp2 ensemble both indicate that halide on 4d connects the Li cages. Li vacancies and 4d halide occupancy change together in our comp1→modelc pair, so we do not assign the transport gain to either one alone."*

## 10. 비판 — 이 논문의 약한 곳 ★

### A. 계산 근거
① **"DFT 가 1S3Br 최적을 밝혔다" 의 DFT 는 남의 계산이다.** `Table S4` 의 R_i 는 de Klerk 2016 의 **Li₆PS₅Cl · 450 K · 공공 없는 1×1×1 셀** AIMD 값과 소수점까지 같다(`deklerk2016` digest SI Table S2 대조). 표 머리말도 de Klerk 의 "4c" 표기를 그대로 달고 있다. 본문은 *"based on AIMD simulations (Table S4).15"* 로만 적는다. de Klerk 스스로 *"Br·I 는 최적 분포가 다를 것"* 이라 적었다 (`deklerk2016` §요약). 이 논문 자체 AIMD 는 밀도맵 두 장이 전부다.
② **Σ P_i R_i 는 "가장 느린 단계가 정한다" 와 논리가 반대다.** 저자는 율속(직렬) 언어를 쓰면서 배치별 율을 **산술평균(병렬)** 한다. 직렬이면 4S(율 0) 영역이 전체를 막고, 병렬이면 가장 빠른 1S3Br 이 지배한다 — 실제 다결정 확산은 그 사이(퍼콜레이션)다. 그리고 R_1S3X = 62 가 표의 최댓값이니 **1S3Br 몫이 31 → 69–74 % 로 커지는 것은 모형의 구조적 귀결**이다 (`Fig. 6b` 는 시험이 아니라 항등식에 가깝다).
③ **모형이 σ 변화를 거의 설명하지 못하는 구간이 있다.** x = 0 → 0.3: R +6.5 % vs σ +42 % (`Fig. 2b`) / +129 % (`Fig. 2c`). x = 0.5 → 0.7: R +10 % vs σ 0 %. 또 eq 4 에 있는 캐리어 밀도 n 은 x = 0 → 0.7 에서 −11.7 % 인데 `Fig. 6a` 비교에서 빠져 있다 (넣으면 예측비가 더 작아진다).
④ **AIMD 의 75 · 100 % 는 "만들었다" 만 있고 결과가 없다.** "100 % 에서 다시 고립" 은 *"100 % Cl/Br"* 이라는 표현처럼 de Klerk 결과와 섞인 서술이다. 0 % "고립" 도 100 ps · 500 K 의 부재 관측이라 **장벽 ≳0.3–0.43 eV** 까지만 말한다 (§5.8 관측창).
⑤ **AIMD 설정 대부분이 비어 있다** — 열욕 · ENCUT · k · 원자 수 · 궤적 길이(">100 ps") · 시드 · 점프 판정.

### B. NMR 해석
① 🔴 **⁶Li 24g/48h 두 성분은 물리적으로 따로 존재할 수 없다.** 분리 0.03 ppm = 2.2 Hz (⁶Li 73.6 MHz) → 두 선이 살아남으려면 교환 ≲ 10 s⁻¹. 그런데 24g↔48h 는 doublet 점프(≥10⁹–10¹¹ s⁻¹)이고, 저자 스스로 *"liquid-like"* 운동(1/τc,0 ~10¹² s⁻¹)을 말한다. 저자 자신의 계산(`Fig. S3`)은 정적 24g/48h 차를 ≈0.7 ppm 으로 주는데 실험은 0.03 ppm — **실험 선은 운동으로 평균된 한 선**이다. 그러니 두 성분 분해의 "24g 분율 37 → 50 %" 는 **결정학적 자리 점유가 아니다** (선 모양의 비대칭 — 예: 입자 표면/내부 · 조성 불균일 · 미량 상 — 을 나눈 숫자일 가능성). XRD(`Table S1`)의 24g 몫 15.4 % · 중성자(`kraft2017`) ≈12 % 와도 2.4–3배 다르다. **이 논문의 24g 서사 전체가 이 지정 위에 서 있다.** (우리 해석 — 논문에 없는 논증)
② 🔴 **추적자 교환의 자리 선택적 농축도 같은 이유로 성립하지 않는다.** 24g·48h 가 ns 로 교환하면 들어온 ⁶Li 는 즉시 평형 분포로 퍼져 **두 성분의 농축 배율이 같아야** 한다. 4.37 vs 1.88 배가 다르다는 것은 두 성분이 **서로 교환하지 않는 다른 Li 집단**(공간적으로 떨어진)이라는 뜻이다. 더해: (a) 바이어스로 반주기마다 움직이는 Li 는 ≈46 nm 어치이고 방향이 계속 바뀌므로, ⁶Li 를 넣는 것은 **자기확산**(√2Dt ≈ 1.6 mm)이다 — "경로가 ⁶Li 로 칠해진다" 는 그림이 맞지 않는다. (b) Li 금속과 100 h 접촉하면 argyrodite 는 Li₂S · LiBr · Li₃P 계면상을 만든다 — **⁶Li 가 많은 계면상**이 차 스펙트럼에 섞였을 수 있고, `Fig. 8a` 의 큰 선폭 증가가 그 신호일 수 있다. 논문은 둘 다 논하지 않는다. (c) 막대(70 : 30)와 차 스펙트럼 적합(65.3 : 34.7)이 5 %p 다르다. (d) x = 0 한 번뿐. 이 기법은 원래 **고분자–세라믹 복합체**(상들이 공간적으로 분리)용이다(refs 31–34).
③ **³¹P 5성분 분해의 자유도가 크다** — 성분 위치·폭을 x 마다 움직였고(≈1 ppm), 저 x 스펙트럼은 넓은 덩어리다. 성분 지정(P1–P5)은 단조 가정이며 **배치별 ³¹P 계산이 없다**. P 에서 4.98 Å 의 **4a 이웃 6개**(그것도 S/Br 혼합)는 무시했다.
④ **이항 "무작위" 검정은 1-파라미터에 고정돼 있다** — 파랑 점이 y = P1^(1/4) 로 계산된 것으로 역산되고(4S 패널 완전 일치), 박스 라벨 y(헤드라인 "70 % Br")와 고 x 에서 3–4 %p 어긋난다 (우리 역산).
⑤ **⁷⁹Br 의 "좋은 일치" 는 ±15–23 %p 오차막대 안의 일치**다.
⑥ **⁷Li T1** — 변온 데이터 없음 · 측정 조건 미기재 · 빠른 운동 극한 가정의 근거가 ref 30 에 기댄 한 문장. Li 희석(×0.883)만으로 T1 ×1.13. 스핀 3/2 의 사중극자 완화는 BPP 쌍극자 식에 없다.

① **우리 comp2 d-스캔은 이 논문 `Fig. 7` 의 UMA 판이다.** 같은 1×1×1 셀 · 같은 4d 할로겐 축(0/50/100 %) · Li₆ 고정. 이걸 *"공공 없이 4d 레버만으로 케이지가 이어진다"* 의 우리 쪽 대조군으로 쓸 수 있다 — 단 d = 0 (comp2 ordered) 의 게이트가 아직 미검사이고 d = 1.0 은 측정 실패 상태다. 정식 주장이 되려면 **결과 전에** 그 둘의 처리(긴 궤적 또는 큰 셀)를 보고량 카드로 정한다.
② **T0 재분석 두 가지 (새 계산 0회 · 기존 궤적)**: (a) 우리 궤적에서 Li 의 **24g/48h 체류 분율**을 세면 `Fig. 3c` 의 계산판이 된다 — 우리 MD 는 자리를 *정의*할 수 있어 NMR 지정 문제가 없다. ③ **modelc 장식의 민감도**: 우리 modelc 는 "최소 반전" 장식(4a Cl 100 % · 4d 60 %)이고, 실험 Cl-rich(`adeli2019` 중성자)는 4a 에 S 38.5 % · 4d-Cl 83 % 다. 이 차이가 우리 결론(전자구조 · 탄성 · 수송)을 얼마나 움직이는지는 **미검토**다 — 장식 하나를 더 두는 것은 새 계산이라 보고량 카드부터.

## 15. 기법 용어 미니사전
- **4a / 4d (argyrodite 자유 음이온 자리)**: F-43m 에서 PS₄ 에 속하지 않는 음이온 자리 둘. **4d = Li 케이지의 중심**(Li 24개가 둘러쌈), 4a = 케이지 사이. 문헌마다 원점 설정이 달라 de Klerk·Adeli 는 같은 자리를 **4c** 로 부른다.
- **24g / 48h**: Li 자리. 48h 는 S₃X 사면체 안의 비중심 자리, 두 48h 가 면을 공유하는 곳 한가운데가 24g. 48h–24g–48h = **doublet**.
- **doublet / intracage / intercage 점프**: 48h 쌍 안 · 같은 케이지의 이웃 쌍 사이 · 다른 케이지 사이. 장거리 확산엔 셋 다 필요하고 가장 느린 것이 **율속**.
- **nS(4−n)X 배치**: P 하나를 둘러싼 4d 네 자리 중 S 가 n 개인 배치. 4S · 3S1X · 2S2X · 1S3X · 4X.
- **MAS (magic-angle spinning)**: 시료를 54.74° 로 고속 회전시켜 고체 NMR 선을 좁히는 기법.
- **화학이동 / 운동 평균**: 자리마다 공명 주파수가 다르지만, 원자가 두 자리 사이를 주파수 차보다 빨리 오가면 NMR 은 **가중평균 한 선**만 본다(합체, coalescence). 두 선이 따로 보이려면 교환 속도 ≲ 2π·Δν.
- **T1 (스핀–격자 완화)**: 들뜬 핵 자화가 열평형으로 돌아오는 시간. 원자 운동의 상관시간 τc 에 따라 변하고, 빠른 운동 쪽(ω₀τc ≪ 1)에선 T1 이 길수록 빠르다. **BPP** = 이 관계의 고전 모델.
- **QCPMG**: 사중극자 핵(⁷⁹Br 등)의 아주 넓은 선을 반복 에코로 "스파이클릿" 묶음으로 받아 감도를 얻는 펄스열 (분해능은 잃는다).
- **GIPAW**: 주기 고체에서 NMR 화학 차폐를 PAW/의사퍼텐셜로 계산하는 선형응답 방법 (Pickard–Mauri · Yates).
- **⁶Li → ⁷Li 추적자 교환**: 천연 Li(⁷Li 92.4 %)를 ⁶Li 금속과 맞대어 ⁶Li 가 들어간 자리를 ⁶Li NMR 로 본다. 상이 공간적으로 분리된 복합체에서 경로를 가르는 데 쓰인 기법.
- **이항 분포 (eq 3)**: 4d 가 독립적으로 확률 y 로 S 이면 P 주변 배치 확률 = C(4,n) yⁿ (1−y)⁴⁻ⁿ.
- **Nernst–Einstein · Haven 비**: σ = n q² D/(H_R k T). H_R = (추적자 D)/(전하 D) — 상관된 운동이면 1 보다 작다.
- **σ-아레니우스 vs σT-아레니우스**: σ = σ₀e^(−Ea/kT) 로 맞추면 σT 로 맞춘 값보다 Ea 가 ≈kT(여기선 0.029 eV) 작게 나온다. D 의 Ea 는 σT 쪽과 같다.
- **화학량론 최소 반전**: Li₆₋ₓPS₅₋ₓX₁₊ₓ 에서 X 가 1+x 개인데 4a 는 1 개뿐이라 **x 만큼은 반드시 4d 로** 가야 한다. 그 이상이 진짜 4a↔4d 반전(anti-site).
- **관측창 (MD 부재 관측)**: 길이 t 의 궤적이 못 보는 장벽 하한 Ea_max ≈ kT·ln(ν₀ t) (+ kT ln n).
