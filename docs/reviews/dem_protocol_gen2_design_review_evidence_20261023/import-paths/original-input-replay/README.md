# 보존된 원 검토 입력의 재현

원본 ZIP의 전체 docs 문맥을 저장소 밖 새 폴더에 풀고 그 안의 원 도구·초안·독립 결과를 사용했다. 실제 argv·도구/원 입력 지문·rc는 `receipt.json`, 네 probe rc 0과 일곱 비교 true는 `replay-summary.json`, 표준 출력은 `replay.log`에 보존했다. 개별 새 raw 출력은 영수증의 외부 출력 폴더에 그대로 있으며 원 검토 raw 결과는 ZIP에도 있다. 경로 정규화된 live 요청서와 원 요청서의 SHA가 같다는 주장이 아니다. 원 도구와 원 JSON은 수정하지 않았다.
