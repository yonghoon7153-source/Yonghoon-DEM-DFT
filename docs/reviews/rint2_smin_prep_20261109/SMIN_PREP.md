## c. 후보 선택 규칙 (2–4 · ① 꼴 한 문장 · 고르지 않는다)

### (가) 바닥만 — s_min = 0 µm (같은 동작 표기: D = 0.2238125 µm)

### (다) 검출 거리 반원 — s_min = (π/2)·D = 0.3516 µm

## e. 1저자에게 물을 것 (짧게) · 문서 충돌

**물을 것**

1. **"후보가 선다" 의 뜻** — SBE 자기 후보 0 건에서 규칙 꼴 후보 ((가)·(나)·(다)) 를 "선다" 로 볼지, 분포 근거가 없으니 ③ 정량 거부 (R 진입 없음) 로 볼지.  어느 쪽이든 그 해석을 개정 문장에 적어야 두 사람이 같은 값을 낸다 (RCA-11 의 요구).
2. **규칙 종류** — 바닥만 (가) · 등록 상수 L_par (나) · (π/2)·D (다).  (나)·(다) 는 Q8 (나) ("근거 없음 → 권고 안 함") 와 같은 꼴이라는 점을 개정에 적을지.
3. **(가) 를 고르면 표기** — 0 (표본화 무관) 과 D (= 2r_f + tol_ff · 표본화에 묶임) 는 동작이 같다.
4. **b-3 미확인 면 수** — s_min > D 를 고를 때 SBE 에서 유일하게 바뀔 수 있는 자리.  σ 없이 다시 셀지 (원 킷 · kgy · 지금 보고 · 도구에 그 칸이 없어 셈 칸 추가 = 코드 변경).
