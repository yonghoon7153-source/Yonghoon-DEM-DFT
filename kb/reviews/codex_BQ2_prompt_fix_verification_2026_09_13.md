## 0. 먼저 — 내가 철회한 것 둘

리뷰어 P0-1 을 확인하고 **스스로 철회**했다. 기록에도 박았다
(`db/properties/cascade_pilot_4b_blocked_2026_09_13.json` → `⛔⛔_회신BQ_정정_2026_09_13`).

1. **"기전 확정 = 골짜기 이동"** — 확정한 적이 없다. 수렴 반환값을 버려서 **미수렴과 다른
   최소점을 분리한 적이 없다.** 시드 3개가 다른 곡선을 낸 것은 셋 다 미수렴이어도 나온다.
2. **"안 B(연쇄)가 기전을 직접 친다"** — ①에 기댄 문장이라 같이 죽는다. B 는 여전히
   합리적 시도지만 *확정된 기전을 친다*고 말할 수 없다.

**살아 있는 것**: 실측 자체(r²·Bp·V₀ 적용 여부·E(V) 점) · §4b ① 불충족 판정 ·
*"질서 있는 H0 만 깨끗하다"* 는 **관측**. 철회한 것은 **원인 귀속**뿐이다.

**Q4 문장도 정정했다**: 내가 쓴 *"기준 부피가 구조마다 달라 비교 불가"* 는 틀렸다 —
각자의 평형부피에서 비교하는 것이 원래 v4 설계이고, 문제는 **그 기준 상태가 검증되지 않은 것**이다.

## 1. P0-1 — 수렴 기록

**한 것**: `_eos_branch` 가 점마다 `{fraction, n_steps, final_fmax_eV_A, converged, hit_step_limit}` 를
남긴다. `converged = (final_fmax <= fmax) and (n_steps < relax_steps)`.
두 갈래를 각각 `hysteresis.convergence_up` / `convergence_down` 에 싣는다.

**증명한 것 (selftest)**:
- `fmax 1e-9 · steps 1` 로 굶기면 **전부 미수렴**으로 찍힌다 + `hit_step_limit` 별도 기록
- ⚠ 픽스처 함정 하나를 겪었다: **완벽한 Cu 결정은 대칭 때문에 힘이 정확히 0** 이라
  굶겨도 '수렴' 이 된다. `rattle` 해야 이 시험이 뜻을 갖는다.

**묻는 것 Q1**: `converged` 의 정의가 적절한가? `final_fmax <= fmax` 와 `n_steps < relax_steps`
둘 다 요구하는데, FIRE 가 한도에 걸리기 **직전** 수렴한 경우를 미수렴으로 볼 위험이 있나?
그리고 *"가지 전환 여부를 확인할 수 있는가"* 라는 요구를 힘·스텝만으로 충족하나 —
**구조 자체**(예: 점별 원자 변위, 배위 변화)를 남겨야 하나?

## 2. P0-2 — 단일 가지 · 높이/모양 분리

**한 것**:
- `min(E_up, E_down)` **제거**. 보고 곡선은 **올라가는 갈래 하나**(`reported_branch: 'up'`).
  내려오는 갈래는 비교용으로만 남긴다.
- 두 갈래 차 `d = E_up − E_dn` 을 **분해**해 싣는다:
  `level_offset_eV = mean(d)` · `shape_max_abs_dE_eV = max|d − mean(d)|`
- `dE/span` 은 **남기되** 기록에 경고를 박았다: *"분모가 부피창에 딸려 줄어든다. 창이 다른
  조건끼리 같은 문턱으로 비교하지 마라."* (리뷰어의 0.04 eV 평행이동 산술 예를 재현해 확인했다:
  ±6 % 11.1 % / ±3 % 44.4 % / ±2 % 100 %.)

**묻는 것 Q2**: 올라가는 갈래를 보고 곡선으로 **고정**한 것이 맞나? 아니면 두 갈래를
**각각 적합해 둘 다 보고**하고 일치 여부만 판정하는 편이 나은가 (지금은 이력 판정에서만
각각 적합한다)? 그리고 `shape_max_abs_dE` 가 *"같은 가지인가"* 를 재는 적절한 양인가 —
더 나은(또는 표준인) 판정량이 있나?

## 3. P0-3 — 상태 승계

**한 것**:
- `eos_sweep` 이 보고 가지의 **마지막 구조**를 `_branch_atoms` 로 돌려준다
  (JSON 직렬화 직전 `process_one` 이 pop).
- `apply_v0_fixed_shape` 가 **그 구조에서** 출발한다. 없으면 원본을 쓰되
  `v0_start_state` 에 **경고를 남긴다**.
- 파일 개명: `post_anneal.xyz` → **`stage1_before_eos.xyz`**(V₀ 적용 전임을 이름이 말한다)
  \+ **`final_v0_applied.xyz`** 신설 — MD·하류가 집어갈 구조는 이것이다.
  `record['structures_written']` 에 각 파일이 무엇인지 적는다.

**묻는 것 Q3**: 보고 가지의 **마지막 점**(부피창 끝)에서 출발해 V₀ 로 되돌리는 것이 맞나,
아니면 **V₀ 에 가장 가까운 점**의 구조에서 출발해야 하나? 후자가 더 작은 섭동일 텐데,
그러면 *"연속 가지를 끝까지 따라간 상태"* 가 아니게 된다. 어느 쪽이 리뷰어가 말한
*"최종 V₀에서도 선택한 가지가 이어지는가"* 를 충족하나?

## 4. P1 — 압력 부호

**한 것**: `P_mean_GPa = −trace(σ)/3`. 편차응력은 **정의대로** `σ − (trσ/3)·I` 라 뒤집지 않았다.
`trace_over_3_GPa` 를 따로 남겨 원래 규약도 보존한다.

**확인**: EMT/Cu 로 물었다 — 0.95 압축 셀에서 `trace/3 = −7.649 GPa`, 1.05 팽창 셀에서 `+5.933`.

⚠ **selftest 가 버그를 지키고 있었다**: `chk(P_mean == trace/3)` 이 바로 그 오류였다.
지금은 압축 양수 · 팽창 음수를 **방향으로** 친다.

**묻는 것 Q4**: 기존에 이 부호로 기록된 값들(`cell_policy.residual_stress.P_mean_GPa`,
`stress_at_elastic_ref`)을 **소급 정정해야 하나**, 아니면 그 기록은 그대로 두고
"당시 규약" 을 명시하는 편이 나은가? (원장 규율상 과거 기록을 개서하면 이력이 깨진다.)

## 5. Q2 잔여 — 게이트에 빠져 있던 확인 둘

**한 것**: `fit_ok` 에 **`B₀ > 0`** 과 **`V.min() ≤ V₀ ≤ V.max()`**(측정 창 안) 을 추가했다.
옛 조건 `0 < V0 < 5·V_mid` 는 창 밖 한참을 통과시켰다 — 실측으로 `P2_Al2S3_B` 가
V₀ **5620 Å³**(셀 4066, 창 밖 38 %)로 나왔는데 그건 **외삽**이지 측정이 아니다.

리뷰어 지적대로 **B0′ < 0 이 보편적 비물리 조건은 아니다**(압력유도 연화는 실재).
게이트는 유지하되 떨굴 때 문구에 **"이 게이트는 보수적 선택이다"** 를 적어,
규칙인 척하지 않게 했다.

**묻는 것 Q5**: `0 < B0' < 15` 를 유지하는 것이 이 파일럿에서 방어 가능한 선택인가,
아니면 **B0' 를 게이트에서 빼고 보고만** 하는 편이 나은가? 우리가 필요한 것은 V₀ 이고
B₀·B0′ 는 부산물이다.

## 7. 아직 **안 한** 것 (일부러)

- 스윕 해석의 **비교 규율** — *"창 효과는 같은 fmax 끼리, 조임 효과는 같은 창끼리"* —
  는 아직 코드가 아니라 **사람이 지켜야 하는 규칙**이다. 표를 만들 때 그 축으로만 읽겠다.
- 스윕을 **다시 던지지 않았다.** 새 게이트(B₀>0 · 창 안)는 적합 결과에 **사후 적용**이
  가능하므로(원자료 E(V)·수렴 기록이 그대로 남는다) 재실행 없이 재판정한다.
- 리뷰어가 준 대안들(제약 완화 · 완화 생략 · 준조화 · 앙상블 EOS)은 **손대지 않았다.**
  리뷰어가 *"같은 양을 더 잘 재는 방법이 아니다"* 라고 했고, 길 ①은 현 보고량을 유지하기 때문이다.
