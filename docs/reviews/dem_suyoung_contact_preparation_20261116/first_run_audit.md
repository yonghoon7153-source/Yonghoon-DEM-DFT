## 2. 다음 구현의 순서

정본 docs/reviews/dem_redesign_direction_20261109/memo_v3_2.md §3-2 선택 규칙 및 §4 U6(a)를 그대로 따른다. ①둘 다 끔 → ②틈 보정만 → ③거리 판정만 → ④둘 다. F의 12셀/16셀 Φ_m 차가 0.005 이하인 첫 설정만 선택한다. 입력/종료가 동일 조건을 만족하지 않거나 목표점 미도달이면 선택값은 없음이다. 네 설정 모두 실패하면 자동으로 다른 값을 고르지 않는다.

구체 보정식은 메모가 미확인/미출처 선택으로 남겼다. 두 옵션을 작은 합성 반례로 먼저 구현하고 식·기하 표현·법선·dt 연결을 기록한다. 변형 그림의 수동 관측자 F_total을 힘 계산에 그대로 연결하지 않는다. 기존 옵션 끔 경로의 trace/평균 바이트와 ID·질량 보존을 다시 확인한다. U6용 고체량은 해상도마다 같은 정확 원판 넓이로 맞춰야 한다(메모 §4 단계0); 현재 격자 점 수만으로 서로 다른 고체량을 비교하지 않는다.
