# 수정 접촉 커널의 첫 F8–F16 해상도 대조

**질문.** 설정 ①에서 격자를 두 배로 세분하면 같은 판 변위의 아래판 압력 곡선이 얼마나 달라지는가? 11-22 F8 독립 판정과 분리해 다룰 개발 계산이다. 이 블록의 새 계산은 F16 원 ID 한 팔이다.

| 조건 | F8 (보존 반환) | F16 (예정) |
|---|---:|---:|
| 지름당 셀 · 물질점 | 8 · 9,653 | 16 · 39,053 |
| 원판 배치 · 입자 번호 | 고정 49원판 · 원 ID | 같은 49원판 · 원 ID |
| 접촉 커널 | `2cf17b1df57396ef01505a72641e01b19629bed5` | 같은 커널 바이트 |
| 판 운동 · 끝 | 고정 속도 가압 · 처음 1.2 MPa 도달 | 같은 규약 |
| 시간 간격 (코드 단위) | 0.0022463670164795577 | 0.0011231835082397789 |

F8은 확인한 반환 SHA256 `9dbf1dda91de65ecdf83c37497b8be34e9a77c6868512d97b2b4a2a438c0a69b`의 원 ID 곡선을 읽는다. 독립 검토 판정은 `docs/reviews/suyoung_u6c_f8_review_receipt_20261122/README.md`에 기록했다. 두 팔의 원판 기하는 같고 물질점 배치와 시간 간격은 각 해상도의 기본값을 따른다. 공간 세분화와 함께 시간 간격도 절반이 되므로 해상도 조합의 차이를 관측한다.

**실행.** 1저자 WSL CPU 1개. 수정 커널의 F16 소요시간은 미측정이다. 계산 자체는 1,740초에 시간 초과를 확인하고 블록은 계산 프로세스에 최대 1,800초를 준다. 배포 블록의 `CHECK_ONLY`는 F8 반환, 배포 소스, 실행 환경 및 F16 초기 상태를 확인한다. `GO_SUYOUNG_F16_CONTACT_ONCE`는 검사를 통과하면 실행 자리를 한 번 확보한다. 계산의 반환 코드가 0이면 판독 후 결과 TAR·화면과 SHA256SUMS를 반환한다. 시간 한도·접촉 미수렴 등으로 중단하면 남아 있는 추적·진단과 반환 코드를 회수한다. 자동 재시도는 0회다.

**판독.** `docs/reviews/suyoung_u6c_force_rule_20261122/rule.json`에 고정한 대로 두 팔의 실제 공통 변위에서 원표본의 합집합을 취하고 각 곡선을 선형 보간한다. 분자 N은 최대 절대 압력차, 분모 D는 F16 압력의 최대 절댓값이다. 반올림 전 20N ≤ D이면 해당 쌍이 기준 이내다. 영수증·추적·종료 조건이 불완전하거나 D가 0이면 해당 쌍은 보류한다. 유효한 초과는 초과로 기록한다. F12–F24는 미측정이며 U6(c) 전체 자격과 단계 3은 HOLD다. 판독 결과는 `grid_comparison.json`의 쌍별 상태에서 확인한다.
