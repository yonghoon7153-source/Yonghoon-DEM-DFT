# So 그림 출처 대조

동봉 생성기 build_seminar_v3.py:395는 `so2021_dem_fabrication_degradation_ductile_particles/fig_4.png`를 읽는다. 해당 정본 자산의 `figures.json`(고정 lit 핀 6e568c4f0bb7df299959fd0e77e349838ad8ac98)은 JES 168 030538 PDF의 Figure 4, PDF 6쪽을 가리킨다. 사본은 이 폴더 `so_figures_source.json`이다.

출판사가 제공한 [논문 미리보기와 Figure 목록](https://www.researchgate.net/publication/349934624_Simulation_of_Fabrication_and_Degradation_of_All-Solid-State_Batteries_with_Ductile_Particles)은 같은 상대밀도/성형압 그림을 JES 논문의 Figure 목록으로 제시하고, 첫 페이지에 DOI 10.1149/1945-7111/abed23 및 JES 168 030538을 표시한다. 출판사 제공 미리보기인 점을 페이지가 명시한다. 전체 PDF를 이번에 새로 읽었다고 주장하지 않는다.

같은 저자들의 [MethodsX 9 (2022) 101857 원문](https://catalog.lib.kyushu-u.ac.jp/opac_download_md/7161227/7161227.pdf)의 References [1]과 [2]도 JPS 508 230344와 JES 168 030538을 별도 논문으로 나누며 두 DOI를 구분한다.

따라서 p6 현재 그림의 크레딧과 [9]를 JES 논문으로 정정해야 한다. 참고문헌 16개를 유지하려면 현재 p6에만 쓰인 [9]를 교체하면 된다. JPS [9]를 반드시 유지한다면 그림을 그 논문의 실제 해당 패널로 교체하고 패널 번호도 다시 확인해야 한다. 현재 이미지를 JPS Fig4a로 계속 인용하는 선택은 불가하다.

서지 정본 카드 자체의 `abe796` 기재도 그대로 전사하면 안 된다. 출판사 미리보기와 저자 원문의 DOI는 `abed23`이다.
