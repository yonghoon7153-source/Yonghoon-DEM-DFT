### KG50Y4D2-01 · P2 — affine 저항을 낙폭 상한·잔차 기전의 하한으로 읽을 수 없음

**위치:** `docs/data/kg50_d1_end_20261031/README.md:41,47`, `docs/50kg/report_y4/draft2/slide_text_draft2.md:204,221,685`, `make_draft2_figs.py:1124`, 요청 Q3(a)/Q5(b).

`R_aff=γNv/(2A)`는 균일 수밀도와 affine 속도를 가정한 **drag/A 기준선**이다. 실제 침대의 일반 낙폭 상한은 아니다. D3에서 `9.25654/7.666=1.2074798`이라는 사실은 다른 기전이 최소 1.59054 MPa를 담당했음을 증명하지 않는다.

**반례:** 고정 바닥–스프링 k_b–점착 없는 입자 묶음(총 선형 drag Γ=γN)–스프링 k_t–등속 판을 둔다. `α=k_t/(k_t+k_b)`이면 준정상 내부 속도는 `αv`이고, 판을 같은 위치에서 고정한 뒤 정적 이완 시 낙폭은 `ΔP=Γα²v/A=2α²R_aff`다. `α=0.777007`, `k_t/k_b=3.484446`이면 D3와 같은 **9.25654 MPa**가 나온다. 입자 속도가 판보다 느리고 탄성·drag만 있어도 affine 선을 20.75% 넘는다. 이는 D3의 실제 기전을 맞춘 모델이 아니라 상한이라는 보편 주장을 깨는 반례다.

`⅔`는 균질 선형 탄성 기둥·균일 수밀도·affine 속도·준정적 초기/최종·양단 고정·접촉 이력/소성 없음 등의 조건에서는 유도된다. “1D 선형 탄성”만으로 보편적으로 정해지지 않는다. 실제 덱은 판 정지와 동시에 γ를 **0.5→10⁻⁵, 50,000분의 1**로 바꾼다. 판이 멈춘다고 입자가 즉시 멈추거나 drag가 즉시 0이 되는 것도 아니다.

또 등록의 182.4/24.2/8.32 MPa는 사전 **drag 상당압**이다. 낙폭의 수치 예측으로 등록하지 않았으므로 0.79/0.85/1.11을 예측 정확도처럼 표현할 수 없다.

**최소 해결:** 선 이름을 `감쇠 저항 규모 기준선 R_aff=γNv/(2A) (affine 가정)`으로 통일한다. “상한”, “감쇠만으로 설명 안 되는 1–1.6 MPa”, 숫자 표의 `어림 Δp`를 삭제·정정한다. 권장 문장은 다음과 같다.

> 판 정지와 전역 감쇠 감소 뒤 압력이 하락했으며, 결과 전에 제기한 감쇠 교란 가설과 정성적으로 부합한다. 기준선은 affine 속도장을 가정한 저항 규모이며, 낙폭의 일반 상한이나 예측값은 아니다. 각 기전의 정량 기여는 미분리이다.

**재현:** `python physics_review/analytic_probe.py`. 공급 값의 산술과 위 반례를 출력한다. 그래프와 원장 설명 수정으로 이 지적을 닫을 수 있으며, 실제 원인 규명은 별도다.

### KG50Y4D2-02 · P2 — R5의 절댓값합과 총 drag의 부호합 혼용

**위치:** `docs/50kg/kg50_q5_dt_damping_registration_draft_20261027.md:201`, D1 README `:48`, 요청 Q3(c)·Q4.

등록 R5는 `Σγ_type|v_z|/(PA)`다. 직접 총 drag는 `D_z=−Σγ_type v_z`다. 두 입자의 `v_z=−0.01,+0.01`, γ=0.5이면 총 수직 drag는 0, 절댓값합은 **0.01 (덱 힘 단위)**이다. 진동·역류가 있으면 같은 값이 아니다. 소산률 `Σγ|v|²`도 또 다른 양이다. [공식 fix viscous 정의](https://docs.lammps.org/fix_viscous.html)는 속도 벡터에 대한 힘을 명시한다.

**최소 해결:** 기존 R5는 `R5_abs`로 보존하고 추가 진단 `R_drag_signed=D_z/F_top`를 별도 열로 기록한다. γ·N·상별 합·상승/하강 수·같은 step 판력과 KE·단위를 함께 둔다. 판 접촉 전 분모 0이면 비율은 미정의로 남긴다. Q9의 “정지 없이 측정”이라는 저자 개정을 뒤집을 필요는 없다.

**재현:** 위 `analytic_probe.py`의 부호합/절댓값합 반례. 정의가 분리되고 판독기가 두 값을 따로 출력하면 닫힘이다.

### KG50Y4D2-03 · P2 — 보고 f는 원 솔버값이 아니라 질량보존 두께 재척도값

**위치:** `slide_text_draft2.md:356,415,429`, `run_draft2_metrics.py:641–646`; [핀의 tau_flux.py 30–32행](https://github.com/yonghoon7153-source/Yonghoon-DEM-DFT/blob/065ad7004c8f970243951d366e3ced8c28af9197/scripts/tau_flux.py#L30), 1397–1404행.

### KG50Y4D2-04 · P2 — 취소 요청 뒤 실제 차단을 확인하지 않고 감시 종료

**위치:** [d07_guard_v2_1031.sh:57–59](https://github.com/yonghoon7153-source/Yonghoon-DEM-DFT/blob/065ad7004c8f970243951d366e3ced8c28af9197/docs/50kg/d07_guard/d07_guard_v2_1031.sh#L57), `:77`; `resume_ckpt.sh:2097–2106`; 이전 한 건 GO 문서 `:143`.

**한정:** 이것은 이미 알려진 일반 관문 결함 PAI-02 자체를 새 P1로 재발견한 것이 아니다. 이전 한 건 GO가 요구한 “늦은 취소면 본 job 유무·종료까지 확인”이 v2로 자동 보장되지 않는다는 지적이다. 저자 흉내의 취소는 항상 성공하는 것으로 구성돼 있다.

**최소 해결:** “본 제출로 못 넘어감”을 “취소 요청·차단 완료 미확인”으로 바꾸고, 시험과 같은 시도의 본 job 종료까지 확인한다. 이번 한 건은 기존 수동 감독 조건을 유지해 보완할 수 있다. 무인 보장을 원하면 본 제출 전 동기 관문이 필요하다.

**재현 근거:** `guard_review/probes/model_guard_failure_paths.py`. 소스에 결속된 **독립 제어 흐름 모형**이며 실제 Bash 끝-끝 시험이 아니다. Bash 두 런타임은 명령 실행 전 Windows 초기화 오류로 막혔다. 보고서의 모형을 실제 취소/제출 관측으로 확대하지 않았다.

### KG50Y4D2-05 · P2 — 신원 출력 전 실패는 무한 대기 가능

**위치:** 같은 지킴이 `:62,68`, 실제 상태 확인 `:78–85`; `resume_ckpt.sh:1808–1811`.

실제 `render()`로 생성한 러너는 `cd ... || exit 1` 뒤에 `LMP_IDENTITY`를 출력한다. 폴더 접근 실패로 먼저 종료하면 신원 줄이 영원히 없다. 지킴이는 그 줄을 기다리는 동안 job 종료 상태·대기 상한을 확인하지 않아 “첫 5분” 검사에 도달하지 못한다. 기존 jobfail/jobgone 흉내는 신원 줄을 먼저 써서 이 경로를 덮지 않는다.

## 5. Q3 답 — 무엇을 말할 수 있고 무엇이 더 필요한가

**(a) 큰 drag가 정지 상태를 교란했다는 가설은 타당한 후보다. 정량 인과확정은 미달이다.** 세 점의 규모·사전 교란 예고·ps45 선례는 가설을 지지하지만, 서로 다른 구조·압력·단일 시드·판 정지와 γ 변경의 동시 개입 때문에 낙폭을 분해하지 못한다. ps45의 0.78은 다른 침대의 관측 하나이며 공통 환산계수 검증이 아니다.

위쪽을 +z로 잡으면 총 운동량 평형은 `dP_z/dt=F_bottom−F_top−Mg+D_z`다. 총 drag는 상·하판 힘 차에 들어간다. 그것만으로 고정 판에서의 최종 상판력 변화가 정해지지 않는다. 소실 중에는 운동량 유출도 고려해야 한다.

**(b) D1 유지+압력 표지+판정 보류는 수용한다.** “정적 압력”은 수렴 인증이 없으므로 **“이완 끝 판 압력”**으로 쓰는 편이 정확하다. SE 5개 소실의 ε_sphere 직접 변화는 **0.00085419 %p**지만, 이는 연결망·응력 영향의 상한이 아니다. 물리 비교 결론을 보류하면서 원자료를 보이는 처리는 적절하다.

**(c) 압축 덤프의 속도 합산은 다음 독립 확인으로 권한다.** 새 런 없이 평균속도 가정을 실제 값으로 바꿀 수 있다. 각 덤프의 완전성·상별 수·γ·단위·동시각 정상 thermo를 연결하고 `R5_abs`와 signed drag를 모두 기록한다. D1 2,650,000·D2 3,900,000·D3 4,450,000은 정지 순간과 시간차가 있으므로 정지값으로 대체하지 않는다. 말기 여러 프레임의 추세를 함께 보고하는 편이 낫다. 실제 파일이 이번 ZIP에 없어 이 직접 drag 측정은 수행하지 않았다.

signed drag가 작다면 큰 drag 가설에 반증력이 있다. 반대로 `D_z≈ΔP·A`만 맞는다고 원인을 확정하지 않는다. 하판력·운동량 변화·하중분담 정보 없이는 전체 힘평형과 이완 인과를 닫지 못한다.
