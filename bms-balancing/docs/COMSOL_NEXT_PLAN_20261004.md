## §1 갈래 A — 실험 대응 ("이 모델이 실제 셀을 나타내는가")

### A-1. 지금 가진 것 · 없는 것

- **모델의 근거:** 규진팀 MSC 연구 (Fe 삽입 액체셀 — SEM l.59 · 68) 의 COMSOL 모델을 재구축한 것이다. 열화 파라미터는 α·β 적합 결과
  XLSX 네 개 (ref1 · ref2 · PE1 · PE5 · 37 행) 중 ref1 cycle 2 한 줄에서 왔고 (MPHR §2 l.128–139), 우리가 본 것은 그 XLSX 의 **간접
  리뷰**뿐이다 — 원 곡선 · V/I/t/T 원시 trace · 시험 SOP · half-cell 곡선 · 적합 코드가 없다 (MPHR l.664–665 · READY l.46). 파일 이름의
  ref / PE 가 어떤 셀 · 조건인지는 이 자료로 정하지 않는다. 프로토콜은 "0.1C · 12 h" 한 줄 (MPHR l.429 · SPEC l.220). 셀 면적 A_cell
  1.53938 cm² 는 후처리 환산에만 쓴다 (SPEC l.60 · 73).
- **대조에 맞춰야 할 모델 정의:** 1D 52 / 25 / 44 µm · 면적 기준 1 m² · 0.1C = 2.5036 A/m² **정전류 충전** (실행된 모델은 고정전류다 — READY l.66.
  SPEC §4-5 (l.201–221) 의 CDC · CV 4.25 V · 12 h 휴지 설계는 별도 사전진단 fixture 에서만 시험됐다 — READY l.74–75) · 시작 평형 **2.1653 V**
  (원본 3.0524 V 에 맞추지 않았다 · 프로토콜 방전 하한 2.7 V 보다 깊다 — SPEC l.297–301 · §37-4 질문 3 l.3028 · L5 l.3039) · 298.15 K 등온 · OCP = COMSOL 라이브러리 MCMB 흑연 / NMC811 (규진팀 half-cell 곡선과
  다르다 — MPHR M3 l.319–343) · 보호 범위 밖 외삽 금지 · 표 안 평형 상한 4.18556 V (CV 목표 4.25 V — SPEC l.309 · 397).
- **대응 대상이 아닌 자료:** Lai 2025 공개 자료 (6S2P 18650 모듈 · 셀 1 에 설계 저항 55–330 Ω · FUDS — SEM l.537 · 542) 는 셀 형식 ·
  규모 · 시험이 달라 이 모델의 대응 대상이 아니다 — COMSOL 쪽 "유한 누설" 과 이름만 겹친다 (ISC l.152–155). REIL-UConn (LFP) 도 무관하다.

### A-2. 필요한 실험 자료 — 요청 목록 (자료 주인 = 규진팀)

**최소 — 이것 없이는 대응을 시작할 수 없다:**

1. 대상 셀 하나 이상 (정상 1 · 가능하면 같은 제작 묶음의 단락 1) 의 **원시 시간–전압–전류 (–온도) trace** — 0.1C · 12 h 시험 그 자체 ·
   샘플링 간격 · 시각 기준 · 단위 · 기기.
2. 그 시험 **직전의 이력** — 휴지 시간 · 시험 시작 OCV · 직전 단계 (방전 하한 2.7 V 도달 여부 · CV 유지 여부). 모델 시작 상태 (2.1653 V)
   와의 차를 정하는 데 필요하다 (SPEC §37-4 질문 3 · L5).
3. **셀 구성** — 전극 면적 (A_cell 1.53938 cm² 확인) · 전극별 두께 · 적재량 (mg/cm²) · 활물질 비율 · 공극률 · 분리막 · 전해질 조성. 모델의
   면적당 용량 Q_el 25.036 Ah/m² 와 대조한다 (SPEC l.258 · READY l.54).
4. **정상 / 단락 분류 기준** — 단락 셀을 어떻게 만들었고 (Fe 삽입 위치 · 양 — SEM l.59 · 68) 무엇으로 단락이라 판정했는가 (전압 강하율 ·
   누설 전류 · 저항 측정 여부) · XLSX 네 개 (ref1 · ref2 · PE1 · PE5) 가 각각 어떤 셀 · 조건인가.

**있으면 좋은 것 — 대응을 넓히거나 확신을 높인다:**

5. 전극별 **half-cell OCP 곡선** (적합에 쓴 것) 과 α·β 적합 코드 또는 그 산출 원본 — OCP 출처 차이 (라이브러리 ↔ 실측) 를 판단한다.
6. 온도 기록 · 반복 셀 (편차 · 재현성) · 같은 셀의 다른 C-rate.
7. 원본 모델 비교값 3.0524 V 가 어느 dataset / solution / savepoint 의 무엇인지 (READY l.53 · l.62 — 원본 파일 SHA · dataset / solution /
   savepoint · 대상 실험 셀 / cycle / 시작 상태를 "한 묶음" 으로).

자료마다 출처 · 라이선스 · sha256 을 붙여 받는다. 원자료는 저장소에 넣지 않고 식별만 남긴다 (기존 원칙 — SPEC l.12–13).

### A-4. 완료 기준

- **A0:** 대응표 v1 의 모든 행이 모델 값 (원장 줄 인용) 과 실험 값의 상태를 갖고, 요청 문안이 자료 주인에게 보낼 수 있는 형태로 있다
  (보낼지는 사용자 결정).
- **A1–A2:** 받은 자료마다 식별 · 단위 · 환산 검사 결과가 표에 있고, 비교 사양이 비교 **전에** 커밋돼 있다.
- 갈래 A 의 첫 결론으로 허용되는 문장은 "어느 입력이 실측과 **맞고 / 다르고 / 확인할 수 없는가**" 까지다. "모델이 실험과 맞는다" · "OCP 를
  바꿔야 한다" 는 비교 전에 쓰지 않는다 (SPEC §40-2 · S2 l.2854).

파라미터 맞춤 · OCP 교체 · 시작 상태 변경 · 유한 σ 실행 (SPEC §8-5 ④ l.344 — OCP / 실험 비교 뒤) · Lai 자료와의 직접 대조.

## §2 갈래 B — 공간 해상도 민감도 ("해가 공간 이산화에 둔감한가 — 기울기가 발달한 상태에서")

### B-1. 이미 한 것 — 모두 초기 얇은 경계층 창

| SPEC | 비교 | 창 | 최대 \|ΔV\| | 판정 (1 mV · 1e−4) |
|---|---|---|---:|---|
| §10 (l.446–447) | 입자 40 → 80 (물리 300) | 0–1 s · 0–5 s | 2.505 mV | 미달 |
| §10 (l.448–449) | 물리 300 → 600 (입자 40) | 0–1 s · 0–5 s | 1.09e−8 mV | 충족 |
| §12 (l.624) | 입자 80 → 160 | 0–1 s · 0–5 s | 1.248 mV | 미달 · 수렴 차수 없음 (l.640–643) |
| §14 (l.796–798) | 입자 160 → 320 | 0–1 s · 0–5 s | 0.617 mV (Δx 1.04e−5) | 충족 — "이번 표본" 한정 |
| §19 (l.1336–1343) | 물리 300 → 600 (입자 320) | 0–1 s · 0–5 s (와 그 안의 0.1–1 s · 1–5 s) | 1.08e−8 mV | 충족 |

다섯 비교 모두 최대 차가 첫 0.001–0.04 s 에 났다 — 0–1 s 와 0–5 s 의 최대가 같다.

시간 cap 반감 (§11 · §13 · §15) 은 시간 축 검사라 이 표에 넣지 않는다. 30–480 s 실행은 모두 물리 300 / 입자 320 이고, 그 사이의 비교는 접두
재현성이지 메시 수렴이 아니다 (SPEC l.2908 · 2984). 1 mV · 1e−4 는 비교 한도이지 수렴 인증선이 아니다 (SPEC §10-1 l.438 · §40-2 l.3280).
ΔV 와 Δx 는 둘 다 독립 기준으로 유지한다 — 20→30 s 의 선형 OCP 구간에서 다른 항을 고정하면 음극 표면 분율 1e−4 의 전압 효과가
≈6.27 mV 라는 것은 국소 설명이지 전역 환산식이 아니다 (R5 l.2809).

### B-2. 남은 물음

R7 · L3 (SPEC l.2811 · l.3037): 위 검증은 초기 경계층 창에서만 했고 영구 면제가 아니다 — **기울기가 발달한 상태 (120 s 이후) 에서 한 번.**
입자 반경 축은 160 → 320 차가 0.617 mV 로 한도의 약 62 % 를 이미 썼고 차이가 줄어드는 차수는 확인되지 않았다 — 가장 민감한 축이다. 물리
축은 초기 창에서 1e−8 mV 급이었지만 전해질 기울기가 발달한 뒤는 보지 않았다.

### B-3. 최소 작업 범위 (안 셋 — 고르는 것은 사용자)

| 안 | 내용 | native 실행 |
|---|---|---:|
| **B-min** | **입자 320 → 640** (물리 300 고정) · fresh 0 → T (제안 T = 150 s) · 비교 창 120–T s 의 요청 시각 × 241 좌표 · 기준 해 = 기존 300 / 320 저장 해 (§38 0→240 s 또는 §39 0→480 s — 같은 정책 · rtol 1e−6) | 1 |
| **B-std** | B-min + **물리 300 → 600** (입자 320) 같은 창 | 2 |
| B-ext | + 입자 640 → 1280 (차이가 줄어드는가) | 3 — 이번에 권하지 않는다 |

- 공통: 정책 · rtol · 시간 cap · 저장 정의 · 관측량 · 241 좌표 표본 · 요청 시각은 기준 해와 같게 — **바꾸는 것은 메시 한 축씩**. fresh 시작
  (저장 MPH 에서 메시를 바꾸어 이어 풀기는 해 사상 오차가 섞이므로 권하지 않는다) · 실행마다 최대 1 회 · 실패해도 자동 재시도 · 자동 연장

- 순서: 준비본 → 변경부 한정 검증 → 수신 검토 → 사용자 승인 → native → 수신 검토. 비용은 준비본에서 추정하고 승인 때 예산을 고정한다 (입자
  640 은 입자 방향 자유도가 두 배다 — 기존 300 / 320 실행의 실측 시간을 기준으로 추정 · 지금 숫자를 만들지 않는다).

### B-4. 완료 기준 · 판정 범주 (결과 전에 고정)

- 지표: 비교 창의 정확 공통 요청 시각에서 최대 \|ΔV\| (z = 0 과 z = 121 µm 집전체 차) 와 전극별 241 좌표 pointwise 최대 \|Δx_surf\| — 기존
  정의 그대로 (SPEC §10-1).
- 한도: 1 mV · 1e−4 (기존 비교 한도 · 수렴 인증선 아님 · 둘은 독립).
- 판정 범주:
  - `WITHIN_LIMITS_THIS_WINDOW` — 이 창 · 이 표본에서 한도 안. 그 축의 "발달한 기울기에서 한 번" (L3) 이 닫힌다 · 수렴 증명은 아니다.
  - `EXCEEDS_LIMITS` — 그 축의 해상도가 이 창의 선언 관측량에 한도 이상 영향을 준다 → 기준 해 (300 / 320) 의 그 창 결과에 "해상도 의존"
    라벨 · 다음 조치는 별도 결정.
  - `INCONCLUSIVE` — 실행 실패 · 공통 시각 부족 · 보호식 발동 등.
- 보고: 초기 창 (§14 · §19) 과 발달 창의 차이를 나란히 둔다 — 커졌는가 / 줄었는가 (차수 주장 없이).

### B-5. 하지 않는 것

수렴 차수 · 수렴 인증 · 480 s 후반 전체 · 시간 연장 · rtol / σ / 물성 / 전류 변경 · 유한 σ 실행.

## §3 두 갈래의 관계와 순서 (우리 의견 — 결정은 사용자)

- A 는 "이 모델이 실제 셀을 나타내는가", B 는 "이 해가 공간 이산화에 둔감한가" 를 묻는다 — 서로 대신하지 않는다 (SPEC §40-3).
- 둘 다 **유한 σ 대비** (모델의 존재 이유 · SPEC §37-4 질문 1) 의 전제다. A 는 정상 기준선이 실측과 같은 자리에 있는가, B 는 유한 σ 대비가 공간
  이산화 차이보다 큰가를 정한다. ~~시간 허용오차 바닥은 0–30 s 에서 µV · 1e−8 급이었지만 (§41), 공간 바닥은 초기 창의 입자 축에서 0.6 mV 급까지~~
  ~~관측된 적이 있다 (§14).~~ **(정정 2026-10-04 · SPEC §42-3)** rtol 1e−6 ↔ 1e−7 두 설정 간 관측 차이는 0–30 s 에서 µV · 1e−8 급이었고
  (§41), 입자 메시 160 ↔ 320 두 설정 간 관측 차이는 초기 창 (0–5 s) 에서 0.617 mV 였다 (§14) — 어느 쪽도 오차 바닥 (참값과의 오차의 하한) 이
  아니다.
- 제안 순서: **A0 먼저** — 계산이 0 이고 바로 할 수 있으며, 자료 요청은 왕복에 시간이 걸리므로 일찍 보내는 쪽이 낫다. **B 는 A0 와 나란히**
  할 수 있지만 계산 비용이 있으므로 사용자가 B-min / B-std 를 고른 뒤 준비한다. 유한 σ 실행은 A2 의 비교 창과 B 의 결과가 정해진 뒤 (SPEC
  §37-6 (e) l.3064 · L7).
