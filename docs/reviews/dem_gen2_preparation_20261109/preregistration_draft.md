# T5/T11 결과 전 등록 문안 — 미완성 초안

상태는 **DRAFT_UNREGISTERED**다. 실제 과학 자격 T5/T11/T12는 NOT_RUN이고 `physical_ready=false`다. 승인된 로컬 생산자·시험 개발은 진행할 수 있다. 수치가 비어 있다는 이유로 과거 Q1–Q16/A1–A5를 재비준 대상으로 만들지 않는다.

정본 §12 A3/A5가 과거 표의 단일 1σ 규칙과 k_p=30 보편 이식 해석에 우선한다. 다음 표와 `preregistration_draft.json`은 동일 문안이며, 최종 등록은 구체 수치·코드 핀·판정 규칙·미리 정한 사례/seed가 결과를 보기 전에 고정되어야 한다. 단순히 null을 채운 JSON만으로 자격이 성립하지 않는다.

## T5: 공극 연산자

| 등록 항목 | 초안 요구 | 실제 등록값 |
|---|---|---|
| estimand | 정확 union과 sphere를 분리; 동일 프레임·고정 ID·판/바닥·PBC·전체/안쪽 영역 정의를 보존 | 실제 프레임·영역 수치 null |
| 해석해 | 두 구의 접촉/비접촉/겹침, 삼중 교집합이 있는 세 구, 벽 절단 구. 쌍 렌즈를 정확 union이라 부르는 반례를 포함 | 사례 좌표·크기·허용 오차 null |
| 오차 | 표본오차 추정식·편향·수치 오차·기하 불일치를 구분 | 오차식의 실제 채택판·폭 null |
| 수렴 | 결과를 보고 표본 수를 고르는 방식 금지; 미리 정한 표본 수 사다리와 재현 가능한 seed/반복 | 사다리·seed·반복 null |
| coverage | 반복별 구간 포함 여부와 사전 평가법; 단일 1σ 결정적 합격 금지 | coverage 목표·평가 문턱 null |
| 실패확률 | 다중 사례의 합성 판정과 허용 실패확률·누락/기술 실패 처리 | 실패확률·다중 사례 규칙 null |
| 독립 오라클 | 구현 경로와 독립한 해석값/수식; 구현 값을 다시 기대값으로 복사하지 않음 | 봉인할 오라클 핀 null |

T5 오프라인 예가 통과해도 실제 침대에서 union의 편향/coverage가 확보됐다는 뜻은 아니다. sphere와 union은 실험 질량/기하 연산자가 다르며, union 보정이 실험 질량 공극 보정의 증거가 되지 않는다. 경계와 PBC가 누락된 단순 구 예를 전체 물리 BOX 자격으로 확대하지 않는다.

## T11: 이산 서보

선형·무지연·비포화 예의 `e[n+1]=(1-a)e[n]`는 가드 시험의 작은 오라클이다. 그 모형 밖의 실제 침대 강성·접촉 이력·시간 지연을 측정한 결과가 아니다. 실제 단위와 변환을 적어 `a=K*k_p*v_max*DeltaT/F_target`의 각 인자가 혼용되지 않게 한다.

| 등록 항목 | 초안 요구 | 실제 등록값 |
|---|---|---|
| 모델/범위 | K·응답 지연·dt/제어주기·포화·부호의 범위를 명시 | 범위·분포·대응 침대 null |
| 정상 예 | 등록 범위 내부에서 유효 창 수렴·추가 유지 확인 | 수렴 창·폭·추가 유지 null |
| 경계/음성 | 무감쇠 진동·발산·부호 반전·지연·포화 고착·비유한 값·stale 관측·예산 소진을 거부 | 각 경계·guard 문턱 null |
| 물리 수지 | 판 압력 외 병진/회전 KE·중력·감쇠·관성·총힘/토크·보존 결합 | 실제 수치 예산 null |
| 시간 | 물리 시간 기준의 창/예산과 dt/2 정수 step 환산 | 등록된 시간·반올림/거부 규칙 null |
| 결론 | 제어용 수렴과 독립 재판독 분리; 예산 소진 NOT_CONVERGED | 실제 자격 영수증 null |

어떤 fixture 상수도 별도 등록 없이 실제 E 사다리/침대/주기에 이식하지 않는다. 포화가 있거나 지연이 있으면 선형 a 구간만으로 안정성을 승인하지 않는다. 모의 시험은 실제 move/mesh 반복 문법·판 접촉 이력·실제 바이너리 또는 S0 직렬화와 소비를 검증하지 않는다.

## 합성 상수와 실제 사실

코드 시험은 손으로 계산 가능한 기하·단위 없는 응답·작은 완전 재고를 사용한다. 그 상수는 코드 핀과 시험 영수증에서 그대로 식별하고, 이 문안의 실제 과학 수치 null을 덮지 않는다. 합성 PASS는 `synthetic_only`로 보고한다. 실제 T5/T11 등록 완료, 정적 300 MPa/R-a 자격, T12 소비 접합, 연구 실행 GO는 각각 별도 사실이다.

50 kg·0.7/1 µm 비교는 같은 압력·단계·물성·단위·관측 연산자의 대응 비교로 설계한다. 하중 정의와 면적이 없으므로 압력 환산은 미정이고, 93.4%/65%는 사용자 과거 인용으로만 남긴다. 실제 결과행은 0이다.
