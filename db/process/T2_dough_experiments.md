# T2 건식 도우 실험 — 프로토콜 + 결과 로그

> 목적: Poly-rich(7:3) 합제가 도우(떡)가 안 되는 공정 문제 해결. 진단·가설은 `../../TROUBLESHOOTING.md` T2.
> 순서(확정 2026-06-26): **① 2nd Thinky rpm → ② 온도(외부가열) → ③ ball-mill only.**

## 공통 조건 (고정)
- 조성 **P:S = 7:3** (대립:소립 = 70:30), **AM:SE:VGCF:PTFE = 80:18:1:1**, 2 g base, 동일 로트.
- 대조군: **단결정 only(3:7 또는 S only)** 같은 공정으로 동시 진행(=도우 되는 기준).
- 매 실험 **합제 온도 IR 측정**(혼합 직후) — shear 효과 vs 열 효과 분리에 필수.

## 도우 등급 (grade) — 결과 표에 공통 사용
| grade | 상태 |
|---|---|
| 0 | 완전 파우더 (응집 X) |
| 1 | 약한 응집 (덩어리지나 취급 시 부스러짐) |
| 2 | 부분 도우 (취급 가능하나 롤링 시 갈라짐) |
| 3 | 완전 도우 (freestanding, crack-free) ← 목표 |

## ① 2nd Thinky rpm test (강도 레버 검증)
- 고정: ball-mill 200rpm 1h(표준), Thinky 시간 동일(예: 5min). 변수: **2nd Thinky rpm**.
- 측정: 도우 grade, 합제 온도(IR), 외관(가루/뭉침/balling/벽타고오름).
- ⚠ confound: rpm↑=발열↑ → 온도 같이 기록. (가설: rpm↑이 미디어 더 pinned → impact 안 늘 수도 → flat 예상)

## ③ Ball-mill only (2nd Thinky 생략)
- 근거: 2nd Thinky가 ball-mill 도우를 *tear*(부숨) → **Poly-rich엔 2nd Thinky 빼고** ball-mill → 바로 롤링.
- 고정: 7:3, 2nd Thinky 생략. 변수: ball-mill **시간(1h/2h)**, ± 가열.
- 측정: 도우 grade, **단면 SEM(섬유망)**, **Poly SEM 전/후(파쇄 체크)**, 균일도(EDS맵/외관).
