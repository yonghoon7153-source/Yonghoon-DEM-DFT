## 3. 알려진 한정

새 13개: 수정 전 실패메서드12(하위 assertion56·오류4), 수정 후13/13. 기존 조립7/7. 내부 리뷰는 외부 판정이 아니며 최초 diff 첫부분에 작성 측 원장·설명 일부가 노출됐으므로 완전한 설명 비노출 리뷰라 쓰지 않는다. Windows에서는 audit 함수 AST를 그대로 추출한 국소 시험이고 러너는 정적 확인이다. POSIX 전체 store/e2e·신호 suite·실제 실행은 미실행이다. serialized hash 기록은 자기 보고이며 임의 위조를 인증하지 않는다. DOF 원번호 생략 시 같은 코드의 순서 전제를 계속 명시한다.

기존 원장 상태는 이 리뷰로 자동 승격하지 않는다. 발견마다 P등급·반례·최소 수정·보존 조건·종결 범위를 회신한다. 원 ZIP/소스/로그는 덮어쓰지 않는다. 실제 신호 실험이 필요하면 이 요청에서 실행하지 말고 별도 namespace·실행 범위를 먼저 명시한다.
