# v0.3 — 코팅 · 실제 장비(Thinky) · 반데르발스로 다시 세우기 (2026-09-20)

> 코팅은 침대를 다시 흐르게 한다. Thinky(268 G) 는 코팅 없이도 흐른다. **그리고 우리는 "섞이나"를 아직 잰 적이 없었다.**

## 쉬운 판

세 가지를 한 번에 했다. ① 활물질 표면을 황화물로 코팅하면(표면이 전해질처럼 됨) 덩어리가 풀려
**다시 흐른다**. ② 실제로 쓰는 장비는 60 rpm 드럼이 아니라 **Thinky(약 2000 rpm)** 라는 것을
알게 돼서, 중력 대신 점착을 1/268 로 낮춰 같은 물리로 맞췄다 — Thinky 조건에선 코팅 없이도 흐른다.
③ "끈적하다"는 말을 **반데르발스/표면에너지**로 바꾸고 문헌(`hare2026`, NMC622 · CGF 200)에서
`Bo ≈ 3` 앵커를 찾았다.

그런데 이 시점에 1저자 질문 *"우리가 보고 싶은 걸 볼 수 있는 거야?"* 로 큰 구멍이 드러났다:
침대를 **처음부터 섞인 상태로 넣고** 돌렸기 때문에, 지금까지 잰 건 "뭉치나/흐르나"이지
**"섞이나"가 아니었다**. 이건 v0.6 에서 고친다.

## 자세한 판

- 코팅 `C1`: AM 쌍 CED 를 SE-SE 값으로 **덮어쓴다**(입자 크기·질량 불변 → `Bo` 는 따라 나온다). 결과 `Bo` 0.0235. 등록 검정은 `E1` 대비 h0(0.57·SE)이나 `E4→C1` 로는 범위의 85 % 회복, `core_frac` ×1/24.
- 고-G: 1저자 정정 — 영률 1e7 은 임의 연화가 아니라 **스케일 팩터**(압축 덱이 `P/E` 를 보존). 중력을 올리면 `Π₁ = ρaR/E` 가 5.7e-6 → 1.5e-3 로 실제(5.4e-10)에서 **멀어진다** ⇒ `Bo` 만 1/G. `T1`(Thinky, Bo 0.079) 1.527 · `T2`(볼텍스 45 G, Bo 0.472) 1.750 · `E4` 2.016 — 단조.
- vdW 재정박: `hare2026` γ 0.25 J/m² → Bo 3.0, `frankenberg2024` Γ 0.0045 → Bo 3.3. γ 는 55배 달라도 Bo 는 같은 대역 ⇒ 전이 대상은 **Bo**. ⚠ 우리는 SJKR 이라 γ 를 못 넣고 `MIX-07` 로 등재.
- `MIX-08`(P1): 삽입이 `insert/pack … once` 로 5 상을 한꺼번에 무작위 배치 → t=0 이 이미 완전혼합(칸별 AM 분율 sd 0.0383). **"섞이나"는 잰 적 없음.** 이 이전의 모든 결론은 유동성 축으로 라벨을 고쳤다.
