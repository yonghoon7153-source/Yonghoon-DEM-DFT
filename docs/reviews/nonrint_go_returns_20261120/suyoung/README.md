설정 ①(틈 보정·거리 판정 모두 끔)에서 두 해상도의 Φ_m 차이가 개발 기준 0.005 이내였다. 결과는 같은 49원판 초기 배열의 **아래판 압력이 처음 1.2 MPa에 도달한 시점**에 한정한다.

반환값 기준 절대차는 **0.0049569399919755**(0.495694%p), 판정선까지 여유는 **0.0000430600080245**(0.004306%p)다. 반올림 전 보간값을 사용했다. 두 점으로 얻은 격자 차이만 관측됐고 연속체 해에 대한 오차는 미측정이다. 반환 지위는 `WITHIN_DEVELOPMENT_BAND`, `selected_setting=null`, `u6_qualified=false`다.

## 교차 검사

- 묶음·화면 SHA256 2/2, command/포장 rc 0을 확인했다. 실행 TXT의 고정 소스 tar를 읽어 반환의 소스 목록 7/7을 대조했다. 다섯 파일은 각 Git 핀의 blob, 두 파일은 핀 문자열과 일치했다. 계산 소스 `00f0a1758`, 실행 드라이버 `a84488223`.
- 이번 F12 반환 JSON, 이전 F12 원 JSON과 실행 블록에 든 참조 JSON은 바이트가 같다. 이전 F16의 0–5,242 step(5,243행과 헤더, 431,007 B)이 새 trace의 앞부분과 같다.
- F12 기존 trace 4,985행, F16 새 trace 6,522행의 step·시간·판 높이·충전율을 대조했다. 두 팔 모두 최초 압력 통과 사이에서 높이를 선형 보간하고, 49개 원판 기준 면적을 그때의 상자 면적으로 나눴다. 독립 산술로 얻은 F16은 0.9850740317357707로 반환값과의 차이는 2.3×10⁻¹⁶ 이내다.
- 1.2 MPa는 메모의 3a 단축 항복 0.4 MPa의 세 배다. 이 2D 면적 비율을 순수 SE 3D 실험 공극률과 견주려면 하중 상태·측정 시점·시료·관측량이 일치하는 대조가 더 필요하다. 앞서 4원판에서 얻은 S/F=2.469는 다른 개발 계산에서 온 값이다.

## 다음 개발 작업

1. 순서 2의 개발용 기본값으로 이번 설정 ①을 사용한다. S/F 판 응력이나 입자 그림으로 F 접촉 설정을 다시 고르지 않는다. 메모의 정식 U6(b)는 고정 설정에서 S·F 양쪽의 같은 Φ_m 응력을 8·12·16·24셀로 대조한다. U6(c)는 다물체 접촉 위반과 ID/장 순서 변경에 따른 응력 차를 본다. 이번 반환에 이 두 판정 자료는 없다.
2. 형상 개발 루프에서 같은 물질점·입자 ID·위치·속도·재료 상태를 가압 → 판 정지 이완 → 판 상승 → 분리 후까지 전달한다. 이번 U6 반환에 점별 재시작 상태는 없다. 새 형상 런의 초기 상태부터 같은 모델을 잇는다.
3. 가압 끝·이완 끝·상승 중·분리 후의 실제 계산 step에서 단면, 판 위치와 반력, 판–재료 간격을 함께 저장한다. 정상력이 0이 된 시각과 기하 간격이 양수가 된 시각은 각각 기록한다. 같은 ID 색·시야·판 위치로 S/F를 대조하고 물질점 기준 겹침과 셀 그림 기준 겹침을 구분한다.
