# Part A. 왜 이 절차인가 (P1–P4, ≈4분)

## P1. 표지 ⏱40
오늘 발표의 중심은 특정 도펀트 하나가 아닙니다. LPSCl 을 개선하려고 여러 치환 후보를 계산하는 동안, **무엇을 믿고 무엇을 탈락시킬지 결정하는 절차** — cascade — 를 말씀드리려고 합니다. 마지막에 나오는 것도 승자 선언이 아니라, 다음 DFT 와 실험이 갈 수 있는 **짧고 방어 가능한 후보 목록**입니다.
→ "먼저, 왜 이런 절차가 필요한지부터 보겠습니다."

## P2. Context — 계면 문제 ⏱70
Argyrodite LPSCl 은 이온전도성과 가공성이 좋지만, 산화 안정성과 계면, 접촉·기계 문제를 동시에 만족하지는 못합니다. 화면 왼쪽은 문헌의 coating 개요도인데 — coating 이 저희 치환과 같다는 뜻이 아니라, **하나의 처방이 Li 쪽·전해질 쪽·양극 쪽 계면을 전부 통과해야 한다**는 문제 구조의 예시입니다.
→ "그래서 단일 지표가 아니라 절차가 필요합니다. 그 절차의 입력이 얼마나 큰지 보시죠."
🛡 *coating 논문을 왜 치환 발표에?* → "처방 종류가 아니라 '여러 계면을 동시에 통과해야 한다'는 문제 구조의 예시입니다 — 캡션에도 coating ≠ substitution 을 적어 뒀습니다."

## P3. Motivation — 91 × 3 = 273 ⏱70
치환은 재료 하나를 수백 개의 결정으로 바꿉니다. 어떤 화합물을, 어느 농도 라벨로, 결함을 어디에 앉혀, 무엇을 볼지 — 곱으로 늘어납니다. 저희 캠페인은 사람이 고른 화합물 91종 × 세 개의 명목 라벨 = **273개 실행 슬롯**이었습니다. x002 같은 표기는 **명목 라벨**이지 실제 조성이 아닙니다.
→ "이 규모를 실험으로 다 볼 수는 없으니, 계산이 우선순위를 좁힙니다."
🛡 *273종을 다 계산했나?* → "273은 물질 수가 아니라 91종 × 3라벨의 실행 슬롯 수입니다."

## P4. Cascade — 비용 배치 ⏱60
Cascade 는 계산을 많이 돌리는 기술이 아니라 **비용 배치 전략**입니다. 싼 단계에서 넓게 비교하고, 물리 게이트로 위험한 후보를 걸러낸 뒤, 비싼 DFT 와 실험은 남은 소수에 집중합니다. 핵심은 각 단계가 **무엇까지 판정할 수 있는지** 한계를 먼저 정해 두는 것입니다.
→ "그럼 이 절차에 실제로 들어간 데이터가 무엇인지 — 계보부터 보여드리겠습니다."

# Part B. 무엇을 어떻게 계산했나 (P5–P8, ≈5분)

## P5. Pool provenance ⏱80 ★
단위를 분리해서 말씀드립니다. 시도한 것은 273개 슬롯이지만, 6월 25일에 **versioned table 로 들어온 것은 산화물 37종 + 불화물 10종, 47종 × 3 = 141개 기록**입니다. 나머지 44종은 물리적으로 탈락한 게 아니라 종별 실패 기록이 없어서 **미분류**입니다. 그래서 저는 "273에서 47이 살아남았다"는 말을 쓰지 않습니다. 이후 게이트 분석은 전부 이 47종 스냅샷에서 시작합니다.
→ "이 47종에 어떤 계산을 어떤 규약으로 돌렸는지 보겠습니다."
🛡 *44종은 왜 없나?* → "manifest 가 없어 미분류입니다 — 탈락이라고 부를 근거가 없다는 것까지가 말할 수 있는 전부입니다."
※ 명단을 물으면 **부록 A1(P20)** 로.

## P6. Tiers ⏱60
계산은 세 층입니다. 아래층에서 UMA 와 저비용 프록시로 전체를 같은 규약으로 훑고, 가운데층에서 선택된 후보만 matched DFT 로 확인하고, 맨 위가 실험입니다. 모든 값에 **프로토콜 태그와 출처 파일이 따라다닙니다.** 정직한 범위는 — 47종은 상대 스크린, DFT 검증은 두 후보입니다.
→ "그 축들을 왜 이렇게 골랐는지, host 계에서 배운 것부터 말씀드리겠습니다."

## P7. LPSCl 이 가르쳐 준 것 ⏱80
Cl 을 늘린 조성과 원조성을 같은 프로토콜로 비교하면 밴드갭 차이는 0.033 eV — 사실상 같습니다. 반면 구조 쪽에서는 Li 공공과 4d 자리 anti-site 무질서가 뚜렷합니다. 그래서 스크리닝 축을 **전자구조가 아니라 구조 기술자** — 안정성·Li 경로·무질서·역학 — 로 잡았고, 전자 축은 가드레일로만 씁니다. comp1 에 인용 가능한 멀티시드 Ea 가 아직 없어서 **두 계의 수송 비교는 오늘 하지 않습니다.**
→ "이 축들을 다섯 개의 게이트로 조립했습니다."
🛡 *0.033 이 오차보다 큰가?* → "같은 프로토콜 안의 차이라 방법 오차는 공통으로 상쇄됩니다 — '작다'는 판정은 어느 쪽이든 같습니다."

## P8. 게이트 5개 ⏱80
게이트마다 질문이 하나씩입니다. G1 host 보다 안정한가 · G2 전기화학 창이 무너지지 않는가(0.05 V) · G3 산화 onset 이 host 2.14 V 보다 나빠지지 않는가 · G4 Li 경로가 유지되는가(정적 BVSE 두 컷) · G5 남은 후보를 역학으로 줄 세우는 순위 단계. 미리 한계를 말씀드리면 **G4 의 blocking 컷은 anchor 없는 heuristic 이고, G5 는 hard gate 가 아니라 ranking** 입니다.
→ "이 다섯을 순서대로 걸면 이렇게 됩니다."

# Part C. 결과 (P9–P15, ≈9분) — 발표의 중심

## P9. Waterfall ⏱90 ★
47에서 시작해 창 게이트에서 43, 산화에서 25, Li 경로에서 11이 됩니다. 마지막 G5 는 그 11을 줄 세워 하나를 고르지만 — **저는 그 1을 winner 라고 부르지 않겠습니다.** 방어 가능한 보고 지점은 G4 까지의 11종이고, 이 waterfall 자체도 문헌 기준을 사후에 투영한 분석 뷰입니다.
→ "이 깔때기를 그대로 믿기 전에, 게이트 자체를 감사해 봤습니다."
🛡 *왜 1을 안 쓰나?* → "G5 는 로스터 중앙값 순위라 물리 게이트가 아닙니다 — endpoint 는 11입니다."

## P10. Gate audit ⏱70
두 게이트가 후보보다 **풀에 대해** 더 많은 걸 말해 줍니다. G1 은 47종 전부 통과했는데, 후보가 훌륭해서가 아니라 애초에 안정한 쪽으로 큐레이션했기 때문입니다 — vacuous 라고 데이터 파일에 적어 뒀습니다. G2 탈락 4종은 전부 late 전이금속 산화물이고 넷 다 G3 에서도 떨어집니다 — unique kill 0, 중복 게이트입니다. **게이트를 감사하는 것 자체가 결과**입니다.
→ "그럼 게이트가 실제로 잡아낸 물리는 무엇이냐 — 오늘의 중심입니다."
※ 순서를 바꾸면 어떻게 되냐는 질문은 **부록 A3(P22)** 120 순열로.

## P11. 트레이드오프 1 — 산화 ↔ 수송 ⏱80 ★★
산화 onset 을 host 위로 올린 후보가 여섯입니다 — B₂O₃, Cr₂O₃, Ga₂O₃, In₂O₃, Sc₂O₃, Y₂O₃. 그런데 **여섯 전부가 같은 Li 경로 게이트에서 멈춥니다.** 한 후보의 불운이 아니라 데이터셋 수준의 트레이드오프입니다. 단서를 달면 이것이 M–O 결합이 Li 를 막는다는 인과 증명은 아니고, BVSE 는 전도도가 아닙니다. 하지만 한 후보의 약점을 다른 후보의 강점으로 메꿔 보는 — 조합의 이유로는 충분합니다.
→ "이게 저희만의 관측인지 확인해 봤습니다."

## P12. 외부 대조 — 같은 방법, 같은 질문 ⏱70 ★★
저희가 산화 축에 쓰는 grand-potential 방법의 **원저자인 Yifei Mo 그룹**이, argyrodite 실험 표준인 Zeier 그룹과 함께 2022년에 같은 질문을 던졌습니다 — *"치환으로 argyrodite 의 산화 안정성을 바꿀 수 있는가."*

그쪽 답은 **아니오** 입니다. HAXPES 가전자대 끝, DFT pDOS·COHP, grand-potential 분해창, stepwise CV 가 전부 같은 말을 합니다 — VBM 은 자유 S²⁻ 와 PS₄³⁻ 의 비결합 S 3p 가 채우고 있어서, **S 가 조성에 남아 있는 한 산화 한계는 S 가 고정**합니다.

저희 스크린에서는 산화 onset 을 올린 후보가 여섯 나왔는데, **그 여섯이 전부 Li 경로 게이트에서 멈춥니다.** 화학이 다르고 수정 방식도 다르지만 — 그쪽은 황화물 골격 **안**의 치환(P→Si/Ge, Cl→I)이고 저희는 산화물·불화물을 **더하는** 쪽입니다 — **경고의 모양이 같습니다: 한쪽에서 얻으면 다른 쪽 제약이 드러납니다.**
→ "그런데 트레이드오프가 하나 더 있었습니다. 이건 게이트가 아니라 값 검증에서 나왔습니다."
🛡 *그쪽이 안 된다고 했는데 왜 계속 하나?* → "그 논문 결론은 '치환만으로는 안 된다, 코팅이나 다른 물질군이 필요하다'입니다 — 저희 캐스케이드가 **어디에 코팅·조합을 쓸지** 좁히는 절차라는 점에서 같은 방향입니다."
🛡 *재현인가?* → "아닙니다. 화학이 달라 재현이 아니라 **독립 관측**이고, 슬라이드에도 그렇게 적어 뒀습니다."

## P13. 트레이드오프 2 — 값 하나가 두 축을 갈랐다 ⏱70 ★★
이건 게이트가 아니라 **값을 검증하다** 나온 트레이드오프입니다.

역학 축에서 가장 연한 후보는 오랫동안 Sc₂O₃ 였습니다. 형성에너지도 1위였고, 데이터 파일에 "가장 연하고 가장 강하게 형성된다"고 적혀 있었습니다. 그런데 같은 값이 다른 파일에 다르게 실려 있는 걸 발견하고 원자료까지 되짚었더니 — **E_VRH 가 18.7 이 아니라 42.082 였습니다. 2.2배 틀렸습니다.**

40개 챔피언을 다시 정렬하면 연질 상위는 Li₂O 32.4 · MnO 32.6 · NiO 33.9 이고 **Sc₂O₃ 는 18위**입니다. 형성에너지 1위는 그대로고요. 즉 **한 후보가 두 축을 모두 이기던 그림이 값 하나로 사라졌습니다.**

앞 장이 게이트가 보여준 트레이드오프라면 이건 **검증이 보여준 트레이드오프**입니다. 두 사례가 같은 말을 합니다 — 이 데이터셋에서 한 후보가 모든 축을 이기는 일은 검사를 통과하지 못합니다.
→ "그래서 11종 안의 선택 구조를 봅니다."
🛡 *그럼 지금 순위는 믿을 수 있나?* → "같은 교차검증을 40행 전부에 돌렸고 어긋난 두 행만 원자료로 확정했습니다. 그리고 이건 UMA 내부 스크리닝이라 절대값이 아니라 **캐스케이드 내부 상대비교 전용**입니다."
※ 다른 철회 사례를 물으면 **부록 A4(P23)** 원장으로.

## P14. Pareto ⏱70
AND 게이트 하나로 끝내면 한 축이 강하고 다른 축이 약한 후보를 일찍 버립니다. 그래서 11종 안에서 ΔE 와 수송 프록시 두 축의 non-dominated 집합을 따로 봅니다. 이 Pareto 집합은 **질문에 따라 달라지는 후보군**이지 winner 목록이 아니고, 축을 바꾸면 집합도 바뀝니다.
→ "질문에 따라 달라진다 — 후보 넷에 적용해 보겠습니다."
※ 다른 배치 질문(공기·비용·경량)은 **부록 A2(P21)** 질문–축 지도로.

## P15. 후보 4종 트레이드오프 ⏱90
LiF 는 정적 계면 축에서 매우 안정해 보입니다 — 다만 kinetics 나 coating 수명까지는 말할 수 없습니다. MgO 와 CaO 는 cost tier 1 에 가볍지만 H₂S 축과 LPSCl 계면 축에서 서로 다른 크기의 부담이 보입니다 — CaO 쪽이 큽니다. Cu₂O 는 문헌 수분 proxy 가 +1.267 로 가장 좋은 축에 드는데, 정작 산화 게이트 G3 에서 멈추고 계면 축도 −341 meV 로 불리합니다. **한 후보의 장점은 반드시 적용 조건과 함께 읽어야 한다** — 이 표의 메시지입니다.
→ "여기까지가 결과라면, 이제 이 절차를 스스로 두들겨 본 결과입니다."

# Part D. 얼마나 믿을 수 있나 (P16–P17, ≈3분)

## P16. Trust boundary ⏱80 ★
지지되는 주장과 아닌 주장을 갈라 두었습니다. 게이트 통과·탈락, 같은 규약 안의 상대 순위, 방금 두 트레이드오프, 게이트 순서 불변성 — 지지됩니다. UMA 절대 에너지, BVSE 를 전도도로 읽는 것, 축퇴군 내부 순위, G5 단일 승자 — 지지되지 않습니다. 계면 반응·전자 절연·doped 계의 실제 수분 반응은 **아직 게이트로 들어오지 못한 축**입니다.
→ "그럼 지금 검증이 어디까지 왔는지 숫자 세 개로 정리하겠습니다."
🛡 *순서 불변은 뭘 보장하나?* → "최종 교집합이 순서와 무관하다는 것까지입니다 — 임계값 자체를 검증해 주지는 않습니다. 120 순열 결과는 부록 A3 에 있습니다."

## P17. 커버리지 3숫자 ⏱80
47은 상대 스크린 수, 11은 게이트 endpoint, 2는 targeted DFT 사례 수입니다. 이 셋은 **한 줄로 이어지는 깔때기가 아닙니다.** 특히 DFT 두 건은 11종에서 뽑은 검증 세트가 아니라 — B₂O₃ 는 G4 에서, Nd₂O₃ 는 G3 에서 멈춘 후보인데 트레이드오프 검증 가치 때문에 고른 사례입니다. 앞으로 비싼 계산은 게이트 경계·모델 불일치·Pareto 가치·저샘플 화학에 우선 배정합니다.
→ "마지막으로, 여기에 ML 이 어디에 들어가는지입니다."

# Part E. 다음 (P18–P19, ≈3분)

## P18. ML 현황 ⏱90
ML 을 둘로 나누겠습니다. UMA 는 에너지와 힘을 대신하는 학습 퍼텐셜이고 — 이미 이 캠페인의 엔진입니다. 반면 co-doping 모델은 단일 도펀트 점수 47개를 1,081개 조합에 이식한 **가설 생성기**입니다. 실제 co-doped 구조도 라벨도 **0개**고, 도펀트를 통째로 빼고 검증하면 R² 가 음수로 무너집니다. 화면의 Cr₂O₃–HfO₂ 쌍이 대표 가설인데 — 산화 쪽 끝과 환원 쪽 끝이 상보적이지만 **두 챔피언 구조가 같은 Li_24g 자리에 앉아 자리 경쟁이 1순위 리스크**고, +0.360 V 도 조립된 끝점 proxy 지 쌍 계산이 아닙니다. 한 줄로 하면 — **ML 은 이미 비용을 아껴 주지만, 발견을 보증하지는 못합니다.**
→ "그래서 다음 단계는 예측이 아니라 라벨 획득입니다."
🛡 *R² 0.9998 은 뭔가?* → "저희가 만든 점수 공식을 되찾은 것 — 성공이 아니라 자기 회귀입니다. 정직한 숫자는 쌍 검증 쪽의 음수입니다."

## P19. Acquisition loop + 마무리 ⏱80 ★
이 그림에는 계보가 있습니다. **Xiao 2019** 은 코팅 후보를 계산으로 훑는 스크리닝을 세웠고, **Kahle 2020** 은 대리 모형으로 그 스크리닝을 가속했고, **Duquesnoy 2023** 은 물리 시뮬레이션 데이터 위에서 ML 이 **다음 실험을 고르게** 했습니다. 저희 다음 cascade 는 그 세 번째 칸입니다 — 게이트를 ML 로 대체하는 게 아니라, **비싼 계산을 어디에 쓸지 ML 이 고르는 폐루프**입니다. 명시적 co-doped 구조를 만들어 라벨을 얻고, 불확실하거나 새로운 화학도 섞어 탐색하고, 게이트 경계는 DFT 로 확인합니다.

※ 한 박자 쉬고, 청중을 보며 마무리.

정리하면, 오늘 보여드린 것은 versioned 스냅샷과 감사된 11종 shortlist, 그리고 라벨 획득 계획입니다. 그리고 **서로 독립인 두 트레이드오프** — 게이트가 보여준 것과 검증이 보여준 것 — 가 같은 말을 합니다. **발견된 승자는 없고, 방어 가능한 다음 걸음이 있습니다.** 감사합니다.

🛡 *(첫 질문 대비) 그래서 뭘 만들 건가?* → "Cr₂O₃–HfO₂ 부터 명시적 co-doped 구조를 만들어 형성에너지와 자리 경쟁을 닫는 것 — 날짜가 있는 다음 계산입니다."
