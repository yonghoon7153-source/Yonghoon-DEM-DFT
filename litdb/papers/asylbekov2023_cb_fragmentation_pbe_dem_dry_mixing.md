## 1. 한 줄 요약

**"나노 카본블랙을 DEM 으로 풀 수 없다"는 것을 정면으로 인정하고, CB 를 DEM 에서 완전히 빼버린 뒤
(DEM 에는 NCM622 활물질만 남긴다), DEM 은 *응력강도 분포 σ̄ 와 접촉빈도 ṅ(σ̄)* 라는 **환경 통계 두 개만**
넘기고, CB 의 입도변화는 **크기-공간(size space)의 population balance equation** 이 풀게 한 논문.**
CB 의 **파괴강도 σ_crit(x)** 와 **파편분포 θ(z)** 는 측정하지 않고 **실험 PSD 에 Nelder–Mead 로 맞춰
역산**한다.  핵심 결과 세 가지: ① **분쇄에 하한이 있다 — x_lim ≈ 0.2 µm 아래로는 안 깨진다**
(σ₅₀ 모델은 x_p = 0.199 µm 로 명시적으로, power-law 모델은 매우 가파른 기울기로 암묵적으로 구현;
습식 유성믹서[63]·마이크로 DEM[64] 의 0.2 µm 한계와 일치); ② **CB 를 brittle(x < 0.766 µm) / soft
(x ≥ 0.766 µm) 두 집단으로 나눠 breakage function 을 따로 주면** 균질 가정이 뭉개버리던 **bimodal
PSD 의 골짜기가 되살아난다**(Case I → Case II); ③ **breakage function 은 공정 독립이 아니다** —
9.5 m s⁻¹ 에서 보정한 파라미터를 13 m s⁻¹ 로 옮기면 잘 맞지만 6.25 m s⁻¹ 에서는 큰 입자 쪽이
크게 어긋나고(Case III), breakage function 만 재보정하면(파괴강도는 고정) 오차가 한 자릿수 준다(Case IV).
**⚠ 단 σ_crit 의 절대값은 독립 측정이 없고 eq (16) 의 자유 스칼라 λ 와 축퇴(degenerate)돼 있어
재료강도로 인용할 수 없다** — 이것은 우리 18× E-연화와 **같은 지위의 effective 파라미터**다.

### 3.2 ★ 카본블랙의 응집체 계층 (이 논문의 소재 모델)

| 층 | 크기 | 결합 | 논문의 취급 |
|---|---|---|---|
| **primary particle(1차 입자)** | **≈ 50–100 nm** | 합성 중 핵생성으로 형성·성장 | ⛔ **모델 안 함** — 절대 안 깨지는 하부 단위 |
| **aggregate = "brittle agglomerate"(취성 응집체)** | **300 nm ~ > 1 µm** (이력·취급에 따라 크게 변동), **프랙탈 차원 D_f = 2.0–2.5** | 1차 입자들이 **소결 브리지(sintered bridges)** 로 연결 | ★ **깨지는 층 ①** — 고유 breakage function |

| **clump(덩어리)** | **수 mm** | 취급·보관·운송 중 형성 | 언급만 (초기 PSD 에 흡수) |

- ★ **brittle / soft 분리선 = x = 0.766 µm** — **질량기준 분포의 특징적 *골짜기*(valley) 위치**로만 정당화.
  저자 자신이 *"this value is by no means constant, so this remains only a rough estimate"* 라고 명시.
  ⚠ 결합력으로 나눌 수 없어(실험적으로도 시뮬레이션으로도 불가) **크기로 대리**한 것.
- ⇒ **어느 층이 깨지나**: **aggregate(brittle) 와 agglomerate(soft) 둘 다**.  **primary particle(50–100 nm) 은 안 깨진다** — 그 결과가 아래 **x_lim ≈ 0.2 µm 분쇄 하한**으로 나타난다.

★ **읽는 법**: **DEM 은 루프 밖에 한 번만 있다**(왼쪽 아래, 화살표가 나가기만 한다).  최적화 루프는
**PBE 쪽에서만 돈다**.  즉 **DEM ↔ PBE 는 *단방향·1회* 결합**이고, CB 가 깨져서 분체 거동이 바뀌는
되먹임은 **없다**(저자도 결론에서 이 점을 문제로 지적).

### 4.1 ★★ DEM 과 PBE 가 무엇을 나눠 갖는가 (사용자 질문 ①의 정답)

| | **DEM 이 주는 것** | **PBE 가 푸는 것** |
|---|---|---|
| 대상 | **NCM622 활물질 입자만** (확대된 강체 구) | **CB 응집체 집단** (크기-공간의 밀도함수 f(x,t)) |
| 공간 | 실공간 3D (믹서 기하, 주기 대표요소) | **공간 없음** — 믹서 전체를 **한 덩어리(one domain)** 로 보고 공간분포 무시 |
| 출력 | ① **평균주응력 σ̄ 의 질량가중 분포**(5760 셀) ② **입자수로 정규화한 비(比)접촉빈도 ṅ(σ̄)** | **f(x,t)** = 입도분포의 시간발전 |
| 물리 | 충돌·전단·마찰·점착(JKR) | **birth(큰 것이 깨져 작은 것이 생김) / death(이 크기가 깨져 사라짐)** |
| 역할 | **환경 통계(공정 특성)** | **재료의 반응(재료 특성)** |

**결합 지점은 단 하나 — breakage rate b(x):**

- **eq (9)**  `b(x) = ṅ · p_s` — **접촉빈도 × 파괴확률**.
- **eq (16)** `ṅ(σ_crit) = λ ∫_{σ_crit}^{σ_max} ṅ(σ) dσ` — 즉 **"CB 가 크기 x 일 때 겪는 유효 파괴 빈도 =
  DEM 응력분포에서 σ_crit(x) 를 넘는 사건의 적분 × 상수 λ"**.
- ⇒ ★ **파괴확률 p_s 는 별도의 확률분포가 아니라 *DEM 응력분포의 생존함수(tail integral)* 로 구현**된다.
  크기 x 의 CB 는 σ_crit(x) 를 **넘는 응력 사건에서만** 깨진다 (hard threshold).
- ⇒ 즉 **DEM 의 유일한 기여는 "어떤 응력이 얼마나 자주 오는가"** 이고, **"그 응력에서 CB 가 깨지는가"** 는
  전적으로 **적합된 σ_crit(x)** 가 정한다.

> ★★ **사용자 질문 ①의 핵심 답 — "이것이 우리와 같은 회피인가?"**
> **구조적으로 같다.  다만 회피의 *방향*이 다르다.**
> - **공통 (같은 회피)**: 둘 다 **"나노 물체를 DEM 입자로 만들지 않는다"**.  본 논문의 이유 = *"CB 가 너무 작아
>   질량분율이 낮아도 DEM 에서 완전히 해상할 수 없다; 훨씬 큰 활물질조차 300 g 믹서 전체로는 부담"*.
>   우리 `scripts/additives.py` 의 이유 = *"discrete DEM 은 수백만 개의 나노 물체가 필요해 불가능"*.
>   **동일한 문장이다.**  그리고 둘 다 **나노상을 *다른 수학 공간*에 재배치**한다.
> - **차이 (재배치하는 공간이 다르다)**:
>   - **그들 → 크기-공간(size space)**.  CB 는 *어디에 있는지* 모르는 대신 ***얼마만 한 것이 몇 개인지*가
>     시간에 따라 변한다**(분쇄가 보인다).
>   - **우리 → 실공간 격자(MPM/복셀)**.  첨가제는 *얼마만 한 것이 몇 개인지*가 **고정**인 대신
>     **어디에 있는지 알고, 그래서 σ_e·σ_ion·τ 를 낼 수 있다**.
> - ⇒ **두 회피는 상보적이다**: 그들은 **진화(evolution)** 를 사고 **공간(placement)** 을 팔았고, 우리는
>   **공간**을 사고 **진화**를 팔았다.  ⛔ **우리에게 입자 파쇄/응집 모델이 없다**는 것은 정확히
>   "우리가 판 쪽"이다.  둘을 합치는 자연스러운 형태는 **셀별(local) PBE** 이고, 저자들도 outlook 에서
>   바로 그것을 지목한다(Peterson [67] · Vikhansky [68]).

### 4.2 선형 breakage equation (PBE, eq 1)

```
∂f(x,t)/∂t = ∫_x^∞ p(x,y) b(y) f(y,t) dy   −   b(x) f(x,t)
             └────────── birth ──────────┘     └─── death ───┘
```
- `f(x,t)` = **부피 x 를 갖는 입자의 개수밀도분포**.  `b(y)` = 부피 y 입자의 breakage rate.
  `p(x,y)` = **breakage function** = 부피 y 가 깨졌을 때 나오는 부피 x 파편의 분포.
- **믹서 전체를 한 도메인으로 보고 공간분포를 무시**한다(Ramkrishna [14] 의 고전형).
- ⚠ **선형(linear)** = breakage rate 가 시간·주변 상태에 무관하다는 가정.  §3.5 에서 저자 스스로
  **Bilgili & Scarlet [65]** 을 들어 이 가정이 깨지는 세 유형을 논한다(아래 4.9).

### 4.3 수치 적분 — method of classes(MOC) + Kumar 질량보존 보정 + RK4

- **왜 MOC 인가**: 목표가 **전체 분포를 해상(resolved)하는 것**이라 **모멘트법(QMOM)은 부적합**.
  MOC = 체분석(sieve)처럼 크기 범위를 N 개 셀로 나눔.  범위 `(0, x_max]`, 셀 i = `(x_{i−1/2}, x_{i+1/2}]`,
  대표점 `x_i = (x_{i+1/2}+x_{i−1/2})/2`.  **분포 폭이 넓어 로그 스케일 권장 → 본 논문 로그 사용**.
- **문제**: 크기 클래스 이산화는 **질량보존이 격자에 의존**한다 → 아주 고운 격자가 필요.
- **해법**: **Kumar et al. [33] (SIAM J. Numer. Anal. 2015) 의 보정항** — eq (3):
  `d f̂_i/dt = (1/Δx_i) Σ_{k=i}^N ω_k^b b_k P_ik f̂_k Δx_k − ω_i^d b_i f̂_i`,
  `P_ik = ∫_{x_{i−1/2}}^{x̂_k^i} p(x, x_k) dx`,
  `ω_k^b = x_k(ν(x_k) − 1) / Σ_{i=1}^{k−1}(x_k − x_i) P_ik`, `ω_k^d = (ω_k^b/x_k) Σ_{i=1}^k x_i P_ik`,
  `x̂_k^i = x_i (k=i일 때) 또는 x_{i+1/2} (그 외)`.
  ⇒ **격자 해상도와 무관하게 질량이 보존**된다.
- **시간적분 = RK4**, `Δt ≤ 0.1 s` 면 시간간격 무관.
- ⚠ **N(클래스 수) 미보고** — "결과 품질이 클래스 수에 크게 의존한다"고 스스로 적으면서 값을 안 준다.

### 4.4 breakage function p(x,y) — 어떤 파편이 나오나

- **질량보존 제약**: `∫_0^y p(x,y) dx = ν(y)` (파편 개수), `∫_0^y x p(x,y) dx = y` (부피 보존),
  `p(x,y) = 0 ∀ x ≥ y`, 그리고 **최소 2개 파편**.
- **균질(homogeneous) 단순화** (eq 7): `p(x,y) = (1/y) θ(z)`, `z = x/y` — **상대 파편부피만의 함수**.
- **선택한 형태 = Diemer & Olson [39] 의 product function** (Hill & Ng [36] 의 일반형을 축약), eq (8):
  ```
  θ(z) = ν · z^(q−1) (1 − z)^(q(ν−1)−1) / B(q, q(ν−1))
  ```
  B = Euler beta 함수.  **파라미터 두 개뿐: ν(파편 개수) · q(파괴 유형)**.
  - `q → 0` : **erosion(표면 침식)**
  - `q = 1` : **무작위 파편부피**
  - `q ↑` : 분포가 좁아짐
  - `q → ∞` : **등크기 파편으로 분할**
- ★ **이질(heterogeneous) 커널**: brittle / soft 응집체에 **각각 독립의 θ(z)** 를 준다(= Case II 이후).
  결합력으로 나눌 수 없으니 **크기 0.766 µm 로 대리 분리**.

### 4.5 ★ breakage rate b(x) 와 파괴강도 모델 — **두 가지를 비교**

**(a) power-law (eq 10)**
```
σ_crit(x) = σ_0 (1/x)^(1/m)
```
- m = 양대수 그림에서 기울기를 정하는 지수, σ_0 = 전인자.
- ⚠ **본문은 "x_0 는 특성길이" 라고 적는데 eq (10) 에는 x_0 가 없다** — 식과 서술이 어긋난다(표기 사고).
- 근거: 고전적 멱법칙 입자강도–크기 관계(Yashima [42]), 볼밀 분쇄 모델링 전통.

**(b) σ₅₀ 모델 (Tavares [41] 계열, eq 11)**
```
σ_50 = σ_∞ [ 1 + ( x_0 / (x − x_p) ) ]^φ
```
- **σ₅₀** = **50 % 확률로 파괴를 일으키는 비(比)파괴응력** (= 파괴가 확률적임을 인정하는 정의).
- **σ_∞** = 조대 입자에서의 수렴 파괴응력.
- **x_p** = **그 아래에서는 소성변형이 지배해 더는 안 깨지는 크기** ⇒ **분쇄 하한을 *모델 안에* 내장**.
- **x₀** = 재료 미세구조를 나타내는 특성길이, **φ** = 곡률 지수.
- 물리 근거(Tavares): **아주 작은 입자에서는 투입에너지가 전부 소성·탄성 변형으로 가고 파괴가 일어나지 않는다**.

**두 모델의 실제 차이(결과)**:

### 4.8 coarse-graining — **본 논문은 force-scaling 을 쓰지 않는다** ★

- **CG factor = 100**.  스케일링 법칙 근거는 **차원해석**(Moseler [53] · Bierwisch [54]).
- **자기닮음(self-similarity) 논거**: Hertzian Spring Dashpot + Mindlin–Deresiewicz 를 쓰면
  **Rocky 내부 마찰력 모델을 수정할 필요가 없다**.
- **보정 흡수**: `μ_static`, `μ_dynamic`, `e`, `Γ_SJKR` 를 **확대된 입자 위에서 직접 보정**해
  **"이미 CG factor 에 적응돼 있게"** 만든다 + **AM 의 상대 PSD 를 그대로 유지**해 유동거동 편차를 더 줄인다.
- **빈도 정규화**: 셀 i 의 응력사건 수 `N_P,i` 를 **시스템 입자 수로 나눠 정규화** →
  *"coarse-grain 방식이 만드는 오차를 **부분적으로(partially)** 보상"*.  선례는 습식분쇄(Kwade & Schwedes [62]).
- ⚠ **Feng et al. [55]: CG = 100 은 이 방법의 *상한 부근*.**  저자도 그대로 인용한다.

> ★★ **이것이 Frankenberg 와 갈리는 지점이다.**
> **본 논문 = 보상(compensation)**: CG 오차를 ⓐ 확대입자 위 보정 ⓑ 입자수 정규화 ⓒ **(사후적으로) 자유
> 파라미터 λ·σ_crit 에 흡수시킨다.  **응력의 scale-invariance 를 유도하지도, 검증하지도 않는다.**
> **Frankenberg 2024 = 보존(conservation)**: `F ∝ f²`, `δ ∝ f`, `τ ∝ f` 로 두면 `σ_CG = σ_0`,
> `E_m,CG = E_m,0` 가 **수학적으로 보장**되고, 충돌 force-time 곡선으로 **검증까지** 한다.
> ⇒ ⚠ **따라서 Fig 3 의 응력 *절대값* 은 어떤 검증도 받지 않았다** — CG 100× 가 그 절대값을 어떻게
> 옮겼는지 논문이 답하지 않는다.  이것이 §10 의 가장 큰 경고다.

### 4.10 ★ 파라미터 보정 (Nelder–Mead)

- **오차함수** (eq 14): `ε(ξ) = ‖f_exp(x,t) − f̂_ξ(x,t)‖²₂` (총제곱오차, TSE).
- **왜 gradient 법이 아닌가**: ⓐ `ε(ξ)` 의 **해석식이 없어 Jacobian 수치근사 비용이 큼**
  ⓑ **얕은 골짜기(shallow valley)** 가 많아(Rosenbrock 류) Newton/Gauss–Newton/Levenberg–Marquardt 의
  수렴이 무너짐, 특히 **breakage function 파라미터에서 gradient 법이 실패**.
- **Nelder–Mead(downhill simplex) [60]**: n+1 점 simplex 를 최악점 반사로 굴려 국소최소로 수축.
  **수렴 속도는 gradient 법에 열세, 강건성(robustness)에서 우위.**
- **다중시작(multi-start)**: **Case I·II 는 무작위 초기벡터 ≥ 15 개**.  Case IV 는 **Case II 최적점에서 출발**.
- **전처리(preconditioning) 2단계** (eq 15a–e):
  ① **스케일 변환** — `q̂ = log₁₀ q` (q ≈ 1 부근 해상도 향상), `ν̂ = log₂ ν` (작은 ν 해상도),
    `σ̂_0 = log₁₀ σ_0`, `σ̂_end = log₁₀ σ_end` (강도는 값 범위가 넓어 로그).
  ② **정규화** — `ξ̂/ξ̂_0` 로 나눠 수치 정확도 개선.
- **물리 제약**: **ν < 2 인 해는 오차가 작아도 버린다**(파괴 시 최소 2 파편).

## 6. Post-processing ★

- **무엇을 계산하나**
  - **주응력 분해**: 셀별 질량가중 응력텐서 → **고유값 = 주응력 σ_I, σ_II, σ_III** → **σ̄ = 평균**.
    대안 `τ_max = (σ_I − σ_III)/2` 는 **분포가 거의 동일**함을 실측 확인 후 미사용.
  - **비(比)빈도**: 셀별 접촉수 / Δt / **시스템 입자수** (coarse-grain 오차 부분보상).
  - **생존함수 적분** (eq 16): σ_crit 초과 응력사건의 적분 × λ → breakage rate.
  - **PBE 적분**: MOC(로그 클래스) + **Kumar 질량보존 보정** + **RK4**.
  - **역보정**: **Nelder–Mead** + **로그/정규화 전처리** + **≥15 다중시작** + **ν ≥ 2 제약**.
  - **오차 지표**: **총제곱오차 TSE** `ε(ξ) = ‖f_exp − f̂_ξ‖²₂` — **가중 없음, 질량기준 분포에 직접**.
- **도구**: **ROCKY DEM (ESSS)** + GPU **V100** (bwUniCluster).  PBE·최적화 코드는 자체(언어 미명시).
  실험: **광산란 입도분석**(기기명 미명시), **원심분리기**, **NMP 현탁**.
  ★ **DEM 재료 파라미터 보정에 CNN(합성곱 신경망) 사용** — 유동거동 영상 → 영상처리로 **이진화** →
  사전학습된 네트워크에 입력해 파라미터 역산.  *"상세한 설명은 향후 논문에서"* ⇒ **본 논문만으로는 재현 불가**.
- **수치화·플롯 규약**: PSD 는 전부 **질량기준(q₃ / Q₃)**, **x 축 로그(10⁻²–3×10¹ µm)**;
  응력·빈도도 **x 축 로그(10²–2×10⁵ Pa)**; 오차는 **로그 막대그래프**;
  breakage function 은 **상대 파편부피 z = x/y 의 로그축**(soft 는 10⁻⁹ 까지).
- ⛔ **하지 않은 후처리**: Heckel · porosity · coordination number · percolation · tortuosity ·
  coverage · contact-area · EIS/TLM · Tabor — **전부 없음**(압밀 논문이 아니다).

## A. 비교 심화

### A-1. ★★ 계보 — 같은 그룹, 같은 장치, **반대 방향의 입도변화**

- **본 논문(2023) = 분쇄(desagglomeration)**.  큰 CB 응집체가 **깨져 작아진다**.  PBE 의 **birth/death 가
  breakage 커널**이다.  PSD 가 **왼쪽(작은 쪽)으로** 이동한다.
- **Frankenberg(2024) = 응집(aggregation)**.  LFP + CB + 할라이드 SE 가 **붙어 heteroaggregate(core-shell)
  가 된다**.  PSD 가 **오른쪽으로** 이동하는 공정이며, 그 논문은 **PBE 를 쓰지 않고** 이미 응집된 결과물을
  **입자 하나로 coarse-grain** 한 뒤 **응력·에너지만** 뽑는다.
- **공통 뼈대**: Rocky DEM · coarse-graining · Hertz–Mindlin · JKR 점착 · 회전 기하의 주기 대표요소 ·
  Eulerian 셀 응력통계 · **Kwade 응력모델의 "강도 × 빈도" 이중축**.
- **방법론 전진**: 2023 은 **CG 오차를 보정/정규화로 흡수**(보상), 2024 는 **f² force-scaling 으로 응력
  invariance 를 유도·검증**(보존).  ⇒ Frankenberg 카드 §A-2 의 표에서 **본 논문은 "우리 18× 연화"와 같은 칸**에 선다.
- **재료계 갈림**: 2023 = LIB 계 **NCM622 + CB**(전해질 없음, 건식 혼합 원료), 2024 = ASSB **LFP + CB +
  Li₃InCl₆ 할라이드**.  ⇒ **둘 다 우리 LPSCl + NMC811 이 아니다**.  ⚠ 단 2023 의 **AM 은 NCM622** 라
  우리 NMC811 과 **같은 층상계 족(族)** 이다(2024 의 LFP 보다 가깝다) — **그래도 σ·강도 전이는 금지**.

### A-4. ★★ σ_crit 와 우리 18× E-연화 — **같은 지위의 effective 파라미터**

**축퇴(degeneracy) 논증** — `b(x) = λ · ∫_{σ_crit(x)}^{σ_max} ṅ(σ) dσ` 에서:
- **λ 는 값이 보고되지 않은 자유 스칼라**다.
- **σ_crit(x) 는 자유 곡선**이다 (power-law 는 σ₀·m 두 개, σ₅₀ 은 σ_∞·x₀·x_p·φ 네 개).
- ⇒ **λ 를 키우고 σ_crit 을 같이 올리면 b(x) 가 거의 그대로다.**  즉 **σ_crit 의 절대 수준은 이 적합만으로
  식별되지 않는다**(비유일).  Fig A1 이 **국소최소의 실재**를 경험적으로 보여준다.
- 게다가 **CB 단일 응집체의 강도를 독립적으로 측정한 적이 없다** — 저자 스스로 *"실험적 파괴강도 측정은
  매우 수고스럽다"* 고 적고 하지 않는다.

**우리 18× 연화와의 대조**:

| 축 | 그들 σ_crit(x) | 우리 E_eff = 1.35 GPa |
|---|---|---|
| 정체 | **적합된 유효 강도곡선** | **적합된 유효 모듈러스** |
| 흡수하는 것 | CG 오차 · λ · 측정 규약 · 비선형 분쇄 · 재응집 부재 | granular 재배열 · GB 슬라이딩 · 미세파괴 (rigid sphere 가 못 하는 것) |
| 실험 앵커 | **벌크 PSD 하나** | porosity(Minnmann) + pure-SE overlap(Cronau) + MPM 독립 교차 |
| 독립 확인 | ⛔ **없음** (단일 축 적합) | ★ **3중**(Cronau overlap 11–12 % · MPM 8 % · Heckel) |
| 재료값으로 인용 가능? | ⛔ **불가** | ⛔ **불가** (실제 E_SE ≈ 22–24 GPa 는 별도 층) |

★ ⇒ **우리 18× 연화가 "임의적"이라는 비판은 이 논문에는 *더 강하게* 걸린다.**  우리는 최소 세 개의
독립 앵커가 같은 연화를 요구하는데, 본 논문의 σ_crit 는 **자기가 맞추려는 곡선 하나**에만 걸려 있다.
⚠ 단 이것이 본 논문의 결함이라는 뜻은 아니다 — **그들이 주장하는 것도 σ_crit 의 절대값이 아니라
"모양(하한이 있다 · 크기의존이 있다 · 상별로 다르다)"** 이다.  **모양만 인용하면 안전하다.**

### A-5. 0D(공간 무시) 가정 — 그들 스스로가 반증을 실었다

- Fig 3 right / Fig 4 right 는 **응력과 빈도가 공간적으로 크게 다르고, 게다가 서로 다른 패턴**임을 보여준다
  (응력은 날 앞, 빈도는 다른 분포).
- 그런데 PBE 는 **믹서 전체를 한 도메인**으로 본다 ⇒ **모든 CB 가 동일한 "평균 환경"** 을 겪는다고 가정.
- 실제로는 CB 가 고응력 영역과 저응력 영역을 **왕복**하며, 체류시간 분포가 분쇄를 좌우한다.
- 저자도 outlook 에서 *"믹서 도메인의 해상된 관점(resolved view)이 결과를 개선할 것"* 이라 인정하되
  **계산비용**을 이유로 미루고, Peterson [67] · Vikhansky [68] 을 대안으로 제시.
- ⇒ ★ **우리에게 주는 교훈**: 우리 복셀/MPM 은 **이미 공간을 갖고 있다**.  우리가 PBE 를 도입한다면
  **처음부터 local PBE** 로 갈 수 있고, 그것이 이 논문 대비 **즉각적인 우위**다.

## B. 적용가능성 (우리 모델에 무엇을 할 수 있나)

### B-1. ★★ `SP_D = 0.20 µm` 에 **문헌 앵커**를 붙인다 (즉시 가능, 계산 0)

- 현재 `scripts/additives.py` 의 `SP_D = 0.20 # Super P / Super C carbon-black aggregate (sphere, particulate)`
  는 **주석에 출처가 없다**.
- 본 논문은 **건식 고강도 혼합에서 CB(Super C65)의 분쇄 하한이 x_lim ≈ 0.2 µm**(σ₅₀ 모델에서 x_p = 0.199 µm)
  이고, **습식 유성믹서[63]와 마이크로 스케일 DEM[64] 에서도 같은 0.2 µm** 임을 **stated** 로 적는다.
- ⇒ **`SP_D = 0.20 µm` 은 "잘 분산된 CB 가 도달할 수 있는 최소 aggregate 크기"라는 물리적 의미를 갖는다**고
  주석에 근거를 달 수 있다 (`asylbekov2023 …` 인용).
- ⚠ **단서 셋**: ⓐ 소재가 **Super C65** 로 우리 Super P 와 **동일 grade 는 아니다**(같은 Super 계열).
  ⓑ 그들 장비는 **고강도 믹서**로 우리 공정의 혼합 강도와 같다는 보장이 없다.
  ⓒ **0.2 µm 는 "더 못 깨지는 하한"** 이지 **"실제 전극의 평균 CB 크기"** 가 아니다 —
  Fig 9 right 가 보여주듯 **6.25 m s⁻¹ 에서는 3–10 µm 조대 모드가 크게 남는다**.
  ⇒ 정확한 주석 문구는 *"완전 분산 극한의 하한(문헌 3경로 일치)"* 이다.

### B-2. ★ **우리에게 없는 것**: 첨가제 PSD 의 시간발전 — local PBE 훅 (미실행, 설계만)

- 현재 우리 첨가제는 **씨앗 시점에 크기·개수가 고정**된다 (`seed_sdcp`, `seed_sheath`, VGCF 점열 …).
- 본 논문의 구조를 우리 파이프라인에 옮기면:
  **STEP1(LIGGGHTS) → 접촉응력 분포 σ̄ 와 빈도 ṅ(σ̄) 를 *셀별로* 집계 → 셀마다 작은 PBE 를 적분 →
  STEP2/STEP3 로 넘기는 첨가제 PSD 를 *공정 함수로* 만든다.**
- 우리 쪽 이점: **응력 집계에 쓸 셀 격자가 이미 있다**(복셀/MPM 격자) ⇒ **0D 가 아니라 local PBE 로 직행**.
- ⚠ **선결 조건 — 지금은 못 한다**:
  ⓐ **우리 DEM 침대에는 CB 가 없다**(첨가제는 MPM/복셀 단계에서 배치).  ⇒ CB 가 겪는 응력은 **AM-SE 침대의
    응력 통계로 대리**해야 하는데, 이것은 본 논문의 "AM 이 grinding media" 가정과 **같은 종류의 가정**이다.
  ⓑ **σ_crit 과 θ(z) 를 적합할 *우리 실험 PSD* 가 없다** — 본 논문 값은 **재료·응력대역이 달라 전이 금지**.
  ⓒ **우리 응력대역(300 MPa)은 그들(≤0.2 MPa)보다 3자릿수 위** ⇒ **σ_crit 곡선을 그대로 쓰면 모든 CB 가
    첫 접촉에서 하한까지 분쇄된다**는 무의미한 답이 나온다.  ⇒ **결론: 구조는 차용 가능, 파라미터는 전면 재보정 필요.**
- 매핑 후보: `scripts/additives.py`(크기 생성부) + STEP1 응력 dump 집계 + `docs/digest_model_application_backlog.md`
  의 신규 항목(예: "첨가제 PSD 진화 — local PBE").

### B-3. ★ 우리 침대의 **초기 PSD 는 공정 변수다** (서술 보강, 계산 0)

- 본 논문 Fig 9 right: **같은 2 분 혼합인데 6.25 m s⁻¹ 은 3–10 µm 조대 CB 모드가 크게 남고, 13 m s⁻¹ 은
  거의 전부 ~0.2 µm 미세 모드**다.
- ⇒ **우리 DEM/MPM 이 "입력"으로 받는 첨가제 크기는 재료 상수가 아니라 *혼합 이력의 결과*** 다.
- 원고에서 첨가제 기하(VGCF Ø0.15 × L10 · PTFE Ø0.25 × L40 · SuperP 0.2)를 제시할 때,
  **"이 값들은 충분히 분산된 상태를 가정한다"** 는 단서를 붙이는 근거가 된다.
  (⚠ 이 논문의 수를 우리 값의 *출처*로 쓰는 것은 **SuperP 0.2 µm 한 항목뿐**이다.)

### B-4. 응력 집계 규약 — **셀별 질량가중 텐서 → 주응력 → 평균** 차용 후보

- 그들: **5760 셀 × (질량가중 응력텐서 → 고유값 3개 → 평균 1개)**.
  **장점**: 좌표계 무관 + **전단 정보 보존** + 6 → 3 → 1 로 데이터 축약.
- 우리: 현재 압밀 침대의 하중분담은 **contact dump(AM-AM 규약)** 또는 **atom dump `c_strs[3]`(phase 규약)** 로
  집계한다(CLAUDE.md, Codex Q2/Q6).  **두 규약 사이가 "운용상 민감도 구간"** 으로 남아 있다.
- ⇒ ★ **주응력 기반 집계는 그 규약 논쟁과 *직교하는 제3의 축*** 이다: `σ_zz` 한 성분 대신 **주응력 3개의
  평균(정수압적)** 과 **τ_max(전단)** 를 같이 내면, **"AM-AM vs phase" 문제와 별개로** 침대의 응력상태를
  더 온전히 기술할 수 있다.  ⚠ 단 **이것이 f_AM 규약 문제를 푸는 것은 아니다** — 다른 질문에 답하는 다른 지표다.
- ★ 그들 실측 한 줄이 유용하다: **"σ̄ 와 τ_max 의 분포가 정량·공간 모두 매우 유사"** ⇒
  **믹서 체제에서는 두 지표가 사실상 같은 정보**.  ⚠ **우리 구속 압밀(confined die)에서는 성립할 이유가 없다**
  (정수압 성분이 크게 다르다) — 옮기지 말고 **우리 침대에서 직접 재는 것이 한 줄짜리 확인 실험**이다.

### B-5. 역보정 방법론 — Nelder–Mead + 로그 전처리 + 다중시작 + 물리 제약

- 우리 스케일링 법칙 적합은 **OLS/Ridge + nested LOOCV** 축이고, 본 논문은 **비선형 역문제 + 휴리스틱 최적화** 축이다.
- ★ 그대로 쓸 만한 규약 넷: ⓐ **로그 전처리**(값 범위가 넓은 파라미터), ⓑ **정규화**,
  ⓒ **무작위 다중시작 ≥15**(Fig A1 이 국소최소 실재를 증명), ⓓ **물리 제약으로 해를 버림**(ν ≥ 2).
- ⚠ 그들이 **안 한 것**(우리는 해야 할 것): **식별가능성(identifiability) 분석** — λ ↔ σ_crit 축퇴(§A-4),
  파라미터 신뢰구간, 교차검증(다른 tip speed 에 대한 hold-out).  ★ Case III 이 사실상 **hold-out 시험**이고
  **실패했다**(한 자릿수 오차 증가) — 즉 **그들의 적합은 일반화되지 않는다는 것이 그들 자신의 데이터로 드러났다**.
  이것은 우리 LOOCV 문화가 왜 필요한지의 외부 사례로 인용 가능.

## C. ★ 우리 novelty — 이 논문 대비 어디가 우리가 앞서고 어디가 밀리나

> **결론 먼저**: 본 논문은 **우리가 갖지 못한 능력 하나(입도 진화 = 분쇄)** 를 **아주 싸게** 구현한 우수한
> 공정 모델이다.  그러나 **전달·압밀·형상·공간해상·재현성**에서 우리가 명백히 앞선다.  두 모델은
> **경쟁이 아니라 직렬·상보**다.

**(1) 전달 삼중항 — 그들 0 채널 (가장 큰 격차)**
- 그들: σ_ionic·σ_e·σ_thermal·percolation·tortuosity **전부 없음**.  CB 가 *왜* 중요한지는 서론에서
  인용으로만 말하고, **PSD → 전도도 → 성능**의 고리를 **잇지 않는다**.
- 우리: **3채널 전부** + 명시 Kirchhoff/Holm 접촉망 + STEP3 복셀 FV.  ★ **본 논문이 낸 PSD 를 받아
  전도도로 바꿔 줄 수 있는 것이 정확히 우리 파이프라인**이다.

**(2) 공간 해상 — 그들 0D**
- 그들: 믹서 = **한 덩어리**.  자기 Fig 3·4 가 공간 불균질을 보여주는데도 PBE 는 그것을 못 쓴다.
- 우리: **MPM/복셀 격자**가 이미 실공간.  ⇒ **local PBE 로 직행 가능**(§B-2) = 그들 outlook 을 우리가 더 싸게.

**(3) 압밀·소성·형상 — 그들 범위 밖**
- 그들 DEM: **탄성 Hertz + 점착 JKR**, 항복 캡 없음, 형상 불변, 파쇄 없음.
- 우리: DEM 압밀(18× 연화 + Stage-E 소성면적) + **MPM 진짜 J2 형상 소성** + void-fill + 변형장.

**(4) 검증 구조 — 그들 단일 앵커·단일 사슬**
- 그들: **CB PSD 하나**에 모든 자유 파라미터를 적합.  독립 모델 없음, 교차검증 없음,
  **Case III(hold-out)에서 실패**.
- 우리: **DEM · MPM 독립 2모델을 각각 실험에 보정**(frame[4], cross-fit 금지) + LOOCV 문화 + 사전등록.

**(5) 재현성**
- 그들: **입자수·입자크기·Δt·클래스 수 N·λ·σ_crit 파라미터 미보고**, *"Research data are not shared"*,
  **DEM 보정 CNN 은 "향후 논문"**.  ⇒ **논문만으로 재현 불가**.
- 우리: 스크립트·매니페스트·`input_digest`·selftest·CI 규율.

**⚖️ 정직하게 — 그들이 우리보다 앞선 곳**
- ★★ **① 입도 진화(분쇄)를 *싸게* 푸는 구조** — **우리에게 통째로 없는 능력**이다.
  PBE(MOC + Kumar + RK4)는 ODE 수준 비용이라 **GPU 도 필요 없다**.  ⇒ **차용 1순위.**
- ★ **② 응집체 계층의 명시적 구분** — primary / aggregate(brittle) / agglomerate(soft) / clump 를
  **크기와 결합기구로 나누고 각 층에 다른 커널**을 준다.  **우리 CB 는 속이 찬 0.2 µm 구 하나**뿐이다.
- ★ **③ 공정 노브 → 미세구조의 직접 실험 연결** — tip speed 3 수준 × 실측 PSD.
  **우리는 혼합 공정 축이 아예 없다**(초기 침대는 무작위 비중첩 삽입).
- ★ **④ 프랙탈성의 인식** — D_f = 2.0–2.5, 소결 브리지, 곁가지 입체 걸림.  우리 blob 근사가 놓치는 물리를
  **명시적으로 이름 붙여** 준다(당장 모델하진 않더라도 한계 서술에 쓸 수 있다).
- ⚠ 단 ①②③④ 는 전부 **혼합공정·CB·저응력(≤0.2 MPa)** 범위다.  **전달·압밀·형상·공간·재현성은 우리 우위** 유지.

  추가 지표.  ⚠ 그들의 "σ̄ ≈ τ_max" 관찰은 **믹서 체제 한정** — 우리 구속 압밀에서 직접 재봐야 한다(1줄 확인).
- ⑥ **역보정 위생** — 로그 전처리 · 정규화 · 무작위 다중시작 ≥15 · 물리 제약으로 해 기각.
  ★ 그리고 **그들이 안 한 것**: 식별가능성(λ↔σ_crit 축퇴)·hold-out.  **Case III 실패가 곧 hold-out 실패**라는
  읽기는 우리 LOOCV/사전등록 문화의 외부 사례.
- ⑦ **응력 스케일 대조표에 한 줄 추가** — 건식 고강도 혼합 **10²–2×10⁵ Pa** / 우리 냉간압밀 **3×10⁸ Pa** /
  ASSB 작동 스택압 **~10⁷ Pa**.  **"제조 ≠ 작동" 인식에 *혼합* 층을 하나 더 얹는다.**
  ⚠ digitized 이므로 **자릿수 비교로만**.
- ⑧ **데이터 파일 제안**: `docs/data/asylbekov2023_cb_breakage.csv` — Table 2·3(stated) + x_lim/x_p(stated) +
  CB 계층 크기(stated) + Table 1 DEM 파라미터(stated) + Fig 3/4/7/9 판독값(**digitized 태그 필수**).
  ⛔ **`densification_porosity_db` 에는 넣지 않는다** — porosity·압력 축이 아예 없다.

## 9. 인용 가능 문장 (deck/paper용)

- "Asylbekov et al. (2023, KIT + TU-Braunschweig IPAT) modelled the **fragmentation of carbon-black
  agglomerates during high-intensity dry mixing** by **removing the carbon black from the DEM entirely**:
  the DEM (Rocky, coarse-grain factor 100, Hertz–Mindlin + JKR) contains **only the NCM 622 active material**,
  which is assumed to act as the **grinding media**, and it supplies just two statistics — the mass-weighted
  distribution of the mean principal stress and the particle-normalised contact frequency, collected on a
  10 × 72 × 8 = **5760-cell Eulerian grid** — to a **population balance equation** that carries the carbon
  black in *size space*."
- "This is **structurally the same evasion we use** for the conductive additives: both refuse to make the
  nano-objects DEM bodies (their reason — *'due to the small size of the CB it is not possible to completely
  resolve the particles in the DEM, even with low mass fractions'* — is the same one our `additives.py`
  states).  The difference is **where the nano phase is re-housed**: they put it in **size space**, so it
  **evolves in time (it fragments) but has no location**; we put it in a **real-space MPM/voxel grid**, so it
  **has a location and yields σ_e / σ_ion / τ but never changes size**.  The two are complementary halves,
  and the natural merge — a **cell-local population balance** — is exactly what their own outlook proposes."
- "Their most transferable result is a **comminution limit**: the breakage rate is identically zero below
  **x_lim ≈ 0.2 µm** (the σ₅₀ model enforces it explicitly with x_p = 0.199 µm, the power-law model through a
  very steep gradient), and the **same 0.2 µm limit was found independently for wet dispersion in a planetary
  mixer and in micro-scale DEM**.  This supports reading our **0.20 µm Super-P aggregate** as the
  *fully-dispersed lower bound* of a carbon-black aggregate rather than an arbitrary modelling choice."
- "Splitting the carbon black into **brittle agglomerates (x < 0.766 µm, primary particles of 50–100 nm joined
  by sintered bridges, fractal dimension 2.0–2.5)** and **soft agglomerates (x ≥ 0.766 µm, up to ~30 µm, bound
  by van der Waals forces and steric hooking)** and giving each its **own breakage function** recovered the
  **bimodal shape** that a single homogeneous kernel had smeared into an essentially monomodal distribution —
  a phase-wise-kernel argument that parallels our phase-wise treatment of additives."
- "⚠ The fitted fracture strengths must **not** be quoted as material strengths.  They were never measured
  independently, they are **degenerate with the unreported free scalar λ** of eq (16), the appendix itself
  shows **multiple local minima across ≥15 random restarts**, and the transfer test (Case III) **fails**: the
  error at 6.25 and 13 m s⁻¹ is an **order of magnitude larger** than at the calibration speed of 9.5 m s⁻¹,
  and only re-calibrating the breakage functions (Case IV) recovers it.  In our vocabulary this is an
  **effective, compensating parameter of the same epistemic status as our 18× softening of E_SE** — except
  that ours is required independently by three anchors, whereas theirs is fitted to the single curve it
  reproduces."
- "Finally, this paper is **process mechanics only** — it computes **no ionic, electronic or thermal
  conductivity, no porosity, no electrode and no cell**; its sole output is a carbon-black particle size
  distribution, and the stresses involved (**≈10²–2 × 10⁵ Pa**) are **three to six orders of magnitude below**
  the 300 MPa cold-press we model.  It is the **upstream** half of a serial chain — fragmentation (this work)
  → aggregation (Frankenberg 2024, which cites this paper) → densification and transport (ours)."

## 10. 주의/한계 (over-claim 방지)

- ★★ **응력 체제가 완전히 다르다 — 절대값 전이 전면 금지.**  믹서 응력 **10²–2×10⁵ Pa (≤0.2 MPa, digitized)**
  vs 우리 **300 MPa**.  **3–6 자릿수** 차이다.  CB 파괴강도도 같은 저대역(10²–10⁵ Pa)이므로, 이 곡선을
  우리 압밀에 그대로 넣으면 **모든 CB 가 첫 접촉에서 하한까지 분쇄**되는 무의미한 답이 나온다.
  ⇒ **옮길 수 있는 것은 "모양·구조·하한의 존재"뿐이고 수치는 아니다.**
- ★★ **소재가 다르다.**  **NCM622 + CB Super C65** (전해질 **없음**, LIB 건식 혼합 원료) vs
  **우리 LPSCl + NMC811 + VGCF/PTFE/SuperP/SDCP**.  ⚠ 특히 **VGCF(섬유)·PTFE(연성 피브릴)에는 프랙탈
  응집체 분쇄 물리가 적용되지 않는다** — 섬유는 굽힘·좌굴, PTFE 는 연신·피브릴화다.
  본 논문의 breakage 물리는 **CB 계열(우리 Super P)에만** 논의 대상이다.
- ★★ **σ_crit 은 재료 강도가 아니다** — 독립 측정 없음 + **eq(16) 의 λ 와 축퇴**(λ 미보고) +
  **Fig A1 의 다중 국소최소** + **Case III hold-out 실패**.  ⛔ **"CB 응집체의 파괴강도는 X Pa" 로 인용 금지.**
- ★ **CG = 100 의 응력 절대값은 검증되지 않았다.**  본 논문은 **force-scaling 을 쓰지 않고** 오차를 보정에
  흡수하며, **빈도만** 입자수로 정규화하고 그것도 *"partially compensates"* 라고 적는다.
  ⇒ **Fig 3 의 응력 *절대값*은 어떤 독립 검증도 없다**(Frankenberg 2024 가 같은 그룹에서 이 구멍을 나중에 메운다).
- ★ **breakage function 은 공정 독립이 아니다** (저자 결론).  9.5 → 13 전이는 괜찮고 **9.5 → 6.25 는 실패**한다.
  ⇒ **"보정된 커널"의 전이 반경은 좁다.**
- ★ **0.766 µm 의 brittle/soft 분리선은 분포의 골짜기 위치일 뿐**이다.  저자 명시: *"by no means constant …
  only a rough estimate."*  결합력 기준 분리는 **실험적으로도 시뮬레이션으로도 불가능**하다고 적는다.
- ★ **ν = 158.2 / 145.8 / 60.0 은 물리적 파편 개수로 읽을 수 없다.**  저자 스스로 *"단순화된 모델링 때문"*
  이라 두 번 적는다.  **ν = 4.0 이 세 번 반복**되는 것은 **ν ≥ 2 제약/`log₂` 전처리 경계에 붙은 신호**로 보인다(논문 미언급).
- ★ **본문과 Table 3 이 어긋난다** — §3.5 의 *"σ 모델은 tip speed 가 오르면 폭이 준다"* 는 표의 q 감소
  (=폭 증가)와 반대이고, 그 문장이 §3.5 안에 **중복**돼 있다.  ⇒ **표를 정본으로.**
- ★ **Fig A1 상호참조 오류** — 본문이 *"분체 유동거동이 CB 분쇄 정도에 의존한다(Fig A1)"* 고 하지만
  Fig A1 은 최적화 TSE 그림이다.  ⇒ **그 주장의 데이터 근거가 논문에 없다.**  서술로만 인용.
- ★ **실험 PSD 자체가 흔들린다** — 손혼합·NMP 현탁·**원심분리**가 **추가 분쇄 또는 재응집**을 일으킬 수 있고,
  **광산란은 구 등가직경**이라 **프랙탈 CB 에서 실제 크기와 크게 다를 수 있다**(저자 명시).
  게다가 PBE 가 **부피 x** 를 쓰므로 그 오차가 **증폭**된다.
- ★ **재응집(re-agglomeration)이 모델에 없다** — 저자는 **soft 응집체의 erosion 형 커널(q = 0.2, ν = 158.2)이
  바로 그 부재를 보상하는 산물**이라고 명시한다.  결론에서 *"바인더를 넣으면 재응집 모델링은 필수"* 라 적는다.
  ⇒ **PTFE 바인더가 들어가는 우리 건식 공정에는 이 모델이 그대로는 부적합**하다.
- ★ **선형 breakage 가정의 한계** — Bilgili & Scarlet [65] 의 세 가지 비선형 중 두 가지(미세입자 부피 증가가
  만드는 **완충층(damping layer)** 이 응력을 낮춤 [22,66])가 **잔차의 원인**으로 지목된다.  ⇒ 시간가변 breakage rate.
- ★ **0D(공간 무시)** — 자기 Fig 3·4 가 응력·빈도의 **공간 불균질**을 보여주는데 PBE 는 못 쓴다.
- ★ **DEM 파라미터 보정에 CNN 을 썼는데 그 방법이 "향후 논문"** 이다 ⇒ **보정 사슬이 이 논문 안에서 닫히지 않는다.**
- ★ **재현 불가**: 입자수 · 입자 크기(mm) · DEM Δt · 시뮬 물리시간 · PBE 클래스 수 N · λ ·
  파괴강도 best-fit 값 — **전부 미보고**.  **"Research data are not shared."**
- ★ **믹서 제조사/모델 미표기** — 특정 장비(예: Eirich)로 단정하지 말 것.
- ★ **Table 1 의 Γ_SJKR·μ·e 는 *확대입자* 보정값**이지 재료 물성이 아니다.  **Frankenberg 2024 의 Γ_pp 와
  직접 비교 금지**(다른 분말·다른 확대율·다른 보정 실험).
- ★ **DEM 입자밀도 1670 kg m⁻³ 와 본문의 NCM622 4500 kg m⁻³ 불일치를 논문이 설명하지 않는다.**  추정 금지.
- ★ **σ₅₀ 의 "50 % 확률" 정의가 실제로 구현되지 않는다** — eq(16)은 σ_crit 을 **hard threshold** 로 쓴다.
  강도의 **확률적 산포**가 모델에 들어가 있지 않다.
- **digitized 목록**(§3.8): Fig 3·4·5·6·7·8·9·A1 판독값 — **추세 전용**.
  **stated 목록**: Table 1·2·3, x_lim ≈ 0.2 µm, x_p = 0.199 µm, 0.766 µm 분리선, CB 계층 크기(50–100 nm /
  300 nm–>1 µm / ~30 µm / 수 mm), D_f 2.0–2.5, CG = 100, 5760 셀(10×72×8), 도메인 1/3,

## 11. 기법 미니 사전 (이 카드를 혼자 읽기 위한 용어)

| 용어 | 뜻 | 이 논문에서 |
|---|---|---|
| **PBE (population balance equation)** | 어떤 입자 성질(여기선 부피 x)의 **개수밀도분포 f(x,t)** 가 birth/death 로 시간발전하는 보존형 수송방정식 | eq (1).  분쇄만 있고 응집(aggregation)은 없음 |
| **breakage rate b(x)** | 크기 x 입자가 **단위시간당 깨질 확률률** | `b = ṅ·p_s`; DEM 통계 + σ_crit 으로 만듦 |
| **breakage function p(x,y) / θ(z)** | 부피 y 가 깨졌을 때 **나오는 파편의 크기분포** | Diemer–Olson product function, 파라미터 (q, ν) |
| **MOC (method of classes)** | 크기축을 유한개 클래스로 잘라 **분포 전체를 해상**하는 PBE 이산화 | 로그 간격 클래스.  모멘트법(QMOM)과 대비 |
| **QMOM** | 분포 대신 **모멘트 몇 개만** 추적하는 저비용 PBE 해법 | **부적합으로 기각**(전 분포가 필요해서) |
| **Kumar 보정** | MOC 의 **질량보존이 격자에 의존하는 문제**를 가중치 ω^b, ω^d 로 고치는 보정 | eq (3)·(4a–c), Kumar et al. [33] |
| **erosion vs fracture** | 표면이 조금씩 깎이는 것(erosion, q→0) vs 덩어리가 쪼개지는 것(q ↑) | soft 응집체 σ₅₀ 팔이 **erosion(q = 0.2)** 으로 감 |
| **stress intensity(응력강도) / stress frequency(응력빈도)** | Kwade 응력모델의 두 축 — **한 번에 얼마나 세게** / **얼마나 자주** | Fig 3(강도) · Fig 4(빈도).  둘을 곱/적분해 b(x) |
| **주응력(principal stress)** | 응력텐서의 **고유값** — 좌표계와 무관, 전단 정보 보존 | σ̄ = 세 주응력의 평균.  τ_max = (σ_I−σ_III)/2 |
| **coarse-graining** | 입자를 f 배 키워 **개수와 timestep 부담을 줄이는** 기법 | f = 100.  **force-scaling 은 안 씀**(보정 흡수) |
| **force-scaling** | CG 로 커진 입자의 접촉력을 f² 로 스케일해 **응력·충돌에너지를 원래 값으로 보존**하는 기법 | ⛔ 본 논문에 없음 — **Frankenberg 2024** 가 도입 |
| **JKR / SJKR** | 표면에너지 Γ 로 **점착**을 넣는 접촉이론 / Rocky 의 단순화 구현 | Γ_SJKR 0.27(pp) / 0.78(pw) J m⁻², **확대입자 보정값** |
| **brittle vs soft agglomerate** | **소결 브리지**로 굳은 프랙탈 aggregate vs **vdW·입체 걸림**으로 뭉친 flake | 0.766 µm 로 분리(분포 골짜기) |
| **프랙탈 차원 D_f** | 응집체 질량 ∝ R^D_f.  낮을수록 성기다 | CB 2.0–2.5.  ⚠ **우리 blob 근사에는 없음** |
| **Nelder–Mead (downhill simplex)** | 도함수 없이 simplex 를 굴려 최소를 찾는 **휴리스틱** 최적화 | 얕은 골짜기·Jacobian 부재 때문에 선택 |
| **TSE** | total squared error, `‖f_exp − f̂‖²₂` | Fig 9 left 의 세로축 |
| **x_lim / x_p** | 분쇄 하한 / **그 아래는 소성이 지배해 안 깨지는 크기**(Tavares) | 0.2 µm / 0.199 µm |
