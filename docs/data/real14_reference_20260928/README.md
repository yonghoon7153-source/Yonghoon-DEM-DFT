## 한정어 (지문에 붙는다)

1. **t_DEM 은 PHASE 4 동안 변하지 않는다** — 판이 고정돼 있다.  ⇒ *"2,060,000 이 마지막 덤프인가"* 는 두께 값에 영향이 없다.
   입자 배치 · 응력 (§12-2 의 f_AM 추출) 에는 프레임이 중요하다 — §12-2 는 같은 2,060,000 을 쓴다.
2. **마지막 덤프인지는 아직 모른다** (값 불변 · 기록용 ⬜).  덱 산술 (재시작 없음 가정): 끝 step = 500,002 + 5,000 · N (N = 압축 루프 수).
   2,060,000 이 PHASE 4 안이므로 312 ≤ N ≤ 331 — **N = 312 면** 끝 step 2,060,002 이고 2,060,000 이 마지막 덤프다.
   로그의 `Current Pressure` 줄 수 (= N) 또는 케이스 폴더의 덤프 목록으로 닫는다.
3. **정지 양자화 0.05 µm** — 압축 루프는 5,000 step 마다 판 힘을 한 번 보고 목표 (sim 0.30 = 300 MPa) 이상이면 멈춘다.  판 속도 0.01 × dt 1e-6 × 5,000
   = 5e-5 sim = **0.05 µm/루프** ⇒ 목표 교차는 정지 위치보다 최대 한 루프 위 ((30.2845, 30.3345] µm).  창 반폭 0.908 µm 의 1/18.
4. **판 겹침 · 관통** — 판 아래에 중심이 있는 입자 중 판과 겹치는 것 (DEM 연성 접촉의 겹침): AM_P 8 (최대 δ 1.0275 µm · δ/r 0.171) · AM_S 38 (0.6225 µm · 0.311) ·
   SE 1,055 (0.4440 µm · **0.888**).  중심이 판 **위**로 빠져나간 SE 3 개 (id 8175 · 9224 · 30960, (x, y) ≈ (17.2, 16.3) · (16.3, 16.7) · (16.4, 15.6) µm —
   두 facet 의 공유 대각선 x = y 에서 1 µm 안) · 그중 2 개는 전체가 판 위.
   ⇒ 스캐폴드 CSV 에서 입자 윗면이 판보다 최대 ≈ 1.05 µm 높게 보이는 것 (최대 31.336 µm = 빠져나간 SE id 9224) 은 **이 겹침 · 누출**이다.
   판이 같은 step 에서 평평하므로 *"다른 step 의 메시"* · *"꼭짓점 평균 편향"* 으로는 설명되지 않는다 (두 가설 기각).
5. **바닥 누출** — SE 중심 z < 0: 122 개 · 전체가 바닥 아래: 109 개 · 바닥과 겹침 (접촉 겹침): AM_P 7 · AM_S 46 · SE 2,161.
   ⇒ 두께 정의 (판 z − 0) 는 4 · 5 와 무관하다.  누출 입자는 공극률 · 부피 부기에만 걸린다 (웹앱 ε 가 그것을 어떻게 셌는지는 여기서 다루지 않는다).
