## 1. 무엇이 잘못됐나 — cap 이 아니다

`plastic_coverage.film_area_from_overlap(mode='physics')` 가 돌려주는 **한 개의 `A_physics`**
를 성질이 다른 **두 소비자**가 읽는다:

| 소비자 | 코드 | 읽는 방식 | 공간 |
|---|---|---|---|
| 피복률 | `coverage_physics_vs_hertzian.py` | AM 입자별로 **합산 → `4πr²` 로 나눔** | **구 표면** |
| 접촉망 수송 | `network_conductivity.py:323` | `a = √(A/π)` | **평면 원판** |

`A_geom = 2π·R_min²` 는 **표면 공간의 상한**이다 — 코드 주석이 그렇게 적고 있다:

```
# Cap (hemisphere): 2π R_min² — lateral spread limit
# Hemisphere cap prevents wraparound.
```

그 목적에서 이 cap 은 **만들어진 이유가 정당하다**.
⛔ **정정 (`AREA-08`)** — 옛 표기 *"독립 기하 ground-truth 로 **검증까지 됐다**"* 는 **철회**한다.  그 `geometric_coverage` 함수는 **구 중심·반경과 band 만** 읽는다 — `A_physics`·cap·힘·막 부피를 읽지 않아 **cap 을 바꿔도 출력이 그대로다** ⇒ 특정 cap 의 타당성을 **식별하는 시험이 아니다**.  a=0.8r 이면 구면 넓이가 투영 원판의 **1.25배**라 구면 cap → 원판에는 **별도 사상**이 필요하다.  아래 수치는 **legacy 지표의 재현**으로만 읽는다 (MPM scaffold,
Fibonacci AM 표면 + SE 중심 KDTree): 접촉 **16 % ≈ Hertz 18** · 1 vox 이내 **49 % ≈ Tabor 52**.
그리고 `CLAUDE.md` 가 이 cap 의 존재 이유를 적고 있다 — *"The min(caps) ceiling stops a
deeply-overlapped contact from over-reporting area → **coverage** stays physical"* = DEM 의
18배 연화가 만든 깊은 겹침을 면적 축에서 막는 장치다 (ε_sphere 과압축 문제의 면적판).

⇒ **cap 은 결함이 아니다.**  결함은 **그 값이 경계를 넘어 원판 리더에게 간 것**이다.

### 1-1. cap 제거는 답이 아니다 (실측)

`geom` cap 을 빼고 같은 접촉(r_SE 0.5 ↔ r_AM 6.0 µm, ligg_area 0)을 다시 통과시킨 결과:

| δ (µm) | A_tabor | A_geom | 현행 A (bind) | ψ | geom 제거시 A (bind) | ψ |
|---|---|---|---|---|---|---|
| 0.10 | 0.7554 | 1.5708 | 0.7554 (tabor) | 0.00268 | 0.7554 (tabor) | 0.00268 |
| **0.12** | **0.9930** | 1.5708 | **0.9930 (tabor)** | **0** | 0.9930 (tabor) | **0** |
| **0.15** | **1.3877** | 1.5708 | **1.3877 (tabor)** | **0** | 1.3877 (tabor) | **0** |
| 0.20 | 2.1365 | 1.5708 | 1.5708 (geom) | 0 | **2.1365** (tabor) | 0 |

δ=0.12 · 0.15 에서는 **`geom` 이 관여조차 하지 않는데 ψ 가 이미 정확히 0** 이다 —
`tabor` 가 먼저 문턱을 넘는다.  cap 을 빼면 면적이 **더 커질 뿐** 결과는 같다.

### 1-2. 진짜 문턱은 `A > π·R_min²` 하나다

```
Rc = 0 분기  ⟺  ψ ≤ 1e-4  ⟺  a/R_min ≥ 0.99784556531
             ⟺  A ≥ 0.9956957722087699 · π·R_min²
ψ 정확히 0   ⟺  A ≥ 1 · π·R_min²                      ← 위와 **다른 문턱**이다
```

⛔ **정정 (`AREA-06`)**: 초판은 둘을 섞어 하나로 적었다.  같은 사다리에서 **Rc 삭제 시작
δ = 0.102337961053 µm** · **ψ 정확 0 시작 δ = 0.102632675670 µm** 로 다르다.  내가 적은
`0.10234` 는 **Rc 삭제**의 근사값이지 ψ 정확 0 의 시작점이 아니다.
(★ `geom` 결속 시작 **δ = 0.162919217325 µm** 는 판정문이 원 helper 이분탐색으로 재현했다.)

어느 cap 이 결속했는지는 무관하다.  위 예에서 **ψ→0 시작 δ = 0.10234 µm (binding=`tabor`)**
이고 **`geom` 결속 시작은 δ = 0.16292 µm** 다 ⇒ 그 사이 구간은 `tabor` 가 결속한 채 협착이
삭제된다.

⚠ 그래서 `SELF-28` 의 **AM–SE 13.843 %** 는 **하한**이다 (그것은 `geom` 결속만 센 값).
진짜 비율은 **미측정** — 아래 §4 가 그것을 잰다.

### 1-3. 왜 `geom` 이 결속하면 **반드시** ψ = 0 인가

`A_geom = 2π·R_min²` 는 원판 문턱 `π·R_min²` 의 **정확히 2배**다 (반구 ↔ 원판의 차이).
따라서 반지름과 무관하게:

```
A = 2π·R_min²  →  a = √(A/π) = √2·R_min  →  a > R_min  →  clamp  →  a_eff = R_min 정확히
               →  ψ = (1 − 1)^1.5 = 0    →  R_constriction = 0
```

`network_conductivity.py:386` 의 `r_min_real = min(r1, r2)` 이 `A_geom` 의 `R_min` 과 **같은
양**이라 `a_eff/R_min` 이 정확히 1 이 된다.  코퍼스 실측: `geom` 결속이 **163/163 케이스
전부에서 > 0**, 접촉 가중 전체 **약 3.97 %** · AM–SE **약 13.84 %**.
⛔ **정정 (`AREA-07`)** — **정수 접촉수는 인용하지 않는다**.  저장이 소수 첫째 자리 반올림이라 (`coverage_physics_vs_hertzian.py:407`·`:413`) 정수는 확정할 수 없다 (반올림 호환 범위 AM–SE **1,239,196–1,248,017**).  ⚠ `volume`·`hertzian` 의 163건 0.0 도 **'실제 0회'의 증거가 아니다** (각 0.0 % 가 0.05 % 미만을 숨긴다).

## 2. 계약 — 한 변수를 둘로 쪼갠다

| | `A_surface` (피복) | `A_transport` (수송) |
|---|---|---|
| 뜻 | 퍼진 막이 작은 입자 표면을 덮은 넓이 | 전류·열이 지나는 **평면 patch** |
| 상한 | **2π·R_min²** (반구 = wraparound 한계) | **π·R_min²** (⟺ `a ≤ R_min`) |
| 하한 | ⛔ **미정** (`AREA-03`) | ⛔ **미정** (`AREA-03`) |
| 소비자 | coverage · 반응면적 · B3 거칠기 | `network_conductivity` 협착 항 |
| 지금 상태 | ⛔ **검증 아님** (`AREA-08`) — legacy 지표로만 보존 | **없다** — `A_surface` 를 빌려 쓰는 중 |

**규칙 셋:**

1. **L2 는 `A_transport` 만 받는다.**  `A_surface` 가 원판 리더에 도달하면 **거부**한다
   (조용히 자르지 않는다).
2. **`A_surface` 는 한 글자도 바꾸지 않는다.**  ⚠ 이유는 *"검증됐으니까"* 가 **아니라**
   (`AREA-08`) **legacy 지표를 보존해 세대 비교를 가능하게** 하기 위해서다.  이 계약은
   그것을 건드리지 않는다 ⇒ **coverage 수치는 불변**이어야 한다 (회귀로 강제).
⛔ **정정 (`AREA-03`)** — 초판은 양쪽에 `max(A_hertz, A_ligg)` 하한을 적고 동시에
`A_surface` 의 **완전 불변**을 요구했다.  **둘은 동시에 못 지킨다.**  Codex 반례(반경 1 µm
두 구, δ=0.0001 µm): 현재 Physics 반환 **0.0001570796326795** vs 그 하한
**0.0003141514113767** = **1.99995배**.  δ/R* = 0.0002 가 yield threshold **0.001131480151**
보다 작아 탄성 가지가 `A_ligg` 보다 작은 값을 돌려주기 때문이다 — **정상 탄성 반례**다.
⇒ 하한은 **재설계 대상**이다.  ⚠ `A_ligg` 가 원판 모양이라는 이유만으로 수송 patch 의
**하한**인 것도 아니다 (작은 겹침에서 교차 원판은 Hertz 면적의 약 2배).

3. **하한 > 상한이면 거부한다** (`L1-01` 의 `cap_conflict`).  `A_transport` 에서 이것이
   전보다 자주 일어난다 — 상한이 절반이 되기 때문이다.  **그 접촉은 "면적 미정" 이지
   "면적이 상한값" 이 아니다.**

### 2-1. 왜 (a) 인가 — (b)·(c) 를 안 고른 이유

- **(b) 표면 피복**: 피복률을 저항으로 바꿀 수 없다.  게다가 우리는 피복을 **이미 별도
  축**(Hertz 16 % / Tabor 52 %)으로 보고하고 있어 L2 에 또 넣으면 이중계상이다.
- **(c) 퍼진 막의 추가 면적**: 막 두께·경로를 가진 **별도 항**이 필요한데 그 앵커가 리포에
  없다 (§F1).  `H_FILM_MIN = 5 nm` 는 부피 보존용 상수이지 전도 경로 두께가 아니다.
- **(a) 전류 patch**: 우리 솔버가 이미 Holm `R = 1/(2σa)` 를 구현한다고 **주장**하고 있고,
  Holm 은 patch 정의 위에서만 성립한다.  ★ 판정문의 *"분리된 여러 patch 의 총면적만으로
  협착저항이 유일하게 결정되지 않는다"* 는 **우리에게 유리하게** 적용된다 — DEM 은 쌍당
  접촉이 **하나**라 patch 가 하나다.  다중 patch 모호성은 피복 해석에만 생긴다.

### ③ 주 지표 — 사전에 **하나**

- 케이스별 `Δ_i = 100·(σ_new − σ_old)/σ_old`.
- **주 요약량 = `median(|Δ_i|)`** — 채널마다 하나씩, 총 **세 판정** (σ_ion · σ_e · κ).
  (중앙값: 한 케이스가 판정을 끌지 않게.  ⚠ 케이스는 독립 표본이 아니다 — 같은 LHS
  설계에서 나왔다.  그래서 이것은 **기술 통계**이지 검정 통계량이 아니다.)
- **함께 보고하되 판정에 쓰지 않는 것**: signed `Δ_i` 의 중앙값·사분위·최소/최대 ·
  `mean(|Δ_i|)` · 전 케이스 표 · 분포.  ⚠ **양·음 상쇄로 평균이 0 인데 모든 케이스가
  크게 움직일 수 있다** — 그래서 주 지표가 `|Δ|` 이고 signed 는 따로 본다.

### ④ 0 과 미정 — 0 으로 바꾸지도, 빼지도 않는다

| 상태 | 조건 | 처리 |
|---|---|---|

- ⛔ **미완결 코호트에서 전체 판정을 발행하지 않는다** — 모든 케이스가 위 셋 중 하나로

### 7-1. STEP 2 — patch 생성식

**(a) 공간 — 평면 원판이다, 구면 cap 이 아니다.**
`A_transport` 는 중심선에 수직인 **투영 원판**이고 `a = √(A/π)` 가 그 반지름이다.
⇒ 상한은 **`π·R_min²`** (⟺ `a ≤ R_min`).

★ 두 상한이 정확히 2배인 것은 우연이 아니다 — **반구의 투영이 대원 원판**이다.
구면 cap(반각 θ) ↔ 투영 원판 사상:
```
A_cap  = 2πR²(1 − cos θ)        A_disc = πR² sin²θ
⇒ A_disc = A_cap − A_cap² / (4πR²)
   (θ=90°: 2πR² → πR² ✓ · A_cap→0: A_disc→A_cap ✓ · 정의역에서 단조 ✓)
```
⚠ **그런데 이 사상을 사다리에 적용하면 안 된다.**  `A_hertz = πR*δ` · 교차 원판 ·
`A_tabor = F/H` · `A_volume = V/h_min` 은 **이미 평면 원판 면적**이다.  구면인 것은
**cap 항 `A_geom` 하나뿐**이다.  ⇒ `A_surface` 와 `A_transport` 의 유일한 차이는
**그 cap 하나**이고 그 아래는 **동일**하다.  (이 방식이 `AREA-03` 의 충돌을 푼다 —
**하한을 건드리지 않는다**.)

**(b) 하나인가 여럿인가 — 모델 가정으로 남긴다.**
쌍당 patch 하나는 **가정**이고 구 중심·반경·겹침만으로는 확정할 수 없다 (판정문 §2-3).
⛔ **부호를 주장하지 않는다**: multi-spot 보정은 `R ≈ 1/(2σa_L) + 1/(2σa_1√N)` 꼴이라
클러스터 반경 `a_L` 이 정해져야 방향이 결정된다.  `a_L ≫ a_1` 이면 낮아지고
`a_L ≈ a_1` 이면 높아진다.  **우리에겐 `a_L` 을 줄 데이터가 없다.**

**(c) flux-tube `b` — 현행은 `b = r_min` 이고, 그것은 별도 가정이다.**
`b` 는 그 접촉이 담당하는 **전류 튜브의 반지름**이다.  배위수 `Z` 인 입자의 표면을
접촉끼리 나누면 접촉당 `4πr²/Z` ⇒ **`b = 2r/√Z`**.

| Z | b/r | `b = r` 과의 비 |
|---|---|---|
| 4 | 1.000 | 1.00 (**현행이 여기에 해당**) |
| 6 | 0.816 | 0.82 |
| 12 | 0.577 | 0.58 |

⇒ `b = r_min` 은 **Z ≈ 4** 를 가정한 것이다.  우리 침대의 CN 은 그보다 크다.
⚠ `b` 를 줄이면 `s = a/b` 가 커지고, **올바른(곱하는) ψ 아래에서는 `R_c` 가 더 작아진다**.
⛔ **미채택** — S3 와 섞지 않는다.  `b` 는 **별도 축**이고 별도 런이다.

**(d) 재료쌍 저항 분할 — 두 반공간의 직렬이다.**
```
R_c = ψ(a/b₁) / (4 σ₁ a)  +  ψ(a/b₂) / (4 σ₂ a)
```
· `σ₁=σ₂, b₁=b₂` 이면 `ψ/(2σa)` ✓ · 추가로 `ψ→1` 이면 Holm `1/(2σa)` ✓
⛔ 현 코드는 `min(σ₁,σ₂)` 를 쓴다 (`network_conductivity.py:390`, 주석 *"conservative"*).
계수비 `2·maxσ/(σ₁+σ₂) ∈ [1,2)` 만큼 크다 → 원장 **`AREA-11`**.  ⚠ **정정 (`R2-07`)**: *"16/9 와
일치"* 는 수치해가 약분되는 계수비라 독립 증거가 아니다 — 실제 기준해 대비 min 식은 **1.6857배**
(s=.1, σ 1:8).  **AM_P–AM_P 도 반경이 다르면 걸린다** (6/2 µm 에서 1.5120).  직렬식도 **모델**이지
참값이 아니고, 열의 `k_weight` 는 이미 조화평균이라 **이중 보정 금지**.

### 7-2. STEP 3 — 단위 · 겹침 · 하한/상한

- **단위**: 면적 µm² · `a = √(A/π)` µm · `R` 은 규격화 저항(ρ=1) — **바꾸지 않는다**.
- ⛔ **하한은 건드리지 않는다.**  `AREA-03` 의 반례(정상 탄성에서 1.99995배)는 표가
  하한을 새로 강제하려 했기 때문이다 ⇒ **그 하한 규정을 철회**한다.
  `A_transport` 의 하한 = **현행 사다리 그대로** (`max(A_hertz, A_ligg)`).
- **상한만** `2πR_min² → πR_min²`.  ⇒
  ```
  A_surface   = max(Lo, min(A_tabor, A_volume, 2πR_min²))     ← 현행, **bitwise 불변**
  A_transport = max(Lo, min(A_tabor, A_volume, 1πR_min²))     ← 새로 노출
  ```
- ⇒ `A_transport ≤ A_surface` · **거부 조건이 새로 생기지 않는다** (하한>상한이 아니라
  사다리 자신의 clamp 다).

### 7-3. ★★ STEP 3 의 귀결 — **S2 는 솔버에 대해 항등 변환이다** (`AREA-12`)

**주장 (산술, 모든 입력에서)**: `a_eff = min(√(A/π), R_min)` 라 할 때
`√(A/π) ≥ R ⟺ A ≥ πR²` 이므로
- `A_transport ≥ πR²` 이면 `a'=R`, 그리고 `A_surface ≥ A_transport ≥ πR²` 이므로 `a=R`.  같다.
- `A_transport < πR²` 이면 `Lo < πR²` 이고 `min(A_tabor,A_volume,πR²) < πR²` 라 그 min 은
  πR² 항이 아닌 데서 나온다 ⇒ `min(A_tabor,A_volume)` 이고, 그 값이 πR² 보다 작으니
  2πR² 보다도 작다 ⇒ `A_transport = A_surface`.  같다.

### 7-5. ★ `R_c = 0` 삭제의 재해석 (`SELF-28` 정정)

올바른 배치 `ψ·R_H` 아래에서 `s→1` 이면 **참값 자체가 0 으로 간다**.
⇒ ⛔ **`geom` 결속에서 `R_c = 0` 이 되는 것은 그 자체로 물리 오류가 아니다** —
**틀린 길로 맞는 극한에 도착한 것**이다 (현 코드에서 그 분기는 자기가 만든 발산을 막는
패치다).  `SELF-28` 의 **사실**(163/163 · 접촉 3.966 % · AM–SE 13.843 %)은 그대로 유효하고,
**해석**(*"협착이 삭제되는 것이 결함"*)은 **하향 조정**한다.
★ **진짜 결함은 반대쪽**이다 — 삭제되지 **않은** 모든 접촉에서 `R_c` 가 곱식의 `(1−s)^−3` 배
부풀어 있다.  그 부호는 σ **상향 가설**이다 (§5-v3 ⑥ — cutoff 분기는 반대 방향도 허용).
⛔ **정정 (`R2-08`)**: 위 "틀린 길로 맞는 극한" 은 **원통에서 a=b** 인 경우에만 맞다.  생산의 clamp 0
은 a=b 의 **독립 측정이 아니라** A_surface 를 원판으로 읽어 강제된 s=1 이므로 "참값 0" 으로 면책하지
않는다.  또 tabor 결속 구간 대부분(δ ≥ 0.10263)도 **이미 clamp 로 s=1** 이다 — floor 만이 양수를
지우는 s<1 띠는 **0.102338~0.102633** 뿐.  삭제는 binding 이 아니라 **s_raw · s_clamped · ψ** 로 가른다
(`clamp_zero` / `floor_only`, S0 도구가 센다 — 코퍼스 값 **미측정**).
