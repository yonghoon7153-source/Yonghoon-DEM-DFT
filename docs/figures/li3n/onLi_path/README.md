# Li3N(001) on-Li → N–N bridge → on-Li — **최단 hop 2.107 Å** (그림 전용)

우리 계산된 최소점이 **on-Li** 라는 판정(카드 §C7)에 맞춘 궤적. 시작점 = 계산된 최소점 xy.

```
python3 tools/neb_diffusion/li3n_hop_frames.py --onLi --ride 2.15 \
  --min <min.vesta> --ts <ts.vesta> --ghost_r 0.62 --end_r 1.30 \
  --xi 0,0.1667,0.3333,0.5,0.6667,0.8333,1.0 \
  --outdir docs/figures/li3n/onLi_path --merge      # 필요시 --no_bonds
  # --merge 빼면 single/ 에 낱장 7장
```

## 왜 2.107 Å 인가

on-Li 자리 = N 삼각형 중심 = Li₂N 면의 in-plane Li 바로 위. 이웃 on-Li 까지는
a/√3 = 3.65/1.732 = **2.107 Å** 이고, 그 중점이 **N–N 다리**다.
(격자 병진 3.65 Å 이상은 전부 N 을 관통한다 — `../hop_frames/README.md`.)

## 강조 3점 + 보간 4점

| ξ | | 표면 N (Å) | 최근접 Li (Å) | 자리 |
|---|---|---|---|---|
| 0.00 | ★ | 2.17 / 2.19 / 2.38 | 2.15 | **on-Li** = 계산된 최소점 xy |
| 0.17 / 0.33 | · | | 2.27 / 2.15 | 보간 |
| **0.50** | ★ | **2.38 / 2.41 (2개)** | 2.15 | **N–N bridge** |
| 0.67 / 0.83 | · | | 2.15 | 보간 |
| 1.00 | ★ | 2.77 / 2.86 / 2.89 | 2.15 | **on-Li′** |

높이는 고정이 아니라 `ride_height` 로 **점마다** 맞춘다 — 최근접 기판 원자와 항상 2.15 Å.
고정 높이로 그으면 반대쪽 끝에서 Li–Li 가 1.37 Å 까지 파고든다 (그쪽 in-plane Li 는
adatom 에 눌리지 않은 상태라서). 그래서 끝점의 N 거리가 시작점보다 길다 — 기판이
그 자리에서 이완되지 않았기 때문이고, 실제로는 그 Li 가 내려가며 adatom 도 내려간다.

## ★ 표시용이다

**시작점 xy 만 계산된 값이다.** 중간점과 반대쪽 끝은 보간이고 높이는 전부 기하로 준 것.
에너지를 붙이면 안 된다. 수렴시킨 두 구조는 `../computed_fixed/`.

⚠ 이 hop 의 중점(N–N 다리) 부근은 KISTI drag p0 와 거의 같은 자리인데
**끝점보다 0.085 eV 낮다** (수렴됨). 즉 이 방향은 우리 데이터상 봉우리가 아니라 골짜기다.
그래프에 봉우리로 그리면 우리 계산과 어긋난다 — 카드 §C3 · §C6.
