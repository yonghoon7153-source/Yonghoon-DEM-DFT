## 1. 한 줄 요약

**상분리 전극(LFP)의 입자는 크기마다 스피노달 간극이 다르다(작을수록 작다) — 그래서 C/50 반쪽셀 탈리튬 곡선의 "평탄부가 서서히 오르는 모양" 이 곧 입자 크기 분포의 누적 기록이다.** 저자들은 regular solution OCP 의 Ω 를 Ferguson–Bazant 의 크기-간극 선형관계로 **입자별**로 만들고, 비대칭 로그정규 PSD 3 파라미터 + 경계보정 2 파라미터를 대리모델(surrogate) 최적화로 곡선에 맞춰 **PSD (모드 반경 34.48 nm, σ_left 15.10 · σ_right 7.50 nm)** 를 얻었다 (반쪽셀 RMSE 11.1 mV, 중간영역 편차 < 1.7 mV).
그 PSD 를 **층화 역변환 표본(대표입자 N 개 × 가중 w)** 으로 풀어 Graule 의 물리화학 등가회로(DFN 대응) 양극 가지마다 다입자모델을 심고, 국소 Newton → 접선(등가 전압원 + 증분저항) → 전역 MNA 로 결합해 Sony Murata 26650FTC1 (LFP/흑연) 풀셀을 C/25 · C/10 · C/2 에서 **RMSE 충전 < 8 · 방전 < 14 mV** 로 재현했다고 보고한다 (Table 3). 입자 수는 N = 100 에서 이산 분해 진동이 보이고 10⁴ 에서 무시할 만하다.
⇒ 우리에게는 **"PSD 를 영상 없이 전기화학으로 읽는다"** 는 역문제 설계 + **연속 PSD → 유한 대표입자** 변환 규약 + **다입자 → 셀 회로 결합** 수치 틀이 남는다. 물리 자체(Ω(r))는 NCM 에 옮겨지지 않는다.

## 4. 모델 · 방법 ★

### 4.1 입자 OCP — regular solution (Eq. 1–2, 논문 [30] 표기)

```
g_hom(Ω,c)/(R_g T) = Ω (c/c_max)(1 − c/c_max) + (c/c_max) log(c/c_max) + (1 − c/c_max) log(1 − c/c_max)     (1)
μ_hom(Ω,c)/(R_g T) = ∂g_hom/∂c = Ω (1 − 2c/c_max) + log( c/(c_max − c) ),   0 < c < c_max                  (2)
```
- Ω = 혼합 엔탈피(regular solution 파라미터). **Ω > 2** 이면 g 가 이중우물 → 상분리 선호 (LFP).
- 탈리튬/리튬화 경로: 입자는 **스피노달**(μ 의 극값, g'' 부호 전환 — Fig. 2 검은 원)에서 불안정해져 2 상으로 분해되고, **바이노달**(공통접선 끝, 초록 마름모)에서 1 상으로 돌아온다. 2 상 상태의 입자 OCP 는 Φ₀ 로 고정.

### 4.2 ★ 입자 크기 → Ω — Ferguson–Bazant 핵생성 관계 (Eq. 3–5, p.12)

```
Δμ_gap = (2 k_B F T / e) [ √(Ω² − 2Ω) − 2 tanh⁻¹( √(1 − 2/Ω) ) ]          (3)   ← 두 스피노달 사이 '전체' 간극
Δμ_gap,j = Δμ_gap,∞ ( 1 − L_c · S/V )                                      (4)   ← 젖은 표면/부피 비에 선형
Δμ_gap,j = Δμ_gap,∞ ( 1 − L_c · 3/r_j )     (완전히 젖은 구)               (5)
```
- **L_c** = 핵생성 장벽이 사라지는 임계 크기 (그보다 작으면 입자 안 2 상 없음). **1/L_c ≈ 0.18 nm⁻¹** [21], **Δμ_gap,∞ = 74 meV** [21, 22] (둘 다 문헌 고정값, 이 논문이 재지 않았다). 관계는 "입자 모양에 거의 무관" [21] 이라고 인용.
- 절차: r_j → Eq. 5 → Δμ_gap,j → Eq. 3 을 Ω 에 대해 풀어 **입자별 Ω_j** (g 의 모양은 유지, 곡률과 스피노달 위치만 입자별).
- derived(ours): 구의 **임계 반경 = 3 L_c = 16.7 nm** (이하에서는 Ω ≤ 2, 이력 없음) · 대입자 극한 **Ω_∞ = 4.52** (298.15 K) · r_mode 34.48 nm 에서 Ω = 3.53, Δμ_gap = 38.2 meV.
- **작을수록 간극이 작다** → 탈리튬 때 작은 입자가 먼저(낮은 전위에서) 분해되고 큰 입자가 나중(높은 전위)에 분해 → **평탄부가 서서히 오른다** (Fig. 1 의 초록 화살표). 이것이 PSD 가 전위곡선에 새겨지는 기전.

### 4.3 경계보정 — 경험항 (Eq. 6–7, p.14)

```
Φ_corr,j(c_j) =
   A_low · [exp(κ_low (c⁻_sp,j − c_j)/c_max) − 1] / [exp(κ_low c⁻_sp,j/c_max) − 1],        0 < c_j ≤ c⁻_sp,j
   0,                                                                                    c⁻_sp,j < c_j < c⁺_sp,j
  −A_high · [exp(κ_high (c_j − c⁺_sp,j)/c_max) − 1] / [exp(κ_high (c_max − c⁺_sp,j)/c_max) − 1],  c⁺_sp,j ≤ c_j < c_max      (6)

Φ_j = Φ₀ − μ_hom,j/F + Φ_corr,j   (1 상 입자) ,    Φ_j = Φ₀   (2 상 입자)                                          (7)
```
- 이유 (저자): 단순 regular solution 은 완전 (탈)리튬 근처의 **가파른 전위 상승·하강을 못 낸다** [32]. 변형·탄성 기여 [6] 를 물리적으로 풀지 않고 **경계영역에서만 켜지는 경험항**으로 대신했다 — "실험 데이터에 맞춰 설정, 다른 조성에선 다를 수 있다".
- 스피노달 농도 c^±_sp,j 가 입자별이므로 보정의 시작점도 입자별. A 는 크기(0.3 / 0.8 V), κ 는 가파름 (적합 대상).
- 핵심 성질 (Fig. 9, p.31): 중간영역(c⁻_sp < c < c⁺_sp)에서는 **정확히 0** → 크기-간극 관계를 건드리지 않는다. 보정 없는 식은 수치 정밀도 한계로 전위창 끝(2.5 / 3.8 V)에 **닿지 못한다** (판독: 보정 없음 ≈ 3.30–3.37 V @ x→1, ≈ 3.56 V @ x→0 · 보정 있음 2.51 / 3.80 V).

### 4.4 다입자 동역학 — Kondo et al. [7] 틀 (Eq. 8–13)

```
∂c_j/∂t = − i_j S_j / (F V_j)                                     (8)   입자 평균 농도 하나 (입자 안 확산 없음)
I_app = Σ_j S_j i_j                                               (9)
i_j = i₀,j [ exp(0.5 F η_j/(R_g T)) − exp(−0.5 F η_j/(R_g T)) ]  (10)  대칭 BV
i₀,j = F k c_j^½ c_e^½ (c_max − c_j)^½                            (11)
η_j = Φ_s,j − Φ_l,j − Φ_j                                          (12)
Φ_s,1 = Φ_s,2 = … = Φ_s,N = Φ                                      (13)  모든 입자가 같은 고체 전위
```
- 가정: **나노 LFP 는 입자 안 Li 수송이 빨라 준평형** → 입자 평균 농도 하나로 충분 [30, 31]. **모든 입자 구형.** 입자마다 농도 이력을 추적해 1 상/2 상 상태를 정한다 (스피노달에서 2 상 진입, 바이노달에서 이탈).
- 반쪽셀(저전류)에서는 Φ_l = 0 으로 두고, 주어진 I_app 에서 Φ 를 **Newton–Raphson** 으로 푼다 [7].

### 4.5 ★ PSD 역산 절차 (Eq. 14–15, Fig. 4–6, 부록 A)

- **원리 (Fig. 5)**: 과전압이 작으면 전극 전위는 "지금 분해 중인 입자군의 스피노달 전위" 를 따른다 [5] → (측정 전위 − Φ₀) 가 곧 그 입자군의 간극 → 크기. **overshoot 구간은 쓰지 않는다** (입자들이 먼저 스피노달까지 밀려가야 하므로) — overshoot 뒤 국소 최소 이후 구간이 "다입자 평형이 스피노달을 따르는" 구간.
- **Fig. 4 (민감도)**: PSD 가 넓을수록 중간영역 기울기↑, PSD 가 클수록 이력↑ (C/50 시뮬레이션). ⇒ **폭은 기울기로, 위치는 이력 폭으로** 식별된다.
- **파라미터화 (부록 A, p.36)**: 모드를 공유하는 두 로그정규의 조각 결합 (**비대칭 로그정규**).
  ```
  σ_q,norm = √( ln[1 + (σ_q / r_ref)²] ),   q ∈ {left, right},  r_ref = 60 nm (임의 고정)   (A.1)
  μ_q = ln(r_mode / r_ref) + σ²_q,norm                                                     (A.2)   → 두 가지 모두 r_mode 에서 최대
  f_q(r) = 1/(r σ_q,norm √(2π)) · exp( −[ln(r/r_ref) − μ_q]² / (2σ²_q,norm) ),  r > 0      (A.3)
  p(r) = w_left f_left(r)  (0 < r ≤ r_mode) ;  w_right f_right(r)  (r > r_mode)              (A.4)
  ```
  w_left · w_right 는 (i) r_mode 에서 연속 (ii) 전체 적분 1 을 만족하도록. **p(r) 는 반경의 수(number) 분포** (§4.6 에서 입자를 이 분포로 뽑는다). 로그정규 선택 근거 = LFP 문헌 PSD [7, 41, 42, 44].
- **최적화 벡터** ξ = [r_mode, σ_left, σ_right, κ_low, κ_high] (Eq. 14) — **5 개를 C/50 탈리튬 곡선 하나로**.
- **목적함수** RMSE(ξ) = √( (1/m) Σ (Φ_sim,i − Φ_meas,i)² ) (Eq. 15) — 시뮬·측정을 **공통 길이 m 으로 재표본** 후 (m · 재표본 축 미기재).
- **루프 (Fig. 6)**: 초기 ξ → PSD + 경계보정 → 다입자모델 (실측과 같은 전류) → RMSE → "RMSE − RMSE_lowest > threshold ?" 이면 **대리모델 기반 최적화(surrogate-based optimization)** 가 새 ξ 제안, 아니면 저장 → 가장 낮은 RMSE 의 ξ 채택. threshold = 0.02 mV (Table 2).

### 4.6 ★ 풀셀 결합 — 물리화학 등가회로(Graule [46]) 안에 다입자모델 (Eq. 16–26, Fig. 7)

- **틀**: 전기 · 전해질 확산 · 고체 확산 3 부모델의 등가회로가 DFN(P2D) [49] 의 주 기능을 재현. 음극(흑연)은 원래대로 요소마다 **전압원 + 전하전달 저항**, **양극 요소마다 대표입자 무리**로 교체. 양극 고체확산 부모델은 **입자당 커패시턴스 하나** (확산 저항 없음 = 입자 내 균일 가정).
- **입자 뽑기**: 양극 요소 k 마다 **고정 수 N** 개를 PSD 에서 **층화 역변환 표본(stratified inverse-transform sampling)** 으로 뽑고, 각 표본입자가 **같은 반경의 실제 입자 w 개**를 대표:
  ```
  A_cell L_k ε_s,k = w · Σ_{j=1}^{N} V_j           (16)   → 활물질 부피 보존으로 w 결정
  I_cat,br,k = w · Σ_j S_j,k i_j,k                  (17)
  ```
  "가중은 각 표본의 상대 기여를 보존하므로 모델 거동은 불변, 계산만 wN → N" (stated).
- **전극 균형(balancing)**: SOC = 1 에서의 풀셀 전압과 음극 전위로 양극 전위를 구하고, **모든 양극 입자를 그 전위 · 거의 완전 탈리튬 상태의 자기 OCP 위 농도로 초기화** (DFN 의 반쪽셀 곡선 이동·늘이기를 입자 해상판으로 옮긴 것).
- **수치해 — 2 단 중첩 (Eq. 18–26)**:
  1. 전역: 회로 전체를 **수정절점해석(MNA)** 으로 `A x = z` (Eq. 18) — 각 소자가 전역 행렬에 스탬프.
  2. 국소: 양극 가지마다 추정 가지전류 Ĩ 를 주고 **가지 전압 U_cat,br 를 Newton** 으로 — 잔차 `e(U) = w Σ S_j i_j(U) − Ĩ` (Eq. 19), 도함수 `w Σ S_j ∂i_j/∂η_j` (Eq. 20), 갱신 (Eq. 21).
  3. 수렴한 국소 해를 **접선 선형화**: 증분저항 `R_inc = (w Σ S_j ∂i_j/∂η_j)⁻¹` (Eq. 22), `U(I) ≈ U(Ĩ) + R_inc (I − Ĩ)` (Eq. 23) → **등가 전압원 U_eq = U(Ĩ) − R_inc Ĩ 와 직렬 증분저항**으로 MNA 에 스탬프 (Eq. 24–25), 가지전류는 추가 미지수.
  4. MNA 해 → 새 가지전류로 국소 해 반복, **max_k |I − Ĩ| < ε_I** (Eq. 26) 까지 (ε_I 값 미기재).
  5. 수렴 뒤 동적 상태 전진: 음극 농도(수렴 전류), 양극 입자(마지막 국소 해의 입자 전류), 전해질 농도(원천항 + 이웃 확산 결합).
- 풀셀 시뮬: 양극 요소당 **N = 100 · 1000 · 10000** · 양극 **두께방향 3 요소** (p.32 "effectively 3N") · 나머지 매개변수 Table B.1 · **흑연 OCP = C/50 리튬화·탈리튬 반쪽셀 곡선의 평균** (음극 이력 모델 없음).

## 8. 적용 인사이트 (우리 연구에 어떻게)

### ① ★★ DEM 입도 입력을 **연속 PSD** 로 — "비대칭 로그정규 3 파라미터 + 층화 역변환 표본" 을 LIGGGHTS 템플릿으로
우리 덱은 상마다 `radius constant` 하나 (폭 0) 다. 실측 NCM PSD 는 폭이 있다 (예: 같은 LPSCl/NMC811 계 Bazzoun 2026 CAM D10/D50/D90 = 3.90/5.50/7.62 µm, `bazzoun2026_dem_fem_rnm_ionic`).
이 논문의 조합이 그대로 **"실측 PSD → K 개 템플릿"** 규약이 된다: (1) 실측 누적분포를 비대칭 로그정규(A.1–A.4)로 적합 → (2) 누적확률을 K 등분한 층마다 대표 반경 하나 (층화 역변환) → (3) 층의 **수** 분율을 LIGGGHTS `particledistribution/discrete` 의 **질량** 분율로 (∝ r³ ρ) 환산.
⚠ 두 함정: **r_ref 규약을 같이 옮겨야** σ 가 같은 분포를 뜻한다 (σ_left 15.10 nm 는 r_ref = 60 nm 에서만 의미 — r_ref 를 r_mode 로 바꾸면 같은 수가 σ_norm 0.248 → 0.419 로 다른 PSD) · 레이저 회절 PSD 는 보통 **부피 기준**이라 수 기준 p(r) 와 섞으면 안 된다. 파라미터 대신 **r10 · r50 · r90** 로 옮기는 편이 안전하다.

### ② ★★ STEP4 poly/SC 분리 — **반경 문턱 대신 상 라벨 · 문턱 대신 연속 함수**
지금 `--am-split-um 3.5` 는 단분산 두 종 사이(반경 2 / 6 µm)에 있으니 문턱 = 상 라벨이다. ①을 적용해 상 내부 PSD 에 폭을 주면 **AM_S 의 큰 꼬리 · AM_P 의 작은 꼬리가 겹쳐** 반경 문턱이 입자를 잘못 분류한다 → 원자 **type 라벨로 분리**해야 한다.
또 이 논문이 크기 → 물성을 **연속 함수** Ω(r) 로 둔 것처럼, 우리도 D_s · i0 의 크기 의존을 쓸 거라면 두 값 계단보다 **D_s(r) · i0(r) 연속 함수**가 자기일관하다 (값은 §F1 문헌 앵커만 — 지금은 없다, `docs/ncm_sc_poly_electrochem_anchors.md`).

### ③ ★ 다입자 전극의 **입자 수 수렴 기준** — 상분리 물질이면 457 개는 진동 영역
그들: 상전이 물질에서 N = 100 (실효 300) 이면 개별 입자 분해가 전압에 **진동**으로 보이고 10⁴ 에서 무시 가능.
우리 NCM (고용체) 은 **이산 분해 사건이 원리상 없어** 이 진동이 생기지 않는다 → real_14 AM 457 개로 충분할 가능성이 높다 (⬜ 확인 방법: 반경 층화 K-bin 대표입자 vs 전수 비교 — 새 물리 없음).
그러나 **LFP · 흑연 같은 상분리 활물질을 STEP4 로 돌리면 457 개는 진동 영역**이다 — 연속체 표현(Clarke et al. [31]) 이나 가중 대표입자(이 논문)가 필요하다.

### ④ ★ "전기화학으로 본 PSD" ↔ "기하 PSD" 교차검증 (frame[4] 규율) — NCM 판은 확산시간 역산
NCM 에서 크기 신호는 핵생성 간극이 아니라 **확산시간 r²/D** 에 있다 (Fig. 4 의 식별성 논리를 옮기면: 폭 ↔ 율속 곡선의 꼬리, 위치 ↔ 평균 과전압). 율속(C/20–2C)·GITT 반쪽셀 곡선을 STEP4 입자별 확산으로 역산해 **"전기화학적으로 활성인 유효 확산길이 분포"** 를 얻고, 그것을 DEM 설계 PSD 와 **각자 실험에 보정한 뒤** 대조하면 기하 ↔ 활성 차이(응집 · 사체 입자 · 피복 결손)를 정량할 수 있다 — 우리 dead-AM 경고(f_AM^cc < 80 %)와 같은 물음. (**가설 · 미실행**. D_s 와 r 이 r²/D 로만 묶여 **동시 식별 불가**라는 점이 이 역문제의 첫 벽이다.)

### ⑤ (가설) LFP-ASSB 로 가면 "젖은 표면" S 가 **SE 피복 면적**이 된다
Eq. 4 의 S 는 **젖은(wetted) 표면**이다 (Eq. 5 는 "완전히 젖은 구"). 황화물 ASSB 에서 액체 대신 SE 가 표면을 덮는다면 S_wet ≈ f_cov · 4πr² (우리 DEM Tabor 피복 ≈ 50 %) → 같은 크기에서 간극이 커지고 임계 반경이 3L_c·f_cov 로 준다 → **완전 젖음 가정으로 역산한 PSD 는 작게 편향**된다. 우리 DEM 은 입자별 피복률을 가지므로 S_wet 을 공급할 수 있다. ⚠ 원문은 액체 완전 젖음만 다루고, Cogswell–Bazant 의 "젖음" 이 고체 계면 피복과 같은 물리인지는 **미검증**.

### ⑥ 역문제 설계 규율 두 줄 (우리 ML/BO 루프에)
(a) **식별성**: 5 파라미터를 곡선 1 개로 — 경계 κ 와 PSD 폭이 서로 새지 않는다는 근거는 "경계항이 중간영역에 정확히 0" (Fig. 9) 하나뿐. 우리 BO 루프도 **목적함수를 구간별로 분해**해 어떤 파라미터가 어떤 구간에서 식별되는지 먼저 적는다.
(b) **전위 → 크기 환산에서 인자 2** 같은 규약 실수는 한 줄로 결론(5 % → 10 %)을 바꾼다 — 환산 식은 **모델 자신의 OCP 식으로 되돌려 검산**한다 (§13-3 이 그 예).

## 10. 주의 / 한계 (over-claim 방지) — 비판적으로

1. **영상 검증 없음.** 역산 PSD 를 SEM/TEM 과 비교하지 않았다 (서론에서 영상법을 "자원 집약적" 대안으로만 언급). 풀셀 적합은 DFN 매개변수 세트 [45] · 음극 OCP 처리와 **공동**으로 맞춘 결과라 PSD 의 독립 증명이 아니다.
2. **절대 크기는 문헌 상수가 정한다.** r = 3L_c / (1 − Δμ_j/Δμ_gap,∞) — 같은 측정에서 **Δμ_gap,∞ ±10 % → r_mode −8.9 / +13.5 %**, **L_c ±10 % → ±10.0 %** (derived(ours)). 두 상수의 출처는 [21] Cogswell & Bazant, *ACS Nano* 6 (2012) 2215 ("Coherency strain and the kinetics of phase separation in LiFePO4 nanoparticles") · [22] Ferguson & Bazant, *Electrochim. Acta* 146 (2014) 89 (이 PDF 참고문헌 목록 그대로) 이고, 이 논문이 다시 재지 않았다.
3. **반경 불확도의 인자 2** (§13-3): 모델 자신의 OCP (Eq. 7) 에서 탈리튬 평탄부 = Φ₀ + Δμ_gap,j/2 인데 (Fig. 5a 판독 11 / 19 / 27 mV 와도 일치), 본문 환산 −1.56 / +1.72 nm 는 δΦ = δΔμ_gap 으로 한 값과 **정확히** 일치한다. 평탄부 기준이면 **−2.99 / +3.62 nm (−8.7 / +10.5 %)**. 본문 문장 *"The difference between the measured potential and the reference potential then directly corresponds to the spinodal gap"* (p.16) 이 같은 혼동을 담고 있다.
4. **C/50 분극 가정의 민감도**: 평탄부에 계통 +1 mV 가 얹히면 r_mode **+5.9 %** (+0.5 mV → +2.9 %, +2 mV → +12.6 %; derived(ours), 반 간극 관계). Φ₀ 도 "실험에 맞춰 설정" 이라고만 되어 있어, 충·방전 평탄부의 가운데로 정했다면 대칭 분극은 반 간극을 그대로 부풀려 크기를 크게 만든다 (**우리 추론** — Φ₀ 를 정한 방법은 원문에 없다). 저자는 문헌 [54–56] 으로 "작다" 고만 한다.
5. **식별성**: 5 파라미터 (PSD 3 + κ 2) ← 탈리튬 곡선 1 개. κ 적합값 미보고. 리튬화 경계는 맞지 않는다 (저자: 방향의존 OCP 가능성 — 모델에 없음).

## 11. 논증 흐름 (절별)

1. **서론 (p.5–9)** — LFP 전극의 세 현상: ① 이완 뒤에도 남는 **이력** [5], ② 전류를 다시 걸 때의 **overshoot** (Kondo [7]: 충분한 입자가 2 상에 들어갈 때), ③ 저전류에서도 평탄부가 **서서히 오르내림** (크기의존 핵생성 전위 [21, 22]). 현상학 이력 모델(Plett · Axén · Wycisk · Ai)은 빠르지만 입자 기전을 못 담는다 → Dreyer 이래의 **다입자모델** [16, 17, 29–33]. 선행 DFN 결합(Foster [30] · Clarke [31])은 Gibbs 에너지를 **입자 공통**으로 둬 크기 의존을 버렸고, PSD 는 단일 크기 · 가정 · 영상 중 하나였다. Ferguson–Bazant [22] 가 반쪽셀로 PSD 를 얻는 이론을 줬지만 **그 PSD 를 다입자모델 입력으로 쓴 예는 없다** → 이 논문의 빈칸.
2. **방법 (p.9–25)** — (a) 크기의존 Ω + 경계 경험항으로 입자 OCP, (b) Kondo 식 다입자 동역학, (c) PSD 역산 (비대칭 로그정규 + 대리모델 최적화), (d) Graule 등가회로에 다입자모델 결합 (층화 표본 · 가중 · 국소 Newton · 접선 스탬프 · MNA).
3. **실험 (p.26–28)** — 26650 셀 수확 반쪽셀 C/50 (2.5–3.8 V) · 풀셀 C/25 · C/10 · C/2.

## 12. 용어 미니 사전

- **다입자모델 (many-particle model, 논문 약어 MPM)** — 전극을 서로 다른 이력을 가진 입자들의 집합으로 보고, 각 입자의 OCP 와 반응전류를 따로 풀어 전극 전위를 합으로 얻는 모델. ≠ material point method.
- **regular solution theory** — 이상 혼합 엔트로피 + 혼합 엔탈피 Ωc(1−c) 로 된 자유에너지 모형. Ω > 2 에서 이중우물 → 상분리.
- **스피노달 (spinodal)** — g'' = 0 인 점. 넘으면 균질상이 불안정해져 즉시 분해. **바이노달 (binodal)** — 공통접선 점, 두 상의 평형 조성 (혼화성 간극의 끝).
- **스피노달 간극 Δμ_gap** — 두 스피노달의 화학퍼텐셜 차 (Eq. 3). 탈리튬·리튬화 평탄부의 차 = 전압 이력. 평탄부 하나와 Φ₀ 의 차는 그 **절반**.
- **L_c (critical size)** — 핵생성 장벽이 사라지는 크기 척도. 젖은 표면/부피 비가 1/L_c 에 이르면 간극 0 (구: r = 3L_c = 16.7 nm).
- **젖은 표면 (wetted surface)** — 전해질과 닿아 표면 에너지가 상분리를 억제하는 표면 (Cogswell–Bazant). 완전 젖은 구 S/V = 3/r.
- **overshoot (메모리 효과 계열)** — 이완 뒤 전류를 걸 때 전위가 먼저 치솟았다 내려오는 현상. 입자들이 스피노달까지 밀려 가야 분해가 시작되기 때문.
- **비대칭 로그정규 (asymmetric log-normal)** — 모드를 공유하고 좌·우 폭이 다른 두 로그정규를 이어 붙인 분포 (부록 A).
- **층화 역변환 표본 (stratified inverse-transform sampling)** — 누적분포를 N 등분한 층마다 하나씩 역변환으로 뽑는 표본법. 무작위 표본보다 적은 수로 분포를 고르게 덮는다.
- **대표입자 가중 w** — 표본입자 하나가 같은 크기 실입자 w 개를 대신. 활물질 부피 보존으로 w 결정 (Eq. 16).
- **물리화학 등가회로 (physicochemical equivalent circuit, Graule 2024)** — DFN(P2D) 의 확산·전도·반응을 저항·커패시터·전원 소자 사다리로 옮긴 셀 모델.
- **MNA (modified nodal analysis)** — 회로를 넷리스트로 두고 각 소자가 전역 행렬에 "스탬프" 를 더해 절점 전위 + 일부 가지전류를 푸는 표준 회로 해석법.
- **증분저항 R_MPM,inc** — 국소 다입자 가지의 전류-전압 곡선 기울기 (Eq. 22). 비선형 가지를 등가 전압원 + 저항으로 선형화해 전역 해에 넣는 도구.
- **대리모델 최적화 (surrogate-based optimization)** — 비싼 시뮬레이션 대신 근사 모델로 다음 시험점을 제안하는 최적화 (여기선 알고리즘 미기재).
- **MacMullin 수 N_M** — 다공 전극의 유효 전도 감소 배수 (= τ/ε 류). 이 논문에선 입력 상수.

### 13-8. 재구성 코드 조각 (App. A — 우리 PSD 파라미터화에 바로 쓸 수 있는 형태)
```python
import math, numpy as np
def asym_lognormal(r_mode, s_left, s_right, r_ref=60.0):          # 모든 길이 같은 단위 (논문: nm)
    s = {q: math.sqrt(math.log(1 + (v / r_ref) ** 2)) for q, v in (("l", s_left), ("r", s_right))}   # A.1
    mu = {q: math.log(r_mode / r_ref) + s[q] ** 2 for q in s}                                         # A.2
    f = lambda q, r: np.exp(-(np.log(r / r_ref) - mu[q]) ** 2 / (2 * s[q] ** 2)) / (r * s[q] * math.sqrt(2 * math.pi))  # A.3
    Phi = lambda z: 0.5 * (1 + math.erf(z / math.sqrt(2)))
    fl, fr = f("l", np.array([r_mode]))[0], f("r", np.array([r_mode]))[0]
    w_l = 1 / (Phi(-s["l"]) + Phi(s["r"]) * fl / fr); w_r = w_l * fl / fr   # r_mode 연속 + 적분 1
    return lambda r: np.where(np.asarray(r) <= r_mode, w_l * f("l", np.asarray(r, float)),
                              w_r * f("r", np.asarray(r, float)))          # A.4 (수 분포 p(r))
p = asym_lognormal(34.48, 15.10, 7.50)   # → p(34.48) = 0.0674 /nm, Fig. 8a 경로와 0.08 % 안
```
