## 4. n_rb 용어 정정 — P3, 기존 판정 무영향

| 관측 부류 | NP2 | NP4 |
|---|---:|---:|
| 표지 0 랭크 경계 쌍 (`n_rb`, 기존 (c)) | 41 | 95 |
| 내부 랭크 경계 중 표지 1 쌍 | 114 | 236 |
| 내부 랭크 경계 전체 | 155 | 331 |
| 모든 표지 1 쌍 (기존 JSON `periodic`, (d)) | 446 | 570 |
| [연속] C 힘 다른 쌍 | 487 = 446+41 | 665 = 570+95 |

덤프 표지는 `is_periodic_ghost`다. 리포 보존 소스 `docs/reviews/codex_kg50_decks_review_20261026/evidence/kg50_design/sources/src__domain_I.h` 165–182행은 로컬 원자가 아닌 고스트의 좌표가 주기 축 상자 면의 `cutneighmax` 띠 안에 있으면 1을 반환한다. 제공된 설명의 절단 0.0045 m는 상자 0.012 m의 37.5%/면이다. 따라서 표지 1을 “실제로 주기 영상을 건너는 쌍만”으로 읽으면 안 된다. 이 소스 사본의 확인을 실행 바이너리 전체의 소스 동일성 인증으로 확대하지 않는다.

이번 수령 산술은 A 원자 위치로 지정 격자의 주인을 정하고, x/y의 원자 간 거리 중 하나가 L/2보다 큰 최소 영상 건너뜀을 내부 경계 집계에서 제외했다. 그 뒤 주인이 다른 쌍의 표지 0/1을 세어 위 155=41+114, 331=95+236을 확인했다. 기존 애매 경계는 0이다. 세부 입력 해시는 `archive_file_hashes.json`에 있다. 이는 반환 덤프의 기하 산술 확인이며 새 판정기나 물리 기전 증명은 아니다.

원 JSON의 `periodic` 키·(a)–(d) 분류·`n_rb` 숫자를 바꾸지 않는다. 역사 어림 179·328은 직렬 침대 및 “표지=주기 영상” 가정을 쓴 값으로 남기며 새 실측과 같다고 쓰지 않는다. 내부 경계 전체 155·331을 `n_rb`로 치환하지 않는다. [연속]의 힘 다른 쌍 487·665와 허용폭을 적용한 kit26 불일치 쌍 484·658도 서로 다른 수다.
