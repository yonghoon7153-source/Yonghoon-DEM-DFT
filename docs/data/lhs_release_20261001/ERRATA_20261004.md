# 정오표 (2026-10-04) — 굴곡도 문장 둘 · 값 불변

이 배포본 (v1 · 10-01 전달) 에서 아래 두 문장을 바꿔 읽는다.  **값은 하나도 바뀌지 않는다** — 이 배포의 어떤 열에도 τ_Laplace,eff · tau2 값이 없고,
`tortuosity_SE_wall(_median)` 은 기하 최단경로 (수송 τ 아님) 다.  배포 파일은 전달된 바이트 그대로 둔다.

| 자리 | 옛 문장 | 바꿔 읽기 |
|---|---|---|
| 열 사전 `lhs_release_20261001_columns.tsv` · `lhsx_release_20261001_columns.tsv` — `tortuosity_SE_wall` 설명 | *"COMSOL/EIS 입력 τ 는 τ_Laplace,eff = √(φ_SE·σ_grain/σ_full) (망 단계 · 이 표에 없음)"* | 수송 굴곡도는 망 단계의 **tau2 = φ_SE·σ₀/σ_full** (tortuosity factor · τ_Laplace,eff = √tau2 · 이 표에 없음) |
| `README.md` — `tortuosity_SE_wall` 행 | *"COMSOL · 유효 전도도 입력용 τ (τ_Laplace) 는 이 표에 없다"* | 유효 전도도 쪽 굴곡도 (tau2 = φ_SE·σ₀/σ_full · √ 값 τ_Laplace,eff) 는 이 표에 없다 |

- **왜**: 연속체 모델 입력 칸 (COMSOL Tortuosity 등) 의 꼴은 √ 값이 아니라 **tau2** 다 — √ 값을 넣으면 유효 전도도가 √tau2 배 과대가 된다.
  COMSOL 배터리 *Porous Electrode* 노드는 식이 인쇄돼 있지 않아 (종 수송 인터페이스 Eq 6-6 의 τ_F 꼴로 강하게 시사), tau2 에 "COMSOL 입력" 표지는
  사용 버전의 GUI Equation 보기로 확인한 뒤에 단다.
