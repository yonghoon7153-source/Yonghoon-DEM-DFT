## 1. 한 줄 요약

**"같은 종류 입자끼리 얼마나 멀리 떨어져 있나"** 하나만 재서 혼합·분리를 정량화하는 입자스케일
지표(NNSI = near-neighbour separation index, 본문에서는 SI 로 줄여 씀)를 제안한다:
`SI = (l̄ − l_min)/(l_ud − l_min)` — 같은 타입 최근접이웃 거리의 평균 `l̄` 을, **접촉(하한)**과
**완전균일분산(상한)** 사이에서 0–1 로 정규화한다. 격자(bin)를 쓰지 않고 **위치 좌표만** 쓰며
**한 프레임으로 끝난다**(이력·초기배치 불요). 저자의 핵심 주장은 두 가지 — (i) Lacey 계열이
구분하지 못하는 *"조성은 같은데 국소적으로 뭉쳐 있는"* 상태(그림 1a vs 1b)를 구분한다,
(ii) **다성분(polynary)·다크기 계에 그대로 확장된다**.
⚠ 그러나 이 논문의 검증은 **전부 2성분**이고, **크기비를 바꾸면 SI 가 비단조로 23배 흔들리며**
(§11-6), **완전혼합=1 의 기준이 "무작위 혼합"이 아니라 "격자형 완전균일"** 이라 무작위 대비
얼마나 뭉쳤는지는 읽을 수 없다 (§11-2).

## 4. ★ 방법 — NNSI 의 정의 전체

### 4-1. 기호

| 기호 | 뜻 | 단위 |
|---|---|---|
| `N` | 계 전체 입자 수 | – |
| `n` | 입자 **타입 수** (A, B, C, …, n) | – |
| `c_i` | 타입 `i` 의 입자 **개수** (A 타입은 `c₁`) | – |
| `d_i` | 타입 `i` 의 입자 **지름** | m |
| `V_i` | 타입 `i` 가 차지하는 **총 고체부피** | m³ |
| `V_T` | **control volume (bulk volume)** — A 타입 입자가 들어 있고 나머지 공간은 다른 타입 + **공극**이 채우는 부피 | m³ |
| `φ` | **solid packing factor** (고체 충전율) | – |
| `l` | 같은 타입 최근접 이웃 두 입자의 **중심–중심 거리** | m |
| `l̄` | 그 `l` 의 **평균** | m |
| `l_min` | 접촉한 같은 타입 두 입자의 **최소 분리거리** | m |
| `l_ud` | **uniform distribution distance** — A 타입이 완전균일 분산일 때의 중심간 거리 | m |
| `SI` | near-neighbour separation index (= NNSI) | – |

### 4-2. 식 (원문 그대로)

```
(16)  N   = Σ_{i=1..n} c_i

(17)  V_i = (π/6) · c_i · d_i³

(18)  V_T = [ Σ_{i=1..n} (π/6) · c_i · d_i³ ] / φ

(19)  l   = sqrt[ (x_i − x_j)² + (y_i − y_j)² + (z_i − z_j)² ]

(20)  l_ud = ( 6 φ V_T / (c₁ π) )^(1/3)

(21)  SI  = ( l̄ − l_min ) / ( l_ud − l_min )
```

**말로 적은 정의** (본문 인용) `[P]`:
- `l_min` = *"the geometrical mean of the two diameters of neighbour (contacting) particles"*
  (접촉한 이웃 두 입자 **지름의 기하평균**).
- `l̄` = *"the average of the measured neighbour distance of the constituent particle contacts"*.
- `l_ud` = *"If all the particles are well mixed and uniformly (homogeneously) distributed in the volume
  calculated in Eqn. (18), **and assuming a constant solid packing factor φ**"* 일 때의 A 타입 간격.
- 경계: *"SI is bounded between 0 and 1 for which **SI = 0 indicates completely segregated** while
  **SI = 1 indicates well and homogeneously mixed**"*.

⚠ `l_min` 의 *"지름의 기하평균"* 은 **접촉 기하와 맞지 않는다** `[R]`: 접촉한 두 구의 중심거리는
`r_i + r_j = (d_i + d_j)/2` = **산술평균**이다. 기하평균 `√(d_i d_j)` 은 크기가 다를수록 작아진다
(12:1 이면 산술 6.5 vs 기하 3.46 — **1.9배 차이**). **같은 타입끼리만 보므로 타입 내부가 단분산이면
둘이 일치**해 이 논문에서는 문제가 드러나지 않는다. ⇒ **타입 내부에 PSD 가 있으면 규약을 정해야 한다.**
(우리 생산 덱은 AM_P·AM_S·SE 각각 단일 반지름이라 **우리에겐 무해**하다 — §12.)

### 4-3. 코너 규약 (논문이 직접 적은 예외처리) `[P]`

| 조건 | 규약 | 결과 |
|---|---|---|
| `c₁ > 1` | 식 (19) 정상 적용 | – |
| `c₁ = 1` | *"l is conveniently assigned the value of the particle diameter"* | `l = d` |
| `c₁ = 0` | *"l = 0 and l_ud tends to infinity and thus the calculated near-neighbour SI = 0"* | `SI := 0` |
| 과도상태·다분산계 | *"a control volume chosen for analysis … may or may not contain some of the particles, in which case, **suitable assumptions and conditions must be satisfied** to maintain the calculation consistency without divergent"* | **어떤 가정을 썼는지는 안 적혀 있다** |

⚠ **`c₁ = 1` 과 `c₁ = 0` 규약은 둘 다 `SI → 0` = "완전 분리"** 로 떨어진다 `[R]`.
`c₁ = 1` 이면 `l = d = l_min` 이고 `l_ud` 는 거대해지므로 식 (21) 이 정확히 0 이다. 그런데
**"그 구역에 A 가 딱 하나" = 물리적으로는 가장 잘 분산된 상태**다. ⇒ **지표가 부호를 반대로
읽는 코너가 정의 안에 들어 있다.** 구역을 잘게 쪼갤수록 이 코너를 자주 밟는다.

### 4-4. 알고리즘 (Fig 3 흐름도 전사) `[P]`

```
Start
  → Read Particles Position Data
  → Identify Particles by Type
  → [ Number of Particles by Type < 1 ? ] ──Y──→ Update Particles Position Data → (다음 프레임)
        │N
  → Loop Through all Same Type Particles Computing Nearest Centre-Centre Distance   … l̄
  → Calculate Total Particle Constituents Volume                                    … Σ(π/6)c_i d_i³, V_T
  → Compute Same Type Particles Uniform Distribution Centre-Centre Distance         … l_ud
  → Output Data: Near-Neighbour Separation Index
Stop
```

★ **이웃의 정의가 이 흐름도에서 확정된다**: *"Loop Through all **Same Type** Particles Computing
**Nearest** Centre-Centre Distance"* ⇒
1. **같은 타입**끼리만 본다 (다른 타입과의 거리는 안 쓴다).
2. **최근접 1개**만 본다 (k-NN 아님, 접촉 여부 무관, 컷오프 없음).
3. **중심–중심 거리** (표면간 간극 아님).
4. 접촉 판정이 필요 없다 ⇒ **contact dump 없이 atom dump(위치)만으로 계산된다.** `[R]`

### 4-5. ★ [R] 논문이 하지 않은 유도 — 식이 실제로 무엇인가

**(a) φ 는 소거된다.** 식 (18) 을 식 (20) 에 대입하면
```
6φ/(c₁π) · [Σ(π/6)c_i d_i³]/φ  =  Σ_i c_i d_i³ / c₁
⇒  l_ud = ( Σ_i c_i d_i³ / c₁ )^(1/3)                      … [R] 항등식
```
**φ 가 정확히 사라진다.** 즉 *"assuming a constant solid packing factor φ"* 라는 단서는
저자 자신의 식 안에서는 **아무 역할도 하지 않는다**. (반대로, 구현자가 `V_T` 를 *입자부피에서
역산*하지 않고 *샘플링 구역의 기하부피*로 잡고 φ 를 상수로 넣으면 `l_ud` 가 **침대 팽창에 따라
움직인다** — 두 구현이 **다른 값**을 낸다. 논문은 어느 쪽을 썼는지 적지 않았다.)

**(b) 상한/하한의 비는 오직 "그 상의 고체부피 분율"만의 함수다.** 타입 A 가 단분산이면
`l_min = d_A`, `Σ_i c_i d_i³ = V_solid·6/π`, `c₁ d_A³ = V_A·6/π` 이므로
```
l_ud / l_min = ( V_solid / V_A )^(1/3) = f_A^(−1/3)          … [R], f_A = A 의 고체부피 분율
⇒  SI_A = ( l̄_A/d_A − 1 ) / ( f_A^(−1/3) − 1 )              … [R] 단분산-상 축약형
```
⇒ **SI 는 "평균 동종-최근접거리를 입자 지름으로 나눈 것"의 1차 재척도(rescale)일 뿐이다.**
조성은 **분모의 상수**로만 들어간다.

**(c) 그래서 동적범위가 조성에 붙어 있다** `[R]`:

| 그 상의 고체부피 분율 `f_A` | `l_ud/l_min` | 분모 `(l_ud − l_min)/d` |
|---|---|---|
| 0.50 | 1.260 | **0.260** |
| 0.27 (우리 SE 수준) | 1.547 | 0.547 |
| 0.091 (Case XII 소수상) | 2.224 | 1.224 |
| 0.01 | 4.642 | 3.642 |

**부피가 많은 상일수록 분모가 작아져** SI 가 "두 비슷한 길이의 차"가 된다 = **오차 증폭**.
(우리가 porosity 에서 이미 겪은 구조다: `ε = C − φ_SE − φ_AM` 의 17배 증폭 — CLAUDE.md
설계→구조 ML 절.)

**(d) `SI = 1` 은 "무작위 혼합"이 아니라 "완전균일(격자형) 분산"이다** `[R]`.
Lacey 식 (1) 은 `σ_r²`(완전무작위 분산)을 **명시적 기준점**으로 갖는 데 반해, 식 (21) 에는
무작위 기준이 **없다**. 밀집 무작위 혼합에서는 같은 타입 입자가 서로 **접촉**하는 일이 흔하므로
`l̄ → l_min`, 즉 `SI → 0` 쪽이다. ⇒ **"무작위 대비 얼마나 뭉쳤나"를 SI 값에서 읽을 수 없다.**
이것이 Couette 정상상태가 0.003–0.093 이라는 **바닥값**으로 나오는 이유이고, 저자도 그 상태를
*"partially heterogeneous mixed system"* 이라 부르면서 **기준점은 끝내 제시하지 않는다**.
★ 동반 카드의 GNN 은 **정확히 이 기준점을 갖는다**(조성이 정하는 무작위 기대로 나눈다) —
**두 지표의 가장 큰 구조적 차이**다 (§13).

**(e) [R] 감사 불가능한 대비 — 같은 조성에서 0.044 와 0.61 이 같이 나온다.**
식 (21) 을 되돌리면 `l̄ = l_min + SI·(l_ud − l_min)` 이다. 조성 50:50·동일크기(`f_A = 0.5`,
`l_ud = 1.260 d`) 에서:
- Couette Case II (L) `SI ≈ 0.044` → **`l̄ ≈ 1.011 d`** = 거의 모든 입자가 동종 입자와 **접촉**.
  밀집 중력침강 침대로서 **완전히 자연스럽다**.
- 날개믹서 Case XI 20 RPM `SI ≈ 0.61` → **`l̄ ≈ 1.159 d`** = 동종 입자와의 접촉이 **드물다**.
  50:50 무작위 배치에서 배위수 6 만 돼도 동종 접촉 확률이 `1 − 0.5⁶ ≈ 98 %` 이므로,
  **무작위 혼합으로는 나올 수 없는 값**이다. 남는 설명은 (i) 교반 중 **침대 팽창(dilation)** 으로
  접촉 자체가 줄었거나 (ii) `l̄`·`l_min` 의 구현이 본문 서술과 다르거나 — 둘 중 하나다.
- ⛔ **논문만으로는 가를 수 없다**: φ 값도, `l̄`·`l_ud`·`l_min` 의 원시값도, 피팅계수도
  **한 건도 보고되지 않았다.** ⇒ **RPM 의존(0.61→0.88)을 "혼합이 좋아졌다"로 읽는 것은
  "팽창이 커졌다"와 구분되지 않는다.** 논문에는 그 둘을 가르는 대조가 없다.

### 4-6. DEM 방법 (지표와 별개) `[P]`

- **코드**: **LIGGGHTS®** (Kloss [39]). HPC = Research Compute Grid, **16 × 512 GB 노드**,
  2.7 GHz Intel Xeon Gold (E5-6150).
- **접촉법칙**: **Hertz–Mindlin no-slip** (법선 Hertz [36] + 접선 Mindlin–Deresiewicz [37]).
  Table 1 에 `k_n = (4/3)E*√(r*δ_n)`, `k_t = 8G*√(r*δ_n)`, `γ_n ∝ √(S_n m*)`, `S_n = 2E*√(r*δ_n)`,
  `β = ln e/√(ln²e + π²)`, `δ_n = r_i + r_j − |x_i − x_j|` 등 표준 관계가 그대로 적혀 있다.
- **구름마찰**: 비구형성 대리로 **CDT(constant directional torque) 모델** [43, Ai 2011]
  `T_r,ij = (ω_rel/|ω_rel|)·μ_r·r*·|F^N_ij|`, μ_r = 0.5.
- **겹침 제한**: *"Particles are allowed to undergo small overlaps with the upper limit generally
  limited to **< 1.0 % of the smallest particle radius**"* ⇒ **지름 기준 0.5 % 미만**.
  ★ 이 한 줄이 §12 에서 우리 적용 가능성을 가른다.
- **점착 없음**: *"considering the relatively large size and non-cohesiveness of such materials"*
  → 중력 + 접촉력만. **cohesion/JKR 항이 없다** ⇒ 우리 `m7` 축(점착 비대칭)에 해당하는 물리가
  이 논문에는 **아예 없다**.

- ① ★ **"응집을 보여 달라"는 요구를 숫자로 바꾸는 방법이 하나 더 생겼다** — 단, 우리 쓰임새는
  **압밀 후 프레임이 아니라 침강 직후(loose) 프레임**이다. 응집을 만드는 물리(`m7` 점착)는
  침강 중에 작동하고, 300 MPa 압밀은 간극을 지워 **모든 상의 `l̄` 을 접촉거리로 밀어붙인다**(§12-2).
  ⇒ **보고창을 하나 더 두자**: 사전등록의 최종 프레임(주) + **침강 종료 프레임(부, NNSI 전용)**.
  ⚠ 사전등록 §4 의 보고창은 **고정**이다 — 새 창은 *추가 서술*이지 판정창이 아니다.
- ② ★ **`l_min` 을 우리 겹침에 맞게 다시 정의해야 한다**(§12-1). 원식의 `l_min = d` 는
  *"겹침 ≈ 0"* 을 전제로 한 하한이다. 우리는 겹침이 그 예산의 **10–20배**라 `l̄ < l_min` 이 되어
  **SI 가 음수로 새어나간다**. 처방 두 가지: (i) `l_min := ⟨접촉 중심거리⟩ = (1 − δ̄/d)·d`
  (같은 프레임에서 실측) 또는 (ii) SI 를 버리고 **`l̄/d` 자체를 보고**하고 조성 정규화는 따로 적기.
  ★ (ii) 가 더 정직하다 — §4-5b 대로 **SI 는 `l̄/d` 의 1차 재척도일 뿐**이므로 정보 손실이 없다.
- ③ **같은 조성 안에서의 팔 비교에는 분모가 상수**다(§4-5b). `m7` 3팔은 조성이 동일하므로
  `f_A` 가 같고 ⇒ **NNSI 와 `l̄/d` 는 같은 순위를 준다.** 즉 *"조성 의존 때문에 못 쓴다"* 는
  이 설계에서는 **성립하지 않는다** — 막는 것은 조성이 아니라 **겹침과 압밀**이다.
- ④ **팽창(dilation) 교락을 우리 쪽에서 먼저 막아야 한다**(§4-5e). `m7` 팔은 점착이 다르면
  **최종 porosity 가 달라질 수 있고**, `l̄` 는 그 차이에 직접 반응한다. ⇒ NNSI 계열을 쓸 거면
  **porosity 를 같은 표에 반드시 병기**하고, 가능하면 `l̄` 를 그 프레임의 **평균 입자간격
  `(V_box/N)^(1/3)`** 으로 한 번 더 정규화한 값을 같이 낸다.
- ⑤ **구역 분할의 교훈**(Fig 10): 같은 케이스인데 배출구 구역이 다른 세 구역의 **2배**였다.
  ⇒ 우리도 전역 1개 값만 내지 말고 **z-띠(상·중·하) 로 나눈 값**을 같이 내는 것이 [19] 의
  *"어디가 응집되나"* 에 더 직접적인 답이다. ⚠ 단 구역을 쪼갤수록 `c₁ = 0/1` 코너(§4-3)를
  밟으므로 **구역당 최소 입자수 가드**가 필요하다.
- ⑥ **음성 결과 보고의 선례**(Fig 7): 교반 20→60 RPM 이 **아무 차이도 안 만든** 것을 그대로
  실었다. 우리 `m7` 판정이 `h0`(비대칭이 응집을 안 만든다) 로 나와도 **그것이 보고 가능한
  결과**라는 문헌 선례로 쓸 수 있다.

## 9. 인용 가능 문장 (deck/paper 용)

- "Particle-scale segregation metrics that avoid grid/spot sampling have been proposed for granular
  flows; the near-neighbour separation index (Chibwe et al., Powder Technol. 360 (2020) 481–492)
  normalises the mean nearest same-type centre-to-centre distance between the contact limit and the
  uniform-dispersion limit, `SI = (l̄ − l_min)/(l_ud − l_min)`, and is reported to be independent of
  binning and applicable to polynary systems."
- "In that formulation SI = 0 denotes complete segregation and SI = 1 a homogeneously dispersed
  species; note that the upper reference is a *uniform* dispersion, not a *random* mixture, so SI does
  not measure deviation from randomness." ★ 두 번째 문장은 **우리 유도**(§4-5d)이므로 인용 시
  Chibwe 에 귀속하지 말 것.
- ⛔ **쓰지 말 것**: *"NNSI 가 다성분·다크기 계에서 검증됐다"* — 논문의 검증은 **전부 2성분**이고
  크기비도 1/0.75/0.5 셋뿐이다.

## 10. 주의 / 한계 (over-claim 방지)

**논문 자체의 결함 — 근거와 함께**

1. ⛔ **동기 그림(Fig 1)의 SI 를 끝까지 계산하지 않는다.** 지표의 존재 이유로 든 (a)/(b) 두 배치에
   대해 SI 값을 보이지 않는다 ⇒ **핵심 주장이 그림 설명으로만 있고 수치 증명이 없다.**
2. ⛔ **그 동기 주장 자체가 이웃-분율 계열에 대해서는 성립하지 않는다.** 본문은
   *"§2.1, 2.2, 2.3, 2.4 의 지표들로 Fig 1 을 재면 **같은 값**이 나온다"* 고 적는데, §2.2 의
   최근접이웃 지표(식 7 `M = (1/N)Σ 2n_diff/n_nb`) 와 §2.4 의 PSMI(배위수 기반)는 **바로 그
   "동종 접촉 수"를 세는 지표**다. 체커보드(동종 접촉 0)와 (b)(동종 접촉 있음)는 식 7 에서
   **명백히 다른 값**을 준다 `[R]`. ⇒ **NNSI 의 차별성 논거는 분산(variance) 계열(Lacey·GMMI)에만
   유효하고, 05번 GNN 계열에는 유효하지 않다.** — §13 의 판단에 직접 걸린다.
3. ⛔ **수치표가 없다.** SI 값·피팅계수(`C_L`,`A`,`λ`)·`l̄`·`l_ud`·`l_min`·φ **전부 미보고**
   ⇒ 제3자가 **감사할 수 없다**. 실제로 같은 조성(50:50)에서 0.044(Couette)와 0.61(믹서)이
   나오는데, 후자는 무작위 배치로 재현되지 않는다(§4-5e)에도 원인을 가릴 정보가 없다.
4. ⛔ **시드 반복 0 · 오차막대 0 · 표본크기 수렴시험 0.** *"flexibility to use any data size"* 는
   **주장일 뿐 시험된 적이 없다.** Couette 구역 부피/입자수도 명시 없음.
5. ⛔ **"입자 이력·초기배치 무관" 은 구조적 사실이지 시험된 결과가 아니다** — 같은 종착상태를
   **다른 초기배치**에서 만들어 SI 가 일치하는지 보는 대조(가장 기본적인 검정)가 **없다**.
   모든 런이 **같은 층상 초기조건**에서 출발한다(§11-3).
6. ⛔ **크기비 민감도가 크고 비단조인데 보정이 없다**: 1.0 → 0.044, 0.75 → 0.070, 0.5 → **0.003**
   (수량비는 거의 고정) `[D]`. 저자는 이 스윙을 *"수량비의 약간의 변화 + 클러스터링"* 으로 돌린다.
7. ⛔ **두 장치의 SI 규약이 다르다**(구역 4개 vs 전체 입자) — 그런데 본문은 두 장치를 나란히 논한다.
8. ⚠ **`c₁ = 1 → SI = 0`** 코너는 물리적 의미가 뒤집힌다(§4-3).
9. ⚠ **"grid-independent" 의 범위**: **bin 을 안 쓴다**는 뜻이고, **샘플링 구역을 안 고른다**는 뜻이
   아니다. 실제로 이 논문의 Couette 결과는 **저자가 고른 상자 4개**의 함수이고 E 구역은 다른
   구역의 2배 값을 준다.
10. ⚠ 편집상 불일치 2건: 축 지름 본문 200 mm vs Fig 4(b) 라벨 25 mm · 샘플링 구역을 "Fig 5(d)" 라
    적었다가 뒤에서 "Fig 4(d)" 로 정정(전자가 오기).

**전이 한계 (우리 쪽)**

11. **소재·스케일이 완전히 다르다**: 제철 소결광 9–18 mm, 비점착, 압밀 없음 vs 우리 µm 급 LPSCl/NMC811,
    점착 있음, 300 MPa 압밀. **어떤 수치도 전이되지 않는다** — 전이되는 것은 **식과 그 구조적 성질**뿐.

## 11. ★ 사용자 7문 직답

### 11-1. NNSI 의 정의식 전체 · 기호 · 입력 · 이웃 정의 · 시간 의존성
→ §4-1 ~ §4-4 가 전문이다. 요약:
- **식**: `SI = (l̄ − l_min)/(l_ud − l_min)`, `l_ud = (6φV_T/(c₁π))^(1/3)`, `V_T = Σ(π/6)c_i d_i³ / φ`,
  `l` = 중심간 유클리드 거리(식 19), `l_min` = 접촉 두 입자 **지름의 기하평균**.
- **입력**: 한 프레임의 **입자 중심좌표 + 타입 + 지름**. 그게 전부. (속도·힘·접촉·이력 불요.)
- **이웃**: **같은 타입 중 최근접 1개**, 중심–중심 거리, 컷오프 없음, 접촉 판정 없음.
- **시간 의존성**: **없다.** 프레임마다 독립 계산(Eulerian). 시간축은 `SI(t)` 를 늘어놓는 것으로만
  들어오고, 보고되는 곡선은 **식 (29) 감쇠지수 피팅**이다(원시값은 시끄럽다 — Fig 6).

### 11-2. 값의 범위와 해석 — 완전혼합·완전분리의 기준
- `SI = 0` = **완전 분리** (`l̄ = l_min`, 동종끼리 붙어 있음) / `SI = 1` = **"well and homogeneously
  mixed"** (`l̄ = l_ud`, 동종이 균일 간격으로 퍼짐). `[P]`
- ⚠ **상한 1 의 기준은 "무작위 혼합"이 아니라 "완전균일(격자형) 분산"** `[R]` (§4-5d).
  밀집계에서 무작위 혼합은 `SI` 를 0 쪽으로 밀어붙인다 — 그래서 저자의 Couette 정상상태가
  0.003–0.093 이라는 **바닥값**으로 나오고, 저자는 그것을 *"partially heterogeneous"* 라고만 부른다.
  **"무작위 대비" 를 읽고 싶으면 이 지표로는 안 된다** (그건 `E_XY` 나 Lacey 의 `σ_r²` 의 일이다).
- ⚠ 실측 동적범위가 계(장치)마다 완전히 다르다: 밀집 침대 0.003–0.17, 교반 침대 0.61–1.0 `[D]`.
  ⇒ **SI 값의 절대 해석("0.6 이면 잘 섞였다")은 계를 건너 전이되지 않는다.**

### 11-3. "입자 이력·초기배치와 무관하게 순간상태를 기술한다" — 근거와 한계
**근거(구조적, 타당)** `[R]` — 식 (16)–(21) 에 들어가는 양은 **현재 프레임의 좌표·개수·지름**뿐이다.
비교군과 대비하면 차별성이 분명하다:
- GMMI(식 3–5)는 **임의 기준점 `x_ref`** 를 필요로 한다(초기배치 의존) → 저자가 *"과도·비정상
  공정에 적용이 곤란"* 하다고 지적.
- 이웃거리법(식 8)은 **무작위 쌍 `x_ik` 로 정규화**하고 **초기 중심간 거리**를 기준으로 쓴다.
- NNSI 는 이 둘 다 없다. 입자 **추적(Lagrangian tagging)도 하지 않는다.**

**한계(네 가지)**:
1. **자(尺)가 프레임마다 변한다.** `l_ud` 는 **그 구역의 현재 내용물**(`c₁`, `Σc_i d_i³`)로 만들어진다.
   입자가 드나드는 열린 구역에서는 **기준선 자체가 움직인다**. 저자도 *"suitable assumptions and
   conditions must be satisfied … without divergent"* 라고만 적고 **무엇을 썼는지 안 밝힌다**.
2. **검정된 적이 없다.** 다른 초기배치 → 같은 종착상태 → 같은 SI 인지 보는 대조가 **없다**.
   모든 런이 같은 층상 초기조건이다. ⇒ **주장은 구조적으로 그럴듯하지만 실증은 0.**
3. **"순간"은 시끄럽다.** 본문 자신이 *"substantial amount of fluctuations … as it cycles through
   mixing and de-mixing"* 라 적고, 보고값은 전부 **감쇠지수 피팅**이다. ⇒ 순간값을 그대로 판정에
   쓰려면 **프레임 평균 또는 시드 평균이 필요**하다(논문은 둘 다 안 한다).
4. **이력 무관 = 이력 정보 없음.** 어떤 경로로 그 배치가 됐는지(대류 혼합인지 확산 혼합인지)는
   원리적으로 못 준다. 저자의 *"will advertently reveal the mixing capability … caused by the initial
   position, and which is caused by the actual process"* 는 **수사이고, 그것을 가르는 측정은 논문에 없다.**

### 11-4. 격자·표본크기 의존을 어떻게 피하는가 + 저자가 적은 함정
**피하는 방식**: (i) **bin/격자 없음** — 모든 입자가 자기 이웃 거리로 기여. (ii) 분산 통계가 아니라
**거리 통계**라 Lacey 의 `σ_r² = p(1−p)/n` 처럼 **표본크기 `n` 이 식에 직접 들어가지 않는다**.
(iii) 저자가 든 장점 5개 `[P]`: 입자간 수준에서 혼합·분리 동시 지시 / DEM 데이터로 구현 용이 /
**모든 입자 위치를 써서 샘플링 독립** / **임의 데이터 크기 사용 가능** / **2성분·다성분 모두 적용**.

**⚠ 그러나 실제로는 다음이 남는다**:
1. **샘플링 구역 선택은 여전히 자유변수다.** Couette 은 상자 4개를 저자가 골랐고 **E 구역은 2배**
   값을 낸다(Fig 10). 날개믹서는 **전체 입자**를 썼다 ⇒ 두 결과가 같은 규약이 아니다.
2. **구역을 고르면 `V_T`·`c₁` 이 바뀌고 ⇒ `l_ud`(자)가 바뀐다.** 즉 **기준선이 샘플에 의존**한다.
   Lacey 의 `n` 의존을 지운 자리에 **구역 의존**이 들어왔다.
3. **경계에서 잘린 클러스터** 처리 규정이 없다 (구역 밖의 동종 이웃이 더 가까워도 안 본다).
4. **코너 규약이 지표를 왜곡**한다(`c₁ = 1 → SI = 0`, `c₁ = 0 → SI := 0`).
5. **수렴시험이 없다** — "any data size" 는 시험되지 않았다.
6. ★ 저자 자신이 적은 함정(원문): *"in a transient polydispersity system, a control volume chosen for
   analysis at some given space and time **may or may not contain some of the particles**, in which case,
   suitable assumptions and conditions must be satisfied to maintain the calculation consistency without
   divergent"* + *"the evaluation in Eqn. (19) is only valid for `c₁ > 1`"* + *"assuming a constant solid
   packing factor φ"*.

### 11-5. 다성분(3상 이상)으로 일반화되는가 — ★ 우리는 AM_P·AM_S·SE 3종
**정의는 된다 / 검증은 안 됐다 / 하나의 계-수준 숫자는 못 준다.** 셋을 나눠 적는다.

- **정의 O**: 식 (16)–(18) 이 처음부터 `A, B, C, …, n` 타입으로 쓰였고, `l_ud` 의 `Σ_i c_i d_i³` 는
  **모든 타입**을 포함한다. 본문: *"The given derivation from Eqns. (16)–(21) **can be done to any other
  particle constituents** of the system"* + 장점 목록의 *"binary or any polynary system"*. `[P]`
  ⇒ 3성분이면 **`SI_AM_P`, `SI_AM_S`, `SI_SE` 세 개**가 나온다. ★ **이것이 우리에겐 오히려 장점**이다 —
  우리가 묻는 것은 "계가 섞였나"가 아니라 **"어느 상이 뭉쳤나"**([19])이기 때문이다.
  ★★ **그리고 이 축에서 NNSI 가 05번 GNN 보다 낫다** — GNN 은 *one-vs-rest*(자기 vs 나머지 전부)로
  뭉개는데, NNSI 는 **상별로 완전히 분리된 세 숫자**를 준다 (§13-1).
- **검증 X**: 이 논문의 **모든 런이 2성분**이다(Table 3·4 전부 `d₁/d₂`, `n₁/n₂`). **3성분 예시는 0건.**
  따라서 *"다성분에 검증됐다"* 고 쓰면 **날조**다. (⚠ 05번 GNN 도 **똑같이 2성분뿐**이다 `[05카드]`.)
- **집계 규칙 없음**: `SI_A`, `SI_B`, `SI_C` 를 **하나로 합치는 정의가 없다**(Lacey·PSMI 는 계-수준
  단일 숫자를 준다). 3종이면 **세 숫자를 각각 보고**해야 하고, 판정선도 상별로 따로 세워야 한다.
  ⚠ 우리 사전등록 §5 는 **`E_SE-SE` 하나를 주지표**로 고정했다 — NNSI 를 쓰더라도 **`SI_SE` 하나**로
  주판정을 하고 나머지 둘은 부지표로 두는, 같은 구조를 지켜야 사전등록과 충돌하지 않는다.
- ⚠ **3성분이 되면 `l_ud` 를 통해 "제3상"이 조용히 끼어든다** `[R]`: `l_ud,SE` 는 `Σc_i d_i³` 에
  AM_P·AM_S 부피를 포함하므로, **SE 를 하나도 안 건드려도 AM 조성이 바뀌면 `SI_SE` 가 움직인다.**
  조성 고정 실험(`m7`)에서는 무해하지만, **조성을 바꾸는 스윕(P:S, AM wt%)에서는 교락**이다.

### 11-6. 입자 크기 차이에 편향되는가 — ★ 우리는 12배 차
**편향된다. 그것도 크게, 그리고 비단조로.** 세 층으로 나눠 답한다.

1. **정규화(분모)는 크기비와 무관하다** `[R]`: `l_ud/l_min = f_A^(−1/3)` 는 **부피분율만**의 함수다(§4-5b).
   ⇒ *"큰 입자라서 분모가 커진다"* 식의 단순 편향은 **없다**.
2. **그러나 측정량(`l̄`)이 크기비에 강하게 걸린다** `[R]`: 작은 상이 큰 상의 **간극(interstice)을 채우는**
   침대에서는 작은 입자의 최근접 동종 이웃이 **거의 항상 접촉**이다 ⇒ `l̄ → l_min` ⇒ `SI_small → 0`,
   **응집 여부와 무관하게**. 즉 **크기비가 커질수록 작은 상의 SI 가 바닥에 눌린다.**
3. **논문 자신의 데이터가 그것을 보여준다** `[D]` (Fig 12, 수량비는 1.0/1.333/1.056 로 거의 고정):

   | 크기비 `d₁/d₂` | 1.0 (Case II) | 0.75 (Case IX) | **0.5 (Case X)** |
   |---|---|---|---|
   | 정상상태 SI (L 구역) | 0.044 | 0.070 | **0.003** |

   **23배 스윙 · 비단조**(0.75 가 1.0 보다 높다). 저자는 이를 *"수량비의 약간의 차이 + 여전히 뭉쳐
   있어서"* 로 설명하고 **크기 효과를 분리하지 않는다.** ⇒ **크기비가 다른 침대 사이의 SI 절대비교는
   근거가 없다.**
4. ★ **게다가 우리 12:1 = 0.083 은 그들이 의도적으로 피한 영역**이다. 본문: *"there is **no segregation
   due to percolation** as the particle size ratio is greater than the percolation limit of **0.1547** [51]"*
   `[P]` — 즉 **모든 케이스가 자발적 침투분리(fine sifting) 가 기하학적으로 불가능한 쪽**에 있다.
   우리 SE/AM_P = 1/12 = **0.083 < 0.1547** ⇒ **우리 침대는 그 한계의 반대편**이고, SI 가 크기비에
   23배 반응한 바로 그 변수에서 **외삽**이 된다.
   (⚠ 05번 GNN 의 시험 범위는 **더 좁다** — 최대 크기비 1.33:1 `[05카드]`.)

### 11-7. mixing index 와 segregation index 는 같은 양의 반대 부호인가, 다른 양인가
**이 논문 안에서는 "같은 축의 반대 방향"이고, 다른 지표들과는 "다른 양"이다.** 정확히 나눠 적는다.

- **이름 대 방향**: 이름은 *separation index* 인데 **방향은 mixing index** 다 —
  `0 = 완전분리`, `1 = 완전혼합`. **값이 커지면 더 잘 섞인 것**이다. `[P]`
  (혼동 주의: "분리지수가 높다" = 분리가 심하다 **가 아니다**.)
- 논문은 시종 *"mixing and segregation"* 을 **한 축**으로 다루고 **segregation 을 독립 정의하지 않는다**
  ⇒ 이 논문 안에서 두 말은 같은 축의 양 끝이다.
- ⛔ **그러나 NNSI 는 다른 지표의 부호 반전이 아니다.** 근거 셋:
  1. **재는 것이 다르다** — NNSI = **한 상의 자기-분산 거리**(길이 스케일). Lacey/PSMI/GNN =
     **조성 균일성/이웃 종류 분율**(세기). **차원도 기준점도 다르다.**
  2. **Fig 15 가 실측으로 보여준다** — 같은 런에서 SI 는 **0.61 에서 평탄**, PSMI 는 **0.86 까지 상승**.
     아핀 변환 관계가 아니다 `[D]`.
  3. 이 논문이 인용하는 [19] (Kukukova, *"A new definition of mixing and segregation: **three dimensions**
     of a key process variable"*) 의 제목 자체가, 혼합·분리가 **단일 축이 아님**을 말한다.
     그 틀에서 보면 **NNSI ≈ 분리의 "스케일(scale)" 축**, **Lacey/PSMI/GNN ≈ "세기(intensity)" 축**이다 `[R]`.
- ⇒ **실무 규칙**: NNSI 와 GNN 계열을 **둘 다** 보고하는 것은 중복이 아니라 **서로 다른 두 축**이다.
  단, *"하나가 다른 하나를 검증한다"* 고 쓰면 안 된다 (frame[4] 의 교차검증이 아니다 — 애초에
  같은 양이 아니므로).

## 12. ★ 우리 3종 · 12배 크기차 침대에 쓸 수 있는가 — 판정

**판정: 원식 그대로는 ⛔ 쓸 수 없다. `l_min` 재정의 + 보고창 이동 + `l̄/d` 병기의 3개 수정 후 🔶
"부지표로 사용 가능". 주지표 교체 근거는 되지 않는다.** 근거를 넷으로 나눈다.

### 12-0. 먼저 — 우리 세 상의 분모가 얼마인가 `[R] × [우리]`
문서값 `real_14` 개수(AM_P **36** · AM_S **421** · SE **32,832**)와 크기비 **12:4:1** 을 식 (17)·(20) 에
넣으면 고체부피 분율은 **AM_P 0.510 · AM_S 0.221 · SE 0.269** 다.
★ **자기검증**: 이렇게 나온 `f_SE = 0.269` 가 문서값 *"SE/solid 25.9–27 %"* 와 맞는다 ⇒
**12:4:1 은 지름비**로 읽는 것이 맞고, 위 분율 계산이 우리 침대에 대해 자기일관적이다.

| 상 | `f_A` | `l_ud/l_min` | 분모 `(l_ud − l_min)/d_A` | `c₁` (표본) |
|---|---|---|---|---|
| AM_P | 0.510 | 1.252 | **0.252** | **36** ⚠ 표본 극소 |
| AM_S | 0.221 | 1.654 | 0.654 | 421 |
| **SE** | 0.269 | 1.549 | **0.549** | 32,832 |

⇒ SE 는 분모가 지름의 **0.55 배**뿐이다. 즉 `SI_SE` 는 *"평균 동종 최근접거리가 접촉거리보다
0.55 d 이상 멀어져야 1 이 되는"* 눈금이고, **압밀된 침대에서 그 여유는 존재하지 않는다**(§12-2).
AM_P 는 분모가 더 좁은 데다 **입자가 36개**라 `l̄` 의 표본오차가 신호를 삼킬 위험이 크다
(논문에는 표본크기 수렴시험이 없어 이 점을 문헌으로 방어할 수 없다 — §10-4).

### 12-1. ⛔ 치명상 — 우리 겹침에서 `SI` 는 **음수로 새어나간다**
원식의 하한 `l_min` = "접촉한 두 입자의 중심거리" = (겹침 0 이면) `d`. 이 논문의 DEM 은
**겹침을 반지름의 1 % 미만(= 지름의 0.5 % 미만)** 으로 묶어 그 전제를 지킨다 `[P]`.
우리는 정반대다 — **연화-E 로 겹침을 *일부러* 크게 쓴다**:

| | 겹침 예산 |
|---|---|
| 이 논문 | 지름의 **< 0.5 %** |
| 우리 (복합, E_SE 1.35, `2mAh_real_9`) | ⟨δ⟩ = **0.0739 µm** — 생산 기본 `r_SE = 0.5 µm`(⌀1.0) 기준 **지름의 ~7 %** `[우리]` |
| 우리 (pure-SE, Cronau 대조) | ⟨δ⟩ ≈ **지름의 11 %** `[우리]` |

접촉한 SE 쌍의 중심거리는 `d − δ ≈ 0.93 d` 다. 압밀된 침대에서 SE 의 최근접 동종 이웃은 거의 항상
접촉이므로 **`l̄ < d = l_min` ⇒ `SI < 0`** `[R]`. 즉 **[0,1] 경계가 우리 침대에서 깨진다.**
- **처방 A(권장)**: `l_min := ⟨접촉 SE–SE 중심거리⟩` 를 **같은 프레임에서 실측**해 넣는다.
  (우리는 이미 접촉 덤프와 `⟨δ⟩` 를 갖고 있다.)
- **처방 B(더 정직)**: SI 를 버리고 **`l̄_A / d_A` 를 그대로 보고**한다. §4-5b 대로 SI 는 그것의
  1차 재척도일 뿐이라 **정보 손실이 0** 이고, 겹침·조성 규약을 **드러내 놓고** 다룰 수 있다.
- ⛔ **처방 C(clamp)는 금지** — `SI = max(0, …)` 로 자르면 CLAUDE.md 의 *"porosity lock/clamp = 신뢰성 0
  (조작)"* 판정을 그대로 재현하는 것이다.

### 12-2. ⛔ 보고창이 어긋난다 — 압밀 후 프레임에서는 **세 상 모두 바닥**
NNSI 의 분해능은 **간극이 있는 침대**에 있다. 이 논문 자신의 데이터가 그 대비를 보여준다 `[D]`:
밀집 중력침강 Couette = **0.003–0.17**, 교반으로 들뜬 날개믹서 = **0.61–1.0**.
우리 사전등록 보고창은 **300 MPa 압밀 후 최종 정착 프레임**이다 — 거기서는 모든 상이 접촉망에
갇혀 `l̄ ≈ 접촉거리` ⇒ **세 상의 SI 가 모두 바닥(또는 음수)** 이다.
⇒ **NNSI 를 쓰려면 창을 "침강 종료 · 압밀 전" 으로 옮겨야 한다.** 그 창은 사전등록의 판정창이
**아니므로**, NNSI 결과는 **서술(descriptive)** 로만 쓸 수 있다 (판정선 이동 = 사전등록 무효).

### 12-3. ⚠ 크기비 12:1 은 문헌이 시험한 범위 밖 + percolation 한계의 반대편
§11-6 대로 SI 는 크기비에 **23배·비단조**로 반응했고(0.5 에서 0.003), 저자는 **모든 케이스를
percolation 한계 0.1547 위**로 잡아 침투분리를 애초에 배제했다. 우리 SE/AM_P = **0.083** 은 그 아래다.
⇒ **크기비 축에서 우리는 외삽이고, 그 축이 바로 이 지표가 가장 크게 흔들린 축이다.**

### 12-4. 🔶 그래도 살아남는 쓸모 (세 가지)
1. **같은 조성·같은 압력의 팔 비교**(= `m7` 설계)에서는 분모가 상수라 **`SI_A` 순위 = `l̄_A/d_A` 순위**.
   조성 교락이 없다 ⇒ **팔 간 상대비교는 원리적으로 성립**한다(12-1·12-2 를 고친 뒤).
2. **접촉이 세지 못하는 구조를 본다**: "닿진 않았는데 뭉쳐 있다"(2번째 껍질 수준의 응집)는
   `E_XY`(접촉 기반)가 **원리적으로 못 보는** 반면 거리 기반 지표는 본다. **침강 직후 loose 침대**가
   바로 그 상태다 ⇒ `E_XY` 와 **상보적**이다.
3. **값싸다**: atom dump 만 있으면 된다. 타입별 KD-tree 최근접질의 = `O(N log N)`, 우리 최대 규모
   (SE ~3.3만, `real_14`) 에서 **초 단위**. GPU 불요, 재실행 불요.

### 12-5. ⛔ 쓰면 안 되는 곳 (명시)
- **조성이 다른 케이스 사이의 `SI` 절대비교** (분모 `f_A^(−1/3)` 가 다름 + 제3상이 `l_ud` 로 끼어듦).
- **크기비가 다른 침대 사이의 비교** (Fig 12: 23배 비단조).
- **porosity 가 다른 프레임 사이의 비교** (팽창 채널이 `l̄` 에 직접 들어감 — §4-5e).
- **"무작위 대비 응집" 주장** (SI 에 무작위 기준이 없음 — §4-5d). 그 주장은 **`E_XY` 로만** 한다.

2. **크기비 시험 범위가 우리 근처에도 못 온다** — 06 은 0.5 까지, 05 는 1.33 까지. 우리는 **1/12 = 0.083**.
3. **압밀 공정이 없다** — 둘 다 혼합/교반 계다. 우리 침대는 300 MPa 에서 접촉망에 갇힌 상태다.
⇒ **어느 쪽도 "문헌이 검증했다"로 방어할 수 없다.** 유일한 근거는 **우리 침대 실측**이고,
05 는 이미 쟀고(0.0239) **06 은 아직 안 쟀다** — §13-4 가 그 다음 단계다.

### 13-3. 권고 — **주지표를 바꾸지 않는다**
1. ★★ **주지표는 사전등록대로 `E_SE-SE`.** 이유는 지표 우열 이전에 **규율**이다 —
   `prereg_m7_aggregation_20260919.md` 가 **런 전에** 주지표·판정선·보고창을 봉인했다. 문헌 카드를
   읽고 주지표를 갈아끼우면 그 순간 **사전등록이 아니다**(`CL-19`/`CL-71` 계열 실패와 같은 부류).
   교체가 필요하면 **다음 런의 새 사전등록**으로 한다.
2. **지표 자체로 따져도 `E_XY` 가 셋 중 우리 조건에 가장 맞다**: 무작위 null 을 갖고, 압밀 후
   프레임에서도 살아 있고(접촉이 많을수록 통계가 좋아진다), 겹침·팽창에 둔감하며, **05 카드의
   항등식에 따르면 GNN 을 포함한다**. 06 은 이 셋 전부에서 불리하다(§12).
3. **둘 중 하나를 골라야 한다면 — 우리 질문에 더 가까운 쪽은 05(GNN) 다.** 우리가 묻는 것은
   *"무작위보다 더 뭉쳤나"* 이고 **그 기준점을 가진 쪽은 05 뿐**이다(06 에는 아예 없다 — §4-5d).
   ⚠ 단 **05 의 스칼라 그 자체도 우리 침대에서 불가 판정**(42배 과소 · `n_nb` 로 12배 이동)이므로,
   **"05 를 쓴다"가 아니라 "05 의 정규화 원리 = 우리 `E_XY`" 라는 뜻**이다.
4. **06 의 고유 가치는 *다른 축*에 있다** — 접촉이 못 보는 *"닿진 않았는데 뭉쳐 있다"* 를 보는
   **유일한 후보**이고, 그 축은 **압밀 전 loose 프레임**에서 산다. ⇒ 역할 배치:

   | 순위 | 지표 | 프레임 | 지위 |
   |---|---|---|---|
   | **주** | `E_XY` (접촉 enrichment) | 압밀 후 최종 정착 | **판정** (사전등록 §4·§5) |
   | **부1** | GNN 형 **입자별 커널** (= 우리 `CLMI`, 이미 CN 보유) | 같은 프레임 | 서술 + **공간 지도** |
   | **부2** | NNSI → `l̄_A/d_A` (`l_min` 재정의) | **침강 종료(압밀 전)** | 서술 전용, porosity 병기 |
5. ⛔ **하지 말 것**: 06 과 05 의 일치를 *"두 지표가 서로를 검증했다"* 고 쓰는 것.
   Fig 15 가 보여주듯 두 계열은 **초기엔 같이 움직이다 갈라진다** — 일치는 우연한 공행이고
   불일치는 결함이 아니다(**다른 양**이므로). 그리고 `E_XY`↔`CLMI` 도 **같은 접촉 목록**에서
   유도되므로 **독립 측정이 아니다** — 그 둘의 일치는 **구현 버그 검사**이지 교차검증이 아니다.

## 14. 부록 A — 논문 §2 가 정리한 비교군 지표 (원식)

| 지표 | 식 | 성질 (논문의 평가) |
|---|---|---|
| **Lacey `M_L`** [3,4] | `M_L = (σ₀² − σ²)/(σ₀² − σ_r²)` (1) | 가장 유명. ⛔ 분산이 **표본크기에 의존** · polynary 계에서 오도(William [26]). 단, **직접 모집단 평균**으로 계산하면 오차 없음 [23]. |
| **GMMI** [22] | `GMMI_A = (GMMI_x + GMMI_y + GMMI_z)/3`, `GMMI_x,A = [Σ_p (x_p − x_ref)/n] / [Σ_q (x_q − x_ref)/N]` (2–5) | **방향성** 지표, 1 = 완전혼합. ⛔ `>1` 과 `<1` 이 **상쇄**되어 가짜 1 을 만든다. 임의 기준점 `x_ref` 필요. |
| **MGMMI** [32] | `MGMMI_A = 1 − (|1−GMMI_x| + |1−GMMI_y| + |1−GMMI_z|)/3` (6) | 상쇄 문제를 절댓값으로 봉합. ⛔ 여전히 **과도·비정상 공정에 곤란**. |
| **최근접이웃법** [28,29] | `M = (1/N)Σ 2n_diff/n_nb` (7) | Godlieb: 이웃 **12개** 고정. Wen [20]: `n_nb` = **배위수**(두 반지름 합의 10 % 이내를 접촉으로). ⛔ *"입자 타입 수에 제약"*. ★ **05번 GNN 의 직계 모체**. |
| **이웃거리법** [20,30] | `M = Σ(x_ij − d̄) / Σ(x_ik − d̄)` (8) | 최근접 쌍 거리 `x_ij` 를 **무작위 쌍 `x_ik`** 로 정규화. ⛔ 정상상태·고정 치수계에 한정, **과도계엔 부적합**. ★ **NNSI 의 직계 조상.** |
| **PSMI** [23] | `PSMI = (S_o² − S_t²)/(S_0² − S_r²)`, `p_i = C_n,B(W)/(C_n,i + 1)` 또는 `(C_n,B(B) + 1)/(C_n,i + 1)`, `S_t² = (1/N)Σ(p_i − p̄_t)²`, `S_r² = p(1−p)/n`, `S_o² = σ_o²` (9–15) | Lacey 형인데 분산을 **배위수 모집단**에서 뽑는다 ⇒ 표본크기 의존 제거. **기하구조에 연결되지만 입자스케일 분산(dispersion)에서는 멀어진다**(저자 평가). |

저자가 NNSI 를 이 계보에서 **이웃거리법(식 8) + 최근접이웃법(식 7) 의 후계**로 자리매김하며,
근거로 *"Wen et al. [20] 이 다른 입자스케일 방법들보다 이웃거리법을 강하게 추천했다"* 를 든다 `[P]`.
★ 즉 **05(GNN) 와 06(NNSI) 은 같은 리뷰 [20] 에서 갈라져 나온 형제**다 — 05 는 식 (7) 계열을,
06 은 식 (8) 계열을 각각 일반화했다.

## 15. 부록 B — 결과 서사 (절별 전수)

**§4.1.1 균일입자 혼합·분리 (Case I–VI)**
- 두 혼합기전: **대류(convective)** = 입자의 집단 운동, **확산(diffusive)** = 무작위 분산 운동 [4,49].

- SI 는 모든 케이스에서 **시간에 따라 완만히 증가 → 정상상태**. **교반기가 벌크 혼합에 미치는
  영향은 거의 없다** — 스냅샷(Fig 8·9)에서 배출구 부근은 개선돼 보이지만 **클러스터가 남는다**.

- 공간: L·M·R 은 사실상 동일(반경방향 균일), **E(배출구)만 높다** → funnel flow 배출이
  **재혼합(remixing)** 을 만든다 [50].

**§4.1.2 2성분(크기 다름) 계 (Case VII–X)**
- 수량비: VII(0.013) 이 VIII·IX 보다 **뚜렷이 높다**. 저자 해석: *"소수상 개수가 적으면 클러스터
  없이 **홀로 서 있는(stand-alone)** 작은 입자가 되어 SI 가 높게 계산된다"*.
  ⇒ ★ 저자 스스로 **"SI 가 높다 = 잘 섞였다"가 아니라 "소수상이라 그렇다"** 는 것을 인정하는 대목이다
  (§4-5c 의 분모 효과와 같은 이야기). ⚠ 그런데 **VIII 과 IX 는 10배 차이인데 값이 같다**(§10-4).
- 침투분리 배제: 크기비 > **0.1547** 이라 percolation 분리는 없다 [51] ⇒ 관측된 혼합은

- 크기비: Fig 12 에서 셋이 **0.044 / 0.070 / 0.003** — §11-6.

**§4.2 날개믹서 (Case XI–XII)**
- 두 케이스 모두 **RPM ↑ → 정상상태 SI ↑** (에너지 투입 의존).

  없기 때문"* 으로 설명한다. ⚠ **그 해석은 PSMI 가 계속 오르는 사실과 정면으로 충돌한다** —

**§5 결론 (저자)** `[P]`

## 16. 기술 미니 용어집

- **NNSI / SI (near-neighbour separation index)** — 이 논문의 지표. 동종 최근접거리를 접촉–균일분산
  사이에서 0–1 로 정규화. **이름과 달리 값이 클수록 잘 섞인 것.**
- **`l_ud` (uniform distribution distance)** — "그 상이 완전균일하게 퍼졌다면 가졌을 중심간 거리".
  `[R]` 실제로는 `(Σc_i d_i³/c₁)^(1/3)` = **그 상의 고체부피 분율만의 함수**.
- **solid packing factor `φ`** — 고체 충전율(= 1 − porosity). 식 (18)·(20) 에 나오지만 **서로 소거**된다(§4-5a).
- **Lacey index** — 분산(variance) 기반 고전 혼합지수. 완전분리 `σ₀²` 와 완전무작위 `σ_r²` 사이에서 정규화.
  **표본크기 의존**이 고질병.
- **GMMI / MGMMI** — 평균 위치 기반 방향성 혼합지수. `x_ref` 필요, 과도계에 부적합.
- **PSMI (particle-scale mixing index)** — Lacey 형인데 분산을 **배위수 모집단**에서 뽑아 표본크기
  의존을 없앤 것. 이 논문의 유일한 외부 대조군.
- **GNN mixing index** — 05번 논문의 지표. 이웃 중 타상 비율을 **조성이 정하는 무작위 기대**로 나눈
  것(`n_nb = 7` 고정). ★ **무작위 null 을 갖는다**는 점이 NNSI 와의 결정적 차이 `[05카드]`.
- **spot sampling / grid dependence** — 구역을 잘라 표본을 뽑는 데서 생기는 의존성. Akao [24,25] 가
  *"spot-sample 로 예측할 때만"* 오차가 난다고 정리.
- **convective / diffusive mixing** — 집단 운동에 의한 혼합 / 무작위 운동에 의한 혼합.
- **funnel flow** — 호퍼 중앙만 흐르고 벽 쪽은 정체하는 배출 패턴. 여기선 배출구 **재혼합**을 만든다.
- **percolation limit 0.1547** — 접촉한 동일구 3개가 만드는 삼각 간극을 작은 구가 통과할 수 있는
  임계 크기비(= 2/√3 − 1). 이보다 **작으면** 미세입자가 자발적으로 체질되어 내려간다(침투분리).
  ★ 우리 SE/AM_P = 0.083 은 **그 아래**.
- **CDT rolling friction** — 상수 방향 토크형 구름저항 모델 [43]. 구로 비구형성을 흉내 내는 표준 수법.
- **damped exponential fit `SI_fit = C_L − A e^(−λt)`** — 잡음 많은 지표 시계열을 정상상태값 `C_L` 로
  요약하는 관행. ⚠ **보고된 곡선은 전부 이 피팅이고 계수는 미보고.**

## 17. 구현 메모 (우리 파이프라인에 붙인다면)

⚠ **아직 구현하지 않았다.** 아래는 사양 초안이며, 붙이기 전에 §12 의 수정이 선행되어야 한다.

```
입력 : atom dump 1 프레임  (id, type, x, y, z, radius)
      + (수정 A 용) 같은 프레임 contact dump 또는 문서값 ⟨δ⟩
출력 : 상 A 마다  l̄_A , l̄_A/d_A , f_A , SI_A(수정판) , n_A

for A in {AM_P, AM_S, SE}:
    P      = positions[type == A]                      # (c1, 3)
    if len(P) < 2:  report "n/a (c1<2)"  and continue   # ⛔ 논문의 c1=1→0 규약은 쓰지 않는다
    l̄      = mean( KDTree(P).query(P, k=2)[0][:,1] )    # 자기 자신 제외 최근접
    f_A    = Σ_A c d³ / Σ_all c d³                      # 고체부피 분율
    l_ud   = d_A * f_A**(-1/3)                          # = (Σ c_i d_i³/c1)^(1/3)   [R] 항등식
    l_min  = mean_contact_centre_distance(A)            # ★ 수정 A: (1 − δ̄/d)·d  (원식의 d 가 아님)
    SI_A   = (l̄ − l_min)/(l_ud − l_min)
```

- **주기경계**: 우리 침대는 측방 주기경계를 쓸 수 있다 ⇒ KD-tree 에 **minimum-image** 를 넣지 않으면
  경계 근처 입자의 `l̄` 가 과대평가된다. (논문은 Couette y축 주기경계를 쓰면서 이 처리를 언급하지 않는다.)
- **구역 분해**(z-띠)를 할 경우 **띠당 최소 입자수 가드**를 둘 것(§4-3 코너 회피). 미달 띠는
  **`n/a` 로 비우고 0 으로 채우지 않는다**.
- **반드시 같이 보고할 것**: `porosity`(팽창 교락) · `⟨δ⟩`(겹침 규약) · `f_A`(분모) · `n_A`(표본).
  이 넷 없이 `SI` 숫자만 적으면 **감사 불가능한 수가 하나 더 늘 뿐**이다(§10-3 과 같은 실패).
- 비용: `real_14` 규모(AM_P 36 · AM_S 421 · SE 32,832 `[우리]`)에서 **초 단위**, GPU 불요.
