## RV2A N1 수치 허용 증인을 정확한 집합 증인과 구분

**P1, 문서 판정 의미의 잔여.** 부속 A §2-2, 123~132행; §7, 414~417행.

`1e-10`이라는 사전 선택 자체를 거부하지 않는다. 다만 “작아서 어떤 상태도 바꿀 수 없다”는 근거는 성립하지 않는다. 경계의 판정은 이산적이므로 작은 양의 위반도 정확한 집합의 안/밖을 바꾼다. 부동소수 좌표를 정확한 유리수로 바꾸는 것은 그 위반을 정확히 측정할 뿐 없애지 않는다.

자료와 무관한 반례는 다음과 같다. 실제 REIL 목적값이 이 점에서 문턱을 만족한다는 주장은 하지 않는다.

| 제약만 보는 예 | 정확 제약 | 부속 A의 수치 수용 |
| --- | --- | --- |
| d_P=0.1, d_N=0.09990000005 | G의 위반 약 5.00000013e-11, 따라서 G 밖 | 1e-10 이내이므로 수용 |
| 명목 m_P=1, τ=0.02, 반환 m_P=1.02000000005 | 명목 상자 위반 약 5.00000219e-11 | 1e-10 이내이므로 수용 |

유한하고 목적 문턱을 통과하는 점이라는 조건까지 붙으면, 이런 점만 찾았을 때 정확한 A 또는 명목 τ 상자의 증인이라고 무조건 부를 수 없다. 현재 경계 근접 라벨은 목적 `J−T`에만 붙어 있어 선형 제약의 작은 위반을 표시하지 못한다. 실제 데이터에서 오류가 발생했다는 진단은 아니지만, 확인적 문서의 보증은 잘못됐다.

**최소 정정:**

1. “어떤 상태도 바꿀 수 없다”, “목적 반올림은 ~1e-15이므로 충분하다”를 보증으로 사용하지 않는다. 수치는 사전 선택한 계산 수용 규칙이며 목적별 실제 오차 상계는 미확인이라고 쓴다.
2. 원 좌표와 제약별 정확 잔차를 남기고, 위반 0 이하인 `exact_feasible`과 0 초과~허용치 이하인 `numerically_accepted`를 구분한다. 기존 witness 필드를 유지해도 별도 flag로 충분하다. 반환점을 clip/투영할 필요는 없다.
3. 허용치에 의존하는 점만으로 양립/폭을 주장할 때는 `수치 경계 의존`으로 한정하고, 정확 집합의 무조건 COMPATIBLE/WIDE로 승격하지 않는다. 정확한 다른 증인이 없다면 해당 주장에는 UNRESOLVED를 병기하는 안을 권고한다. 프로파일 t와 실제 h(x)가 어긋나는 경우에도 같은 원칙을 적용한다.
4. P0의 정확한 PRIOR_INCOMPATIBLE을 수치 허용 증인으로 뒤집지 않는다. 목적 문턱 경계 라벨과 선형 제약 경계 라벨을 서로 대체하지 않는다.

새 solver나 더 엄격한 허용치, 실측 경계 시험을 지금 요구하는 것은 아니다. 기존 수치 규칙의 의미와 보고 라벨만 닫으면 된다. [부속 A 해당 문장](https://github.com/yonghoon7153-source/Yonghoon-DEM-DFT/blob/a82d7135ea5f91f4d9596e1dd370df4365c6fef0/bms-balancing/docs/REIL_EXTERNAL_VALIDATION_PROTOCOL_v2_ANNEX_A.md#L119-L135)

## RV2A N2 적응적 시작점의 봉인 시점과 부족 처리

**P2, 결정적 탐색 계약의 잔여.** 부속 A §3-1, 199~201행; §3-3~3-4, 217~234행.

Phase A 최적점과 이미 끝난 이웃 격자점의 반환값을 쓰는 s1/s2는 맞춤 전에는 존재하지 않는다. 따라서 “모든 시작점 배열을 맞춤 전에 만들어 봉인”과 실제 제안한 적응적 순회는 동시에 이행할 수 없다. 시작점을 쓰지 말라는 뜻이 아니라 **고정 규칙과 사전 생성 가능한 배열, 실행 결과로 정해지는 배열의 시점**을 나눠야 한다.

또 Phase A 유효 증인이 1~3개만 있어도 §2-3에서는 UNFIT이 아니다. 이때 §3-4의 “상위 4 + Sobol 12 = 16”은 완성되지 않는다. 프로파일에는 시작 부족 규칙이 있지만 동시 양립에는 없다. 한 점을 복제할지, Sobol을 더 뽑을지, 적은 수로 돌릴지가 결과 후 선택으로 남는다.

**최소 정정:**

- 맞춤 전: 순회·동률·대체·중복·부족 규칙과 label 문자열 형식, Phase A 및 독립 Sobol 배열을 봉인한다.
- 적응적 시작점: 앞선 결과가 생긴 뒤 **해당 지역 실행 시작 전** 실제 배열을 봉인한다. 근거 Phase A/이웃 run ID·반환 증인 식별·변환·clip 여부를 연결한다. 이미 끝난 실행의 시작점을 소급 교체하지 않는다.
- `정확히 4/16`은 명목 최대 수와 실제 수를 구분한다. 기존 프로파일의 부족 원칙을 동시 양립에도 적용하는 최소안은 **가용 상위 min(4,n_valid) + 고정 Sobol 12**, 중복/부족 사유 기록, 숨은 추가 시작이나 재배분 없음이다. Phase A 두 번째 증인이 없는 s2도 같은 부족 규칙으로 명시한다.

이렇게 해도 54,901회 상한은 증가하지 않는다. 탐색법을 바꾸거나 구현을 시작할 필요는 없다. [부속 A 시작점 규칙](https://github.com/yonghoon7153-source/Yonghoon-DEM-DFT/blob/a82d7135ea5f91f4d9596e1dd370df4365c6fef0/bms-balancing/docs/REIL_EXTERNAL_VALIDATION_PROTOCOL_v2_ANNEX_A.md#L199-L246)

## RV2A N3 격자점 교차는 좌표 계산값 대신 격자 index로 합치기

**P2, H4 교차 유효성 규칙의 잔여.** 부속 A §4-2, 298~301행.

교차가 격자점에 정확히 있어도 인접 구간의 보간식을 각각 계산하면 마지막 비트가 다를 수 있다. 따라서 “같은 float Q만 하나로 합친다”로는 같은 물리 교차가 두 개로 남아 H4 비유한 판정을 받을 수 있다.

문서 식만 계산한 예: 1000점 균일 격자 [0,0.1]의 앞 세 좌표와 V=(1.1,2.0,2.5), cutoff=2.0을 놓는다. 왼쪽 보간은 `0.00010010010010010012`, 오른쪽은 `0.0001001001001001001`이다. 둘은 같은 가운데 격자점의 교차지만 float equality는 false다. 실제 반쪽전지 곡선이나 H4 코드를 실행한 결과가 아니다.

**최소 정정:** 양 끝 전압이 모두 cutoff인 평탄 구간을 먼저 거부한다. `V_j == c`이면 식을 다시 계산하지 말고 정확히 해당 `Q_j`와 격자 index를 교차의 정체성으로 쓴다. 양 끝 어느 쪽도 cutoff가 아닌 엄격한 부호 변화 구간만 보간한다. 동일 격자 index의 접촉을 한 번 세면 된다. 임의의 새 Q 허용오차나 더 촘촘한 격자는 필요하지 않다. [부속 A 교차 규칙](https://github.com/yonghoon7153-source/Yonghoon-DEM-DFT/blob/a82d7135ea5f91f4d9596e1dd370df4365c6fef0/bms-balancing/docs/REIL_EXTERNAL_VALIDATION_PROTOCOL_v2_ANNEX_A.md#L294-L303)

## 선택 사항과 Q1부터 Q6까지의 답

### Q1 네 항목의 닫힘

RV2-N1은 수용·종결이다. N2/N3/N4는 위 세 국소 정정만 남긴다. 이미 수용한 목적함수·영역·실용 탐색·E3a/E3b의 역할을 다시 열지 않는다. 정정된 부속 문서와 세 행의 대응표면 다음 제출물로 충분하다.

### Q2 공통 갱신과 독립 풀

한 번의 최종 갱신은 사전 등록된 선택으로 수용한다. 분모가 양수인 범위에서 최종 Ĵ가 내려가면 단일 목적 문턱은 내려가고 ρ는 올라간다. **같은 최종 저장 점 집합**에 옛 문턱과 새 문턱을 적용해 비교한다면 충족 집합은 커지지 않는다. 탐색 중 새 점을 추가하면서 보는 상태까지 단조라는 뜻은 아니다. 최소가 0이 된 상대 판정은 정의한 UNFIT 분기를 따른다.

독립 풀은 방법별로 정한 발견 최소다. 결합이 더 낮은 단일 목적값을 발견했다면 그 사실을 별도 보고한다는 조건으로 수용한다. 이를 “모든 관측점의 최소”나 전역 최소라고 부르지 않는다. 문턱 유지보다 보편적으로 낫다는 결론도 없다. 이 선택은 초기의 높은 기준값으로 문턱이 느슨해지는 것을 줄이지만, 결합 탐색은 여전히 잠정 분모에 최적화되어 있어 최종 분모에서의 탐색 충분성을 보장하지 않는다.

최종 ρ로 판독할 때는 저장된 모든 유효 반환점의 `(J_V,J_D)`를 다시 비교해야 한다. 잠정 ρ에서 가장 낮았던 점 하나만 보존하거나 ρ 값만 저장하면 순위 변화에 대응할 수 없다. 현재 §1-1의 전체 기록점·저장값 재판독 규칙을 이 뜻으로 수용하며 새 탐색은 요구하지 않는다. H4도 ray 생성 전 기준 증인의 식별을 보존하고, 최종 최소가 바뀌었다는 이유로 ray를 다시 생성하지 않는 순서를 유지한다.

### Q3 수치 규칙과 정확 P0

독립 재평가, budget 종료 증인 허용, 무효 결과 제외, 정확한 구간식은 수용한다. `Fraction(float)`는 저장된 이진 float 값을 정확히 나타내며, 원 물리량이나 십진 명목값의 무오차를 증명하는 것은 아니다. 명목값은 십진 문자열로, max_q는 정해진 계산 경로의 float 값 그대로 결속하는 구분은 적절하다. [Python Fraction 문서](https://docs.python.org/3/library/fractions.html)

P0의 필요충분 구간식과 D의 세 영역은 맞는다. 1/400, 50/13, 25/3, 25/8 및 하한 분수도 상수 산술로 대조했다. 실제 max_q·P0 상태는 계산하지 않았다. 선형 수용 허용오차는 RV2A-N1을 반영해야 하며, 작은 값이라는 이유로 실제 상태 불변이나 목적 오차 상계를 단정하지 않는다.

### Q4 결정적 탐색과 옵션 및 예산

나열한 COBYQA 옵션 이름·의미는 조회한 공식 문서와 맞는다. scale=True는 유한 bounds에서 [-1,1] 스케일링을 뜻한다. feasibility_tol을 증인 허용치보다 작게 두는 것은 의도한 선택으로 수용하되 실제 반환 유효성 보증은 아니므로 독립 판정을 유지한다. final_tr_radius=1e-6도 목표 함수 오차나 전역 해의 정확도 인증이 아니다. 설치 버전 고정과 전달된 실제 옵션 확인은 C6에 남긴다. [SciPy COBYQA 문서](https://docs.scipy.org/doc/scipy/reference/optimize.minimize-cobyqa.html)

seed/배열 봉인 방향, 한 번의 중심 밖 순회, 충족/미해결 격자점 보고는 적합하다. 다만 RV2A-N2가 필요하다. Sobol 16개에서 앞 12개를 쓰는 것은 결정적 시작점 선택으로 가능하지만 그 12개에 2의 거듭제곱 Sobol의 균형 성질을 주장하지 않는다. 문서의 seed/rng 버전 경계 확인은 유지한다. [SciPy Sobol 문서](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.qmc.Sobol.html)

713×77=54,901 지역 실행, 54,901×2,000+77×201=109,817,477 목적 호출, E3a optimizer 275는 일치한다. 이는 명시한 별도 항목을 제외한 명목 상한이지 전체 모든 평가 비용이나 예상 시간은 아니다. 독립 재평가·H4 대조/ray·E3a·기록·벽시계는 별도 비용으로 유지한다. 비용 측정은 피팅이며 파일럿 제외·별도 승인·변경 가능 항목 제한을 둔 것은 적절하다.

### Q5 H4 대조와 반증 철회

ν=0.01 V를 근거 있는 실험 오차 상계가 아닌 **사전 선택한 운영 수용 폭**으로 쓰는 것은 수용한다. P0 관측 후 값을 넓히지 않는다. “이완 구간을 거른다”도 이 폭 밖인 경우의 규칙일 뿐 모든 이완 상태를 판별한다는 보증은 아니다.

R1~R3의 상자/G 조건과 c=0.9/1.1 결합, 대칭 기준 1e-9, 모델 곡선 음성 대조 기준 1e-6은 사전 선택된 구현 대조로 수용한다. 실제 곡선에 이 대조가 통과하는 후보가 있는지는 미확인이다. “비평탄이면 언제나 D_abs>1e-6”은 보장되지 않으므로 실패를 자동으로 실측 가설 반증이나 특정 구현 결함으로 단정하지 않는 현재 점검 경계를 유지한다.

ray를 조건부 모델 대칭으로 좁히고 관측 점만 보고하며 과학적 반증 문구를 철회한 부분은 수용한다. 목적 경계 여유를 구분한 것도 맞다. 남는 것은 RV2A-N3의 정확 격자점 교차 처리다. 격자 근사 자체의 정확도 시험을 새로 요구하지 않는다.

### Q6 확인적 문서 조건의 종결

**현재는 아직 아니며 세 문서 정정 뒤 종결 검토가 가능하다.** 남은 사항은 각각 수치 증인의 주장 범위, 적응적 시작점의 봉인 시점/부족 규칙, 교차 중복의 정체성이다. 새 실험이나 대형 코드 라운드가 아니라 해당 문장·표의 제한 수정이다.

수정 뒤 문서 조건이 닫혀도 C1-core, 실행 환경/판 고정, 별도 승인한 P0와 비용 측정, 실제 실행 승인은 그대로다. 논문이나 동등 명세가 확보됐다고 추정하지 않고, C1-E3b 미충족을 E3a/H의 새 차단으로 넓히지도 않는다. 2σ̂는 경험 폭, 명목 허용오차는 참값 측정 불확실성과 별개라는 기존 한계를 유지한다.
