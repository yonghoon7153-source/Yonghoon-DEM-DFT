COHP 곡선 — bonding / antibonding −pCOHP > 0 = 결합성, < 0 = 반결합성

{% if cohp_curves %}
ICOHP 는 이 곡선을 EF 까지 적분한 값이에요 — 표는 "얼마나 센가"만, 곡선은 어느 에너지에서 결합/반결합인가를 보여줘요. {% if cohp_curves.legacy %}
구형 CSV 이 계의 곡선은 예전 규약이라 매칭된 결합의 합(sum)이에요. 결합 수 N 이 다른 패널끼리 높이를 비교하면 안 되고 (합이라 N 에 비례), 곡선 적분도 ICOHP 표시값과 일치하지 않아요. tools/figures/extract_cohp_curves.py 로 다시 뽑으면 결합당 평균이 됩니다. {% else %} 곡선은 결합당 평균으로 정규화해서, 패널 높이가 곧 결합 하나의 세기예요 (N 이 1인 P–O 와 100 넘는 Li–S 를 같은 눈금에서 비교할 수 있게 — ∫(−pCOHP)dE|EF = −ICOHP/bond 로 상자와 자기일관). {% endif %}
x 눈금은 패널마다 달라요 — P 계(−6~−8 eV)와 Li 계(−1~−2 eV)를 한 눈금에 두면 Li 패널이 뭉개져서요. 높이 비교는 눈금이 같은 패널끼리만 하세요. {% set lowcov = cohp_curves.pairs.values()|selectattr('window_coverage','defined') |rejectattr('window_coverage','ge',0.95)|list %} {% if lowcov %}

ELF 결합 프로파일 — 결합 경로를 따라간 전자 국재화

ICOHP 가 "얼마나 센가", Bader 가 "전하가 어디로 갔나"라면 ELF 는 결합 사이에 전자가 모여 있나(공유) 비어 있나(이온)를 말해요. 판정은 결합 경로의 가운데 구간 [{{ elf_curves.window[0] }}, {{ elf_curves.window[1] }}] 최솟값으로 하고 (> {{ elf_curves.cov }} 공유 · < {{ elf_curves.ion }} 이온), 노란 띠가 그 구간이에요.
⚠ 곡선 전체의 최솟값으로 읽으면 안 돼요. Li 결합은 frac 0.65 근처에서 ELF 가 0.03~0.08 까지 떨어지는데, 이건 결합이 아니라 Li 의 1s|2s 코어 노드예요 (쓰는 유사퍼텐셜에서 Li 1s 가 가전자라 Li 핵에서 ELF→1). 원자 성질이라 그 골로 줄을 세우면 순서가 뒤집혀요.
