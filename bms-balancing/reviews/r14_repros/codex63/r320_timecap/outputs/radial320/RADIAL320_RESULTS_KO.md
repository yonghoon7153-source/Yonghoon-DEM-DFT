# 300/320H0250 단일 5초 계산 결과

**새 Caps300R320H0250 계산 1회만 완료했다. 판정은 이번 비교 표본의 160→320 세분 민감도 기준 충족이다. 참값 오차·320의 시간 정확도·전체 수렴·장시간 운전 GO로 확대하지 않는다. 전체 수렴 미완과 장시간 운전 보류를 유지한다.**

## 실제 메시·solver·accepted step

native 요소 수300/320/320과 영역별120/60/120을 확인했다. CDI 자유도1202(+내부12)는 같고 transient 자유도는160의40765(+내부12)에서320의79485(+내부12)로 늘었다. ParticleIntercalation의 Nel320·Nord1·CubicRoot도 확인했다.

Time/Variables의 실제 속성1143개를 되읽어 기준과 모두 동일함을 확인했다. 시간상한은 maxstepconstraintbdf=expr, maxstepexpressionbdf=if(t<0.1[s],0.00025[s],0.1[s])다. 실제 Time rtol1e-6, 초기 step1e-5초(active=on), BDF·strict·tout=tsteps·tstepsstore=1·consistent=bweuler, scaled/factor 절대허용오차 factor=.1, 변수 scale(전해질농도1000·고체농도각10000·전위각1)을 유지했다. Study rtol1e-5와 실제 Time rtol1e-6을 구분하며 expr 모드의 maxstepbdf=.1과 manual용 atolglobal=.001은 비활성 슬롯이다. ## 보호·보존·확인 수준

OCP 표·초기 조성·Li 재고를 바꾸거나3.0524 V에 맞추지 않았다. OCP 외삽 금지와 기존 OCP입력·고체 표면 조성 StopCondition을 유지한다. 전해질 양수는 **후처리 검사**이며 실시간 음수 중단은 미구현이다. 저장값의 guard·표면범위·실제 Eeq/반응입력·Li 수지·전해질 양수 후처리 검사는 results/analysis.json에 별도로 기록했다. 보존량 일치나 solver 완료를 수렴 PASS로 대신하지 않았다.

기존 failed·INCOMPLETE_RANGE_STOP·부분 결과를 보존했고 다른 실패를 같은 분류로 자동 처리하지 않았다. 변경 전 현지867개 현재 바이트를 별도로 기록했으며 NEXT_RUN_PLAN 변경 전 원문도 보존했다. 이전 R160_TIMECAP ZIP의 생성본과 사용자 확인 수신본은307305998 bytes·SHA481ce9ebb1455de18ffcc35554d34b8a5fceb5c8cea3018938a200fadd920bdc로 일치한다. 사용자가 확인한267payload·manifest·CRC 검증은 현지 현재867개 전체의 외부 검증과 구분한다. 기존 원본 영수증은 변경하지 않고 새 확인 사실은 [출처·확인 수준](PROVENANCE_LEVELS.json)에 기록한다. 이전 TIME_CAPS 두 rawZIP 차이 원인은 여전히 미확인이다.
