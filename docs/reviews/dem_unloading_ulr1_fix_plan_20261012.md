## 1. 등록 개정 2 문안 (finding 별 · 판정문 최소 문안 그대로 · REG = `docs/reviews/dem_unloading_ps45_prereg_20261009.md`)

- **ULR1-01 → §12-4 ④ 끝점 유효성 전이** (새 줄): δ_dt · δ_v 는 해당 두 팔의 주 측정 상태가 유효하고 ρ 가 유한할 때만 계산 · 필요한 끝점이 무효 · 결손 · 무교차 (UNSTEADY · NOISE_FLOOR · TECH · NaN 포함) 면 `SELECTION_UNRESOLVED` — 최종 튜플 발행 안 함 · 다음 팔 제출 안 함 · 나머지 네 침대 U 도 돌리지 않음 (그 침대들의 "본 설정" = 최종 튜플).  기술 재시도 = 이미 등록된 범위만 (§5-2 restart 재개 한 번 · 잡 실패 두 번 → EXECUTION_FAILED) · 다른 설정 · 추가 팔 · 결측 대체 = 새 승인 · 등록.  `NO_BRACKET` (중력 팔 전용) 이름은 개발 팔에 쓰지 않는다.  ③ 의 "동시 실패 포함 · 팔 셋으로 끝난다" → "유효한 δ 두 개면 팔 셋으로 끝난다" (`SELF-105`).
- **ULR1-02 → §5-2 "최대 실행" · §7-1 TIMEOUT 행 대체**: 상태 두 축 — `primary_status` (주 측정) ↔ `trajectory_status` (분리 · 표면 · 중력 분기 · 종료).  ① 첫 교차 · 등록 확인 두 단까지 정상 완료 뒤 분리만 TIMEOUT = 유효 ρ + 실제 괄호 보존 · trajectory = 분리 / 표면 미완료 ② 교차 전 TIMEOUT + 마지막 정상 단까지 정상 · 유접촉 · 단조 = 그 전제에 한정한 하한 (ρ > ρ(마지막 정상 단)) ③ 교차 끝점 무효 · 결손 · 비단조로 ② 전제 불충족 = 하한 자동 발행 안 함 (미식별 사유).  끝내지 못한 보조 관측을 완료라 부르지 않는다 · §5-2 의 S1 · S2 · S4 문턱은 그대로.
- **ULR1-03 → §12-6 대체 (우선순위 표)**: 창마다 접촉 상태 (CONTACT · TENSION · SEPARATED · `OBS_MISSING` — 관측 누락 ≠ 0) · 상쇄 표지 (교차 끝점 인장 합 ≥ 0.5 · P_meas · A) · 주 측정 자격을 **세 칸으로 분리** · 상쇄 표지의 처분 = **Q2** · 분리 선언 = 연속 두 창 접촉 0 의 **둘째 창 끝** (h_surf · 분리 뒤 4 창의 시작 = 그 창 · 첫 0 창은 대기) · 분리 선언 뒤 재접촉 = 상태를 CONTACT / TENSION 으로 되돌리고 분리 연속 창 계수 · 분리 뒤 유지 계수 · 그 분리의 표면 관측 초기화 (재분리 때 새로 시작) · 유지 예산 안에 다시 못 서면 trajectory = 분리 미완료 (주 값 무영향) · "창에서 0" 의 관측 = **Q4**.
- **ULR1-04 → §12-8 첫 줄 대체 (물리 창 표 하나)**: W₀ = 5,000 은 dt₀ 에서의 step 수 · T_W = dt₀ · W₀ 고정 · W(dt) = T_W / dt (UT · dt* = dt₀/2 의 UV = 10,000) · UV 유지 × 2 = 같은 창 시간에서 창 수 × 2 (8–24 창).  같은 표에서: k = 0 최소 세 창 · S1 연속 차 둘 · 분리 두 창 · 분리 뒤 네 창 · 중력 팔 네 창 · 회전 KE 기준 창 · σ_P 표본 · `fix ave/time` · thermo 주기 · UC 50,000 step (× dt₀ / dt) — 덱 생성기가 이 표에서만 읽는다.
- **ULR1-05**: ① REG:320 의 b 판정 · REG:413 · 435 예문의 b = **명시 폐기** 표지 · 비단조 처리 = **Q3** (7:3 b 재이식 안 함) ② REG:473 동시 제출 예문 = 폐기 표지 · 새 순서 = UB · UT · UC 먼저 (서로 독립) → UB · UT 끝 → 끝점 유효성 · δ_dt → dt* → 그 dt* 의 UV 제출 ③ UT = 첫 교차 + 확인 두 단까지 돌고 그 자리 restart (UT 의 R_M) 저장 · δ_dt = 두 팔의 첫 교차 · 결정표 3 행 (UT 채택) 이면 **같은 UT 궤적을 그 restart 에서** 분리 · 분리 뒤 유지 · 중력 분기까지 이어 돌림 (같은 팔의 후속 관측 · 새 설정 아님 · UB · UV 는 처음부터 전체 멈춤 규칙).

## 2. 키트 단계에서 fixture 와 함께 정할 것 (판정문 §3 · Q2 받음 — 지금 숫자를 채우지 않는다 · 정한 뒤 §12 덧붙임 → 1저자 비준 → Codex)
