## 0. 이 프로젝트의 목적지 (리뷰가 이것을 기준으로 판단해 달라)

**목적 = MPM 을 확실히 쓴다.**  구체적으로 세 가지가 동시에 서야 한다:

| | 무엇 | 현재 |
|---|---|---|
| ① 역학 | morphology · porosity · thickness | 거의 섬 — 단 **플래튼 정지 결함** 트랙이 열려 있다 (`docs/mpm_platen_kinematic_stop_defect.md`) |
| ② 수송 | STEP3 복셀 FV 의 σ_ion / σ_e / k_th | **여기가 이번 쟁점** |
| ③ 신뢰 영역 | "어느 해상도·어느 상에서 믿을 수 있나" 의 명시적 규칙 | 역학 `d_h/dx ≳ 3.5` · **수송 = 2026-08-16 신설 (CL-30, 아래 §0b)** |

★ 이번 사태의 핵심을 목적지 기준으로 다시 쓰면:
- 무너진 것은 **미해상 첨가제**에 관한 결론이다.  vox 0.4 µm 에서
  **VGCF Ø0.15 = 0.37 셀 · SDCP Ø0.3 = 0.75 셀** — 애초에 격자에 올릴 수 없는 크기다.
- 해상된 상은 사정이 다르다: **AM_P Ø5 = 12.5 셀 · SE Ø1 = 2.5 셀**.
- ⚠ 그런데 **SE 2.5 셀도 안심할 수 없다** — 역학 쪽 자체 규칙 `d_h/dx ≳ 3.5` 에 미달이고,
  실제로 SBE 의 σ_ion **절대값이 0.3 → 0.25 µm 에서 +27.0 % 움직인다**.  이건 첨가제
  얘기가 아니라 **SE 해상도** 얘기다.
- ⇒ **③ 이 목적지의 병목**이다.  "수송을 믿을 수 있는 최소 해상도" 규칙이 없으면 ② 의
  어떤 수치도 인용할 수 없다.  ①은 이미 그 규칙을 갖고 있어서 서 있는 것이다.

### §0b 수송 해상도 규칙 — 이번에 세웠다 (CL-30, GPU 불요)

`solve_sigma_z` 가 **sid 배열을 직접 받으므로** MPM 압밀 없이 킷 스캐폴드의 **해석적 구**를
원하는 vox 로 래스터해 풀 수 있다.  기하가 해석적이라 참값이 격자 무관 → 남는 변화는 전부
이산화 것이다.  20 µm RVE · half-cell origin ×4:

| SE Ø/dx | origin-평균 σ_ion | 증분 | **origin 폭** |
|---:|---:|---:|---:|
| 2.5 | 1.6055e-4 | — | 3.52 % |
| 3.3 | 1.6757e-4 | +4.37 % | **5.78 %** |
| 4.0 | 1.7040e-4 | +1.69 % | 3.20 % |
| 5.0 | 1.7172e-4 | **+0.78 %** | 2.44 % |

⇒ **규칙: origin-평균은 SE Ø/dx ≳ 4 에서 ±3 % 안. 단일 origin 은 위상에 최대 5.8 % 흔들려
그 tol 을 못 지킨다** — 단일 origin σ 를 5 % 보다 좁게 인용하지 말 것.

★ 부수 소득: 같은 0.3→0.25 구간에서 이 RVE 는 **+1.7 %** 인데 실침대 SBE σ_ion 은
**+27.0 %** 였다.  SE 해상도만으로 설명 안 되는 크기 ⇒ 첨가제(또는 MPM 침대 기하)가
지배한다는 CL-25 방향과 정합.  **단 침대가 달라 직접 비교는 아니다** — 여기를 쳐 달라.

## 2. ★ 특히 물고 늘어질 곳 (내가 스스로 지목)

### [A] CL-29 — 내가 Codex 를 되돌린 자리.  여기가 제일 약하다

Codex: "k = 1.4855/1.4917/1.4461 (폭 0.046) 이므로 k 는 격자 무관이 아니다."
나: "그 산포는 ① `np.unique` 로 경로 순서를 버린 estimator 결함 ② vox 에 따라 달라지는
모집단 ③ 서브복셀 조각 — 셋의 합이다."

실침대 전 섬유 (24,733 섬유 · 39,778 구간) 실측:

| vox | k_legacy | k_new | k_공통모집단 |
|---:|---:|---:|---:|
| 0.4 | 1.4855 | 1.4834 | 1.4859 |
| 0.3 | 1.4917 | 1.4891 | 1.4915 |
| 0.25 | **1.4461** | 1.4910 | 1.4922 |
| **폭** | **0.0456** | 0.0076 | **0.0063** |

legacy 세 값은 Codex 와 **비트 일치** — 그들의 측정은 정확하다.

**⚠ 이 반박의 급소를 내가 먼저 쟀다**: 공통 모집단을 만들며 **11.7 %(개수)** 를 버렸는데,
버린 군은 길이 중앙 **0.170 µm** 이고 **격자 산포가 0.0922 = 공통군의 10 배**다.
= **이견 내던 데이터를 버린 것이 맞다.**
방어: k 는 길이 가중이고 버린 군은 **길이로는 0.69 %** (32.4 vs 4,646.4 µm).  측정 가능한
격자에서 전부 포함해도 k 는 −0.003 이내 이동, **폭 0.0093 → 0.0114** — 여전히 legacy 의
4 배 아래.

**공격 지점**:
1. **정규화가 동어반복 아닌가.**  `L_ref = L_arc·(span/L_chord)` 는 축정렬 직선에서
   **정의상** k = 1 을 준다.  내가 원하는 답이 나오게 정규화를 고른 것 아닌가?
   (변호: 대각 1.7306 vs √3 = 0.086 % 차, 등방 1.4995 vs 1.5 — 정확히 안 맞으므로
   동어반복은 아니다.  그러나 이 변호가 충분한지 판정해 달라.)
2. **0.69 % 방어가 옳은 가중인가.**  길이 가중은 **직렬** 저항 가정이다.  서브복셀 조각이
   퍼콜레이션 경로의 **병목**에 있으면 길이 비중과 무관하게 지배할 수 있다.
   ⇒ 판별: 조각들이 spanning cluster 위에 있는지 아닌지를 세야 한다.  **미실행.**
3. **잔여 0.006~0.011 을 0 으로 읽지 않았는지.**  나는 "수렴 중" 이라 썼다.  3 점으로
   수렴을 주장하는 것 자체가 CL-24 에서 내가 비판받은 것과 같은 형태 아닌가?

### [B] `couple_to_voxel_grid` — 새로 만든 것이라 검증이 가장 얕다

동축 `G = 2πσ_m·L/ln(b/a)`, `b` = **Peaceman 1978 등가반경 0.2·vox**.

**공격 지점**:
1. **Peaceman 이 전이되는가.**  원 도출은 **2D · 단상 Darcy · 정방격자 · 셀 중심의 우물**
   이다.  우리는 **3D · 다상(AM/SE/SDCP) · 섬유가 셀을 비스듬히 관통 · 셀 중심 아님**.
   전이 근거를 나는 제시하지 않았다.  ⇒ 이 앵커는 **가짜 앵커**일 수 있다.
2. **`b/a < 1.5` 게이트의 1.5 는 어디서 왔나.**  내가 정했다.  앵커 없다 (§F1 위반 후보).
3. **결론이 너무 편리하지 않은가.**  "생산 격자는 무효, vox ≳ 1 µm 를 써라" 는 결론은
   지금 미수렴인 0.25~0.4 를 피해가게 해 준다.  결과가 편한 쪽으로 나온 것 아닌가?
4. 계면 접촉저항 = 완전 접촉 가정 (앵커 없어 미모형).  σ_e 를 얼마나 부풀리나 미측정.

### [C] 접촉 모형 — 눈먼 탐침을 내가 하나 찾았는데 더 있을 수 있다

`contact_sensitivity` 가 기본 범위 (0.8/1.0/1.25) 에서 **`spread 0.0 %`** 를 냈다.
그것이 "둔감해서 안전" 으로 읽혔는데 실은 **아무것도 못 재고 있었다** — 패치 병합 후
접촉 수가 늘 1 이고 Holm `G = 2σ·a_frac·d` 가 **간격과 무관**하기 때문이다.
범위를 0.4~2.0 으로 넓히니 절벽이 **0.6 → 0.8 사이**에 있었다 (접촉 0 → 1).

**공격 지점**:
1. **`a` 가 간격을 무시한다** = 문턱에서 σ 가 **불연속**.  실제 협착 반경은 간신히 닿을 때
   0, 파고들수록 커져야 한다.  간격-의존 a 모형은 앵커가 없어 미구현 — 그래도 되는가?
2. **패치 병합이 비대칭**이다: 같은 선쌍에서 **선 A 의 연속한 선분 인덱스**로만 단일연결을
   묶는다.  선 B 쪽 연속성은 안 본다.  A/B 를 바꾸면 패치 수가 달라질 수 있다.  **미검증.**
3. `distributed` 라벨의 문턱 `len > 3·d` — 내가 정했다.  앵커 없다.
4. **다른 눈먼 탐침이 더 있는가.**  이번엔 내가 찾았지만, "민감도 0 = 안전" 으로 통과하는
   시험이 리포에 또 있는지 훑어봐 달라.

### [D] 받아들인 것들이 **옳게** 받아들여졌는가

되돌린 것보다 **그냥 받아들인 것**이 더 위험할 수 있다 (검증 없이 접었을 수 있다).

  (`sig_i` 표를 확인해 달라 — 내가 확인하지 않고 산술만 했다.)
- **CDX-01 (SDCP 4.53×)**: 단입자 산술이다.  실침대는 셀 충돌·상 overwrite 가 있어

  그런데 CL-21 의 "단일 기전 귀속 철회" 는 이 미측정 값에 기대고 있다.  과한가?
