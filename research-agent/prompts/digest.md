# 디제스트 작성 프롬프트 (morning job)

입력: 오늘 디제스트에 포함할 논문들의 분석 JSON(우선순위 순), 날짜, 최근 7일 DB 통계.
출력: Obsidian 호환 Markdown 본문(템플릿 `templates/daily_digest.md`의 `{{body}}` 자리).

규칙
1. 첫 두 줄: 해요체 인사 + 오늘 요약 한 문장 ("오늘은 DEM 2편, DFT 1편이에요. Nature Communications의 Kissel 논문이 핵심입니다." 식).
2. Tier A → B → C 순서. 각 논문 블록은 `### [[노트이름]]` 헤더로 시작하고 IF·저널·연도·관련도를 한 줄 메타로.
3. 논문마다 "선정 이유 → 핵심 내용(3~5 bullet, 수치 포함) → 내 연구 연결/논문 활용 → 비판 포인트 1~2개" 순서. 길이는 A 8~12줄, B 5~7줄, C 3줄.
4. 오늘의 한 줄 인사이트: 논문들을 가로지르는 공통 흐름이나 내 연구에 대한 시사점 1~2문장.
5. 마지막 `## References`: 번호. 저자 et al. 제목. *저널* 연도. [DOI](https://doi.org/...) — 노트 위키링크도 병기.
6. 문체는 style_guide.md. 번역투 금지, 고유명사 영어.
