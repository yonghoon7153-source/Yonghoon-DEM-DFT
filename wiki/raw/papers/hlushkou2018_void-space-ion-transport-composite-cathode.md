# 2. 방법 — 두 경로, 두 시편

## 2.1 경로 A — 대칭셀 EIS (§2 식 (1)–(6), §3.1, §4.1)

`[인쇄]` 식:

```
(1) σ_ion,composite = d / (R_ion · A)
(2) σ_ion,composite = ε · σ_ion,electrolyte                       ← 이상 경우
(3) τ_cond = (σ_ion,electrolyte / σ_ion,composite) · ε            ← 굴곡도 인자
(4) Z_overall = 2R_electrolyte + Z_composite + Z_interfaces
(5) Z_high = 2R_electrolyte + Z_interfaces                        ← R_e− ≪ R_ion, ≪ 2R_electrolyte 일 때
(6) Z_low = 2R_electrolyte + R_interfaces + R_ion/(iωβ)^α · tanh(iωβ)^α   ← Warburg-short, 이상 α = 0.5
```

(식 (6) 은 쪽 렌더로 확인 — 추출 텍스트는 조각난다.) Fig. 1(`[도표]`, 쪽 렌더로 봄): (A) 고주파 — Li⁺ 는 SE 층을 지나고 복합체 안에서는 **전자가 가로지른다**(e⁻ 화살표) · (B) 저주파 — 전자는 SE 층에 막히고(× 표시) Li⁺ 가 복합체를 가로지른다.
`[해석]` **EIS 셀의 LCO 를 부분 탈리튬화(Li₀.₇₁CoO₂)한 이유**가 여기 있다 — 식 (5) 의 조건 `R_e− ≪ R_ion` 은 탄소 없는 양극에서 LCO 가 전자 전도 망이어야 성립한다. 원문은 이유를 적지 않는다("with delithiated LCO as active material").

시편: LTO 복합 음극 + LCO 복합 양극 전지를 조립 · 부분 충전(→ Li₀.₇₁CoO₂) → **음극을 Dremel 로 갈아 제거** → 양쪽에 SE 층 → **4 t cm⁻² 5 min** → Li 분말 양쪽 → **1 t cm⁻²**. 관 내경 9.8 mm · 스테인리스 다이. Autolab PGSTAT302N · OCP · **500 kHz–0.3 mHz** · 10 mVrms · RelaxIS 적합. 사후: 에폭시 매립 · 띠톱 절단 · 광학 현미경 단면 → 두께.

두 방법의 값(1.6 ± 0.1 ↔ 1.74) "close" · 차이는 수지 · 무공극 가상 구조 1.27 · `[인쇄]` "This problem associated with void space does not exist in conventional Li-ion batteries using liquid electrolytes, although entrapped air may give rise to similar consequences" · `[인쇄]` "close attention should be paid to the **actual amount of void space** formed during the preparation" · `[인쇄]` "It is not unlikely that the void space problem becomes worse for composite electrodes with smaller volume fractions of the solid electrolyte" — **고에너지(저 SE) 쪽 외삽은 주장이 아니라 추측으로 인쇄**.
`[해석]` 결론의 권고("actual amount of void space")를 **이 편의 EIS 시편에는 적용하지 않았다**(G5).

# 4. 식별성 해부 — void 의 두 효과와 수송 곱

**① 관측 연산자.** 경로 A 가 보는 것: `R_ion` → `σ_comp = d/(R_ion A)` → `σ_comp/σ⁰ = ε/τ` **하나**(σ⁰ 를 입력으로). `ε` 와 `τ` 는 곱으로만. 경로 B 가 보는 것: 한 구조의 `ε`(영상) 와 `D_eff/D⁰ = 1/τ`(모의) **각각**.

**② 경로 B 안에서는 곱이 풀린다.** 영상이 `ε` 를, 모의가 `τ` 를 따로 준다 — 54호와 같은 방식. 가상 치환은 한 구조에서 **void 의 경로 효과**를 `ε` 몫과 `τ` 몫으로 나눈다(`[재현]` 로그 41 : 59).

**③ 두 경로 사이에서는 곱이 안 풀린다.** 경로 A 의 시편에 경로 B 의 `ε` 를 빌려 올 근거가 없다(G5 · G7). 원문은 경로 A 의 `ε` 를 인쇄하지 않고(G1) `τ` 끼리 비교했다 — `[재현]` 1.6 은 `ε` ≈0.65 를 쓸 때 나오고, 그 `ε` 는 공칭(0.62)도 영상(0.537)도 아니다. 곱 기준으로는 EIS 0.406 ↔ 모의 0.309(×1.31).
- `[해석]` 0.406 을 설명하는 조합은 한 줄이 아니다: (a) FIB 와 같은 void + Bruggeman 형 `τ`(0.394) (b) void 가 더 적고 구조형 `τ`(무공극 0.527 과 void 0.309 사이) (c) σ⁰ 가 온도 · 압착으로 달랐음(G3) (d) 충전 상태 차의 LCO 부피 · 접촉 변화(G7). **(a)–(d) 를 가를 입력이 지면에 없다.**

**④ void 의 접촉 효과는 자리조차 없다.** 모의는 반응 · 계면이 없는 확산이라(식 (9) 전제) LCO 표면이 SE 에 닿든 void 에 닿든 `D_eff` 에 들어가지 않는다. 카드 기준으로:

| 접촉 변화 | 카드 이름 | 이 편 |
|---|---|---|
| 입자 통째 비연결 | `u` / `θ` | 0 — LCO 연결성 · 고립 분율 계산 없음 |
| 경로 좁아짐 | `σ_eff` ↓ (`τ`) | ✅ **계산** — void 13.2 % → `ε/τ` ×0.59(`[재현]`) |
| 계면 면적 감소 | `φ` / `A_eff` | 0 — 같은 재구성에서 셀 수 있으나 안 셌다 · `[도표]` Fig. 4D 정성뿐 |

⇒ `[해석]` **이 편은 void 를 [[assb-tortuosity-factor-effective-conductivity-split]] 표의 둘째 줄("경로 좁아짐 → `σ_eff` ↓ → `η(z)`")에 수를 붙인 첫 표본**이다. 14호(Oh Maxwell) D12 "void 2 배 셀이 용량 유지율 차이 없음" 과 방향이 맞는다 — void 는 용량(`θ`)이 아니라 수송(율 의존)으로 간다. 단 이 편은 용량을 재지 않았다.

# 7. 곱 축퇴 처방 — 서른여덟 번째 적용

대상은 카드의 동역학 곱(`A_eff·ε_p/R_s`)이 아니라 **수송 곱 `σ⁰·ε/τ`** 와 그것을 재는 **두 경로의 대조**다.

| 단계 | 입력 | 판정 |
|---|---|---|
| **1단계** `R`·`C` | EIS 1 장 — `R_ion` 만 인쇄, `β`(시상수) · `α` · 계면 호 미인쇄 | ❌ `C` 0 |
| **2단계** 면적 대조군 | **디지털 치환(void → SE) — 같은 구조 · LCO 고정 · void 만 바꾼 대조** | ⚠ 부분 — **수송만**(계산), 접촉 면적 0 |
| **3단계-a** `Ea` | SE 펠릿만 −120 → 160 °C 측정(`Ea` 미인쇄), 복합체 온도 0 | ❌ |
| **3단계-b** `C` 상한 | — | 해당 없음 |
| **4단계** 두 영역 / 두 경로 | EIS(주파수) ↔ 구조 모의 — **시편 넷이 다르다**(수지 · 충전 상태 · 압착 · 두께) | ❌ 24호 줄 "두 영역 대조의 시편 조건" 위반 |

**곱이 선 자리**: 경로 B 안에서 `ε`(영상) · `τ`(모의) 각각 ✅. 경로 A 의 `ε` 는 미측정 · 미인쇄 ⇒ `σ_eff/σ⁰` 0.406 에서 `ε`/`τ` 분할 ❌. 두 경로의 비교 양이 `τ` 라 **각 경로가 다른 `ε` 로 나눈 뒤** 비교됐다.

**⇒ 이 적용이 처방에 더하는 것**:
1. **새 줄 "두 경로(측정 ↔ 구조 계산) 대조는 관측 곱 `σ_eff/σ⁰`(= `ε/τ`)로, 같은 시편 · 같은 `ε` 로"** — `τ` 끼리 비교하면 각 경로가 고른 `ε` 가 판정을 정한다. 이 편: `τ` 1.6 ↔ 1.74(9 %) · 곱 0.406 ↔ 0.309(31 %).
2. **디지털 치환 대조(재구성 위 상 바꾸기)는 2단계 면적 대조군의 계산판** — 한 구조에서 한 상만 바꿔 효과를 떼는 유일한 방법이다. 이 편은 수송에만 썼다; **같은 치환으로 LCO 표면 분할(LCO–SE ↔ LCO–void)을 세면 void 의 접촉 효과(`φ`)를 경로 효과와 한 구조 위에서 가를 수 있다**(`[해석]`, 후보).
3. **영상 상 이름의 검사** — "void" 상에 수지 · 다른 비전도 물질이 섞이면(이 편 · 39호 AB) 그 상의 분율은 곱의 인자로 바로 쓰지 않는다.

**⚠ 이것이 곱을 푼 것은 아니다** — 경로 B 는 FIB 시편의 곱을 풀었을 뿐이고, EIS 시편의 곱 · 카드의 동역학 곱(`A_eff·ε_p`)은 건드리지 않았다. 위 `[재현]` 은 인쇄값 · 관 내경 가정 위의 우리 계산이다.

# 13. 이 digest 가 주장하지 않는 것

- **void 가 이온 수송을 해친다는 결론이 틀렸다고 하지 않는다** — 경로 B 안에서 치환 계산은 그 결론을 받친다(`[재현]` 로그 몫 `τ` 59 %). 주장은 **두 경로의 "일치" 가 `ε` 규약 위에 있고, 곱으로는 ×1.31 어긋난다**는 것까지다.
- **EIS 시편에 void 가 없었다고 하지 않는다** — 재지 않았다는 것(G5)과, 측정 곱이 여러 조합과 양립한다는 것(§4 ③)까지다.
- **`ε` ≈0.65 를 저자가 쓴 값이라고 적지 않는다** — 인쇄된 `R` · `d` · σ⁰ 와 관 내경 9.8 mm 가정에서 1.6 을 역산한 우리 값이다. 면적 · σ⁰ 가 다르면 달라진다(R5).
- **39호 해상도 판정에 이 편 void 현 분포를 수치로 옮기지 않는다** — 화학(LGPS ↔ LPSI) · 입경 · 압력 · 수지가 다르다. 방향만(`[해석]`).
- **void 의 접촉 효과가 작다거나 크다고 하지 않는다** — 이 편에 그 양이 없다. Fig. 4D 는 정성이다.
- 원문 인용 원전(Thorat 2009 · Landesfeind 2016 · Kaiser 2018 등)은 **열람하지 않았다**.
