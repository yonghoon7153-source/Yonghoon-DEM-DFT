# DEM 프로토콜 세대 2 요청서 작성자 검산 (2026-10-23)

이 문서는 요청서 작성자의 검산 기록이다. 독립 리뷰·실제 DEM 결과·실험 측정이 아니다. 원계획서와 shared ledger는 수정하지 않았다. 작업 디렉터리의 source/CLAUDE/shared gate/봉인 코드에 대한 쓰기·commit·push도 하지 않았다.

## 2. 숫자·전칭 대조

|---|---|---|

| TD 1.64 점값 경계 0.7763656 mm | `zero_porosity_thickness_mm_density_1_64` | m=0.100 g, d=10 mm, ε=0을 직접 풀었음 |
| t=0.770±0.010 mm, m=0.1000±0.0001 g → ρ∈[1.630726,1.676991] | `density_measurement_interval_counterexamples[1]` | d 정확히 10 mm 가정의 반례. 지름 오차는 실측에서 더 넣어야 함. 반증 아님 |

## 3. 문헌 신선도와 한계

- 계획서 핀 `9dc235c38f6347c1d94febc598b1d93ee2ffef68` → 대조한 정본 최신 핀 `aaa275e2081ce43a6892c7dde40ea4d8f82576de`.
- 바뀐 카드: `litdb/papers/sakuda2013_sulfide_mechanical_property.md`. 10-21 원문 대조가 추가되어 1.88 g/cm³의 대상은 열간프레스 투명 **유리 펠릿**이며 결정밀도가 아님을 명확히 한다. 기존 계획의 ‘24 GPa=다른 유리 계열, LPSCl 재료 정답 아님’ 한정은 유지해야 한다.
- 이번 검산은 카드 파일의 존재·바이트 변경과 변경분을 확인했다. PDF/SI 45편을 새로 읽어 각 표를 재판독하지 않았다. 요청서에 외부 수치의 신규 출처를 추가하지 않았다.
- source manifest의 22개는 §9가 지정한 최소 설계 근거의 신원 목록이다. 최종 발송 묶음은 언로딩 최신판·독립 리뷰·문헌 blob까지 더한 후 별도 manifest로 봉인해야 한다.

## 4. 독립 검토자에게 넘길 공격 목록

1. R1: 힘 750 N 고정·병진 KE 0인데 회전만 남은 입력, 반대 국소 잔류의 상쇄, 관측 간격 사이 주기 운동. 표본 전부/창/초기 구간 계약의 구멍을 찾을 것.
2. R2: 판 전체 하강 중 국소 접촉이 제하되는 경우, 이름이 같은 새 fix, restart 직후 같은 위치/다른 δ_max, move/mesh 반복으로 접선·구름 이력이 바뀌는 경우.
3. R3: 같은 질량/밀도의 두 구에서 sphere와 union을 맞바꾸기, 벽 절단·안쪽 영역·표면 지표의 분모 바꾸기, 0.776 mm 경계를 측정오차 안에서 넘나들기.
4. R4: 현재 g-off 변화 0이지만 준비 기억이 큰 합성 2×2 표. 고중력·저중력에 같은 step 수만 쓰면 준비 완료가 다른 경우.
5. R5: 단일 seed에서 우연히 단조인 E→공극, 여러 교차/평탄부, MC 오차에 의한 bracket 변경, E* 확인 seed 실패 후 사다리 재선택을 사후 보정으로 숨기는 경우.
6. R6: 과거 카드와 최신 카드의 대상 상태 혼동, 물성 표의 assumed 값을 measured로 승격, 재료 영률과 보정 입력의 이름 혼동.
7. R7: X4의 반대 방향을 TECH로 자동 배제하는 문장과 물리 반증 처리의 충돌, X2 기대를 데이터가 아니라 실패 구제 띠로 쓰는 경우.
8. R8: 이름에 g2가 있다는 이유로 DEM P2로 분류, unknown을 집계에서 조용히 제외해 초록으로 만드는 경우, P1/P2 혼합 시 분모 변동.
9. R9: ULPR 부분 재개, CSV·dump timestep 불일치, 같은 이름의 다른 kit/reader/params, 결손 G2c의 값 불일치 승격, Δz·상한만 h₀ 비례인데 표면·안정 문턱은 절대값인 접합 명세.

계획 초안이 아직 숫자를 봉인하지 않은 것 자체를 코드 결함으로 세지 않는다. 다만 어떤 숫자·함수·실패 상태를 누가 언제 정할지 미정이면 등록 준비의 HOLD 사유로 구체화한다. 독립 리뷰의 새 결함은 이 작성자 체크리스트에 맞추지 말고 별도로 보고한다.

## 5. 전달 범위

- 실행한 것: stdlib 해석 반례, 기존 산술 probe 한 개, Git blob·hash·원장 상태 대조.
- 수행하지 않은 것: 새 DEM 코드/덱, T0–T14 실제 실행, 외부 기계·스케줄러·네트워크 요청, 펠릿 측정, 문헌 원문 새 전수 검토, shared record 수정, commit/push, 발송.
- 최종판 문서 참조·철회값 스윕·원장 자기일관·전체 게이트와 ZIP 검증은 메인 통합 뒤 필요. 이전 결과로 대체하지 않는다.
