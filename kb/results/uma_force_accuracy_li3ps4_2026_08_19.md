# UMA-s-1p1(omat) 힘 정확도 — Li₃PS₄ DFT 라벨 벤치

> **한 줄**: 우리 정본 MLIP 이 **학습한 적 없는** 황화물 데이터에서 **힘 MAE 30.0 meV/Å**,
> 같은 test set 에 대해 그 데이터로 **1940개 학습한 전용 모델(35.6)보다 정확하다.**
> ⇒ **"UMA sulfide PES softening"** 이라는 알리바이의 근거가 사라진다.
> ⚠ 다만 이 벤치는 **응력·장벽을 안 잰다** — NEB 0.528 vs MD 0.253 격차 자체는 못 닫는다.

## 0. 왜 쟀나

2026-08-19 하루 종일 같은 논쟁이 되풀이됐다 — 전부 **참값이 없어서** 생긴 것이다:
- cascade 부피축이 뒤집힌 게 UMA 편향인가 미수렴인가 (→ 미수렴이었다)
- NEB 0.528 eV 가 UMA 탓인가 단일 경로 탓인가 (→ 이 카드가 절반을 답한다)
- preflight 이 **"UMA sulfide PES softening"** 을 알리바이로 썼다 (→ 근거 없음)

PET-MAD 논문(EPFL COSMO, *Nat. Commun.* 2025, 16, 10653)이 **Li₃PS₄ DFT 라벨 데이터셋**을
공개했다 ⇒ **우리가 DFT 를 한 판도 안 돌리고** 황화물에서 오차를 잴 수 있다.

## 1. 설정

| 항목 | 값 |
|---|---|
| 모델 | **UMA-s-1p1, task `omat`** (우리 정본) |
| 데이터 | PET-MAD 배포 `Li3PS4/` — train **1940** / test **243** 구조, 16–64 원자, α/β/γ 3상 |
| 라벨 | energy + forces, **PBEsol** (QE 7.2+SIRIUS, SSSP v1.2-eff, 110/1320 Ry, non-magnetic) |
| 도구 | `tools/mlip/bench_against_dft.py` (2026-08-19 신설) |
| 실행 | kgy (RTX3090, uma env) · test 84 s / train 667 s |
| 산출 | `db/properties/mlip_bench_li3ps4_uma.json` |

**참조 보정**: 두 DFT 설정의 절대 총에너지는 **원소별 상수만큼** 어긋나므로
`E_MLIP − E_DFT ≈ Σ_el n_el·e_el` 를 **train 에서 적합해 test 에 적용**한다.
적합값 **Li +0.0931 · P +0.0310 · S +0.1242 eV/atom**, R² 0.620.

| 지표 | 값 |
|---|---|
| **힘 MAE** | **0.0300 eV/Å** (RMSE 0.0446, 최악 0.477) |
|  ├ Li | **0.0132** (RMSE 0.0187, n=8064) |
|  ├ P | 0.0368 (RMSE 0.0546, n=2688) |
|  └ S | 0.0409 (RMSE 0.0545, n=10752) |
| 에너지 (보정 후) MAE | 0.0135 eV/atom (RMSE 0.0185, 중앙 0.0086, 최악 0.0553) |
| **상대에너지 RRMSE** | **2.4 %** (RMSE 0.688 eV) — ⚠ 아래 지표 경고 |
| 실패 구조 | **0 / 243** |

> ⚠⚠ **RRMSE 2.4 % 는 약한 지표다 (fable-5 자기리뷰 2026-08-20, 코드 재독으로 확인).**
> 구현이 `ΔE(i) = E_i − E_0` (첫 구조 기준) 인데 test set 이 **16–64 원자 혼합**이라
> 분모(기준 ΔE 의 RMS)가 **크기 차이라는 자명한 항**으로 부풀어 있다. 정직한 수치는
> **RMSE 0.688 eV** 쪽이다. 특히 Zhang npj 의 22.8 %(같은 셀 안 CI-NEB 전이상태 상대에너지,
> ΔE ~0.1–1 eV 스케일)와 **나란히 놓으면 안 된다** — 분모의 성질이 다르다.
> 제대로 재려면 **같은 조성·같은 크기 부분집합 안의 쌍**으로 다시 계산해야 한다 (도구 미수정,
> codex 교차검증 뒤 일괄 반영).

### 2-1. 같은 test set 공표값과의 위치

| 모델 | 힘 MAE (meV/Å) | 학습 |
|---|---|---|
| PET-MAD 기저 | 63.9 | 범용 (MAD 9.6만) |
| PET-MAD LoRA (N=1940) | 39.2 | **이 데이터로 파인튜닝** |
| bespoke (N=1940) | 35.6 | **이 데이터로 from-scratch** |
| **UMA-s-1p1/omat (우리)** | **30.0** | **이 데이터 학습 안 함** |

⇒ **범용 모델이 전용 모델을 이겼다.** 그것도 **참조 범함수가 다른데도**(UMA=OMat24/PBE 계열 ↔ 라벨=PBEsol).

> ⚠ **"이겼다"는 힘 축에서만이다 (fable-5 자기리뷰).** 에너지는 bespoke 가 **1.165 meV/atom**
> (에이전트 parity 재계산)인데 우리는 보정 후 **13.5** — 자릿수로 밀린다. 우리 잔차에는
> PBE↔PBEsol 비선형 불일치가 섞여 있어 등가 비교는 아니지만, 어쨌든 **"전용을 이겼다"를
> 에너지·안정성 순위로 확장 인용하면 안 된다.** MD/NEB 를 모는 건 힘이므로 우리 용도에는
> 힘 축 결론으로 충분하다.

## 3. 이 결과가 닫는 것 / 못 닫는 것

**닫는다**
- ⛔ **"UMA 가 황화물에서 PES 를 무르게 본다"** — 적어도 Li₃PS₄ **힘**에서는 근거가 없다.
  preflight 이 이 문구를 알리바이로 쓰던 것을 **철회해야 한다.**
- **Li 힘이 특히 정확하다**(13.2 meV/Å, 전체의 44 %). Li 이동이 우리가 재는 전부이므로
  MD/NEB 입력으로서의 건전성이 이 축에서 확인된다.

**못 닫는다 (도구 자신이 docstring 에 적어 둔 한계)**
- **응력을 안 잰다** — 이 데이터셋에 stress 라벨이 없다.
  ⇒ **cascade 부피 편향(+32.7 %) 은 이 벤치로 무죄가 되지 않는다.** 별건이다.
- **장벽을 안 잰다** — 힘이 맞아도 NEB 장벽이 맞는다는 보장이 없다.
  오히려 그게 안 된다는 것이 문헌의 요지다 (Zhang npj 2026: MACE-MP-0 이 힘 0.16 eV/Å 인데도
  **CI-NEB 전이상태 상대에너지 RRMSE 22.8 %**).
  ⇒ **NEB 0.528 vs MD 0.253 (109 %) 격차의 남은 후보는 경로 선택**이다.
- **데이터셋의 DFT 설정을 검증하지 않는다.** 그쪽이 틀리면 이 값도 틀린다.

## 4. 반론 / 약한 곳 (지우지 말 것)

1. **참조보정 R² 0.620** — 원소별 선형 모형이 ΔE 분산의 **62 %만** 설명한다.
   즉 에너지 오차는 **참조 offset 만이 아니다**. 보정 후 13.5 meV/atom 이 정직한 수치다.
   ⚠ 단 **자기적합(낙관치)이 13.49 로 train-적합 13.45 와 사실상 같다** ⇒ 잔차는
   **적합 부족이 아니라 진짜 모델 오차**다. 이 점은 결과를 강화한다.
2. **최악 힘 0.477 eV/Å = 평균의 16배.** Kauwe 2021 §2.5 의 교훈("평균 RMSE 가 낮아도
   목표 물성이 틀릴 수 있다")이 그대로 적용된다. 꼬리를 평균으로 덮지 말 것.
3. **범함수 교차**(PBE 계열 모델 ↔ PBEsol 라벨). 힘은 offset 에 둔감하지만 무감하지 않다.
   ⇒ **UMA 가 실제 PBE 라벨에서는 더 좋을 수도, 더 나쁠 수도 있다** — 미측정.
4. **공표값의 분할을 우리가 직접 확인하지 않았다.** PET-MAD 63.9 / bespoke 35.6 이
   **이 test.xyz 243구조 위의 값인지**는 배포 parity 데이터로 재계산한 에이전트 보고에 의존한다.
   ⇒ **원고에 넣기 전에 반드시 직접 확인할 것.** (지금은 `figure-read`급 신뢰도)
5. **조성이 Li₃PS₄ 다** — 우리 계는 Li₆PS₅Cl(+Cl, +O, +B). **Cl 이 없다.**
   PET-MAD MAD-bench 1562 구조에도 Li+P+S 동시 구조가 0개였다(에이전트 실측).
   ⇒ **아르지로다이트·Cl 무질서로의 전이는 이 벤치가 보증하지 않는다.**

## 5. 후속 4건 — **3건 완료 (2026-08-20)**

### 5-1. ✅ 보존성 — **비보존 아니다** (`mlip_engine_probe_comp1.json`)
comp1 52원자, 표본 4원자 × 3축 × δ 2개:

| δ (Å) | 상대편차 평균 | 최대 |
|---|---|---|
| 0.001 | 1.256 % | 3.652 % |
| **0.005** | **0.198 %** | 0.573 % |

**근거 ① — δ 의존성**: δ 를 키우니 편차가 **6배 줄었다**. 비보존이면 δ 를 키워도 편차가
남아야 한다(그건 δ→0 극한에서도 사라지지 않는 계통항이니까). 줄어든다는 건
**에너지의 수치잡음**이 유한차분 분모 2δ 로 나뉘어 증폭된 것뿐이라는 뜻이다.

**근거 ② — 재현되지 않는다**: 같은 구조·같은 시드·같은 표본 원자로 다시 돌렸더니
δ=0.001 평균이 **1.256 % → 0.939 %**, 최대가 3.652 % → 1.993 % 로 **달라졌다**
(GPU 리덕션 순서 비결정성). 진짜 비보존 항이 있으면 편차는 **재현돼야 한다** —
매번 다르다는 것이 잡음이라는 독립 증거다.

⇒ **UMA 는 보존적이다 (힘 = −∇E).**

> ⚠ **적용 범위 (fable-5 자기리뷰)**: 이 프로브는 **DFT-V0 근처(near-minimum) 배치의 원자 4개**만
> 봤다 — 코드 재독으로 rattle 없이 주어진 구조 그대로임을 확인. PET-MAD `Fig. S16/S17` 의
> 직접힘 병리는 **고온 MD 의 far-from-minimum 배치**에서 드러난다. 결론을 MD 영역으로
> 일반화하려면 **rattle(~0.1 Å) 또는 MD 스냅숏 배치에서 같은 프로브를 반복**해야 한다
> (1분짜리, 미실행). 지금 판정은 "시험한 배치에서 보존적" 까지다.
⇒ PET-MAD `Fig. S5`(기하최적화 9–11 % 미수렴) · `Fig. S16/S17`(종별 온도 분리 Cl>2000 K,
MSD 자릿수 과대) 의 직접힘 병리는 **UMA 에 걸리지 않는다.**
**"우리 D 가 과대·Ea 가 과소인 것은 힘이 gradient 가 아니어서" 가설은 죽었다.**

### 5-2. ✅ 골격(비-Li) MSD — **1000 K 에서 안 녹는다** (LPSOCl 10런)
`tools/ionic/msd_diffusive_check.py --framework --from_traj`

| 런 | 최악 골격 원소 | Li 대비 비 | 골격 β | MSD_Li@50ps |
|---|---|---|---|---|
| lpsocl_3x3x1 T1000 ×1 | O | 0.022 | 0.29 | 144.8 |
| lpsocl_3x3x1 T600 ×3 | O | 0.011–0.020 | ≈0.0 | 40–43 |
| lpsocl_new T1000 ×3 | Cl/S | **0.006–0.009** | 0.03–0.17 | 148–154 |
| lpsocl_new T600 ×3 | O/S | 0.028–0.048 | 0.03–0.12 | 17–32 |

전부 판정선(WARN 0.10)의 **절반 이하**이고, 더 결정적인 것은 **골격 β 가 0 근처**라는 점이다
— MSD 가 평평하다 = 순수 진동. 녹고 있다면 β 가 1 근처여야 한다.
⇒ **Zhang npj 2026 이 MACE-MP-0 에서 본 LGPS 골격 융해(1050–1500 K)가 UMA·LPSOCl 에는 없다.**
**아레니우스 1000 K 앵커는 (적어도 LPSOCl 에서) 안전하다.**

⭕ 지표 건전성 확인: **600 K 에서 비가 오히려 크다**(0.048 > 0.009). 골격 절대 MSD 는 온도에
거의 무관한 진동 진폭인데 분모(Li MSD)가 17–43 으로 작아져서다 — 물리적으로 맞는 거동.
`save_fs=100 fs` 가정은 이 판정에 무관하다(비는 같은 인덱스, β 는 로그기울기라 시간축 상수배에 불변).

> ⚠ **경계 사례 (fable-5 자기리뷰)**: lpsocl_3x3x1 **T1000 의 O(9) β = 0.29** 는 rigid 문턱
> (0.30) **바로 밑**이고 n=9 는 MIN_N=8 바로 위다. "전부 rigid" 를 이 한 점으로 과신하지 말 것 —
> **지금 kgy 에서 돌고 있는 T1000_s3 이 끝나면 그 시드의 O β 가 판정을 굳히거나 흔든다.**
> ⚠ β 창(2–50 ps)은 `save_fs` **절대값에는** 민감하다(창이 실시간으로 이동). kgy 캠페인은
> `--save_fs 100` 명시라 안전; gabia 6월 런(b2o3/modelc)은 §5-2 표가 아니라 별도 카드 대상이고
> **두 계가 같은 캠페인 스크립트라 공통 오차면 상대 비교는 살아남는다.**

⚠ **미판정 3조성**: comp1 · modelc · b2o3 는 traj 가 gabia 에 있어 아직 못 봤다.
특히 **b2o3 는 구조적으로 의심할 이유가 있다** — B₂O₃ 도핑이 free-S 12개를 만들어
골격이 원래 계보다 무를 수 있다. 이게 1000 K 에서 드러나면 "+B₂O₃ 전도도 1등" 자체가 흔들린다.
그리고 **옛 캠페인 런 21개는 traj 가 없어 원리적으로 판정 불가**다.

### 5-4. ✅ Li₃P 잔여력 — **Li₃N 같은 파탄이 아니다** (`mlip_engine_probe_li3p.json`)
MP `mp-736`(VASP-PBE 이완, 8원자) 위에서 UMA 힘:
**fmax 0.0205 · frms 0.0145 eV/Å** (Li fmax 0.0205 / P 정확히 0.0000)
⇒ 판정 `agrees` — DFT 최소점이 UMA 최소점이기도 하다.
**Li 금속 계면(Lai 2025 HAML 축) 작업의 1차 관문 통과.**

⚠ **이걸로 Li₃P 에 UMA 를 써도 된다고 결론내면 안 된다**:
- **8원자 고대칭**이라 P 힘은 대칭으로 0 — 사실상 **Li 만** 시험했다.
- **최소점만** 봤다. 곡률·장벽·비평형 배치는 미검증이다.
- **Li₃Nd 에서 UMA 는 c–c 장벽을 1.76배 과대평가**했다(UMA 0.403 vs DFT 0.229, 같은 32원자 셀).
  같은 Li-rich 프닉타이드 족에서 **장벽은 이미 틀린 전례**가 있다.
⇒ 다음 단계는 **rattle 한 Li₃P 구조 10–20개에 QE 단일점**을 찍어 힘 RMSE 를 재는 것이다
(이건 새 DFT 가 필요하다 — 셀이 작아 싸다).

### 5-5. ⬜ 남은 것
- 같은 벤치를 **Cl 포함 계**에서 반복 — PET-MAD 데이터에 Cl-thiophosphate 가 없어
  우리가 DFT 라벨을 만들어야 한다.
- **응력**은 아무것도 재지 않았다 ⇒ cascade 부피 편향(+32.7 %)은 여전히 별건이다.
