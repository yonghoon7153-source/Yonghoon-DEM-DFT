## 2. ★★ 공격 지점 — **내가 스스로 의심하는 것부터** 적는다

### Q1 (최우선) — B 판정의 T1 은 **반증 가능했나, 아니면 항등식이었나?**

T1 은 "② 를 이관한 채 자유도 0 으로 전자 +PTFE 를 예측한다" 로 등록했다.  그런데 이
표현에서 차단 셀(sid 9)은 이온·전자 **같은 셀**이고, PTFE 펠릿의 도체는 양망 모두 SE
매트릭스뿐이다 ⇒ **F_e ≡ F_ion 이 구조적 항등식**이다 (실측 증인: 같은 팔의 SE(log₁₀)가
이온·전자 소수 12자리까지 동일).  그러면 T1 은 사실상

> "실험의 이온 감쇠비 0.272 와 전자 감쇠비 0.400 이 ×3 안에 있는가"

로 환원된다 — 이는 **실험 데이터의 성질**이지 모델의 예측력이 아닐 수 있다.
나는 이 항등식을 **런 전에** freeze 문서 §4 에 등록했지만, 등록했다는 사실이 그것을
검정으로 만들지는 않는다.
**묻는다**: T1 을 (a) 유효한 검정 (b) 항등식이라 무정보 (c) 그 사이 — 로 판정해 달라.
(b) 라면 `CALIB_VALIDATED` 표기는 **T2·T3 만으로** 다시 써야 한다.

### Q2 — ② 동결의 선택 규칙이 **사후**다

★ 그리고 **T1 만 보면 0.12 가 더 좋다** (|Δlog₁₀| 0.026 vs 0.17 의 0.300).  나는 이온

### Q4 — 검사기를 **약화시켰나** (세 건, 전부 이번 주)

**(4a) `code_sha` dirty 정의** — 옛 정의는 `git status --porcelain` 전체(untracked 포함)라,
kgy 의 상주 로컬 디렉터리(`anchor_params/ db/ tools/`)만으로 **모든 생산 런이 `+dirty` →
판정기 무조건 HOLD** 였다 (실측).  새 정의 = tracked 수정 ∨ **scripts/ 안** untracked.
⚠ 논거는 "코드를 못 바꾸는 파일은 재현성 딱지를 못 바꾼다" 인데, **정말 못 바꾸나?**
`PYTHONPATH`·`sitecustomize.py`·`.pth`·데이터 파일을 읽는 코드 경로 등으로 scripts/ 밖
untracked 가 거동을 바꾸는 시나리오가 있는가?  있으면 그 부류를 seed 로 잡아 달라.

**(4b) 프로브 자동 seed** — 규칙 L 의 `set -u` 프로브가 seed 목록을 **손으로** 유지해,
조립 줄에 변수를 넣을 때마다 같이 안 고치면 프로브가 통째로 죽고 그 죽음이 **엉뚱한
오류로 위장**됐다 (`SBRG_FLAG` 8/25 → `L_LEANDEFAULT('None')` · `RQG_FLAG` 8/27 →
`L_EXPECT` 빈 문자열).  ⇒ 조립 줄이 참조하는 변수 중 **러너가 실제로 대입하는 것**만
자동 seed 하도록 고쳤다.  오타 검출력은 실측 확인했다 (`RQG_FLGA` 는 여전히 죽는다).
⚠ 그러나 "러너가 대입한다" 판정이 정규식 `^\s*(local\s+)?[A-Z][A-Z0-9_]*=` 다 —
**조건부 대입**(`[ x ] && VAR=y`)이나 `read VAR` 는 안 잡히고, 그런 변수는 여전히 unbound
로 죽는다 (과잉차단 쪽이라 안전하지만 다음 사람이 또 밟는다).  반대로 이 정규식이 **덮으면
안 되는 것을 덮는** 경우가 있는가?

**(4c) `--step3-require-gpu` 를 `numeric` 으로 등재** — 논거: backend 는 σ 를 안 바꾼다
(같은 행렬·같은 rtol 1e-8) ⇒ 규약 해시에 들어가면 **같은 물리가 두 규약으로 갈린다**.
⚠ 그 전제(GPU/CPU 가 같은 σ 를 낸다)가 이 리포에서 **어디서 검증됐나?**  나는
`step3_sigma.py` docstring 의 선언(*"SAME matrix + tol → SAME φ (backend swap only)"*)에
기대고 있는데, 그것은 선언이지 측정이 아니다.  (리포의 반복 교훈: 선언은 거동이 아니다.)

   출력을 못 본 채 초록이라 가정**했다.  실제로는 그때 이미 빨간불이었고 배터리는

   폐기하고 재실행했다.
3. **기본값 돌연변이가 처음엔 안 물렸다** — `require-gpu` 하위시험 셋이 값을 **명시로**

   부류**이고, 같은 실수를 **두 번** 한 것이다.  계약을 직접 단언해 고쳤다.
4. 러너 편집에서 따옴표를 잘못 다듬어 셸 문법을 깨뜨렸다 (즉시 발견·복구).
