# 같은 수직 압축 응력에 대한 F8·F16 아래판 반응

**첫 5% 초과 양옆의 두 지점에서, 같은 균일 압축을 넣은 관측값은 F8이 F16의 1.414배였다. 실제 수직 응력이 전달한 반력은 각각 3.862배, 3.876배였다.** 두 격자의 입자 배치와 벽이 선택한 하향 노드 집합은 각 팔의 원래 상태로 두었다. 따라서 동일한 응력 입력도 다른 반력을 낼 수 있다는 점을 확인했다. 어느 격자가 실험을 더 잘 나타내는지는 여기서 결정할 수 없다.

| 실제 표본 F8/F16 | 같은 압축을 준 F8/F16 (MPa) | 균일 압축 F8/F16 비 | 원래 수직 응력의 F8/F16 기여 (MPa) | 실제 수직 성분 F8/F16 비 |
|---|---|---:|---|---:|
| 269/538 | 4.101253 / 2.899990 | 1.41423 | 0.042961 / 0.011124 | 3.86205 |
| 270/540 | 4.102903 / 2.900439 | 1.41458 | 0.044882 / 0.011579 | 3.87623 |

균일 압축은 인장 양의 부호로 τyy = −1(모델 응력 단위 1 = 10 MPa)인 가상의 장이다. 표의 출력은 이 장을 **원래 아래판 하향 마스크**에 투영해 얻은 압력이다. 각 팔의 가압 조건을 10 MPa로 바꾼 계산이 아니다. 실제 응력 기여 역시 벽 반력의 한 항이며, 입자 내부 응력의 산술평균과 구별한다.

## 실제 응력의 정상·전단 성분

수직 정상 성분(τyy)의 F8−F16 차이는 초과 직전 +0.03183711 MPa, 직후 +0.03330323 MPa였다. 수직 운동량을 바꾸는 전단 성분(τyx)의 순 차이는 각각 +7.84 × 10⁻¹⁹ MPa와 −1.01 × 10⁻¹⁸ MPa였다. 개별 노드의 전단은 0이 아니다. 예를 들어 F8 270걸음에서 전단 기여의 절댓값 합은 약 0.001369 MPa이지만 부호를 보존하면 거의 전부 상쇄된다. 이 두 성분을 합하면 앞선 응력 전달량이 원 노드별·전체에서 복원된다.

공통 높이 y = 0.15 행만 따로 합산하면, 실제 수직 응력 차이의 98.96%, 98.97%와 단위 압축 전달량 차이의 93.30%, 93.30%가 이 행에 있었다. 원 하향 집합의 공통 물리 입자 ID 7개는 각각 같은 방향으로 기여했다. 두 격자의 노드 개수와 가중치는 다르다. 이 위치별 집계는 반환 후의 보조 대조다.

한 가지 균일장에 같은 상수를 곱하는 설명은 두 팔에서 관측된 실제 반력비를 재현하지 못한다. 두 비율을 나누어 재료 응력의 배수 또는 원인별 기여율을 산출할 근거는 없다. 비균일 응력의 공간 분포와 입자 위치·부피·격자 지지 영역·벽 선택의 상호작용은 여전히 가능하다.
