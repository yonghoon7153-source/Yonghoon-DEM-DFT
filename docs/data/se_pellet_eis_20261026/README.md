## 2. 판독 (읽기만 · `python3 -I docs/data/se_pellet_eis_20261026/read_se_eis.py`)

판독기는 자체 코드다 — `.mpr` 형식은 galvani 0.5.0 (`pip download` sdist sha256 `da0e3b34…` = 10-16 DC 판독과 같은 판) 의 `BioLogic.py` 소스를 **읽어** 확인했고 그 코드는 실행하지 않았다.

모양: 맨 위 주파수 (7 MHz) 는 유도성 (−Im < 0 · L ≈ 0.3–0.5 µH) → −Im 이 0 을 지난 뒤 **단조 증가하는 블로킹 꼬리만** 있다 (반원 · 계단 없음 · 네 파일 모두 −Im 단조).  ⇒ 이 셀은 이온 차단 전극이고, 펠릿의 이온 저항은 꼬리가 실수축을 만나는 점 R 이다 (bulk + 입계 + 접촉 · 리드 — 7 MHz 위라 **bulk 와 입계를 나눌 수 없다**).  지그 · 리드 저항은 빼지 않는다 (10-16 DC 판독과 같은 규약).

- 주 값 = ② 100 Hz 창 (R + L + CPE · |Z| 가중 · 상대 잔차 2.2–2.9 %).  ① 과 ② 는 1.8 % 안에서 같다.  ③ 은 10 % 높다 — 꼬리가 실수축 가까이에서 휘어 직선 외삽이 맞지 않는다 (주 값으로 쓰지 않는다).
- 같은 종류 두 개의 차: 대립 8.9 % · 소립 7.3 % (두께가 같다는 가정 아래의 재현성 — 두께가 다르면 이 차의 일부는 두께).
- 평균 R: 소립 40.32 Ω · 대립 26.55 Ω → **R 비 소립/대립 = 1.52**.  이 비가 σ 비 (대립/소립) 가 되는 것은 두 펠릿의 두께 · 지름이 같을 때뿐이다.

## 3. σ (두께 · 지름이 오면)

σ [mS/cm] = 1000 · L[cm] / (R[Ω] · A[cm²]).  지름 10 mm (1저자 10-27 확인) → A = 0.7854 cm² 이고

  σ [mS/cm] = 0.12732 × L[µm] / R[Ω]   → 두께 100 µm 당: 대립 0.502 · 0.459 · 소립 0.328 · 0.305 mS/cm

같은 0.1 g 이라 두께 차이 = 밀도 차이다: 펠릿 겉보기 밀도 ρ [g/cm³] = 0.1 / (0.7854 × L[cm]) = **1.2732 / L[mm]**.
⇒ 두께를 재면 σ 와 밀도가 함께 나온다.  소립이 덜 치밀하면 (더 두꺼우면) σ 비 (대립/소립) 는 R 비 1.52 보다 작아진다.
두께 예상 (가정 — 겉보기 밀도 1.4–1.8 g/cm³ 이면): L ≈ 0.71–0.91 mm → 측정 분해능 10 µm 의 σ 상대 오차 1.1–1.4 % (두 개 사이 차 7–9 % 보다 작다 · 그 측정기로 충분).  여러 점을 재어 평균한다.

## 4. "소립 펠릿이 부서졌을 수 있다" (1저자 10-26) — EIS 로 본 것

EIS 만으로는 판정할 수 없다.  관찰만 적는다:
1. 두 소립의 R 차 7.3 % = 두 대립의 차 (8.9 %) 와 비슷 — 한 개만 크게 부서진 흔적은 없다 (둘 다 비슷하게 부서졌을 가능성은 남는다).
2. 반원 · 계단 · 두 번째 꼬리가 없다 (−Im 단조).
3. 저주파 용량이 소립에서 약 2 배 (Cs 7.7–9.2 vs 3.1–3.6 µF · CPE Q 3.4e-6 vs 2.4e-6) — 전극과 맞닿은 면적이 더 크다는 쪽 (작은 입자가 전극에 더 잘 붙는 것과 맞는다 · 추정).
4. 소립은 꼬리가 덜 수직이다 (α 0.81 vs 0.84 · 맨 끝 위상 −53 ~ −56° vs −68 ~ −72°) — 저주파에서 꼬리가 실수축 쪽으로 휜다 = 새는 경로나 전극면 불균일 (원인 미확인 · 금 · 표면 · 화학 모두 후보).
5. R 이 소립에서 1.52 배 — 금이 가도 R 이 오르지만, 작은 입자 펠릿의 입계가 많거나 밀도가 낮아도 오른다.  두께 · 무게 (→ 상대 밀도) 없이는 가를 수 없다.
6. 평균 Ewe 가 소립 −0.31 V · 대립 −0.05 V — 차단 전극 셀의 개회로 전압은 열역학적으로 정해지지 않아 판정에 쓰지 않는다.  다만 두 묶음이 다르니 전극 · 지그 구성이 같았는지 확인이 필요하다.

확인 방법 (권고): 펠릿 사진 (금) · 여러 점 두께 · 무게 · 지름 → 상대 밀도 · 같은 펠릿을 다시 눌러 재측정.

## 6. 두께 (1저자 10-28) — 어느 쪽이 소립인지 모른다

1저자 10-28: 한 종류 **0.76** · 다른 종류 **0.64–0.67** · *"소립, 대립 각각의 두께인데 뭐가 뭔지 모르는상태야"*.  단위 = mm 로 읽는다 (측정기 분해능 10 µm · §3 의 예상 0.71–0.91 mm 와 같은 자리) · 0.64–0.67 = 여러 점의 범위로 읽는다 · 한 종류의 두 펠릿은 같은 두께라고 둔다 (가정).  계산 = 이 절의 식 그대로 (메인 컨테이너 10-28 · 반올림 표기).

겉보기 밀도 ρ = 1.2732 / L[mm] (질량 0.1000 g · 지름 10.00 mm 명목값):

| 두께 (mm) | 겉보기 밀도 (g/cm³) | 공극 (TD 1.64) | 공극 (TD 1.86) |
|---|---|---|---|
| 0.76 | 1.675 | −2.2 % | 9.9 % |
| 0.64 | 1.989 | −21.3 % | −7.0 % |
| 0.655 (범위 가운데) | 1.944 | −18.5 % | −4.5 % |
| 0.67 | 1.900 | −15.9 % | −2.2 % |

- TD 1.86 = 결정밀도 계열 (정본 카드 1.86–1.88 · 대조표 `docs/reviews/dem_protocol_gen2_plan_draft_20261014.md` §3-3) · TD 1.64 = 랩 표준값 (`docs/density_generations_20261014.md`).
- **0.64–0.67 펠릿은 TD 1.86 으로도 공극이 음수** → 명목 질량 0.1 g · 지름 10 mm 와 그 두께가 함께 맞을 수 없다.  가장 그럴듯한 것 = 그 펠릿의 실제 질량이 0.1 g 보다 적었다 (공극 0 이어도 0.0935–0.0979 g · 공극 10 % 면 0.084–0.088 g) — 추정 · 펠릿 무게를 다시 재면 가린다.

σ [mS/cm] = 0.12732 × L[µm] / R[Ω] (§3 · R = §2 의 100 Hz 창 · 면적은 다이 면적이라 **질량과 무관**):

| 배정 | 소립 #01 · #02 | 대립 #01 · #02 | 대립 / 소립 (평균) |
|---|---|---|---|
| X — 소립 0.76 · 대립 0.64–0.67 | 2.49 · 2.32 | 3.29 (3.21–3.36) · 3.01 (2.94–3.08) | 1.31 |
| Y — 소립 0.64–0.67 · 대립 0.76 | 2.15 (2.10–2.20) · 2.00 (1.95–2.04) | 3.82 · 3.49 | 1.76 |

- **어느 배정이든 대립 σ > 소립 σ (1.31–1.76 배)** — R 비 1.52 가 두께 비 0.76/0.655 = 1.16 보다 커서 방향이 배정에 걸리지 않는다.  크기 (1.31 ↔ 1.76) 는 배정에 걸린다.
- 한정: R = bulk + 입계 + 전극 접촉 + 리드 (7 MHz 위라 못 나눔 · 리드 안 뺌 → 겉보기 σ · 리드를 빼면 커진다) · 두께 = 꺼낸 뒤 상태 (측정 지그 100–150 MPa 안에서는 조금 얇다 → σ 조금 과대 · 크기 미상) · 한 종류 두 펠릿 같은 두께 가정.
- **진밀도 1.64 검산 (Q7 · 계획서 §12 A2) = 미판별.**  명목값으로는 두 펠릿 다 TD 1.64 에서 공극 < 0 이다.  그러나 A2 는 질량 · 지름 · 두께의 측정구간과 공통 오차를 결과 전에 정하고 그 집합 전체에서 판정하라고 한다 — 펠릿 질량 · 지름을 재지 않았고 오차 모형도 정하지 않았다.  0.76 펠릿은 실제 질량이 0.0979 g 이하 (−2.1 %) 면 TD 1.64 · 공극 0 과 양립한다.
- 가르는 방법: ① 두 펠릿 무게 (저울 마지막 자리까지) ② 지름 (캘리퍼) ③ 어느 쪽인지 = 한 펠릿만 다시 EIS — R 39–42 Ω 이면 소립 · 25–28 Ω 이면 대립 (지그 · 압력이 같을 때 · 두 종류 R 차 52 % 가 두께 차 16 % 보다 커서 가를 수 있다).
- 이 절은 결과 뒤 산술이다 — 등록 판정 · 모델 입력 자격이 아니다 (§5 의 쓰는 곳 대조는 입경 D50 · 밀도를 받은 뒤).
쓰는 곳 = SE 펠릿 σ_ion (모델 입력 σ₀ — 보고 기준 1.5 mS/cm · 솔버 상수 3.0) 과 SE 입경 효과 (`Cronau(r_SE)` = 출처 없는 모델 가정 · `SELF-51`) 의 실측 방향.
