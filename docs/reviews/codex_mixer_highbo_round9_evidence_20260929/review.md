후행 6런은 이미 확인 18런 **뒤**에 있다. 이를 없애도 선행 18런의 계산량은 줄지 않는다.

권고하는 비용표는 단계별 `팔 수 × 예상 실행시간 × NP`, E0/회전 분리, 스모크 의존관계·유휴·불확실성, 그리고 **발사 전 개발 소요와 발사 후 소요의 구분**을 포함한다. 개발이 이미 끝난 뒤의 ETA에 개발 시간을 다시 더하는 이중계상도 피한다.

### 합성 반례 — M을 전혀 읽지 않아도 문턱 선택은 가능하다

```text
확인 soft 저장 프레임 최대 겹침 = 6.2%
M / d / q는 비열람
범위를 6.0%로 고정했다면 OUT_OF_RANGE
QC를 본 다음 6.3%로 정하면 범위 내
```

이 숫자는 **합성 반례이며 6.0/6.3%를 권하는 것이 아니다.** “M-blind니까 결과 전”이라고 하면 이 선택을 막지 못한다. 확인 자료의 접촉 최대값·실패 패턴도 **해당 문턱을 고르는 데 쓰이는 결과 정보**다.

이 때문에 “결과 전”을 다음 문장으로 바꾸길 권고한다.

> “soft 허용 진단 범위와 초과 처리는 확인 18런의 발사 봉인 전에 확정한다. 확인 soft의 M뿐 아니라 겹침·실패·정규화 QC를 보고 범위를 선택하거나 늘리지 않는다. 개발 자료를 활용했다면 자료·열람 시점·근거·개정 이력을 기록하며, 해당 자료는 독립 확인 근거로 전용하지 않는다.”

이 문장이 soft 미정으로 ref-only 개발까지 금지한다는 뜻은 아니다.

### 무엇을 확정해야 하는가

숫자 하나만 채우면 끝나지 않는다.

1. **관측량:** 저장 프레임 전체 최대인지, 입자쌍/벽 분모와 단위, 대상 창·상·위상 불확실성 처리. 원 1% 계약의 정의와 비교 가능한지.
2. **진단 범위와 근거:** 유한 겹침 모델·계측의 적용 한계나 명시적 보수 정책. 과거 E0의 4.7–5.8%를 모두 살리는 값이라는 이유만으로 물리 타당성이 입증되지는 않는다.
3. **경계 비교:** 부동소수 여유·불명/비유한·원자료 부족 처리.
4. **초과 시 권위:** 원 1%는 NOT_MET로 보존, 추가 진단 범위도 넘으면 OUT_OF_RANGE. q를 공식 확인 판정에 쓰지 않음.
5. **후속 처리:** 중단/보존/보고 범위, terminal 상태와 불완전 paired block 처리. 범위 초과는 같은 조건 재시도로 지워질 TECH 사유가 아니다.
