## §2 의존 순서 (제안 — 사용자 결정)

**C1-core → C6 → C3 (P0) → C5 → C4.** E3b 는 C1-E3b 와 따로.

- C1-core 가 먼저인 이유: P0 은 자료를 처음 여는 단계인데, 어느 시트 · 셀 · step 이 무엇인지 (①③) 와 참값의 정의 (②) 가 고정돼 있지 않으면 P0 의
  닫힌 구간식이 무엇을 계산하는지부터 정해지지 않는다.
- C6 이 P0 앞인 이유: P0 도 자료를 읽는 코드 실행이다 — 실행 환경의 판을 먼저 고정해야 P0 의 결과가 어느 환경의 것인지 말할 수 있다. (부속 A §3-1 은
  "실행 승인 때" 라고만 적었다 — 이 순서는 우리 제안이다.)
- C5 (비용 측정) 는 맞춤이므로 P0 뒤 · C4 (본 실행) 앞.
