1. 봉인된 `B_ch`의 N·ID·중앙 순위를 먼저 고정한다. 실패를 지워 분모를 바꾸지 않는다.
2. 유효 old가 확정된 행의 new 미정을 A-4의 0/+∞ 경계로 계산한다.
3. 수치 미정과 프로그래밍/입력 계약 오류를 분리하고 예외 종류·사유를 남긴다. 계약 오류는 공식 판정 중단, 등록된 수치 미정은 경계 계산이다.

## 3. §4-1·4-4 — 전환과 oracle

### 3.1 clamp 제거 no-op: CONFIRMED, 조건부 산술 명제

유한 양의 반지름·유효 면적을 전제하면:

- `a_contact ≤ r_min`: clamp 전후의 `a_eff`가 같다.
- `a_contact > r_min`: clamp하면 ψ=0. clamp를 빼도 `max(1-a/r_min,0)^1.5=0`이다.
- 두 경우 모두 같은 floor 분기로 간다. 바뀐 `a_eff`를 분모에 쓰는 코드는 **활성 분기에서만** 실행된다.
- R_bulk·R_Maxwell·면적 진단 필드는 이 clamp 변수로 바뀌지 않는다.

실제 Physics 양팔·다채널 대조 **1,926개**, 반환 간선 차이 **0**. clamp를 유지한 채 `max(...,0)`만 빼는 것도 이 유효 영역에서는 `1-a_eff/r_min ≥ 0`이어서 동일했다.

따라서 이 두 **동치 변이**를 빨갛게 만들기 위한 인위적인 검사는 필요 없다. NaN·음의 반지름·오버플로 입력까지의 전역 정리는 아니다. Hertzian은 애초 이 분기를 타지 않는다.

### 3.2 ψ oracle: 기존 두 구멍은 닫혔지만 재료계수 oracle은 아니다

| 변이 | 전체 감사 결과 | 판정 |
|---|---|---|
| floor `1e-4 → 0` | 15/18, ⑦d·⑦f·⑦i FAIL | 이전 사각지대 개선 CONFIRMED |
| ψ 지수 `1.5 → 1` | 15/18, 같은 3개 FAIL | 개선 CONFIRMED |
| clamp 제거 | 18/18 | 유효 영역의 동치 변이 |
| max 제거, clamp 유지 | 18/18 | 유효 영역의 동치 변이 |
| `r_min_real=min(r1,r2) → r1` | 18/18 | **유해 변이 누락** |
| `sigma_rel_contact=min(...) → sigma_rel_1` | 18/18 | **유해 변이 누락** |
| `psi > floor → psi < floor` | ZeroDivisionError로 검사 중단 | 초록 아님; 표적 실패와 harness 오류는 구별 |
| `> → >=` | 18/18 | 정확한 경계 등호의 판별력은 입증되지 않음 |

마지막 행은 "유해한 실물 반례를 확보했다"는 finding으로 세지 않는다. 표현 가능한 입력에서 ψ가 정확히 floor와 같은 사례까지 확인한 것은 아니다.

**R_Maxwell 자기참조 질문의 답:** ψ 축에 한정하면 독립성 개선은 진짜다. R_Maxwell 필드만 두 배로 바꾸면 oracle에서 old/new 각각 **8건 불일치**가 생긴다. 그러나 열의 조화평균 `k_weight → 1`을 식 전체에 일관되게 적용하면 oracle의 `bad_div=bad_mul=bad_floor=0`이다. **ψ 배치가 맞는 것과 재료계수가 맞는 것은 서로 다른 주장**이다.

### P2-AREA5-05 — 기본값 회귀의 기준이 도입 전이 아니라 움직이는 HEAD다

이번 checkout에서 working source와 `git show HEAD:...`의 SHA256은 동일하다:


따라서 ⑦f는 커밋 후 "도입 전과 같다"를 고정하지 않는다. **커밋할 때 기준이 함께 이동한다.**

열 AM–SE 조화평균을 1로 바꾼 소스를 "새 HEAD에도 커밋됐음"으로 모사하면 실제 감사 **18/18, rc=0**이다. 같은 활성 fixture의 old R_total은 **5.812108579096786 → 9.8929507729307**로 바뀌는데도 그렇다.

- **현재 기본값 보존:** 시험한 영역에서 CONFIRMED.

처방: pre-flag 소스의 **고정 전체 SHA** 또는 독립적으로 봉인한 기대값을 기준으로 삼는다. 동결 재료·분기·상 조합을 포함하고, 기준을 못 읽으면 실패한다.

### P2-AREA5-06 — 한 방향의 열 fixture로 기하·전자 분기 동결을 보증하지 못한다

### P2-AREA5-07 — 곱셈판도 finite floor에서는 불연속이다

⑦h가 실제로 검사하는 것은 "이산 스윕의 마지막 양수가 legacy보다 작다"이지 연속성이 아니다. floor가 유한한 1e-4로 남으므로 cutoff 직전 극한은

실제 함수, r1=r2=1 µm, native 면적으로 cutoff 인접 float를 구성한 결과:
