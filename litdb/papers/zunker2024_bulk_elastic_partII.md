## 1. 한 줄 요약

Part I 의 MDR 접촉모델(탄성·완전소성·점착·다중이웃)에 **세 번째 구간 = 벌크탄성** 을 얹는다.
핵심은 두 가지: **(a) 발동 기준** — Voronoï 셀 계산(Harthong 2009)이나 힘 부등식(Giannis 2021) 대신
**입자의 남은 자유표면적 비 `A_free/A_tot < ψ_b`** 라는 값싸고 물리적인 판정을 제안하고,
**(b) 힘의 형태** — 변위증분을 **면적가중 평균 표면변위 `d δ̄_o`(=벌크분)** 와 **그 편차(=MDR 분)** 로
쪼개고, 선형탄성 `tr(ε̄) = tr(σ̄)/3κ` 에서 **`dF_Bulk,i = (A_con/V)·κ·dδ̄_o·A_C,i`** 를 유도한다.
**이 처방은 Part I 과 독립적이라 어떤 접촉모델에도 얹을 수 있다** (저자 명시).

## 4. 방법 ★ — 벌크탄성을 어떻게 유도하나

### 4-1. 왜 새 기준이 필요했나 (§1 선행연구 정리 — 우리 지도에 그대로 유용)

| 선행 | 벌크구간 처리 | 발동 판정 | 한계 (저자 지적) |
|---|---|---|---|
| **Harthong 2009** | 경험적 | **Voronoï 셀** | 계산비용 큼(대규모 불가) + 강소성 한정(탄성 부피변화 미고려) |
| **Frenning 2013/2015** | 기하·역학적으로 건전, **경험 파라미터 1개** | 단순 기하 | **삼축압밀 한 가지 하중만** 처리 가능 |
| **Garner 2018** | **전면 경험적**(다수 피팅함수) | — | 재료마다 재보정 + **배위수 고정** ⇒ 모든 접촉이 같은 시점에 발동 |
| **Giannis 2021a** | 경험 스프링상수 | **힘 부등식** | 재보정 필요; 다중이웃은 σ 트레이스(Giannis 2021b) |
| **★ Zunker Part II** | **선형탄성에서 유도, 물성은 κ 하나** | **`A_free/A_tot`** | ψ_b 값이 유일(비유일)한 자유도 |

### 4-2. 유도 (§4.3 — 6줄로 재구성)

```
tr(∇u) = tr(σ̄)/(3κ)                                              … (20) 선형탄성 + 소성 등적
∇u = (1/V) ∫_S n ⊗ u dS                                          … (21)
A_free/A_tot ≪ 1 이면  d(∇u) ≈ (1/V) Σᵢ (A_C,i · nᵢ ⊗ dδ_o,i)     … (22)  ← 자유표면 무시 가능
tr(v⊗w)=v·w 를 쓰면  (A_con/V)·[ (1/A_con) Σᵢ (A_C,i nᵢ·dδ_o,i) ] = tr(dσ̄)/(3κ)   … (24)
대괄호 안 = 면적가중 평균 표면변위 증분  dδ̄_o                       … (25)
⇒ tr(dσ̄)/3 = (A_con/V)·κ·dδ̄_o                                    … (26)
⇒ dF_Bulk,i = [tr(dσ̄)/3]·A_C,i = (A_con/V)·κ·dδ̄_o·A_C,i          … (27) ★ 최종
```

**변위 분해** (eq 17, 19):
```
δ_o = δ_o,MDR + δ_o,Bulk
  A_free/A_tot ≥ ψ_b :  dδ_o,MDR = dδ_o          , dδ_o,Bulk = 0
  그 외              :  dδ_o,MDR = dδ_o − dδ̄_o   , dδ_o,Bulk = dδ̄_o
F = F_MDR + F_Bulk                                                … (18)
```
★ **중첩이 성립하는 이유** (§4 서두): 벌크응답은 **구형(정수압) 응력상태만** 건드리고, **항복을
지배하는 편차응력은 안 건드린다**.  ⇒ 탄소성 해와 벌크탄성 해를 그냥 더할 수 있다.
★ **부수 결과**: 삼축압밀에서 **모든 변위가 평균과 같으므로 편차 = 0** ⇒ **벌크구간에 들어가면 소성
누적이 멈춘다** (§5.1) — FEM 과 일치하는 예측.

### 4-3. 면적·부피 부기 (§4.3.1–4.3.2) — ★ 우리 규약과 직접 비교되는 곳

```
A_C,i  = π(2 δᵢ R − δᵢ²) + c_A,i                                  … (30)   (δ_MDR 아니라 δ 사용)
A_con  = Σᵢ A_C,i                                                 … (31)
A_tot  = 4πR² − 2π Σᵢ (δ_max,MDR,i + δ_o,Bulk,i) R + A_con        … (32)
A_free = A_tot − A_con                                            … (33)
V_geo  = (4/3)πR³ − Σᵢ (π/3) δᵢ² [3R − δᵢ]                        … (29)
```
- `A_tot` = "완전한 구 표면 − 잘려나간 구관 표면 + 접촉면적" — **부피식 (29) 의 면적 판(version)**.
- `V_geo` 는 **힘이 필요없다** → 전방재하·벌크구간에서 쓰기 좋다.  Part I 의 `V = V_o(1+tr ε̄)` (힘 필요,
  제하 포함 전 구간 유효) 와 **역할 분담**.  App B 는 두 식의 FEM 대조를 보여주고 **품질이 비슷**하다고 결론.
- ⚠ **`A_C` 정의가 Part I 과 미묘하게 다르다**: 벌크구간에서는 `δ_MDR` 이 아니라 **`δ`(전체 겉보기겹침)**
  를 쓴다 → 그래서 벌크구간에서도 면적이 계속 자란다 (δ_o 증가 때문; R 은 동결).

## 6. Post-processing ★

- **무엇**: 접촉당 `F, A_C, p̄`, 입자당 `V`, 그리고 **`A_free/A_tot`(구속비)** — ★ 마지막 것이 신규 관측량.
- **도구**: Abaqus 3D (C3D10, 1/8 구 + 대칭 BC) + 자체 수치구현 (App C 의사코드).
- **수치화**: Part I 과 같은 무차원 축.  구속비는 그 자체로 0–1 무차원.
- **구현 순서 (App C — ★ 이식 난이도의 핵심)**:
  ```
  Main:
    δ^{n+1} = δ^n + Δδ
    [Δδ̄_o, A_C, A_con, A_tot, A_free, V_geo] = calcBulkItems(...)   ← ★ 접촉 루프 "밖"에서 먼저
    for i = 1..N:                                                    ← 그 다음 접촉 루프
        구속비로 Δδ 를 MDR/Bulk 로 분배
        F_MDR = calcMDRforce(...)
        F_Bulk = (A_con/V_geo)·δ_o,Bulk,i·κ·A_C,i
        F_i = F_MDR + F_Bulk
    [R^{n+1}, V^{n+1}] = findUpdatedRadiusAndVol(...)                ← 다시 접촉 루프 밖
  ```
  ⇒ **한 타임스텝에 "입자-집계 → 접촉-루프 → 입자-집계" 3패스**가 필요하다.  일반 DEM 의 단일 pairwise
  패스와 구조가 다르다 (③ §9 이식 논의).

| R 성장 | 벌크구간에서 **동결** | 없음 | ★ 우리 ε_sphere 음수(dense pure-SE) 와 **같은 붕괴점**을 저자도 인정하고 회피 |
| 부피 | `V_geo` (힘 무관) ↔ `V=V_o(1+trε̄)` (힘 필요) 2종 | `ε_sphere` (= ΣV_o) / `ε_union` | 우리 ε_sphere ≈ 그들 `V=V_o(1+trε̄)` 의 tr ε̄→0 극한 |
| 2차 접촉 | **자동 생성·진화·잔류힘** | ✗ | 우리가 못 하는 것 |
| 원거리 응력 결합 | ❌ 미고려 (저자 인정, Fig 5c 불일치의 원인) | ✗ | **양쪽 다 없음** (Varkey 의 F_mc 가 이 자리를 평균장으로 채움) |
| 파괴 | ❌ | ✅ Auerbach | 우리 우위 |
| 전달 σ | ❌ | ✅ 삼중항 | 우리 우위 |

### 7-2. ★★ **Varkey F_mc ↔ Zunker Bulk — 같은 증상, 다른 처방** (사용자 질문 ⑤)

| 축 | **Varkey 2026** (`F_mc`, Giannis 계열) | **Zunker Part II** (`F_Bulk`) |
|---|---|---|
| 무엇을 고치나 | 조밀 영역(ρ>0.7)에서 접촉모델이 **과연**해 응력이 부족 | 공극이 사라진 뒤 **급격한 강성 상승**을 못 냄 |
| 물리 서사 | **Poisson 구속** — 이웃 접촉이 만든 입자 평균압이 이 접촉의 힘을 올림 | **공극 소멸** — 입자가 연속체 요소가 되어 **벌크탄성률 κ** 가 살아남 |
| 수식 | `F_mc = β·ν·a_ij·P_ij`, `P_ij = (tr σ_i + tr σ_j)/3`, `σ^p = (1/V^p) Σ lⁿ⊗fⁿ` | `dF_Bulk,i = (A_con/V)·κ·dδ̄_o·A_C,i` |
| 유도 근거 | **평균장 근사** + 경험 상수 **β = 0.5** | **선형탄성 + 표면적분 이산화** (평균장 아님) |
| 자유 파라미터 | **β** (1개) | **ψ_b** (1개) |
| 발동 | **없음** — 항상 켜져 있고 고밀도에서 저절로 커짐 (연속) | **문턱 스위치** — `A_free/A_tot < ψ_b` (불연속 전환) |
| 필요 물성 | ν (+β) | **κ** |
| 다중이웃을 몇 개 기구로 다루나 | **1개** (F_mc 가 다 함) | **2개** — R 성장(기하·부피보존) + 벌크(공극소멸).  ★ Varkey 의 F_mc 가 하는 일의 **상당부분을 Zunker 는 R 성장으로 이미 처리**하고, 벌크는 그 *뒤* 단계다 |
| 신규 접촉 생성 | ❌ | ✅ |
| 검증 | 압밀 곡선(거시) | **단일입자 FEM 4종 접촉**(미시, 접촉당) |

★ **우리에게 주는 판정**:
1. **두 처방은 배타적이지 않다.**  Zunker 의 2단 구조(R 성장 = 기하 다중이웃 / 벌크 = 공극소멸)가
   **더 분해능이 높다** — Varkey 는 둘을 β 하나에 럼핑한다.
2. **우리 18× 연화는 이 둘 중 어느 쪽도 아니다.**  우리는 **저압에서 겹침을 늘리려고** 전 구간을 무르게
   했고, 그들은 **고압에서 뻣뻣해지는 것을 되살리려** 한다.  ⇒ 우리 연화는 **압력 전 구간에 걸친 상수 배율**
   이고 그들의 보정은 **밀도에 게이팅**돼 있다.  **연화를 그들 처방으로 대체하려면 압력-의존성이 맞는지
   부터 봐야 한다** (우리 4압력 Heckel 이 그 시험대).
3. **κ 를 우리가 이미 갖고 있다**: DFT EOS `B₀ = 26.23 GPa`.  ⇒ `F_Bulk` 는 **추가 보정 없이** 우리 값으로
   평가 가능하다 (ψ_b 만 정하면 된다).

### 7-3. ⚠ ψ_b 의 정직한 평가 (이 시리즈 "무보정" 주장의 최대 약점)

- Part II §4.1: *"No precise value of ψ_b exists, however ψ_b around 0.08 gives reasonable results."*
- Part II App A: **0.08 이 0.28·0.48 보다 낫다**는 근거는 **소성변위(제하 후 잔류) 예측 정확도**다.
  ψ_b 가 크면 변위가 벌크로 **조기 배분**돼 MDR 소성누적을 갉아먹는다 → 잔류변위를 못 맞춘다.
- ③ (2025 PowderTech) §7.1: **`ψ_b = 0.5`** — *"The value for ψ_b is tuned to trigger the high confinement
  bulk response stiffening in alignment with the experimental results."*  MPFEM 대조(§4)도 **0.5**.
- ⇒ ★ **같은 저자가 6.25배 다른 값을 쓰고, 두 번째는 명시적으로 실험에 맞춘 튜닝이다.**
  Part II 의 "물리적으로 동기부여됨"은 사실이지만 **"보정 불필요"는 사실이 아니다.**
  ⚠ 다만 **공정하게**: ψ_b 는 **차원 없는 기하 문턱**이라 재료가 바뀌어도 옮겨갈 여지가 있고, 무엇보다
  **E 를 18배 바꾸는 것과 같은 등급의 자유도는 아니다** (전자는 물성 자체를 왜곡, 후자는 전이 시점만 옮김).
  우리 문서에 쓸 때 **"1개 무차원 문턱 vs 물성 18× 왜곡"** 으로 대비할 것.

## 8. 적용 인사이트

- ① ★★★ **`A_free/A_tot` 를 우리 DEM 후처리에 즉시 추가**.  LIGGGHTS 덤프만 있으면 계산된다 —
  입자별 `A_tot = 4πR² − 2πΣδᵢR + ΣA_C,i`, `A_free = A_tot − A_con`.  **DEM 재실행 불필요.**
  용도 3가지: (i) 우리 침대가 **벌크탄성 구간에 들어갔는지** 판정 → 300 MPa 에서 SE 가 층(3) 물리를
  요구하는지 정량 답; (ii) **coverage 의 자연스러운 분모** — 우리 `coverage_AM_*` 는 AM 표면 기준인데,
  `A_con/A_tot` 는 **SE 자신의 표면이 얼마나 소진됐나** 라는 다른 축; (iii) MPM scaffold 의 **공극 도달성
  (d_h/dx 트랙)** 과 상관 볼 것 — 둘 다 "재료가 흘러들어갈 곳이 남았나"를 재는 양이다.
- ② ★★ **F_Bulk 항을 우리 DEM 에 얹는 저비용 시험**: `dF_Bulk = (A_con/V_geo)·B₀·dδ̄_o·A_C`.
  우리 B₀ = 26.23 GPa 를 그대로 쓰고 ψ_b 만 {0.08, 0.28, 0.5} 스윕 → **18× 연화 없이도 고압 응력이
  올라오는지** 를 4압력 Heckel 위에서 본다.  ⚠ 단 이것만으로는 **저압 겹침 부족**이 안 풀린다
  (연화는 저압에서도 필요) — 그래서 **①항복캡(Part I) + ②벌크(Part II) 를 같이 넣어야** 시험이 성립한다.
- ③ ★ **"벌크구간에서 면적 성장이 정체"(Fig 2b)** 는 **우리 Stage-E 면적 캡의 독립 근거**다.
  우리 5-regime 은 `min(A_tabor, A_volume, A_geom)` 으로 상한을 씌우는데, 그 물리적 이유가
  **"흘러들어갈 공극이 없다"** 라는 것을 이 FEM 이 직접 보여준다.
- ④ ★ **소성 정지 판정**: 벌크구간에서 편차변위 = 0 → 소성 누적 멈춤.  우리 MPM 의 Σdg(누적소성변형)
  가 고밀도에서 포화하는지 대조하면 **frame[4] 교차검증 1건**이 된다 (비용 0, 기존 데이터 재분석).
- ⑤ ⚠ **die 2차 접촉의 원거리 인장응력 효과**(Fig 5c) 는 우리에게도 있다 — 하중을 지지하는 강체 AM
  골격이 **주변 SE 를 조기 항복**시킬 것이다.  우리 AM-shielding 서사(SE overlap 1.75 % vs pure-SE 12 %)와
  **부호가 반대인 효과**라 순수 상쇄가 아니다.  ⛔ 정량화 전 인용 금지.

## 9. 인용 가능 문장

- "Zunker & Kamrin (JMPS 2024, Part II) trigger the bulk-elastic stiffening of a compacting particle from a
  purely geometric confinement measure — the fraction of the particle surface not involved in any contact,
  `A_free/A_tot` — replacing the Voronoï-cell computation of Harthong et al. and the force-based inequalities
  of Giannis et al.; the resulting force requires a single material property, the bulk modulus."
- "The same threshold (ψ_b = 0.08) predicts bulk onset at δ_o/R_o = 0.21 for triaxial and 0.49 for die
  compaction, i.e. the criterion is loading-agnostic even though the onset displacement is not."
- "Because a bulk-elastic response perturbs only the spherical part of the stress, it superposes on any
  deviatoric elastic-plastic contact solution — the treatment is independent of the underlying contact model."

## 10. 주의 / 한계 (over-claim 방지)

- ⚠⚠ **ψ_b 는 자유변수다.**  저자 스스로 "정확한 값 없음"이라 쓰고, ③ 에서 **0.08 → 0.5** 로 바꾼다.
  이 시리즈를 "무보정"이라고 쓰면 **틀린 인용**이 된다.
- ⚠ **DEM 런 0건.**  검증은 **단일 입자 vs 강체 평판**뿐이다.  다체 검증은 ③.
- ⚠ **E/Y = 20, ν = 0.3 한 조합만** 시험했다.  Part I 처럼 재료 스윕이 없다 → **ψ_b 가 E/Y 에 의존하는지
  미검증** (우리 LPSCl E/Y ≈ 74–442 는 이 값에서 멀다).
- ⚠ **원거리(far-field) 응력 결합 미고려** — 저자가 Fig 5c 불일치의 원인으로 명시하고 향후과제로 남김.
  ⇒ 비대칭·이방 하중에서는 평균압 예측이 나빠진다.  "실제 응용은 더 등방적일 것"이라는 저자의 방어는
  **우리 AM-SE 복합양극에는 잘 안 맞는다**(강체 AM 골격 = 강한 비등방 구속).
- ⚠ **제하 시 면적 급락**(Fig 4b)은 **모델 인공물**이다 — 저자 인정.  면적 기반 전달량(우리 σ)을 이
  모델에서 뽑으면 제하 구간에서 비물리적 점프가 생긴다.
- ⚠ **eq (13) 오타** (−1.1 vs −4.4).  구현 시 eq (5)/App C 를 따를 것.
- ⚠ **파괴·마찰·회전·전단벌크 없음.**  저자가 "bulk **shear** response (μ 기반)"를 향후과제로 명시.
- ⚠ **소재 무관 이론** — 황화물/배터리 수치 0.
