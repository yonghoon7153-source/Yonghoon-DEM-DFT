# 세미나 v3 재확인 증거 묶음

먼저 `codex_review_seminar_v3_20261013.md`를 읽으세요. 통합 판정문이 `notes/`의 개별 편집안보다 우선합니다. 원 발표물은 수정하지 않았습니다.

- `v3/`: 사용자가 제공한 v3 ZIP의 내용 그대로. PPT/PDF와 렌더는 **검토 대상**이지 수정 완료본이 아닙니다.
- `evidence/`: ZIP 목록/해시, PPT 실제 본문/노트/좌표, PDF 텍스트, 새 동일성·산술·인용 패턴 검사 결과.
- `notes/`: 두 영역으로 나눈 시각 검토 상세. 통합 판정문 작성 중 교차 수정한 보조 노트입니다.
- `inspect_versions.py`: 원 v2/v3 ZIP을 비교·추출하는 도구. 원 첨부 ZIP과 이전 검토 자료가 있는 기존 작업 경로 기준입니다.
- `verify_followup.py`: 본문 동일성·저장 수치·상수/CSV·리터럴 금지 패턴 재검사. 원 다운로드 파일 및 v2 추출본을 요구하므로 그대로 복사한 ZIP만으로 단독 재실행된다고 주장하지 않습니다.
- 형제 폴더 `seminar_review_20261013/`: 이전 통합 판정문, 읽기 전용 산술 스크립트, 고정 근거 `sources/`와 `evidence/`. 초기 PPT/PDF/렌더는 현재 발표물과 동일하므로 중복 수록하지 않았습니다.

자체 완결적인 저장자료 산술 재계산은 압축 해제 루트에서 다음과 같습니다. 표준 Python 라이브러리만 사용하며 솔버·배치 러너는 실행하지 않습니다.

```text
python -X utf8 -B seminar_review_20261013/verify_results.py
```

원 10-13 템플릿은 사용자 묶음에도 없으며, 이 묶음에도 없습니다. 네이티브 PowerPoint 렌더와 실제 투영 시험도 하지 않았습니다.

`bundle_manifest.json`에는 포장된 파일의 SHA-256이 있습니다. 감사 기록의 과거 상태/원자료 숫자를 발표에 재인용할 허가로 읽으면 안 됩니다. 발표용 인용 범위는 통합 판정문을 따릅니다.
