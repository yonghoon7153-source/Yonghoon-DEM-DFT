## 다음 수정과 자격

다음 개발 대상은 아래판 바로 위 입자 응력과 운동량이 격자 폭에 따라 어느 깊이까지 판 반력에 들어가는지다. 저장한 8칸 270걸음에서 폭을 바꿀 때의 +0.019610 MPa 가운데 +0.018442 MPa가 미세 격자 폭의 2–3배 높이에서 왔다. 기존 합성 평벽과 네 저장 장면을 기준으로 벽의 물리적 위치를 사용하는 경계 처리 후보를 검토한다. 후보는 (1) 떨어지며 접근하지 않는 입자에 생긴 판 충격량, (2) 압축 시 판 충격량과 입자·격자의 수직 운동량 수지, (3) 일정 응력과 깊이 방향 응력 구배의 격자 민감도를 차례로 확인한다. 보고 압력에 상수를 곱해 수렴선을 맞추는 방식은 이 검사를 충족하지 않는다.

후보의 합성 시험 뒤 같은 변위의 짧은 대조를 먼저 수행한다. 이후 같은 후보의 완주 곡선 F8–F16 및 F12–F24에 원래 분모와 5% 기준을 적용한다. 기존 F8–F16 완주 최대 차 80.8586%, 같은 커널 F12–F24 미측정. U6(c) ⑥과 단계 3·3D 진입은 계속 보류한다.
