## 2. 명령 순서 (한 편 · 단계 이름 = §0)

> 돌리는 자리 = **리포 밖 작업 폴더** (이 폴더의 `tools/` 와 편 폴더를 복사해 간다).  리포 안에서 렌더하면 mp4 · 점검 그림이 작업 트리에 생긴다 (`.gitignore` 가 막지만 자리를 섞지 않는다).  글꼴 = `AVI_FONT_DIR=<Pretendard 폴더>` (없으면 Noto CJK 대체 글꼴 · 글자 폭이 달라 화면 자리가 바뀐다).

1. **대본 · 화면 (S2 → S3 · S4)** — `build_scenes.py` 를 고친다 (말 = `say` 에 읽는 꼴 · 화면 = `text` 와 개체 · 숫자마다 `src(...)` 출처 줄).  `python3 -I ep01_mixer/build_scenes.py` 는 50 음절 넘는 문장 · `say` 안의 기호 · 24 자 넘는 자막 · '처음 / 최초 / 가장 먼저' 를 경고한다.  쓴 뒤 마무리하지 않고 독립 조수가 내부 반박 리뷰 (판본 동결 = 읽기 전용 사본 + 해시 · 기승전결 지도 · 전환 판단표 · 편 폴더 review/ · 스킬 §4-1) → 고침 → P1 0 · P2 처분까지 짧은 재리뷰 → ★ 1저자 대본 승인 (사본 해시 · 글자 예산 고정).  승인 뒤 대본이 바뀌면 (S11 · 끝말 · S9b 뒤) 같은 재리뷰를 다시 한다.
2. **무음 미리보기 (S5)** — `python3 -I tools/avi.py render ep01_mixer` → `preview_silent.mp4`.  시간은 말 빠르기 모형 (아래 §4) 으로 잡는다.  장면 사진만 빨리 보려면 `python3 -I tools/avi.py stills ep01_mixer --shots` (장면마다 한 장 → `qa/stills/sheet_*.jpg`).  0.5 s 장면 점검 · 전환 판단표를 렌더 시각으로 다시 (스킬 §8).
3. **목소리 고르기 (S6 · 공개판 편 · 새 목소리일 때만)** — `voice_audition.txt` 10 줄을 후보 목소리로 생성 → `python3 -I tools/avi.py audio-qc ep01_mixer --wav ep01_mixer/audio_in/audition_<목소리>.wav` 로 빠르기 · 쉼 · 끝 억양을 본다.
4. **TTS 생성 (S6)** — Typecast 에 `tts_typecast.tsv` 의 '문장 (읽는 꼴)' 칸을 한 줄씩 넣고, 줄마다 빠르기 · 쉼 · 감정을 표대로 맞춘다 (감정 프리셋 이름은 목소리마다 다르다 — 가장 가까운 것).  장면 하나를 한 파일로 받는다.  **11-25 부터는 아래 '음성 단계 자동 판단'** (`avi.py voice-auto` 가 Typecast API 로 문장마다 만든다 · 손으로 넣는 이 길은 예비).  ⚠ 여기 3–4 는 **공개판 편만** — 내부 자료 편 = 로컬 TTS: `<MeloTTS venv>/bin/python -I tools/avi_melo.py lines <편> --out <폴더> --only <문장 id …> --speed 1.2 --no-split` (바깥 호출 0 · 예비 = `tools/avi_xtts.py` · 모델 파일 11-25 지움 = 쓰려면 다시 받음).
5. **음성 넣기 (S6)** — 파일을 `ep01_mixer/audio_in/` 에 넣고 `python3 -I tools/avi.py audio-prep ep01_mixer` → 문장 경계를 찾아 문장 사이 쉼을 표의 값으로 다시 맞추고 (`--keep-pauses` 면 TTS 쉼 그대로) −14 LUFS · 참 최고점 −1.5 dBTP 로 맞춘다.  음악을 쓰면 `--bgm 음악.wav --bgm-lufs -28` (레퍼런스: 목소리가 음악보다 13–14 LU 크고 덕킹 없음).
6. **음성 QC (S7)** — `python3 -I tools/avi.py audio-qc ep01_mixer` → 편 폴더의 audio/audio_qc.md (리포 밖 · 알림이 있으면 그 문장만 다시 생성).
7. **최종 렌더 (S8)** — `python3 -I tools/avi.py render ep01_mixer --out ep01_final.mp4 --audio ep01_mixer/audio/mix.wav --timing ep01_mixer/audio/timing.json` (음악 없으면 `narration.wav`).  자막 · 화면 쌓기가 실제 음성 시간에 다시 맞춰진다.  `ep01.srt` 도 다시 쓴다.  0.5 s 장면 점검 + 10 fps 필름 · 전환 판단표를 실제 렌더 시각으로 다시.
8. **썸네일 (S8)** — `python3 -I tools/avi.py thumb ep01_mixer` (끝 화면의 물체 그림 `assets/powder_obj.png` 도 없으면 함께 만든다 · `--obj` = 다시 만듦 · 그림자는 그림 가장자리 40 px 에서 0 으로 사라지게 해 잘린 선이 안 보인다).
9. **QC · 기준표 (S8 · S9)** — `qc.md` 표를 다시 확인 (숫자 ↔ 출처 · 화면 금지 문장 · 공저 밝힘).  철회값 = `python3 -I tools/ban_sweep_files.py <파일 …>` (리포 `docs/reviews/claims.json` 을 읽기만 · 다른 자리면 `AVI_CLAIMS_JSON`).
10. **최종 흐름 검수 (S9b)** — 이 편을 처음 보는 새 독립 조수가 흐름만 본다 (입력 = 장면 표본 · 자막 · timeline · 장면표 · 빈 화면 목록 · 장면 경계 앞뒤 0.5 s 칸 · 음성으로 잰 쉼) → 편 폴더 review/final_flow_review.md · 판정은 보고만 · 고칠지는 1저자.
11. **검토 후보 (S10)** — 이 컴퓨터만 · `--internal` 꾸러미 · 목소리 그대로 (§6) → 1저자에게 들을 MP4 sha256 을 드린다.
12. **1저자 듣기 · 승인 둘 (S11)** — `/videos` (이 컴퓨터) 에서 듣고 점수 · 번호로 답 → 바뀐 문장만 `build_scenes.py` 에서 고쳐 (대본이 바뀌면 S4 재리뷰 다시) `avi.py voice-auto` (원장이 문맥 해시로 그 문장 + 앞뒤까지 다시 만든다 · 멀쩡한 판은 그대로) → S6–S10 → 승인 ① (들은 MP4 sha256 + 공개 부속물 목록) → 같은 MP4 · 같은 빌드로 공개판 꾸러미 (§6) → 승인 ② (시청자 대본 · ZIP sha256) → 등록 · 바깥 공개 (1저자).

### 음성 단계 자동 판단 (`avi.py voice-auto` · 1저자 11-25)

1저자 11-25 *"이런 권고안들은 저절로 판단되게 백그라운드 에이전트로"* — 음성 단계 (TTS → 점검 → 걸린 문장 다시) 는 백그라운드 조수가 규칙대로 스스로 정하고 끝에 한 번 보고한다 (정본 = 스킬 §7-1).  `python3 -I tools/avi.py voice-auto ep01_mixer` = 미리 보기 (API 호출 0 · 파일 안 씀 · 만들 줄 · 글자 · 예산 · 지금 이음매) · `--run` = 실제로 만든다 (`nice -n 19` · 기본 `--rounds 2 --takes 2 --budget-x 3`).  **공개판 편만** (내부 자료 편 = 로컬 TTS · Typecast 도구가 폴더 · episode · 제목 이름으로 거부) · 목소리 = Typecast 문정 · **smart** (앞뒤 문장을 같이 보냄) · 빠르기 **1.0** 한 값 · 톤 (프리셋) 을 섞지 않음 · 길이 = S0 편별 (ep01 = 상관없음 예외 · 정한 길이를 넘으면 대본을 줄이지 말고 1저자에게) · 원장 (audio_in 의 typecast_ledger.json) 과 안 맞는 줄만 만든다 → audio-prep → audio-qc 의 **이음매 검사** (이웃 문장 높이 차 ≥ 2.5 반음 = 뜀) → **다시 찍기** (뜀마다 이웃에서 더 먼 문장 하나 · 2 판씩 × 2 회 · 지금 판과 새 판 중 이웃 높이에 가장 가까운 판) → 그래도 튀는 문장만 뜻 그대로 끝말을 차분하게 (`build_scenes.py` 의 그 줄 · 조수가 고침 · 명령은 글을 고치지 않는다 · 원인 주장 · 숫자 · 부정 · 가설 · 범위가 바뀌면 뜻이 바뀐 것 → S4 · 1저자 · 바꾼 뒤 S4 재리뷰) 고친 뒤 한 번 더 · 작은 뜀 (< 3.5 반음) 은 그대로.  결제 · 계정 실패 · 글자 예산 넘김 (승인 대본 글자 × 3 · S4 고정 · 자동 · 수동 · 실패 호출을 한 원장에 누계 · 재시작 · 끝말 바꿈에도 이어 씀) · 공개 범위 · 바깥 TTS 전송 범위 · 뜻이 바뀌는 고침 · 목소리 바꿈은 멈추고 1저자에게 묻는다 (종료 코드 2).  기록 = 판마다 편 폴더의 audio/voice_auto_report.md (리포 밖) + `DECISIONS.md` 한 줄 — 그 줄에 글자 · 예산 숫자가 들어가므로 리포 공개 사본에서는 뺀다 (ep01 = 뺌).  높이 차는 귀의 대리 지표일 뿐이라 "자연스럽다" 고 쓰지 않는다 (듣기 확인 = 1저자) · 문턱 2.5 · 3.5 반음 = ep01 경험값.  ep01: preset 판 뜀 27 → smart 15 → 다시 찍기 · 끝말 둘 · 마지막 voice-auto = 3 곳 (최대 2.99 반음 · 모두 작은 뜀).

### 1저자가 넣을 음성 파일

- **장면마다 한 파일**: `ep01_s01.wav` … `ep01_s11.wav` (v2 = 11 장면 · 장면 번호 = TSV 의 '장면 번호' 칸 · 파일 안에서 문장 순서 = 표 순서).
- 형식: **WAV 48 kHz (또는 44.1 kHz) · 16 / 24 bit · 모노 또는 스테레오** — MP3 면 **320 kbps**.  m4a · flac · ogg 도 읽는다.
- 한 파일로 받았다면 `ep01_full.wav` 로 넣으면 된다 (v2 = 113 문장 전체를 한 번에 맞춘다 · 장면 파일이 하나라도 있으면 장면 파일을 쓴다).
- 파일 앞뒤 무음 · 문장 사이 쉼 길이는 상관없다 (파이프라인이 다시 맞춘다).  다만 **문장 사이에 쉼이 0.1 초 이상** 있어야 경계를 찾는다.  한 문장 안에서 0.5 초 넘게 쉬면 경계로 오인할 수 있다 → 그런 문장은 따로 다시 생성.
- 음악 · 효과음은 섞지 말고 목소리만.  음악은 따로 `--bgm` 으로 (사용권은 1저자가 확인).
- 가격 · 상업 이용 · 유튜브 수익화 조건 = **1저자가 각 사이트에서 확인** (여기에 적지 않는다).

## 4. 말 빠르기 모형 (무음 미리보기)

- 레퍼런스 측정: 발화 속도 8.37 음절/s · 문장 끝 쉼 중앙 0.335 s (80 % 가 0.24–0.46 s) · 문장 안 경계 74 % 쉼 없음 · 절 경계 1.3–1.7 s (작업 폴더의 `reference_analysis.md` §4).
- 우리 기본: `base_rate` **7.2 음절/s** × 문장별 빠르기 (0.92–1.05) + 쉼표마다 0.16 s · 문장 뒤 쉼 = 표의 값 (이음 0.3–0.45 · 문단 끝 0.6–0.8 · 물음 뒤 0.85–1.0 · 절 끝 1.4–1.5 s).
- ⚠ **7.2 음절/s 는 잠정값** — 실제 목소리의 기본 빠르기는 모른다 → 오디션 파일 QC 의 '빠르기 중앙' 을 `build_scenes.py` 의 `voice_model.base_rate` 에 넣으면 미리보기 길이가 맞아진다.  최종 영상은 실제 음성 시간 (`timing.json`) 으로 다시 잡으므로 이 값은 미리보기용이다.

## 5. 다른 트랙에 쓰려면

1. `ep01_mixer/` 를 `ep02_<트랙>/` 로 복사 → `build_scenes.py` 의 `EP` (episode · title · series · thumb) 와 장면을 새로 쓴다.
2. 숫자 · 연구는 **litdb 정본 카드** (`origin/claude/friendly-meitner-lldvar` 의 `litdb/papers/`) 에서만 · 우리 연구실 공저 논문은 출판 (학술지 · DOI) 확인 뒤에만 · 비공개 수치 · 봉인 런 값 · 내부 코드 · 기계 이름 금지.
3. 썸네일 물체는 `avi_thumb.py` 에 그 트랙의 장면 함수를 하나 더 만든다 (남의 이미지 금지).

## 6. 웹앱 영상 섹션 (`/videos`)

- 꾸러미 = `python3 -I scripts/avi_package_episode.py <편 폴더> --id <편 id> -o <편 id>.zip` (검토 후보 · 내부 자료 편이면 `--internal` · 렌더가 리포 밖이면 `--video <mp4>` · 다른 목록을 더 대려면 `--deny-list <리포 밖 목록>`).
  - 순서 = S10 검토 후보 (`--internal` · 이 컴퓨터만 · 목소리 그대로) → S11 승인 ① (들은 MP4 sha256 + 공개 부속물 목록) → 공개판 꾸러미 (같은 MP4 = `--video` · 같은 빌드의 편 폴더 = 작업 폴더 · 등록 전) → 승인 ② (시청자 대본 · ZIP sha256) → 등록.
  - 공개판 꾸러미 = 영상 · 썸네일 · 자막 · 시청자 대본 (장면 파일에서 만든다) · 공개 장면 (투영) · 시간표만 · 제작 기록 = 뺌 · 판 대조 다섯 (MP4 길이 ↔ 시간표 끝 · 자막 수 ↔ 시간표 자막 수 · 자막 마지막 줄 ↔ 시간표 마지막 자막 · 자막 마지막 줄 ≤ MP4 길이 (허용 0.5 s) · 장면 파일 문장 (id · 글) ↔ 시간표 문장) 가 어긋나면 만들지 않는다 (공개판 · 검토 후보 둘 다 · 리포 `ep01_mixer` 9:22.9 판 글 + v3.x MP4 = 거부) · 공개판은 다섯을 다 재야 (ffprobe 없음 · `--no-probe` · 시간표 · 자막 · 장면 파일 없음 = 거부 · 사유 = 대조 이름만) · 검토 후보 (`--internal`) = 못 잰 대조를 `build_check` 미측정으로 적는다.
- **내부 숫자 목록 (1저자 11-24 Q2)** = 작업 폴더 편 폴더의 internal/ 안 `public_deny_list.txt` (예: ep01 = 작업 폴더 ep01_mixer/internal/ · 리포에는 없다 · 내부 자료 편의 화면 숫자 · 한 줄에 하나).  공개판을 꾸릴 때 `<편 폴더>/internal/` 과 `--video` 로 고른 영상 폴더의 `internal/` 에 이 파일이 있으면 **늘** 검사한다 (`--deny-list` 없이도 · 걸리거나 목록이 깨졌으면 꾸러미를 만들지 않는다).  내부판 꾸러미 (`--internal`) 는 검사하지 않는다.  목록 파일은 꾸러미 (역할 밖 · 하위 폴더) 에도 리포 (`.gitignore` 의 `public_deny_list*.txt` · `docs/avi/**/internal/`) 에도 들어가지 않는다 — 내부 자료 편의 숫자가 바뀌면 AVI 조수가 목록도 같이 고친다.
- **공개 보류** — 등록된 공개판이 지금 공개판 기준 (공개 안전 검사 · 역할 · 장면 투영 · 판 대조 기록 = 지금 판 · 다 잰 통과) 에 맞지 않으면 다른 컴퓨터에는 등록 안 된 편과 같은 404 (목록 · 받기 · 대본 · 재생 · 자막 없음) · 이 컴퓨터에는 빨간 "공개 보류 · 걸림" 배지 + 까닭 (규칙 · 파일 이름만) → 고친 꾸러미로 `--replace`.  공개판 등록도 같은 기준 (판 대조 기록이 없거나 덜 잰 꾸러미 = 거부 · 기록을 본다 — 영상을 다시 재지 않는다).
- **내부판 = 이 컴퓨터에서만 (1저자 11-24 Q1)** — 루프백 · 프록시를 거치지 않은 요청에만 목록 · 화면 · 재생 · 받기 · 자막이 있다.  다른 컴퓨터의 요청에는 등록 안 된 편과 같은 404 (있다는 사실도 흘리지 않는다).
- 등록 = `python3 -I scripts/avi_register_episode.py <편 id>.zip` (자리 = `WEBAPP_VIDEO_FOLDER` · 없으면 `webapp/videos/` · git 밖) 또는 웹앱 `/videos` 의 "꾸러미 올리기" (이 컴퓨터에서만 · 같은 등록 함수).
- 규칙 · 화면 · 공개 / 내부 = 스킬 `.claude/skills/avi-generate/SKILL.md` 의 "웹앱 영상 섹션" 절 · 라이브러리 `webapp/video_library.py` · 시험 `webapp/test_video_page.py`.
