# L-3 / LPI-A01 — 최초 원인 미확정 상태의 진단·수령 계획

**최초 원인은 UNKNOWN이며 원 지적을 종결하지 않는다.** 보수적인 조상 경로 drift 거부와 기존 재고 명령 바이트를 보존한다. 현재 재고 결과나 후속 성공으로 과거 실패의 원인을 소급 확정하지 않는다.

## 1. 고정 근거·보존

B `13eb293cd9ac44502517c81e8f5e9b7ae02d817f`의 `docs/reviews/findings.json` LPI-A01 항목, `docs/reviews/lhs_pressure_inventory_20261104/pressure_inventory.sh` 및 `docs/reviews/lhs_pressure_inventory_20261104/README.md`의 범위가 근거다. 이 문서 작성에서 실제 연구 파일 내용·원 실패 로그를 새로 읽거나 기존 명령을 실행하지 않았다. 앞서 수령한 WSL30 재고와 LHS O1 현재 신원 정책도 새로운 재고 GO가 아니다.

상태: **0 = 보존·변경 없음**, **1 = 미확정**, **2 = 실제 실시 0회**. 숫자는 승인 수준이 아니다.

| 구분 | 상태 | 보존 원칙 |
|---|---|---|
| 과거 최초 실패 원인 | 1 | UNKNOWN 유지. 기대 경로/시각 또는 후속 성공만으로 파일시스템·타이밍·사용자 오류라고 단정 금지 |
| 보수적 drift guard | 0 | 조상 링크/권한/신원 변화의 거부를 완화하거나 비교 항목 삭제 금지 |
| 기존 운영 명령 | 0 | 별도 진단 허가 없이 명령·입력·출력 계약을 바꾸지 않음 |
| 실제 재현·재시도 | 2 | 자동 재시도·범위 확대·실패를 완료로 집계 금지 |
| 원장 처분 | 0 | 독립 근거 없으므로 open/기존 상태를 임의 갱신하지 않음 |

## 2. 다음에 허가할 진단의 최소 계약

**권고안 전제(Q-LPI-1)**: 원인 확인이 필요하면 1저자가 범위와 시간 상한·중단/회수를 정하고, 같은 고정 명령의 시도 영수증을 먼저 보존한다. 실제 실시 전 해당 변경 범위의 반박 검토와 1저자 GO가 필요하다. 본 문서만으로 진단 명령 실행 권한이 생기지 않는다.

| 영수증 칸 | 기록할 것 | 금지/한계 |
|---|---|---|
| 시도 신원 | attempt alias·고정 command SHA·해당 OS/POSIX/runtime 메타·시작/종료 시각·호출자가 확인한 범위 | 리포 밖 경로/주소를 리포에 넣지 않음; 실제 원자료 목록을 임의 확대 수집하지 않음 |
| 사전/사후 메타 | 허가된 고정 입력·조상 계층의 type/link/stat/접근권한 신원과 관측 순서 | 비교는 변화를 관측하는 것; hash 일치만으로 동시 변경 부재 인증 불가 |
| 실패 증거 | 원 rc·원 stdout/stderr·완전/부분 여부·어느 검사에서 종료됐는지·수령 해시 | 최초 stderr가 없으면 미보존을 명시; 후속 로그로 복원했다고 쓰지 않음 |
| 시간·중단 | 선택 상한·누가 중단했는지·중단/회수 완료 여부 | 원 명령에 timeout이 있다고 가정하지 않음; 미완료·부분 JSON을 정상 완료로 쓰지 않음 |
| 원인 분류 | 명령/입력 신원 불일치, 관측된 drift, 권한/링크 불일치, 시간 상한, 기타 기술 실패, UNKNOWN | 원인 이름은 관측한 증거 범위에 한정; 결손을 특정 원인으로 강제 배정하지 않음 |

원 로그/값을 진단 증거로 요구하지 않는다. 비결과 메타만으로 구분할 수 없으면 UNKNOWN을 유지하고 다음 범위를 별도로 제안한다. 현재 O1 초안에 진단 절차를 몰래 붙이거나 기존 재고를 다시 돌려서는 안 된다.

## 3. 작성 측 처분

이번 산출은 문서 1개·쪽지 1개다. 새 구현 0건·시험 실행 0회, 현장 접근·재고 재실행 0회, 실제 값·원 로그 열람 0회, 기존 guard·명령·원장 변경 0건. 최초 원인 해결·재고 실행 승인·LHS 동결/값 GO를 주장하지 않는다. 전체 HOLD.
