## 6. 교훈 — 규율 ⑥ 의 보강

- **본문만 읽은 카드의 *"없다"* 는 거짓 음성일 수 있다** — Cronau 2021 의 3.0 은 SI 그림에 있었다.  *"원문에 없다"* 는 SI 까지 본 뒤에만.
- **2차 인용은 한 단계만 원문으로 가도 다른 양으로 드러난다** — *"230 GPa 단결정 NCM811"* (Sedlatschek 의 인용) 은 Sharma 원문에서 NMC811
  소결 펠릿의 압입탄성률이었다.  *"207 MPa"* 는 평판 압축에서만 나온 값이었다.
- **인벤토리는 자기 형식 밖을 못 본다** — 저자-연도 정규식은 권호만 적힌 인용 · `.tex` · `.bib` 를 원리적으로 놓친다.  커버리지를 재고
  사각을 따로 훑는다 (규율 ⑤ 와 같은 부류: *후보를 고르는 코드가 곧 사각지대다*).
- **숫자가 맞아도 출처가 맞는 것은 아니다** — E_AM 140 · ν 0.25 는 NMC622 단결정 VRH 쌍과 소수점까지 가깝지만 조성이 다르다.  값과 출처와
  측정 부류를 따로 적는다.
