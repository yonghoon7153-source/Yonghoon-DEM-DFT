## 제안 판단선 — 숫자 문턱 없음 · 저자 비준 대기

유효 쌍0건은 방향 일치가 아니다. ΔN=0인 쌍은 N 대비에 사용하지 않고 별도 보존한다. 정확한0은 산술 동률이며 측정 오차 내 동등성을 뜻하지 않는다. 이 범주들은 대응쌍의 기술적 요약이지 개별 LHS의 합격/탈락·통계 유의성·인과 판정이 아니다. 대응되지 않은 전체 코호트의 기울기/상관도 별도 기술값으로만 제안하며, 불확실성 계산법은 값 열람 전에 정한다.

원자료에 근거한 압력상태 비교 가능성이 별도로 정당화되기 전에는 모든 범주에서 조성만의 효과라는 해석을 보류한다. 기존 `pressure_MPa` 명목 상수에 실측 P_relaxed를 덮어쓰지 않는다. porosity의 구합/합집합 규약, 기하 τ/수송 τ, Hertz/Physics/H12 역할은 각각 보존한다. 접촉·피복·응력·전도인자와 porosity–sigma–CN 후속 해석도 같은 압력상태 조건을 함께 명시해야 한다. 이번에는 해당 코드·값·인계 상태를 수정하지 않는다.
