## 제안하는 한 칸과 선행 정의

제안 이름은 **정지 판정 시점 감쇠 저항의 부호 있는 판힘 대비 비율**이다. `damping_resistance_share`는 현재 null이다. 공통·균일한 선형 입자 외력 `F=-c_v v`가 해당 그룹에 실제 적용됨을 확인한 경우에만 분자 후보를 `-c_v Σv_z`로 쓸 수 있다. `c_v`는 이 선형 점성 계수이며 표면에너지 `gamma`와 다른 물리량이다. 질량/타입별 계수, 상대속도 또는 접촉 dashpot이면 이 식을 그대로 적용하지 않고 정의를 다시 정한다.

| 향후 확인할 조건 | 필요한 원자료/결정 |
|---|---|
| 동일 실행·동일 정지 사건 | 실제 덱·감쇠 fix·재개 구간·판정 로그와 파일 해시의 연결; 현재 재고 줄 수로 동일 실행을 증명하지 않음 |

| 계수·힘 정의 | c_v 단위·적용 그룹·타입/질량 의존 여부·속도 기준계, 판힘의 성분·방향·단위·접촉 반력/구동력 구분 |

부호 있는 비율을 자동으로 0–1 범위의 힘 분담률로 해석하지 않는다. 비율에 따른 합격선·정지선·압력 적격성 문턱은 제안하지 않는다. 시점이 다른 마지막 dump나 명목값으로 빈칸을 메우지 않는다.
