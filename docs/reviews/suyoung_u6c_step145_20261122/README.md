# 수영 F8 원 번호 팔의 145번째 걸음 중단

## 1. 1저자 반환에서 확인한 것

개발 핀 `001e5e5e5f3bedde8106b608910e95f5dd1f78cb`으로 11월 22일 00:58:32 UTC에 원 번호 F8을 시작했다. 초기 상태와 1~144걸음까지 총 145개 표본을 쓴 뒤, 145번째 걸음에서 같은 노드의 접촉 계산이 수렴하지 않아 중단했다. 원 번호 팔 rc 1, 실행 블록 rc 1. 반전 번호 팔은 시작 전이다.

정리된 수령 자료는 `docs/reviews/suyoung_u6c_step145_20261122/partial_return.json`이다. 보고된 비율은 수치 잔차를 해당 노드의 수렴 문턱으로 나눈 값이다. 반력의 상대 오차를 나타내는 수치는 아니다. 반환에는 궤적, 소스 목록, 종료 로그가 있으나 실패 직전 각 노드의 질량, 속도, 법선, 충격량은 저장되지 않았다. 노드의 실제 배치를 알기 전에는 물체 수, 어느 접촉 쌍이 원인이었는지 또는 마찰식 자체의 해 존재 여부를 판정할 수 없다.

## 2. 다음 개발 관측

같은 원 번호·소스·시간 간격에서 145번째 걸음까지만 재현해 중단 당시의 노드 상태를 수집한다. 새 실행의 앞 145개 표본을 원 궤적의 해시와 대조한다. 같은 걸음에서 같은 중단 경로를 확인한 경우에만 노드를 후속 검산에 사용한다. 중단에 도달하지 않거나 앞부분이 다르면 재현 불일치로 기록한다. 마찰계수·반복 상한·허용 오차는 원 핀의 값을 사용한다. 추가 현장 작업은 1저자가 실행한다.

기존 함수가 예외를 낸 뒤 해당 함수의 실행 프레임에서 미수렴 노드만 읽는다. 각 노드의 질량·속도·법선, 최종 반복의 충격량, 수렴 문턱과 실제 잔차를 기록한다. 파일 `failing_nodes.json`과 그 SHA256을 담은 `capture_receipt.json`이 대응한다. 수집 성공의 표지는 `CAPTURED_STEP_145`다. 이 표지는 원래의 수치 중단을 재현했다는 뜻이다.

후속 판독기 `analyze_stop_node.py`는 같은 최종 충격량에서 70자리 산술로 잔차를 다시 계산한다. 물체가 넷 이하면 접촉 상태 조합을 열거해 원래 허용 오차와 에너지 조건을 만족하는 해를 찾는다. 다섯 이상이거나 대체 해를 찾지 못하면 해의 존재 여부는 미정이다. 수집 전에는 중단 원인의 가설별 결론을 내리지 않는다.

1저자용 실행 블록은 WSL CPU 1코어에서 과거 실패 TAR 하나를 받는다. 계산 예산 120초, 강제 종료 포함 상한 150초, 같은 릴리스 자동 재시도는 0회다. 반환 파일은 `suyoung_capture145_result.tar.gz`, `screen.txt`, `SHA256SUMS`다.
