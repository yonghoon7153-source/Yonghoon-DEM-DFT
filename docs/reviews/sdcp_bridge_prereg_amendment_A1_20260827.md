# 사전등록 개정 A1 — 브리지 판정의 **분석식 고정** (2026-08-27, unblinding 전)

> 대상: `sdcp_bridge_prereg_20260825.md` §4 (물리 가설·30/70 % 문턱은 **그대로**).
> 계기: Codex R7 Q6 [P1] — *"물리 가설과 30/70 % 문턱은 고정됐지만, confirmatory 판정을
> 내릴 만큼 통계 규약은 고정되지 않았다"*.  일곱 항목을 지목했고 전부 타당하다.
> ⚠ **이 개정은 문턱을 옮기지 않는다** — 문턱에 넣을 **숫자를 어떻게 만드는지**만 정한다.

## 0. ★ 왜 지금 등록할 수 있나 — **아직 눈이 멀어 있다**

Codex 조건: *"결과가 아직 완전히 blind 이고 payload 를 아무도 열지 않았다면, unblinding 전에
버전된 amendment 로 분석식을 고정하는 것은 가능하다.  이미 값 또는 파생량을 보았다면 현재
4런은 exploratory 로만 보고, 새 cohort 에서 confirmatory 판정을 해야 한다."*

**증거 (검증 가능)**:
1. 러너의 봉인은 **값을 안 찍는다** — 통과 시 σ 원값을 출력하지 않고 명령만 알려 준다
   (규칙 L 의 `L_SEALORDER` 가 이 순서를 강제; 실패 시에만 원값을 찍는다).
   실제 kgy 로그에 찍힌 것은 `✓ 계약 봉인 통과 (8 팔)` 과 `--collect-only` **명령 문자열**뿐이다.
2. `--collect-only` 를 **한 번도 돌리지 않았다** (세션 기록: 8/27 09:13 에 a1 봉인 통과 직후
   *"지금 `--collect-only` 는 돌리지 마세요 … 한 런만 먼저 보면 보고 나서 고른다는 통로가
   열린다"* 로 명시적으로 막았다).
3. payload JSON 은 kgy 로컬에 있고 이 세션에서 **읽은 적이 없다** (푸시도 자격증명 문제로
   막혀 있어 클라우드 쪽에는 존재조차 하지 않는다).
⇒ 이 개정을 쓰는 시점에 **어떤 σ 값도 어떤 파생량도 관측되지 않았다.**
⚠ 만약 위 셋 중 하나라도 사실이 아니면 **이 개정은 무효**이고, 4런은 exploratory 가 된다.

## 1. 관측량과 팔 (Codex 지적 ①②)

- **팔**: origin 8팔 = `{0, h/2}³` full factorial.  **arm 0 포함, 사후 제외 없음**
  (자기리뷰 N-6: 팔은 표본이 아니라 결정론적 유한 모집단이므로 편향 통로는 **사후 선별**뿐).
- **격자 간 짝짓기**: 실제 µm 좌표가 아니라 **정규화 비트 튜플** `(bx,by,bz) ∈ {0,½}³` 로
  짝짓는다 (vox 0.15 의 `0.075` ↔ vox 0.125 의 `0.0625` 가 같은 팔).
  ⚠ µm 로 짝지으면 격자마다 값이 달라 짝이 정의되지 않는다.
- **팔별 비**: `R_i = σ_e(DBE, arm i) / σ_e(SBE, arm i)` — 같은 origin 의 쌍대응.

## 2. 대표값과 오차 (Codex 지적 ①⑦)

- **정본 = 쌍대응 산술평균**: `R̄ = (1/8) Σ_i R_i`, `SE(R̄) = sd(R_i)/√8` (ddof=1).
  근거: 이 리포가 이미 쓰던 규약 (CL-33/34 의 "쌍대응 SE").
- **부차 보고 = ratio of means** `R_rom = mean_i σ_e(DBE,i) / mean_i σ_e(SBE,i)` —
  **게이트가 아니다**.  둘이 크게 갈리면 그 사실 자체를 보고한다.
- **비대응 quadrature SE** 도 부차 보고 (보수적 대조).  **정본 게이트는 쌍대응이다.**

## 3. 격자 의존과 감소율 (Codex 지적 ③④)

같은 팔이 두 격자에 모두 있으므로 **팔 단위로** 격자차를 만든다 (짝짓기 유지):

```
ΔR_i(off) = R_i(vox 0.125, 브리지 off) − R_i(vox 0.15, 브리지 off)
ΔR_i(on)  = R_i(vox 0.125, 브리지 on)  − R_i(vox 0.15, 브리지 on)
ΔR̄(off) = mean_i ΔR_i(off)      SE = sd(ΔR_i(off))/√8
ΔR̄(on)  = mean_i ΔR_i(on)       SE = sd(ΔR_i(on))/√8
```

**감소율** (사전등록 §4 가 문턱을 건 그 양):

```
A = 1 − ΔR̄(on) / ΔR̄(off)
```

**SE(A)** — 네 런 모두 같은 8팔이므로 팔 단위 공분산이 추정된다.  델타법:

```
A = 1 − u/v,   u = ΔR̄(on), v = ΔR̄(off)
Var(A) = (1/v²)·Var(u) + (u²/v⁴)·Var(v) − 2·(u/v³)·Cov(u,v)
Cov(u,v) = cov(ΔR_i(on), ΔR_i(off)) / 8      (ddof=1, 팔로 짝지어 계산)
```

## 4. 판정 (문턱 §4 불변 + **불능 조건 신설**)

| 조건 | 판정 |
|---|---|
| `A − 1.96·SE(A) ≥ 0.70` | **h1** (브리지가 격자 의존을 없앤다 = 채널 A 지배) |
| `A + 1.96·SE(A) < 0.30` | **h0** (채널 B 지배 — 연결 검출로는 못 고친다) |
| 구간이 0.30~0.70 **안에 온전히** 들어감 | **BOTH_REJECTED** (섞여 있다 — 그 자체가 결과) |
| 95 % 구간이 **0.30 또는 0.70 을 걸침** | **INDETERMINATE_PRECISION** (판정 없음) |
| `|ΔR̄(off)| < 3·SE(ΔR̄(off))` | **INDETERMINATE_NO_GRID_EFFECT** (분모가 잡음 — A 정의 불가) |

⚠ **Codex 지적 ⑤⑥ 대응**: 분모가 0 근방이면 A 는 발산한다.  그때는 "브리지가 고쳤다" 가
아니라 **"고칠 격자 의존이 애초에 없었다"** 이므로 판정을 내리지 않고 그렇게 적는다.
경계를 걸치는 경우도 마찬가지로 **판정 없음**이다 (문턱을 옮기는 대신 정밀도 부족을 적는다).

## 5. 부수 계약

- **수렴·봉인**: 32팔(4런×8) **전부** `check_arm` 통과 + `cg_info=0` + `resid ≤ 1e-6` 여야
  한다.  하나라도 실패하면 그 런은 판정에서 빠지고 **판정 자체를 미룬다** (팔을 버리고
  나머지로 판정하지 않는다 — 사후 선별 금지).
- **backend**: 32팔 전부 `used='gpu'` 여야 한다 (CPU 폴백 팔이 섞이면 판정 없음).
  ⚠ Codex Q4c: CPU/GPU σ parity 는 이 리포에서 **미측정**이므로 혼합 cohort 는 금지다.
- **보고 형식**: A · SE(A) · ΔR̄(on/off) · 각 R̄(4런) · 팔별 표 · 부차 지표(rom, 비대응 SE).
  판정 문자열은 §4 의 다섯 중 하나.

## 6. 이 개정이 **주장하지 않는 것**

- 문턱(30/70 %)·물리 가설·팔 수·격자 두 점은 **원 사전등록 그대로**다.
- 이 개정은 **분석식만** 고정한다.  결과를 본 뒤 이 문서를 고치면 그 판정은 무효다.
- A 판정은 전극 σ 비의 **수치를 승격하지 않는다** (그 수치는 여전히 p1↔p2 세대 문제와
  W4 재압밀 뒤에 온다).
