# 연구세미나 덱 v3.3 종결 확인

작성 2026-10-15. 대상은 제출된 v3.3 PPTX·PDF 18장과 ZIP v9다. 이전 v3.2 판정의 최소 수정 목록 및 이번 Q1–Q7을 실제 파일에서 대조했다.

## 1. 판정

**내용·수정 항목 종결 GO. SEMV32-01–04와 원 수식 덱 누락 SELF-117은 닫힘. 새 P1/P2 없음.**

단, **발표 파일의 무조건적인 최종 GO는 아직 아니다.** 이전부터 남긴 발표 PC의 PowerPoint 표시 확인을 유지한다. 그 컴퓨터에서 3장의 네이티브 수식 8개 및 두 줄 출처의 아래첨자가 잘리지 않고 읽히는지 확인하면 발표물 종결 조건을 채운다. 이 보고서는 PowerPoint 앱에서 열어 보았다는 증서가 아니다.

수치 재계산·시뮬레이션 재실행·추가 과학 문구 수정을 요구하지 않는다. 발표물 수용은 모델 검증, 언로딩/믹서 발사, 194·보충 20·v1.3 배포 승인과 무관하다. 11장 내부 진단, 15장 미실행 계획, 16장 최종 검증 미결 표지는 계속 유효하다.

## 4. Q1–Q7 답

### Q1 3장 출처 줄과 notes로 닫히는가

**동의.** 식 자체를 바꾸지 않는 저자 결정 Q1(가)와 맞는다. 화면이 정확한 구현식 전체를 주장하지 않고 대표식 및 반지름 지렛대 근사를 선언한다. notes는 실제 구현과의 차이를 설명한다. 따라서 이미 수용한 Newton–Euler 식이나 이력 모델을 다시 교체할 필요는 없다.

현재 논리적 3장의 부품은 `ppt/slides/slide3.xml`이다. 이전 v3.2의 논리적 3장은 `slide18.xml`이므로 XML 번호만 맞추어 비교하지 않았다. 원 수식 덱의 8개 OMML C14N, 대체 이미지 8개, 일반 그림 2개가 모두 일치한다. v3.2의 네이티브 Choice와 Fallback을 포함한 AlternateContent 8개도 유지됐다.

PDF의 출처 둘째 줄은 제목과 겹치지 않고 읽힌다. 추출 좌표상 출처 하단과 제목 상단의 간격은 5.26 pt다. 다만 PDF 대체 이미지와 PowerPoint OMML은 별도 표시 경로다. **발표 PC 확인은 이 동일성 검사로 대신하지 않는다.**

### Q2 11장 복합 개입과 내부 진단 한정

**닫힘.** 실제 본문은 `combined follow-up protocol` 다음에 plate-contact history reset, lower damping, force hold를 적고 내부 진단 지위를 유지한다. notes의 핵심 문장은 다음과 같다.

> Passing these internal checks would qualify the numerical state of this bed; it would not validate the model against experiment.

표의 이력 초기화와 13 SE 소실 행은 그대로이며 모두 `open`이다. 관측된 두께 감소를 서보 단독 효과나 실험적 타당성으로 소개하지 않는다. 같은 침대 끝점의 수치적 자격화와 실험 검증을 구별하는 수정으로 충분하다.

### Q3 15장 단계 순서와 미래형

**닫힘.** 같은 y 좌표의 흐름도 상자를 x 좌표 순으로 읽으면 다음과 같다.

`insertion → stabilization → compression → servo → relaxation → unloading → platen removal`

notes도 같은 순서이며 본문·notes 모두 `Heckel analysis to be redone`이다. 이는 이전 판정에서 확인한 10-14 저자 비준과 맞는다. 계획을 이미 실행한 절차로 바꾸지 않았다.

### Q4 Kissel 문구

**닫힘.** 실제 notes는 다음 문장이다.

> Coating coverage depended on stress intensity as well as stress number; increasing stress number alone did not collapse results across rotor speeds.

기존의 “횟수보다는 강도”라는 배타적 함의가 사라졌다. 이 문장 외 기존 과학 한정은 보존됐다. 이번 확인은 이전 문헌 판정의 교정문 반영 여부이며, 새 문헌 일반화나 드럼 결과 검증 승인이 아니다.

### Q5 F_p4_v33은 과장하지 않는가

**수용.** CSV 값만 대조한 것이 아니라 SVG의 축 눈금·막대·띠 좌표에서 값을 역산했다.

| 항목 | v3.2 → v3.3 대조 |
| --- | --- |
| 압력 막대 | 300.906 · 165.340 · 299.274 MPa 유지 |
| 구 체적합 공극률 막대 | 14.953 · 10.769% 유지 |
| 예측 띠 | 8.3–11.7% 유지, SVG 좌표 반올림 오차 10⁻⁶ %p 미만 |
| 예측 점 | 10.0% 유지 |

상한 확대는 띠 이름을 놓을 공간을 확보하며 수치나 막대 비를 바꾸지 않는다. `registered prediction band`와 지시선이 PDF에서도 보인다. 화면의 빗금 해석과 notes의 **결과 전 모델 예측·실험 범위 아님·통계 신뢰구간 아님**이 함께 유지돼, 띠 포함을 검증 통과로 승격하지 않는다. 이전 판정의 원자료 검산 범위도 그대로 승계한다. 새 입자 재합산이나 솔버 계산은 하지 않았다.

### Q6 단어 상한의 소폭 초과

**발표물로 수용.** 선언된 제외 규칙으로 독립 재계산한 7장 104/100, 11·15장 각 121/120은 이번 한정 문구·미래형을 보존하기 위한 소폭 초과다. 이 수는 화면의 모든 단어를 센 총수가 아니라 출처·크레딧·섹션 표지·표 등의 제외 규칙을 적용한 본문 수다. 실제 PDF에서 새 문구의 잘림·덮임·쪽 밖 이탈은 발견하지 않았다. 자동 단어 수 상한을 맞추려고 `nominal`, 복합 개입, `model-internal`, 미래형을 삭제할 이유가 없다.

11장은 읽을 내용이 많지만 제목·강조 구절·그래프·열린 검사 표가 분리돼 있다. 투사 거리·화면 밝기에 따른 실제 가독성까지 이 파일 검사로 보증하지는 않는다. 발표자는 본문을 낭독하기보다 **복합 개입·내부 진단·검사 미결**을 설명하면 된다. 이것은 재수정 조건이 아니다.

### Q7 원 수식 덱과 ZIP 목록

**닫힘.** 원본이 들어 있어 A8의 8/8·8/8·2/2 대조가 재현됐다. 요청서의 파일 목록 및 매니페스트가 ZIP 실물과 일치하므로 이전 SELF-117이 반복되지 않았다. 파일명이나 제작자의 PASS 문자열만으로 판정하지 않았다.

## 5. 변경 범위와 승계

변경하지 않았다는 12장 `1·2·4·6·8·9·10·12·14·16·17·18`은 논리적 슬라이드별 본문 run·notes·이미지·수식이 모두 같다. 슬라이드 및 notes XML 자체도 바이트 동일하다. 공유 스타일 자원 19개와 18장 전체의 layout 관계·대상도 동일해 전역 테마 변경으로 승계 화면이 바뀐 흔적이 없다. 바뀐 6장도 실제 변경 범위가 요청서와 맞는다.

15장의 `ε_union 10–13%`는 provisional geometric calibration target이고 실험 정의·하중 상태를 아직 맞춰야 한다는 notes가 들어갔다. 5장의 기존 10% 보정 목표와 다른 계획임도 명시한다. 4·6장의 승계 내용이나 다른 이미 수용된 과학 한정을 새 HOLD 사유로 재분류하지 않는다.

## 6. 발표 직전 남은 확인

필수로 남는 것은 **실제로 발표할 PC의 PowerPoint에서 3장을 여는 표시 확인**이다.

1. 네이티브 수식 8개가 빈칸·잘림·겹침 없이 보이는지.
2. 두 줄 출처의 `ℓᵢⱼ ≈ Rᵢnᵢⱼ` 아래첨자와 ②가 읽히는지.
3. 슬라이드 쇼 화면에서도 같은지.

이 확인이 통과하면 이번 발표물의 최소 종결 목록을 완료할 수 있다. 화면만 확인하는 일이므로 새 모델 검토나 계산은 필요 없다. 기존 날짜 placeholder와 발표자 그림칸은 앞 판정과 같은 상태다. 실제 발표 전에 채울 운영 항목이지 이번 변경분의 새 과학 finding은 아니다.
