# ADR 0040 — EIS 검수: 데이터가 있는 기계에서, 읽기만 하고, 글로 낸다

- 상태: 채택 (2026-09-23)
- 관련: ADR 0019, ADR 0022, ADR 0028, ADR 0039,
  `packages/wrdkit/src/wrdkit/eis/capacitance.py`,
  `packages/wrdkit/src/wrdkit/eis/audit.py`

## 맥락

"지금 임피던스로 넣은 모든 셀들을 검수해줘." 한 셀(`2600922_No1_55_sym_60um_#1`)을
들여다봤더니 화면이 세 가지를 조용히 넘기고 있었다.

1. 저주파 끝이 실수축에 내려앉은 **안 막는** 스펙트럼을 끝에 블로킹 CPE 가 달린
   회로로 맞췄다. 맞춤은 그 CPE 를 **지우는** 쪽으로 갔다 (Q = 1000, n = 1.00,
   둘 다 경계). 화면은 "물리적 한계에 붙은 파라미터" 한 줄로만 적었다.
2. 두 아크를 "벌크 / 입계" 라고 불렀는데, 커패시턴스로 보면 "벌크" 는
   4.66e-7 F 로 벌크일 수 없는 크기였고 "입계" 는 3.00e-4 F 로 전극 쪽이었다.
3. 그 이름 위에서 σ 를 냈다.

한 셀에서 셋이 나왔으면 다른 셀에도 있다. 그런데 **데이터는 랩 PC 에 있다**
(`/mnt/d/bml-data`, 원본 234개). 이 저장소를 고치는 쪽은 그 DB 를 볼 수 없다.

## 결정

### 1. 검수는 데이터가 있는 기계에서 돈다 — `bml audit`

`GET /api/eis/audit` 가 저장된 스펙트럼 전부를 훑고, `bml audit` 가 그것을
받아 **글**로 찍고 파일로도 남긴다. 글의 모양은 Python 이 만든다
(`?format=text`) — 셸에서 JSON 을 깎으면 판정 문장이 두 군데에 산다.

글로 내는 이유는 읽을 사람이 둘이라서다: 랩 사람, 그리고 그 글을 붙여 받는
에이전트. 화면 캡처 스무 장보다 붙여 넣은 글 한 벌이 낫다.

### 2. 읽기만 한다

검수는 맞춤도, 라벨도, 캐시도 **바꾸지 않는다.** 고치면서 보고하면 무엇이
틀려 있었는지가 지워지고, 맞춤은 "보고된 그 수" 여야 한다 (`SpectrumFit`
docstring). 고치는 길은 따로 있다:

- 파서가 바뀌었으면 `bml reparse` — 이제 EIS 원본도 다시 읽는다 (아래 5).
- 회로가 틀렸으면 그 스펙트럼 화면에서 다시 맞춘다. 검수는 어느 회로를
  권하는지만 적는다. 회로를 기계가 바꾸면 사람이 고른 것이 어디 갔는지 모른다.

### 3. 무엇을 보나

등급은 셋이다.

| 등급 | 뜻 |
|---|---|
| `문제` | 화면의 어떤 수가 **틀렸거나 이름이 틀렸을** 가능성이 높다 |
| `확인` | 사람이 한 번 봐야 한다 — 틀렸다고 말할 근거는 없다 |
| `참고` | 알고 있으면 좋은 것 |

- **원본·캐시**: 원본이 있는가, 내용이 기록(sha256)과 같은가, 점 캐시가 있는가
  (없으면 원본에서 읽되 **쓰지 않는다**), 점이 너무 적지 않은가.
- **기록**: 전고체인데 셀 구성이 비었는가, 대칭셀인데 두께·면적이 없는가,
  두께·면적이 단위를 잘못 적은 크기인가, 이름이 말하는 두께·구성과 적힌 값이
  다른가 (이름은 힌트다 — `확인` 이지 `문제` 가 아니다).
- **맞춤**: 수렴한 맞춤이 있는가, 평균·최대 상대오차(`|Z_fit − Z| / |Z|`),
  오차가 저주파 끝에 몰렸는가 (`edge_misfit`), 경계에 붙은 파라미터, 미결정
  파라미터, 옛 규칙의 행 (`legacy_unknown`).
- **물리**:
  - 스펙트럼이 안 막는데(`blocking_verdict`) 회로 끝에 블로킹 소자(`C`, `CPE`,
    `Wo`)가 있다 → `문제`. 반대로 막는데 끝에 아무것도 없다 → `확인`.
  - 대칭셀인데 안 막는다 → 벌크·입계 σ 가 없다는 것을 명시 (`확인`). 전에
    화면에 σ 가 떴을 수 있으므로 슬라이드에 옮긴 수를 다시 봐야 한다.
  - 아크의 꼭지 주파수 `f₀ = 1 / (2π (R·Q)^{1/n})` 가 잰 구간 밖이다 → 그
    저항은 외삽이다 (`확인`).
  - CPE 의 `n ≤ 0.6` → 반원이 아니라 확산에 가깝다 (`확인`).
  - 커패시턴스가 라벨과 모순된다 (아래 4) → `문제`.
  - σ 가 1e-9 ~ 1e-1 S/cm 밖이다 → 두께·면적 단위를 의심한다 (`확인`).
- **스캔**: 온도가 빈 스윕, 적은 저항이 그 스윕의 `Re(Z)` 가 지나간 범위 밖인
  스윕 (제대로 읽은 값은 무엇이든 곡선 위의 점이다 — 밖이면 소수점이거나 다른
  스윕의 값), 활성화에너지의 기존 경고 (ADR 0039). "실수축 교점의 세 배" 로
  보면 안 된다: 아크가 보이는 스윕에서 랩이 읽는 오른쪽 끝은 교점의 몇 배다.

### 4. 커패시턴스로 아크 이름을 **검사**한다 (정하지는 않는다)

R∥CPE 의 유효 커패시턴스는 `C = (Q·R^{1−n})^{1/n}` (Hsu–Mansfeld; 꼭지에서
`R·C = τ` 가 되게 정한 값, `n = 1` 이면 `C = Q`). 어느 과정의 커패시턴스인지는
Irvine–Sinclair–West (Adv. Mater. 1990) 의 표로 본다. 그 표는 셀 상수
`l/A = 1 cm⁻¹` 기준이라 **두 가지로 규격화해야 한다**:

| 과정 | 규격화 | 범위 |
|---|---|---|
| 벌크 | `C·l/A` (두께를 가로지르는 유전체) | < 1e-11 F (≈ 1e-12) |
| 입계 | `C·l/A` (brick-layer) | 1e-11 – 1e-8 F |
| 표면층 | `C/A` (면적에만 비례) | 1e-9 – 1e-7 F/cm² |
| 전극 계면 | `C/A` | 1e-7 – 1e-5 F/cm² |
| 전기화학 반응 | `C/A` | ≥ 1e-5 F/cm² (≈ 1e-4) |

벌크·입계는 두께 전체를 가로지르는 축전기라 `A/l` 에 비례하고, 계면은 얇은
층이라 면적에만 비례한다. 둘을 같은 `l/A` 로 규격화하면 60 µm 펠릿의
1 µF/cm² 이중층이 입계**로만** 읽히고 전극 계면이 후보에서 빠진다 — 처음
계산이 그렇게 틀렸다.

한 커패시턴스는 **후보 여럿**에 들 수 있다 (`2600922` 의 R1: `C·l/A = 3.6e-9` 로
입계, `C/A = 5.9e-7` 로 전극 계면 — 이 측정만으로는 못 가른다). 그래서 검수는
라벨을 **바꾸지 않고**, 라벨이 말하는 과정이 후보에서 **빠졌을 때만** `문제` 로
적는다. "벌크일 수 없다" 는 말할 수 있고, "입계다" 는 못 한다.

적용 범위는 좁게 둔다: 전고체 · 대칭셀 · `p(R,CPE)` 나 `p(R,C)` 아크 ·
두께와 면적이 둘 다 적힌 스펙트럼. 액체 셀은 뺀다 — 다공성 전극의 실면적을
모르면 `C/A` 가 두세 자리 흔들리고, 그 표는 세라믹의 표다. 파라미터가 미결정이면
판정 대신 값만 적는다.

### 5. `bml reparse` 가 EIS 원본도 다시 읽는다

"재파싱해서 넣어도 된다" 고 했다. 지금까지 `bml reparse` 는 충방전만 원본에서
다시 읽고 EIS 는 **캐시된 점으로** 다시 맞췄다 — 파서가 고쳐져도 옛 점이 남았다.
`POST /api/eis/reparse` 를 두고 맞춤보다 **먼저** 부른다.

여러 스윕이 든 파일은 스윕 번호로 고른다. 오늘 파서가 센 스윕 수가 기록과
다르면 **건드리지 않고** 적는다 — 번호가 가리키는 스윕이 바뀌었을 수 있고,
그때 조용히 덮으면 다른 온도의 점이 그 온도 이름으로 들어간다.

같은 길의 결함도 하나 고친다: 캐시가 없을 때 되살리는 `_load_points` 가
여러 스윕 파일에서 늘 409 로 끝났다 (`read_mpr_bytes` 가 스윕이 여럿이면
거절한다). 스윕 번호로 고르게 한다.

## 결과

- 검수 결과는 **셀의 목록이 아니라 판정의 목록**이다. 깨끗한 스펙트럼은 이름만
  한 줄에 모아 적는다 — 234개를 다 늘어놓으면 읽을 것이 묻힌다.
- 판정 규칙은 `wrdkit.eis.audit` 에 순수 함수로 산다. 화면에 검수 표시를
  붙이는 날 같은 함수를 부른다.

## 비용

- Irvine–Sinclair–West 의 표는 **경험칙**이다. εr ≈ 10 의 세라믹을 두고 쓴
  표이고, 경계는 자릿수 단위로 흐리다. 겹치는 곳에서는 아무 말도 안 하게
  했으므로 놓치는 것이 생긴다 (위의 R1 처럼).
- 검수 한 번에 모든 스펙트럼의 점을 읽고 모든 맞춤의 곡선을 다시 계산한다.
  수백 개면 몇 초에서 수십 초다. 캐시하지 않는다 — 검수가 옛 결과를 보여 주면
  검수가 아니다.
- EIS 재파싱은 원본을 전부 읽는다. 52 MB `.mpt` 하나가 몇 초다.

## 대안

**커패시턴스로 이름을 정한다.** 라벨 규칙(`label_arcs`) 전체를 바꾸는 일이고
SOC 스캔 표·대시보드·내보내기까지 번진다. 그리고 겹치는 범위에서는 어차피 못
정한다. 먼저 검수로 **얼마나 자주 틀리는지** 보고 정한다.

**검수가 고친다.** 위 2 — 무엇이 틀려 있었는지가 지워진다.

**웹 화면으로 낸다.** 언젠가 붙인다 (같은 순수 함수). 지금 필요한 것은 한 번에
전부 읽을 글이다.
