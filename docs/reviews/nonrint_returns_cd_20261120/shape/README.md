# 수영 설정 ① 네 원판 형상 · 11-20 개발 반환

**S와 F 모두 판이 정지한 이완 중에 판 반력이 0이 됐고, 그 뒤 판과 재료 셀 사이에 양의 틈이 나타났다.** 두 팔의 가압 종료는 1200 step, 판 상승 시작은 1801 step이다. 1저자 WSL 반환의 각 4,000행에서 판정 시각을 다시 읽었다. 두 팔과 전체 명령의 rc는 모두 0이다.

| 시점·관측 | S · 단일 속도장 | F · 원판별 속도장 |
|---|---:|---:|
| 가압 마지막 양압 step | 1200 | 1200 |
| 가압 뒤 첫 0압 step | 1201 | 1201 |
| 가압 뒤 첫 양의 셀 틈 step | 1366 | 1366 |
| 판 정지 끝(1800) 판–셀 틈 | 0.026191 | 0.024760 |

| 상승 후 0압·양의 틈 연속 길이 | 600 step | 600 step |

틈은 정규화한 판 높이에서 재료점이 운반한 셀의 가장 높은 꼭짓점 높이를 뺀 값이다. 1201과 1366에서 판 높이는 0.71, 판 속도는 0이다. 반력이 사라진 시점과 기하학적 간격이 양수가 된 시점 사이에는 165 step 차이가 있다. 상승 후 최종 600 step은 개발 판정선 120 step을 채웠다. 두 팔의 지위는 `DEVELOPMENT_SEPARATION_OBSERVED`다. 이 기록만으로 판 상승이 최초 분리를 일으켰다고 볼 수 없다.

**반환 대조.** 고정 드라이버 `33f5756dad27`와 커널 `00f0a1758349`에 결속한 발송 블록에서 소스 목록 5/5를 대조했다. 반환 tar·화면 2/2, 두 팔의 trace·arm JSON과 공통 그림 해시가 일치했다. 각 팔에서 0·1200·1800·2600·3400·4000의 NPZ 여섯 파일 해시와 저장 시각, 물질점 1,108개의 ID와 원판 번호 4개를 확인하고 저장 좌표·총 변형에서 셀 꼭짓점 간격을 재계산했다. 세 단계 전환의 전후 상태 해시 쌍도 팔마다 일치했다. 결과 tar의 SHA256은 `efe83ce7dd7f26e1cbd8576b4d4dbe7083dd9edb1a38e23015d58c34da809e71`이다.
