## 이번에 확정한 것

실험 자료 요청은 정상 셀 하나의 원시 trace와 직전 이력부터 시작한다. 자료가 없다는 주장은 **현재 확인한 범위에서 미확보**로 한정한다. OCP·초기상태·전류를 먼저 맞춰 바꾸지 않는다.

B-min의 기준은 `normal480_candidate_001` 하나다. 주 비교는 120–150초 301개 필수 요청 시각과 전극별 241좌표다. 150초는 480초의 시간 연장이 아니라, 더 세밀한 입자 축을 새로 계산할 경우의 짧은 비교 종료시각이다. 현재 계산을 수행한 것은 아니다.

과거 rtol·공간 설정 간 차이는 관측된 민감도이지 참값 오차의 바닥이나 상한이 아니다. B-min이 통과해도 두께 방향, 480초 후반, 유한 σ 신호, 실험 타당성은 별개다.

## 다음 행동

1. 사용자가 자료 요청 초안을 확인하고 직접 전달한다. 파일을 받으면 원본 경로와 정상·단락 구분을 알려준다. 이 묶음은 발송 권한을 부여하지 않는다.
2. B-min 문서 범위를 확인한 뒤 **오프라인 후보 작성만** 별도로 승인한다. 후보가 고정되면 변경부 검증, 그 결과 수용 후 native 최대 1회를 별도로 승인한다. 지금 승인 파일·runtime·token은 없다.
