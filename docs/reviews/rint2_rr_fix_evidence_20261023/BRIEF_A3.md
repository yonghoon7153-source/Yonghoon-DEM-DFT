## A13. 정상 FLOAT 기록 거부 고치기 (Q17 (가))
- 문제: 끊은 SV 다리 면이 판에 닿지 않는 (떠 있는) 성분에만 있으면, 끊어도 판에 닿는 계가 그대로라 그 끝 증서 = 주 해 증서다 (정상 기록).  그런데 `n_sv_faces_cut` 은 떠 있는 성분을 버리기 **전** 에 센 수라 > 0 이고, ⑥ ("끊었으면 더 작아야 · 같으면 거부") 이 거부한다.  보고 표: 끊은 다리 2 · census 끊을 면 행 2 · 아래 끝 증서 = 주 해 증서 · 위상 수 (11, 12, 1, 1) · 비 1.0.
- 고침 (비준 범위):
  - 생산자가 끝마다 **판에 닿는 성분 (생산자 자신의 기준 = `kept_c` 와 같은 판정) 에서 끊은 수** 를 따로 기록한다 (새 칸 · 이름은 기존 칸 꼴을 따라 네가 정한다 · 옛 칸 `n_sv_faces_cut` · `n_edges_cut` · `n_plate_couplings_cut` 은 그대로 둔다 = 기록 · ⑦ 용).
  - ⑥ 은 그 새 수로 판단한다: 새 수 > 0 이면 그 끝 증서 위상 수 ≠ 주 해 (더 작다) · 새 수 = 0 이면 그 끝 = 주 해 (같은 계).  ①–⑤ · ⑦ 은 그대로.
  - 새 수의 정의는 **모든 정직한 생산자 기록에서 "새 수 > 0 ⇔ 그 끝 증서 위상 수가 주 해와 다르다"** 가 정확히 성립하도록 잡는다 — 증서의 `target_n_*` 가 간선을 어떻게 세는지 (원래 목록 · 병렬 간선 합침) 를 읽고 맞춘다.  병렬 간선 꼴 (같은 두 dof 를 잇는 끊지 않은 간선이 있어 끊어도 증서 수가 그대로인 꼴) 이 정직한 기록으로 생기면 그것도 통과해야 한다.  이 둘을 한 정의로 맞출 수 없으면 고르지 말고 "결정 필요" 로 보고한다.
  - 새 칸과 옛 칸의 관계 (새 수 ≤ 옛 수 등 생산자가 보장하는 것만) 를 검증기가 대조한다 — 등식은 생산자가 보장할 때만.
  - 위 끝도 같은 원리 (위 끝에서 판에 닿는 성분 안에서 더 뺀 것 · 끊은 것) 로 — 위 끝 ⑤ · ⑥ 의 "끊은 것" 이 같은 이유로 거짓 거부되는 꼴이 있으면 함께.
- 시험 먼저:
  - FLOAT (실제 생산자 경로로 만든 침대 · 끊은 다리가 떠 있는 성분에만) → 계약 None (통과) · 표지 = 원래 판정대로.
  - 병렬 간선 꼴 (정직한 생산자 기록으로 만들 수 있으면) → 통과.
  - A2 (아래 끝 ← 주 해 증서 바꿔 끼우기 · 끊은 수 그대로) → 여전히 거부 (자기 사유 문장).
  - 새 칸 결손 · 형 바뀜 · 음수 · bool · NaN · 옛 칸과 모순 (생산자 보장 관계를 어긴 꼴) → 거부.
  - 한정 셋 ((a) SVX 아래 끝 ← 주 해 증서 + 끊은 수 0 · (b) QD2-3 위 끝 ← 주 해 증서 + n_edges_cut 0 · (c) 위 끝 ← 아래 끝 증서) → 지금처럼 받는다 (한정 확인 시험 · Q18 (가) — 막지 않는다).  단 (a) · (b) 에서 새 칸까지 0 으로 맞춰야 받는지, 새 칸이 남아 있으면 이제 걸리는지를 결과로 보고한다.
  - 모든 기존 생산자 기록 (SVX · QD2-1 · QD2-2 · QD2-3 · QD4 · 다섯째 rail · 진단 기록 · census 불일치 꼴) → 계약 None 그대로.
- 문서: `_topo_problem` 머리 주석 (⑥ · ⚠ 한정 문장 고침) · 등록 R §5-6 SV 행의 C1 단락 · 등록 R 머리 줄에 "10-23 묶음 A″ (C1 FLOAT · 1저자 Q17 (가) · Q18 (가))".
