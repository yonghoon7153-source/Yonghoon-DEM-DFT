## 2. 번호와 소유

| 항목 | 받은 계약 | 이번 연결에서 지킬 것 |
|---|---|---|
| 이름공간 | AM = scaffold canonical id(중심 사전순), SE = DEM atom id, 탄소 = (fid, branch) | 같은 정수여도 서로 다른 번호. 입력 행 번호로 대체하거나 SE 번호를 새로 매기지 않음 |
| 청구자 | 셀 중심을 포함하는 구(경계 포함) | 청구자 없는 셀을 최근접 중심에 배정하지 않음. SE에 AM 브리지 규칙을 임의로 추가하지 않음 |
| power | p = 거리 제곱 − 반경 제곱 | 반경 없는 Voronoi 경로와 구분. 실제 부동소수 평가 순서·ε는 공유 함수 규약을 재사용 |
| ε 집합 | 전체 청구자의 p_min → p ≤ p_min + ε 집합 → canonical 키 최소 | 두 개씩 비교해 대표를 바꾸는 fold 금지. 합성 사례의 ε는 정규화된 시험 입력이며 생산 ε 변경 아님 |
| canonical 키 | 행 번호가 아닌 정본 키 | 새 모듈은 공유 인터페이스가 준 키를 받는다. SE·탄소용 키 생성/인코딩을 이 문서에서 새로 정의하지 않음 |
| 변형 뒤 | 셀 안 점이 운반한 번호의 다수결, 동률은 canonical 키 | 현재 위치에서 다시 최근접 중심을 찾아 번호를 덮지 않음 |
| 복제 | 씨앗 셀당 복제 점은 같은 번호 | 현재 계획의 8점/셀 대응을 보존. 점 순서만으로 번호 대응이 증명됐다고 하지 않음 |
| 분할·재배치 | 정의 없음 | 분할 계약은 미정. 기존 점의 번호 불변을 넘어선 규칙을 승인된 것으로 구현하지 않음 |

측정은 x,y 최소 영상, z 비주기. `_ball_cells` 자체의 상자 절단을 주기 처리가 있다고 해석하지 않는다. 주기 이미지 구성과 같은 번호의 중복 청구 제거는 새 측정 어댑터의 대조 대상이다.
씨앗 점유 기준 n/8 ≥ 1/2(정본 §4-1)은 3점/4점 경계로 준비한다. 가변 점 부피·분할에는 이 기준을 그대로 확장하지 않는다.

현재 `scripts/mpm3d_compaction.py`의 `--save-se-id` 구현(정본 O4, 반경 없는 비주기 최근접 중심)은 이 경로의 정본 번호 공급자로 사용하지 않는다. 생산기는 그대로 둔다.

## 3. 피복 측정 계약

- 주 값 C(0): AM 자유 표면 중 SE 물질에 닿는 비율. 분모에서 AM–AM 가림과 영역 밖을 **합집합으로** 뺀다. 가림이 겹치는 부분을 두 번 빼지 않는다.
- b > 0는 보조 근접 띠 `near_b<µm>`. 옛 hertz/tabor 키의 읽기 호환 표지·표시는 Claude의 payload 변경 범위다. 키 직렬화 형식을 새 모듈에서 확정하지 않는다.
- C_강체·C_씨앗·C_끝을 같은 상·b·분모 정의·추정기 설정과 함께 보관한다. 소성 증가 = C_끝 − C_씨앗, 치우침 = C_씨앗 − C_강체. 서로 다른 b나 상의 값을 빼지 않는다.
- 주 추정기 = h_MPM 면 걷기, 대조 = r_pt 점 구름 KD. 기하 원판·구면 cap·복셀 면적을 같은 값으로 취급하지 않는다. `intersection_disc_area`는 원판이며 `union_cap_coverage`는 주어진 cap의 합집합/가림 계산이다.
- `union_cap_coverage`의 반환 단위는 percent다. 합성 사례는 명시된 fraction 단위만 쓴다. 연결할 때 단위를 명시해 변환하고, 차이는 fraction 차 또는 %p로 구별한다.
- AM 상이 없으면 None. AM 상과 자유 표면이 있고 피복만 없으면 측정된 0. 자유 표면이 비면 None과 `free_surface_empty` 사유(기존 함수)로 구분한다.
- 주기는 측정만 x,y. STEP3 비주기 풀이는 변경하지 않는다. seam 계면 수·면적은 `seam_unrepresented`로 별도 기록하며, 주기 풀이에 반영됐다고 쓰지 않는다.
- 법선 보정(D11)·해상 경계 k·분할 규칙은 미정이다. 원 면적 census를 법선 보정·물리 자격 완료로 올리지 않는다. SE–SE 막 솔브와 r 선택은 이번 연결 밖이다.

## 4. 합성 입력과 앞으로 확인할 것

`synthetic_cases.json`의 16개는 손으로 구성한 입력·기대값이다. 시험 실행이나 엔진 결과가 아니다. canonical_rank는 순서 의존을 가려내기 위한 **시험용 키의 순위**이며 실제 입자 키 생성 규칙을 대신하지 않는다. 소수·유리수 문자열은 정확 산술 기대를 적는 표기이며 생산 입력 스키마를 정한 것이 아니다.

| 먼저 확인할 경계 | 사례 | 구본/변이에서 기대하는 차이 |
|---|---|---|
| 이름공간·power·청구자·ε 집합 | namespace, power_radius, no_claimant, epsilon_set | 번호 충돌·가까운 중심 선택·공극 배정·연쇄 ε 동률을 드러냄 |
| 주기·z·순서 | periodic_xy, nonperiodic_z, permutation | seam 누락·z 감기·행 순서 의존을 드러냄 |
| 운반·복제·점유 | cloning, majority, majority_tie, occupancy | 번호 재부여·동률 임의 선택·3/4점 혼동을 드러냄 |
| 분모·기준 셋·없는 상 | free_surface_union, empty_free_surface, baseline_triplet, missing_phase | 중복 차감·0/None 혼동·씨앗 대신 강체 빼기를 드러냄 |
| 분할 미정 | split_undefined | 지원 규칙이 없는 분할을 보장하지 않음 |

씨앗 재생성의 셀 수·작은 침대 MPM 출력 비트 대조, 저장 끝 점의 개수/순열/변위 대응은 아직 미수행이다. 런 로그 셀 수나 실제 끝 점 파일을 이번에 열지 않았다. 해당 비교는 허용된 복사본·작은 개발 입력과 별도 실행 범위에서 준비한다.
