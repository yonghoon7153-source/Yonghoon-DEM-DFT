# 보고량 카드 (estimand card) — **계산을 던지기 전에** 한 장

> **이름**: 사람이 읽는 글에서는 **보고량 카드**라고 쓴다 (2026-09-01 용어 규율).
> **파일명 `estimand_card.md` 과 기계 필드 `kind: "estimand"` 는 그대로 둔다** —
> 개서하면 `db/governance/decisions.json` 과 게이트가 끊긴다.
> 영문은 *the reported quantity* · *target quantity* · *well-defined observable*.

> 왜 이게 있나 (2026-08-28 채택): SDCP-doped 흡착에너지를 **여덟 번** 계산했고 여덟 번 다
> 리뷰가 *"그 숫자는 네가 원한 양이 아니다"* 로 반려했다. 매번 다른 이유로 보였지만 뿌리는
> 하나였다 — **"E_ads 가 이 계에서 잘 정의되는가" 를 아무도 안 물었다.**
> 우리가 받은 리뷰는 전부 *"제대로 돌렸나"*(번들 무결성·해시·INCAR·pin·게이트) 였고
> 전부 통과했다. *"맞는 양을 재고 있나"* 는 여덟 번째에야 물었고, 즉시 P0 가 나왔다.
> ~~일곱 번은 안 돌려도 됐다.~~ ⛔ **철회 (회신 N)** — 카드를 블라인드로 재생했을 때
> 이 카드가 **확실히 잡는 것은 #7–8 정도**다. 여덟 실패의 원인은 하나가 아니라 **층위**다.
> (원문은 이력으로 남긴다. CLAUDE.md §계산 규율이 같은 문장을 철회한다.)
>
> ⛔ **이 카드가 못 하는 것**: 계산이 맞는지는 안 본다. 질문이 성립하는지만 본다.
> 통과했다고 결과가 옳은 게 아니다 — 옳을 **자격**이 생길 뿐이다.

## 1. 무엇을 원하는가 (한 문장)

> *예: "SDCP 중성형이 LiNiO₂(104) 에 얼마나 강하게 흡착하는가"*

## 1-b. 🔴 **설계를 선언한다** — 도핑·치환·계면 계산이면 필수 (2026-09-09 · 회신 BK)

> **다섯 칸을 채우지 않으면 계산을 던지지 않는다.** 이 칸이 없어서 우리는
> **코팅 후보 hull 을 도핑 데이터로 읽었고**(회신 BJ NO-GO), 그 다음엔
> **배위 관측을 Wyckoff 자리 판정으로 승격시켰다**(회신 BK 1-4).

| 칸 | 무엇 | 안 적으면 나는 사고 |
|---|---|---|
| `substitution_mode` | **`lattice`** / `separate_phase` / `additive` | "도핑" 이라 부르며 **별도 상** 데이터로 순위를 매긴다 |
| `host` | 어느 조성·구조를 모체로 삼는가 (파일 경로까지) | comp1 결과와 modelc 결과가 한 표에서 섞인다 |
| `실제_조성_농도` | **셀에 실제로 들어간 화학식**과 도펀트 분율 | "같은 계의 크기 차이" 로 읽었는데 조성이 달랐다 (BK 1-2) |
| `보상_방식` | 전하중성을 **무엇으로** 맞추나 — Li 추가/제거·침입형·배경전하·등가치환 | ③ "중성 치환" 은 모호하다: 셀 총전하 0 만으로 정해지지 않는다 |
| `부모_치환_자리` | 시작 Wyckoff 자리 (4a/4b/4c/16e/24g/48h …) | **관측된 배위**를 **자리 판정**으로 착각한다 (BK 1-4) |

⚠ **`보상_방식` 은 "확인했다" 가 아니라 "모델 조건으로 선언했다" 로 쓴다.**
합성 평형에서 그 보상이 실제로 일어나는지는 **다른 질문**이다.

⚠ 전 단계에서 유지할 것은 **같은 보상 정책과 원자수 계보**다 —
"모든 도펀트에 같은 공공 수" 가 아니다.

## 1-c. ⛔ **이 계산이 답하지 않는 것** — 한 줄로 미리 못박는다

> *예(Nd 배열): "같은 조성·같은 셀 안의 배열 선호를 답한다. **치환 형성에너지도
> 고용 가능성도 답하지 않는다** — 식에 무도핑 host 도 저장소(μ) 도 안 들어간다."*

`substitution_mode: lattice` 라도 **"선언한 격자 치환 모델의 조건부 성질"** 까지가
답이고, *"실제로 그만큼 고용된다"* 는 별도 질문이다 (회신 BK).

## 2. 그것을 재는 양 (식으로)

```
X = ⟨식⟩
```

각 항이 **무엇의 에너지인지** 적는다. 참조 상태(reference state)를 빠뜨리지 않는다.

> *예: `E_ads = E(복합체) − E(슬랩) − E(분자, box24)`*

## 3. 🔴 이 계에서 X 가 **잘 정의되는가** — 여기가 본체다

아래를 **하나씩 답한다.** "아마 괜찮다" 는 답이 아니다.

| 물음 | 답 | 근거 |
|---|---|---|
| SCF 해가 **하나**인가? 여럿이면 어느 것인가 | | |
| 열린 껍질(홀전자)이 있는가 | | |
| 기판이 **자성**인가 (자기 basin 이 여럿인가) | | |
| 기판이 **산화환원 활성**인가 (전하이동 가능한가) | | |
| 참조 상태가 계산 대상과 **같은 전자 상태**인가 | | |
| 흡착 전후로 **보존된다고 가정하는 것**이 무엇인가 | | |

**판정 규칙 (회신 N 문구)**: admissible state 가 여럿인데 **선택·집계 규칙이 없으면**
**스칼라 보고량(scalar estimand)** 은 정의되지 않는다. 상태별 `X(s)` · 표본 최저 · Boltzmann 앙상블 · 분포
전부 정당한 **보고량**이 될 수 있다 — 무엇으로 집계하는지 **여기서 적는다.**
탐색이 불완전하면 "전역 최소" 가 아니라 **"검색한 상태 중 최저"** 라고 쓴다.

⚠ 이 여섯 물음은 **DFT 흡착의 전자상태 모듈**이다 (회신 N D4). 보고량 core(estimand core)
(대상계·앙상블·균형 반응식·관측량·집계 규칙·intercurrent event 처리·결측 처리·판정바닥)와
MD·NEB·스크리닝 모듈은 후속 개정에서 분리한다 — 그때까지 다른 계산 종류에 이 카드를
쓸 때는 §3 을 그 계산의 위험요인으로 바꿔 채운다.

> *SDCP-doped 실패 사례: doublet(홀전자 O) × AFM 슬랩(basin 여럿 O) × 산화환원 활성
> LiNiO₂(전하이동 O). 셋 다 "여럿" 이었는데 단일 E_ads 를 여덟 번 요구했다.*

## 4. 검증 게이트 — **결과를 보기 전에** 정한다

계산이 이 중 하나라도 어기면 **그 잡을 버린다.** 결과를 보고 게이트를 고치지 않는다.

- invariant 를 **계·상태별로 선언**한다: expected / tolerance / rationale.
  (⚠ "정수 자화" 는 범용이 아니다 — 금속·부분점유는 비정수 가능, NUPDOWN 고정 뒤
  정수는 강제 결과라 검증이 아니다)
- 참조와 대상의 **전자수·스핀·전하**가 의도한 값인가
- 판정 해상도(바닥)를 **미리** 정했는가 — 그 아래는 "작다" 가 아니라 "판정 안 함"

> *실측 ① (phaseB, ISMEAR=1): `mol_doped` 총자화가 **0.175** 였다(1.0 이어야 함).*
> *실측 ② (wave1, ISMEAR=0): `mol_doped` 는 **1.0000** 이었다 — 그런데 `NUPDOWN=1` 로
> 묶어서 나온 값이라 **검증이 아니라 강제**다. 정작 복합체는 `NUPDOWN=−1`(자유)로 돌아
> −0.31 / −0.33 / 3.72 / 3.63 μB 에 떨어졌다.*
> ⇒ **게이트는 "기준과 대상이 같은 제약인가" 까지 물어야 한다.** 우리는 제약된 기준에서
> 자유로운 복합체를 뺐고, 강제된 정수를 통과로 읽었다. (2026-08-28 정정 —
> `kb/methodology/estimand_before_running_2026_08_28.md` §2.1)

## 4-a. 깔때기라면 — **계획과 실측을 다른 칸에** (2026-09-09 · 회신 BK)

⛔ **종전 규율을 철회한다.** 우리는 *"각 단은 (판정량·문턱·입력수·**탈락수**·GPU-h·
규칙인가 스케줄인가) 여섯 칸을 채운다. 못 채우면 게이트가 아니라 주석이다"* 라고 썼다.
**틀렸다** — 유효한 사전 문턱을 모두 통과하면 **탈락은 0 일 수 있다.**
탈락 **건수**를 지표로 삼으면 **문턱을 억지로 좁히는 유인**이 생긴다.

**고친 규율 — 계산 전에 채우는 칸과 뒤에 채우는 칸을 나눈다.**

| | 계산 **전** (계획) | 계산 **후** (실측) |
|---|---|---|
| 판정량 | 무엇을 재나 | — |
| **문턱** | **어떤 조건에서 탈락시키나** (사전 정의) | — |
| 유효성 | **그 판정량이 목표 질문에 유효한가** | — |
| 층 선택 | **규칙인가 스케줄인가** | 실제로 무엇이 골랐나 |
| 입력 수 | 예상 | 실제 |
| 결과 | — | **통과 / 탈락 / 미판정 / 계산실패** 를 **네 갈래로 구분** |
| 비용 | 견적 | GPU-h 실측 |

⚠ **계산 전 카드에 아직 모르는 탈락수를 요구하지 않는다.** 그게 종전 규율의 결함이었다.

⚠ 그러면 남의 깔때기 비판도 좁아진다 — 문제는 *"탈락이 0 이었다"* 가 아니라
**사전 문턱이 선언돼 있지 않았고, 수렴률(93.9 %)을 탈락률처럼 읽히게 쓴 것**이다.

### 눈금 — 관련성은 확인하되 자릿수로 판정하지 않는다

⛔ *"판정량 눈금이 목표 도핑량과 같은 자릿수가 아니면 게이트가 아니라 순위표다"* 도 **철회**.
**예측 고용도가 목표보다 훨씬 낮으면 그건 오히려 강한 탈락 근거**다.

먼저 맞출 것은 **단위 · 온도 · 화학퍼텐셜 · 희석/고농도 적용 범위 · 평형 가정**이고,
자릿수 일치는 그 다음이다.

## 4-b. **관측 결과는 설계와 다른 절에 적는다** (2026-09-09 · 회신 BK)

세 층을 **섞지 않는다.** 섞으면 관측이 판정으로 조용히 승격된다.

| 층 | 무엇 | 예 |
|---|---|---|
| **설계** | §1-b 다섯 칸 — 우리가 **정한** 것 | 부모 자리 = 16e · 보상 = Nd 당 Li +2 |
| **배열** | 구체적 원자 배치 · 무질서 · 시드 | `O-bo4` / `O-distributed` / `O-free_s` |
| **관측 결과** | 이완 **후** 자리 대응과 국소 배위 — **잰** 것 | P–O 3/3 · 0/3 · Nd–O 2.19–2.26 Å |

⛔ **실측 사고 (2026-09-09).** `P–O 0/3` 은 옳게 쟀는데, 거기서
*"⇒ 다른 Wyckoff 자리(4a/4c)로 옮겼다"* 로 한 걸음 더 갔다.
생성기가 그 O 를 **부모 16e 에서 골랐다**는 것을 안 보고 말한 것이다 —
그리고 그 사면체의 P 는 치환돼 있으니 **P–O 가 없는 건 구성상 당연**했다.
**측정은 옳았고 판정이 틀렸다.**

⚠ **결과를 본 뒤에 추가한 항목에는 그 사실을 표시한다.**
카드가 `⚠_결과_보기_전에_썼다` 를 달고 있어도, 뒤에 붙인 칸은 그 보증 밖이다.

## 4-c. 비용 견적 — **같은 캠페인·기계의 실측 장부와 대조한다** (필수 · 2026-10-05 · 회신 CS)

> *실측: li2s 대조 계 카드가 담금질을 '시드당 ≈ 3 h · 15 GPU-h' 로 적었다. A 카드(09-21)의 **잰 적 없는 어림**을
> 옮긴 것이었고, 같은 캠페인의 실측 장부(시드당 벽시계 28.7–47.0 h · 등분 점유 14.3–16.5 GPU-h)는 안 봤다.
> 발사 4 시간 뒤 첫 진행 줄에서 드러났고, 총상한 80 을 MD 전에 넘는 견적이 됐다
> (`db/properties/lpscl_smallcell_glass_control_li3ps4_amendment_cs_2026_10_05.json`).*

- **견적의 출처를 적는다** — 같은 캠페인·같은 기계의 **실측 장부**(런별 벽시계 · 그때 같이 돈 GPU 잡)가 있으면 그걸로 낸다.
  잰 적 없는 어림을 옮기지 않는다. 장부가 없으면 '실측 없음 · 어림' 이라고 적고 첫 런 뒤 갈아끼운다.
- **셈법을 적는다** — 공유 GPU 면 벽시계와 점유 환산을 **나란히**. 점유분율은 잴 수 있으면 잰다
  (gabia: nvidia-smi 표본), 못 재면(kgy: 프로세스별 정보가 막힘) 동시 잡 수 등분을 **가정으로** 적고
  그 가정이 **어느 방향으로 틀리는지** 적는다 (가벼운 잡이면 우리 몫을 과대평가 = 상한 비교에 보수적).
- **여유와 멈춤 경로** — 실측 산포를 넣은 최악 견적 대비 상한 여유를 적고, 상한에 닿아 멈추는 일이
  실현 가능한 경로인지 적는다. 멈췄을 때 무엇을 할지(예: 시드가 넷이면)를 **결과 전에** 박는다.
