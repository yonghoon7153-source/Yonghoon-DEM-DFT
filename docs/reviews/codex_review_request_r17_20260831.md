## 1. 하려는 것

Fig 4b 에 σ_ion 을 **절대값 한 쌍**으로 싣는다:

```
SBE  0.5534 mS cm⁻¹      DBE  0.5580 mS cm⁻¹      (σ_ion(SE) = 3.0e-3, r = 1/3)
```

그리고 나머지 시나리오는 **감도로 병기**한다 (`r = 0 · 0.0184 · 0.1737` → DBE 0.5410 ·

## 2. 찬성 근거

- **Table S2 가 그 값을 이미 선언한다.**  `σ_ion(LPSCl) = 3.0 × 10⁻³ S cm⁻¹ (Ref. S5)` ·
  `σ_ion(SDCP) = 0.001 S cm⁻¹` (코드 기본).  ⇒ `r = 1/3` 은 **우리가 오늘 고른 값이 아니라
  원고가 심사자에게 선언한 파라미터 집합**이다.
- **전자축이 이미 같은 형식이다** — 선언된 규약 하나의 값을 본문에 쓰고 대안을 병기한다.
- **감도가 작다** — 전 구간에서 전극 σ_ion 변화 3.1 %.  대표값을 쓰든 안 쓰든 그림이 거의 같다.
- **환산이 정확하다** — 선형 FV 항등식(모든 이온상을 k 배 → σ_eff 가 정확히 k 배).
  σ_SE 3.57e-3 런에서 3.0e-3 로 옮기는 데 근사가 없고 **비는 불변**이라 판정에 영향이 없다.

## 3. ⚠⚠ 반대 근거 — 이쪽이 더 무겁다

### 3-1. 하필 그것이 **우리에게 유리한 유일한 시나리오**다

```
r = 0        R = 0.977   DBE 낮음
r = 0.0184   R = 0.980   DBE 낮음
r = 0.1737   R = 0.997   DBE 낮음
r = 0.3333   R = 1.008   **DBE 높음**   ← 네 개 중 이것만
```

⇒ *"선언된 규약이니까"* 라는 근거가 **결과 방향과 완벽히 정렬**한다.  선택 편향의 정의에 가깝다.

### 3-2. **생산 규약이 펠릿 보정과 불일치한다**

D13(2026-08-31, 이 SHA 에 원자료 반입 예정)이 같은 펠릿 표적을 RVE 로 맞춘 결과:

| | 값 | 펠릿 ±5 % 허용창 |
|---|---:|---|
| 보정값 | `r = 0.1737` (표적 +0.19 %) | 안 |
| **생산 규약** | **`r = 0.3333`** | **밖** (창 상한 0.2752 를 21 % 초과) |

⇒ 원고가 선언한 파라미터가 **원고 자신의 Fig 2f 측정과 맞지 않는다.**
⚠ 단, 그 창은 `ρ_SDCP = 1.30` 조건부다 — Codex 가 R16 에서 재실행한 대로 `ρ = 1.10` 이면
생산값이 +4.90 % 로 창 **안**이다.  그리고 **ρ_SDCP 는 원고에 없다** (Table S2 에 밀도 열
자체가 없다; 코드는 `PROXY from generic PEDOT web-lit` 이라 적는다).

### 3-3. R16 이 이미 REFUTED 했다

Q5 판정: *"어느 것도 final calibrated value 가 아니다 … production representation 에서
재식별하기 전에는 8팔 값을 정하지 말라"* (D13 사전등록 §7 인용).  이 요청은 **그 판정을
다른 근거로 다시 여는 것**이다.

### 3-4. 부호가 `ρ_SDCP` 에 걸려 있다 (2026-08-31 발견)

같은 1 wt% 인데 밀도가 달라 **DBE 의 바인더 부피가 SBE 의 1.346배**다 (PTFE 2.2 vs SDCP 1.3).
모델 안에서 두 항이 싸운다 — ① SDCP 의 이온 기여(DBE 유리) ② 부피 점유(DBE 불리).

```
ρ_SDCP = 1.1 → 부피비 1.500 · 1.3 → 1.346 · 1.7 → 1.147 · 2.2 → 1.000 (페널티 소멸)
```

⇒ **미측정 프록시 하나가 보고할 부호를 정한다.**

## 4. 질문

**Q1.** *"Table S2 가 선언한 생산 규약"* 이라는 근거가 R16 Q5 의 *"단일 r 선택 REFUTED"* 를
넘어서는가?  아니면 **같은 선택을 다른 이름으로 하는 것**인가?

**Q2.** 생산 규약이 **펠릿 보정과 불일치**하는 상태(§3-2)에서 그것을 대표값으로 쓰는 것이
정당한가?  정당하다면 원고에 그 불일치를 어떻게 적어야 하는가?

**Q3.** 대안 셋 중 어느 것이 옳은가 — 그리고 각각 어떤 문구가 필요한가?

```
ⓐ 생산 규약 한 쌍 + 감도 병기          (이 요청)
ⓑ 대표값 없이 네 점 전부               (R16 권고)
ⓒ 펠릿 보정값(r = 0.1737) 한 쌍 + 감도  ⚠ 그러면 Table S2 를 고쳐야 하고,
                                        DBE < SBE 가 되어 우리에게 불리하다
```

**Q4.** `ρ_SDCP` 실측이 이 문제를 닫는가?  닫는다면 **어떤 값이 나와야** 각 대안이
정당해지는가 (사전에 등록해 두려 한다 — 값을 보고 정하지 않기 위해).

**Q5. (코드 리뷰)** 이온 경로 자체에 전용 리뷰가 없었다.  전자축은 R8~R16 을 거쳤지만
`ionic_sigma_table` · `apply_ptfe_blocking` · `--sigma-ion-*` 배선 · 온도 보정
(`sigma_ion_se` 를 T_ref 로 받아 Arrhenius 적용)은 **한 번도 적대적으로 읽히지 않았다.**
읽어 줄 수 있는가?  특히:
- SWCNT(sid 8)가 기본 ion-transparent 인 분기가 두 침대에서 대칭인가 (둘 다 SWCNT 없음)
- `sigma_ion_se_S_cm`(적용) ↔ `sigma_ion_se_ref_S_cm`(기준) 분리가 실제로 지켜지는가
