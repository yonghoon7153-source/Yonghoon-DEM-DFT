# ADR 0014 — 바깥에서 볼 때만 문을 하나 단다

- 상태: 채택 (2026-08-21)
- 관련: `apps/api/app/gate.py`, `tools/bml` (`share`, `password`),
  ADR 0011 (데이터는 중추 서버 한 대에), ADR 0012 (이름은 신원 확인이 아니다)

## 맥락

ADR 0011 로 데이터를 중추 서버 한 대에 모았다. 같은 공유기 안에 있으면
`bml use 192.168.0.40` 이면 끝이다. 그런데 실제로는 실험실 PC 와 집 노트북이
**다른 공유기** 뒤에 있다 (`192.168.0.x` 와 `192.168.1.x`). 사설 주소끼리는
서로 못 닿고, 방화벽을 아무리 열어도 달라지지 않는다.

길은 셋뿐이다.

1. **같은 공유기로 옮긴다** — 가장 안전하고 설정이 없다. 물리적으로 같은 곳에
   있을 때만 가능하다.
2. **공유기에서 포트를 연다 (+DDNS)** — 상시 인터넷 공개. 앱에 로그인이 없어서
   주소를 아는 사람은 전부 읽고 전부 지운다.
3. **바깥을 한 번 거쳐 되돌아오는 터널** — 공유기 설정 없이 뚫린다.

## 결정

**3번, 그리고 켜는 동안만.** `bml share` 가 임시 터널을 하나 띄우고 주소를
찍는다. 끄면 그 주소는 사라진다.

```bash
bml password <암호>     # 한 번
bml share               # 연다.  주소가 나온다
bml share stop          # 닫는다 (`bml stop` 도 함께 닫는다)
```

터널은 **창에 매달지 않는다.** 처음에는 `bml share` 를 붙잡아 두게 만들었는데,
그 창을 Ctrl-C 하거나 닫는 순간 주소를 받은 사람은 Cloudflare 오류 1033 을 본다
— 그리고 그 화면은 "닫혔다" 가 아니라 "고장 났다" 로 읽힌다. 서버와 같은
방식으로 띄우고, 닫는 것을 명시적인 명령으로 뒀다. 무엇이 열려 있는지는
`bml status` 가 말한다.

터널은 Cloudflare 의 quick tunnel 을 쓴다 — 계정도 도메인도 필요 없고, 실행
파일 하나면 되며, 공유기를 건드리지 않는다. 실행 파일이 없으면 `bml share` 가
`.bml/bin/` 에 받아 놓는다.

### 암호 없이는 안 연다

ADR 0012 는 "이름은 기록이지 신원 확인이 아니다" 라고 정했고, 그것은 지금도
맞다. 다만 그 판단은 **같은 랩 안**을 전제로 한 것이다. 주소가 인터넷에 있는
동안에는 전제가 달라진다 — 랩 밖의 아무나가 대상이 되고, 이 앱에는 삭제를
막는 것이 없다.

그래서 문을 정확히 **하나만** 단다.

- `WORKBENCH_PASSWORD` 가 비어 있으면 **아무것도 바뀌지 않는다.** 랩 안에서
  쓰는 사람은 이 ADR 이 있는 줄도 모른다. 없는 문을 지나가느라 아무도
  느려지지 않는 것이 중요하다.
- 그 값이 있으면 모든 요청이 쿠키 하나를 요구한다. 쿠키에는 암호를 담지 않고
  HMAC 만 담는다. 비교는 `hmac.compare_digest` 로 한다.
- `bml share` 는 암호가 없으면 **띄우지 않는다.** "나중에 걸어야지" 는 걸리지
  않고, 안 걸린 채로 도는 터널은 주소만 알면 열리는 실험 데이터다.
- `/api/health` 만 문 밖에 둔다. 응답에 데이터가 없고, `bml use` 가 주소를
  확인하는 통로다 — 이것까지 막으면 암호를 아는 사람도 주소를 등록할 수 없다.

### 하지 않은 것

- **사람별 계정.** ADR 0012 를 뒤집지 않는다. 여기서 푸는 문제는 "네가
  누구냐" 가 아니라 "이 주소를 우연히 마주친 사람을 들이지 않는다" 이다.
  누가 무엇을 했는지는 여전히 이름으로 남고, 여전히 검증하지 않는다.
- **상시 공개 (2번).** 터널은 켜는 동안만 열린다. 잊고 꺼 두는 쪽이 잊고
  열어 두는 쪽보다 훨씬 낫다.
- **암호를 데이터베이스에 두기.** `.bml/env` 의 한 줄이다. git 에 올라가지
  않고, 기계마다 다르고, 바꾸는 데 마이그레이션이 필요 없다.

## 결과

- 랩 안: 아무것도 안 바뀐다.
- 랩 밖: `bml share` 한 줄, 상대는 `bml use <그 주소>` 한 줄.
- 암호를 잃으면 `bml password <새 암호>` 로 바꾸고 다시 알려 준다. 되찾는
  장치는 없다 — 되찾을 수 있는 암호는 아무도 못 여는 문보다 나쁘다.
