## UMA는 집계지표가 좋아도 촉매 착물의 에너지 순위를 자주 틀린다

> UMA-s-1.1은 DFT와 R² 0.96–0.97로 맞지만 리간드별 순위 신뢰율은 44–84 %에 그친다. (L34 · 365)

### 요점

1. UMA-s-1.1(OMol25 task)의 single-point 에너지를 DFT 최적화 구조 위에서 PBE0-D3(BJ)/def2-SVP 값과 비교해, 전이금속 촉매 착물의 conformer와 configuration 순위가 보존되는지 Spearman ρ로 따졌다. (L34 · 48 · 51 …)
2. 집계지표는 좋았지만 리간드별 순위 신뢰율은 강직계 84 %에서 유연계 53 %로, Ru 61 %에서 Mn 44 %로 떨어졌다. (L34 · 61 · 63)
3. 원문은 실패가 에너지 차 2–5 kJ/mol 이하의 near-degenerate 영역에 몰려 치명적이지 않다고 결론짓되, 집계지표만 보고 MLIP을 믿으면 안 된다고 적었다. (L34 · 276)

### 무엇을 묻나

전이금속 착물의 DFT 계산은 고속 스크리닝에 쓰기에 비싸다. 원문은 착물 1개에 32 CPU core로 4 h가 들고, 1만 개면 €12,800 정도라고 셈했다. 반면 UMA single-point는 노트북 GPU에서 구조당 수 초에 끝난다. (L43–46)

질문은 에너지 오차가 아니라 순위다. UMA가 예측한 여러 배열의 상대 안정성 순서가 DFT와 같은지를 본다. 원문은 UMA로 기하최적화를 하지 않았고, DFT 최적화 구조 위의 에너지 재현만 평가한다고 범위를 밝혔다. (L48 · 50–51 · 53)

### 두 데이터셋

Data set 1은 Ni 착물의 conformer 집합이다. 중성의 강직한 [L]Ni(II)Cl₂는 19 리간드에서 746 conformers, 양이온성 유연계 [L]Ni(II)(CH₃CN)(p-OMeC₆H₄)⁺는 1260 conformers로 비교했다. 구조는 입체이성질체 열거 도구 MACE와 CREST @ GFN2-xTB 탐색으로 만들었다. (L61–62 · 139–140 · 187 …)

Data set 2는 88개 chiral bisphosphine 리간드와 Ir, Ru, Mn 수소화 촉매를 조합한 909 geometries다. 여기서 configuration은 축방향 자리에 어느 주개원자 쌍이 오는가로 정의된다. 리간드별 순위는 ρ > 0.6과 p < 0.05를 모두 만족하고 conformer가 넷 이상일 때만 신뢰로 판정했다. (L155–157 · 230–232)

- 그림 — Fig. 1: 아래쪽 Data set 2 도해에서 Ir은 두 가지, Ru와 Mn은 네 가지 axial 배열이 그려져 있다. 리간드당 표본 수는 캡션에 없고 이 도해에서 세어야 한다. (L233–235 · 286)

### 집계지표는 좋다

세 계 모두 UMA와 DFT의 상대에너지가 높은 상관을 보였다. 강직계는 R² 0.96, RMSE 2.39 kJ/mol이고 Data set 2는 R² 0.97, RMSE 4.92 kJ/mol이다. 유연계만 R² 0.68, RMSE 9.07로 눈에 띄게 낮았다. (L61–63)

원문은 R²와 RMSE가 같은 리간드 안에서 순위가 보존됐는지를 직접 재지 않는다고 지적했다. 그래서 값이 아니라 순위에만 작용하는 Spearman ρ를 리간드마다 따로 계산했다. (L150 · 152)

- 그림 — Fig. 2: (a) 강직계는 점들이 회귀선에 바짝 붙는다. (b) 유연계는 |ΔE| < 25 kJ/mol 구간이 구조 없는 뭉치이고, 상관은 왼쪽 아래 소수 점이 떠받친다고 검토 측은 그림에서 읽었다. (L196 · 198)

### 순위는 흔들린다

Data set 1에서 순위 신뢰율은 강직계 84 %, 유연계 53 %였다. 유연계의 L2와 L12에서는 ρ가 음수로, UMA가 순위를 거꾸로 매겼다. 원문은 두 경우 conformer가 각각 8개, 6개뿐이고 ΔE_DFT가 모두 2 kJ/mol 미만이라고 설명했다. 링커가 짧은 dppm과 dppe는 형태공간이 좁아 양쪽 모두 순위가 맞았다. (L205 · 210 · 213 …)

Data set 2에서는 Ru 61 %, Mn 44 %가 신뢰로 판정됐다. 원문은 Mn(I) 착물이 더 fluxional해 PES가 얕고 복잡하다는 기전을 제시했지만 계산 근거는 없다. 실패 사례 L149의 Mn 배열은 기준 대비 0.2 kJ/mol 차이였고, 원문은 실패가 configuration 간 5 kJ/mol 미만에 몰린다고 적었다. (L85 · 248 · 253–254 …)

- 그림 — Fig. 3: 막대 색이 판정이고 빨간 파선은 ρ = 0.6이다. (a)의 L25는 파선 위인데 회색이라, 실제 판정이 p 필터에 걸린다는 것을 보여 준다고 검토 측은 본다. (L203 · 208)

### 어디까지 믿나

검토 측은 두 데이터셋의 신뢰율이 같은 척도가 아니라고 본다. Data set 2는 리간드당 배열이 4개라 p < 0.05를 통과하는 ρ는 1.0뿐이고, ρ=0.8은 p = 0.20으로 탈락한다. 따라서 61 %와 44 %는 네 배열 순위를 완벽히 맞춘 비율이며, 원문의 'A similar pattern' 병치는 방어되지 않는다고 판단한다. (L165 · 411 · 413 …)

검토 측은 near-degenerate 면책의 근거도 약하다고 본다. 실패 리간드 가운데 에너지 간격으로 설명된 것은 L2, L12, L133, L149뿐이고 ρ 대 에너지 간격 그림이 없다. 참조 DFT가 하나뿐이라 UMA 오차가 DFT 자체 불확실성과 같은 크기라는 주장은 측정되지 않았다. 이 화학은 OMol25 학습분포 안쪽이어서 in-distribution 성능만 잰 것이라는 점도 결론에 달리지 않았다. (L463 · 466 · 469)

- 그림 — Fig. 5: 히트맵은 Mn과 Ru 열 모두 대부분 초록인데 본문 신뢰율은 44 %와 61 %다. 검토 측은 ρ=0.8 셀이 n=4에서 모두 탈락하기 때문이라고 이 겉보기 충돌을 풀었다. (L249–250)

### 용어 풀이 (논문에 없는 일반 설명)

- **Spearman ρ**: 두 값 목록의 순위가 얼마나 같은 방향으로 움직이는지를 재는 비모수 상관계수로, 값의 크기나 분포 모양과는 무관하다.
- **configuration**: 이 논문에서는 팔면체 착물의 축방향 자리에 어느 주개원자 쌍이 놓이는가로 구분한 배위 배열을 뜻한다.
- **fluxional**: 분자 안의 리간드가 실온에서 자리를 바꿔 다니는 성질로, 에너지가 비슷한 국소최소가 촘촘해 순위 매기기가 어렵다.

### 우리 연구에 주는 뜻

- 이 논문의 UMA-s-1.1은 우리가 쓰는 uma-s-1p1과 같은 체크포인트 세대지만 task가 omol이라 우리 omat과 다르고, 우리가 하는 MD, 이완, NEB는 시험하지 않았다. (L21 · 107–108 · 337 …)
- 우리가 겪은 b2o3 O-자리 −6.63 eV 역전과 Li₃N 계통 편향은 near-degenerate 순위잡음이 아닌 분포 밖 계통 오답이라 이 논문의 면책으로 설명되지 않는다. (L356–357 · 359–360)
- 같은 프로토콜을 우리 S/Cl 무질서 배열에 UMA(omat) single-point 대 QE 총에너지로 돌릴 수 있고, 문턱은 52원자 셀당 ΔE로 다시 정해야 한다. (L373 · 375 · 377)

### 읽을 때 조심할 것

- Data set 2의 61 %와 44 %는 n=4라 사실상 완벽 순위 비율이므로 Data set 1의 84 %와 53 %와 같은 척도로 비교하면 안 된다. (L462 · 565 · 567)
- RMSE는 원자당이 아니라 구조당 값이고 omol task와 PBE0-D3/def2-SVP 기준이어서 주기계 meV/atom 오차 옆에 놓을 수 없다. (L65 · 382)
- single-point 에너지만 잰 in-distribution 결과이므로 힘, 이완, MD, 장벽, 분포 밖 화학에 대한 근거로 쓸 수 없다. (L53 · 346 · 466–467)
- Spearman p의 구현과 OMol25 전하, 스핀 입력이 원문에 없고, 구조 생성 도구 MACE는 MACE MLIP과 다른 물건이다. (L446–447 · 470)

- Fig. 5 히트맵을 본문 신뢰율과 나란히 놓고 n=4 산술로 겉보기 충돌이 풀리는지 본다. (L249–251)
- 서론 마지막 문단에서 기하최적화를 하지 않은 이유와 평가 범위의 자기 제한을 읽는다. (L50–51)
