## §1 RV2-N1 — 목적별 문턱 · 계산 순서

### 1-1. 기준 최소 Ĵ — 출처와 한 번의 공통 갱신

- **잠정 Ĵ⁽⁰⁾:** (셀 · 영역 · 목적) 마다 점 추정 단계 (§3-2 Phase A · 128 지역 실행) 반환점 중 **유효 증인** (§2-1) 의 최소. 유효
  증인이 0 이면 그 단위는 UNFIT (§2-3) 이고 뒤 단계를 돌리지 않는다.
- **최종 Ĵ:** 같은 (셀 · 영역) 의 **등록된 탐색이 모두 끝난 뒤 한 번**, 그 목적을 **자기 탐색 목적으로 쓴 단위**의 기록 점 (지역
  실행 반환점 · 명목 격자점 · H4 는 ray 점까지 — 유효 증인만) 전체의 최소. Ĵ_V · Ĵ_D 는 셀 · 영역별로 **서로 독립**이다 (재검토 문구):
  결합 단위의 반환점은 J_V · J_D 를 둘 다 평가하지만 두 풀에 넣지 않는다 — 결합 단위가 그보다 낮은 J_V · J_D 를 본 경우는 `결합이 본
  더 낮은 단일 목적값` 으로 따로 보고하고 문턱에 쓰지 않는다. 대조 (§4-4 · §4-5) 의 점은 탐색이 아니므로 넣지 않는다. 지역 실행 안의
  중간 평가는 기록하지 않으므로 넣지 않는다.
- **판독:** 모든 문턱을 최종 Ĵ 로 한 번 다시 계산하고, 모든 상태를 **저장된 값으로** 다시 읽는다 (새 탐색 없음). 최종 Ĵ ≤ Ĵ⁽⁰⁾ 이므로
  이 갱신은 문턱을 **조이기만** 한다 — 잡음 · 상대 문턱은 내려가고, ρ 는 분모가 줄어 커진다. 그래서 양의 증거 (COMPATIBLE · WIDE) 를
  줄이는 쪽으로만 움직이고 새로 만들지 않는다. **주 판정 = 갱신 뒤** · 갱신 전 판독은 부표로 함께 싣는다. 결과를 보고 둘 중 하나를
  고르지 않는다.
- 탐색은 문턱을 쓰지 않는다 (모두 목적의 최소화) — 그래서 문턱의 사후 갱신이 탐색 경로를 바꾸지 않는다. 예외는 결합 단위의 ρ (분모가
  탐색 목적 안에 있다) 뿐이다 — 탐색은 Ĵ⁽⁰⁾ 분모로, 판독은 최종 Ĵ 분모로 한다 (§1-3).

### 1-3. 결합 = ρ (v2 127 · 132–133 대체)

`ρ(x) = max(J_V(x)/Ĵ_V, J_D(x)/Ĵ_D)`. 각 δ 에서 `ρ(x) ≤ 1 + δ` ⇔ `J_V ≤ (1 + δ) Ĵ_V 且 J_D ≤ (1 + δ) Ĵ_D` — v2 의 벡터 제약 집합
`S_VD` 와 **정확히 같은 집합**이다. 결합 점 추정 = `argmin ρ` (v2 의 `argmin max(J_V/T_V, J_D/T_D)` 는 `T_o = (1 + δ) Ĵ_o` 에서
`ρ/(1 + δ)` 이므로 같은 점이고 δ 와 무관하다). ρ 의 발견 최소 ρ̂ 에 (1 + δ) 를 다시 곱하는 판정은 **두지 않는다** — 재검토의 대수
예처럼 단일 목적 최소를 1 로 두고 ρ̂ = 1.2 · δ = 0.1 이면 성분별 문턱은 1.1 인데 `1.2 × 1.1 = 1.32` 는 두 성분 문턱을 넘는 점까지
받는다. ρ̂ 은 보고만 한다 (ρ̂ > 1 + δ 이면 그 δ 에서 결합 증인 없음 = UNRESOLVED).

탐색 · 판독 분리: 결합 단위의 모든 탐색은 분모 `Ĵ⁽⁰⁾_V · Ĵ⁽⁰⁾_D` (A0 의 J_V · J_D 단위 Phase A — 결합 단위보다 먼저 끝난다 · §3-2) 로 ρ
를 최소화한다. 판독은 저장된 (J_V, J_D) 쌍을 최종 Ĵ 분모로 다시 나눈다 — 분모가 줄면 ρ 는 커지기만 한다 (§1-1).

### 1-4. H4 문턱 (v2 231–234 의 빈 T 를 채움)

`T_s = Ĵ_s + 2σ̂_v` **하나**로 정한다. H2 주 판정과 같은 잡음 폭 (V 단위 · 같은 셀의 σ̂_v) 을 형상 목적에 그대로 써서 H2 ↔ H4 비교를
같은 척도로 둔다. Ĵ_s 는 H4 자신의 기준 최소 (§1-2) · 상대 δ 판정은 H4 에 등록하지 않는다. 경계 근접 (`|T_s − J| ≤ 1e-9 V`) 의 뜻은
§4-6.

## §2 RV2-N2 — 유효 증인 · 수치 규칙 · P0

### 2-1. 유효 증인

기록 점 x (지역 실행 반환점 · 격자점 · ray 점) 가 **유효 증인**인 것은 다음이 모두 참일 때다. x 를 고치지 (clip · 투영) 않는다 — 반환점
그대로 판정한다.

1. **독립 재평가:** solver 가 보고한 `fun` 을 쓰지 않는다. 같은 고정 평가 함수로 x 에서 목적을 다시 계산한 값이 유한하다 (H4 는 §4-2
   의 교차 조건까지).
2. **선형 제약:** §2-2 의 수용 규칙 안 (잔차는 x 의 float 좌표를 정확한 유리수로 바꿔 계산한다).
3. 외삽 계수 `n_out_PE` · `n_out_NE` 는 유효성 조건이 아니라 **라벨**이다 (v2 §4-1 그대로 — `n_out > 0` = 외삽 의존).

유효하지 않은 점은 Ĵ · 증인 · 상태의 근거가 되지 못한다. 버리지 않고 이유별로 센다: `NONFINITE` (재평가 비유한 · 교차 실패) ·
`INFEASIBLE_RETURN` (§2-2 밖) · `SOLVER_ERROR` (예외 — 반환점 없음).

### 2-2. 수치 규칙 (단위 · 근거) — v2 192 "영역 잔차 0" 대체

| 검사 | 단위 | 수용 |
|---|---|---|
| 상자 `xl ≤ x ≤ xu` (소거된 좌표의 상자 포함 — §3-3) | m: 무차원 · d: 원 코드의 용량 좌표 (q_PE_hc 와 같은 단위 — v2 §1-4 의 mAh 환산) | 좌표마다 위반 ≤ `1e-10` (그 좌표의 단위) |
| G `d_P − d_N ≥ 1e-4` | d 단위 | 위반 ≤ `1e-10` |
| 프로파일 등식 `h_k(x) = t` | 무차원 (h 좌표) | 위반 ≤ `1e-10` — 등식은 소거로 만족시키므로 (§3-3) 이 검사는 반올림 확인이다 |
| 명목 τ 상자 `‖h(x) − h_true‖∞ ≤ τ` | 무차원 | 위반 ≤ `1e-10` |
| 목적 문턱 `J ≤ T` | 목적 단위 (V · V/mAh · ρ 무차원) | 고정 환경의 float 비교 · 같음은 충족 · `|T − J| ≤ 1e-9` 이면 **경계 근접** 라벨 (판정은 그대로 · 근접 증인에만 기대는 상태는 그 라벨을 달고 보고) |

- 근거: 좌표와 h 는 크기 O(1) 이고 double 의 반올림 단위는 2⁻⁵² ≈ 2.2e-16 이다. `1e-10` 은 그 약 10⁵ 배라 계산 잔차 (예: scale 변환
  왕복의 1 ulp 넘침) 를 흡수하고, 판정 해상도 (G 여유 1e-4 · τ ≥ 0.02 · LII 로 옮기면 `1e-10/max_q`) 보다 6 자릿수 이상 작아 어떤
  상태도 바꿀 수 없다. `1e-9` (목적 단위) 는 H4 구현 대칭 기준 (§4-4) 과 같은 값이다 — 목적 계산의 반올림 (상대 ~1e-15) 보다 충분히
  크고, 의미 있는 잔차 차이 (mV 급) 보다 충분히 작다.
- **±0.02 · ±0.05 는 성능 판정 허용오차이지 이 표의 계산 오차 허용치가 아니다** — 섞지 않는다. 이 값들은 결과를 본 뒤 넓히지 않는다.
- solver 의 종료 판단 (§3-1 `feasibility_tol` 등) 은 이 수용 규칙과 **독립**이다 — solver 가 수렴 · feasible 이라고 해도 위를 못 넘으면
  증인이 아니다.

### 2-3. 종료 상태 ↔ 증인 유효성 분리 — v2 197 대체

지역 실행마다 두 필드를 따로 적는다.

| 필드 | 값 |
|---|---|
| `termination` | `converged` (solver 가 자기 기준으로 끝냄) · `budget` (`maxfev` · `maxiter` 도달) · `solver_error` — solver 의 원 status · message 를 함께 그대로 |
| `witness` | `valid` · `invalid:<NONFINITE · INFEASIBLE_RETURN · SOLVER_ERROR>` |

- `budget` 으로 끝났어도 반환점이 유효하면 **증인으로 쓴다** — "수렴" 이라고 쓰지 않고 `budget` 을 함께 적는다 (실용 선택: 유효 증인은
  보존하고 최적화 미완을 병기).
- UNFIT (계산) = **그 단위의 Phase A 128 반환점 중 유효 증인 0** — 종료 상태와 무관하다. v2 의 "지역 방법 전부 실패" 를 이것으로 바꾼다.
  자료 쪽 UNFIT (빈 마스크 · σ̂_v 정의 불가 · 자료 영역 부적합) 은 v2 그대로.
- 프로파일 격자점의 네 실행이 모두 무효이면 그 점은 `실패` (§3-7 · 미해결).

### 2-4. Ĵ 는 유효 증인으로만 — v2 173 대체

"128 결과의 최소" → "128 반환점 중 **유효 증인**의 (재평가) 최소". 무효 수와 이유 (§2-1) · 두 seed 묶음 각각의 유효 최소 (탐색 안정
지표 · 문턱 없음) 를 함께 보고한다.

### 2-5. P0 — 닫힌 구간식 (v2 87 · 164–165 대체)

P0 의 사전 양립성 `{x ∈ A : ‖h(x) − h_true‖∞ ≤ τ} ≠ ∅` 를 선형 계획 없이 **닫힌 구간식**으로 판정한다 (재검토의 유도 · 우리 대조 —
같은 식 · 자료 계산 아님).

- 기호: `P = [m_P* − τ, m_P* + τ] ∩ (m_P 상자)` · `N = [m_N* − τ, m_N* + τ] ∩ (m_N 상자)` · `I = [LII* − τ, LII* + τ]` · offset 차
  `Δ = d_P − d_N` 의 영역별 구간 D: **A0 = [1e-4, 0.5]** · **A1 = [1e-4, 2]** · **A2 = [−2, 2]**. (D 는 `[lo(d_P) − hi(d_N),
  hi(d_P) − lo(d_N)]` 에 G 가 있으면 `[1e-4, ∞)` 를 교차한 것 — 두 offset 이 독립 구간이라 차가 그 구간 전체를 채운다.)
- `LII = m_P − Δ/max_q` 이므로 `m_P − LII = Δ/max_q`. m_P 가 P 를 연속으로 움직일 때 `[m_P − max I, m_P − min I]` 의 합집합은 연결된
  구간 `[min P − max I, max P − min I]` 다.
- **양립 ⇔ P ≠ ∅ 且 N ≠ ∅ 且 `[min P − max I, max P − min I] ∩ (D / max_q) ≠ ∅`** (max_q > 0). m_N 은 LII 와 무관하므로 N 은 상자
  검사뿐이다.
- 계산은 **정확한 유리수**로: 명목값 · τ · 상자 · `1e-4` 는 십진 문자열에서 (`Fraction("0.64")` 처럼), max_q 는 그들 경로가 만든 float
  값 그대로의 정확한 유리수 (`Fraction(max_q)`). 구간은 닫힌 구간이라 끝점이 닿으면 양립이다. 반올림한 값 (3.85 · 8.3) 을 판정에 쓰지
  않는다.
- 결과 셋: `PRIOR_COMPATIBLE` · `PRIOR_INCOMPATIBLE` · **`P0_UNFIT`** (max_q 가 유한한 양수가 아님 · 자료 읽기 · 시트 · step 추출 실패).
  수치 · 자료 실패를 PRIOR_INCOMPATIBLE 로 바꾸지 않는다. 구간 끝점은 분수와 십진 근사를 둘 다 적는다.
- 프로파일의 t 범위 (v2 183 "선형 계획") 도 같은 식이다: m_P · m_N 은 상자 구간 · LII 는 `[lo(m_P) − hi(D)/max_q, hi(m_P) −
  lo(D)/max_q]`.

## §3 RV2-N3 — 결정적 탐색 · 보고 · 예산

### 3-1. 판 · 옵션의 사전 고정 (v2 172 "판 기본값" 대체)

지역 방법 = SciPy `minimize(method="COBYQA")`. 옵션은 판 기본값에 기대지 않고 **모두 명시**한다.

| 옵션 | 값 | 비고 |
|---|---|---|
| `maxfev` | 2000 | v2 와 같음 · 변수 수 (4 · 프로파일 소거 뒤 3 · 다듬기 1) 와 무관하게 고정 — §3-8 상한의 근거 |
| `maxiter` | 4000 | 고정 |
| `f_target` | −∞ | 목표값 조기 종료 없음 |
| `feasibility_tol` | 1e-12 | solver 의 내부 판단 — 증인 수용 (§2-2 · 1e-10) 보다 엄격하게 두어 solver 의 "feasible" 반환이 수용 규칙 안에 들게 한다 · 둘은 독립 |
| `scale` | True | m (폭 0.5–1.2) · d (폭 0.5–2) 의 범위가 달라 bounds 로 [−1, 1] 정규화 |
| `initial_tr_radius` | 1.0 | 정규화 좌표 기준 |
| `final_tr_radius` | 1e-6 | 정규화 좌표 기준 |
| `disp` | False | |

- **판 고정은 실행 승인 때** 한다 (환경 고정 — PyBaMM 라운드의 목적별 분리 환경과 같은 방식). 고정 판에서 위 옵션의 이름 · 의미가 다르면
  **실행하지 않고** 이 표를 새 등록으로 고친다 (fail-closed). 실행 기록에는 solver 가 실제로 받은 옵션을 남겨 이 표와 대조한다 — 기록이
  사전 결정을 대신하지 않는다.
- 이 값들의 적합성 (무효 반환 비율 등) 은 실행 0 이라 확인하지 않았다. 비용 측정 (§3-9) 을 본 뒤 바꾸면 그 뒤 실행은 새 등록이고 그
  측정은 파일럿이다.
- 준-무작위 시작점: `scipy.stats.qmc.Sobol(d, scramble=True, <seed>)` · 점 수는 2 의 거듭제곱 (64 · 2 · 16). 판에 따라 seed 인자 이름과
  생성 배열이 다를 수 있으므로 **모든 시작점 배열을 맞춤 전에 만들어 sha256 으로 봉인**한다 (max_q 에 기대는 슬라이스 · τ 상자
  시작점은 P0 뒤 · 맞춤 전).

### 3-2. 계산 순서 (셀 · 영역마다)

1. **Phase A (점 추정 · H1):** J_V (A0 · A1 · A2) · J_D (A0) · J_V^s (A0 · A1) 각각 128 실행 = Sobol 64 (seed 0) + Sobol 64 (seed 1) ·
   4 차원 · 영역 상자 위 (G 를 어기는 시작점은 그대로 둔다 — v2 그대로). → Ĵ⁽⁰⁾.
2. **결합 Phase A:** A0 의 J_V · J_D Phase A 가 끝난 뒤 ρ (분모 Ĵ⁽⁰⁾) 로 128 실행 (같은 seed 0 · 1 배열).
3. **Phase B (집합):** 단위마다 프로파일 (§3-3) → 동시 양립 (§3-4) → 명목점 정확 대조 (§3-5). H4 는 그 뒤 ray (§4-6).
4. **공통 갱신 · 판독 (§1-1):** 그 (셀 · 영역) 의 모든 단위가 끝난 뒤 한 번.

### 3-3. 프로파일 (v2 183 대체)

- **격자:** 좌표 k 의 t 범위 (§2-5 의 닫힌 식) 의 41 등분점 + 명목 · 명목 ± 0.02 · ± 0.05 (십진 값 → float). 범위 밖의 추가점은
  `미평가 (영역 밖)` 로 적고 돌리지 않는다. 같은 float 값은 한 번만 돌린다 (`미평가 (중복)`). 오름차순 정렬.
- **등식 소거:** k = m_P → `m_P := t` · k = m_N → `m_N := t` · k = LII → `d_N := d_P − max_q (m_P − t)`. 자유 변수의 상자는 bounds · G 는
  선형 제약이다. d_N 이 소거되는 것은 k = LII 일 때뿐이고, 그때 d_N 의 상자는 선형 제약이 되며 G 는 `m_P ≥ t + 1e-4/max_q` 가 된다. 내부 최소화는 3 변수 COBYQA (§3-1 옵션).
- **순회 — sweep 하나 · 숨은 추가 sweep 없음:** 중심점 = Ĵ⁽⁰⁾ 를 낸 Phase A 최적 증인 x̂⁽⁰⁾ 의 h_k 에 가장 가까운 격자점 (같으면 작은 t).
  나머지는 (중심과의 거리, t) 오름차순 — 바깥으로 번갈아 나간다.
- **시작은 정확히 4:**
  1. s1 = x̂⁽⁰⁾ 의 자유 좌표 (k 좌표만 t 로 — 소거식이 나머지를 정한다).
  2. s2 = **안쪽 이웃** (중심 쪽으로 붙은, 이미 끝난 격자점) 의 최적 유효 증인의 자유 좌표. 그 점에 유효 증인이 없으면 안쪽으로 더 걸어가
     처음 만나는 유효 증인 · 끝까지 없거나 중심점 자신이면 Phase A 의 두 번째 유효 증인 (J 순 · 같으면 실행 번호 순).
  3. s3 · s4 = 자유 변수 상자 위 Sobol 2 점 (seed = §3-6).
  - 시작점은 bounds 안이면 된다 — 선형 제약 (G · 소거 좌표의 상자) 위반은 그대로 둔다 (Phase A 규칙과 같다). 증인 좌표가 bounds 를
    반올림만큼 넘으면 시작점으로 쓸 때 bounds 로 자른다 (시작점 구성일 뿐 증인 판정이 아니다 — §2-1).
  - 시작점 둘이 정확히 같으면 뒤의 것을 다음 대체 후보 (Phase A 의 다음 유효 증인) 로 바꾼다. 후보가 바닥나면 `시작 부족` 을 적고 적은
    수로 돈다 — 남는 예산을 다른 점으로 넘기지 않는다.
- **격자점의 값:** `J_k(t)` = 네 실행의 유효 반환점 중 최소 (그 x 가 증인).

### 3-4. 동시 양립 (v2 185 대체)

τ ∈ {0.02, 0.05} 마다 (P0 가 PRIOR_INCOMPATIBLE 이면 돌리지 않는다) 시작 16 = **Phase A 유효 증인 J 순 상위 4** (m_P · m_N 을 P · N
으로 자른 점 · d 는 그대로) + **Sobol 12** (상자 `P × N × (d_P 상자) × (d_N 상자)` 위 Sobol 16 점 중 앞 12 · seed = §3-6). bounds =
그 상자 · 선형 제약 = G 와 `LII(x) ∈ I` 의 두 면. 동시 증인 = 유효 반환점 중 J ≤ T 인 것 (최소를 보고).

### 3-5. 명목점 정확 대조 (τ = 0 · v2 186 대체)

P0 의 τ = 0 이 PRIOR_INCOMPATIBLE 이면 돌리지 않는다. m_P · m_N 을 명목에 고정하면 `Δ* = max_q (m_P* − LII*)` (정확 유리수로 계산한 뒤
float). d_N 의 허용 구간 `[max(lo(d_N), lo(d_P) − Δ*), min(hi(d_N), hi(d_P) − Δ*)]` 의 201 등분 격자 평가 → 최저 격자점 (같으면 작은
d_N) 에서 1 변수 COBYQA 다듬기 1 회 → 둘 중 유효한 최소.

### 3-6. seed 규칙

Phase A = seed 0 · 1 (v2 그대로). 그 밖의 모든 Sobol 은 `seed = int(sha256(label).hexdigest()[:8], 16)` ·
`label = "reil-v2a|<셀 #>|<영역>|<목적>|<단계>|<k>|<격자 index>|<τ>"` (해당 없는 칸은 `-`). 판과 무관하게 label → seed 가 정해지고, 생성
배열은 §3-1 대로 봉인한다.

### 3-7. 보고 단위 (v2 183 "끊긴 구간" 대체)

- 프로파일 격자점마다 상태 하나: **`충족`** (유효 증인 · `J_k(t) ≤ T`) · **`초과`** (유효 증인은 있으나 최소가 T 초과) · **`실패`** (네
  실행 모두 무효) · **`미평가`** (영역 밖 · 중복). `초과` · `실패` = **미해결 격자점**. 낮은 목적값을 찾은 점 (`J < Ĵ⁽⁰⁾`) 은 따로
  표시한다 (§1-1 공통 갱신의 근거).
- 41 + 5 점은 **관측한 투영 점들의 집합**이다 — 연속 구간의 충족 · 공백 · 연결 성분을 증명하지 않는다. "끊긴 구간" 대신 "충족 / 미해결
  격자점" 으로 보고하고, 그림의 연결선은 시각 보조라고 적는다.
- WIDE = 서로 2τ 넘게 떨어진 `충족` 격자점 둘 (v2 정의 그대로 — 관측 점 기준).

### 3-9. 비용 측정의 승인 경계 (v2 216 대체)

한 셀 · 한 단위의 비용 측정은 **맞춤이다** — P0 와 다르게 본다. 이 문서는 그 측정을 등록하지도 승인 요청하지도 않는다. 측정 승인을
요청할 때 그 요청문이 **측정 전에** 고정해야 할 것과 우리 제안:

|---|---|

| 최대 작업 · 벽시계 | 128 실행 · 실행 수 상한 · 벽시계 상한을 요청문에 숫자로 |
| 확인적 분석 포함 여부 | **제외** (파일럿) — 확인적 실행은 그 단위를 처음부터 다시 돈다 |
| 측정 뒤 바꿀 수 있는 것 | 벽시계 예산표 · 병렬 수만. 문턱 · 수치 규칙 · 옵션 · 시작 · 격자 · 상태 정의는 바꾸지 않는다 — 바꾸면 그 측정은 탐색 / 파일럿이고 바뀐 등록은 새 판 |

## §4 RV2-N4 — H4 의 계산 대조와 과학적 반증의 구분

### 4-1. 이름 (v2 230 "격자 의존 제거" 철회)

모델 쪽 cutoff 교차는 **"고정 1000 점 선형 교차 근사"** 다. 원 코드의 250 점 최근접 index 를 다른 고정 근사로 바꾼 것이지 격자 의존을
없앤 것이 아니다. 더 촘촘한 계산은 등록하지 않는다.

### 4-2. 모델 쪽 교차 · span

`Q_j = linspace(0, max Q_PE, 1000)` · `V_j = V_full(Q_j)`. cutoff c ∈ {2.0, 3.6} V 마다:

- 구간 j 가 c 를 품는다 ⇔ `(V_j − c)(V_{j+1} − c) ≤ 0`. 품는 구간마다 선형 보간 교차 `Q_c = Q_j + (c − V_j)(Q_{j+1} − Q_j)/(V_{j+1} −
  V_j)`. `V_j = V_{j+1} = c` (평탄 구간) 이면 그 x 의 H4 목적은 **비유한**.
- **원시 교차 수**와 **유일 물리 교차 수**를 따로 센다. 교차가 격자점에 정확히 놓이면 (`V_j = c`) 이웃 두 구간에서 같은 Q 로 두 번 나온다
  → 같은 float Q 의 교차는 하나로 합친다. 유일 교차가 정확히 1 이 아니면 비유한.
- span: 실험의 시작 cutoff c_a (§4-3) 의 교차 Q_a · 다른 cutoff 의 교차 Q_b · `span = Q_b − Q_a`. **span ≤ 0 이면 비유한** (방향이 실험과
  반대이거나 한 점). `s = (Q − Q_a)/span`.

### 4-3. 실험 쪽 끝점 수용 (v2 229 대체)

P0 가 셀마다 원 측정점의 첫 · 끝 전압 `V_first` · `V_last` 를 기록한다 (v2 §4-2 그대로). **c_a = V_first 에 가까운 cutoff · c_b = 다른
cutoff ({c_a, c_b} = {2.0, 3.6} V). 수용 ⇔ `|V_first − c_a| ≤ ν` 且 `|V_last − c_b| ≤ ν`, ν = 0.01 V.** 아니면 그 셀의 H4 = UNFIT. 실험 쪽은 `Q_a = 0` · `Q_b = Q_exp_max`
(그들 추출 구간의 양 끝).

ν 는 **사전 선택한 수용 폭**이다 — 측정 해상도에서 유도한 값이 아니다 (자료 미개봉 · 해상도 미상). 저율 (C/20) cutoff 판정과 기록 간격이
만드는 끝점 어긋남의 상한으로 둔 선택이며, P0 에서 끝점을 본 뒤 바꾸지 않는다. 휴지 뒤 이완 전압 (cutoff 가 아닌 곳) 에서 시작한 구간은
이 규칙이 거른다.

### 4-4. 양성 대조 — 구현 대칭 (v2 233 의 양성)

기준점 후보 (사전 고정 · 이 순서): **R1 = (1.0, 1.0, 0.10, 0.05) · R2 = (0.9, 0.9, 0.20, 0.10) · R3 = (0.8, 0.8, 0.15, 0.05)** (x = m_P ·
m_N · d_P · d_N). 셋 모두 c ∈ {0.9, 1.1} 에서 c·x 가 A0 상자 ∩ G 안이다 (대수 확인 — R1 의 1.1 배는 m 상한 1.1 에 닿는다). 셀마다
x · 0.9x · 1.1x 셋이 모두 유효 (§2-1 · n_out = 0 · §4-2 교차 · span > 0) 인 첫 후보를 쓰고, 없으면 그 셀 H4 = UNFIT (구현 검증 불가).

통과 ⇔ `|J_V^s(c·x) − J_V^s(x)| ≤ 1e-9 V` (c 둘 다). 1e-9 V 는 **구현 대칭 검사 기준**이지 실험 정밀도가 아니다. 실패 → H4 구현 기각
(모든 셀의 H4 중단 · 구현 점검) — 실측 가설의 판정이 아니다.

### 4-5. 음성 대조 — 구별이 알려진 곡선 기준 (v2 233 의 음성 대체)

v2 의 "절대 용량 J_V 는 둘을 구별한다" 는 실측 자료에서 **항상** 성립하지 않는다 (오차 norm 이 우연히 같을 수 있다 — 재검토). 그래서
자료가 아니라 **모델 곡선끼리** 비교한다. 같은 기준점 x (§4-4) 에서

- `D_abs = RMSE_k |V_full^{c·x}(Q_k) − V_full^{x}(Q_k)|` · `Q_k = linspace(Q_lo^x, Q_hi^x, 100)` (x 자신의 두 cutoff 교차 사이 · 절대
  좌표). c·x 의 곡선은 Q 축이 c 배 늘어난 것 (`V^{c·x}(Q) = V^{x}(Q/c)`) 이므로 비평탄 곡선에서 0 이 아님이 알려져 있다. 반쪽전지
  곡선만 쓰므로 셀과 무관하다 — 기준점마다 한 번.
- 통과 ⇔ `D_abs > 1e-6 V` (c 둘 다). 1e-6 V 는 양성 기준 1e-9 V 보다 세 자릿수 큰 "구별됨" 판정선이다.
- 실패 → **구현 · 수치 점검** (예: 절대 목적이 실수로 정규화됨) — H4 가설의 기각이 아니다.

### 4-6. ray 의 해석 범위 (v2 234 대체)

- **대칭은 모델의 대수다.** 정적 모델에서 x → c·x 는 Q 축을 c 배 늘리고 (PE 선형 외삽 · NE 상수 연장 · 1000 점 격자 모두 함께 늘어난다)
  양쪽 정규화가 그것을 지운다. 유효한 ray 점에서 J_V^s 가 같은 것은 **채택한 모델의 조건부 구조**이지 실측 동역학의 검증이나 반증 가능한
  예측이 아니다. v2 의 "반증: … ray 위의 점 (직접 평가) 이 T 를 넘으면 예측 기각" 을 **철회**한다.
- 셀 · 영역마다 H4 최적 증인 x̂_s 의 ray `{c·x̂_s}`: c 의 허용 구간 (상자 · G 가 c 에 거는 선형 부등식의 교집합 — 닫힌 꼴) 의 41 등분점 +
  c = 1 을 **직접 평가**한다.
- **ray 점 분류 (먼저 이것부터):** ① `외삽 의존` (n_out > 0) · ② `cutoff 경계` (유일 교차 ≠ 1 · span ≤ 0) · ③ 유효 점에서
  `|J_V^s(c·x̂_s) − J_V^s(x̂_s)| ≤ 1e-9 V` → `대칭 확인` · ④ 유효 점인데 그 차가 1e-9 V 초과 → **`구현 · 수치 경계`** (H4 구현 재점검
  대상 — 실측 가설의 반증이 아니다).
- **문턱 판독:** 유효 ray 점의 J_V^s ≤ T_s → `ray 증인`. x̂_s 의 여유 `T_s − J_V^s(x̂_s)` 가 1e-9 V 미만이면 ray 점이 대칭 허용 안에서도
  T_s 를 넘을 수 있으므로 그 셀의 ray 판독 전체를 `수치 경계 미해결` 로 적는다 (이탈로 읽지 않는다).
- **보고:** 직접 확인한 ray 증인의 c (관측 점 목록 · 최소 · 최대) 와 양 끝의 경계 원인 (상자 · G · 외삽 · cutoff). **ray 의 모든 점을
  확인했다고 쓰지 않는다.** 상자 끝에 닿았다는 사실만으로 실측 세 모드가 구조적으로 식별 불가능하다고 확정하지 않는다 (v2 그대로).
- H4 의 경험적 내용은 ray 가 **어디서 멈추는가** (영역 · 외삽 · cutoff) 와, J_V^s 의 근최적 집합이 ray 밖으로도 열리는가 (H4 단위의
  프로파일 · 동시 양립 — §3-3 · §3-4) 에 있다.

## §5 상자 문구 정정 (v2 §1-3 · §1-4)

### 5-1. #0 · #4 · #5 (v2 82–83 대체)

명목점은 G 의 경계 위가 **아니다** — `d_P = d_N` 인 **무여유 선 위, 곧 G 밖**이다 (G 는 `d_P − d_N ≥ 1e-4` 를 요구). τ = 0 에서는 A0 ·
A1 에서 모든 max_q 에 대해 PRIOR_INCOMPATIBLE 이다 (A2 는 G 가 없어 양립). τ = 0.02 의 양립은 **max_q 에 조건부**다 — §2-5 식으로
`[−0.04, 0.04] ∩ [1e-4/max_q, (hi D)/max_q] ≠ ∅` ⇔ **`max_q ≥ 1/400`** (A0 · A1 · 세 행 모두 m 이 상자 안). P0 가 확정한다. LII 위쪽
폭의 "제약 절단" 표시는 그대로다.

### 5-2. τ = 0 의 A0 양립 — 정확 비율 · 양쪽 조건 (v2 89–94 대체)

| 행 | m_P − LII | A0 에서 τ = 0 양립 ⇔ (필요충분) |
|---|---:|---|
| #1 · #7 | 1/10 | `1/1000 ≤ max_q ≤ 5` |
| #2 · #8 | 1/5 | `1/2000 ≤ max_q ≤ 5/2` |
| #10 | 13/100 | `1/1300 ≤ max_q ≤ 50/13` (≈ 3.8461538) |
| #6 · #9 | 3/50 | `1/600 ≤ max_q ≤ 25/3` (≈ 8.3333333) |

τ = 0 에서는 P · I 가 점이라 §2-5 식이 그대로 이 표가 된다 (m 은 모두 상자 안). 십진 근사는 읽기용이고 판정은 분수로 한다. v2 표의 3.85 ·
8.3 과 상한 한쪽만 적은 것을 대체한다. τ > 0 이나 A1 · A2 는 표로 미리 적지 않고 P0 가 §2-5 식으로 계산한다.

### 5-3. #2 · #8 의 τ = 0.02 (v2 97–99 대체)

§2-5: `[0.98 − 0.82, 1.02 − 0.78] = [0.16, 0.24]` → A0 양립 ⇔ **`1/2400 ≤ max_q ≤ 25/8 = 3.125`** (τ = 0.05 는 `[0.10, 0.30]` → `1/3000 ≤
max_q ≤ 5`). 우리가 가정한 max_q ≈ 3.0–3.3 (자료 아님 · v2 §1-4) 은 **3.125 를 사이에 둔다** — 그 범위 전부를 "경계" 라고 부르지 않는다.
3.125 이하면 양립 · 넘으면 배제이고, 어느 쪽인지는 P0 가 정한다.

### 5-4. 영역 셋의 보고

A0 · A1 · A2 는 **서로 다른 분석**으로 셋 다 보고한다. A2 의 양립을 A0 의 성공으로 합치지 않고, 세 상태표가 모두 나오기 전에 유리한
영역만 결론으로 고르지 않는다. 예산 종료 · UNFIT · 미해결도 예정 표에 남긴다.

## §7 증거 라벨의 구조 (재검토 권고 — v2 §4-5 의 해석 정정)

v2 §4-5 의 여섯 상태는 서로 배타적인 칸이 아니라 **함께 붙는 라벨**이다. (셀 · 영역 · 목적 · τ) 마다 축별로 따로 저장한다.

| 축 | 값 |
|---|---|
| 양립 (개별 k · 동시 각각) | `COMPATIBLE` (증인) · `NOT_FOUND` (미해결) · `PRIOR_INCOMPATIBLE` (P0) |
| 발견 폭 (좌표 k) | `WIDE` · `NARROW_FOUND` (미해결) |
| 계산 | `OK` · `UNFIT:<이유>` · `P0_UNFIT` |
| 부가 | `외삽 의존` · `제약 절단` · `경계 근접` (§2-2) · `수치 경계 미해결` (§4-6) · `budget` 종료 증인 |

COMPATIBLE 과 WIDE 는 함께 붙을 수 있다. 이 설계는 양립 · 넓음의 **양의 증거**를 얻을 수 있지만 좁음을 인증하지 못한다 — 긍정적 축퇴
증거를 못 찾은 것이 식별 가능성의 입증도 아니다 (v2 의 비대칭 그대로).

## §8 이 문서가 아닌 것

실행 · P0 · 비용 측정 · 맞춤 · 설치 · 구현의 승인이 아니고, 결과도 우리 축퇴 결론의 근거도 아니다. GATE88 · PyBaMM 고정 라운드와
무관하다 (게이트 차수 밖). 이 문서의 선택은 재검토 대상이고, 수용된 뒤에도 C1-core · 판 고정 · P0 · 비용 측정 · 실행의 별도 사용자
승인은 그대로 남는다.
