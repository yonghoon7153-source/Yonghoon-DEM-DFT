## 4. 합격선 (**런 전 고정**)

- **T1**: 전자 +PTFE 예측이 실측 0.12 의 **×3 이내** (|Δlog₁₀| ≤ 0.477).
- **T2**: +SDCP 전자 RVE 에서 SDCP 상의 **z-스패닝 성분 부재** (모든 시드).
  연결성분 크기 분포를 별도 관측량으로 저장한다.
- **T3**: 순서 +PTFE < neat < +SDCP 가 모든 시드 평균에서 성립.
- **시드 요건**: 팔당 시드 **≥ 4**.  T1 예측의 시드 SE(log₁₀)가 **0.16 이하**
  (= 합격 반폭의 1/3, bridge prereg 의 SE 규약과 같은 꼴)여야 판정한다.  넘으면 시드를
  늘리고, 그래도 넘으면 **판정하지 않는다**.
- **감도 (판정 뒤집힘 검사)**: ρ_SDCP proxy 1.30 을 **1.1 / 1.7** 로 흔들어 (vol% 12.7–18.2 %
  상당) T1·T2 판정이 뒤집히면 `SENSITIVE` 로 기록하고 **합격을 선언하지 않는다**.

**판정 표기**: T1·T2·T3 전부 통과 = `CALIB_VALIDATED` / T2 실패 = `MODEL_REJECTED`
(퍼콜 오류는 파라미터로 못 가린다) / T1 만 실패 = `BLOCKING_NOT_TRANSFERABLE`
(이온 보정은 유효하되 전자 이관 불가 — 이것도 결과다) / 시드·감도 요건 미달 = 판정 없음.

## 5. 실패 조건 (**무엇이 나오면 모델이 틀렸다고 적을 것인가**)

1. ③ 또는 ⑥ 이 **비물리 값**을 요구 (σ < 0, 또는 σ_e(SDCP) 가 σ_e(LPSCl) 보다 작아야만
   1.53 이 맞는 경우) → 표현이 틀린 것이다.  파라미터를 늘리지 않고 **기각을 기록**한다.
2. **T2 실패** (모델 퍼콜) → 복셀 스탬프가 이 vol% 에서 가짜 연결을 만든다는 뜻 =
   `MODEL_REJECTED`.  이 경우 A 트랙의 채널 B(가짜 근접 연결)와 같은 병인일 수 있음을
   기록하되, **이 런에서 인과를 주장하지 않는다**.
3. ② 의 노브가 물리 범위 밖 (피복 > 100 % 등) → "복셀 이산화로 PTFE 차단을 표현할 수
   없다" 를 원고에 적는다.  **그것도 결과다.**

## 6. 음성 대조 (**필수**)

1. **희석 재현** — ② ③ 노브를 전부 끄면(스탬프만) 이온 축이 희석 산술(3.09 / 2.82)의
   **±10 % 안**이어야 한다.  RVE 가 Bruggeman 과 정확히 같을 이유는 없으므로 이건
   게이트가 아니라 **기록 관측량**이되, ±10 % 를 넘으면 RVE 구성 자체를 의심한다.
2. **축 간 기하 동일** — 이온/전자 팔의 `input_digest` 가 쌍별로 동일해야 한다
   (`--compare-dir` 규약).  다르면 "같은 기하로 예측했다" 가 거짓이 된다.
3. **기본값 no-op** — 새 노브(②)를 안 주면 기존 결과와 비트 동일 (bridge 와 같은 규약,
   회귀 상주).

  (250 은 논문 밖 가정값, ⑥ 은 이 논문 Figure 2 앵커값.  출처 계보가 다르다).
