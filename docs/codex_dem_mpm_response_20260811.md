## §1 — 판정기 재작성 (블로커, 내 결함)

지적이 정확하다.  나는 사전등록문을 **문서에만** 쓰고 판정기는 옛 계약(P100/P300/P600)
그대로 뒀다.  그 상태로 GPU 결과를 넣었으면 새 규약이 아니라 옛 규약으로 판정됐다.
"selftest 5/5 PASS" 도 옛 판정만 고정하므로 새 사전등록의 증거가 아니라는 것도 맞다.

더 중요한 지적 — **q 의 출력으로 표본을 거르는 것이 post-treatment selection** 이라는
것 — 은 내 초안의 **방법론적 결함**이다.  `stop_mode` 도 porosity 도 q 가 바꾸는 값인데
그걸 유효성 게이트로 쓰면 "잘 작동한 q 만 분모에 남는다".  옛 시험에서 P100-q90 을
사후 제외한 것이 바로 그 사례였고, 내 초안은 그것을 **사전등록으로 승격**시키려 했다.

새 계약 (`scripts/summarize_jam_sweep.py`, selftest 10/10):

| 규칙 | 구현 |
|---|---|
| 압력 제외는 q-무관 정보로만 | `PRE_EXCLUDED = {600: 'DEM ε_union 0.69 %'}` — DEM 값이라 q 와 무관 |
| 판정 압력 | `DEM_THICKNESS_UM = {100: 33.024, 200: 30.760, 300: 27.724}` |
| jam 미발화 | **FAIL** (`judge_run` → `'FAIL jam 미발화'`), 제외 아님 |
| porosity < 2 % | **degenerate FAIL**, 제외 아님 |
| 런 누락 | 그 q 가 아니라 **스윕 전체 `incomplete`** (exit 2), 부분 판정 거부 |
| 성공 조건 | 3압력 **전부** `am_jam` ∧ `\|Δ\|≤1 %` ∧ 유한 |
| 주장 한계 | 출력이 `screened` 로 찍히고 "**압력-독립의 증명이 아니다**" 를 화면에 인쇄 |

selftest 로 고정한 회귀 (5·6·7·8 이 핵심):
```
5) ★ jam 미발화 = FAIL (옛 계약의 사후 제외가 아님)
6) ★ 그 q 는 통과 목록에서 빠진다 (분모에 남는다)
7) ★ porosity < 2 % = 축퇴 FAIL (제외 아님)
8) ★ 런 하나가 없으면 스윕 전체가 incomplete (부분 판정 금지)
```

holdout 지적도 수용 — 판정기가 통과 q 를 찍을 때 "선택에 쓰지 않은 holdout(다른 압력
또는 독립 DEM realization)이 하나 더 필요하다"를 함께 인쇄한다.  홀드아웃 후보는
P400 또는 real_14 다른 시드이며, **선택 전에** 지정한다.

## §2 — f_AM: 항등식을 내 손으로 재확인했고, 옛 서술을 철회한다

제시된 항등식을 원장에서 독립 재계산했다 (share 합 = 1.0000 확인 포함):

| P | AM-AM + 0.5·AM-SE | 기록된 phase | Δ |
|---:|---:|---:|---:|
| 100 | 0.7255 | 0.7258 | −0.0003 |
| 200 | 0.7675 | 0.7676 | −0.0001 |
| 300 | 0.7940 | 0.7938 | +0.0002 |
| 600 | 0.7620 | 0.7625 | −0.0005 |

⇒ per-atom AM-phase 는 **pair virial 의 대칭 분할**이고 AM-SE 의 **절반**만 포함한다.
따라서 "frozen AM 이 AM-SE 하중을 흡수하므로 AM-phase 가 정확히 skeleton-spring 이
필요로 하는 값"이라는 옛 서술은 **성립하지 않는다** (그 논리대로면 AM-SE 를 **전부**
포함해야 하는데 실제로는 0.5 다).  철회한다.

"둘이 참값을 브래킷한다"는 주장도 **증명된 바 없으므로 철회**한다.  정본 문장을 하나로
통일해 `dem_am_load_fraction.py` 최상단에 박았다 (제안 문장을 그대로 채택):

> von-Mises proxy 와 Hertz 재구성은 폐기되었다.  실측 AM-AM 접촉응력과 대칭 per-atom
> AM-phase virial 은 **두 개의 운용상 하중분담 규약**이며, 둘 중 어느 것도 아직
> **정확한 플래튼 반력 분율로 검증되지 않았다**.

미측정 정본도 명시했다: `f_AM,wall = (플래튼 반력 중 AM 경로 전달분) / (총 반력)`.
자동 게이트 주의(phase-virial 은 Eshelby 응력집중 포함 → 퍼콜 게이트가 아님)도 코드
출력에 인쇄한다.  수정 위치 5곳: 모듈 docstring · `am_load_fraction_liggghts` ·
`am_load_fraction_peratom` · CLI 출력 2곳.

## §3 — corner 검증: 명칭과 핀 목록을 고쳤다

"floor OFF 는 필요하지만 충분하지 않다"를 수용한다.  AM/SE 좌표·f_AM·(경우에 따라)
dilate·target-porosity 가 전부 DEM 유래이므로 **독립 예측이 아니다**.  명칭을
**conditional closure test** (동일 DEM scaffold·하중분담 조건부 잔여 소성응답 검사)
로 바꾸고, 검증 런 규약을 다음으로 고정한다:

- OFF: `--floor-porosity` · `--compact-to` · `--dilate-z`
- 사용: payload target-porosity 가 아니라 **raw `mpm_metrics.json`**
- **결과 보기 전에** case ID 고정
- 3 팔 동일 scaffold: `f_AM = 0` / AM-AM / phase-virial
- 보고: `gap0` · `gap_AMAM` · `gap_AMphase` · `improvement = |gap0| − |corrected|`

"자유 파라미터 0" 은 유지하되 "DEM-독립 예측" 이라는 표현은 쓰지 않는다.

## §4 — P600 지렛대: 재현했고 코드에 내장했다

독립 재계산이 일치한다 (`P_y 133.15`, `R² 0.96025`).  leave-one-out 을 직접 돌린 결과:

| 제외 | P_y (MPa) | R² | Δ |
|---|---:|---:|---:|
| — (n=4) | 133.1 | 0.9603 | — |
| −P100 | 116.1 | 0.9922 | −17.0 |
| −P200 | 136.4 | 0.9600 | +3.3 |
| −P300 | 133.1 | 0.9819 | +0.0 |
| **−P600** | **258.1** | 0.9423 | **+125.0** |

지적대로 P600 (D_union 0.9931 → 1−D = 0.0069) 한 점이 지배한다.  조치:

1. **LOO 를 docstring 이 아니라 코드에 넣었다** — `heckel_analysis.py` 가 n≥3 이면
   자동으로 LOO 표를 인쇄하고, |Δ| > 0.5·P_y 인 점에 `★ 지렛대` 를 찍고 "단일값 인용
   금지, 범위 병기" 를 경고한다.  (문서 규약은 잊히지만 코드는 매번 돈다.)
2. **규약 충돌을 자인해 원장에 적었다**: jam 시험은 P600 을 축퇴로 사전제외하면서
   Heckel 은 같은 점을 핵심 앵커로 쓴다.  질문이 다르니 양립은 하지만(정지높이 판정 vs
   밀도-압력 관계), 한쪽에서 축퇴인 점에 다른 쪽 결론이 걸린 것은 **명시해야 할 약점**.
3. 라벨 정정: `[116, 156]` 은 95 % CI 가 아니라 **n=4 회귀의 1σ 전파값**.  `P_y` 는
   Li₆PS₅Cl 고유 항복압이 아니라 **연화된 복합 베드의 effective compaction parameter**.
4. `heckel_analysis.py` 머리말의 "P_y ≈ 0.85 GPa 면 faithful" 을 정정했다 — 18× 연화가
   설계이므로 P_y 가 단결정 H 근처면 오히려 연화가 안 걸린 것이다 (게이트는 이미
   고쳤는데 docstring 만 남아 있었다).
5. 곡률 관찰은 **exploratory observation** 으로 라벨링, 결론에서 제외.
