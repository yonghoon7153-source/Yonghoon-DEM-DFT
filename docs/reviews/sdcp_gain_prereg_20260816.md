# 사전등록 — SDCP 전자 이득이 물리인가 스탬프 인공물인가 (2026-08-16)

**⚠ 이 문서는 판별 런을 돌리기 _전에_ 작성·커밋한다.  결과를 보고 창을 옮기면 무효다
(규약 prereg §7).  아래 예측값은 vox 0.15 런 **이전**에 확정된 것이고, 그 사실은 이 파일의
커밋 해시와 타임스탬프로 증명된다.**

목표: `docs/reviews/review_request_20260816.md` §0 의 **B 경로** — SDCP 이득을 원고에
주장하려면 통과해야 하는 조건 1~5 중 **③ 기전 분리**의 결정적 판별.

---

## 1. 왜 이 검사인가 (한 문단)

생산 STEP3 는 SDCP 를 **입자당 셀 하나**로 찍는다.  그러면 한 입자가 `vox³` 를 차지해
참부피 `π/6·(0.3)³ = 0.014137 µm³` 대비 표현 부피가 격자에 따라 **크게 달라진다**:

| vox (µm) | 0.4 | 0.3 | 0.25 | **0.15** |
|---|---|---|---|---|
| `V_rep/V_true` | **4.53** | 1.91 | 1.11 | **0.239** |

★ 결정적인 점: 점-스탬프 부피가 **정확해지는 지점이 vox = 0.2418 µm** 다
(`vox³ = π/6·d³`).  생산 격자 0.25 는 그 바로 옆이다.  ⇒ **0.4 → 0.25 스윕은 "격자 수렴"
과 "SDCP 부피가 정답을 통과하는 것" 이 섞여 있고, 그 아래로 내려가면 SDCP 는 이제
과소표현된다** — 즉 두 가설이 **반대 방향**으로 갈린다.  이것이 판별 창이다.

(참고: SDCP 를 참 구로 래스터하면 vox 0.4 에서 입자의 **87.5 %가 통째로 사라진다** —
서브복셀이라 셀 중심이 구 안에 안 들어온다.  그래서 점-스탬프가 쓰이고 있는 것이고,
**두 규약 다 생산 격자에서는 틀린다**.  `scripts/sdcp_stamp_confound.py` selftest 8/8.)

## 2. 기전 예측식 — **이미 관측된 3 점으로** 세웠다

관측(원장 CL-24 raw 표, vox 0.4/0.3/0.25 의 σ_e 비):

| vox | `V_rep/V_true` | 이득 = 비 − 1 |
|---|---|---|
| 0.4 | 4.53 | 0.4215 |
| 0.3 | 1.91 | 0.1621 |
| 0.25 | 1.11 | 0.0849 |

log-log 국소 기울기 **1.106 (0.4→0.3) · 1.190 (0.3→0.25)** ⇒ `이득 ∝ V_rep^p`, **p ≈ 1.15**.

⚠ 정직하게: **3 점 적합**이고, 이 리포는 3 점 적합으로 지수를 인용하는 것을 이미 비판했다
(CL-24 · Richardson 극한).  그래서 이 지수를 **물리 상수로 인용하지 않는다** — 오직
**h1 의 정량 예측을 만드는 데만** 쓴다.  그리고 두 국소 기울기가 1.11 / 1.19 로 가까운 것이
이 용도의 근거다 (한 점만으로 세운 것이 아니다).

## 3. 가설과 **한 양**의 예측

**판별 런**: 같은 침대쌍(SBE/DBE, case 260714_145738_778fa4), 같은 코드, 같은 규약,
**vox 0.15 µm** 만 새로 — 실침대 87M 셀 ≈ **13 GB** 이므로 V100 32 GB 에 들어간다.

| | 가설 | **한 양의 예측** |
|---|---|---|
| **h0** | 이득은 **물리**다 (혼합전도 SDCP 가 실제로 전자망을 잇는다).  남은 격자 변화는 수렴 중인 잔차 | **σ_e 비(0.15) ≥ 1.05** |
| **h1** | 이득은 **SDCP 표현 부피의 인공물**이다 (`이득 ∝ V_rep^1.15`) | **σ_e 비(0.15) = 1.015** |

- 분해능: **0.02** (두 예측이 0.035 떨어져 있으므로 1.75 배).
- h0 의 근거: 관측 이득의 감속 (증분 −18.25 % → −6.64 %, 비 0.36).  그 감속이 계속되면
  0.25 → 0.15 구간에서 비는 1.05~1.07 에 앉는다.
- h1 의 근거: §2 의 `V_rep^1.15`.  `0.0849 × (0.239/1.11)^1.15 = 0.0145` → 비 1.0145.

**두 예측이 겹치지 않는다** — h0 는 ≥ 1.05, h1 은 1.015 ± 0.01.  중간대(1.025~1.05)가
나오면 **둘 다 기각**하고 제3 기전을 찾는다 (그 경우도 미리 적어 둔다: 가장 유력한 후보는
SE 해상도(CL-30)와 탄소 서브복셀 연결의 동시 변화).

## 4. 필요한 origin 수 — **런 전에 정한다**

CL-30 실측: 단일 origin 의 σ 는 격자 위상에 **2.4 ~ 5.8 %** 흔들린다.  판별하려면 그 잡음을
평균으로 눌러야 한다.

- 팔 하나의 표준오차 ≈ (스프레드/2)/√N.  스프레드 5.8 % 가정 시 N=4 → 1.45 %,  N=8 → 1.03 %.
- 비는 두 팔의 조합이므로 √2 배 → **N=4 에서 2.05 % · N=8 에서 1.45 %**.
- 판별 간격 0.035 (= 3.5 %p) 를 3σ 로 가르려면 σ ≤ 1.17 % 가 필요하다.

⇒ **origin 8 팔(full factorial: {0, h/2}³) 을 쓴다.**  4 팔은 ~1.7σ 밖에 안 되어
**부족하다** — 4 팔로 돌리고 결론 내면 그 자체가 결함이다.  이것을 지금 적어 둔다.

## 5. 실행 계약

```
런 A: SBE @ vox 0.15, origin {0,h/2}³ = 8 팔
런 B: DBE @ vox 0.15, origin {0,h/2}³ = 8 팔
  · 그 외 모든 인자 고정: 같은 침대 dump, 같은 코드 SHA, 같은 스탬프 규약(segment),
    같은 σ 표, 같은 브리지(--step3-bridge-um 를 **명시**한다 — 기본 1.2·vox 는 격자마다
    달라지므로 CL-22 의 결함을 반복하지 않는다), 같은 plate band.
  · 각 런의 payload 에 code SHA · input hash · vox · origin · bridge 를 기록.
보고: 16 개 σ_e 값 전부 + 팔별 평균 + 비 + 8-팔 표준오차.  **하나도 빼지 않는다.**
```

**판정 순서** (결과를 보기 전에 고정):
1. 8 팔 표준오차가 1.17 %p 를 넘으면 → **판정 보류**, origin 을 늘린다 (결론 내지 않는다).
2. 비 ≥ 1.05 → h0 채택, h1 기각.
3. 비 ≤ 1.025 → h1 채택, h0 기각.  ⇒ **SDCP 전자 이득은 원고에서 철회**한다.
4. 1.025 < 비 < 1.05 → **둘 다 기각**, 제3 기전 조사.

## 6. 이 검사가 **증명하지 못하는 것** (미리 적는다)

- **이온 축은 안 다룬다.**  σ_ion 비의 부호 반전(CL-24)은 별건이고 origin 앙상블(①)이 따로 필요하다.
- **탄소(VGCF)는 안 갈린다.**  VGCF 는 Ø0.15 µm 라 vox 0.15 에서도 **1 셀**이다 —
  이 런으로 탄소 서브복셀 문제는 해결되지 않는다.  그래서 h0 가 채택돼도 그것이
  "이득이 물리다" 를 **완전히** 증명하지는 않는다 (SDCP 축만 닫는다).
- **실침대 상별 부피 원장**은 여전히 별도로 필요하다 (`count(sid)·vox³` vs 레시피) —
  §1 의 배수는 단입자 산술이라 셀 충돌·상 overwrite 를 포함하지 않은 **상한**이다.
- CPU RVE(`sdcp_stamp_confound.py`)는 **합성 SDCP 배치**라 기전의 크기·부호만 준다.
  실침대 보정계수가 아니다.
