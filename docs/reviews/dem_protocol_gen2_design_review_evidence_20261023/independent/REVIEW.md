## 재현

```bash
  --repo /workspace/Yonghoon-DEM-DFT \
  --request /workspace/.cloud-setup/nonrint/dem-gen2-request/codex_dem_protocol_gen2_design_request_20261023_draft.md \

  --repo /workspace/Yonghoon-DEM-DFT \

```
