# 독립 연구 트랙 — LPSCl / Ag–C 인터레이어 / VGCF 계면의 임계 점착에너지 (2026-09-23 개설)

**상태: ⬜ 설계 · 결과 0 건.**  DFT 팀 협업 트랙이며 기존 트랙(Phase A · Lee · 믹서 · MPM ②)과 **독립**이다.
DFT 팀 요청 원문: `docs/dft_request_adhesion_agc_20260923.md`.

## 0. 질문

두 계면 ① **LPSCl ↔ Ag–C 인터레이어** ② **Ag–C ↔ VGCF 호스트** 의 **임계 점착에너지 (J/m²)**.
정확도 목표는 **자릿수** (mJ/m² 급인가 J/m² 급인가).  구동압 의존성이 있으면 좋다.

## 1. 두 양을 섞지 않는다

| 양 | 뜻 | 전형 크기 | 어디서 |
|---|---|---|---|
| **W_ad** (열역학 점착일) | 이상 두 표면을 떼는 가역 일 = γ_A + γ_B − γ_AB | 물리흡착 ~0.01–0.3 · 화학결합 ~1–5 J/m² | **DFT 팀** (원자 계산) |
| **G_c** (임계 에너지 해방률 = 박리 시험 값) | W_ad × 실접촉 면적 비율 + 소성·마찰 소산 | ≥ W_ad, 수~수십 배 가능 | **우리** (DEM · 연속체) |

"mJ 냐 J 냐" 는 **W_ad 가 정한다**.  ⛔ W_ad 를 G_c 로 부르지 않는다 (소산이 빠진 값이다).

## 2. ⚠ 구동압의 물리적 한정

- 원자 스케일 W_ad 는 구동압(수~수십 MPa)에 **거의 불변**이다 — 결합 응력은 ~W_ad/0.1 nm = GPa 급.
  MD 에 MPa 를 걸어도 효과가 안 보인다.
- 구동압이 바꾸는 것은 **실접촉 면적**이다 (거칠기 눌림 · Ag·LPSCl 소성 conform) ⇒
  `G_c,eff(P) ≈ W_ad · A_real(P)/A_nom (+ 소산)`.  이것은 리포가 이미 가진 접촉 면적 축(Tabor A=F/H ·
  JKR/DMT · MPM coverage)과 같은 축이다 ⇒ **구동압은 DEM 층에 넣는다.**

## 3. 분업과 파이프라인

| 단 | 무엇 | 누가 | 산출 |
|---|---|---|---|
| 1 | 계면 슬랩 W_ad (W_sep 과 이완 W_ad) + 분리 스캔 E(d) | **DFT 팀** | J/m² 표 · 견인–분리 곡선(σ_max, δ_c) |
| 1′ (선택) | 범용 MLIP 로 같은 계면을 크게·많이 (registry·두께·결함) — **DFT 값으로 검증** | 우리 | ⚠ 리포에 MLIP 의존이 **아직 없다** (새 의존) |
| 2 (선택) | 원자 스케일 인장·박리 MD | 우리 또는 DFT 팀 | ⚠ 당김 속도 m/s 급 → **과대 추정**으로 라벨 |
| 3 | DEM 박리 시험 — Ag–C 막(Ag 입자 + 카본블랙)을 LPSCl 기판 / VGCF 호스트 위에 쌓고 → 구동압 P 로 누른 뒤 → 각도 θ 로 당김 | **우리** (LIGGGHTS) | `G = (F/b)(1 − cos θ)` (탄성 보정은 Kendall 식) → **G_c,eff(P) 곡선, 하한** (소성 소산 미포함) |

- 3 단의 점착 모델은 믹서 캠페인이 이미 쓰는 LIGGGHTS `cohesion sjkr` 를 쓴다 (`dem_scripts/mixing_cohesion_20260919/`).
- ⚠⚠ **W_ad → DEM 점착 파라미터 매핑은 정의를 명시해서 한다.**  sjkr 의 cohesion energy density 는 W_ad 가
  **아니다**.  믹서 캠페인 R-4 에서 코드의 Bo(평형 인력/무게)와 문헌의 Bo(pull-off/무게)가 **6.75배** 어긋났던
  전례가 있다 ⇒ **JKR pull-off 힘(F = 1.5πR·w)** 기준으로 맞추고 그 식을 문서에 박는다.
- 접착 접촉 모델 문헌은 litdb 에 있다 (DMT 1975 · Thornton–Ning 1998 · Pasha 2014 · Thakur 2014 EEPA) — ⚠ 이
  브랜치의 litdb 는 동결 스냅샷이라 **정본 브랜치에서 확인**한다.
- ⚠ frame[4] 원칙 그대로: DEM 박리 결과를 DFT W_ad 에 맞춰 튜닝하지 않는다 (W_ad 는 입력이다).  실험 박리값이
  생기면 **독립 대조**로만 쓴다.

## 4. 가설 (계산 전 — 판정 아님)

- LPSCl ↔ Ag: Ag–S 결합 경향 → S 쪽 종단에서 **J/m² 급 화학결합** 후보.  실효값은 Ag 가 닿는 **면적 비율**이 좌우.
- Ag ↔ 흑연(VGCF): 흑연질 탄소 위 Ag 는 물리흡착 영역으로 알려져 있다 (Giovannetti 2008 PRL 계열 — ⚠ **기억에
  의존, litdb 카드로 확인 필요**) → **수십~수백 mJ/m² 급** 후보.  결함·산소 작용기가 있으면 강해진다.
- ⚠ 사이클 중 Ag–C 는 **리튬화(Li–Ag 합금)** 된다 — 실제 전지 조건의 계면은 pristine 이 아닐 수 있다 (DFT 요청 P3).
