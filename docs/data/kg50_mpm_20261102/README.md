## 3. 피복률 (coverage) — 숫자는 보고에 쓰지 않는다 (1저자 11-02 Q4 *"다 권고대로"*)

| 침대 | 소성 (Hertz 띠 0.13 µm / Tabor 띠 0.26 µm) | 강체 (같은 띠 · DEM 구 해석) | DEM 접촉 면적 (덱 5장 · Physics 합집합 / Hertz) |
|---|---|---|---|
| 3 µm | 27.5 / 37.5 % | 24.6 / 32.9 % | 52.6 / 19.1 % |
| 2 µm | 36.0 / 52.0 % | 32.2 / 46.4 % | 54.2 / 21.1 % |
| 1 µm | 56.0 / 80.0 % | 51.2 / 76.3 % | 46.8 / 19.0 % |

쓰지 않는 이유 (원장 `MPMC-01` – `03`):
1. **정의 = 띠 (가까이 있는 표면) · 닿은 면적 아님** — 작은 전해질이 많을수록 근처 개수만으로 커진다.  MPM 없이 DEM 구로 잰 강체 값도 이미 33 → 46 → 76 % (Tabor 띠) → 1 µm 80 % 의 대부분은 정의에서 온다.  DEM 접촉 면적은 활물질 하나당 접촉 10 → 24 → 100 개여도 접촉 하나의 겹침이 작아져 (4.20 → 1.55 %) 52.6 → 54.2 → 46.8 % 로 늘지 않는다.
2. **띠 ≈ 격자 한 칸** — 격자 간격 ≈ 0.216 µm (54.35 µm ÷ 252) ↔ 띠 0.13 · 0.26 µm → 값이 점 구름 밀도에 좌우된다.
3. **MPM 이 더한 몫 (소성이 강체보다 2.9 … 5.6 %p 높음) = 측정 치우침 크기** — 가압 전 씨앗 상태에서도 2.3 … 5.1 %p 높음 (키트 점검 · 점 구름 이산화 + x,y 주기 이미지 미반영).

더 맞는 것: 피복률 숫자 = DEM 접촉 면적 (덱 5장 그대로 · 이온은 닿은 면으로만 넘어간다) · MPM = 그림 (소성 변형으로 어디를 채우고 어디에 닿나).  MPM 숫자를 쓰려면 셋을 고친 뒤 (아래 §4) — 지금 말할 수 있는 것 = "MPM 소성 변형으로 피복이 크게 늘지 않는다 (치우침 2–5 %p 안)" 까지.
