# LPSOCl 600 K 상자 크기 — β 는 안 움직이고 D 만 1.65× 움직인다

`lpsocl` 600 K 의 β 게이트 탈락이 **상자 탓인지** 시험하려고 3×3×1(558원자·3시드·200 ps)을
돌렸다. 답: **상자 탓이 아니다.** 그런데 시험하다 **더 큰 것**이 나왔다 — 같은 상자 확대가
β 는 안 건드리고 **D 를 1.65 배** 올린다.

## 1. 실측 (같은 잣대 — STO 곡선 · 시드평균 · 창 2–50 ps)

| | 작은 셀 | 3×3×1 | 비 |
|---|---|---|---|
| 최소 수직폭 L | 5.67 Å | 17.02 Å | 3.00× |
| 유한크기 여유 (d/2)² vs MSD | **3.21× 초과** | **0.36× 여유** | — |
| **β̄** (시드평균 곡선) | **0.82** | **0.80** | −0.02 |
| 절편 c [Å²] | 1.36 | 3.15 | 2.3× |
| 기울기 m [Å²/ps] | 0.467 | 0.768 | **1.65×** |
| MSD@50ps [Å²] | 25.3 | 41.7 | 1.65× |
| **D** (m/6) | **7.78e-6** | **1.280e-5** | **1.645×** |
| 시드별 D | 7.42 / 8.91 / 7.04 e-6 | 1.286 / 1.169 / 1.383 e-5 | 겹치지 않음 |

**D 출처 검산**: 저장된 `D_Li_cm2_s` 평균과 도구가 창 2–50 에서 다시 맞춘 `m/6` 이
양쪽 셀 모두 **0.1% 안에서 일치**한다 (7.790 vs 7.783e-6 · 1.279 vs 1.280e-5).
`fit_window_ps` 가 파일에 안 적혀 있었는데, 이 일치가 **창 2–50 이었음을 사후 증명**한다.

## 2. 판정 ① — 상자는 β 의 원인이 아니다

사전에 선언한 규칙은 `β̄ ≥ 0.80 → 상자가 원인 확정` 이었다. 3×3×1 이 0.80 이니
글자대로면 통과다. **그런데 대조군이 0.82 다.** 규칙의 전제("작은 셀이 더 낮다")가
깨졌으므로 규칙을 적용하면 안 된다.

```
유한크기 위반 3.21× → 0.36× 로 없앴는데  β̄ 0.82 → 0.80  (오히려 −0.02)
```

⇒ **남은 sub-diffusion 은 상자 밖 이유다.** LPSOCl 600 K 가 200 ps 창에서
Fickian 을 못 보이는 건 O 치환이 만든 느린 자리 갈아타기 자체이지 셀이 작아서가 아니다.

### 실무 결론: modelc·b2o3 를 큰 셀로 다시 돌리지 않는다
셋 다 같은 5.67 Å 상자다. 상자가 β 의 원인이 아니므로 **셋을 같은 상자에 두는 쪽**이
맞다 — 비대칭 가감은 Ea 비교를 통째로 깨뜨린다(캠페인 규약).

## 3. 판정 ② — 대신 D 가 1.65× 움직인다 (이게 더 큰 문제)

β(곡선의 **모양**)는 그대로인데 m(곡선의 **기울기**)만 1.65 배다. 모양이 아니라
속도가 눌려 있었다는 뜻이고, 이건 주기 경계의 전형적인 유한크기 거동이다
(Yeh–Hummer 꼴: D 가 1/L 로 눌린다).

2점 1/L 외삽 — **참고값이지 인용값이 아니다**:

```
D(L) = D∞ − A/L   →   D∞ ≈ 1.53e-5
  작은 셀  D∞ 대비 −49 %
  3×3×1    D∞ 대비 −16 %      ← 큰 셀도 아직 수렴 안 했다
```

⚠ 점 두 개로 법칙 하나를 가정한 값이다. 세 번째 셀 없이 이 숫자를 쓰지 않는다.

## 4. 그래서 '+90 meV' 는?

Ea 는 ln D 의 **기울기**라, 유한크기 억제가 **온도에 무관**하면 상쇄된다.
온도에 따라 변하면 그대로 Ea 에 실린다.

**지금 데이터로는 못 가른다** — 3×3×1 을 600 K 에서만 돌렸다.

| 필요한 것 | 비용 | 답하는 것 |
|---|---|---|
| 3×3×1 @ 800·1000 K (3시드씩 6런) | 6런 × 200 ps | 1.65× 가 T 에 상수인가 |

상수면 Ea 는 무사하고 세 계 비교가 그대로 선다. T 에 따라 변하면 세 계의 Ea 차이가
화학 차이인지 셀 차이인지 못 가르고, 그때는 셋 다 큰 셀로 가야 한다.

## 5. 곁가지 — 도구 fail-open 두 건 (같은 날 수정)

`msd_diffusive_check.py` 가 이 판정 도중에 두 번 거짓말했다.

1. **못 잰 런을 통과로 셌다.** MSD 배열이 없으면 `continue` 로 건너뛰고 `bad` 에도
   안 넣어서, β 를 하나도 못 쟀는데 총평이 `✅ 3개 전부 확산 영역 — D/Ea 인용 가능`
   이었다. → `unmeasured` 를 따로 세고 ✅ 를 막는다.
2. **"MSD 배열 없음" 이 오진이었다.** 작은 셀은 `msd_Li_A2`/`times_ps` 를 갖고 있었고
   없는 건 `msd_Li_A2_mto` 뿐이었다. 처방이 정반대인데(전자는 `--mto` 만 빼면 끝,
   후자는 재계산) 같은 문구로 뭉갰다. → 두 경우를 갈라 찍는다.

`--selftest` 신설, 12건 중 **8건이 음성 경로**.
이 두 건이 없었으면 "작은 셀은 못 잰다" 로 결론 내고 하루를 버렸다.

## 6. 방법 교훈 — STO ↔ MTO 를 섞어 비교하면 안 된다

같은 3×3×1 을 두 방식으로 재면:

| | 시드별 β | 시드평균 β̄ |
|---|---|---|
| STO (단일 시간원점) | 0.81 / 0.73 / 0.87 | 0.80 |
| MTO (다중 시간원점) | 0.81 / 0.80 / 0.81 | 0.81 |

시드 산포 0.73–0.87 은 **물리가 아니라 시간원점 하나로 잰 잡음**이었다.
MTO 로는 세 시드가 0.80–0.81 로 붙는다.

⇒ 판정은 MTO 가 낫지만, **대조군에 MTO 가 없으면 양쪽 다 STO 로 재야 한다.**
작은 셀은 MTO 저장이 없어서 이 카드의 비교는 전부 STO 다.

## 이 카드가 말하지 않는 것

- **1.65× 가 온도에 상수인지** — 600 K 한 점뿐이다. 4절이 그 시험이다.
- **D∞ 절대값** — 2점 외삽이라 참고값이다. σ 절대값은 애초에 인용 금지(CLAUDE.md).
- **modelc·b2o3 의 유한크기 인자** — 재보지 않았다. lpsocl 의 1.65× 를 그들에게
  이식하면 안 된다 (D 가 다르면 억제 정도도 다르다).
- **왜 LPSOCl 만 β 가 낮은가** — 상자가 아니라는 것까지만 말한다. O 치환이 만든
  자리 갈아타기 때문이라는 건 이 데이터로 **입증되지 않았다**.
- 작은 셀 β̄ 로 캠페인이 써 온 **0.77 의 출처** — 이 명령으로 재현되지 않는다
  (같은 3시드·같은 창·STO 로 0.82). 어느 잣대의 값인지 확인 전까지 인용하지 말 것.
