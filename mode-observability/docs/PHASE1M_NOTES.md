# Phase 1m — `n₁` 은 맞다. **계수가 틀렸다** (그리고 그 계수는 프레임이 정한다)

**정본은 `mode-observability/results/phase1m/` 의 CSV 다.** 아래 숫자는 사본이며
인용 근거가 아니다. 재현: `python3 mode-observability/phase1m_li_de_null.py` (~30 s)

## 시험한 것

이 계보가 세 번 진술한 축퇴를 **처음으로 시뮬로** 시험했다:

- `[인쇄]` **Dubarry 2012** 식 (8'): `{LAM_liNE = x} ≡ {LAM_deNE = x, LLI = LR·x}`
- `[인쇄]` **Birkl 2017** §4.2: 산문으로 "같은 OCV 시그니처" (정량 없음)
- **Marongiu 2016**: 그 축퇴를 **근거로 파라미터를 죽이면서** 이름을 안 붙인다
- 우리 위키가 닫힌 형태로 풀어 `n₁ = (−N, 0, 0, +1, −1)` 로 적었다

**세 편 중 아무도 수치로 확인하지 않았고**, 우리 격자도 `de` 만 돌렸다.
`src/modes.py:build_overrides(..., lam_ne_type="li")` 가 이미 `li` 를 지원해서
(우리가 안 돌렸을 뿐) `degradation-degeneracy/` 를 **import 만** 하고 잴 수 있었다.
한 조건 ~2 s.

## 실측 ① — 예측대로 하면 **틀린다**

`N = Q_NE/Q_PE = 0.678500` (셀 기하에서 계산 — 원전들은 이 값을 인쇄하지 않았다).
`{LAM_Ne,li = δ}` 와 `{LAM_Ne,de = δ, LLI = N·δ}` 를 각각 돌려 비교:

| δ | LLI 등가 (`N·δ`) | 용량 상대차 | 평균 \|ΔV\| | 최대 \|ΔV\| |
|---:|---:|---:|---:|---:|
| 0.04 | 0.02714 | 1.63 % | 17.9 mV | 30.2 mV |
| 0.08 | 0.05428 | 2.30 % | 40.6 mV | 65.4 mV |
| 0.12 | 0.08142 | 2.37 % | **67.8 mV** | **102.1 mV** |

**같은 곡선이 아니다.** 그리고 대조군이 방향을 뒤집는다:

```
LLI = 0                     평균|ΔV|  0.254 mV · 최대  0.573 mV
LLI = 0.5·N·δ               평균|ΔV| 37.610 mV · 최대 57.253 mV
LLI = N·δ  (Dubarry 계수)    평균|ΔV| 67.796 mV · 최대 102.082 mV
```

**보정을 안 한 쪽이 가장 가깝고, 보정을 키울수록 단조롭게 나빠진다.**
즉 **올바른 계수는 `N` 이 아니라 거의 0 이다.**

## 실측 ② — 계수를 프레임에서 다시 유도하면 맞는다

`li` 가 `de` 보다 더 빼는 리튬은 **재료가 제거되는 프레임에서 그 재료가 쥐고
있던 양**이다. 우리 파이프라인은 열화를 **완방(discharged) 프레임**에서 적용한다
(`build_overrides` 의 `[코드]` "charge_first / 완방 프레임 통일"). 그 프레임에서
음극은 **거의 비어 있다**:

```
z_gr(완방) = 0.001277        z_si(완방) = 0.012396
완방 프레임에서 음극이 쥔 Li = 0.018439 Ah   (총 재고 8.1053 Ah 의 0.23 %)
```

그러므로 올바른 계수는

```
LLI 등가 = δ · [완방 프레임에서 음극이 쥔 Li] / [총 재고]
```

| δ | 올바른 LLI 등가 | `N·δ` | 과대 배수 |
|---:|---:|---:|---:|
| 0.04 | 0.000091 (0.0091 %) | 0.02714 | **298 배** |
| 0.08 | 0.000182 (0.0182 %) | 0.05428 | **298 배** |
| 0.12 | 0.000273 (0.0273 %) | 0.08142 | **298 배** |

그 값으로 다시 재면:

```
LLI = 0                     평균|ΔV|  0.254 mV · 최대 0.573 mV
LLI = 프레임 보정값 ★         평균|ΔV|  **0.048 mV** · 최대 1.401 mV   ← 가장 작다
LLI = 0.5·N·δ               평균|ΔV| 37.610 mV
LLI = N·δ                   평균|ΔV| 67.796 mV
```

**평균 오차가 0.048 mV — Dubarry 계수의 1400분의 1이고, 보정 없음의 5분의 1이다.**
(최대값이 1.401 mV 로 LLI = 0 의 0.573 mV 보다 큰 것은 양 끝 한 점의 값이다.
평균이 이 비교의 옳은 통계다.)

## 판정

1. **`n₁` 은 성립한다.** 구조 — "음극 활물질을 리튬화 상태에서 잃는 것은
   탈리튬화 상태에서 잃는 것 + 그만큼의 LLI 와 같다" — 는 우리 셀에서도 맞다.
2. **그러나 계수는 로딩비 `N` 이 아니다.** 계수는 **재료가 제거되는 프레임의
   음극 화학량론**이 정하고, 그것이 우리 파이프라인에서는 ~0 이라 `N` 이
   **298배 과대**하다.
3. **★ 그러므로 우리 격자에서 `lam_ne_type` 은 사실상 무효 노브다.**
   `de` 와 `li` 가 0.25 mV 안에서 같다 — 우리 잡음층(1 mV·5 mV) 아래다.
   `[해석]` 격자가 `de` 만 돌린 것은 **NE 에 관한 한 손해가 아니었다.**
   (PE 는 완방 프레임에서 리튬이 차 있으므로 **같은 논증이 안 간다** — 아래 경계 3.)
4. **★ `n₂`(PE)가 그 이론을 확증한다.** 같은 프레임에서 PE 계수는 **0.9977**
   이어야 한다는 예측이 맞았고, **인쇄된 계수 1 보다 2~7배 더 잘 맞는다.**
   두 전극이 정반대(NE ~0 · PE ~1)이고 그 차이를 프레임 점유율이 예언한다.
5. **계보에 대한 지적**: Dubarry 식 (8') 의 `LR` 은 **재료가 완전 리튬화 상태에서
   제거된다**는 암묵 가정 위에 있다. `[해석]` **그 가정을 적지 않고 계수만 인쇄하면
   불완전하다** — 프레임이 다르면 계수가 300배 틀린다. 이 계보에서 그 축퇴를
   진술한 세 편 중 프레임을 명시한 편은 없다.

## 실측 ③ — `n₂` (PE) 로 **프레임 이론이 예측을 맞혔다**

프레임 이론이 반증 가능한 예측을 하나 낳는다. `n₂ = (+1, −1, +1, 0, 0)` 곧
`{LAM_Pe,li = ε} ≡ {LAM_Pe,de = ε, LLI = ε}` — Dubarry 의 계수는 **1** 이다.
그런데 완방 프레임에서 **양극은 거의 차 있다** (`y₀ = 0.926088`):

```
완방 프레임에서 양극이 쥔 Li = 8.0869 Ah / 총 재고 8.1053 Ah
★ 예측 계수 = 0.997725      ← NE 는 ~0 이었는데 PE 는 ~1 이어야 한다
```

**시험 결과 (평균 \|ΔV\| mV):**

| ε | LLI = 0 | **프레임 예측 (0.9977·ε)** | Dubarry 계수 1 |
|---:|---:|---:|---:|
| 0.04 | 19.653 | **0.008** | 0.054 |
| 0.08 | *infeasible* | **0.032** | 0.058 |
| 0.12 | *infeasible* | **0.067** | 0.152 |

`[해석]` **예측이 맞았다. 그리고 인쇄된 계수보다 낫다.** 프레임 보정값이
Dubarry 의 정확한 1 보다 **2~7배** 더 잘 맞는다 (0.008 vs 0.054 등) — 그 차이가
곧 `y₀ = 0.9261 ≠ 1` 의 몫이다.

**대조가 완벽하다**: 같은 셀·같은 프레임에서 **NE 계수는 ~0**(`z_gr` = 0.0013),
**PE 계수는 ~1**(`y₀` = 0.9261). 두 전극이 정반대이고, **그 차이를 프레임
점유율이 정확히 예언한다.**

**덤**: `ε ≥ 0.08` 에서 `LLI = 0` 짝이 **infeasible** 로 걸린다 —
`[코드]` "PE 초기농도 63522 > c_max 63104 (줄어든 PE가 완방 재고를 수용 불가 —
PE-limited 영역)". **보정 없이는 조건 자체가 물리적으로 성립하지 않는다.**
guard 가 그것을 잡아 준 것이고, `n₂` 가 **선택이 아니라 필연**임을 보여 준다.

## 이 판정이 말하지 않는 것 (경계)

1. **한 프레임·한 화학·δ 3개.** 완충 프레임에서 열화를 적용하는 파이프라인이면
   계수가 `N` 에 가까워질 것이다 — 그것이 이 판정의 요점이지 **재 본 것은 아니다.**
2. **판정 3(무효 노브)은 NE 에만 해당한다.** 실측 ③ 이 보였듯 PE 는 정반대다 —
   `lam_pe_type` 의 de/li 구분은 **무효가 아니고**, 보정 없이는 ε ≥ 0.08 에서
   조건 자체가 성립하지 않는다. **판정 3 을 PE 로 옮겨 읽으면 안 된다.**
3. **용량 상대차 1.6~2.4 % 는 `N·δ` 짝에 대한 것이다.** 프레임 보정 짝의 용량차는
   따로 적지 않았다 (곡선 일치가 더 엄격한 시험이라 그것으로 판정했다).
4. `extract_curves` 의 기본 격자(300점)와 x 축 재보간이 들어 있다 — 0.048 mV 수준은
   그 보간 오차와 같은 자릿수일 수 있다. **"0 과 구별되지 않는다" 까지가 주장이다.**

## 다음

- 완충 프레임에서 열화를 적용하는 파이프라인이면 NE 계수가 `N` 으로 가는지 (경계 1).
  그것이 맞으면 "계수는 프레임이 정한다" 가 **두 방향 모두에서** 확증된다.
- `li`/`de` 를 **섞은** 조건 (실제 셀은 중간 SOC 에서 열화한다) — 계수가
  그 SOC 의 점유율로 연속적으로 움직이는지.
