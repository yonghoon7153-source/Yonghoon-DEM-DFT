# 보장 범위와 남은 조건

1. **정수 파싱 수용은 역사 사실이다.** 외부 재검토가 본 소비자는 `01c1aaf5be8acdf7d1716f34cc86fc77d8e27362`이고, 정확히 인식된 RESUME 경로의 반올림 교정은 수용됐다. 이번 두 P2는 그 전에 기록이 잘못 분류되어 사라지는 경계다. 기존 `_resume_integer`는 바꾸지 않았다.
2. **event 원문을 먼저 본다.** LF/CRLF/CR 물리 줄에서 첫 event 셀이 정확한 RESUME와 앞뒤 whitespace만 다르면 오류다. 공용 CSV의 Unicode `splitlines()`가 선행 구분자를 버리기 전에 검사한다. 잘못된 셀을 `.strip()`한 정상 사건으로 바꾸지 않는다. 이 검사는 임의의 UNKNOWN 사건 전체를 금지하는 허용목록이 아니다.
3. **manifest 구분자를 먼저 본다.** U+000B·U+000C·U+001C·U+001D·U+001E·U+0085·U+2028·U+2029는 키 선택 전에 오류다. 키 앞뒤와 다른 문자열 뒤의 위치에 걸린다. LF·CRLF·CR 정상 줄 끝은 유지하며, 금지 구분자를 LF로 정규화해 수용하지 않는다.
4. **원자료와 분석 행을 구분한다.** 오류가 있으면 정상 재개 표지만 골라 경계를 인증하거나 옛 행을 분석에서 제외하지 않는다. 실제 arm 판정은 UNIDENTIFIED/null·순위 불가다. 입력 CSV·manifest·state는 바뀌지 않는다. `arm`의 rc 0을 승인으로 읽지 않는다.
5. **정상 값은 합성 대조다.** k=0/1/2/3의 주 값 보존은 생성 덱 제어 흐름으로 만든 작은 관측 fixture의 판독 비교다. 실물 언로딩의 변형률 측정, 물리 동등성, 실제 체크포인트 복원 자격이 아니다. 생산 덱·params·물리 기준을 바꾸지 않았다.
6. **이 검증은 외부 재확인을 대신하지 않는다.** 새 판의 ULPRI-01/02는 로컬 claimed fixed이며 외부 재확인 대기다. 기존 외부 HOLD 원문을 수정하지 않았다. 실제 본 R·10:0 연장·U와 기계 실행, Claude 중심 가지 통합은 이번 로컬 수정에서 하지 않았다.
7. **검사 수는 합산하지 않는다.** reader 346에는 R39 90과 R40 42가 포함된다. 작성자 별도 CLI 43, 변이 5, 독립 추가 CLI·변이, 공유 155개는 중첩 범위와 실행 경로가 다르다. 공유 검사·CI의 키트 직접 검사 배선은 이번 수정 범위 밖으로 남았다.
