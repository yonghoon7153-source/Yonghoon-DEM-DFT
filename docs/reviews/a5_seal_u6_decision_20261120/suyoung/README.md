# 수영 설정 ① · U6(b)·(c) 개발 대조 결정

1저자는 2026-11-20에 **설정 ①을 U6(b)와 U6(c)의 개발 대조에 고정**했다. F의 셀 크기 틈 보정과 거리 기반 접촉 판정은 모두 끈다. 공유 격자 노드에 걸친 물체의 접근 판정과 마찰계수 0.5는 유지한다. S는 같은 출발의 단일 속도장 대조다.

| 결정 근거 | 값 |
|---|---|
| 같은 49원판 초기 배열, 아래판 1.2 MPa 첫 도달 | F12 Φ_m 0.990030971727746 · F16 Φ_m 0.9850740317357705 |
| 해상도 차이와 여유 | 절대차 0.004956939991975551 · 판정선 0.005까지 0.00004306000802445(판정선의 0.8612%) |
| 같은 조건의 반복 | 각 해상도의 첫 trace와 반복 trace가 원바이트로 일치. 시드·초기 배치 민감도는 미측정 |

판정에 사용한 값은 F의 Φ_m이다. 네 원판 S/F 형상 결과와 판 응력은 설정 선택 근거에서 제외했다. 이전 실행이 기록한 `selected_setting=null`, `u6_qualified=false`는 당시 반환 원문에 보존했다. 개발 설정 고정은 오늘의 별도 저자 결정이다.
