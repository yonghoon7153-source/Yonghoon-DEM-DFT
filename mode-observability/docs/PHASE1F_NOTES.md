# Phase 1f — Birkl 등식을 우리 좌표로: **하나는 닫혔고 하나는 막혔다**

> ## ⚠ 정정 (2026-09-04, Phase 1n) — 아래 "근이 없다" 는 **사실이 아니다**
>
> `[코드]` `phase1n_birkl_ported.py` 가 같은 식을 `Δx ∈ [−1.5, +1.5]` 에서 풀어
> **근을 찾았다 — `Δx_EoD = +1.0` 이다.** 이 문서(§"막힌 것", 46줄)가 "근이 없다"
> 고 적은 것은 **탐색 구간을 ±0.4 로만 잡은 artifact 였다.** 그 문장과 그것에
> 기댄 서술은 **철회한다.**
>
> **막힌 것 자체는 실재한다 — 원인이 다르다.** 그 근은 PE 창을 `[0, 2]`, 곧
> **폭 2** 로 만든다. 반쪽전지 보간자에 넣을 수 없다. 원인은 이 문서가 지목한
> 두 정규화 사이 환산 부재(→ Phase 1j 가 그 진단도 반박했다)도 NE 축 방향도
> 아니라, **식 (8) 의 `+1` 이 식 (10) 에 짝이 없다는 비대칭**이다. `+1` 을 양쪽에
> 대칭으로 두면(또는 양쪽에서 빼면) **두 창이 정확히 `[0,1]` 이 된다.**
>
> **그리고 참고문헌 [33] 은 필요하지 않았다.** Phase 1n 은 계수를 지어 넣지
> 않고 규약 16가지를 전수해 4개만 통과함을 보였다 — 이 문서가 [33] 을 요청한
> 것은 **과잉 요구**였다. 판정·경계 전문은 `PHASE1N_NOTES.md`.

목표는 Phase 1e 가 스스로 신고한 한계 ②("우리 제약은 **대리물**이다")를 닫고,
Birkl 의 **3-파라미터 판**을 실제로 구성해 스펙트럼을 재는 것이었다.
`degradation-degeneracy/` 는 읽기만 했다.

## ✅ 닫힌 것 — 대리물이 아니었다

Birkl 식 (11)(12) 를 **조판본에서 직접 읽어** 확인했다
(`de62df59-…Degradation_diagnostics….pdf` p.9):

```
E^OC_Cell,high − Ê^OC_PE,EoC(x_PE,EoC) + Ê^OC_NE,EoC(x_NE,EoC) = 0     … (11)
E^OC_Cell,low  − Ê^OC_PE,EoD(x_PE,EoD) + Ê^OC_NE,EoD(x_NE,EoD) = 0     … (12)
```

full-cell = PE − NE 이므로 이 둘은 글자 그대로

```
U_full(EoC) = E_high        U_full(EoD) = E_low
```

이고, **Phase 1e 가 쓴 제약과 형태가 같다.** 그러므로 Phase 1e 의 한계 ② 는
**과한 신고였고 철회한다** — 주각 판정(제약이 강한 쌍과 1.5°·2.0°)은 대리물이
아니라 Birkl 의 등식 그 자체에 대한 것이다. 결론이 약해지는 게 아니라 **강해진다.**

또한 `raw/papers/birkl2017_…` 의 식 (7)–(12) **전사가 조판본과 정확히 일치**함을
확인했다 (부호·항 모두). digest 를 의심할 이유는 없었다.

## ✗ 막힌 것 — 식 (7)–(10) 만으로는 pristine 셀이 재구성되지 않는다

3-파라미터 판을 세우려면 `θ = (LLI, LAM_PE, LAM_NE)` → 전극 창 네 끝점이
필요하다. 그런데 식 (7)–(10) 을 pristine(`LLI = LAM_PE = LAM_NE = 0`)에 넣으면:

```
x_PE,EoC = Δx_EoC              x_PE,EoD = Δx_EoD + 1
x_NE,EoC = Δx_EoC              x_NE,EoD = Δx_EoD
```

**음극 창의 폭이 `Δx_EoD − Δx_EoC` 이고 양극은 `1 + (Δx_EoD − Δx_EoC)` 다.**
둘이 동시에 1 일 수 없다 — pristine 에서 음극 창이 **퇴화**한다.

실측으로도 그렇게 나온다. 우리 reference 곡선의 양 끝(`E_high = 4.1594 V`,
`E_low = 2.5428 V`)을 컷오프 상수로 놓고 식 (12) 를 `Δx_EoD` 에 대해 풀면
**부호 변화가 없다** — `Δx_EoD ∈ [−0.4, +0.4]` 전 구간에서 잔차가
`−1.13 ~ −0.86 V` 로 음수에 머문다. 근이 없다.

```
[pristine] g_eod(Δx) = E_low − (f_PE(1+Δx) − f_NE(Δx))
  Δx=-0.40 → -1.128592      Δx=0.00 → -0.917997      Δx=+0.40 → -0.864047
```

(같은 식으로 (11) 은 `Δx_EoC = 0` 에서 정확히 0 이 되어 잘 풀린다 — 문제는
(10)/(12) 쪽, 즉 **음극의 EoD 좌표**다.)

### 원인을 끝까지 따라갔다 — 그리고 **인쇄된 식으로는 닫히지 않는다**

`Ê^OC_PE`·`Ê^OC_NE` 는 원시 반쪽셀 표가 아니라 Birkl §3.2 의 **매개화된 전극
OCV** 다. 조판본에서 그 층을 전부 꺼냈다:

식 (1) — 5상(phase) 합. `x` 를 `E^OC` 의 함수로 준다 (역함수는 수치로 푼다):

```
x(E^OC) = Σᵢ₌₁⁵  Δxᵢ / (1 + exp((E^OC − E₀,ᵢ)·aᵢ·e/kT))
```

Table 5 (p.9) 가 그 파라미터를 **전부 인쇄한다** (`/C0` = 마이너스):

| | E₀,PE [V] | a_PE | Δx_PE | E₀,NE [V] | a_NE | Δx_NE |
|---|---|---|---|---|---|---|
| P1 | 5.038 | 1.753 | 0.021 | 0.226 | −18.072 | 0.025 |
| P2 | 4.079 | 0.178 | 0.523 | 0.219 | −0.165 | 0.112 |
| P3 | 3.936 | 0.681 | 0.124 | 0.173 | −1.188 | 0.243 |
| P4 | 3.900 | 3.074 | 0.136 | 0.132 | −14.773 | 0.254 |
| P5 | 3.688 | 0.470 | 0.178 | 0.094 | −6.690 | 0.365 |

ΣΔx = **0.982**(PE) · **0.999**(NE) — `x` 가 0~1 임과 맞는다. 모델을 세워 보니
물리도 맞는다: PE 는 `x` 가 전압에 **감소**(리튬화 분율), NE 는 **증가**(탈리튬화
분율). `x_NE ≈ 0.03` 이 `E_NE ≈ 0.05 V`(완전 리튬화)에 대응한다.

**그런데 그 모델로 Birkl 자신의 식 (11)(12) 를 pristine 에서 풀면 (12) 에 근이
없다.** 실측:

```
식 (11)  x_PE,EoC = x_NE,EoC = Δx_EoC
   Δx=0.05 → 잔차 −0.2067 V     Δx=0.15 → +0.0506 V
   → 근 Δx_EoC = 0.119891                                    ✓ 존재

식 (12)  x_PE,EoD = Δx+1 · x_NE,EoD = Δx   (인쇄된 형태)
   Δx=0.00 → x_PE=1.000 x_NE=0.000  ← x_PE 가 정의역(≤0.982) 밖
   Δx<0    → x_NE < 0               ← 정의역 밖
   → 정의역 안에서 U_full 이 2.7 V 에 닿지 않는다               ✗ 근 없음
```

`[해석]` 식 (8) 과 (10) 이 함께 **`x_PE,EoD − x_NE,EoD = 1`** 을 강제하는데,
Table 5 모델에서 두 전극의 `x` 가 동시에 그 차이를 낼 수 있는 자리가 없다
(모델의 `U_full` 은 정의역 안에서 3.2 V 아래로 안 내려간다).

**가설 하나를 시험했고 그것도 실패했다.** "(10) 이 (8) 을 따라 `Δx_EoD + 1`
이어야 한다" 로 놓으면 `x_PE = x_NE = Δx+1` 이 되어 `U_full` 이 3.72~3.29 V —
역시 2.7 V 에 못 닿는다. **그래서 추측한 수정본을 채택하지 않는다.**

### 남은 후보 — 두 개의 `x` 정규화

> **2026-09-04 Phase 1j — 환산을 세웠다. 그런데 이 Phase 는 그것으로 안 열린다.**
> `results/phase1j/bridge.csv` 가 **우리 셀의** 창을 못 박는다 (PE 는 전극의
> 65.61 %, NE 는 96.70 %). 그 환산으로 Phase 1g 의 무전류 판은 지어졌고 검산도
> 통과했다. **그러나 여기 필요한 것은 Birkl 의 셀의 창 상수**이고, 그것은
> 여전히 인쇄돼 있지 않다 — 참고문헌 **[33]** 이 계속 필요하다.
> **다만 우회로가 하나 생겼다**: 그의 *상수* 대신 그의 *구조*(식 7–10 의 형태)를
> 우리 환산으로 **우리 좌표에** 얹으면 3-파라미터 판을 우리 셀에서 구성할 수 있다.
> 그러면 이 스크립트가 겨눈 "논문이 비워둔 자리" 를 원전 없이 채우게 된다.
> 다음 라운드의 후보다.

논문에는 `x` 정규화가 **둘** 있다. 식 (1)·Table 5 의 `x` 는 **전극 자신의 격자
점유율**(0~1)이고, 식 (7)–(10) 의 `x` 는 `[인쇄]` "the active material originally
**utilised within the capacity range of the full cell**" 기준이다. 둘을 잇는
환산이 인쇄돼 있지 않다 — 식 (6) 의 `q_Cell`(2단계 셀 동시적합 파라미터)이
그 자리로 보이지만 Table 5 가 `q`(반쪽셀, 식 3)인지 `q_Cell`(식 6)인지 캡션이
가르지 않는다. 확정하려면 참고문헌 **[33]**(이전 OCV 모델 논문)이 필요하다.
