## §1. 목표와 **비목표**

**목표** — 건식 혼합 공정을 우리 파이프라인에 붙인다. 지금 우리 계는 *"이미 섞인 침대"* 에서
시작하고, **어떻게 섞였는지**가 없다.

⛔ **비목표 (이 설계가 답하지 않는 것)**
1. 믹서에서 나온 침대를 **그대로 전달 솔버에 넣는 것** — §2 가 그것을 불가능으로 만든다.
2. 카본블랙 분쇄를 DEM 으로 푸는 것 — `asylbekov` 가 그것을 **DEM 밖**(PBE)으로 뺐다.
3. 문헌의 **소재 절대값**(γ·μ·ρ·d) 전이 — `lischka` 는 **SE 가 한 알도 없는** NMC+CB 2성분계다.

## §2. ⛔ 실현가능성 — **믹서에 우리 조성을 그대로 넣을 수 없다**

Eirich EL1 침대 부피 = **534.6 cm³** (pan Ø165 mm × 충진 25 mm, `hare2026` 실측).
우리 조성 `φ_AM 0.369 · φ_SE 0.154` (LHS `lhs00_000` 실측), P:S 7:3, 크기비 **12:4:1**.

| 구성 | 입자 수 |
|---|---|
| 3종 · 12:4:1 보존 · `d_AM_P = 2 mm` | **34,374,864** |
| 같은 것 · `d_AM_P = 1 mm` | **274,998,908** |
| 2종(AM 합침) · 비 10:1 | **19,700,138** |
| **문헌** (`lischka`·`hare`, **단일종** CGF 200, d = 2 mm) | **46,000 – 67,000** |

**구조적 이유**
```
N_SE / N_AM = (φ_SE/φ_AM) · (d_AM/d_SE)³ = 0.417 × 1000 = 417배
```
⇒ 문헌이 성립하는 것은 믹서가 작아서가 아니라 **입자종이 하나**이기 때문이다
(`lischka`: NMC 2차입자 + 표면 CB 를 합친 **10 µm 덩어리 한 종**).

반대 방향 확인: **실제 크기**(12/4/1 µm)로 총 50만 입자가 되는 상자는 한 변 **119 µm**
= 우리 생산 RVE 규모 그대로다.

> [!danger] 결론
> **"믹서 런의 최종 배치를 전달 솔버에 넘긴다" 는 경로는 닫혀 있다.**
> 크기비를 줄이면 Furnas 패킹이 죽고(정본: dip 은 크기비에 산다), 안 줄이면 입자 수가 죽는다.

## §3. 그래서 구조 — **두 트랙이 통계로 만난다** (`asylbekov` 아키텍처)

`asylbekov2023` 이 같은 벽에 부딪혀 내놓은 답: **DEM 은 응력·빈도만 주고, 미세상의 변화는
DEM 밖(PBE)에서 푼다. CB 는 DEM 안에 아예 없다.** 그것을 우리 문제에 맞춰 쓴다.

```
[트랙 A] 믹서 규모 · 거친 DEM · 단일(또는 2)종
      │  산출 = 구조가 아니라 **통계**
      │        전단율 · 충돌에너지 스펙트럼 · 응력영역 체류 · 툴 충돌률
      ▼
[커플링] 응집 파괴 법칙  (PBE 또는 보정된 스케일링)
      │  산출 = **응집수 N_agg** (또는 응집체 크기분포)
      ▼
[트랙 B] RVE 규모 · 실제 크기 · 3종 · otani 방식
         응집수를 **입력으로 지정**해 침대를 만든다
      │
      ▼
   기존 파이프라인 (압밀 → STEP3 σ → …)
```

★ 이 구조의 값어치: **트랙 B 는 오늘 돌릴 수 있고**(RVE 규모), 트랙 A 는 그 축에
**공정 의미를 붙인다**. 그리고 둘 중 하나가 늦어도 다른 하나가 서지 않는다.

## §4. 트랙 B — 응집수 제어 RVE (먼저 돌린다)

`otani2025` 방식. **새 기구 없음 · 기존 덱 구조 유지.**

- 설계축 = **응집수 `N_agg`** (한 응집체에 든 SE 입자 수). 스윕 `N_agg ∈ {1, 2, 4, 8, 16}` (안).
- 생성: SE 를 낱개로 뿌리지 않고 `N_agg` 개를 뭉친 덩어리로 시드 → 정착 → 플래튼 압밀.
- ⚠ **응집을 무엇으로 유지하나** 가 결정 사항이다 (§6).
- 산출: porosity(ε_sphere) · coverage · τ · σ_ion/σ_e — **기존 디스크립터 그대로**.
- ⇒ *"분산이 나쁘면 전극이 얼마나 나빠지나"* 의 **응답면**이 나온다.

## §6. ⛔ 미해결 — 점착 파라미터화가 **문헌과 다르다**

| | 우리 생산 덱 | 문헌(`lischka`·`hare`) |
|---|---|---|
| 접촉법칙 | `hooke/hysteresis` | Hertz–Mindlin |
| 점착 | **`coefficientAdhesionStiffness` `m7` (k_c)** · **3×3 비대칭** (SE–SE 가 AM–AM 의 10배) | **JKR 표면에너지 γ** · 상별 구분 **없음**(입자종 1개) |
| 코스그레이닝 시 재계산 | **없음** | **cohesion number 불변 → γ ∝ R\*^1.6** (실측 지수 밴드 1.6–1.85) |

> [!danger] 두 간극이 실재한다
> ① **`k_c ↔ γ` 환산식이 `lischka` 에 없다** — 그 논문은 JKR-γ 계열 하나뿐이다.
>    ⇒ `prereg_m7` §2-3 의 ⬜ 는 이 카드로 **안 닫힌다.** Luding 2008 · Pasha 2014 ·
>    Thakur 2014 로 내려가야 한다.
> ② **γ 를 실제 입경까지 되짚으면 비물리적으로 작다** — `0.3 / 200^1.6 ≈ 6.3e-5 J/m²`
>    (산화물 vdW 는 보통 1e-2–1e0). `lischka` 자신도 *"NMC–NMC 표면에너지는 **모르고
>    재기 어렵다**"* 며 그 방향을 **포기**한다.
>    ⇒ **"보정된 CG 점착을 되짚어 실제 점착을 얻는다" 는 경로는 문헌의 수에서 성립하지 않는다.**

⇒ **트랙 A 의 점착은 절대값이 아니라 무차원 불변량(Bond 수 / cohesion number)으로만
전이한다.** 절대 γ·k_c 를 문헌에서 베껴오지 않는다.

## §7. 검증 앵커 (우리가 실제로 맞출 수 있는 것)

| 앵커 | 무엇 | 가용성 |
|---|---|---|
| **소비전력** | 믹싱툴 power draw ↔ 실험 | `lischka` 가 이 방법으로 보정 — ⬜ **우리 실험값 없음** |
| **PEPT 속도장** | 3D 유동 ↔ DEM | `hare` — ⬜ **우리 장비 없음** |
| **AOR / shear cell** | 벌크 유동성 ↔ 점착 파라미터 | 분야 표준 — ⬜ **우리 값 0** |
| **벌크밀도** | 혼합시간 ↔ ρ_bulk | `lischka` 실험 — 🔶 측정 가능할 수도 |
| **혼합지수** | Lacey / CLMI / `E_XY` | ✅ **우리가 계산한다**(후처리) |

> [!warning] 정직하게
> 트랙 A 는 **지금 앵커가 하나도 없다.** ⇒ 첫 판은 **절대 예측이 아니라 상대 비교**로만
> 설계한다 (`prereg_m7` 이 이미 그렇게 짜여 있고, `Pantaleev 2017` 이 *"FT4 보정이
> 맞았는데도 혼합속도는 정성적으로만 맞았다"* 는 반례를 준다).

## §8. 판정선 — 런 **전에** 등록한다

**트랙 B (응집수 스윕)**
- 주지표: `σ_ion` · `coverage_AM_total` · `ε_sphere`, `N_agg` 에 대한 단조성
- `h1`: `N_agg 1 → 16` 에서 `σ_ion` 이 **시드-SE 의 2·SE 밖으로** 단조 감소
- `h0`: 같은 구간 변화가 **1·SE 안**
- 시드 ≥ 3 · 조성 고정 · `--add-rng-per-phase` 필수 (`CL-77`)

**트랙 A (믹서)**
- 주지표: **툴 충돌률**(정규화) · 전단율 분포 · 응력영역 체류
- `h1`: tip-speed 3배(10→30 m/s)에서 혼합속도 `k` 가 **1.4배 이하** (= `hare` 의 판정을 우리 계에서 재현)
- ⚠ 이것은 **재현 시험**이지 새 발견이 아니다 — 그것이 첫 판의 목적이다(앵커가 없으므로)
