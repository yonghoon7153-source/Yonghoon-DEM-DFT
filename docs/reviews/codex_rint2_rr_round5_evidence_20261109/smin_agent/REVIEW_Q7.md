# Q7 / RCA-11 독립 검토 — `s_min = 0 µm`

검토 핀: `abf0911ebc994167ac50132c78207c6c8d4421f1`. 범위는 등록 문면, 동봉 SBE 보고 JSON의 재계수, 실제 함수의 두 소형 합성 기하이다. 원 S0/DBE/전도도 풀이·호스트 접근·등록 변경은 하지 않았다. 외부 NPZ의 독립 확인은 이 문서의 근거에 포함하지 않았다.

**판정: `0 µm`를 선택한 규칙·공개·순서는 수용 가능하다. RCA-11 전체 종결은 부분이다. 새 P2 한 건은 등록 105–106행의 영향 범위와 동등성 판정이다.** 이 결과는 다른 숫자를 선택하라는 권고가 아니다. 실제 σ 영향은 측정하지 않았다.

## 1. 수용되는 것

1. 등록 99–103행은 “빈 분포에서 0을 추정했다”가 아니라 **등록된 바닥 밖의 추가 필터를 두지 않는다**는 저자 선택이다. 후보·선택자·열람한 JSON SHA·실패 처리와 이후 봉인 순서를 적었다. 같은 문장을 구현하면 같은 숫자 0이 나오므로 “두 사람이 같은 값을 낸다”는 절차적 재현성은 충족한다. 실험적 식별이나 최적값이라는 뜻은 아니다.
2. 한정어 ⑪(등록 293행)은 “SBE 자기 후보 0건 — 자료가 아니라 규칙으로 고름”을 보존한다. SBE의 빈 분포가 DBE의 자기 접합·같은 조각 면·SV 연결 분포를 식별하지는 못한다.
3. `s_min ∈ [0,D]`의 **분류 동작** 동등성은 실제 코드로 성립한다. `_self_floor`는 `s > D`와 `s > (π/2)d`를 요구한다(`carbon_junction.py:200–207`). 바닥을 통과한 쌍은 모든 `t ≤ D`에 대해 `s ≥ t`; 바닥 밖이면 `_continuity`가 이미 참이다(`:195–197`, `:1387–1393`, `:1460–1466`). 이것은 자기 후보가 0이라서 성립하는 항등식이 아니다. 어느 침대든 같은 D와 같은 입력에서 성립한다.
4. 다만 `None`과 0의 **상태·기록 바이트**는 같지 않다. `None`은 `self_s_min_missing`과 정량 거부를 남긴다(`:951–957`). 숫자·fingerprint도 달라지므로 “S0 원장 전체 바이트 동일”로 넓히면 안 된다.

## 3. RR5-01 [P2] — 자기 후보 0으로 동일 동작을 선언하는 기준은 반례가 있다

**근거 위치:** 등록 `rint_carbon_additive_registration_R_draft_20261020.md:105–106`, 요청서 `codex_rint2_rr_round5_request_20261109.md:86` 및 `:139`.

105행은 DBE에서 후보값 사이 차이가 짧은 자기 접합뿐이라고 적고, 106행은 `s ≤ (π/2)D` 자기 후보가 0이면 후보 (가)–(다)가 DBE에서도 같은 동작이었다고 해석한다. 둘 다 성립하지 않는다.

**고정 소형 반례:** 격자 10×10×4, vox 0.15 µm, r_f 0.075 µm, tol_ff 0.07381254285530132 µm, L_par=r_port=0.3 µm. 세 점으로 된 한 가닥 V:

```text
(0.9729629131445341, 0.5844095225512604, 0.225)
(0.49,               0.455,              0.225)
(0.9729629131445341, 0.32559047744873965,0.225)
```

실제 `segment_cells`와 `cjunc_registry`를 호출한다. 함수 mock·σ 풀이·입력 결과값 사용은 없다. 첫 변형은 VGCF만, 둘째는 격자 셀 `(4,2,2)`, `(4,3,2)`에 SDCP 두 셀을 더한다. 두 경우 모든 반환 `rejections=[]`.

|---|---:|---:|---:|---:|

`.3515639202077327`도 이 반례에서 `.3`과 같은 쪽이다. 반대로 `D/2`와 `D`는 0과 같은 분류다.

바뀐 VV 면은 선형 셀 번호 169, axis=1, owner 위치 (2,5)다. 두 셀 부분의 **s_face=0.2277607596902182 µm, d_face=0.058948822334846995 µm**라 바닥을 통과한다. s_min=0에서는 `K_UNREG(5)`, .3에서는 `K_SELF_FUSED(6)`로 바뀐다(`carbon_junction.py:869–890`). 선분 전체의 최근접점은 공통 꼭짓점이므로 자기 후보는 여전히 0이다.

같은 두 owner의 SV 무리는 `_pos_pair_sd → _continuity`를 거쳐 합쳐진다(`:2077–2079`). 그 결과 `_sv_split`의 끊을 면과 bridging 판정이 달라진다(`:2119–2138`). 이 경로는 등록한 자기 후보 수에 들어 있지 않다.

**무너지는 결론:** 후보 0만으로 `s_min=0/.3/.3516`의 DBE 분류·SV 진단이 같다고 선언하는 것. 실제 DBE에서 이 현상이 발생한다거나 σ 차이가 크다는 결론은 이 반례로 내리지 않는다. 제안된 0 값 자체, SBE 보고의 자기 후보 0 사실, [0,D] 동등성은 무너지지 않는다.

**최소 수정:**

1. 등록 105행의 “DBE 차이 = 짧은 자기 접합뿐”을 “자기 instance/포트·같은 조각 비축방향 면·SV 무리/반사실 절단에 영향을 줄 수 있다; 실제 빈도와 σ 영향은 미측정”으로 바꾼다. 준비자료 `SMIN_PREP.md:62–64`, `:149`도 이미 이 세 경로를 구별한다.
2. 106행의 “그 수 0이면 같은 동작”을 지운다. 자기 후보 수는 **자기 접합 후보 진단**으로만 보고한다. 전체 동등성을 주장하려면 같은 고정 입력에서 적어도 instance/포트·같은 조각 면 분류·SV 무리/절단을 직접 비교해야 한다. 기준값은 그대로 봉인하고 기술 비교 결과로 다시 선택하지 않는다.
3. 105행의 19.9Ω 근거에는 **해당 두 점 사이 축방향 전기 경로가 실제로 살아 있고 그 이상 원통 근사가 적용될 때만**을 복구한다. `SMIN_PREP.md:183`에는 이 조건과 SDCP 덮임 예외가 있으나 등록 본문에서 빠졌다. `carbon_junction.py:938–946`도 살아 있는 경로와 path-broken을 구별한다. r′s의 산술만으로 실제 DBE 전도도 영향 상한은 증명되지 않는다.

## 4. UNREG와 감도 없음의 해석

SBE에서 같은 조각 미등록 면 중 일부만 융합하는 경우, **같은 그래프·같은 R_j·다른 모든 설정 고정**의 `UNREG=all fused`가 그 부분 융합의 σ 상한이라는 Rayleigh 주장은 타당하다. 이것은 그 부분집합의 개수나 효과가 작다는 증명이 아니다.

또한 이 상한을 자동으로 다음에 옮기면 안 된다: (i) s_min이 바꾼 SV 반사실 절단/무리, (ii) 자기 instance가 바뀐 DBE 전체, (iii) 각 변형이 SBE에서 별도로 R_j를 재보정한 뒤의 DBE 예측 구간. 등록은 필수 감도마다 동일 판정 함수를 쓰고 보정을 다시 수행하므로(등록 59행) 고정 R_j 단조성과 보정 후 비교를 구별해야 한다.

감도 팔을 안 두는 것은 저자의 공개된 범위 선택으로 남길 수 있다. 다만 “이미 영향이 작거나 같은 것이 입증돼 불필요”라는 근거는 철회해야 한다. 이를 새 값 선택이나 새 연구 실행의 승인으로 쓰지 않는다.

## 5. 종결 제안과 재현

**닫을 수 있는 부분:** s_min 선택 규칙의 결정성, 후보/열람/선택 기록, 0이 ‘추가 문턱 없음’이라는 뜻, [0,D]의 분류 동등성, 자료가 아니라 규칙이라는 한정어.

**남는 부분:** RR5-01 문면 교정, 실제 계획의 0 봉인, DBE의 관련 분포/동작 기술 보고, 실침대 영향·s_min 자격·반복/비용 범위. 따라서 RCA-11 전체는 **부분**으로 두는 것이 맞다. 등록 98·108행의 열림 기록과도 일치한다. 이것으로 S0 단계2/R 런/생산 GO를 내지 않는다.

검토 트리에서의 최소 재현(고정 pin을 가진 자신의 리포 경로를 넣음):

```bash
python -I -B -X utf8 reproduce_smin_counterexample.py --repo /path/to/repo --out result.json
```

제공 파일:
- `reproduce_smin_counterexample.py`: 고정 두 기하, 모든 실제 함수 호출, 거부 사유/경계 동등성/반례 assert. 회귀 전체 실행 없음.
- `fixed_counterexample.json`, `fixed_counterexample.log`: 위 명령 실행 결과(rc0). 함수 호출 횟수·여러 문턱을 별도 고유 시험 수로 합산하지 않음.
- `probe_smin.py`, `probe_smin.json`, `probe_smin.log`: JSON 재계수·산술·발견 과정의 원로그. 6개 작은 V를 조사한 뒤 첫 반례를 고정했고, SV 위치를 찾는 25개 작은 기하를 조사했음을 보존. 연구 침대/결과 선택이 아님.

최종 권고 문장: **“s_min=0 µm는 빈 SBE 자기 후보 분포로 식별한 값이 아니라, 기존 바닥 밖의 추가 필터를 두지 않는 사전 규약으로 채택한다. 후보 수만으로 DBE의 동일 동작이나 작은 σ 영향을 주장하지 않으며, 실제 계획 봉인과 등록된 후속 기술 보고는 별도다.”**
