## 1. 무엇을 하는가 — 그리고 **하지 않는가**

**한다**: 네 시나리오 각각을 **8 origin phase** 에서 푼다.  지금 보고값은 전부 arm 0
한 팔이고, 전자축은 8팔 평균이라 **같은 그림 안에서 등급이 다르다** (Codex R17 Q3).

**하지 않는다**:
- ⛔ **STEP B 의 h0 판정을 다시 하지 않는다.**  그 분류는 arm 0 등록식으로 확정됐고
  (CL-59, R16 Q1 CONFIRMED) 이 런은 그것을 재판정하지 않는다.
- ⛔ **대표값을 고르지 않는다** (R16 Q5 · R17 Q1 둘 다 REFUTED).  네 점 병기 그대로다.
- ⛔ 문턱(`W ≤ 0.10` / `W ≥ 0.30`)을 건드리지 않는다.

**목적은 하나** — 보고하는 값에 **origin 통계를 붙여** 전자축과 같은 등급으로 만든다.

## 4. 방향 문장을 허용하는 조건 (**결과 전 등록**)

지금은 *"방향 미결정"* 이다.  8팔이 그것을 바꿀 수 있는 유일한 경로를 여기 못 박는다.

- **개별 시나리오의 부호**: 그 시나리오의 `|R̄ − 1|` 이 그 시나리오의 **origin SD 의 3배**를
  넘을 때만 *"이 규약에서 R 이 1보다 크다/작다"* 라고 쓸 수 있다.
  ⚠ 그래도 그것은 **그 규약 안의 서술**이지 물리적 방향 주장이 **아니다**.
- **전체 방향**: 네 시나리오가 **전부** 위 조건을 만족하고 **부호가 같을 때만**
  *"SDCP 치환이 이온 전도를 올린다/내린다"* 를 쓸 수 있다.
  ⚠ 현재 arm 0 값으로는 이것이 성립하지 않는다 (0.977 · 0.980 · 0.997 · 1.008).
- ⛔ 위 둘 중 어느 것도 만족하지 않으면 **문장은 지금 그대로** — *"네 시나리오에서
  |R−1| < 2.3 %, 방향 미결정"*.
- ⛔ **equivalence 주장은 어느 경우에도 불가**다 (margin 미등록, R16).

⚠ RSA 시나리오의 `R−1 = −0.28 %` 는 전자축 origin 산포(0.30 %)보다 **작다**.  이 런의
가장 그럴듯한 결과는 *"개별 시나리오 부호도 여전히 판별 불가"* 이고, **그것도 결과다.**

## 5-1. ⚠⚠ `ρ_SDCP` 의 지위 — **이 축에 앵커가 하나도 없다** (런 전 명시)

밀도 실측값이 **없다** (저자 확인, 2026-08-31).  Table S2 에 밀도 열 자체가 없다.
현재 쓰는 두 수의 출처를 추적한 결과:

| 값 | 출처 | 성격 |
|---|---|---|
| **1.30** | `scripts/additives.py:25` — *"⚠PROXY from generic PEDOT web-lit — REPLACE with the user's manuscript value"* | **다른 물질**(일반 PEDOT)의 웹 문헌값.  리포에 구체적 인용 없음 |
| **1.1 / 1.7** | `sdcp_ion_calib_prereg_20260825.md` §감도 | **우리가 정한 ±30 % 프로브**.  문헌값이 아니다 |

⇒ 설포네이트 자기도핑 PEDOT 의 밀도에 대해 **문헌·측정 어느 앵커도 없다.**

### 5-1a. 그런데 이 값이 결과를 어디까지 정하는가

`ρ` 는 0.5 wt% SDCP 의 **입자 수**를 직접 정한다 (`additives.py:158`):

```
V_SDCP = (0.5/100) × M_total / ρ_SDCP        n = V_SDCP / (Ø0.30 구 부피)
```

그리고 바인더 부피비가 `V_DBE/V_SBE = 0.5 + 1.1/ρ_SDCP` (Codex R17 Q4) 이므로
`ρ` 가 SDCP 의 이온 기여와 **부피 점유 손실** 사이의 균형을 옮긴다.

⚠ **그러나 "ρ 가 부호를 정한다" 는 아직 측정된 것이 아니다** (R17 Q4).  현재 네 R 점은
**전부 ρ=1.30 의 같은 전극 geometry** 에서 나왔다 — 그것은 기전 추론이지 실행된 밀도
민감도 결과가 아니다.  재려면 밀도별로 **침대를 재생성**해야 한다.

### 5-1b. 그래서 이 런의 지위 (런 전 선언)

- 이 런의 **절대값은 `ρ_SDCP = 1.30` 프록시 조건부**다.  캡션에 그렇게 적는다.
- ⛔ *"밀도 감도를 확인했다"* 라고 쓰지 않는다 — 이 런은 단일 ρ 다.
- ★ 그래도 이 런이 답하는 질문은 **ρ 와 별개로 유효**하다:
  *"개별 시나리오의 `R−1` 이 격자 원점 산포를 넘는가?"*
  (RSA 의 `R−1 = −0.28 %` 가 전자축 산포 `0.30 %` 에 묻히는지)
- `ρ` 가 나중에 확정되면 **침대를 재생성하고 다시 푼다** (R17 Q4).  이 런의 방법과
  *"격자 산포가 0.3 % 급"* 이라는 결론은 그때도 남는다.

### 5-1c. ⚠⚠ 밀도는 **얻을 수 없다** — 미측정이 아니라 구조적 한계다

2026-08-31 저자 확인: **합성처에서도 진밀도를 못 준다.**  ⇒ 이 축은 *"측정 대기"* 가 아니라
**"이 연구에서 확정 불가"** 다.  성격이 다르므로 취급도 달라야 한다 — 쫓는 것이 아니라
**보고하는 것**이다.

- 원고·SI 에 `ρ_SDCP` 를 **파라미터로 싣지 않는다** (측정값이 아니므로).
- 대신 σ_ion 시나리오 설명에 *"the calculations use an unmeasured generic-PEDOT density
  proxy (1.30 g cm⁻³); the true density of this polymer was not available"* 를 넣는다.
- 문헌 앵커(`PEDOT-S` 계열)는 **찾으면 더 나은 프록시**일 뿐 측정값이 되지 않는다.
  ⚠ 이 브랜치의 `litdb/` 는 2026-07-16 동결본이라 정본 브랜치에서 찾아야 한다.

### 5-1d. ★ 그래서 더 나은 질문이 생긴다 — **ρ 가 상쇄되는가**

`ρ` 는 **두 곳에** 들어간다:

```
펠릿 역산   ρ 가 높으면 바인더 부피가 작아 덜 막힘 → 같은 표적을 맞추는 r̂ 가 **작아진다**
전극 기하   ρ 가 높으면 SDCP 가 SE 를 덜 밀어냄   → 부피 페널티가 **작아진다**
                                  ↓
                     두 효과가 **반대 방향**으로 R 을 민다 = 부분 상쇄
```

⇒ 지금처럼 **`ρ` 를 1.30 에 고정한 채 `r` 만 흔드는 것은 상쇄를 끄고 보는 것**이고,
따라서 **보고하는 폭이 실제보다 넓을 수 있다.**

★ 그리고 이것은 **밀도를 몰라도 답할 수 있는 질문**이다.  *"어떤 `ρ` 든 그 `ρ` 로 역산한
`r̂(ρ)` 를 쓰면 전극 결과가 이 범위"* 라고 보일 수 있으면, **밀도 미상이 결론을 못 흔든다는
것 자체가 결과**가 된다.

⚠ 그러려면 `ρ` 마다 **침대를 재생성**해야 한다 (입자 수가 바뀐다) — MPM 압밀 포함이라
이 8팔보다 무겁다.  ⇒ **후속으로 분리하고 여기서 등록만 해 둔다**:

```
ρ-정합 프로브 (후속, 별도 사전등록)
  · ρ ∈ {1.1, 1.3, 1.7} 각각에 대해 침대 재생성 + D13 재역산으로 r̂(ρ) 를 얻는다
  · 그 (ρ, r̂(ρ)) 쌍에서 전극 R 을 arm 0 로 잰다
  · h1: 세 R 이 지금의 r-스윕 폭(3.1 %)보다 **좁다** ⇒ ρ 가 상쇄된다
  · h0: 그렇지 않다 ⇒ 밀도 미상이 그대로 결론 폭이다
  ⚠ 문턱은 그 사전등록에서 정한다.  여기서 정하지 않는다 (런이 아직 설계 전이다)
```

⚠ 이 8팔은 그 프로브가 **아니다** — 단일 `ρ` 다.  둘을 섞어 보고하지 않는다.
