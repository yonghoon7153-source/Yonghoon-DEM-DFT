# LPSCl | Ag–C | VGCF 점착일(W_ad) — 계획 v3 · 보고량 카드 초안

### DFT 검증
- 짝 = 같은 기하에서 UMA ↔ **분산 없는 PBE/PBE+U**. ⚠ omat 은 VASP·특정 PP 계보라 QE 설정 차이도 오차에 섞인다 — 검증 범위를 그만큼 좁혀 적는다.
- 힘은 **기하 적정성 진단**이다 — 보고량을 평형값으로 승격하지 않는다.
- 오차 예산 (결과 전 채택): **검증 표본마다** |W^PBE − W^UMA| ≤ **0.10 J/m²** (평균이 아니라 표본 하나하나에 적용 — Codex 보충 · *BV 제안 운영값*, 문헌 표준값 아님) · 계면별 검증 표본 평균 부호오차 절댓값 ≤ **0.05 J/m²** ·
  기준 DFT 수치 설정에 따른 W 변화 ≤ **0.02 J/m²** · 오차 범위가 0 또는 구간 경계를 건드리면 **보류**. 25 % 는 합격선에서 빼고 보조 오차율로만.
- 표본 = **사전 고정 5개** (UMA 분포의 최소 · Q1 · 중앙 · Q3 · 최대, 동률 처리도 결과 전 고정). 처음 2개는 실행 가능성·조기 실패 확인용이고 **2개 통과 종료는 폐기**.
  선별한 DFT 표본의 중앙값·IQR 로 20시드 분포를 대표시키지 않는다.

### NCM
- 정상 LiNiO₂ 가 먼저. 상태 정책 **택1**: ① FM 고정 → *FM-conditional* 로 보고 (저비용) ② FM + 서로 다른 보상형 자기 시드 2개(최소 3 초기화) 중 정상 수렴한 최저 — *"선언한 초기화 집합의 최저"* 이지 바닥상태 주장이 아니다. 전체 스핀 반전은 독립 시드가 아니다.
- U = **Dudarev 6.2 eV, J = 0** (MP 계보) 출발값 — PP · Hubbard projector · 상태 정책과 함께 **고정**. W 를 맞추려고 U 를 바꾸지 않는다.
- 계면과 분리 참조에 **같은 상태 정책**. 상태를 이어가는 분리인지, 끝점마다 최저를 찾는 분리인지 구분해 적는다.
- NCM 이 실패하면 **Ag/NCM 대비만** 멈춘다 — Ag|SE · Ag|흑연 은 독립이다.
- 1L = 유한 시트 **조건부 비교만** 허용 (벌크 양극 대표값·DEM 보정 기준 불허 · 3L 이면 자동 통과도 아님). 옛 1L → 2L(+74 %) → 5L 은 **두께만 바꾼 대조가 아니다** — 두께 효과로 읽지 않는다.

### 문헌 반영 — Giovannetti 2008 (`litdb/papers/giovannetti2008_doping_graphene_metal_contacts.md` · 메인이 PDF `Table I`·각주 [18] 로 재대조)

### P2 격자 정합 후보 — 정방 SE 단면 위 직사각 초격자 (메인 재계산 · **결정 전 후보**)

**분리 참조 (MoLE)**: 주 경로 $W_{sep} = (E_{A+B,far} - E_{A+B,bound}) / (n_{interface} A)$ — **결합·분리 두 끝점에 같은 (충분히 높은) 셀**. 셀 경계를 넘는 간격까지 확인.
진공·주기영상 변경 ΔW ≤ 0.01 · 추가 분리 ΔW ≤ 0.01 · D3 장거리 꼬리 포함 (UMA 절단거리 밖이라고 완료 처리하지 않는다).
가산성 잔차 $\delta_{add} = (E_{A+B,far} - (E_A + E_B)) / (n A)$ 는 **기록** — 합친 셀 경로만 쓰면 잔차가 커도 경로를 탈락시키지 않되 독립 슬랩 합으로 **바꿔 계산하지 못하게** 한다. 두 경로를 섞거나 교환 가능하다고 주장하면 |δ_add| ≤ 0.01 J/m².

**UMA+D3**: 같은 좌표·셀·끝점·D3 구현이면 $W_{PBE+D3} - W_{UMA+D3} = W_{PBE} - W_{UMA}$ → 이 검증은 *PBE+D3 모형 재현도*를 묻는다. D3 자체의 계면 정확도·금속 차폐의 독립 증거가 **아니다**.
대표 registry 에서 같은 고정 내부 기하로 **압축 쪽 · UMA 최소 부근 · 인장 쪽 E(d)** 를 대조한다 (끝점 W 하나가 맞아도 곡선이 틀릴 수 있다). 간격은 **"UMA+D3 최적화 간격"** 이라 부르고 DFT 평형 간격으로 승격하지 않는다.

**SE\|SE 4층**: $W^{4L}_{cleave} = (E_{110} + E_{98} - 4E_{bulk,52}) / (2A)$ — 계수 **4** (6층 결정문의 6 을 복사하지 않는다). 집계기(`se_sym_slab.py --collect`)는 P 개수로 계수를 내지만 **결정문·입력 명세도** 새 조성과 맞춘다 → 경보 결정문 개정 필요.

## 4. 보고량 카드 초안 v2 (proposed — 비준 전)

### §1 무엇을 원하는가
> **같은 조작 · 같은 SE 셀 규약 · 같은 계산기**로 낸 LPSCl|Ag 와 (다시 낸) LPSCl|NCM 의 **W 분포**를 나란히 놓고, 그 **비**와 자릿수 급을 —
> 같은 기하의 **DFT(PBE) 로 검증된** 짝으로 — 말한다. 헤드라인 절대값은 DFT(PBE+D3) 에서만.

### §1-c 답하지 않는 것
> 반응 **후** 계면(Ag–S 화합물 · LiAg 합금 뒤) · 실험 박리강도 · 실접촉면적·구동압(DEM 층의 몫) · `α·ΔW_strain` 보정값과의 비교 ·
> **두께 수렴된** NCM 값 (1L 라벨) · **UMA 절대값** (repo 금지 규칙) · AFM aJ 와의 절대 비교.

### §2 재는 양
```
W_sep(s)  = [E_sep(s) − E_int(s)] / A            # 분리 +30 Å · 셀 +30 Å · 이완 없음 (워크플로와 같은 조작)
W_ad(s)   = [E_A^rel + E_B^rel − E_int(s)] / A   # 각 슬랩을 같은 셀에서 이완 (워크플로에 없던 값) — 항상 W_ad ≤ W_sep
W^PBE     = 같은 식 · PBE(+U: NCM 쪽) 단일점 · UMA 기하 위 · D3 없음      ← UMA 의 검증 짝
W^PBE+D3  = W^PBE + ΔD3(같은 기하 · D3(BJ) 가산항 — 고정 기하에서 정확히 분해)   ← 헤드라인 후보
UBER E(d) = 이완 계면을 강체로 z-스캔, 평형 + 8 Å
```
s = xy-shift 시드. A = 404 Å² (정방 20.11²). *"D3 끈 값"* = **W^PBE** (같은 기하에서 D3 항 제외) — *D3 끄고 이완한 값*이 **아니다** (물리흡착 계면은 D3 없이 이완하면 떨어진다).
⛔ `− α·ΔW_strain` 보정은 넣지 않는다 (실험 순위로 맞춘 항이고 Ag 에 대응물이 없다. 같은 셀의 W_sep·W_ad 에서 변형에너지는 상쇄된다).
