# Q-B2 후보 — 남은 격자 의존의 기전은 **SDCP 접촉 양자화**다 (2026-08-25)

> 원장: `docs/reviews/claims.json` CL-41 (status `hold`) · CL-39 · CL-44.
> ⛔ 이 문서는 CL-41 의 R 값을 **인용하지 않는다** (p1 규약, `quotation_ban`).
> 여기서 쓰는 것은 **구조량**뿐이다 — 증분비 1.773 · 멱법칙 최소 2.187 · 상승률 0.849 → 0.933.

## 0. 왜 이 문서가 필요한가

CL-41 은 세 격자에서 이득이 **단조 증가하고 멈추지 않으며**, 증분비 1.773 이
`R = R∞ − C·h^p` 가 이 간격에서 낼 수 있는 **최소값 2.187**(p→0⁺) 보다 작아
**어떤 p > 0 도 안 맞는다**고 적었다.  Richardson 은 무의미하고, 정규화 상승률은
오히려 커진다.  그리고 그 기전에 대해 원장은 **"Q-B2, 후보 없음"** 이라고 적어 두었다.

이 문서가 후보를 하나 댄다.  **측정으로.**

## 1. 먼저 — CL-39 의 수렴 판정에는 판별력이 없다

CL-39 는 SDCP 표현부피/참부피가 `0.986 / 0.984 / 0.984` (폭 0.2 %) 이므로
**"기전 변수는 수렴했다"** 고 적었다.  그런데 그것은 **배치 평균**이다.

생산 규약 그대로(셀 중심이 반지름 안이면 그 셀) Ø0.30 µm 구를 **고정 격자**에
무작위 하위-복셀 위치로 4,000 개 찍어 재면:

| d/vox | 배치평균/참 | 입자별 min | max | CV % |
|---:|---:|---:|---:|---:|
| **2.00** (vox 0.15) | 1.0014 | **0.478** | **1.910** | **26.1** |
| 2.40 (0.125) | 0.9955 | 0.553 | 1.382 | 11.5 |
| 2.61 (0.115) | 0.9979 | 0.753 | 1.291 | 10.7 |
| 3.00 (0.10) | 1.0010 | 0.566 | 1.344 | 11.2 |
| 3.50 (0.0857) | 1.0006 | 0.891 | 1.425 | 7.0 |
| 6.00 (0.05) | 0.9997 | 0.928 | 1.158 | 2.6 |
| 8.00 (0.0375) | 1.0001 | 0.940 | 1.067 | 1.6 |

★ **배치 평균은 어느 해상도에서도 무편향이다** (0.9955–1.0014).  d/vox = 2 처럼
명백히 미수렴인 격자에서도 1.0014 를 낸다 ⇒ **그 지표는 수렴을 판별하지 못한다.**
반면 입자별 CV 는 **26.1 % → 1.6 %** 로 움직이고, 실제 런 구간(2.00 → 2.61)에서만도
**26.1 → 10.7 %** 로 절반 이하가 된다.

⚠ 이 측정은 코드가 이미 적어 둔 값과 **정확히 일치**한다 — `step3_sigma.py` 의
게이트 오류문이 `per-입자 부피 산포가 [0.48, 1.91]× 로 커서다` 라고 적고 있고,
내 측정은 `[0.4775, 1.9099]` 다.  ⇒ 래스터라이저가 생산 규약을 재현한다.

**그 사실은 이미 코드 안에 있었고, 게이트 값 2.0 의 근거로만 쓰였다.  비의 미수렴과
연결된 적이 없다.**

## 2. 전도에 직접 걸리는 양 — 접촉 검출

솔버는 **6-면 harmonic-mean** 커플링이다 (`voxel_conductivity.py:162`).  그러면
두 SDCP 구가 이어지는지는 "면-인접 셀 쌍이 하나라도 있는가" 다.  고정 격자에
입자 위치·축 방향을 무작위로 두고 200 회:

| d/vox | 접함(gap 0) 연결확률 | 5 % 틈 | 10 % 틈 |
|---:|---:|---:|---:|
| **2.00** | **0.650** | 0.505 | **0.325** |
| 2.40 | 0.805 | 0.690 | 0.490 |
| 2.61 | 0.815 | 0.685 | 0.490 |
| 3.00 | 0.915 | 0.780 | 0.490 |
| 4.00 | 0.940 | 0.775 | 0.435 |
| 6.00 | 0.995 | 0.750 | 0.240 |

**생산 격자(vox 0.15)에서:**
- **참 접촉의 35 % 가 누락된다** (연결확률 0.650)
- **10 % 물리적 틈이 있는 쌍의 32.5 % 가 가짜로 연결된다**

두 오차는 **σ 에 반대 방향**으로 작용하고, **h 에 대한 수렴 속도가 다르다.**

## 3. 그래서 멱법칙이 안 맞는다

`R = R∞ − C·h^p` 는 **지배 오차가 하나**라고 가정한다.  여기서는 최소 둘이고
부호가 반대다 (누락된 참 접촉 ↑복구 vs 가짜 접촉 ↓제거).  두 항의 **차**는
일반적으로 멱법칙이 아니다.  ⇒ CL-41 의 *"어떤 p > 0 도 안 맞는다"* 는
**이상 현상이 아니라 이 구조의 예측**이다.  Richardson 이 안 되는 이유도 같다.

## 4. 왜 하필 **비**가 움직이나 — DBE 전용 오차이기 때문

- 전자 격자에서 SBE↔DBE 의 **유일한 차이가 SDCP** 다 (VGCF 동일 · PTFE 는 기본
  설정에서 애초에 안 찍힌다).  실측 증거: CL-33 의 **SBE 음성 대조 8/8 셀 단위
  완전 동일** — 구 스탬프 옵션이 SBE 침대에 no-op 이다.
- 그러므로 §2 의 접촉 검출 오차는 **DBE 에만** 걸린다.  침대 간 공통모드 상쇄가
  원리적으로 없다.
- `step3_sigma.py` docstring 이 상대 비교를 정당화하며 적은
  *"identical across compared runs (relative trust preserved)"* 은 **vox 가 같은
  런들 사이**에서만 참이다.  격자 사다리는 정확히 그 전제를 깬다.

## 5. ★ 코드는 이 문제를 이미 알고, **다른 상에는 고쳐 두었다**

`step3_sigma.py:232-237` 이 명시한다 —
*"plain rasterization randomly DROPS touching contacts (6-neighbour faces need
shared/adjacent voxels) — the integration test showed a non-percolating AM
skeleton from quantization alone."*

그래서:
- **AM–AM** : 접촉 중점에 1-복셀 반경 **브리지를 찍는다** (`tol_am_um`)
- **섬유**  : `_fibre_segment_ijk` 가 **6-면 연결을 보장**한다 (`:403`)
- **SDCP 구**: **아무 처리도 없다** — 평범한 중심-포함 래스터

⇒ 이득 전체를 짊어진 **단 하나의 상**이, 접촉 양자화 보정을 **안 받은 유일한 상**이다.

## 6. 해상도 기준의 자기모순

| 기준 | 값 | 출처 |
|---|---|---|
| 구 스탬프 게이트 | **d/vox ≥ 2.0** | `step3_sigma.py:319` |
| 리포가 확립한 실용 규칙 | **d_h/dx ≳ 3.5** (잔여 의존 ~4 %) | CLAUDE.md, SE-곡선 트랙 |

Ø0.30 SDCP 로 d/vox = 3.5 를 만족하려면 **vox ≤ 0.0857 µm** 이고, 실측 peak RSS
35.6 GB @0.115 에서 h⁻³ 로 투영하면 **≈ 86 GB** 다.  vox 0.10 조차 3.00 으로
기준 미달이고 이미 ≈ 54 GB 로 이 하드웨어 밖이다.

⇒ **이 축에서 기준을 만족하는 격자는 한 번도 돈 적이 없고, 격자를 조여서 도달할
수도 없다.**  "메모리가 더 있으면 된다" 가 아니다.

## 7. 판별 실험 (제안, 미실행)

★ **상관은 인과가 아니다.**  CV·누락률·R 이 전부 vox 에 단조라, vox 를 노브로
쓰는 한 CL-43 이 걸린 함정(*"vox 에 단조인 양은 무엇이든 붙는다"*)에 똑같이 걸린다.
**노브를 바꿔야 한다.**

**제안 = `--step3-sdcp-bridge`** — AM–AM 브리지 기계를 SDCP 에 그대로 재사용해
gap ≤ tol 인 SDCP 쌍(및 SDCP–VGCF·SDCP–AM)의 접촉 중점에 1-복셀 브리지를 찍는다.
그러면 **vox 를 안 바꾸고** 접촉 검출만 고칠 수 있다.

- **h0** : 브리지를 켜도 R 의 격자 의존이 그대로다 (기전이 다른 데 있다)
- **h1** : R 의 격자 의존이 **무너진다** (0.15↔0.125 이동이 문턱 아래로)
- 음성 대조 : SBE 는 SDCP 가 없으므로 **셀 단위 동일**해야 한다 (CL-33 과 같은 증인)

★ **h1 이면 이것은 나쁜 소식이 아니라 출구다** — 메모리를 늘리지 않고 수렴하는
파이프라인을 얻는다.  지금 헤드라인을 못 쓰는 이유가 바로 미수렴이므로.

⚠ **이 문서가 주장하지 않는 것**: §2 는 진공 속 **고립 쌍** 측정이다.  실침대에서
SDCP 는 44.4 % 가 AM-anchored 이고 VGCF 옆에 있으므로, 지배적 커플링은
SDCP–SDCP 가 아니라 SDCP–VGCF 일 수 있다.  기전의 **종류**는 같지만 **크기**는
침대 안에서 재지 않았다.  §7 이 그것을 재는 방법이다.
