# 등록 팔 하나 · 등록 일정 · 등록 한도 (블록이 부른다) · 종료 코드 0 완주 · 3 한도 · 4 기술 미완료 (incomplete.json)

`--cpu N` 을 주면 CPU 배정이 {N} 하나이고 스레드 환경 변수 여섯이 모두 1 일 때만 돈다 (블록용).  `--root` 로 원천이 든 다른 트리 (블록 꾸러미) 를 가리킬 수 있다.

팔 이름: 등록 ① = `R1-{G1|G2}-{PLATE|S|F2|F1}-{P|E}-{V0|V4}-{칸}` (V4 = V0/4) · 등록 ②-a = `R2-BED-{S|F2|C1}-P-V0-{12|16|24|36}` · 보고 팔 `R2-BED-{S|F2}-P-U4-24` (탈압만 V0/4).

## 7. 확인 못 한 것 · 1저자가 정할 것

확인 못 한 것:
- WSL (Python 3.12.3 · NumPy 2.5.2) 에서 한 번도 돌리지 않았다.  `CHECK_ONLY --require-wsl-env` 가 그 환경을 요구할 수 있다.
- 실제 팔 시간 — 위 컨테이너 몇 걸음 어림뿐.  특히 ②-a F36 · C1-36 의 한도 여유.
- ②-a 가압 구간 신원 (Q13 원궤적과 비트 같음) — 원 반환 TAR 이 리포에 없어 직접 대조하지 못했다.  대신 같은 원 설정 ② 루프 (원 판 연산자 · 원 틈 보정 커널 · 원 단일장 경로) 를 8 칸에서 돌려 trace 첫 다섯 열과 끝 상태가 비트 같음을 시험으로 본다.  12–36 칸 · Q13 TAR 대조는 판독기 몫.
- 실행 블록과 판독기는 만들지 않았다 (다음 단계).

1저자가 정할 것 (권고 한 줄씩):
- **Q-D1** G1 = "판만" (단일장 검사 · S 와 F 같은 계산) · 한도는 등록대로 F 비율.  — 권고: 그대로.
- **Q-D2** 기술 감시 (\|Δx\| > 0.01 D · 옆벽) 를 넘어도 런은 계속하고 표지만 남긴다.  — 권고: 그대로 (보류 판정은 판독기 · 멈추면 그 팔의 나머지 자료가 없다 · 대가 = 보류될 팔에도 시간을 쓴다).
- **Q-D3** ②-a 가압은 원 루프의 1.2 MPa 정지를 쓰지 않고 Φ_m 0.95 까지 누른다 (1.2 MPa 첫 걸음은 기록).  — 권고: 그대로 (등록 = Φ_m 0.95 · Q13 표에서 S · F 는 0.95 가 먼저).
- **Q-D4** m3 "열린 접촉쌍": 장이 셋 이상 겹친 노드의 쌍별 충격량은 커널을 바꾸지 않고는 가를 수 없다 → 마지막 걸음에 두 장 노드만 쌍별로 세고, 셋 이상 노드가 있는 쌍은 그 수를 따로 적는다.  — 권고: 판독기가 그 쌍을 "미판별" 로 표지 (m3 는 보고 지표).
- **Q-D5** J5 의 부피 평균 σ_yy = Σ V₀ τ_yy / Σ V₀ J (τ = 커널 `stress()` 의 Kirchhoff 응력 · 현재 부피 가중 Cauchy 평균 · 우리 정의) · G1 팔만.  — 권고: 받는다.
- **Q-D6** 탈압 걸음 수 = ⌈0.06 / (V_u Δt)⌉ (이동이 처음 0.06 이상이 되는 걸음까지).  — 권고: 받는다.
