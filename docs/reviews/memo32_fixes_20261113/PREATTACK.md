# 작성 측 사전 점검 — M32R-01–06

독립 검토가 아닌 작성 측 점검이다. 원 독립 판정과 구분하며 수정 후보의 외부 재확인은 요청서로 넘긴다. 전체 HOLD.

| 보장 / 공격 | 관측 | 판정 / 한정 |
|---|---|---|
| 관측 접두부 같고 cap 뒤 연장 반대 | cap .94에서2.4, 목표 .95에서 .6/2.4 모두 가능 | Φ_cap 안정성으로 목표 응력 단조성 인증 불가. 문서/부록 모두 미확정 |
| 두 팔 cap 또는 한 충전 cap만 | 수정 전 버림/한쪽 경계, 뒤 점 중간 | 버림을 통한 같음 표본 선택을 막음. 미관측 목표점 방향을 예측하지 않음 |
| cap+기존 유효 큰 변화/밖 | cap이 낀 해당 띠 점은 미정; 다른 띠 점의 독립된 밖/큰 변화와 기술 실패 우선은 유지 | cap 자체를 밖/구현 오류로 읽지 않음 |
| 운동량 보존하지만 에너지 생성 | 0→0, 1→1.21 | U6(c) 초과 하나로 중단; 낮은 위반 비율로 통과 불가 |
| 미등록 허용폭/분모/순열/해상도, 관측 없음 | 문서와 모형에서 보류 | 허용폭을 이 작업에서 수치로 채우지 않음; 실제 U6 미수행 |
| 자기 걷기 정상, 추가 필수점만 실패 | .18 정상, .12 결측 | F-비교미확정; 두 맥락 분리; 결측≠측정된 효과 |
| 비교 빈/중복/NaN/inf/실패 유한 잔여값 | 작은 상자 모형에서 미완전 | 명부/완료/신원 실제 판독기 자격 아님. 검증 전에 정규화하는 구현을 만들지 않음 |

| M0 3계수 다 맞춤 | 공통 규칙과 충돌 | 적합1+고정2, 변수·값·출처 미정. 새 예외 승인 없음 |
| LA25 즉시 탈압과 6시간 후를 같게 취급 | 합성 h 1% 변화 시 공극 .024→.033663… | 실제 관측으로 쓰지 않음. 카드 해석 표지를 두 요약에 유지 |
| 수치/전칭 | 14 메서드와 29 하위 실패 관측 분리, 원 탐침4와 변이4 따로 | 연구/전체 gate/독립 종결로 확대하지 않음 |

수정 전/후 시험은 문서의 선택된 문장을 수동 전사한 모형이다. 기능 세 곳을 원 규칙으로 되돌린 변이와 부록 연결만 거둔 변이 네 개가 실패했다. 이 증거로 모든 산문 해석을 자동 인증했다고 하지 않는다. 원 문서/원 판정/원 ZIP은 고정 바이트로 남는다.

이미 알려진 d0=0, 느린 숨은 항, 실제 잡음/접촉/상자 효과 미자격은 해소했다고 쓰지 않는다. 기존 시험 등급은 관측 가능한 점의 등록 분류이며, 중간 점의 미관측 반대 방향까지 배제하는 보편 정리가 아니다. DRD 전체 종결 여부는 독립 창이 좁은 범위로 판단한다.
