## 0. 설계 상자를 **읽었다** (플랜 §5 미확인 항목 해소)

`~/dem_test/lhs/lhs00_*/input_*.liggghts` 헤더 130건 전수 파싱 + LIGGGHTS 덤프 실측 대조.

### 0-1. `pdd` 는 **질량분율(wt%)** 이다 — 개수도 부피도 아니다

두 후보를 데이터가 기각했다.  결정적 반례는 `lhs00_110` — `rAM = rSE = 1.0 µm` 로
**반지름이 같아 개수분율 = 부피분율**인데, 헤더는 `AM 0.80 / SE 0.20` 이고 실측은
**둘 다 0.625 / 0.375** 다.  어느 해석도 0.80 을 못 낸다.

밀도(`ρ_AM = 4800`, `ρ_SE = 2000`, 입력 파일 `particletemplate/sphere … density constant`)를
넣으면 정확히 맞는다:

```
(0.80/4800) / [ (0.80/4800) + (0.20/2000) ] = 0.625      ← 실측과 소수 셋째 자리까지 일치
```

3-type 교차검증 (`lhs00_000`, 헤더 `0.51 / 0.34 / 0.15`):

| type | 질량→부피 예측 | 실측 부피분율 | 차 |
|---|---|---|---|
| AM_P | 0.4215 | 0.4280 | +1.5 % |
| AM_S | 0.2810 | 0.2776 | −1.2 % |
| SE | 0.2975 | 0.2944 | −1.0 % |

⇒ **설계에 결함이 없다.**  `fix particledistribution/discrete` 가 mass-based 로 받고 있고,
헤더의 wt% 가 전극 조성을 적는 자연스러운 규약 그대로다.
★ 이것을 확인하지 않았으면 확장 상자를 **잘못된 축** 위에 세울 뻔했다.

### 0-2. 그래서 φ_AM 은 `1 − pdd_SE` 가 **아니다**

$$\varphi_{AM}=\frac{\rho_{SE}\,w}{\rho_{AM}-(\rho_{AM}-\rho_{SE})w}=\frac{2000\,w}{4800-2800\,w},
\qquad w \equiv w_{AM} = 1-\texttt{pdd\_SE}$$

역함수 (설계에 쓰는 방향):

$$w = \frac{\rho_{AM}\,\varphi}{\rho_{SE}+(\rho_{AM}-\rho_{SE})\varphi}
     = \frac{4800\,\varphi}{2000+2800\,\varphi}$$

### 0-3. 현재 상자 (130점 = 3-type 100 + 2-type 30)

| 노브 | 하한 | 상한 | 비고 |
|---|---|---|---|
| `rP` (또는 `rAM`) | 2.5 | 7.5 µm | |
| `rS` | 0.5 | 2.5 µm | 3-type 만 |
| `rSE` | 0.5 | 1.0 µm | |
| **`pdd_SE`** | **0.05** | **0.30** | wt% |
| `volfrac` | 0.176 | 0.318 | 삽입 시 목표 |
| `E_se` | 0.135e7 | 고정 | 자유 노브 아님 |
| ⇒ **`φ_AM`** | **0.493** | **0.888** | 유도량 |

★ 현재 상자의 φ_AM 0.493–0.888 은 코퍼스 밴드 **0.37–0.88 과 거의 그대로 겹친다** —
LHS 가 코퍼스를 잘 덮고 있었다는 뜻이고, 그래서 **밀도를 높이는 것은 값이 없다**(플랜 §2).

## 1. 무엇을 판정하려는가

CLAUDE.md 가 못박은 것: **σ_e Stage 22.5 는 `φ_AM < 0.3` 에서 쓰면 안 된다.**
코퍼스가 문턱 위에만 있어 **퍼콜레이션 문턱항이 없고**, `φ_AM⁴` 는 멱함수라 문턱에서
유한하므로 **붕괴를 표현할 수 없다.**  Luan 2025 는 φ_AM ≈ 0.28 → 0.20 에서 σ_e 6자릿수
붕괴를 보고한다 (litdb `luan2025_graded_cathode_400whkg_pouch`).

⇒ **판정 대상 = 그 영역에서 멱함수가 실제로 깨지는가, 그리고 어디서 깨지는가.**

⚠ **기존 폼을 고치려는 것이 아니다.**  CLAUDE.md: *"그 영역이 필요해지면 문턱항을 **새로**
세운다 — 기존 폼에 끼워넣지 않는다."*  이 배치는 **새 폼의 근거 데이터**를 만든다.

## 2. 등록 축 — `pdd_SE` 하나

**목표 영역** `φ_AM ∈ [0.20, 0.35]`  ⇒  **`pdd_SE ∈ [0.4362, 0.6250]`**

| φ_AM | 0.20 | 0.25 | 0.30 | 0.35 |
|---|---|---|---|---|
| `pdd_SE` | 0.6250 | 0.5556 | 0.4930 | 0.4362 |

### ★ 중복 없음이 **구조적으로** 보장된다

현재 상자의 `pdd_SE` 최대는 **0.30**, 확장의 최소는 **0.4362**.
두 구간은 **겹치지 않는다** (간극 0.136).

⇒ **거리 문턱을 정할 필요가 없다.**  `pdd_SE` 축 하나가 두 집단을 완전히 가르고, 그 축은
**이 문서에서 런 전에 등록**되므로 사후 판정이 아니다 (플랜 §4-3 이 걱정한 함정 회피).
사용자 조건 1(중복 없을 것)이 **설계로** 충족된다.

### 나머지 노브 — 현재 범위 그대로

`rP` 2.5–7.5 · `rS` 0.5–2.5 · `rSE` 0.5–1.0 · `volfrac` 0.176–0.318 · `E_se` 고정.
**한 축만 밖으로 나간다** — 그래야 관측된 변화를 그 축에 귀속할 수 있다.
⚠ 두 축을 같이 밀면 교락되고, 그것이 게이트 ⑤ 2×2 가 대각선 비교로 무너진 방식이다 (CL-19).

## 3. 점 수와 **계산 비용 상한** (런 전 등록)

### 3-1. N = 30 (3-type 20 · 2-type 10), LHS 층화

3-type / 2-type 비율은 현재 배치(100 : 30)를 대략 따른다.

### 3-2. ⚠ 입자 수 폭증 — **상한을 런 전에 건다**

SE 를 늘리고 `rSE` 를 줄이면 입자 수가 곱으로 늘어난다.  `lhs00_000` 실측
45,030 입자 (pdd_SE 0.15 · rSE 1.0) 기준 추정:

| `pdd_SE` \ `rSE` | 1.0 µm | 0.75 µm | 0.5 µm |
|---|---|---|---|
| 0.436 | 1.14× | 1.49× | **2.95×** |
| 0.625 | 1.20× | 1.64× | **3.42×** |

현재 최장 런이 **43 h** 이므로 3.4× 는 **≈ 6 일/케이스**다.

**등록하는 규칙**: 후보점의 예상 총 입자 수가 **150,000 을 넘으면 그 점을 버리고 다시
뽑는다.**  판정은 **런 전에** 헤더 산술만으로 한다 (DEM 불요).
⚠ 이 규칙은 `rSE = 0.5` + 고 `pdd_SE` 조합을 **체계적으로 걸러낸다** — 그 편향을 여기
적어 두고, 결과 보고 시 *"확장 배치의 `rSE` 분포는 저역에서 절단됐다"* 를 함께 쓴다.
숨기지 않는다.

## 4. 관측량과 판정식 — **런 전 고정**

각 신규 케이스에서:

- `σ_e` = 기존 파이프라인의 `electronic_sigma_full_mScm` (같은 규약, 같은 코드)
- `σ̂_e` = **Stage 22.5 를 그대로 외삽한 예측** (계수 재적합 금지 — 외삽이 요점이다)
- `d_i = log10(σ̂_e,i / σ_e,i)` — 멱함수가 몇 자릿수 과대예측하는가

### 4-1. 퍼콜레이션 축퇴는 **버리지 않는다**

| 산출 | 처리 |
|---|---|
| `σ_e > 0` | `d_i` 계산 → 적합에 사용 |
| `σ_e = 0` (AM 미퍼콜) | `d_i` **정의 불가** → 적합에서 제외.  단 **`f₀` 로 계수**하고 **문턱 위치의 증거로 보고** |

⚠ **이 구분을 사후에 정하면 "안 맞는 점을 뺐다" 가 된다.**  그래서 여기 적는다.
`f₀` = (σ_e = 0 인 케이스) / (완주 케이스).

### 4-2. 판정

`D = median(d_i)` (σ_e > 0 인 케이스에 대해)

| | 조건 | 뜻 |
|---|---|---|
| **h0** | `D ≤ 0.5` **그리고** `f₀ ≤ 0.10` | 이 구간에서 멱함수가 산다.  문턱항 불필요 |
| **h1** | `D ≥ 1.5` **또는** `f₀ ≥ 0.40` | 붕괴 실재.  Stage 22.5 외삽 금지가 **실측으로 확인**되고 문턱항의 근거가 선다 |
| 분해능 | `0.5 < D < 1.5` 이고 `0.10 < f₀ < 0.40` | **INDETERMINATE** — 곡선만 보고하고 h 를 붙이지 않는다 |

⚠ `f₀ > 0.5` 이면 `D` 는 **생존자 편향** 추정이다 — 그때는 `D` 에 그 표지를 달아 보고하고
h0 을 주장하지 않는다 (h1 은 `f₀` 조건으로 이미 성립).

### 4-3. 무엇을 **주장하지 않는가**

- 문턱 `φ_c` 의 **단일 수치**를 인용하지 않는다.  30점·1축으로는 그 해상도가 없다.
  보고 형식은 `φ_c ∈ (φ_k, φ_{k+1})` — σ_e 가 0 으로 떨어지는 구간의 양 끝.
- Luan 2025 의 6자릿수와 **크기를 맞추려 하지 않는다.**  그쪽은 실측 풀셀이고 우리는
  DEM 접촉망이다.  비교는 **방향과 자릿수**까지다.
- 이 배치로 **새 폼을 적합하지 않는다.**  근거 데이터를 만드는 것까지가 이 등록의 범위다.
