## ★ 한 문장 결론 — 이게 무엇이고 우리에게 왜 결정적인가

**큰 다결정 + 작은 단결정 CAM을 섞는 bimodal 조성이 입자 packing을 최적화해 porosity를 낮추고, 이것이 ionic
tortuosity를 낮춰 Li⁺ 전달(rate)을 높이며 동시에 (응력 완화가 아닌) 균일 응력 분산으로 chemo-mechanical
건전성을 높인다.  CAM 90 wt%에서 P:S = 7:3(CAM7:3)이 최저 porosity(2D 7.55% / He 8.83%) · 최저 ionic
tortuosity(11.13) · 최고 rate · 87.80% retention @200 cyc로 최적.**  porosity/tortuosity의 dip은 CAM7:3에서
극소, 양 끝 UCC(CAM10:0, CAM0:10)에서 모두 높음 = **전형적 Furnas/de Larrard bimodal packing dip**.

**★ 우리 hook (왜 이게 #271/Bazzoun보다도 더 결정적인가 — "검증 앵커"를 넘어 "headline 재현"):**
이 논문은 **우리 정확한 소재계(LPSCl argyrodite SE + Ni-rich NCM CAM, ASSB) + 정확한 조건(90 wt% CAM, 300 MPa,
SE D₅₀≈0.72 µm ≈ 우리 0.5 µm) + 정확한 변수(poly:single = 큰:작은 = P:S)**다.  그리고 **우리 `input_2mAh_a9_50`
P:S sweep(p00→p10)은 이 논문의 실험을 우리 DEM으로 그대로 재현한 것**이다:
- **(A) porosity DIP 1:1:** #266 2D porosity 16.80 → **7.55(CAM7:3 최소)** → 17.96, He pycnometry 12.78 →
  **8.83(CAM7:3 최소)** → 11.58.  우리 DEM porosity 17.92 → **12.70(P:S 6:4 최소)** → 18.45.  **둘 다 같은
  Furnas dip, 우리 rigid DEM이 #266의 실험 dip을 독립 재현**(frame[4]).  최적 위치 #266 7:3(poly 0.7) ↔ 우리
  6:4(poly 0.6) = sweep 간격 0.2에서 **인접 = 동일 최적 구간 0.6–0.7**.
- **(B) MPM porosity vs He pycnometry like-for-like:** #266 He pycnometry(3D 물리 기공) CAM7:3 **8.83%** ↔

  든다**(소성 void-fill로 rigid floor 아래 도달).  우리 **DEM rigid** porosity 12.70%(p06)는 #266 **2D-SEM area**
  porosity 7.55%(CAM7:3)보다 높음 → **2D 면적 측정(작은 pore 누락)이 3D 물리/소성보다 낮게 나오는 알려진 경향**.
  ⇒ **우리 모델 중 #266 He pycnometry "물리 porosity"에 매칭되는 것은 MPM(소성)** (DEM rigid는 #266 He보다
  약간 높음 = rigid floor; 2D-SEM은 셋 중 최저).
- **(C) σ_ionic / σ_e per-composition 절대 앵커:** Table S5가 **σ_eff,ion = 0.042/0.049/0.055/0.046/0.034 mS/cm**
  (CAM10:0→0:10), **σ_eff,e = 4.09/2.99/2.37/2.16/0.95 mS/cm**을 직접 준다.  Bazzoun(0.065–0.137) + #271

- **(D) 우리 P:S 7:3 production calibration의 직접 실험 근거:** CLAUDE.md "Production calibration (2D)… P:S 7:3"
  의 출처가 바로 이 논문의 CAM7:3 최적이다.

⚠ **단, σ_grain 매핑 주의:** #266 SE는 **Li₅.₅PS₄.₅Cl₁.₅**(Cl-rich, σ_bulk 3.09 mS/cm; 모델 입력 σ_SE=10 mS/cm는

## 1. 배경 / 동기 (Introduction, p.1–2)

- LIB는 액체전해질 인화성 + layered CAM 구조불안정 → 안전성·신뢰성 우려.  **황화물 SE 기반 ASSB**가 차세대
  (sulfide SE는 σ가 액체전해질급 + 가공성 우수).  그러나 **SE로 액체를 대체하면 CAM 이론용량을 불완전 활용** —
  복합양극 설계의 근본 난제(CAM↔SE 계면 접촉 불량 + SE 전기화학 불안정 → 계면저항↑ → 가역용량·cycling 저하).
- **고porosity의 이중 폐해:** (1) Li⁺ 경로 차단, (2) **비정수압 응력 생성을 악화** — ASSB에서 LIB보다 더 두드러져
  기계열화·장기수명 저하.  → ASSB는 재료뿐 아니라 **전극-수준 엔지니어링**이 필요.
- **CAM 선택이 SE만큼 critical:** **큰 다결정 CAM**(액체 LIB 표준) — 저비용 제조성 + 고 packing density + 높은
  체적에너지밀도 BUT rate 한계; **작은 단결정 CAM** — 짧은 Li⁺ 확산경로 → 우수 rate + 기계적 강건성(2차입자
  균열 없음) BUT 큰 비표면적 → CAM-SE 부반응↑.  둘은 **상보적 장단점**.
- **본 연구(명시):** **unimodal vs bimodal 복합양극을 체계 비교** — 큰 다결정 NCWA + 작은 단결정 NCM 블렌드.
  **CAM 90 wt% 고정**(최근 보고된 최고 수준 중 하나)에서 NCWA:NCM = 8:2/7:3/6:4 BCC + 10:0/0:10 UCC.  핵심
  아이디어: **NCM이 NCWA 입자 사이 틈(interstitial void)을 채워 전극 porosity↓ + packing↑** → tortuosity↓ →
  Li⁺ 전달↑ + 기계건전성↑.  분석: post-mortem 전기화학 + 구조 + 기계 특성 + **operando 전기화학 pressiometry**
  + **3D 시뮬레이션**(packing이 성능·건전성을 어떻게 좌우하는지 메커니즘 규명).

## 2. 소재 & 5개 양극 구성 (Experimental Methods, SI p.S3–S13)

### 2.1 재료 합성·제작
- **SE 합성:** Li₂S + P₂S₅ + LiCl → 유성 볼밀 800 rpm 6 h → glassy LPSCl1.0 분말 550°C 1 h 어닐, **LPSCl1.5**는
  500°C 1 h 어닐(Ar, 봉인 석영관).  복합양극용 미세 입자는 **wet milling**(heptane:dibutyl ether = 8:1 vol)으로
  **S-LPSCl1.5**(D₅₀ 0.72 µm, σ 3.09 mS/cm) 제조.
- **CAM LiNbO₃ 코팅:** Li metal + niobium ethoxide를 ethanol에 용해 → NCWA·NCM에 동일 조건 코팅 → 400°C O₂ 소성.
- **복합양극 제작:** CAM : S-LPSCl1.5 : Super P = **90 : 9.5 : 0.5 wt%**, MM400 믹서, **SUS 볼 추가**(다결정 NCWA
  2차입자 손상 방지), 10 Hz 1 h 혼합.  BCC = NCWA:NCM 8:2/7:3/6:4.  복합음극 = LTO : S-LPSCl1.5 : Super P = 50:40:10.
- **셀(반쪽):** 13 mm 몰드.  LPSCl1.0 150 mg → 150 MPa 분리막 → 양극 8.9 mg 200 MPa → 음극 300 MPa.  **측정 중
  100 MPa 일정 압력**, 상온 냉간압축.  loading 양극 6.71 / 음극 20.35 mg/cm², N/P ≈ 1.5–1.6.

### 2.2 측정
- **σ_eff,ion (effective ionic conductivity):** **[SUS|Li|Li₆PS₅Cl|복합양극|Li₆PS₅Cl|Li|SUS] full-blocking 대칭셀**,
  AC 임피던스 **1 MHz–0.0005 Hz**, 100 mV.  R_total = R_sse + R_composite (식 1) → 동일두께 LPSCl1.0 펠릿으로 R_sse
  측정·차감 → R_composite → σ = (l/S)·(1/R) (식 3).  ★ **우리 σ_ionic 정의("복합양극의 유효 σ_ionic")와 동일 셀.**
- **σ_eff,e (effective electronic conductivity):** **[SUS|복합양극|SUS] ion-blocking**, **DC chronoamperometry**
  (0.1 V 10 min → 0.1 V씩 0.5 V까지 step), R = V/I(마지막 100점 평균 전류), σ = (l/S)·(I/V) (식 2).
- **Ionic tortuosity (식 4):** **τ_ion = ε / (σ_eff,Li⁺ / σ)** = (SE 부피분율 ε) / (양극 유효 σ / SE bulk σ).
  ⚠ **여기 ε = SE 부피분율**(글에 "ε represents the volume fraction of the SSE"), pore volume은 2D 이미지 분석값.
  ⇒ **이건 우리 측지(geodesic) τ(~1.2)와 전혀 다른 "MacMullin 류 τ-factor"** = σ_bulk/σ_eff를 SE 부피로 가중한
  것(값이 11–16으로 큼).  **추세만 비교**(우리 τ_Dijkstra/τ_Laplace와 절대값 비교 불가).
- **Operando pressiometry:** BS-3520(Bongshin) 압력센서(0.01 MPa 분해능), cycling과 동일 셀, 0.5C.  베이스라인
  drift 보정(각 사이클 충전시작↔방전끝).  **ΔP_avg = 사이클 내 (최대−최소) 압력, 5사이클 평균** [MPa].  LTO
  zero-strain 음극으로 양극 부피변화만 분리.
- **DRT:** EIS를 Ciucci DRTtools로 변환, τ = 1/(2πf) (식 5).  4개 kinetic 피크 정의(D1–D4, 아래 §4.3).
- **Cycling:** 30°C, 2.7–4.3 V, **2 formation @0.1C → 0.5C cycling**(1C = 180 mA/g), CC-CV(CV cutoff 50%).
  EIS = 1st 충전 후 + 200th 충전 후.  Rate = 0.1/0.2/0.33/0.5/1/2/3C → 0.5C 복귀.
- **분석:** FE-SEM(Regulus 8230 / Verios) + ion-mill 단면(ArBlade 5000) + EDS / He pycnometry(BELPYCNO) /
  XPS(PHI5000, S 2p·P 2p) / ToF-SIMS(M6, Bi₃⁺) / operando XRD(Empyrean, Be-window) / Rietveld(TOPAS).
- **porosity 측정 2종:** (1) **2D 이미지 분석** — 단면 SEM에서 pore를 수동 적색 마킹(EDS로 carbon 제외) →
  ImageJ IsoData 이진화 → 적색면적/전체면적; (2) **He pycnometry** — 370 MPa 냉간압축 펠릿, porosity =
  (1 − V_true/V_apparent)×100, V_true는 He pycnometer, V_apparent는 펠릿 높이(식 6).

### 2.3 ★ 3D 시뮬레이션 (digital-twin, SI p.S9–S13) — GeoDict(FVM) + COMSOL(FEM chemo-mechanical)
★ 핵심 — **측정 파라미터로 가상 3D 재구성 → FVM으로 수송, FEM으로 chemo-mechanical.**
- **구조 생성:** 측정 (i) loading·두께, (ii) CAM/SSE/CC/pore 목표 부피분율, (iii) 입자 크기·형상으로 제약된
  microstructure-generation 알고리즘 → 3D digital-twin.  **도메인 = 40×40×t µm³**(t = 실측 전극두께, tap density에서
  산출 = 18.3/17.5/16.8/17.6/18.5 µm), **voxel 0.1 µm**.
- **입자 형상:** **NCWA = 구(sphere), NCM = convex polyhedron**(faceted 재현), **SSE = 구**, **CC(Super P) =
  공간균일 연속상**(voxel보다 작아 입자화 불가 → 목표 부피분율 채우는 continuum, 전자 percolation 보장).  각 상
  D₅₀를 packing 대표크기로 사용.
- **FVM 형태분석(GeoDict, Math2Market):** contact 비표면적, pore-size 분포, ionic·electronic tortuosity, 유효
  σ_ion/σ_e.  메싱 전 sharp corner에 mild smoothing(3 voxel).
- **FEM chemo-mechanical(COMSOL Multiphysics):** 반쪽셀 **100 MPa stack 압력 + 0.5C CC-CV 4.3 V** 충전 조건.
  Ohmic 전도(식 7) + 접촉저항 계면 전위강하(식 8, R_c = area-specific 입자-입자 접촉저항) + **Butler-Volmer**
  계면반응(식 9) + 과전압 η = φ_s − φ_e − E_OCV(c) (식 10) + Li 확산(식 11–12) + **chemo-mechanical 변형**:
  ε = ε_el + ε_chem (식 13), 화학변형 ε_chem = (1/3)(V₀/V)(c−c_ref)I (식 14, 등방), Cauchy 응력 σ = 2μ(ε−ε_chem)
  + λ tr(ε−ε_chem) (식 15) → **elastic strain energy density W_el**.  CAM 수축은 operando XRD unit-cell 변화로 입력.
- **★ 모델 검증(frame[4] 그들 내부판):** 시뮬 σ_ion/σ_e를 **실측과 매칭**해 모델 타당성 확인 — **평균편차 σ_ion
  1.98% / σ_e 3.66%**(Table S9/S11) → "재구성 모델이 실제 전극거동을 정확히 재현".  ★ Young's modulus는 Ni
  함량·Li 농도 함수(Fig S14, ref S4–S6), CAM 부피변화는 operando XRD 직접 입력.
- ⚠ **이것도 GeoDict 라인 reconstruct-from-measurement(출력단)** — `docs/positioning_vs_geodict.md`의 #271/#281/
  #275 패턴.  우리 DEM+MPM은 **공정→구조 예측(입력단)** + Kirchhoff/Holm 접촉망(연속 FVM이 놓치는 점접촉 constriction).

## 3. 핵심 메커니즘 — bimodal packing → porosity↓ → tortuosity↓ → kinetics↑ + 균일 응력분산

**(1) Bimodal 기하 = 작은 단결정이 큰 다결정 틈을 채움 → packing↑ porosity↓.**  큰 NCWA 사이 interstitial void를
작은 NCM이 점유 → 더 조밀한 전극.  tap density: CAM-only 2.26(10:0)→**2.54(7:3 최대)**→2.22(0:10), 복합양극
3.28→**3.59(7:3)**→3.26 g/cc.  ⚠ **개선폭은 CAM-only보다 작다** — SE 입자가 unimodal을 bimodal로, bimodal을
trimodal로 바꾸기 때문(SE가 packing 위계를 한 단계 복잡화).

**(2) porosity↓ → ionic tortuosity↓ → σ_eff,ion↑ → rate↑.**  reduced porosity가 더 짧은 Li⁺ 경로 → tortuosity↓
→ 유효 σ_ion↑.  CAM7:3가 최저 porosity·최저 tortuosity → 최고 rate.  ⚠ **CAM0:10의 역설:** CAM10:0과 CAM0:10은
**총 pore 면적은 비슷**하나 σ_eff,ion은 크게 다름(0.042 vs 0.034) — **pore 크기·분포가 수송을 좌우**(CAM10:0은
큰 pore 몇 개 = 낮은 tortuosity; CAM0:10은 작은 pore 다수 = 높은 tortuosity).  → **porosity 양뿐 아니라 pore
구조가 transport를 결정**(우리 percolation/coverage 물리와 정합).

**(3) ★ chemo-mechanical 건전성 = 응력 "완화"가 아니라 균일 "분산"(중요 통찰).**  BCC의 향상된 기계안정성은
**내부응력 생성 감소(stress relaxation)에서 오는 게 아니다** — operando pressiometry로 증명: BCC의 ΔP_avg는
**CAM10:0/0:10의 질량가중 평균과 거의 같다**(예 CAM8+2 = 0.304 ≈ 측정 CAM8:2 0.303).  즉 **내부 응력변화 크기는
조성(CAM 질량분율)에 의해 지배되지 packing/porosity에 의해 바뀌지 않는다.**  대신 **조밀 packing이 응력을 더 많은
접촉점·균일 SE 골격으로 분산(uniform stress dispersion)** → 국소 응력집중↓ → 기계열화↓.  → "porosity 제어가
응력 *완화*가 아니라 응력 *분산*으로 기계건전성을 높인다"는 게 본 논문의 핵심 mechanistic 주장.

**(4) 단결정 NCM의 양면성.**  단결정 NCM = 짧은 확산경로 → 우수 rate + 2차입자 균열 없음(기계강건) BUT 큰 비표면적
→ CAM-SE 부반응↑(D2 피크↑, sulfate↑).  큰 다결정 NCWA = 고 packing·고에너지밀도 + rod-like primary로 기계강건
BUT 긴 확산경로 → rate 한계.  **bimodal = 둘의 장점 결합**(NCM rate + NCWA packing/energy).

**(5) 결론적 설계 통찰:** UCC는 본질적 trade-off(NCWA = rate·기계 한계; NCM = 부반응·저에너지밀도).  **BCC가
void를 메워 porosity↓·σ_ion↑·tortuosity↓** → 단순 조성혼합으로 두 CAM의 상보 장점 leverage.  CAM7:3가 최적.

  (소성, 10.44% @p06)** — DEM rigid(12.70%)는 He보다 약간 높음(= rigid-sphere floor, 소성 flow 부재).  2D-SEM
  area(7.55%)는 셋 중 최저(단면 누락).  → frame[5] 정확히: **물리 porosity 절대값 = MPM(소성); dip 모양/추세 =
  DEM(rigid Furnas)**.  ⚠ 우리 MPM endpoint(p10 9.31%)는 #266 He(CAM10:0 12.78%)보다 낮음 — 우리 MPM이
  mono-modal에서 소성 over-densify(소성 SE가 큰 AM 사이로 과도하게 흘러듦, CLAUDE.md "MPM은 mono-modal rebound를
  지움")이므로 **endpoint absolute는 MPM 과소, dip 모양은 DEM 소유** — 이미 알려진 frame[3]/[5] 분업.

### (d) tortuosity — 추세 1:1 (절대값은 정의가 달라 비교 불가)

  **dip @CAM7:3, 양 끝 높음**(특히 CAM0:10 16.08 = 작은 pore 다수).
- **우리 τ_Dijkstra(측지, 값 1.59–2.02):** p10 1.59 → p06 1.68 → p00 2.02.  ⚠ **우리 τ는 P 증가(큰 AM↑) 방향으로
  단조 감소**(2.02 → 1.59) — #266의 dip 모양과 **다르게 보임**.  이유: **정의 차이** — #266 τ_ion은 σ_bulk/σ_eff에
  SE 부피를 곱한 "유효 저항 factor"(porosity·pore구조 종합 → dip), 우리 τ_Dijkstra는 SE 네트워크의 **순수 기하
  측지경로 굴곡**(큰 AM↑ → SE가 큰 AM 표면 따라 더 곧게? → 단조).  → **τ는 절대값·모양 모두 직접 비교 금지,
