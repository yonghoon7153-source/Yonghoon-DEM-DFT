## 7. 판정 규칙 (결과 전 · 칸 판정 순서 ①–④ 와 같은 꼴)

결정 관측량 o 마다 · 비교 X ↔ A (같은 창 · 같은 시각):

1. ① **기술**: X · A · F 중 하나라도 T0 실패 → 그 비교 **판정 불가 (기술)** · 다시 돌릴지 = 1저자 (자동 재실행 없음).
2. ② **바닥**: |F − A| / |A| > τ_o → o **판정 불가** (그 창이 τ 를 가를 해상도가 없다).
3. ③ |X − A| / |A| > τ_o → o **불합격**.
4. ④ 그 밖 → o **합격** (|X − A| = τ 는 합격).

- **(a)** = X = B · 결정 관측량 (W1: O1 · O2 / W2: O2 · O3) 중 하나라도 불합격 → 불합격 · 아니고 하나라도 판정 불가 → 판정 불가 · 다 합격 → 합격.
