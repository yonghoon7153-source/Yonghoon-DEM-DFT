# 3점만 찍은 표시용 구조 (min · saddle · 대칭점)

계산된 두 구조의 adatom 위치를 **원본 좌표 그대로** 한 파일에 넣고, 세 번째 점만
대칭으로 이어 붙인 것. **평행이동·회전 없음** — 두 원본 .vesta 와 같은 시야다.

| | frac | |
|---|---|---|
| 1 | (0.887775, 0.120635, 0.446500) | **min — 계산됨** |
| 2 | (0.750001, 0.250006, 0.455211) | **saddle — 계산됨** |
| 3 | (0.612227, 0.379377, 0.491700) | saddle 기준 대칭점 (계산 아님) |

간격 2.534 Å · 총 5.067 Å · 공 반지름 셋 다 1.30 Å.
3번의 높이는 기판 최근접 원자에서 2.15 Å 뜨도록 맞춘 것(`ride_height`).

## 한계

3번은 계산된 자리가 아니고, 그 부근 기판은 **N32 가 가로 0.96 Å 에** 있어 실제 흡착
자리가 아니다. min→3번 직선도 ξ≈0.82 에서 Li–N 이 1.14 Å 로 N 을 관통한다.
그림에서 세 공만 찍는 용도로만 쓰고, 사이를 잇는 경로로 해석하면 안 된다.
