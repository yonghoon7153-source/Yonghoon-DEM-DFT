## ⛔ 이 코호트를 다루는 사람이 반드시 알아야 할 것 넷

1. **`ls | tail` 로 짝 스텝을 고르지 말 것** — **사전순**이라 `995000` 이 `3560000` 보다 크게 나온다.
   실제로 그 때문에 거짓 경보가 **두 번** 났다 (09-18 · 09-19).
   `ls … | sed 's/.*_//;s/\..*//' | sort -n | tail -1` 로 볼 것.
   ⚠ `comm` 에 물릴 때는 **사전순**으로 주고 교집합을 받은 **뒤에** 숫자 정렬할 것 (`sort -n` 을
   먼저 물리면 `comm: file 1 is not in sorted order` 로 죽는다 — 이것도 실제로 났다).
2. **`pick_mesh` 는 atom 과 같은 디렉터리**에서 `mesh_*.stl` 을 찾는다.  atom·contact 만 옮기면
   수확이 `NO_MESH` 로 떨어진다.  ⚠ **TSV 에 mesh 열은 없다** — 봉인 검사로는 안 잡힌다.
3. **리허설의 `127/127 rc=0` 은 dry-run 이었다.**  `lhs_harvest_batch.py:65` 가 그 false-green 을
   **이미 이름으로 적어 두고 있었다**.  ⇒ 본번과 리허설을 **같은 말로 쓰지 말 것**.
4. **수확은 리포 밖에서 돌린다** (`ROOT = parent.parent`).  `/tmp/lhsh/scripts/` 구조가 필요하다.
