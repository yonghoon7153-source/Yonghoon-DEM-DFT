NO-GO — 현재 (A)를 "작은 모델 DFT 검증을 마친 전체 계면의 절대 W"로 DEM에 전달하는 것은 승인하기 어렵습니다. 다만, 검증 범위를 제한한 파일럿에는 조건부 GO입니다. CP2K 전환이 필수는 아닙니다.
수정본 (1).md와 저장소 650a6fb5를 기준으로 봤습니다. 수정된 **"큰 계산은 GPU, CPU 메모리 추정은 허용"**을 반영했습니다. 좌표·조성·배위는 직접 재계산했지만 UMA·DFT는 실행하지 않았고 파일도 수정하지 않았습니다.
핵심은 작은 모델로 바꾸는 것 자체가 잘못이 아니라, 작아진 검증 대상을 원래의 전체 계면과 동일시하면 안 된다는 것입니다.
Q1. (A)로 가능한가, CP2K가 필요한가?
(A)의 탐색 경로에는 찬성, 현재의 절대값 승인 논리에는 반대입니다.
작은 모델에서 맞더라도 전체 계면에는 다음 차이가 남습니다.
- Ag 조각과 연속 금속막의 전자구조·차폐 차이
- 그래핀 조각의 가장자리와 흑연 기저면의 차이
- 유한 두께·피복률·장거리 상호작용 차이
- 작은 모델과 전체 모델 사이의 UMA 조성 라우팅 차이
따라서 작은 모델의 오차가 0.10 J/m² 이내여도 전체 P1·P2 오차가 같은 범위라는 결론은 나오지 않습니다. 목표를 정밀값이 아닌 저·고 접착 구간으로 낮춰도, 이 확장 적용의 오차가 미상이라는 문제는 남습니다.
권하는 경로는 **A′**입니다.
1. 작은 주기 계면은 그 모델 자체의 DFT 값을 보고합니다.
2. 큰 계면은 UMA+D3 예측으로 따로 보관합니다.
3. DEM에서 큰 계면 값을 사용하려면 미검증 예측을 넣은 민감도 시나리오로 한정합니다. 검증된 물성값·오차가 보증된 입력이라고 부르지 않습니다.
4. 전체 계면의 검증된 절대값이 꼭 필요할 때만, 같은 보고 대상을 검증할 계산 경로를 다시 확보합니다.
자원 근거도 표현을 좁혀야 합니다
CPU판 QE의 Estimated max dynamical RAM은 GPU VRAM 피크 실측이 아닙니다. QE 추정식에는 파동함수·FFT·대각화 등 여러 항이 들어가므로, 단순한 부피×밴드 비례도 전체 메모리를 보증하지 않습니다. 따라서 "전체 계산을 현재 자원·위험 정책에서 추진하지 않는다"는 결정은 타당하지만, "48 GB에서 불가능함을 실측했다"는 표현은 과합니다. 4층의 22–27 GB 역시 실행 가능성 추정이지 보증이 아닙니다. QE 메모리 추정 코드
CP2K도 자동 해법은 아닙니다. "진공에 비용을 안 낸다"는 수정해야 합니다. 원자 중심 궤도 기저 수는 진공에 비례하지 않지만, GPW의 전하밀도 격자·FFT에는 셀 크기가 들어갑니다. GPU 지원도 연산별이므로 host RAM 부담이 사라지는 것은 아닙니다. CP2K GPW 설명, GPU 지원 현황
공유 GPU에 위험한 대형 잡을 띄워 이 점을 증명하라는 요구는 아닙니다.
Q2. V1–V4의 지위·정규화·합격선
확장 계면과 가장 가까운 것은 '얇은 주기 계면'입니다. 다만 그것도 유한 두께 모델이며, 벌크 두께 극한과 같다는 보장은 별개입니다.
변형된 단층은 단층 조건부 모델이고, 조각-위-슬랩은 국소 결합 진단입니다. 세 모델은 같은 수준의 대체물이 아닙니다.
V1 — SE|SE: 필수 경보 대조
양 종결과 대응 벌크를 사용합니다. 정규화는 화학량론이 닫힌 벽개식의 J/m²입니다.
기존 0.3–0.7 J/m²는 경보 구간 그대로 유지합니다. 구간 안에 들어와도 Ag–SE·탄소–SE 상호작용을 검증한 것은 아닙니다.
V2 — Ag|흑연: 해당 값을 전달하려면 필수, 직접 DFT 경로 유지
사전 지정한 대칭 비등가 registry 최소 4개를 유지하고, 실제 변형된 면적으로 나눕니다.
여기서 직접 DFT 값을 낼 수 있다면 UMA 통과 여부 때문에 그 DFT 결과까지 막을 이유는 없습니다. 다만 그래핀 단층 모델의 값을 흑연 두께 수렴값으로 바꾸어 부르면 안 됩니다.
V3·V4 — 각각 P1·P2 검증에 필요하지만, 현재 조각형은 진단용
현재 제안한 Ag 조각·그래핀 조각은 선택적인 조기 실패 탐지로는 유용합니다. 그러나 이것만 통과하여 전체 P1·P2를 승인하는 경로에는 반대합니다.
조각에서는 우선 고정된 조각 전체의 결합에너지와 오차를 eV/조각으로 보고하세요. 접촉 원자당 값은 보조 항목으로 가능합니다.
조각의 투영 면적이나 계산 셀 면적으로 나눠 BV의 0.10 J/m² 문턱을 옮기는 것은 불허합니다. 같은 조각도 빈 측면 공간을 늘리면 셀 면적당 오차가 작아집니다. 접촉 원자 수 역시 거리 문턱에 따라 바뀝니다. 이는 정확도가 좋아진 것이 아닙니다.
따라서 현재 조각형 V3·V4에는 전체 계면 W의 승인용 합격선을 부여하지 않겠습니다. 숫자를 하나 붙여도 빠진 연결 근거를 만들 수 없기 때문입니다.
작은 주기 계면으로 바꾸었을 때 적용할 운영 기준
아래는 문헌의 보편 표준이 아니라 이번 파일럿에 결과 전에 고정할 기준입니다.
- 검증 표본마다 동일한 기하·분리 끝점에서 DFT와 UMA의 W 차이 절댓값 ≤ 0.10 J/m².
- 각 계면·종결별 검증 집합의 평균 부호 있는 오차 절댓값 ≤ 0.05 J/m².
- 기준 DFT의 수치 설정 변경에 따른 최종 W 변화 ≤ 0.02 J/m².
- 각 검증 대상군에서 사전 선택한 5개 표본을 완료합니다. 처음 2개는 조기 실패 판정용이지 조기 승인용이 아닙니다.
- 통과 문구는 **"이 작은 주기 모델의 지정 표본에서 운영 기준을 충족했다"**까지입니다. 전체 계면의 최대오차 보증으로 확대하지 않습니다.
V2의 직접 DFT 보고에 별도의 UMA 검증 5점을 억지로 추가할 필요는 없습니다.
사전등록에는 모델 조성·두께·종결·피복률·변형률, 표본 선택과 동률 처리, 끝점 생성법, 실패·제외 처리, 그리고 통과 후 허용할 문장까지 함께 고정하세요.
Q3. 같은 셀 원거리 참조로 MoLE 문제가 해결되는가?
조성 라우팅 불일치를 피하는 방향으로는 맞습니다. 모든 모델 오차를 해결하지는 않습니다.
UMA는 전체 원소 조성을 라우팅 입력으로 사용합니다. 결합 상태와 분리 상태의 조성을 같게 유지하면 그 입력은 일치하지만, 기하에 따른 에너지 오차까지 상쇄된다는 뜻은 아닙니다. 작은 모델과 큰 모델 사이에는 조성비도 달라질 수 있습니다. UMA 공식 설명
주 계산 경로는 다음처럼 고정하는 것이 좋습니다.
\[
W_{\rm sep}
=\frac{E_{A+B,\mathrm{far}}-E_{A+B,\mathrm{bound}}}
{n_{\rm interface}A}.
\]빠진 중요한 조건은 주기경계 너머의 분리 거리입니다.
원래 셀에서 흡착층을 멀리 옮기면 반대편 주기영상에 가까워질 수 있습니다. 따라서 결합·분리 상태를 모두 담을 충분한 높이의 셀을 먼저 만들고, 두 끝점에 같은 셀을 사용해야 합니다. 내부 간격뿐 아니라 셀 경계를 넘는 간격도 확인해야 합니다.
제안하는 운영 기준은 다음입니다.
- 진공·주기영상 조건 변경에 따른 최종 W 변화 ≤ 0.01 J/m².
- 원거리 참조는 더 큰 분리 거리에서 직접 확인하고, 추가 분리로 인한 W 변화 ≤ 0.01 J/m².
- D3의 장거리 꼬리까지 포함합니다. UMA 이웃 절단거리 밖이라는 이유만으로 완료 처리하지 않습니다.
가산성 잔차는 다음으로 기록하세요.
\[
\delta_{\rm add}
=\frac{E_{A+B,\mathrm{far}}-(E_A+E_B)}
{n_{\rm interface}A}.
\]이번처럼 같은 조성의 합친 셀 경로만 사용한다면, 잔차가 크다는 이유만으로 그 경로 자체를 자동 탈락시킬 필요는 없습니다. 대신 독립 슬랩 합으로 바꿔 계산하지 못하게 해야 합니다.
반대로 두 경로를 교환 가능하다고 주장하거나 섞어 사용할 경우에는 잔차 절댓값 ≤ 0.01 J/m²를 요구합니다. 이것이 앞선 BV의 가산성 요구를 이번 설계에 맞게 구체화한 판정입니다.
Q4. UMA+D3 — 이중계산과 검증의 한계
명시적 D3 항의 중복 추가는 아니라는 판단에 찬성합니다. omat 학습 기준은 분산 보정 없는 PBE/PBE+U입니다. 그러나 이것이 UMA+D3의 정확성까지 보증하지는 않습니다.
동일한 좌표·셀·끝점과 동일한 D3 구현을 사용하면,
\[
W_{\rm PBE+D3}-W_{\rm UMA+D3}
= W_{\rm PBE}-W_{\rm UMA}.
\]따라서 이 검증은 선택한 PBE+D3 모형을 UMA+D3가 얼마나 재현하는지를 묻는 데 적절합니다. 반면 D3 자체의 실제 계면 정확도나 금속 차폐를 검증하는 독립 증거는 아닙니다.
또한 \(d_{\rm eq}\)를 "UMA 반발이 정한다"고만 쓰면 부족합니다. 평형 간격은 UMA 항과 D3 항의 힘이 균형을 이루는 위치입니다. D3의 단거리 감쇠도 영향을 줍니다. D3 개발자 문서
최소한 대표 registry에서는 같은 고정 내부 기하로 **압축 쪽·UMA 최소 부근·인장 쪽의 E(d)**를 대조하세요. 끝점 W 하나가 맞아도 곡선 모양은 틀릴 수 있습니다.
다만 보고량이 고정기하 W라면, DFT 잔류 힘이 있다는 이유만으로 값을 폐기할 필요는 없습니다. 대신 간격을 UMA+D3 최적화 간격이라고 부르고 DFT 평형 간격으로 승격하지 마세요.
D3(BJ) 2체 명시와 ATM 분리는 맞는 수정입니다. QE 입력 규약
Q5. SE|SE 4층이면 경보 대조로 충분한가?
조건부 찬성입니다. 6층 수렴 인증은 아닙니다.
직접 재계산한 기존 6층 좌표에서는 다음을 확인했습니다.
- 162/150원자 조성
- 양쪽 모두 P 12개가 각각 S 4배위
- 형식 전하 합 0
- C2x 대응 오차 약 \(10^{-4}\) Å 수준
PS₄를 끊던 기존 문제에 대한 구조 수정은 지지됩니다. 다만 이는 새 4층 입력까지 검증했다는 뜻은 아닙니다.
4층에서는 벽개식도 바뀝니다.
\[
W_{\rm cleave}^{4L}
=\frac{E_{110}+E_{98}-4E_{\rm bulk,52}}{2A}.
\]현재 6층 결정문의 계수 6을 복사하면 안 됩니다. 분석 코드는 P 개수로 계수를 계산하지만, 결정문·입력 명세도 새 조성과 맞아야 합니다.
또한 인용한 0.22 대 0.20은 한 종결의 문헌 두께 비교입니다. 우리 양 종결 조합과 다른 Li 배열까지 수렴했다고 말할 근거는 아닙니다. 여기서는 얇은 경보 모델을 선택하는 근거로만 쓰세요.
진공 15 Å와 k점 3×3×1은 출발값으로 가능하지만, 그 자체가 수렴 판정은 아닙니다. 경보 밖이면 원인 진단, 안이면 다음 단계 진행이지 물리적 타당성 인증은 아닙니다.
Q6. SE 고정·흡착층 변형 규칙
조건부 찬성입니다.
결합 상태와 분리 참조에서 흡착층의 같은 면내 변형과 같은 내부 기하를 유지하고, 실제 변형된 면적으로 나누면 됩니다.
그 값의 정확한 이름은 다음입니다.
SE에 정합되도록 변형된 Ag 또는 흑연 박막의 고정기하 분리일.

분리 참조만 무변형 흡착층으로 바꾸면 탄성 변형에너지가 섞여 다른 양이 됩니다.
같은 SE를 쓴다는 것은 비교 조건을 맞추는 장점이지만, Ag와 흑연의 변형률 효과가 서로 상쇄된다는 뜻은 아닙니다. SE 자체가 대칭이어도 한쪽에 다른 물질을 붙인 전체 계면은 비대칭이므로, DFT의 쌍극자·전기적 경계 처리는 별도로 유지해야 합니다.
Q7. 지금 DEM에 무엇을 약속할 수 있나?
회신 2′를 바탕으로 고치세요. 현재 2′도 그대로 보내기에는 두 표현이 과합니다.
- "작은 모델에서 검증된 MLIP" → 검증 대상과 전체 계면 예측을 명시적으로 분리.
