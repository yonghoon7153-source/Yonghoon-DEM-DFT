## 1. 증상

P:S 5킷(AM_P:AM_S = 10:0 / 7:3 / 5:5 / 3:7 / 0:10, n_grid 256, hold, target 0.3 GPa) 1차 런:

| P:S | 두께 frame0 → 최종 | 스트로크/초기두께 | ÷ 0.008 | 최종 wallP |
|---|---|---|---|---|
| 10:0 | 121.32 → 117.44 µm | 0.03198 | 4.00 | 0.0026 GPa |
| 7:3 | 118.91 → 115.10 | 0.03204 | 4.01 | 0.0148 |

## 2. 원인

### 2-1. 판독 식

```python
# mpm3d_compaction.py:2087-2092  am_mask 영점화 (먼저)
# mpm3d_compaction.py:2095-2097  플래튼 판정 (나중)
wallf += grid_m[I] · (grid_v[I][2] − wall_vel)     # 플래튼 위 모든 노드
```

`:2059` substep마다 영점화 → `:2254` `wacc += wallf/(dt·area)` → `:2256` `wallp = wacc/sub`
(순수 산술평균).

**플래튼 운동학**(`:2472-2473`): `wall_z`는 프레임당 **한 번에 step만큼 점프**하고 substep 중
고정, `wall_vel = −step/(sub·dt)`가 40 substep 동안 부과된다.  부드러운 하강이 아니라
**텔레포트 + 속도 부과**다.

플래튼이 **정지**해 있으면(`wall_vel = 0`) 이 값은 경계 힘/면적 = 정적 응력이다.
**움직이면** 세 가지가 섞여 들어온다.

### 2-2. 16.67 GPa의 구성

킷: 베드 H = 2.184 box, `vmax = 0.008·H`, 프레임시간 `sub·dt = 40 × 2e-4 = 0.008`
→ **V_platen = H = 2.184 box/t.u.** (항등식).
SE E=1.53 / ν=0.49 → µ=0.513, λ=25.16 → **c_P = √26.18 = 5.117**, **c_S = √µ = 0.717**.

| 항 | 값 | 성격 |
|---|---|---|
| 음향복사 ρc_P·V | **≤ 11.2 GPa** | 파동이 나르는 **실재 동적 응력** |
| 램압 ρV² | φ·4.77 GPa (프레임평균 ~1–2) | 삼켜진 슬랩의 운동량 소거 |
| **격자 셔블링** | **4.3–12.8 GPa** | am_mask 노드가 `grid_v=0`으로 영점화된 **뒤** 플래튼 판정을 받으므로(`:2087→:2095` 순서), 플래튼 위 마스크 셀에 스플랫된 SE 질량이 **매 substep** `m·\|v_wall\|` 기여 |
| 진짜 준정적 응력 | ~0.01–0.1 GPa | 동프레임 σzz_vol = 0.104가 상한 증거 |

**합계는 실측 16.67 (7:3) / 16.24 (5:5) GPa와 정합하나, 항별 정확 분해는 UNVERIFIED**
(계측 커널 재실행 필요).  셔블링이 최대 단일 기여 후보다.

> ⚠ **"순수 운동량 플럭스"라고 쓰면 반격당한다.**  ρc_P·V 단독 상한 11.2 GPa로는 16.67을
> 못 채우고, 그 항은 실재하는 동적 응력이다.  올바른 명칭: **"이동 경계에서의 속도-결합
> 판독 편향(음향복사 + 램 + 격자 셔블링)"**.

조성 무관(2.6 % 산포)인 이유: 판독에 **SE 질량만** 들어가고(AM은 마스크) 상단 SE 밀도는 조성에
둔감.  **정지 후**(0.0233 vs 0.0276)는 18 % 다르다 — 움직일 때는 조성을 못 보고 멈추면 본다.

### 2-3. 준정적 조건 위반 (수치 정정)

| 지표 | 값 | 관행 한계 | 초과 |
|---|---|---|---|
| **플래튼 마하수 V/c_P** | **0.427** | ≤ 10⁻² | **43×** |
| **V/c_S (전단파)** | **3.05** | ≪ 1 | **초음속** |
| **입상 관성수 I** | ≈ 0.034 | 10⁻³ (GDR-MiDi) | 34× |
| 기본주기 T = 4H/c_P | 213 프레임 | 재하 ≫ T | 하강 7프레임 = T/30 |

**ν = 0.49 재료의 소성(등체적) 응답은 c_S로 전파**된다.  플래튼이 재료의 회피 흐름보다
**3배 빠르다** — 이것이 가장 강한 진단 근거다.

파동 전파(정정): n_grid 256에서 CFL 캡은 3.05e-4라 **기본 `dt = 2e-4`가 binding**
→ 실효 CFL 0.262 → `c_P·dt·sub·n_grid` = **10.5칸/프레임**, 베드 546칸 **편도 52프레임**.
하강은 4~6프레임 → 플래튼이 누른 정보가 바닥에 도달한 적이 없다.

## 3. 결정적 증거 — 독립 속도 스윕 실험

리뷰어가 리포를 수정하지 않고 소형 재현 런 3개를 실행했다
(pristine SE, n_grid 48, hold, frames 22, `--sub 80/40/20` = 프레임당 스텝 동일, **플래튼 속도만**
½ / 1 / 2배).

**세 런의 `wall_z` · `porosity` 궤적은 비트단위 동일**(= 동일 변형 이력)인데:

| frame | sub80 (V/2) | sub40 (V) | sub20 (2V) | 배증당 비 |
|---|---|---|---|---|
| 10 | 0.152 | 0.335 | 0.820 | 2.20 / 2.45 |
| 15 | 0.137 | 0.373 | 1.151 | 2.72 / 3.09 |
| 20 | 0.116 | 0.332 | 1.107 | 2.87 / 3.34 |

**같은 변형 상태에서 판독이 속도에 따라 2.6~10× 변한다** → 판독은 재료 상태량이 아니다.
탄성 스파이크였다면 세 런이 같아야 한다.  초선형 스케일링(2.2→3.3/배증)은 V¹+V² 혼합 구성을
실증한다.

### ★ 부수 발견 — 베드 상태 자체도 rate-오염

같은 `wall_z`에서 **σzz_vol이 속도 배증당 1.7~1.8× 차이**난다.  즉 **판독만의 문제가 아니라
베드의 응력 응답 자체가 이 속도역에서 rate-의존**이다.  → 처방에서 판독 수정(동결 프로브)과
속도 감속이 **둘 다** 필요한 이유(§7).

## 4. 운동학적 정지의 증명 (정수 프레임이 아니라)

1. **N이 갭 산술로 예측된다.**  `WALL0 = am_top + 0.05` (`:1226`) → 갭 0.05 box,
   step = 0.01747 → `gap/step = 2.86` → 최소 접촉 프레임 3, + 스침 1 = **N = 4** (4킷);
   SE 소립이 정상에 있는 0:10만 **N = 3**.  **5/5 적중**이고 target·조성·강성에 **무관**하다
   (이동 판독이 target의 56배라 target을 10배 올려도 같은 N).
2. **등응력-정지 가설은 자기 데이터가 반박한다.**  등-스트로크(N=4) 정지 후 정지-판독이
   0.0026~0.0148 GPa로 **5.7× 산포**.  같은 변형에서 응력이 5.7× 다르다면 등응력 정지는
   부등-스트로크를 요구한다 — 스트로크가 같았으므로 응력 정지가 아니다.
3. **속도 스윕**(§3) — 판독이 재료 상태량이 아님을 직접 보인다.
4. **재실행이 결정타** — STOP_HOLD 추가 후에도 강성이 다른 7:3 / 5:5가 **똑같이 6프레임**
   (첫스침 + STOP_HOLD 3)에서 정지.
5. **대안 기하 정지 배제** — `--am-jam`은 opt-in(`:477`)이고 로그 부재; `hard_floor`는
   4/5킷 최종 ε가 DEM ε **아래**로 뚫려 부정합.

### Δε 분해 (신규)

−2.7 %p 중 **−1.9 %p는 초기 에어갭(0.05 box = 2.8 µm) 폐쇄의 부기**이고 **실제 베드 물림은
−0.8 %p**뿐이다 (0:10은 −1.8 / −0.1).  사전등록 문서의 "0:10만 −1.9" 각주와 0.1 %p 이내 정합.

## 5. 발동 조건 — 두 축이 다르다

`V_platen = (WALL0−FLOOR)` (항등식) → **두꺼운 전극일수록 빨리 내려찍는다.**

| 대상 | 베드 H (box) | 칸/frame | V/c_P | 상태 오염 |
|---|---|---|---|---|
| pure-SE Minnmann 보정 | 0.23 | ~0.7 | **0.098** | 있음 (↓§6) |
| real_14 앵커 | 0.607 | 1.87 | **0.119** | 있음 |
| SDCP 침대 | ~1.2 | — | ~0.24 | 있음 |
| P:S 킷 | 2.184 | 4.57 | **0.427** | 심함 |

**두 결함을 분리해야 한다:**

* **판독 결함 (항상)** — 이동-판독 편향이 target을 넘는 조건은 `ρ·c·V ≳ 0.3 GPa`
  → `V ≳ 0.07–0.12` → **H ≳ 0.07–0.12 box**.  실사용된 **모든** 구성(H 0.23~2.19)에서 성립.
  → **순간-비교 정지는 어떤 생산 구성에서도 건전한 적이 없다.**
* **상태 오염 (연속 등급)** — 프레임당 물림량(0.7 → 4.5칸)과 σ(ε)의 rate-의존은 베드가 길고
  n_grid가 클수록 심해진다.

> ⚠ **rev1의 `--dilate-z` 가설은 기각.**  갭은 `WALL0 = am_top + 0.05`로 **dilate 무관 고정**
> 2.72 µm이고, 앵커 시점 코드(702fa318)도 현행과 동일 구조다.  차이는 **베드 높이**다.

## 6. real_14 앵커 — rev1 판정 뒤집힘

**rev1: "결함 미발동" → rev2: REFUTED.  결함은 발동했다.**

실측 두께 **29.95 vs DEM 30.28 µm = 0.33 µm = 2.3칸 = 정확히 ~1.2프레임 물림** — 5킷과 동일한
"첫스침 + ~1프레임" 시그니처다.

그런데도 앵커가 맞은 이유는 두 겹이고, **"우연"보다 나쁘다**:

1. 물림이 작아(≈ −0.9 %p) 손상이 검증 오차대에 숨었다.
2. **더 나쁘게** — 트리거가 관성 지배라 **재료 모델과 무관하게** 플래튼이 `am_top − (1~2프레임)`
   위치에 멎는다.  실측 SE 부피 + 실측 AM 골격 위에서 **porosity ≈ DEM porosity가 되는 것은
   준-항등식**이다.  15.93 %는 압밀 물리가 아니라 **기하·질량 부기의 자기일관성 검증**이었다.

`:1163-1167`의 주석 "moving wall_z is the real press response, not an artefact"는 hold 경로에
대해 **반증됐다**.  `docs/mpm3d_calibration.md:241-245`의 "ZERO targeting → porosity EMERGE"
서술은 하향 조정이 필요하다.

(단 `se_frac = 0.27` **servo** 교차검증 16.7 %는 별개 경로 — 양방향 servo는 정지 근방 왕복으로
자기보정하므로 이 진단의 직접 사정권 밖.  limit-cycle 진폭 0.04–0.08 %p는 `:2500-2503` 기록.)

### ★ 신규 우려 — Minnmann σ_y 보정

pure-SE Minnmann 보정 런도 **V/c ≈ 0.098**에서 수행됐다.  §3의 스윕에서 베드 σ(ε)가 이
속도역에서 rate-의존임이 확인됐으므로, **σ_y = 0.30 보정에 속도 아티팩트가 흡수됐을 가능성**이
있다.  rev1에서 이 자산을 [A]로 분류한 것은 *정지 분기* 기준이었는데, **rate 오염은 그와 직교하는
축**이다.  → **[A] → 별도 검증 필요**로 하향.

### 첫 시도(커밋 68df3dae)가 실패한 이유

scaffold 분기의 순간 비교에 STOP_HOLD 3연속 요구를 걸었다.  결과:

* **킷을 못 고쳤다** — 이동 판독이 target의 56배로 지속되니 reach_cnt가 무조건 연속 충족
  → 정지 = 첫스침 + 3.  1차 4프레임 → 재실행 **6프레임**.
  `Δε = (1−ε)/t × (2프레임 × 0.008 × 118 µm) = 1.38 %p` 예측 vs 실측 −1.45 / −1.43 →

**real_14 에는 충격 슬램이 없다.**  frame 0–10 동안 wallP 가 정확히 `0.0000` 이고 frame 11 에
처음 0.0005 가 뜬다 — 에어갭 2.73 µm(= `WALL0 = am_top + 0.05`)를 0.272 µm/f 로 **10.0 프레임
자유주행**한 것과 정확히 일치한다.  이후 ~6 프레임 동안 진짜 접촉이 쌓이고 **공극률이 실제로
5.21 %p 압밀**된다 (26.02 → 갭닫힘 19.59 → 최종 14.38; 앞의 6.43 %p 는 갭 부기).

⇒ **rev2 의 "real_14 도 발동" 은 유지하되 등급을 나눈다**: real_14 는 *손상됐지만 무효는 아니다*
(진짜 압밀이 일어났고 정지가 이르게 발동), 첨가제 킷은 *사실상 갭만 닫고 끝*.

## 17. ★ 정지만 고치면 더 나빠진다 — 과압축

`--sub` 사다리 (real_14, n_grid 384, hold, 다른 조건 전부 동일):

| sub | 속도 | 하강 정지 프레임 | porosity | 정착 wallP | vs target |
|---|---|---|---|---|---|
| 40 | 1× | 16 | 14.38 % | 0.0064 GPa | **1/47** |
| 80 | ½ | 19 | **12.76 %** | 0.0229 GPa | **1/13** |
| 160 | ¼ | (진행) | | | |

**두 가지가 동시에 확정된다.**

**(a) porosity 는 정지 프레임의 함수일 뿐이다.**  sub=80 궤적에서 frame 15 가 **15.93 %**
(= 기록된 앵커값), frame 17 이 **14.38 %** (= STOP_HOLD 런의 최종).  정확히 **2 프레임 차이** —
68df3dae 가 더한 그 +2 다.  step/frame 이 같으니 기하 사다리가 동일하고 **움직이는 것은 정지
프레임 하나뿐**이다.  앵커 15.93 % 는 물리가 아니라 **정지 시점**이 정한 값이었다.

**(b) 수렴하지 않는다.**  속도 ½ → porosity −1.62 %p, 정착 응력 ×3.6.  0.3 GPa 에 닿으려면
13 배 더 올라가야 하니 두어 단계 더(sub≈320) → **porosity 9~10 %** 로 외삽된다.
이것은 CLAUDE.md 에 이미 기록된 **servo 과압축 15.9 → 9.5 %** 와 같은 자리다.

⇒ **"첫 접촉에서 얼어붙는" 결함이 그 과압축을 우연히 상쇄하고 있었다.**  그래서 15.93 ≈ 실험
15.6 이 나왔고, 우리는 그것을 검증으로 읽었다.  정지만 제대로 고치면 베드는 ~9.5 % 로 무너진다.

### 왜 무너지는가 — 빠진 물리

12.76 % 공극률의 베드가 **22.9 MPa 밖에 못 버틴다**.  실제 전극은 15.6 % 에서 300 MPa 를
버틴다 — **13 배** 차이.  이유는 코드에 있다: **얼린 AM 은 wallP 에 기여가 0**
(`am_mask` 영점화가 플래튼 판정보다 먼저, `:2087→:2095`)이고, SE 는 고체의 25.9 % 뿐인
공극 뚫린 망이라 혼자서 300 MPa 를 지탱할 수 없다.  실제 전극에서는 강체 AM 골격이 하중
대부분을 받는다.

## 19. 순환논리 방어선 (사용자 지적, 2026-08-04)

> "f_AM 을 넣어 porosity 를 15.6 % 에 맞추면 순환 아닌가?  DEM·MPM 단독이라는 장점은?"

**위험은 실재한다.**  9.5 % 로 무너진 걸 보고 f_AM 을 15.6 % 가 나올 때까지 돌리면, 사고로
상쇄되던 것을 **의도적으로 맞춘 것**으로 바꾼 것뿐이고 frame[4] 정면 위반이다.

**방어선 1 — f_AM 은 측정량이지 노브가 아니다.**  설계가 이미 그렇다:
`f_AM = Love-Weber σzz^AM-AM / σzz^total`, **DEM 접촉력에서 추출**(파이프라인이 이미 contact
force 를 재구성하므로 extractor 만 추가).  규율은 **순서**다 — f_AM 을 먼저 뽑고, porosity
예측을 **사전등록**한 뒤, 그 다음 실행.  맞으면 교차검증, 틀리면 정량화된 한계.  순서를
뒤집는 순간 순환이다.

**방어선 2 — scaffold 는 원래 독립이 아니었다.**  AM 위치를 DEM 에서 통째로 받는다
(CLAUDE.md: `COUPLING = scaffold`).  현재 상태는 오히려 **일관성 없는 결합**이다: AM 의
*기하*는 받아쓰면서 *하중 분담*은 무시한다 — 공간은 차지하는데 힘은 안 받는 강체.
f_AM 은 새 결합을 만드는 게 아니라 **이미 있는 결합을 완성**한다.

**진짜 독립인 자산은 그대로다**: pure-SE Minnmann 보정(DEM 입력 0, ⚠σ_y rate 검증 대기) ·
2D champion morphology · 2D dip/해상도 불변성 · DEM 수송 삼중항.  frame[4] 는 여기 산다.

**포기할 주장 하나**: "scaffold porosity 가 DEM 과 1 %p 내로 맞으니 교차검증" — 씨앗이 DEM
압축완료 좌표라 준-항등식.  f_AM 때문에 잃는 게 아니라 **오늘 이미 잃었다**.

**방어선 3 — 독립성 회복 경로: AM-as-material.**  AM 에 실제 탄성을 주면 골격이 물리로 하중을
지고 **DEM 파라미터가 0 개**가 된다.  CLAUDE.md 의 AM-freeze 근거 4개 중 ②"mobile-rigid AM →
force-chain over-shielding 36–41 %" 가 지금 의심스럽다 — **"베드가 높은 공극률에서 target
도달했다고 주장하며 멈춤"이 정확히 운동학적 정지의 서명**이고, 그 진단이 같은 내려찍는
플래튼 아래서 내려졌다.  (단 2D CORRECTION 1 이 force chain 의 일부를 soft-bulk 아티팩트로
이미 규명하고 ν=0.49 로 고쳤으므로 전부가 이 결함 탓이라 단정하면 안 된다.)

⇒ **순서를 강제한다**: ⓐⓒ 수정 → f_AM **없이** 준정적 극한 측정 → **AM-as-material 재시험** →
안 되면 그때 f_AM(측정→사전등록→실행).  결합을 늘리기 전에 결합 없는 길을 먼저 시험한다.
