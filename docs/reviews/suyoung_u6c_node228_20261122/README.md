## 실패 원인과 수정

노드 2304의 물체 네 개에는 접촉 후보가 여섯 쌍 있다. 512회 뒤 추정한 상태에서 **세 접촉을 열면서 다른 한 접촉의 접선 상태를 미끄러짐에서 고착으로 바꾸면** 원래의 힘 전달 조건을 만족하는 해를 얻는다. 기존 보완은 두 상태까지 임의로 바꾸거나 여러 접촉을 열기만 하는 경우를 검사했다. 이번 혼합 변경은 그 범위 밖에 있었다.

`scripts/suyoung_multicontact_dev.py`는 네 물체에서 기존 탐색이 모두 실패했을 때만 남은 접촉 상태 조합을 검사한다. 마찰이 있으면 여섯 쌍에 가능한 조합은 총 4⁶ = 4,096가지다. 228걸음에서는 기존 196가지 뒤 168가지를 더 검사해 364번째에서 수용했다. 145걸음의 결과는 기존과 같은 172번째에서 얻었다.

| 고정 노드 2304의 수치 | 값 |
|---|---:|
| 원 비선형 잔차 허용치 (속도 단위) | 8.4752 × 10⁻¹³ |
| 구본의 마지막 충격량을 70자리 산술로 확인한 잔차 / 허용치 | 90,895,613.6 |
| 수정 후보가 선택한 충격량의 70자리 산술 잔차 | 3.3424 × 10⁻¹⁷ |
| 운동에너지 관문 | 통과 |

선형계의 계수가 종속인 상태에서는 최소제곱 대표 해 하나를 검사한다. 각 노드의 유일성 및 모든 입력의 수렴은 미확정이다. 기존 잔차·운동에너지 기준을 넘으면 실행을 중단한다. 5체 이상은 기존 탐색 범위를 따른다.
