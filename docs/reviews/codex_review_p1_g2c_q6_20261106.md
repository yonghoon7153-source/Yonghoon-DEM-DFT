다만 sort 0으로 다음 경로까지 없어지지는 않습니다.

Q6-2 — 예측 라: 조건부

CW→F′→CR에도 같은 답입니다. “같은 실행 파일이므로 CW=11-04 C”는 근거가 부족합니다. 최초 command restart의 바이트, include·물성·fix ID, dump 형식과 행 순서까지 같아야 합니다.
동일한 command restart와 동일 입력·출력 조건에서 CW와 기존 C의 동일성을 예상하며, CW/CR 왕복 동일성과 기존 C 재현은 별도로 비교한다.

주기 파일과 명령 파일의 첫 차이가 왕복으로 사라지거나, 원 런 상태가 복구됐다는 뜻은 아닙니다.

Q6-3 — 예측 바: 제시한 연쇄등식은 틀림

같은 접촉 방향·기하·물성·법선 상태이며 양쪽 모두 고착 분기라면, 실수 산술에서 전체 힘 차이는 맞습니다.
\[
\Delta\mathbf F=-k_t\Delta\mathbf s
\]
하지만 덤프의 force_normal과 force_tangential은 전체 힘의 사영과 그 잔여입니다. 따라서 정확한 예측은 다음입니다.
\[
\boxed{\Delta\mathbf F_{n,\mathrm{dump}}
=-k_t\mathbf n(\mathbf n\!\cdot\!\Delta\mathbf s)}
\]
\[
\boxed{\Delta\mathbf F_{t,\mathrm{dump}}
=-k_t\left[\Delta\mathbf s-\mathbf n(\mathbf n\!\cdot\!\Delta\mathbf s)\right]}
\]
즉 \(\mathbf n\cdot\Delta\mathbf s=0\)일 때만 전체 힘 차이와 덤프 접선력 차이가 같습니다. setup에서는 shear의 현재 접평면 재투영도 생략되므로, 그 조건을 자동으로 가정하면 안 됩니다. tangential_model_history.h:143–158, 166–217, compute_pair_gran_local.cpp:477–508

추가로:
- 고착 여부는 스프링력 크기 kt·|shear| ≤ x_mu·|Fn|로 분류해야 합니다.
- %.17g는 출력 정밀도이지, 차분·곱셈·사영의 끝자리 일치 보장이 아닙니다.
- CDT는 delta_torque만 갱신합니다. 해당 시점의 덤프 힘 열에 직접 더해지는 경로는 없습니다. rolling_model_cdt.h:160–166

Q6-4 — “setup/덤프는 이력을 안 바꾼다”: 틀림

정확히는 접촉 중 접선 이력의 적분·회전·미끄럼 후 저장을 막는다입니다. 다음 예외가 남습니다.
- deltaMax=max(deltaMax,δ)는 setup·덤프에서도 실행: normal_model_hooke_hysteresis.h:156–157
- 이웃 재구성에서 미등록 접촉은 이력 0, 거리 조건 밖 접촉도 이력 0: neigh_gran.cpp:587–614
- 바닥 primitive wall도 setup에서 계산하고 비접촉 이력을 지울 수 있음: fix_wall_gran.cpp:681–687, 1145–1149

법선 이력, 이웃 이력 복원, 벽 이력 초기화

다만 첫 setup에서 이 변경이 끝나면 두 번째에는 그대로일 수 있습니다. 이 예외만으로 다·라의 불일치를 단정하지 않습니다. 또한 쌍 30열·원자 12열의 일치만으로 별도 벽 이력 전체까지 인증되지는 않습니다.
