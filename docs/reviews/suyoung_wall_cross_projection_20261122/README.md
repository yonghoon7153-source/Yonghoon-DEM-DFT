# 같은 입자 상태를 F8과 F16 격자에 투영하는 개발 대조

같은 균일 압축에서는 F8/F16 반력비가 약 1.414였고, 실제 수직 응력 기여의 비는 약 3.86–3.88이었다. 이번에는 한쪽 팔의 입자 배열과 응력장을 그대로 두고, 어느 격자와 아래판 하향 마스크로 읽느냐에 따라 반력이 얼마나 달라지는지 본다. 이와 짝을 이루는 비교는 하나의 격자·마스크에서 입자 상태만 바꿨을 때의 차이다.

## 결과 전 고정할 네 가지 조합

| 고정한 입자 상태 | F8 격자 + F8 원 마스크 | F16 격자 + F16 원 마스크 |
|---|---|---|
| F8의 위치·부피·입자 ID·응력 | F8 원 관측을 노드별로 재현 | F8 입자장을 F16으로 읽은 가상 값 |
| F16의 위치·부피·입자 ID·응력 | F16 입자장을 F8으로 읽은 가상 값 | F16 원 관측을 노드별로 재현 |

두 표를 만든다. 첫 번째는 F8 269걸음과 F16 538걸음, 두 번째는 F8 270걸음과 F16 540걸음이다. 각 짝에서 반력 관측의 **걸음 끝 판 변위**는 일치한다. 응력 전달에는 해당 걸음 시작의 입자 상태를 쓰므로, Δt가 두 배 다른 양팔의 시작 시점은 서로 다르다. 각 행 안에서 두 격자에 읽힐 입자 상태는 같은 스냅샷이다.

- 두 원 조합은 직전 반환과 같은 노드 키에서 수직(yy)·전단(yx)·균일 기준 응답 및 원 압력 기록을 재현해야 한다.
- 가상 조합은 대상 격자의 **기존 원 마스크**를 유지한다. 주어진 입자장에서 해당 노드·입자장에 들어오는 지지가 없으면 기여 0으로 합산하고 그 키 수를 기록한다. 대상 격자의 계산 영역을 벗어나는 상태는 외삽하지 않는다.
- 두 상태에서 격자를 바꾼 압력 차이와, 두 격자에서 상태를 바꾼 압력 차이를 각각 MPa로 보고한다. 두 경로의 차이도 남긴다. 격자와 함께 바뀌는 마스크는 원래 속도 이력의 영향을 받고, 상태에는 입자 위치·부피·실제 응력이 함께 들어간다. 원인별 백분율은 매기지 않는다.
- 얇은 합성 평판 대조는 `docs/reviews/suyoung_wall_stress_probe_return_20261122/README.md`를 참조한다. 이 판별은 원 가압 경로의 스냅샷에서 실제 공간 분포를 유지한 비교이며, 덱이나 접촉 모델은 수정하지 않는다.

## 실행과 보존

1저자 WSL CPU 1개 · F8 270걸음, F16 540걸음 · 팔당 300초 상한 · 자동 재시도 0. 각 원점에서 바이너리 배열로 위치, 입자 ID, 부피, 수직 및 전단 응력을 저장한다. 이들 상태와 반환 자료가 있으면 이후의 투영 대조는 가압 재실행 없이 할 수 있다. 시간 전진 없이 읽는 가상 조합은 물리 궤적으로 채택하지 않는다.

실행 인수는 `GO_SUYOUNG_WALL_CROSS_ONCE`, 균일 응력 반환 TAR, 직전 아래판 구간 반환 TAR 순서다. 포장·신원만 보려면 `CHECK_ONLY`를 쓴다. 출력은 `suyoung_wall_cross_result.tar.gz`, 화면, SHA256SUMS이다. U6(c)와 단계 3은 HOLD다.
