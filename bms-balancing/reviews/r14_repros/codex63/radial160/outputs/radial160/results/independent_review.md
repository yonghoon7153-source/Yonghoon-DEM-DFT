# 300/160 단일 추가 계산의 독립 수치 검토

**새 80→160 비교는 전압 기준을 충족하지 못했다.** 0–1초와 0–5초 모두 최대 전압 차가 0.01초에서 **1.2482181141973 mV**다. 표면 조성 차는 두 구간 모두 기준 이내지만, 전체 반경 수렴이나 입자 160요소의 수렴은 입증되지 않았다.

## 비교 범위와 검증 방법

새로 계산한 것은 `Caps300R160H0500` 한 작업이다. 300/80은 지정된 기존 primary 기준 해이고, 300/40은 같은 시각의 추세를 확인하기 위한 기존 참조다. 이전 결과를 수정하거나 다시 계산하지 않았다. 이 분석기는 COMSOL이나 Java를 실행하지 않았다.

| 조건 | 역할 | job | 저장 시각 수 |
|---|---|---|---:|
| Caps300R40H0500 | 기존 추세 참조 | b6752f9caed845f88551386132051aa8 | 390 |
| Caps300R80H0500 | 기존 primary 기준 해 | 72c9c6b5210a4e0d96b74290e4392423 | 388 |
| Caps300R160H0500 | 새 승인 계산 1회 | 450b46add79c439bbce5886454c4328a | 388 |

새 소스 SHA-256은 `874e70a9d6531a2a83ebd05f439d514c324b3ca79875494b1cf304797cc90e26`이다. 세 소스 모두 native job 사본의 실제 SHA가 설정과 제출 기록에 일치한다. 세 이름·기존 참조 job ID·role을 명시적으로 검증했으며, jobs 배열의 입력 순서와 무관하게 40/80/160 순서를 고정했다.

세 해 모두 공통 요청 시각 187개를 정확하고 유일하게 저장했다. [0,1]초에는 107개, [0,5]초에는 187개가 있다. 시간 보간·근처 시각 대체·서로 다른 adaptive 시각의 비교는 없다. 각 전극의 공통 241개 물리 좌표에서 COMSOL의 FE 공간 평가값을 사용했다. Python 공간 보간은 없다. domain 1/3, 좌표 일치 허용치 1e-15 m, 모든 저장 profile의 행 수·유한값·범위를 검사했다. 최대값은 이 지정된 시간·공간 표본의 최대이며 연속장의 엄밀한 오차 상한이 아니다.

새 해는 전극당 93,508개 profile 행(388시각×241좌표)을 검증했다. 실제 격자·전체 solver 속성과 accepted step은 root의 [별도 native 기록](../native_steps_summary.json)에 있다. 분석기의 runtime core getter는 80과 160에서 모두 같았고 식 `if(t<0.1[s],0.0005[s],0.1[s])`도 설정과 일치했다.

## Primary 80→160 결과

차이의 부호는 160요소 해 − 80요소 해다. 기준은 최대 절대 전압 차 ≤1 mV, 최대 점별 절대 표면 x 차 ≤1e-4다.

| 구간 | 최대 절대 전압 차 (mV) | 시각 (s) | 최대 점별 절대 표면 x 차 | 시각 / 전극 / 물리 좌표 | 판정 |
|---|---:|---:|---:|---|---|
| 0–1초 | 1.2482181141973 | 0.01 | 2.0911839020788e-5 | 0.01초 / N / 52 µm | 전압 미달, x 충족 |
| 0–5초 | 1.2482181141973 | 0.01 | 2.0911839020788e-5 | 0.01초 / N / 52 µm | 전압 미달, x 충족 |

새 전압 최대와 표면 차이 최대가 모두 0.01초에 발생했다. 기존 40→80 비교의 최대는 0.04초였다. **새 0.04초 전압 차 0.6902861312578 mV만 사용하면 실제 최대를 놓친다.** 5초 끝점·Li 보존·특정 시각 하나를 근거로 통과시키지 않았다.

최대 표면 차이 위치인 음극 오른쪽 끝 52 µm는 단자 전압 분해에 사용하는 음극 집전체 0 µm와 다른 위치다. 전압은 두 집전체의 phis 차이고, profile의 최대 위치는 별도로 평가했다.

## 같은 시각의 전압 분해

각 해에서 `V=(Eeq_P−Eeq_N)+(etaMid_P−etaMid_N)+(phil_P−phil_N)`이다. 아래 모든 성분은 동일 시각의 두 해 차이이며 단위는 mV다. 성분별 최대가 발생한 서로 다른 시각을 합산하지 않았다.

| 평가 | 시각 (s) | δ(ΔEeq) | δ(ΔetaMid) | δ(Δphil) | δV | 합계 잔차 (V) |
|---|---:|---:|---:|---:|---:|---:|
| 새 최대 전압·표면 차이 시각 | 0.01 | +1.2688514702157 | −0.020902710440976 | +0.0002693544225 | +1.2482181141973 | 7.6e-17 |
| 별도 0.04초 평가 | 0.04 | +0.7045674354991 | −0.01437203811583 | +0.0000907338746 | +0.6902861312578 | −7e-17 |

두 시각 모두 Eeq 차이가 가장 크고 과전압 차이가 일부 상쇄한다. 이는 저장된 성분의 분해 결과이며, 반경 오차와 시간 적분 오차를 완전히 분리했다는 뜻은 아니다.

## 물리 검사·시간 이력·보호의 한계

새 해는 총 Li 상대 변화 최대 3.245202022391813e-15, 전압 항등식 잔차 최대 5.61e-16 V, 후처리 전해질 최소 농도 1194.4372147785944 mol/m³다. 실제 Eeq와 표면 함수의 차이, 실제 반응 입력과 표면 농도의 정규화 차이, eta−etaMid는 모두 CSV 출력 정밀도에서 0이다. 모든 저장 표면 조성이 감시 범위 안이고 guard는 0이었다. 새 해에 범위 중단이나 비유한값 오류는 없었다. 이 검사들을 반경 수렴의 대체 근거로 사용하지 않았다.

Native 기록상 새 실제 격자는 물리 300개, 각 전극 입자 160개이고 transient 자유도는 40,765개와 internal 12개다. 초기 상한 0.0005초·후반 상한 0.1초의 interval 검사는 통과했다. 그러나 80의 초기 accepted step 수 209개와 160의 210개는 같지 않다. 같은 설정과 공통 요청 시각이 동일한 adaptive 적분 이력을 뜻하지 않는다. 새 160에서 별도 시간 상한 반감 시험을 실행하지 않았으며 순수 반경 오차로 완전히 분리하지 않았다. t=0은 CDI/consistent initialization 이후다.

OCP/entropy 외삽 금지와 실제 표면/입력의 실시간 범위 감시를 유지했다. 전해질 양수는 후처리 검사이고 전해질 음수의 실시간 중단은 구현되지 않았다. OCP 표·초기 조성·Li 재고를 조정하지 않았다. 과거 failed/INCOMPLETE_RANGE_STOP 결과는 수정하지 않았다. 누락 CSV 또는 다른 solver/내보내기 오류만으로 OCP 실패라 추정하지 않는다.

## 재현과 파일 보존

분석기: `work/radial160/analyze_results.py`. 기본 입력은 `outputs/radial160/{jobs,source_configs,comparison_contract}.json`이며 결과는 `outputs/radial160/results/`에만 쓴다. 이전 분석기와 이전 결과는 수정하지 않았다. Primary pass와 과거 trend reference pass는 별도 필드이며, 과거 참조의 실패를 새 작업 실패 원인으로 섞지 않는다.

합성 회귀 테스트 13개가 통과했다. 정확한 시각·좌표 검증, 동일 시각 전압 분해, pointwise profile 비교, role/고정 참조 ID, 입력 순서와 무관한 3수준 값, core 설정 차이 거부, 근거 없는 OCP 실패 분류 방지를 포함한다.

승인된 새 5초 계산은 한 번뿐이다. 추가 계산은 제출하지 않았다. 새 primary 전압 기준 미달과 수렴 미완 판정을 유지한다.
