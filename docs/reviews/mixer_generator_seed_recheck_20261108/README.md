## 변경과 범위

- `scripts/make_mixer_deck.py`: 실제 `ins` 또는 `insA`와 파생 `insB`에 ASCII 양의 정수 표기, `1..2147483647`, 소수 검사를 적용한다. 초기 시드의 범위를 소수 검사 전에 제한한다. 층상 두 번째 시드는 기존 `next_prime(seed + 2)`를 유지하되 최종 값도 같은 검사를 거친다. 실패는 덱 문자열 반환 전이며 CLI의 기존 일괄 생성 전 검사가 출력 쓰기 전에 차단한다.
- API의 bool, float, 비정규 문자열은 실제 출력 표기를 보장하지 못하므로 거부한다. 정규 ASCII 숫자 문자열은 정수로 사용한다. CLI `argparse(type=int)`는 그대로 두어 `+`, 선행 0, 밑줄, Unicode 숫자, 공백을 정수로 정규화하던 기존 사용법을 보존한다. CLI 이후 출력 토큰은 정규 ASCII 정수다.
- `scripts/test_mixer_generator_seeds.py`: 새 8개 시험. 범위·소수·API 표기, 층상 파생 초과, CLI 정규화, 기존 출력 보존, `--all-arms` 부분 출력 방지와 경계 양성을 다룬다.
- `scripts/test_mixer_d2_consumers.py`: 과거의 부적격 생성기에 의존하던 R01 fixture를 유효 경계 덱의 명시적 시드 변조로 바꾸고 메타 해시·크기를 재결속한다. 수정 전 두 방식의 결과가 2상·3상, 코팅 쌍, 메타까지 같음을 확인했다. 기존 세 CLI 시험 호출에는 기존 R01 호출과 같은 UTF-8과 `-B`를 명시했다. 소비자 검증 조건은 그대로다.

독립 상한 상수는 생성기가 소비자를 역으로 import하지 않게 하기 위한 것이다. 신규 양성·음성 시험과 기존 R01 소비자 시험이 같은 경계를 함께 검사한다. 이 후보는 seed 외의 덱 적격성을 전부 보증하지 않는다.

## 복사본에서의 재현

Python 3.12.14와 NumPy가 있는 격리된 검토 복사본에서, 쓰기 가능한 임시 폴더를 TMP/TEMP에 지정한 뒤 다음 **합성 단위 시험만** 실행한다. `source_inventory.json`은 필요한 12개 스크립트와 바탕/후보 신원을 기록한다. 이번 시험 경로는 SciPy를 요구하지 않았다.

```text
python -I -B -X utf8 scripts/test_mixer_generator_seeds.py

```
