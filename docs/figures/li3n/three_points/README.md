# 3점만 찍은 표시용 구조 (min · saddle · 대칭점)

계산된 두 구조의 adatom 위치를 **원본 좌표 그대로** 한 파일에 넣고, 세 번째 점만
대칭으로 이어 붙인 것. **평행이동·회전 없음** — 두 원본 .vesta 와 같은 시야다.

3번의 높이는 기판 최근접 원자에서 2.15 Å 뜨도록 맞춘 것(`ride_height`).

## 지그재그 3점 (`*_zigzag_*`) — 120° 꺾임

on-Li 자리는 **벌집 배열**이라 이웃이 3개이고 연속 hop 은 120° 로 꺾인다.
대칭점을 쓰면 정의상 일직선이 되므로, 꺾인 그림은 이웃 on-Li 를 연달아 잡아야 한다.

| 파일 | 경로 | A–B–C 끼인각 |
|---|---|---|
| `li3n_3pt_zigzag_Li88_*` | Li77 → Li76 → **Li88**, 2.039 + 2.089 Å | **117°** |
| `li3n_3pt_zigzag_Li44_*` | Li77 → Li76 → **Li44**, 2.039 + 2.147 Å | 113° |

이상 격자면 정확히 120°. 기판 이완 때문에 ±3–7° 어긋난다.
1번 점은 계산된 min 그대로이고, 2·3번은 이웃 on-Li 자리 (Li 바로 위, 기판에서 2.15 Å).

## 한계

3번은 계산된 자리가 아니고, 그 부근 기판은 **N32 가 가로 0.96 Å 에** 있어 실제 흡착
자리가 아니다. min→3번 직선도 ξ≈0.82 에서 Li–N 이 1.14 Å 로 N 을 관통한다.
그림에서 세 공만 찍는 용도로만 쓰고, 사이를 잇는 경로로 해석하면 안 된다.
