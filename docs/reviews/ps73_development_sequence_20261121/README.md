## 1저자용 운영

WSL 실행 TXT 한 파일로 준비·상태·회수 모드를 고른다. `GO_PS73_SEQUENCE_ONCE`는 ibb 1노드, NP6, 팔당 최대 5일로 **기본 탈압부터 등록 설정 선택까지** 순차 실행하는 선택이다. 한 번에 한 잡만 제출한다. 정상 시 네 잡, t3일 때 같은 UT 궤적의 연장까지 다섯 잡이다. 큐 대기 시간은 별도다. `GO_UB_ONCE`는 첫 UB만 돌리는 별도 선택이다. 두 모드를 처음부터 연달아 실행할 필요는 없다. 실제 제출과 큐 상태는 STATUS의 잡 번호로 확인한다.

1. `CHECK_ONLY`는 로컬에서 실행 핀과 포장 바이트를 대조한다. GO 모드에서도 이 대조가 먼저 수행된다.
2. `GO_PS73_SEQUENCE_ONCE`는 원격 감시기를 분리 실행한다. WSL을 닫아도 이미 시작된 감시기와 계산은 계속된다. 제출 전과 작업 시작 때 원 A5 증서·장부, UK 기준 파일, 덱·원 입력, 각 팔의 새 쓰기 위치를 검사한다. 현장 자원 확인에는 368315 때 1저자가 확인한 저장 계획과 현재 파일시스템 여유를 사용한다. 제출 당시 사용자 쿼터를 새로 측정한 값은 없다.
3. `STATUS`는 등록된 잡 번호·계산 단계·중단 사유를 조회한다. SSH 응답이 끊긴 경우 먼저 같은 명령으로 상태를 본다. `RESUME_ACKNOWLEDGED`는 기존 승인을 바탕으로 알려진 잡을 확인하고, 전 단계가 끝난 경우 아직 제출하지 않은 다음 팔을 진행한다. 제출 의도만 남고 잡 번호가 불명확하면 운영자가 대조할 때까지 중지한다. 자동 재시도·취소는 0건이다.
4. `RETURN`은 새 로컬 반환 폴더에 `private_return.zip`과 SHA256, `development_readback.json`을 쓴다. 기술 실패의 경우 생성된 영수증과 회수 가능한 보고를 남긴다. 완료 전에도 회수할 수 있다. 각 팔의 Slurm 종료, 실제 러너 영수증, 원 판독과 반환 보고의 파일 해시를 별도로 확인한다. 새 계산 GO는 포함하지 않는다.
5. `REVIEW`는 7:3 기본 비교가 끝나 결과를 읽을 차례라는 상태다. 이 표지만으로 궤적 분리·실험 일치·논문 숫자 채택을 확정하지 않는다.

## 제출 순서와 멈춤

기준은 `docs/reviews/dem_unloading_ps45_prereg_20261009.md` §12-3·12-4, §13-1·13-5, §14, §15-7과 원위치 복원 판독기 `docs/reviews/p1_rt_a5_preseal_20261120/a5_certificate.py`다. 원 RJ 전용 진입점과 봉인된 143파일을 그대로 보존한다. 새 실행은 별도 개발 드라이버에서 A5 강화 증서 소비 검사와 원 일반 러너 검사를 모두 거친다.

| 차례 | 계산 | 무엇을 구분하는가 |
|---|---|---|
| 1 | UB | 기본 속도·시간 간격에서 판을 올려 1 MPa의 회복률과 실제 교차 괄호를 얻는다. |
| 2 | UT | 같은 속도에서 시간 간격을 반으로 줄여 1 MPa 회복률 민감도를 본다. |
| 3 | UC | 판을 고정한 채 50,000 스텝의 표류·변동을 측정한다. UC에는 제하 교차를 요구하지 않는다. |
| 4 | UVa 또는 UVb | UB·UT 유효 끝점 차이가 0.10%p 이하면 기본 시간 간격, 초과하면 절반 간격을 쓴다. 선택한 간격에서 판 속도를 반으로 줄이고 유지 시간을 두 배로 한다. |
| 5 (t3만) | UTc | 선택된 UT의 동일 체크포인트를 이어 분리·표면 관측을 마친다. 주 값은 UT, 보조 관측은 UTc에서 가져온다. |

기술 실패·불명확한 제출, 입력 신원 불일치, 유효한 끝점 결손, 원 궤적과 판독 불일치 때 후속 제출을 멈춘다. 등록된 선택기에서 한 행만 성립해야 한다. 0.10%p는 개발 민감도 선택 기준이다.

## DEM 우선 2에 넘기는 내용

- **출발 상태** — 7:3, 원 복원 잡 368315, 체크포인트·접촉 이력·운동에너지 기준의 신원을 함께 둔다. 실제 값을 갖는 비교는 결과 회수 뒤 채운다.
- **압력과 두께** — 판 압력 1 MPa에서의 회복률, 실제 교차 괄호, 설정별 차이를 같은 단위로 인계한다. 압력이 남아 있는 1 MPa와 판 분리 뒤 자유 표면 높이는 다른 항목이다.
- **해석 범위** — 모델의 압력–두께 변화와 계산 설정 민감도로 기록한다. 같은 시료의 질량·면적·측정 압력·두께가 갖춰지면 실험 앵커와 대조한다. 다른 조성, 50 kg 전극 및 세대 2의 물리 자격은 각각 등록 조건에 맞춰 이어간다.
- **후속 준비** — 실제 중력 대조를 위해 판정할 접촉 이력, GT1·GT2 덱, 출처 체크포인트, 실패·결측 처분을 결과 전에 확정한다. 현재 선택한 7:3 개발 경로와 증서를 보존해 그 작업과 이어 붙인다.
