# DEM 프로토콜 gen2 생산자·사전등록 준비 — 2026-11-09

이 묶음은 사용자가 지시한 DEM gen2의 오프라인 생산자 구현·합성 시험 및 T5/T11 사전등록 문안 준비다. 정본은 `docs/reviews/dem_protocol_gen2_plan_draft_20261014.md` §12가 우선한다. 이미 비준된 Q1–Q16과 A1–A5를 다시 승인 대기로 돌리지 않는다. **실제 연구 실행·현장 자격·운영 봉인은 이 준비와 별개이며 전체 HOLD다. T12=NOT_RUN, physical_ready=false다.**

바탕은 `e48e5fa0498ab7ee8fd84163d9af024d07cbb135`다. `preregistration_draft.json`은 과학 등록의 빈 수치·증거 칸, 비준된 정책, 합성 시험의 역할을 나눈 서술용 초안이다. JSON 형식의 적합성이나 오프라인 시험 통과가 과학 등록 또는 실행 승인 표지가 되지 않는다. 합성 fixture의 상수는 테스트 사례의 입력이며 실제 재료·침대·제어기의 등록값이 아니다.

## 생산자 경계

단계는 insertion → stabilization → compression → servo → relaxation(R-a) → unloading → separation/free-surface다. 정본 §2-6–2-8에 따라 접촉 중인 판을 먼저 삭제하지 않는다. 안정화에서 판 메시·벽 fix를 한 번 만들고, 압축·서보·R-a·언로딩 동안 그 신원과 접촉 이력을 보존한다. 분리의 두 유효 무접촉 창이 확인된 뒤에만 제거·자유 표면 단계로 간다.

단계별 gamma와 중력을 분리해 기록한다. 준비 감쇠를 압축 감쇠로 암묵적으로 넘기지 않는다. 명목 목표는 정적 300 MPa지만, 첫 힘 도달·낮은 KE 하나·생산기 단계 이름은 정적 자격이 아니다. 실제 연속 창의 압력·병진/회전 KE·힘 수지·저항/관성 기여·보존을 함께 확인해야 한다. R-a는 판을 고정한 별도 재확인이며 그 **끝**을 S0로 넘긴다. 단계 예산 소진·관측 결손·불충족을 완료로 바꾸지 않는다.

`scripts/make_dem_gen2_decks.py`는 비활성 7단계 덱 묶음 후보, `scripts/dem_gen2_qualification.py`는 순수 합성 기하/MC coverage·이산 제어·정적 창 guard다. 출력은 실행 플래그로 우회할 수 없는 입구 HOLD와 각 단계에서 정지하는 필수 gate include stub를 갖는다. 일반 PASS 문자열만으로 활성화하지 않는다. 실제 관측값을 덱의 단계 전이와 연결하는 adapter 및 P2 ULPR serializer는 **UNIMPLEMENTED**, 실제 바이너리 문법·이력/복원 자격은 **NOT_RUN**이다. 완성된 실행용 생산 파이프라인이 아니다.

생산자가 덱 골격과 인계 계약을 만들 수 있다는 사실과 실제 LIGGGHTS 빌드가 그 덱의 문법·판 이력·시간·복원을 만족한다는 사실은 별개다. 구현 결과의 현재 범위는 해당 코드 diff와 시험 영수증을 따른다. 이 문서는 실제 판 힘·서보/R-a 궤적·S0·침대·새 E*를 생성하거나 관측했다고 기록하지 않는다.

## T5/T11 문안

- T5: 정확 union/고정 ID의 sphere 연산자와 전체·안쪽 영역을 구분한다. 두 구·세 구·벽 절단 구의 해석해, 수렴/편향, coverage·반복·seed·실패확률·다중 사례 및 결손 처리의 사전 정의가 필요하다. 실제 표본 수·수치 문턱은 null이다. 단일 MC 1σ를 결정적 합격선으로 쓰지 않는다.
- T11: 양의 정상 제어 예와 강성·응답 지연·포화·부호·주기 경계의 불안정/비수렴 예를 함께 둔다. k_p=30을 보편 자격값으로 이식하지 않는다. 실제 K·지연·주기·예산·guard 범위는 null이다. 합성 고리 검사는 실제 서보/R-a/T12 통과가 아니다.
- DEMP-01/02: `demp01_demp02_handling.md`에 감쇠 수지와 보존·판 통과의 거부 조건을 적는다. 국소 guard 개선을 원 결함의 물리적 종결로 기록하지 않는다. 공유 원장 변경은 없다.

## 같은 정적 압력의 입경 비교

사용자가 요청한 50 kg 및 0.7/1 µm 비교를 gen2 안에 둔다. 두 입경 팔은 같은 **실제 정적 압력과 관측 단계**에서 비교해야 한다. 50 kg의 하중 표기 의미·면적·힘 환산이 확인되지 않았으므로 이를 300 MPa와 동치라고 쓰지 않는다. 면적·하중 정의·시간·표본·대응 seed·측정 상태·실험 불확실성은 아직 null이다. 입경을 바꾸면 N·표면적·해상도·접촉/벽 영향이 달라지므로 같은 입자 수만으로 공정한 비교를 선언하지 않는다.

사용자가 언급한 “0.7 µm 93.4% · 1 µm 65%”의 대응은 사용자 인용 그대로 보존한다. 원 관측량·분모·하중/단계·원자료를 이번에 독립 확인한 것은 아니므로 측정행·보정 표적·합격선으로 사용하지 않는다. 새 원값을 열람하거나 두 수치의 차이를 재계산하지 않았다.

## 현재 구현과 아직 없는 연결

생산기 후보는 1–3상(SE/AM_PC/AM_SC)의 명시적 질량분율 입력, 물성 행렬, 최대 반경 기준 배치, 정수 물리 시간, 단계별 감쇠, 같은 판 장치와 유한 예산의 덱 골격을 만든다. 합성 레시피·접촉 상수는 실제 레시피나 등록값이 아니다. 순수 함수의 창/재고 guard는 입출력 의미를 시험하는 도구이며 실시간 관측기를 대신하지 않는다.

현재 없는 것은 실제 창의 완전성·힘/토크 수지와 덱 전이의 연결, 정확한 경계 atom/pair/wall/mesh/state 직렬화, P2→ULPR 인계, 실제 h0에 따른 A/B 언로딩·선택 관문, 두 유효 무접촉 창 및 이후 자유표면의 실제 관측·판정이다. 생성 파일의 gate는 모두 정지한다. 입구 정지문 하나를 지우거나 합성 guard의 문자열을 복사해도 이 연결이 구현되지 않는다. 기존 P1 코드/입력은 고치지 않았다.

재현은 `verify_preparation.py`에 고정 snapshot과 새로운 출력 폴더를 주는 로컬 합성 검증만이다. 이 검증기는 외부 프로세스·네트워크 호출을 막고 새 네 소스의 해시 및 시험 로그를 기록한다. 실제 과학 코드의 전체 gate, Rint 시험, LIGGGHTS/MPI/Slurm은 호출하지 않는다. 최종 수와 중간 실패 구분은 `verification_summary.json`을 따른다.

## 아직 필요한 사실

기존 T12 준비 문서의 P1 소비자 제약과 P2 갭을 유지한다. 물성/단위·h0 환산·물리 시간·정수 step·이력/복원·dt/2·재개·외부 재확인·Q7–Q9 실제 측정 상태를 이 초안의 존재로 채우지 않는다. `preregistration_draft.json`의 null은 없거나 확정되지 않은 사실이며 승인 거부를 뜻하지 않는다. 승인된 오프라인 구현·합성 시험은 계속할 수 있다.

실제 자료행·결과·등록된 수치·실험 자격을 추가하지 않았다. Rint 관련 구현·시험·리뷰 폴더, 원본 입력, 기존 봉인과 공유 원장을 수정하지 않는다. 별도 독립 검토는 `review_request.md`의 소스·모의 경계에 한정한다.
