# Phase 1c — Lin 의 해석적 null 방향을 우리 좌표에서 수치 검증

> **수치의 정본은 `results/phase1c/` 의 CSV 다.** 이 문서에 적힌 값은 사본이고,
> 재현은 `python3 phase1c_null_direction.py` 다 (입력은 읽기 전용, ~30초).
>
> 이 분석은 **RUN_SCOPE 를 건드리지 않는다** — degradation-degeneracy 의
> `results/grid_curves_v4/curves.parquet` 를 읽기만 했으므로 게이트 리뷰 대상
> code identity 와 봉인 산출물은 움직이지 않았다.

실행 2026-09-03. 입력 `grid_curves_v4/curves.parquet` (11×11×11 모드 격자,
0~0.20, 0.02 간격, noise 3층, 곡선 300점).

## 무엇을 물었나

Lin & Khoo 2024 §2.3 은 **SOC 정규화된 full-cell OCV 의 형상 자유도가 정확히
2** 이고, `(1−LLI, 1−LAM_NE, 1−LAM_PE)` 의 **스칼라배가 곡선 형상을 전혀 바꾸지
않는다**고 닫힌 형태로 적는다 (`wiki/concepts/np-lip-ocv-reparametrization.md`).
pristine 에서 미분하면 그 null 방향은 `(dLLI, dLAM_PE, dLAM_NE)` 좌표에서
**정확히 `(1,1,1)/√3`** 이다.

우리 위키는 그 방향을 **인쇄만 하고 한 번도 확인하지 않았다.** 그리고 우리
곡선은 **PyBaMM DFN · 유한 전류**인데 Lin 의 정리는 **순수 열역학**이다. 그래서
두 물음이 갈린다.

| | 물음 |
|---|---|
| **A** | 그 방향이 우리 격자에서도 실제로 가장 평평한 방향인가 |
| **B** | 평평하다면 **얼마나** — 잡음과 비교해서 |

**B 가 판정을 정한다.** "구조적으로 불가" 와 "우리 잡음에서 불가" 는 다른
문장이고, 방어할 수 있는 것은 후자뿐이다.

절차는 Schaeffer 2024 에서 가져왔다 (`wiki/concepts/fitting-degeneracy.md` 의
「그 방향을 그리는 법」 2단계) — `JᵀJ` 를 고유분해해 최소 고유벡터를 본다.
**Schaeffer 는 이 그림을 959차원에서 시도했다 포기했다.** 우리는 3차원이고
Lin 이 답을 닫힌 형태로 줬으므로 비교 대상이 있다.

## 결과 1 — 총용량은 Lin 예측 그대로다

null ray(`LLI = LAM_PE = LAM_NE = x`)의 11개 격자점이 전부 있었다.

| x | q (mAh) | q/q₀ | 예측 `1−x` | 상대오차 |
|---|---|---|---|---|
| 0.00 | 5621.07 | 1.00000 | 1.00000 | 0.000 % |
| 0.10 | 5054.16 | 0.89915 | 0.90000 | −0.095 % |
| 0.20 | 4486.97 | 0.79824 | 0.80000 | **−0.220 %** |

**상대오차가 최대 0.22 % 이고 부호가 한쪽이며 x 에 단조**다. 무작위 산포가
아니라 계통 보정이고, 유한 전류로 읽힌다. 즉 **Lin 예측 1 은 우리 DFN 곡선에서
사실상 성립한다.**

## 결과 2 — 곡선은 불변이 **아니다**. 그러나 깨짐이 아주 작고, 방향이 하나다

| x | max\|ΔV\| (mV) | RMS ΔV (mV) | 최대 지점 x_norm |
|---|---|---|---|
| 0.02 | 0.763 | 0.298 | 0.839 |
| 0.10 | 3.840 | 1.474 | 0.839 |
| 0.20 | **8.271** | **3.291** | 0.839 |

두 가지가 눈에 걸린다.

1. **`max|ΔV|` 가 x 에 거의 정확히 비례한다** — 기울기 **0.417 mV per 1 %p**.
   비례는 "1차항이 살아 있다" 는 뜻이고, 그 1차항의 크기가 곧 열역학 정리가
   유한 전류에서 깨지는 양이다.
2. **최대 지점이 11개 조건 전부에서 `x_norm = 0.839` 한 점**이다
   (pristine 전압 **3.2785 V**). 잡음이면 이렇게 안 된다.

`ΔV` 를 `x` 로 나눠 모양만 남기면 11개가 **상관 0.9911 이상**으로 겹친다
(x=0.20 기준, x 가 클수록 1에 수렴). 즉 **깨짐의 방향이 하나로 고정되어 있고
크기만 x 에 비례한다.** 이 고정된 프로파일이 `results/phase1c/residual_profile.csv`
에 있다 — Phase 2 가 이 모양을 그대로 겨눌 수 있다.

> **연결하지 않은 관찰**: Schaeffer 2024 의 LFP 데이터에서 nullspace 자유도가
> 가장 컸던 구간이 3.0–3.3 V 였고, 우리 잔차 봉우리가 3.2785 V 다. **화학이
> 다르므로**(LFP vs NMC811‖Gr+Si) **이것은 우연이며 증거가 아니다.** 두
> 시스템에서 같은 전압대가 문제가 되는 이유가 있는지는 별도 물음이고, 여기서는
> 좌표만 적어 둔다.

## 결과 3 — ★ Lin 의 null 방향이 우리 좌표에서 **12°** 안에서 확인된다

전방차분(스텝 0.02)으로 `J` 를 만들고 `JᵀJ` 를 고유분해했다.

```
순서: (LLI, LAM_PE, LAM_NE)
열 노름 (V/단위)     = [9.3211  8.1343  3.6352]
특이값               = [0.689263  2.786328  12.57081]
조건수 (max/min)     = 18.2

u_min                = [0.66186  0.63716  0.39492]
Lin 예측 (1,1,1)/√3  = [0.57735  0.57735  0.57735]
cos = 0.977999   →   각도 12.04°
```

**해석적으로 유도된 방향이 우리 격자의 실측 최소 감도 방향과 12° 안에서
일치한다.** 이것이 이 프로젝트에서 Lin 의 정리를 처음 수치로 확인한 것이다.

> **⚠ 2026-09-04 정정 (Phase 1h) — 이 12.04° 는 점 추정이다.**
> 동작점 8개 × 전방차분 스텝 2개를 훑으면 각이 **4.61° ~ 21.89°** 에 흩어진다.
> 같은 pristine 에서 스텝만 `0.02 → 0.04` 로 바꿔도 **12.04° → 18.62°** 다 —
> 전방차분이 수렴하지 않았고, 격자 간격이 0.02 라 **더 작은 스텝은 이 자료로
> 못 잡는다.** 아래 본문은 이 한계를 신고하지 않았다. 인용할 때는
> **"이 측정의 분해능 안에서 Lin 의 방향과 같다"** 로 쓴다.
> 정본 `mode-observability/results/phase1h/sweep.csv` · `docs/PHASE1H_NOTES.md`.

12° 의 틈도 그냥 오차가 아니다. `u_min` 은 `(1,1,1)` 에서 **LAM_NE 쪽으로
기울어져 있다** (0.395 vs 0.577). 두 가지가 함께 작용한 것으로 읽힌다 —
Lin 의 정리는 열역학이고 우리 곡선은 유한 전류다(결과 2 의 0.417 mV/%p 가 그
크기), 그리고 우리 셀은 음극 제한이라 LAM_NE 의 개별 감도가 세 축 중 가장
작다(열 노름 3.64 vs 9.32·8.13). **어느 쪽이 얼마인지는 이 분석으로 갈리지
않는다** — 가르려면 순수 OCV(무전류) 곡선으로 같은 계산을 해야 하고, 그것이
Phase 1c 의 다음 단계다.

## 결과 4 — 판정: **구조적 축퇴가 아니라 잡음 제한 축퇴다**

조건수가 **18.2** 다. 선형대수 의미로 이것은 **나쁜 조건수가 아니다** — 진짜
null 이면 무한이고, 흔히 "ill-conditioned" 라 부르는 것은 10³ 이상이다.
그러므로 **이 방향은 "평평" 하지만 "0" 은 아니다.**

판정을 정하는 것은 잡음과의 대조다. 우리 격자의 잡음층은 실측 σ **1.002 mV**
(`noise=0.001`)와 **5.006 mV**(`noise=0.005`)다.

| | σ = 1 mV | σ = 5 mV |
|---|---|---|
| x = 0.02 ~ 0.06 | **묻힌다** | **묻힌다** |
| x = 0.08 | 1.1σ | 묻힌다 |
| x = 0.10 | 1.5σ | 묻힌다 |
| x = 0.20 | 3.3σ | **묻힌다** |

**σ = 5 mV 에서는 null ray 전체가 x = 20 % 까지 잡음에 묻힌다.**
σ = 1 mV 에서도 x ≤ 6 % 는 묻히고, x = 10 % 가 겨우 1.5σ 다.

그래서 지금 방어할 수 있는 문장은 이것이다:

> **세 모드가 같은 비율로 진행하는 방향은 우리 DFN 곡선에서 구조적으로
> 사라지지는 않는다 (조건수 18.2, 0.417 mV/%p 의 1차 신호가 남는다). 그러나
> 그 신호는 5 mV 잡음 아래에서 x = 20 % 까지 관측 불가능하고, 1 mV 에서도
> x ≲ 6 % 는 관측 불가능하다.**

## 이것이 22p 에 대해 말하는 것과 말하지 않는 것

**말하는 것.** 22p 삼중항(LAM_PE ≈ LAM_NE ≈ 13 %, LLI ≈ 17 %)은 이 null ray
바로 옆이다 (`wiki/questions/22p-physics-or-degeneracy.md` 의 좌표 환산:
`r_N/P` 가 pristine 에서 안 움직이고 `z₀⁺` 만 4.6 % 줄었다). x ≈ 13~17 %
구간이면 위 표에서 **σ = 5 mV 에서 묻히고 σ = 1 mV 에서 2σ 내외**다. 즉
**측정 잡음이 그 판정을 직접 지배한다.**

**말하지 않는 것.** 이건 **합성 격자**의 국소(pristine 근방) 분석이다.
(a) 22p 동작점에서 `J` 를 다시 잡으면 방향이 회전할 수 있다 — 국소 분석의
한계이고 Lin 자신이 세 곳에서 명시한 것과 같은 한계다. (b) 실제 셀의 잡음이
1 mV 인지 5 mV 인지 이 분석은 모른다. (c) 모델 오차(SEI·저항 분포)는 여기 없다.
(d) **`degradation-degeneracy` 의 복원 실패율과 이 값을 섞어 인용하면 안 된다** —
그쪽은 추정기를 실제로 돌린 결과이고 이쪽은 문제의 국소 기하다.
