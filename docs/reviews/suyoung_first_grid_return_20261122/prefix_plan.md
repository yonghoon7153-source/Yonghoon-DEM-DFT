# 첫 초과 부근 아래판 관측 · 개발 진단

## 질문과 선택한 구간

입자 지름당 8셀과 16셀에서 아래판 압력이 다르다. 첫 초과 부근에 아래판 경계가 한 걸음에 멈추는 **하향 운동량**을, 그 경계에서 멈춘 질량과 질량가중 평균 하향속도로 나눠 관측한다. 블록은 전체 가압 곡선을 판독한 뒤 설계한 사후 진단이다. 관측 범위는 F8의 첫 270걸음, F16의 첫 540걸음이다. 각 팔의 물리 코드와 배치·시간 간격을 완결 핀 `99938d3bd4cb1cbba0e1377be2ff9dac9b228d2f`에 결속한다.

1. 한 걸음에서 아래판 속도 제약은 입자 간 접촉 투영 직전·직후에 한 번씩 적용된다. 각 호출에서 실제 아래판 조건에 걸린 항목 중 양의 질량을 갖는 항목을 센다. 동일 격자 노드에 여러 입자의 항목이 있을 수 있다. 질량 합 *M*과 아래판이 멈춘 하향 운동량 *J*를 구한다. *M* > 0일 때 평균 하향속도는 *J* / *M*이다. *M* = 0이면 평균은 결측이고 운동량은 0이다.
2. 압력 단위에서 두 성분은 각각 10 × *J* / (Δ*t* × 판 폭) MPa이다. 두 값을 합해 원 압력을 복원하고 매 걸음의 가압 추적 바이트를 이미 완주한 팔의 앞부분과 대조한다. 격자별 시간 간격이 달라 단일 걸음의 운동량을 직접 압력 차이로 읽을 수 없다.
3. 최초 초과 표본은 F16 539걸음(판 변위 0.01208702447)이다. 그 변위에서 F8은 269·270걸음의 원 압력을 선형 보간한다. 질량과 속도 인자를 각각 보간해 곱하면 원 압력의 선형 보간값을 보장할 수 없다. 인자별 비교는 같은 변위에 원표본이 있는 F8 270·F16 540걸음에서 한다.
4. 5%의 분모는 이미 완주한 F16의 **전체 공통 변위 구간** 최대 반력 0.66369911 MPa다. 짧은 관측 구간 안에서 기준값을 재계산하지 않는다. 초기 아래판의 질량·속도·접촉 전후 성분을 알 수 있지만, 이후 최댓값의 원인이나 공간·시간 오차의 개별 몫을 이 자료 하나로 결정할 수 없다.

## 기존 관측이 제공하는 단서

순차 접촉 커널의 과거 관측에서 같은 변위 *u* = 0.01210944938에 F8·F16의 접촉 전 아래판 성분은 각각 0.04602440, 0.01169266 MPa였다. 접촉 직후 성분은 각각 1.18 × 10⁻⁹, 0 MPa였다. 이때 접촉 전 아래판에서 속도가 제한된 양의 질량 항목은 각각 82개, 91개였으나 각 집합의 총질량은 저장되지 않았다. 이 숫자의 출처는 과거 벽 관측 반환의 F8 270·F16 540걸음이다. 새 커널의 두 성분과 총질량은 새 관측에서 따로 확인한다.

## 실행과 회수

1저자 WSL CPU 1개 · 팔당 최대 300초 · 새 실행 1회 · 자동 재시도 0. 이전 F8·F16 완결 TAR 하나를 입력한다. 실행 전후 소스와 입력 신원, 짧은 두 가압 추적의 원본 보존을 확인한다. 조회·검사만 할 때는 배포 TXT의 `CHECK_ONLY`를 사용한다. 계산·판독이 실패하면 이미 작성한 부분 근거와 rc를 별도 반환 폴더로 회수한다. 결과는 개발 진단이며 U6(c) 자격과 단계 3은 HOLD다.
