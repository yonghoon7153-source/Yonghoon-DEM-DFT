## 과제 정의
- 상위: 세라믹 공정 기반 황화물계 전해질·고용량 후막 전극 친환경 제조·응용기술.
- 세부: 세라믹 catholyte 기반 전극 성능 향상을 위한 **단결정 양극재 제조 기술 개발**.
- 주관 ㈜엘앤에프 / 참여 한양대(이종원). 연차별 목표는 `00_PROJECT_OVERVIEW.md` §2.

## 1차년도 연구개발 내용 (요지)
1. **후막 바이모달 복합양극 두께·구조 분석**: 대립 다결정 + 소립 단결정 NCM 바이모달 제작.
   - 변수: fam(0.7/0.8/0.9) × P:S(3:7/5:5/7:3). 제작압 450 MPa, 펠렛 ⌀10 mm.
2. **기공도 산출** (NCM·LPSCl 진밀도 기반): fam↑ → 기공↑, 대립 비율↑ → 기공↑.
   - ⚠ 모델은 단조증가로 기술하나 실험은 bimodal dip (ISSUES #8).
3. **대립/소립 구조차 반영 모델링**: 대립=무작위 배향 1차입자 집합(grain boundary 저항→국부 Li 활용 저하),
   소립=배향 지배 Li 이동.
4. **후막 복합양극 미세구조 P2D 모델** (7종): 기준 Model 대비 면용량/fam/P:S/전도도 독립 변화.

## P2D 시뮬레이션 결과 (정성 요지)
- **면용량 4/6/8 mAh/cm²**: 용량↑ → Li⁺ 경로↑ → 두께방향 반응 불균형↑. 8에서 분리막측 반응 집중, 집전체측 NCM 이용률↓ → CC 충전 조기 종료.
- **fam 0.7/0.8/0.9**: fam↑ → 기공↑·catholyte↓ → Li⁺ path↓, 두께방향 이용률 편차↑.
- **P:S 3:7/5:5/7:3**: 대립↑ → 기공↑·경로 장거리화, GB 저항↑, 집전체측 대립 입자 반응 기여 저하.
- **σ_ion↑**: 이용률 균일화. **σ_e↓**: 집전체측 반응 집중·셀 과전압 급증 (반응분포 역전).
- **0.1C vs 0.2C**: 저율에서 두께방향 편차 완화.
- **전기화학-기계**: 후막화 → bulk측 입자 주응력↑, 대립 입자 GB debonding 심화 (4→6 mAh/cm²).

## 임피던스 디커플링 (3전극 + TLM)
- NCM | LPSCl | Li-In, Ag-Li 기준전극. 성능결정요소 3분류: (i) 계면 전하전달 (ii) Li⁺ 이동 (iii) Li 확산.
- TLM 등가회로로 R_elec / R_ion / R_int / R_i,gb 분리, cycle 전후 비교 → 열화 메커니즘.
