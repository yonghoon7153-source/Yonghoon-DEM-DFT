# ADR 0007 — 💬 comment 게시판은 Pages Function 하나 + D1 로 한다

- 상태: 채택 (2026-09-27)
- 관련: `functions/api/comments.ts`, `src/ui/comments.ts`, ADR 0004 (공유는 Cloudflare Pages), 체크리스트 #55

## 맥락

사용자: "comment 버튼도 넣어서 다른 사람들이 추가로 글 써서 넣을 수 있게 (뭐뭐 넣어줘! 같은 내용을 써달라고)".
지금까지 にほんちず 는 서버가 없는 정적 사이트였다 (ADR 0004). 다른 사람이 쓴 글은 어딘가에 남아야 한다.
권고안과 대안(사이트에 보이는 게시판 · 나만 보는 요청함 · 구글 폼)을 물었고, 사용자가 고른 것은
**사이트에 보이는 게시판**, 버튼 이름은 **💬 comment** (상단 「✎ 메모장」 옆).

## 결정

1. 서버 조각은 **Cloudflare Pages Function 하나**: `functions/api/comments.ts` → `/api/comments`.
   Pages 가 git push 때 같이 배포하고, 이 경로만 함수를 부른다 (`_routes.json` 자동, 나머지는 그대로 정적 파일).
2. 저장은 **D1** (Cloudflare 의 SQLite, 무료 한도 안). 바인딩 이름 `DB`. 표는 첫 요청 때 스스로 만든다.
3. **로그인 없음.** 이름 · 県 은 안 써도 된다. 글 400자, 이름 20자.
4. 막는 것 — 사람 손이 안 가게:
   - 보이지 않는 칸(`website`)을 채우면 봇으로 보고 "고마워요" 만 답하고 버림.
   - 한 사람 10분에 5개, 전체 하루 300개.
   - 제어 문자 · 폭 없는 문자 · 방향 표시 문자는 지운다 (글을 숨기거나 뒤집는 데 쓰임).
   - 화면에는 늘 글자로만 그린다 (HTML 로 해석하지 않음).
5. **IP 는 저장하지 않는다.** 도배 막기용으로 IP + 비밀값의 해시 앞 24자만 남기고, 목록에는 내보내지 않는다.
6. 지우기는 사이트 주인만: 비밀 `ADMIN_KEY` (Cloudflare 에만 있음). 게시판 맨 아래 「관리」 에 넣으면 글마다 🗑.
   비밀번호는 페이지를 연 동안만 기억한다 (새로고침하면 끝 — 9차 요청대로 아무것도 저장하지 않음).
7. D1 이 아직 연결되지 않았으면 함수가 `not-configured` 로 답하고, 게시판은 「여는 중이에요」 를 보여 주며
   보내기를 막는다 — 반쯤 연결된 채로 배포돼도 깨지지 않는다.

## 결과

- ADR 0004 의 "서버도 터널도 필요 없다" 에서 **함수 하나** 가 예외가 된다. 터널 · 따로 도는 서버는 여전히 없다.
- 사용자가 대시보드에서 한 번 할 일: D1 만들기 → Pages 프로젝트에 바인딩 `DB` → 비밀 `ADMIN_KEY` → 다시 배포
  (`nihon share` 가 순서를 보여 준다).
- 검증: `tsc -p functions` (`nihon check` 안), `wrangler pages functions build` 로 Pages 와 같은 컴파일,
  함수 단위 시험은 node:sqlite 로 만든 D1 모양 가짜 DB 에서 실제 SQL 로.

## 덧붙임 (2026-09-27, 11차 요청)

버튼 이름을 사용자 말대로 **💬 コメント** (가타카나) 로 바꿨다 — 게시판 제목도 같이. 코드의 id 와 주소(`#comment-btn`, `/api/comments`)는 그대로.
