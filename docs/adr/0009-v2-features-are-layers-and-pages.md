# ADR 0009 — v2 의 새 기능은 켜고 끄는 레이어나 따로 페이지로 둔다 (첫 화면은 그대로)

- 상태: 채택 (2026-09-28)
- 관련: ADR 0008 (v2 방향), `data/transit.json`, `data/festivals.json`, `src/map/layers.ts`, `src/ui/fx.ts`, 체크리스트 #69 · #70 · #72 · #73 · #74

## 맥락

v2 는 「여행지를 고르는 지도」다 (ADR 0008). 사용자: "v2 느낌으로 너무 혼잡하지 않게 기능들 추가해보자."
첫 묶음으로 고른 것은 ✈🚄 가는 법 레이어와 🎆 축제 달력. 둘 다 지도 첫 화면에 늘 보이면 도시 · 다리 · 마스코트와 겹쳐 혼잡해진다.

## 결정

1. **새 기능은 첫 화면을 바꾸지 않는다.** 지도 위 정보는 오른쪽 아래 레이어 버튼(기본 꺼짐)으로, 목록 정보는 상단 버튼의 팝업 페이지로.
2. **🚄 가는 법 레이어** (`data/transit.json`, 기본 꺼짐):
   - ✈ 공항 41곳 — 좌표는 OurAirports(퍼블릭 도메인). `hub`(국제 관문 7곳: 新千歳 · 成田 · 羽田 · 中部 · 関西 · 福岡 · 那覇)만
     전국 화면에서도 보이고, 나머지는 확대하거나 그 県을 열면.
   - 🚄 신칸센 11개 노선 — 역을 **직선으로 이은 대략선**이다 (노선 모양이 아님, 파일에 적어 둠). 山形 · 秋田(미니)는 점선,
     札幌 연장(공사 중)은 촘촘한 점선. `major` 역(약 40곳)만 확대하면 이름이 붙는다. 선 색은 JR 계열색에 가깝게.
   - 県 패널의 県庁所在地 밑에 「가는 법」 한 줄: 그 県의 공항과 이름 있는 신칸센 역. 데이터에서 그대로 나온다.
   - 이름은 다른 라벨과 같은 충돌 회피(`placeName`)를 쓰므로 県 이름을 덮지 않는다.
   - **노선 모드** (사용자: "노선도 산맥처럼", "on/off"): 버튼을 누르면 산맥 모드와 같은 모양으로 켜진다 — 지도에 ①…⑪ 번호,
     패널에 노선 목록(누르면 그 노선으로 확대 · 강조 + 주요 역), 「이름 가리기」 퀴즈, 지방별 공항 목록(누르면 그 県). 다시 누르면 꺼진다.
     주소 `#shinkansen`. 산맥 모드의 패널 부품(range-*)을 파랑으로 다시 써서 새 스타일이 거의 없다.
3. **🎆 축제 달력**은 따로 페이지 (`data/festivals.json`, 상단 「🎆 축제」 버튼, 주소 `#matsuri`):
   - 1월부터 12월까지 달마다 축제 · 시즌 38개. 내 마인드맵 · 보충에 칸이 있는 축제는 `box`(칸 이름)로 그 칸과 이어져
     출처 표시(내 마인드맵 / 보충)가 붙고, 달력을 채우려고 Claude 가 더한 것은 「Claude」. 날짜는 `MM-DD`, 해마다 바뀌는 것은 `approx`.
     해를 넘기는 것(夜神楽 11월 ~ 2월)은 시작 달에. 위의 달 띠에서 지금 달이 표시되고, 누르면 그 달로 내려간다.
   - 줄을 누르면 달력이 닫히고 지도가 그 県으로 날아간 뒤(0.8초) **축제에 어울리는 효과**가 県 위에서 터진다
     (사용자: "누르면 해당 축제랑 어울리는 느낌의 임팩트"). 효과는 데이터의 `fx` 일곱 가지로 고정 — 불꽃 · 눈 · 벚꽃잎 · 단풍잎 ·
     등롱 불빛 · 북 · 리본 (`src/ui/fx.ts`) — DOM + CSS 애니메이션만 써서 몇 초 뒤 스스로 사라진다. 도는 동안 무대 전체가 그 축제의
     빛을 살짝 띤다(불꽃은 밤, 등롱은 노을, 눈은 푸른 기, 벚꽃은 분홍). `prefers-reduced-motion` 이면 거의 보이지 않는다.
   - 효과 층(`#fx`)은 지도 · 스티커 위, 패널 · 모달 아래(z 19)이고 클릭을 막지 않는다. 그림 파일 없음 — 저작권 걱정이 없다.

## 결과

- 레이어 버튼이 넷(도시 · 다리 · 가는 법 · 산맥). 폰에서도 한 줄에 들어간다. 상단 버튼은 셋(🎆 축제 · 메모장 · コメント), 폰은 아이콘만.
- 지도 데이터 파일이 하나 더(`transit.json`, 스키마 · 검사기 포함). 역 좌표가 대략값이라 "정확한 노선도"로 쓰지 않는다 — README 에 적음.
