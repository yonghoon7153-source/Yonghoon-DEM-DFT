## 1. 사실 (리포 · 1저자 전달)

- **실험 앵커** (DC 분극 10-16 · `docs/data/sdcp_dc_polarization_20261016/README.md`): SBE 1.63 · DBE 4.68 mS/cm (비 2.86) · R = 7.016 · 2.178 Ω · 두께 90 · 80 µm (상태 미확인) · 지름 10 mm (추정) · 2 전극 · n = 1 씩 · **지그 저항 빼지 않음**.
- **조성** (1저자 11-24 전달 · 원고 methods 대조 = 미확인): SBE = PTFE 1 wt% · DBE = PTFE 0.5 + SDCP 0.5 wt% · 둘 다 VGCF 같음.
- **원고 그림 원본 넷 (위에서 본 면)** [Claude 판독 · 추정 · 배율 · 위치 · 어느 시료의 몇 번째 자리인지 미확인]: SBE SEM = 표면을 가로지르는 **균열 하나** · SBE F 지도 = F 가 대각선 **띠로 몰림** / DBE SEM = 더 촘촘 · 균열 안 보임 · DBE F 지도 = 고르게 흩어짐.  원고 자체 해석 = SDCP 가 PTFE 뭉침을 억제 (`docs/sdcp_manuscript_anchors.md` L85).
- **예전 판 단면 그림** (원본 없음): SBE 쪽 NCM 둘레 · 사이에 어두운 선 (틈 또는 균열로 보임 · Claude 판독 · 추정).
- **모형**: 두 전극 = 같은 압밀 침대 (DBE = SDCP 평균 1 µm 재압밀 · SE · VGCF · PTFE 점 수 같음) · PTFE = 중심선 섬유 한 셀 절연 (`CL-60` · 표면 코팅 없음 `CL-49` · 실제 PTFE 부피의 0.40–0.41 만 셀) · SDCP = 분산 구 · 재료 σ 만 흔든 closure 공동 스윕 = DBE > SBE 방향은 강건하나 비는 생산 꼴 ≈1.34 · σ_SDCP ×100 은 이득 +3.5 % (포화) (`CL-70`).
- **Rint ② (봉인 · 진행 중)**: 축 = P (PTFE 가 덮은 접점을 끊는가) × c (SDCP 가 접점을 잇는가) × R_j (탄소 접합 저항 · 보정값 · 낮은 끝 · 높은 끝) · 보정 = SBE 1.63 한 점 · DBE 4.68 = holdout (봉인본 = 봉인 가지 claude/rint2-seal-20261118 의 등록 R 봉인본) · 같은 값으로 모형판 가르는 실험 팔 ① · ② 를 따로 등록했다 (결과 0 건 · `docs/reviews/rint2_middle_arm_ptfe05_sdcp0_registration_20261124.md` — 이것도 봐 주세요).
