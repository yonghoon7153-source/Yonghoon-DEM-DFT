## 4. 한정

- 한 점이다 (SBE · arm 0 · R_j 1e6 Ω · P0 · c 0). 다른 법칙 · c · R_j · 침대 (DBE) · origin 에서 필요한 반복 수는 이 한 점으로 모른다.
- 이 값을 쓰는 곳 = 계획의 전처리 · maxiter · 시간 상한 숫자뿐이다 (원장 §2 "채택 불가") — R 판정 · 보정 · 예측 값으로 쓰지 않는다.
- 반복당 초는 위 한계다 (ⓓ 증서의 CPU 계산 포함). 주 풀이와 이어 풀기의 시간을 묶음으로는 가르지 못한다. 같은 GPU 를 다른 프로세스가 함께 썼다 — 시간에 미친 영향은 미확인.
- 탄소 접합 준비 4,040 s 는 팔 하나의 값이다. 같은 침대 · 같은 격자의 다른 팔에서 다시 드는지 (재사용 여부) 는 이 묶음으로 모른다.
- 수렴 판정 = 판독기가 팔 JSON 의 닫힌 칸 목록에서 읽은 증서 깃발이다. 증서가 보증하는 범위는 증서 설계 문서의 한정 그대로다 (이 기록이 넓히지 않는다).
- 가린 줄 5 개는 판독기가 수를 `#` 로 가린 꼴로만 있다 (`runner_filtered.log` · 러너의 진단 런 안내 줄).
