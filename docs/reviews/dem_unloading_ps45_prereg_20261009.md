## 1. 질문 · 범위

### 1-1. 질문 (Codex Q4 행 "질문" 그대로 한정)

**현재 이완 체크포인트 (PHASE 4 · 판 고정 · 21 단면 σ_zz 158–175 MPa) 에서 판 하중을 정해진 측정 압력 P_meas 까지 제거했을 때, 모델 안 축방향 회복 ρ 가 다섯 조성에서 어떻게 다른가 (크기 · 순위).**

- 추정량 = 침대 c 마다 ρ_c = (h_c(P_meas) − h_c,0) / h_c,0 × 100 % (§6-1).  주 목적은 이 다섯 값 · 순위 자체다 (모델 안 · 실험과 독립).

### 7-2. 분해능 · 순위

- δ_num = 7:3 개발의 수치 차 (§4-4) · r_int = Δz_B / h₀ (≈ 0.045 %) · **띠 b = 2 δ_num + r_int**.  δ_num 은 7:3 에서 잰 것을 다섯 침대에 쓴다 (한정 · §9-5).
- 회복 미분해: ρ_c < 3 b → 그 침대 "회복이 수치 분해능보다 작다" → 미식별.
- 순위: 값 순 이웃 짝의 차 > b 인 짝만 "구분됨" · 하나라도 b 이하면 다섯 자리 순위 = 불확실 → 구분된 부분 순서만 보고.

### 7-3. 순위상관 — Codex 권고 문안 (그대로)

> 조성별 회복량과 사전 고정한 AM–AM 기여율의 순위상관은 탐색적 일관성 지표로 보고한다. 이 지표만으로 AM 지배 기전 또는 실험–DEM 차이의 주원인을 판정하지 않는다. 회복량이 수치 분해능보다 작거나 순위가 불확실하면 미식별로 보고한다.

- 사전 고정 기술자 = **D(S0)** (§3-1 · 런 전 커밋) · D(s_d) 병기.
- 숫자 경고 (Codex): n = 5 · 동률 없는 120 순열에서 ρ_S ≥ 0.8 은 단측 8/120 = 0.0667 · \|ρ_S\| ≥ 0.8 은 16/120 = 0.1333 —
  0.8 (또는 1.0) 을 넘어도 '지지 · 확인' 판정을 주지 않는다 · 이 수를 p 값으로 쓰지 않는다 (사후 선택 자료).
- 같은 방식 (기술 · 판정 아님) 으로 함께 적는 순서 (값은 §2-1 · 결과 전 고정): DEM ε_union · DEM 두께 · 절대 AM–AM σ_zz 기여 · LW AM 몫 · 실험 공극 (선택 자료 · §7-5).
- 미리 적어 두는 대조점 (결과 전 · 판정 아님 · n = 5 · 한 시드):
  - AM–AM 기여율 순서 0:10 > 10:0 > 3:7 > 5:5 > 7:3 ↔ DEM ε_union 순서 0:10 > 3:7 > 5:5 > 10:0 > 7:3 — **10:0 의 자리만** 다르다 ⇒ ρ(10:0) 이 ρ(3:7) · ρ(5:5) 보다 b 밖으로 큰지가 둘을 가르는 자리.
  - 절대 AM–AM 기여 · LW AM 몫 순서는 맨 앞이 10:0 (0:10 과 자리가 바뀐다) ⇒ ρ(10:0) ↔ ρ(0:10) 이 그 둘과 기여율을 가르는 자리.
  - 7:3 은 모든 기술자에서 맨 끝이다 → 7:3 최소만으로는 어느 기술자도 가르지 못한다.

### 7-4. 하지 않는 주장

- "공극 차이의 큰 몫 = 되튐" · "AM 골격 (전체) 하중 몫" · "골격 강성 · 유효 영률" · ρ 와 "필요 회복" 환산값의 대조 · 비율 (`RB-01` · `RB-02`).
- 인과 · 기전 단정 ("AM–AM 접촉이 회복을 만든다") · 실험 검증 · 앵커.
- ρ 절대값 인용은 한정어와 함께만: *"연화 SE (E 1.35 GPa) 모델 안 값 — 실제 회복보다 클 수 있다 · 측방 고정 (주기 경계) · 출발 = 이완 상태"*.

### 7-5. 실험 순위와의 비교 (1저자 10-09 새 사실 반영)

- 실험 두께는 경향이 맞는 것만 추린 3 개의 평균이다 (추린 3 개 안 흩어짐 ≈ 0.5–1 µm · 실제 재현성 미상).  ⇒ **실험 순위는 선택된 자료**로 다룬다:
  DEM ρ 순위 ↔ 실험 순위 비교는 **탐색**이고, 선택된 실험 경향과의 일치는 **독립 확인이 아니다** (불일치도 반증이 아니다).
- 이 비교를 적을 때 반드시 함께 쓴다: *"실험 순위는 경향이 맞는 측정만 추린 평균의 순위 — 원 측정 분포 미반영 (§10 Q9)"*.
- 추린 흩어짐 (0.5–1 µm) 만으로도 가장 가까운 이웃 (10:0 138 ↔ 3:7 137 µm · 차 1 µm) 의 구분은 불확실하다 — 실험 쪽 "다섯 자리 순위" 를 쓰지 않는다.
- DEM ρ 순위 · 크기는 그 자체로 모델 안 결과다 (§1-1) — 실험 자료의 상태와 무관하게 §7-1 – §7-3 규칙으로 보고한다.
- ⚠ AM–AM 기여율 순위와 실험 공극 순위가 같으므로 "ρ ↔ D(s_d)" 와 "ρ ↔ 실험" 의 순위상관은 숫자가 같다 — 둘을 두 개의 증거로 세지 않는다.

### 7-6. 쓸 수 있는 문장 틀 (결과에 따라 채움)

- 구분됨: *"판 고정 이완 상태에서 측정 압력 P_meas 까지 판을 들어 올린 DEM (연화 SE · 주기 측방 경계) 의 축방향 회복은 조성별 x–y % 였고, 그 순위와 AM–AM 접촉 수직응력 기여율 (사전 고정) 순위의 Spearman ρ = … (n = 5 · 탐색적 일관성 지표) 였다. 이 지표만으로 AM 지배 기전이나 실험–DEM 공극 차이의 원인을 판정하지 않는다."*
- 미식별: *"… 회복량 (또는 조성 간 차) 이 수치 분해능 (b = … %p) 안이라 순위를 식별하지 못했다."*

## 9. 한정 (보고 · 그림에 함께 적는다)

1. **측방 고정** — `boundary p p f` (주기 50 × 50 µm) 는 측방 크기가 고정된 모델이다.  탈형 뒤 측방 팽창까지 포함한 실험 회복과 같은 시험이 아니다 · 다이 안 측정과도 다이 벽 마찰 · 다이 탄성이 없다.
2. **시간** — 수치 감쇠 (viscous 1e-5 · 접촉 감쇠 e 0.3) 로 안정되는 시간은 실제 수분 · 수시간의 점탄성 회복 시간이 아니다 · step 은 축척 덱 시간 (압밀 README §5) · DEM 에는 시간 의존 회복이 없다.
3. **연화 E_SE 1.35 GPa** (재료 영률 22–24 GPa · CLAUDE.md 의 18 배 연화) — 같은 응력에서 겹침이 커서 탄성 회복 크기가 실제보다 클 수 있다 (방향 추정) · SE 만 연화한 강성비 (덱 ≈ 104 : 1 ↔ 실제 ≈ 7 : 1) 가
   조성 간 회복 **순위**를 보존한다는 원리는 없다 (Codex Q2 · `MV-07`) → 순위도 모델 안 값.
4. **소스 판독 (내 판독 · Codex Q6 확인)** — `normal_model_hooke_hysteresis.h` (3d5c00f · 리포 사본 sha256 `fd8c4c71…`): δ_max ≥ δ_lim = k2Max/(k2Max − kn) · φF · 2 r_eff (163 행) 이면
   하중 · 제하 모두 F = k2Max (δ − δ_lim) + kn δ_lim (169 행) — 영구 겹침 δ_lim (1 − kn/k2Max) 의 선형 스프링 · 비포화면 Codex 식 F = k2 (δ − δ_max) + kn δ_max (180–181 행) ·
   점착 가지 (kc = kn × 1e5–1e6 · 151 행) 는 δ → 0 바로 앞에서만 · 분리하면 δ_max = 0 (261 행).  덱 φF · 반경으로 δ_lim ≈ SE–SE 0.003 · AM_S–SE 0.012 · AM_P–SE 0.0135 ·
   판–SE 0.015 · AM_S–AM_S 0.30 · AM_P–AM_S 0.42 · AM_P–AM_P 0.68 µm (내 산술).  ⇒ SE 가 낀 접촉은 대부분 포화 = 제하 때 겹침 대부분을 돌려주는 스프링 (k2Max = 3 · 5 kn) ·

   한정 3 과 같은 뜻 · 실제 LPSCl 가역 변형의 크기로 읽지 않는다.
5. **δ_num 은 7:3 에서만 잰다** — 다른 조성의 수치 오차가 같은 크기라는 가정.
