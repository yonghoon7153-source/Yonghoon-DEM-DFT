### 5-1. 고친 뒤 남는 한정 (이 판에서 더한 것)

- 수렴 조건은 한 항 꼴을 가정한다.  두 항이 서로 지우는 꼴 (예: 4/n − 72/n²) 은 고친 규칙도 다름으로 잘못 보낼 수 있다 (부록 D-4′).  결론 문장에 "세 단 추정 · 한 항 꼴 가정" 을 붙인다.
- 상자 효과의 1 %p · 값의 뒤집힘 √1.5 · 탐색 폭 2.2 %p · 누적 역행 0.5 %p 는 같은 크기의 다른 자격에 빗댄 [제안] 이다.  실제 상자 크기 효과의 크기는 모른다.
- 노드 다물체 풀이의 꼴 (쌍별 충격량의 순서 · 반복) 은 구현 전에 정한다.  1–2 주는 [추정] 이다.
- D2 의 두께 비는 진밀도에서 자유롭지만 다이 벽 마찰 · 연속 가압 속도 · 고체 탄성의 차에서는 자유롭지 않다.  등급은 보고용이고 갈림에 쓰지 않는다.
- 1.64 가 우리 랩 로트에서 어디서 왔는지는 카드로 정하지 못했다 [미확인] (§5 Q9 · §6-34).
- BE24 · OH20 의 영문 제목은 카드에 없다 [미확인].
- 리포 검사기는 리포에서 돌리지 않았다 (지시대로 리포 안에서 명령을 시작하지 않음).  철회값은 `claims.json` 의 quotation_ban 패턴 42 개를 메모에 직접 대 보아 걸린 것이 없음만 확인했다.

### 6-1. 고친 뒤 남는 한정 (이 판에서 더한 것)

- 팔 규칙은 팔마다 오차가 한 항 꼴 (A) 이거나 잡음 (B) 일 때만 극한을 담는다.  한 팔 안에서 서로 지우는 두 항 (진폭을 키우면 거짓 다름) · 빠른 항 아래 숨은 느린 항 (거짓 다름 · 아래에서는 거짓 같음) · 잡음이 가린 느린 표류 (B · 거짓 다름) 는 못 막는다.  넷째 단 (36 셀) 으로도 숨은 느린 항은 못 가른다.  결론 문장에 "수치 오차 구간 (세 단 추정 · 팔마다 한 항 꼴 또는 잡음 가정) 까지" 를 붙인다 (메모 §4 단계 3 ③ · §6-21 · 35).
- 검정력 수치 (팔 0.933 · 점 0.660 · G 같음 0.083) 는 단마다 독립 정규 잡음 · τ ≫ 잡음 가정의 산술이다.  실제 셀 건너감 잡음의 크기와 상관은 모른다.  같음 (가) 은 여전히 다름 (나) 보다 닿기 어렵다.  S 와 F 에 공통인 느린 항은 ln R 에서 지워지지만 팔 규칙은 팔마다 보므로 그런 점도 중간으로 간다.
- τ 의 값은 1저자 (Q10 · 기본 τ = δ).  U6 (b) 에서 부호가 엇갈리며 τ 를 넘는 팔이 나오면 단계 3 전에 묻는다 (결과 뒤 바꾸지 않는다).
- ②′ 의 사후 미끄럼 기준은 노드 다물체 풀이의 꼴 (동시 · 순차) 이 정해져야 시점이 정해진다 (등록 항목).
- 둔감 팔이 단계 4 범위 (0.03–1.35 GPa · 실제 쌍) 에서도 W1 처럼 둔감할지는 모른다 [추정].  (4-iii) 의 두 팔 창 아래 조합에서 F-(iii) 이 예상된다는 것도 [추정] 이다.
- 낱말 검색은 같은 부류의 카드를 더 놓쳤을 수 있다 (규율 ⑤).  원문 PDF 는 열지 않았다 (카드만).  JU26 의 제목 · 권은 카드 기준이고 원문 대조는 [미확인].
