## 발견 사항 — LHS-PKG-01: 격리 실행 규율 누락

handoff §7은 `python -I`를 명시한다. 그러나 증거 README의 재생 예시 네 명령은 `python "$REVIEW_TOOLS/..."`이고, `docs/reviews/lhs214_preflight_review_evidence_20261023/tools/mutations.py` 및 `docs/reviews/lhs214_preflight_review_evidence_20261023/tools/provenance_replay.py`의 자식 실행도 `[sys.executable, '-c', ...]`다. 전자의 진입 명령과 후자의 자식 인터프리터에 `-I`(필요시 `-B`)를 추가해야 한다. 명시적인 sys.path 삽입을 사용하므로 구조상 격리 실행에 필요한 저장소 경로는 유지된다. 이 누락은 숫자·기존 반례의 거짓을 뜻하지 않으나 저장한 재생 절차가 적용 지침과 맞지 않는 실제 결함이다. 부모에게 즉시 전달했다. 수정되면 영향받은 도구 해시와 MANIFEST도 갱신해야 한다.

## 감사자의 별도 재현

`/tmp` 작업 디렉터리에서 명시 REPO_ROOT와 공백을 포함한 새 EVIDENCE_OUT을 주고 venv Python `-I -B`, BLAS 한 스레드로 번들 `pin_probe.py`를 실행했다. rc 0, 자체시험 123/123, 여섯 입력의 실패 ID가 기존 두 결과와 동일했다. 결과 위치는 `nonrint-package-audit/lhs214 replay/`이며 원 증거를 덮어쓰지 않았다. 이 한 차례 재현은 전체 게이트나 외부 독립 반박 세션이 아니다.
