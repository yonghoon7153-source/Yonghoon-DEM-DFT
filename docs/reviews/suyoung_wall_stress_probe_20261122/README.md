# 같은 응력을 주었을 때의 아래판 전달량 · 수영 2D 개발 대조

## 결과 전 질문

첫 5% 초과 양옆의 두 공통 변위에서 F8−F16 반력 차이의 약 97%는 그 걸음에 입자에서 격자로 전달된 응력 항이다. 동일한 균일 응력을 모든 물질점에 줄 때에도 두 격자의 원래 아래판 하향 노드 집합이 서로 다른 수직 반력을 받는지 확인한다. 이 대조는 기존 실행의 첫 부분만 재생한다. 가상의 균일 응력은 관측기 안에서만 쓰며 압력·접촉·재료 상태는 원 계산대로 갱신한다.

## 무엇을 저장하는가

- 원 결과 `2390d2a1e7a6663c8c8c32eb9a1cdda65aff4b06`, 물리 핀 `99938d3bd4cb1cbba0e1377be2ff9dac9b228d2f`. 입력은 운동량 반환과 그 직전 아래판 반환이다.
- 원 ID와 원 설정 ①에서 F8 270걸음, F16 540걸음까지. 실제 반력의 직접 비교점은 269/538과 270/540이다. F16 539에서 F8의 대응 원표본은 없다.
- 각 팔이 원 계산에서 선택한 같은 노드·입자장에 대해 수직 운동량에 들어가는 정상 성분(τyy)과 전단 성분(τyx)을 부호대로 따로 합산한다. 두 성분의 합으로 저장된 원 응력 항을 노드별 및 팔별로 복원한다.
- 같은 물질점 위치·부피와 원 마스크에 각각 균일한 정상 응력 또는 전단 응력을 준 가상 전달량을 읽는다. 정상 +1은 인장, −1은 압축이다. 전단 +1은 대칭 텐서이며 수직 운동량에는 yx 성분이 들어간다. +1은 풀이기의 정규화 응력 1(응력 단위 E = 10 MPa)이다. 출력은 이 규정된 장을 가했을 때의 벽 압력 MPa다. 수직 운동량의 소스는 응력 텐서의 y행이며 전단 성분은 수평 변위, 정상 성분은 수직 변위와 곱한다. 아래판 압력 단위와 응력 단위의 환산을 구분한다.
- 두 원 반환의 키와 해시, 원 압력·벽 추적·운동량과의 대조를 먼저 적용한다. 관측 수식이 재현되지 않거나 팔의 계산이 중단되면 그 반환은 불완전으로 기록한다.

## 어떻게 읽는가

두 점에서 같은 균일 기준 응력의 전달 차이가 재현되면 **실제 응력장을 같게 주어도 이 두 격자·물질점 배치·하향 마스크가 전달량에 차이를 낼 수 있음**을 보여 준다. 차이가 작으면 방향별 원 응력 기여와 공간 분포에 눈을 돌린다. 한 성분이 서로 상쇄되거나 두 지점의 경향이 갈리면 부호와 크기만 보고한다. 상쇄로 작아진 기준 응답을 분모에 두어 유효 응력을 추정하지 않는다.

가상 응력은 실제 재료에서 관측한 응력과 단위 크기가 다르다. 기준 응답과 실제 반력 차이의 몫을 원인별 백분율로 보고하지 않는다. 이론적 균일장 전달에 대한 개발 대조 한 건이며, 원 재료의 타당성, U6(c) 5% 자격, 단계 3은 별도다.
