## 1. 조건과 표본

- U와 C에서 AM/SE 표면에너지비를 0.1에서 1로 올렸다. SE–SE Bo_code 0.21244 및 벽/SE 표면에너지비 0.00256은 공통이다. 혼합 규칙에 따라 AM–AM과 AM–SE 점착이 함께 달라져 두 계면의 기여를 분리할 수 없다.
- 두 팔 모두 t₀는 1,121,184 step, bin1은 4,418,784–7,683,408 step에서 32,976 step 간격으로 저장한 동일한 100프레임이다. AM 두 종류는 134개와 708개, SE는 99,158개다. N0(367547)는 점착 0 회전 대조, E0(366423)의 1,121,000 step 균일 정착 프레임은 격자마다 기준 분산을 제공한다.
- 거시 혼합은 격자 안 조성의 분산으로, 국소 군집은 접촉으로 연결된 SE의 분율로 읽었다. 같은 프레임에서 조성이 더 고르게 분포하면서 군집에 속한 SE 비율은 비슷하게 남을 수 있다.
