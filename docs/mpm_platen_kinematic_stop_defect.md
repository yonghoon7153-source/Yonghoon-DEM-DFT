**발견 2026-08-04** (P:S 5킷 시리즈) · 진단 3각 적대리뷰(물리·코드·영향범위) · 상태: **원인 확정, 처방 확정, 구현 대기**

## 0. 한 줄

`--protocol hold` scaffold 압밀에서 플래튼이 **너무 빨리** 내려가, 정지 트리거로 쓰는 `wallP`가
재료 응력이 아니라 **플래튼 운동량**을 읽었다.  그 결과 압밀이 "300 MPa에 도달해서" 멈춘 게
아니라 **정해진 걸음 수만큼 내려간 뒤** 멈췄다.

## 1. 증상 — 무엇이 이상했나

P:S 5킷(AM_P:AM_S = 10:0 / 7:3 / 5:5 / 3:7 / 0:10, n_grid 256, hold, target 0.3 GPa)의
1차 런 원자료:

| P:S | 두께 frame0 → 최종 | 스트로크/초기두께 | **÷ 0.008** | 최종 wallP |
|---|---|---|---|---|
| 10:0 | 121.32 → 117.44 µm | 0.03198 | **4.00** | 0.0026 GPa |
| 7:3 | 118.91 → 115.10 | 0.03204 | **4.01** | 0.0148 |
| 5:5 | 118.31 → 114.52 | 0.03203 | **4.00** | 0.0058 |
| 3:7 | 119.70 → 115.87 | 0.03200 | **4.00** | 0.0133 |
| 0:10 | 122.25 → 119.31 | 0.02405 | **3.01** | 0.0037 |

플래튼 속도가 `vmax = 0.008·(WALL0−FLOOR)` **프레임당**이고 플래튼은 `wall_z ≈ WALL0`에서
출발하므로

```
스트로크 / 초기두께 = N × 0.008          (N = 하강 프레임 수)
```

실측이 **4·4·4·4·3 정수**로 떨어진다(0.2 % 이내).  응력이 정지를 정했다면 조성마다 다른
변형률에서 멈춰 정수가 나올 수 없다.  **정지를 정한 것은 프레임 수다.**

방증 셋:

1. 최종 wallP가 목표(0.3 GPa)의 1/20~1/100인데 조성별로 **5.7배** 흩어진다.  응력-정지라면
   전부 target 근처여야 한다.
2. 프레임 5에 wallP = **−0.049 GPa** (플래튼 인장) — 동적 반동 서명.
3. `[am-jam]` 로그 부재 — `--am-jam`은 opt-in이고 킷에 없다.  기하 정지도 아니었다.

## 2. 원인 — wallP는 무엇을 읽고 있었나

### 2-1. 판독 식

```python
# mpm3d_compaction.py:2095
wallf = Σ_{노드 I: k·dx > wall_z, grid_m>0}  grid_m[I] · (grid_v[I][2] − wall_vel)
```

`am_mask` 영점화(:2087-2089)가 먼저 걸리므로 **AM은 질량이 없고 SE 질량만 이 합에 들어간다.**
프레임 판독은 `wacc += wallf/(dt·area)` (substep마다, :2254) → `wallp = wacc/args.sub` (:2256).

**플래튼이 정지해 있으면**(`wall_vel = 0`) 이 값은 경계 힘/면적 = 정적 응력이다 (검증된 판독).
**플래튼이 움직이면** 그 프레임에 새로 쓸려 들어온 정지 상태 질량마다
`m·(0 − wall_vel) = +m·|v_wall|`이 적분된다 — **재료가 버틴 힘이 아니라 밀어낸 운동량**이다.

### 2-2. 정량 — 16 GPa가 어디서 나오나

킷 조건: 베드 121.3 µm = 2.232 box, `vmax = 0.008 × 2.232 = 0.01786 box/frame`,
프레임 시간 `sub·dt = 40 × 2e-4 = 8e-3` →

```
v_wall = 0.01786 / 8e-3 = 2.232 box/time
c_p    = √((λ+2µ)/ρ) = √26.2 = 5.12 box/time        (E=1.53 GPa, ν=0.49 → K=25.5, µ=0.51)
v/c_p  = 0.44                                        ← 음속의 44 %로 내려찍는 중
```

| 항 | 식 | 값 |
|---|---|---|
| 임피던스(파면 생성) | ρ·c_p·v | **11.4 GPa** |
| 램(질량 쟁기질) | ρ·v² | **5.0 GPa** |
| **합** | | **16.4 GPa** |

**실측 16.67 (7:3) / 16.24 (5:5) GPa.**  자릿수가 아니라 값이 맞는다.

이 식이 **조성 무관**인 이유도 여기서 나온다 — 판독에 SE 질량만 들어가고 상단 SE 밀도는
조성에 둔감하다.  실제로 AM 1,498개(7:3)와 2,380개(5:5) 베드가 이동 중 wallP는 2.6 %만
다르고, **정지 후**(0.0233 vs 0.0276)는 18 % 다르다.  움직일 때 읽는 값은 조성을 못 보고
멈추면 조성을 본다 — 앞엣것이 운동량, 뒤엣것이 재료 반응이라는 뜻이다.

### 2-3. 준정적 조건 위반의 크기

| | 값 | 준정적 요건 |
|---|---|---|
| 플래튼 프레임당 이동 | 0.95 µm = **z격자 4.57칸** | ≪ 1칸 |
| 프레임당 응력파 전파 | ~16칸 (sub 40 × CFL 0.4) | — |
| 베드 두께 | 579칸 | — |
| **파동 편도 시간** | **~36 프레임** | — |
| **실제 하강** | **4~6 프레임** | ≫ 편도 |

플래튼이 누른 정보가 **바닥에 도달하기 전에 압밀이 끝났다.**  wallP는 판 바로 아래 몇 칸이
받는 충격을 읽었을 뿐, 베드 전체의 저항을 본 적이 없다.

### 2-4. 코드는 이미 이 문제를 알고 있었다

`mpm3d_compaction.py`는 "이동 중 판독 불가"를 **두 곳에서 실측으로 명기**한다:

* `:2308-2313` — "mid-rise frame read −0.23 GPa on a bed really at +0.19"
* `:2496-2508` (S-1, 2026-07-29) — 판독 편향의 부호가 제어 동작과 같아 **양의 되먹임**;
  실측 −0.019 ↔ +0.206

그래서 **제하(unload) 프로브**(:2330)와 **S-1 servo 평형 판독**(:2510)은 `wall_vel = 0`으로
동결한 뒤 읽는다.  **하강 판정만 이 처리가 없었다.**  원칙은 이미 코드에 있었고 한 경로에
적용이 빠진 것이다.

## 4. 왜 지금까지 안 보였나

1. **씨앗이 정답을 인코딩한다.**  scaffold의 SE 씨앗은 `atom_2060000` — **DEM 압축이 끝난**
   상태의 좌표다.  스트로크가 구-래스터/dilate 슬랙 규모(~2 %p)라서 **운동학적 정지도
   DEM ±1 %p에 착지한다.**
2. **그 일치를 validity 증명서로 썼다.**  "DEM↔MPM |gap| ≤ 4 %p = 신뢰"라는 판정 규칙이
   결함을 통과시켰다.  결정적 반례가 P:S 1차 런 자신이다 — 운동학적 정지 확정인데
   DEM 대비 |gap| ≤ **0.7 %p**.  **hold 시대의 "DEM과 일치"는 응력 평형의 증거가 못 된다.**
3. **단발 런으로는 안 보인다.**  정수 프레임 서명은 **여러 조성을 같은 조건에서 나란히**
   놓아야 드러난다.  5점 시리즈 + 사전등록이 아니었으면 계속 숨어 있었을 결함이다.
4. **selftest 커버리지 0.**  70개 chk 전부 헬퍼 단위테스트이고, 프레임 루프의 정지 분기를
   실행하는 테스트는 하나도 없다.

## 6. 처방

### 6-1. 첫 시도가 실패한 이유 (커밋 68df3dae, 철회 대상)

scaffold 분기의 순간 비교에 **STOP_HOLD 3연속 요구**를 걸었다.  결과:

* **킷을 못 고쳤다** — 편향(16.6 GPa)이 목표의 55배로 **지속**되므로 3연속 카운트가 그냥
  채워진다.  정지 = 첫 crossing + 2 → 재실행이 4프레임에서 **6프레임**으로 늘었을 뿐.
  porosity 변화도 정확히 산수로 설명된다:
  `Δε = (1−ε)/t × (2프레임 × 0.008 × 118 µm) = 1.38 %p` 예측 vs 실측 −1.45/−1.43.
  **물리적으로 달라진 것이 없다.**
* **진짜-crossing 런을 깬다** — real_14처럼 정지가 정당했던 런에 `+2·vmax` 과주행이
  opt-out 없이 붙어 15.93 → **~14.6 %** (−1.3 %p).  검증된 앵커 재현이 깨진다.
* **미신고 부작용** — restart+scaffold 경로에서 새 로그가 찍힌다(동작 불변, 로그-only).
* **"selftest 70/70 PASS"는 빈 검증이었다** — 70개 중 이 경로를 실행하는 테스트 0개.

철회만 하면 1프레임 스파이크 동결 버그로 회귀하므로, **대체**가 답이다.

### 6-2. 대체안

1. **동결-프로브 정지** ★ 핵심
   하강 중 순간 `p + am_skel ≥ target`이 뜨면 그 프레임 **이동하지 않고** `wall_vel = 0`으로
   동결 → S-1 servo·제하 프로브와 **같은 적응 창**(`_srv_left`/`_srv_win`/
   `settle_is_quasistatic`/`_settle_max_srv`, :2509-2545)으로 정지 판독 `p̂`를 얻는다.
   `p̂ ≥ target`이면 **그 높이에서** reached (과주행 0), 미달이면 `reach_cnt = 0` 후 하강 재개.
   `hard_floor` / `am_jam`은 기하 정지라 즉시 유지.  기존 인프라 재사용 → 신규 코드 최소.
2. **접촉 후 감속** — 첫 프로브 발화 이후 `step = 0.25·vmax` (`--compact-to` 관례 :2400-2401
   재사용).  스트로크 분해능 0.8 % → 0.2 %, 과도응답 4배 완화.  두꺼운 베드의 근본 원인
   (v ∝ 베드높이)에 대한 최소 침습 대응.
3. **`--stop-legacy`** — pre-68df3dae 순간 정지 복원.  기존 scaffold 코퍼스 byte-재현용
   (`--servo-legacy` 전례 그대로).  68df3dae 중간 동작은 유효 코퍼스를 생산한 적이 없으므로
   전용 플래그 불요.
4. **selftest 보강** — 정지 판정을 순수 함수로 추출해 스파이크 기각 / 지속 crossing /
   프로브 판정 / floor·jam 즉시성을 고정.  현재 커버리지 0을 메운다.

## 7. ★ 재실행 전 결정이 필요한 것 — dilated 침대

첨가제 침대의 최종 두께가 **씨앗 × λ와 정확히 일치**한다
(`additive_test_campaign_6mAh_real_4.csv`: 125.128 = 112.87 × 1.0711 **EXACT**).
부풀린 두께가 그대로 살아남는 것 자체가 "프레스가 첫 접촉에서 얼었다"는 서명이다.

그런데 dilate 시 **fibre-stiff 스트럿이 드랍**된다(이중계상 방지,
`mpm_input_from_case.py:665`) — 부풀린 침대를 역학적으로 지탱하는 것이 없다.
**프레스만 고쳐서 재실행하면 SBE/DBE 기하가 도로 눌려 붕괴한다.**  따라서 택일:

| 방침 | 내용 | 비용 | 결과 |
