## 층마다 통신을 반복하면 GNN 포텐셜을 여러 GPU로 나눠 돌릴 수 있다

> 통신 반경을 컷오프로 묶고 층마다 통신을 반복해 등변 GNN 포텐셜을 LAMMPS 다중 GPU MD로 확장했다. (L56–58)

### 요점

1. 메시지패싱 GNN 포텐셜을 공간분할로 병렬화하는 알고리즘을 만들어 NequIP 기반 패키지 SevenNet으로 LAMMPS에 구현하고, 결정만 학습한 범용 모델 SevenNet-0으로 대형 비정질 Si₃N₄를 만들었다. (L18–20 · 60)
2. 원문은 32-GPU 약스케일링에서 80 % 이상의 효율을 얻었고, 강스케일링은 GPU가 충분히 채워질 때만 이상에 가깝다고 적었다. (L58–59 · 327)
3. 검증은 평형 근처 test set 오차와 비정질 구조 지표뿐이어서, 고온 에너지와 힘의 정확도나 동역학 물성은 이 결과로 말할 수 없다. (L30–31 · 341–342)

### 넓어지는 수용영역

메시지패싱 GNN 포텐셜은 공간분할 병렬화가 어렵다. 층을 거칠 때마다 이웃 정보를 한 겹씩 더 모으기 때문에, 한 원자가 의존하는 범위가 컷오프 r_c에 층 수를 곱한 거리까지 넓어진다. 엄격히 국소인 MLIP은 경계에서 r_c 안쪽만 주고받으면 되지만 GNN은 그렇지 않다. (L56 · 137–138 · 432–433)

통신 반경을 그만큼 키우는 해법을 원문은 기각했다. 이웃 프로세서가 큰 공통 부분그래프를 가져 중복 계산이 폭증하기 때문이다. 선행 연구에서 MACE를 공간분할로 64 GPU에 돌린 예가 있었지만, 다중 GPU 비용이 커서 매우 큰 계에서만 이득이었다고 원문은 적었다. (L141–143 · 435–437)

- 그림 — Fig. 1: (b)에서 점선원이 층마다 한 겹씩 커지는 모습이 유효 반경이 층 수에 비례해 넓어진다는 뜻이다. (L226)

### 층마다 주고받기

해법은 통신 반경을 원래 r_c로 묶고 대신 층마다 통신을 반복하는 것이다. 한 MD 스텝에서 forward 방향으로 ghost atom의 위치와 원자번호를 한 번, 갱신된 노드 feature h를 T−1번 보낸다. reverse 방향으로는 에너지 기울기 ∇_hE를 T−1번, 마지막에 부분 힘을 한 번 되받는다. 첫 interaction block은 h가 원자번호 embedding이라 통신이 필요 없다. (L144 · 152–153 · 155–156 …)

이 구조에서 통신 데이터 크기는 채널 수에, 통신 빈도는 층 수에 비례한다. 구현은 층 하나를 TorchScript 파일 하나로 나누고 그 사이에 LAMMPS 통신 루틴을 끼웠다. 원문은 직렬과 병렬 실행에서 에너지와 힘이 같음을 확인했다고 적었다. 단일 GPU에서도 SevenNet은 NequIP보다 빨라 1.99 대 1.12 timesteps/s였다. (L165–166 · 450–451 · 453)

- 그림 — Fig. 3: (c)부터 (f)까지가 위치, feature, 기울기, 힘을 차례로 주고받는 통신 스케줄이다. ghost atom은 점선원으로 그려져 있다. (L229)

### 병렬 성능

벤치마크는 α-quartz SiO₂에서 채널 수와 층 수를 바꾼 20개 모델로 했다. 약스케일링은 GPU당 4,608 원자로 고정해 32 GPU에서 147,456 원자까지 늘렸고, 원문은 80 % 이상의 효율을 보고했다. 효율은 8 GPU에서 16 GPU로 넘어갈 때 꺾인다. 노드당 GPU가 8장이라 여기서 노드간 통신이 시작되기 때문이라고 원문은 설명했다. (L58 · 458 · 460 …)

강스케일링은 12,960 원자를 고정하고 GPU를 늘렸다. 원문은 32채널 모델이 32 GPU에서 13.1에서 15.4배 빨라졌다고 적었고, 이는 이상적 32배의 절반 수준이다. 포화의 원인은 GPU당 원자가 줄어 GPU가 덜 채워지는 데 있다고 원문은 보았다. (L97 · 351–352 · 467 …)

- 그림 — Fig. 5: 32 GPU 지점의 speed-up이 이상선에서 얼마나 떨어지는지 보면 된다. 64채널 3층에서 5층 곡선은 단일 GPU 메모리 부족으로 빠져 있다. (L231 · 468)

### SevenNet-0 실증

범용 모델 SevenNet-0은 NequIP 구조를 두 군데 줄여 만들었다. self-connection 층의 텐서곱을 선형층으로 바꾸고 마지막 block의 중복 경로를 없애 파라미터를 16.24 M에서 0.84 M으로 줄였다. 학습은 Materials Project 결정 이완 스냅샷인 M3GNet 데이터셋으로 했고, 액체와 비정질은 들어 있지 않다고 원문은 명시했다. test set 오차는 에너지 25 meV/atom, 힘 0.070 eV/Å였다. (L82 · 123 · 129 …)

이 모델로 112,000 원자 비정질 Si₃N₄를 melt–quench로 만들었다. 5000 K 초가열, 3000 K 평형, 2000 K까지 급랭한 뒤 0 K 최적화를 했고, 전체가 8장의 A100에서 12.7 h 걸렸다. Si 4배위와 N 3배위가 유지되고 g(r)과 g(θ)가 DFT 참조와 부합해, 원문은 이를 일반화 능력으로 해석했다. (L100 · 207–210 · 478)

- 그림 — Fig. 6: 실선이 SevenNet-0, 빈 원이 DFT 참조다. Si–N 첫 피크 위치와 g(θ)의 90° 어깨가 양쪽에서 맞는지를 보면 된다. (L233–234)

### 믿을 수 있는 범위

검토 측은 이 논문이 고온 정확도를 판정할 실험을 하지 않았다고 본다. 정확도는 평형 근처 결정 test set에서만 쟀고, NVE 에너지 보존, 고온 스냅샷의 DFT 재평가, 포논, 동역학 물성이 모두 없다. 2000 K에서 0 K로 건너뛴 근거도 측정이 아니라 주장이라고 검토 측은 지적한다. (L29–31 · 387–388 · 390)

검토 측은 결과 일부가 본문 서술보다 덜 좋다고 본다. 그림을 실측하면 본문의 하한 13.1은 64채널 점이고, 2층 32채널은 약 9.6배라고 검토 측은 읽었다. 응력 오차 0.68 GPa는 M3GNet의 0.41 GPa보다 나쁜데 본문은 언급하지 않는다. 벤치마크가 균질 벌크라 표면과 계면에서의 효율은 원문도 향후 과제로 남겼다. (L85–86 · 363 · 366–367 …)

### 용어 풀이 (논문에 없는 일반 설명)

- **메시지패싱(message passing)**: 그래프의 각 원자 노드가 이웃에서 정보를 모아 자기 상태를 갱신하는 일을 층 수만큼 반복하는 방식이다.
- **공간분할과 ghost atom**: 시뮬레이션 셀을 공간적으로 쪼개 프로세서에 나누고, 경계 너머 이웃 원자를 복제해 와 계산에 쓰는 병렬화 방식이다.
- **약스케일링과 강스케일링**: 약스케일링은 GPU당 일을 고정하고 GPU를 늘리는 시험이고, 강스케일링은 전체 계를 고정하고 GPU를 늘려 얼마나 빨라지는지 보는 시험이다.

### 우리 연구에 주는 뜻

- SevenNet은 우리 UMA와 같은 등변 GNN 계열이라 PES softening 대조군으로 읽었지만, 판정에 필요한 에너지 보존이나 고온 재평가가 없어 우리 T1b 질문은 닫히지 않는다. (L24 · 26 · 28–29 …)
- 원문의 112,000 원자 실행 비용에서 우리가 계산한 처리량은 1.58×10⁶ atom·ps/day per A100이고, 이를 T3-small에 적용하면 ≈89 A100-day가 든다. (L48–49 · 105)
- 5층·5 Å 모델의 수용영역 25 Å은 우리 슬랩 두께 설계의 하한이 되지만, 우리 UMA의 층 수는 아직 확인하지 못했다. (L293–295)

### 읽을 때 조심할 것

- 정확도는 평형 근처 결정 test set에서만 쟀으므로, 고온이나 비평형에서 GNN이 잘 작동한다는 근거로 쓰면 안 된다고 검토 측은 본다. (L89 · 341–342)
- Fig. 6의 일치는 피크 위치에 대한 것이고, 단일 112,000 원자 구조와 112 원자 40개 평균을 비교한 데다 오차막대가 없어 진폭 차이로 경직이나 연화를 판정할 수 없다고 검토 측은 본다. (L378 · 382–384)
- Fig. S2의 MACE 비교는 계와 출처가 다르고, NequIP 대비 속도도 특정 설정과 다른 LAMMPS 버전에서 잰 값이라 일반화하면 안 된다고 검토 측은 지적한다. (L335–336 · 338–339)
- SiO₂ 20개 모델의 정확도와 MD 시간 간격이 보고되지 않아, 설정별 효율 비교는 정확도를 통제하지 않은 결과라고 검토 측은 본다. (L87–88 · 400 · 405)
