# 절별 해체 (본문)

## 초록 (p. 1)

`[인쇄]` SSB 연구와 함께 모의 · 모형 연구가 늘었으니 "the interplay of experiments and simulations and the upcoming dilemma of **drawing general conclusions from increasingly complex model approaches**" 를 돌아볼 때라는 것 · 이 편은 "(microstructure) models for composite cathodes" 에 초점을 두되 "the epistemological considerations and the proposed **tentative agenda** on how to build useful models" 를 다른 고체전지 하위 분야에도 권한다. `[해석]` 초록의 문제의식("복잡한 모형에서 일반 결론")은 27호가 이 편을 인용한 쓰임과 같다(§인용 대조).

## Introduction (p. 1)

`[인쇄]` 물음 넷 — "(How) Are these research questions accessible by models and simulations?" · "Which requirements should these models fulfill? How detailed do they have to be?" · "What interfaces with experiments are there?" · "**How to assure reliability and computational feasibility?**" — 그리고 "It expresses my opinion that can be quite controversial and is not the jack-of-all-trades. It is not intended to deny the importance and progress that rather complex and highly specific approaches offer." 구성: 인식론(모형 · 모의 · 실험) → **Berro[2] 에서 고친 안건**(이 편의 "heart") → Newman 모형 · SSB 모의 지형. "The lion's share of this perspective is reprinted from my cumulative dissertation.[3]"

## Models, Simulations and Experiments (p. 1–2)

- **Similarities and Differences** — `[인쇄]` 모형 = "mathematical constructs accompanied by verbal interpretations"[5] · 해석적으로 못 풀면 "simplification or computer simulation"[6] · 모의 = "approximations of mathematical models, implemented in a software" · Box[4] "All models are wrong, but some are useful." → "All simulations are wrong, but some are useful." · "It is essential to understand the underlying assumptions, the use cases and, correspondingly, the **limits of validity**." 모형과 모의를 따로 다루지 않는다.
- **Useful Models** — `[인쇄]` Truran[6]: "the **verification**, testing and real world application is, what builds confidence and trust into a model. The verification assures that the model is **internally consistent, from the suitability of the assumptions to the correct implementation of the mathematical equations into program code**. The **validation** then checks whether the model is capable of providing the information it is intended for … Is it able to reproduce experimentally measured data under similar model conditions?" · M. Brenner(Möbius & Laan[9] 경유) "If a model does not tell you something new, it needs to go." · LIB 쪽 Franco[14,15]("A model is a more or less lovely imperfect representation of a physical system.") · 세포생물학 · 생물물리의 Berro[2] · Möbius & Laan[9] 가 "when, how and and to which extent" 모의를 쓸지 지침을 냈다 → **Berro 의 9 단계 안건을 고쳐**(그림 1) 1호(전도망 · 도전재 필요 여부)에 적용.

## 안건 9 단계 (p. 3–4 · 그림 1)

1. **Find a good […] question** — 비자명 · 아직 여러 번 답해지지 않은 · 모형으로 다룰 수 있는 물음. `[인쇄]` "If the question can better be answered by an experiment, there is no need for a model.[2] But if there is a chance for a model to become a shortcut for the experiments, it can still be a useful tool." 도전재 물음은 실험(Minnmann[19] · Jiang[20])으로 답할 수 있으나 설계 변수 전체를 훑는 데 모형이 지름길.
2. **Determine the most useful model approach** — 절약(parsimony) · Box "simplicity illuminates, and complication obscures." · Occam · 그러나 "**simplicity is not well-defined** and has to be put into context" — 직선(데카르트 두 점) ↔ 원(극좌표 반지름 + 중심)의 자유도 예[21] · Riesch[21] 의 정성 연구(과학자 다수는 단순성이 쓸모 있다고 보지만 Occam 을 대놓고 거부하는 이도 드물지 않다) · "parsimony does not only make the modelers life easier, but also **avoids overfitting**." · von Neumann(Dyson[22]) "With four parameters I can fit an elephant, and with five I can make him wiggle his trunk." → 권고: "use a **universal approach**, because of its broad applicability and lower computation cost[9] or to focus on a specific phenomenon and stick with **manageable degrees of freedom**." 1호 예: 열화 · 역학 · 온도까지 넣은 전셀 모의도 가능했으나("The road of complexity is endless") "with a rather simple approach of a network analysis … accessible at low computational cost and with **few input parameters**." 가정은 실험에서 온다 — SE 의 전자 전도도 · CAM 의 이온 전도도 무시[23].
3. **Implement the model** — 자체 C 코드 ↔ 상용 인터페이스 · 저자 일화: 미세구조 생성 + Hoshen-Kopelman[24] 를 Matlab[25] 으로 짜다가 "a ready-to-use software available in my vicinity that did the job with less bugs" 를 썼다(그림 1: GeoDict) · FEM ↔ 복셀은 미세구조 과제에 똑같이 맞지 않을 수 있다[26].
4. **Measure reliable model input parameters** — "This is, where a different focus is proposed." Berro 의 원래 단계 "Identify model parameters that fit the data." · 매개변수를 훑어 모형 출력이 실험에 맞을 때까지 = 일반 관행 · **"He warns that a parameter set which produces a good fit is not necessarily the only parameter set that does."** → "while this procedure might be fine in other fields", LIB 전기화학 모형 매개변수화 연구들[27–29]은 "a reliable simulation result can only be obtained when the input parameters are reliable" — "Garbage in, garbage out." → **처방: 시뮬레이션할 재료(조합)에서 입력을 잰다** · 남이 잰 자료는 "with caution and only if the materials are the same". Ecker[29]: CAM 의 Li 확산 계수는 문헌값이 크게 흩어지고 리튬화도 의존을 넣어야 한다 · 층상 NCM 의 확산은 공공 농도 · c 축 팽창 · 전이금속 원자가 · 전자 친화도가 리튬화와 함께 바뀐다[30,31] · Lee[32]: P2D 에서 화학 확산 계수 · 교환 전류 밀도 측정 기법을 비교 — 입력 신뢰도가 결정적. **입력을 못 잴 때**: `[인쇄]` "models can either be simplified, e.g. instead of simulating a full electrochemical cell, relying on a flux-based simulation of the effective conductivity, or to factor out the specific parameter by **making a sophisticated guess that assures this parameter will not affect the simulation result**. Of course, such a step must be explained in detail and with a discussion of the consequences."
5. **Explore the space of free parameters and perform a sensitivity analysis** — `[인쇄]` "Even with a reliable input parameter set, one has to be aware that all input data are limited by their **accuracy and precision**. To get an impression how robust the simulation is with respect to the input parameters, a sensitivity analysis is appropriate. If small changes in a parameter result in large deviations in the results, the particular parameter should be elaborated on." 1호: void · CAM 입도 · 두께 · 조성 스윕 — "Due to the model simplicity, the parameter space was comparably small."
6. **Validate the model** — 통제된 같은 조건의 실험 대조 · P2D 새 구현은 "validated numerically by comparison with an existing well-established implementation … COMSOL[34] or DUALFOIL[35]" · 복잡 기하는 격자 · 복셀 크기 검사(h · p 세분화[36]). 1호: "the main comparison to experimental data was later done by Minnmann et al.[19] However, the effect of the CAM particle size on the electronic conduction network and its utilization degree had already been shown experimentally by Strauss et al.,[37] previously and helped to assure the model suits the intended purpose. **Still, technically, this is rather a qualitative agreement than a full validation.**"
7. **Test alternative hypotheses** — "If a phenomenon can be explained by different mechanisms, one should test the alternative as well to distinguish which hypothesis is most likely to be true. This may require the design of adequate experiments that discard one of the possibilities." (자기 예 수행 여부 — 본문 0 · 그림 1 "(not done)")
8. **Make testable predictions and test them experimentally** — "the best prediction is useless, if it is not experimentally verifiable. – Another argument to keep it simple. – If the model becomes excessively complex, its predictions are unlikely to be concrete, **distinguishable** and verifiable." 1호 예측 "Conductive carbon is not required above a CAM fraction of 68 vol%."[16] → Minnmann[19]: "tested cathode compositions between **25 to 61 vol% NCM622** as CAM and observed that the electronic tortuosity factor goes down to **4.3** for the highest CAM fraction, compared to **120** at 25 vol% NCM622 … high CAM fractions could enable sufficient electron percolation and supersede carbon additives. **This is not the exact same conclusion, but considerably close.**" · Jiang[20] "who further include different CAM particle sizes confirm the model predictions on electronic and ionic percolation."
9. **Repeat** — "Scientific questions reproduce."

## Battery Models — The Newman Model (p. 5–7 · 식 1–6 · 그림 2)

- P2D = Doyle · Fuller · Newman[42,43] · 단일 입자 ↔ 다중 척도 · 노화 · 역학 확장(Falconi[28] 1.4 장 · Ramadesigan[44]) · 핵심은 3D 미세구조를 두 단계로 2D 로 접는 것.
- **유효 미세구조 매개변수** — 공극률 ε("In conventional LIBs the porosity is usually around **30%**.[46]") · 굴곡도 τ = l_eff/l(식 1 · 그림 2) · `D_eff = (ε/τ²)·D_bulk`(식 2 — 본문은 이어서 "denoted as D^ion_bulk", D4) · 3D 에서는 **굴곡도 인자 κ**: `D_eff = (ε/κ)·D_bulk` · "Both, τ and κ as well as their common assessment by the **Bruggeman relation(s)**[47] are **controversially discussed**.[48–51] Commercial LIB cathodes possess tortuosity factors around **4**.[52]" · 활성 표면적 A_s. 이 개념이 이온 · 전자 유효 수송 양쪽에 쓰인다.
- **AM 안 구좌표** — NCM · 흑연은 전자 전도도가 이온보다 자릿수 크다[23] · `[인쇄]` "In theory, the chemical lithium diffusion coefficient D̃_Li (of neutral Li) is the **geometric mean** of both the electronic diffusion coefficient D̃_e and its ionic equivalent D̃_Li⁺" — 식 (3) `D̃_Li = D̃_e⁻·D̃_Li⁺/(D̃_e⁻ + D̃_Li⁺)`(렌더 — 꼴은 직렬 결합 · D2) · 식 (4) 구 Fick(계수 `D_s` — D3) · 식 (5) 중심 무플럭스 `−D̃_Li ∂c/∂r|_{r=0} = 0` · 식 (6) 표면 `−D̃_Li ∂c/∂r|_{r=r_p} = j_n`("current density j_n" — 좌변은 몰 플럭스 · D5). 한계: 입자가 구가 아니다(천연 흑연 판상 · NCM 단결정 팔면체 · 십사면체[53–55] · 2차 입자는 구[56]) · 균질화 가정 — 양산 전극의 바인더(PVDF · NBR) · 탄소(Ketjenblack · Super C65 · VGCF)는 무게 분율은 작아도 밀도 차로 부피가 무시 못 할 수 있다 — `[인쇄]` ρ_PVDF 1.78 · ρ_NBR 1 · ρ_VGCF 1.8 ↔ ρ_NCM **4.76** g cm⁻³(뒤 하나 출처 0) · 제조가 바인더 분포 · 탄소 응집을 바꾼다[60–62] · 나노 공극 침투 미상[63,64] → FEM · 복셀 모의[26].

## All-Solid-State Battery Models (p. 7–10 · 그림 3 · 4 · 표 1)

- `[인쇄]` "In ASSBs the above mentioned issues are supplemented by another component in the electrodes: **Voids.** Other than in conventional cells, the electrolyte cannot wet and penetrate the pores. In ASSBs that feature ceramic or glassy electrolytes, the SE has a particle morphology, even if it is a rather soft material, like the thiophosphate SEs.[65,66] **The assumption that all volume that is not filled with CAM contains electrolyte no longer applies.** This is shown schematically in Figure 3. ## 2. 네 축 판정

- **검증 — 있다, 그러나 이름이 섞였다.** p. 2 Truran 정의: verification = "internally consistent, from the suitability of the assumptions to the correct implementation of the mathematical equations into program code" · validation = 목적 적합 · 실험 재현. 6단계("Validate")의 예 셋 중 **코드 대 코드 · 격자 세분화는 정의상 verification** 이다(D11). 자기 예의 validation 은 정성("qualitative agreement")이라고 저자가 인쇄했다 — 정직하다.
- **실험 연결 — 안건의 중심이다.** 아홉 중 여섯이 양쪽 화살 · "Experiments are an integral part of simulations providing the motivation for simulations as well as the foundation and the credibility." · 4단계 처방 자체가 측정(실험)에 기댄다.
- **불확실성 — 한 문장과 스윕 하나.** "all input data are limited by their accuracy and precision" → 5단계 국소 강건성. 입력 불확도의 전파 · 출력 구간 · 오차 막대 · 앙상블 0 · `uncertaint*` 0. 강건성 스윕이 "큰 반응" 을 찾으면 처방은 "그 매개변수를 더 공들여 재라" 다 — 입력 쪽 처방이고 출력 구간은 없다.
- **식별성(유일성) — 단계가 아니다.** 비유일성은 **Berro 의 경고를 옮긴 한 문장**뿐이고(`[인쇄]` "a parameter set which produces a good fit is not necessarily the only parameter set that does"), 처방은 **적합 삭제**(측정)와, 못 재는 매개변수는 **"결과에 영향 없을 정교한 추측"** 이다. `[해석]` 둘째는 [[assb-sensitivity-sweep-vs-identifiability]] 의 "0 열" 을 실천으로 바꾼 것이다 — 그 출력에 둔감하면 아무 값이나 넣어도 그 출력은 같다. 그러나 둔감은 **본 출력 · 본 조건의 성질**이라, 8단계(미시험 영역 예측)로 넘어가면 그 추측이 다시 결과를 정할 수 있다 — 이 편은 그 조건을 적지 않는다. 판별의 실험판인 7단계는 자기 예에서 수행되지 않았다.

# ★ (d) "단순성" 논지 ↔ 우리 요구서의 유일성 신고

## 1. 단순성의 근거 — 인쇄된 셋

1. **과적합 회피** — "parsimony does not only make the modelers life easier, but also avoids overfitting" + von Neumann 코끼리[22].
2. **작은 매개변수 공간** — "with few input parameters" · "Due to the model simplicity, the parameter space was comparably small." · "The conduction network models do not require a plurality of input parameters and rely solely on the particle sizes, distributions and shapes."
3. **구별 · 검증 가능한 예측** — "If the model becomes excessively complex, its predictions are unlikely to be concrete, distinguishable and verifiable." · 그림 4 "large number of parameters … difficult to draw general conclusions".

## 2. "입력이 적다 → 식별된다" 를 쓰는가 — **아니다**

식별성 낱말이 0 이다(§(a) 3). 이 편은 단순성을 **과적합 · 계산비 · 일반성 · 검증 가능성**의 언어로만 말하고, 유일성은 Berro 경고 한 문장(4단계)에만 나온다. `[해석]` 그러나 세 근거를 우리 요구서(유일성 신고 — 맞는 곡선 ≠ 맞는 분할)에 대면:

- **① 은 자기 예에 닿지 않는다** — 과적합은 **적합한** 매개변수의 문제인데, 1호 전도망은 적합 0 인 기하 순방향 모형이고, 4단계 처방이 적합을 지웠다. 근거(①)는 적합 모형을, 처방(4단계)은 무적합 모형을 본다.
- **② 는 물리 입력만 센다** — 1호 digest 전사로 보면 결과를 정하는 **모형 선택**이 따로 있다: 이용률 40 % 문턱(임의 · 감도 0 — 1호 G6) · SE 3 µm 고정(G3 — 크기비 교락) · AM 겹침 금지 · SE 겹침 허용 규칙 · 200 nm 복셀 · 전이 구간 밖 조성당 배열 1 개(G7) · 접촉 저항 배제(G8). "few input parameters" 는 이 선택들을 세지 않는다.
- **③ 은 척도가 없고, 자기 예의 출력도 유일하지 않다** — 1호 Q4 `[해석]`(digest 전사): `A_spec,a` 봉우리가 평탄해 조성 ±4 vol% 를 못 가르고 두께 20–140 µm 곡선이 최적 근방에서 겹친다 → 단순 모형의 출력 하나로 (조성 · 공극률 · 두께)를 되찾을 수 없다. 단순성은 **매개변수 수**를 줄이지 **출력 → 입력 사상의 단사성**을 보장하지 않는다.
- 그리고 이 편 스스로 단순성의 척도가 좌표계에 따라 바뀐다고 인쇄했다(직선 ↔ 원 — "simplicity is not well-defined"). 식별성도 매개변수화 의존이지만(곱 `A·j₀` 는 어떤 좌표로도 하나), 이 편은 그 연결을 하지 않는다.

## 4. "68 vol%" ↔ 검증 실험 — 같은 기준으로 (`[재현]` — 73호 digest 전사 값)

- **예측의 기준**: 1호 인쇄 "below 69 vol% AM and 31 vol% SE (69/31 vol%)"(20 % 공극 · 균일 5 µm — **고상 기준**) = 전체 부피 55 vol% · `[재현]` 55 / (1 − 0.20) = **68.75** → 이 편 "68"(내림) ↔ 1호 "69"(반올림) — **같은 점**이다(G2 — 문장 자체는 1호 digest 전사에 없다).
- **검증의 기준**: 73호 Φ_NCM = **공극 14 %(가정) 포함 전체 부피 기준**("25 to 61 vol%" = Φ 24.6 · 32.2 · 41.6 · 52.9 · 61.05 · 50–86 wt%) — `[재현]` 고상 기준으로 **28.6 · 37.4 · 48.4 · 61.5 · 71.0 %** · 예측 문턱(고상 68.75 %)을 공극 14 % 전체 기준으로 옮기면 59.1 % → **문턱 위는 맨 위 한 조성**.
- **전자 굴곡도 인자**(73호 `[도표]`): τ²_el 121.5 · 13.7 · 7.47 · 4.73 · 4.34 — 이 편 "120 · 4.3" ✅. 문턱 아래(고상 61.5 %)에서 이미 4.73 → **전자망은 예측 문턱보다 낮은 분율에서 이미 섰다**(조건이 다르다 — NCM622 공칭 3 µm · 14 % 가정 · Li₆PS₅Cl ↔ 1호 균일 5 µm · 20 % · LPS).
- **도전재 대조**(73호 그림 4 `[도표]` 전사 · 0.1 · 0.25 · 0.5 · 1 C): 33 vol%(고상 37.4 %) + VGCF **+14.3 · +19.1 · +16.5 · +13.2 %**(+19.7 · +22.4 · +17.0 · +10.8 mAh g⁻¹) ↔ 61 vol%(고상 71.0 %) + VGCF **−1.6 · −11.0 · −23.5 · −53.2 %**(−2.1 · −8.8 · −10.1 · −8.4 mAh g⁻¹) — **예측 문턱 양쪽에 한 점씩**: "어느 분율 위에서는 탄소가 필요 없다" 는 **방향은 서고**, 그 분율이 68(고상)인지는 **시험되지 않았다**(사이 조성 VGCF 쌍 0).
- ⇒ "This is not the exact same conclusion, but considerably close" 는 **방향 일치**로는 맞고, **문턱 위치**로는 73호 자료가 1호보다 낮은 쪽을 가리킨다(73호 digest "01호와 어긋남 — 같은 방향 네 번째 실측").

## 5. "측정하라" 의 역모형 — 유일성은 측정 쪽으로 옮겨진다 (`[해석]` — 56호 digest 전사)

- **`j₀`** — 56호 Table S2 `[인쇄]`(56호) "calculated from R_CT Rueß et al. (equation 12)" · R_CT = RT/(zFA·j₀) · **A 미정의** → 측정량은 **A·j₀ 곱**이고, `j₀` 를 "잰" 값으로 쓰려면 면적을 가정해야 한다 — 카드의 곱 축퇴([[assb-lampe-contact-product-degeneracy]])가 **입력 측정 단계**에 그대로 있다.
- **`D̃`** — 56호 `[인쇄]` "may be underestimated significantly"(두 전극 EIS 의 음극 몫 혼입 · 3.75–3.9 V 불균일 리튬화 · 고전압 혼화 간극에서 GITT/EIS 가정 붕괴) · 이 편 [32] Lee 2022 가 기법 비교(미열람).
- **미세구조** — 그림 1 4단계 예 "Reconstruct electrodes properties from SEM-images": 2D 단면 → 3D 는 같은 단면 통계를 내는 구조가 여럿이다(재구성 역문제) — 그리고 1호는 실제로 무작위 합성이었다(D8).
- **자기 시험** — 56호 그림 7: 측정 SOC 의존 입력 ↔ 상수 `{D₂, j₁}` 가 같은 곡선 가족을 비슷하게(0.5 C 에서는 상수가 더) 낸다. ⇒ **"적합 0" 은 유일성 문제를 지우지 않고 측정 역모형과 입력 선택으로 옮긴다** — 이 편은 그 이동을 말하지 않는다.

## 새 판단 거리 (셋 — 글자는 호출자가 붙인다)

1. **측정 입력의 역모형 층위 표기 (measure-don't-fit 판)** — 모형 편이 "적합하지 않았다 · 입력을 쟀다(none fitted · measure reliable inputs)" 고 쓸 때, 카드 · 개념 · 합성 truth 로 옮기며 측정 입력마다 **역모형과 그것이 요구한 가정**(면적 · 확산 길이 · ε 규약 · 문헌 OCV)을 값 옆에 적고, 카드 Q3 칸에 "측정(역모형 경유)" 층을 따로 둘지 — 93호: 4단계 처방 · 56호 `j₀` ← Rueß `R_CT`(A 미정의) · `D̃` "may be underestimated significantly" · [32] Lee 2022(기법 의존 — 미열람) · 56호 그림 7(측정 SOC 의존 ↔ 상수 입력 가족이 같은 곡선).
2. **"단순성(입력 수)" 근거 명제의 척도 · 출력 유일성 표기** — "입력이 적다 · 계산비가 낮다 · 일반 결론" 을 모형 신뢰 · 일반성의 근거로 옮길 때 단순성의 척도(물리 입력 수 · 모형 선택 — 문턱 · 해상도 · 겹침 규칙 · 배열 수 · 적합 매개변수 수 · 계산비)와 그 단순 모형 출력의 유일성 검사를 같이 적고, 적합 0 인 모형에 "과적합 회피" 근거를 붙이지 않게 할지 — 93호: "few input parameters" ↔ 1호 모형 선택 다섯(1호 digest 전사) · `A_spec,a` 평탄(±4 vol%) · 코끼리 인용.
3. **모형 결론의 회고 인용 — 조건 복원 규칙** ((치)(애)의 회고판으로 묶어도 됨) — 저자 자신 또는 후속 편이 모형 결론을 요약 · 회고 인용할 때(특히 안건 · 종설), 카드 · 개념으로 옮기기 전에 원 지면의 조건(공극 · 입도 · 부피 기준 · 판정 문턱)을 복원해 붙이고, 검증 실험과의 비교는 같은 기준으로 옮긴 뒤 **"방향 일치 ↔ 문턱 위치 일치"** 를 갈라 적게 할지 — 93호: 본문 "68 vol%" ↔ 그림 1 조건 · 1호 69/31(고상) · 73호 Φ(전체 · 14 % 가정) · VGCF 두 점 → 방향 ✅ · 위치 미시험.

# 이 편이 우리 프로젝트에 주는 것 (정리)

1. **Q4 — "식별" 을 다루는 넷째 방식: 안건에서 지우기.** 26호의 "sensitivity = 스윕" · 34호의 "입력 설계 = 정보량" · 92호의 "identification = 구조 판정" 에 이어, 이 편은 "**유일성은 입력을 재서 피한다**" 다. `degradation-degeneracy/` 가 합성 truth 로 채점하는 "맞는 곡선 ≠ 맞는 성분 분할" 의 관점에서, 측정 입력은 truth 쪽 정보라 방향은 옳지만 **측정이 다시 역문제**(R_CT → `A·j₀` · GITT/EIS → `D̃`)이면 축퇴는 측정 단계에 남는다 — 같은 저자 56호 그림 7 이 그 실례다(우리 쪽 수치는 `degradation-degeneracy/docs/RESULTS*.md` 가 정본 — 여기 옮기지 않는다).
2. **합성 truth 요구 R3 의 원칙을 원저자가 인쇄했다** — "The assumption that all volume that is not filled with CAM contains electrolyte no longer applies." R3 가 우리 쪽 추론만이 아니라 문헌 쪽에서도 서는 요구라는 근거 하나(그리고 같은 저자 56호 검증 구조의 위반과 짝).
3. **공극 입력의 출처 규칙** — truth 에 공극을 넣을 때 "≈15 %" 같은 요약값 대신 출처별 값 · 방법(상 혼합 · 가정 · 분할) · 압착 · SE 입도를 적고, 상수로 두지 않는다(82호 14.1–24.3 % · 55호 수지 + void · 73호 가정 · 4호 FIB-SEM 2.87 → 9.50 % 사이클 성장).
4. **결론의 "유효 매개변수 진화" 제안 = truth 설계의 반례 경고** — `A_s(N)` 로 접촉 손실을 넣으면 R5 없이는 계면 열화와 항등이고, 통째 고립(`θ`)이 갈 자리가 없다(R1). 단순한 확장이 카드 물음을 **truth 단계에서 미리 답하는** 길이 된다.

# 이 digest 가 주장하지 않는 것

1. **단순 모형이 쓸모없다고 하지 않는다** — 1호 방향(고 CAM 분율 무탄소)은 73호 VGCF 대조 두 점과 맞는다(R6). 걸린 것은 조건 · 부피 기준 · 문턱 위치다.
