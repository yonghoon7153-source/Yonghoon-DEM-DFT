### A. Q1 (다) — SV 반사실 괄호 판정 (PRE2-impl-01 · 04)

   - 못 가른 덩어리 (`n_unsplit_bridging_components` > 0) 가 있으면 반사실을 한 번 더 푼다.  이때 그 덩어리 SDCP 셀의 모든 면을 끊는다 (덩어리를 통째로 뺀 판).
   - 기록: 아래 끝 비 (지금 판 · 덩어리 그대로) · 위 끝 비 (뺀 판) · 각 풀이의 증서 · 못 가른 덩어리 수.
   - 위 판에 관통 길이 없으면 위 끝 = +∞ 로 기록한다 (지금의 `no_through_without_sv` 꼴과 같은 방식).
   - 못 가른 덩어리가 0 이면 다시 풀지 않는다.  위 = 아래로 기록한다.
   - 값 봉인: 아래 끝을 보고 건너뛰지 않는다.  덩어리가 있으면 늘 두 번 푼다.
2. 기록 · 사슬 (`scripts/ca_ext_svcf.py` 의 `chain_view` · `sv_cf_problem` · `scripts/rint_r_chain.py` 의 `sv_assess`)
   - 모서리마다: 아래 끝 > 문턱 → `SV_DEPENDENT` · 위 끝 ≤ 문턱 → 표지 없음 · 그 밖 (걸침 · 못 읽음) → `SV_UNCHECKED`.
   - 모서리 묶기는 지금 규칙 ("하나라도") 을 그대로 쓴다.  하나라도 `SV_DEPENDENT` 면 `SV_DEPENDENT`.  아니고 하나라도 `SV_UNCHECKED` 면 `SV_UNCHECKED`.
   - 증서 오차를 문턱 비교에 넣는 방식은 지금 코드의 SV 비교 방식을 두 끝에 똑같이 쓴다.  등록이 정하지 않은 자리면 고르지 말고 보고한다 (지금 방식 유지).
3. 웹앱 · 한정어
   - SV 반사실 줄에 "[아래, 위] · 못 가른 덩어리 n" 을 보인다.

4. 시험 (먼저 · 고치기 전 판에서 실패 확인)
   - 리뷰어 회로 (두 섬유가 같은 덩어리를 지남): 기대 = 괄호 [1.0, ∞] → `SV_UNCHECKED`.
   - 대조 회로 (한 섬유만 지남): 기대 = 지금처럼 끊고 `SV_DEPENDENT`.
   - 괄호 성질: 참 비를 손으로 구할 수 있는 작은 회로 (가를 수 있는 꼴) 에서 아래 ≤ 참 ≤ 위.

   - 리뷰어의 실제 payload 끝-끝 꼴 (`probe2_sv_unsplit_payload.py`) 을 가벼운 회귀 시험으로 옮길 수 있으면 옮긴다.  무거우면 `--long` 쪽에 둔다.
