# DEM gen2 오프라인 생산자·사전등록 초안 한정 검토 요청

검토 핀은 전달 패키지의 SOURCE_PIN/PIN_MAP에 고정된 단일 커밋을 따른다. 변경된 생산자·합성 시험·이 폴더의 문안을 함께 본다. 실제 실행·새 원값·기존 Rint 범위·원장 변경은 요청하지 않는다. 발송은 1저자가 한다.

## 확인할 것

1. 정본 §12의 현재 우선순위가 보존되는가. T5의 단일 1σ 합격 조건이나 k_p=30 보편 안정성이 되살아나지 않았는가. 과학 수치의 null과 합성 fixture 상수가 분리되는가.
2. 7단계 순서, 안정화부터 분리까지 판/벽 fix 신원, R-a 끝 S0, 감쇠 단계 분리와 정적 300 MPa 수지가 구현 설명과 맞는가. 생성된 문안이 미구현 binary/servo/unloading 자격을 통과로 주장하지 않는가.
3. 실제 구현된 합성 기하/제어/보존 guard가 완전한 양성뿐 아니라 잘못된 부호·비유한 값·시간/예산·ID/상 교체·판 경계·결손을 fail-closed로 다루는가. 시험 기대값이 구현 값의 복사본이 아닌가. 아직 구현하지 않은 요구를 명시했는가.
4. 50 kg·0.7/1 µm 비교가 같은 정적 압력·단계·관측 연산자 계약 안에 있고, 미확인 면적/하중 환산이나 과거 “93.4%”/“65%”를 실제 입력·보정 표적·신규 결과로 쓰지 않는가.
5. T5/T11 과학 등록 및 실제 자격, T12 접합, 현장 이력/문법/재개·dt/2, 외부 판정, 연구 실행 GO가 모의 시험과 분리되어 있는가. DEMP-01/02·MV 원장의 물리적 종결로 확대하지 않는가.
6. 비활성 출력의 입구 HOLD와 단계별 필수 정지 include를 단순 실행 플래그나 일반 PASS 토큰으로 우회할 수 없는가. observer→live-deck adapter와 P2 ULPR serializer의 미구현을 숨기지 않고, 생성된 단계 본문을 완성된 물리 파이프라인으로 표시하지 않는가.

## 검토 범위 밖의 미완료

실제 K/지연/제어주기·γ_comp·오차 예산·MC 표본/coverage/반복 규칙, 원 S0·실험 입력·하중 면적·측정 상태, 실제 LIGGGHTS/NP/호스트·시간·디스크 자격, 언로딩 소비 경로와 재개를 이 검토만으로 채우지 않는다. **T12=NOT_RUN, physical_ready=false, 전체 HOLD.** 문서/오프라인 구현 한정 수용을 운영 활성화·재봉인·추가 자료 접근 권한으로 해석하지 않는다.
