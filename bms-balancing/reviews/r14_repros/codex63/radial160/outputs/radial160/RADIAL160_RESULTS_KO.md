# 300/160 단일 5초 계산 결과

**새 300/160 계산 한 번만 완료했다. 지정 표본의 80→160 최대 전압 차는 1.248218114 mV로 1 mV 기준을 넘었고, 표면 x 차는 기준 안이다. 전체 수렴은 미완이다.** 새 최대 시각은 .01초이며, 기존 .04초의 차이 .690286131 mV만으로 통과 판정하지 않았다.

## 비교 범위

새 Caps300R160H0500을 기존 Caps300R80H0500과 비교했다. 기존 Caps300R40H0500은 같은 시각의 세 수준 추세에만 사용했다. 40·80 조건은 재실행하지 않았다. 새 소스는 기준80 소스의 클래스·모델 이름과 두 전극의 Particle Intercalation Nel 값80→160만 바뀌었다. 물리 요소300개(120/60/120), 입자 반경 음극7.5 µm·양극10 µm, 물성·초기 조성·Li 재고·OCP 표는 동일하다.

모두0.1C·sigma=1e-20 S/m, 5초, 동일187개 요청 시각(첫1초107개)과 전극별241개 공간 좌표를 사용했다. 요청 시각이 저장 해에 정확하고 유일하게 있는지 확인했다. 시간 보간이나 근처 시각 대체는 없다. 표면 x=cs/csmax는 COMSOL FE 공간 보간값으로, domain1/3을 분리하고 recover=off·ext=0·timeinterp=off를 유지했다. 분석에서 추가 공간 보간을 하지 않았다. 최대값은 지정 시간·공간 표본의 최대다.

## 실제 메시와 시간 적분

native 로그의 요소 수는300/160/160이며, 물리 mesh API는300 edges·301 vertices, 영역별120/60/120이다. 입자 부모 Nel160·Nord1·CubicRoot도 확인했다. CDI 자유도1202+12 internal은 유지되고 transient 자유도는80요소의21405+12에서160요소40765+12로 증가했다. 입자 메시 계수는 native 추가 mesh 로그와 pin 설정을 근거로 하며 component.mesh API가 입자 요소까지 직접 센 것으로 표현하지 않는다.

| 항목 | 새160 계산의 실제 값 |
|---|---|
| 저장 시각 / accepted 구간 (t=0 제외) | 388 / 387 |
| 초기 t≤.1까지의 구간 / 상한 도달 구간 | 210 / 197 |
| 초기 최대 실제 간격 | 0.00050000000000001 s |
| .1초 이후 구간 / 최대 실제 간격 | 177 / 0.05 s |
| .1초 경계 | .0995→.1: .0005 s; .1→.1005: .0005 s; .1005→.1015: .001 s |
| 상한 위반 / 저장 경계 건너뜀 | 0 / 0 |

상한은 기존 maxstepconstraintbdf=expr, maxstepexpressionbdf=if(t<0.1[s],0.0005[s],0.1[s])를 그대로 사용했다. 이는 [COMSOL 6.3 Time API](https://doc.comsol.com/6.3/doc/com.comsol.help.comsol/comsol_api_solver.51.50.html)의 지원 설정이다. expr 모드의 maxstepbdf=.1은 비활성 상수 슬롯이며, 이후 실제 간격이 반드시 .1초까지 커져야 하는 것은 아니다.

공통 실제 Time 설정은 BDF, rtol=1e-6, initialstep=1e-5초(active=on), strict, tout=tsteps, tstepsstore=1, consistent=bweuler다. scaled/factor 절대허용오차 factor=.1, 수동 scale은 전해질농도1000·고체농도각10000·전위각1이다. 기록된 모든 Time·Variables 속성은80 기준과 동일하다. Study rtol=1e-5 및 manual용 atolglobal=.001의 비활성 설정과 구분한다.

실제 간격은 연속 native 저장 시각의 차이로 계산하고 batch의 index·시각·간격·행 수와 대조했다.1e-12초의 반올림 허용 범위를 명시했다. t=0은 CDI/일관성 초기화 뒤의 상태로 구간 수에서 제외했다. API가 명시하지 않은 내부 식 평가 시점은 추정하지 않았다.

**160요소의 시간 정확도는 별도 입증하지 않았다.** 80요소의 초기 시간반감 결과를160요소의 증거로 대신하지 않는다. 초기 accepted 구간 수는80의209개와160의210개로 달라 완전히 같은 적분 이력도 아니다. 같은 설정·상한 준수는 시간 오차 검증이 아니며, 초기 상한 시험으로 .1초 이후의 시간 정확도도 보증하지 않는다.

## 보호 및 보존

OCP 표·초기 조성·Li 재고·입자 물리 반경은 그대로며3.0524 V에 맞추지 않았다. 네 OCP/entropy 함수는 extrap=none이다. 실시간 StopCondition은 OCP 입력·고체 표면 조성을 감시한다. **전해질 양수는 후처리 검사이고 실시간 음수 중단은 미구현이다.** 저장값의 guard·표면범위·Eeq/실제 반응입력·Li 수지·후처리 전해질 양수는 통과했지만 수렴 기준의 대체 근거로 쓰지 않았다. 기존 job의 failed·INCOMPLETE_RANGE_STOP 및 부분 결과는 보존했고 다른 실패를 같은 분류로 자동 처리하지 않는다.

이전333개 보관 바이트의 수신자 독립 검증 완료는 사용자 확인으로 기록했다. 이것을 현지 현재468개 전체의 원격 검증이라고 표현하지 않는다. 이번에 현지663개 현재 바이트를 별도로 읽어 실행 전 ledger와 일치함을 확인했다. 현지 파일 보존 확인과 전달된 보관 바이트의 동일성은 다른 범위다.
