## 확인한 실패 경로

원 후보에서는 kebase 계산이 성공한 뒤 완료 행 쓰기에 실패해도 후속 소비자가 작업 완료로 받아들였다. 수정 후보에서 독립 검토자는 생성된 셸 구간과 모의 수치 판독기를 사용해 kebase 행과 마지막 end 행에서 각각 실제 쓰기 오류를 주었다. 두 경우 모두 rc2로 종료하고 후속 소비가 거부됐다. 실제형 판독 반환값 2와 120도 정상 전파됐다. 선택 판독 의무는 증서 발행 직전에 고정한 UB 상태를 따른다.

## 수령 검산 및 이전 포장 설명 보완

수령자는 ZIP과 판정문 바이트를 읽어 대조했다. 새 합성 시험은 실행하지 않았다. 증거 ZIP 428파일·427/427 해시, CRC·경로·중복·링크 검사를 통과했다. ZIP 속 검토 입력 315/315파일은 실제 발송본과 동일하다. 원바이트 판정문은 Claude용 전달 ZIP에 동봉한다. 원시 결과에 로컬 경로가 포함되어 리포에는 수령 식별자와 판정만 기록한다. SHA256과 변경 파일명은 `docs/reviews/p1_rt_a5r01_closure_20261120/intake.json`에 있다.

앞 인계에서 축약본의 제외 파일을 하나만 언급했다. 과거 302파일 중 **역사 설명문과 당시 재현 안내서 두 파일**이 빠졌고, PIN·해시 목록·소스 목록 세 파일이 갱신됐다. 축약본에 남은 300파일 중 297파일이 원바이트와 일치한다. 수정 전후의 키트는 각각 143파일 전부 재조립 일치했다. 두 키트의 차이는 A5 러너·증서 소비자·그 해시 목록 세 파일이며 나머지 140파일이 같다.

## 현장으로 넘기는 조건

고정 키트의 목록 SHA256은 `26bdbdc05ba3f6c71a0b042ebd13adb64b38271c1889a894898a4ccf55322f1d`이다. 현장 사전 점검은 367546의 원위치 45파일, 별도 원 문법 영수증, 지정 바이너리, 현재 writer 덱·로그·입력 신원 및 고정 판독기를 대조하는 단계다. 항목이 없거나 다르면 중단하고 그 사유를 돌려받는다. 이전 잡 367546의 최초 FAILED 2:0과 원위치 재판독 20/20은 역사 기록으로 유지한다. 새 RJ의 RT1/RT2·연속성·완료 자료와 탈압 물리 판정은 실제 새 작업 뒤에 평가한다. B의 일반 장부 소비자·실패 및 재큐 이력의 기존 한계도 남는다.
