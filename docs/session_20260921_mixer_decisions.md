## 2. 영률 — 왜 A안인가

**지금 "전 상 1e7" 은 AM 을 14,000배, SE 를 135배 연화**해서 실물 대비 104 가 **1.0 으로 사라졌다.**

| | AM | SE | 비 |
|---|---|---|---|
| 실물 | 1.4e11 | 2.4e10 | 5.8 |
| 18배 연화 (물리 대리) | 1.4e11 | **1.35e9** | **103.7** |
| 압연 덱 (÷1000 단위재척도) | 1.4e8 | 1.35e6 | 103.7 |
| **믹서 A안 (÷135 균일)** | **1.037e9** | **1.0e7** | **103.7** |

= 압연 덱 값 × **7.41**.  `dt` 는 가장 작은 입자(SE)가 정하므로 **SE 를 안 건드리면 비용 0.**

⛔ **기각된 안 (÷14,000 = AM 1e7 · SE 9.64e4)**: 중력만으로 SE 겹침 **5.39 %** = 천장 1 % 를 5배 초과.
   (내가 제안했다가 계산으로 철회.  "10배 싸진다" 도 그 안에서 나온 값이라 무효.)

**겹침 (침대 바닥 응력 221 Pa 기준)**

| 안 | AM_P | SE | dt |
|---|---|---|---|
| 실물 1.4e11/1.35e9 | 0.0004 % | 0.0093 % | 0.101 µs (588 h/팔 — 불가) |
| 지금 1e7/1e7 | 0.249 % | 0.244 % | 1.172 µs |
| **A안 1.037e9/1e7** | **0.011 %** | **0.244 %** | **1.172 µs** |
| B안 1.4e8/1.35e6 | 0.043 % | 0.928 % ⚠ | 3.189 µs (18.9 h/팔) |

**왜 연화해도 되나 — 하중이 136만 배 다르다**: 압연 300 MPa vs 믹서 침대 바닥 **221 Pa**.
믹서의 산출물은 Lacey 혼합도·H/R = **궤적**의 함수이고, 지배 무차원수 `Fr`·`Bo` 에 **E 가 없다**.
조건 둘만 지키면 된다 — ① 겹침 δ/r ≪ 1 (0.24 % < 1 %) ② 접촉시간 ≪ 회전주기 (0.042 %).
★ 점착은 **CED 가 아니라 Bo 를 고정**하므로 E 를 바꿔도 물리가 안 바뀐다.
⛔ 믹서 E 를 물성으로 인용 금지 · 믹서에서 압밀/porosity 읽기 금지 · 압연 겹침과 비교 금지.

## 3. VGCF·PTFE 를 뺀 이유 — 비용이 아니다

| | 값 |
|---|---|
| 실물 VGCF 종횡비 L/Ø | **66.7** |
| 옛 덱의 것 | **2.6** (26배 어긋남) — 섬유가 아니라 짧은 소시지 |
| 진짜 종횡비로 풀면 | 원자 5만 중 **97 %** 를 섬유가 먹음 → AM_P 가 드럼을 4.8 알갱이만 가로지름 |
| 굵힌 채로 두면 | 9.9 % → **빼도 비용 거의 안 줄음** (15.3x → 15.8x) |

⇒ 판단 근거는 **비용이 아니라 "말이 되게 하려고"**.
⚠ 포기하는 것: *"카본이 잘 분산되나"* 는 이 덱으로 못 묻는다 → AM 줄인 작은 도메인 + 진짜 종횡비로 따로.
★ 그래서 섬유 기계를 **지우지 않고** `set_phases(ALL_TYPES)` 로 되살릴 수 있게 남겼다.

## 9. ⚠ `abs_mult` 가 반쪽짜리였다 (2026-09-21 저녁 발견)

오늘 아침 구현은 **목록에 적힌 쌍만** 절대 Bo 로 만든다:

```python
bo = (bo_abs * a['bond']) if bo_abs is not None else (bond0 * a['bond'] * f)
#                                                     ^^^^^^ 안 적힌 쌍은 아직 BOND0
```

`LA` 는 `abs_mult` 에 **AM 쌍만** 있다 ⇒ **SE–SE · AM–SE 는 여전히 `BOND0 × 1`**.
새 덱에서 BOND0 이 0.21244 → 0.37412 (**1.76배**)이므로 **LA 의 SE 점착이 1.76배 세진다** —
아무도 지시하지 않았는데.

⇒ **`abs_base` 신설**: 팔마다 "모든 쌍의 기본 Bo" 를 절대값으로 두고, `abs_mult` 는 덮어쓰기.

| 팔 | `abs_base` | `abs_mult` |
|---|---|---|
| E1 | 0.212 | — |
| E2 | 0.212 | AM 쌍 2.124 |
| E4 | 0.212 | AM 쌍 21.244 |
| LA | 0.212 | AM 쌍 3.0 |

### 검증 — 옛 값을 새 덱에 박아도 겹침 천장을 안 넘는다

(10만 원자 · A안 영률 AM 1.037e9 / SE 1.0e7 · 점착분만)

| 팔 | AM 쌍 Bo | AM_P 겹침 | SE 겹침 |
|---|---|---|---|
| E1 | 0.212 | 0.013 % | 0.076 % |
| E2 | 2.124 | 0.060 % | 0.076 % |
| **E4** | **21.244** | **0.280 %** | 0.076 % |
| LA | 3.0 | 0.076 % | 0.076 % |

중력 겹침(AM 0.011 % · SE 0.244 %)을 더해도 최대 **0.32 %** = 천장 1 % 의 1/3.  ✅

### BOND0 을 움직이는 것 / 안 움직이는 것 (실측)

| 움직인다 | 안 움직인다 |
|---|---|

## 10. 확정된 팔 구성 (1저자 비준 2026-09-21)

**전부 층상 삽입.  기계 팔 0 개 — 씽키·볼텍스는 곡선 위에서 읽는다.**

| 팔 | Bo | 시드 | 역할 |
|---|---|---|---|
| `L0` | 0 | 1 | 지표 상한 (음성 대조) |
| **`LC`** | **0.0235** | **3** | ★ 헤드라인 **코팅** |
| `LB1` | 0.1 | 1 | 사다리 — 씽키 구간 |
| `LB2` | 0.5 | 1 | 사다리 — 유동성 경계 |
| `LB3` | 1.5 | 1 | 사다리 — 볼텍스 `E4` |
| **`LA`** | **3.0** | **3** | ★ 헤드라인 **무코팅** (문헌 앵커) |

**10 런** (4×1 + LA·LC 3 시드; 앞서 11 로 잘못 셌다 — 셀프테스트 ㉞c 가 잡음).  비용은 §13.

### 왜 이 구성인가

1. **교락 해소** — `LA`(3.0) vs `LC`(0.0235)는 **Bo 가 128배** 다르다.  사다리가 없으면
   *"코팅 효과"* 와 *"Bo 를 128배 낮춘 효과"* 를 **구별할 수 없다**.  사다리 위에 `LC` 를
   올려놓고, 곡선 위에 있으면 *"코팅 = Bo 낮추기"*, 벗어나면 *"코팅에 Bo 외 효과가 있다"*.
2. **시드 가중** — 오차 막대가 필요한 것은 *"LA 와 LC 의 차이가 진짜냐"* 를 묻는 **두 팔뿐**.
   사다리 점은 **곡선 모양**을 보는 것이라 시드 1개면 된다.
   ⇒ 균등 3시드(5팔=15런)보다 **점이 많고 비용이 싸다**.
3. **기계 흡수** — 장비 제원이 바뀌어도(볼텍스 45→14 G 같은 일) 곡선은 그대로이고
   화살표만 옮긴다 ⇒ **재실행 불필요**.

### 사다리 덮개 검증

| 기계/조건 | Bo | 최근접 점 | 보간 거리 |
|---|---|---|---|
| 코팅 | 0.0235 | 0.0235 | **1.00×** |
| 씽키 앵커 | 0.0112 | 0.0235 | 2.10× |
| 씽키 `E4` | 0.0793 | 0.1 | **1.26×** |
| 볼텍스 앵커 | 0.2143 | 0.1 | 2.14× |
| 볼텍스 `E4` | 1.5174 | 1.5 | **1.01×** |
| 무코팅 앵커 | 3.0 | 3.0 | **1.00×** |

점 사이 최대 간격 **5.0×**, 최악 보간 **2.14×**.

## 11. 씽키 G — ⬜ **미확정, 그러나 결론에 영향 없음**

**확정**: ARM-310 공전 200–2,000 rpm · 자전 = 공전의 **40 %** (2000 → **800**, 우리 문서와 일치) ·
제조사 표기 **"over 400 G"**.

**미확정**: 우리 **268 G** 가 함의하는 공전 반경 **59.9 mm** 의 **1차 출처가 없다**
(우리 값에서 역산한 것이라 순환).  제조사 페이지·매뉴얼 PDF 는 **egress 차단**으로 못 봄.

**그런데 결론이 안 바뀐다** — G 가 112 든 268 이든 400 이든 425 든, 씽키는 **사다리점
0.0235 와 0.1 사이**에 떨어지고 전이 경계 0.5 에서 한참 아래다:

| G | `E4` 기준 Bo | 앵커 기준 Bo |
|---|---|---|
| 112 (컵 안쪽) | 0.1897 | 0.0268 |
| **268** (우리 문서) | 0.0793 | 0.0112 |
| **400** (제조사) | 0.0531 | 0.0075 |
| 425 (컵 바깥) | 0.0500 | 0.0071 |

⛔ **원고에는 점이 아니라 띠로 쓸 것**: *"씽키 = Bo 0.007 ~ 0.19 (앵커~E4 기준 ×
컵 안 위치 편차), 전이 경계 0.5 대비 최악에도 2.6배 여유"*.
유성형은 컵 안에서 G 가 위치에 따라 변하므로 **단일 숫자 자체가 근사**다.

### 왜 — 마찰은 `Bo` 앵커와 **한 세트**다

`LA` 의 `Bo = 3.0` 은 `hare2026` 의 γ 0.25 J/m² 에서 나오는데, **그 γ 는 측정값이 아니다**.

실제 분체의 **bulk 유동성**을 재현하도록 맞춘 유효값"* (**정적/동적 안식각 + Schulze 전단셀**).

⇒ γ(→Bo 3.0)는 **안식각·전단셀로 역산된 값**이고, 그 역산은 **μ_s 0.9 · μ_r 0.075 에서** 이뤄졌다.
⇒ 마찰이 다르면 같은 γ 가 다른 안식각을 낸다 ⇒ **Bo 3.0 이 그 분말의 유동성을 뜻하지 않게 된다.**
⇒ **우리 분말 안식각을 따로 잴 필요가 없다** — 그 보정이 이미 앵커 안에 들어 있다.
⛔ 다만 **한 개만(Bo) 가져오고 나머지를 우리 값으로 두면 세트가 깨진다.**  그게 채택 전 상태였다.
