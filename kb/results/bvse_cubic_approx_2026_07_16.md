# BVSE 큐빅 근사 — "이상화 셀" 지적 대응 + LPSOCl 첫 BVSE (2026-07-16)

**계기** 6월 cubic 버전(`b2o3_lpscl16_cubic_bvse.cube`)은 프로토타입 대칭 자리(4.842/14.526… 반복, 50원자)에 조성만 얹은 **이상화 셀**이라 "실제 구조가 아니다"라는 지적을 받음.
**해결** `tools/comp1_v3/bvse_faithful_cubic.py` — 실제 격자가 fcc-프리미티브 스택(a≈7 Å, 60°; c=5×/10×)임을 이용, 관습 큐빅 벡터를 **실제 격자벡터의 조합**(C₁=A₂+p₃−A₁ 등, p₃=A₃/N)으로 만들고 **실제 완화 원자(주기 이미지)를 그대로 접어 넣음**. BVSE 값은 큐빅 그리드에서 **원본 주기 결정 맵을 리샘플**(A-셀 최소상 거리) → 이음새 인공물 0, 박스는 "표시/샘플링 창"일 뿐. 채널% 기준은 원본 맵 전역 최소.

## 검증 (원본셀 재현)
- modelc 원본: 1.23/3.32/8.36/13.44/17.85 % (iso 0.25–2.0) — **6월 등록값과 완전 일치**.
- b2o3 원본: 6.73/12.22/17.09/21.25 (0.5–2.0) — 7월 csv와 일치 (0.25는 7월이 보간값, 직접계산 3.83이 정확).

- 대표(벌크형) 박스는 원본을 ±1.3 %p 안에서 재현 → **표현(셀 프레임)에 결과가 안 묶임**.
- **LPSOCl 첫 BVSE**: 4.74% — O 도핑도 채널을 열고(+43% vs undoped), B₂O₃(+103%)의 중간. perc onset a/b/c = 0.55/0.35/2.05 val².
- **b2o3 국소성**: 도펀트 중심 박스 23.8% ≈ 벌크 4배 → 채널 확장은 B₂O₃ 주변에 집중. 단 도펀트 없는 벌크 박스(S16 Li23 P3 Cl7)도 6.2% ≫ undoped 3.3% → **격자 전체가 열린 위에 국소 확장이 얹힌 구조**. 7월 "in-plane open / c-axis 도펀트 병목" 분석과 정합.

## 한계
BVSE는 경험적(valence², eV 아님) — 상대비교 전용. 큐빅 박스는 진짜 주기가 아니라서 박스 경계에서 등고면이 잘려 보임(시각 전용); 정량은 항상 원본셀 값을 인용.
