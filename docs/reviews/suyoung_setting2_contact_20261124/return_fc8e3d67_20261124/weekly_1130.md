# 11월 30일 주간보고 · 수영 2D

입자를 누를 때 계산한 힘이 격자를 더 촘촘하게 해도 재현되는지 확인했다. 입자 사이의 틈을 반영하고 아래판에 닿는 입자 표면의 힘을 이웃 물질점들이 나누어 전달하도록 수정했다. 아래판 압력이 처음 1.2 MPa에 도달했을 때 12칸과 16칸의 충전율 차이는 0.00416으로 허용값 0.005 이내였다. 그러나 같은 판 변위에서 압력 곡선의 최대 차이는 8·16칸에서 79.25%에서 80.02%로 커졌고, 12·24칸에서는 19.25%에서 17.07%로 줄었다. 두 쌍 모두 허용값 5%를 넘었다. 충전율은 비슷해도 가압 중 힘이 전달되는 과정은 격자에 따라 달라져, 이 수정으로는 단면 변형과 3차원 결과 해석으로 넘어가기 어렵다고 판단했다.

그림. 입자 지름당 격자 수에 따른 1.2 MPa 도달 시 충전율. 격자마다 초기 배치 한 개를 사용했다. 서로 다른 초기 배치 사이의 산포는 미측정이다.
