# 기록 변경 이력

- 사용자 승인: Astra High 수준의 수신 기록·NEXT_RUN_PLAN 정리 및 다음 시험 제안까지만. 새 계산 승인 없음.
- 수신 첨부 원문과 생성 영수증의 변경 없는 사본, 변경 전 계획서를 별도 보관했다.
- 생성 ZIP의 현재 크기/SHA와 사용자의 수신 식별을 대조했다. 원래 ZIP·영수증·기존 B 보고서·두 소스·기존 범위 실패 폴더 파일·job JSON 중 LOCAL_PRESERVATION_CHECK에 나열된 파일의 전후 바이트가 같다.
- 현지 기존 B 결과 보고서나 원시 CSV를 수정하지 않았다. 수신 측의 독립 재계산은 사용자 보고로 기록하며 이번 로컬 재계산으로 서술하지 않았다.
- NEXT_RUN_PLAN을 시험별 입증 범위·한계·수신 보존 범위·승인 대기 후보 C로 갱신했다. 시간 이력이 실제 같았다는 관측을 명시했다.
- 후보 자원2400초는 제안이다. COMSOL 호출·제출·실행용 Java 생성0회, 추가 job 폴더0개다.
- 본 소형 전달 ZIP은 기록 변경분만 담는다. 원래 B ZIP/MPH/CSV 전체 또는 역사적333개 보관 바이트의 새 전달본이 아니다.
