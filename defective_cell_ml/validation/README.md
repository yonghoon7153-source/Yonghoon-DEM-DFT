# 배포 전 검증 기록

검증 자료는 모두 가상 입력이다. 실제 배터리 원시 자료가 없어 실측 성능·성능 개선 폭·외부 배치 일반화는 검증하지 않았다.

| 확인 | 결과 |
|---|---|
| 입력/분할/출력/예측 자동 테스트 | 34개 통과 |
| 기본 전체 후보 중첩 검증 | 가상 12셀, 3개 타깃 완료 |
| 원시 TXT/MPT 변환 → 그룹 평가 | 완료 |
| 변환 CSV → 동일 그룹 평가 | 원시 입력 경로와 OOF 예측 일치, rtol=1e-8 / atol=1e-12 |
| 배치 분리 | 용량·CC 비율·Logistic의 안쪽/바깥 그룹 비중복 확인 |
| 결과 파일 | 3개 실행 각각 11개 Excel 시트, 유한 예측, 혼동행렬 분모 12, 출력 해시 일치 |
| 정답 없는 EIS → 저장 모델 추론 | 새 ID 12개 예측 완료. ID만 바꾼 가상 특징이므로 독립 성능 검증이 아님 |
| 원본 ZIP | SHA-256 보존 확인 |

환경: Windows, Python 3.12.14, NumPy 2.3.5, pandas 2.3.3, scikit-learn 1.7.2, SciPy 1.16.3, openpyxl 3.1.5, joblib 1.5.2, threadpoolctl 3.6.0. `pip check`에서 의존성 충돌이 없음을 확인했다.

`release_verification.json`에 명령, 환경, 검증 항목, 실제 시험한 Python 파일의 SHA-256이 있다. 7개 명령의 로그를 동봉했다. `01_unit_tests.log`는 개별 테스트 결과다. 실행 경로는 이식성을 위해 `{package}`, `{validation_output}`으로 표시했다. 라이브러리 버전과 테스트 데이터 생성 seed는 고정했다. 완전히 다른 OS/라이브러리의 비트 단위 동일성까지 보장한 검증은 아니다.

최종 ZIP을 별도 폴더에 풀어 수행한 배포 검증 결과와 ZIP 해시는 ZIP 옆의 최종 검증 보고서에 기록한다. 큰 가상 실행 결과·모델 바이너리·가상환경은 ZIP에 포함하지 않았으며 `tests/verify_release.py`로 재생성할 수 있다.
