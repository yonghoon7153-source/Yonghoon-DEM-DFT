### 셋 공통 양식 (11-25 · 신호로 잰 값)

- 틀 = 앞서 잰 레퍼런스 A 와 화소 단위로 같다 (바탕 · 남보라 · 자막 상자 7.9 % H · 가운데 y 90.4 % H · 자막 글자 4.0 % H).
- 장 카드 ≈ 4 s (점 줄 + 명사구 제목 · 그동안 자막 없이 음악만) · 도입 29–45 s (날짜 있는 사건 · 숫자 → 반전 → 물음 → "오늘은 … 보겠습니다") · 장 7–12 · 장 길이 중앙 55–65 s · 끝 = 시청자 물음 · **다음 편 예고 없음**.
- 화면 변화: 구성 바뀜 분당 7–8 (길이 중앙 5–7 s) · 변화 없는 화면 최장 ≤ 4 s · 자막 하나에 쌓기 ≈ 1 번 (자막 시작 0.7–0.8 s 뒤).
- 자막: 한 줄 · 컷으로 바뀜 · 글자 중앙 16–18 (최대 25) · 길이 중앙 1.7–1.9 s.
- 소리: −14 LUFS · 7.9–8.1 음절/s · 문장 끝 쉼 중앙 0.25 s · '?' 를 단 물음만 끝이 오른다 · 음악 깔개 처음부터 끝까지 (−27 ~ −32 LUFS) · 효과음은 못 찾음 (없음이 아니다).
- 우리 ep01 v3.2 와 다른 곳 (같은 검출기): 화면 변화 분당 27.6 (레퍼런스 62–64) · 변화 없는 화면 최장 7.5 s · 장 카드 없음 · 음악 없음 · 6.7 음절/s.  어느 것을 따를지 = 1저자 (장 카드 · 샷 쪼개기 · 음악 곡과 라이선스).
- 따르지 않을 것: 빠르고 고른 말과 짧은 쉼 · 1인칭 강사 화법 · 판매 · 다른 편 홍보 · 남의 화면 캡처 (쓸 때는 1저자 확인 뒤 · 출처 줄) · 사건 · 사람 이야기로 여는 갈고리 (우리는 날짜 · 숫자 있는 문헌 발견으로 연다).

## 보이스

- 레퍼런스 = 남성 음역 (F0 중앙 133–140 Hz) · A 와 셋 모두 같은 목소리 · TTS 로 보임 [추정] · 도구 · 목소리 이름 = ⬜ 모름 (1저자).
- 우리 = Typecast 문정 (F0 234 Hz) · 빠르기 1.0 (6.7 음절/s) · 레퍼런스의 고른 쉼은 따르지 않는다.
- 이 환경에서 쓸 수 있는 TTS = 공개판 = Typecast API (세션 프록시 · `docs/avi/tools/avi.py` voice-auto · 스킬 §7-1) · 내부 자료 편 = 로컬 TTS (MeloTTS 기본 · 스킬 S6).  키는 채팅에 붙이지 않는다 (세션 자격 증명 양식으로).

## 영상을 만들 때 순서

- AVI 영상 = 스킬 `.claude/skills/avi-generate/SKILL.md` 의 정본 순서 (S0–S11 + S9b).
- 그 밖의 영상:
  1. 이 문서를 읽고, 빈 칸이 있으면 먼저 1저자에게 묻는다 (짐작으로 정하지 않는다).
  2. 레퍼런스의 구성 (장 길이 · 자막 꼴 · 전환) 에 맞춘 대본 초안 → 1저자 확인.
  3. 화면 (그림 · 3D · 애니메이션) → 보이스 (레퍼런스 보이스) → 자막.
  4. 렌더 → 1저자 확인 → 고침.
- 그림 · 글자 원칙은 `docs/report_making_principles.md` 와 CLAUDE.md 의 논문 · 그림 · 발표 원칙을 따른다.
