# ADR 0003 — 시계열은 디스크, 요약만 DB

- 상태: 채택 (2026-08-20)
- 관련: `apps/api/app/storage.py`, `apps/api/app/models.py`

## 맥락

파일 하나가 148k 행 × 22 컬럼이다. 1000 사이클 실험은 파일 여러 개로 쪼개지므로
셀 하나가 수백만 행이 된다. 이걸 관계형 테이블에 넣으면 셀 50개에 수억 행이다.

한편 "3번 셀 유지율" 같은 질문은 **사이클 요약**만 있으면 답한다.

## 결정

- **시계열**: 파싱 결과를 `data/runs/<run_id>/columns.npz` 로 압축 저장.
  numpy 가 그대로 읽고, 컬럼 단위 접근이 빠르다.
- **요약**: 사이클/스텝 지표만 SQLite 에 넣는다. 목록·필터·정렬이 여기서 돈다.
- **원본**: `data/uploads/<sha256>.wrd` 를 그대로 보존한다. 파서가 좋아지면
  언제든 다시 파싱할 수 있다 (`POST /runs/{id}/reparse`).

## 결과

- 셀 목록과 비교 화면은 DB 만 읽는다. 즉시 뜬다.
- 프로파일 화면만 npz 를 연다. 필요한 사이클 구간만 슬라이스한다.
- 백업이 단순하다: `data/` 디렉터리 + `workbench.db` 파일.
- 대가: DB 와 디스크가 어긋날 수 있다. 정합성을 미리 검사하는 장치는 없고,
  조회 시점에 npz 가 없으면 원본(`.wrd`)에서 자동 재생성한다
  (`services.load_wrd_columns` → `storage.reparse`). 원본까지 없으면
  `FileNotFoundError` 로 드러난다.
