# DEM 수영 — P2G 시도·폐기·복원 계약 초안

## 1. 범위와 바탕

단계1/S-F 설계 db5abe6b359abdc44b3c17bb91d984a5fee3a567, 손 계산 사례 ede6170502ca9f41635e6656234b99427e445924를 연결한다. 이 문서는 solver 구현·수치 동결·실제 재색칠/복원 시험이 아니다. 실제 입력0·연구/현장0·전체 HOLD. 적용 대상은 3D 색칠 장 재사용 제안이며 2D F의 입자별 독립 장을 색 재사용으로 바꾸지 않는다.

권고안 전제(DTX-Q1): 한 걸음의 실패는 그 걸음의 모든 임시 기여를 폐기하고 마지막 완결 상태에서 다시 준비한다. 구체 허용폭/최대 시도 수/장 수/자원 한도는 미정이다. 이 권고로 자동 재시도 구현이나 연구 실행을 승인하지 않는다.

## 2. 상태 소유권

| 객체 | 최소 내용 | 쓰기 규칙 |
|---|---|---|
| C_n 완결 상태 | step/time, 입자/물질점 ID·소속·질량/원부피, 위치·속도·변형/응력·소성 내부 상태, 강체 위치/속도/회전, 경계/접촉 이력, RNG/진행 단계 | 시도 동안 불변; 실제 모델에 없는 필드는 비적용 근거, 필요한 필드는 누락 불가 |
| A_(n+1,k) 시도 | 부모 C_n 신원, 같은 목표 step/time, attempt k, 점 이동 예산, 색/장/노드 소유 표, 임시 grid·trial point/history·판 반력/수지 누적 | 한 시도 전용; C_n에 직접 누적하지 않음 |
| K 색 계획 | 원 입자→색, 생성 기준 상태, 예산·주기·노름·커널·순서·용량 신원 | 색 번호는 입자 ID가 아님; 계획 변경을 새 신원으로 남김 |
| M 자원 계획 | old/new 계획·graph·grid·point/history 사본·rollback·sort/통신/검증/입출력 임시·runtime 여유의 동시 생존 구간 | 누락 비용0 처리 금지; 공유 메모리는 수명/별칭 근거 없이 이중 차감하지 않음 |
| C_(n+1) 새 완결 상태 | 모든 등록된 검사·필수 필드·단계가 완결된 A의 결과, 부모 신원과 유일한 commit 표시 | 마지막에 한 번 교체하는 설계. 파일 atomicity·내구성 구현 증명은 아직 없음 |

RNG 또는 이력 업데이트가 시도 중 일어나면 실패 전 C_n의 해당 상태도 유지해야 한다. grid만 비우고 trial 응력/반력/소성 변수·RNG 진행을 남기는 복원은 불충분하다. 실제 사용 필드 목록은 구성식/접촉/경계 구현 선택 뒤 닫는다. 빈 JSON을 완결 상태로 인정하지 않는다.

## 3. 상태 전이

| 출발 → 도착 | 조건 | 반드시 남길 것 | 금지 |
|---|---|---|---|
| COMMITTED → PRECHECK | 부모 신원·입력/정책·점 소속·자원 계획 확인 | C_n 보존, 목표 n+1 및 시도번호 | 시작과 동시에 step/time 증가 |
| PRECHECK → RECOLOR_PREP | 마지막 색칠 이후 점 이동 예산 초과 | 병진/회전/변형·주기 근거 | 판 이동만으로 통과 |
| PRECHECK → P2G_TRIAL | 예산·용량·필수 필드 확인 | 시도 전용 기여·소유 표 | 이전 시도의 grid 재사용 누적 |
| P2G_TRIAL → DISCARD | 같은 색·같은 노드의 서로 다른 원 입자 기여 발견 | 충돌 원 ID·색·노드·시도, C_n 불변 | 충돌 셀만 지우고 나머지로 G2P |
| DISCARD → RECOLOR_PREP | 모든 시도 상태 폐기 확인 | C_n와 같은 시간/이력/RNG에서 새 계획 | 실패 시도 응력·반력·난수 진행 승계 |
| RECOLOR_PREP → PRECHECK | 새 색/용량/peak 통과, 등록된 유한 시도 예산 남음 | attempt 증가, 목표 step/time 그대로 | 실패 시도 수 초기화·무한 반복 |
| ANY_TRIAL → TECH_FAIL | 용량/메모리 부족·불명 상태·등록된 시도 한도 도달 | C_n와 실패 원인·부분 산출 구분 | 부분 결과를 완료로 쓰기·자동 증설 |
| P2G_TRIAL → PHYSICS_TRIAL | 노드 소유 충돌0·등록 P2G 수지/완전성 충족 | 같은 공통 커널의 구성식/외력/경계/접촉/G2P 검사 | P2G 통과만으로 물리 단계 PASS |
| PHYSICS_TRIAL → COMMIT_READY | 전체 등록 검사·필드·완료 조건 충족 | 부모 C_n 신원 재대조 | 실패/미확인을0 또는 정상으로 채움 |
| COMMIT_READY → COMMITTED | 부모가 여전히 같은 버전이고 단일 소유자가 교체 | step/time 한 번 증가, 시도별 감사 연결 | 동시 변경된 부모 위에 덮어쓰기 |

새 색 계획을 만들기 전 old/new가 함께 살아 있는 구간의 peak를 판단한다. ‘먼저 old를 지우면 메모리가 된다’는 선택은 rollback 근거를 잃으므로 별도 구조/증명 없이는 허용하지 않는다. 병렬 구현의 가시성·원자 교체·예외 중 메모리 회수는 구현 후 별도 자격이다.

## 4. ID·격자 계약

원 입자 ID는 소속 의미, point ID는 물질점의 고유 신원, field ID는 계산 장 할당, node ID는 경계/주기 규약으로 정한 격자 신원이다. 좌표가 같아도 ID를 합치지 않는다. 출생/소멸/분할/병합은 이번 계약 밖이며 별도 규약 없이 ID 재활용하지 않는다. 경계 이미지가 같은 원 점을 중복 계상하지 않는 규약도 고정해야 한다.

합성 입력 예: C_n의 point 목록 (point7→particle2, point8→particle3), 두 점이 같은 색0/노드4에 양의 질량 기여 → DISCARD. 물리 질량 합 보존만으로 두 입자가 한 장에 섞인 오류를 허용하지 않는다. 노드 소유 표가 비어 있는 것을 충돌0의 증거로 삼지 않으며 P2G 전체 기여와 표 집합을 대조한다.
