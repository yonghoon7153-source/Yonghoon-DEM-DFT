## 2. PRE8-02 실제 로딩 코드와 출처

원 외부 반례인 import 후 analyse 진입 전 디스크 sentinel 변경과 새 프로세스 대조를 다시 확인한다. 의존 코드는 해시한 소스 bytes를 직접 compile/exec한 별도 모듈 집합이어야 하며, 이미 로드된 전역 모듈과 .pyc를 읽어 고정 출처를 우회할 수 없어야 한다. 내부 import·지연 import·함수 별칭·생성기의 자기 소스 재읽기도 같은 소스 집합에 결속되어야 한다.

observer 자기 코드는 기록한 bytes를 컴파일한 코드와 실행 중 module code의 동등성을 확인하는 경계다. 주석만 다른 역사적 원문의 bytes를 유일하게 복원했다는 뜻은 아니다. 기록 해시는 실행에 결속한 고정본이어야 하며 진입/반환에서 현재 디스크와 다르면 TECH·값 제거여야 한다. 초기 소스 경계 실패도 contact 모듈의 예외 클래스가 없다는 이유로 새 예외를 내며 빠져나오면 안 된다.
